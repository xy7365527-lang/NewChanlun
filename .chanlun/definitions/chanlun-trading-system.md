# 缠论交易策略体系

## 存在论位置

缠论不是以盈利为主旨的交易系统，而是通过区间套和短差操作把成本降为0甚至负数的操盘方法。
这与外部金融工程（ATR止损、Kelly仓位、最大回撤百分比控制）有根本性的存在论差异：

| 维度 | 缠论体系 | 外部金融工程 |
|------|---------|-------------|
| 目标 | 成本归零 → 挣股票 → 大级别卖点清仓 | 控制单笔亏损 / 最大化期望收益 |
| 退出依据 | 买入程序的判断条件被否定（走势从能搞变不能搞） | 固定点数/百分比/ATR倍数 |
| 仓位逻辑 | 不往上加码，只在下跌中买入；短差不增加仓位 | Kelly公式 / 固定风险比例 |
| 风控本质 | 操作级别的买卖点系统本身就是风控 | 独立于交易系统的风控层 |

**核心命题**：在缠论中，风控不是独立模块，而是买卖点系统的内在属性。

## 概念1：退出条件（替代"止损"）

### 原文依据

> "从来不存在真正的止蚀问题，只存在股票是否依然在能搞的范围内的问题"（第13课）

> "一旦变为不能搞，就立刻从买入程序中退出，这个防护的启动是和任何盈亏无关的，只和当下的走势有关"（第13课）

### 严格定义

退出条件 = 买入程序的判断条件被否定。具体分类：

**第一类买点介入后的退出条件**：
> "一旦上涨时依然出现男上位的缠绕，那么一定要退出。因为第一个买点买入的基础在于男上位最后一个缠绕后出现背驰，而现在又出现男上位的缠绕，意味着前面引导买入程序启动的缠绕并不是最后一个缠绕"（第13课）

翻译为缠论形式化语言：
- 触发条件：在操作级别上，买入后的上涨走势中再次形成同级别中枢（缠绕）
- 含义：背驰判断的前提被否定（"最后一个缠绕"的判断错误）
- 动作：退出

**第二类买点介入后的退出条件**：
> "一旦该缠绕中出现跌破前面男上位的最低位，就意味着买入程序出现问题，必须在任何一个反弹中把股票出清"（第13课）

翻译为缠论形式化语言：
- 触发条件：当前走势跌破前一个下跌趋势的最低点
- 含义：第二类买点的成立条件被否定（不是有效的缠绕转折）
- 动作：在次级别反弹中退出

**第三类买点介入后的退出条件**：
- 触发条件：回试跌破 ZG（中枢上沿）
- 含义：第三类买点的成立条件被否定
- 动作：退出

### 与外部"止损"的根本区别

缠论退出条件是**买入逻辑的否定**，不是价格偏离的度量。
- 外部止损：入场价 - N 点 / 入场价 × (1 - N%) → 与走势结构无关
- 缠论退出：买入程序的判断条件被否定 → 与走势结构直接相关

## 概念2：资金管理——成本归零策略

### 原文依据

> "一个最简单又最有效的管理，就是当成本为0以前，要把成本变为0；当成本变成0以后，就要挣股票，直到股票见到历史性大顶，也就是至少出现月线以上的卖点"（第31课）

> "买股票，宁愿不断跌不断买，也绝对不往上加码"（第31课）

### 严格定义

资金管理分三个阶段，每个阶段有不同的操作规则：

**阶段一：成本 > 0（降成本阶段）**
- 操作：用机动资金（如总仓位的 1/10）做短差
- 约束：每次短差，买入数量 = 卖出数量，**不增加持仓总量**
- 目标：通过短差利润降低持仓成本
- 原文："每次短差，一定不能增加股票的数量，这样，成本才可能真的降下来"（第31课）

**阶段二：成本归零（翻倍出半仓）**
- 触发：股票达到1倍升幅附近
- 操作：在大级别卖点出掉部分仓位，使剩余仓位成本 = 0
- 原文："在股票达到1倍升幅附近找一个大级别的卖点出掉部分，把成本降为0"（第31课）

**阶段三：成本 = 0（挣股票阶段）**
- 操作：利用每一个短差，上面抛了以后**全部回补**
- 约束：卖出多少资金就买入多少资金，**仓位持续增加**
- 目标：股票越来越多，成本永远为0
- 终点：超大级别卖点出现时一次性清仓
- 原文："利用每一个短差，上面抛了以后，都全部回补，这样股票就越来越多，而成本还是0"（第31课）

### 与外部仓位管理的根本区别

- 外部仓位管理：每笔风险 = 账户 × N%（Kelly/固定比例）→ 独立于走势结构
- 缠论仓位管理：仓位变化由走势阶段决定（降成本→归零→挣股票）→ 与走势结构直接耦合

## 概念3：短差程序

### 原文依据

> "缠中说禅短差程序：大级别买点介入的，在次级别第一类卖点出现时，可以先减仓，其后在次级别第一类买点出现时回补"（第14课）

### 严格定义

短差程序 = 在持仓期间，利用次级别买卖点做波段操作以降低成本。

- 操作级别：N 级别买点介入
- 短差级别：N-1 级别（次级别）买卖点
- 减仓点：N-1 级别第一类卖点
- 回补点：N-1 级别第一类买点
- 约束（成本>0阶段）：减仓数量 = 回补数量（不改变总仓位）
- 约束（成本=0阶段）：回补金额 = 减仓金额（仓位增加）

### 递归性

短差程序本身可以递归：
> "如果资金量小，不是按周线的，第一类、第二类买点都是最多按日线的，就可以相应在30分钟等更小的级别内找到第一类卖点而弄出短差来"（第14课）

即：操作级别为日线时，短差在30分钟级别；操作级别为30分钟时，短差在5分钟级别。

## 概念4：区间套精确定位

### 原文依据

> "一定要从大级别往小级别看，用区间套的方法"（第29课）

> "首先看大级别的背驰段，然后再按区间套的方法看小级别来精确定位"（第29课）

### 严格定义

区间套 = 从大级别确定方向，逐级缩小到小级别精确定位买卖点。

- 大级别确定：当前处于上涨/下跌/盘整的哪个阶段
- 中级别确认：背驰段是否出现
- 小级别定位：精确的买卖点位置

区间套是缠论风控的核心机制——通过多级别确认，降低单一级别判断错误的风险。

## 概念5：操作级别与风控的统一

### 原文依据

> "在你的操作级别上，你是不参与任何调整或下跌走势类型的"（第35课）

> "介入的关键是你明白你的风险在哪里，能承受多少，怎么退出"（第10课）

### 严格定义

操作级别的选择本身就是风控决策：
- 操作级别越大（周线/月线）→ 容忍的波动越大 → 短差空间越大 → 成本归零越快
- 操作级别越小（5分钟/1分钟）→ 容忍的波动越小 → 适合小资金快速周转

风控 = 在操作级别上严格执行买卖点系统 + 在次级别上执行短差程序。
不存在独立于买卖点系统的"风控模块"。

## 边界条件

1. 本定义在以下条件下需要修正：
   - 发现缠师原文中有独立于买卖点系统的风控概念 → 需要补充
   - 发现缠师原文中对"止损"有不同于第13课的定义 → 需要重新审视

2. 本定义不覆盖：
   - 具体的均线参数选择（缠师未给出统一标准）
   - 资金分配到多只股票的比例（缠师说"一开始就应该研究好"但未给出公式）
   - T+1 制度下短差程序的具体执行方式（需要 T+0 或隔日操作）

## 下游推论

1. `src/newchan/risk/` 模块不应存在——风控是买卖点系统的内在属性，不是独立模块
2. 回测引擎需要支持的是：短差程序模拟、成本归零追踪、多级别联动
3. 退出条件的代码实现应在 BuySellPoint 判定逻辑中，不在独立的 StopLoss 类中
4. 仓位管理的代码实现应追踪"当前阶段"（降成本/归零/挣股票），不是固定比例计算
