### 1.4 定义要素三条（从 `027:44/:46` 直读）

2. **递降轴 ＝ 级别（大→小）**。
3. **产出 ＝ 转折点／买卖点的精确位置**。

## 2. 【N-3】名分收束：区间套 ＝ 纵向级别下钻，只有这一个义

### 2.1 教义条款

> **区间套 ＝ 从大级别往下，用逐级的背驰段收缩范围，把转折点定位准。**
> **纵向一个方向，没有横向义。**

**名分 `[旧缠论]`**。承重：`027-第27课.md:44`【正文】（该课正文界 `:78`，`:44` 在其内）。

**「区间套正本 ＝ 算子 N」不成立。**

### 2.2 五条理由（按承重排序，首条不是「原文没有横向义」）

1. **并列两者等于新造一个同名异物**（最硬的一条）。缠师的区间套有定理原文；代码的横向义**原文零出处**。把两者塞进同一个名字下，是**制造**混淆而非消除混淆——本正本的职责恰恰相反。
2. **原文只有纵向**。110 课全量检索：`区间套` 命中 35 文件／101 处，其中【正文】层 **27 处全部**是级别下钻；`板块`／`选股` 与 `区间套` **零共句**。
3. **那个「统一」在代码里不承重**（三条实测）：
   - `nesting_type` 字段**生产代码零读取**（唯一出现在 `src/newchan/nesting/nesting_operator.py:33` 声明处 + 测试 kwarg）；
   - 跑 [#804](https://github.com/xy7365527-lang/NewChanlun/issues/804) 总缝判别式——同一份数据分别标 HORIZONTAL／VERTICAL 喂进去，四个判定函数**输出逐位相同** ⟹ 方向这个区分不起任何作用；
   - 约束①（级别单调 `k_{i+1} ≤ k_i`）在横向**恒可取等号**、约束②（搜索空间 `|S|` 非增）在纵向**恒取等号** ⟹ **「统一算子」＝两条互不相交的约束做合取**，各自在另一支上退化为恒真；docstring 自陈的「纵向收缩**时间范围**」在 `NestingStep` 五个字段（`nesting_operator.py:33-37`）里**根本没有载体**。
4. **两者是串接不是并列**。横向第六步字面就是「标的内**纵向区间套**」（`src/newchan/nesting/horizontal.py:34`）；教义源自陈「**先横向收缩到标的，再纵向收缩到时机**」。先 A 后 B ⟹ 不是同一算子的两个实例，是流水线的两段。
5. **「算子 N」名分不够**。唯一出处 `tmp/levels-bsp-v2-push.md:205-230`——按 [ADR 0012](../../docs/adr/0012-inference-layer-document-naming.md) 三段式，在 `tmp/` **连推论层都不算**；`docs/adr/` 与 `.chanlun/definitions/` **各 0 命中**。拿无名分抽象当 `[旧缠论]` 概念的正本，方向反了。

### 2.3 连带条款：缠师是**借**「区间套」这个词，不是在用数学的闭区间套定理

**`027:40`【正文】** 缠师自陈「这些级别**不是无限下去的**，因此理论上并不能去证明就是一个如极限一样的点状情况的出现」；`027:50` 重申「不可能达到数学上唯一一点的精度」。

⟹ 闭区间套定理的前提（区间列**无限**且长度→0）**被他自己否掉了**。

### 2.5 ⚠️ ADR 0011 的「横向」与代码的「横向」＝ 同名异物（须点名，防第 6 次）

六栏对照**无一重合**：

| | ADR 0011 `:21`「横向」 | `nesting_operator.py:22`「横向」 |
|---|---|---|
| 轴 | **时间轴**（同一标的、同一级别切时间） | **标的/资产轴**（同一时刻收候选集合） |
| 输入 | 一层已造好的走势类型序列 | 一组比价线（配置空间／独立边／板块／标的） |
| 输出 | 该层走势类型分段 | 一个 target 标识（角／国家／板块／标的） |
| 递归 | **无**（ADR 0011 `:85` 明写「同级别分解是一次性切分」） | 六步 ＝ 同一操作六次应用 |
| 实装 | **本仓尚无实现**（ADR 0011 `:86` 明写） | 有（`horizontal.py`，`pipeline.py` 在消费） |

**这是本仓已登记的第 5 处同名异物**（前四：① 声部 vs 重；② 三阶段实例单位；③ 操作级别 vs 结构级别；④「次级别」的配仓义 vs 定位义）。**序数「第 5 处」把握中等**（依据是已成文的四处，`analysis/` 480 份里若另有未成文登记会变）；**序数不承重，同名异物这个判定承重**。

### 2.6 「横向落在 ADR 0011 三格之外」的推论

ADR 0011 三格是「纵向向上 = 塔／纵向向下 = 区间套／横向 = 同级别分解」。`nesting_operator` 的横向**落不进任何一格**——它不造级别、不读某层走势分段、不打点、不管筹码。它做的是「这一重该挂在哪个标的上」，即 **L-选标的**层，与区间套（L-判定层）分开列。

⟹ **「算子 N」这个名字承载的是选标的，它把「区间套」这个词借去当自己的名，借错了。**

#### 3.5.3 裁定的载体形态

**不产出一条更短的新序列**，而是**保持原始 K 一根一根都在、序号都在**，每根额外挂上「**所属标准化组的组号**」+「**该组标准化后的高低**」。

**收益**：
- **(a) 与 (c) 直接消掉** —— 原始序号→组号一步得，组号→成员集合一步得，且跨语言可共享同一载体。
- **(b) 消不掉但变成明账** —— 组标记带「**已确认／暂定**」状态位，与 `fractal.rs` 现行的增量纪律（前缀不动、只重算尾部两组）同源，只是抬到地基层。

**代价**：多一份与原始 K 等长的标注（每根几个整数），**判断逻辑一行不改**。

#### 3.5.4 ⟹ 正本硬要求（一句）

2. **第二层 —— 到过现在的底才有资格（前置不变）**：修完 SPEC [#847](https://github.com/xy7365527-lang/NewChanlun/issues/847) 的 **S4-a**（方向判据拿外缘启发式凑，实测下钻失败头号原因 63.79%）与 **S4-b**（背驰判据只有趋势背驰入口，盘整背驰进不来）→ 复用 [#852](https://github.com/xy7365527-lang/NewChanlun/issues/852) 那套失败分类**重测下钻深度** → **确认断链主因已从「判不出背驰」转为「到底了」**。
   > **一句判据：没到过现在的底，就没有资格说现在的底太浅。**

#### 4.5.4 ★ 次序护栏（硬条款）

本图排序原则「**打扫干净屋子再请客 —— 接实盘排在统一之后**」**不变**。在案实测（[#792](https://github.com/xy7365527-lang/NewChanlun/issues/792)）**目前没有任何一条路在拿缠论信号实盘下单**。

> **⟹ 高频是这条线的终点定位，不是下一步。本裁定不得被引作「现在就该去接实盘」的依据。**

### 4.8 可达性：「停在哪一级」在生产上**从没被问过** ⟹ 当下零行为改动

**本条依 map [#787](https://github.com/xy7365527-lang/NewChanlun/issues/787) Notes N-1 预授权判定**（伪分歧，举证到行）。

六条载体只有 **②** 真在生产 π 上：

```
fill.rs:4851  interp::coverage_elements_and_gamma_with_tower_cached_gen(...)   ← π fill loop
   → interp.rs:1256  nest_confirmed: nest_confirm(lvl, point.source_index, &point.bits, dir)
   → interp.rs:586   nest::chi_bool(level, &chain)
```

**而它被 `interp.rs:580/:581/:586` 的单元素链字面量塌缩成一个 bit**（逐字复核成立）：

| 退化 | 保证它的那一行 | 后果 |
|---|---|---|
| 链恒为**单元素** | `interp.rs:580` `let chain = [NestLevel { … }];` | `chi_bool` 恒走 `[last]` 分支，`[head, next, rest @ ..]` **永不进入** |
| `ev` 与 `chain[0].lvl` **同一个变量** | `interp.rs:581` `lvl: level` ＋ `:586` `chi_bool(level, …)` | `last.lvl == ev` **恒真，不可否证** |
| `cands` 恒**非空** | `interp.rs:582` `cands: vec![Interval::new(…)]` | `last.chosen().is_some()` **恒真** |

**⟹ 链长度永远是 1，「末级是哪级」从未被求值。**

其余五条：**①⑤** 唯一入口 `decompose_capturable_spread`（`econ_positive.rs:229`）的**全部**消费者在 `#[cfg(test)]`（`:1814` 起的 `mod tests`，消费点 `:3369/:3969/:3970/:3984/:3985/…` 全部落在其内）＋ 一个集成测试（`rust/tests/econ_oddeven_diagnosis.rs:55`）；**③** 门控默认 false 且 `trading_system/` 零引用；**④** HTTP 端点默认 `"false"`（`src/newchan/server.py:432`）。

> **⟹ 本组裁定当下零行为改动，作用是给 SPEC [#847](https://github.com/xy7365527-lang/NewChanlun/issues/847) 抬验收线。**

#### 4.8.1 ★ 承重的是这六行可达性举证，**不是 [#852](https://github.com/xy7365527-lang/NewChanlun/issues/852) 的 d≥2=0**

后者量的是「**开了会怎样**」（那个诊断在 `#[cfg(test)]` 里主动调用了生产默认不走的路径），且它**自陈的邻域口径没测** —— 若允许次级别一类点落在背驰段区间内而非与 `src` 端点重合，窄口径的 0 可能变非 0，**一改口径分歧就变真**。

**⟹ 「因为钻不动所以无所谓」这个说法不成立。** 钻不动是 ⑥ 一条链上、一种坐标口径下、一个基底配置下的读数，它撑不起对四说法的判定。

### 4.9 耦合硬约束：N-2 的实施侧被 N-5／N-6 挡着

**X1（停执行级）不能独立落地**，两道门：

1. 要它生效，先得让生产产出**长度 > 1 的链** —— 那是 **N-6**（保证单元素的那一行就是 `interp.rs:580`）。
2. 链长 > 1 后**每级都要算 `Cand^δ_ℓ`**，而它**无定义式** —— 那是 **N-5**（`classifier/nest.rs:331-332` 自陈「`Cand^δ_ℓ` 定义式缺失见 spec 疑点2（[需人工确认]）」）。

> **⟹ N-2 的实施侧被 N-5／N-6 挡着，教义侧不受影响。** 「N-2 裁完就生效」是错觉。
