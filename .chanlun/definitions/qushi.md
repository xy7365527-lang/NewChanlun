## 存在论位置

趋势和盘整是走势类型（Move）的两种**特化子类型**，不是简单的字符串标签。

- **构造层**（第33课）：只有中枢。"盘整、趋势这些概念，其实没有也可以的，唯一有效的就是中枢的概念。"
- **分类层**（第17课）：趋势和盘整是对中枢构造结果的实体化解读，拥有中枢层面不存在的涌现属性。

两层不矛盾——构造层提供基础，分类层提供操作语义。类比：化学中"分子由原子构成"，但水和盐酸是不同物质，有不同性质。

## 定义

### 走势类型三分法 [旧缠论]

> "任何级别的所有走势，都能分解成趋势与盘整两类，而趋势又分为上涨与下跌两类。" — 第17课

> "走势类型三种：上涨、下跌、盘整。上涨、下跌合起来叫趋势。" — 第17课答疑L606

- **二分法**：走势 = 趋势 ∪ 盘整
- **三分法**：走势 = 上涨 ∪ 下跌 ∪ 盘整
- 二分法与三分法中的"盘整"是同一对象（009号定理结论）

### 盘整（Panzheng / Consolidation）[旧缠论]

> "缠中说禅盘整：在任何级别的任何走势中，某完成的走势类型只包含一个缠中说禅走势中枢，就称为该级别的缠中说禅盘整。" — 第17课

**核心特征**：
- 中枢数量：恰好 **1 个「相应级别的」中枢**（限定词由 #815 M-1 补上，见下「#815 M-1 裁定」节——**计数永远相对于指定级别，从来不是绝对的**）
- 方向：**无**（第31课L390："盘整哪里有什么方向，只有趋势才有方向，这是最基本的概念。"）
  - 数据模型中 `Move.direction` 字段在盘整时填充中枢的 `break_direction`（突破方向），这是技术性标识字段，用于前端展示和走势连接定位，不表示盘整走势类型本身的概念方向
- 完成条件：3个连续次级别走势类型重叠形成中枢后即可完成，但可无限延伸
- 延伸机制：围绕同一中枢 [ZD, ZG] 反复震荡，不产生新中枢
- 背驰类型：**盘整背驰**（力度衰竭不一定终结走势）

### 趋势（Qushi / Trend）[旧缠论]

> "缠中说禅趋势：在任何级别的任何走势中，某完成的走势类型至少包含两个以上依次同向的缠中说禅走势中枢，就称为该级别的缠中说禅趋势。该方向向上就称为上涨，向下就称为下跌。" — 第17课

**核心特征**：
- 中枢数量：**≥2 个「相应级别的」中枢**（依次同向；限定词同上，#815 M-1）
- 方向：**有**（上涨/下跌）
  - 上涨：后DD > 前GG（中心定理二，第20课）— **外缘**分离，#815 M-2 裁定，见下
  - 下跌：后GG < 前DD（中心定理二，第20课）— 同上
- 完成条件：2个依次同向中枢形成后即可完成，但可无限延续
- 延伸机制：不断产生新的同向中枢
- 背驰类型：**趋势背驰**（必然终结趋势）
- 内部结构：a+A+b+B+c（A/B为中枢，a/b/c为连接段）— 第37课

### 趋势中枢间约束 [旧缠论]

> "缠中说禅走势中枢定理一：在趋势中，连接两个同级别'缠中说禅走势中枢'的必然是次级别以下级别的走势类型。" — 第18课

> "趋势中的中枢之间必须绝对不存在重叠。" — 第18课L28

- `017-第17课.md:44`【正文】逐字：「缠中说禅盘整：在任何级别的任何走势中，某完成的走势类型只包含一个缠中说禅走势中枢，就称为该级别的缠中说禅盘整。」

  **⚠️ 层级订正（本次落盘时查出）**：#815 的 M-1 定案 comment 把这一句标为【正文】，**标错了**——`031-第31课.md` 的 `---------↑正文---------` 标记在 `:32`，`:390` 在其后，属**答疑**。裁定结论不因此翻，因为 `017:44` 这条**正文**定义句自身即带级别限定（「就称为**该级别的**盘整」）；但正本不得沿用错误的层级标注。名分仍 `[旧缠论]`（答疑亦为缠师本人所写，非注家）。
- **两处「级别」作用位置不同**：`017:44` 的「该级别」指*这个盘整属于哪一级*；`031:390` 的「相应级别」指*数哪一级的中枢*。**两处合看 ⟹ 级别不是外挂条件，是定义自带的。** `[新缠论:推论]`（推理链：定义句自带级别归属 + 复述句自带计数级别 ⟹ 计数与级别不可分离）。
- **延伸不增计数** `030-第30课.md:92`【答疑】逐字：「其实没必要考虑什么头肩顶。中枢扩展有精确的数学定义，在一个中枢还延伸的时候，只有一个中枢，不存在中枢1、2的问题。」；`018-第18课.md:44`【正文】：「而对于盘整来说，其"延伸"就在于不能产生新的……」
- **扩展不放宽计数，而是升级别** `033-第33课.md:196`【答疑】逐字：「盘整+盘整还是盘整，但加多了就是级别大的盘整，这没有什么问题。盘整还有一个级别的问题。」；`023-第23课.md:188`【答疑】：「但两个中枢并没有形成趋势，只形成了中枢的扩展。只有中枢的新生才能形成趋势的。」

## #815 M-2 裁定：两中枢「同向」＝ 外缘分离（后 DD > 前 GG）（2026-08-03）

**裁定原文**（[#815](https://github.com/xy7365527-lang/NewChanlun/issues/815) M-2 定案 comment；考据底稿 `.chanlun/review-results/issue815-m2-same-direction-doctrine-20260803.md`）：

> **两个同级别中枢「依次同向」（构成趋势）的判据 ＝ 外缘分离：后 `DD` > 前 `GG`（上涨）／后 `GG` < 前 `DD`（下跌）。**
> **核心分离（`后 ZD > 前 ZG`）但外缘仍重叠 ＝ 中枢扩展，升一级，不是趋势。**

名分 `[旧缠论]`。

### 决定性依据：中心定理二把两种边界写在同一句里，分工明确

`020-第20课.md:58`【正文】逐字：

> 「缠中说禅走势中枢中心定理二：前后同级别的两个缠中说禅走势中枢，后GG<前DD，等价于下跌及其延续；后DD>前GG等价于上涨及其延续。后ZG<前ZD且后GG>=前DD，或后ZD>前ZG且后DD=<前GG，则等价于形成高级别的走势中枢。」

| 条件 | 原文判 | 用的量 |
|---|---|---|
| 后 DD > 前 GG | **上涨及其延续（趋势）** | **外缘** |
| 后 ZD > 前 ZG **且** 后 DD ≤ 前 GG | **形成高级别走势中枢（扩展）** | 核心 + 外缘 |

**⟹ `ZD`/`ZG` 在定理里出现了，但它管的是「是不是扩展」；管「是不是趋势」的那一支，明写用 `DD`/`GG`。** 这不是从两个候选里挑了一个，是**原文把两个都写出来并各自指派了角色**。

**两条旁证**：

- `018-第18课.md:28`【正文】逐字末句：「注意，趋势中的缠中说禅走势中枢之间必须绝对不存在重叠。」——「绝对」是强化不是对冲。
- `017-第17课.md:1146`【答疑】读者逐字问的就是本组争点：「２、两个同向中枢能否的轻微重叠，假如是一个向上的趋势，第二个中枢的下边与第一个中枢的上边有重叠，这种……」→ `017-第17课.md:1150`【答疑】缠师答：「这将会构成高一级别的中枢。而在本级别中，也将这看成一个中枢。在一个趋势中，中枢之间是绝对不重叠的。」
  **⚠️ 只作旁证**：读者所说的「上边／下边」**原文未明说是核心还是外缘**，不得当作判据依据。
  **但它另有一处硬价值**：末半句「在本级别中，也将这看成一个中枢」**直接支撑上节 M-1**——外缘重叠 ⟹ 本级别看成一个中枢 ⟹ 那段是盘整。**M-1 与 M-2 在此合流。**

## 趋势 vs 盘整：差异属性

| 属性 | 趋势 | 盘整 |
|------|------|------|
| 方向 | 有（上涨/下跌）| 无（数据模型中填充 break_direction 作为技术性标识）|
| 中枢数量 | ≥2个（同向）| 恰好1个 |
| 背驰类型 | 趋势背驰（必然终结）| 盘整背驰（不一定终结）|
| 延伸机制 | 产生新同向中枢 | 不产生新中枢 |
| 内部结构 | a+A+b+B+c | 单中枢 + 围绕震荡 |
| 力度度量 | 趋势力度、趋势平均力度 | 无专属度量 |
| 中枢间约束 | 不重叠 | 不适用 |
| 转折后续 | 三种结果（级别扩展/更大盘整/反趋势）| 第三类买卖点 → 趋势或更大盘整 |
| 买卖点关系 | 第一类买卖点=趋势背驰点 | 盘整背驰不产生买卖点 |

## 趋势的生命周期

1. **诞生**：第一中枢后出现第三类买点并形成非背驰类向上（第107课）
2. **形成确认**：至少两个依次同向走势中枢形成（第17/18课定义）
3. **存续/延续**：同向中枢不断产生（第18课）
4. **背驰预警**：a+A+b+B+c 中 c 段力度弱于 a 段（第24/37课）
5. **终结**：趋势背驰确认（第29课背驰-转折定理）
6. **中阴阶段**：趋势终结后到新走势类型确立前的模糊阶段（第88课）

---

## 盘整的生命周期

1. **形成**：三个连续次级别走势类型重叠（第17课）
2. **延伸**：后续 Z走势段与 [ZD, ZG] 有重叠（中心定理一）
3. **终结方式一**：次级别走势离开中枢后回抽不回 → 第三类买卖点（第18课定理三）
4. **终结方式二**：与同级别另一中枢波动区间重叠 → 级别扩张（第20课）

## 边界条件

### 正常情况
1. **最小构成**：任何走势类型至少3段次级别走势（走势分解定理二）
2. **趋势最小构成**：至少2个同向中枢 → 至少5段次级别走势
3. **盘整最小构成**：恰好1个中枢 → 至少3段次级别走势

### 翻转条件
- 当前判定为趋势的走势类型，如果两枢波动区间重叠 → 级别扩张，非趋势
- 当前判定为盘整的走势类型，如果新中枢同向产生 → 升级为趋势
- 如果引入 Trend/Consolidation 子类型 → `Move.kind` 字符串标签方案失效

### 级别扩张（第20课）
- 两个同级别中枢波动区间重叠 → 形成更大级别中枢
- 当前级别走势终结，成为更大级别中枢的一部分
- 判定条件：`(后ZG < 前ZD ∧ 后GG ≥ 前DD) ∨ (后ZD > 前ZG ∧ 后DD ≤ 前GG)`
