### 0.3 三范式的关系：既不是包含链，也不是对称互不包含

```
P1 ∩ P3 = ∅        P2 ∩ P3 = ∅        （P3 孤立）
P1 ⊄ P2   ∧   P2 ⊄ P1   ∧   P1 ∩ P2 ≠ ∅   （互不包含且交非空）
```

**五笔手算样例**（考据给出）：同一条 5 笔序列上 **P1 = {[0,2], [2,4]}**（每段恒 3 笔），**P3 = {[0,1], [2,3], [4,4]}**（每段恒 2 笔）⟹ 两者段边界全不同。
P2 在同序列上可给出 `{[0,4]}`（一段 5 笔）—— P2 能出 5 笔段而 P1 不能；P1 能在无特征序列分型处切段而 P2 不能 ⟹ **互不包含**；两者在「恰好 3 笔且特征序列分型落在第 3 笔尾」的序列上重合 ⟹ **交非空**。

> **未测**：上述见证是**手算，未实跑**。见 §16。

### 第65课 (2007-07-16) — 笔破坏定义（关键转折）

> 「对于从向上一笔开始的，其中的分型构成这样的序列：d1g1d2g2d3g3…dngn……如果找到i和j，j>=i+2，使得dj<=gi，那么称向上线段被笔破坏。」

### 第67课 (2007-08-01) — 特征序列法（核心创新）

- **特征序列**：向上段取向下笔（X序列），向下段取向上笔（S序列）
- **标准特征序列**：对特征序列做包含处理后的序列（`067:20`【正文】，归约到普通K线包含 ⟹ §2）
- **第一种情况**（无缺口）：分型出现即终结
- **第二种情况**（有缺口）：`067:38`【正文】须第二特征序列出分型才终结；`067:46`【正文】「只要有分型就可以」（⟹ §3）
- **缺口封闭**：`067:170`／`:196`【答疑】（⟹ §4）

### 第71课 (2007-08-16) — 包含关系作用域与第一种情况的两种结局

> 「从上面的分析就可以知道，从转折点开始，如果第一笔就破坏了前线段，进而该笔延伸出三笔来，其中第三笔破点第一笔的结束位置，那么，新的线段一定形成，前线段一定结束。」（`071:30`【正文】，界 `:46`）
>
> 「这种情况还有更复杂一点的情况，就是第三笔完全在第一笔的范围内，这样，这三笔就分不出是向上还是向下，这样也就定义不了什么特征序列……这种情况，无非两种最后的结果：1、最终还是先破了第一笔的结束位置，这时候，新的线段显然成立，旧线段还是被破坏了；2、最终，先破第一笔的开始位置，这样，旧线段只被一笔破坏，接着就延续原来的方向，那么，显然旧线段依然延续，新线段没有出现。」（`071:32`【正文】）
>
> 「假设某转折点是两线段的分界点，然后对此用线段划分的两种情况去考察是否满足，如果满足其中一种，那么这点就是真正的线段的分界点；如果不满足，那就不是，原来的线段依然延续，就这么简单。」（`071:38`【正文】）
>
> 「特征序列的分型中，第一元素就是以该假设转折点前线段的最后一个特征元素，第二个元素，就是从这转折点开始的第一笔」（`071:40`【正文】）
>
> 「这里还要强调一下包含的问题……在这假设的转折点前后那两元素，是不存在包含关系的……但假设的转折点后的顶分型的元素，是可以应用包含关系的。」（`071:42`【正文】）
>
> 「这一笔不是严格地属于前一段的特征序列，属于待定状态」（`071:26`【正文】）；「特征序列的元素要探讨包含关系，首先必须是同一特征序列的元素」（`071:28`【正文】）

- **转折点两边不能包含**；**转折点后可以包含**；**第三笔在第一笔范围内 ⟹ 待定，结局由 b 的两个端点哪个先被破决定** ⟹ §7.1

   确认只依赖第一次出窗，前缀确认不回退（第二种情况同，第 8 条）；增量层不因本条扩大回退面；checkpoint 安全边界沿 #1344 第四问（最早 OPEN 候选所在段起点之前）。
2. **转折点前后两元素不做包含（`[旧缠论]`，`071:42` 第一句、`071:26`、`071:28`；Lean `formal/Origin/SegmentFeatureSeq.lean:270-271` `BoundaryNoInclusion`）**：入元素与末标准元素互含且入元素在段方向上更极端时，它是可能的转折点中元素，二者为 (a,b)，不合并。实现不得以「当下是否凑出分型」决定合不合并（v1「先试不合并」在两句上都反，#1487 E1／E2 为在案反例）。
3. **转折点窗（`[新缠论:推论]`，链：`071:32`「定义不了什么特征序列」+ `071:42` 第二句 + #1490 原型反例）**：c ⊂ b 时 c 记为 b 的**窗成员**（保留身份与区间），不做包含合并，b 的区间就是窗；窗结束（确认或作废）后 b 保持自己的区间。不得按 G-2 方向性把成员折进 b：`dir_state` 在互含后不更新，陈旧方向会改写 b 的极值一侧并伪造缺口（#1490 原型随机组 48：b.low 8190→8215，使下一候选的 `a.low > b.high` 成立）。G-2 对非假设处的同序列互含（末元素不是峰候选）照常适用，本条不是 G-2 的第二档（#799 核：分派条件是「末元素是否峰候选」，非严格／宽松）。退场条件：正本原文或 Lean 给出 c ⊂ b 期间的并入定义式且与本条不同时，以其为准并开新规则版本。**本条只管第一种情况**（#1493 裁定 2：窗的依据 `071:32`「分不出是向上还是向下」在「最早破坏那笔就是转折点下来的第一笔」这一前提下成立，`071:26`；有缺口时见第 4 条）。
4. **第一种情况的确认判据（`[旧缠论]`，`071:30`／`:32`；并列口径同 #1343 Q1）**：候选 b 的 `CONFIRMED` ⟺ 此后某根与 b 同向的笔 c 在 b 终点一侧严格越过 b 的终点，且 c 在 P 一侧的极值不超过 P（破 = 严格越过，相等不是破）。向上段 `b.high > a.high ∧ c.high ≤ b.high ∧ c.low < b.low`，向下段镜像。这是唯一判据，不是 067 分型谓词加例外：在无并列输入上它与 067 严格分型谓词（Lean `IsTopFractal`／`IsBottomFractal`）逐位等价（推导见 #1490 DECISION Q2-c；等价性由叶片性质测试锁承载），并列（c 的 P 侧极值与 P 相等）由本判据直接裁决。缺口按 `071:40`（a、b 之间）判；有缺口 ⟹ 第二种情况，仍走 067 严格分型 + 第二特征序列，一字不改；此时并列元素记为 b 的窗成员（第 3 条）。有缺口时 c ⊂ b（入元素被峰候选 b 包含，含与 b 相同、含 P 侧相等而另一侧更窄）按 G-2 方向性合并区间，合并元素的代表笔保持 b——段端 = b 前一笔终点 = P，第二序列自 b 起（`[新缠论:推论]`，`067:20` 标准特征序列、`067:38` 段端在分型极值、`071:42` 第二句、`078:54`；#1493 裁定 2）。旧 G-2 把代表笔改成 c 会使段端离开极值（违 `067:38`），窗成员不做包含会使落在 b 内、在段方向反侧高出 c 的后续笔不能与合并元素成分型（违 `067:20`）。#799 核：第一种与第二种是 `071:34`「判断的标准只有一个」分出的两个判断，不是同一判断的宽严两档；代表笔规则只在峰候选上与 R3 不同，峰候选是段端与第二序列起点的唯一来源。Lean 严格谓词不改，登记补「第一种情况确认」定义式与等价性引理（X-31）。
5. **流首段起点的定义（`[新缠论:推论]`，链：`078:22` + `078:24`）**：流首段（无前段可破的那一段）的起点 = 其终结确认之前、该段全部成员笔中段方向反向的最极端点（向上段取最低点所在向上笔的起点，向下段镜像；并列取先者）。起点在段确认前随前缀变化，段未确认不发布；非流首段一律不适用。之前的笔是未分段前缀。

## 8. 定义（正本）

线段是由**至少三笔**组成的结构，且前三笔必须有重叠部分。**笔数为奇数。**

### 线段划分定理

线段被终结，当且仅当至少被「有重叠部分的连续三笔」中的某一笔终结。等价表述：**旧线段终结 = 新线段形成**。

### 方向与奇数性

- 方向与起始笔一致（向上笔开始 = 向上线段）
- **线段的笔数一定是奇数**（`077:62` 逐字「线段中包含笔的数目，都是单数的」）
- **⟹ 「恒 2 笔」和「恒 3 笔」都不满足奇数性 + ≥3 的联合要求**：P3（恒 2）违反两条；P1（恒 3）满足两条但**只取下界**，见 §0。

### 硬约束（第78课）

> 「一个线段，两端的一顶一底，顶肯定要高于底」

违反此条件的线段划分是错误的。这是定义的一部分，不是后置过滤。

### 相切边界

**未裁**（§6）。当前两个生产载体不一致（P1 `<` / P2 `<=`），Lean 侧两个载体也不一致。

## 10. 口径 B：特征序列线段（P2，原 v1）—— **正本口径**

**定义**: 反向笔组成特征序列 → 特征序列做包含处理（**方向性**，§2）→ 标准特征序列出现分型 → 旧段终结、新段生成。

**规则**（第67课完整定义）:
1. 构造特征序列：向上线段取反向笔（X序列），向下线段取反向笔（S序列）
2. 特征序列元素当K线做**方向性**包含处理 → 标准特征序列（**外包络那一档不得作生产判据**，§2.1）；第一种情况的转折点前后两元素不做包含、c ⊂ b 记窗成员（§7.1 第 2／3 条）；有缺口时 c ⊂ b 按方向性合并、代表笔保持 b（§7.1 第 4 条，#1493 裁定 2）
3. 标准特征序列上找分型：向上线段找顶分型，向下线段找底分型
4. 分型出现 → 两种情况：
   - **第一种**（无缺口）：候选三态见 §7.1 第 1 条——c 破 b 终点即终结于 P；c ⊂ b 为转折点窗（§7.1 第 3 条），由后续笔先破 b 终点（确认）或先越过 P（作废、旧段延续）决定
   - **第二种**（有缺口）：**须**从分型极值点开始的**同向笔**序列（`078:54`「方向和原线段一致」）出现分型才终结，且**只要有分型就可以**（`067:46`），并**必须严格按包含关系处理**（`078:54`）
5. 结算锚验证：新段前三笔必须重叠（相切边界未裁，§6）
