# 376号：T(S) proxy 一致性 + 选股效果 L2 验证——双重否定性结果

**认识论等级**: L2（否定性结果——信息增量为正：缩小了 T(S) 有效域边界）

## 1. 结论

两个实验均产出否定性结果：

### 实验1：Proxy vs Strict T(S) 排序一致性

**否定性结果**：24个标的的严格 T(S) 全部为零（0/24）。`nested_divergence_search` 在日线5年（1489根K线）数据上未检测到任何跨级别嵌套背驰链。

| 指标 | 值 |
|------|-----|
| 标的数 | 24（覆盖 AU/OIL/BOND/RE/EQUITY 五个折叠通道） |
| strict T(S) > 0 标的数 | 0 |
| Spearman rho | 0.682（无参考意义——退化为 tie-breaking） |
| Kendall tau | 0.0（无参考意义） |

**根因**：所有标的的 Level 2 moves=0, zhongshus=0。Level 1 最多产出 3 个 moves（万科A、湖南黄金、招商银行），这不足以在 Level 2 形成中枢和走势。`nested_divergence_search` 需要至少 Level 2 有背驰才能启动搜索。

371号的数学断裂（乘法 vs 加法结构差异）在此数据集上无法量化——不是因为断裂不存在，而是因为被测对象（strict T(S)）在日线数据上不存在。

### 实验2：Proxy 分组选股效果

**不可判定结果**：分组极度不平衡（2 vs 22），低组无确认买点。

| 指标 | 高 proxy 组 (T>0.8) | 低 proxy 组 (T<=0.8) |
|------|---------------------|----------------------|
| 标的数 | 2（万科A、招商银行） | 22 |
| 平均 proxy | 1.80 | 0.69 |
| 确认买点数 | 1（仅招商银行） | 0 |
| 20日后续收益信号 | 59 | 0 |
| 20日平均收益 | -7.42% | N/A（无数据） |
| 正收益率 | 0.0% | N/A |

高组唯一有确认买点的标的（招商银行 600036）的 59 个后续收益信号全部为负。但 n=1 标的的结论不具备统计效力。

**诚实标注**：由于 strict T(S) 全零，实验2使用 proxy 代替。结论仅对 proxy 有效，不可反向背书 T(S)（371号约束）。

## 3. 边界条件

| 条件 | 当前 | 翻转可能 |
|------|------|---------|
| strict T(S) = 0 | 全部24标的 | 更高频数据（5分钟/15分钟）或更长历史（10年+）可能产生非零 T(S) |
| Level 2 结构为空 | 全部24标的 | 更多K线 → 更多 Level 1 moves → Level 2 可能形成结构 |
| 确认买点稀疏 | 仅 2/24 标的有 confirmed BSP | 更高频数据可能产生更多买点 |
| 分组不平衡 | 2 vs 22 | 需要更多高 proxy 标的（扩大标的池或用更高频数据） |

## 4. 下游推论

1. **T(S) 有效域边界确认**：strict T(S) 在日线5年数据上的有效域为空集。这不是代码 bug，是数据分辨率的结构性限制
2. **371号断裂量化需要更高频数据**：日线不足以产出 strict T(S)，因此乘法 vs 加法结构差异的实际影响只能在 5分钟/15分钟数据上验证
3. **366号 L2 结论降级确认**：366号的 L2 验证使用 proxy，strict T(S) 在同数据集上全零 → 366号的 L2 只验证了 proxy 的效果，确认371号的判定
4. **proxy 选股效果未决**：n=1 标的（招商银行）的后续收益全负，但统计效力不足，需扩大验证规模
