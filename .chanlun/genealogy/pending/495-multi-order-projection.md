# 495号：多阶投影——索罗斯表是扁平化

**认识论等级**: L0（数学形式化声明）

## 发现过程

编排者出示索罗斯量子基金 1985 年 8-9 月敞口表作为对照。Claude 指出：索罗斯表是一种**扁平化的多账本呈现**（宏观/微观双账本），与拓扑化框架的**多阶投影矩阵 B** 存在结构性差异。

## 核心命题

### 1. 索罗斯表的扁平化结构

索罗斯的双账本呈现：
- **宏观账本**：股指期货、债券、外汇、大宗商品
- **微观账本**：个股多空配对

**扁平化特征**：
- 两账本平行列出，无显式层间耦合
- 敞口各自报告，不显式追踪同一资金跨账本移动
- 没有"矩阵子类"这一中间层

### 2. 多阶投影矩阵 B 的定义

定义投影算子 $B: \Pi_{position} \to \prod_{l \in \{L1,L2,L3\}} E_l$：

对单一持仓 $p$，$B(p)$ 同时在三层有非零分量：
- **L1 投影** $B_1(p)$：持仓对四矩阵的资金存量贡献
- **L2 投影** $B_2(p)$：持仓对矩阵子类（如能源/贵金属）的贡献
- **L3 投影** $B_3(p)$：持仓在具体合约上的 Greeks（2-jet 完整分量）

这不是"分类讨论"——是**同一持仓在三层上的同时显影**。

### 3. 索罗斯 vs 拓扑化的结构差异

| 维度 | 索罗斯表 | 拓扑化 B |
|------|---------|---------|
| 层次 | 2（宏观/微观） | 3（L1/L2/L3） |
| 层间关系 | 平行（无耦合报告） | 共同来源同一持仓 |
| 报数单位 | 独立账本 | 同一持仓的多阶分量 |
| 信息完整性 | 各层独立读数可加和 | 跨层耦合通过 jet bundle 保留 |

### 4. 索罗斯生产性误读的另一例

索罗斯的双账本不是"错"——它是在**1985年可用的工具和直觉范围内的最佳逼近**。编排者把它**扬弃为多阶投影**：
- **否定**：扁平化的双账本遮蔽了层间耦合
- **保留**：敞口按层分别报数的精神
- **提升**：用 jet bundle 结构让层间耦合可计算

这是 482 号"生产性误读：把线性能量提升到旋转回路"模式的延续——**把扁平化提升到多阶投影**。

### 5. 持仓必全景报数（493号纪律 7）的数学基础

持仓必全景报数 = $B(p)$ 的所有三个分量都必须显式列出。

- 不允许"这个持仓的主要敞口是 L3"而隐匿 L1/L2 投影
- 任何持仓都有三层投影（可能其中某层投影为零，但零也要显式报）

## 多阶投影的报数模板

对每个持仓 $p$：
```
持仓 p 的多阶投影:
  L1（四矩阵资金存量贡献）:
    - 现金矩阵: Δ{M_cash}
    - 商品矩阵: Δ{M_goods}
    - 金融资产矩阵: Δ{M_finance}
    - 生产要素矩阵: Δ{M_production}
  L2（矩阵子类贡献）:
    - 子类 X: Δ{M_X}
    - 子类 Y: Δ{M_Y}
    - ...
  L3（合约 Greeks 2-jet）:
    - value, delta, gamma, vega, theta, rho, vanna, charm, ...
```

**三层必须同时报**——任何一层缺失 = 报数不合法。

## 下游推论

### 推论1：rules.md 不按"账本"组织

不学索罗斯按宏观/微观分两组。rules.md 按**持仓层面**（position-level）组织，每条规则自动触发三层投影计算。

### 推论2：审查按多阶投影

交易后审查不看"这笔赚了还是赔了"，看 $B(p)$ 的三层投影如何在时间上演化。

### 推论3：塌陷事件的投影变化

塌陷时（488号三个失败点），$B$ 本身的算子形式可能改变（不只是分量值变）——这是 490号 L_ontic 变形的数学表达。

## 边界条件

| 条件 | 当前 | 翻转阈值 |
|------|------|----------|
| 三层同时投影 | 每持仓必有 L1/L2/L3 三分量 | 出现只能在某层有投影的持仓 → 投影不全 |
| B 保持线性 | 投影是线性算子 | 发现投影需非线性处理 → B 不是线性的 |
| 索罗斯扬弃有效 | 多阶投影严格扩充双账本 | 证明双账本已包含全部信息 → 扬弃无增益 |
