# 503号：M 代理变量选择——M2 vs Fed 资产负债表

## 发现过程

PDF Page 19-22 记录的**第四次否定**：

Claude 提出：既然关心 MCM' 的力量，为什么用 M2（广义货币）而不是用 Fed 资产负债表（基础货币 + 逆回购）？理论上 Fed 资产负债表更"干净"（直接的央行行为，不受商业银行信用创造噪声影响）。

编排者 CC 实验（PDF Page 21）：
- M2×ω 与 GDP：协整 p=0.033, r=-0.36, L/GDP +3.48σ
- Fed_Asset×ω 与 GDP：协整 p=0.17, r=-0.21, L/GDP +2.1σ
- **M2 版本全面优于 Fed 资产版本**

编排者裁决（PDF Page 22）："Fed 资产负债表反而更差，说明**信用创造本身就是 MCM' 的实体**。去掉信用创造的'纯粹基础货币'不是更干净的 M，是**缺失了 MCM' 大部分内容的 M**。M2 包含商业银行的信用扩张，这不是噪声，是 MCM' 的本体。"

## 核心概念链

### 1. M2 包含的内容：基础货币 + 信用创造

M2 定义 = 基础货币（Fed 资产负债表中的现金+准备金）+ 商业银行创造的存款货币（M1-base）+ 定期存款。信用创造部分（M2 - Fed_Asset）是商业银行通过贷款派生的货币，不由 Fed 直接控制。

### 2. Fed 资产负债表的"干净性"是陷阱

直觉认为 Fed 资产负债表更"干净"——它只反映央行政策，不受商业银行行为干扰。但这个"干净"是**缺失**：
- Fed 只管基础货币，不管信用创造
- MCM' 的实际运转主要通过信用创造（商业银行贷款、影子银行、衍生品）
- 去掉信用创造 = 去掉 MCM' 的主体

### 3. 编排者的原创判断：信用创造 = MCM' 的实体

"M2 优于 Fed 资产"不是经验巧合，是**本体论的判断**：MCM' 的物质基础是信用关系（M → C → M'，中间的 C 必须通过信用才能完成资本循环），信用创造不是 MCM' 的外部条件，是 MCM' 的内部机制。

这与传统货币主义不同——货币主义将信用视为"货币的派生物"，编排者将信用视为"MCM' 的本质"。

## 定义依据

- **M2 定义**：FRED M2SL（季节性调整）
- **Fed 资产负债表**：FRED WALCL（联邦储备银行总资产）
- **协整检验**：Engle-Granger 两步法，窗口 2000-2026
- **信用创造与 MCM' 的关系**：PDF Page 22（编排者原话"信用创造本身就是 MCM' 的实体"）

## 边界条件

| 条件 | 当前 | 翻转阈值 |
|------|------|----------|
| M2 作为 M 的正确代理 | 2000-2026 协整 p=0.033 | 若出现一个货币总量变量与 ω 结合后协整更强（如 M3、影子银行 M4），M2 被替代 |
| Fed 资产劣于 M2 | 2000-2026 p=0.17 | 若央行政策转向完全替代信用创造（CBDC 完全取代商业银行货币），Fed 资产的地位上升 |
| 信用创造=MCM'实体 | 商业银行贷款是 MCM' 循环的主要物质基础 | 若经济彻底去信用化（100% 准备金制度），信用创造与 MCM' 的等式失效 |

## 下游推论

### 推论1：QE 政策对 ω 的有限作用

Fed 通过 QE 直接扩张基础货币，但如果商业银行不放贷（信用创造停滞），M2 不会对应扩张，MCM' 的旋转力度不会增强。2008-2015 QE1/2/3 期间 Fed 资产膨胀但 M2 增速平稳，对应 L/GDP 未出现与 Fed_Asset 比例的增长——**QE 直接作用于 Fed_Asset，间接作用于 M2，对 ω 的影响被信用传导机制调制**。

### 推论2：影子银行是 MCM' 的延伸

M2 不包含影子银行（回购、MMF、证券化产品）的"货币等价物"。如果将影子银行流动性纳入 M（所谓 M4 或 divisia M），MCM' 的度量会更完整——这是 M 代理变量的潜在升级方向。

### 推论3："干净数据"谬误

在宏观经济建模中，"更干净的数据"（Fed 资产 vs M2）往往意味着"更缺失的内容"。数据的"脏"不是噪声，可能是真实机制。选择代理变量的原则：**优先匹配概念本体，不优先匹配测量精度**。
