# 506号：协整作为脚手架——早期经验工具的认识论降级

## 发现过程

PDF Page 33-36 记录编排者对协整地位的反思：

早期阶段（~2025Q3-Q4），协整 p=0.033 是说服他人接受 L=Mω 框架的**关键经验证据**——没有协整，L=Mω 无法与"纯概念构造"区分。这个阶段协整具有**认识论必要性**。

到 2026Q1 后，拓扑工具（H1 环）、一阶差分负相关（r=-0.36）、L/GDP 偏离度（+3.48σ）、跨窗口鲁棒性测试都已完成，L=Mω 框架的证据基础已经多元化。此时协整的地位发生变化。

编排者原话（PDF Page 35）："协整是脚手架。早期用它来证明 L 和 GDP 不是独立乱动的，这对说服自己和别人很重要。但到了旋转动力学成型后，协整只是众多签名之一——如果明天协整因窗口变化失效，L=Mω 框架不会崩溃，因为 H1 环、一阶差分、+3.48σ 各自独立支撑。协整可以**拆掉作为脚手架**，框架本身站得住。"

这是**认识论层级的变化**——同一工具（协整）在不同时刻具有不同的方法论地位，不是工具本身的变化，是**它在证据生态中的位置**的变化。

## 核心概念链

### 1. 协整的早期必要性：唯一的"非平凡"证据

早期研究阶段，可供使用的证据工具有限：
- 一阶差分负相关（r=-0.36）：可能是噪声
- L/GDP 偏离度：需要长期回归才能定义"偏离"
- 拓扑工具：尚未成熟

此时协整 p=0.033 作为**经典计量经济学工具**，是唯一能说服读者"L 与 GDP 关系不是偶然"的证据。协整的**认识论必要性**来自证据生态的贫瘠。

### 2. 证据生态的充实：协整的必要性降低

随着框架成熟：
- H1 环（504号）：独立几何签名
- 跨窗口验证（2000-2010, 2010-2026, 2000-2026）：鲁棒性证据
- 一阶差分 r=-0.36（动态过程签名）：动力学证据
- +3.48σ 偏离度：极端值证据
- 第三/四/五次否定：概念约束证据

此时协整变成**众多证据之一**，不是唯一支柱。它的失效（比如在短窗口 p=0.099 不显著）不会推翻整个框架。

### 3. 脚手架隐喻的精确化

脚手架（scaffold）的特性：
- **建造时必需**：没有它建不成楼
- **使用时可拆**：楼建成后可以拆掉，楼不会倒
- **可能还要用**：若要继续加层建新部分，脚手架可能再次搭起来

协整在 L=Mω 框架中的位置完全对应：
- 早期必需（说服自己和读者）
- 成型后可选（独立证据已足够）
- 扩展时可能再用（若要建立新的子框架，协整作为验证工具可能再次重要）

## 下游推论

### 推论1：方法论工具的地位随证据生态演变

协整的"降级"不是因为协整变差了，是因为周围证据变丰富了。这给出一个一般原则：**任何方法论工具的地位都是生态性的，不是绝对的**。同一 p值、同一 r 值，在不同证据生态中的权重不同。

### 推论2：L=Mω 框架的稳健性不依赖单一检验

若协整明天失效（比如 2026Q3 数据让 p>0.2），L=Mω 框架不会崩溃——因为 H1 环、一阶差分、偏离度、+3.48σ、跨经济体拓扑对比等证据各自独立。这是**多元鲁棒性**（multiple robustness）的具体表现。

### 推论3：早期研究者的困境——必须搭脚手架才能前进

这也解释了为什么研究初期必须做大量"最终可以拆掉"的工作。早期没有脚手架（协整、经典计量检验），读者没有"抓手"理解新框架。**拒绝搭脚手架 = 拒绝被理解**，但 **永久依赖脚手架 = 拒绝成熟**。
