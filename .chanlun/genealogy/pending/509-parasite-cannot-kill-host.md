# 509号：寄生者不能杀死宿主——P 存量的内在监控

## 发现过程

PDF Page 37-39 记录编排者对 MCM' 持续性问题的回答：

Claude 提问（PDF Page 37）："如果 MCM' 越转越快（ω 趋于无穷），P 被抽干到零，资本主义系统崩溃。但这没发生——为什么？"

编排者回答（PDF Page 38-39）："寄生者不能杀死宿主。这不是道德选择，是**结构约束**。MCM' 的每一轮循环都需要 P 提供流动性投入。若 P 存量衰竭（真实生产能力、可雇佣劳动力、可抽取资源），MCM' 的下一轮循环无法启动。

不是 MCM' 有'克制'，是**数学上的稳态条件**——ω 的上升速度受 P 存量衰退速度约束。系统不会崩溃，是因为存在**内在负反馈**：ω 增加 → P 衰退 → MCM' 下一轮投入减少 → ω 增速放缓。

这就是为什么金油比虽然能到 40-60 的极端值，但不会指数上升到 1000。P 存量是 ω 的内生阻尼。"

## 核心概念链

### 1. 寄生者-宿主的动力学稳态

生物学中的寄生-宿主系统稳态条件：
- 寄生率 × 宿主存量 = 寄生者人口
- 宿主存量衰竭 → 寄生者无法繁殖 → 寄生率下降 → 宿主存量恢复
- 结果：**稳态振荡**，而非崩溃

MCM'/P 的对应：
- ω × M（每轮抽取量）= MCM' 增速
- P 存量衰竭 → MCM' 下一轮投入减少 → ω 增速放缓 → P 存量恢复
- 结果：**稳态振荡**（金油比在 10-60 之间波动），而非崩溃

### 2. P 存量的具体内涵

P 存量不是 GDP 流量，是**生产能力的存量**：
- 真实生产能力：工厂、设备、基础设施
- 可雇佣劳动力：技能、健康、可支配时间
- 可抽取资源：自然资源、生态承载力
- 组织资本：公司结构、供应链、制度

这些是**慢变量**——不随交易而即时变化，只随长期寄生而衰退。

### 3. 编排者的原创判断：稳态 ≠ 稳定

"寄生者不能杀死宿主"不意味着"系统是稳定的"。系统处于**稳态振荡**：
- 每次振荡的低点：P 存量严重衰退（如经济危机、产能退化）
- 每次振荡的高点：ω 极端值（空转压价到极限）
- 振荡中心：长期 ω 均值（历史上金油比约 15-20）

**稳态是振荡的稳态，不是静止的稳态**。每次振荡都有巨大的社会成本，但系统不会崩溃为零。

## 下游推论

### 推论1：ω 的长期均值是结构参数

金油比的长期均值（15-20）不是偶然，是 P 存量恢复率 / 寄生率 的稳态解。这意味着：
- 回归到均值不是"回归到趋势"，是**回归到结构稳态**
- L/GDP 偏离 +3.48σ 不会永久持续，必然回归（不是选择问题，是数学必然）
- 回归时间尺度由 P 存量恢复时间决定（通常是经济周期 5-10 年）

### 推论2：生态崩溃是稳态的唯一破坏者

寄生-宿主稳态的破坏条件：宿主存量某组分不可逆退化。在 MCM'/P 系统中，这对应：
- **生态崩溃**：资源不可再生（如油气枯竭 + 未建立替代）
- **社会解体**：劳动力质量不可恢复（教育系统崩溃、健康危机）
- **组织资本损毁**：制度断裂（如国家崩溃）

这些是**稳态的外部条件**，不是内部机制。MCM' 不会自我毁灭，但外部条件的退化可以让整个系统脱离稳态。

### 推论3：危机是稳态的一部分，不是稳态的终结

金融危机（2008、2020、未来的危机）不是"MCM' 杀死了 P"，是**稳态振荡的低点**——ω 到极值后 P 无法支撑，触发系统性清算，P 存量在清算中部分恢复（破产重组、产能出清）。

危机是**痛苦但必要**的稳态机制——没有危机，ω 会真的失控。从这个视角，"防止一切危机"的政策目标在结构上是不可能的。
