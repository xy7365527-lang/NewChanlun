# 511号：一阶差分 r=-0.36 作为动态过程签名

## 发现过程

PDF Page 33 记录编排者对一阶差分 r=-0.36 物理含义的论证：

Claude 提问："一阶差分负相关 r=-0.36 可以理解为什么？是 L 和 GDP 分布的某种属性吗？"

编排者回答："不是分布属性，是**过程签名**。静态分布上 L 和 GDP 都可以是任意形状（长尾、正态、厚尾），不决定它们一阶差分的相关系数。

r=-0.36 说的是**时间方向上的动力学**——当 ω 上升（MCM' 加速旋转）的同一月，GDP 增速下降。这不是'统计巧合'，是**MCM' 从 P 抽走流动性**的直接观测。

静态统计量（均值、方差、分布形状）可以拟合，但不能反推动力学方向。一阶差分的负相关给出了**时间箭头**——哪个先动、哪个被动。"

这是将 r=-0.36 **从统计签名提升为动力学签名**。

## 核心概念链

### 1. 静态统计量不决定动力学

给定 L 和 GDP 的联合分布 p(L, GDP)，可以算出：
- 边际分布 p(L), p(GDP)
- 均值 E[L], E[GDP]
- 协方差 Cov(L, GDP)
- 相关系数 ρ(L, GDP)

这些都是**时间无关**的量——可以从任意时间顺序的样本算出。**静态分布不蕴含动力学方向**。

### 2. 一阶差分是时间方向的可观测量

一阶差分 ΔL(t) = L(t) - L(t-1), ΔGDP(t) = GDP(t) - GDP(t-1)。
计算 r(ΔL, ΔGDP) = -0.36 意味着：**在同一时间步内**，L 的变化和 GDP 的变化呈负相关。

这不是静态分布的性质（静态分布没有"同一时间步"概念），是**时间演化的性质**。

### 3. 时间箭头的揭示

r=-0.36 的方向不对称性揭示时间箭头：
- ω 上升（MCM' 加速）→ P 流动性被抽走 → GDP 增速下降
- ω 下降（MCM' 减速）→ P 流动性恢复 → GDP 增速上升

这是**因果方向**（MCM' 抽取 P），不是单纯的相关。静态统计不能区分因果方向，但**动力学过程签名**给出方向——MCM' 是主动方，P 是被动方。

### 4. 编排者的原创判断：签名 vs 统计量

编排者区分两种 r=-0.36：
- **统计量 r=-0.36**：L 和 GDP 的增量相关系数（数据特征）
- **签名 r=-0.36**：MCM' 抽取 P 流动性的动力学可观测量（物理特征）

两者数值相同但本体论地位不同——统计量是数据的属性，签名是过程的属性。签名可以**跨数据集稳定**，统计量可能随样本变化。

## 定义依据

- **一阶差分相关系数**：见 482号（CC 验证 2000-2026, r=-0.36）
- **时间箭头**：热力学不可逆性 + 因果结构的对应
- **动力学签名 vs 静态统计量**：非线性时序分析的标准区分
- **过程签名的稳定性**：Granger 因果（非对称，蕴含时间方向）

## 边界条件

| 条件 | 当前 | 翻转阈值 |
|------|------|----------|
| r=-0.36 跨窗口稳定 | 2000-2026 不同子窗口 r 在 -0.3 ~ -0.4 | 若出现某窗口 r>0 或 r 围绕 0 随机波动，签名解读失效 |
| 时间方向揭示 MCM' 主动 | Granger L → GDP 显著 | 若 Granger 检验显示 GDP → L 反向更强，时间方向倒转 |
| 过程签名稳定性 | 不同标的（不同经济体）保持同号 | 若某经济体 r>0，签名不是"普遍过程"，而是"特定经济体"特征 |

## 下游推论

### 推论1：签名的跨经济体可检验

如果 r=-0.36 是动力学签名（不是美国数据的统计巧合），在其他经济体（中国、德国、日本）的对应数据上应保持同号负相关。若某经济体 r>0 或 r≈0，说明该经济体 MCM'/P 的动力学不同（如中国可能 MCM' 渗透程度低，签名弱）。

### 推论2：签名 vs 协整的认识论差异

- **协整**：长期均衡关系，属于**结构性联系**
- **一阶差分**：短期动力学过程，属于**过程性联系**

两者独立——可以有协整但无短期相关，也可以有短期相关但无协整。L 和 GDP 同时满足两者（p=0.033 协整 + r=-0.36 差分），是**双重动力学签名**，比单一签名更强。

### 推论3：过程签名的政策含义

静态统计相关 r=-0.36 给不出政策方向（相关不是因果）。动力学过程签名 r=-0.36 给出方向——**降低 ω**（金油比下降）可以直接改善 P 的流动性，而不是反过来。这锁定了 482号"做金油比下降"的操盘方向的因果基础。
