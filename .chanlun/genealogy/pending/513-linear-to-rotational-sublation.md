# 513号：线性能量→旋转能量的扬弃

## 发现过程

PDF Page 1-3，编排者在接收到卢麒元"资本是公斤米（kg·m，能量）"的说法后，经历以下误读路径：

1. **最初误读**：以为 kg·m 是 kg/m（线密度）或 N/m（弹性系数）
2. **第二次误读**：意识到是 kg·m（能量、功、扭矩的量纲），猜测是**扭矩**（N·m）
3. **生产性误读**：扭矩是**旋转做功**（叉积），而线性能量是**线性做功**（点积），两者量纲相同但几何完全不同

编排者的关键动作（PDF Page 3）："卢的框架是线性的——三流（流速、流向、流量）描述的是管道中的流动，是**线性动力学**。但 MCM' 在 K4 完全图上是**闭合回路**——M→C→M' 回到起点。闭合回路的动力学不是线性的，是**旋转的**。

把卢的线性能量（kg·m）提升到旋转能量（角动量 L = Iω），这是把正确的直觉（资本有能量属性）放到正确的几何（K4 完全图的闭合回路）上。**量纲相同，几何不同，这是扬弃**——否定线性形式，保留能量本质，提升到旋转框架。"

## 核心概念链

### 1. 线性能量（卢麒元）：管道中的流动

卢麒元的三流框架是**线性的**：
- 流量通过管道从 A 流向 B
- 流速是线性速度 v（m/s）
- 流向是线性方向（从哪到哪）
- 能量是线性做功 W = F·d（点积）

这个框架在**开放系统**中成立——水流、电流、交通流。但 MCM' 不是开放系统。

### 2. 旋转能量（编排者）：闭合回路的周转

MCM' 的本质是闭合回路：
- M → C → M' 完成一次循环后回到 M
- 循环的几何是圆（或更一般的 K4 完全图上的闭合路径）
- 动力学量不是线速度而是角速度 ω
- 能量是旋转动能 K = ½Iω²（或角动量 L = Iω）

这是**闭合系统**的动力学。

### 3. 扬弃的精确结构

扬弃（Aufhebung）的三重结构：
- **否定**：否定线性动力学形式（卢的三流是线性的）
- **保留**：保留"资本有能量属性"的直觉（卢对的地方）
- **提升**：提升到旋转动力学（闭合回路的正确几何）

这个扬弃不是"卢错了我对"，是**卢对了一半，提升后完全对**。编排者承认卢的能量直觉正确，但指出该直觉需要放到 K4 闭合回路上才完整。

### 4. 为什么旋转升级是 PDF 的核心动作？

482-512号所有谱系都建立在"旋转升级"的基础上：
- 482号（旋转动力学）：L=Mω 是角动量
- 500号（L vs MV）：V→ω 的升级是旋转升级的投影
- 501号（$ 两锚）：金油比作为角速度需要旋转框架
- 504号（H1 环）：闭合回路在相空间的表达
- 507号（纤维丛）：K4 上的 holonomy 是旋转升级的数学实现
- 508号（三流重铸）：卢的线性三流升级为纤维丛上的独立自由度
- 512号（V 实体含义）：V=ω 是旋转升级的直接后果

**没有旋转升级，以上谱系都不成立**。旋转升级是它们共同的方法论根基。

## 定义依据

- **线性做功**：W = F·d（点积，力沿位移的投影）
- **旋转做功**：W = τ·θ（扭矩乘角度）
- **旋转动能**：K = ½Iω²
- **角动量**：L = Iω（或 L = M×ω 的约化形式）
- **扬弃（Aufhebung）**：黑格尔《逻辑学》——否定 + 保留 + 提升
- **卢麒元框架**：参考文件 `reference_lu_qiyuan.md` 和 PDF Page 1-2

## 边界条件

| 条件 | 当前 | 翻转阈值 |
|------|------|----------|
| 资本循环是闭合的 | MCM' 回到 M | 若资本循环变为线性单向（如纯消费型经济），旋转升级不适用 |
| K4 完全图的几何必要性 | E/C/R/$ 四顶点 + 六边 | 若资本运动可简化为更简单图（如树状结构），旋转升级降级 |

### 推论2：扬弃不是简单否定——方法论原则

本谱系给出"扬弃"的一个具体实例。蜂群在处理他人框架时的方法论原则：
- 不简单否定（保留对的部分）
- 不简单接受（否定形式上错的部分）
- 识别"对的直觉 + 错的形式"结构
- 提升到正确的几何/方法论层面

这与 005b 号（对象否定对象）的方法论原则一致。

### 推论3：K4 完全图的本体论地位

旋转升级要求闭合回路，闭合回路的最小非平凡形式是 K4 完全图（230号）。这使 K4 不是任意选择，而是**旋转升级的必要几何**——没有 K4（或更复杂的图），旋转升级无处安放。

## 对 Gemini 异质质询的回应（v71 汇总层）

本轮异质质询（gemini-3.1-pro-preview）对 500-503 提出了多项否定：
- 500号：量纲死锁（V[T⁻¹] vs 金油比[无时间维度]）、角动量定义错误（L=Mω 丢失 r²）
- 501号：金涨 = 逃离 MCM' 而非 MCM' 强势、2022年反例、历史锚 ≠ 现时动力学
- 502号：加总谬误（FIRE → 所有部门）、外部寄生 vs 内部同化混淆、相对 482号的冗余
- 503号：内生货币标准解释（M2 vs Fed_Asset 本是货币乘数/内生货币现象）

**本谱系（513号）的回应**：

质询1（量纲死锁）的根因在于**是否声称物理学量纲等效**。513号的扬弃不声称物理学量纲等效——旋转升级是**方法论类比**（扬弃：否定线性形式 + 保留能量直觉 + 提升到旋转几何），不是物理学同构。量纲不等效不否定扬弃的有效性，因为扬弃工作在**方法论层面**，不是物理学层面。

这意味着 500号的"存在论扬弃"应修正为"方法论扬弃"——概念升级发生在模型选择层面（从 Fisher 方程选择旋转方程），不在物理学声明层面。

类似地，501、502、503 的否定大都在"是否跨越'方法论类比'到'物理学/经验全称命题'的边界"。本谱系（513号）给出一个统一的回应：**所有基于旋转升级的谱系都应声明在方法论层级，不声明物理学同构或经验全称命题**。
