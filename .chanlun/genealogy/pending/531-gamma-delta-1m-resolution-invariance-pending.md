该断言基于两个异质数据点（30m 正典 vs 1min 期货），但这两个点在 X 维度、顶点实例、numeraire、窗口均不同。

## 五个待质询裂隙（同质层预判，非最终结论）

### 裂隙1：「分辨率不变」证据基础

- 观测点：30m 正典（3 交叉边，H(X)=3.941，残余 0.812 bits，5 变量）vs 1min 期货（2 交叉边，H(X)=3.165，残余 2.074 bits，2 变量）
- 问题：两点不构成"不变性"论证。且两者 X 维度不同，残余熵绝对值不可比。
- 预判：断言强度超过证据基础，建议降级为"初步观察"。

### 裂隙2：跨实例混淆（高优先级）

- X 从 3 维降至 2 维（去掉 R 轴 VNQ），可约空间天然减小。
- 0.812 → 2.074 bits 的变化有三种解释：a0 效应 / X 维度效应 / 实例差异。
- 报告把全部变化归因于 a0，但没有控制变量（固定 X=2，比较 30m vs 1min 期货）。
- 预判：跨实例混淆污染了 a0 效应解读，此裂隙可能不可消化。

### 裂隙3：shuffle 噪声地板 vs 贪心阈值

- 单变量 shuffle 伪增益 ~0.345，6E 真实增益 0.084（信噪比 1:4）。
- 贪心第2步 6E 条件增益 0.023，阈值 0.005。
- 0.005 << 单变量噪声地板（量级差两个数量级），阈值设定依据未在报告中说明。
- 预判：需要精确化阈值设定依据；多变量条件下 shuffle 伪增益会衰减，不直接等于单变量值，但仍需说明。

### 裂隙4：自相关→有效独立样本（方法论盲区，高优先级）

- 日末采样 2297 个点，但相邻天的 σ 高度自相关（一个走势持续数天到数周）。
- 报告过拟合诊断使用名义样本数 N≈1856，不是有效独立样本数 Neff。
- 若缠论走势平均持续 10-30 交易日，Neff ≈ 60-230，样本/cell 从 7.93 降至 0.25-1.0。
- 过拟合风险等级从"中/低"可能升至"高"。
- 预判：结构性方法论盲区，需要补充 Neff 估计或自相关诊断。

### 裂隙5：2 vs 3 交叉边对"补到0"难度的影响

- 本质是裂隙2的子集：X 维度不同，"补到0"的代数难度不同，不可比。
- 补充问题：如果用 30m 版的 5 个变量组合（ω+VIX+oil+gold+slope）在 1min 下跑，残余是多少？这个"同配方跨 a0"对照实验缺失。
