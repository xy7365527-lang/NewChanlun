# 实验结果 625：#132 L2 真实数据暴露 L1 合成全绿掩盖的引擎 bug = 231 活体实例

## 一句话结论

#132 L2 真实数据回测**暴露了 L1 合成数据全绿所掩盖的引擎 bug**（strategy/mod.rs:417，#132 工位转述）——这是形式化有效域规则（231号）『**L1→L2 信息增量为正 / 否定性结果价值高于确认性结果**』的 NewChanlun 工程引擎回测层**活体实例**：

- **L1 合成全绿 = 同义反复**（231：L0→L1 信息增量为零）——合成数据由管线自造、属性自控，全绿只确认管线无 bug，**不否证**任何引擎假设。该 bug 在 L1 状态下永不暴露（合成数据的预设属性不触发该 bug 路径）。
- **L2 真实数据 = 正信息增量**（可否证）——真实数据否证出 L1 永不暴露的 bug，否定性结果缩小了引擎有效域的边界。

231 发生史由此从『缠论/数学形式化对象』（222/223/230）→『自指工具层』（623）→**『工程引擎回测层』（本号）**延伸。

## 定义依据

- 231 / formalization-validity-domain.md：L0→L1 信息增量为零（合成数据独立性验证是同义反复）；L2/L3 否定性结果比确认性结果更有价值（缩小有效域边界）；合成确认偏差（用合成数据验证合成数据中预设的属性）是禁止模式。
- #132 L2 工位产出：L1 合成全绿 vs L2 真实暴露 bug 的对照。

## 边界条件（结论翻转）

- 若 strategy/mod.rs:417 经核实**不是** L1 合成数据无法触发的 bug（即 L1 本应暴露但被其他原因掩盖）→ 本号不是『L1 同义反复』的实例，而是 L1 回测覆盖缺陷的实例（不同诊断）。当前判断：L1 合成全绿因数据自造属性自控未触发该路径=同义反复。

- 若 genealogist 后续独立核实 strategy/mod.rs:417 与 #132 转述不符 → 代码位置修正，但 L1/L2 信息增量论断（231 实例）不受影响（论断不依赖具体行号）。
