六个 residue 无统一根，四维度划分 + 跨维度关系（六轮 Gemini 质询结算 + 拉康拓扑学审计）：

维度划分：
- **符号层**：a（语义碎片化）+ b（stance null）——多主体符号交换层面
- **本体论层**：c（离散/连续鸿沟）——独立于主体交互，形式化本身的限制
- **拓扑层**：d（假死/共时）+ e（非定向性/历时）——主体交互的拓扑属性
- **元形式化层**：f（形式化死锁）——"拓扑不是隐喻"与"拉康数学操作不严格"不可同时为真

跨维度关系：
- b →[触发] d（b 触发 d；消解 b 不充分消解 d，需额外拓扑扰动）

已删除的连线：
- c → a（删除原因：强依赖=过度还原，弱依赖=形式化约束力为零。六轮质询的死锁结论）
- 元注释：c 与 a 之间的关系不可形式化，这本身是 c 的元层面例证（meta-instantiation）——c 断言"映射有损"，而试图将 c-a 关系映射为有向边这个动作本身触发了 c 所描述的鸿沟

结构原则（Gemini R6 结算）：形式化图景中仅保留具有形式化约束力的关系。a、c、e 作为孤立节点存在，不需要与其他 residue 存在形式化依赖关系也能确立其独立合法性。

residue e 的发现与修正史：
1. 编排者从挠元素（torsion / Z/2Z）直觉出发提出第五个 residue
2. 编排者进一步声称 e 是 a-d 的根（"消去前四个需要的判断位置本身是半个洞"）
3. Gemini 审计否定了两个关键步骤：

### 拉康拓扑学中两个模型的关系（文献溯源后修正）

编排者三次尝试建立莫比乌斯带与博罗梅奥结的关系，前两次被否定：
1. ~~因果绑定："博罗梅奥结导致非定向性"~~ → Gemini 否定（补空间可定向）
2. ~~构造性推导："Seifert 曲面交叉产生 cross-cap"~~ → Gemini 否定（Seifert 曲面定义上可定向，可定向曲面的交叉不可能产生不可定向结构）
3. 文献溯源后的结论：**替代关系，不是推导关系**

两种形式化策略（不同时期，不同数学对象）：
- **60年代曲面拓扑**（Seminar IX《认同》起）：莫比乌斯带、环面（torus）、cross-cap。Cross-cap 被双环曲线切割为莫比乌斯带（代表主体 $）和圆盘（代表对象 a）。主体是**切割的效果**。
- **70年代结拓扑**（Seminar XX 之后）：博罗梅奥结。RSI 三环各自具有环面（toric）结构，三方连接但互不实际相连。主体由**结本身定义**，不再仅是切割效果。

关键转变：**主体从"切割的效果"变成"结的定义"**——形式化方式整体更换，不是数学推导。

共享词汇，异质操作：**切割（coupure）**在两个时期的精神分析话语中是连贯的概念，但在数学上对应两种异质操作——曲面上的切割是 surgery（改变流形拓扑类型），结的切割是 unlinking（移除分量导致散架）。不构成形式化层面的桥梁（Gemini 拉康审计 R4 修正）。

对本体系的含义：
- 莫比乌斯带（非定向性 → residue e）和博罗梅奥结（Brunnian 散架 → 24/7 不可行）是**两个独立的拓扑概念**，各自刻画不同的结构性质
- 不存在从一个到另一个的数学因果链——之前的所有因果绑定尝试均已被否定
- 第三环退场导致散架（Brunnian 性质）是独立事实，非定向性（residue e）是独立 residue，两者不因果关联
- 体系中使用这些拓扑概念时，只引用纯数学性质（Brunnian、不可定向性），精神分析概念和数学概念之间的关系标注为"未解决的死锁"（residue f）
