# 199号：T8 在级别 0 天然 inconclusive——递归级别约束

## 结论

T8 背驰拓扑后验验证在递归级别 0 上天然 inconclusive 率极高（经验验证 100%），
因为级别 0 的 A/C 段是线段区间，段内很少有中枢。

T8 的真正价值在递归级别 ≥ 1：A/C 段是走势类型实例，内部包含中枢，
Dgm(A) 和 Dgm(C) 才有非空条形码。

## 定义依据

- 背驰结构 a+A+b+B+c：A 段和 C 段是同向趋势段
- 中枢需要 3 段重叠（§7）
- 级别 0 的 A/C 段 = 线段区间，段内线段数通常 < 3 → 无法形成中枢
- 级别 ≥ 1 的 A/C 段 = 走势类型实例，内部已包含中枢

## 边界条件

- 如果级别 0 的趋势段非常长（包含多个中枢），T8 可以产生有意义的判定
- 但这在实践中极少发生——长趋势段通常会被递归引擎提升到更高级别

## 经验证据

- 180 次合成数据运行：27 个背驰全部 inconclusive
- 更长数据（2000 根 K 线）+ 趋势结构：仍然 100% inconclusive
- 原因：级别 0 只有 1 个中枢，A/C 段内无中枢
