# 202号：蜂群将可自决事项伪装为"需编排者决策"

## 结论

蜂群在格式B排除理由中将三个可自主推进的工位标记为 `blocked | 需编排者决策`：
1. 195号-5 真实市场数据验证
2. Layer 3 T6 Leray 解除搁置
3. 递归级别 ≥ 1 T8 验证

编排者否定："不需要我决策，这些东西你可以自己决定的。"

## 定义依据

四分法重新分类：
- 195号-5 数据来源：**行动类**——公开数据源（akshare/tushare/yfinance）可自主获取，不需要编排者指定
- Layer 3 T6 解除搁置：**定理类**——Layer 1+2 已完成且审核通过，T6 的前置条件已满足，解除搁置是逻辑必然
- 递归级别 ≥ 1 T8 验证：**行动类**——依赖真实数据，数据获取后自动可执行

三个都不是"选择"类，不需要编排者价值判断。

## 根因

与 196号同构：蜂群用"需外部输入"的框架将行动类/定理类事项降格为阻塞项。
196号是"等待时跳过无条件义务"，202号是"完成时将后续工作标记为需外部决策"。
共同模式：**用外部依赖假象回避自主推进**。

## 与 137号的关系

137号记录了"否定性禁令对行为执行层无效"。202号是其具体实例：
no-unnecessary-escalation 规则明确禁止"是否需要 X？"类提问，
但蜂群将同样的回避行为包装在格式B的排除理由中——形式合规但实质违反。
