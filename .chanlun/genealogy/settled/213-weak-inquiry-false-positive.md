# 213号：弱质询信号词扫描——全 false positive + 扫描器精度改进

## 结论

gangju_analysis.py 新增的弱质询信号词扫描首次运行，检测到 8 处命中（5 个谱系文件）。
经逐一审计，8 处全部为 false positive。

## 审计明细

| 谱系 | 命中词 | 上下文 | 判定 |
|------|--------|--------|------|
| 194号 | 不影响 | "只影响分型位置不影响极值"——精确技术判断 | FP |
| 195号 | 不需要 | "我不需要长期方向"——引用编排者原话 | FP |
| 201号 | 不需要 | "编排者声明'不需要问我'"——引用编排者原话 | FP |
| 202号 | 不需要 | "不需要编排者价值判断"——四分法分类结论 | FP |
| 204号 | 不需要 | "不需要 sheaf 库"——技术范围界定 | FP |

## 根因分析

"不需要"、"不影响"在技术文档中是高频词，出现在：
1. 编排者引语（"我不需要..."）
2. 技术范围界定（"不需要 X 库"）
3. 精确影响判断（"不影响极值"）

这些都不是质询深度不足的信号。关键词列表缺乏上下文区分能力。

## 改进方案

1. 排除引用行（含"编排者"、引号包裹的文本）
2. 排除技术范围界定（"不需要 X 库/定义/工具"模式）
3. 缩窄关键词：移除"不需要"、"不影响"等过于宽泛的词
4. 保留真正的回避信号词："暂不处理"、"可忽略"、"问题不大"、"已足够"
5. 增加上下文窗口：命中后检查前后行是否有分析支撑

## 边界条件

如果未来谱系中出现"不需要"用于回避质询（如"不需要深入分析"），当前改进可能漏报。
但 false positive 率 100% 说明精度优先于召回率。

## 下游推论

1. gangju_analysis.py 的 WEAK_INQUIRY_KEYWORDS 列表需要精简 + 上下文过滤 → 待实现
2. 扫描器首次运行的校准数据已获得——可作为后续精度评估的 baseline
