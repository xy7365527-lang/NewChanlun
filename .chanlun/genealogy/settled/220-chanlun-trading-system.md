# 220号：缠论交易策略体系溯源

## 发现

v60-swarm 中 risk 相关工位生成了 ATR 止损、Kelly 仓位管理、最大回撤百分比控制等外部金融工程代码，被编排者否定。编排者明确指出：

> "缠论-新缠论的运动，不允许外部语言的介入，因为一切其他语言都不合法"
> "缠论是一个不以盈利为主旨，而是通过区间套和短差操作把成本降为0甚至负数的操盘方法"

## 溯源结果

从缠师原文108课中提取了五个核心概念，建立定义文件 `.chanlun/definitions/chanlun-trading-system.md`：

### 1. 退出条件（替代"止损"）
- 来源：第13课
- 核心：不存在止损，只存在"从能搞变不能搞"
- 形式：买入程序的判断条件被否定 → 退出
- 第一类买点退出：上涨中再次出现同级别中枢
- 第二类买点退出：跌破前一下跌趋势最低点
- 第三类买点退出：回试跌破 ZG

### 2. 资金管理——成本归零策略
- 来源：第31课
- 三阶段：降成本（短差不增仓）→ 归零（翻倍出半仓）→ 挣股票（回补增仓）
- 核心约束："买股票，宁愿不断跌不断买，也绝对不往上加码"

### 3. 短差程序
- 来源：第14课
- 形式：大级别买点介入 → 次级别卖点减仓 → 次级别买点回补
- 递归性：操作级别 N → 短差级别 N-1

### 4. 区间套精确定位
- 来源：第29课、第32课
- 形式：大级别确定方向 → 中级别确认背驰段 → 小级别精确定位

### 5. 操作级别与风控的统一
- 来源：第35课、第10课
- 核心命题：风控不是独立模块，是买卖点系统的内在属性

## 下游推论

1. `src/newchan/risk/` 模块的设计方向需要根本性改变——不是独立风控层，而是买卖点系统的扩展
2. 回测引擎需要支持：短差程序模拟、成本归零追踪、多级别联动
3. 退出条件实现应在 BuySellPoint 判定逻辑中
4. 仓位管理应追踪"当前阶段"（降成本/归零/挣股票）

## 边界条件

- 如果发现缠师原文中有独立于买卖点系统的风控概念 → 本谱系需要修正
- T+1 制度下短差程序的具体执行方式未在原文中明确 → 需要实践验证
