# 矛盾描述

v4 §5.4 模式D（独立边同向正）的派生边观测后分类初版只有两种：

> 若派生边均≈0：现金角在贬值。
> 若派生边有方向：资产间确实有差异化流转。

这个分类不完备，遗漏了混合状态。

## 反例构造

设 E/$=+（涨幅20%），C/$=+（涨幅15%），R/$=+（涨幅15%）。

则：
- E/C = E/$ ÷ C/$ → E 涨幅 > C 涨幅 → E/C = +（有方向）
- E/R = E/$ ÷ R/$ → E 涨幅 > R 涨幅 → E/R = +（有方向）
- C/R = C/$ ÷ R/$ → C 涨幅 ≈ R 涨幅 → C/R ≈ 0（盘整）

此时派生边状态为 (+, +, 0)——既不是"均≈0"，也不是统一的"有方向"。

## 修复

v4 §5.4 模式D和模式E已补充第三种情况：

> 若派生边部分有方向、部分≈0（混合状态）：局部差异化流转。例如E/C=+、E/R=+、C/R≈0，说明动产相对商品和房地产都在走强，但商品和房地产之间没有流转——动产是唯一的相对赢家，商品和房地产同步贬值。需要逐条派生边读取，不能笼统归类。
