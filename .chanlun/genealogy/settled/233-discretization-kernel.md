# 233号：离散化算子 D 的核结构——缠论的内在选择性原理

## 1. 结论

缠论的离散化不是对连续动力学的近似，而是**拓扑滤波器**。

定义离散化算子 D: C(连续配置空间) → S(离散缠论状态 = {-1, 0, +1})：

```
D = D3 ∘ D2 ∘ D1
```

其中：
- **D1（bar → 笔）**：包含处理 + 分型 → 笔只编码方向（up/down），丢弃幅度
- **D2（笔 → 线段）**：特征序列分型 → 短促振荡被合并，弱方向信号被吸收
- **D3（线段 → 中枢 → 走势方向）**：中枢 [ZD,ZG] 吸收区间内振荡，走势方向仅由中枢间位置关系决定

**核结构定理**：

```
ker(D) = {耦合模式 φ ∈ C | φ 是纯幅度耦合}
```

即：一个耦合模式属于 ker(D)，当且仅当它仅调制共同方向内的收益率大小，不调制方向本身。

**推导链**（纯公理推导，L0）：

1. 公理1（bi.md）：笔是走势的最小可编码单元，只编码方向
2. 公理2（xianduan.md）：线段被终结当且仅当被线段终结
3. 公理3（zhongshu.md）：中枢 = 至少三个连续次级别走势类型重叠
4. 公理4（qushi.md）：只有趋势才有方向，盘整无方向

D1 丢弃幅度信息 → 纯幅度耦合在 D1 层即被消除。
D2 通过特征序列合并吸收短程方向噪声。
D3 通过中枢定义将区间内振荡归为"无方向"。

结论：D 系统性地滤除幅度维度信息，保留方向维度信息。ker(D) 恰好是纯幅度耦合的集合。

## 3. 边界条件

结论在以下条件下翻转：

1. **幅度耦合携带方向信息**：如果某资产对的幅度共振同时伴随方向同步（如：大涨时同涨，大跌时同跌，小幅时独立），则 D1 不完全吸收，部分幅度耦合可能穿透到离散层面。当前 E-R 数据显示这不成立（β ≈ 0）。

2. **缠论参数改变**：如果笔的间距阈值、中枢的重叠条件等参数改变，ker(D) 的边界会平移。例如更宽松的笔定义（保留更多短促波动）可能使 D1 的幅度吸收减弱。

3. **时间尺度变化**：ker(D) 的结构在不同级别（1分钟/日线/周线）可能不同，因为不同时间尺度下幅度耦合和方向耦合的相对强度可能改变。

4. **非线性耦合**：当前分析假设耦合以线性偏相关度量。强非线性耦合（如尾部依赖）可能在线性度量中被低估，在离散层面显现。

## 4. 下游推论

### 4.1 缠论离散化是信息重组，非信息损失

传统观点认为离散化必然损失信息。233号证明缠论的离散化是**选择性的**——它有一个明确的核（ker(D) = 纯幅度耦合），选择性地保留方向信息。这不是信息损失，而是信息重组：从连续幅度空间到离散方向空间的拓扑映射。

### 4.2 E-R 跷跷板的"消失"是结构性的

232号发现的 E-R 耦合强度反转（偏相关 -0.336 → β -0.017）不是统计噪声或方法误差，而是 ker(D) 的直接表现。E-R 风险跷跷板是**幅度现象**（跌时一个跌多一个跌少），恰好落入 ker(D)。

### 4.3 C-R 避险同向性的"放大"是结构性的

C-R 偏相关 0.153 在离散层面"放大"为 β 0.688，不是因为离散化引入了假信号，而是因为 C-R 避险同向性是**方向现象**（黄金涨→债券涨），穿透了 ker(D)。离散层面去除了幅度噪声后，方向信号更加清晰。

### 4.4 纤维丛联络 = D 的余像结构

232号的纤维丛联络 ω 参数化了 D 的余像（image）的结构。ker(D) 描述 D 吸收了什么，联络 ω 描述 D 保留了什么。两者互补。

### 4.5 FLAT 态是 ker(D) 的"容器"

配置空间中的 FLAT 态（sigma = 0）是 ker(D) 中耦合模式的"去处"——连续层面的幅度耦合被离散化投影到 FLAT 态。这解释了为什么 E-R 方向耦合在 FLAT 态中最强（232号 §4.4 观察）。
