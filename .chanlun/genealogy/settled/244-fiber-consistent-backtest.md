# 244号：纤维丛管道自洽后回测对比——矛盾操作归零 + 裁决翻转为平局

## 1. 结论

243号修复（fiber_scan_direction 改用 fiber_polarity）后，重跑全 27 配置 × 20 BSP 交替序列的双模型回测。

### 核心发现

1. **矛盾操作完全消除**：纤维丛版矛盾操作率从 17.65% 归零，证实 242号中所有矛盾操作的唯一来源是层间不一致（scan 用直积 polarity，共振用 fiber_polarity）。

2. **裁决翻转为平局**：两条管道在各自内部一致后，干净度评分完全相同（0.8765）。直积版在 242号中的优势完全来自纤维丛版的集成缺陷。

3. **决策分歧不变**：22.2% 的 BSP 事件仍有不同的入场/阻断决策。这些分歧来自 polarity 计算方式的结构性差异（直积=线性求和，纤维丛=联络条件概率 mode），不因层间一致性修复而改变。

4. **两版入场/阻断总量不变**：修复只改变了矛盾检查的 scan direction 来源，不改变入场/阻断决策本身。

## 2. 定义依据

### 公平对比的前提

公平对比要求两条管道各自内部一致。即：
- 直积版：polarity 计算 → scan direction + 共振信号方向 均来自 `polarity_index(config)`
- 纤维丛版：polarity 计算 → scan direction + 共振信号方向 均来自 `fiber_polarity`

242号的对比不公平：纤维丛版的共振信号用 fiber_polarity，但 scan direction 用直积 polarity。
243号修复了这个不一致。244号是修复后的公平对比。

### 干净度评分公式（继承自 242号）

综合得分 = (1 - 假信号率) × 0.4 + (1 - 矛盾操作率) × 0.3 + 信号一致性 × 0.3

两版修复后：
- 直积：(1-0) × 0.4 + (1-0) × 0.3 + 0.5882 × 0.3 = 0.4 + 0.3 + 0.1765 = 0.8765
- 纤维丛：(1-0) × 0.4 + (1-0) × 0.3 + 0.5882 × 0.3 = 0.4 + 0.3 + 0.1765 = 0.8765

## 3. 边界条件

### 3.1 平局不等于"纤维丛没有价值"

平局意味着两条管道在干净度上无差异。但 22.2% 的决策分歧仍然存在——在真实数据上，这些分歧点的胜率对比才能判断哪种 polarity 计算更优。

### 3.2 合成数据局限性

同 242号：合成 BSP 序列不反映真实 BSP 出现频率和配置转换路径。平局结论的有效域是合成数据上的干净度对比。

### 3.3 翻转条件

如果修改干净度评分的权重（当前假信号率 0.4、矛盾率 0.3、一致性 0.3），且两版在某维度有差异，则平局可能打破。当前三个维度上两版完全相同，任何权重组合都是平局。

### 3.4 fiber_scan_direction 的作用域

fiber_scan_direction 仅用于回测矛盾检查。核心管道 `pipeline.py` 的 `scan_configuration` 不变（仍用直积 polarity）。如果要让纤维丛版影响实际入场决策，需要进一步集成——让 PipelineBacktestEngine._pipeline_enter 使用 fiber_scan_direction。

## 4. 下游推论

### 4.1 直积版作为默认入场筛选器的地位需要重新评估

242号"直积版更干净"的结论已被推翻（因为建立在不公平对比上）。现在两版平局，选择哪版入场不再有干净度差异依据。

决策因素转向其他维度：
- 真实数据上 22.2% 分歧点的胜率对比
- 计算成本（纤维丛版需要额外计算 KL 散度和联络概率）
- 概念一致性偏好（纤维丛版从理论上更精确）

### 4.2 真实数据分歧点追踪

120 个分歧事件中，两版给出不同的入场/阻断决策。在真实数据上追踪这些分歧点的后续走势，可以打破平局。这是下一步最有价值的验证方向。

### 4.3 集成完整性的方法论

243号修复验证了一个方法论：比较两种模型时，必须确保每种模型的管道内部一致。部分集成状态下的对比结论是误导性的。
