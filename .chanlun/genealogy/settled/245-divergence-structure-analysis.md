# 245号：22.2%分歧事件结构特征——与C-R方向不一致100%重合

## 1. 结论

244号修复后（两管道各自内部一致），对 540 个事件（27配置 × 20 BSP 交替序列）执行分歧事件结构特征分析。

### 核心数据

| 指标 | 值 |
|------|-----|
| 总事件 | 540 |
| 分歧事件（product_resonates ≠ fiber_resonates） | 120 (22.2%) |
| 非分歧事件 | 420 (77.8%) |
| 分歧事件中 sign 不一致占比 | **120/120 (100%)** |
| 非分歧事件中 sign 不一致占比 | 80/420 (19.0%) |

### 236号假设验证：通过

236号假设：分歧集中在 C-R 方向不一致（即 sign(polarity_index) ≠ sign(fiber_polarity)）的配置。

验证结果：**100% 重合** — 所有 120 个分歧事件的 product/fiber polarity 符号不同。

### 分歧事件的结构特征

1. **C-R 方向不一致是决策分歧的必要条件**：120/120 = 100%
2. **C-R 方向不一致不是充分条件**：非分歧事件中有 80 个 sign 不一致但两管道决策相同（共振检查结果一致）
3. **分歧配置集中在 10 个配置**（27 个中的 37%）：全部是 C 和 R 分量方向不同的配置

### 分歧配置列表

| 配置 (σ_e, σ_c, σ_r) | 分歧事件数 | polarity_index sign | fiber_polarity sign |
|---|---|---|---|
| (+,-,+) | 20 | +1 | -1 |
| (-,+,-) | 20 | -1 | +1 |
| (+,-,0) | 10 | 0 | -1 |
| (-,+,0) | 10 | 0 | +1 |
| (0,-,+) | 10 | 0 | -1 |
| (0,+,-) | 10 | 0 | +1 |
| (+,0,+) | 10 | +1 | 0 |
| (-,0,-) | 10 | -1 | 0 |
| (+,0,0) | 10 | +1 | 0 |
| (-,0,0) | 10 | -1 | 0 |

规律：C（σ_c）和 R（σ_r）方向相反或一方为零时，直积求和与纤维丛联络给出不同的策略方向。

### sign 组合分布（分歧事件）

| 组合 | 数量 |
|------|------|
| P=+1, F=-1 | 20 |
| P=-1, F=+1 | 20 |
| P=+1, F=+0 | 20 |
| P=-1, F=+0 | 20 |
| P=+0, F=-1 | 20 |
| P=+0, F=+1 | 20 |

每组恰好 20 个事件（10个配置中有6组符号对，每组贡献10或20个BSP事件）。

## 2. 定义依据

### polarity_index（直积版）

`polarity_index(config) = σ_e + σ_c + σ_r`（线性求和），来自 `src/newchan/topology/config_space.py`。

### fiber_polarity（纤维丛版）

`fiber_polarity` 由 `FiberSignalFilter` 通过 C-R 联络条件概率 mode 计算，来自 `src/newchan/topology/fiber_pipeline_adapter.py`。当 C 和 R 方向一致时，fiber_polarity 与 polarity_index 方向相同；当 C 和 R 方向相反时，fiber_polarity 偏向 C-R 联络修正后的方向。

### decision divergence

`product_resonates ≠ fiber_resonates`：两条管道对同一 BSP 给出不同的入场/阻断决策。

### C-R 方向不一致

`sign(polarity_index) ≠ sign(fiber_polarity)`：直积版和纤维丛版给出不同的策略方向。

## 3. 边界条件

### 3.1 合成数据局限性

同 242号/244号：合成 BSP 序列不反映真实 BSP 出现频率和配置转换路径。100% 重合在合成数据上成立，真实数据上需独立验证。

### 3.2 充分条件缺失

C-R 方向不一致是分歧的必要条件但非充分条件。80 个非分歧事件有 sign 不一致但两管道决策相同——因为共振检查可能在两条管道中都通过或都不通过，即使 polarity 方向不同。

### 3.3 翻转条件

如果 FiberSignalFilter 的 kl_threshold 从 0.0 改变，fiber_polarity 的计算方式可能变化，100% 重合可能不再成立。当前分析基于 kl_threshold=0.0（与 244号一致）。

### 3.4 β_cr=0.688 的直接含义

236号的 β_cr=0.688 表示 C-R 联络修正系数。本分析从决策层面验证了这个系数的操作含义：纤维丛修正只在 C-R 分歧配置下改变决策。

## 4. 下游推论

### 4.1 裁决问题缩小

"直积 vs 纤维丛谁更好"缩小为"C-R 分歧时段（10个配置）该听谁的"。这是一个更小、更精确、更容易在实盘中观察的问题。

### 4.2 实盘验证策略

在真实数据上，只需追踪 C-R 分歧配置下的 BSP 事件后续走势：
- 如果纤维丛版在这些配置下的入场/阻断胜率更高 → 纤维丛修正有价值
- 如果直积版胜率更高 → 纤维丛修正在 C-R 分歧时段是错误的
- 如果两者胜率无显著差异 → 两种 polarity 计算在操作层面等价

### 4.3 非分歧事件中的 sign 不一致（80 个）

这 80 个事件是"方向不同但决策相同"的情况。它们的存在说明共振检查在某些情况下能吸收 polarity 差异——纤维丛修正在这些情况下不改变最终决策。
