# 251号谱系：60min 单层背驰检测——方向性力度 vs 振幅力度对比

## 结论

在 SPY 60min 730天数据（5078 bar → 407 笔 → 40 段 → 8 中枢 → 7 走势）上，
振幅力度（∈ ker(D)）与方向性力度（∉ ker(D)）对同向走势背驰的判断存在 **2/6 差异**：

| 走势对 | 振幅力度 | 方向性力度 | 判断 |
|--------|---------|-----------|------|
| Move[0]↔[1] | 127.82 → 56.26 (背驰) | 3.25 → 1.25 (背驰) | 一致 |
| Move[1]↔[2] | 56.26 → 63.70 (无) | 1.25 → 1.83 (无) | 一致 |
| **Move[2]↔[3]** | 63.70 → 69.63 (无) | 1.83 → 1.67 (背驰) | **不同** |
| Move[3]↔[4] | 69.63 → 158.05 (无) | 1.67 → 4.78 (无) | 一致 |
| Move[4]↔[5] | 158.05 → 82.06 (背驰) | 4.78 → 1.67 (背驰) | 一致 |
| **Move[5]↔[6]** | 82.06 → 61.17 (背驰) | 1.67 → 3.79 (无) | **不同** |

差异分析：
- **Move[2]↔[3]**：振幅力度递增（63.70→69.63，价格区间扩大）→ 无背驰。方向性力度递减（1.83→1.67，结构复杂度上升/方向持续性下降）→ 背驰。方向性力度捕捉到了振幅掩盖的方向衰减。
- **Move[5]↔[6]**：振幅力度递减（82.06→61.17，价格区间收缩）→ 背驰。方向性力度递增（1.67→3.79，seg_span 从 3 段扩展到 7 段而 zs_count 不变）→ 无背驰。方向性力度认为结构展开弥补了价格收窄。

## 定义依据

- 振幅力度：`_move_amplitude(move) = |move.high - move.low|`（`multi_tf_adapter.py:181-187`）
- 方向性力度：`_directional_move_force(move, lr) = 0.5 * persistence + 0.5 * density_force`（`multi_tf_pipeline.py:42-89`）
  - density_force = 1 / (zs_count / seg_span)
  - persistence = same_direction_segments / total_segments
- 背驰条件：后一走势力度 < 前一走势力度，且方向相同（缠论第24课/第29课）
- ker(D)：方向算子 D 的核——振幅力度在 D 作用下不变（|high-low| 不区分上涨/下跌），方向性力度不在 ker(D) 中（direction 参与 persistence 计算）

## 边界条件

1. 本次 7 个走势全部为 up 方向（6 个 consolidation + 1 个 trend）——无下跌走势对照。如果存在 down 方向走势，persistence 组件可能产生更大差异。
2. Move[6] 为 unsettled（最新走势），其力度值可能随后续数据变化。
3. 数据窗口为 2024-03 至 2026-02（SPY 处于长期上升趋势），单一方向的走势序列可能不代表震荡市场中的表现。

## 下游推论

1. **ker(D) 有操作意义** `[resolved: 2/6 差异经验验证完成]`：2/6 的判断差异证明方向性力度 ∉ ker(D) 确实产生与振幅力度不同的背驰检测结果。两种力度不可互相替代。
2. **差异的性质** `[resolved: 双向差异性质已确定]`：差异不是单方向的（不是"方向性力度总是更多/更少检测到背驰"），而是双向的——Move[2]↔[3] 方向性力度检测到额外背驰，Move[5]↔[6] 振幅力度检测到额外背驰。两种力度捕捉的是走势的不同维度。
3. **振幅力度捕捉价格区间变化，方向性力度捕捉结构展开模式** `[resolved: 为 v106 双管道回测提供理论依据]`。两者互补而非替代——这为多维度背驰检测（同时使用两种力度，取交集或取并集）提供了实证基础。
4. **对 233号 ker(D) 的最终判定** `[resolved: ker(D) 操作意义已验证，233号已更新验证引用]`：ker(D) 的操作意义已在单层走势上得到验证，不需要 T6 跨级别递归——单 TF 60min 的 7 个走势就产生了可观测的差异。
