# 259号：黄金折叠剥离实验——C-$ 吸收是 C 类资产的一般性质

## 1. 结论

**情景 A 成立**：C_pure(DBA)-$(UUP) 仍在 ker(D) 中，吸收率 = 80.4%。234号 GLD 版本 C-$ 吸收率 = 92.8%。

**核心结论**：C-$ 吸收是 C 类资产（商品）的一般性质，不依赖黄金与美元的特殊计价关系（自指）。232号底空间 B = σ_e × σ_c 直积结构保持有效。254号定理3（黄金折叠→K4退化为K3）是黄金截面的局部奇点，不影响非黄金截面的 K4 完整性。

## 2. 实验设计

| 参数 | 234号（基准） | 259号（实验） |
|------|-------------|-------------|
| E | SPY | SPY（不变） |
| C | GLD（黄金） | DBA（纯农产品 ETF） |
| R | TLT | TLT（不变） |
| $ | UUP | UUP（不变） |
| 期间 | 2007-03-01~2026-02-27 | 2007-03-01~2026-02-26 |
| 交易日 | 4780 | 4779 |

DBA（Invesco DB Agriculture Fund）选择理由：
- 纯农产品成分，不含贵金属（排除 DBC/GSG）
- 不含铜等宏观周期商品（排除 CPER，避免 E-C 噪声）
- 起始日期 2007-01-05，与 234号实验期间完全重叠

### 决胜判据

- 情景 A：C_pure-$ 仍在 ker(D)（高吸收率）→ C-$ 吸收是 C 类的一般性质
- 情景 B：C_pure-$ 移出 ker(D)（保留或放大）→ 234号 C-$ 结论为黄金伪影
- 实际结果：C_pure-$ 吸收率 80.4%，稳固处于 ker(D) 中 → **情景 A**

#### 控制变量验证

三条不变边（E-R, E-$, R-$）全部保持 amplitude 分类——实验控制有效。

#### 实验变量发现

三条替换边（涉及 C）变化显著：

1. **C-$（核心判据）**：amplitude → amplitude，吸收率 92.8%→80.4%。**情景A确认**——C-$ 吸收不依赖黄金自指。吸收率下降 12.4pp，说明黄金增强了 C-$ 耦合强度但不改变拓扑分类。
2. **E-C**：independent → amplitude（∈ ker(D)）。GLD 与 SPY 几乎无偏相关（-0.029），DBA 与 SPY 有正偏相关（+0.217）。黄金的 E-C 独立性是黄金的特殊性质，不是 C 类一般性质。
3. **C-R**：direction → amplitude。GLD-TLT 有方向耦合（234号 C-R 放大比≈76），DBA-TLT 回归幅度耦合（吸收率 64.9%）。黄金-债券的避险方向耦合是黄金特有的。

## 5. 边界条件

### 5.1 吸收率下降（92.8% → 80.4%）

GLD 的 C-$ 吸收率（92.8%）高于 DBA 的 C_pure-$ 吸收率（80.4%）。差异来源：

- 黄金的 $ 计价自指效应增强了 C-$ 连续层耦合（|partial_corr| 从 0.230 增至 0.414）
- DBA 的 |β| = 0.045 接近 kernel_threshold = 0.05 的边界
- **结论翻转条件**：如果 DBA 的 |β| 增加到 > 0.05，C_pure-$ 将移出 ker(D)。当前 |β| = 0.045，距边界仅 0.005

### 5.2 控制变量偏差（R-$）

R-$ 吸收率从 23.3%（234号）跃升至 79.0%（259号）。原因：

- 234号 R-$ 使用 232号偏相关（控制 GLD/SPY），本实验偏相关控制 DBA/SPY
- 控制变量 C 从 GLD 换为 DBA，改变了 R-$ 的条件独立结构
- 234号 R-$ 的 partial_corr = -0.065（弱），259号 partial_corr = -0.157（显著增强）
- 这不影响实验有效性（R-$ 分类不变，仍为 amplitude），但标记了偏相关对控制变量的敏感性

### 5.3 E-C_pure 不再独立

232号底空间直积条件的有效域标注：
- C = GLD 时，E-C 偏相关 ≈ -0.029 → 直积成立
- C = DBA 时，E-C 偏相关 ≈ +0.217 → 直积不成立

232号直积结构有效域 = C 与 E 低相关的资产（黄金符合，农产品不符合）。

### 5.4 DBA 代表性限制

DBA 仅代表农产品。其他商品类别（能源 XLE、基础金属 DBB）可能有不同的耦合模式——需要 L3 验证。

## 6. 下游推论

### 259-1（定理类）：C-$ 吸收是 C 类资产的一般性质

C-$ 吸收不依赖黄金的 $ 计价自指。232号底空间 B = σ_e × σ_c 的直积结构在非黄金截面（DBA 截面）上保持有效。254号定理3（黄金折叠）确认为局部奇点。

### 259-2（定理类）：GLD 的特殊性在 E-C 和 C-R 方向

234号六条边中，GLD 的特殊性表现为：
- E-C 独立（偏相关≈0）：黄金与股票在控制其他变量后几乎无相关
- C-R 方向耦合（放大比≈76）：黄金与债券有方向性联动（避险同向）

DBA（农产品）不具有这两个特征：E-C_pure 回归幅度耦合（偏相关 +0.217），C_pure-R 回归幅度耦合（偏相关 -0.108）。

**235号的 C-R 放大态（三态中最显著的异常）是黄金特有的**，不是"商品 vs 债券"的一般性质。黄金-债券方向耦合反映的是避险资金在黄金和国债之间的流动。

### 259-3（选择类）：纯商品 K4 的"全吸收"结构

DBA 版 K4 六条边全部 ∈ ker(D)——"全吸收"结构。与 GLD 版（4吸收+1方向+1独立）形成拓扑差异：

- 解释 A：纯商品对宏观环境（E, R, $）都是被动响应，没有自身的方向性逻辑
- 解释 B：DBA 的流动性/市场深度不足，导致 BiEngine 离散化精度下降，方向信号被噪声淹没
- 解释 C：农产品价格由供给侧（天气、种植周期）主导，不跟随宏观资本流——幅度随宏观波动，方向独立

编排者需要从 A/B/C 中选择方向（或识别新方向）。

### 编排者决断（260-3）

选择解释 A+C 组合：纯商品对宏观环境被动响应（解释A），且缠论 D 算子对 C 的分辨力依赖货币属性（DBA 无货币属性 → 信号被噪声淹没不是精度问题，是 D 算子的选择性）。

新增推论：
- **259-4**（定理类）：纯消费品"全吸收"是 D 算子的盲区，不是市场的平坦——D 看不见不等于不存在
- **259-5**（定理类）：C 顶点的有效代理条件——需具有货币/结算属性（当前实例：黄金），此条件随公理0的结算尺结晶演化
