# 259号：黄金折叠剥离实验——DBA替换GLD验证C-$吸收的一般性

## 1. 结论

**情景 A 成立**：C_pure(DBA)-$(UUP) 仍在 ker(D) 中，吸收率 = 0.955（高于 234号 GLD 版本的 0.928）。

**核心结论**：C-$ 吸收是 C 类资产（商品）的一般性质，不依赖黄金与美元的特殊计价关系（自指）。232号底空间 B = σ_e × σ_c 直积结构保持有效。254号定理3（黄金折叠→K4退化为K3）是黄金截面的局部奇点，不影响非黄金截面的 K4 完整性。

## 2. 实验设计

|------|-------------|-------------|
| E | SPY | SPY（不变） |
| C | GLD（黄金） | DBA（纯农产品 ETF） |
| R | TLT | TLT（不变） |
| $ | UUP | UUP（不变） |
| 期间 | 2007-03-01~2026-02-27 | 2007-03-01~2026-02-26 |

DBA（Invesco DB Agriculture Fund）选择理由：
- 纯农产品成分，不含贵金属（排除 DBC/GSG）
- 不含铜等宏观周期商品（排除 CPER，避免 E-C 噪声）
- 起始日期 2007-01-05，与 234号实验期间完全重叠

### 控制变量验证

三条不变边（E-R, E-$, R-$）全部保持 amplitude 分类——实验控制有效。

### 实验变量发现

三条替换边（涉及 C）变化显著：

1. **C-$（核心判据）**：amplitude → amplitude，吸收率 0.928→0.955。**情景A确认**——C-$ 吸收不依赖黄金自指。
2. **E-C**：independent → amplitude（ker(D)中）。GLD 与 SPY 几乎无偏相关（-0.029），DBA 与 SPY 有正偏相关（+0.217）。黄金的 E-C 独立性是黄金的特殊性质，不是 C 类资产的一般性质。
3. **C-R**：direction → amplitude。GLD-TLT 有方向耦合（C-R 放大比≈76，235号），DBA-TLT 回归幅度耦合。黄金的 C-R 方向耦合是黄金的特殊性质。

## 5. 边界条件

1. DBA 仅代表农产品。其他商品类别（能源、工业金属）可能有不同的耦合模式——需要更多代理变量的 L3 验证。
2. 2007-2026 期间包含 2008 金融危机、2020 疫情、2022 通胀周期——样本覆盖了多种宏观环境，但不代表所有可能的宏观状态。
3. R-$ 的吸收率从 0.233（234号）跃升至 0.854（259号）——这一变化的原因不清楚（C 替换不应影响 R-$），可能是 DBA inception date 导致的数据对齐差异。需要注意。
4. E-$ 吸收率从 0.967 降至 0.852——同样可能受数据对齐微调影响。

## 6. 下游推论

### 259-1（定理类）：C-$ 吸收是 C 类资产的一般性质

C-$ 吸收不依赖黄金的 $ 计价自指。232号底空间 B = σ_e × σ_c 的直积结构在非黄金截面（DBA 截面）上保持有效。254号定理3（黄金折叠）确认为局部奇点。

### 259-2（定理类）：GLD 的特殊性在 E-C 和 C-R 方向

234号六条边中，GLD 的特殊性表现为：
- E-C 独立（偏相关≈0）：黄金与股票在控制其他变量后几乎无相关
- C-R 方向耦合（放大比≈76）：黄金与债券有方向性联动

DBA（农产品）不具有这两个特征——E-C_pure 回归幅度耦合，C_pure-R 也回归幅度耦合。

**这意味着 235号的 C-R 放大态（三态中最显著的异常）是黄金特有的**，不是"商品 vs 债券"的一般性质。黄金-债券的方向耦合反映的是避险资金在黄金和国债之间的流动，不是商品-固收的一般关系。

### 259-3（选择类）：纯商品 K4 的"全吸收"结构

DBA 版 K4 六条边全部 ∈ ker(D)——这是一个"全吸收"结构。与 GLD 版（4吸收+1方向+1独立）形成对比。

全吸收结构的理论意义：
- 解释 A：纯商品对宏观环境（E, R, $）都是被动响应，没有自身的方向性逻辑
- 解释 B：DBA 的流动性/市场深度不足，导致 BiEngine 离散化精度下降，方向信号被噪声淹没
- 解释 C：农产品的价格由供给侧（天气、种植周期）主导，不跟随宏观资本流——幅度随宏观波动，方向独立

编排者需要从 A/B/C 中选择方向（或识别新方向）。
