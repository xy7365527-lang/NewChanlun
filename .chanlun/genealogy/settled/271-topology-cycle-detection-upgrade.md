# 271号：审讯终止检测升级——从文本stance-diff到拓扑否定边等价检测

## 1. 编排者 INTERRUPT

270号设计用文本层 stance-diff（Key+Value 集合不变）检测立场重复。编排者指出可以升级为拓扑层检测——更稳健。

## 2. 拓扑方法

### 观察

每轮 Gemini 的攻击作为谱系条目写入，有：
- 源节点（攻击依据）
- 目标节点（被攻击的主张）
- 边类型（否定）

如果攻击 N 和攻击 N+3 打的是同一个目标、用的是同一个逻辑结构，它们在拓扑上就是**重复边**或**短环**。

### "法医验尸报告"四轮的拓扑表现

四条否定边，全部从"时间延迟"指向"可观测性主张"：
- R1: 法医验尸报告 → 可观测性
- R2: 偷换概念 → 可观测性（=法医验尸报告变体）
- R3: 时间窗口失步 → 可观测性（=法医验尸报告在三重联立上的投影）
- R4: 区间套实时性幻觉 → 可观测性（=法医验尸报告在区间套上的投影）

topology-analyst 读出多重边 → 触发 suspended:topology-cycle。

### 优势

| 维度 | 文本 stance-diff | 拓扑否定边等价 |
|------|-----------------|---------------|
| 换措辞但逻辑同构 | 可能漏报（Key 命名不同） | 能抓到（源节点和目标节点相同） |
| 相似措辞打不同层面 | 可能误判（Key 名相近） | 不误判（目标节点不同） |
| 基础设施 | inquiry_loop stance-diff | topology-analyst 已有重复边检测 |
| 判据性质 | Key+Value 集合比较 | 拓扑结构（环/多重边）= 结构判据非数字阈值 |

### 触发条件

不设固定数字阈值——用拓扑语言：当否定边形成的子图出现**环**或**多重边**时触发。这是**结构判据**，不是数字阈值（005b号合规）。

## 3. 设计升级

270号选项D修正：
- 检测层从单一文本 stance-diff 升级为三层互补架构（272号裁定修正）：
  1. **拓扑层**：同源同目标的多重边检测（纯结构判据）
  2. **canonical form 层**：不同节点但缺陷本质 ID 相同的语义重复检测
  3. **文本层**（降级方案）：270号 `_check_stance_repetition()` stance-diff
- 检测到拓扑等价否定边 → 冻结为 `suspended:topology-cycle`

## 4. 边界条件

1. 拓扑检测依赖攻击被写入 block-topology——如果攻击未写入拓扑，降级为文本 stance-diff
2. "逻辑结构同构"的判断依赖源节点和目标节点的正确标识——需要在写入时标准化节点命名
3. 270号的文本 stance-diff 作为降级方案保留，两层检测互补
