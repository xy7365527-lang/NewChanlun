# 284号：OQ1-OQ5 动力学维度扩展——形态+测度同步阅读

## 1. 发现

283号确立了缠论已内置拓扑/测度分裂（形态学=D算子产出，动力学=MACD）。原来五个 OQ 全部只考虑了 D 算子的结构产出，没有考虑动力学层。每条边上形态和动力学是两层独立的东西，不可互相替代。

**核心修正**：所有 OQ 的实验设计从"只跑 D 算子看结构"扩展为"同时跑 D 算子和 MACD，记录形态和动力学的一致性与不一致性"。不一致本身是信息，不是误差。

## 2. OQ 逐条重表述

### OQ1（层间时序）

**旧表述**：层1的K4配置转折和层2的个股买卖点之间，谁先谁后？

**新表述**：层间事件的时序关系需要在形态和动力学两个维度上分别考察。四组时序关系：
1. 层1形态事件（中枢破坏） vs 层2形态事件（笔背驰）
2. 层1动力事件（MACD背驰） vs 层2动力事件（MACD背驰）
3. 层1形态事件 vs 层2动力事件
4. 层1动力事件 vs 层2形态事件

两个时序可能不一致。实验应同时记录两层的形态事件和动力事件，看四组时序关系。

### OQ2（E的内部拓扑）

**旧表述**：板块比价的D算子产出是什么拓扑？

**新表述**：板块比价的形态拓扑 + 动力学维度。增加的观察项：板块之间的 MACD 是否给出形态学没有的信息。例如：两个板块比价在形态上还在中枢震荡（没有方向），但 MACD 面积已经连续递减（力度在衰竭）——形态学和动力学的分裂说明板块轮动正在酝酿但还没有在结构上显现。

实验应同时跑 D 算子和 MACD，记录两者一致和不一致的情况。

### OQ3（基本面的地位）

**不变**。理论问题，和动力学层无关。基本面的否决权作用于底空间的可行集，不作用于测度。

### OQ4（K3截面）

**旧表述**：黄金计价下 D 算子产出什么结构？K3 截面下的操作规则？

**新表述**：K3 截面的形态结构 + 动力学可操作性。增加的观察项：K3 下的 MACD 是否还能给出有意义的背驰判断。可能的发现：K3 的形态结构完整（笔和段都在），但动力学退化——MACD 面积的比较失去意义，因为尺子变了。这直接决定 K3 截面下能做什么级别的操作。

**与 OQ5 的关系**：OQ5 读不自洽的形态（结算尺正在运动），OQ4 读退化后还能做什么（结算尺到达极限后的操作空间）。两者保持独立但互为补充。

### OQ5（结算尺状态阅读）

**旧表述**：三重联立判据能否检测到结算尺断裂？

**新表述**：六条 K4 边 + 现金角子图内部比价（美元/黄金、国债/黄金、M2/黄金），同时跑 D 算子和 MACD。观察项不是"三重联立是否触发"，是：

1. 六条边的 D 算子产出之间的不自洽呈现什么形态——哪几条边的走势结构互相矛盾、矛盾在什么级别上出现、纯资产边和现金边讲的故事具体怎么分裂
2. 不自洽有两种独立形态需要区分记录：
   - **形态不自洽**：纯资产边说趋势，现金边说盘整
   - **动力学不自洽**：纯资产边 MACD 不背驰，现金边 MACD 背驰
   - 两种不自洽可能对应不同性质的结算尺状态
3. 在 1971（锚定物变更事件）和 2008（锚定物内部事件）两个已知事件上，这些形态是否有共性、能否分类

**前提修正**：
- 扭曲是常态。不存在"尺子不动"的正常态。美元同时是顶点和尺子 = 当前结算体系的存在方式
- 实验目的不是"验证三重联立能不能检测到断裂"，是在历史已知事件中分类不自洽形态
- 不自洽不是从外面算出来的量，是同一张图同步阅读时看到的东西

## 3. 实验设计原则

所有 OQ 实验的共同原则：
1. **同步记录**：每条边同时产出 D 算子走势结构 + MACD 三维度（面积/DIF峰值/HIST峰值）
2. **不一致分类**：形态一致+动力一致 / 形态一致+动力不一致 / 形态不一致+动力一致 / 形态不一致+动力不一致 — 四种组合各有不同含义
3. **不把不一致当误差**：形态和动力学的分裂是信息，可能是结构变化的先行征兆

## 4. 实验指令（编排者裁定，废除之前的三重联立检测框架）

### OQ5 实验：结算尺状态的结构阅读

**输入边（完整 K4 + 现金角子图）**：

纯资产边：
- ^GSPC/GC=F（E/Au）
- ^GSPC/^TNX（E/R，需处理收益率→价格）
- GC=F/^TNX（Au/R）

现金边：
- ^GSPC（E/$）
- GC=F（Au/$）
- ^TNX（R/$）

现金角子图内部：
- XAU/USD（FRED 长历史）
- 国债/黄金比价
- M2/黄金（如有数据）

**每条边同时跑**：RecursiveOrchestrator（形态学）+ MACD 面积（动力学）

**观察项**：
1. 纯资产边和现金边的叙事是否一致（形态上同向还是矛盾）
2. 纯资产边和现金边的动力学是否一致（背驰状态同步还是分裂）
3. 现金角子图内部的自洽性（USD/Gold 和 Treasury/Gold 讲的故事是否一致）
4. 以上不自洽的形态在不同历史窗口中是否可分类

**验证窗口**：
- 1971 布雷顿森林瓦解（FRED 数据）
- 2002-2007 美元贬值周期
- 2008 流动性危机
- 全历史扫描

**产出**：每个窗口的"六条边 + 现金角子图自洽形态图谱"。不是触发/未触发的二元结果，是形态分类。

### OQ1 实验：层间四组时序关系

层1 = K4 六条比价边。层2 = 个股/ETF 价格序列。

**同时记录四组时序**：
1. 层1形态事件（中枢破坏、走势完成）vs 层2形态事件（买卖点）
2. 层1动力学事件（MACD背驰）vs 层2动力学事件（MACD背驰）
3. 层1形态事件 vs 层2动力学事件
4. 层1动力学事件 vs 层2形态事件

**统计**：四组各自的先后关系、领先/滞后 bar 数、是否有稳定模式。如果四组时序不一致，这本身就是"两层测度独立不可还原"的经验证据。

### OQ2/OQ4 实验：补充 MACD 层

OQ2：记录板块比价的形态-动力学一致性/不一致性。
OQ4：记录 K3 截面下 MACD 背驰判断是否仍有意义。

**数据源**：yfinance + FRED 组合（不变）。
