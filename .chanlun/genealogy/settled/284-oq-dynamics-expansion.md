# 284号：OQ1-OQ5 重表述——D 算子 + MACD 联合阅读

## 1. 发现

283号确立：缠论已内置拓扑/测度分裂（形态学=D算子产出，动力学=MACD）。原来五个 OQ 全部只考虑了 D 算子的结构产出，没有考虑 MACD。

**核心修正**：每条边跑 D 算子 + MACD，一起读，不分层。不一致本身是信息，不是误差。

**编排者废除项**：
- "三层动力学"——从外面对同一张图做的分类，废除。读的就是六条边构成的完整图
- "三重联立是否触发"——二元检测思维，废除。读图的自洽形态
- "前置监控层"——现金角子图是图的一部分，不是前置检查，废除
- "强度"、"噪声"、"降权"、"信号可信度"——度量语言，全部废除

## 2. OQ 逐条重表述

### OQ1（层间时序）

**旧表述**：层1的K4配置转折和层2的个股买卖点之间，谁先谁后？

**新表述**：四组时序关系：
1. 层1形态事件（中枢破坏） vs 层2形态事件（笔背驰）
2. 层1 MACD 背驰 vs 层2 MACD 背驰
3. 层1形态事件 vs 层2 MACD 背驰
4. 层1 MACD 背驰 vs 层2形态事件

如果四组时序不一致，这本身就是不同对象上的积分各自独立的经验证据。

### OQ2（E的内部拓扑）

**旧表述**：板块比价的D算子产出是什么拓扑？

**新表述**：板块比价每条边跑 D 算子 + MACD，一起读。观察项：形态上还在中枢震荡但 MACD 面积已连续递减——这个分裂说明板块轮动正在酝酿但还没有在结构上显现。

### OQ3（基本面的地位）

**不变**。理论问题。基本面的否决权作用于底空间的可行集。

### OQ4（K3截面）

**旧表述**：黄金计价下 D 算子产出什么结构？

**新表述**：K3 截面每条边跑 D 算子 + MACD。观察项：K3 的走势结构完整（笔和段都在），但 MACD 面积的比较是否还有意义（尺子变了之后）。这直接决定 K3 截面下能做什么级别的操作。

**与 OQ5 的关系**：OQ5 读图的自洽形态（当前扭曲形式是否在逼近极限），OQ4 读退化后还能做什么（极限到达后的操作空间）。独立但互补。

### OQ5（结算尺状态阅读）

**旧表述**：三重联立判据能否检测到结算尺断裂？

**废除**：三重联立检测框架、前置监控层、强度/噪声语言、正常态/危机态二分。

**新表述**：六条 K4 边 + 现金角子图内部比价，联合阅读，分类自洽形态。

**前提**：扭曲是常态。美元同时是顶点和尺子 = 当前扭曲的具体形式。纯资产边和现金边的叙事差异永远存在。实验不是检测"异常"，是在不同历史窗口中读图的自洽形态，看这些形态是否可分类。

## 3. 实验指令（编排者最终版）

### OQ5 实验：六条边 + 现金角子图的联合阅读，分类自洽形态

**输入**：K4 完整六条边 + 现金角子图内部比价。每条边跑 RecursiveOrchestrator + MACD。

纯资产边：
- ^GSPC/GC=F（E/Au）
- ^GSPC/^TNX（E/R，需处理收益率→价格）
- GC=F/^TNX（Au/R）

现金边：
- ^GSPC（E/$）
- GC=F（Au/$）
- ^TNX（R/$）

现金角子图内部：
- XAU/USD（FRED 长历史）
- 国债/黄金比价
- M2/黄金（如有数据）

**读法**：六条边一起读。观察纯资产边和现金边讲的故事是否一致、在什么级别上分裂、分裂的具体形态是什么。现金角子图内部（XAU/USD、Treasury/Gold）的结构是图的一部分，不是前置检查。

**验证窗口**：
- 1971 布雷顿森林瓦解（FRED 数据）
- 2002-2007 美元贬值周期
- 2008 流动性危机
- 全历史扫描

**产出**：每个窗口的自洽形态描述（不是触发/未触发）。形态是否可分类。不同窗口之间的形态差异对应什么样的结算尺状态变化。

### OQ1 实验：层间四组时序关系

层1 = K4 六条比价边。层2 = 个股/ETF 价格序列。

同时记录四组时序：
1. 层1形态事件（中枢破坏、走势完成）vs 层2形态事件（买卖点）
2. 层1 MACD 背驰 vs 层2 MACD 背驰
3. 层1形态事件 vs 层2 MACD 背驰
4. 层1 MACD 背驰 vs 层2形态事件

统计：四组各自的先后关系、领先/滞后 bar 数、是否有稳定模式。

### OQ2/OQ4 实验

OQ2：板块比价每条边跑 D 算子 + MACD，记录形态-动力学一致/不一致。
OQ4：K3 截面每条边跑 D 算子 + MACD，记录 MACD 背驰判断是否仍有意义。

**数据源**：yfinance + FRED 组合（不变）。
