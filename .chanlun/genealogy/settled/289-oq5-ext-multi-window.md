# 289号：OQ5-ext 多窗口扩展实验——Au/R 六窗口行为验证

## 递归判断

任务不可分解，因为：实验设计、执行、报告分析是一条串行管线，运行 D 算子是原子操作。

## 1. 实验设计

验证 287号下游推论1：Au/R 背驰状态是否区分'逼近边界'的不同阶段。

六个窗口，每条边在每个窗口内独立跑 RecursiveOrchestrator：

| 窗口 | 日期范围 | 背景 |
|------|---------|------|
| 前危机平静期 | 2005-01-01 ~ 2006-12-31 | GLD 上市后的第一个平静期 |
| 流动性危机 | 2007-01-01 ~ 2009-12-31 | 次贷→雷曼→全球流动性枯竭 |
| 欧债危机 | 2010-01-01 ~ 2012-12-31 | 希腊→PIIGS→OMT |
| 中国股灾 | 2015-01-01 ~ 2016-12-31 | A股崩盘→人民币贬值→熔断 |
| 贸易战 | 2018-01-01 ~ 2019-12-31 | 中美关税→全球供应链重构 |
| 当前周期 | 2020-01-01 ~ 2026-03-01 | COVID→通胀→加息→当前 |

脚本：`scripts/experiments/oq5_multi_window.py`
结果：`tmp/oq5-multi-window-results/`
72 次独立 D 算子运行（6窗口 x 12边），总耗时 234.7s。

## 2. 核心发现

### 2.1 Au/R 只在系统性危机窗口激活

| 窗口 | Au/R 状态 | 含义 |
|------|----------|------|
| 前危机 2005-2006 | **沉寂** | 正常震荡——避险关系未被激活 |
| 流动性危机 2007-2009 | **激活，无背驰** | 逼近边界——力度充沛 |
| 欧债危机 2010-2012 | **激活，无背驰** | 逼近边界——力度仍充沛 |
| 中国股灾 2015-2016 | **沉寂** | 正常震荡——区域性事件不激活避险关系 |
| 贸易战 2018-2019 | **沉寂** | 正常震荡——贸易摩擦不激活避险关系 |
| 当前周期 2020-2026 | **激活+背驰(2 BSP)** | 力度衰竭——20年来首次 |

**三分类**：
- **沉寂**（2005、2015、2018）：系统在正常运作区间，Au/R 比价无走势产出
- **激活无背驰**（2007、2010）：系统逼近边界，避险力度充沛
- **激活+背驰**（2020）：系统逼近边界但力度衰竭——**仅当前窗口出现此状态**

287号假说得到加固。Au/R 背驰确实区分了"逼近边界的不同阶段"。

### 2.2 六窗口全部 0 趋势

| 窗口 | 活跃边 | 背驰边 | 趋势边 | 全盘整 |
|------|--------|--------|--------|--------|
| 前危机 2005-2006 | 2/12 | 1 | 0 | Yes |
| 流动性危机 2007-2009 | 11/12 | 7 | 0 | Yes |
| 欧债危机 2010-2012 | 4/12 | 2 | 0 | Yes |
| 中国股灾 2015-2016 | 1/12 | 0 | 0 | Yes |
| 贸易战 2018-2019 | 0/12 | 0 | 0 | Yes |
| 当前周期 2020-2026 | 11/12 | 9 | 0 | Yes |

287号-3 加固：趋势走势仅在跨周期累积时出现，单窗口内全部盘整。

### 2.3 活跃度梯度

六个窗口的活跃边数形成梯度：0→2→4→1→11→11。
两个系统性危机窗口（2007、2020）活跃度最高（11/12），对称性显著。
中等危机（欧债 2010）活跃度中等（4/12）。
正常/区域事件（2005、2015、2018）活跃度极低（0-2/12）。

### 2.4 沉寂边位置变化

| 窗口 | K4 现金边沉寂 |
|------|-------------|
| 2005-2006 | E/$、Au/$、R/$ 全沉寂 |
| 2007-2009 | R/$ 沉寂 |
| 2010-2012 | E/$ 沉寂 |
| 2015-2016 | E/$、Au/$、R/$ 全沉寂 |
| 2018-2019 | E/$、Au/$、R/$ 全沉寂 |
| 2020-2026 | E/$ 沉寂 |

沉寂位置在危机窗口之间发生结构性变化，在非危机窗口则接近全沉寂。

## 3. 边界条件

- 窗口长度不完全相等（2年/3年/6年混合）——更长窗口有更多结构产出机会。但即使是最长的当前窗口（1547 bars），Au/R 的 3 个走势中只有 2 个 BSP，不是窗口长度决定的
- GLD 上市时间 2004-11，所以 2005 年前的 Au/R 无数据——无法验证更早的危机（如 1997 亚洲金融危机、2001 科网泡沫）
- FRED 汇率 O=H=L=C 退化数据的影响不变
- 所有结论均为 L2 验证，使用同一标的集（SPY/GLD/TLT + FRED 汇率）——L3 需要不同资产组合
