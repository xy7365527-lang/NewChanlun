# 319号：层内折叠否定——断裂事件统计独立，ratio序列不折回自身

## 假设

ratio序列的断裂事件不是独立发生的——后一次断裂的动力学特征被前一次约束。这种序列依赖就是层内折叠（ratio序列自己折回自身）。对应缠论直觉："走势终完美"在ratio层面的表现。

## 检验方法

数据来源：317号实验一的真实数据（Agent A 24个断裂事件 + Agent B 12次中枢转换）。L2级别。

### Agent A（ratio断裂层）

四种离散化方案构建状态转移矩阵 + 连续特征lag-1自相关 + 游程检验：

| 方案 | chi-square p值 | 结论 |
|------|----------------|------|
| 方向二分类 (up/down) | 0.790 | 转移概率接近均匀 |
| 强度三分类 | 0.881 | 完全不显著 |
| 波动率三分类 | 0.307 | 不显著 |
| 游程检验 (up/down) | 0.886 | 序列随机 |

连续特征lag-1自相关：8维全部 < 临界值0.408，无显著自相关。

注：原始4-cluster方案p=0.049，但cluster 2/3各仅1个样本（期望频率<1），检验前提不满足，不可信。

### Agent B（中枢转换层）

转换序列是**完全确定性交替**：extending→expanding→newborn 循环，无例外。这不是"折叠"——这是中枢生命周期的定义。

### 跨层同构

不适用。一边随机一边确定性，性质根本不同，同构检验无意义。

## 判决：否定（0/3）

1. ratio序列断裂事件之间**统计独立**——后一次断裂的动力学特征不被前一次约束
2. "走势终完美"在ratio层面不成立——断裂序列无周期性闭合，无环路结构
3. 层内折叠不存在
4. Agent B的确定性交替是定义层面的，不携带新信息

## 下游推论

1. 折叠的定义不能从"层间映射"改为"自折叠结构的拓扑同构"——因为自折叠结构本身不存在（至少在ratio层不存在）
2. 从317号（层间否定）到319号（层内否定），折叠在FCX/Cu-Au数据上的两条可检验路径都被封死。剩余路径（"类型连续化"）是理论修正不是实验问题
3. 如果发起新实验（不同标的/级别），必须先操作化"逻辑级别"概念——317号推论2仍然成立
