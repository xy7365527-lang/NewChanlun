# 321号：折叠第三轮——历史性的位置：事件外注入，易感性内生产

## 实验设计

### 前两轮误构诊断

前两轮在边上工作。折叠不发生在边上，发生在节点上——同一节点被多条边撕扯到角色不相容的位置。本轮修正对象。

### 核心问题

历史性在折叠中的位置是什么？

- 命题 A（历史性外在）：折叠由不可从走势推导的外部事件决定。节点上的角色不相容是被外部注入的。
- 命题 B（历史性被走势收编）：走势自身的边动态在演化中内在地积累出节点不相容。历史性是折叠被象征化后获得的名字。

### 方法论：不测而测

Agent A 不知道我们在找什么。盲描述三条 ratio 序列（e1=Au/USD, e2=Cu/Au, e3=Au/SPX）的联合动态。节点 = Au。

Agent B 对 GC=F 日线做缠论结构标记（备用验证）。

### 数据

6391日线观测（2000-08-30 ~ 2026-02-27）。三条 ratio 取公共时段交集。

## Agent A 关键发现

1. **e1-e3 正相关25年从未翻转符号**（0.21~0.90）——Au/USD 与 Au/SPX 共享持久公因子
2. **e1-e2 高度时变**（-0.72~+0.17，10次符号翻转）——Cu/Au 与系统的关系不稳定
3. **PC1 解释 62.5% 收益率方差**——存在主导公因子
4. **24个极端期**（Mahalanobis 距离 top 1%），最大 d=15.9（2025-07-31）
5. **有效维度均值 2.02**（1.40~2.83），系统内部结构时变

## 判决执行

### 第三步：统计

- G = 0
- S = 23

**初步判决：命题 A 得到压倒性支持。**

## 判决限定：尺度分离

判决框架暴露了一个盲点——"突然"和"渐进"是尺度相关的。

## 最终判决

命题 A 和 B 不是在同一时间尺度上竞争。

1. **日线级别**：折叠事件本身是外部注入的（命题 A）。走势自身的日线动态不包含关于下一次折叠何时发生的信息。S=23, G=0, p≈0。
2. **年度级别**：折叠发生的条件——系统的耦合度——是走势内在地渐进生产的（命题 B 的变体）。耦合度漂移不是折叠，是折叠的易感性。
3. **综合**：走势不生产折叠，走势生产折叠的易感性。历史性提供事件，走势决定事件的后果。

## 下游推论

1. **可继续检验**：同等规模的外部冲击，在紧耦合时期和松耦合时期，产生的 Mahalanobis 距离是否系统性不同？如果是，走势通过改变耦合度来调制折叠的强度
2. **对折叠体系的修正**：折叠定义需要区分"折叠事件"（外注入）和"折叠条件"（内生产）。292号的折叠本体论需要增加这个维度
3. **与317/319号的关系**：三轮实验形成完整否定链——跨层映射否定(317)→层内序列否定(319)→节点联合动态部分确认(321)。"部分确认"是因为命题B未被否定而是被精化

## 边界条件

1. 如果 epoch 窗口缩短到1年，渐进漂移的pattern可能不同
2. 有效域严格限于 Au 节点 / FCX-Cu-Au-SPX-DXY / 2000-2026 / 日频
3. 判决框架的"突然/渐进"二分法在尺度分离面前不够精细——需要多尺度 entry mode
