## 观察结果

### 观察1（发散——方法论信号）：编排者预判命中率

编排者在三线并行协议中预判："如果发现 eff.dim 压缩深度在各 cluster 之间几乎无差异，直接用波动率 z-score 做判决，不要硬算 Q 值。"

线二结果：eff.dim 压缩深度 CV = 0.052（UNIFORM），Q 值确实退化。编排者的预判完全命中。

这是继 v142-swarm（编排者预见 percentile 四节点收敛）之后的第二次"编排者提前预见实验结果"。模式：编排者在下发实验协议时已经对结果有定性预判，实验的功能不是"发现"而是"确认+量化"。

**方法论含义**：这种模式下，实验的信息增量不在于定性结论（编排者已预判），而在于：
1. 量化参数（CV = 0.052 具体多均匀）
2. 意外发现（OIL 边 11σ vs 非 OIL 边 0.1σ 的二分法未被预判）
3. 否定性分支（Dollar 特异性 = NO，被抑制而非被放大）

**四分法分类**：语法记录候选——编排者预判驱动的实验设计模式。如果在第三轮继续出现，可考虑结晶为"确认+量化"实验范式规则。

### 观察2（发散——新发现）：非 ceremony session 的工作模式转变

本 session 不是蜂群 ceremony，而是编排者直接驱动的实验执行。特征：
- 无 ceremony_scan → 工位列表由编排者直接指定
- 无 RTAS 循环 → Lead 直接 spawn background agent + 等待结果
- 无 rescan → 三线结果汇总后等编排者判断

这是一个新的工作模式——"编排者直驱实验"。与 ceremony 模式的区别：

| 维度 | ceremony 模式 | 编排者直驱模式 |
|------|-------------|--------------|
| 工位来源 | ceremony_scan.py 自动扫描 | 编排者直接指定 |
| 终止条件 | 不动点（rescan 无新工位） | 编排者判断（三线结果评估） |
| Lead 角色 | 调度+路由+持久化 | 执行+汇报 |
| 递归 | 可能多轮 rescan | 单轮（除非编排者追加线程） |

**四分法分类**：语法记录候选——如果"编排者直驱实验"在后续 session 中频繁出现（如 C4/C5 实验），应结晶为与 ceremony 并列的第二种工作模式。

### 观察3（定理）：C3-invariance 否定性结果的认识论价值

线一结论：阈值 NOT_CONVERGENT（max |diff| = 20.94%）。全样本 ~0.8% 是两种制度的加权平均。

这是 231号（形式化有效域规则）的又一正面实例——阈值的"有效域"不是全时间段，而是制度依赖的。QE 期间有效域内的阈值（~1.4%）和非 QE 期间的阈值（3.9-22.4%）是不同的。

否定性结果（"不收敛"）的信息增量高于确认性结果——它缩小了"~0.8% 是什么"的解释空间：不是拓扑不变量，是制度加权平均。

**四分法分类**：定理——231号的正面应用实例（与 327号观察2 同构）。

### 观察4（定理）：坍缩质量二分法——OIL边/非OIL边的 K4 结构意义

线二最意外的发现不是 Q 退化（编排者预判），而是 Sync vs Non-sync 波动率比值的二分：
- 非OIL边（Au/DXY, Au/SPX, DXY/SPX）：Sync/NonSync = 0.47-0.54（同步天**更安静**）
- OIL边（Au/OIL, DXY/OIL, SPX/OIL）：Sync/NonSync = 1.51-1.55（同步天**更波动**）

**K4 结构解读**：在 K4 完全图中，4 个节点有 6 条边。OIL 节点（Commodity）的 3 条边在同步压缩天异常波动，而不含 OIL 的 3 条边反而比平时安静。维度压缩 = "一个节点暴力震荡，其余三个节点的相互关系被冻结"。

这可能指向一个更深层的结构：K4 的同步压缩不是"全图均匀收缩"，而是"一个顶点被外力拉扯，拓扑应力传导到全图导致有效维度坍缩"。OIL 是被拉扯的顶点（2020 负油价），其他三个顶点的相互关系被"冻结"在低维状态。

**四分法分类**：定理——C3 cross-node all-or-nothing 结果的延伸解释。

### 观察5（定理）：三个 cluster 冲击源不同但压缩深度一致

线二报告：Cluster 1 = OIL 冲击（Au/OIL 边 11σ），Cluster 2 = Equity 冲击（SPX/Au 5-6σ），Cluster 3 = Au 冲击（Au/DXY 5σ）。但三个 cluster 的 eff.dim 压缩深度 z-score 几乎相同（CV = 0.052）。

**含义**：冲击可以从 K4 的任何顶点进入，但导致的维度压缩是定量一致的。这支持"阈值因果"框架——一旦冲击强度超过阈值，压缩深度由 K4 拓扑结构决定（而非冲击来源），与冲击的具体来源和强度无关。

这与 C3 v2 的 FLAT 结论互补：条件概率平坦 = 阈值因果，压缩深度一致 = 拓扑决定。

**四分法分类**：定理——C3 v2 THRESHOLD_CAUSAL 的延伸推论。
