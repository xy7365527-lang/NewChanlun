# K4折叠内在性检验：最终结算

**结算时间：2026-03-04**
**替代文件：323号theoretical_settlement.md（2026-03-03版）**

## 一、完整谱系

### 起点

资本流转的拓扑折叠被什么决定？走势还是基本面？

推进路径：
1. 二元对立被解构——"基本面"是K4拓扑折叠的投影，不在拓扑之外
2. 折叠生产级别，级别事后遮蔽折叠的历史来源
3. 走势自身应该能生产折叠——级别不是预先存在的
4. 核心问题收窄：历史性在折叠中的位置是什么？
5. 两个竞争命题：走势能否内在地生产折叠，还是折叠由外部事件注入？

### 折叠概念

折叠 = 同一节点在K4的不同流转回路中承担不相容的角色。Au同时是美元对立面（Au/$）、风险偏好分母（Cu/Au）、避险资产（Au/SPX）。当三个角色不能被同一个价格同时满足时，节点被折叠。

概念拓扑的折叠与此同构：一个概念在不同话语回路中承担不同角色，当这些角色不能被同一个定义满足时，概念被折叠。

## 二、实验结果完整汇总

### 第一轮：跨层事件映射 → 全部否定（0/3）

聚类数量N=4而非预期的3（轮廓系数0.200），聚类-中枢对应Fisher p=1.000（完全随机），时间方向性54%正侧p=0.42（无方向性）。

**否定内容：** ratio断裂与中枢状态之间不存在事件级别的对应。

**误构诊断：** 对象错误——在边上工作，但折叠发生在节点上。

### 第二轮：层内序列结构 → 全部否定

方向转移chi2 p=0.79，强度转移chi2 p=0.88，波动率转移chi2 p=0.31，连续自相关全部低于临界值。

**否定内容：** ratio断裂事件之间统计独立。"走势终完美"在ratio层面不成立。缠论中枢状态转换是语法规则，不是经验类型学。

**误构诊断：** 仍在边上工作。

### 第三轮：Au节点联合动态盲描述

24个联合结构突变事件中G=0, S=23, U=1。

**核心判决：日线折叠由外部事件注入。** 走势自身的日线动态不包含关于下一次折叠何时发生的信息。在日线级别，历史性是外在的。

**同时发现：** 三条边的年度相关结构在缓慢漂移。有效维度（eff.dim）从1.40到2.83，走势内在地改变着系统的耦合度。

### 第三轮附加：Au节点级别与折叠的关系

**命题一（eff.dim是级别的度量）→ 通过。** T组均值2.269 vs N组2.356，Welch t=-15.44 p≈0，Cohen's d=-0.39。走势在场时系统被压缩到低维。

**趋势方向不对称（独立发现）：** 上升趋势越走eff.dim越高（r=+0.79, +0.88），下降趋势越走eff.dim越低（r=-0.43, -0.77）。下降趋势eff.dim均值1.982，上升趋势2.350（t=63.78 p≈0）。上升散开，下降压缩。

**命题二（级别调制折叠深度）→ 不通过。** Spearman ρ=+0.09 p=0.33。多窗口稳健性均不显著。

**事件密度 → 不通过。** T组4.52/1000d vs N组4.09/1000d，Fisher p=0.66。级别不调制折叠频率。

**阈值效应 → 边缘支持。** eff.dim<1.8的区间（占1.3%天数）零极端事件。事件eff.dim均值2.347 vs总体2.297，Welch t p=0.073。

### 四节点复制：$、Equity、Commodity

**不对称性——四节点四种模式（编排者"普通节点对称、$节点不对称"假说被否定）：**

| 节点 | 上升段散开？ | 下降段压缩？ | 模式 |
|------|------------|------------|------|
| Au | 2/2 ✓ | 2/2 ✓ | 对称 |
| $ | 1/3 ✗ | 4/5 ✓ | 不对称（上升不散开） |
| Equity | 2/4 ✗ | 1/4 ✗ | 混合 |
| Commodity | 4/4 ✓ | 2/4 ✗ | 反向（falling均值>rising均值） |

**实物/名义二分法（从数据涌现但非检验结论）：** Au+Commodity上升散开鲁棒，$+Equity上升不散开。下降压缩在Au+$上鲁棒，在Equity+Commodity上混合。

**命题二四节点全部FAIL：** 级别不调制折叠深度是K4层面结论。

**事件密度四节点全部无显著差异：** 级别不调制折叠频率是K4层面结论。

**Mahalanobis距离跨四节点恒等：** log(a/b)=-log(b/a)，四个节点看到的是同一组64天、同一组23个事件。折叠不是节点局部事件，是K4整体的全局事件。

### 三条数据线

**数据线一（共享边假说）→ 两组分群确认但p=0.79。** Group A（Au, $）frac_below~7%，Group B（Equity, Commodity）frac_below~0.8%。跨组距离是组内距离的30-150倍。统计功效不足。

**数据线二（QE跨节点验证）→ QE方向分裂与分群一致。** Group A QE期eff.dim降低（d=-0.72, -0.87），Group B升高（d=+1.05, +0.23）。四节点全部p≈0。

**数据线三（相对阈值）→ percentile收敛。** 统一边结构（CL=F）后四节点min event percentile：Au 0.77%, $ 0.60%, Equity 0.78%, Commodity 0.81%。极差0.21pp。之前Au/$=7% vs Equity/Commodity=0.8%的分裂是代理选择差异导致的伪影。

### C阶段

**C1（有效一维条件）→ 不完全解释。** PC1>90%不普适（Equity在事件地板处PC1=85%）。percentile~0.8%收敛是真实的但不被"有效一维"完全解释。

**C2（QE期间Group A/B有效一维区间验证）→ 方向性全部一致。** Au/$非QE期间0天在有效一维区间，QE期间18-19天——一个从未自发发生过的状态被制度干预创造出来了。Equity从未接近有效一维。

**C3-empirical（阈值因果直接检验）→ 通过。** P(Mahalanobis极端事件 | eff.dim > t-th percentile)在t从0.8%移到50%过程中稳定在~1.0%（范围0.78%-1.24%），四节点斜率全部不显著（p>0.05）。**阈值因果成立，线性因果被否定。**

**C3 交叉节点同步性 → all-or-nothing。** 64个极端日中，below 5th percentile的分布完美二分：56/64天四节点全部>5%，8/64天四节点全部<5%，0天部分同步。不存在"局部折叠"。

**C3-invariance（percentile阈值QE/非QE不变性）→ 不收敛。** QE期地板percentile 1.17-1.44%，非QE期3.87-22.38%。~0.8%全样本收敛是两个不同制度的加权平均，是统计伪影。**QE不只改变eff.dim分布，还改变阈值本身。**

**坍缩质量分析 → 边冻结机制确认。** 同步压缩天的非OIL边波动率只有正常天的0.47-0.54倍。OIL边波动率是正常天的1.51-1.55倍。**向心坍缩 = 只有一条边在动，其他边被冻结。维度压缩的机制是冻结，不是震荡。** $在同步压缩中是最安静的节点（vol z=3.85 vs 其他节点6.37）。

## 三、什么被确认，什么被否定，什么留存

### 被确认的（按确认强度排序）

1. **折叠是K4的全局事件，不是节点局部的。** Mahalanobis恒等性 + all-or-nothing同步压缩。没有"局部折叠"。

2. **日线折叠由外部事件注入。** S=23, G=0, p≈0。走势的日线动态不包含下一次折叠的信息。

3. **eff.dim是级别的可操作度量。** 四节点、跨两种走势定义方法（MA和手工标注）鲁棒。走势在场时系统被压缩到低维。

4. **阈值因果成立。** 跨过阈值后P(fold)~1%恒定，不随eff.dim进一步增加。级别提供折叠的可能性条件，不调制深度和频率。

5. **趋势方向不对称地改变eff.dim。** 下降压缩跨Au+$鲁棒（6/7段一致）。上升散开在Au+Commodity上鲁棒（6/6段一致），在$+Equity上不鲁棒。

6. **QE系统性改变eff.dim分布方向。** Group A（Au, $）被压向低维，Group B（Equity, Commodity）被推向高维。四节点方向性无例外。

7. **向心坍缩的机制是边冻结。** 同步压缩天非OIL边波动率降低一半。$在坍缩中最安静。

8. **级别不调制折叠深度。** 四节点Spearman ρ全部不显著。K4层面确认。

9. **级别不调制折叠频率。** 四节点Fisher p全部>0.25。K4层面确认。

### 被否定的

1. **跨层事件对应。** 两轮实验否定。ratio断裂与中枢转换在时间上基本独立。

2. **层内序列结构。** ratio断裂之间无记忆。"走势终完美"在ratio层面不成立。

3. **缠论中枢状态作为经验类型学。** 中枢三状态的转换序列是定义内置的语法。

4. **"普通节点对称、$节点不对称"假说。** 四个节点四种模式。二分法不成立。

5. **~0.8% percentile作为K4拓扑不变量。** 是QE期和非QE期两个不同分布的加权平均。制度干预改变阈值本身。

6. **$边波动率异常作为不可逆坍缩签名。** 方向反了。$在坍缩中最安静。

7. **Q值框架（$边vol z-score / |eff.dim压缩深度|）。** eff.dim压缩深度跨cluster均匀（CV=5.2%），分母退化为常数。

### 留存待决的

1. **可逆坍缩与不可逆坍缩的区分。** 概念上有意义但经验基础只有n=3同步压缩cluster（全在2020年），且Cluster 1被负油价合约事故污染。不能推广。

2. **实物/名义二分法的检验。** 从四节点数据涌现但未被独立检验。四个数据点上的事后分组。

3. **制度相关阈值的具体形式。** QE下阈值~1.4% percentile，非QE下阈值3.9-22.4%。但两个值各自是否稳定不知道。

4. **边的内部结构。** 卢麒元指出的实物黄金/纸黄金背离 = Au/$边内部的分裂。当前框架把边当作原子的ratio。边的内部分裂是更深一层的危机，框架未覆盖。

## 四、理论后果

### 对折叠概念的最终修正

折叠是K4的全局事件。不是一个节点被折叠——是全图同步坍缩。四个节点的eff.dim要么全部在正常范围（可折叠相），要么全部被同步压缩到极端（不可折叠相）。

折叠的触发是外部事件（日线级别）。折叠的可能性条件是eff.dim高于阈值（走势内在地通过趋势方向改变eff.dim）。阈值本身被制度干预改变。

### 两相框架

| | 不可折叠相 | 可折叠相 |
|---|---|---|
| 条件 | eff.dim < 阈值（制度相关） | eff.dim > 阈值 |
| 外部冲击效果 | 被公共因子吸收 | 产生角色不相容 |
| 折叠行为 | 不可能 | 可能但深度/频率不取决于eff.dim |
| 机制 | 边冻结（非活跃边波动率降半） | 边独立运动 |

阈值因果的核心特征：跨过阈值后条件概率恒定（~1%），不随eff.dim进一步增加。级别提供的是开关，不是调节器。

### 自发/自觉区分

走势的自发维度（eff.dim漂移、趋势方向不对称性）遵循可检测的内在规律。制度干预（QE、布雷顿森林体系、利率决策）从外部打断或偏置这些规律。缠论描述的是自发层的结构（笔、线段、中枢），不描述制度层的干预。

ratio层面"走势终完美"不成立的原因：ratio混合了自发动态和自觉干预。每一次制度性利率决策都在ratio序列中注入不可从走势推导的断裂。

### 与卢麒元向心坍缩的交汇

卢麒元从《资本论》第二卷的资本循环断裂出发：金融资本脱离产业循环→堰塞湖→向心坍缩（流动性冻结→一切资产以$定价→资本回流美国→抄底全球）。

K4框架从拓扑出发：all-or-nothing同步压缩→四节点eff.dim同时跌入底部→一个公共因子支配全部六条边→$成为唯一定价标准。

两者在"全图同步坍缩到一维、$的度量功能达到极致"这个结构上完全一致。向心坍缩的"心"就是$的度量功能。坍缩的机制是边冻结——不是所有边一起震荡，而是只有一条边在动、其他边被冻结。自由度消失。

卢麒元的终局性预测（下一次坍缩不可逆）在K4上对应：坍缩过程中$的度量功能被否定→一维态本身瓦解→K4的ratio定义基准消失。这是语义相变——不只是拓扑相变。当前框架未能覆盖。

## 五、对操盘的可用产出

1. **eff.dim是实时可计算的级别度量。** 取任意节点的三条边的rolling correlation matrix，计算特征值的Shannon entropy指数。

2. **下降趋势中对冲失效。** 系统被压缩到低维，所有边共线。分散化不工作。

3. **上升趋势中实物资产节点（Au, Commodity）散开。** 不同资产开始讲不同的故事，对冲空间打开。名义资产节点（$, Equity）不确定。

4. **eff.dim处于自身分布的极端低位时极端事件极少发生。** 不是交易信号，是风险判断的背景：全局坍缩态中系统被锁定，不会产生角色不相容。

5. **QE系统性地保护名义资产节点免于折叠，同时暴露实物资产节点于折叠。** 这是QE环境下资产配置的结构性偏置。

## 六、开放问题

1. **不可逆坍缩的形式化。** 数据基础不足（n=3同步压缩cluster）。需要下一次同步压缩事件的新数据。

2. **制度相关阈值的稳定性。** QE期和非QE期各自的阈值是否在其制度期内保持恒定？

3. **边的内部结构。** 实物黄金/纸黄金背离 = 一条边内部的分裂。框架需要扩展。

4. **K4的全局度量。** 四个节点的eff.dim是六条边联合结构的四个三维切片。正确的全局量应该是6×6协方差矩阵的谱，而非节点级别的3×3切片。

5. **上升/下降不对称的来源。** 为什么下降压缩比上升散开更鲁棒？是K4的一般性质还是当前美元体制的特殊性质？
