# 334号：同步压缩是体制不是事件——329号三项修正 + 分析框架转换

## 起点

329号最终结算基于 yfinance CL=F（原油期货）数据识别出 2020 年的 3 个分离的同步压缩 cluster（2020-04、2020-06、2020-11）。用 FRED DCOILWTICO（WTI 现货）替代 CL=F 后，三个 cluster 合并为一个连续 263 天的同步压缩体制（2020-04-03 to 2021-04-23）。

CL=F 的合约展期跳跃在连续压缩态中制造了虚假间隔。三个"事件"实际上是一个持续体制。

## 数据证据

| 分析 | 数据源 | 窗口 | Cluster 数 |
|------|--------|------|-----------|
| 329号原始 | yfinance CL=F（期货）| 2000-2025 | 3 |
| 本次四节点 | yfinance + FRED WTI现货 | 2000-2025 | **1**（263天连续） |
| 本次三节点（无Au）| yfinance + FRED WTI现货 | 1986-2025 | 3（1987/1990-91/2020-21） |

三节点 40 年分析新增了两个体制：
- 1987-01-06 to 1987-02-04（22天）
- 1990-10-23 to 1991-09-06（219天）——海湾战争

## 329号三项修正

### 修正一：all-or-nothing 的含义从离散共现变为持续相态

**329号原文**："64个极端日中8天四节点同步在底部5%，0天部分同步。"

**修正**：这8天不是散布在25年里的8个独立事件。它们集中在一个263天的连续窗口内。all-or-nothing 不是描述离散事件的共现，是描述一个**持续相态**的存在。K4 进入了不可折叠相，然后住在里面 263 天。

不可折叠相是一种**体制**（regime），不是一种**事件**（event）。体制有进入、持续、退出三个阶段。事件是点状的，体制是区间状的。

### 修正二：阈值因果的统计基础从 n=8 天变为 263 天连续窗口

**329号原文**："跨过阈值后 P(fold) ~1% 恒定，不随 eff.dim 进一步增加。"

**修正**：统计基础不是"8天中0次折叠"，而是"263天的连续窗口中折叠行为被系统性地抑制"。这反而**更强**——一个连续的 263 天窗口比 8 个散布的独立日子提供了更强的证据说明不可折叠相中折叠不发生。

### 修正三：向心坍缩是持续状态不是瞬间事件

**329号原文**：向心坍缩与 K4 全图同步压缩在结构上一致。

**修正**：向心坍缩不是"某天市场崩了"。它是一个持续的状态。2020年3月 COVID 冲击把 K4 推进不可折叠相，然后 QE 把系统**锁在**那个状态里——直到 2021 年 4 月通胀开始显现，系统才退出。263 天的连续压缩 = QE 制造的向心坍缩态的持续时间。

## 分析框架转换

### 旧框架（329号）

分析对象 = 离散的同步压缩**事件**（cluster）。统计方法 = 跨事件比较。硬约束 = 事件数量太少（n=3）。

### 新框架（本谱系）

分析对象 = 同步压缩**体制**（regime）。统计方法 = 体制内部的时间序列分析。每个体制有几十到几百天的内部数据，统计基础在**体制内部**。

三个已识别体制：
1. **1987 体制**（22天，三节点）
2. **1990-91 体制**（219天，三节点）——海湾战争
3. **2020-21 体制**（263天，四节点）——COVID + QE

频率约每 13 年一次。拉长历史不会大幅增加体制数量——全图同步压缩是极端体制，不是高频事件。

### 新框架下的可执行分析

1. **体制进入/退出的边冻结序列**（330号"断裂位点→边冻结模式"预测的直接检验）
   - 三个体制各自的断裂节点是否不同
   - 不需要跨体制统计——每个体制内部有足够数据

2. **体制内部 eff.dim 演化**
   - 进入速度 vs 退出速度
   - 内部结构（平坦/加深/反转）
   - 跨体制共同模式

3. **basis 前导性**（仅 2020-21 体制）
   - 体制进入前 60 天的 basis 行为 vs 正常期
   - 单体制内有足够数据点

## 329号原始结论的状态

| 329号结论 | 本修正后状态 |
|-----------|-------------|
| 折叠是 K4 全局事件 | **加强**：不只是全局事件，是全局体制 |
| 日线折叠由外部事件注入 | **不变**：体制由外部冲击触发 |
| eff.dim 是级别度量 | **不变** |
| 阈值因果成立 | **加强**：263天连续窗口，统计基础更强 |
| all-or-nothing 同步 | **修正**：从离散共现修正为持续相态 |
| 向心坍缩 = K4 同步压缩 | **修正**：向心坍缩是持续状态不是瞬间事件 |
| n=3 cluster 统计不足 | **修正**：n=3 体制，但分析对象转为体制内部 |

## FRED London Fix 黄金数据删除

FRED 于 2022-01-31 永久删除了 GOLDAMGBD228NLBM（LBMA London Fix Gold AM Price）和相关 IBA 数据。1986-2000 的黄金现货日线数据无法通过免费公开渠道获取。四节点分析仍受限于 2000 年（GC=F 起始）。

要覆盖 1986-2000 的四节点分析需要付费数据源（Bloomberg/Refinitiv）。当前三节点分析（无 Au）可回溯到 1986 年。

## 边界条件

1. 如果 CL=F 和 DCOILWTICO 的差异不只是合约展期（例如期货市场结构性 contango/backwardation 携带信息），则三 cluster 合并为一可能丢失了信息
2. 体制的边界（进入日和退出日）取决于 5th percentile 阈值——阈值本身是全样本统计量，改变阈值会改变体制边界
3. 1987 体制（22天）可能太短，不足以做有意义的内部时间序列分析
4. 三节点体制（无 Au）与四节点体制（有 Au）不完全可比——缺少 Au 节点意味着少了 3 条边
