# 349号：赋格状态机形式化定义

## 1. 结论

赋格状态机的形式化定义已具备完整的谱系基础和工程实现。本谱系将分散在 267号第七节、265号层2、338号修正中的赋格概念统一为显式的状态机规格。

### 1.1 有效域声明

赋格状态机的有效域是**单一标的上的多级别嵌套短差操作**（267号第七节定义）。不是帕萨卡利亚三层之间的层间关系（264号已否定赋格在本体论层面的适用性），而是层2内部（265号§2.3）或单标的操作级别内部（267号§七）的多声部嵌套。

### 1.2 赋格的定义（267号第七节原文）

> 满仓满融下赋格 = 同一个满仓仓位上、不同级别的短差操作的嵌套 + 小转大后新旧循环并存。不是多个独立仓位的并行操作，是单一仓位上的多层嵌套。

---

## 2. 状态集 S

赋格状态机嵌入降成本状态机内部。降成本状态机的五态已由 267号§二和 cost_reduction_fsm.py 定义：

| 状态 | 符号 | 语义 |
|------|------|------|
| 选股扫描 | SCANNING | 无持仓，等待买点 |
| 建仓完成 | POSITION_OPEN | 满仓满融已建仓，等待次级别卖点启动降成本 |
| 降成本运行 | COST_REDUCING | 次级别短差循环运行中 |
| 本金已退出 | PRINCIPAL_WITHDRAWN | 累计回收 >= 初始自有资金，免费仓位 |
| 止损退出 | STOPPED_OUT | 买点结构失效，全部清仓 |

赋格扩展的状态维度——**声部数量 V(t)**：

| V(t) | 含义 |
|------|------|
| V = 0 | 无声部（SCANNING 或 STOPPED_OUT） |
| V = 1 | 单声部（正常降成本，尚未发生小转大） |
| V >= 2 | 多声部（小转大后，旧循环利润底仓 + 新级别新降成本循环并存） |

赋格状态 = (降成本状态, 声部集合)。声部集合是赋格的核心——每个声部是一个 (级别, 持仓份额, 是否利润底仓, 累计利润) 四元组。

## 3. 输入字母表 Σ

| 事件 | 符号 | 来源 |
|------|------|------|
| 买点确认 | BUY_POINT_CONFIRMED | 缠论区间套收敛到一买 |
| 次级别卖点 | SUB_LEVEL_SELL_POINT | 次级别走势类型完成的卖出信号 |
| 次级别买点 | SUB_LEVEL_BUY_POINT | 次级别走势类型完成的买入信号 |
| 买点失效 | BUY_POINT_NEGATED | 买点定义条件被否定 = 止损 |
| 主级别卖点 | MAIN_LEVEL_SELL_POINT | 主级别走势类型完成 = 正常退出 |
| 小转大 | LEVEL_UPGRADE | 次级别走势超出次级别结构范围，更大级别结构成立 |
| 重置 | RESET | 止损后重新进入扫描（own_capital 动态重置，338号修正1） |

不存在 SWAP / SWITCH_POSITION（不换仓原则，267号§五）。

## 4. 转移函数 δ

### 4.1 核心转移

| 当前状态 | 事件 | 下一状态 | 副作用 |
|----------|------|---------|--------|
| SCANNING | BUY_POINT_CONFIRMED | POSITION_OPEN | 满仓满融建仓，V := 1 |
| POSITION_OPEN | SUB_LEVEL_SELL_POINT | COST_REDUCING | 开启第一个短差循环 |
| POSITION_OPEN | BUY_POINT_NEGATED | STOPPED_OUT | 止损，V := 0 |
| COST_REDUCING | SUB_LEVEL_BUY_POINT | COST_REDUCING / PRINCIPAL_WITHDRAWN | 买回完成短差；若累计回收 >= own_capital 则转 PRINCIPAL_WITHDRAWN |
| COST_REDUCING | SUB_LEVEL_SELL_POINT | COST_REDUCING | 开启新短差循环（需前一短差已关闭） |
| COST_REDUCING | BUY_POINT_NEGATED | STOPPED_OUT | 止损，V := 0 |
| COST_REDUCING | MAIN_LEVEL_SELL_POINT | STOPPED_OUT | 正常退出 |
| COST_REDUCING | LEVEL_UPGRADE | COST_REDUCING | **赋格分裂**（见 §4.2） |
| PRINCIPAL_WITHDRAWN | MAIN_LEVEL_SELL_POINT | STOPPED_OUT | 免费仓位退出 |
| PRINCIPAL_WITHDRAWN | BUY_POINT_NEGATED | STOPPED_OUT | 免费仓位止损 |
| PRINCIPAL_WITHDRAWN | SUB_LEVEL_SELL_POINT | COST_REDUCING | 免费仓位上继续短差 |
| STOPPED_OUT | RESET | SCANNING | 动态重置 own_capital（338号修正1） |

### 4.2 赋格分裂（LEVEL_UPGRADE）

小转大触发赋格分裂——这是赋格状态机的核心事件：

1. 当前短差停止（active_short_diff := None）
2. 旧声部冻结为利润底仓：FugueVoice(level=旧级别, is_profit_floor=True, cumulative_profit=已回收)
3. 新声部启动：FugueVoice(level=新级别, is_profit_floor=False, cumulative_profit=0)
4. 操作级别切换到新级别（entry_level := 新级别）
5. 等待新级别的次级别出现后，在新级别上继续短差降成本

赋格分裂可以递归发生——如果在新级别上再次发生小转大，产生第三个声部。声部数量无上限（受市场级别层次限制）。

### 4.3 强趋势浅回调规则（338号修正4）

当次级别卖出后，若次级别买点价格 >= 前次卖出价格，**不执行加回**。仓位保持减仓状态，等待：
- 更深回调出现低于前次卖出价格的买点 → 恢复降成本操作
- 小转大确认 → 在新级别上重新定义短差参数

## 5. 输出函数 ω

| 状态/事件 | 输出 |
|----------|------|
| 短差完成（买回） | cost(t) = cost(t-1) - profit(t) / total_shares |
| 赋格分裂 | 声部集合扩展，操作级别上移 |
| 累计回收 >= own_capital | 状态转 PRINCIPAL_WITHDRAWN，资金释放信号 |
| 止损 | 全部清仓信号 |

### 5.1 成本递推公式（267号§3.2 / 255号步骤3）

```
cost(t) = cost(t-1) - profit(t) / size(t)
```

其中 profit(t) = (sell_price - buy_price) * short_shares，size(t) = total_shares。

## 6. 与帕萨卡利亚的映射

| 帕萨卡利亚结构（265号） | 赋格状态机对应 | 映射关系 |
|------------------------|---------------|---------|
| 层0 固定低音线 | 四层递归状态机 L0（state_machine.py） | 层0不参与赋格——赋格在层2内部 |
| 层1 和声进行 | 四层递归状态机 L1 | 层1设定操作约束，不参与赋格 |
| 层2 旋律赋格 | 降成本状态机（cost_reduction_fsm.py） | 赋格状态机运行在层2内部 |
| 声部（FugueVoice） | 小转大后的多循环并存 | 每个声部 = 一个级别上的降成本循环 |

264号确认赋格在层间（层0-层1-层2之间）不适用——层间关系是条件设定（帕萨卡利亚通奏低音），不是赋格（声部平等对位）。赋格只在层2内部成立，因为层2内部的时间尺度差距可仲裁（265号§4.3：分钟到小时，同数量级）。

---

## 7. 递归同构：帕萨卡利亚 = 走势类型的递归

帕萨卡利亚结构与缠论走势类型的递归是同构的：

| 帕萨卡利亚 | 缠论 |
|-----------|------|
| 固定低音线（ostinato） | 主级别走势类型（不变的结构约束） |
| 上层声部在低音线框架内变奏 | 次级别走势在主级别约束内展开 |
| 声部之间的对位规则 | 买卖点定律（次级别一类买卖点 = 本级别二类买卖点） |
| 小转大 = 低音线本身被新的、更大的低音线取代 | 更大级别结构成立，旧主级别变为次级别 |

这个同构不是外部类比，是缠论递归结构的自然形式——267号从缠论内部推导出的赋格定义恰好与帕萨卡利亚同构。265号的帕萨卡利亚类比事后被确认为恰当的（267号§与265号帕萨卡利亚的关系）。

## 结果包六要素

### 1. 结论

赋格状态机 = 降成本状态机 + 声部维度扩展。五态 + 七种事件 + 赋格分裂（小转大触发）。形式化定义完整：状态集（§2）、输入字母表（§3）、转移函数（§4）、输出函数（§5）。赋格运行在帕萨卡利亚层2内部，不在层间。

### 2. 定义依据

| 概念 | 来源 | 关键表述 |
|------|------|---------|
| 赋格定义 | 267号§七 | 满仓满融下赋格 = 单一仓位多层嵌套 |
| 降成本三阶段 | 267号§二 | 建仓→降成本→零成本运营 |
| 多重赋格 | 缠师第40课 | 同一标的不同级别同时产出买卖点 |
| 帕萨卡利亚层2 | 265号§2.3 | 层2旋律声部 = 多级别同步运行 |
| 小转大 | 267号§三 / 338号修正4 | 不可事前预测，事后由结构确认 + 强趋势浅回调处理 |
| 初始自有资金动态重置 | 338号修正1 | 每次新循环独立核算 |

### 3. 边界条件

- **赋格分裂次数**：理论上无上限，实际受市场级别层次限制（从1min到年线，缠论级别有限层）
- **声部间资源竞争**：多声部共享同一仓位，声部间的短差操作不能超过总仓位。当前实现中每层短差动用比例 <= sub_ratio（267号§不入语法的外部参数），多声部并存时需确保总动用比例不超过 100%
- **本体论层面**：赋格在层间（L0-L1-L2）不适用（264号）。若未来发现层间存在可仲裁的时间尺度关系（当前无此证据），层间赋格需重新评估
- **338号修正4翻转条件**：如果次级别回调深度始终不足，最终必须由小转大或主级别卖点终结循环
