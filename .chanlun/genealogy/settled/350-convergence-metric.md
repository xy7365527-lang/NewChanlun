## 结论

定义**收敛紧度函数** T(S)，用于在多标的之间排序区间套收敛质量。

### 概念来源

区间套：从大级别向小级别逐级寻找背驰点（即买卖点）的方法。（缠论知识库 11.1）

缠师原文（第27课）：
> "某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。"
> "在5分钟进入背驰段后，找1分钟相应段的背驰段，再找1分钟背驰段的背驰段，这样就可以精确定位了。"

267号操作方法论：
> "收敛紧度 = 嵌套层数 x 级别大小 x 各层一致性。大级别收敛优于小级别收敛。"

### 输入

给定标的 S 的区间套搜索结果（NestedDivergence 链），定义如下。

### 三项分量

**1. 嵌套层数 D(S)（depth）**

D(S) = 区间套背驰链中实际检测到背驰的级别数量。

```
D(S) = |{L_i ∈ chain(S) : div(L_i) ≠ None}|
```

含义：有多少个级别的买卖点在时空上重叠。D(S) >= 1（至少一个级别有背驰），D(S) = 0 表示无区间套。

示例：5分钟背驰 + 1分钟背驰 + 次1分钟背驰 → D = 3。

**2. 级别大小 L(S)（level magnitude）**

L(S) = 区间套链中最高级别的 level_id。

```
L(S) = max{level_id(L_i) : L_i ∈ chain(S), div(L_i) ≠ None}
```

含义：涉及的最大级别——越大越有信号意义。周线背驰套日线背驰优于5分钟背驰套1分钟背驰。

注意：level_id 是递归层级编号，由自底向上的递归构造决定，不是时间周期。level_id 越大，级别越大。

**3. 各层一致性 C(S)（consistency）**

C(S) = 链中所有有效背驰的方向一致率。

```
directions(S) = {direction(div(L_i)) : L_i ∈ chain(S), div(L_i) ≠ None}

C(S) = 1  若 |directions(S)| = 1（全部同方向）
C(S) = 0  若 D(S) = 0（无背驰）
C(S) = max_count / D(S)  否则
       其中 max_count = max{count(d) : d ∈ directions(S)}
```

含义：所有级别的买卖点是否同方向（都是买点或都是卖点）。完全一致 = 1.0，完全矛盾 = 0.5（两个级别各一个方向）。

### 收敛紧度函数 T(S)

```
T(S) = D(S) * L(S) * C(S)
```

**排序规则**：T(S1) > T(S2) 则 S1 优先于 S2。

**退化情况**：
- 若标的无区间套（D = 0）→ T = 0，不参与排序
- 若只有一个级别的背驰（D = 1）→ T = L(S) * 1.0 = L(S)，退化为纯级别大小排序
- 若多级别但方向不一致（C < 1）→ 收敛紧度被一致性折扣

### 多标的选择流程（267号第一步的量化）

给定通过二值筛选的标的集合 {S1, S2, ..., Sn}，对每个标的执行区间套搜索，计算 T(Si)，选择 T 最大的标的。若存在 T 相等的标的，选 L 更大的（大级别优先——267号"大级别收敛优于小级别收敛"）。

## 边界条件

1. **level_id 的语义**：level_id 是递归层级编号，不是时间周期。两个不同标的的 level_id=3 可能对应不同的时间跨度（取决于各自的递归深度）。因此 L(S) 在跨标的比较时假设所有标的使用相同的递归构造基底。如果递归基底不同（例如一个用1分钟K线，另一个用5分钟K线），L(S) 的跨标的可比性需要校准
2. **链断裂**：如果区间套搜索在某个中间级别未找到背驰（chain 中出现 None），该级别不计入 D(S)。链断裂不影响已有层的 L 和 C 计算
3. **方向定义**：direction 取值为 "top"（卖点方向）或 "bottom"（买点方向），由 Divergence.direction 字段给出
4. **T(S) = 0 的标的不参与排序**：无区间套的标的虽然可能通过二值筛选（存在单一级别的买卖点），但缺乏多级别收敛确认
5. **同 T 值打破规则**：L 优先 → D 优先 → 保持原顺序。这是267号"大级别收敛优于小级别收敛"的直接推论

## 下游推论

1. **代码实现**：T(S) 可直接从 NestedDivergence.chain 计算，不需要额外数据源。实现为纯函数 convergence_tightness(nd: NestedDivergence) -> float
2. **多标的扫描器**：结合267号的二值筛选，构建 scan → filter → rank 管线。filter 产生通过二值筛选的标的，rank 使用 T(S) 排序
3. **收敛事件**：当 T(S) 发生变化（新级别背驰出现或旧级别背驰消失），可产生收敛事件用于实时监控
4. **回测验证（L2）**：T(S) 的选股效果需要在真实数据上验证——高 T 标的是否确实产生更高质量的买卖点。这是 L0→L2 的必要跳跃
