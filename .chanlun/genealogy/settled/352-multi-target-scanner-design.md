# 352号：多标的扫描器设计——递归区间套 × 资本流转拓扑折叠 × 商空间排序

## 1. 结论

350号下游推论2的扁平设计（scan → filter → rank）被替代。扁平管线的问题：它将每个标的视为独立实体，忽略了标的之间通过 K4 矩阵存在的资本流转关系。正确的设计必须反映以下已结算结构：

1. **帕萨卡利亚三层条件设定**（265号）：扫描不从个股开始，从层0活跃截面开始，层层条件设定向下收敛
2. **递归区间套**（267号§一第二步）：每个标的本身有多级别嵌套的收敛紧度 T(S)
3. **折叠拓扑**（292号）：标的不是独立的——通过折叠通道存在等价关系，折叠后形成商空间
4. **商空间排序**：排序不在全体标的上做，在折叠等价类的商空间上做

### 架构：三阶段递归扫描

```
阶段1：帕萨卡利亚条件设定链
  层0：确定活跃截面（Σ 中哪些结算尺活跃）
  层1：截面内 K4 配置 → 资本偏向（E/R/Au）→ 确定目标矩阵
  层2入口：目标矩阵内的标的池

阶段2：递归区间套 + 折叠等价类构造
  对标的池中每个标的 S：
    2a. 多级别区间套搜索 → NestedDivergence 链
    2b. 计算 T(S) = D(S) * L(S) * C(S)（350号定义）
    2c. 二值筛选：T(S) = 0 的标的排除
  对通过筛选的标的集合：
    2d. 折叠等价类构造（见§3）

阶段3：商空间排序
  在折叠等价类的商空间上排序（见§4）
  输出：排序后的等价类 + 每个等价类的代表标的
```

## 2. 阶段1：帕萨卡利亚条件设定链

这不是新设计，是265号§5的操作化——选股是区间套的一部分（从层0到层2的下钻过程本身就是选股）。

### 2.1 层0 → 层1 条件设定

输入：层0背景参数——当前哪些截面活跃（254号定义2：K4共展开后的截面 K4_i）。

层0的更新极低频（季度/年度），不是扫描器的实时计算。扫描器读取层0的缓存状态作为运行前提。

输出：活跃截面列表 + 每个截面的结算通道权重。

### 2.2 层1 → 层2 条件设定

输入：活跃截面 K4_i 的六条边的走势状态。

计算：232号纤维丛运行 → 极性指数 P(v) = net($) → 资本偏向（E/R/Au）。235号三态分类给出信号质量标注。

输出：目标矩阵（资本偏向方向对应的资产类别）+ 信号质量标注。

**关键约束**（265号§6.3）：信号质量标注不决定入口顺序。入口由结构完备性决定——哪个矩阵内的标的先有完备的买卖点结构，哪个矩阵就是入口。

### 2.3 层2 标的池生成

输入：层1确定的目标矩阵。

收敛路径（267号§一第二步）：K4配置（E/Au/R） → 板块（指数/ETF）→ 个股。收敛可以停在任何一层——哪层结构最完备就在哪层操作。

输出：标的池 {S₁, S₂, ..., Sₙ}。

## 3. 阶段2：折叠等价类构造

### 3.1 为什么需要折叠等价类

扁平管线假设标的之间独立。但292号已确立：标的之间通过折叠通道存在结构性关系。例如：

- 黄金ETF和黄金期货：同一个 Au 折叠的不同金融化包装
- 石油ETF和石油期货：同一个 Oil 折叠的不同包装
- 同一板块内强相关个股：通过同一条 K4 边（如 $/Equity）的流转而联动

这些关系不是巧合——是折叠拓扑的结构性产物。将它们视为独立实体排序，会重复计数同一个资本流转信号。

### 3.2 折叠等价关系定义

给定通过二值筛选的标的集合 F = {S : T(S) > 0}，定义等价关系 ~：

**S₁ ~ S₂ 当且仅当 S₁ 和 S₂ 处于同一个折叠通道的同一侧。**

具体判据（从292号折叠盘点推导）：

| 折叠通道 | 同侧判据 | 示例 |
|---------|---------|------|
| Au: C ↔ $ | S₁、S₂ 都是 Au 折叠通道上的金融工具 | GLD（ETF）~ GC=F（期货）~ 黄金股 |
| Oil: C ↔ $ | S₁、S₂ 都是 Oil 折叠通道上的金融工具 | USO ~ CL=F ~ 石油股 |
| Bond: $ ↔ E | S₁、S₂ 都是同一经济体 Bond 折叠上的工具 | TLT ~ ZN=F ~ 国债ETF |
| RE: RE ↔ E, RE ↔ $ | S₁、S₂ 都是同一地区 RE 折叠上的工具 | 房地产ETF ~ REITs |
| 同板块 Equity | S₁、S₂ 在同一行业板块内，且 D 算子三态一致 | 同板块内走势高度同步的个股 |

最后一类（同板块 Equity）的判据更严格：不仅要求同板块，还要求 D 算子的三态分类（235号）一致——即两个标的在 K4 框架下的信号质量相同（同为保留态或同为放大态）。不一致的同板块标的不等价。

### 3.3 等价类的代表元选取

每个等价类 [S] 需要一个代表元 rep([S])。代表元选取规则：

1. **T(S) 最大者**：收敛紧度最高的标的
2. **同 T 打破**：流动性最好的标的（日均成交量最大）

代表元的语义：同一个折叠通道上的多个金融工具中，收敛信号最清晰的那个。其余标的与代表元是替代品——选哪个都是在操作同一个折叠。

### 3.4 形式定义

商空间 F/~ = {[S₁], [S₂], ..., [Sₘ]}，其中 m ≤ n（等价类合并后数量减少）。

每个等价类携带的信息：
- 代表元 rep([S])
- 类内最大 T 值：T([S]) = max{T(S') : S' ∈ [S]}
- 类内标的数量 |[S]|
- 折叠通道标记：该等价类对应哪个折叠

## 4. 阶段3：商空间排序

排序在 F/~ 上进行，不在 F 上进行。

### 4.1 排序函数

等价类 [S] 的排序键：

```
rank([S]) = T([S]) * W(fold([S]))
```

其中：
- T([S]) = 等价类内最大收敛紧度（§3.4）
- W(fold([S])) = 折叠共享性权重（从292号§3.3的区间套顺序推导）

### 4.2 折叠共享性权重

292号确立了区间套顺序：共享折叠是外层，特有折叠是内层。外层信号约束内层。

| 折叠 | 共享性 | W | 理由 |
|------|--------|---|------|
| Au: C ↔ $ | 全局共享 | 4 | 最外层约束——黄金折叠松动影响所有内层 |
| Oil: C ↔ $ | 半共享 | 3 | 次外层——石油美元体制是结算骨架 |
| Bond: $ ↔ E | 经济体特有 | 2 | 内层——各国主权信用独立 |
| RE: RE ↔ E, RE ↔ $ | 地区特有 | 1 | 最内层——受所有上层约束 |
| 同板块 Equity | 板块特有 | 1 | 最内层——纯个股级别 |

权重的语义：不是"重要程度"的人为赋值，是292号区间套顺序的量化表达——外层折叠的收敛信号比内层折叠的收敛信号携带更多结构信息（因为外层约束内层，内层不约束外层）。

### 4.3 排序规则

1. rank([S₁]) > rank([S₂]) → [S₁] 优先
2. rank 相等 → T([S]) 更大者优先（回退到纯收敛紧度）
3. T 也相等 → L([S]) 更大者优先（大级别优先——267号）
4. L 也相等 → |[S]| 更大者优先（等价类越大，信号越有代表性）

### 4.4 输出

```
输出 = [(rank₁, [S₁], rep([S₁])), (rank₂, [S₂], rep([S₂])), ...]
```

第一个元素的 rep 就是267号§一"选股输出"——区间套收敛最紧的那一个标的。但现在这个"最紧"是在商空间上度量的，不是在扁平标的集合上度量的。

## 5. 与350号扁平管线的对比

| 维度 | 350号扁平管线 | 352号递归+折叠管线 |
|------|-------------|-----------------|
| 标的间关系 | 独立（无关系建模） | 折叠等价类（结构性关系） |
| 排序空间 | 全体标的 F | 商空间 F/~ |
| 重复计数 | 有（同折叠的多个标的各自排序） | 无（等价类合并） |
| 帕萨卡利亚 | 未纳入（直接在层2扫描） | 层0→层1→层2条件设定链 |
| 折叠共享性 | 未纳入 | 外层折叠的信号权重 > 内层 |
| 输出 | 单一标的 | 排序后的等价类 + 代表元 |

350号的 T(S) 定义不变——它是单标的层面的收敛紧度度量，仍然正确。变化的是 T(S) 的消费方式：不再直接在全体标的上排序，而是先折叠再在商空间上排序。

## 7. 边界条件

1. **折叠等价关系的粒度**：当前定义基于292号的四组折叠，粒度较粗。如果标的池中大量标的不属于任何折叠通道（如纯个股、非大宗商品相关），等价类退化为单元素集，商空间退化为扁平排序。此时352号自动退化为350号
2. **折叠共享性权重 W 的标定**：当前 W = {4,3,2,1,1} 是从区间套顺序的定性排序量化得来。具体数值是否最优需要 L2 验证
3. **层0/层1 的实时性**：扫描器假设层0/层1 的状态已由上游系统（K4 monitor + 纤维丛）维护。扫描器不自行计算层0/层1，只读取缓存
4. **等价类合并的信息损失**：合并后等价类内的非代表元标的被遮蔽。如果代表元因非结构原因（停牌、流动性枯竭等）不可操作，需要回退到类内次优标的。这是操作层面的异常处理，不影响概念设计
5. **D算子三态一致判据**（§3.2最后一类）：三态分类依赖 K4 框架在该标的上的可运行性。如果标的不在 K4 覆盖范围内（如加密货币），三态判据不可用，退化为纯板块分类
6. **递归基底一致性**（350号边界条件1的继承）：跨标的 T(S) 比较假设所有标的使用相同的递归构造基底。不同递归基底的标的的 T 值不可直接比较

## 8. 下游推论

1. **代码实现**：扫描器核心为三个纯函数——(a) 标的池生成（层1→层2条件设定链）、(b) 折叠等价类构造（从标的属性到等价关系）、(c) 商空间排序（rank 函数）。三者无副作用，可独立测试
2. **与赋格状态机的接口**（349号）：扫描器输出的 rep([S]) 是349号 SCANNING → POSITION_OPEN 转移的输入。扫描器给出"操作哪个标的"，赋格状态机给出"怎么操作"
3. **折叠生命周期监控**（292号§4）：等价类的折叠通道标记可接入300号的折叠生命周期测度论签名。如果某个折叠通道处于重新结算期，该等价类的信号质量应标注为可疑
4. **回测验证（L2）**：需要验证——(a) 商空间排序是否优于扁平排序（选股效果对比），(b) 折叠等价类的合并是否正确（类内标的的替代性），(c) W权重的敏感度分析
