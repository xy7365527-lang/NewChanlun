# 371号：T(S) proxy 与严格定义的数学断裂

**来源标注**：[Gemini 异质质询] gemini-3.1-pro-preview

## 矛盾描述

350号定义 T(S) = D(S) * L(S) * C(S)（乘法结构），而 366号 Scanner L2 验证使用的是"扩展版 tightness proxy"（加法结构：BSP+1.0 / moves+0.5 / zhongshus+0.3 / 递归层+1.0）。

两种计算在数学上属于不同的空间：

| 属性 | 严格 T(S) = D*L*C | 扩展 proxy（加权累加） |
|------|-------------------|----------------------|
| 结构 | 乘法 | 加法 |
| 零值行为 | 任一项为0则整体=0 | 某项为0不影响其他项 |
| 量纲 | 层数×级别×一致率 | 各分量权重之和 |
| 单调性 | 三项同向单调 | 各项独立单调 |

Gemini 的否定：**加法空间的排序拓扑完全不同于乘法空间**。用 proxy 做的 L2 验证（366号）不能反向背书 T(S) 的有效性，因为 proxy 的高分标的不一定是严格 T(S) 的高分标的。

## 现有自承认

366号边界条件4已明确："扩展 tightness proxy 合理但非严格等价于 350号 T(S)。如果真实 T(S)（从 NestedDivergence 计算）的排序与 proxy 排序不一致，L2 结论需重新评估。"

但谱系结论摘要处（§1 核心发现）直接说"商空间排序（rank=T*W）与扁平排序产生显著不同的选股序列"，未注明此结论依赖 proxy 而非严格 T(S)。

## Gemini 推导链摘要

1. 读取 350号：T(S)=D*L*C 是乘法，任一项为0则 T=0
2. 读取 366号验证方法：使用扩展 proxy（加权累加）
3. 识别：proxy≠严格 T(S) 在数学上是两个不同的函数
4. 结论：366号的 L2 验证对象是"proxy 的效果"，不是"T(S) 的效果"
5. 否定：366号不能声称验证了 T(S) 的有效性

## 质询判定：否定成立

定义回溯：350号 T(S)=D*L*C 定义明确，366号使用 proxy 明确，两者不等价。

反例：若某标的 D=1, L=5, C=1.0 → T=5；但若 D=0（无递归背驰）且有大量 moves/zhongshus → proxy 可能 >5 但严格 T=0（D=0）。这两个标的在严格 T(S) 下的排序与 proxy 下的排序完全相反。

推论检验：如果 366号的 L2 只验证了 proxy 的效果，则商空间排序结论（"外层折叠优先"的拓扑逻辑）虽然概念上正确（L0），但其 L2 验证等级应降级为"proxy 已验证，T(S) 待验证"。

## 边界条件

## 结算意见（settler-math, v163-swarm）

### 判定：否定成立，予以结算

### 结论

371号指出的数学断裂是真实的。350号 T(S)=D*L*C 是乘法结构，366号使用的扩展 proxy 是加法结构（BSP+1.0 / moves+0.5 / zhongshus+0.3 / 递归层+1.0）。两者在数学上属于不同空间，排序拓扑不等价。

关键差异：乘法结构中任一分量为零则 T=0（例如 D=0 无递归背驰则 T=0），而加法 proxy 中某项为零不影响其他项的贡献。这意味着一个在严格 T(S) 下排序为零的标的，可能在 proxy 下获得非零甚至较高分值。

### 定义依据

| 概念 | 来源 | 关键表述 |
|------|------|---------|
| T(S) = D*L*C | 350号 §收敛紧度函数 | 乘法结构，D=0 → T=0 |
| 扩展 tightness proxy | 366号 §2 管线步骤2 | 加法结构，BSP/moves/zhongshus/递归层各项独立 |
| 有效域 ≠ 定义域 | 231号 | 形式化工具的验证等级必须与对象匹配 |

### 边界条件

- 如果 proxy 与严格 T(S) 的 Spearman 秩相关系数 ρ > 0.9，则两种排序在实际标的集合上高度一致，否定的实际影响弱化（但定义层面的断裂仍然存在）
- 当前无此相关性数据——366号未做 proxy vs T(S) 的秩相关分析
- 366号边界条件4已自承认差异，但核心发现摘要处未标注

### 下游推论

1. **366号 L2 声明降级**：366号的认识论标注应从 "L2: 商空间排序 vs 扁平排序" 修正为 "L2: proxy-based 商空间排序 vs 扁平排序"。核心发现成立（商空间 ≠ 扁平），但度量的对象是 proxy 而非严格 T(S)
2. **350号下游推论4 仍然开放**：T(S) 的 L2 验证需用严格 T(S)（从 NestedDivergence 计算 D*L*C）重新执行
3. **proxy 与 T(S) 的秩相关分析**：作为增量验证——如果 ρ 高，则 proxy-L2 的结论可转移至 T(S)；如果 ρ 低，则 proxy-L2 和 T(S)-L2 是两个独立问题
