# 373号：加权Morse循环论证——362号洞察1的方法论根本错误

**来源标注**：[编排者洞察] + [本代理同质质询降级] + [Gemini 异质验证已补充]

---

## 编排者原始洞察

> "CC 把'类型化边对 Morse 函数的约束'翻译成'给不同类型的边赋权重'。这个翻译把范畴差异（negates 和 depends_on 是不同种类的关系）压缩成了量的差异（negates=4, depends_on=1），好像 negates 只是'4倍强的 depends_on'。"
>
> "加权 Morse 把应该是研究产出（类型和临界性的关系）变成了研究输入（预设的权重）。"
>
> "正确做法：在标准（无权重）最优 Morse 函数上跑真实数据，统计临界集中各类型边的比例。如果 negates 边在临界集中的占比显著高于它在全部边中的占比——这才是类型化离散 Morse 理论的第一个实质性结果。"

---

## 循环论证的精确数学形式

加权 Morse 的代数结构：

1. **先验假设**（P）：negates 边是 Morse 临界集的骨架 → 赋权 w(negates)=4
2. **代数保证**：配对算法优先消除低权重边（depends_on=1），高权重边（negates=4）**在代数上被迫留在临界集**
3. **验证目标**（Q）：检验加权临界集是否更好捕捉"关键否定"事件

问题：Q 的结果被 P 的预设部分决定。如果 Q 成立，无法区分：
- "因为 negates 确实是骨架（独立事实）"
- "因为权重预设了 negates 是骨架（循环）"

这是严格意义上的**循环论证**（begging the question）——假设预设了结论。

### 与 363号 L2 否定的关系

363号从**实证层面**否定（加权未改善预测能力）。

两者是**平行的独立否定**：
- 363号：加权 Morse 不管用（实证）
- 373号：加权 Morse 即使管用也不能证明任何事（方法论）

## 范畴差异问题

negates 和 depends_on 在命题层面是不同范畴（改变真值 vs 建立依赖）。加权 Morse 把范畴差异压缩为量差异（4 vs 1）。

这不是**致命的**范畴错误（单纯复形 Morse 函数从定义上就对所有 1-单形赋实数值），但使加权 Morse 的"类型敏感性"成为假象：它的敏感性来自权重预设，而非来自关系类型的数学性质。

---

## 编排者建议的替代方法（正确做法）

**方法**：在均匀权重最优 Morse 函数（optimal_morse.py 已实现）上，统计临界集中各类型边的比例。

**形式化检验**：
```
H₀: C_neg/C_all = E_neg/E_all  （negates 在临界集中的占比 = 在全体边中的占比）
H₁: C_neg/C_all > E_neg/E_all  （negates 在临界集中显著过表达）
方法：Fisher 精确检验（2×2 列联表）
```

**为何避免循环**：optimal_morse.py 不使用类型权重，临界集由拓扑结构（余面数、连接度）决定，类型信息是**事后统计**而非**事前预设**。

**可行性**：optimal_morse.py 已实现，真实 relations.jsonl 存在，此实验可在现有代码基础上执行（在 simplicial_complex 构造时保留边的 relation_type 属性，执行最优 Morse 后按类型统计临界集组成）。

## 结算意见（v163-swarm/settler-morse）

### 结论

373号循环论证诊断**成立并结算**。

**核心判断**：加权 Morse 将研究产出（类型与临界性的关系）预设为研究输入（权重），构成严格的 begging the question。Gemini 异质验证确认此诊断，并从代码层面（`weighted_morse.py:sort_key`）给出了循环的机械证据。

**Fisher 实验结果的定位**：373号自身已执行编排者建议的替代实验（均匀 Morse + Fisher 检验），获得 p=0.0058。但此 p 值受 374号否定（独立性假设不满足），需要置换检验替代。Fisher 结果降级为"有方法论局限的初步观测"（L2*）。

### 定义依据

- 编排者洞察原文："把范畴差异压缩成量的差异"是循环论证的精确诊断
- Gemini 确认：`sort_key` 中低权重边优先消除 → 高权重边代数上被迫留在临界集
- 循环形式：P（negates 权重=4）→ Q（negates 在临界集中过表达）→ "验证"P

### 边界条件

循环论证判断在加权 Morse 框架内无条件成立。唯一翻转条件：如果存在独立于 Morse 框架的先验证据证明 negates 是骨架（如 Fisher/置换检验），则加权 Morse 可重定位为"先验注入工具"（Gemini 建议），但这不改变循环论证本身的成立性。
