# 379号：置换检验否定——negates 过表达是拓扑位置效应非类型内禀属性

**认识论等级**: L2（否定性结果——信息增量为正：否证了 negates=骨架的本体论主张）

## 1. 结论

置换检验（10000次置换，保持图拓扑不变，随机打乱边类型标签）结果：**p=0.0927（不显著）**。

| 指标 | 值 |
|------|-----|
| 图规模 | 4535 边，3691 临界（81.4%） |
| negates 边数 | 20（含 negated_by） |
| 观察到的 negates 临界数 | 19/20 = 95.0% |
| 零分布均值 | 16.30 |
| 零分布中位数 | 16 |
| 零分布95分位 | 19 |
| 零分布99分位 | 20 |
| p 值（单侧） | **0.0927** |

**核心发现**：由于整体临界率高达 81.4%，随机放置的 20 条"negates"标签也大概率落在临界边上（零分布均值 16.30/20 = 81.5%，与整体临界率几乎一致）。观察到的 19/20 = 95% 虽然高于零分布均值，但在零分布的正常波动范围内（95分位=19）。

**结论**：negates 边的高临界率（95%）不是因为 negates 类型在拓扑上有特殊地位，而是因为整体临界率就很高（81.4%），任何类型的 20 条随机边都大概率表现出类似的临界率。**Fisher p=0.0058 是拓扑位置效应（局部聚集）导致的伪显著性**，374号的判断完全正确。

## 2. 对 373号本体论主张的影响

373号声称"negates=概念空间骨架"的本体论主张获得了 Fisher p=0.0058 的支持。置换检验否定了这一支持证据：

- **Fisher p=0.0058**：假设独立性不满足 + 置换检验不显著 → 伪显著性
- **置换 p=0.0927**：在控制了拓扑位置效应后，negates 的过表达不显著
- **结论**：362号洞察1的本体论主张（negates=骨架）**既无工具层支持（373号循环论证）也无实证支持（379号置换否定）**
