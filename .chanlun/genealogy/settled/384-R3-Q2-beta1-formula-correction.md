# 384号：R3-Q2 β₁差值分解公式精确化

**认识论等级**: L0(修正公式证明) + L1(两个最小例子验证) + L2-ready(O(|E|)算法就绪待真实数据运行)

## 1. 结论

v164 Gemini derive 产出的 Q-R3-2（折叠的 Discrete Morse Function 存在，L0）被编排者双重否定后修正：

### 1.1 否定1：β₁=m-1 过度简化

原始公式 β₁=m-1（m=下链接节点数）假设下链接无边、无自环。实际：
- 下链接有边时，连通分量数 c < m
- 自环存在时，每个自环贡献 +1 到 β₁

**修正公式**：Δβ₁ = (c - 1) + n_loop

其中：
- c = 下链接连通分量数
- n_loop = 下链接中的自环数（节点的 negates/depends_on 指向自身的边）

### 1.2 否定2：Forman 3.3 不适用于商映射

原始 Q-R3-2 将商映射（quotient，识别多个顶点为一个）等同于单纯塌缩（collapse，移除自由面对），错误引用 Forman 1998 Thm 3.3。

**区分**：
- **塌缩（collapse）**：移除自由面对，保持同伦型，β₁ 不变
- **商映射（quotient）**：顶点识别，改变拓扑，β₁ 可增可减

**反例**（Gemini derive 构造）：空心三角形 S¹（3 顶点 3 边），无自由面无法塌缩。识别两个顶点后 K/∼ = S¹ ∨ S¹，β₁ 从 1 变为 2。塌缩+手术分解不存在。

**替代框架**：分层 Morse 理论（Goresky-MacPherson 1988）——K/∼ 是分层空间，奇点具有"下降流形"，扬弃的拓扑隐喻在此框架下可定义。

### 1.3 修正后的认识论等级

| 问题 | 原始等级 | 修正等级 |
|------|---------|---------|
| Q-R3-2：折叠的 Morse 函数存在 | L0（Forman 3.3） | **开放研究问题**（需分层 Morse 理论） |
| Q-R3-2：塌缩=折叠 | L0 | **证伪** |
