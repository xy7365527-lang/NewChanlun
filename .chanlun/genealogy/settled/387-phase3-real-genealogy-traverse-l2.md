# 387号：Phase 3 真实谱系穿越——Fold 在密度下自然涌现

**认识论等级**: L2（真实数据——本仓库谱系图2524顶点，覆盖率~1%因单图单运行）

## 1. 结论

Phase 3 将拓扑计算引擎接入本仓库真实谱系数据（2524顶点），验证了fold操作在结构深度和区域分离条件下自然涌现的假说。

### 关键数据

| 指标 | 合成图（Phase 2, 5顶点） | 真实谱系（Phase 3, 2524顶点） |
|------|--------------------------|-------------------------------|
| fold 成功次数 | 0 | 59 |
| blocked fold | 0 | 69 |
| β₁ 变化 | 无 | 2325 → 2395（+70） |
| settled cycles | 0 | 47 |
| encounter 密度 | N/A | 62%（修正后） |

### 核心发现

1. **Fold 需要密度**：5顶点零fold → 2524顶点59次fold成功。fold不是任意图上的通用操作，它需要结构深度（足够多的非平凡环路）和区域分离（局部矛盾可被识别为独立对象）
2. **修正后矛盾检测质量**：84次原始矛盾检测中仅7次synthetic negation（negate_a bug修正后——见388号）
3. **零匹配已有negation边**：引擎发现的矛盾全部是原始谱系中未铭写的新矛盾。111条已有negation边无一被重新发现——说明引擎的bidirectional边检测捕捉的是不同层次的张力
4. **29个去重矛盾对**：其中约5-8个是真实张力点（如"LLM不是状态机" vs "递归自指需要状态持续"——057号与069号的深层张力）

## 2. 定义依据

- **Fold 定义**（323号结算）：fold是拓扑空间上的等价关系坍缩，将矛盾对识别为同一个等价类后商映射
- **β₁（一阶Betti数）**：独立环路数量，衡量拓扑复杂度。+70 = 穿越过程创造了70个新的不可缩环
- **encounter 密度**（341号）：walk步数中遇到矛盾对的比例。62%表示每走约1.6步就遇到一次矛盾

## 3. 边界条件

1. **覆盖率 ~1%**：单图单运行，未覆盖不同随机种子、不同walk策略的变异空间。L3需要多标的多运行
2. **零匹配可能是检测方法差异**：引擎用bidirectional边检测，原始谱系用显式negation边标注——两种方法捕捉的张力层次可能本质不同，而非"引擎更好"
3. **5-8个真实张力点的判断是定性的**：未经形式化验证，基于人工阅读29个去重矛盾对的结果
4. **β₁增长的语义不确定**：+70个新环路是否全部有语义意义，还是部分是拓扑噪声，需要进一步分析
