# 391号：R3 Phase 2 Gemini代数分析——f/g函数性质 + 统一势函数Φ

## 1. 结论

Gemini对拓扑计算引擎中f(v,w)和g(v,w)两个函数的代数性质进行了系统分析，并提出统一势函数Φ。

### Q-R3-7（f函数性质）

- **f(v,w) = 0 充要条件**：(c=1 ∧ n_loop=0) ∨ (c=0 ∧ n_loop=1)。其中c为v-w之间的连通分量数，n_loop为环路数
- **f上界**：原始猜想 f ≤ |N△N|-1+n_loop 被Gemini构造反例推翻——对称差集公式不构成f的上界
- **f与Morse函数的关系**：f不是Morse函数（不满足非退化临界点条件），但f⁻¹(0)定义了有效的离散梯度向量场——f=0的顶点对集合具有向量场结构

### Q-R3-8（g函数性质）

- **Δβ₁ = min(1, g(v,w))**：fold操作的β₁变化量被g限制在{0,1}
- **否定环稳健性 = g(v,w)**：v-w之间的独立路径数（Menger定理推论）等于否定关系的拓扑稳健性——移除g-1条边后否定关系仍存在
- **关键结构不等式：f(v,w) ≤ g(v,w) - 1**：fold代价（f）严格小于negate稳健性（g）。代数含义：否定关系的冗余度总是大于fold操作的拓扑代价

### Q-R3-9（统一势函数Φ）

- **Φ极小值 = 宏观空洞边界**：fold操作的自然目标——拓扑上"薄弱"的位置
- **Φ极大值 = 密集局部团**：negate操作的自然目标——拓扑上"稠密"的位置
- **λ的内禀定义 = 图的特征环长度的倒数**：势函数中的权重参数不需要外部赋值，可以从图的拓扑结构自身导出

## 2. 定义依据

- **f(v,w)**：fold操作将顶点v,w合并时的拓扑代价函数——衡量合并后的Betti数变化
- **g(v,w)**：v与w之间的独立路径数（边不相交路径数）——Menger定理给出的拓扑连通度量
- **β₁（一阶Betti数）**：独立环路数，拓扑不变量
- **Discrete Morse Function**（351号研究线）：f的零水平集f⁻¹(0)与DMF的梯度向量场结构相关
