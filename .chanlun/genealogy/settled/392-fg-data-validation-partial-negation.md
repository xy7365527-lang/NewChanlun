# 392号：Q-R3-10 数据验证——f/g猜想部分否定

**认识论等级**: L2（真实数据——2000步实验的前150个fold/negate对采样，Mann-Whitney检验）

## 1. 结论

对391号Gemini代数分析的三个核心预测进行L2数据验证，结果为：一个否定、一个强烈支持、一个部分支持。

### 预测1（f是fold判据）：否定

fold的f均值10.85 > 随机对3.57（Mann-Whitney p≈0, Cohen's d=1.08）。

**方向反转**：391号预测"f小=fold候选"（fold代价低的对更适合fold），但数据显示fold实际发生在f较大的对上。fold不是选择拓扑代价最低的对——相反，有效的fold发生在拓扑代价较高（即拓扑变化较大）的对上。

### 预测2（g是negate判据）：强烈支持

negate的g均值49.5 >> 随机3.71（Mann-Whitney p≈0, Cohen's d=7.03）。

negate几乎只发生在高度连通的顶点对之间。效应量d=7.03极其显著——negate对的独立路径数比随机对高一个数量级以上。这验证了"独立路径数=矛盾深度"假说：拓扑上高度连通的节点对之间的否定关系最为稳健。

### 预测3（f/g空间分离）：部分支持

- **f维度**：fold和negate之间有显著分离（p=1e-6）——fold偏向高f，negate偏向低f
- **g维度**：fold和negate之间无显著分离（p=0.42）——两者的g都很高

f/g的二维空间不能完全分离fold和negate操作。g维度上的重叠表明：fold和negate的目标对都是高连通度的对——它们在"连通性"维度上是同质的，差异在"拓扑代价"维度上。

## 2. 定义依据

- **f(v,w)**（391号定义）：fold操作的拓扑代价函数。数据显示f在fold对上均值10.85，在随机对上均值3.57
- **g(v,w)**（391号定义）：独立路径数（Menger定理）。数据显示g在negate对上均值49.5（达到BFS迭代上限），在随机对上均值3.71
- **Mann-Whitney U检验**：非参数检验，不假设正态分布。适用于f和g的分布可能偏斜的情况
- **Cohen's d**：效应量。d=1.08（f维度）为"大效应"，d=7.03（g维度）为"极大效应"

## 3. 边界条件

1. **采样偏差**：数据来自2000步实验的前150个fold/negate对，不是全部484次blocked fold和116个settled cycles的完整统计。采样可能不代表稳态（1301+步）的行为
2. **g的上限截断**：g的BFS迭代上限设为50。negate对的g几乎全部达到上限——真实的g值可能远大于50。这意味着预测2的效应量被低估
3. **预测1否定的解读空间**：fold发生在f较大的对上可能意味着：(a) fold不是选择"代价最低"的对，而是选择"拓扑变化最大"的对——fold的判据可能是变化幅度而非变化代价；(b) f的定义需要重新理解——f较大可能不意味着"代价高"，而是"参与环路多"（邻域共享度高）
4. **f/g不独立**：f和g可能不是独立维度——高连通度（高g）的对可能倾向于高f（参与更多环路）。相关性未检验
5. **单图单运行**：所有数据来自本仓库谱系图（2524顶点/6751边）的一次2000步运行。L3需要多图验证

## 6. 影响声明

- **391号代数结论的有效域收缩**：f ≤ g-1的代数关系在数据中成立（f均值10.85 < g均值49.5），但"f小=fold候选"的语义解读被推翻。391号的结论在代数层（L0）仍然成立，但在操作语义层被否定

- **fold判据的研究方向转向**：从"预测Δβ₁大小"（391号f函数路线）转向"拓扑邻域相似性"（Jaccard/spectral路线）。fold的判据可能不是Betti数变化量，而是局部结构相似度
