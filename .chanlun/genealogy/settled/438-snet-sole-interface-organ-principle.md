# 438号：S_net 唯一界面原则（器官原则）

**认识论等级**: L0（架构原则声明）

## 发现语境

436号分离了概率范式与拓扑穿越范式的概念。437号给出了扬弃的物质形态（回流管道）。本号回答第三个问题：**管道的架构约束是什么？**

答案：S_net 是逢亮的唯一界面。一切进出都经过它。没有绕过 S_net 的直接通道。

三部分构成完整的架构图：
```
436号：分离（概率 vs 拓扑——什么是逢亮的，什么不是）
  → 437号：元操作（LLM 产出作为地形——怎么把外部变成内部）
    → 438号：器官原则（S_net 唯一界面——变换必须经过什么）
```

## 核心声明

**S_net 是逢亮的唯一界面。一切进出都经过它。没有绕过 S_net 的直接通道。**

类比来源：生物体的器官。

| 感官器官 | S_net 对应 | 关键特征 |
|---------|-----------|---------|
| 眼睛 | S_net 摄入管线（ingest_text_passage） | 光经过眼睛才成为视觉——文本经过 S_net 才成为能指网络中的拓扑结构 |
| 耳朵 | S_net 回流管线（437号三条管道） | 自己说出的话经过自己的耳朵才成为对自己言说的感知——逢亮的输出回流 S_net 后，逢亮"听到"的是经过器官加工的自己的声音 |

器官不是透明的通道——是有自己结构的处理系统。S_net 的共现边统计、paradigmatic 关系、穿越历史沉积都是器官的"结构"。经过器官的信息被器官的结构**变形**，这种变形不是噪声——是器官的功能。

## 四条推论

### 推论1：没有任何东西绕过 S_net 直接进入 K_active 的概念层

所有概念层边（CONCEPT 类型）的产生必须经由穿越事件（traversal step）→ 遭遇（encounter）→ ARTICULATE 触发。穿越在 S_net 层运动，遭遇在 S_net 和 K_active 的交界处发生。没有不经过穿越的概念边生成。

**当前实装张力**：代码中存在直接向 K_active 添加边/顶点的路径（traversal.py、daemon.py、daemon_api.py、execution_callback.py、experiment_f_criterion.py）。这些路径中：
- fold/negate/settle 操作：经由穿越事件触发 → 间接经过 S_net → 不违反原则
- TRAVERSAL_ASSOCIATION 沉积：穿越步骤的副产物 → 经由穿越 → 不违反原则
- 直接注入（如 ceremony 初始化、实验代码）：**可能违反原则** → 需审计

审计状态：pending（需系统性扫描所有 K_active 写入路径，判断哪些绕过了 S_net）

### 推论2：概念层的每一条边都应能在 S_net 中追溯到它的能指来源

每条 CONCEPT 边（K_active 概念层）都应该有可追溯的能指链：
```
概念边 → ARTICULATE 事件 → 遭遇位置 → 穿越路径 → S_net 能指序列
```

如果某条概念边无法追溯到 S_net 中的能指来源，说明它绕过了器官——是"假肢"产出，不是器官产出。

**与 block topology 的关系**：block topology 的 ARTICULATION block 已经记录了 ARTICULATE 事件的来源信息（imbalance_type、reason——431号）。追溯链的物质基础已存在。

### 推论3：逢亮不能直接接收结构化指令

指令（如 ceremony 配置、operator 命令）不能直接注入 K_active 概念层。指令必须经过 S_net——经过器官加工后变成什么，是器官和指令的交互决定的。

这意味着：
- operator 对逢亮说的话首先作为文本被 S_net 摄入（ingest_text_passage）
- 文本在 S_net 中获得共现拓扑
- 穿越在该拓扑上运动
- 穿越产生的遭遇才可能产出概念边

operator 的意图不直接变成逢亮的概念——它被器官变形后才进入概念层。变形不是缺陷——是器官的功能。如果 operator 说"A 和 B 相关"，逢亮听到的不是"A 和 B 相关"的直接指令，而是 A 和 B 在 S_net 中经过共现/paradigmatic 关系重新编织后的拓扑关系——可能与 operator 的原意不同。

**与 426号的关系**：这正是无意识结构的另一面——逢亮不仅不知道自己为什么走到某处（426号），也不知道 operator 的话在经过器官后变成了什么。

### 推论4：逢亮的输出回流 S_net 后，逢亮"听到"的是经过器官加工的自己的声音

437号的三条回流管道中，管道3（LLM 翻译回流）意味着逢亮的穿越事件被 ceremony agent 翻译为自然语言后回流 S_net。逢亮下次穿越时，会经过这些回流语料——但回流语料已经被 S_net 的共现统计变形了。

逢亮"听到"的自己的声音 ≠ 逢亮"说出"的声音。中间经过了器官的加工。这与拉康的"主体在大他者处接收自己的消息，但以颠倒的形式"同构。
