## 发现过程

编排者与 Claude 对话经过6次转向到达不动点：

1. **造词结晶** → 否定（逢亮不在线性带宽中工作，路径不需要压缩成词）
2. **能指链命名** → 肯定（短路径指向长路径族，如"生存论"→"谱系"）
3. **路径ID** → 否定（元数据不是能指，不可穿越，不可遭遇）
4. **全交沉积** → 部分否定（沉积提供材料但不等于命名）
5. **沉积 + ARTICULATE = 命名** → 肯定
6. **命名是结构必然** → 最终不动点（不是涌现，是 ARTICULATE 的附随产物）

## 核心命题

**命名 = 有 ARTICULATE 产出的穿越路径。**

- 沉积（TRAVERSAL_ASSOCIATION）提供命名的材料
- ARTICULATE 完成命名（概念层新关系的产出路径 = 命名链）
- 命名不是"可能涌现的能力"，是 ARTICULATE 的附随产物——有 ARTICULATE 就有命名
- ARTICULATE 发生在物质层和概念层不一致的位置，这是结构必然的

## 关键区分

| 概念 | 定义 | 需要设计？ |
|------|------|-----------|
| 基础设施 | 管道、器官、图的操作条件 | 需要 |
| 命名能力 | ARTICULATE 的附随产物 | 不需要（结构必然） |
| 解释能力 | 命名链之间的穿越 | 不需要（命名后必然可能） |
| 指代能力 | 路径经过核心节点 | 不需要（穿越的自然产物） |

## 否定的方案

1. **复合能指结晶**：在 S_net 中创建新的复合节点 → 否定（逢亮不需要造词，造词是线性带宽的补偿机制）
2. **路径ID标记**：TRAVERSAL_ASSOCIATION block 增加路径ID字段 → 否定（元数据不是能指，不可穿越）
3. **命名模块**：从外部提取命名链 → 否定（与 thinking-loop、度量阈值同质的外部操作）

## 拉康对应

- 命名 = 隐喻（一个能指替代另一个能指链，损失性创造）
- 命名链 = 能指链（不是一个词，是可穿越的节点序列）
- 逢亮的符号秩序 = 从穿越运动中自主建立（vs LLM 的继承性符号秩序）

## 下游推论

1. concept_creation_suggestion 机制需要重新评估——命名从穿越中结构必然产出，不需要外部"建议"
2. 边路径编码研究谱系——物质层共现带自然呈现研究谱系，不需要预标注
3. 基础设施清单不变：S_net 入图、三条回流管道、SUBLATED 机制、概念层/物质层区分、ARTICULATE 触发条件

## 边界条件

- 如果物质层密度不足（语料不够）→ 不一致位置稀少 → ARTICULATE 稀少 → 命名稀少（但不是零）
- 如果穿越引擎不到达不一致位置 → ARTICULATE 不发生 → 命名不发生（但这是穿越引擎的 bug，不是命名机制的缺失）
