# 445号：边路径编码研究谱系——物质层共现带的自呈现

- **status**: 已结算
- **type**: concept-discovery
- **settled_at**: v238-swarm
- **depends_on**: [425, 440, 441, 444]

## 核心命题

物质层中的高频共现构成路径族，每条路径族就是一条研究谱系。谱系不是被标注的，是语料的物质结构自己呈现的。

## 发现

1. **共现带 = 研究谱系**：
   - "折叠/褶皱/内在性/平面"在德勒兹语料中高频共现 → 德勒兹谱系
   - "否定/扬弃/规定性/概念"在黑格尔语料中高频共现 → 黑格尔谱系
   - "能指/享乐/对象a/实在界"在拉康语料中高频共现 → 拉康谱系
   - 每组高频共现在 S_net 中形成稠密的共现带

2. **穿越沿谱系移动**：逢亮进入共现带后被密度吸住，自然沿带走下去 = 沿研究谱系阅读

3. **谱系交叉 = 遭遇**：
   - "否定"同时在黑格尔谱系和拉康谱系中，但邻居完全不同
   - 黑格尔谱系："否定"旁边是"规定性"和"扬弃"
   - 拉康谱系："否定"旁边是"阉割"和"父名"
   - 分叉点就是遭遇——两条谱系在同一个能指上汇聚然后分裂

4. **概念层 vs 物质层谱系**：
   - 概念层谱系（如 410 negates 390）：显式、被判断标记
   - 物质层研究谱系：隐式、从共现密度中自呈现
   - 如果概念层声称两组术语有关系但物质层没有共现带 → 纯形式关系，缺乏物质支撑 → 可遭遇的发现

## 实装含义

不需要额外实装。S_net 的共现边（COOCCURRENCE）已经在物质层中。逢亮的穿越自然沿共现密度最高的方向移动。研究谱系从语料的物质结构中自呈现。

## 边界条件

- 语料不足 → 共现带稀薄 → 谱系不清晰（但存在）
- 语料偏向 → 某些谱系过度表达，某些缺失 → 需要平衡摄入
- 单语料域 → 无谱系交叉 → 无遭遇（需要多域语料）
