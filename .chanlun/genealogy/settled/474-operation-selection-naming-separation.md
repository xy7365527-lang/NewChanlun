# 474号：操作/选择/命名三层分离——黑格尔/谢林/毛泽东

**认识论等级**: L0

## 核心命题

穿越引擎的三个不同层级各自有不同的决定原则，不可混淆：

| 层级 | 决定原则 | 哲学对位 | 代码位置 |
|------|---------|---------|---------|
| **操作层** | fold/negate/sublate 的形式逻辑规则 | 黑格尔（辩证法形式） | engine.py: fold/negate/sublate 函数 |
| **选择层** | 哪个操作在此步发生 = 遭遇决定 | 谢林（穿越的实存决定） | traversal.py: detect_encounter + terrain 标记 critical edge |
| **命名层** | β₁ 变化量 D 标记主次矛盾 | 毛泽东（主次矛盾分析） | traversal.py: execute_encounter 中 D≠0 判据 |

## 三层不可混淆

1. **操作层不决定命名**：sublation 的形式逻辑（创建合题顶点、添加 SUBLATION 边）不决定该合题是否"重要"。重要性由命名层的 D 判据决定。

2. **选择层不决定操作规则**：terrain 标记哪些边是 critical 影响的是穿越路径和遭遇检测（选择层），不影响 fold/negate/sublate 的内部逻辑（操作层）。

3. **命名层不决定选择**：D≠0 是事后标记（473号已确认），不是事前预测。命名层不干预选择层的遭遇检测。

## 推导链

```
370号：Morse 有效域 = terrain 标记 + 遭遇检测（选择层）
  → 370号精确终止于关键性判断 → 命名层不能用 Morse 预测
  → 命名层改用 β₁ 变化量 D（事后标记）
  → D 的来源是 engine.py 的 OperationResult.delta_beta_1_actual（操作层输出）
  → 命名层消费操作层的输出，不干预操作层的逻辑
  → 三层分离
```

## 与毛泽东方法的同构

毛泽东的"主次矛盾分析"区分：
- **矛盾的存在**（操作层）：矛盾客观存在，不以分析者意志为转移
- **矛盾的展开**（选择层）：在具体情境中哪个矛盾被激活
- **主次矛盾**（命名层）：哪个矛盾的解决改变了全局结构（主矛盾 = D≠0）

D=0 的操作是"次矛盾"——它存在、它展开了、但它没有改变全局结构。

## 边界条件

| 条件 | 翻转阈值 |
|------|---------|
| 三层是否穷尽 | 如果发现不属于任何一层的决定机制，需要扩展分层 |
| D 是否是命名的充分判据 | 如果 D≠0 但顶点后续被 fold 消灭，命名权可能需要追溯撤销 |
| 选择层的 terrain 是否是唯一选择机制 | 当前 terrain + critical_neighbors 是主要选择机制，但 f_criterion 是另一个选择机制 |

## 下游推论

1. 任何试图在操作层（engine.py）中加入"重要性"判断的提案，违反三层分离
2. 任何试图在命名层（D 判据）中修改遭遇检测逻辑的提案，违反三层分离
3. 三层分离是 370号有效域边界的架构表达——370号在概念上区分了"什么是 Morse 理论能做的"和"什么不是"，474号将此区分固化为代码架构
