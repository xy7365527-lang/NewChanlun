# 475号：T8 重新表述——背驰=条形码 Wasserstein-1 递减 + 三算子方案定位

**认识论等级**: L0（代数/定义层——MACD 与 Wasserstein 的形式对应关系）+ L1（当前实现已通过合成+少量真实数据验证）。L2 验证路径在本文件中规划。

## 结论

### 1. 两个数学工具的不可替代性

缠论形式化需要两个数学工具，各自有不可替代的有效域：

| 工具 | 读什么 | 缠论对应 | 有效域 |
|------|--------|----------|--------|
| **Morse**（空间性） | 地形标记，结构/噪音区分 | 笔模式阈值 delta_k（宽笔/严笔/新笔），临界集=拓扑显著的结构 | 空间结构分类。有效域**精确终止于**关键性判断（370号） |
| **Wasserstein**（时间性） | 力的递减，动力学判据 | 背驰=力度衰竭=W_1递减 | 时间序列的力度比较。有效域=同级别同向趋势段的力度比较 |

两者不能互相替代。Morse 读结构，Wasserstein 读力。

### 2. T8 定理候选：背驰 = Wasserstein-1 递减

**陈述**：在 a+A+b+B+c 结构中，C段背驰于A段，当且仅当：

```
W_1(Dgm(C), empty) <= W_1(Dgm(A), empty) - eta
```

其中：
- Dgm(X) 是 X 段走势的持续图（条形码）
- W_1(Dgm, empty) = sum |d_i - b_i| / 2 （条形码到空图的 Wasserstein-1 距离，即"总持续量"）
- eta >= 0 是容差参数

**核心主张**：MACD 柱子面积是 Wasserstein 距离在特定参数化下的近似。

### 3. MACD面积 approx W_1 的推导（L0）

MACD 柱子面积的物理含义：
- MACD HIST = DIF - DEA = EMA(12) - EMA(26) - EMA(DIF, 9)
- 柱子面积 = sum |HIST_t| 在某段时间内的积分
- 这衡量的是"快慢均线差异的累积量"——即趋势动量的时间积分

条形码 W_1 范数的物理含义：
- Dgm(X) 的每个 bar (b_i, d_i) 对应一个拓扑特征的生命周期
- W_1 = sum |d_i - b_i| / 2 = 条形码的"总持续量"
- 当 Dgm 由笔振荡构造时，每个 bar = (笔低点, 笔高点)，W_1 = sum (笔振幅) / 2

**对应关系**：
- MACD 面积 ~ 价格动量在均线参数化下的时间积分
- W_1(笔振荡) ~ 价格振幅在缠论笔分解下的总量

两者都衡量"力度"，但参数化不同：
- MACD 依赖均线周期选择（12/26/9）→ **gauge 依赖**
- 条形码由走势的拓扑结构直接计算 → **gauge 不变**（不同合法分解下长寿命部分一致）

这是 T8 相对于 MACD 的核心优势：条形码不需要选均线周期。

### 4. 三算子方案

```
X_{k+1} = S circ Z circ M_{delta_k}(X_k)
```

- **M_{delta_k}**（Morse 消去）：降噪，去掉 non-critical cells。阈值 delta_k 对应笔模式（宽笔/严笔/新笔）。这是 Morse 工具的有效域——空间性的结构/噪音区分
- **Z**（zigzag 条带构造）：中枢识别。三段重叠 → 中枢
- **S**（层化/stratification）：级别提升。走势类型实例 → 更高级别的笔/线段

三算子的级别递归：
1. 原始K线 X_0
2. M_{delta_0}(X_0) → 包含处理+分型+笔（Morse消去噪音K线）
3. Z(M(X_0)) → 线段+中枢（zigzag条带=中枢区间[ZD,ZG]）
4. S(Z(M(X_0))) → 走势类型实例（层化=级别提升）
5. 回到步骤2，以走势类型实例为新的 X_1，delta_1 可能不同

**T8 在三算子中的位置**：T8 作用于每一层的输出——比较同级别同向趋势段的条形码 W_1。T8 不是第四个算子，而是**跨层的判据**——在每个级别上读取力度递减信号。

## 下游推论

### 推论1：T8 L2 验证路径

**目标**：在真实市场数据上验证 T8 passed 率是否显著高于随机基线。

**所需数据**：
- 分钟级K线数据（1min 或 5min），时间跨度 >= 1年
- 需产生递归级别 >= 1 的背驰（199号约束）
- 理想数据源：AV 1min（20只美股，已在 215号使用）或 akshare 分钟数据

**所需计算**：
1. 管线运行：K线 → 笔 → 线段 → 中枢 → 走势类型 → 背驰 → T8
2. 条形码构造：两种路径——(a) A/C段内中枢的 centers_to_barcode，(b) 笔振荡的 _strokes_to_barcode
3. W_1 范数计算：_w1_norm（已实现）
4. 统计检验：T8 passed 率 vs 随机排列基线（置换检验）

**验证标准**：
- **必要条件**：T8 passed 率 > 50%（非 inconclusive 案例中）
- **充分条件**：T8 passed 率 vs 随机基线的 p < 0.05
- **210号分歧处理**：T8 passed=False 且 MACD agrees=True 的案例分析（不同维度力度）

**当前阻塞项**：
- 分钟级长时间跨度数据获取（208号已尝试 akshare，15min 期货 3个月数据段数不足）
- 递归级别 >= 1 的背驰稀疏性（199号：级别0天然 inconclusive，需大量数据才能产生级别1+的背驰）

**认识论等级标注**：
- 当前实现 + 合成数据验证 = L0 + L1（信息增量为零——合成数据验证管线正确性，不验证假设）
- 5只A股日线 + 16只期货日线 + 4只指数日线 = L2（弱）（208号第二轮：T8 14/23 passed=60.9%）
- 分钟级多标的长跨度 = L2（强）（待执行）
- 多标的多时段交叉验证 = L3（远期目标）

### 推论2：W_1 范数的 gauge 稳定性验证

**问题**：209号显示条形码 bottleneck 距离是 Tier 3（gauge 不变性差），但 W_1 范数（总持续量）是否比 bottleneck 更稳定？

**方法**：在已有的 5只A股 x 3模式（wide/strict/new）数据上，计算每个背驰案例的 W_1 值，分析 W_1 在模式切换下的保持率。如果 W_1 保持率 >= Tier 1（73%），则 T8 的 gauge 不变性得到确认。

**认识论等级标注**：L2（真实数据验证）

### 推论3：三算子方案与现有代码的映射

当前代码结构：
```
a_inclusion.py   → M_delta（包含处理=Morse消去的具体实现）
a_fractal.py     → M_delta（分型识别=临界点标记）
a_stroke.py      → M_delta（笔=Morse消去后的骨架）
a_segment_v1.py  → Z（线段=zigzag条带的第一层）
a_zhongshu_v1.py → Z（中枢=[ZD,ZG]区间=zigzag条带的参数化）
a_move_v1.py     → S（走势类型=层化输出）
a_level_fsm.py   → 递归控制（X_k → X_{k+1} 的循环）
```

这不是新的代码变更需求——三算子方案是对现有代码结构的数学解读。验证方式是确认每个算子的输入/输出类型与代码模块的接口一致。

**认识论等级标注**：L0（纯定义/映射）

### 推论4：条形码多维性

缠师说"力度"是多维度的（MACD面积、价格区间、时间跨度）。T8 的条形码方案天然多维：
- 每个中枢对应一个 bar (birth, death)
- 不同中枢的 bar 长度不同——长 bar 对应持续时间长/价格区间大的中枢
- W_1 范数是所有 bar 的加权总和
- 还可以提取：最长 bar（主中枢特征）、bar 数量（中枢个数）、bar 分布（中枢结构）

这与 MACD 的三维度（面积/黄白线高度/柱子伸长）形成不同的多维度分解。两套多维度互补（210号结论）。

**认识论等级标注**：L0（概念分析）
