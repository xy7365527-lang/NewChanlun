# 523号：中枢基线偏离积分不能平替 MACD

**认识论等级**: L2（腾讯 700 日线单标的单时段，可否证，**否定性结果**——用户明确指示不补
30min 弱 L3）。附带的"第24课面积=动量强度"是**编排者裁定**（语法记录类，价值判断）。

## 发现过程

用户任务：实现无参数力度度量「中枢基线偏离积分」`force = Σ|close(t) − M|`，M = (ZD+ZG)/2 =
中枢中间价（结构性 0 轴，替代 MACD 的 EMA 0 轴），并在腾讯 700 验证能否承担 §5 中
MACD 承担而 H0 不能的角色。

设计动机是针对 §5 两个原因各做一次**换基底**尝试（非绕过，是换基重新表达）：
- 对原因一（H0 ∈ ker(D) 时间盲）：用段内逐根求和 Σ（时间外延）替代端点 persistence。
- 对原因二（0 轴依赖全局 EMA）：用中枢 M（结构性 0 轴）替代移动 EMA 基线。

腾讯 700 日线 L2 实测（`scripts/tencent_zhongshu_force.py`，zigzag legs 与 §5 设置逐字一致，
#33/#37 索引可比）给出**否定性结果**。

## 结论（六要素）

1. **结论**：中枢基线偏离积分（无论 `force` 时间外延积分还是 `force_normalized` 归一化，
   任何字段）**不能平替 MACD 面积**。腾讯 700 日线 L2：

   | 检验 | 偏离积分 | 对照（amp / H0） | MACD 基准 |
   |------|---------|-----------------|-----------|
   | §5 决定性 #33 vs #37 比值 | force **0.71×（反向）**、force_norm 0.51×（反向） | amp 0.98×（反向）、H0 1.13×（同向弱） | **20.9×** |
   | 跨 15 下跌段 vs MACD Pearson | force **+0.580**、force_norm +0.533 | amp **+0.715**、H0 +0.647 | 1.0 |
   | 背驰一致率（19 对） | force 58%、force_norm **68%** | H0 **74%** | 100% |

   - 偏离积分与 MACD 的相关度（+0.53~0.58）**低于纯振幅**（+0.715），背驰一致率
     （58~68%）**低于 H0**（74%）——它不携带 MACD 独有的动量信息，反而比已知劣于
     MACD 的 H0 更差。
   - §5 决定性 case 上**反向** MACD：缓跌 #33 偏离积分反而大于急跌 #37。

2. **定义依据**：
   - 中枢 M=(ZD+ZG)/2：缠论第17-19课中枢定义（ZD=max(member births), ZG=min(member deaths)，
     引自 `a_ph_zhongshu.Zhongshu`）。验证用 zigzag 整理区中点实现 M，并用 `detect_zhongshu`
     结构中枢（日线识别 4 个）交叉印证。
   - 背驰=C段力度<A段：第24课。
   - §5 原因二（第24课一级权威）：背驰 0 轴判据本质依赖**全局连续 EMA**（移动均衡基准）。

3. **边界条件（推翻条件）**：
   - 若 force 与 MACD 相关度 >0.8（任务设定的"可作无参数替代"阈值）——实测 +0.58，远未达。
   - M 取法：当前用"段间整理区中点"。M 取法不同 §5 比值会变（边界条件），但 P2 相关性
     +0.58 < amp +0.715 的结构性弱点不因 M 微调翻转——这是"静态基线偏离=距离×时间，与
     动量正交"的度量本性，非基线伪影。
   - L3 多标的：未做（用户指示不补）。结论不外推至其他标的/时段。

4. **下游推论**：
   - **强化 521号 / §5 原因二 / archive/pending-013**：这是"非 MACD 动量替代"失败的**又一独立
     证据**（与 520号路径空间 PH 否决同构）。MACD 的 0 轴是**移动 EMA 基线**，携带跨段路径
     依赖的 IIR 记忆；任何**静态**基线（结构中枢 M）测的是"离某价位多远×多久"=距离×时间，
     与动量（相对移动均衡的带符号进展率）**正交**。故背驰动量闸**仍必须 MACD**（521号不变）。
   - **§6 三层架构不变**：偏离积分至多作监视层描述性距离标量，**不进决策层**、**不作动量闸**。
   - **补充 522号边界**：522号证 persistence 泛函比面积泛函更抗参数。本结果补充关键 caveat——
     **无参数/参数鲁棒 ≠ 有效**：中枢偏离积分 L0 层 100% 参数鲁棒（根本不读 MACD 参数，
     同义反复），但 L2 无效。常函数也 100% 鲁棒。鲁棒性必须与有效性联合评估（231号 L0 警示）。

5. **谱系引用**：521号（纯拓扑动量不存在——本度量虽非拓扑而是几何积分，但同样因缺移动
   基准而失败）、239号（ker(D) 时间盲——本度量相关度甚至低于振幅）、520号（路径空间 PH
   否决，非 MACD 替代失败的同构先例）、522号（参数鲁棒——本结果补充"鲁棒≠有效"边界）、
   231号（有效域 L0-L3 + 否定性结果优先）、§5/§6/archive/pending-013（persistence_theory）。

## 附：编排者裁定——第24课"面积"= 动量强度（语法记录类）

用户（编排者，2026-05-27）裁定缠论语义：**第24课红绿柱"面积"的本质是动量强度
（force_normalized = 每 bar 平均偏离 = 推进强度/速率），不是时间外延积分（force = Σ）**。

- 据此 `a_zhongshu_force.compare_force` **默认字段改为 `force_normalized`**（原默认 `force`）。
- L2 旁证（非裁定依据，仅一致）：force_normalized 背驰一致率（68%）> force（58%）。
- **此裁定不改变主结论**：force_normalized 与 MACD 相关 +0.533、一致率 68%，仍**不能平替
  MACD**。字段选择只决定本度量内部最忠实第24课语义的读法，不改变"不可平替 MACD"的否定。
- 类型：语法记录（编排者对第24课"面积"语义的价值判断显式化），非定理、非数据推导。
