# 525号：中枢组件局部完成性 + 笔中枢退化基底路径

**认识论等级**：L0（纯原文考据 + 定义推导）。考据见 `analysis/zhongshu_recursion_strictness.md`。
**权威链**：第18课正文（一级权威，博文）> 第17课正文/答疑（一级权威，博文）> 仓库定义文件。

## 概念发现一：原文否定"递归链必须完整到底"

### 决定性原文（缠师亲笔，非编纂版）

> 注意，次级别的前三个走势类型都是完成的才构成该级别的缠中说禅走势中枢，完成的走势类型，
> 在次级别图上是很明显的，**根本就不用着再看次级别下面级别的图了**。
> — 第18课正文（`docs/chanlun/text/blog/018-第18课.md:24`）

第17课答疑对"是否要一路下钻到1分钟图才判定中枢"的提问，缠师**连续两次以"错"开头否定**：

> [答] 错，次级别的前三个走势类型都是完成的才构成该级别的中枢……**根本就不用看到再下面的级别去**。
> — 第17课答疑（`docs/chanlun/text/blog/017-第17课.md:1094-1098`）

### 推论：中枢组件的成立条件 = "在次级别图上完成"（局部、当前级别可观测）

```
前提1: 中枢组件 = 已完成的次级别走势类型（第17课原理二：完成的走势必含≥1中枢）
前提2: "完成"的判定在次级别图上可观测（第18课:24），不需下钻验证内部中枢递归真实性
前提3: 递归下钻只在"最低不可分解级别"触发口径切换（K线重叠，第17课:40），
       这是自上而下递归的边界条件，不是每个高级别中枢都必须展开链到底的要求
────────────────────────────────────────────────────────────
推论: 中枢有效性 = 组件局部完成性，不以"递归链完整可追溯至最低级别"为前提
```

### 对123号的修正（本号的核心否定）

123号引入"真中枢（递归链完整）/ 假中枢（断链）"，并将"递归链完整可追溯至 Move[0]"
列为真中枢的**有效性判据**（`level_recursion.md:138` 条件③，`level_recursion.md:151` "有效性100%/不确定"）。

**本号判定**：条件③作为**有效性判据越界**——原文（第18课:24）明确"完成的走势类型在次级别图上很明显，
不用再看下面级别"，一个在本级别图上**已完成**的中枢，其有效性不以"能否一路追溯到最低级别"为前提。
把"链不完整"单独用作判废一个本级别已完成中枢的理由，与第18课:24 直接冲突。

**但区分两层，避免误伤口径A**（`level_recursion.md:120` 编排者决断 2026-02-16）：

| 条件③ 的用法 | 判定 | 理由 |
|------------|------|------|
| 作为**口径A（自下而上递归）的构造不变量** | ✅ 合法 | 口径A内所有 Move[k] 本就从 Move[0] 构造，"可追溯"是构造副产品 |
| 作为**中枢有效性的概念判据** | ⚠️ 越界 | 原文不支持；中枢只有"完成 vs 未完成"，无"真 vs 假"（"假中枢"是[新缠论]概念） |

**结论**：123号"真/假中枢"二分**保留**，但严格限定为"**组件完成状态（settled）+ 口径A内部一致性**"，
**不得**把"链未完整"单独当作判废本级别已完成中枢的理由。`zhongshu_from_segments` 用
`confirmed AND kind=="settled"` 过滤组件（与原文"完成"条件一致）是正确实现。

## 概念发现二：笔中枢退化基底路径（[新缠论:选择]）

### 选择内容（编排者决断 2026-05-31）

增加构造路径 `zhongshu_from_strokes(strokes) -> list[Zhongshu]`：三笔重叠构成**笔中枢**。
笔级别走势（包含笔中枢的盘整/趋势）可作为更高级别中枢的组件。

### 与107号 C1（笔不裁决）的关系——不冲突

107号 C1 / zhongshu.md #3：「中枢组件必须是线段（次级别走势类型），笔不可作为中枢组件」。

**这仍然对**——但其有效域是**段中枢（线段级中枢）**：在该级别，组件必须是"次级别走势类型"，
而单个笔不是走势类型（走势类型须含≥1中枢，笔不含中枢）。

笔中枢是**不同级别**的中枢：把笔当作"**最低不可分解级别的单位**"，类比第17课递归终止条件——

> 对最后不能分解的级别，其缠中说禅走势中枢就不能用"至少三个连续次级别走势类型所重叠"定义，
> 而**定义为至少三个该级别单位K线重叠部分**。
> — 第17课正文（`017:40`）

**笔中枢 = 把第17课的"单位"从 K线 提升为笔**（[新缠论:选择]）。在此路径下，笔不是"次级别走势类型组件"，
而是"终端递归单位"——正是第17课赋予 K线 的角色。因此笔中枢**不违反**107号 C1（笔仍不可作段中枢组件）。

### 递归关系

```
笔 → (三笔重叠) → 笔中枢 → (笔中枢组合) → 笔级别走势(盘整/趋势)
                                              ↓ 作为组件
                                         更高级别中枢
```

这与发现一一致：笔级别走势在**笔级别图上完成**即可作组件，不需下钻——发现一的"局部完成性"
为笔中枢路径提供了原文层的正当性。

## 结果包六要素

### 1. 结论
原文（第17/18课）否定"递归链必须完整到底"——中枢组件成立条件 = 局部完成性（次级别图上完成）。
123号"递归链完整"作为有效性判据越界，收窄为口径A构造不变量。增加笔中枢退化基底路径
（[新缠论:选择]），不违反107号 C1。

### 2. 定义依据
- 第18课正文 `018:24`：组件条件=完成，且明确禁止下钻。
- 第17课答疑 `017:1098`：两次以"错"否定无限下钻。
- 第17课原理二 `017:52`：完成的走势必含≥1中枢。
- 第17课递归终止 `017:40`：最低级别用"单位"重叠定义中枢（笔中枢把单位=笔）。

### 3. 边界条件
- 若博文中找到缠师明确要求"中枢有效性依赖内部中枢递归完整性"的表述 → 发现一翻转
  （已检索17/18课正文+全部答疑，未发现，反有两处直接否定）。
- 若放弃口径A（自下而上递归）→ 条件③连构造副产品的合法性也失去，须重评估。
- 笔中枢路径：若未来要求笔中枢组件也必须是"走势类型"而非"单位" → 笔中枢路径需重新定位。

### 4. 下游推论
- `level_recursion.md` 真/假中枢二分严格限定为"组件完成状态 + 口径A内部一致性"。
- 高级别中枢判定不应隐式触发到最低级别的递归验证（性能 + 认识论双重理由）。
- `zhongshu_from_strokes` 产出的笔中枢可经 Move 构造层升级为笔级别走势，作为更高级别中枢组件。
- 实时数据中"最高级别总是不完整"是"未完成"而非"假"，两范畴不混用。

### 5. 谱系引用
- 123号（真/假中枢谱系入口）：本号修正其条件③有效性判据越界。
- 107号 C1（笔不裁决）：本号澄清其有效域为段中枢，笔中枢路径不与之冲突。
- 006号（级别递归 vs 多周期下钻）：口径A是"可追溯Move[0]"的合法语境。
- **未发现需矛盾上浮的定义冲突**——原文表述清晰自洽（no-workaround：非绕过，是边界澄清）。
