## 一、(a) 同一-差异双重性（L0，三层证据齐全）

### 1.1 规格原文（doc §3）

> 注意: child.P&L ≡ father.降成本金额（同一数字）
> — `docs/nested_fugue_accounting.md` §3

§8 全局不变量第2/3条：
> 2. 同一笔物理交易只在 ledger 中出现一次（物理层），视图层按需导出
> 3. 子voice.P&L ≡ 父voice.cost_reduction（对任何已完成的短差周期）

**同一**：同一笔物理交易（一个 price×units），物理层**存一次**。
**差异**：父级别视图 = 降成本（cost_basis 降低）；子级别视图 = 独立头寸
（SHORT，capital = 父释放现金，独立 P&L）。**两视图按需导出，同一数字两身份。**

### 1.2 引擎守恒守卫（code §8.1，违反即 Err）

`nested_fugue.rs` 逐 bar 检验 `Σ 链上在手单位 = N_base`（恒仓）；回补时
`子 P&L = units×(entry−exit) ≡ 父降成本`（单元测试数值断言：子
P&L=250×(104−96)=2000 ≡ 父降成本）。守恒守卫返回 `Err` = 双视图不一致即
bug——这是「同一笔存一次」的强制实现。

### 1.3 对抗标注：「同构于信号层」原是用户框架

doc 原文**未做**「会计双重性同构于信号层线段-走势类型双重性」的类比，只到
「同一笔物理交易存一次、视图按需导出」。该同构是编排者 §7.1 洞察 + 蜂群
形式化——**现已由 537号结晶**，故本号 `parallels: ['537']` 是结晶后的对偶
关系，非 doc 原文断言。

## 二、(b) 资金守恒是递归嵌套的解锁条件（证据强度不对称，逐腿标注）

### 2.1 版本命名陷阱（关键——必读）

「v1 配额制 / v2 资金守恒」指的是 `nested_recursive_fugue_final_results.md` 的
**【配额制 v1 vs 资金守恒 v2】**，**不是** analysis 里的 nrf_v2/v3/v4/v5
**回测系列**。`nrf_final_*.json` = 资金守恒 v2 数据。**混淆这两套版本号会导致
严重误读**（nrf 回测系列的 v2/v3/v4/v5 是清仓原则的迭代，与此处「配额制 vs
资金守恒」正交）。

### 2.2 资金守恒 v2 解锁深层（L2，可复验）

- 机制：子 voice 资本 = 父卖出**内生释放**的现金（doc §2「cash_released =
  m×current_price」→ §3 子 capital）。无需「资金分配」，守恒自动成立。
- 实测（`nrf_final_*.json` depth_bars，可复验）：CL depth3 = 131,535 bar +
  depth4 = 67,666 bar（链长 5 = 5 voice 并存，depth≥3 占比 3.6%）；BTC
  depth3 = 54,110 bar。**「4-5 层嵌套」= 链长 4-5 = 4-5 个 voice，在 CL/BTC
  真实涌现**——多空嵌套从边缘现象升为真实结构。

### 2.3 配额制 v1 depth≥3≈0（历史断言，不可独立复验）

- 机制（final_results.md §6）：v1 将 spawn 实装为「θ 配额从 pool 开新头寸」
  ——子头寸从资金池**抢配额**，深层无钱可抢 ⇒ depth≥3 为边缘现象。编排者
  中断否定（「平多/开空混淆为同一交易的两种描述、配额机制非法」），v1 代码
  已被 v2 **全量替换**（commit 39a4b341c2 后丢弃）。
- **对抗标注**：cache 中**无 v1 的 depth_bars 数据**可独立复验。「v1 depth≥3≈0」
  是 L2 断言中**不可复查的一腿**——相信它依赖对已删除 v1 代码的信任，**无法
  从当前仓库重跑验证**。诚实定级：**历史断言**，非可复验实证。

### 2.4 机制因果的强度（弱确认）

「资金守恒是解锁条件」的因果（v1 抢配额无钱→无深层；v2 内生释放→有深层）
与 v2 数据一致，但这是「v2 有深层 + v1 声称无深层」的**对照推断**，**非控制
实验**（无「v1 配额制重跑确认 depth=0」的可复验产出）。属 regime 因果的
**弱确认**——方向合理，强度受 2.3 的不可复验腿限制。

### 2.5 深度上界修正

任务措辞「解锁 4-5 层」。实测**任何版本最深到链长 5**（depth_bars index 4，
CL final=67,666 bar、CL v3=93,956 bar）；depth index≥5（链长 6）未观测到。
「4-5 层」准确，但应理解为「链长 4-5 = 4-5 voice」，非「深度索引 4-5」。

## 四、下游推论

1. **537号是本号的对偶面**：信号层（同一段次级别走势 = 中枢构件 + 走势内容）
   ∥ 会计层（同一笔交易 = 父降成本 + 子独立头寸）。两者是「同一-差异双重性」
   在信号/会计两层的同构实例（§7.1 编排者洞察的结晶）。
2. **不清仓原则的会计前提**：父降成本（不减净暴露）依赖「子独立头寸」吸收
   释放的现金——这是 NRF 恒仓基座（534 趋势 regime 独立暴露）与降成本短差
   在严格会计下兼容的机制。
3. **资金守恒 = 深层嵌套的物质条件**：递归深度（区间套下探到 a0）的**操作
   实现**依赖资金守恒（每层释放的现金成为下层资本）——配额制（外部分配）
   在深层枯竭。这把「区间套递归」从信号层（537/信号双重性）落到会计层的
   资本流。
4. **earning 重定基的对称会计**（doc §7）：cost_pool≤0 后纯利润增 N，多空
   对称；空头「挣负股数」L0 不可构造（在册结算）——双层身份在 earning 阶段
   仍守恒（Σunits=N′）。
