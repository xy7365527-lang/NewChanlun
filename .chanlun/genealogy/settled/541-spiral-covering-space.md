## 一、覆盖空间 → 对数螺旋（共形自相似的唯一性）

走势终完美（T₂：每个走势必走完背驰、新势必反向涌现，第29课）+ 级别递归（T₁₆：每级别完整
形态学，自相似）⟹ 走势的语义空间是一个**递归覆盖空间**：每升一级别 = 覆盖空间的一层
（deck transformation），自相似把第 k 层映到第 k+1 层。

**建模公理 A₅（尺度比 λ 恒定，L2 可证伪）**：相邻级别的尺度比 λ_k = r_{k+1}/r_k 恒定。
在 A₅ 下，递归自相似覆盖空间唯一实体化为**对数螺旋**（伯努利 *spira mirabilis*，confirm
doc §1.2）——它是**唯一**与自身缩放副本共形相似的平面曲线。这不是类比，是范畴论意义的
唯一性：自相似（缩放=旋转）的共形不变曲线在 ℝ² 中只有 r=ae^{bφ}。

**若 A₅ 失效**（λ_k 随 k 剧烈漂移）⟹ 退化为一般单调展开曲线，但 §8.2 标注的"不依赖 A₅"
定理（角向唯一奇点 T₄₇、手性 ℤ/2 T₅₁）仍成立（载体拓扑不依赖 λ 值）。L2 锚：
[[project_highest_level_sigma_frozen]] / `project_1min_resolution_irreducible`。

## 三、螺旋群 G = D∞（穷尽性的群论判定）

**生成元**：h = 角向推进一环（绕一周 r×λ）；τ = 手性翻转（ε↦−ε，多↔空）。

**关系**：τ²=e（手性对合）；**τhτ⁻¹=h⁻¹**（手性翻转反转绕向）；h²³=σ（角径耦合，23 环/圈）。

**为什么半直积 D∞ 而非直积 ℤ×ℤ/2（圆柱）**：直积 = 平凡丛（圆柱）= 多空对称。asymmetry doc
已证方向丛是**莫比乌斯（非平凡）**——ℝ₊ 载体下 τ 把闭端（c=0）映到开端（c=∞），纤维不
同胚 ⟹ 丛非平凡 ⟹ 无全局截面。对应群关系 `τhτ⁻¹=h⁻¹`（半直积）。**群结构编码多空不对称**：
D∞ ⟺ 莫比乌斯 ⟺ 多空不对称。

**统一 group doc 三构造**：
| group doc 构造 | \|G\| | 在 D∞ 中的身份 |
|---|---|---|
| (a) Z/23Z | 23 | 角向商（基本域，丢径向 σ + 手性 τ） |
| (b) F₂₂ | ∞ | 过逼近（仅 R₁，缺 τ²=e + 耦合 + h²³=σ 三关系） |
| (c′) HNN-ℤ | ∞ | 平移子群 ⟨h⟩≅ℤ（径向 σ 塔，缺手性 τ） |

**精确结论**：`G_spiral = D∞` 是完整群；三构造分别是它的商/过逼近/子群。

**穷尽性终判**：
1. **有限呈现穷尽**：2 生成元（h,τ）+ 2 关系（τ²=e, τhτ⁻¹=h⁻¹）从基本域（一圈 = 23 环 ×
   2 手性）生成全部推论类型——§6.4 角向商 Z/23Z 上闭合，**定理类型穷尽**。
2. **群元素不穷尽**：\|G\|=∞（D∞），具体 级别×方向 组合无限——**实例不穷尽**（与 AB 超越判据
   一致：D∞ 无限 ⟹ ξ_u 超越；D∞ 自动群 ⟹ Cobham 自动性相容）。
3. **51 条推论穷尽 = 有限基本域**：46 定理（基本域：角向 23 环 + 手性 + 组合细化）+ T₄₇–T₅₁
   五条三坐标对称定理 = **51 条**，全部落在有限呈现内（不增加 D∞ 生成元）。14 开放轴 =
   D∞ \ 基本域 残余（σ-塔径向 + τ-轨道手性），按结构完备分类无遗漏。

> 「有限呈现穷尽 ∧ 群元素无限」和解为「群作用于空间、基本域有限」标准图景——这是 group doc
> §5.1 差值分析（\|G\|=23−46=−23 或 ∞）的精确答案：完整群无限（D∞），基本域有限（23 环）。
