## 四、核心病灶：顶层腿冻结

**顶层腿全标的全模式 `sw=0 op=1`**——最高级别腿开仓一次后冻结，方向锁死首段（回测起点方向 = 硬币翻面）：

- **ES / S 顶层锁 Long → +694732 超 BH**（锁对 ⟹ ES +681.4★ 是 P1 唯一存活点）；
- **CL / GC / BTC / OKLO 顶层锁 Short → 大涨中失血强平 −100%**（锁错 ⟹ 强平归零）。

顶层腿是几何塔最大配额的承载者，方向首段冻结意味着回测全程押注一个永不翻转的方向。锁对则吃满最高级别趋势（ES），锁错则在该趋势的反方向上被几何塔最大配额放大至强平。

## 七、几何塔配额 = 强平放大器（非配额收敛失效）

几何塔配额**收敛成立**（N=5 不耗尽，与 553/[[project_t_multiscale_independent_filters]] 收敛性一致）。但：

**顶层最大配额 + 顶层方向冻结 → 顶层锁错被几何塔放大至强平**（BTC/OKLO/CL/GC −100%）。

配额收敛是对的，**「顶层最大配额 + 顶层冻结」组合**才是强平主因——不是配额机制错，是顶层腿冻结使最大配额押在了永不翻转的错误方向上。这与 552 §的几何塔分裂（底仓死扣 2/3 + 机动 1/3）形成对照：552 的底仓死扣是 anchor 主动死扣多（吃涨），556 的顶层冻结是被动锁死首段（赌方向），前者吃涨可控、后者赌错即强平。

## 九、张力检查结论

**无不可分层解决的矛盾，不新建张力记录。**

- 556 与 555 是**开放轴 → L3 裁决**的递进关系（555 §5.4 指向读法 B 开放轴，556 是其 L3 否证），分层清晰，非对立结论。556 negates 的是 555 §5.4 的**隐含命题**（每级别独立腿 + d_top 精确切换⟹吃每级别涨跌幅自动成立），不是 555 的已结算结论（区间套递归保证定理 L0+L3、检测对象错诊断）——后者不受影响。
- 556 与 552（anchor 吃涨 5/8）成**吃涨/吃跌有效域对偶**：吃涨（anchor 不等完成）可达 / 吃顶层跌（等完成翻空）样本期不可达。这是同一「最高级别样本期稀疏」根因的两侧，非矛盾。
- 556 与 554（A 路第二层消费级别⊥贯通级别）同构：顶层腿冻结 = 554 第二层在每级别独立腿架构下的复现（顶层 d_top 稀疏）。两者分层一致（554 是单核心消费漏级别、556 是每级别腿但顶层级别无信号），非矛盾。
- 556 与 539（做空失血）：判据 2 否证 = 539 的复现（空腿系统性失血未改善反恶化），分层一致。
- **混合架构（顶层 anchor 死扣多 + 低级别读法 B）= 开放轴**（未试），非已结算矛盾，不上浮。混合架构与读法 B 不是矛盾，是「吃每级别」目标的不同消费架构（读法 B 每级别独立腿赌顶层方向 vs 混合让顶层 anchor 死扣对方向 + 低级别 d_top 切换）。
- **前向链接（557 推进）**：本号 §五「顶层腿冻结=最高级别走势完成 d_top[top] 不触发」诊断已被 **557 部分推进（aufhebung）**——557 实测最高级别卖点 type2（反弹不创新高）@L4=36>type1@L4=30，顶层闸门 view.sell[cc](type1∨2∨3) 使顶层 clears 0→2/3/2/3/1/2/5。本号「最高级别走势完成样本期稀疏」对 **type1（趋势背驰，跨年冻结 clears=0）/type3（cc 中枢需大量 bar，@L4=0）成立**，对 **type2（反弹不新高，不依赖走势完成识别）不成立**。即本号诊断针对「方向/走势完成」（type1）成立，对「卖点 type2」被 557 解（编排者『买卖点不是方向』洞察）。557 是顶层闸门吃跌路径的 L3 PARTIAL（机制成立 + 收益 regime），见 `settled/557-top-all-sell-short-gate-partial-regime.md`，不改本号读法 B 四判据否证结论（读法 B 每级别独立腿赌顶层方向冻结的否证不受影响——557 换的是卖点闸门消费架构非方向腿消费架构）。
