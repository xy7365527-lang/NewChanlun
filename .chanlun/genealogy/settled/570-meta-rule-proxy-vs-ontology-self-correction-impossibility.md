# 元规则观测：代理量→本体量 的自纠不可能性（insight #2）

## 观察

team-lead 报告 insight #2：编排者用**苏格拉底式连续纠正**把"走势涌现/完成"
（模糊代理量）逐步逼回缠论本体"买卖点 + 区间套定位"（精确操作语言）。

这不是孤例。MEMORY 记录了**同结构的领域侧反复**（"代理量 vs 本体量" / "事件 vs
状态范畴" / "错位谱型"）：

- `project_trend_direction_proxy`：回测用 swing 笔端点**代理**走势方向，但走势方向
  缠论正典由中枢定义——标签错配（**第一例**）。
- `project_recursive_position_bsp_falsified`：确认深度被当作 BSP 卖点 = **事件代理
  状态第二例**。
- `project_master_recursive_entry_falsified`：级别确认是**状态范畴第三例**。
- `project_ph_settle_usage_boundary`：PH settle 是形态学必要条件，被越界当作操作
  充分确认。
- 多条 "错位谱型第 N 例"（第四/第五例）跨标的复现。

## 核心判断

> **蜂群的默认梯度指向代理量**——代理量（"走势涌现/完成"、swing 端点、确认深度）
> **易计算**；本体量（"买卖点 + 区间套定位"、中枢定义的方向）**须精确操作定义**。
> 蜂群在缺外部纠正时**系统性地用代理替换本体**，且**不能自纠**——纠正每次都由
> 编排者（外部主体）的苏格拉底链发起。

这是 **187号** 的方法论实例：187 说"亏格必须由异质主体碰撞产生，体系不能自生成
真 Tension"。代理/本体的张力正是这样一类亏格——**蜂群自身分辨不出"我用的是代理
还是本体"**（代理在合成数据/L0 上"看起来工作"，掩盖了它非本体）。分辨需要编排者
持有的本体参照（缠论正典）来碰撞。

## 为什么不能自纠（机制）

1. 代理量在 L0/L1（纯代数 / 合成数据）上与本体量**行为一致**——formalization-
   validity-domain 规则的"合成确认偏差"：代理在自造数据上验证通过，看不出它是代理。
2. 代理与本体的分歧只在 **L2/L3（真实数据）** 暴露（如 swing 端点方向 vs 中枢方向
   在真实行情背离）。但蜂群默认在 L0/L1 收敛、过早结算（meta-orchestration "不要
   过早结算"被违反）。
3. 故"代理 ≠ 本体"是一个**需要本体参照才能看见的亏格**——蜂群内部无此参照
   （参照在编排者/缠论正典处），自纠路径不存在。

## ★自环检查：收敛 / 发散

- **收敛（高）**：MEMORY ≥5 个领域实例（"第二/三/四/五例"）+ 本 session 走势代理
  = 跨多次 session 稳定重复的**领域侧**模式。
- **发散（新维度）**：先前各实例被记为**领域**谱系（各自标的的回测否证）。本观测把
  它们**上提为元层模式**——不是"某个代理在某标的失败"，而是"**蜂群的认知梯度
  结构性偏好代理**"。这是从领域散点到元层根因的跨层归并（历史未在元层命名）。

## 与 010 / 047 的关系

- 010号（construction-vs-classification）：构造优先于分类——代理量常是"分类标签"
  （swing 端点贴方向标签），本体量是"构造定义"（中枢构造出方向）。代理 = 越过构造
  直接贴分类标签 = 010 的违反模式。
- 047号（cash-vertex-redefinition）：曾发生过"操作量 vs 观测量"的概念分离——代理/
  本体之分与之同构（观测代理 vs 操作本体）。

## 定义依据

- 187号（settled）：亏格须异质主体碰撞产生，体系不能自生成真 Tension——本观测的根因。
- 010号（settled）：构造优先于分类——代理量=越构造贴标签的违反。
- 047号（settled）：操作量/观测量概念分离先例——代理/本体同构。
- formalization-validity-domain（rule）：合成确认偏差——代理在 L0/L1 掩盖其非本体性。
- MEMORY：project_trend_direction_proxy / project_recursive_position_bsp_falsified /
  project_master_recursive_entry_falsified（≥3 显式"第 N 例"领域复现）。

## 边界条件（结论翻转）

1. 若蜂群能在**无编排者介入**下，仅靠 L2/L3 真实数据回测**自主**从代理回退到本体
   （如 quality-guard skill 内建"代理量检测"）→ "自纠不可能"被否证，本观测降级为
   "尚未实装自纠机制"而非"结构不可能"。
2. 若"走势涌现/完成"在某严格定义下**等价于**"买卖点+区间套"（非代理而是同义）→
   则本 session 实例不是代理替换而是术语差异，需领域工位裁定。当前 team-lead 述
   "模糊代理 → 精确操作语言"明确指代理，故成立。
3. 若编排者的苏格拉底纠正可被**结晶为可执行判据**（代理/本体的形式化判别函数）→
   则该亏格从"须主体介入"降级为"机器可处理"（187 的两类亏格边界移动）。

## 下游推论

1. **方法论警示**（语法记录候选）：涉及"走势"的产出，须先核验用的是**本体量**
   （买卖点 + 区间套定位 / 中枢定义方向）还是**代理量**（swing 端点 / 确认深度 /
   "涌现/完成"措辞）——后者须标注为代理并说明有效域（L2/L3 才能证伪）。
2. 这条警示可下沉为 domain-conventions 或 quality-guard 的扫描项（代理量措辞检测）
   = 选择（是否结晶 + 落点）→ /escalate。
3. 编排者苏格拉底链的**可结晶性**（能否形式化为判别函数）= 187 亏格边界的开放轴。
