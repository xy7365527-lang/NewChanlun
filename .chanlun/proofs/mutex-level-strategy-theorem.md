## 定理1（细分类 oracle 不劣 V(Z)≥V(Y)）— PDF §6 p5-6 + §11 p23

### 陈述
细状态 `Z=(ℓ,δ,I_γ,r,σ_p,ω,κ,β,d,c,m)` 是粗状态 `Y=(ℓ,δ,I_γ)` 的细化（存在粗化投影
`ϕ:Z→Y`，把细状态映到其前三分量）。则细状态的 oracle 价值不劣于粗状态：

    V(Z) ≥ V(Y)。

### 前提
- **细化关系**：`Y=ϕ(Z)`，ϕ 是从细状态到粗状态的投影（丢弃 `(r,σ_p,ω,κ,β,d,c,m)`）。
- **oracle 价值**：`V(·)=` 已知真实条件期望后、在该状态空间上可达策略集的上确界收益。

### 证明（L0）
任意粗状态策略 `π_Y: Y → A` 可被细状态策略**模拟**：定义 `π_Z(z)=π_Y(ϕ(z))`——
即细状态忽略额外分量 `(r,σ_p,ω,κ,β,d,c,m)`，沿用其粗化投影 `ϕ(z)` 对应的动作。
故细状态可达策略集 ⊇ 粗状态可达策略集，上确界单调：

    V(Z) = sup_{π_Z} 收益(π_Z) ≥ sup_{π_Y} 收益(π_Y) = V(Y)。∎

### 结论
引入级别 ℓ / 多空 σ_p / 角色 r / 背驰 β 等额外分量，**在 oracle 意义下不降低可达 alpha**——
只提升表达力（细 oracle 总能模拟粗策略），不会变差。

### 关键警示（必写 — PDF p7 / p24）
**「提高表达力 ≠ 保证实证赚钱」。** 定理1 是 **oracle 不等式**（已知真实条件期望 μ 时成立），
**不是有限样本下的实证保证**：

- `V(Z)≥V(Y)` 用的是**真实条件期望**（oracle）。
- 实践中须从**有限样本估计** μ̂。状态越细，每个细状态的样本越**稀疏** → 估计噪声越大 →
  过度细分导致 μ̂ 严重偏离 μ，实证表现可能**劣于**粗状态。
- 因此细分必须配合 **OOS（样本外）/ 收缩（shrinkage）/ LCB（置信下界）** 控噪声（p7 / p24）。

把定理1 当作「细分一定赚钱」是**有效域膨胀**（formalization-validity-domain 禁止模式）：
oracle 不劣（定义域）≠ 有限样本不劣（有效域）。

## 定理2（级别×多空拆分必要性）— PDF §4/§5 p4-5

> **本份 PDF 真正新增**（前序三份 alpha.pdf/alpha2.pdf/严格alpha.pdf 均无此命题）。

### 陈述
不按级别 ℓ、多空 σ_p 拆分而直接**合并估计**条件收益 μ_pool，会把不同级别/多空的条件收益
**平均/抵消**，导致误判「无 alpha」——即使各子条件确有 alpha。故按级别×多空拆分**不是可选项，
是必要项**。

### 前提
- **合并估计** `μ_pool = E[X | I_γ]`：不条件化级别/多空，只按拓扑分类 I_γ 聚合。
- **拆分估计** `μ_{ℓ,σ} = E[X | I_γ, ℓ, σ]`：进一步条件化级别 ℓ 与多空 σ。

### 证明（L0，反例构造）

**反例一（多空抵消，PDF p4）**：设同一拓扑分类下
- 多头条件收益 `μ_{ℓ,+} = +0.3`
- 空头条件收益 `μ_{ℓ,−} = −0.3`

若多空各占一半样本，合并估计

    μ_± = ½·(+0.3) + ½·(−0.3) = 0。

合并 μ_±=0 ⟹ 误判「无 alpha」，**实则多头有 alpha**（μ_{ℓ,+}=+0.3>0）。多空方向相反的
条件收益在合并时直接抵消。

**反例二（级别稀释，PDF p5）**：设高级别 buy 有 alpha（`μ_{ℓ高,+}>0`），但该高级别状态条件概率
极低 `P(ℓ高 | +) ≪ 1`。合并估计

    μ_pool ≈ P(ℓ高|+)·μ_{ℓ高,+} + (1−P(ℓ高|+))·μ_{ℓ低,+} ≈ μ_{ℓ低,+} ≈ 0

（低级别无 alpha 主导，高级别 alpha 被稀释到可忽略）⟹ `μ_pool≈0` 误判「无 alpha」，
**实则高级别有 alpha**。

两反例共同机制：合并是**条件收益的概率加权平均**，方向相反者抵消、低概率者被稀释，
均可使 `μ_pool→0` 而掩盖子条件的 `μ_{ℓ,σ}>0`。∎

### 结论
**引入级别×多空拆分不是可选项，是必要项**——不拆分则合并平均/抵消，把存在的 alpha 误判为不存在。
这与定理1 互补：定理1 说细化在 oracle 上不劣（表达力侧），定理2 说级别×多空这一维度的细化是
**识别 alpha 所必需**（不细化则 alpha 不可见）。

### 边界条件（结论翻转条件）
- 反例一翻转：若多空不抵消（`μ_{ℓ,+}` 与 `μ_{ℓ,−}` 同号或样本权重悬殊），合并不掩盖——
  但一般无法先验保证不抵消，故拆分仍是稳健必要项。
- **关键警示**：拆分识别出的 `μ_{ℓ,σ}>0` 仍是 **L2 经验命题**——定理2 只证「不拆分会掩盖 alpha」
  这一 L0 结构事实，**不证**任何具体 `μ_{ℓ,σ}` 实际为正。拆分使 alpha 可见，不创造 alpha。
  样本稀疏代价仍适用（定理1 警示）：拆分越细每格样本越少，须配合收缩/LCB/OOS。

### 认识论等级
**L0**（反例构造，从合并 = 概率加权平均的定义直接推出，零信息增量）。
拆分后各 `μ_{ℓ,σ}` 是否真正为正是 L2/L3 经验命题，PDF 不提供，本文档不声明。

## 定理3（鞅不可能定理 — 级别化版）— PDF §12 p10 / p24

### 陈述
即使把级别 ℓ、多空 σ、背驰 β、仓位等全部加入扩展信息集 `F_t`，若价格对 `F_t` 仍是鞅
（`E[P_{t+1}−P_t | F_t]=0`），则任意以这些特征为条件的策略期望净收益 `E[ΔR] ≤ 0`。

### 前提
- **扩展信息集鞅**：`E[P_{t+1}−P_t | F_t]=0`，其中 `F_t` 已含级别/多空/背驰/仓位等全部特征。
- **特征 F_t-可测**：细状态 `Z_t`、配额/动作 `q_Θ`、多空方向 `side` 均为 `F_t`-可测
  （它们都由当前可观测信息算出）。

### 证明（L0）
策略在 t 时刻的净敞口 `N_t`（由 `Z_t, q_Θ, side` 决定）是 `F_t`-可测的。由塔性质：

    E[N_t (P_{t+1}−P_t)] = E[ N_t · E[P_{t+1}−P_t | F_t] ] = E[N_t · 0] = 0。

毛收益期望 = 0。扣交易成本 `C ≥ 0`：

    E[ΔR] = E[N_t (P_{t+1}−P_t)] − E[C] = 0 − E[C] = −E[C] ≤ 0。∎

### 结论
**这不是实现问题，是所有因果交易策略的数学限制。** 无论特征集如何细化（加级别/多空/背驰/仓位），
只要价格对扩展信息集是鞅，所有 `F_t`-可测敞口的期望净收益 ≤ 0。细化特征集不能突破鞅约束——
这正划出定理1（表达力不劣）的有效域上界：表达力提升在鞅市场下不转化为正期望收益。

### 边界条件（结论翻转条件）
市场**非鞅**（`E[P_{t+1}−P_t | F_t] ≠ 0`）时，`F_t`-可测敞口可有正期望净收益——
这恰是「条件方向预测 μ>0」的情形（严格alpha 定理3 的 alpha 充要来源）。鞅是否成立是 L2 经验命题，
可被真实数据否证；定理3 只证「若鞅则 E[ΔR]≤0」这一 L0 蕴含。

### 与前序谱系的对齐（不重复造）
**= 《严格alpha.pdf》定理1（结构完备 ⊬ alpha）的级别化版**：`strict-alpha-theorem-chain.md`
定理1 的信息集是「全互斥分类 C_Θ:X→Z」，本份把 `F_t` 扩展为**显式含级别/多空/背驰/仓位**——
证明骨架（塔性质 + F_t-可测敞口 + 扣成本）一字同构。本份贡献 = 显式声明「特征集再细化也不能突破鞅」，
是定理1 oracle 不劣命题的**有效域上界**。

### 认识论等级
**L0**（塔性质恒等式，从鞅 + F_t-可测敞口定义推出，零信息增量）。
鞅是否对真实市场成立是 L2/L3 经验命题（可否证），本文档不声明。

## 三定理整体结构

| 定理 | PDF | 确立/否定的对象 | 与前序关系 | L 等级 |
|------|-----|----------------|-----------|--------|
| 1 | §6 p5-6 + §11 p23 | 确立细分类 oracle 不劣 V(Z)≥V(Y)（含级别/多空/角色/背驰），+ 样本稀疏警示 | = 严格alpha 定理4 级别化同构 / 657 同源 | L0 |

**逻辑链**：定理1 说细化（含级别/多空）在 oracle 上不劣（表达力侧不亏）→ 定理2 说级别×多空拆分是

非鞅才有 alpha 来源）。三者共同结论：**级别×多空细化是合法且必要的表达力方向，但表达力 ≠ 盈利，
盈利须 L2 实证 + 收缩/LCB/OOS 控样本稀疏噪声。**

## 结果包六要素

1. **结论**：第4份 PDF《缠论的全互斥定义策略》含三条 L0 定理。本文档逐条对齐 PDF 页码并标注认识论等级。
   核心命题：**细分类 oracle 不劣 V(Z)≥V(Y)（定理1，L0，含稀疏警示）；级别×多空拆分必要——不拆则
   合并抵消/稀释掩盖 alpha（定理2，L0，本份新增）；扩展信息集鞅下 E[ΔR]≤0，细化特征集突破不了鞅
   （定理3，L0）。** 三定理全 L0，是数学必然，非 alpha 经验证据。

2. **定义依据**（输入数据特征满足定义的哪些条件）：
   - 定理1 依据「细化关系 Y=ϕ(Z)（粗化投影丢弃 8 个额外分量）」+「oracle 上确界单调」
     （PDF §6 p5-6 / §11 p23）——Z 含级别/多空/角色/背驰满足「Z⊇Y 的加细」条件。
   - 定理2 依据「合并估计 μ_pool = 条件收益的概率加权平均」（PDF §4/§5 p4-5）——
     多空 μ_{ℓ,+}=+0.3 / μ_{ℓ,−}=−0.3 满足「方向相反抵消」、P(ℓ高|+)≪1 满足「低概率稀释」。
   - 定理3 依据「扩展信息集鞅 E[P_{t+1}−P_t|F_t]=0」+「Z_t,q_Θ,side 均 F_t-可测」
     （PDF §12 p10 / p24）——所有特征由当前信息算出满足 F_t-可测，敞口 N_t 因而 F_t-可测。

3. **边界条件**（结论翻转条件）：
   - 定理1 翻转（实证层）：有限样本下细分状态样本不足 → μ̂ 噪声 > 信号 → V̂(Z) < V̂(Y)（p7/p24）。
     oracle 层不翻转（加细可模拟粗化是恒真）。
   - 定理2 翻转：多空不抵消（μ_{ℓ,+}/μ_{ℓ,−} 同号或权重悬殊）时合并不掩盖——但无法先验保证，
     故拆分仍为稳健必要项。拆分识别出的 μ_{ℓ,σ}>0 是 L2 经验命题，可被真实数据否证。
   - 定理3 翻转：市场非鞅（E[P_{t+1}−P_t|F_t]≠0）时 F_t-可测敞口可有正期望收益（= alpha 充要来源）；
     鞅是否成立是 L2 经验问题。

4. **下游推论**：
   - 任何「靠级别/多空/背驰特征细化就赚钱」的设计在鞅下 E[ΔR]≤0（定理3）——细化是表达力前提，
     不是盈利保证；alpha 仍须 μ>0（严格alpha 定理3 充要来源）。
   - 层级收缩工作（sg-hier-shrink + sg-three-way-l2）的方向合法（定理1 oracle 不劣 + 定理2 拆分必要），
     但**必须**用收缩/LCB/OOS 控样本稀疏噪声落到 L2 实证——其实证价值是 L2，非本文档承载。
   - 任何把 L0 表达力定理（定理1/2）的有效域膨胀为「细分一定赚钱」的产出被否决（有效域膨胀禁止模式）。
