## 定理0（过拟合是估计器属性，非分类器属性）— PDF §6, p26

### 陈述
结构层 `Z_t = C_Θ(X_t)` 给定数据是**确定函数**，不优化训练收益：

    C_Θ ∉ argmax_C Σ_t R_t(C)

故结构层**无统计学习意义上的训练过拟合**。但估计层选择器

    χ(z) = 𝟙[μ̂(z) > θ]

等价于「在训练集上寻找正样本均值类别」，其有效自由度大约与可选类别数 K 有关，
与缠论规则参数数无关。

### 结论（原文方框，p26）
> **过拟合的自由度来自 z 类别选择和 μ̂ 的噪声，不来自 C_Θ 的拓扑规则。**

### 认识论等级
**L0**。从「C_Θ 是确定函数（不含 argmax 优化）」+「χ 含 argmax_z 选择」的定义直接推出。
这是后续定理1–3 的对象界定：下文所有过拟合机制都发生在 **μ̂ 估计层 / χ 选择层**，与 C_Θ 无关。

## 定理1（winner's curse：零 alpha 世界必现训练内假阳）— PDF §3, p24–25

### 陈述
设 K 个状态类别 z=1,…,K，**每类真实收益都为零** μ_z = 0。
训练样本估计 μ̂_z = ε_z，其中 ε_z ~ N(0, σ²/n_z)（取 n_z = n 简化）。
策略选训练最佳类别 ẑ = argmax_{1≤z≤K} μ̂_z。则训练内估计收益 μ̂_ẑ = max_z ε_z。

### 证明（L0）
极大值期望为正且有闭式近似（原文 p24–25 方框）：

    E[max_z ε_z] ≈ (σ/√n) · √(2 log K) > 0

故**即使真实所有类别都没有 alpha（μ_z=0），训练中也几乎一定出现一些「看起来很赚钱」的类别**。
但在 OOS 中，所选类别的真实期望仍是 μ_ẑ = 0，扣成本后：

    E[X_OOS | ẑ] ≤ 0

∎

### 结论（原文方框，p25）
> **在零 alpha 世界里，选择训练均值最高的类别必然产生训练内正收益假象，OOS 消失。**
> 这就是 winner's curse。**这与缠论结构是否确定无关。**

### 推论1a（稀疏高级别类别更严重）— PDF §4, p25
当 n_z 不同时 sd(μ̂_z) = σ_z/√n_z。某高级别类别只有 n_z = 1,2,3 时估计分布非常宽
（n_z=2 时只要两笔交易恰好都盈利就得到很大的正 μ̂_z）。故：

> **稀疏高级别类别最容易被误选为 alpha。** = variance-estimation noise relabeled as signal.

这与 660（高级别 χ_t inconclusive）的稀疏机制直接同构。

### 认识论等级
**L0**。`E[max ε_z] ≈ (σ/√n)√(2logK)` 是高斯极值统计的标准结论（零信息增量，由 N(0,σ²/n) 分布推出）。
**winner's curse 是 argmax 选择算子的属性，对任何零均值噪声成立，与被分类对象的语义无关。**

## 定理2（多重比较：高维 z 空间裸 μ̂>θ = 大量多重比较）— PDF §5, p25–26

### 陈述
K 个类别各做一次检验 H_{0,z}: μ_z ≤ 0。

### 证明（L0）
即使每个类别在零假设下只有 5% 假阳性率，**至少出现一个假阳性**的概率（独立检验下）：

    1 − (1 − 0.05)^K

当 K = 100 时：1 − 0.95¹⁰⁰ ≈ 0.994。∎

### 结论（原文方框，p26）
> **高维 z 空间里，裸 μ̂ > θ 等价于大量多重比较。**
> 若不做 shrinkage、LCB、FDR、holdout/cross-fit，必然过拟合。

### 认识论等级
**L0**。`1−(1−α)^K` 是独立伯努利试验「至少一次成功」概率的恒等式（零信息增量）。
**多重比较是检验次数 K 的属性，不是分类规则的属性。**

## 定理3（Le Cam 两点下界：信息论硬墙，非估计器可解）— PDF §13–§14, p31–32

### 陈述（这是最深的一条）
高级别稀疏类别的可识别性受**信息论硬墙**限制，不是换估计器能解决的。分两层：

#### 第一层：功效下界（§13, p31）
高级别状态 z 出现概率 λ_z，训练窗口 T，则样本数 n_z ≈ T·λ_z。
真实边际收益 Δ_z = μ_z − θ > 0，效应大小 d_z = Δ_z/σ_z。
要以一侧 5% 显著、80% 功效检出，约需 n_z ≳ 6.19/d_z²，即：

    T ≳ 6.19 / (λ_z · d_z²)

> 如果高级别信号几个月一个，则 λ_z 很小，所需 T 会非常大。**这不是工程问题，而是信息问题。**

#### 第二层：Le Cam 两点论证（§14, p31–32）
考虑两个世界 H_+: μ_z = +Δ vs H_−: μ_z = −Δ，观测 X_i ~ N(μ_z, σ²), i=1,…,n。
两个分布的 KL 距离（原文 p31）：

    D_KL(H_+ ‖ H_−) = n(2Δ)²/(2σ²) = 2nΔ²/σ²

### 证明（L0）
若 `nΔ²/σ² ≪ 1`，则 KL 距离 → 0 ⟹ 两个世界统计上不可区分 ⟹
**任何规则都无法可靠判断 μ_z 是正还是负**（Le Cam 两点法：KL 小 ⟹ 任意检验的错误概率有正下界）。∎

### 结论（原文方框，p32）
> **当 n_z d_z² 很小，任何估计方法都无法可靠识别高级别 alpha。**
> 这证明了：稀疏高级别类别不是靠换估计器就能完全解决的。

### 推论3a（660 的信息论根因）
660 号「高级别 χ_t inconclusive」的「功效不足」**= `n_z·d_z² ≪ 1` 在真实数据上的实例**。
Le Cam 下界给出 660 的根因：不是 χ_t 估计器选得不好，而是高级别类别样本量 `n_z ≈ T·λ_z`
在 λ_z 小时（高级别信号稀疏）落进信息论不可区分区。**换估计器、调阈值、加特征都无法逾越——
唯一出路是增大 T（更长历史）或降低有效维数（§11–§12，pooling/正则化提高 λ_z 或 d_z）。**

### 推论3b（跨品种 pooling 的严格条件）— PDF §15, p32
pooling 可提升有效样本 `n_z^pool = Σ_a n_{a,z}`，但仅当跨品种同类信号异质性 τ_z² 小时无偏；
τ_z² 大时强行 pooling 引入偏差。层级模型 `μ̂_{a,z}^shrink = w_{a,z} X̄_{a,z} + (1−w_{a,z}) μ̂_z^pool`
在两者间折中（品种样本少但跨品种同质 → 收缩强；品种差异大 → 收缩弱）。
**即：pooling 是降低 Le Cam 墙的合法手段，但有效性是 L2/L3 经验命题（τ_z² 须实测）。**

### 认识论等级
**L0**。功效公式 `n ≳ 6.19/d²` 是标准功效分析；`D_KL = 2nΔ²/σ²` 是两个等方差高斯 KL 的恒等式；
Le Cam 两点法是统计判定下界的标准定理（零信息增量）。
**这是信息论硬墙——它界定了「无论何种估计器」都无法逾越的有效域边界，是不可能性结果（最强的 L0）。**

## 结果包六要素

1. **结论**：本 PDF §3–§14 含三条 L0 定理 + 一条对象界定（定理0），完整回答「为什么过拟合」。
   核心命题：**过拟合是估计器属性（μ̂ 选择层）非分类器属性（C_Θ 拓扑层，定理0/§6）；
   零 alpha 下 argmax 选择必现 winner's curse（定理1，E[max ε]≈(σ/√n)√(2logK)>0，OOS≤0）；
   高维 z = 大量多重比较（定理2，K=100→0.994）；高级别稀疏类别受 Le Cam 信息论硬墙限制
   （定理3，nΔ²/σ²≪1 ⟹ 任何估计器不可区分 μ 正负）。** 全部 L0。

2. **定义依据**：
   - 定理0 依据「C_Θ 确定函数，C_Θ ∉ argmax_C Σ R_t(C)」+「χ(z)=𝟙[μ̂>θ] 含 argmax_z」（§6, p26）。
   - 定理1 依据「μ_z=0 + μ̂_z=ε_z~N(0,σ²/n) + ẑ=argmax μ̂_z」+ 高斯极值期望（§3, p24–25）。
   - 定理2 依据「K 个独立检验 H_{0,z}: μ_z≤0, α=0.05」+ 至少一假阳概率恒等式（§5, p25–26）。
   - 定理3 依据「n_z≈Tλ_z + 功效公式 n≳6.19/d²」（§13）+「两高斯 KL = 2nΔ²/σ² + Le Cam 两点法」（§14, p31–32）。

3. **边界条件**（结论翻转条件）：
   - 定理0/1/2 不翻转（恒等式/极值统计/伯努利概率，数学必然）。其**前提**（μ_z=0、独立检验）
     是否对真实数据成立属 L2——但即便 μ_z≠0，winner's curse 仍使 μ̂_ẑ 上偏（只是 OOS 不必 ≤0）。
   - 定理3 的硬墙在 `n_z·d_z² ≫ 1` 时**失效**（样本充足时可区分）——即增大 T（更长历史）、
     提高 λ_z/d_z（pooling/降维，§11/§15）可越过墙。但 `n_z·d_z²` 的实际取值是 L2/L3 经验问题
     （由 sg-lcb-l2 工位实测，可否证）。

4. **下游推论**：
   - 任何「训练集 μ̂>θ 选最佳类别」的裸策略在高维 z 下必然过拟合（定理1/2）——
     sg-lcb-l2 工位**必须**用 shrinkage + LCB + holdout/cross-fit（§7–§10），不可裸阈值。
   - **660 号「高级别 χ_t inconclusive」的根因被定理3 给出**：不是估计器问题，是 `n_z·d_z²≪1`
     的信息论不可区分——故 660 的合法出路是「增大 T / 降低有效维数 / 跨品种 pooling」，
     不是「换估计器或调阈值」（后者无法逾越信息论硬墙）。
   - 降低有效维数（§11，φ:Z→U 压缩映射；§12，L1/L2 正则化）是提升 λ_z/n_z 的合法方向，
     与 strict-alpha-theorem-chain.md 定理4「细分 oracle 不劣但须控噪声」互补——
     **定理4 给上界（表达能力），本文定理3 给下界（信息论可识别性），共同夹出有效域**。
