## 定理1（结构完备 ⊬ alpha）— PDF p9-10

### 陈述
全互斥分类 C_Θ: X → Z（每个走势态 x 被唯一映射到一个分类标签 z）作用于鞅市场，
则任意建立在该分类上的全互斥策略期望净收益 ≤ 0。

### 前提
- **全互斥分类** C_Θ: X → Z：分类完备（覆盖所有 x）且互斥（每个 x 唯一标签）。
- **鞅市场**：E[P_{t+1} − P_t | F_t] = 0（在信息集 F_t 下，下一步价格变化的条件期望为零）。

### 证明（L0）
任意全互斥策略在 t 时刻的净敞口 N_t 是 F_t 可测的（由分类标签决定，分类是当前可观测的）。由塔性质：

    E[N_t (P_{t+1} − P_t)] = E[ N_t · E[P_{t+1} − P_t | F_t] ] = E[N_t · 0] = 0。

毛收益期望 = 0。扣除交易成本 C ≥ 0：

    E[ΔR] = E[N_t (P_{t+1} − P_t)] − E[C] = 0 − E[C] = −E[C] ≤ 0。

∎

### 结论
**完全分类是动作合法性定理，不是盈利定理。** 分类完备保证「每个走势态都有合法动作」，
不保证「这些动作组合起来赚钱」。在鞅假设下，纯依赖分类（不含条件方向预测）的策略期望净收益 ≤ 0。

### 认识论等级
**L0**。零信息增量——结论从「鞅 + F_t 可测敞口」的定义直接推出，不依赖任何市场数据。

## 定理2（吃到每个元素 ⊬ alpha）— PDF p10-11

### 陈述
对走势分解的每个元素 e 执行 Eat(e)（按元素自身端点方向建仓），单元素毛收益恒正，
但元素组合的净收益不保证为正。

### 元素毛收益恒正（L0 同义反复）
元素 e 的毛收益：

    G_e = q_e · ε_e · (P_ρe − P_λe) = q_e · |P_ρe − P_λe| > 0

其中 ε_e = sign(P_ρe − P_λe) 是**端点方向定义**（用元素终点 P_ρe 和起点 P_λe 算出的事后方向）。
代入后 ε_e·(P_ρe − P_λe) = |P_ρe − P_λe| ≥ 0 恒成立——**这是端点方向定义的同义反复，非因果预测**。

### 反例：覆盖完备 ⊬ 净值盈利
- 父元素多头腿：净敞口 +Q
- 子元素短差空头腿：净敞口 −Q
- 合并净敞口：N = Q − Q = 0 ⟹ N·ΔP = 0 ⟹ R = −C ≤ 0

虽然每个元素单独的毛收益都 > 0，组合后净敞口抵消，净收益退化为 −成本。

### 结论
**覆盖完备 ⊬ 净值盈利。** 「吃到每个元素」是覆盖性陈述，不是盈利性陈述。

### 与已结算谱系的对齐（不重复造）
定理2 的「ε_e 端点方向同义反复」**= 项目 pending 657 候选2 / M24 因果可测性的同一发现**，
引用其精确措辞（`.chanlun/genealogy/pending/657-*.md` candidate_2_m24_causal_measurability）：

- **(a) L0 同义反复（零预测）**：G_e = q_e|ΔP| > 0 恒真——按段自身方向投影必非负，
  对任何走势数据恒成立，零预测力。= **645 T2**（G_e>0 恒真语法）在 M24 的实例。
- **(b) 因果失败（非 F_λe 可测）**：ε_e = sign(P_ρe − P_λe) 用**未来段终点 P_ρe**，
  非段起点 F_λe 可测 = 事后方向标签（lookahead）。= **645 T3**（ε_e lookahead）在 M24 的实例。

即定理2 是 alpha.pdf 对「645 T2/T3 + 657 候选2」的**第三份独立深化**（不是新发现，是外部权威再确认）。

### 认识论等级
**L0**。G_e>0 是恒真语法（端点方向定义的同义反复），ε_e 用未来端点非 F_λe 可测——
两者都从定义推出，零信息增量。**G^sep>0 是恒真语法，不是可交易 alpha。**

## 定理3（真 alpha 的充要条件）— PDF p11-12, p23

### 陈述
可交易 alpha 存在 ⟺ 存在状态 z 和动作 a，使条件期望收益 μ(z,a) > 0。

### 形式化
动作集含**不交易动作 a0**，且 X(a0) = 0（不动则零收益）。定义条件期望收益：

    μ(z, a) = E[X(a) | Z = z]

最优价值（oracle，在已知 Z 后选最优动作，含「不交易」兜底）：

    V* = E[ max(0, max_a μ(Z, a)) ]

（max(0, ·) 来自 a0 的存在——任何状态下都可选不交易得 0，故最优值 ≥ 0。）

### 证明（L0）
- **充分**：若 ∃z*, a*: μ(z*, a*) > 0，则在状态 z* 选 a* 的条件收益 > 0，对其余状态选 a0 得 0，
  故 V* ≥ P(Z=z*)·μ(z*,a*) > 0。可交易 alpha 存在。
- **必要**：若 ∀z,a: μ(z,a) ≤ 0，则 max_a μ(Z,a) ≤ 0 ⟹ max(0, max_a μ(Z,a)) = 0 ⟹ V* = 0。
  无任何状态-动作组合产生正条件收益，最优策略退化为永远不交易。

∴ V* > 0 ⟺ ∃z,a: μ(z,a) = E[X(a)|Z=z] > 0。∎

### 结论
真 alpha 的**唯一来源**是「存在某个状态下，某个动作的条件期望收益为正」。这与定理1/2 互补：
定理1/2 否定了「分类完备」「覆盖完备」作为 alpha 来源，定理3 给出 alpha 的**充要来源**——
条件方向预测（μ>0），而非覆盖或分类。

### 认识论等级
**L0**（充要条件本身是数学恒等式）。**但注意**：μ(z,a) > 0 这一命题**是否对真实市场成立**
是 **L2/L3 经验命题**——定理3 只证明「若 μ>0 则 alpha 存在」，不证明「μ>0」。
μ>0 的实证由 sg-lcb-l2 工位承载（真实数据，可否证）。

## 定理4（细分类不劣）— PDF p24

### 陈述
用非拓扑度量（背驰力度 β、风险距离 d_risk）细化状态空间得到
Z_full = (Z_top, β, d, c, r) ⊇ Z_top，则细状态的 oracle 价值不劣于粗状态：V(Z_full) ≥ V(Z_top)。

### 证明（L0）
Z_full 是 Z_top 的**加细**（refinement）——Z_top 是 Z_full 的粗化投影。任意建立在粗状态 Z_top 上的
策略 π_top，都可被细状态 Z_full 上的策略模拟（在每个细状态上沿用粗状态对应的动作，忽略 (β,d,c,r)）。
故细状态可达的策略集 ⊇ 粗状态可达的策略集 ⟹ 细 oracle 的上确界 ≥ 粗 oracle 的上确界：

    V(Z_full) ≥ V(Z_top)。∎

### 结论
表达能力上，加细状态空间**理论上**不会变差（细 oracle 总能模拟粗策略）。

### 关键警示（必须写进文档 — PDF p25）
**「提高表达能力 ≠ 保证实证赚钱」。** 定理4 是 **oracle 不等式**（已知真实 μ 时成立），
**不是有限样本下的实证保证**：

- V(Z_full) ≥ V(Z_top) 用的是**真实条件期望 μ**（oracle）。
- 实践中 μ 须从**有限样本估计** μ̂。状态越细，每个细状态的样本越少 → 估计噪声越大 →
  过度细分导致 μ̂ 严重偏离 μ，实证表现可能**劣于**粗状态。
- 因此细分必须配合 **LCB（置信下界）/ OOS（样本外）/ 收缩（shrinkage）** 控制估计噪声（p25）。

**定理4 是 L0 表达能力陈述；LCB 选择器的实证改善是 L2 命题**（需真实数据，由 sg-lcb-l2 工位承载，
非本文档）。把定理4 当作「细分一定赚钱」是**有效域膨胀**（formalization-validity-domain 禁止模式）：
oracle 不劣（定义域）≠ 有限样本不劣（有效域）。

### 认识论等级
**L0**（oracle 不等式，从加细可模拟粗化推出）。p25 警示明确划出 L0→L2 边界：表达能力 L0，实证赚钱 L2。

## 结果包六要素

1. **结论**：严格alpha.pdf 含一条 L0 定理链（定理1-4）。本文档逐条对齐 PDF 页码并标注认识论等级。
   核心命题：**结构完备/覆盖完备 ⊬ alpha（定理1/2，L0），alpha 充要来源是条件方向预测 μ>0（定理3，L0），
   细分类 oracle 不劣但须 LCB/OOS 控噪声落实证（定理4，L0 + p25 警示）。**

2. **定义依据**：
   - 定理1 依据「鞅 E[P_{t+1}−P_t|F_t]=0」+「全互斥分类 C_Θ:X→Z」（PDF p9-10）。
   - 定理2 依据「端点方向定义 ε_e=sign(P_ρe−P_λe)」（PDF p10-11）——同义反复，非因果预测。
   - 定理3 依据「条件期望收益 μ(z,a)=E[X(a)|Z=z]」+「不交易动作 a0, X(a0)=0」（PDF p11-12, p23）。
   - 定理4 依据「状态加细 Z_full⊇Z_top」+「oracle 上确界单调」（PDF p24-25）。

3. **边界条件**（结论翻转条件）：
   - 定理1 翻转：市场**非鞅**（E[P_{t+1}−P_t|F_t]≠0）时，分类策略可能 E[ΔR]>0——但这正是定理3 的 μ>0 情形。
   - 定理2 翻转：元素组合**不抵消**（净敞口 N≠0 且方向与 ΔP 同向）时毛收益不抵消——但这要求 μ>0（定理3）。
   - 定理3 不翻转（充要条件是数学恒等式）；其**前件 μ>0 是否成立**是 L2 经验问题，可被真实数据否证。
   - 定理4 翻转（实证层）：有限样本下若细分状态样本不足，μ̂ 噪声 > 信号，则 V̂(Z_full) < V̂(Z_top)（p25）。

4. **下游推论**：
   - 任何「靠完全分类/吃满覆盖赚钱」的策略设计在鞅假设下 E[ΔR]≤0（定理1/2）——蜂群已结算谱系
     645/657 的同一结论，本 PDF 是外部权威再确认。
   - alpha 工作的方向必须是**寻找 μ(z,a)>0 的 (z,a)**（定理3）——即 657 候选1 所述「因果可测的 χ_t 择时方向 π^bsp」，
     不是覆盖 π^cov。
   - 细化状态空间（β/d_risk）是合法的表达能力提升方向（定理4），但 sg-lcb-l2 工位必须用 LCB/OOS 防过拟合。
