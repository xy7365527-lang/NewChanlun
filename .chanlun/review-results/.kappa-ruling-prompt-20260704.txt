# 裁定问题：M7 三阶段资金的 barrier 缓冲系数 κ —— 冻结值 / 网格 / 裁定依据

## 背景

M7「三阶段资金接入」的核心是一个 barrier-gated 状态机：CostReduction → CapitalRecovered → EarningShares（单向不可逆）。进入 EarningShares（增股数）阶段的门槛是「在险权益 η_t 必须 ≥ 风险 barrier η_*」。

η_* 的定义（PDF §10 原文）：

    η_*(x_t) = L^wc_{t+1} + κ · Q_t

其中：
- L^wc = 建仓后最坏损失（worst-case loss）= (notional_in − withdrawn)⁺（尚未退回的在险本金；本金全退后 = 0）
- Q_t = 名义敞口 = notional_in（campaign 原始名义）
- κ = barrier 缓冲系数（PDF 明确标注「价格不可导出」——即 κ 不是缠论可导的量，是 extra-缠论的风险政策参数）

EnterReady 五合取谓词（PDF §10 步骤3）：
    EnterReady_t = (S_t=II) ∧ (W_t ≥ I_0) ∧ (openLegacyLegs_t=0) ∧ RiskNormal_t ∧ (η_t ≥ L^wc_{t+1} + κ·Q_t)

本金全退时 withdrawn ≥ notional_in ⟹ L^wc = 0 ⟹ η_* = κ·Q。故：
- κ=0 ⟹ η_* = 0 ⟹ η≥0 恒过 barrier（最小基线，仅要求在险权益非负）
- κ>0 ⟹ η_* = κ·notional_in > 0 ⟹ 要求在险权益超出名义敞口 κ 倍才能进增股数（额外安全缓冲）
