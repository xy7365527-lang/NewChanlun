## 2. 口径 A 降 legacy 的命名与保留方案

口径 A 不能简单删除——`third_spans_core`（站点2）承担**A/B 等价见证**的功能（谱系 637 codex L0 核验：`ZD_B≤ZG_B ⟺ A 前两段核心非空 ∧ 第三段贯穿`）。删除它 = 抹掉 A→B 迁移的等价性证据链。保留但明确其"降级"身份。

### 2.1 站点2 `third_spans_core`——保留为派生见证，命名不改，注释补 legacy 标注

- **裁决（定理类，四分法自决）**：保留函数，**不改名**（改名会破坏已存在的测试引用 `center.rs:304` + 上级几何路径复用注释）。
- **补充**：在 doc 注释首行加 legacy 血统标注——`/// [口径 A legacy 派生谓词]`——使其"非 canonical 构造路径、仅见证"的身份在符号级可见（当前身份只在段落中隐含）。
- **理由**：`no-patch` 要求"代码能做什么就声明什么"。当前 `third_spans_core` 的注释已说明它是派生谓词，但函数签名/首行未标 legacy，读者可能误当构造判据复用。

### 2.2 站点2 `geometric_window_two_segment_core_bit_exact` 测试名——重命名（残留 A 命名）

- **裁决（定理类）**：测试名含 `two_segment`，但 body（center.rs:339-349）实为全三段 B（`zd=max(0,3,5)=5`）。名实不符 = 声明膨胀。
- **方案**：重命名为 `geometric_window_three_segment_core_bit_exact`。零逻辑改动，纯名同步。

### 2.3 站点4 `legacy_v0_interval`（口径 C）——保留为反例负锚点，声明不变

- **裁决**：保留。已正确标注"已裁决错"+`legacy_v0` 前缀 + parity 负锚点（`v0_v1_interval` fixture 断言 `v0≠v1`）。**无需改动**。
- **理由**：口径 C 是 637 谱系的机器反例（`legacy_v0_not_correct_for_v1_reference`），删除 = 抹掉反例。当前命名已严格。

### 2.4 站点2/主塔 `classifier/mod.rs` docstring——文档漂移，必须同步 B

- **发现（缺口）**：`mod.rs:122` `detect_centers_complete` docstring 写 "完整判据：方向交替 ∧ **前两段核心非空 ∧ 第三段贯穿**"，`mod.rs:140` `detect_centers_geometric` 写 "几何三支：**前两段核心非空 + 第三段贯穿**"。二者均描述**旧 A 三支判据**，与它们实际调用的 `center_from_segments`/`center_from_window`（已迁 B 两支：方向交替 ∧ 全三段核心非空）**不一致**。
- **裁决（定理类）**：docstring 同步为 B——"方向交替 ∧ 全三段核心非空（第三段贯穿已吸收，637号 codex L0 等价）"。这是 137 号语法记录的镜像：声明层漂移必须消除。纯注释改动。

## 3. 原文对齐（权威链裁决 B canonical）

任务要求"第17/18课中枢定义行号"。逐字考古结果——**血亲证据直接支持 B 为 canonical，A 是编纂版误差**：

### 3.1 一级权威（缠师博文，最终权威）——口径 B 严格公式

- **blog `018-第18课.md` line 24**（决定性）：
  > "具体的计算以前三个连续次级别的重叠为准，严格的公式可以这样表示：次级别的连续三个走势类型A、B、C，分别的高、低点是a1\a2,b1\b2,c1\c2。则，中枢的区间就是（**max（a2,b2,c2），min（a1,b1,c1）**）"
  → a2/b2/c2=低点、a1/b1/c1=高点 ⟹ `ZD=max(三段低)`、`ZG=min(三段高)` = **口径 B 全三段**。缠师用"严格的公式"明示这是权威口径。
- **blog `017-第17课.md` line 38**：中枢定义 = "被至少三个连续次级别走势类型所重叠的部分"——三段重叠 ⟹ B 语义。

### 3.2 第二级权威（chan99 编纂版）——口径 A（前两段），与 B 冲突

- **chan99 `0010-第八节 走势中枢.md` line 23**：
  > "再定义 ZG=**min(g1、g2)**，ZD=**max(d1、d2)**，显然，[ZD，ZG]就是走势中枢的区间"
  → **口径 A 前两段**。这是编纂版的"再定义"，与 line 5 的定义"三个连续次级别重叠"自相矛盾。
- **知识库 `缠论知识库.md`**：行 253（原文口径 = 前三个重叠 = B）vs 行 267-268（再定义 = 前两段 = A）——编纂版内部张力被知识库如实记录。

### 3.3 裁决

CLAUDE.md 三级权威链："当层级间有出入时，以更高层级为准"。blog 第18课（一级，line 24 严格公式 = **B**）**压倒** chan99 第八节（二级，line 23 = A）。

> **口径 B（全三段）= canonical（一级权威严格公式背书）。口径 A（前两段）= 编纂版误差口径，降 legacy。口径 C（首尾段）= 机器反例，已否定。**

这为主塔已迁 B（cefb29df69）提供了溯源依据——迁移方向与最终权威一致，非任意选择。第18课 line 24 的严格公式应作为 637 谱系"A/B 有效域"的**权威裁决锚点**（当前谱系仅引 chan99 §6.4 二级，未引 blog 第18课一级严格公式——建议 genealogist 补录）。

## 4. GOLDEN 重基线与信号集差异报告的执行方案

### 4.1 现状确认（parity 层已 B 一致，无需重基线）

- `theta_v0_center_parity.json` fixture 锚 `ref_v1`（B）+ `legacy_v0`（C 反例），**不锚** center.rs `compute_zd/zg`。B 迁移未触碰此 fixture，parity 层已 B 自洽。

### 4.2 待确认缺口（backtest GOLDEN 信号基线）

**未验证项**：backtest 端（`runner.rs`/`incremental.rs`）是否有一条 GOLDEN 信号序列基线随 A→B 变化。B 收窄核心（`ZD_B≥ZD_A`、`ZG_B≤ZG_A`），仅当**第三段比前两段窄**时 B≠A，此时下游随之变：

| 下游消费 ZD/ZG | B 收窄的方向性影响（代数 L0，非 L2 定量） |
|----------------|---------------------------------|
| 位置三态 `classify_position` | 核心 [zd,zg] 变窄 ⟹ 更多点判 below/above，更少 within |
| 中枢延伸（区间重叠判据） | 核心变窄 ⟹ 后续段更易脱离核心 ⟹ 中枢更早终结 ⟹ 中枢**数量可能增加**、单枢**段数减少** |
| 三类买卖点（ZG/ZD 边界） | 阈值边界收窄 ⟹ 三买回抽"不破 ZG"更易满足（ZG 降低）、三卖"不破 ZD"更易满足（ZD 升高） |
| 背驰/力度（跨中枢） | 中枢分段变化 ⟹ 力度比较的锚区间移动 |

**方向预期（L0 定性）**：越是"第三段收窄"高发的级别/标的，B 与 A 分歧越大；第三段普遍贯穿的走势 A=B 无差异。哪些级别实际变窄 = **L2 经验问题，本设计不能断言**（formalization-validity-domain：定量属 L2，读只读设计只给方向）。

### 4.3 执行方案（留给 #11 实装 + 回测工位）

1. **基线捕获**：在 B 迁移 commit 的**父提交**（cefb29df69^）checkout，跑 BTC/CL 等 GOLDEN 标的 backtest，dump 信号序列（type1/2/3 买卖点 + 中枢边界）为 `pre_B_signals.json`。
2. **后基线**：HEAD（B）同标的同参数跑，dump `post_B_signals.json`。
3. **差异报告**：diff 两序列，按级别/标的统计 (中枢数 Δ、信号数 Δ、变窄枢占比)，落盘 `.chanlun/review-results/637b-golden-diff-<date>.md`。认识论标 **L2**（真实标的假设检验）。
4. **GOLDEN 更新裁决**：若差异非空 ⟹ B 是正确口径（§3 权威裁决），旧 GOLDEN 是 A 误差基线 ⟹ **重生成 GOLDEN = post_B**（不是"回退保 A"）。若差异空（GOLDEN 标的第三段全贯穿）⟹ 无需改 GOLDEN，报告记录"A=B on GOLDEN"。
