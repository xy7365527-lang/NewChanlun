## 1. 结论

A2 残余三件全部落地：

1. **边界③ codex 裁定**：`VERDICT: ISOMORPHIC-WITH-AMENDMENT-收窄成立但prereg须改`——ForceStateA5 与 Θ_DOM 支配序结构同构（四态判据同 schema），𝒜₄→𝒜₅ 是 proxy 参数扩展非判据结构差异；A2 收窄**不撤销**，但 OOS 统计口径必须标 A5 amended，不冒充原 prereg A4。已按裁定在新 prereg 中显式 amendment。
2. **判定口径开关**（L1）：`DivergenceGauge { MacdArea(默认), ThetaDom, Conjunction }` 落 `divergence.rs`，判定单一点 `confirm_divergence()`（divergence.rs）；开关经 `ThetaConfig.divergence_gauge` 进 `judge_first_cached`（signal.rs）——D（buy1/sell1 背驰确认）从硬编码 `macd_c_lt_a` 变为口径参数化。**默认 MacdArea bit-exact 不变**（1483 lib 测试全绿含全部 GOLDEN/digest guard 零改）。ThetaDom 口径下 force 无源（dif/closes 空）⟹ D=false（诚实不判，不 fallback 混口径）。
3. **Θ_SCORE 原语**（设计档 §4.2 有定义 ⟹ 同批实装）：`ForceProxies::theta_score()`（β_norm=(m_A−m_C)/(m_A+m_C)，m=dif_peak，双零→0）+ `ThetaScoreBin`/`theta_score_bin()`（K=3 冻结边界 0/0.33）。角色=分层键候选（方案 B）非判定口径；**分层键接入点在 mu_estimator/ResidualTrade（ws-etab 并发域，本工位不触碰）——接入登记为诚实缺口**，原语层已备。

### 2.2 Θ_SCORE 单特征 vs 原文「多特征」——诚实收窄标注（231号/formalization-validity-domain）

**原文 p10 §9.2 逐字**：`Θ_SCORE：标准化多特征得分`（**多**特征）。**代码 `theta_score()`（divergence.rs:388-395）用单 proxy `dif_peak` 的归一化差** `β_norm=(m_A−m_C)/(m_A+m_C)`。

这是 beta-bucket-design v2 §4.2 的显式工程选择（m=dif_peak，理由=第17课「黄白线最重要」+层级 `级别≻DIF≻面积` 中 DIF 是最高单指标），**不是原文 canonical Θ_SCORE**。原文「多特征得分」的完整形态应是多个 proxy 的加权/组合标量——但 p7 定理2 已证：任意加权和 `F(m₁,m₂)` 都是额外选择 Θ，无原文唯一推出。故：

- **有效域标注**：`theta_score()` 是 Θ_SCORE 族的**单特征实例**（有效域 ⊂ 定义域），非原文完整多特征得分。命名诚实——设计档 §4.2 已注「m=指定单一 proxy」。
- **不虚报**：不声称 `theta_score()` 是原文 canonical β 标量。它是分层键**候选之一**（方案 B），K=3 冻结边界本身是预注册 Θ 选择（p10「不能先看结果再选」）。
- **本任务不扩多特征的理由**：Θ_SCORE 是分层键候选（非判定口径），且分层键接入点在 ws-etab 域（本工位不触碰）；多特征组合需先定权重 Θ 并预注册，属分层键真接入时的工作，非本批 judge 口径接入范围。原语层提供单特征实例已足够解锁下游，多特征扩展登记为诚实缺口。

## 3. 边界条件（结论翻转）

- (a) 若编排者否决 A5 amendment（严格按原 prereg 𝒜₄ 跑）⟹ OOS 须重跑 4-proxy 投影口径（codex 裁定给出的退路；`force_state()` 加 A4 变体即可，判据结构不变）。
- (b) G2≡G3 的「Dominated⟹MACD 衰减恒成立」是 BTC OOS 域观测（L2），非定理——若换标的/窗口出现 area 等值 + 其余 proxy 严格衰减的样本，G3 与 G2 分歧。
- (c) 三口径 alpha 差异 inconclusive 依赖当前一类样本量（17-38 笔）——一类触达率若因上游（#144/#145 修复链）提升一个量级，须重跑本批。
- (d) 非默认口径（ThetaDom/Conjunction）若被切为生产默认 ⟹ 信号集合变更 ⟹ 所有既有 MacdArea 口径 alpha 冻结失效，须全链重冻结（与 margin #113 同纪律）。
- (e) **诚实缺口——递归力度**：原文 §5(p6) 𝒜_ℓ 含 `Σ_{次级别同向段} m_{ℓ-1}(u)`（递归次级别力度），现 `ForceProxies` 缺此项 ⟹ `ForceStateA5` 是完整 𝒜_ℓ 支配序的宽近似（Dominated 是超集）。补齐后 Dominated/Tie 只可能变 Incomparable（单调，codex②），不反向 ⟹ 现口径宽判背驰是安全侧（不漏背驰、可能多判）。补齐属 A1/A6 透传链下游，非本批范围。
- (f) **诚实缺口——Θ_LEX 未实装**：原文 §9.2 三套 Θ 中 `Θ_LEX(结构>DIF>面积 词典序)` 本批未做（只做 Θ_DOM + Θ_SCORE 原语）。Θ_LEX 需 §8.3 的 `Weak_LEX` 分层判定（level 可判非平局→用 level；平局→DIF；DIF 不可判→area），是独立 gauge 变体。登记为诚实缺口——若终局 alpha 重跑（#181/#182）要求三套 Θ 全 OOS 对比，须补 `DivergenceGauge::ThetaLex` 变体。
