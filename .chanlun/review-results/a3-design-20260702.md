## 1. 任务(a)：05_compose_resume 内部拆解方案

### 1.1 05 当前是黑箱

`compose_level_resume`（recursive_tower.rs:396-426）单个 `stage_profile::time` 包住三件事：
1. `detect_centers_windowed_resume`（:409）——从 `resume_start` 续扫窗口的**纯中枢检测循环**（center_from_segments/center_from_window）。
2. `tail_centers` collect（:410）——`windowed.iter().map(|(c,_)| *c)`，Center 是 Copy，O(tail)。
3. `tail_upper` build（:411-424）——每个新窗口 `subs_moves[win[i]].clone()`×3 + `LeveledMove::compose`。`clone` 是 `Rc<Vec<LeveledMove>>` 引用计数（O(1)），但 `compose` 内可能有分配。

60% 的耗时到底落在哪一件上，**无数据**。三种假说定性完全不同的处置：

| 假说 | 若成立 | 处置域 |
|------|--------|--------|
| H-detect：耗时在 detect 循环，且**重扫跨度 `units.len() - resume_start` 随 n 增长** | resume_from 滞后 → O(n²) 续扫（`project_frontier_resume_bt_too_late` 同源） | **A4 域**（窗口封存/resume 锚前移），算法层，A3 不动 |
| H-detect-bounded：detect 循环耗时但跨度 O(1)（resume 锚贴近末尾） | 每 bar 常数次 center_from 调用×levels×bars = 真不可约计算 | **不可约**，唯一出路是减 build 调用频次（generation 已做），A3 不动 |
| H-clone：耗时在 tail_upper build（subs clone/compose 分配） | 有可压拷贝 | 可 A1 式 Rc 复用 subs / 预分配，**A3 可延伸** |

### 1.2 拆解插桩设计（零行为改变，env-gated）

在 `compose_level_resume` 内加三个子标签（`super::stage_profile::time`，classifier 是 recursive_tower 的父模块，路径可达；env 未启用时闭包直通，bit-exact 铁律不动 mod.rs:770-772）：

```
05a_detect_windowed   ← detect_centers_windowed_resume(units, build, start_i)
05b_tail_centers       ← windowed.iter().map collect
05c_tail_upper_build   ← windowed.iter().enumerate().map(compose) collect
```

**关键第四维（区分 H-detect vs H-detect-bounded）**：detect 内部的**重扫跨度**必须单独统计，不能只测时间。加一个 env-gated 累加器 dump：

```

05_span_max    = max(span)                      // 峰值跨度
```

## 2. 任务(b)：per-level dirty_from 证书（禁 did_extend 全局标志）

### 2.1 为什么禁 did_extend（verdict 已证伪）

`did_extend`（mod.rs:952）是**全局 bool**：任一级 extend 非空即置真。它无法定位「哪个下标以下不可变」。verdict 反例：**pop-and-rescan 在 did_extend=false 时仍改写尾部**——

主循环 :1024-1033：当 `had_emitted_window`（`resume_from < consumed`），pop 掉最后一个 center/upper_move（:1031-1032），compose 从 `resume_from` 重扫重新产出。若重扫在**当前 bar 未新增窗口**（tail 空 ⟹ did_extend 不置），但重扫产出的 frontier upper_move **值**可能已变（bar-1464 seg[9] end 1384→1170 同类：段数不变、末段原地改写）。全局标志 did_extend=false 会误判「前缀未动」，漏掉尾部改写 ⟹ 投影/BSP memo 复用陈旧。

**根因**：正确的不可变前缀边界是**每级一个下标**，不是一个全局布尔。

### 2.2 证书 = 已存在的 prefix_count（最小改写下标，零新簿记）

关键洞察：主循环 :1044 已经在算这个下标——`compose_level_resume(..., lc.upper_moves.len())` 的第 6 参 `prefix_count`。它取值时机 = pop 块（:1031-1032）**之后**、extend（:1053）**之前**，正是「本级 upper_moves 经 pop 后的不可变前缀长度」：

- 无 pop 无 cascade：`prefix_count = 旧 upper_moves.len()`（前缀全稳）。
- had_emitted_window：`prefix_count = 旧 len − 1`（pop 掉 frontier 那一个，其余稳）。
- cascade_reset：upper_moves 已 clear（:996），`prefix_count = 0`（全重扫）。

**证书定义**：`prefix_count[L]` = 本级 upper_moves 的不可变前缀长度。它同时是：
1. 本级 `projected_units` 需重投影的起点（投影 `[prefix_count..]` 可能变，`[..prefix_count]` 必不变）。
2. **下一级** units 的不可变前缀 `dirty_from[L+1] = prefix_count[L]`。

**为什么下标精确（含投影的前驱依赖）**：`project_to_units` 的 `projected[idx] = fold_direction(moves[idx], moves[idx-1])`（recursive_tower.rs:443/462）。upper_moves`[..prefix_count]` 不变 ⟹ `projected[..prefix_count]` 不变（`projected[prefix_count-1]` 依赖 `moves[prefix_count-1]` 和 `moves[prefix_count-2]`，二者均在稳定前缀内）。`projected[prefix_count]` 依赖 `moves[prefix_count]`（extend 首元，可能新）⟹ 从 `prefix_count` 起脏。**无需 −1 偏移**，证书恰好落在 prefix_count。

### 2.3 L0 的 dirty_from

L0 的 units = `l0_units`（segment 投影），无父级 prefix_count。其不可变前缀 = mod.rs:856 的 `reuse = l0.segments_confirmed_len.min(l0_units_cache.len())`——parser confirmed 前缀跨 bar bit-stable（#106 证书，同 moves_tower_l0）。故 `dirty_from[0] = reuse`（与现 03 的 `stable = confirmed_len.min(scanned)` 同源，:981-982）。

### 2.4 证书线程（top-down，天然可达）

级别自顶向下处理（L0→L1→…），处理 L 时父级 L−1 已算完 prefix_count[L−1]：

```
loop 前：dirty_from = reuse            // L0
loop 内 L：
  用 dirty_from 做 03 stable + 04 keep（见 §3）
  … pop / compose(prefix_count=lc.upper_moves.len()) / extend …
  重投影 projected_units（truncate 到 prefix_count 再 append，见 §2.5）
  dirty_from = prefix_count            // 传给下一级 L+1
```

新增状态 = 主循环一个 `let mut dirty_from: usize`。**无新 cache 字段、无全局标志**。

### 2.5 顺带修正 project_to_units_resume 的 append-only 脆弱性（soundness 加固）

**现状（脆弱但当前 sound）**：`project_to_units_resume`（:1123）是纯 append（`for idx in cache.len()..moves.len()`），**不感知 pop**。had_emitted_window pop 后，projected_units 未 truncate，其 `[prefix_count]` 保留上 bar 值。当前之所以不炸：唯一会让该值陈旧的情形（frontier 改写）被 03 检出 ⟹ cascade ⟹ :1001 清空 projected_units 全重投影，**pop 非 cascade 时重扫产出的 frontier bit-identical**（窗口已 sealed 或前缀稳定），陈旧值恰好等于新值。这是**隐式依赖 cascade 兜底**的 subtle soundness，非显式证书。

**证书化修正**：重投影显式 truncate 到 prefix_count：

```rust
lc.projected_units.truncate(prefix_count);          // 丢弃 pop 掉的 frontier 投影
recursive_tower::project_to_units_resume(&lc.upper_moves[..], &mut lc.projected_units);
```

- bit-exact：pop 非 cascade 时重投影的 `[prefix_count]` 与旧值 bit-identical（同输入同 fold）⟹ 结果不变，只多算 1~3 个 frontier 元素（O(tail)，可忽略）。cascade 时 prefix_count=0，与现 clear+全投影一致。
- 加固：不再隐式依赖「cascade 会兜底 frontier 陈旧」，dirty_from 显式覆盖 pop 尾部。这消除 verdict 点名的 did_extend 类漏判。
- 现 :1001 的 `projected_units.clear()` 可保留（cascade 时 prefix_count=0，truncate(0)==clear，冗余但无害；ponytail：留着当 cascade 显式意图标记，不删）。

### 2.6 修正：级别早停缓存血缘失效（codex 审计完备性缺口）

**codex 审计点名的第三条真实缺口**（§4 表原只列了「pop 单删末尾 / fold 1 阶前驱」两条翻转条件，遗漏此条）：两处早停会跳过某级及所有更高级本 bar 的处理，但**不失效它们的 `LevelCache`**，令 `dirty_from` 与陈旧快照之间失去血缘 ⟹ §3.3 的 `stable = dirty_from.min(scanned)` 比较区间可能坍缩为空 ⟹ `frontier_mutated` 无条件为 `false` ⟹ cascade 该触发未触发 ⟹ 下游复用陈旧数据。

**为何是 A3 新增失效面（非既有 bug 重述）**：当前生产 L1+ 恒 `stable=0`（:985），`stable` 永不大于 `scanned`，坍缩路径不存在。A3 §3.3 引入 `dirty_from` 抬高 `stable` 后才新增此面。

**两处早停 = 两处不同的可达级别边界**：

| 早停 | 代码锚 | 语义 | 已处理的最高级 | 修复 |
|------|--------|------|---------------|------|
| `units.len() < min_parts` | mod.rs:956-958（循环体**顶部**，break 前 level_idx 未处理） | level_idx 及所有更高级本 bar 全跳过 | `level_idx − 1` | `cache.levels.truncate(level_idx)` |
| `units.is_empty()` | mod.rs:1128-1130（循环体**尾部**，level_idx 已处理完） | level_idx 已处理，level_idx+1 起因空 units 跳过 | `level_idx` | `cache.levels.truncate(level_idx + 1)` |

**为何 truncate 是正解（不是 clear 单槽）**：跳过的是 level_idx 起的**连续尾段**级别，且这些级别与其上所有级别本 bar 全部无输入。`truncate` 直接丢弃这段不可达尾巴的 `LevelCache`（含陈旧 `cached_units`/`scan_cursor`/`last_input_len`）。当这些级别 M 个 bar 后重新达到 `min_parts` 恢复，主循环 :964 的 `if cache.levels.len() <= level_idx { push default }` 会重建**空** `LevelCache`（`start_i=0` 全量扫）——无陈旧血缘，`dirty_from` 与新鲜全扫快照血缘自洽。

**bit-exact**：truncate 掉的级别本 bar 本就不产出（早停跳过），删其缓存不改本 bar 任何输出；恢复时全量重扫与「从未缓存」语义一致（等价于该级首次出现）。cascade/generation 不受影响：早停级别无 extend、无 frontier 比较。

**ponytail 边界**：truncate 只在早停**发生时**执行（稀疏，非每 bar），O(被删级数) 且级数 ≤ l_max（常数级）——零热路径开销。不引入新状态、不改 `l_max` 上界逻辑。

## 3. 任务(c)：04 cached_units_copy 显式纳入证书半边

quality-guard 点名：04 是克隆簇最大单段（4010ms），若只做 03 不做 04，收益从裂缝掉出。

### 3.1 现状

```
03: frontier_mutated = units[stable..scanned] != cached_units[stable..scanned]   // 检测器
04: cached_units.clear(); cached_units.extend_from_slice(&units);                 // 每 bar 全量快照
```

- L0：`stable = confirmed_len.min(scanned)`（已用证书）。
- L1+：`stable = 0`（:984，保守全量比较，「不假定相等」）。
- 04：**无论级别每 bar 全量拷贝** units → cached_units。

### 3.2 证书化 04（truncate + extend，O(tail)）

`cached_units` = 上 bar 的 units 快照。`units[..dirty_from]` 可证 == 上 bar units[..dirty_from]（§2.2），而 cached_units[..dirty_from] = 上 bar units[..dirty_from]（04 上 bar 所写）⟹ **cached_units[..dirty_from] == 本 bar units[..dirty_from]，前缀无需重拷**：

```rust
// 04 证书化
let keep = dirty_from.min(lc.cached_units.len()).min(units.len());
debug_assert!(
    units[..keep] == lc.cached_units[..keep],
    "dirty_from 证书违反：cached_units[..{keep}] 应等于 units 前缀（bit-exact 护栏）"
);
lc.cached_units.truncate(keep);
lc.cached_units.extend_from_slice(&units[keep..]);
```

- **终长约束（:969 截断语义）**：`keep + (units.len() − keep) == units.len()` ⟹ `cached_units.len() == units.len()` 恒成立（含 units 回缩：keep ≤ units.len()，truncate 到 keep 再补到 units.len()）。✓
- **debug_assert 全量比较作 debug/test 护栏**（约束）：debug/test 构建跑 O(keep) 全前缀比较，证书若被违反立即炸；release profile 按 Rust 语义剥离 debug_assert（这就是省下的 4010ms 的来源）——故 debug_assert 是 debug/test 层锁，非 release 正确性锁。

### 3.3 证书化 03（L1+ stable 抬到 dirty_from）

```rust
let stable = dirty_from.min(scanned);   // L0: reuse.min(scanned)（不变）；L1+: 父 prefix_count（从 0 抬起）
let frontier_mutated = units[stable..scanned] != lc.cached_units[stable..scanned];
```

- soundness：dirty_from 是可证不可变前缀 ⟹ `[..stable]` 不可能变 ⟹ 不比较该区间不漏 mutation。真正触发 cascade 的 mutation 恒在 frontier `[stable..scanned]`（bar-1464 末段在 scanned 内），仍逐值比。✓
- L0 无变化（reuse ≈ confirmed_len）；**收益全在 L1+**（原 stable=0 全窗比较 → 前缀跳过）。
- 与 04 共用 §3.2 的 debug_assert 护栏（同 dirty_from、同 cached_units），一处 debug 全比覆盖 03+04 两处。

## 4. bit-exact 论证汇总（codex 审重点）

| 声明 | 依据 | 翻转条件 |
|------|------|---------|
| dirty_from[L+1] = prefix_count[L] 是可证不可变前缀 | pop 只删末 1 / cascade clear 到 0 / 无 pop 保全长；投影 fold 前驱依赖落在稳定前缀内（§2.2） | 若 pop 改为删 >1 或改写非末尾 ⟹ 证书失效（当前 pop 恒 `.pop()` 单个，:1032） |
| 04 truncate+extend ≡ 全量 clear+extend | cached_units[..keep] == units[..keep]（§3.2）；终长 == units.len() | debug_assert 全前缀比较；GOLDEN digest |
| 03 stable=dirty_from ≡ stable=0 | 不可变前缀不含 mutation，frontier 窗仍全比 | 同上 debug_assert |
| 重投影 truncate(prefix_count) ≡ append-only | pop 非 cascade 时 frontier 投影 bit-identical；cascade 时 prefix_count=0 退化全投影 | GOLDEN + bit_exact_per_bar |
| 级别早停后 `stable` 无坍缩（§2.6） | 早停处 `cache.levels.truncate(level_idx/level_idx+1)` 丢弃不可达级陈旧血缘 ⟹ 恢复时全扫重建，`dirty_from` 与新鲜快照血缘自洽 | 若删 truncate ⟹ 跳过后恢复的级别 `stable=dirty_from.min(scanned)` 坍缩为空、`frontier_mutated` 假阴（§2.6）；always-run oracle 级别重入路径锁 |

**护栏三层**：(1) `debug_assert` **debug/test 护栏**（debug/test 构建全前缀比较，release profile 按 Rust 语义被剥离——**不是** release 正确性锁；若需 release 校验须用 env-gated `assert!` 或采样，本设计不寄望于此）；(2) GOLDEN digest（signal.rs:1666）；(3) 新增 always-run 合成 oracle（§5）。

## 5. 验收（护航组强制）

继承 plan §二泳道A 验收 + 护航组额外要求：

1. `bit_exact_per_bar`（incremental.rs:116）+ `bit_exact_synthetic`（:164）+ `gen_fastpath_bit_exact_debug`（:1074）+ signal GOLDEN digest（:1666）全绿。

3. **新增 always-run 合成 oracle：稀疏变异事件对拍**（codex 审计强制，非 ignored/诊断）。理由（plan §二泳道A + codex 审计(3)）：`bit_exact_synthetic` 2000 bar 对 pop-and-rescan 覆盖弱，现有 `project_to_units_resume` 测试（recursive_tower.rs:803 附近）只覆盖 append-only/clear 两路径，bar-1464 相关测试（incremental.rs:520/1071）多 ignored/诊断。新测须 **always-run**（默认 CI 执行，非 `#[ignore]`），构造 had_emitted_window 反复触发（末段古怪线段重划序列，bar-1464 型），逐 bar 对拍「证书增量 04/03/09」vs「全量 clear+extend / stable=0 / clear+全投影」，assert 逐字段等。**显式覆盖清单（逐 bar 断言 `cached_units == units`、`projected_units == project_to_units(upper_moves)`、证书路径输出与强制全量路径 bit-identical）**：
