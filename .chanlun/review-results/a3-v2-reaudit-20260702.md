## 逐条判定

### 1. §2.6 truncate 位置与边界（对应原裁决第4条 refuted）

**verdict: confirmed**

对照实际代码（非设计稿引用的行号，行号因无关 diff 略有漂移但结构一致）：
- `units.len() < min_parts` 早停在循环**顶部**（mod.rs:959，`level_idx` 尚未 push/触碰 lc）
  ⟹ `cache.levels.truncate(level_idx)` 插在 break 前，保留已处理的 `0..level_idx`，丢弃当前级
  及以上陈旧缓存——位置和边界正确。
- `units.is_empty()` 早停在循环**尾部**（mod.rs:1131，`level_idx` 已完整处理、已 `levels.push`、
  已投影）⟹ `cache.levels.truncate(level_idx + 1)` 插在 break 前，保留已处理的当前级，丢弃
  `level_idx+1` 及以上不可达缓存——位置和边界正确。

关键推演（本工位提出、codex 独立确认）：truncate 后该级下次恢复处理时触发
`cache.levels.len() <= level_idx` → `LevelCache::default()`，此时 `scanned=0`（cached_units 空）
⟹ `stable=dirty_from.min(0)=0` ⟹ `frontier_mutated` 恒假——**这不是原第4条意义上的"坍缩"**。
原坍缩问题是"陈旧 cache 仍被复用但比较区间为空"；truncate 后该级**没有**陈旧数据可复用，
`compose_level_resume(start_i=0, prefix_count=0)` 走真全量重扫语义，与级别首次出现完全同构，
是 harmless trivial-false，不存在静默复用陈旧值的风险。

### 2. §5 item3 always-run oracle 设计描述（对应原裁决第6条 refuted）

**verdict: confirmed，附实现期精修建议**

作为设计描述（非已写代码）已具体到可实现，逐 bar 对拍"证书增量路径" vs "强制全量路径"，断言
`cached_units == units`、`projected_units == project_to_units(upper_moves)`、输出 bit-identical，
覆盖第4条早停重入场景和第6条 pop-and-rescan 覆盖弱点。

**非阻塞精修建议**（落地测试代码时采纳）：
- 两处早停边界不同（`level_idx` vs `level_idx+1`），实现时须拆成两个独立 fixture，不能合并成一个
  "跳过后重入"泛化 case。
- 设计文本 "T==1"（重扫仅复现被 pop 窗口）表述有歧义，实现时用精确变量定义（如
  `tail_upper.len() == 1` 或"净新增窗口数为 0"），避免测试断言语义漂移。

### 3. 第2/第5条是否与第4条"同根因"（附录A表述精度）

**verdict: needs_work（措辞精修，非设计缺陷）**

codex 指出：不是"2/4/5/6 全量同根因"。第2条只有"早停恢复"子项与第4条同根因（主体由 §2.2
`prefix_count` 证书闭合，非 §2.6）；第5条只有"跳过级别缓存脱血缘"子项继承第4条（主体由 §2.5
`lc.projected_units.truncate(prefix_count)` 闭合，非 §2.6）。

**本工位核验**：设计稿 v2 附录A表格本身其实**已经**做了这个区分——"2 did_extend 替代完备性"行
明确写"连续处理级别的 did_extend 漏判已由 per-level prefix_count 消除（confirmed 子项，不变）；
早停恢复路径 refuted 子项 = 第4条同根因"；"5 project_to_units truncate 加固"行同样写"truncate
(prefix_count) 加固本身不引入回归（confirmed 子项，§2.5 不变）；继承的根因由 §2.6 同一 truncate
解除"。即设计稿正文已区分"主体由 §2.2/§2.5 闭合"与"早停子项由 §2.6 闭合"，codex 的 needs_work
更多是对复审 prompt 引言段"核心根因：级别早停...不清空缓存"这一概括性摘要的精度提醒，**不是对
v2 设计稿本身的否定**——设计稿正文未犯 codex 描述的过度概括错误，只是复审 prompt 的引言简化了。
