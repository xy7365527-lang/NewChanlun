## 3. 边界条件（结论翻转）

1. **跨标的（L3）**：暴露面 = 0 是 **BTC 单标的**结果（L2）。其他标的（CL/ES/金油等）若在
   LiveDetached 分布或 registry 作废时序上不同，`restore_break_registry_lost` 可能转正 ⟹ 结论翻转为
   路径1（实装严格修复）。本报告不声明 L3——**有效域 = BTC**（formalization-validity-domain 规则：
   定义域=全标的，有效域=BTC 单标的，不得膨胀）。
2. **数据窗口扩展**：BTC 若追加新历史使 registry 生命周期出现当前 4.6M bar 未覆盖的作废模式，须复测。
3. **彻底修复实装后**：若增量 extract_elements/confirmed prefix immutable 被实装，overlay 语义改变，
   本 L2 结果作废须重测（但届时 ceiling 本身消失）。
4. **探针被移除**：若 coverage.rs 探针（ancok_probe_*）被删，休眠缺口失去可观测性，697 须回退为
   不可验证 ceiling。探针为此常驻（ponytail 注释已锚定）。
