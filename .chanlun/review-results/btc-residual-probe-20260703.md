## 2. (a) 功效路径核算——BTC 主桶结构性欠功效

| 量 | 值 |

**外推需多少历史**：若聚集因子稳定，n_eff→272 需 n≈272·9.63≈2618，即多 ~1005 主桶买信号。当前 1613 信号来自 2.5yr OOS（2023-01~2025-06），密度 ~645/yr ⟹ 多 1005 需 **~1.56yr 更多 OOS 数据**。但 BTC 数据已到 2025-06（OOS 耗尽），无更多历史可用 ⟹ **「等数据」= 等未来实盘约 1.5yr**，现有历史下不可立即达成。

**★σ̂-归一化对单品种功效无效（关键洞察）**：CV=σ/|μ| 是**尺度不变量**——v2 的 σ̂-归一化对**单品种 BTC** CV 几乎无改变（raw-$ 10.36 → 归一化 10.025），因单品种内 σ̂ 是常数，同除不改 CV。故 BTC 主桶欠功效是**结构性**的，不能靠 σ̂-归一化收口（归一化只对跨品种降 CV 有效，v2 已证——但跨品种收口方向是 FALSIFIED）。降 BTC 单品种 CV 的剩余手段 = 收益率/夏普尺度（memory 命题②③，待验）或更长持有期聚合。

**功效判定**：BTC 主桶在现有历史 + raw-pnl 判据下**结构性半不可达**——需未来 ~1.5yr 数据，或换判据尺度（收益率化降 CV），二者皆非本轮可达。

## 4. 边界条件 / 不可判部分（缺什么）

- **决定性证毕缺 corr(Y_i, 持有窗净漂移) 直接检验**：本判用 5 窗符号跟随（n=5 功效弱）。决定性证毕 = 对 BTC 主桶每笔残差 Y_i 与其持有窗 BTC 净漂移（P_exit−P_entry 的 beta 分量）做相关检验，或 memory 方法1 的非分层 δ 置换 S=Σ|μ̂|（perm_p）。前者需新诊断跑批（未做，本轮 context 受限）。
- **perm_p=0.020 显著的再解释**：v2 的 stratified δ 置换 perm_p=0.020（层内含 time_block 分层）显著，看似支持真结构。但层内显著可能是 regime×δ 交互（memory：奇偶交替=level×σ_higher 交互项，winner's curse），非跨 regime 稳定 edge。time-block 符号跟随（§3）揭示桶均值正号由 win10/11 大正值驱动、win9 转负 ⟹ 非稳定 edge。stratified perm 与 time-block 符号检验的张力 = 分层吸收 vs 跨窗聚合两个视角，指向 regime 依赖。
- **翻转条件**：若 corr(Y_i, 持有窗漂移) 检验显示残差与 beta 无关（corr≈0）且 win9 负是独立噪声（非 regime 跟随）⟹ 几何真结构候选复活。当前证据（符号跟随 + 幅度跟随 + oddeven 先例 + v2 跨品种 Falsified）强烈不支持此翻转。

## 5. 结果包六要素

1. **结论**：BTC 主桶正号 = **beta 漂移伪结构否证倾向成立**（机制C 主导）——time-block 残差符号/幅度跟随 BTC regime（4 上涨窗正、唯一回调窗 win9 负、幅度随涨幅），非跨 regime 稳定几何真结构；附功效边界（BTC 主桶结构性欠功效，σ̂-归一化对单品种 CV 无效因尺度不变）。
2. **定义依据**：可交易 alpha μ(z)>0 须几何真结构非 beta 投影（663/665）；功效门 n_eff≥(1.645·CV)²（667）；B̂=ĝ·h 扩张窗线性漂移（l3_delta_r_alpha.rs）无法吸收窗内 regime 切换 ⟹ 残余 beta（oddeven #109 addendum）。
3. **边界条件**：corr(Y_i,持有窗漂移)≈0 且 win9 负为独立噪声 ⟹ 真结构候选复活（当前证据强烈不支持）；BTC 主桶功效收口需未来 ~1.5yr 数据或收益率尺度降 CV。
