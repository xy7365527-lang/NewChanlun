## ★ 最关键判决（喂给 prop4-bidir 实装侧）

> **二卖失败 → cover 平空 + 持多/做多 的精确触发判据（539 欠覆盖死扣的正确操作 = 吃跌穿仓真解）**：
>
> 设当前在某级别 k 持空（s_k=Short，骑下跌走势 d_k=Down，由前一个下跌趋势的一卖/二卖建立）。
> 二卖**失败**的**精确充要判据**（第20课中心定理二 + 第21课定律一 + maimai.md 2S）：
>
> **二卖位（= 一卖后次级别下跌结束后再次上涨段的结束点）之后，下一段次级别下跌走势的低点 `dd_new`
> 未创出前低（`dd_new >= 前低 DD_prev`），且与前中枢围成新中枢（`ZG_new > ZD_new` 成立、且
> 后中枢与前中枢满足「后GG >= 前DD」即波动区间重叠 → 高级别中枢/盘整，非下跌延续）。**
>
> 形式化（用引擎已有量 `divergence.rs` / `zhongshu.md` 符号）：
> - 令前下跌趋势末中枢 `B_prev=[ZD_prev, ZG_prev]`，其波动下界 `DD_prev`、上界 `GG_prev`。
> - 二卖后新形成的次级别下跌段低点 `g_new_low`。
> - **二卖失败 ⟺ `g_new_low >= DD_prev`**（未创前低，"再跌没跌下去"的精确阈值 = `DD_prev`）
>   **∧ 三段重叠成立 `max(d2,d3) < min(g2,g3)`（新中枢 `ZG_new>ZD_new` 诞生）**。
> - **操作 = `recover`（次级别空腿全平升回，平空）→ core 在 φ=0 缝 `flip`/`enter` 多**
>   （持多/做多）；若空头是 sink 出的次级别短差腿 ⟹ `recover(parent, sub)`；若是 core 整仓空
>   ⟹ φ=0 缝合法 `flip`（clear_all + enter Long）。**`cover=平空`= recover 或 flip 的 Long 侧。**
>
> **二卖成功 → 持空判据**：
> **二卖位之后下一段次级别下跌走势 `g_new_low < DD_prev`（创出前低，"跌下去了"）∧ 回抽未重回
> 前中枢区间 `[ZD_prev, ZG_prev]`（中枢终结定理：离开后回抽不回返）** ⟺ **后GG < 前DD（中心定理二
> 下跌延续）** ⟹ **下跌趋势延续 ⟹ 持空/加空（极性 Short 不变，no-op 或 同向 sink 子腿吃次级回调）**。
>
> **核心边界（539 死扣的精确根因）**：当前 `route_bsp`（rec_engine.rs:983）**只消费 `is_buy` 二元**，
> 无 `BSPKind` type2 + 中枢三态输入 ⟹ **二卖成功/失败两轨道坍缩进同一 `is_buy=false` 粗分支**：
> 子级走 `is_reduce=sink/drain`（持空被当"减仓信号"误处理），core 走 `dir!=cdir?` flip 门
> （无成败判据）⟹ **二卖失败该 cover（平空转多）时，引擎要么死扣 Short（落 `is_buy` 同分支不平），
> 要么误触发**。落盘路径见末。**有 1 处 `/escalate`（§五，"再跌没跌下去"阈值的逐 bar 时序边界）。**

## 一、轨道树：二买/二卖**成败分叉**完全枚举（编排者原话场景形式化）

编排者原话锚定（poltev 561 §9.1 二买卖成败轨道）：
- 「一笔下跌→二卖再跌没跌下去→形成中枢」= **二卖失败 → 中枢新生（盘整）/反转**。
- 「跌下去了」= **二卖成功 → 下跌趋势延续**。

成败分叉是**第20课中心定理二**（前后同级别两中枢关系）在二买卖位的实例化。每个成/败叉对应中心定理二的一个分支：

```
                          二卖（持空/吃跌侧，= 一卖后回升结束点）
                          ├── 二卖成功（向下离开中枢，下一段创前低 g_new_low < DD_prev，回抽不回返）
                          │      └─ 中心定理二：后GG < 前DD ⟹ 下跌及延续 ⟹ 持空/加空（Short 守恒）
                          └── 二卖失败（再跌没跌下去 g_new_low >= DD_prev，三段重叠成新中枢）
                                 ├─ 中心定理二：后ZG<前ZD 且 后GG>=前DD ⟹ 高级别中枢（扩张=盘整）
                                 └─ 或后DD>前GG ⟹ 反转上涨
                                 ⟹ 两子情形操作同：cover 平空（recover/flip Long）+ 持多/做多观望

                          二买（持多/吃涨侧，严格镜像）
                          ├── 二买成功（向上离开中枢，下一段创前高 g_new_high > GG_prev，回抽不回返）
                          │      └─ 中心定理二：后DD > 前GG ⟹ 上涨及延续 ⟹ 持多/加多（Long 守恒）
                          └── 二买失败（涨不上去 g_new_high <= GG_prev，三段重叠成新中枢/反转）
                                 ⟹ 减多/平多/观望（drain 减暴露 或 recover 平多腿；不强制翻空）
```

**成败判据的统一形式**（第20课中心定理二，逐字依据见 §二）：
- 设前中枢波动区间 `[DD_prev, GG_prev]`，二买卖位后新段极值 `x_new`，新中枢 `[ZD_new, ZG_new]`。
- **二卖成功** ⟺ 新段下跌**创前低** `x_new < DD_prev` ∧ 新中枢与前中枢**不重叠**（后GG<前DD）⟹ 趋势延续。
- **二卖失败** ⟺ 新段下跌**未创前低** `x_new >= DD_prev` ∧ 三段重叠**成新中枢**（后GG>=前DD，波动重叠）⟹ 盘整/扩张。
- 二买对称（`>`↔`<`，`DD`↔`GG`，low↔high，Short↔Long）。

## 三、539 欠覆盖死扣的代码现场逐字坐实（route_bsp:983-1043）

二卖失败轨道在当前引擎的死扣路径（逐字追踪 `rec_engine.rs:983` route_bsp）：

设当前持空（某级别空），二卖失败信号到达（语义上应 cover），但**信号层只传 `is_buy=false`**（二卖 = sell 点，丢失 type2 + 成败 + 中枢三态）：

1. **子级分支 `Some(p)`（987）**：`pdir` = 父方向。两种死扣：
   - 若父空（`pdir=Short`）：`is_reduce = is_buy = false` ⟹ 走 `else`（同父向 BSP）分支（1004-1014）：
     `j 持短差则 recover；否则 no-op`。**二卖失败若 j 未持反向短差 ⟹ `buy_noop`/no-op = 死扣不 cover。**
   - 若 j 自身是空腿（`direction==mob`）且收到 sell（`is_buy=false`，`is_reduce`随父向）：可能走 `sink`（999-1000）
     = **继续向次级别加空**（反向操作，加剧失血）。
2. **核心级分支 `None`（1017）**：`dir = if is_buy {Long} else {Short} = Short`（二卖=sell）。
   `highest_active=Some(cc)`，`cdir=Short`（当前持空）⟹ `dir==cdir` ⟹ 走同向分支（1026-1030）：
   `j>cc?ascend:no-op`。**`dir==cdir` ⟹ 不 flip ⟹ 死扣 Short**（该 cover 平空时，引擎判定"同向卖点"= no-op/ascend，**永不平空**）。

**根因（poltev 561 §9.4 坐实）**：`route_bsp` 的 `is_buy` 二元接口**无法表达"二卖失败=该 cover"**——
cover（平空转多）需要的输入是 **type2_sell + 成败标志（中枢新生）+ 该级别走势已终完美**，
但接口只有 `is_buy=false`，与"二卖成功=持空"**同值坍缩**。Ω 定义域 ⊊ 完全分类 ⟹ 二卖成/败落同一粗分支。

## 四、操作映射的引擎原语对照（cover 的精确实现）

| 语义操作 | 引擎原语 | rec_engine.rs 位置 | cover（平空）是哪一个 |
|---|---|---|---|
| 持空守恒 | `no-op`（同向 BSP 不 pyramid） | route_bsp 1011-1013 | —— |
| 加空（次级别回调吃反弹） | `sink(k, sub, flip(d_k))` | 860-905 | 否（这是开空，二卖**成功**侧的子腿） |
| **cover 平空（次级别短差腿）** | **`recover(parent, sub)`** | 907-950 | **✅ recover 的 Long 升回侧 = 平空** |
| **cover 平空（core 整仓空，有 type1_buy 转折）** | **`flip` = `clear_all` + `enter(Long)`** | 1034-1037 | **✅ flip 的 enter Long = 平空转多** |
| cover 平空（盘整新生无 type1，观望） | `recover` 平 + core 不 enter（flat 观望） | 907 + 跳过 enter | ✅ recover 平空后不重建 |
| 减多（二买失败弱镜像） | `drain(j)` 减暴露 1/3 | 952-980 | 否（减多非平空） |
| 升级归属 | `ascend(from,to)` | 820-838 | 否 |

**cover = 平空的两条合法路径**：①次级别短差空腿 → `recover`（整条平清升回父向，父若多则恢复多暴露）；
②core 整仓空 + 下跌走势终完美（某级别 type1_buy 在 φ=0 缝）→ `flip`（clear_all 清空头 + enter Long）。
两者都把 `s_k` 从 Short 改为 Long/flat，**满足 N9 协变（561）：极性翻转只在 φ=0 缝**（= 二卖失败 = 下跌
走势终完美 = 走势完成断面，561 §1.3 PC1 合法 τ@φ=0）。

## 五、/escalate：成败定义矛盾（"再跌没跌下去"阈值的逐 bar 时序边界）

> **no-workaround 触发**：二卖失败的"再跌没跌下去"阈值在**逐 bar 流式判定**下存在不可硬编码的定义矛盾。

**矛盾精确描述**：

- **静态定义（事后）**：二卖失败 ⟺ 二卖后下一段下跌完成时 `g_new_low >= DD_prev` ∧ 三段重叠成新中枢。
  **这要求"下一段下跌走势**已完成**"**——而走势完成由背驰/反向走势确认（divergence.rs `judge_divergence`
  需 c 段创新低 + 力度衰减 + 中枢锚定），**是回溯性确认**（561 §3.4 (b1)：NR-4 向心读过去，确认滞后 L0 不可约）。

- **流式矛盾**：在 cover 决策的当下 bar，"下一段下跌是否会创前低"**尚未确定**——价格可能先反弹（看似失败）
  再破前低（实为成功，二卖延续）。即：
  - 若**等待**下一段下跌走势完成才判成败 ⟹ cover 滞后，二卖失败若是反转，已错过反转起点（确认滞后税）。
  - 若**提前**在"未破前低"的当下 cover ⟹ 可能假信号（价格随后破前低，二卖实为成功，cover 后踏空主跌段）。

**两端定义冲突**：
- 接受 **A（事后严格成败）**：cover 永远滞后于反转起点 = 确认滞后税（561 (b1) L0 不可约），
  但**无假 cover**（二卖成功不会被误判为失败）。
- 接受 **B（当下提前判）**："未破前低"即 cover ⟹ 把**中枢延伸中的正常回升**误判为"二卖失败"，
  导致主跌段中途 cover 踏空 = 过覆盖（561 §9.4 过覆盖形式）。

**不可硬编码理由**："再跌没跌下去"的精确阈值 `DD_prev` 是**清晰的**（静态），但**"什么时候算'没跌下去'已成立"
的时序锚点不清晰**——这正是 539 死扣的潜在第二根源（不只是 route_bsp 二元坍缩，还有成败判定的**确认时刻**
未定义）。硬编码任一端（提前/滞后）都是 workaround，会把 561 (b1) 确认滞后矛盾掩盖。

**依据**：
- 第20课中心定理二给的是**两中枢关系**（事后，需两中枢都成形）——天然偏 A（事后）。
- 第21课「第三类卖点比第一二类要后知后觉」+ 第19课「背驰只可能出现一次」——确认是回溯的。
- 561 §3.4 codex 精化：(b1) 确认滞后 L0 不可约（NR-4），(b2) 净亏 L3 未决。

**`/escalate` 报告**：二卖成败的**判定时刻**（事后严格 vs 当下提前）是**选择类**（需价值判断：吃跌收益
vs 假 cover 踏空，是 regime 函数），**不是定理类可自决**。本工位枚举了成败轨道树 + 操作映射（确定），
但**成败的时序确认锚点**需编排者裁决（或交 prop4-bidir L3 判决场用 `is_seam_bar`/区间套链精度实测）。
这与 561 §2.3「N9 工程捕获能力依赖 is_seam_bar 精度（L2/L3）」同构——成败操作内容是 L1（确定），
成败**判定时刻**是 L2/L3（依赖精确走势完成识别）。

## 六、结果包六要素

### 1. 结论
枚举二买/二卖**成败分叉**完全轨道树（4 轨道：二卖成/二卖败/二买成/二买败）+ 每轨道确定操作映射
（§二 spec table）。**核心产出**：二卖失败 → **cover 平空（recover 或 flip Long）+ 持多/做多** 的精确
触发判据 = "再跌没跌下去" 的精确阈值 `g_new_low >= DD_prev` ∧ 三段重叠成新中枢（第20课中心定理二
扩张/反转分支）；二卖成功 → 持空判据 = `g_new_low < DD_prev` ∧ 回抽不回返（后GG<前DD 下跌延续）。
539 死扣 = route_bsp 二元 `is_buy` 接口使二卖成/败坍缩同分支 ⟹ 二卖失败该 cover 时死扣 Short
（no-op）或误 sink（继续加空）。**有 1 处 /escalate（§五：成败判定时刻 = 选择类）。**

### 2. 定义依据
- **第20课中心定理二（逐字，zhongshu.md:68/366）**：「后GG<前DD，等价于下跌及其延续」（二卖成功）；
  「后ZG<前ZD且后GG>=前DD……等价于形成高级别的走势中枢」（二卖失败=扩张）；「后DD>前GG等价于上涨
  及其延续」（二卖失败=反转）。
- **第21课（逐字，021-第21课.md:40/62/66）**：「一个上涨趋势确定后，不可能再有第一类与第二类买点，
  只可能有第三类买点」（成功侧延续只出 type3）；「市场必然产生赢利的买卖点，只有第一、二、三类」
  （完备性）；「市场中的任何向上与下跌，都必然从三类买卖点中的某一类开始以及结束」（升跌完备性）。
- **第17课（逐字，017-第17课.md:22/70）**：「任何级别的任何走势类型终要完成」（走势终完美，二卖失败
  = 前下跌走势终完美）；「任何的下跌转折都是由某级别的第一类买点构成」（转折定律 → cover 转多由
  type1_buy 触发）。
- **第19课（逐字，019-第19课.md:140/146）**：「一旦出现背驰性的上涨，就要出货」（力度=二卖成败信号，
  二卖失败的回升若背驰则反转概率高）；「背驰是两个同级别趋势之间对比产生的」。
- **maimai.md:74/76（第18课）**：「第二类卖点：某级别中，第一类卖点的次级别下跌结束后再次上涨的那个
  次级别走势的结束点」（二卖位定位）；定律一「二类买卖点都由次级别相应走势的第一类买点构成」。
- **divergence.rs**：`leg_extreme(Down)<prior_ext`（创新低=成功判据已有量）；`judge_consolidation_divergence`
  （盘整背驰=二卖失败后中枢新生的 type1 产出）；`trend_diverging_segment`（背驰段=cover 提前/滞后边界）。
- **输入特征满足定义**：route_bsp 收到 sell BSP 时，`is_buy=false` 不携带 type2/成败/中枢三态 ⟹ 满足
  「Ω 定义域 ⊊ 完全分类」的欠覆盖条件（561 §9.4）。

### 3. 边界条件（结论翻转条件）
- **若信号层把成败标志（中枢新生 vs 创前低）+ type2 注入 route_bsp**（接口从 `is_buy` 扩为
  `BspOrbit{kind, 中枢态, 成败}`）⟹ 二卖失败轨道获得显式 cover 映射 ⟹ 死扣消失（架构层，L0）。
- **若 "再跌没跌下去" 的判定时刻采用事后严格（A）**：cover 无假信号但滞后于反转起点（确认滞后税，
  561 (b1) L0 不可约）；**若采用当下提前（B）**：cover 及时但中枢延伸正常回升被误判 = 过覆盖踏空。
  此边界翻转 cover 的净收益符号（§五 /escalate）。
- **若 cover 后强牛继续上涨**（二卖失败=反转向上为真）⟹ cover 转多吃涨（编排者命题成立）；
  **若 cover 后中枢延伸最终向下破前低**（二卖实为成功，A 端误判）⟹ cover 踏空主跌段（B 端风险）。
  net 符号 = regime 函数（震荡可吃、强牛假 cover 少、强跌假 cover 多）= L3 未决。
- **若空头是 core 整仓空但无 type1_buy 转折确认（盘整未定向）**：cover 只能 recover 平空观望，
  不能 flip 做多（N9：φ=0 缝未到，强制翻多 = 561 τ@φ≠0 违反）⟹ cover 的"做多"分量退化为"平空观望"。

### 4. 下游推论
- 二卖失败 cover 映射成立 ⟹ route_bsp 必须从二元 `is_buy` 升级为消费 `BSPKind`+中枢三态+成败
  （= 任务 #29 完全分类覆盖实装的核心改动）。
- cover=平空 = `recover`/`flip` 的 Long 侧，满足 N9 协变（561）：二卖失败 = 下跌走势终完美 = φ=0 缝 =
  极性翻转合法点 ⟹ **本轨道是 561 N9（type1-flip 单轨道）的二卖侧实例**，二者一致（CC ⊇ N9）。
- 二卖**成功**轨道（持空 no-op）当前靠"同向卖点 no-op 巧合"幸存 ⟹ 显式映射后行为不变但**可观测**
  （make-decision-observable，137号）——成功轨道是死扣的"对照组"（同 is_buy=false 但应不同操作）。
- 与 orbit-center3 协作：中枢三态（延续/扩张/新生）本身由 center3 工位枚举；本工位只给"成败→操作"
  的 cover/hold 映射，引用"二卖失败→中枢新生"作输入（561 §9.5：CC 各轨道工位分工）。
- 喂给 prop4-bidir：二卖失败 cover 是"开放轴 C 严格逐级区间套"在二卖侧的具体操作（561 §9.6）——
  cover 的净收益（能否在强牛/反转跨标的真消除做空失血）= task #22/#29 L3 判决场。
