## ★ 主判决（中枢三态 = 走势分解定理的三轨道，每态一确定操作）

**中枢自身变化有且仅有三态**（第49课课间答疑 2007-01-05 16:52:13 缠师亲口："中枢延续与产生新中枢
以及产生更高级别的中枢这**三种情况**……有最严格的定义"；第20课正文区分 1/2/3 类），构成
**走势分解定理（第21课升跌完备性）在中枢轴上的完全三分类**：

| 态 | 缠论判据（中心定理一/二，DD/GG/ZD/ZG 不等式） | 确定操作（引擎原语）| 极性影响 |
|---|---|---|---|
| **延续（延伸）** | 中心定理一：∃Zn `[dn,gn]∩[ZD,ZG]≠∅`（区间不变，盘整内震荡）| **hold 核心 + sink/recover 次级别短差**（不动核心极性）| s_k 不变（无 φ=0 缝）|
| **新生（趋势延续）** | 中心定理二：后 DD>前 GG（上续）/后 GG<前 DD（下续）= 同向新中枢 | **ascend 核心仓骑乘升级**（同向，无新资金）| s_k 不变（同向延续）|
| **扩张（升级高级别）** | 中心定理二：后 ZG<前 ZD ∧ 后 GG≥前 DD（或镜像）= 高级别中枢 | **emergence_upgrade 升级归属到更高 ladder** | s_k 不变（核心级别上移）|

**关键分界（编排者 mandate 要求的"何时升级 vs 何时延续"精确判据）**：三态**互斥穷尽**（中心定理一
与二的不等式划分整个 (DD,GG,ZD,ZG) 空间），分界点是**两个连续同级别中枢的波动区间是否重叠**：

```
设前中枢 [ZD₁,ZG₁] 外缘 [DD₁,GG₁]，后中枢 [ZD₂,ZG₂] 外缘 [DD₂,GG₂]：

延续：还在同一个中枢内（只有一个中枢，后续 Zn 区间触及 [ZD₁,ZG₁]）
   ⟺ 中心定理一：∀Zn [dn,gn]∩[ZD₁,ZG₁]≠∅          → hold + 次级别短差

—— 一旦 ∃Zn dn>ZG₁ 或 gn<ZD₁（离开中枢，中心定理一终结）→ 形成第二个中枢，进入二分：

新生：后中枢与前中枢波动区间【无】重叠（同向，趋势延续）
   ⟺ 后 DD₂>前 GG₁（上涨）/ 后 GG₂<前 DD₁（下跌）       → ascend 同向升级

扩张：后中枢与前中枢波动区间【有】重叠（升级为更高级别中枢）
   ⟺ 后 ZG₂<前 ZD₁ ∧ 后 GG₂≥前 DD₁（或镜像）            → emergence_upgrade 升级归属
```

第20课原文逐字界定此分界（行 36/38）：
> "走势中枢的延伸与不断产生新的走势中枢并相应围绕波动**互不重叠**而形成趋势，在这两种情况下，
> **一定不可能**形成更大级别的走势中枢。而要形成一个更大级别的走势中枢，**必然要采取第三种的
> 方式**：就是围绕新的同级别走势中枢产生后的波动**与围绕前中枢的某个波动区间产生重叠**。"

**⟹ 新生 vs 扩张的唯一分界 = "围绕新中枢波动 ∩ 围绕前中枢波动 = ∅（新生/趋势）vs ≠∅（扩张/升级）"。**
波动区间 = 外缘 [DD,GG]（含全部瞬间波动，非核心 [ZD,ZG]）。这就是级别延续定理二（第20课行 44）：
"更大级别走势中枢产生，**当且仅当**围绕连续两个同级别走势中枢产生的波动区间产生重叠。"

### 1.1 三态与买卖点轨道的耦合（type3 后 → 新生或扩张，正交但耦合）

第21课行 32-34 逐字钉死三态与 type3 的耦合：
> "而中枢扩张或新生，在中枢之上都会存在买点，这类买点，就是第三类买点。……中枢扩张导致一个
> 更大级别的中枢，而中枢新生，就形成一个上涨的趋势，这就是**第三类买点后必然出现的两种情况**。"

**⟹ type3 买点 fire 后，中枢态分叉为新生 OR 扩张**（边界工位约定：type3 本身归 type3 工位；本工位
管 type3 之后中枢**自身**走向新生还是扩张的操作分界）：

```
type3 买点 fire（次级别离开中枢 + 回抽不破 ZG，第20课行 60）
   │
   ├─ 后续走出同向新中枢且波动无重叠（后DD>前GG）→ 【新生】→ ascend 骑趋势腿
   │
   └─ 后续走出同向新中枢但波动有重叠（后ZG<前ZD∧后GG≥前DD）→ 【扩张】→ emergence_upgrade 升级
```

第21课行 30 补充延续态下**无买点只有卖点**（对买方向）：
> "如果是中枢延续，那么在中枢上是不可能有买点的，因为中枢延续必然要求所有中枢上的走势都必然
> 转折向下，在这时候，只可能有卖点。"

⟹ **延续态**：核心持多时，中枢上只出卖点（次级别回落 type1_sell）→ 走 route_bsp 子级 sink 开次级别
空腿（吃盘整内回落），不翻核心。这正是 hold + 次级别短差 的原文依据。

## 二、三态各自确定操作的完整论证（引擎原语逐一对应）

### 2.1 延续 → hold 核心 + 次级别 sink/recover（盘整内操作）

**缠论依据**：中心定理一——延续 = 区间 [ZD,ZG] 不变、震荡在中枢内。第49课三态"当下在该中枢之中"。
盘整内的涨跌是**次级别走势**（次级别的 type1/2/3 买卖点驱动），不是本级别走势完成。

**引擎映射**：
- 核心仓（本级别）：**no-op / hold**——本级别走势未完成（无 φ=0 缝），无 type1，s_core 协变守恒（N9）。
- 次级别短差：本级别中枢内的次级别回落（type1_sell@次级别）→ `route_bsp` 子级分支（`Some(p)`）
  `is_reduce`（父多+卖点）→ `sink(p, sub)` 开次级别空腿吃回落；次级别反弹完成（type1_buy@次级别）→
  `recover(sub→p)` 平空升回。**这是"盘整内震荡短差"的精确引擎形式**（rec_engine.rs:987-1014）。

**为何不是"核心持仓不变什么都不做"**：编排者 mandate 问号"持仓不变?震荡短差?"——答案是**两者都对，
但分层**：核心（本级别）持仓不变（hold），次级别（sub）做震荡短差（sink/recover）。这正是
"多空双开多重赋格"的目的（吃每级别涨跌幅绝对值，见 547/death-deadlock memory）。

### 2.2 新生 → ascend（持趋势腿，同向升级）

**缠论依据**：中心定理二——后 DD>前 GG（上续）= 同向新中枢、波动无重叠 = **趋势延续**。第20课注"二之1
类：中枢新生"。走势分解定理一：趋势 = ≥2 个同向中枢（types.rs:162 `UpTrend`）。新生第二个同向中枢
⟹ 单中枢盘整**升级为趋势**，走势级别本身在长大。

**引擎映射**：`ascend(from, to, node)`（rec_engine.rs:822）——核心仓 relabel 上移，无新资金，NAV 中性
（`prove_relabel_invariant` 守敞口不变）。同向延续故 s_core 不变（无翻转，无 clear_all）。

**为何不是"加多"**：编排者 mandate 问号"持趋势腿/加多/ascend?"——答案是 **ascend 不是加多**。新生
是同一笔核心资金骑到更高级别趋势腿（级别升一格），不增加敞口（区别于 pyramid 加仓）。原文第21课
行 40："一个上涨趋势确定后，不可能再有第一类与第二类买点，只可能有第三类买点"——趋势确定后不在
中枢下加多（无 type1/2 买点），只在 type3 续骑。故新生的引擎语义 = **ascend 骑乘，非 enter 加仓**。

### 2.3 扩张 → emergence_upgrade（升级归属到更高 ladder）

**缠论依据**：中心定理二——后 ZG<前 ZD ∧ 后 GG≥前 DD = 高级别中枢。级别延续定理二："当且仅当……
波动区间产生重叠"。第20课注"中枢扩张"。两个本级别中枢**波动重叠** ⟹ 在本级别将两中枢视为一个
（zhongshu.md:189"本级别中将两个中枢视为一个合并"），**分析上移到更高级别**。

**引擎映射**：`emergence_upgrade(target_level, target_dir, node)`（rec_engine.rs:842）——`target_level` =
扩张形成的高级别中枢级别；核心同向 → 内部调 `ascend(cc, target_level)` 升级归属。这是"核心仓升级到
更高 ladder"的精确引擎形式。

**扩张 vs 新生的引擎分界**：两者**都用 ascend 升级核心仓**，但 **target_level 不同**：
- 新生：升一格（次个同向中枢 = 本级别趋势成立 = 封装为 level+1 笔，types.rs:84 递归恒等式）→ ascend 到 level+1。
- 扩张：可能升**多格**（两中枢波动重叠合并 = 直接形成更高级别中枢）→ emergence_upgrade 到该高级别。

这与 zhongshu.md:185-191 一致："扩展……理论可无限向上扩展"——扩张的级别跃迁幅度由波动重叠的级别决定。

  方向代理，不读中心定理二不等式）；延续态无独立轨道，落子级默认。

## 四、与 N9 / type 工位 / orbit-levelT 的关系（边界）

- **N9（561 §1-§八）= 本三态覆盖的一个推论**：N9 管 type1 走势完成单轨道的极性翻转（φ=0 缝）。
  本工位的三态覆盖管**中枢自身变化**（延续/新生/扩张），三态全部 s_core **不翻转**（无 φ=0 缝——
  中枢态变化不是走势完成，是走势**延续/升级**），故三态正交于 N9 的翻转轴。N9 ⊊ CC，三态 ⊊ CC，
  二者是 CC 完全分类的不同子集。
- **type1/2/3 买卖点本身归各 type 工位**：本工位不裁决买卖点 fire 条件，只裁决买卖点 fire **之后**
  中枢自身走向延续/新生/扩张的操作分界（type3 后 → 新生 or 扩张，§1.1）。
- **跨级别归 orbit-levelT**：扩张态的"升级到哪个更高 ladder"（级别跃迁幅度）的精确级别计算归
  orbit-levelT；本工位只给"扩张 ⟹ emergence_upgrade 升级"的态→原语映射，不算具体 target_level 级数。

## 七、矛盾检查（no-workaround：三态定义边界）

按 mandate 要求检查三态定义的两处潜在矛盾边界：

### 7.1 扩张与新生的边界（波动重叠 vs 无重叠）—— 无矛盾
中心定理二用**外缘波动区间 [DD,GG]**（含全部瞬间波动）判重叠，不是核心 [ZD,ZG]。第20课行 22 明确：
"同级别的前后走势中枢是不能有**任何重叠**的，这包括**任何围绕走势中枢产生的任何瞬间波动之间的重叠**"
（新生）vs 行 24"围绕该中枢产生的波动**触及**前面走势中枢延续时的某个瞬间波动区间"（扩张）。
分界清晰：**外缘波动 ∩ = 扩张，外缘波动 ∩ = ∅ = 新生**。引擎 `Zhongshu.gg/dd` 已实装外缘 → 可判。**无矛盾。**

### 7.2 中心定理一（延续）与中心定理二（新生/扩张）的重叠态 —— 无矛盾
中心定理一管**单中枢内**（延续，区间不变）；中心定理二管**两中枢间关系**（新生/扩张）。两者作用于
不同对象（一个中枢 vs 两个中枢），**不在同一状态空间竞争**。延续 = 还没形成第二个中枢（中心定理一
未终结）；一旦第二个中枢形成（中心定理一终结：∃Zn dn>ZG），才进入中心定理二的二分。**时序互斥，无
重叠态。** zhongshu.md:328 已结算："延伸 ∪ 新生 ∪ 扩展 = 全集"。**无矛盾。**

**结论：三态定义无 no-workaround 触发的矛盾，不需 /escalate。** 三态覆盖图纸严格自洽。
