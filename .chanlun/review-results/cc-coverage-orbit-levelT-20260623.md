## ★★ 一句话判决

**操作映射 Ω 的级别协变 = T自相似：同一 orbit（如 type1 完成→flip）在级别 k 的操作 = 级别 k−1 的同构操作（T 骑该级别走势节点，命题4/558），但作用域随级别角色变化——最高活跃级别=整仓极性翻转（N9 唯一合法点）、次级别=短差腿 sink/recover（吃回调）、次次级别=更细短差递归到 a0=笔级别（560 读法乙）。区间套重合点（第27课）= 多级别背驰段嵌套收缩到同一笔时多级别走势同时完成共点——重合点操作由最高级别角色主导（整仓翻转），次级别同步作为 sink/recover 的退出，不独立翻转。** 这是 561-CC 在「级别递归轴」上的展开：Ω 必须对**每级别×每轨道**都全函数覆盖，且各级别的操作是同一算子 T 的自相似实例。

## 一、原文逐字依据：T自相似 + 区间套是级别协变的根据

### 1.1 第37课答疑（核心）：所有买卖点归根结底是 type1，级别投影 = T自相似根据

> 「**所有买卖点，归根结底都是第一类买卖点，只是级别不同而已。**」（37课答疑，缠文观止问）

这是级别协变的**根据定理**：操作类型在级别上投影——同一 type1（走势完成→转折）在不同级别复制为 type1/type2/type3。type2 = 次级别的 type1（买卖点定律一，第17课）；type3 = 中枢上的延续。**操作算子 T 在级别 k 的形式 = 级别 k−1 的同构形式**，差别只是级别（作用域）。

> 「**任何级别的操作模式是一样的，你明白了日线的，自然就可以去操作1分钟、5分钟的。**」（37课答疑，朗月无花问）

→ T自相似的操作侧逐字声明：操作模式跨级别同构（命题4/558 推论1 构成关系 L0 的操作侧表达）。

### 1.2 第27课（区间套定理）：自顶向下逐级背驰段嵌套收缩 = 重合点定位

> 「以万科为例子，季度图上的第三段，在月线上，可以找到针对月线最后中枢的背驰段，**而这背驰段，一定在季度线的背驰段里，而且区间比之小**，把这个过程从月线延伸到周线、日线、30分钟、5分钟、1分钟，甚至是每笔成交，这区间不断缩小……就这一笔是万科历史底部的最后一笔成交。」（27课正文）

**缠中说禅精确大转折点寻找程序定理**（27课正文逐字）：

> 「某大级别的转折点，先找到其背驰段，然后在次级别图里，找出**相应背驰段在次级别里的背驰段**，将该过程反复进行下去，直到最低级别，相应的转折点就在该级别背驰段确定的范围内。」

→ **区间套 = 级别协变的几何形式**：高级别背驰段 ⊇ 次级别背驰段 ⊇ … ⊇ a0 背驰段（笔），逐级嵌套（套娃），范围单调收缩。重合点 = 各级别背驰段嵌套到同一笔的共点。

> 「今早第二波的下跌，通过 **5分钟背弛段的1分钟背弛段的次级别的背弛这样的三重背弛**的类似数学分析中的区间套定理的精确定位，所以就很容易把握到了。」（27课作业答案）

→ 三重背驰嵌套 = T自相似递归三层（5分→1分→1分次级别），每层 T(k)=T(k−1) 同构，**重合点 = 三层背驰段同时收敛**。

### 1.3 第27课（操作级别协变）：买卖点级别错配 + 次级别短差

> 「**下跌趋势中的买点要比卖点级别高一些才有效，上升趋势中的卖点要比买点级别高。**」（27课答疑，惑问，缠师未否定此理解方向）

→ 操作级别协变：在下跌趋势中（最高级别走势=Down），买点（反向操作）须用更高级别；卖点（顺势）可用低级别。这是 N9 协变（s_k=dir_to_polarity(d_k)）的操作级别表达——**反主级别向的操作（吃回调）要在较高级别，顺主级别向的操作（短差）在低级别**。

> 「日线是相对的大趋势，以日线买点进，**看30分钟买卖点做短差降成本**。30分钟卖点后当然有买点。」（27课答疑，空读问）

→ **次级别短差 = sink/recover 的原文依据**：主级别（日线）持仓不动（核心仓），次级别（30分钟）做短差降成本。这正是「次级别走势完成→consume平空+做多」的轨道——次级别卖点 sink（开反向短差），次级别买点 recover（平短差升回主向）。

> 「除了用部分筹码打短差，就要持得住。」（37课答疑）+「中线持股……按照低级别图弄点短差。」（21课答疑）

→ 核心仓持住（最高级别），机动仓打短差（次级别）= 多重赋格的级别分工。

### 1.4 第17课（递归基底 a0）+ 第37课（aN+1=f(aN)）

> 「明白数学中递归定义的实质，就知道对 **a0 是如何定义，并不影响 aN+1=f(an) 的函数定义**。」（37课答疑，一头雾水问）

→ T = aN+1=f(aN) 的形式化（命题4/558 + project_unified_recursive_operator_T）。级别协变 = f 在每级别同构应用，a0=笔级别（最低不可分解级别，17课「定义为至少三个该级别单位K线重叠部分」）是递归基底。

### 1.5 第21课（升跌完备性 + 强牛只出 type3）：协变的完备性根据

> 「**一个上涨趋势确定后，不可能再有第一类与第二类买点，只可能有第三类买点。**」（21课正文）

→ **CC 协变的级别×regime 完备性**：最高级别走势=Up（强牛）⟹ 最高级别只出 type3 买（延续），不出 type1/2 卖 ⟹ s_top 协变保持 Long（N9）⟹ 不在最高级别做空。做空只发生在**次级别回调走势 d_sub=Down** 的级别（次级别 type1 卖 = sink）。这是 561-CC 编排者论证「强牛架构层不做空」的级别协变形式。

## 四、区间套重合点：操作归属裁决（no-workaround 检查点）

### 4.1 重合点的定义（27课+21课逐字）

**区间套重合点 = 多级别背驰段嵌套收缩到同一笔时，多级别走势同时完成的共点。** 两个原文来源：

1. **区间套侧（27课）**：高级别背驰段 ⊇ 次级别背驰段 ⊇ … ⊇ a0 笔背驰，逐级嵌套。当各级别背驰段同时收敛到同一笔（理论极限），该笔 = 多级别走势同时完成的重合点。
2. **二三类重合侧（21课）**：「第二买点与第三买点重合的情况」——次级别 type1（=本级别 type2，定律一）与本级别 type3 在同一点重合。这是**跨级别买卖点重合**的特例（次级别 type1 ∧ 本级别 type3 同点）。

### 4.2 矛盾候选检查：重合点是「多级别同时翻转」还是「单级别主导」？

任务明确要求检查此矛盾（no-workaround）。逐字核验：

**候选A：多级别同时翻转**（各级别 T 实例独立同时翻转整仓）
- 反驳：违反 N9（561）+ 558 fold⊥unfold。若各级别独立翻转整仓，则 N 个独立腿 = 读法B（556 已 L3 否证，顶层冻结 P1 1/8）。重合点的「多级别完成」**不等于**「多级别各有独立仓位各自翻转」——单一资本池（项目裁决，free 单根账本）下不存在 N 个独立整仓。

**候选B：最高级别角色主导整仓翻转 + 次级别同步退出**（本工位裁决）
- 依据：27课「**从大级别往下精确找大级别买点**」——区间套定位的目标是**大级别买卖点**（最高级别），a0/次级别只是**精确定位器**（找到大级别转折点的精确位置），不是独立操作主体。原文逐字：「这种从大级别往下精确找大级别买点的方法，和区间套是一个道理。」
- 操作形式：重合点 = 最高级别 type1 完成（整仓翻转 N9）∧ 各次级别短差腿同步 recover 退出（次级别走势也完成⟹短差闭合归还）。**一个整仓翻转（最高级别）+ N 个短差退出（次级别），不是 N+1 个独立翻转。**
- 引擎现场：`nest_try_flip` 已是此形式（a0 定位 `loc` 但翻转作用于 `highest_active` 整仓，:1240-1265）；`enable_nest_strict` 的 loc..=top 逐级校验（:1228-1238）= 确认是真重合点（各级别背驰段一致）而非单级别误触发。

**裁决：候选B（最高级别主导）。无 /escalate**——27课逐字（「往下精确找大级别买点」）明确定位重合点操作主体=大级别，次级别是定位器+短差退出。候选A（多级别同时独立翻转）= 读法B 范式（556 已否证）+ 违反单一资本池裁决，非真矛盾。

### 4.3 次级别 consume 与最高级别 flip 的时序（第二个矛盾候选检查）

任务要求检查「次级别consume与最高级别flip时序冲突」。逐字核验：

- **consume平空**（task22, nest_consume_step :1278）：次级别反核心向背驰段 ⇒ 平核心 1/3（缩短长持，不开反向腿）。
- **最高级别flip**（nest_try_flip :1240）：top 背驰段武装 + a0 定位 ⇒ 整仓翻转。
- **时序关系**：引擎现场 nest_step（:1182-1208）先尝试 flip（:1203），`if !flipped` 才走 consume（:1205）。即 **flip 优先于 consume**——若最高级别走势完成（重合点）则整仓翻转，否则（仅次级别完成、最高级别未完成）才 consume 平核心 1/3。
- **无冲突**：二者互斥触发（flipped 与否），且语义分层——flip=最高级别走势完成（重合点，整仓），consume=仅次级别完成（最高级别走势未完成，部分平仓吃回调）。这正是级别协变：最高级别事件→整仓操作，次级别事件→分数仓操作。**时序由级别角色决定（最高级别完成优先），非冲突。**

**裁决：无时序冲突，无 /escalate。** flip（最高级别完成）优先于 consume（次级别完成）= 级别协变的时序表达（高级别事件支配低级别事件，27课「低级别走势的意义，是在高级别意义的彰显后才能彰显」，17课答疑 x股者）。

## 六、结果包六要素

### 1. 结论
操作映射 Ω 的级别协变 = T自相似：同一 orbit 在级别 k 的操作同构于级别 k−1（T 骑该级别 TrendNode），但作用域随级别角色变化——最高活跃级别=整仓极性翻转（N9 唯一合法点）、次级别=短差腿 sink/recover（吃回调闭合=平空+做多）、递归到 a0=笔级别（区间套定位）。区间套重合点（多级别背驰段嵌套共点）操作由**最高级别角色主导整仓翻转 + 次级别同步退出**（27课「往下精确找大级别买点」），非多级别同时独立翻转。flip（最高级别完成）时序优先于 consume（次级别完成）。

### 2. 定义依据
- **T自相似根据**：37课「所有买卖点归根结底都是第一类买卖点，只是级别不同」+「任何级别的操作模式是一样的」（操作跨级别同构）；37课「a0 如何定义不影响 aN+1=f(an)」（T=f 递归）。
- **区间套（级别协变几何形式）**：27课精确大转折点寻找程序定理「先找背驰段，然后在次级别图里找相应背驰段在次级别里的背驰段，反复进行……直到最低级别」（逐级嵌套收缩）+「往下精确找大级别买点」（重合点主体=大级别）。
- **操作级别分工**：27课「以日线买点进，看30分钟买卖点做短差降成本」（核心仓持住+次级别短差=sink/recover）；27课「下跌趋势中买点要比卖点级别高」（反主向操作用高级别）。
- **强牛协变完备性**：21课「上涨趋势确定后只可能有第三类买点」（最高级别 d_top=Up⇒只出type3⇒s_top锁多，不在最高级别做空）。
- **输入数据满足的条件**：引擎 highest_active/nearest_active_parent 二分（最高级别 None / 次级别 Some(p)）= 级别角色分层的代码实现；sink/recover/ascend 已是协变 by construction（子级永不独立翻转）；route_bsp 核心级门控仅 `dir!=cdir` 无 d_top 检查 = 满足「过覆盖」（N9 违反）的代码现场。

### 3. 边界条件（结论翻转条件）
- 若重合点经 L3 验证应是「多级别各有独立仓位同时翻转」（读法B 范式复活且收益正），则候选B（最高级别主导）翻转。**当前 556 读法B L3 否证（P1 1/8）+ 单一资本池裁决指向候选B**，但 task22 严格逐级区间套 L3 未跑，未最终定。
- 若 consume平空（次级别完成→平核心）经 L3 在强牛跨标的转正（缩短长持减穿仓 + 保 556 解冻），则「次级别事件→分数仓操作」级别协变形式被收益侧确证；当前 L3 未决（task22 判决场）。
- 若 sink 次级别腿的 node.direction 未对齐次级别**实测**走势（flip_pol 代理失配），则次级别协变 s_sub=dir_to_polarity(d_sub) 不成立，N9 在子级捕获违反（与 561-N9 §3.3 同标注）。

### 4. 下游推论
- **喂给 prop4-bidir「最高级别走势完成→整仓极性」轨道**：最高级别 type1 完成（重合点）⇒ 整仓 flip（clear_all+enter），是唯一合法整仓翻转点（N9）。task22 应在 route_bsp 核心级分支加 d_top 真翻转检查（非仅 `dir!=cdir`），消除过覆盖。
