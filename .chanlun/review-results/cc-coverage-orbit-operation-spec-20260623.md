## 三、结果包六要素

1. **结论**：枚举了买卖点完全分类的全部 orbit-class（type1/2/3 × 买卖 + 中枢三态 + 二买卖成败 + 级别协变），
   为每轨道导出确定操作（映射引擎原语），形成完全分类操作 spec table（§一）。**填充了 poltev 561 §9.3 显式延期的
   `canonical_operation(orbit)` 内容**。核心：五类操作（flip/add/ascend/emergence_upgrade/recover）互不可坍缩，
   当前 route_bsp 二元 `is_buy` 是 539 过/欠覆盖同一根源。**两失败模式分离**：穿仓（type1 过覆盖：背驰段误 flip →
   补 confirmed 门）⊥ 踏空（type2/3 欠覆盖：缺 add 原语 → 强牛只 type3 买永不翻空 + 加多吃涨）。

2. **定义依据**：
   - 第17课定律一/趋势转折定律（type1/type2）、第19课力度（背驰强度）、第20课 type3 定理+中心定理一/二+级别延续定理
     （type3/中枢三态/成败）、第21课买卖点完备性+升跌完备性+「上涨趋势确定后只 type3 买」+二三类重合、
     第27课区间套（级别协变重合点）、第37课级别投影（T 自相似）。
   - 信号层代码坐实：`BSPKind` 6 类（types.rs:171）+ 中枢三态（TrendKind + Zhongshu ZD/ZG/DD/GG）已产出完全分类；
     `route_bsp(j, is_buy)`（rec_engine.rs:983）坍缩为二元 = Ω 坍缩现场。
   - 群论侧（561/orbit doc）：Burnside 506→46→2→1 穷尽 = 状态空间完全划分；N9-PC1 协变 = type1-flip 单轨道规则（CC 推论）。

3. **边界条件**（结论翻转条件）：
   - 若引擎已有原语能表达"极性不变加仓"（add 非缺），则 type2/type3 覆盖无需新原语，§二坍缩论部分翻转。
     **反例**：逐一核验 enter/flip/sink/recover/drain/ascend/no-op 无一是加仓 ⟹ add 确缺，结论成立。
   - 若强牛中走势会产真 type1/type2 卖（而非只 type3 买），则「强牛永不翻空」翻转。**反例**：第21课:40 逐字
     「上涨趋势确定后不可能再有一二类买卖点」⟹ 成立。

## 五、开放轴（选择类，已 /escalate 报 Lead）—— 来自 orbit-2bs

**二卖成败的判定时刻是选择类，不可硬编码**（orbit-2bs 子工位 /escalate）：

- 静态成败判据（`DD_prev` 阈值、创新低与否、三段重叠）**清晰**（L0 原文）；操作内容（recover/flip/持空）**确定**。
- 但"**什么时候算'没跌下去'已成立**"的**时序锚点**不清：
  - **候选 A（事后严格）**：等中枢三段完整确认后才判失败 → 无假 cover，但反转起点滞后（= 561 (b1) 确认滞后税，L0 不可约）。
  - **候选 B（当下提前）**：回抽未破前低即判失败提前 cover → 及时，但中枢延伸的正常回升被误判 = 过覆盖踏空。
- **硬编码任一端 = workaround 掩盖 561 (b1) 矛盾**。这是 539 死扣的潜在第二根源（不只 route_bsp 二元坍缩，还有成败
  **确认时刻**未定义）。
- **定位（no-unnecessary-escalation 四分法）**：这是**选择类**——A/B 是确认滞后税 vs 过覆盖踏空的真实价值权衡，
  且**映射到 561 §2.3 / 539 A′ 已识别的同一开放轴**（is_seam_bar 精度 = 555/553 精确走势完成识别）。本 spec 把操作内容
  **参数化**（操作 = f(成败信号)，成败信号 = is_seam_bar 的子情形），**判定时刻精度委托给该既有开放轴**，不在 spec 层硬编码。
- **诚实分层**：操作内容 = L1（确定）；判定时刻 = L2/L3（依赖 is_seam_bar）；净收益 = L3 未决（regime 函数，prop4-bidir 判决场）。
