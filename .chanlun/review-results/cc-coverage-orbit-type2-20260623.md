## 一、type2 完全轨道枚举：缠论事实（第17/19/21课逐字）

### 1.1 type2 的本质（定律一，第17课 L66 逐字）

> 「缠中说禅买卖点定律一：任何级别的第二类买卖点都由次级别相应走势的第一类买点构成。」

**精确读法（极性导出的关键，561 §9.1 须校正之处）**：
- **type2 买点@级别 k = 次级别（k-1）第一类买点的投影**（mod.rs `project_type2`：`type2_k = type1_{k-1}` 同极性，bar>type1_k）。
- 第17课 L60 逐字定义 type2 买点：「在第一类买点出现后**第一次次级别回调制造的低点**……后面必须还至少有一个向上的次级别运动，这样的买点是绝对安全的」。
- 即：type2 买 = 级别 k 已出 type1 买（下跌走势完成、已转多）→ 第一次**次级别回调**（k-1 级别的一段下跌走势）的**低点**（= k-1 级别的 type1 买点）。

**关键区分（type2 ≠ type1）**：
| 维度 | type1 买 | type2 买 |
|---|---|---|
| 触发结构 | 级别 k 下跌趋势**完成**（≥2 中枢 + 末段背驰，φ=0 走势完成奇点）| 级别 k **已转多后**第一次次级别回调低点（次级别 type1 买，非本级别走势完成）|
| 极性变化 | **翻转**（Short→Long 或空仓→Long，τ@φ=0 手性缝）| **极性不变**（已是 Long，回调低点继续多）|
| 操作语义 | 转折建仓 / 整仓翻转（flip = clear_all + enter 反向）| **加仓/补仓**（极性不变，仓位增加）|
| 安全性来源 | 走势终完美：下跌完成只能转上涨/盘整（第17课原理一）| 走势必完美：第一类买点后必有第三段向上次级别（第21课 L42-44）|
| 协变身份（561 N9）| s_k 在 φ=0 缝翻转（合法 τ）| s_k 不变（无 τ）；次级别回调 = k-1 级别 d 局部反向，s_{k-1} 协变于 d_{k-1}=Down |

### 1.2 type2 的力度判据（第19/21课）

第21课 L44 逐字（type2 的中枢位置 → 后续力度，已结算 maimai.md）：
> 「第二类买点，不必然出现在中枢的上或下，可以在任何位置出现，**中枢下出现的，其后的力度就值得怀疑了，出现扩张性中枢的可能性极大，在中枢中出现的，出现中枢扩张与新生的机会对半，在中枢上出现，中枢新生的机会就很大了。但无论哪种情况，赢利是必然的。**」

第18行（页眉逐字补充）：「第二类买点，不必然出现在中枢的上或下，可以在任何位置出现，中枢下出现的，其后的力度就值得怀疑了」。

**轨道细分（type2 × 中枢位置 = 力度子轨道）**：
- type2买@中枢上 → 中枢新生概率大（强势，加仓力度可大）；
- type2买@中枢中 → 扩张/新生对半（中性加仓）；
- type2买@中枢下 → 扩张性中枢概率大（弱势，但仍赢利——加仓但谨慎）。

**力度（第19课 L150 逐字）**：「背驰是两个同级别趋势之间对比产生的」——type2 自身不是背驰点（type2 是次级别 type1，次级别底背驰已含在投影里），本级别力度判据用于**加仓量**调节，非操作方向（方向已由极性不变锁定）。

### 1.3 type2 的退出/成败轨道（边界，归 orbit-2bs，引用不重复）

第20课 L62 逐字操作策略：「**二买后破一买低点退出**」。
- **二买成功**（不破一买低点，后续创新高续涨）vs **二买失败**（破一买低点 / 跌下去形成中枢）= 专门成败轨道，**归 orbit-2bs 工位**。
- 本工位（type2 一般轨道）只管：type2 点**触发时**的确定操作（加仓）；触发后的成败退出由 orbit-2bs 枚举。

### 1.4 type2 的递归身份（升跌完备性，第21课 + 561 §9.1）

第21课 L40 逐字：「**一个上涨趋势确定后，不可能再有第一类与第二类买点，只可能有第三类买点。**」
- type2 只存在于：级别 k 刚出 type1 后、上涨趋势**尚未确定**的窗口（type1→type2→type3 序列的中间态）。
- 一旦上涨趋势确定（≥2 同向中枢），type2 轨道**关闭**，后续只有 type3（延续加仓）。
- 这是 type2 轨道在递归塔的**时间局部性**：每个级别每段上涨的"建仓-补仓-延续"序列里 type2 恰出现一次（type1 后首回调）。

### 2.3 route_bsp 收到 type2 后的实际行为（坍缩后果）

`route_bsp(j, is_buy=true, …)`（rec_engine.rs:983-1043）对一个 type2 买点（极性应不变 = 加仓）的实际路由：
- **若 j 有活跃祖先 P（子级分支）**：按父方向判 is_reduce。父多 + 买点 → **非 reduce 分支** → 若 j 持反父向短差则 recover（升回），否则 **`buy_noop`**（rec_engine.rs:1011-1013 逐字「父多+买点+j 无短差 → no-op（**浪费的买点**）」）。
  ⟹ **type2 买的加仓语义丢失**：本应加仓，实际 no-op（欠覆盖死扣）或误当 recover。
- **若 j 是核心级（无活跃祖先）**：`highest_active()` 同向 → 仅 ascend 或 no-op（j>cc 才 ascend，否则 no-op）。
  ⟹ **type2 买在核心级同向时也是 no-op**（不加仓，浪费买点）。

**坐实**：现架构对 type2 买点的实际操作 ∈ {recover, no-op, ascend}——**没有一个是"极性不变加仓"**。
type2 的确定操作（加仓）落入默认/粗分支 = 561 §9.4 **欠覆盖**（真买卖点轨道无确定操作 → 死扣/浪费）。

## 四、关键缺口：引擎缺 `add`（极性不变加仓）原语（no-workaround 停下点）

### 4.1 缺口精确描述（非矛盾，是缺失，可自决报告）

type2 的确定操作 = **极性不变加仓**。检查现有 7 原语，**无一实现此语义**：
| 原语 | 语义 | 为何不是 type2 操作 |
|---|---|---|
| enter | 首次/反向建仓 | type2 时已持仓（type1 后），非首次；极性不变非反向 |
| flip | clear_all+enter 整仓翻转 | type2 极性**不**翻转——用 flip 会错误翻空（539 过覆盖） |
| sink | 父减1/3 + 子级开**反向**短差 | type2 加仓是**同向**增仓，非反向短差 |
| recover | 子短差腿**全平**升回 | type2 是增仓非平仓；仅当 k 恰持反向短差时 recover 是前置步，非 type2 本体 |
| drain | 减仓 | 方向相反（type2 是增不是减）|
| ascend | 核心仓升级**更高 ladder**（不加资金，relabel）| type2 加仓在**本级别**增 units，非升 ladder；ascend 复用 units 无新建仓 |
| no-op | 无操作 | type2 是浪费买点（现架构实际落点）= 欠覆盖死扣 |

**结论**：type2 完全覆盖**必须新增 `add(k, dir, frac)` 原语**（极性不变、本级别、按力度档增 units）。这不是 workaround——是 561 §9.2 定理 CC 要求的"每轨道确定操作"在 type2 轨道的必要新原语。

### 4.2 这不是定义矛盾（无需 /escalate）

type2 = 加仓，是第17/21课**逐字明确**的语义（「绝对安全」「赢利必然」→ 应增仓吃确定行情）。
现架构缺 `add` 原语是**实现缺口**（route_bsp 二元坍缩的产物），非定义冲突——
按 testing-override「不改变任何定义即可修复」判据，这是**实现错误**（缺原语），正常补全，不上浮。
**故本工位无 /escalate**。实装（新增 `add` 原语 + LevelView 加 `t2buy/t2sell` 字段 + route_bsp 分 type）= 任务 #29 的 type2 子集，需隔离 worktree（编排者并行调度），本工位仅 spec 不实装。

### 4.3 与 561 N9 协变的一致性检查（无矛盾）

561 定理 PC1：s_k = dir_to_polarity(d_k)，唯一改变 s_k 的操作是 φ=0 缝 τ。
type2 **不翻转极性**（s_k 不变）⟹ **不调用 τ** ⟹ **不触及 N9 不变量**。
type2 的 add 操作在 N9 守卫下**恒合法**（不改 direction，只增 units）。
子级 type2（T2-3）：k 自身回调完成转多，s_{k-1} 从 Short（回调段）协变切到 Long（回调完成）——
这是 k-1 自身的 φ=0 缝 τ（次级别 type1 买），**协变 by construction**，N9 捕获正确。
**type2 spec 与 561 N9 完全一致**：N9 管 type1-flip 轨道，type2 是极性不变加仓轨道，二者正交不冲突。

## 五、对 539 欠覆盖的填补（mandate 核心交付）

**539 欠覆盖的 type2 切面**（561 §9.4 表「欠覆盖：真买卖点轨道无操作 → 死扣」）：
- 现架构把 type2 买坍缩进 `view.buy[ladder]=true` → route_bsp 实际产出 ∈ {no-op（"浪费的买点"）, recover, ascend}。
- **没有一个是加仓** ⟹ type2 的"在确定安全点增仓吃行情"语义**完全丢失**。
- 后果：强牛中本应在每次次级别回调（type2 买）加仓放大多头敞口，实际 no-op 踏空（与 project_unn_btc_spawn_throwback、project_t_emergence_upgrade_ab 的"踏空"病灶同源——加仓轨道缺失）。

**填补**：本 spec 给出 T2-1..T2-8 每轨道的确定操作（add + 力度档），把 type2 从二元坍缩中**解出**——
type2 买 ≠ type1 翻转 ≠ type3 延续，而是**极性不变的本级别加仓**，是完全分类覆盖（CC）中独立的一类轨道。

**与 type1/type3 的边界（完全分类的 type2 划界）**：
- type1（轨道归 orbit-type1）：极性翻转 flip（走势完成转折）。
- **type2（本工位）：极性不变加仓 add（type1 后首回调，趋势未确定）。**
- type3（轨道归 orbit-type3）：极性不变延续加仓（趋势已确定，中枢突破）。
- **type2 vs type3 的精确区分**：type2 在"上涨趋势尚未确定"窗口（第21课 L40），type3 在"上涨趋势已确定后"——
  二者操作都是"极性不变加仓"，但**触发条件不同**（type2=次级别回调低点不破前低，type3=离开中枢回试不破ZG），
  且 type2 有成败退出（破一买低点退出，orbit-2bs），type3 后必赢利（即使盘整也有高点，第20课 L62）。

## 六、结果包六要素

1. **结论**：type2（第二类买卖点）的确定操作 = **极性不变下的本级别加仓（add 原语，按中枢位置分力度档）**，

2. **定义依据**：

   - 第21课 L40「上涨趋势确定后……只可能有第三类买点」——type2 时间局部性（T2-8 边界）。
   - 第21课 L44「中枢下/中/上……力度……但无论哪种情况，赢利是必然的」——力度子轨道（T2-4/5/6）+ 加仓必然性。
   - 第21课 L48「第二类买点与第三类买点可能重合……大级别上涨」——T2-7。
   - 输入数据满足：`BSPKind::Type2Buy/Sell`（types.rs:179）由 `project_type2`（mod.rs:130）按定律一投影产出 = 满足定律一定义。

3. **边界条件（结论翻转条件）**：
   - 若引擎已有等价"极性不变加仓"原语（误判 §4.1），则"缺 add 原语"翻转——**反例**：7 原语逐一核验无一匹配（§4.1 表），add 缺失成立。

     "补 add 原语 ⟹ 净收益改善" = **L3 未决**，不声称（formalization-validity-domain 模式 3 禁有效域=定义域）。
