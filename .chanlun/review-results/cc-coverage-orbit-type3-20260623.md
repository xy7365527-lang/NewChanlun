## ★ 一句话主结论（吃涨踏空 + 强牛误翻空的正解）

**「上涨趋势确定后只可能有 type3 买点，不可能再有 type1/2」（第21课逐字）⟹ 若 Ω 只在真买卖点
操作，强牛中走势只产 type3 买点，type3 买点的极性恒为 Long（延续/加多），核心仓永不翻空。** 这把
539 的两个失血面同时解掉：
- **过覆盖（强牛误翻空）的正解**：强牛中没有真 type1/2 卖点（走势未完成），当前 NEST/cascade 用
  **背驰段（≠买卖点）或经验趋势**武装翻空 = 在非买卖点状态操作 = CC 过覆盖。type3 买点是强牛中
  **唯一**合法操作轨道，其确定操作 = `ascend`（核心升级骑趋势）/`enter` 加趋势腿，**极性不变（Long）**，
  不是 `flip`。补 type3 轨道 ⟹ 强牛误翻空在架构层消失（不需 if-else 硬编码 regime）。
- **吃涨踏空的正解**：当前 `route_bsp` 把 type3 买坍缩为二元 `is_buy=true`，在核心级（None 分支）
  同向时只 `ascend`（j>cc）或 **no-op**（j≤cc）——**type3 买点的"加多吃延续"在 no-op 分支被丢弃** =
  欠覆盖 = 踏空。type3 买点的缠论语义是"中枢突破后趋势延续，必然赢利"（第20课），确定操作是
  **持多/加多**（earning 增股数 deploy 或 ascend），不是 no-op。

## 一、type3 完全轨道枚举（第20/21课逐字 L0）

### 1.1 type3 的判据（第20课原文，逐字）

> 「由定理一，可以得到第三类买卖点定理：一个次级别走势类型**向上离开**缠中说禅走势中枢，然后以
> 一个次级别走势类型**回试**，其低点**不跌破ZG**，则构成第三类买点；一个次级别走势类型**向下离开**
> 缠中说禅走势中枢，然后以一个次级别走势类型**回抽**，其高点**不升破ZD**，则构成第三类卖点。」
> （`docs/chanlun/text/blog/020-第20课.md:60`）

> 「并不是任何回调回抽都是第三类买卖点，**必须是第一次**。」（020:62）

> 「第三类买卖点后，并**不必然是趋势**，也有进入**更大级别盘整**的可能，但这种买卖之所以**必然
> 赢利**，就是因为即使是盘整，也会有高点出现。」（020:62）

### 1.2 type3 的两个后继分叉（第20课级别延续定理一 + 第21课）

> 「第三类买点是中枢扩张或新生产生的。中枢扩张导致一个更大级别的中枢，而中枢新生，就形成一个
> 上涨的趋势，这就是第三类买点后必然出现的两种情况。」（`021-第21课.md:34`）

中枢延续定理一（020:40）：「在更大级别走势中枢产生前，该级别走势类型将延续。」⟹ type3 买点后，
在更大级别中枢产生前，**上涨延续**——核心多仓持有。

### 1.3 完全轨道表（type3 × 买/卖 × 后继分叉 × 级别）

type3 的轨道维度 = **方向（买/卖）× 后继（新生→趋势 / 扩张→大级别中枢）× 第一次序数 × 级别 k**。
后继分叉的**操作内容**归 orbit-center3 工位（中枢三态变化），本工位枚举 type3 **离开-回试事件本身**的
操作 + 引用后继分叉作为操作延续/退出的边界（§五）。

| 轨道 ID | 状态描述（缠论事件） | 第一次？ | 后继分叉 |
|---|---|---|---|
| **T3B** | 次级别向上离开中枢 + 回试低点不破 ZG（type3 买） | 是 | →新生(趋势) / →扩张(大中枢) |
| **T3S** | 次级别向下离开中枢 + 回抽高点不破 ZD（type3 卖） | 是 | →新生(下跌趋势) / →扩张(大中枢) |

**完备性边界**（第21课逐字，021:72）：「绝对不可能出现的是线段端点为 3买卖开头」⟹ type3 **不是
走势的起点端点**，是**延续中**的买卖点（趋势内部）。这锁定 type3 的操作语义 = **延续操作**（持/加/减），
**不是翻转**（翻转是 type1 转折轨道，归 orbit-type1 工位）。

### 3.3 编排者论证的 type3 坐实（强，L0 架构）

第21课:40 逐字「**一个上涨趋势确定后，不可能再有第一类与第二类买点，只可能有第三类买点**」是
"强牛只产 type3 买"的**原文定理**，非经验假设。推论链（L0）：
1. 强牛 = 上涨趋势确定（≥2 同向中枢，d_k=Up）。
2. ⟹ 该级别走势只产 type3 买点（第21课:40），不产 type1/2。
3. type3 买点的操作 = 延续（持多/加多，第20课:62「必然赢利」），极性恒 Long（561号 PC1 协变）。
4. ⟹ 若 Ω 只在真买卖点操作，强牛核心仓**恒 Long 不翻空**（吃大涨）。
5. ⟹ 539 强牛误翻空 = Ω 在**非 type3 买点状态**（背驰段/经验）操作的架构产物，**非市场规律**。

## 四、与 orbit-type1 / 561号 N9 的关系（推论归位）

- **type3 ⊥ type1（轨道正交）**：type1 = 走势完成的**转折**轨道（中枢下买/中枢上卖，flip）；
  type3 = 趋势内部的**延续**轨道（中枢上买/中枢下卖，ascend/deploy）。两者在完全分类中互斥
  （第21课:46「第一类与第三类…不可能产生重合」）⟹ Ω 对二者必须**不同操作**：type1→flip（仅 φ=0
  缝，561号 N9）；type3→延续（非缝，极性不变）。**当前二元坍缩把两者混进同一 is_buy 分支 = CC 违反。**
- **N9（561号）对 type3 的约束**：type3 买点极性恒 Long（d_k=Up 时 s_k=Long），N9 协变在 type3 轨道
  **自动满足**（无翻转，s_k 不变）⟹ type3 轨道**不触发 N9 的 φ=0 缝豁免**——它是"持多不动"的轨道，
  N9 的违反风险（中途翻转 τ@φ≠0）只发生在 type1 误判为翻转时。type3 的正确操作恰恰是 N9 守恒的
  典范（s_k=d_k 全程保持）。
- **N9 ⊊ CC ⊇ type3**：561号已定 N9 是 CC 的推论（type1-flip 单轨道）；type3 是 CC 的**另一组轨道**
  （延续，6 类中的 2 类 + 1 重合类），与 N9 正交。本工位填补 CC 在 type3 子空间的覆盖。

- **type2 轨道**（type1 后首次回调）→ **orbit-type2 工位**；本工位仅枚举 **2B∩3B 重合**轨道（type3 侧）。

## 七、结果包六要素

### 1. 结论
枚举 type3 买/卖完全轨道（T3B/T3S 核心级+子级、2B∩3B 重合、T3B/S-rep 排除），每轨道确定引擎操作
（spec table §二）。核心结论：**「上涨趋势确定后只 type3 买」（第21课:40 逐字）⟹ type3 买极性恒
Long（持多/加多），核心仓永不翻空** = 539 强牛误翻空（过覆盖）的正解 + 吃涨踏空（欠覆盖 no-op
丢弃加多）的正解。type3 操作 = `ascend`/`deploy_earning`（延续），**不是 flip**。

### 2. 定义依据
