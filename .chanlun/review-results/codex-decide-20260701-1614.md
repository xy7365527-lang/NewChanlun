## Response

**决策**：选 **其他**。

`Cand^δ_ℓ(x)` 在忠实实装中不应定义成 A“破中枢”，也不应定义成 B“次级别第一类买卖点”。应定义为：

> **δ 方向、ℓ 级别上可被区间套递归消费的背驰段候选区间存在性谓词**。  
> 即 `Cand` 负责选出当前中间级别的候选背驰段/候选区间 `J^δ_ℓ`；递归的 `J^δ_{ℓ+1} ⊆ J^δ_ℓ` 和最低级 `Confirm_e` 再完成逐级收缩与最终买卖点确认。

**推理链**：

① canonical/Lean 中 `Cand^δ` **无显式独立定义式**。  
S_Θ / FULL 都只在 `N^{δ}_{ℓ↓e}` 递归里引用 `Candidate` 符号；Lean 明确把它实现为 `candBuy/candSell` 抽象 Bool，并诚实标注“PDF 仅作符号，未给独立定义式”。

② §11.3 的理论依据是“低级别背驰是本级别背驰的必要条件，非充分”。这不是“破中枢是候选”，也不是“次级别第一类买卖点才是候选”。结合 §11.1/§11.2/§11.4，区间套的对象是“从大级别背驰段逐级缩到小级别背驰段，最终定位背驰点/买卖点”。

③ 因此 `Cand` 的代码语义应服务于“产生当前级别可继续下钻的 `J^δ_ℓ`”，而不是直接触发买卖点。买卖点确认已经由基例 `Confirm_e = B1 ∨ B2 ∨ B3` 承担；把 `Cand` 写成“次级别第一类”会把基例确认提前塞进中间层，而且错误排除 B2/B3。

**替代方案**：

- A“破中枢”：拒绝。破中枢不是权威文本里的区间套定义对象；它可能产生大量非背驰候选，过宽。
- B“次级别第一类构成”：拒绝。文本说的是低级别背驰必要，不是低级别一买必要；且最低级确认包含三类买卖点，不限第一类。
- 保持纯 Bool 抽象：Lean/规范层可以；W1 实装不够，因为无法审计 `J`、选择器、嵌套关系。

**W1 具体指令**：

实现 `Cand` 为不可变证据对象的派生 Bool：

```text
CandidateEvidence {
  dir: δ,
  level: ℓ,
  interval: J^δ_ℓ,
  basis: BackchiSegment / NestedBackchiSegment,
  selector: Sel_Θ version,
  source_ids: backing segment ids
}

Cand^δ_ℓ,t = selected CandidateEvidence exists
J^δ_ℓ,t = selected.interval
```

递归执行：

1. 非基例 `ℓ > e`：只从 δ 方向兼容的背驰段/可下钻候选区间生成 `CandidateEvidence`。
2. 多候选必须经固定 `Sel_Θ` 唯一选择。
3. 无候选返回 `0/false`，不是 undefined。
4. 递归层检查 `J^δ_{ℓ+1,t} ⊆ J^δ_{ℓ,t}`。
5. 基例 `ℓ = e` 才调用 `Confirm_e^δ = B1/B2/B3` 或 `S1/S2/S3` 析取。
6. 不允许把 `break_center` 或 `sublevel_B1` 直接命名为 `Cand`；若要保留，必须作为外部启发式字段，不能作为忠实谓词。

**边界条件**：

若后续 authoritative spec/PDF 明确给出 `Cand^δ_ℓ` 独立定义式，则推翻本决策，以新定义为准。若 W1 没有可用的背驰段区间 `J` 数据结构，则不能假装忠实实现，应先补 `BackchiSegment -> interval` 证据链。

**风险**：

主要风险在“对应背驰段”的工程判定：区间边界、级别映射、选择器稳定性都会影响结果。其次，旧测试若按 A 或 B 写 oracle，会出现信号集变化；这应记录为语义修正，而不是回退到 A/B。
