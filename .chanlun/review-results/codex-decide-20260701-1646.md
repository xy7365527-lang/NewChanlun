## 权威文本 1：FULL_USER_FORMULA_SOURCE.md 第十一节（核心方向资本三阶段）

账本恒等：`R_t = Π_t − A_t − W_t`（Π=累计已实现净利润，A=已分配增仓资本，W=已取回本金，R=未分配已实现利润储备，I_0=初始本金）。

调整资本基准：`K_t^adj = I_0 + A_t − Π_t = I_0 − W_t − R_t`。核心单位 Q_t>0 时 `c_t^adj = K_t^adj / Q_t`。
负成本条件：`c_t^adj < 0 ⟺ W_t + R_t > I_0`。取回全部本金 W_t=I_0 后：`c_t^adj = −R_t/Q_t`（R_t>0 ⟹ 负成本）。

### 阶段一：固定核心单位
要求 `A_t=0, W_t=0`。根仓目标绝对单位数固定 Q_0。所有次级别短差利润进 Π_t，不增根单位数。

### 安全取本条件（★阶段一→二的触发谓词）
可安全分配现金 D_t^dist。定义：
```
ReadyReturn_t :=
    [μ_t = Normal]                          （风险模式正常）
  ∧ [O_t = ∅]                               （无未完成订单）
  ∧ [∀v≠r, a_{v,t}=0]                        （所有次级别声部已关闭）
  ∧ [D_t^dist ≥ I_0 − W_t]                   （可分配现金够取剩余本金）
  ∧ [R_t − (I_0 − W_t) ≥ R_⋆ + L_{t+1}^wc]  （取本后仍留最低储备 R_⋆ + 下周期风险缓冲 L^wc）
```
最后一项：取出剩余本金后系统仍保留最低利润储备和下一周期风险缓冲。

### 阶段二：关闭战术仓并取本
禁止新开子声部。依次：平后代仓 → 等待结算 → 提现。
提现目标：`w_{t+1} = min{ I_0 − W_t, D_t^dist }`。结算后 `W_{t+1} = W_t + w_{t+1}`。
★阶段二→三触发：`当 W_{t+1} ≥ I_0 且所有战术仓、订单均已清除时进入第三阶段`。

### 阶段三：修复、保护、增加单位（Φ_t ∈ {III_repair, III_protected, III_accretive}）
增加一根单位所需安全资本 m_t^unit>0。三互斥子状态：
```
III_repair    ⟺ R_t < R_⋆ + L_{t+1}^wc
III_protected ⟺ R_⋆ + L_{t+1}^wc ≤ R_t < R_⋆ + L_{t+1}^wc + m_t^unit
III_accretive ⟺ R_t ≥ R_⋆ + L_{t+1}^wc + m_t^unit
```
完成一组短差得净实现利润 g_t，g_t^+ = max(g_t, 0)。增根单位资本：
```
a_t = LotCost[ min{ α·g_t^+, (R_t + g_t − R_⋆ − L_{t+1}^wc)_+ } ],  0 ≤ α < 1.
ΔQ_t = LotFloor( a_t / m_t^unit ).
```
★记账递归：`Π_{t+1}=Π_t+g_t, A_{t+1}=A_t+a_t, R_{t+1}=R_t+g_t−a_t, Q_{t+1}=Q_t+ΔQ_t`。
★增根单位准入：`仅当 ∀v≠r, a_{v,t}=0 且 O_t=∅ 时才允许增加根单位`（保证下一轮同单位数短差可重新严格匹配）。

### 阶段完全分类（Φ_t，第十二节，Y_t=待结算提现金额）
```
Φ_t = I               if W_t<I_0 ∧ Y_t=0 ∧ ¬ReadyReturn_t
    = II              if W_t<I_0 ∧ [Y_t>0 ∨ ReadyReturn_t]
    = III_repair      if W_t≥I_0 ∧ R_t < R_⋆+L^wc
    = III_protected   if W_t≥I_0 ∧ R_⋆+L^wc ≤ R_t < R_⋆+L^wc+m^unit
    = III_accretive   if W_t≥I_0 ∧ R_t ≥ R_⋆+L^wc+m^unit
```
Σ_φ 1[Φ_t=φ] = 1（完全互斥分类）。
