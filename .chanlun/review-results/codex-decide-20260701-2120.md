## 决断问题

`signal.rs:286` 的 MACD veto（`if !abc.diverges(hist, a_idx, c_idx) { return None }`）是"第一类买卖点"定义的实现。但外部 Q6 裁决认定此 veto 造成选择偏差——候选永不进样本。

## 缠论原文定义（权威来源）

### 第一类买点定义（缠论知识库 §10.1）
> 某级别下跌趋势中，次级别走势向下跌破最后一个中枢后形成的**背驰点**

第一类卖点镜像。

### 背驰定义（缠论知识库 §9.1）
> 趋势力度比上一次趋势力度弱 → 力量衰竭

### MACD 辅助判断（缠论知识库 §9.3）
> 用 MACD 判断背驰的常用框架：C 段完成时，对应的 MACD 柱子面积小于 A 段对应面积 → 标准背驰

关键：MACD 是"工程上常用简化"辅助判断，不是背驰的唯一充要定义。

### 买卖点完备性定理（§10.2）
> 市场必然产生赢利买卖点，只有第一、二、三类

## 代码现状（signal.rs）

### 第一类判定函数 `judge_first_cached`（line 250-301）

判定条件（当前实现）：
1. τ 门控：L0 中枢序列 ≥2 全链同向（Trend(Down)/Trend(Up)） ← L0 纯整数几何
2. 破中枢几何：C 段端点 < last_center.zd（买）或 > last_center.zg（卖） ← L0 纯整数几何
3. A 段定位：locate_trend_seg_a 找相邻前中枢的同向离开段 ← L0 纯整数几何
4. **MACD veto（line 286）**：C 段面积 < A 段面积（`abc.diverges(hist, a_idx, c_idx)`） ← L1 MACD 真算

如果第 4 步为 false，返回 None，候选**不进入样本**。

### 影响

level-anomaly-dx 实测：level0 全历史 714 个买卖点全是第三类（buy3/sell3）。
第一类 buy1/sell1 **全历史从没触发过**——极大概率是 MACD veto 把所有第一类候选都卡死。

## 两方案

### 方案 A：删除 MACD veto，buy1 不再要求 MACD 背驰

```rust
// 删除这 3 行（signal.rs:286-288）：
if !abc.diverges(hist, a_idx, c_idx) {
    return None;
}
```

**含义**：buy1 = 趋势 ∧ 破中枢（结构判据），不要求 MACD C<A。

代价：
- 测试 `first_buy_rejected_without_divergence` 变红（该测试断言"不背驰不产第一类"）
- 知识库"第一类=趋势背驰"与代码断裂：破中枢≠背驰
- MACD 背驰判定从 gate 降为 feature 字段（但当前 BspPoint 结构无此字段）

### 方案 B：保留 buy1 语义，新增候选域

新增 `struct_broke_buy/sell` 结构候选字段（`BspPoint` 或 candidate 层新结构），
破中枢但 MACD 未验证的候选用 `bsp_class` 编码区分，下游不当第一类。

**含义**：buy1 保持"趋势背驰"语义；扩展候选域让"结构破中枢但未背驰"的点也可进样本。

代价：
- `assemble_gamma::candidate_dir` 需扩展（新字段 bsp_class 区分）
- 可能动 bit-exact Gamma 组装
- 需要新的 BspPoint 字段或新候选结构

### 方案 Q6 Fix1（外部裁决建议）

候选域用**结构判据**（方向/可比/新高低/背驰上下文），MACD/Force/volume 降为 **feature 非 veto**。
选择器 χ = 1[LCB(μ(Z,a)) > θ] 学习，不预删候选。

**含义**：从结构识别阶段完全分离 MACD 过滤，结构层只做几何判据，MACD 降为下游选择器特征。

## 关键约束（codex 评估时需考虑）

1. **缠论语义**："背驰"是第一类买卖点的结构定义成分，不是辅助过滤
2. **选择偏差**：MACD veto 使未过候选永不进样本，无法通过数据否证 MACD 的有效性
3. **bit-exact 保护**：Gamma 组装是核心不变量，任何改动须保证 bit-exact
4. **L0/L1 分层**：结构判据（破中枢、趋势门控）是 L0 整数几何；MACD 面积比较是 L1 浮点；两个层次分开处理是认识论正确的
5. **全历史 buy1=0**：MACD veto 已经事实上消灭了第一类买卖点，这是最强的实证信号

## Response

**决策**：选 **Q6-Fix1，但按 B 的分层思想落地**。

即：第一类语义不改，仍是“趋势破中枢后的背驰点”；但 `MACD C<A` 不能再作为 `judge_first_cached` 的 hard veto。正确拆分是：

- L0 候选域：`趋势门控 + 破最后中枢 + 可定位 A/C 段`
- L1 特征域：`macd_diverged / force / volume / area_ratio`
- 选择器：χ 用 `LCB(μ(Z,a)) > θ` 学习准入

`MACD C<A` 是背驰的一个工程测量，不是“背驰”本体。

**推理链**：

1. 背驰是第一类买卖点的必要语义条件，不能删。
2. 但当前代码把“MACD 面积缩小”当成“背驰”的唯一充要条件，这是错误建模。
3. hard veto 会造成选择偏差：MACD 未过的结构候选永不进样本，无法被数据否证。
4. 纯 A 会把“破中枢”直接升级为 buy1，语义太松。
5. 纯 B 如果只是新增 `struct_broke_buy/sell` 但继续让 confirmed buy1 受 MACD gate 控制，仍会把第一类样本域切断。
6. 因此最优是：结构候选进入样本，MACD 作为 feature，`BspBits` 不承载“MACD 失败/成功”这种测量状态。

**BspPoint 最小扩展**：

不要给 `BspBits` 加第七位，也不要滥用 `bsp_class`。最小可接受扩展是给第一类上下文加证据字段，例如：

```rust
pub type1_evidence: Option<Type1Evidence>

pub struct Type1Evidence {
    pub a_seg: (usize, usize),
    pub c_seg: (usize, usize),
    pub macd: MacdDivergenceFeature,
}

pub enum MacdDivergenceFeature {
    CWeaker,
    NotWeaker,
    Unavailable,
}
```

更稳的实现是 sidecar：`SignalCandidate` / `CandidateEvidence`，由 `(level, source_index, side)` 关联到 `BspPoint`，这样不污染当前 [BspPoint](/Users/silencehan/Projects/NewChanlun/rust/src/theta_v0/classifier/bsp.rs:101) 和 Γ 组装。

**bit-exact 影响**：

新增字段不必然破坏 Gamma。现有 [assemble_gamma](/Users/silencehan/Projects/NewChanlun/rust/src/theta_v0/strategy/interp.rs:159) 只依赖 `level/source_index/bits/dir/bsp_class`。只要新增证据字段不参与 `candidate_dir`、排序、`bsp_class`、`bits`，Gamma 语义可保持。

会破坏的情况是：把结构候选直接塞进 `classification.levels[*].bsp` 并改变遍历长度/顺序，或改变 `BspBits`。另外，当前 bit-exact digest 若基于 `Debug` 全字段，新增字段会让 golden 变红；这是测试表面变化，不是 Gamma 不变量变化。sidecar 可避免。

**替代方案**：

- A：拒绝。删除 MACD veto 是对的，但如果没有证据字段，会把“破中枢”伪装成“背驰”，语义断裂。
- B：部分接受。新增候选域是对的；但不要用 `bsp_class` 编码结构破中枢，也不要把候选伪装成 1/2/3 类。
- 现状：拒绝。`signal.rs:286` 的 veto 已经实证导致 buy1/sell1 全历史为 0，样本域被 MACD 代理量截断。

**边界条件**：

推翻此决策只在三种情况下成立：严格 spec 明确把 `MACD C<A` 定义为背驰的唯一判据；修复 A/C 定位或 MACD 映射 bug 后 buy1 仍自然出现且无选择偏差；或 Gamma 合约被正式限定为“只能含 confirmed BSP，不能含 raw candidate”，那 raw 候选必须留在 L2 sidecar，不进入执行 Gamma。

**风险**：

主要风险是命名漂移：团队会把“结构候选”口头叫成“第一类”。测试也要改名，`first_buy_rejected_without_divergence` 不应删除，而应改成验证“结构候选进入样本且 `macd=NotWeaker`”。如果采用纯 A，则断言应从“不产生 buy1”改为“产生候选，MACD 背驰特征为 false”，但我不建议纯 A。
