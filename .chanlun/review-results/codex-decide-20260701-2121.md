# Codex Decide: P2 第一类买卖点定义冲突

## 决断问题

`signal.rs:286` 的 MACD veto（`if !abc.diverges(hist, a_idx, c_idx) { return None }`）是"第一类买卖点"定义的实现。但外部 Q6 裁决认定此 veto 造成选择偏差——候选永不进样本。

## 缠论原文定义（权威来源）

### 第一类买点定义（缠论知识库 §10.1）
> 某级别下跌趋势中，次级别走势向下跌破最后一个中枢后形成的**背驰点**

第一类卖点镜像。

### 背驰定义（缠论知识库 §9.1）
> 趋势力度比上一次趋势力度弱 → 力量衰竭

### MACD 辅助判断（缠论知识库 §9.3）
> 用 MACD 判断背驰的常用框架：C 段完成时，对应的 MACD 柱子面积小于 A 段对应面积 → 标准背驰

关键：MACD 是"工程上常用简化"辅助判断，不是背驰的唯一充要定义。

### 买卖点完备性定理（§10.2）
> 市场必然产生赢利买卖点，只有第一、二、三类

## 代码现状（signal.rs）

### 第一类判定函数 `judge_first_cached`（line 250-301）

判定条件（当前实现）：
1. τ 门控：L0 中枢序列 ≥2 全链同向（Trend(Down)/Trend(Up)） ← L0 纯整数几何
2. 破中枢几何：C 段端点 < last_center.zd（买）或 > last_center.zg（卖） ← L0 纯整数几何
3. A 段定位：locate_trend_seg_a 找相邻前中枢的同向离开段 ← L0 纯整数几何
4. **MACD veto（line 286）**：C 段面积 < A 段面积（`abc.diverges(hist, a_idx, c_idx)`） ← L1 MACD 真算

如果第 4 步为 false，返回 None，候选**不进入样本**。

### 影响

level-anomaly-dx 实测：level0 全历史 714 个买卖点全是第三类（buy3/sell3）。
第一类 buy1/sell1 **全历史从没触发过**——极大概率是 MACD veto 把所有第一类候选都卡死。

## 两方案

### 方案 A：删除 MACD veto，buy1 不再要求 MACD 背驰

```rust
// 删除这 3 行（signal.rs:286-288）：
if !abc.diverges(hist, a_idx, c_idx) {
    return None;
}
```

**含义**：buy1 = 趋势 ∧ 破中枢（结构判据），不要求 MACD C<A。

代价：
- 测试 `first_buy_rejected_without_divergence` 变红（该测试断言"不背驰不产第一类"）
- 知识库"第一类=趋势背驰"与代码断裂：破中枢≠背驰
- MACD 背驰判定从 gate 降为 feature 字段（但当前 BspPoint 结构无此字段）

### 方案 B：保留 buy1 语义，新增候选域

新增 `struct_broke_buy/sell` 结构候选字段（`BspPoint` 或 candidate 层新结构），
破中枢但 MACD 未验证的候选用 `bsp_class` 编码区分，下游不当第一类。

**含义**：buy1 保持"趋势背驰"语义；扩展候选域让"结构破中枢但未背驰"的点也可进样本。

代价：
- `assemble_gamma::candidate_dir` 需扩展（新字段 bsp_class 区分）
- 可能动 bit-exact Gamma 组装
- 需要新的 BspPoint 字段或新候选结构

### 方案 Q6 Fix1（外部裁决建议）

候选域用**结构判据**（方向/可比/新高低/背驰上下文），MACD/Force/volume 降为 **feature 非 veto**。
选择器 χ = 1[LCB(μ(Z,a)) > θ] 学习，不预删候选。

**含义**：从结构识别阶段完全分离 MACD 过滤，结构层只做几何判据，MACD 降为下游选择器特征。

## 关键约束（codex 评估时需考虑）

1. **缠论语义**："背驰"是第一类买卖点的结构定义成分，不是辅助过滤
2. **选择偏差**：MACD veto 使未过候选永不进样本，无法通过数据否证 MACD 的有效性
3. **bit-exact 保护**：Gamma 组装是核心不变量，任何改动须保证 bit-exact
4. **L0/L1 分层**：结构判据（破中枢、趋势门控）是 L0 整数几何；MACD 面积比较是 L1 浮点；两个层次分开处理是认识论正确的
5. **全历史 buy1=0**：MACD veto 已经事实上消灭了第一类买卖点，这是最强的实证信号

## Response

**决策**：选 **Q6 Fix1 的第三方案**，但实现上采用 B 的语义纪律：  
L0 只产出“第一类上下文候选/破最后中枢候选”，MACD 作为 L1 feature，不再作为候选 gate；`buy1/sell1` 这个严格语义标签不要等同于“破中枢”。

**推理链**：

1. “背驰”是第一类买卖点的必要概念条件；但 **MACD C<A 不是背驰的唯一充要条件**。  
   所以当前 `abc.diverges(hist, a_idx, c_idx)` 可以作为 `macd_c_area_lt_a_area` 特征，不能作为“是否进入样本”的定义 gate。

2. 当前 MACD veto 会造成选择偏差：未过 MACD 的结构候选永远不进样本，下游无法学习或否证 MACD 的有效性。`buy1=0` 说明实现作为检测器已经失效，但不能推出“背驰定义应删除”。

3. 最小正确分层是：
   - L0：整数几何，识别 `trend + broke_last_center + A/C context`
   - L1：浮点/量能/MACD 等背驰证据特征
   - χ：选择器或验证器决定是否采用该候选

4. 不要把 `struct_broke_buy/sell` 塞进 `bsp_class`。这会污染买卖点类别代数。应新增候选层或 sidecar feature 层，例如：
   ```rust
   struct BspCandidate {
       point: BspPoint,
       kind: CandidateKind, // FirstTrendBreak, Third, ...
       first_ctx: Option<FirstContext>,
       features: BspFeatures,
   }

   struct BspFeatures {
       macd_c_lt_a: Option<bool>,
       macd_area_a: Option<f64>,
       macd_area_c: Option<f64>,
       macd_area_ratio: Option<f64>,
   }
   ```
   如果必须扩展 `BspPoint`，只加一个默认空的 evidence/feature 字段，且不得参与 `class_index/from_class_index`、排序、hash、Gamma bit-exact 比较。

**替代方案**：

- 拒绝 A：直接删除 MACD veto 会消除选择偏差，但会把“趋势破中枢”误命名为“第一类背驰点”。这是领域概念降级。
- 拒绝纯 B：如果只是新增 `struct_broke_buy/sell` 并让下游不当第一类，方向对，但容易把候选类别混入 `bsp_class`，影响 Gamma 组装和类别代数。B 只有在“候选层独立于 BspPoint 类别层”时成立。
- 采纳 Q6 Fix1：候选域结构化，MACD/力度/量能降为 feature，避免预删样本。

**边界条件**：

应推翻此决策的情况只有这些：

1. 权威缠论规格明确要求“MACD C<A 是第一类买卖点的必要定义条件”，而不是辅助判断。
2. 后续实证显示结构候选域爆炸到不可控，并且无法通过简单 L0 上下文约束降低规模。
3. Gamma 组装无法隔离候选层，新增 candidate/feature 必然改变核心 bit-exact 输出。
4. 项目决定 `BspPoint` 不再表示语义买卖点，而只表示策略信号；那需要整体重命名语义，不能局部改一处。

**风险**：

1. 命名风险：`buy1`、`first_candidate`、`macd_diverged` 混用会继续制造定义冲突。建议把 MACD 字段命名为 `macd_c_lt_a`，不要叫 `diverged`。
2. bit-exact 风险：只要 feature 进入排序、hash、class index、Gamma 输入，就可能破坏核心不变量。
3. 学习风险：候选域放宽后，负样本会增加，需要明确标签、收益窗口和 selector 目标。
4. 语义风险：如果 selector 只学盈利而不约束“趋势背驰”语义，最终会得到“ profitable first-context signal”，不等于严格第一类买卖点。

`first_buy_rejected_without_divergence` 不应删除，应改写：验证“结构候选仍然产出，并且 `macd_c_lt_a == false`”。如果还保留严格 `buy1` 输出测试，则应断言“不因 MACD false 删除候选”，而不是断言“无 MACD 背驰就完全不存在”。
