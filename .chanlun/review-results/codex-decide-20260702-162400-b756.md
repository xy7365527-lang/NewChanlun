## 本次补全：这是一个确定性代数证明，不是统计相关性论证

### 背景定义

- 660号候选已提出：DIM-1（过拟合控制）与DIM-2（功效/样本量）是两个正交维度的门控效应。
- 662号candidate用一个**代数不等式**（非统计学相关性）证伪"正交"这一子命题。

### 核心机制（L0，纯代数，源码：`lcb_vs_naive_l2.rs:57` 单调性诊断）

给定同一组数据（某bsp类的信号样本），定义两个门控判据：
- 裸μ判据：`accept ⟺ mean ≥ θ`
- LCB判据：`accept ⟺ LCB(μ) ≥ θ`，其中 `LCB(μ) = mean − z_α·std/√n`

由于 `z_α > 0`、`std ≥ 0`、`n > 0` 对任意实际数据恒成立：

```
LCB(μ) = mean − z_α·std/√n ≤ mean        （数学恒等式，无需数据验证）
```

这是一个**逐点（pointwise）不等式**，对任意bsp类样本都成立，不依赖具体数据分布假设。

### 由此推出的集合论必然性

对同一阈值θ，两个判据的通过集合满足：

```
AcceptSet(LCB) = { c : LCB(μ_c) ≥ θ } ⊆ { c : mean_c ≥ θ } = AcceptSet(裸μ)
```

证明：若 `c ∈ AcceptSet(LCB)`，则 `LCB(μ_c) ≥ θ`；又 `mean_c ≥ LCB(μ_c) ≥ θ`；故 `c ∈ AcceptSet(裸μ)`。∎

这是**集合包含关系的形式证明**，在 `lcb_vs_naive_l2.rs:57` 的单调性诊断中被数值验证坐实（该诊断遍历全部候选bsp类，逐类核验 `AcceptSet(LCB) ⊆ AcceptSet(裸μ)` 恒成立，无一反例）。

### 为什么这直接推出"非正交"（比协方差更强的证据）

设 `Δ = AcceptSet(裸μ) \ AcceptSet(LCB)`（被LCB额外拒绝、但裸μ会接受的类）。

- **DIM-1的度量对象** = Δ 集合（LCB相对裸μ多拒绝的类，即"过拟合修正"发生的位置）。
- **DIM-2的度量对象** = 因Δ集合被拒绝而损失的样本/功效（这些类原本贡献的信息量）。

DIM-1 和 DIM-2 度量的**是同一个集合 Δ 的两个投影**（"被拒绝"和"被拒绝导致的样本损失"），不是两个独立采样得到的随机变量。这不是"部分相关"（correlation < 1），而是**同一底层动作（收紧LCB阈值）产生的两个必然性（determinstic）后果**——Δ集合本身既定义了DIM-1的分子，也定义了DIM-2损失的分子。

正交性要求两个维度可以独立变化（一个变化不必然导致另一个变化）。但由于 `LCB ≤ 裸μ` 的代数必然性，任何收紧LCB的操作（增大z_α或减小n）都单调扩大Δ集合，同时单调增加DIM-1修正量与DIM-2损失量——两者不能被独立设定，是同一参数（LCB收紧程度）的两个单调函数。这满足"完全函数依赖"的更强条件（比协方差/条件独立更精确）。

## Response

**决策**：成立，但限定为代码层/操作定义下的证伪。

技术选型上应把 `LCB门控` 与 `裸μ门控导致的功效损失` 建模为同一门控机制的两个派生量，而不是两个正交维度。也就是：保留 `Δ = AcceptSet(裸μ) \ AcceptSet(LCB)` 作为核心领域对象，DIM-1 和 DIM-2 都从 `Δ` 派生。

**推理链**：

`LCB = mean - z * std / sqrt(n) <= mean` 是逐点代数恒等式。因此在同一阈值 `θ` 下：

```text
AcceptSet(LCB) ⊆ AcceptSet(裸μ)
```

这个包含关系不是统计相关性，而是确定性约束。只要 LCB 通过，裸μ必然通过；反过来不成立。于是 LCB 的全部额外作用都集中在：

```text
Δ = AcceptSet(裸μ) \ AcceptSet(LCB)
```

如果 DIM-1 定义为“LCB 相对裸μ额外拒绝了哪些类”，DIM-2 定义为“这些额外拒绝造成的样本/功效损失”，那两者共享同一个底层集合 `Δ`。这已经足以证伪“代码层正交”：它们不是两个可独立调节的门控轴，而是同一次收紧操作的两个投影。

更精确地说，成立的是：

```text
Δ -> DIM-1
Δ -> DIM-2
```

在候选类全集、样本权重、功效计算规则固定时，也可以说 `Δ` 对两者构成完全函数依赖。

**替代方案**：

拒绝“继续把 LCB 过拟合控制 与 功效损失建模为正交维度”。

理由是正交建模会误导架构：它暗示两个维度可以独立开关或独立优化，但实际代码里 LCB 收紧会单调改变 `Δ`，而 `Δ` 同时决定额外拒绝与由此产生的功效损失。

也拒绝“必须用协方差/条件独立/残差信息量才能判定非正交”。

这里不是随机变量相关性问题，而是门控集合的确定性包含关系。统计证据可以补充经验强度，但不是此命题成立的必要条件。

**边界条件**：

应推翻此决策的情况：

1. DIM-2 的功效损失不再由 `Δ` 定义，而引入独立功效模型，例如外部采样成本、类别优先级、后续补样策略、独立实验设计。
2. LCB 与裸μ使用不同阈值、不同样本全集、不同候选类 universe，导致 `AcceptSet(LCB)⊆AcceptSet(裸μ)` 不再成立。
3. `std`、`n`、`z` 的实现允许非法值，例如 `z < 0`、`n <= 0`、异常 NaN 传播，使代数单调性失效。
4. “DIM-1”只记录一个聚合标量，例如 `|Δ|`，而“DIM-2”依赖每个类的样本权重；此时 `|Δ|` 不完全决定 DIM-2，必须保留完整 `Δ` 或权重映射。

**风险**：

主要风险是把“非正交”过度表述成“两个标量之间必然一一对应”。严格说，完全函数依赖成立在 `Δ` 这个完整集合层面，不一定成立在聚合后的标量层面。

因此代码层建议是：不要建两个独立 gate；建一个 `GateDelta` / `RejectionDelta` 领域对象，再从它派生过拟合修正指标和功效损失指标。这样既忠实表达概念，也避免把同一机制拆成伪正交维度。
