### 功效计算（本次新增，回应codex"功效计算"要求）

**H0下（真实无alpha，p=0.5）单侧符号检验，n=5时的精确二项分布**：

| 观测正例数 X | P(X\|H0) | 累积 P(X≥x\|H0) | 单侧p值判定 |
|---|---|---|---|
| 5/5 | 1/32 ≈ 0.03125 | 0.03125 | p<0.05，唯一可显著的观测 |
| 4/5 | 5/32 ≈ 0.15625 | 6/32 ≈ 0.1875 | p=0.1875，不显著 |
| 3/5（实际观测） | 10/32 ≈ 0.3125 | 16/32 = 0.5 | p=0.5，不显著 |

**关键结论**：n=5时，唯一能在α=0.05单侧下拒绝H0的观测是 X=5（全正）。X=4已经不显著（p=0.1875）。

**最小可检测效应（功效计算，本次新增）**：

在n=5、α=0.05单侧检验下，拒绝域仅为{X=5}。设真实胜率为p_true，则：

```
Power(p_true) = P(X=5 | n=5, p=p_true) = p_true^5
```

| 假设真实胜率 p_true | 检出力 Power |
|---|---|
| 0.6（弱edge） | 0.6^5 ≈ 7.8% |
| 0.7（中等edge） | 0.7^5 ≈ 16.8% |
| 0.8（强edge） | 0.8^5 ≈ 32.8% |
| 0.9（极强edge） | 0.9^5 ≈ 59.0% |

**要达到常规80%检出力所需的最小真实胜率**：
```
p_true^5 ≥ 0.8  ⟹  p_true ≥ 0.8^(1/5) ≈ 0.956
```

即：除非真实胜率高达95.6%（对交易信号而言是不现实的极端值），否则n=5的符号检验有80%以上的概率无法探测到该效应，即使效应真实存在。**即使假设一个相当乐观的70%真实胜率，检验在此样本量下也有83.2%的概率将其误判为"无显著效应"**。

## Response

**决策**：成立。L3 判定应从 `falsification` 降级为 `inconclusive`，代码层应记录为 `INCONCLUSIVE_LOW_POWER`，而不是“真无信号”。

**推理链**：n=5 的单侧符号检验在 α=0.05 下拒绝域只有 `X=5`。因此功效为 `p_true^5`，在 60%-90% 合理胜率假设下仅 7.8%-59.0%，低于 80% 常规标准。实际 `3/5, p=0.5` 只能说明“未检出显著性”，不能区分“无 alpha”和“有 alpha 但样本太小”。

独立结构证据也支持低功效解释：16K 短窗、高级别 z 类 μ 估计退化、L3 样本饥饿、静默不交易、P0 修复后 L3 仍为 3/5。这些使“观测接近零是估计/样本问题”比“结构性真零”更符合当前证据。

代码层选择：使用精确二项符号检验 + 功效门槛。`p>=0.05` 不直接映射为 falsification；只有在预设效应下功效足够时，非显著结果才可升级为证伪证据。

**替代方案**：

- 保持 `falsification`：拒绝。它把“未显著”误当成“无效应”，在 n=5 下统计上不成立。
- 判为 `confirmation`：拒绝。3/5 和 p=0.5 也不能支持有信号。
- 用正态近似或 χ² 近似：拒绝。n=5 太小，应使用精确二项分布。

**边界条件**：若后续 L3 样本量足够，并且在预设最小效应下功效 ≥80%，仍观察到接近零、方向不稳定或负收益，则可重新判为 falsification。若能证明 L3 空仓/μ=None 与样本饥饿无关，也应推翻当前降级。

**风险**：`inconclusive` 可能被误读为“支持 alpha”。它只表示当前证据不足以证伪。还需避免事后选择效应假设，最好在代码中固化 `p_min`、`alpha`、`power_threshold` 和 verdict reason。
