# 裁定2（G4）：统计层 X_i 出场时点是否须用 typed exit（τ^typed）而非 τ^reverse

## PDF 权威（docs/formal-chain/完整的策略.pdf §9 正规出场层，编排者钦定验收规格）

> 完整策略不能只用"下一个反向信号"出场。出场应是 typed exit：
>
> Exit_Θ(v,x_t) ∈ {CloseRoot, ReduceCore, CloseShortDiff, RiskExit, Hold}
>
> 例如：第一类反向点：根仓清仓；第三类反向点：核心仓减仓；短差反向确认：关闭子声部；保证金/强平：风险优先退出。
>
> 收益函数必须使用正规出场：
>   X_i^full = δ_i(P_{τ_i^typed} − P_{τ_i}) − C_i
>
> 不能继续用：
>   X_i^old = δ_i(P_{τ_i^reverse} − P_{τ_i}) − C_i
>
> 因为 τ_i^typed ≠ τ_i^reverse 一般成立。

§15 checklist P7 明确列为完整性必要项："P7：CloseRoot/ReduceCore/CloseShortDiff 等正规出场进入回测。"

## Response

**决策**：现口径不合规。统计层 `X_i` 必须改用 `τ^typed`；当前两条路径都是先用“下一反向确认信号”定 `exit_bar`，再事后贴 `ExitDecision` 标签，这不是 PDF §9 的 typed exit。

**推理链**：
- 路径 A 明确在 [l3_delta_r_alpha.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/backtest/l3_delta_r_alpha.rs:201) 用首个反向 `VoiceSide` 信号定 `exit_bar`，然后直接算 `x_gamma` 和 `ResidualTrade`。
- 路径 B 明确在 [econ_positive.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/backtest/econ_positive.rs:394) 用首个后续反向信号配对，`exit_decision_from_bits` 到 [econ_positive.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/backtest/econ_positive.rs:466) 才计算，已经晚于 `P_τout` 的选择。
- `sell_decision_of` 本身会返回 `Hold`，见 [sell.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/closed_loop/sell.rs:122)。所以“反向信号”不可能自动等价于 `CloseRoot/ReduceCore`。
- `Type2Missing` 和 `Hold` 仍被统计为已出场标签，见 [econ_positive.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/backtest/econ_positive.rs:493)。这反证了“所有 τ^reverse 都是 τ^typed”。

严格实现选择：新增一个共享的 typed-exit 选择器，而不是在两个调用点各补过滤。

语义上：

```text
τ_i^typed = min { t > τ_i_entry :
  Exit_Θ(v_i, x_t) ∈ {CloseRoot, ReduceCore, CloseShortDiff, RiskExit}
}
若集合为空：按该统计路径原删失规则处理。
Hold / Type2Missing 不停止扫描。
```

实现上：
- `CloseRoot/ReduceCore`：复用 `sell_decision_of` / `exit_decision_from_bits`，但必须在扫描过程中决定是否停止，而不是事后标注。
- `RiskExit`：已有 `KThetaRiskGate` 与 runner 内 `k_theta_risk_gate` 逻辑，但统计路径没有直接 reusable 的 `RiskExit` API；需要抽一个小的纯函数/适配器。
- `CloseShortDiff`：已有 `Vertical::ShortDiff`、`ActiveLeg`、`interpret` 的 close bucket 语义，见 [interp.rs](/Users/silencehan/Projects/NewChanLun/rust/src/theta_v0/strategy/interp.rs:940)，但没有显式 `CloseShortDiff` 事件；需要新增薄枚举/映射，不要重写领域判据。

**替代方案**：
- 保持 `τ^reverse` 并声称标签已实装：拒绝。标签不改变 `exit_bar` 和 `P_τout`。
- 只把当前配对结果中 `Hold/Type2Missing` 过滤掉：拒绝为正式方案。它仍只看反向信号，会漏掉更早的 `RiskExit`，也不能表达短差子声部关闭。
- 重写完整策略解释器给统计层：拒绝。最小正确方案是复用现有 sell/risk/interp 原语，抽一个共享 typed-exit 选择器。

**边界条件**：
- 只有在形式化规格改口，明确统计层目标是 legacy `Π_simp / τ^reverse` 诊断，而非 full strategy `P7`，才可保留当前口径，但必须改名隔离。
- 或者给出机器可检验不变量：每个首个反向信号恒为 typed exit，且此前无 `RiskExit/CloseShortDiff`。当前代码和统计枚举不支持这个不变量。
- 若后续 runner 能输出完整 typed ledger，统计层应直接消费 ledger，而不是再维护一套 exit 扫描器。

**风险**：
- 旧的 W-VERIFY、perm_test、GAP3 econ、χ 选择器、历史 L2/L3 alpha 结论全部失效，需要重收集/重放 typed exits、重算 μ̂/ResidualTrade、重跑批。
- `RiskExit` 需要账户/保证金/权益状态；若统计路径只有 bars，会有有效域缺口。
- `ReduceCore` 是减仓不是全平，若统计对象从“单 voice 收益”升级到账本收益，还要同步处理数量语义。当前先裁定时点，不偷换成完整账本。
