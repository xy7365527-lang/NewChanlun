## 1. 原文证据（三级权威链，缠师原始博文为最终权威）

### 1.1 第 33 课《走势的多义性》（一级博文，2007-03，「九段升级」的唯一明文出处）

> 例如，5分钟级别的中枢不断延伸，出现9段以上的1分钟次级别走势。站在30分钟级别的中枢角度，3个5分钟级别的走势重合就形成了，而9段以上的1分钟次级别走势，每3段构成一个5分钟的中枢，这样也就可以解释成这是一个30分钟的中枢。这种情况，只要对中枢延伸的数量进行限制，就可以消除多义性，一般来说，中枢的延伸不能超过5段，也就是一旦出现6段的延伸，加上形成中枢本身那三段，就构成更大级别的中枢了。

要点：(a) 阈值=延伸 6 段+本体 3 段=总 9 段；(b) 机制描述=「每 3 段构成一个（本级别）中枢」→ 3 个本级别走势重合 → 高一级中枢；(c) 定位=消除多义性的**约定**（「一般来说」），非定理。

### 1.2 第 20 课（一级博文，2007-01，任务名义引用的「中心定理二」）

> 缠中说禅走势中枢中心定理二：前后同级别的两个缠中说禅走势中枢，后GG<前DD，等价于下跌及其延续；后DD>前GG等价于上涨及其延续。后ZG<前ZD且后GG>=前DD，或后ZD>前ZG且后DD=<前GG，则等价于形成高级别的走势中枢。

**注意**：中心定理二讲的是「两个同级别中枢的波动区间重叠 ⟹ 高级别中枢」（扩张路径），与「延伸段数升级」是**不同机制**。且第 20 课明文（涨停例）：

> 一个股票开盘立刻封涨停，那么，只能算是一分钟级别上出现了走势中枢的延伸，无论这个延伸有多长时间，都不可能产生更大级别的走势中枢。……换言之，走势中枢的延伸与不断产生新的走势中枢并相应围绕波动互不重叠而形成趋势，在这两种情况下，一定不可能形成更大级别的走势中枢。

⟹ 第 20 课（延伸不升级）与第 33 课（延伸≥9段升级）存在表面张力。两课均为一级博文；33 课晚出且自称「消除多义性的限制约定」。

## 2. 现实装路径（rust/src/theta_v0/classifier/）

塔数据流（mod.rs 塔循环，全量与增量同构）：每级 `compose_level(units)` → `detect_centers_windowed_resume`（Step1 seed 三段判据成立 → Step2 延伸吸收 → Step3 non-extension 终止）产出 (centers, upper_moves) → `decompose(centers)` 按 `classify_relation` 切走势块 → `project_to_units(upper_moves, blocks)` 作为上一级输入 units。上一级中枢由上一级 detect 自行 seed（单一来源，无跨级注入）。

关键现状：

- **延伸吸收无上限**（recursive_tower.rs Step2）：`while j < units.len() && units[j].lo <= c.zg && units[j].hi >= c.zd { 吸收 }`。核心 [ZD,ZG] 由 seed 三段交冻结（口径 B，Q3 裁决保留），延伸只扩外缘 DD/GG。BTC L0 实测最长延伸窗口 42 段。
- **classify_relation**（center.rs）：next.dd > prev.gg → UpContinuation；next.gg < prev.dd → DownContinuation；否则 LevelExpansion。LevelExpansion run 在 decompose.rs 中折为 Consolidation 块——**目前只是标记，不构造高级别中枢**（注释明文「中心定理二升级候选，#145 承接」→ 实为本 #148）。
- **增量协议**（#142 frontier 协议）：末位中枢开放，resume = pop 末位 + 从其 seed 起点（resume_from）重扫；`classify_with_tower_incremental` 已有护栏——frontier 中枢 pop 后重扫改值或一次重扫多产 ⟹ cached_outcome=None 走全量裁决。T^inc==T^full 定义性成立是铁律。
- **既有裁决 Q2**（一类买卖点.pdf §5，#142 时钦定）：「连续围绕同一区间震荡 = 一个延伸中枢，不拆成多个重叠碎片」。该裁决出台语境=修旧版 94.4% 相邻重叠伪影（旧版每 3 段就开新中枢）。**Q2 与第 33 课 cap 的边界需重划**：若第 33 课成立，Q2 有效域收窄为「总段数 ≤8（或裁定阈值内）」。
- **seed 判据**：L0 = `center_from_segments`（完整判据：方向交替 + 三段交非空）；上级 = `center_from_window`（几何判据）。
- **几何事实**：延伸窗口内每段都触及核心 [ZD,ZG]（吸收条件），但窗口内**任意连续 3 段**：(i) 三段交可能为空（各自与核心相交≠两两相交非空）；(ii) 方向交替不保证（延伸吸收不检查方向）。⟹ 若切分后子窗口须复验 seed 判据，可能 build 失败产生游离段。

### Q-B 升级构造语义（核心裁量）
- **B-I（贪心 cap8）**：Step2 延伸吸收上限 5 段；第 9 段起照常从该段继续扫描 seed 新本级别中枢。后果：9~10 段窗口只产 1 个 8 段中枢 + 游离段，**不足以在上级 seed**（需 ≥3 个本级别单元重合）——实际升级门槛被推到 ~14 段（8+3+3），与第 33 课「9 段=高一级中枢」字面冲突。
- **B-II（≥9 逐 3 重切）**：Step2 照常吸收判定；当窗口总段数达 9 时，把整个窗口**重新解释**为每 3 段一个本级别中枢（9 段=恰 3 个；继续延伸时余数段作为末子中枢的延伸段吸收，满 3 段成新子中枢）。后果：9 段 → 3 个本级别中枢，两两 LevelExpansion（围绕同核心，外缘必重叠）→ 上级三单元区间交 ⊇ 原核心 ≠ ∅ → 上级 seed 必成立 → **升级经由塔现有 compose 路径自然涌现，零跨级注入**；42 段 → 14 个子中枢 → 上级吸收为一个 ≥9 段窗口 → 递归再升级（语义自相似）。字面精确实现第 33 课机制（「每3段构成一个中枢」）。
- **B-III(跨级注入)**：本级别保留单一延伸中枢，≥9 段时直接向 L+1 注入升级中枢。后果：破坏「上级中枢由上级 detect 单一来源」，与 L+1 自身链的排序/去重/增量协调复杂。
执行工位倾向 B-II（字面+塔递归贯通+无跨级注入），请裁定或否决。

### Q-C 子窗口 build 判据
若裁 B-II：3 段子窗口是否须复验 seed 判据（L0 方向交替+三段交非空）？
- C1：**不复验**——子中枢是「同一已成立中枢的重新解释」（第 33 课语义），区间=该 3 段的 [max lo, min hi]∩ 或几何构造，方向交替/三段交不再要求。风险：可能产出三段交为空的「中枢」（违反中枢原始定义——第 20 课注：「没有至少3个连续次级别走势类型重叠的部分是扩张不了高级别中枢的」）。
- C2：**复验**——失败的 3 段组不成子中枢（并入相邻子中枢作延伸段/游离）。风险：切分不整齐，9 段可能产 <3 个子中枢 → 升级不触发（回到 B-I 的门槛推迟问题）。
- C3：折中——子中枢核心取「3 段与原核心 [ZD,ZG] 的交」（每段都触核心 ⟹ 每段∩核心非空，但三段∩核心的公共交=核心∩三段交，仍可能空？注意每段都满足 lo≤ZG∧hi≥ZD ⟹ 每段与 [ZD,ZG] 相交，三段各自与核心的交集之交 = 三段交∩核心——不保证非空）。请从定义忠实度裁定。

### Q-D 第 20 课涨停反例与第 33 课的调和
第 20 课：「延伸无论多长不可能产生更大级别中枢」；第 33 课：「≥9 段构成更大级别中枢」。调和候选：
- D1：33 课是晚出的多义性消解约定，覆盖 20 课的概念性陈述（20 课语境=严格定义层，33 课=操作层约定）；实装采用 33 课。涨停例在段数口径下自洽：一字板不产生完成的次级别走势段，段数不增长，延伸只是时间延伸 ⟹ 不触发 9 段升级。
- D2：20 课为准，延伸永不升级，只有中心定理二（两中枢波动重叠）路径升级 ⟹ #148 应实装的是 LevelExpansion 关系 → 高级别中枢构造，而非段数阈值。后果：721 个长延伸窗口维持不消化；93.7% 残余重叠走 LevelExpansion 路径消化。
- D3：两路径并存实装（33 课段数升级 + 中心定理二 LevelExpansion 升级），各自触发条件不同。
