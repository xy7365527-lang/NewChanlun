```python
def block_boot_lcb(vals, n_boot=2000, block=10, alpha=0.05):
    if len(vals) < 3: return None
    b = min(block, len(vals)); n_blocks = max(1, len(vals)//b)
    means = []
    for _ in range(n_boot):
        sample = []
        for _ in range(n_blocks):
            start = random.randint(0, len(vals)-b)
            sample.extend(vals[start:start+b])
        means.append(statistics.mean(sample))
    means.sort()
    return means[int(alpha*len(means))]   # 95% 单边下界
```

**核心判定**

`候选 G=∅` 只能严格表述为：

`G_validated = ∅`：在当前 BTC L2 样本、当前三判据、当前实现下，没有任何 `(ℓ,q)` 被认证为可交易 alpha。

它不能严格表述为：

`G_alpha = ∅`：候选单元没有 alpha，或 ChatGPT 纲领已被经验真否证。

直接原因：

根本原因：
