## 事实核验（codex 独立验证行号）

### 事实1：类别轴已完整承载，未坍缩

`MuClass.i_class` 是 6-bit 不压扁的 `I_γ`（mu_estimator.rs:61 docstring；mu_estimator.rs:180/200 构造取 `bits.class_index()`）。位权重 `B1,B2,B3,S1,S2,S3 = 1,2,4,8,16,32`（types.rs:223）⟹ Long 侧纯 B2=0x02、纯 B3=0x04、B2+B3 共生=0x06，三者天然不同 μ̂ 桶。test「重合买卖点保留为不同 I_γ」（mu_estimator.rs:811-828）。`RawSignal` 同时携带完整 `z` 与 `trigger`（econ_positive.rs:241-261）。

**⟹ 下游今天即可从 z.i_class 区分纯 Type2 / 纯 Type3 / Type2+3 共生。类别信息从未丢失。**

### 事实2：Type2/Type3 base gate 谓词体逐字相同

`cand_delta_type2_completion`（econ_positive.rs:814）与 `cand_delta_type3_retest`（econ_positive.rs:833）函数体逐字相同：`lvl == 0 || descend_type1_anchor_depth(...).is_some()`。分派处（econ_positive.rs:873）Type2/Type3 分别调用但布尔等价。test `cand_delta_rung_dispatch`（econ_positive.rs:2025/2038）断言同 fixture 结果一致。保护边界（Type2=一类点极值 / Type3=中枢 ZG/ZD）由上游结构分类器置 bit 时强制，Cand 层不重门（#673-fix 裁决①：Type3「保护边界归属记录」而非「Cand 层重门」，双门=dead gate 信号集差 0，econ_positive.rs:830 docstring）。

**⟹ 共生点因优先级只走 Type2 path 是执行事实，但对 gate pass/reject 零差异。「Type3 几何谓词不评估」= #673-fix 已裁的 dead-gate 设计，非缺口。**

### 事实3：cand_channel 定义域=准入门通道，非买卖点类别

`NestTrigger` docstring 自述「Cand 门通道类型」（econ_positive.rs:1151）。枚举值按**准入门通道**分类（econ_positive.rs:1161）：Type1 背驰通道 / Type2·3 次级 Type1 下沉锚 / XZD / PanDiv——不是按买卖点类别。`MuClass.cand_channel` 字段 docstring 明确「本维承载的是门通道轴」（mu_estimator.rs:116）。`nest_trigger` 把 Type2/Type3 的 Nest 都映射为 `Type23SublevelType1`（econ_positive.rs:1178）。消费点（econ_positive.rs:4546 acc_nest_trigger_quality_probe）按四个 trigger 做质量归因，不按 Type2/Type3 类别还原。

**⟹ Type2 与 Type3 经同一 descend_type1_anchor_depth base gate 准入 ⟹ 同一通道 Type23SublevelType1 在通道语义下正确。**

## 裁决理由

`bsp_cand_type` 的坍缩只发生在 gate dispatcher 层；canonical 类别没坍缩，已在 `z.i_class`。`cand_channel=Type23SublevelType1` 不是 `cls_Θ({2,3})=2`（PDF 可选压缩），而是「经次级别 Type1 下沉锚这个准入门进入」。与 PDF 精神一致：

- **i_class 承载 I_γ**（PDF 买卖点2.pdf §2「更严格的做法是保留整个集合 I_γ，让仓位函数、优先级函数、风险函数读取它」）
- **cand_channel 承载准入 provenance**（正交轴，非 cls_Θ 类别压缩）
- 二者正交，无冗余

**(a) 有害**：把类别信息第二次塞进 cand_channel，增加 MuClass 桶键基数，把 i_class 已表达的方向/类别信息重复编码到第 10 维 = 共线维（project_iclass_delta_collinearity_perm_degeneracy 先例：类别维进桶键即毁置换检验）。

**(b) 非 bit-exact**：改变信号集基数；当前 seen-set 是 `(lvl, source_index, bsp_disc(bits))` 全掩码去重（econ_positive.rs:282/315），多路分派不是修命名，是改数据生成语义（seen-set 键 / 死门断言 / dx 对拍全域重算）。

## 边界条件（裁定翻转条件）

1. 若未来出现下游消费者**只能拿 cand_channel、拿不到 z.i_class/bsp_class**，且必须按 Type2/Type3 做不同交易/风控决策 → 可翻转，但**优先修接口传 i_class**，不污染通道轴。
2. 若未来 Type2/Type3 的 Cand 层 gate **真正分化**（谓词体不再逐字相同），且共生点语义要求「按每个 bit 独立 gate 后取并集/交集」→ 再讨论 (b)。

当前代码事实下，Task #176 = 伪缺口，谱系立条，无代码变更。
