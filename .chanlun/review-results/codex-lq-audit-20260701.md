## 结论（一句话）

**codex 否定成立，且翻转了负结论的认识论性质。** "候选 G=∅"**不是** ChatGPT 纲领在 BTC L2 上被
**经验证伪**，而是**判据3（LCB_OOS）功效不足导致的未认证（inconclusive）**——`LCB_OOS ≤ 0` 只表示
"未能以 95% 下界排除 0"，其补集**不能推出 μ≤0**。把 `LCB_OOS ≤ 0` 当作 μ 非正的否证是负结论最脆弱点。
下游命题应标 **"待验"（未认证）而非"证伪"**。正确标注：`G_validated = ∅ under raw-pnl single-split criterion`。

## codex 定量功效判据（核心武器——审查者复核通过）

近似正态下，OOS 95% 单边下界转正的样本需求（CV=σ/μ，单笔）：
```
LCB > 0  ⟺  μ − 1.645·σ/√n_eff > 0  ⟺  n_eff > (1.645·CV)²
```

| CV | LCB 转正约需 n_eff（50%功效）| 80%功效 | 90%功效 |
|---:|---:|---:|---:|
| 10 | 271 | 618 | 856 |
| 15 | 609 | 1391 | 1927 |
| 20 | 1082 | 2473 | 3426 |

对照各单元 OOS 段（约全样本 30%）实际 n：

| 单元 | OOS n(≈30%) | 相对 (1.645·CV)² 门槛 | 判定 |
|------|------|------|------|
| L0,−1 | ~1085 | CV=10 够/CV=20 不够 | **需补 μ_oos/σ_oos/n_eff 才能定** |
| L0,+1 | ~2259 | CV≤15 够 | **需补 CV_oos 才能定** |
| L1,−1 | ~130 | 远低于 271 | **明确 underpowered** |
| L1,+1 | ~188 | 远低于 271 | **明确 underpowered** |
| L2,−1 | ~38 | 远低于 271 | **明确 underpowered** |
| L2,+1 | ~59 | 远低于 271 | **明确 underpowered** |

**审查者复核**：`n_eff > (1.645·CV)²` 是标准正态近似（1.645=95% 单边 z），推导正确。CV=10-20 由报告
自己给出（"单笔 pnl 标准差是均值 10-20 倍"）。L1/L2 的 OOS n（38-188）**远低于** CV=10 时的最低门槛 271
→ 即使真 μ>0，判据3 也几乎不可能让 LCB>0。**L1/L2 的 `LCB<0` 不构成否证，是判据无检出力的必然结果**。

## 逐质疑判定（codex 否定 + 审查者质询）

### 质疑1（最关键）：判据3 是否 underpowered → **成立（CRITICAL）**

codex 否定：`LCB_OOS > 0` 是**高置信认证门槛**，不是有效的**反证门槛**。补集 `LCB_OOS ≤ 0` 在
CV=10-20 时需要很大有效样本才有检出力（见上表）。L1/L2 明确 underpowered；L0 不能简单说"必然深负"
（OOS n≈1085-2259），其深负更像 OOS regime 变差/CV 实际更高/自相关厚尾压低 n_eff，需补 μ_oos/σ_oos/n_eff。

审查者质询：
- **codex 误读上下文？** 否。功效表基于报告明确给的 CV 和 n，正态近似推导正确。
- **已被报告覆盖？** 部分——报告把 L3+（n<30）标 INCONCL，但**门槛画错位置**：报告把 L0/L1/L2（n≥30）
  的 `LCB<0` 当"修复后否证"（结论段"不是确认而是否证"），而真门槛是 `n_eff vs (1.645·CV)²`，
  按此 L1/L2 也在 underpowered 区。报告的 `n<30` 阈值是任意的，不是功效导出的。
- **严重性合理？** CRITICAL——它决定 667 命题②是"证伪"还是"待验"。**动摇负结论的性质**。

### 质疑2：pnl 尺度 vs 夏普 → **成立（定义变更，须另列）**

codex 否定：原始 pnl 尺度非风险归一，混入价格水平/波动率/持仓期方差。Sharpe/R-multiple 可能翻转结论——
**但那是定义变更，必须另列为"归一化尺度检验"**，不能默认替换。

审查者质询：成立。报告边界条件1 自认这一点。**动摇**："候选 G=∅"是**原始 pnl 尺度这一具体判据**的产物，
非"级别×上级方向无结构"的普适结论。审查者补充（no-workaround）：夏普是**新判据**，不是修补——须作为独立
L2 检验另跑，不能在同一报告里"改尺度救活"充当已验证。

### 质疑3：单一 70/30 切分 → **成立**

codex 否定：单切分只说明"一个后验时段未认证"，不代表时序稳定性。应做 walk-forward。
审查者质询：成立。**动摇**：单切分 OOS 下界代表性不足，多窗某窗可能翻正。

### 质疑4：判据1 稳固 vs 判据3 否决的张力 → **成立**

codex 否定：更合理表述是"样本内信号存在，但 OOS 稳定性未通过认证/可能 regime 依赖"，**不是"无 alpha"**。
审查者质询：成立。与 [[project_oddeven_mu_identity]]（μ̂ 逆上级更赚样本内稳固 vs OOS 深负）同源——
"逆上级短差"是**真实但 OOS 未认证/可能 regime 依赖**的信号，非"无 alpha"。

### 质疑5：θ(ℓ) 代理跳过 → **跳过合理（不动摇）**

codex 判定：本级/父级平均持有期比是粗代理，**不等于**父级 Move 生命期中的真 θ；**不能否定 ℓ*≈3**，
只能说当前代理不足。审查者认同：工位诚实标跳过符合 no-workaround（不硬凑单调）。ℓ*≈3 留 tower Move 生命期后续，**中性**。

## 分类判定：这不是实现错误，是定义/解释冲突

codex 明确：`block_boot_lcb` 本身正确实现了"原始 pnl 均值的 95% bootstrap 下界"，**非实现 bug**。

真正冲突（testing-override 判据：修复需改判据含义 → 定义冲突）：
- **A（三判据定义，纲领第72节）**：`LCB_OOS > 0` 是可交易 alpha 的**必要条件**；不过则排除出 G。这是**二值认证规则**。
- **B（统计推断）**：`LCB_OOS ≤ 0` 只是"未认证为正"，**不是"已证明非正"**；低功效时应标 inconclusive。这要求**三值状态**（validated / negative-evidence / inconclusive）。

**不可弥合点**：A 是二值，B 要求三值。不改报告语义就无法同时满足"不过判据即非 alpha"与"低功效不过判据不构成否证"。

**审查者裁定**：此冲突**不改任何定义含义**——纲领的三判据作为"认证规则"依然成立，冲突在于**报告把"未通过认证"
误标为"经验证伪"**。修正是**标注层**的（把 `G_alpha=∅` 改为 `G_validated=∅ under raw-pnl single-split`），
工位可自行修正，**不触发 escalate**。若要真否证，须给出 OOS `UCB ≤ 0`（上界证伪）或针对最小经济均值的
**有功效反证检验**，并在多窗 walk-forward 稳定成立。

## 边界条件（本审查结论翻转条件）

1. **补 OOS 统计量**：若为 L0 补出 μ_oos/σ_oos/CV_oos/n_eff/自相关，证明 CV_oos 确实 >20 或自相关压低
   n_eff 至门槛下 → L0 也归 underpowered，全网格 inconclusive；若 CV_oos≤10 且 n_eff≈1000+ 仍 LCB 深负
   → L0 是真 OOS 泛化失败（真否证），负结论对 L0 成立。
2. **多窗 walk-forward**：若多窗一致 LCB<0 → 稳定性否负加强；若某窗翻正 → inconclusive 加强。
3. **有功效反证检验**：若补 OOS UCB≤0 或最小经济均值反证且多窗稳定 → "证伪"成立，命题②可标证伪。
