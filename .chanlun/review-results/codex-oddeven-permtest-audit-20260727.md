## 攻击点 1：置换对象与注释声明不符（决定性）

`:254` 注释声明「保持每条信号 entry/出场/持有期/成本 + 买卖总数，只 shuffle δ」。

但 `:273` 用打乱后的 δ 重新调用 `pnl_next_reverse`，而该函数（`:150-159`）的出场是这样找的：

```rust
let opp = -delta;
let Some(&(exit_bar, ..)) = sig[idx + 1..].iter().find(|(eb, d, ..)| *eb > entry_bar && *d == opp) else { continue };
```

出场 = 往后找第一个**方向相反**的信号。δ 一变，随之全变：

- 出场 bar 与持有期
- 出场价格与成本
- **样本构成** —— 找不到出场的交易被 `else { continue }` 直接丢出样本

⟹ 承诺的控制变量一个都没实现。这不是"只扰动方向标签"，是同时扰动了交易窗口、成本、样本集合。

附带：`:260/270-272` 是跨全部级别、全部时间的**全局**打乱，只保持买卖总数，不保持各级别或各 regime 内的方向构成。

即便这些量真能固定，标签置换也只检验「δ 与固定窗口收益的关联」——几何信息仍可能留在 entry/level 中，beta 也可能通过时间/regime 与 δ 相关。**A 与 C 依然不能被唯一分开。**

## 攻击点 2：统计量对要检验的命题是瞎的（决定性）

`:256-258` 的统计量：

```rust
let s_stat = |b| b.values().filter(|(n, _)| *n > 0).map(|(n, s)| (s / *n as f64).abs()).sum();
```

即 `S = Σ_桶 |μ̂(ℓ,δ)|`。

而要检验的现象，代码自己在 `:232` 写得清清楚楚：**`sign μ̂(ℓ,δ) = sign(δ·(−1)^ℓ)`** —— 整个命题是关于**符号**的。

`.abs()` 把符号抹掉了。完美奇偶交替与所有级别同号，只要各桶绝对均值相同，**S 完全相同**。

它对什么敏感：任何桶均值幅度 —— 包括 beta 漂移、成本、异常值、持有期变化、小样本噪声；且各桶等权，小桶与大桶贡献相同。

⟹ 它至多是「桶均值总幅度」统计量，不是机制 A 的专门统计量。

## 攻击点 3：从不显著推出机制 C，推理形式错误

`:275-276` 的 p 值只说明：在这个置换分布与这个 S 下，观测值并不异常偏大。

「不显著」= 未拒绝该交换性零假设，**不能推出零假设为真**，更不能推出特定成因就是 beta 漂移。也不能据此证伪 A —— 可能是统计量不对题、功效不足、几何信息未被置换掉，或 A/C 并存。

⟹ `:280` 的「高 p ⇒ 机制 C」不成立。附带：`0.69` 本身也不是该行所写的「≈1」。

## 攻击点 4：置换实现（次要，不影响结论）

**正确的部分**：Fisher–Yates 循环边界与交换范围正确（`k=n−1…1`，`j∈[0,k]`）；固定种子用于复现没有问题；每轮从原始 `deltas` 重建；`(+1)/(n_perm+1)` 修正正确。

**两点瑕疵**（非致命）：

- `n_perm=200` ⟹ p 值分辨率仅 `1/201≈0.005`；在 `p≈0.69` 处蒙特卡洛标准误约 `0.033`
- `:262-264` 用 31 位 LCG 输出直接 `% m`，存在模偏差 ⟹ 非严格均匀置换
