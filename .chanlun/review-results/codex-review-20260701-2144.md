## Response

判决：**假消除**。  
未背驰破中枢候选只进入了 `Classification.levels[k].bsp`，但在 `assemble_gamma -> decompose_capturable_spread` 的样本路径上被 `Flat` 过滤掉；`StructBreakFeature` 又没有传到回测样本层。因此 μ̂ 回测样本仍看不到这些候选，选择偏差没有在目标层消除。

- **问题**：MACD gate 只是从 `judge_first_cached` 移到了 `Flat` 过滤处，样本层偏差仍存在  
  **位置**：`interp.rs:205-210`，`interp.rs:163-202`，`econ_positive.rs:257-268`  
  **严重性**：致命  
  **修复建议**：不要用零 bit `BspPoint -> Flat Candidate -> continue` 表达 feature-only 候选。应把结构破中枢候选作为独立样本维度传入回测，或让 `decompose_capturable_spread` 能计入 `StructBreakFeature` 的结构候选 denominator，再仅用 `macd_c_lt_a` 作为解释变量/特征，而不是执行过滤条件。

- **问题**：`StructBreakFeature` 是不可达 sidecar，生产路径丢弃后无法影响样本  
  **位置**：`signal.rs:512-513`，`mod.rs classify` 调用链  
  **严重性**：重要  
  **修复建议**：将 features 显式纳入 `Classification` 或回测输入结构；否则不要声称 gate→feature 已在回测层生效。

- **问题**：零 bit `BspPoint` 改变了 `BspPoint` 序列内容，不是 bit-exact 隔离  
  **位置**：`signal.rs:324`  
  **严重性**：重要  
  **修复建议**：如果要求旧 `BspPoint` 语义不变，未背驰结构候选不能塞进 `bsp`；应放独立 collection。若允许改变，则测试必须覆盖长度、排序、序列化、迭代消费方，而不是只看 non-Flat 样本。

- **问题**：MACD 区间映射失败仍然 `return None`，feature 计算失败继续充当结构候选 veto  
  **位置**：`signal.rs:271-325`  
  **严重性**：重要  
  **修复建议**：结构候选已成立时，MACD 映射失败应产出候选并记录 `macd_c_lt_a: None` 或等价 unknown；买卖点 bit 只在 `Some(true)` 时置位。

- **问题**：`buy1/sell1` 仍由 MACD 面积背驰近似直接置位，定义忠实度不足  
  **位置**：`signal.rs:271-325`  
  **严重性**：重要  
  **修复建议**：若 `buy1/sell1` 表示缠论第一类买卖点，必须引入走势力度判据；否则重命名为 MACD 辅助信号，避免把辅助指标当定义判据。

- **问题**：审计测试复用了生产过滤，不能证明选择偏差消除
