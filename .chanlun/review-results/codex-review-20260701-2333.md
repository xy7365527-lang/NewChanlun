### interp.rs：candidate_dir（关键函数）

```rust
/// 候选方向 σ_g（root_sel 镜像反对称消歧）：买侧→Long、卖侧→Short、双侧/空→Flat（不可交易）。
///
/// 完全无方向（`!conf_plus() && !conf_minus()`——严格零 bit，**不是** `root_sel(...)==Flat`）且
/// `struct_break_dir=Some(s)` 时，用破中枢结构方向 s 恢复方向。
///
/// ★护栏1 严格性：`root_sel` 对 `(1,1)` 双触发也返回 `Flat`。若用 `root_sel(...)==Flat` 作
/// 回退条件，则双触发冲突候选会被 struct_break_dir 误改向。
/// 严格零 bit `!conf_plus() && !conf_minus()` 只匹配 `(0,0)` 真无方向，排除 `(1,1)` 冲突。
///
/// bit-exact：`struct_break_dir` 不进 `class_index()`/`MuClass`/桶 key。
fn candidate_dir(point: &BspPoint) -> VoiceSide {
    let bits = &point.bits;
    let base = root_sel(RootCandidates {
        long_trigger: bits.conf_plus(),
        short_trigger: bits.conf_minus(),
    });
    if !bits.conf_plus() && !bits.conf_minus() {
        if let Some(side) = point.struct_break_dir {
            return match side {
                Side::Long => VoiceSide::Long,
                Side::Short => VoiceSide::Short,
            };
        }
    }
    base
}
```

## Response

基于你给出的片段审查；本地工作区为空，codebase-memory MCP 调用被取消，所以不能独立跑全仓定位。

- **问题**：`struct_break_dir` 同时承担“结构破坏方向元数据”和“零 bit 候选可恢复为可交易方向”的权限。`candidate_dir` 只检查 `!conf_plus() && !conf_minus()`，不检查零 bit 的原因是否确为 `C>=A` MACD 预删。因此只要未来某条构造路径给零 bit 点填了 `struct_break_dir=Some(_)`，就会被提升为 Long/Short 并进入 μ 样本。这不是当前片段必然 bug，但恢复资格没有被类型或字段显式表达，安全性依赖所有构造点的外部约束。
- **位置**：`interp.rs:candidate_dir`；`signal.rs:judge_first_cached`
- **严重性**：重要
- **修复建议**：把字段拆开，保留 `struct_break_dir` 作为结构方向元数据，另加显式恢复资格，例如 `dir_recovery: Option<RecoveryReason::MacdCGeA>` 或在构造处只对确认为 `C>=A` 的候选设置 `recover_dir_from_struct_break=true`。`candidate_dir` 应检查该资格，而不是仅凭 `struct_break_dir`。

- **问题**：GOLDEN 更新不能单独作为 bit-exact 证据。若 GOLDEN 是基于 `derive(Debug)` 字符串，新增 `struct_break_dir` 后哈希变化确实可以解释为 Debug 扩展，但这个 oracle 已经混入非六 bit 字段。它只能证明快照变化被接受，不能证明 MuClass/class_index bit-exact。
- **位置**：GOLDEN fixture / Debug-hash 测试
- **严重性**：建议
- **修复建议**：保留 Debug GOLDEN 可以，但另建只序列化 `BspBits` / `class_index()` / `MuClass` 六维 key 的 bit-exact GOLDEN。现有逐案 `extract_signals_bit_exact_vs_orig_per_case` 是必要的，建议让它成为主验收，而不是 Debug hash。

其余结论：

Q1：`candidate_dir` 的严格零 bit 判断能防住 `(1,1)` 双触发被 `struct_break_dir` 误改向；`struct_break_dir` 不进 `class_index/MuClass` 这一点在设计上成立，前提是确如上下文所说 `class_index()` 只读六 bit。

Q2：方向恢复到 μ 采样的链路在片段层面闭合：`assemble_gamma_with_tower` → `candidate_dir` → 非 Flat → 不被 Flat 过滤 → `signals.push`。声明必须收窄为“几何门通过且 A/C 可配对候选的 MACD C>=A 预删偏差消除”，不能说是 `Γ_struct` 全量或 canonical 力度层完成。

Q3：接受分层验收，但只能条件通过。R2 可以闭合“结构方向恢复/消 MACD 预删偏差”；WeakTheta / ForceState 支配序未接通不应阻塞 R2。反过来，任何声称“buy1 已按 canonical 力度判据完成选择偏差消除”的表述都应拒绝，必须落到 #42。
