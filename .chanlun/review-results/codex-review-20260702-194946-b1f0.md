## 2. 维度一：候选类型 τ 的分划

### 2.1 判别函数（布尔级精确条件）

```
bsp_cand_type(b, δ):
  match δ:
    Long  => if b.buy1 then T1 elif b.buy2 then T2 else T3
    Short => if b.sell1 then T1 elif b.sell2 then T2 else T3
```
（`econ_positive.rs:588-609`，逐字）

谓词形式（δ=Long 侧；Short 对偶）:
- `τ=T1 ⟺ buy1`
- `τ=T2 ⟺ ¬buy1 ∧ buy2`
- `τ=T3 ⟺ ¬buy1 ∧ ¬buy2`   （**注意: 无 `buy3` 前件——else 兜底**）

### 2.2 引理 τ-EX（两两互斥）— L0

**命题**: ∀x, τ(x) 取 {T1,T2,T3} 中恰一值 ⟹ `τ⁻¹(T1), τ⁻¹(T2), τ⁻¹(T3)` 两两交空。

**证明**（谓词逻辑级）: 固定 δ=Long（Short 对偶）。三谓词的合取:
- `T1 ∧ T2 = buy1 ∧ (¬buy1 ∧ buy2) = ⊥`（buy1 ∧ ¬buy1）
- `T1 ∧ T3 = buy1 ∧ (¬buy1 ∧ ¬buy2) = ⊥`
- `T2 ∧ T3 = (¬buy1 ∧ buy2) ∧ (¬buy1 ∧ ¬buy2) = ⊥`（buy2 ∧ ¬buy2）

三对合取恒 ⊥ ⟹ 纤维两两交空。等价地: `match`/`if-elif-else` 从恰一臂返回，函数单值 ⟹ 互斥。∎

### 2.3 引理 τ-CO（完备覆盖）— L0

**命题**: τ 是全函数 ⟹ `τ⁻¹(T1) ∪ τ⁻¹(T2) ∪ τ⁻¹(T3) = X`。

**证明**: `match δ` 对 `{Long,Short}` 穷尽（Side 只有两值，`types.rs` Side 枚举）；每臂 `if-elif-else` 的 else **无卫词** ⟹ 覆盖所有不满足 buy1/buy2（resp sell1/sell2）的 b。三谓词析取:
`buy1 ∨ (¬buy1 ∧ buy2) ∨ (¬buy1 ∧ ¬buy2) ≡ ⊤`（真值表穷举 buy1,buy2 四组合全覆盖）。∴ 全函数。∎

**推论（τ 分划）**: τ-EX ∧ τ-CO ⟹ `{τ⁻¹(t)}_{t∈{T1,T2,T3}}` 是 X 的分划。

### 2.4 纤维语义缺口 G1 + G2（L2 可证伪）

**G1（兜底纤维语义错配）**: `τ⁻¹(T3) = {x : (δ=Long ∧ ¬buy1 ∧ ¬buy2) ∨ (δ=Short ∧ ¬sell1 ∧ ¬sell2)}`。**无 `buy3`/`sell3` 前件** ⟹ T3 纤维 ⊋ {真三类买卖点}。特别地: 若 §1.1 的 δ/b 不对齐发生（δ=Long ∧ b 仅 sell 位），该 x 落 T3 却不含任何买点。
- **分划不破**（τ 仍单值函数）；
- **可证伪的是语义断言**「T3 纤维 = 三类点集」: 枚举真实信号，检验 δ 是否曾与 b 置位侧不对齐。**找到即证伪该语义断言**（T3 沦为 garbage-collector 类）。
- 减轻假设（未证）: 若 `assemble_gamma` 的 dir 恒与 b 的主置位侧对齐，则 G1 不激活——此假设本文件 L0 未追踪到保证，**列为开放可证伪候选**。
- 溯源: `maimai.md:170`「六买卖点可同点重合」+ PDF4 §行为等价（纤维须对应行为类）。

**G2（2B/3B 共生坍缩 = PDF4 行为商 Q 跑偏）**: `BspBits` 非互斥（`types.rs:170-171` 注释「一个点可同时是 [2B,3B]」；P4§5 line 233「不要求六买卖点互斥」）。τ 按优先级 buy2>buy3 坍缩 ⟹ `[2B]` 与 `[2B,3B]` **同映 T2**，走同一 `cand_delta` 路径（`:682` Type2/Type3 分支）⟹ 门不可区分，但二者 Obs 差一个 buy3 位。
- PDF4《行为同余商》§行为商 Q=X/~_b:「任意合法重组后 Obs 一致 ⟹ 等价」。把 Obs 可区分的 `[2B]`/`[2B,3B]` 并入同纤维 = **粗粒化不保行为 ⟹ Q 跑偏**（PDF4 §风险，精确命中）。
- **可证伪**: 若下游（gate pass / 交易判断）在 buy3 与 buy2 共置时**可证不同**，则坍缩丢失可交易结构。此为 673 号 over-filtering 的镜像（673=谓词范围误用致假阴性；G2=坍缩致信息丢失）。
- 认识论: L0 坍缩结构确定；行为差异 = L2 未测。

seen-key κ 含 ℓ（`:266`）⟹ **同一 pivot `s` 可在多个 ℓ 生成不同对象**（不同 (ℓ,s,·) 键各入 seen）。故:
- 「每个候选对象恰属一 λ 类」**真**（对象=信号元组）；
- 「每个 pivot 恰属一级别」**假**（pivot 跨级）。
- **定义域澄清**: 本证明的对象空间 X = 信号元组（§1.1），非 L0 pivot。在此定义下 λ 分划成立。若下游把"对象"理解为 pivot，则 λ 唯一性不成立——须显式声明对象粒度。

### 4.3 G6（lvl==0 免门 ⟹ 通道退化）

`cand_delta_type2/3_completion` 在 `lvl==0` 无条件返回 true（`:647/:666` 免门；docstring `:638-639`「无次级别递归底 ⟹ Type2@level0 不误拒」）⟹ λ=0 时 T2/T3 恒走 Nest（若执行段∃），**永不 Xzd**。又 `XzdEvidence.level ≥1`（`:827` 不变量）。故:
- `(T2/T3, Xzd, 0) = ∅`（结构空胞）。
- 分划不破（这些对象归 Nest）；通道维在递归底退化。免门是设计选择（非几何确认），诚实标注。

## 5. 组合分划定理

### 5.1 定理（Φ 分划）— L0

**命题**: `Φ = (τ, γ, λ) : X → {T1,T2,T3} × {Nest,Xzd,Reject} × ℕ` 是全函数，其纤维 `{Φ⁻¹(t,c,l)}` 构成 X 的分划。

**证明**:
- **存在性（完备覆盖）**: τ（τ-CO §2.3）、γ（γ-CO §3.2）、λ（§4.1）各为全函数 ⟹ 积映射 Φ 处处有定义 ⟹ ∀x, x∈Φ⁻¹(Φ(x)) ⟹ `⋃_{(t,c,l)} Φ⁻¹(t,c,l) = X`。
- **唯一性（两两互斥）**: Φ 是三个单值函数的积 ⟹ 单值 ⟹ x 的像唯一 ⟹ x 落恰一纤维 ⟹ 纤维两两交空。
∎

**认识论 L0（零信息增量）**: 此证明是"全函数的联合纤维必分划"的实例，纯代数、同义反复（231/formalization-validity-domain: L0→L1 信息增量为零）。它**不**证明纤维对应缠论定义——那是 §2.4/§3.4 的 L2 缺口。

### 5.2 直积退化（im(Φ) ⊊ 全格；230 号镜像）

分划成立，但 Φ 的**像是稀疏的**——若干积胞结构性为空:

| 空胞 | 依据 | 代码锚 |
|------|------|--------|
| `(T1, Xzd, ·) = ∅` | T1 nest 失败 ⟹ Reject，永不 Xzd | `:1015` |
| `(T2/T3, Xzd, 0) = ∅` | lvl==0 免门恒 Nest（G6） | `:647/:666/:827` |
| `(·, Xzd, 0) = ∅` | `XzdEvidence.level≥1` 不变量 | `:827` |

**结论**: 三维度**非正交/非独立**——通道 γ 条件依赖 τ 与 λ（T1 决定不入 Xzd；λ=0 决定不入 Xzd）。「全部胞非空」**不**是分划的必要条件（空胞仍是合法分划块）。故分划成立 ∧ 直积结构退化，二者不矛盾。此为 230 号「直积在定义域代数成立、有效域退化<自由度」在分类空间的镜像: 定义域 = 3×3×ℕ 全格，有效域（真实现的胞）严格更小。

> 引用: 230 号（直积退化）；`formalization-validity-domain.md`（有效域 ≠ 定义域）。

### 5.3 「pass/fail」不等于「通道」（下游澄清）

γ 在 `build_gate_certificate` 时赋值；信号是否真通过门是**独立谓词**: `Nest ⟹ n_delta()` 可仍 false（`:314`），`Xzd ⟹ gate_pass()` 可仍 false（`:315`，C2 不成立）。故:
- 「对象的通道类」= build variant（本证明的 γ）——分划成立。
- 「对象是否入信号集」= γ ∧ (n_delta ∨ gate_pass) 的合取——**不是**分划维度，是过滤谓词。
若下游把"分类"误当"通过/否"，须加第四谓词 `pass`，且 pass 不参与分划（它切每个通道纤维成 pass/reject 两半，是细化非新维度）。

# 相关缠论定义（用于纤维语义对齐判断，G1/G2 相关）

## 三类买卖点定义（书中版本）

- 第一类买点：某级别下跌趋势中，次级别走势向下跌破最后一个中枢后形成的**背驰点**
- 第一类卖点：某级别上涨趋势中，次级别走势向上突破最后一个中枢后形成的**背驰点**
- 第二类买点：第一类买点后，次级别上涨结束，再次下跌的那个次级别走势的结束点
- 第二类卖点：第一类卖点后，次级别下跌结束，再次上涨的那个次级别走势的结束点
- 第三类买点：上涨趋势中，次级别走势向上离开中枢后，次级别回抽低点**不跌破 ZG** 的中枢终结点
- 第三类卖点：下跌趋势中，次级别走势向下离开中枢后，次级别回抽高点**不升破 ZD** 的中枢终结点

关键定律/定理：
- 买卖点定律一：任何级别的第二类买卖点都由次级别相应走势的第一类买卖点构成
- 买卖点完备性定理：市场必然产生赢利买卖点，只有第一、二、三类
- 升跌完备性定理：市场中任何向上/向下，都必然从三类买卖点之一开始并结束

## 买卖点互斥/重合关系（maimai.md）

| 买点对 | 是否可能重合 | 说明 |
|--------|-------------|------|
| 1B 与 2B | **不可能** | 时间上前后出现 |
| 1B 与 3B | **不可能** | 1B在中枢下方，3B在中枢上方 |
| 2B 与 3B | **可以重合** | 当1B后凌厉上破最后一个中枢、且回抽不触及该中枢时 |

卖点的互斥/重合关系对称。

**关键点**：原文承认 2B/3B 可重合，但**没有承认 1B 与 T3-谓词失败的组合可以脱离"三类点"语义**——
即原文的三类买卖点定义是穷尽性的（"只有第一二三类"），G1 质疑的正是代码里 `bsp_cand_type` 的
Type3 else 分支是否会把"既非 1B 也非 2B 也非 3B"（即根本不是买卖点，δ/b 不对齐产生的伪对象）的
输入也归入 T3 标签——如果这种输入在实际信号流中根本不可能出现（因为 δ 与 b 恒对齐），则 G1 是
空担忧；如果确实可能出现，则 T3 标签被"污染"为兜底垃圾桶。
