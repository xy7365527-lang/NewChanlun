### 2. P0 缺维接入设计稿

P0 是把已算出的 role/σ_p 接入 `econ_positive.rs` alpha 回测的信号元组 + 分桶键，使回测状态从 Y 升到 Z。

#### 2.1 判别函数来源（复用，不重写）

#### 2.2 接入点（最小 diff，复用既有类型）

`econ_positive.rs` 两处：
1. `collect_signals`（`222`）signal 元组扩展：现元组 `(usize, VoiceSide, usize, u32, i8, u8)` → 加 `parent_dir:i8` + `position`（或直接携带 `OperationRole`）。`291` 处 `for c in &assemble_gamma_with_tower(...)` 已有 `c.role`，按 `selector.rs:150` 同一 match 算 `parent_dir`。
2. 分桶键升级：所有 `(d.level, d.delta, d.bsp_class)` 三元键（`2070/2318/2729/2823` 等）→ 改用 `MuClass::from_certificate(...)` 作 key（`MuClass` 已 `Eq+Hash`，`mu_estimator.rs:68`）。推荐方案 (a)：直接以 `MuClass` 为桶键（canonical z）。

**降维分叉**：细化桶键→每桶样本降→winner's curse。原文药方 `ϕ:Z→U`（`mu_estimator.rs:161 project_to_u`）已实装。接入后若高维 z 桶稀疏，回测统计层走 `UClass` 折叠——这条路径已存在，接入 z 桶键不需新建降维，只需在 alpha 聚合处二选一（Z 桶=oracle alpha 上界 / U 桶=抗过拟合估计）。

#### 2.3 H 轴是否进 z（选择类，明确上浮 codex 裁定）

`MuClass` 现含 V 轴（parent_dir/short_swing/position）但不含 H 轴。原文 R(g)=18 类含 H，故严格补维应把 H 进 z。但：
- 补 H 进 z 论据：原文 18 类完全分类含 H；细分类优势定理——补维不降 oracle alpha。
- 不补 H 论据：H（同级前兄弟顺/反）是结构关系非操作极性，UClass 降维本就把 role 折叠掉 H；补 H 使 |Z| ×3，加剧稀疏；H 对 μ 的贡献 spec 未给 L2 证据（`coverage.rs:796` 明标"18 类经验全可达性 spec 未覆盖"）。

设计稿建议：P0 先接入 V 轴+σ_p（已在 z，零结构改动）；H 轴进 z 作为独立决策交 codex 裁。若裁定补，H 进 `MuClass` 加一字段 `horizontal:Horizontal`，`from_certificate` 加参，桶键自动升 54 类（3H×3V×2δ×|I_γ|×|ℓ|）。

#### 2.4 与既有 GateCertificate / BspCandType 关系

正交，不冲突。`GateCertificate` 是准入门（成交与否），role/σ_p 是状态分类维（成交后按哪个 z 桶记 alpha）。

#### 2.5 dx 守恒式扩展

`econ_positive.rs` 有"captured 分解恒等式"（`2292`）与 per-bucket Σpnl 一致性断言。桶键从 Y 细化到 Z 是分划细化（partition refinement）：Z 桶是 Y 桶的不相交细分（同一 (ℓ,δ,I_γ) 按 σ_p 再分）。
- 逐笔 dx 守恒不变：`captured 分解恒等式`是逐笔恒等式，与分桶无关。
- 聚合守恒扩展：`Σ_{Y桶} pnl` 断言 → 扩展为 `Σ_{Z桶} pnl == Σ_{Y桶} pnl`（分划细化的求和守恒）。

/// 候选 γ (Candidate) → 全互斥分类 z (MuClass)（§16 z 六维）的桥接。
/// Candidate 已带 level/dir(δ_g)/bits(I_γ)/role(R(g)=(H,V,δ))。z 的 parent_dir σ_p 与
/// position 仓位态从 role.v (Vertical) 推：
/// - Ambient（σ_p=0，去根化无父）⟹ position=Root，parent_dir=0。
/// - FollowParent（δ_g=σ_p，顺父）⟹ position=Child，parent_dir=δ_g（同向）。
/// - ShortDiff（δ_g=−σ_p，短差）⟹ position=Child，parent_dir=−δ_g（反向）。
pub fn z_of_candidate(c: &Candidate) -> MuClass {
    let delta: i8 = match c.dir {
        VoiceSide::Long => 1,
        VoiceSide::Short => -1,
        VoiceSide::Flat => 1, // Flat 不可交易候选，δ 占位
    };
    let (parent_dir, position) = match c.role.v {
        Vertical::Ambient => (0, PositionState::Root),
        Vertical::FollowParent => (delta, PositionState::Child), // σ_p = δ_g
        Vertical::ShortDiff => (-delta, PositionState::Child),   // σ_p = −δ_g
    };
    MuClass::from_certificate(c.level, delta, c.bits, parent_dir, position)
}

# 原文权威定义（docs/formal-chain/，三级权威链第1级——最严格起点）

## A. `递归完全分类买卖点.pdf` §7.1/§7.2/§8（H/V/R(g) 18 类完全互斥，唯一性定理条件之一）

> **7.1 水平关系：同级别兄弟关系**
> 设候选事件 g 所在级别为 ℓ_g，其父容器为 p(g)∈C_{ℓg+1}。在同一父容器下，令前一个同级别兄弟为 prev(g)。如果不存在，则记为 prev(g)=∅。
> 定义水平关系：
> H(g) = First，若 prev(g)=∅；SameFollow，若 prev(g)≠∅ ∧ δ_g=σ_{prev(g)}；SameReverse，若 prev(g)≠∅ ∧ δ_g=−σ_{prev(g)}。
> 这三类互斥且穷尽。证明：要么没有前一个兄弟；要么有前一个兄弟，若有，则因为 δ_g,σ_{prev(g)}∈{+1,−1}，必且仅有 δ_g=σ_{prev(g)} 或 δ_g=−σ_{prev(g)}。所以 Σ_h 1[H(g)=h]=1。
>
> **7.2 垂直关系：相对父容器的关系**
> 父容器方向为 σ_{p(g)}∈{−1,0,+1}，其中 0=父容器尚未有方向，或处于胚元/空状态。
> 定义垂直关系：V(g)=Ambient 若 σ_{p(g)}=0；FollowParent 若 σ_{p(g)}≠0 ∧ δ_g=σ_{p(g)}；ShortDiff 若 σ_{p(g)}≠0 ∧ δ_g=−σ_{p(g)}。
>
> **唯一性定理的必要条件之一**：「5. 水平关系 H(g) 唯一；6. 垂直关系 V(g) 唯一；7. 角色 R(g)=(H,V,δ) 唯一」——由 5 和 6，每个候选事件的水平关系和垂直关系唯一；由 7，每个候选事件的完整角色唯一。
>
> **分类不是 {根、同级别、次级别}，而是 水平关系×垂直关系×方向，即 R(g)=(H(g),V(g),δ_g)。其中 H(g)∈{First,SameFollow,SameReverse}，V(g)∈{Ambient,FollowParent,ShortDiff}，δ_g∈{+1,−1}。这三轴形成严格互斥完全分类：Σ_{r∈R} 1[R(g)=r]=1。**
> 短差统一定义为：V(g)=ShortDiff ⟺ σ_{p(g)}≠0 ∧ δ_g=−σ_{p(g)}。所以父多则短差为空，父空则短差为多。而所谓"根方向"被消去，改成 V(g)=Ambient，它只是父容器无方向的普通情形，可以出现在任意级别。

## B. `推导完全分类.pdf`（细分类优势定理，z 状态向量定义——**注意 r 的定义与 A 不同**）

> 令粗状态为 Y_t=(I_γ,δ)，只包含买卖方向和三类买卖点集合。
> 令细状态为 **Z_t=(ℓ,δ,I_γ,r,σ_p,ω,β,d,c,m)**。
> 显然存在映射 ϕ:Z_t↦Y_t，也就是说 Z 是 Y 的细化。
> 定理：细分类 oracle 价值不低于粗分类 V(Z)≥V(Y)。证明：任取一个粗分类策略 π_Y:Y→A，构造细分类策略 π_Z(z)=π_Y(ϕ(z))，则二者在每个状态上动作相同，所以收益相同。因此细分类策略集合至少包含所有粗分类策略的模拟版本，对策略集合取上确界，V(Z)≥V(Y)。
> 这说明：引入级别、多空、角色、背驰强度等细分类，在 oracle 意义下不会降低可达 alpha。它只会带来一个现实代价：样本更稀疏，估计更难。
>
> **z 分量定义（该 PDF 明确列出）**：
> `r ∈ {开根声部, 平仓, 短差, 顺势, 反手}` 是操作角色；
> `σ_p ∈ {−1,0,+1}` 是父声部方向；
> `ω` 是当前仓位状态；`β` 是背驰强度或其他力度度量；`κ` 是级别结构位置（例如中枢内、中枢上、三买后、三卖后）。
>
> 另一处（同文档不同小节）重复给出：`Z_t=(ℓ,δ,I_γ,r,σ_p,ω,κ,β,d,c,m,…)`，其中 r：操作角色，例如开根、平仓、短差、顺势、反手（**5 类枚举，不含 H(g) First/SameFollow/SameReverse**）。

## C. `推导完全分类.pdf`（续，维数控制原则）

> 更本质的解：限制有效维数。Shrinkage 和 LCB 是估计层修复；更本质的是减少状态空间维数。
> 原始状态：z=(ℓ,δ,I_γ,σ_p,r,ω,…)。理论组合数：K=|ℓ|·2·|I_γ|·|σ_p|·|r|·|ω|⋯。如果 K 大，而总样本 M 固定，则平均每类 n̄=M/K 很小。
> 因此必须有一个压缩映射 ϕ:Z→U，把高维状态 z 映射到较低维状态 u。例如 u=(ℓ,δ,I_γ) 或 u=(level bucket, δ, role, divergence bucket)。
> **维数控制的严格原则是：不要把不能可靠估计的维度放进 z。如果某个维度不能提升 OOS value，就应删除或正则化。**
