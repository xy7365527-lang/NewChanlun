## G4：统计层出场口径是否 typed exit

### PDF §9 原文

> 「完整策略不能只用"下一个反向信号"出场。出场应是 typed exit：
> `Exit_Θ(v,x_t) ∈ {CloseRoot, ReduceCore, CloseShortDiff, RiskExit, Hold}`。
> 例如：第一类反向点：根仓清仓；第三类反向点：核心仓减仓；短差反向确认：关闭子声部；
> 保证金/强平：风险优先退出。
> 收益函数必须使用正规出场：`X_i^full = δ_i(P_{τ_i^typed}−P_{t_i})−C_i`。
> 不能继续用：`X_i^old = δ_i(P_{τ_i^reverse}−P_{t_i})−C_i`。
> 因为 `τ_i^typed ≠ τ_i^reverse` 一般成立。」

### 代码事实（供你核实）

生产 walk-forward μ 估计管线 `rust/src/theta_v0/backtest/l3_delta_r_alpha.rs::build_mu_from_bars`
（这是喂给 χ 选择器/W-VERIFY/econ_positive 全部 alpha 判定的核心统计管线）的出场规则**逐字**是：

```rust
// 找下一个反向方向信号的确认 bar（exit）；无则 censored 到 train 末可交易 bar。
let opp = match dir {
    VoiceSide::Long => VoiceSide::Short,
    VoiceSide::Short => VoiceSide::Long,
    VoiceSide::Flat => continue,
};
let exit_bar = signals[idx + 1..]
    .iter()
    .find(|(eb, _, d)| *eb > entry_bar && *d == opp)
    .map(|(eb, _, _)| *eb)
    .unwrap_or_else(|| /* censored 到 train 末 */);
```

这正是 PDF 明确要求废弃的 `X_i^old`（τ^reverse=下一个反向信号）——统计层的出场时点是
"下一个反向方向的新确认买卖点"，而**不是** π 层（生产回测执行层）实际使用的 typed exit 语义
（`interp::interpret` 的 close 桶触发 / `KThetaRiskGate.force_flat` 风险强平 / 短差子声部
关闭等，这些在 π 层已经实装且经 codex 裁定为语义正确——见前序 D1/Q2 裁定）。

`ResidualTrade`（`mu_estimator.rs`，携带 `resid_base = H_i − B̂_i`）唯一的生产构造点就在
`build_mu_from_bars` 内（`l3_delta_r_alpha.rs:253`），继承同一出场口径。
