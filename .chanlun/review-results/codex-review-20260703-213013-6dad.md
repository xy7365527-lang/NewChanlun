> Q5. A/C 段对象粒度
> 裁决：A/C 应为次级别走势类型，不应默认是单一线段。
> If a lower-level departure move consists of multiple segments, the MACD/force comparison
> should cover the whole lower-level move type interval:
>   I(A) = [λ_A, ρ_A],  I(C) = [λ_C, ρ_C]
> Then:
>   Area(A) = Σ_{t∈I(A)} |hist_t|
>   Area(C) = Σ_{t∈I(C)} |hist_t|
> Current code chooses one segment for A and one segment for C; the report explicitly
> identifies this mismatch. So after fixing trend decomposition, also fix:
>   A, C : Segment → LowerLevelMoveType

> 9.3 Type1Cand（修复后判据）：
> For move M: Type1Cand(M,s) iff
>   1. M.kind = Trend(d)
>   2. M has at least two centers
>   3. s is the lower-level move type leaving the last center in direction d
>   4. s breaks the last center boundary
>   5. Weak(s, A) = 1, where A is the previous comparable lower-level departure move.

## 代码：divergence.rs::locate_departure_move_a（A 侧区间定位，含测试）

```rust
pub fn locate_departure_move_a(
    segments: &[Segment],
    prev_center: &Center,
    last_center: &Center,
    trend_dir: Direction,
) -> Option<(usize, usize)> {
    let mut it = segments.iter().filter(|s| {
        s.direction == trend_dir
            && s.start_index >= prev_center.end_index
            && s.start_index < last_center.end_index
    });
    let first = it.next()?;
    let last = it.last().unwrap_or(first);
    // I(A) = [首个匹配段起点, 末个匹配段终点]——整个离开走势区间（Q5：多段时含中间反向段 bar）。
    Some((first.start_index, last.end_index))
}
```

要点：
1. `segments` 是**扁平线段列表**（本级别的 Segment 对象，L0=线段/duan，高级别=递归塔投影单元）。
   代码**没有**对这些 segments 做"次级别走势类型分解"（decompose.rs 的 Trend/Consolidation 块划分）
   ——只是简单地把 `[prev_center.end_index, last_center.end_index)` 区间内所有 `direction==trend_dir`
   的段挑出来，取首尾拼成区间。中间夹的**反向段**（不管方向、不管是否曾经"回中枢"）全部被隐式
   纳入 `[first.start_index, last.end_index]` 数值区间内（因为区间端点覆盖了它们的下标范围）。
2. **没有"回中枢"（reentry）检测**：如果这个区间内先出现一小段同向尝试后**真正回撤进了
   prev_center 核心区间 [zd,zg]**（即失败的离开，价格缩回中枢内部），然后再重新离开、最终衔接上
   last_center——本函数依然会把从"第一次失败尝试"到"最终成功离开"之间的所有 bar 都并入 I(A)，
   等同于把两个语义上分离的"离开episode"当成一个连续走势类型来算 MACD 面积。
   （对比：同一 diff 里 Q4 的 `judge_pan_div`——用于盘整背驰——显式实现了 `reenters` 判据来区分
   两次独立的离开，正是为了避免这个问题。Q5 的趋势侧 A/C 定位完全没有对应机制。）
3. 单段兼容性测试 `locate_departure_move_a_single_segment_bit_compatible` 证明：恰一个匹配段时
   `(first.start_index, last.end_index)` = 旧 `.next_back()` 语义的 `(s.start_index, s.end_index)`，
   bit 相同。
