## 我方独立复核（不照单全收——亲验代码）

Codex 裁定 B 的核心技术前提是："sizing 层的 `1/d` 和 estimand 层的 `X/d` 不互相替代……如果
当前 `X` 是未按仓位缩放的 per-trade PnL，则新增 `X/d` 不是 double-count"。这是一个可用代码
验证的事实断言，不能仅凭 Codex 自己的陈述采信，必须亲验：

1. **`X` 的真实定义**：读取 `rust/src/theta_v0/backtest/mu_estimator.rs:301-326` 及生产调用点
   `l3_delta_r_alpha.rs:197`（`resid_base: h - b_hat // r_i = H_i − B̂_i`）确认：生产环境里
   `X_i = δ_i·H_i − C_i` 中的 `H_i` 是**单位价格边际收益**（`marginal_return` 测试
   `mu_estimator.rs:730` 验证其语义 = 方向签名的价格差，qty 固定为 1），**不是** `qty·(P_τ−P_t)`
   这种被 sizing 手数缩放过的美元 PnL。即：当前 X 与 `risk.rs:147` 的 sizing `qty` 完全无关——
   两者是两条独立的计算路径，从未合流。
   → **Codex 的"未按仓位缩放"前提为真**，据此推出的"当前不构成 double-count"结论成立。

2. **`d` 的 ex-ante 可得性**：`structural_stop()`（`risk.rs:74-105`）在决策时刻（1/2 类买卖点用
   pivot 极值，3 类用中枢 ZG/ZD）即可确定止损价，`d=|entry-stop|` 在建仓前已知，非回看拼接。
   → 满足 Codex 边界条件里"翻转到 A"的反面条件（"d 无法可靠 ex-ante 取得"不成立），
   支持 B 而非降级到 A。

两处关键事实核验通过，Codex 的裁定不是建立在误读代码之上的空中楼阁。
