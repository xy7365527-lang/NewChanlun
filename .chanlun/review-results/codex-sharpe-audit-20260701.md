## 结论（一句话）

**codex 判 (B) 归一化伪影，审查者复核否定成立（CRITICAL）。** 命题②"收益率/夏普尺度证伪"**不是**真否证——
`lq-sharpe-scale` 没有把命题②从 underpowered 推进到证伪，而是把判据3 的对象从"原始 pnl"偷换成
**"按信号等权的 `mean(pnl/hold)`"**，再把这个描述统计量**误解释**为"每 bar 可交易收益/夏普尺度"。
根因是**测度错配（measure mismatch）**：抽样权重从"资金暴露/持有时间"变成了"每笔信号一票"。
命题②应退回 **inconclusive**——pnl 尺度 underpowered，r 等权信号斜率不是有效证伪统计量，正确的时间轴尺度**未给出真否证**。

## 审查者独立算术自检（4 条，与 codex 独立收敛）

**自检2（决定性反事实）**：除固定常数 CV 不变，除各自 hold CV 骤降 80-97%：

| (ℓ,q) | CV(pnl) | CV(pnl/固定常数) | CV(pnl/hold各自) |
|-------|---------|-----------------|------------------|
| (0,−1)| 32.91   | **32.91**       | 3.44             |
| (0,+1)| 59.77   | **59.77**       | 4.67             |
| (1,+1)| 218.86  | **218.86**      | 6.01             |
| (2,−1)| 49.94   | **49.94**       | 2.69             |

→ CV 压缩 100% 来自 hold 分母的逐笔异质性，**不是** pnl 信号本身方差缩小。
n_eff 门槛 `(1.645·CV_r)²` 越过（13-68）是算术假象——门槛公式里的 CV 被人为压缩了。

**自检3（符号系统性翻转，corr(pnl,hold)≈+0.54）**：6/7 单元 mean(pnl)>0 但 mean(pnl/hold)<0。
pnl 与 hold 正相关（赢家长持有）→ 除 hold 系统性压低长持有赢家、放大短持有输家。

**自检4（bar 对齐时间轴组合夏普，Lead 提出的第三度量）**：把每笔 pnl 按 pnl/hold 摊到 [entry,exit)
每个 bar，构造真实时间轴每-bar 组合收益序列：

| (ℓ,q) | n_bars | mean | sharpe |
|-------|--------|------|--------|
| (0,−1)| 2.74M  | +0.052 | +0.032 |
| (0,+1)| 3.75M  | +0.041 | +0.018 |
| (1,−1)| 490K   | +0.059 | +0.052 |
| (2,−1)| 104K   | +0.025 | +0.022 |
| (2,+1)| 187K   | +0.027 | +0.029 |

**按 bar 对齐（时间轴）的组合收益全为正夏普——符号根本没翻。** 与 codex 独立复核吻合。

## codex 五问判定（审查者认同）

| Lead 必问 | codex 判定 |
|-----------|-----------|
| 1. CV 压缩是真检出力还是算术假象 | **假象**。CV 压缩对 `E_signal[pnl/hold]` 这个人工目标是真的，但对"可交易 alpha"的检出力是假的。`n_eff>(1.645·CV)²` 只能用于它实际抽样的变量，不能把等权信号斜率的低 CV 转移成时间轴收益的高功效 |
| 2. 符号翻转是收益变负还是加权重排 | **加权重排**。抽样权重从"持有时间/资金暴露"变成"每笔信号一票"。长持有赢家降权、短持有输家升权。根因是 length-weighting / ratio-estimator 错配，称 Jensen 型可以，但**根因是测度错了** |
| 3. 哪个度量对应可交易性 | (a) 原始 PnL 认证，或更好 (c) 时间轴组合收益 Sharpe。**(b) mean(pnl/hold) 可作描述性"单信号斜率"，但不能证伪可交易性** |
| 4. 双尺度分裂结算是否严谨 | **应推翻**。可并列成立的是两个描述统计：mean_pnl>0 与 mean_signal(pnl/hold)<0。**不能并列成立的是"r/夏普尺度已证伪可交易 alpha"** |
| 5. 4 窗 walk-forward 能否救 | **不能**。每窗仍取 r=pnl/hold 等权列表，同一个错测度重复四次，只证明偏置稳定。按时间轴口径复核，窗口符号是混合的，不是全窗一致负 |

2. **已被其他机制覆盖？** 否。sharpe-scale 报告边界条件2 只说"归一化选择可能不同"，**未识别** `mean(pnl/hold)`
   是错误测度这一根因；上游 codex-lq-audit 审的是 pnl 尺度 underpowered，**没审到 r 尺度的测度错配**。这是新盲区。
3. **严重性合理？** CRITICAL。它决定命题② 是"证伪"还是"inconclusive"，且防止把**假证伪**写进谱系结算 667号。

**否定成立。** codex 还精化了审查者判断：根因不止是 Jensen 凸性，而是**测度错配**——即使无凸性，抽样权重从
"资金暴露"变"每笔一票"也会翻转符号。这比"Jensen 伪影"更准（Jensen 是它的一个特例）。

## 修复方案（codex 给出，审查者认同）

1. 保留 `mean(pnl/hold)`，但**降级命名**为 `signal_equal_slope_mean`，**不得**称为"每 bar 策略收益"或"可交易 Sharpe"。
2. 新增 `R_t` 构造：对每个 (ℓ,q) 和每个 OOS/WF 窗口，把每笔 `pnl_i/hold_i` 加到 `[entry,exit)` 每个 bar，
   按资本/exposure 规则归一化（自检4 已给原型）。
3. 用 `R_t` 计算 mean、Sharpe、block bootstrap LCB/UCB；**block 单位应是时间 bar，不是交易行**。
4. 若要"证伪 μ>0"，报告 **UCB≤0** 或针对最小经济收益 ε 的反证检验；`LCB<0` 本身不是反证统计量
   （与上游 codex-lq-audit 边界条件3 一致）。
5. **命题②当前结算退回**：`pnl 尺度 underpowered=inconclusive；r 等权信号斜率不可作为证伪；
   正确时间轴尺度未给出真否证`。

## 边界条件（本审查结论翻转条件）

1. **若补时间轴 R_t 尺度**：用 codex 修复方案2-3 重跑，若时间轴组合收益的 95% **UCB≤0** 且多窗稳定
   → 命题② 在正确的可交易尺度下**真证伪**成立。当前自检4 显示时间轴夏普**全正**（+0.018~+0.052）→
   反而更可能翻向"未证伪/弱正信号"，而非证伪。
2. **测度选择**：本审查限定 `mean(pnl/hold)` 等权 = 错误测度这一判定。若有理论论证 `pnl/hold` 等权
   对应某个真实可实现策略（如每信号固定资金、不并发）→ 需明确该策略假设，届时它才是有效测度（当前报告未给此假设）。
3. **时间轴归一化选择**：自检4 用"每 bar 摊分 + 简单叠加"，未做资金/并发归一化。若按不同资本规则归一，
   夏普数值会变，但符号（正）由 mean(pnl)>0 主导，不易翻负。
