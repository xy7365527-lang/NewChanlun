## 结论（一句话）

codex 从对立面攻击 5 点：**3 点成立并动摇结论、1 点部分成立、1 点被驳回**。核心结论"σ_higher 是级别调制器不是 alpha 门控"（判定1否证 ChatGPT）**未被动摇**，但报告的**统计推广范围**被严格收缩：全局 perm_p 只能支持 L0 主导的总体显著，**不能推广到 L3+**，也**不能严格声称"扣 beta 后的 σ_higher alpha"**。最致命的是攻击点1+3合流——**口径4/出场窗口内生性**未被证伪前，L1 超beta +107608 和 perm_p 同时失去统计解释力。

## 逐点质询（codex 否定 + 审查者判定）

### 攻击点1：分层置换的 beta 吸收严格性 → **成立（核心有效性漏洞）**

codex 否定：σ_higher∈{−1,0,+1} 只吸收方向不吸收幅度；h_bucket 仅 5 桶。同层内 raw 幅度、波动率、时段、趋势强度高度不均。置换零假设**只能检验"给定粗层后 δ 标签是否可交换"，不能检验"扣 beta 后仍有 alpha"**。显著 p 可能是残余 beta/时间趋势泄漏。

审查者简化质询：
- **问题真实存在？** 是。报告§口径修正自己承认"σ_higher≈raw粗粒度方向"——"粗粒度"三字即漏洞：粗吸收留残余幅度。BTC corr(raw,B_market)=1.0 意味着 raw 内几乎全是 beta，方向吸收后幅度残余仍是 beta。
- **是否已被报告覆盖？** 部分。报告边界条件1（单标的 raw>0 主导）触及但未量化残余泄漏。
- **严重性合理？** 合理判 HIGH。这是把"δ 可交换"当事实的定义级问题，直接决定 perm_p 的语义。

**动摇结论**：perm_p=0.002/0.004 的"显著"不足以支撑"顺/逆都有 σ_higher 之上的残余 alpha"——它证明的是"给定 (level,σ_h,hbin) 粗层后 δ 选边非随机"，其中仍含未吸收的 beta 幅度。

### 攻击点2：全局 T=Σpnl 的层规模主导 → **成立（外推范围）** ★审查者实测确证

codex 否定：T 是全局和，L0/L1 大样本天然主导；L3+ (n≈93) 对 T 几乎无权重。把"总体加权平均显著"误读为"每 level 都显著"。

审查者**实测确证**（`groupby(level).sum()/T`）：

| level | n | Σpnl | 占全局T |
|-------|---|------|--------|
| 0 | 11149 | 297520 | **92.6%** |
| 1 | 1059 | 25689 | 8.0% |
| 2 | 324 | 7644 | 2.4% |
| 3 | 69 | −8215 | −2.6% |
| 4+ | 25 | −1227 | −0.3% |

- **问题真实存在？** 是，且比 codex 估计更极端——**L0 独占 92.6%**。全局 perm_p=0.002 几乎是 L0 单层的显著性。L2-L5 合计贡献 <0.3%。
- **严重性合理？** 判 HIGH。判定3（L3+接飞刀）报告了 mean_pnl 但**没有对 L3+ 单独做 perm 检验**——L3+ 的符号翻转结论无置换支撑，是描述性统计而非假设检验。
- **修复**：报告须补 per-level perm_p（或 max-T 层级校正）。全局 p 只能标注为"L0 主导的总体显著"。

**动摇结论**：判定3"符号翻转边界 L2→L3"和"L3+接飞刀"是**未经置换检验的描述统计**，认识论等级应从 L2（可否证）降为 L1.5（观测但未检验）。报告§下游推论2已自认 L1 相位"仍是 L2 单标的需 L3 跨标的验证"——审查追加：L3+ 结论连单标的 perm 都缺。

### 攻击点3：L1 超 beta +107608 的真伪 → **成立（与点1合流后最致命）**

codex 否定：全做多 L1 亏 −81919 vs 策略 L1 赚 +25689，差额被解释为相位 alpha。但**全做多基准与策略共享"口径4=下一反向信号"出场窗口**——出场边界不是外生市场窗口，而是信号系统内生。若 L1 反向信号密度/边界本身放大盈亏，全做多差额就不是纯 beta 对照（不是同一个对象）。

审查者质询：
- **问题真实存在？** 是。这正是 [[project_oddeven_mu_identity]] 的口径4放大器机制在 L1 的实例——报告§下游推论2**自己已预警**"否则是 BTC 特有的口径4×L1配对边界放大"。codex 独立复现了这个自我怀疑，说明它不是过度谨慎。
- **必要证伪检验（codex 给出）**：改用固定时间 horizon / 固定 bar 数 / 外生日历窗口 / 同 entry 随机 exit / 非口径4 exits；若 L1 超额仍稳定 → 排除口径4伪影。
- **严重性合理？** 判 CRITICAL（合并点1）。若窗口内生性成立，L1 超beta 和 perm_p 同时失去解释力——这是整份报告"级别相位 alpha"主张的支柱。

**动摇结论**：判定3的核心正面主张（"超beta主要来自L1=级别相位alpha"）**降格为待证伪假设**，不是已验证结论。审查者判定：#114 号"L1相位超beta alpha"新号在口径4伪影被证伪前**不可结算为 alpha 发现**。

### 攻击点4：多重比较 → **部分成立**

codex 否定：判定1两组+全局+逐level+train/holdout+判定2/3 构成同一发现族，未做 Bonferroni/Holm/max-T 校正。探索性比较写成确认性结论。

审查者质询：
- **问题真实存在？** 是，报告确实未标注 family 和校正。
- **但严重性有限**：codex 自己指出"若只校正 2-10 个检验，0.002/0.004 大概率仍过 0.05"。判定1的两个主检验即使 Bonferroni×10 也是 0.02/0.04，仍显著。
- **严重性合理？** 判 MEDIUM。校正不改判定1（顺/逆都显著）的定性结论，但报告应显式声明 family 大小。

### 攻击点5：train/holdout 异常 → **成立（判据过弱）**

codex 否定：holdout mean 比 train 高 2-4 倍却被"方向一致"判作非 winner's curse。只比符号不检量级/beta强度/时段交互。近期 BTC 更牛时 holdout 同向更强**可能只是 beta regime 更强，不是策略泛化更好**。

审查者质询：
- **问题真实存在？** 是。报告的"方向一致=非winner's curse"判据只看符号。holdout(近期)=BTC 后期强牛段，所有组升高更可能是 regime 效应。这与点1（残余 beta）同源。
- **严重性合理？** 判 MEDIUM-HIGH。它不推翻判定1符号，但削弱"策略泛化"声明。
- **修复**：holdout 须与"全做多 holdout"对比（超额是否也在 holdout 保持），而非只看策略自身 holdout 均值正负。

### 附加漏洞A：no_higher 仅 3 样本 → **成立（三态实为二态）** ★审查者实测确证

审查者实测 σ_higher 分布：`+1: 6337, −1: 6286, 0: 3`。**σ_higher 三态实测近似严格二态**（no_higher=0.02%）。
- codex 判"部分成立"：不直接推翻顺/逆结论（因为二分穷尽了样本），但若定义预期中性态应常见则是实现错误。
- 审查者补充：这实际**加强**判定1的效力——顺/逆二分几乎无遗漏地覆盖全样本，no_higher 可安全忽略。但需在报告中声明"σ_higher 实为二态，中性态定义几乎不触发"，否则读者误以为存在有意义的三分。

### 附加漏洞B：raw=actual_spread·δ 恢复的循环性 → **驳回（不成立）**

codex 判定：**代数本身不成立为漏洞**。若 actual_spread=δ_original·market_raw，恢复 raw 后配 δ_π 是语义正确的反事实（δ²=1 使 raw=market_raw 与 δ 无关）。真正风险不在 δ² 而在窗口内生性（已并入点3）。
- 审查者认同驳回：Lead 必问点中的这一条（"raw 由原始δ恢复，配 δ_π 是否语义正确"）**不构成漏洞**——raw 恢复后是纯市场价差，与哪个 δ 恢复的无关。这是审查者对自己质疑的诚实否定。

## 边界条件（本审查结论翻转条件）

1. **窗口内生性证伪**：若用外生日历窗口/固定 horizon/非口径4 exits 重跑，L1 超beta 仍稳定 → 攻击点3失效，"级别相位alpha"回升为已验证结论。
2. **per-level perm 补齐**：若对 L1/L2/L3+ 各自做层内 perm 且显著 → 攻击点2的"外推"批评失效，判定3回升为 L2。
3. **残余 beta 量化**：若能证明同 (level,σ_h,hbin) 层内 raw 幅度方差已足够小（beta 泄漏 <某阈值）→ 攻击点1软化。
