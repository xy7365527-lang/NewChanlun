## 0. 顶层结论（缺口优先）

**原文的"完全互斥分类"远比我们的 Φ=(τ,γ,λ) 丰富。** 我们的分划证明 L0 严格，但它分划的是一个**被坍缩、去掉多个维度**的对象空间。原文的分类是一个 5~7 维状态元组上的分划，其中至少 **4 个维度我们完全没有**（角色 r、父声部方向 σ_p、非坍缩 64 类 bsp 向量、区间套递归证书 N^δ 的严格单调嵌套），另有 2 处**结构性分歧**（去根化自相似 vs 我们的 level0 免门特殊化；冲突解释器 ≺_Θ vs 我们的 buy2>buy3 优先级坍缩）。

**同构的部分**：分划=函数纤维（存在性+唯一性）这一 L0 骨架，两边完全一致——原文 §"全互斥要求" 𝒳=⊔_z 𝒞_Θ⁻¹(z) 与我们的 §5.1 是同一命题。原文自己也承认（多份 PDF 反复强调）：**分类完备 ≠ alpha**（结构完备只是理论严密的必要条件，不是赚钱的充分条件），这与我们 partition-proof 的"L0 同义反复、语义在 L2"认识论**完全一致**。

**两条矛盾即报**（已单独 SendMessage main）：
- **矛盾-A（触 StructBreak #62 裁定）**：原文"证书成立当且仅当 I_γ≠∅"，零 bit（I_γ=∅）候选在原文里落 **C_0=保持（不交易）** 或 **L_t=记录但不交易的证书**；我们 #62 把零 bit 归入 `BspCandType::StructBreak` 第四类纤维。是否分歧取决于 StructBreak 纤维是否产生**交易动作**——若只记录不交易则与原文一致，若参与门控/下单则与原文"I_γ=∅⟹保持"分歧。
- **矛盾-B（触分划 G6/去根化）**：原文核心公理"根级别不是特殊级别、级别平移自相似 𝒞_Θ(S_k x)=S_k𝒞_Θ(x)"，我们分划 G6 的 `lvl==0 免门`+`XzdEvidence.level≥1` 使 level0 成为特殊级别，**破坏平移等变**。我们的 L0 分划仍成立（空胞不破分划），但违反原文的自相似公理。

## 2. 原文分类方案综合重建（跨 4 条推导线）

### 2.0 元框架（截图版前段独有）
- 数学"完全分类"最严标准 = **双射分类定理**：不变量 I:X→P 满足 不变性(x~y⟹I(x)=I(y)) + 完备性(I(x)=I(y)⟹x~y) + 可实现性(∀p∃x I(x)=p) ⟹ 商集 X/~ ≅ P。
- 缠论式完全分类最严版 = **固定级别下互斥穷尽分区 + 唯一递归分解 + 无前视全定义状态转移 δ:S×E→S(全函数) + 全定义应对规则 π:S→A**。
- **动力学完备**：δ 是全函数（不是只对部分情形有定义）——对应我们分划的"τ/γ 全函数"要求。
- **无前视**：s_t=f(x_0,…,x_t)（不偷看 t 之后）——对应我们的零前视回测约束。
- **关键**：分类完备 ≠ 逻辑完备（Gödel）；分类完备只是严密性必要条件，**不是有效性/赚钱充分条件**。⟵ 与我们 partition-proof "L0 同义反复"认识论同构。

### 2.1 完整状态（推导线①，权威全本）
```
z = (ℓ, δ, I_γ, r, σ_p, ω, β, κ, d, c, m)
```
- ℓ 级别；δ∈{+1,-1} 证书方向（+1 买/做多，-1 卖/做空）；
- **I_γ ⊆ {1,2,3}**：一二三类买卖点集合（**子集，非坍缩**！例 I_γ={2,3}）；δ=+1 时 I_γ={i:B_{i,ℓ}=1}，δ=-1 时 ={i:S_{i,ℓ}=1}；**证书成立当且仅当 I_γ≠∅**（⟵矛盾-A 根）；
- **r 操作角色** ∈{开根声部,平仓,短差,顺势,反手}；
- **σ_p 父声部方向** ∈{-1,0,+1}（0=父容器无方向/胚元/ambient）；
- ω 仓位态；κ 中枢/走势语境；β 背驰强度/力度；d 结构止损距离；c 成本；m 保证金。
- **alpha 定理**（三本一致）：存在赚钱因果策略 ⟺ P(max_a μ(z,a)>0)>0；细分类优势 V(Z)≥V(Y)（细化不降 oracle alpha，代价=样本稀疏）；鞅不可能（市场对 z 仍鞅⟹扣成本后无 alpha）。

### 2.2 角色轴（推导线②，推导完全互斥分类.pdf）
两个正交维度：
- **Role(e)** ∈{RootDir, SameDir, SubFollow, ShortDiff}——4 类**互斥穷尽** ∑1[Role=R]=1；由 ρ_e∈{Root,Same,Sub} × 方向关系推出。
- **Side(e)=ε_e** ∈{做多,做空}——绝对方向，与 Role 正交。
- **短差严格定义**：ShortDiff=Sub∧ε_e=-σ_{父}；`父级多头的短差=次级别做空，父级空头的短差=次级别做多`；短差≠反手，短差=**父仓保持+次级别反向双开**。
- **同级别反向≠短差**（SameDir，关闭/切换/反手，非短差）；**次级别顺向=SubFollow**（顺势子腿，非短差）。
- **分账本**：多头腿/空头腿作独立坐标，**不净额抵消**（Qe⁺+Qe⁻≠0）；每元素毛收益 G_e^sep=s_e·ε_e(P_ρe-P_λe)>0。
- **Eat(e)/AncOK**：A_{t+1}=AncOK[(A_t\D_t)∪O_t]，AncOK(S)={v:Anc(v)⊆S}（子声部 active⟹父声部 active）；Eat(e)⟺规范腿在 e 整个生命期以方向 ε_e、数量 s_e 覆盖它。

### 2.3 去根化递归自相似轴（推导线③，递归完全分类买卖点.pdf——最深）
- **去根化**：没有特殊根级别，只有前沿 ℓ_max(t)；根=父级尚为胚元 ∂_{ℓ+1} 的普通子级别；更高级别涌现=同一提升算子 Prom 在前沿再作用，ℓ_max(t+1)=ℓ_max(t)+1。
- **64 类买卖点向量** b_ℓ(x)=(B1,B2,B3,S1,S2,S3)∈{0,1}⁶，**不要求六买卖点互斥**（可重合），天然 64 类完全分类 ∑1[b_ℓ=u]=1。⟵ **这是我们 seen-key κ 的 bsp_disc/class_index 64 掩码的直接原文出处**。
- **区间套递归证书** N^δ_{ℓ↓e}(x)：ℓ=e 时 Conf^δ_e（Conf⁺=∨B_{i,e}，Conf⁻=∨S_{i,e}）；ℓ>e 时 Cand^δ_ℓ ∧ **[J^δ_{ℓ-1}⊆J^δ_ℓ]**（严格区间单调嵌套）∧ N^δ_{ℓ-1↓e}；递归级别下降有限终止。
- **角色三轴** R(g)=(H(g),V(g),δ_g)：
  - **水平关系** H(g)∈{First, SameFollow, SameReverse}（同父容器下与前一同级别兄弟 prev(g) 的方向关系）——互斥穷尽；
  - **垂直关系** V(g)∈{Ambient, FollowParent, ShortDiff}（相对父容器 σ_{p(g)}∈{-1,0,+1}：0⟹Ambient，同向⟹FollowParent，反向⟹ShortDiff）——互斥穷尽；
  - R(g)∈ 3×3×2 = **18 类严格互斥完全分类** ∑1[R(g)=r]=1。Ambient 不是根规则，是任意父容器无方向的普通情形。
- **冲突解释器** ≺_Θ：固定级别平移不变总序（g1≺g2⟺S_k g1≺S_k g2），按序处理候选 Γ(x)⟹唯一解释 (D,B,K)。⟵ 我们 buy2>buy3 优先级坍缩的原文对应物（但原文保留 64 类再排序，不坍缩）。
- **全分类函数** 𝒞_Θ(x)=(D_t,(b_ℓ)_ℓ,(χ⁺,χ⁻)_ℓ,Γ,(R(g))_g,𝓡_Θ(Γ),A_{t+1},p̃_{t+1})；𝒳=⊔_c 𝒞_Θ⁻¹(c)；**级别平移自相似 𝒞_Θ(S_k x)=S_k𝒞_Θ(x)**（⟵矛盾-B 根）。

### 2.4 覆盖定理 + 二值背驰 + 过拟合（推导线④）
- **吃到每一笔**：规范吃笔声部 ν(b)=包含 b 的最深同向活动声部；∀b∃!ν(b) Eat^max(ν(b),b)；毛收益吃到每一笔（可证）≠组合净值吃到每一笔≠事后端点无延迟吃满（后二者不可无条件证明，多空双开父子抵消）。
- **二值背驰**：D_t^δ(c,s1,s2)∈{0,1}；B_{i,ℓ}=Context^+_{i,ℓ}∧D⁺；`二值背驰足以定义买卖点`；背驰强度 β=K 分箱是**状态细分变量**（提升 alpha 识别），**不是定义买卖点的必要条件**；D=1⟺TopContext∧M(s2)<M(s1)∧P(s2)创新高/低（力度比较内嵌）。
- **过拟合层**：`缠论确定性结构层不过拟合；因果选择器 μ̂(z,a) 估计层会过拟合`；winner's curse（零 alpha 世界选训练最高类必现假阳）；稀疏高级别类最易误选 alpha；修复=层级收缩 μ̂^shrink + LCB(置信下界) + 维数控制 + 正则化 + cross-fit OOS；Le Cam 两点：n_z·d_z² 很小时任何估计器无法可靠识别高级别 alpha（信息论下界，非工程问题）。

## 4. 缺口清单（按阻塞性分级）

### 阻塞级（P0——原文核心分类维度，我们分划根本没有，直接决定"完全互斥分类"是否成立）
- **P0-① 角色维 r / R(g)=(H,V,δ) 18 类**：原文的完全互斥分类是 (级别×方向×I_γ×**角色**×父声部…) 的分划；我们 Φ=(τ,γ,λ) 缺整条角色轴（水平兄弟关系 H、垂直父容器关系 V）。**没有它，我们声明的"完全互斥分类"只是原文分类的一个投影 π(Z)=Y=(ℓ,δ,I_γ) 的粗化**（原文 §细分类优势定理明确 Y=(ℓ,δ,I_γ) 是粗状态，Z 才是细状态）。
- **P0-② 父声部方向 σ_p∈{-1,0,+1}**：角色/短差的判定量；缺它则无法区分"同一买点在父多/父空/无父下的不同操作语义"（原文 §10 明确"否则把不同操作语义混进一个 μ"）。

### 高级（P1——维度存在但被坍缩/退化，损失可交易结构）
- **P1-③ 64 类非坍缩 b_ℓ vs 坍缩 τ**：原文保留 {0,1}⁶ 全向量；我们 τ 坍缩为 {T1,T2,T3}（G2）。alpha 桶键若用 bsp_class(64 掩码) 不受影响，但 τ 层 gate 分派吞并 [2B,3B]。原文的 ≺_Θ 有序解释器是比 buy2>buy3 更严的共生解析。
- **P1-④ 区间套 N^δ 严格单调嵌套证书**：原文要求 [J^δ_{ℓ-1}⊆J^δ_ℓ] 逐级区间包含；我们区间套已接入但实测 95% 退化 base-case（跨级仅 4.6% max 深度=1）。缺严格嵌套=我们的 Nest 通道不是原文的递归区间套。
