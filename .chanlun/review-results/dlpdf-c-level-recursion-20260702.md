### 3. 子声部.pdf（27页，两段会话）——P1∧P2∧D 不可能定理 + K_i 双视图解
**第一段（1-11页）**：集合论严格证明——子声部可开仓集合被 tree 覆盖域（T_i=↓r_i，只取最高 compose chain 可达元素）、BSP全格域、hostOf 定义域（严格右端点命中）的交集所限。实测 `|T_i∩U_{i,0}|/|U_{i,0}| = 486/1360 ≈ 36%`，说明大量 L0 走势属于 orphan frontier（树外孤儿边界）。证明三命题 **P1（extract tree只取最高链）∧ P2（hostOf严格右端点命中T_i）∧ D（全格BSP都应可操作证书）三者不可同时成立**——若子声部BSP主要落在orphan frontier上，则 `π_Θ^bsp` 子声部结构性恒为0。这**不是**"买卖点无alpha"的证明，而是"当前对象没有被实际交易到，或只交易了hostable子集"的结构定理。三条解决路线：A破P1（扩展extract tree到全森林/frontier，代价="547复活"风险）/B破P2（放宽hostOf到区间包含，代价="638复活"风险）/C保留P1∧P2（接受子声部结构性为0）。

**第二段（12-27页，续会话）**：给出最干净解——**双视图架构**：T_i=结构视图树（保持bit-exact extract tree不变）vs K_i=操作carrier森林（K_i=T_i∪F_i^op∪G_i，即结构树+所有可能被BSP host的frontier carrier+必要胚元容器），要求 K_i 满足 endpoint-complete（每个BSP在K_i中都有唯一严格右端点host）。这**不是**放宽hostOf到区间包含（避免"638复活"），而是扩大host的**载体宇宙**从T_i到K_i，hostOf仍是严格右端点命中。证明定理1：endpoint-complete K_i下子声部不再因orphan host而结构性为零。最终严格结论："若要全格BSP参与多重赋格子声部，必须把操作host宇宙从T_i扩展到endpoint-complete的K_i；否则，保留P1∧P2时，子声部结构性为零是定理，不是工程bug。"

### 4. 递归证明.pdf（11页）——Lift 谓词：上级买卖点的严格递归定义
纠正一个方向性错误：命题不是"任意次级别一买/一卖⇒必然是上级别三类买卖点之一"，而是**反过来**："任意上级别买卖点，若按区间套递归确认，则必须由某个次级别终端买卖点作为证书"（必要非充分）。严格定义提升谓词 `Lift^δ_{j,ℓ}(c,g) = Host(g) ∧ Nest(c,g) ∧ Context^δ_j(c,g) ∧ Fresh(g)` 四个条件：
- **Host**：g 的 source_index 恰好命中某次级别走势容器 d 的右端点
- **Nest**：区间套嵌套 `J_ℓ(d)⊆J_{ℓ+1}(c)`
- **Context**：次级别一买/一卖 g 本身只说明"该段走势发生了转折确认"，不能单独决定自己是上级一买/二买/三买——需要上级容器 c 的结构语境判定（这是最重要的一步）
- **Fresh**：未被使用过（避免重复触发）

递归定义 `P^δ_{j,ℓ+1}(c) ⟺ ∃g∈P^δ_{1,ℓ} Lift^δ_{j,ℓ}(c,g)`，证明"上级买卖点必有次级别一买/一卖证书"（存在性，严格证明）+"次级别一买/一卖不会自动乱提升"（需要 U(g)={(c,j):Lift=1}≠∅ 才提升，允许多类重合如 {2,3} 作为合法复合证书）。证明自相似递归在级别平移算子 S_k 下不变。

最关键的概念澄清：**"方向本身是低级别元素的内在属性，不会被未来高一级结构改写。真正需要处理的是它相对于尚未确认父级的F/S/A操作角色。"** 形式化证明：低级别完成元素 g₁...gₘ 后来复合为高级别走势类型 G=Prom_ℓ(g₁,...,gₘ)，系统只添加包含关系 g_i⊏G，**不改写** δ(g_i)（持久性公理：g∈E^fin_{ℓ,t}, t'≥t ⟹ δ_{t'}(g)=δ_t(g)）。真正需要修正的是角色函数 R(g)——若定义为绝对单元函数 R(g)∈{A,F,S} 则依赖父元素（父元素是后来涌现的），这是非法的；正确写法是相对当前操作容器 c 的关系 `R(g;c)`（A当σ(c)=0；F当δ(g)=σ(c)；S当δ(g)=−σ(c)），或相对区间套证书 `R_t(γ)`。"在线不可回溯"只应出现在订单/动作层，不应出现在方向层（方向层根本没有不可回溯问题——它是纯语法不变量）。证明A/F/S严格互斥、高级别涌现不破坏之前分类（R_t(γ_t)和R_{t'}(γ_{t'})是不同证书上的不同函数值，不矛盾）。最终口径："方向是元素属性；包含关系是结构属性；短差/顺势/ambient是相对当前操作容器的关系属性"——三者不可混淆。

## 「声部 vs 级别」两套能指的原文精确定义（#59 悬案回应）

七份文档给出的答案是明确且一致的——**级别（level, ℓ）**和**声部（voice, v）**是两条不同的轴，此前的混淆正是级别容器.pdf/子声部.pdf诊断的根本bug来源：

- **级别 ℓ**：递归趋势容器塔（tower）的结构索引——`C_ℓ`（第ℓ级操作容器集合）、`G_ℓ`（第ℓ级买卖点候选集合）。这是**拓扑/结构轴**：由 `compose_level`（recursive_tower.rs）逐级窗口化聚合三段次级别走势产生，ℓ 严格递增（次级别→上级），是走势分解定理决定的客观索引，不携带"谁持仓"的信息。
- **声部 v = (carrier, entry_certificate, direction σ)**：**持仓/会计轴**——是一个三元组位置实例，`carrier(v)∈C_ℓ`（某个级别的容器）、`entry(v)=g`（触发它开仓的买卖点证书）、`σ(v)=δ(g)`（持仓方向）。声部之间的父子关系由 `p_V(u)=v ⟺ par_C(κ(u))=κ(v)`（子声部的**结构carrier的父容器**等于父声部的carrier）定义——这条关系**继承**了级别容器的父子关系，但声部树本身的"深度"（depth-1/2/3...）是持仓语义上的深度，不是级别ℓ的直接同义词。

两者的精确耦合规则（子声部.pdf §5 + 级别容器.pdf §5）：**子声部通常锚定在比父声部低一级的容器上**（ShortDiff腿：`par_C(d)=c`, d是c的次级别子容器），**且方向必须相反**（`σ(u)=−σ(v)`）——这是级别关系（容器降一级）与声部关系（持仓方向对冲）的"绑定但不同一"：级别降一级是**充分不必要**条件（区间套证书 `γ=(c;g_ℓ,g_{ℓ-1},...,g_e;δ)` 允许更深的区间套跨多级），声部对冲方向才是持仓语义的**定义性**要求。

混淆两者的具体历史bug（级别容器.pdf §6-8 的反证核心）：如果把"买卖点触发开仓"错误实现为"激活买卖点叶子 g 本身"（把 g 当作声部对象），会导致 g 的 host 容器 c=h(g) 从未被标记为 active（因为 g∈G_ℓ 不是 C_ℓ 的元素），进而祖先闭合下所有依附于 c 的子声部永远无法激活——这正是把"级别索引上的一个证书事件"误当成"声部树上的持仓节点"的对象类型错误。
