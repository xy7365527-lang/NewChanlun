## 一、结论：**H2**（O(n²) = 持久化陈旧伪影，非内在；advancing 变体可退回 O(n)）

判别信号 = 持久化 `earliest_unsealed_from`（euf_p，恒锚 stroke 10）vs 本轮重扫新算 `last_rescan_euf`（euf_r，未跨 append 取历史最小值）。CL 逐 bar：

```
       n |    repro advanced     none    clean | late_repro  late_adv late_none | verdict
   50000 |      153     8770    40696      381 |         0      1692      8308 | H2
  150000 |      153    28749   120717      381 |         0      6842     23158 | H2
```

- **reproduce**（euf_r==euf_p，本轮仍在 stroke 10 复现 SecondKind-skip）：**总计仅 153**，且两档 n 完全相同（=同一批最早 bar），**后期（后 20%）late_repro=0**。
- **none**（euf_r==None，本轮重扫区间 [10,n) 无任何 skip）：**主导**（40696/120717）。
- **advanced**（euf_r>euf_p，锚点已 resolve、本轮 min-skip 在更右）：8770/28749。

**判读**：持久化把 confirmed_bound 永久锚死 stroke 10（#88 exp=2.04 O(n²) 的直接成因），但**本轮实际重扫绝大多数根本不复现该锚点**——stroke 10 的 SecondKind 候选在最早 ~153 bar 后即 resolve（`second_seq_has_fractal` monotone，一旦 true 恒 true），此后 euf_r 恒为 None 或右移。**late_repro=0 决定性排除 H1**（锚点候选并非恒未 resolve）。O(n²) 是"不丢弃历史最小值"这条持久化规则的伪影，非 scan_window=0 bit-exact 的内在下界。

## 二、补救：advancing 变体（送 codex 专门 soundness 再审，不单方实装）

**advancing 变体** = `earliest_unsealed_from` 不跨 append 取历史最小值，每次 append 直接取本轮 `euf_rescan`（= 现 `last_rescan_euf`）。据本探针，后期 euf_r 恒 None/右移 ⟹ confirmed_bound 退回末段端 ⟹ rescan O(pending)/bar ⟹ 退回 O(n)。

**soundness 草证**（须 codex 严格化）：kept 区间 `[0, confirmed_bound)` 恒无 pending（false）SecondKind 候选——归纳：append t 的 euf_r 是重扫区间 [resume_t, n) 的 min-skip；[0,resume_t) 由归纳无 pending；`second_seq_has_fractal` monotone ⟹ 一旦 true 恒 true ⟹ 已 resolve 候选不回退为 pending ⟹ kept 前缀稳定 ⟹ prefix stability 成立 ⟹ bit-exact。本探针 late_repro=0 是该草证的经验支撑（早期锚点候选此后从不再 skip）。

**为何不单方实装**：(a) 裁定 #87 prescribe "历史最小值/不丢弃"，advancing 是明确的算法变更；(b) codex 曾 reject `candidate_a_direct`（advancing-ish），本变体与之不同（取重扫区间 min 而非单一 active anchor，且有 kept-区间-无-pending 不变量），但差异点正是 soundness 关键，须 codex re-audit；(c) team-lead 硬约束：H2→报 team-lead 送 codex，不单方实装。

**替代（若 codex 否 advancing soundness）**：accept O(n²)（correctness-first）或切候选 C。本探针不改变这两个 fallback 的有效性，只证明 advancing 值得先审。

## 四、结果包六要素

1. **结论**：H2。#88 的 O(n²) 是持久化历史最小值的陈旧伪影（euf 锚死 stroke 10 但 late_repro=0，本轮重扫恒不复现锚点），非 scan_window=0 bit-exact 内在下界。advancing 变体（不持久化，取本轮 euf_rescan）据探针可退回 O(n)，须 codex 专门 soundness 再审后方可实装。
2. **定义依据**：`second_seq_has_fractal` 关于 strokes 后缀 monotone（一旦某三元组成分形，后续 append 不消除该分形）⟹ resolve 后候选不回退为 pending ⟹ kept 前缀 [0,confirmed_bound) 无 pending 候选（advancing soundness 草证核心）。探针 late_repro=0 经验坐实。PDF §九 prefix stability ⟹ 归纳等价。
3. **边界条件**：(a) 若 codex 证 advancing soundness 草证有洞（某 pending 候选可在 kept 前缀内新生）⟹ H2 补救退回 accept O(n²)/候选C；(b) 探针 late 阈值取后 20%，若改窗口 late_repro 仍 0 则结论稳健（153 全在最早区，与 n 无关已证）。
4. **下游推论**：三选一收敛到 advancing 变体（待 codex 审）为首选，O(n²) accept 为 fallback。#88 修复的 bit-exact 正确性不受影响（advancing 仍 bit-exact，仅改回退深度策略）。
5. **谱系引用**：`project_frontier_resume_bt_too_late`（本探针深化其性能维度）；#88 结果包 `parser-frontier-fix-20260702.md`（边界条件3 触发的判别）。建议 genealogist：「持久化历史最小值 sound 但退化 O(n²)；monotone resolve ⟹ advancing（本轮重扫 min，不持久化）sound 且 O(n)——待 codex 严格化」并入 #88 谱系条目。
6. **影响声明**：改 segment.rs（+last_rescan_euf 诊断字段+手写PartialEq+getter）、mod.rs（+ParseLayerIncr getter）、incremental.rs（+判别探针）。零生产判定改动（语义零改动硬约束）。护航基线：全 lib 通过（PartialEq 改写不影响任何结构对拍——诊断字段排除，earliest_unsealed_from 仍比）。零 commit。
