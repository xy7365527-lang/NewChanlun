# 第一部分：项目背景（你需要知道的最小集）
===================================================================

这是一个把**缠论**（缠中说禅的中国技术分析理论，Chan Theory）形式化为代码、并做量化回测的项目。目标：检验"完整的缠论买卖点策略在真实历史数据上是否有 alpha（超额收益）"。

技术栈：
- 缠论定义 → Rust 引擎（笔/线段/中枢/走势/背驰/三类买卖点识别）+ Lean 形式化证明
- 回测：BTC 等标的全历史逐 bar 模拟，统计每类买卖点信号的收益 μ̂

缠论核心概念（裁决需要）：
- **笔/线段**：K 线经包含处理后的基础走势单元
- **中枢**：至少三个次级别走势重叠的价格区间
- **走势**：趋势（含中枢的方向运动）或盘整
- **背驰（beichi）**：价格创新高/新低但"力度"衰竭（通常用 MACD 面积代理）——是买卖点的核心信号
- **三类买卖点**：第一类（趋势背驰点）、第二类（次级别回抽不破前低/高）、第三类（离开中枢后回抽不回中枢）。买卖各三类，共六种
- **级别递归**：缠论是自相似的——大级别的走势由次级别走势构成，可无限递归
- **区间套**：从大级别的背驰段出发，逐级向下收缩定位到小级别的精确买卖点。这是缠论"精确定位转折"的核心机制

# 第二部分：核心争议 —— "假否证"
===================================================================

此前团队跑了一系列回测，**否证**了缠论策略的 alpha（结论："无显著 alpha"），包括几个检验：奇偶交替相位、σ_higher 调制、(ℓ,q) 三判据、夏普比率、以及"663"逐信号 μ̂ 检验。

但随后一次深度审计发现：**这些否证全部建立在"简化实装"上**——缠论策略的几个核心机制根本没有真正进入回测。于是这些否证的"有效域"被限定在简化子集，**不能外推"完整缠论无 alpha"**。

具体的"假否证根源"（三个 + 两个相关缺口）：

- **P1 区间套零调用（最严重）**：区间套的递归定位证书（下称 N^δ）在 Rust 里**完整实装了，但回测生产链从未调用它**——回测只用了单级退化（base case），从没做过"从大级别背驰段逐级收缩到小级别买卖点"的定位。等于从没测过区间套定位的转折点。
- **P2 MACD 一票否决**：背驰判定用"MACD 面积"作为唯一判据，且是**一票否决门**——MACD 判为"无背驰"的候选段直接被 `return None` 丢弃，从不进入样本。后果：这些被丢弃的候选**永远无法被检验**——这是把"选择机制嵌入了标签定义"，构成选择偏差。
- **P4 类型信息抹除**：一/二/三类 × 买卖侧（六种类型）在统计时被抹成单一方向 δ，μ̂ 分桶键只有 (级别, 方向)、不含类型。后果：buy1/buy2/buy3 的收益混在一个桶里平均——若 buy1 有 α、buy3 无 α，会互相抵消，单类型 α 不可辨（"混合池稀释"）。
- **P7 正规出场未接**：回测出场用"口径4"（反向信号配对平仓），而缠论正规出场逻辑（第一类卖点清仓 CloseRoot / 第三类卖点减仓 ReduceCore）已实装但没接进回测。
- **GAP3 三阶段资金管理未接**：缠论第31课的资金管理三阶段（降成本 → 退本金 → 增股数）在引擎侧实装了，但回测的调度器只派生"降成本/退本金"，**从不派生"进入增股数阶段"**——所以"负成本挣股数"这个模式从没被测过。

## 3.1 区间套递归证书 N^δ（三方已初步一致的定义）

方向化区间套证书 `N^δ_{ℓ↓e}(x_t) ∈ {0,1}`：δ = 交易方向（+1 买/做多，−1 卖/做空），从起始级别 ℓ 递归下钻到执行级别 e。

- **基例（ℓ=e）**：`N^δ_{e↓e} = Conf^δ_e`
  - `Conf^+_e = B1 ∨ B2 ∨ B3`（三类买点析取）
  - `Conf^-_e = S1 ∨ S2 ∨ S3`（三类卖点析取）
- **递归步（ℓ>e）**：`N^δ_{ℓ↓e} = Cand^δ_ℓ(x) ∧ [ J^δ_{ℓ-1}(x) ⊆ J^δ_ℓ(x) ] ∧ N^δ_{ℓ-1↓e}(x)`
  - `Cand^δ_ℓ` = 该级别候选背驰段存在性谓词（见 3.2）
  - `J^δ_ℓ` = 该级别的定位区间（选中候选背驰段的时间区间 [start, end]）
  - `⊆` = 区间套嵌套关系（子区间在时间上被父区间包含：child.start≥parent.start ∧ child.end≤parent.end）
  - 多候选时用固定选择器 `Sel_Θ`：按 (end_time, start_time, idx) 字典序选唯一 → 保证 J 唯一 → 证书唯一
- **关键性质**：任一级 `Cand^δ_ℓ=0`、或任一相邻 ⊆ 不成立、或基例 `Conf^δ_e=0` ⟹ 整个证书 = 0（该次定位失败，合法，非 bug）

**争议点**：区间套的本质是"逐级收缩定位"（J 嵌套链 J^δ_e ⊆ … ⊆ J^δ_ℓ）。有人提出可以先只实装单级的 Cand 判定作为过滤门（不做多级 J 嵌套递归），作为"渐进第一步"。

## 3.2 Cand^δ_ℓ 的判据 —— DivCand 四条件

`Cand^δ_ℓ(x_t) := [存在因果可见的 ℓ 级 δ 交易方向的候选背驰段]`

对候选走势段 s，`DivCand^δ(s,t) = 1` 当且仅当四条件全满足：
1. **方向**：`dir(s) = −δ`（买点 δ=+1 找**下跌**衰竭段；卖点 δ=−1 找**上涨**衰竭段。注意背驰段方向与交易方向相反——这点若写反，多空会全反）
2. **可比较**：存在同一上级语境中可比较力度的前一个同向走势段 s'（如同一中枢前后的离开段）
3. **创新（Extreme）**：买向候选段 s 相对 s' 有更低低点（minP(s)<minP(s')）；卖向有更高高点（maxP(s)>maxP(s')）
4. **力度弱化（Weak）**：s 价格有推进，但"力度"弱于前一可比段 s'（力度衰竭 = 背驰）

其中"力度"用力度泛函 `M_Θ(s,t)`——MACD 面积是它的一个实现（Θ=MACD），"次级别走势力度累积 Σ Power" 是另一个实现（Θ=Force）。

两种语义：
- `SettledCand`（只用已完成段）：稳定、不重绘，适合历史审计/Lean 证明，但"交易太晚"（外层背驰段完成时执行级买卖点已过）
- `LiveCand`（含正在形成段）：适合实盘逐级定位，但正在形成的候选以后可能失效。`SettledCand ⇒ LiveCand`，反之不成立

## 3.3 两套账本（GAP3 的 576 号争议）

回测/执行涉及两套不同构的账本：
- **R 账本**：`R = Π − A − W`（Π=累计利润，A=已投入成本/建仓额，W=已物理提取的现金）。这是 closed_loop（平仓逻辑）主用的账本，其中 **W 恒为 0**（从不真提现）
- **TW 三阶段账本**：`TStage ∈ {CostReduction 降成本, CapitalRecovered 退本金, EarningShares 增股数}`，单向不可逆迁移。提现端（真提取本金 W）属于这套账本

**冲突**：提现端的 W 属于 TW 账本，但回测主链用 R 账本且 W 恒 0——两套账本对接方向未定，导致提现端"增股数"接不进回测。三个方案：
- **A 单账本**：全用 R=Π−A−W，把 TW 三阶段降为观测层
- **B 单 TW**：全用 TW 三阶段账本
- **C 双层并置**：R 和 TW 各管自己的语义层，接口对齐

## 3.4 三阶段资金管理（缠论第31课）与 η⋆

- **CostReduction 降成本**：高位卖出降低持仓成本基（cost_basis）
- **CapitalRecovered 退本金**：`cost_basis ≤ 0`（成本降到零）⟹ 物理提取本金
- **EarningShares 增股数**：本金全额退出后，用纯利润买入更多核心 units（Σ|units| 单调增）

η（负成本缓冲）与 η⋆（安全缓冲阈值，η⋆>0）：
- 预算约束：`η_{n+1} = η_n + g_n − a_n`；且 `a_n + L_wc_{n+1} ≤ η_n + g_n − η⋆`（买入后仍保留安全缓冲，L_wc = 最坏情况损失准备）
- **争议**：η⋆ 该是硬编码常量（如 10000），还是从风险约束导出的状态依赖 barrier `η⋆(x_t) = L_wc_{t+1} + κ·Q_t`（κ = 每股成本下限风险参数，Q = 持仓量）？
- 相关：**OQ-9**——"本金已提取（W≥初始本金 I0）"**不蕴含**"所有旧的降成本腿已闭合（openLegacyLegs=0）"（反例：W=I0 但仍有一条旧腿未平），所以进入增股数阶段的触发条件必须显式合取 openLegacyLegs=0
