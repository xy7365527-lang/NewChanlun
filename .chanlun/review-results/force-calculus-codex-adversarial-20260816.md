## 总裁决

## P1　望远镜恒等式

对任意 \(F:\mathbb Z\to\mathbb R\) 和整数 \(s<e\)，

\[
\begin{aligned}
\sum_{t=s+1}^{e}\bigl(F(t)-F(t-1)\bigr)
&=\sum_{t=s+1}^{e}F(t)-\sum_{t=s+1}^{e}F(t-1)\\
&=\sum_{t=s+1}^{e}F(t)-\sum_{u=s}^{e-1}F(u)\\
&=F(e)-F(s).
\end{aligned}
\]

中间各项逐对抵消，只剩首尾。这是有限项代数恒等式，不涉及极限、收敛或离散近似。

取 \(F=v\)，令第 \(t\) 根 bar 上的带号冲量为

\[
I_t:=\Delta v_t=v(t)-v(t-1),
\]

则

\[
\sum_{t=s+1}^{e}I_t=v(e)-v(s)=L((s,e]).
\]

因为 \(v\) 是笔阶梯函数，笔内部 \(\Delta v_t=0\)，仅在换笔处出现跳变。因此：

\[
\boxed{\text{逐 bar 带号冲量累积}=\text{速度端点差}}
\]

无近似，也没有新增信息。

该结论只适用于累积对象确为带号 \(\Delta v_t\)。累积 \(v(t)\)、\(|\Delta v_t|\) 或 MACD 柱不受此结论保证。

## P2　带号测度的良定性

### 端点约定

如果相邻两笔都使用闭区间表示，共享转折 bar 会同时属于两笔，而两笔速度通常不同。因此“\(v(t)\) 是 \(t\) 所在笔的速度”并未自动定义单值函数。

必须固定一致约定，例如把笔区间写成

\[
(\tau_{j-1},\tau_j],
\]

或直接在笔索引上定义速度，再规定段端点取左侧笔还是右侧笔。以下证明以单值函数 \(v:\mathbb Z\to\mathbb R\) 已经确定为前提。

### 有限可加性

定义

\[
\mu((a,b]):=v(b)-v(a).
\]

若 \(a<b<c\)，则

\[
(a,b]\mathbin{\dot\cup}(b,c]=(a,c],
\]

且

\[
\begin{aligned}
\mu((a,b])+\mu((b,c])
&=[v(b)-v(a)]+[v(c)-v(b)]\\
&=v(c)-v(a)\\
&=\mu((a,c]).
\end{aligned}
\]

对任意由笔端点给出的分割

\[
a=t_0<t_1<\cdots<t_n=b,
\]

同样有

\[
\sum_{i=1}^{n}\mu((t_{i-1},t_i])
=\sum_{i=1}^{n}[v(t_i)-v(t_{i-1})]
=v(b)-v(a).
\]

所以结果与如何进一步细分无关。若同一区间有两种拼接，取两组端点的共同加细即可证明两种表示相等。

### 离散 Stieltjes 带号测度

在有限观测窗 \(W=(m,n]\cap\mathbb Z\) 上，定义原子质量

\[
q_t:=v(t)-v(t-1)
\]

以及

\[
\nu(A):=\sum_{t\in A}q_t,\qquad A\subseteq W.
\]

所有和都是有限和，因此对不交集合严格可加。由 P1，

\[
\nu((a,b]\cap\mathbb Z)
=\sum_{t=a+1}^{b}[v(t)-v(t-1)]
=v(b)-v(a)
=\mu((a,b]).
\]

若速度从 \(3\) 跳到 \(1\)，对应原子质量为 \(-2\)，所以它是带号测度而非正测度。这正是离散的 Lebesgue–Stieltjes 型构造。

限定如下：

- 在有限数据窗上，它是真正的有限带号测度。
- 在无限 \(\mathbb Z\) 上，可无条件称为局部有限构造。
- 若要称为全局有限带号测度，还需例如

\[
\sum_{t\in\mathbb Z}|v(t)-v(t-1)|<\infty.
\]

### “零参数”的准确含义

一旦以下内容全部固定：

1. 两个段的四个形态学端点；
2. 公共端点归属及端点取哪一侧速度；
3. 笔速度的价差、方向和 bar 计数规则；

则

\[
L(b)=v(e_b)-v(s_b),\qquad L(c)=v(e_c)-v(s_c)
\]

被唯一确定，不需要 MACD 窗口、平滑系数、积分步长或权重。

但正本目前仍写道：

> “`v(段初)` 取值：转折点上速度理论为零，实装时取第一笔还是取零，须定；”
>
> “段末速度取「当下那一笔」还是「最后完成的那一笔」——涉及当下可判定性。”
>
> ——「★力度的精确定义／尚未落定的」，`.chanlun/definitions/beichi.md:450-454`

因此，“零参数”在题设已经给定单值 \(v\) 的数学模型内成立；对尚未选定端点采样规则的生产实例，只能条件成立。

## P3　总变差与端点差不同

令段内速度依次为

\[
v_0,v_1,\ldots,v_n,\qquad \delta_i=v_i-v_{i-1}.
\]

则

\[
L=\sum_i\delta_i=v_n-v_0,
\qquad
TV=\sum_i|\delta_i|.
\]

定义

\[
P=\sum_i\max(\delta_i,0),\qquad
N=\sum_i\max(-\delta_i,0).
\]

于是

\[
L=P-N,\qquad TV=P+N,
\]

故

\[
TV-|L|
=P+N-|P-N|
=2\min(P,N)\ge0.
\]

所以

\[
|L|\le TV.
\]

并且

\[
TV=|L|
\iff P=0\ \text{或}\ N=0.
\]

也就是：

\[
\boxed{TV=|L|\iff\text{所有非零 }\Delta v\text{ 同号}}
\]

零跳变不构成变号；若正、负跳变同时出现，则严格有 \(TV>|L|\)。

### 显式反例

取两个同为向下、相邻笔方向交替的五笔段：

\[
v^{(b)}=(-100,10,-98,10,-96),
\]

\[
v^{(c)}=(-100,90,-200,80,-99).
\]

两者均为 \(-,+,-,+,-\)，且速度总和都为负，聚合方向相同。\(b\) 的主方向速度绝对值 \(100,98,96\) 平滑减小；\(c\) 剧烈震荡但首末速度净变化很小。

对 \(b\)：

\[
L(b)=(-96)-(-100)=4,
\]

\[
TV(b)=110+108+108+106=432.
\]

对 \(c\)：

\[
L(c)=(-99)-(-100)=1,
\]

\[
TV(c)=190+290+280+179=939.
\]

因此

\[
L(c)=1<4=L(b),
\qquad
TV(c)=939>432=TV(b).
\]

端点差判 \(c\) 更弱、构成背驰；总变差却判 \(c\) 路径活动更强、不构成背驰。两者能够给出相反结论。

### P4(a)　代理链是否只有一处近似

正本逐字主张：

> “`柱面积 = 8 × ( DEA(段末) − DEA(段初) )`”是“精确恒等式”；
>
> “同色柱区间两端 `H ≈ 0`……`柱面积 = 8 × ΔDIF`”是“近似（唯一一处近似）”；
>
> “匀速趋势 `P(t)=P₀+vt` 下……`DIF = 7v`”是“精确计算”。
>
> ——「★力度的精确定义／推理链」，`.chanlun/definitions/beichi.md:374-383`

结论：除端点近似外，还有隐藏近似和附加条件。

#### 第2步：望远镜本身精确，但需四个限定

令 \(D_t=DIF_t\)、\(E_t=DEA_t\)、\(q=1-\alpha\)。信号 EMA 满足

\[
E_t=\alpha D_t+qE_{t-1}.
\]

采用中式柱

\[
H_t=2(D_t-E_t)
\]

时，

\[
E_t-E_{t-1}=\frac{\alpha}{2q}H_t.
\]

signal=9 时 \(\alpha=0.2\)，所以

\[
H_t=8(E_t-E_{t-1}),
\]

以及

\[
\sum_{t=s+1}^{e}H_t=8(E_e-E_s).
\]

但必须限定：

1. 必须保留符号。几何面积 \(\sum|H_t|\) 在一个单色 run 上是 \(8|\Delta E|\)，不是无条件的 \(8\Delta E\)。
2. 闭区间 \([r,e]\) 的和对应 \(E_e-E_{r-1}\)，存在明确的 off-by-one 约定。
3. 必须是连续区间。若在一个形态段中筛出多个不连续同色 run，只能逐 run telescope。
4. 系数 8 使用 \(H=2(DIF-DEA)\)。生产代码使用 `hist=DIF-DEA`，对应系数是 4。

这些不全是数值近似，但缺失时原等式不能直接成立。

#### 第3步：已声明近似

因为 \(D_t-E_t=H_t/2\)，

\[
(D_e-D_s)-(E_e-E_s)=\frac{H_e-H_s}{2}.
\]

所以 \(\Delta DIF\approx\Delta DEA\) 需要端点柱差相对于 \(|\Delta DEA|\) 足够小。离散 sign-change run 的首末非零 bar 并不是连续零交叉点，“刚变号”不能保证端点柱足够接近零。

#### 第4步：隐藏的稳态近似

仓内 EMA 使用首值初始化 \(EMA_n(0)=P_0\)。对

\[
P_t=P_0+vt,\qquad
\alpha_n=\frac{2}{n+1},\quad q_n=1-\alpha_n,
\]

递推的精确解是

\[
EMA_n(t)
=P_t-v\frac{q_n}{\alpha_n}(1-q_n^t).
\]

因此

\[
DIF_t
=7v
+5.5v\left(\frac{11}{13}\right)^t
-12.5v\left(\frac{25}{27}\right)^t.
\]

有限 \(t\) 时通常不等于 \(7v\)；只有 \(t\to\infty\) 时趋近 \(7v\)。一段趋势从任意历史状态中途开始时，还会携带依赖段前 EMA 状态的记忆项。

而且教义中的笔速度是端点价差除以 bar 数，只是平均斜率；笔内实际收盘价不必逐 bar 满足 \(P_t=P_0+vt\)。MACD 又依赖整个历史路径。因此，真实笔端点上的 `DIF=7v` 不是恒等式。

该式只有在价格对足够长过去始终严格仿射、EMA 已处于稳态特解时才精确。

#### 第5、6步

由于第3步误差不小，第4步又不是实际 MACD 的一般恒等式，所以

\[
\text{面积}=56\Delta v
\]

不能作为严格推论。

即使该比例在仿射稳态路径上成立，它也只约束这一小类路径；许多在仿射路径上为零、在震荡路径上非零的泛函都能加到 \(\Delta v\) 上。因此代理链不能证明 \(\Delta v\) 是唯一可能定义。

**P4(a) 裁决：正本“唯一一处近似”的说法不成立，严格链在第4步断裂。**

### P4(c)　生产绝对值面积

正本写道：

> “默认代理 = MACD 同色柱面积之和。”
>
> ——「力度是什么／两层结构」，`.chanlun/definitions/beichi.md:274-277`

生产函数却明确计算闭区间内

\[
\sum|hist_t|,

见 `rust/src/theta_v0/classifier/divergence.rs:227-239`。

令生产 \(h_t=D_t-E_t\)。由 EMA 递推，

\[
h_t=\frac{1-\alpha}{\alpha}(E_t-E_{t-1}).
\]

signal=9 时，

\[
h_t=4(E_t-E_{t-1}).
\]

因此生产面积严格等于

\[
A_{\mathrm{prod}}
=\sum_t|h_t|
=4\sum_t|E_t-E_{t-1}|.
\]

这测量的是 `DEA` 的缩放总变差。

单一同色 run 内，

\[
\sum_{t\in R}|h_t|
=\left|\sum_{t\in R}h_t\right|
=4|\Delta E(R)|.
\]

若形态段跨多个异色 run \(R_1,\ldots,R_m\)，则

\[
A_{\mathrm{prod}}
=4\sum_j|\Delta E(R_j)|
\ge4\left|\sum_j\Delta E(R_j)\right|,
\]

正、负增量同时存在时通常严格大于。不同颜色之间本应发生的抵消已被绝对值删除。

生产单测还用 `hist=(1,-2,3,-4)` 明确锁定混色绝对值求和，见 `divergence.rs:987-994`。

即便暂时接受每个 run 上

\[
DEA\approx DIF\approx7v,
\]

生产口径也至多近似

\[
28\sum_j|\Delta v(R_j)|,
\]

中式 \(H=2h\) 才对应系数 56。它近似的是路径总量，而非整段带号 \(\Delta v\)。

**P4(c) 裁决：生产 `segment_macd_area ≈ 56×Δv` 不成立。只有整个段恰为单一同色 run，并补上方向、索引及稳态条件时，才可能退化为端点差的绝对值版本。**

### P4(d)　对用户问题的最终回答

若“逐 K 线累积冲量”指

\[
\sum_{t=s+1}^{e}[v(t)-v(t-1)]
\]

且保留符号，则

\[
\sum\Delta v=v(e)-v(s)=L.
\]

它与端点差完全相同。

若累积

\[
\sum_{t=s+1}^{e}|v(t)-v(t-1)|,
\]

得到的是总变差 \(TV\)，是独立候选，可与 \(L\) 给出相反背驰判定。

若“像 MACD”字面指累积柱子：

- 单一 run 的带号柱和精确给出缩放的 \(\Delta DEA\)，并非直接给出 \(\Delta v\)；
- 跨 run 的 \(\sum|hist|\) 给出缩放的 \(TV(DEA)\)；
- 从 DEA/DIF 到笔速度还依赖已经失效的端点近似与稳态假设。

正本关于形态学的原文是：

> “`L = F(末) − F(初)` 里的四个端点 `b初`/`b末`/`c初`/`c末` 全部由形态学钉死……而笔、线段、中枢的构造本身是确定的、无参数的。”
>
> “⟹ 端点一钉死，`F(末) − F(初)` 就是精确的。”
>
> ——「★『精确』二字的来源」，`.chanlun/definitions/beichi.md:344-352`

以及：

> “⟹ MACD 需要参数，是因为它没有结构，只能拿参数化的平滑去凑；缠论有结构，不用凑。”
>
> “定义本身零参数。”
>
> ——「★为什么缠论这边不需要参数」，`.chanlun/definitions/beichi.md:391-402`

数学上的裁决是：

1. 作为良定性理由，条件成立：固定结构、单值 \(v\) 和端点规则后，端点差唯一且无 MACD 参数。
2. 作为唯一性理由，不成立：同一结构也会把 \(TV(v)\)、峰值、振幅等其他零参数泛函定死。
3. 作为 MACD 代理有效性的证明，不成立：形态学钉死端点与代理是否准确是两个独立命题。
4. 当前生产端点速度约定仍未全部裁完，故只能说数学模型零参数，不能提前说运行实例已经完全无选择。

## 最终结论

\[
\boxed{\text{带号逐 bar 累积}=\Delta v=\text{端点差}}
\]

\[
\boxed{\text{绝对值逐 bar 累积}=TV(v)\neq\Delta v\text{，是独立候选}}
\]

端点差是数学上干净、条件零参数的候选定义；但现有 MACD 代理链没有严格推出它，更没有证明它优于同样零参数的总变差候选。
