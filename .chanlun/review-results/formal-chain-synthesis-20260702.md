## 1. 推导链主线重建（37 份 PDF 按下载时间序＝推导演进序）

链是一条**从"结构完备"逐步逼近"经济有效"的单调收敛**：先把缠论完全分类严格公理化（6-25~28），再把递归/级别/持仓对象厘清（6-29），再把 alpha 的统计判定与去污体系建起来（6-30），最后自己指出体系里所有还没跑通的缺口（7-01）。每步核心命题各一句：

### 6-25~28 完全分类奠基（8 份 → A 组 + B 组部分）
1. **推导完全分类 / (1)**：数学"完全分类"最严标准＝双射分类定理（不变量满足不变性+完备性+可实现性 ⟹ 商集同构）；缠论版＝固定级别互斥穷尽分区 + 唯一递归分解 + 无前视全定义状态转移 δ:S×E→S（全函数）+ 全定义应对 π:S→A。
2. **推导完全互斥分类**：角色轴 Role(e)∈{RootDir,SameDir,SubFollow,ShortDiff} 4 类互斥穷尽 × Side∈{做多,做空} 正交；**短差＝Sub∧反父方向＝父仓保持+次级别反向双开**；多空分账本不净额。
3. **递归完全分类买卖点**（最深）：去根化（无特殊根级别，只有前沿 ℓ_max）；**64 类买卖点向量 b_ℓ∈{0,1}⁶ 非坍缩**（六买卖点可重合）；区间套递归证书 N^δ 要求 **[J^δ_{ℓ-1}⊆J^δ_ℓ] 严格单调嵌套**；R(g)=(H,V,δ) 18 类；**级别平移自相似 𝒞_Θ(S_k x)=S_k𝒞_Θ(x)** 是硬公理。
4. **买卖点**：覆盖净收益 G_e>0 端点定向恒真（结构层 soundness，非 performance）。
5. **绝对资本**：非平凡尺度等变 + 固定绝对资本上限 + 全域策略等变，三者不相容；修复 A（资本改协变量，全域自相似）/B（承认资金层打破自相似）/C（固定资本+binding regime 分类）。
6. **最高级别走势类型**：**方向是低级别元素的内在属性，不被未来高级结构改写**（持久性公理）；需相对当前操作容器写角色 R(g;c)，绝对角色函数非法。

### 6-29 递归结构与级别（8 份 → C 组 + B/D/E 部分）
7. **anc**：per-bar 全量重建 ⟹ 旧 held 身份丢失 ⟹ AncOK 剪 depth>0（身份层剪枝，非交易逻辑）；引入 persistent registry，confirmed prefix immutable。
8. **级别容器 / 2**：开仓必须激活"容器/位置实例"而非"买卖点叶子"（对象类型错误诊断）；AncOK 是过滤约束不是父声部生成器。
9. **子声部**：P1（extract tree 只取最高链）∧P2（hostOf 严格右端点）∧D（全格 BSP 可操作）**三者不可同时成立**——orphan frontier 占 64%，子声部结构性恒零是定理不是 bug；解＝双视图（结构树 T_i vs 操作 carrier 森林 K_i，K_i endpoint-complete）。
10. **递归证明**：Lift^δ_{j,ℓ}(c,g)=Host∧Nest∧Context∧Fresh；"上级买卖点必有次级别一买/一卖证书"（必要非充分），不会自动乱提升。
11. **多空对冲**：净额 NAV 不可识别定理（N^{#5}=N^{base}⟹ΔSharpe=0 是数学必然）；双开抵消定理（同标的同单位反向双开 ⟹ 价格 PnL≡0，扣成本<0）；分账本层分离 P^sep。
12. **买卖点 alpha / 2**：择时 alpha 判定 E[N^bsp·ΔP−C]>0；π^cov（覆盖净额）≠π^bsp（择时）；前视禁止（定理3）。

### 6-30 alpha 检验体系（11 份 → B 组 + E 组）
13. **alpha / 严格alpha / 买卖点alpha2**：V*=E[max(0,max_a μ)]>0；存在赚钱因果策略 ⟺ P(max_a μ(z,a)>0)>0；LCB 门控 χ_t、no-trade a_0、鞅不可能；|E|=O(n) 复杂度。
14. **缠论的全互斥定义策略 / 2**（当前 goal 原文出处）：完整状态 **z=(ℓ,δ,I_γ,r,σ_p,ω,β,κ,d,c,m)**；细分类优势定理 V(Z)≥V(Y)（细化不降 oracle alpha，代价样本稀疏）；全互斥解释器 C_j=P_j∧⋀¬P_k + C_0 兜底；**二值背驰谓词 D_t^δ∈{0,1}，力度 β 是细分非定义必要**。
15. **经济正条件**：端点序关系"顶高于底"（结构-价格正条件）**推不出**因果扣成本净收益为正（经济正条件），需额外 CEP 公理 `q_e ε_e(P_out−P_in)−C_e≥η_e>0`。
16. **过拟合**：结构分类器零参数不过拟合，但收益估计器 μ̂+选择器 χ 必然过拟合（winner's curse）；标准解＝shrinkage+LCB+OOS+block/cluster+Le Cam 两点下界。
17. **alpha检验 / 多级别检验**：统计判定四定理（n_eff 自相关校正 / 功效门 n_eff>(1.645·CV)² / 三态判据 / block bootstrap / 删尾 / 方向不对称）；严格定理 **Π_0⊆Π_{≤L}⟹V_{≤L}≥V_0**（L0-only 无 alpha 推不出多级别无 alpha）；regime 不被全互斥分类自动消灭。
18. **on2**：|E^can|=O(n)（DAG 共享 b<m 才保线性）；Eat(e) 证明有缺口，充要条件是祖先生命期半开区间包含不变量 WF-Contain。

### 7-01 缺口与收敛（10 份 → C/D/E 组）
19. **奇偶相位**：BTC 461 万 bar 级别×方向 μ̂ 完美奇偶交替；三机制（几何真结构/出场滞后/级别即 regime）**不可识别**，参数>12 需反事实。

23. **问题**：Π_simp≠Π_full（五处结构不等价 P1/P2/P4/P7/GAP3）；旧回测"无 alpha"只否证 Π_simp；账本选 C；完整重跑需三层分离验收（信号/组合/资金管理不可混算一个 alpha 数）。
24. **k的条件**（实为 GAP3 κ 严格定位，非 K 线预处理）：κ 对价格不可识别（风险偏好参数）；κ 太大 ⟹ 永不进增股阶段。
25. **关于背驰**：力度＝完整递归签名 𝔉_ℓ（MACD 面积只是一个投影坐标）；力度比较＝支配序，无唯一全序，三值 {Weak,NotWeak,Incomparable}；背驰四条件。
26. **区间套**：跨级 rung 用端点相等定位是区间包含的真子条件 ⟹ 系统性 false negative ⟹ **depth≥2 恒零是伪影非结构真相**；正确语义 J_child⊆J_parent；frontier 未确认必须重算。

**链的自我诊断（贯穿 6-30~7-01，最关键的元命题）**：原文反复强调 **分类完备≠有效性（≠赚钱）**——结构完备只是理论严密的必要条件，不是 alpha 的充分条件。这与我们 partition-proof 的"L0 同义反复、语义在 L2"认识论**完全同构**。链没有承诺缠论一定赚钱；链承诺的是"如果缠论赚钱，赚在哪个 z、怎么严格检验它"。

## 3. 续接方案（3 条具体路线 + 推荐顺序）

### 路线 A — 区间套问题①修复效果重验（廉价解锁，最高性价比）

- **原文依据**：区间套.pdf §2「端点相等是区间包含真子条件」+ 定理2「Γ_old⊊Γ_new」。
- **工作量**：小-中（1 泳道，重跑 + 对照 depth 分布，无新设计）。
- **与 M1 关系**：**解锁一大批被伪影污染的结论**——"C3 level==1 关闭=结构无小转大 alpha"（0/84）、"depth≥2=0=高级别无 alpha"、"#5 α=0/ΔSharpe=0" 在问题①未修前其"结构无 alpha"解释被端点相等 false negative 污染（D 组 + codex 自己在 xzd2 审计承认）。修复后重验：若仍 0＝结构真相（可安心据此判定），若非 0＝之前多级别否定结论需全部重估。**这是判断"多级别 alpha 到底有没有"的地基校验，必须先做。**
