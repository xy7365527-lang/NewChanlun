## 1. 结论

按裁定五个要点全部落地：

1. **MuClass 第 9 维**（`mu_estimator.rs`）：`pub sigma_higher: Option<i8>`。`Some(v)` = 生产路径塔真值
   （+1 上级净涨 / −1 净跌 / 0 持平或无上级——**0 是计算结果非未知**）；`None` = 裸证书口径无 tower/bars 源
   （`from_certificate`，诚实 None 不伪造，231 号，对齐 `horizontal: Option<Horizontal>` 先例）。
   与 σ_p（parent_dir）并列独立分量，不合并（#81 反对合并的原理由仍成立，裁定原文确认）。
2. **单一来源**：`sigma_higher_at` 从 econ_positive.rs 上移 `selector.rs`（`pub(super)`），z 构造（第 9 维）
   与 666 号信号分解（`SignalDecomp.sigma_higher`）共用同一函数；econ 顶部 import 消费，函数体逐字不变。
3. **护航点（裁定明文）**：`z_of_candidate(c, tower, bars)` / `z_of_candidate_with_force(c, fp, tower, bars)` /
   `filter_gamma*(…, tower, bars)` **签名强制携塔**——"训练表填真值/实盘查询填 None"的静默未见类别退化
   在类型层不可构造（不存在无塔重载）。生产 χ 过滤（selector.rs `filter_gamma_with_admission` 内
   `z_of_candidate`）与 fill loop（runner.rs `pi_theta_fill_loop` 传 `&tower_i, bars`）已接真值。
4. **调用点一致性**（裁定要求全检）：econ_positive `collect_signals`（+`debug_assert_eq!` 护栏：z 内
   σ_higher 与 SignalDecomp 口径同值）、econ dx 探针（与生产同源）、`l3_delta_r_alpha.rs`
   `build_mu_from_bars` + `enumerate_candidate_z`、runner fill loop——全部传塔真值。
5. **碎片化防护（H 轴先例复用）**：`UClass::project_to_u` **不读** σ_higher（canonical z 完备供 oracle
   上界，UClass 降维供 selection 抗 winner's curse）——零新设计，文档显式声明。

**perm_test 桶键不动**（任务明令）：fullz δ-free base 仍 8 维；fullz 重构闭包显式 `sigma_higher: None`
（防经 `..*c` 泄漏 stratum 首条 trade 的代表值——键携带未分层的伪信息）。**顺带修复一个被本变更激活的
真陷阱**：`wverify_run::wverify_fullz` 判定键原为全维恒等 `|c| *c`——records 现带 `Some(v)` 而 perm 表键
`None`，会全表 miss（正是护航点针对的同款口径分叉，只是发生在 records↔perm 表之间）。修复 = 判定键同投影
`sigma_higher→None`，分层与桶数语义均不变。

**验证**：最终 `cargo test --lib` **1436 passed / 0 failed / 108 ignored**（G4/G7/#115 全部落树后）；
`cargo check --all-targets` 全绿。（过程记录：中途一次 1418+1 fail 的 `extract_signals_bit_exact_
digest_guard` 后证实为与 ws-route3 的 GOLDEN 常量更新赛跑——其批内已按注释预告完成诚实重算
0x56ed→0x90c7，guard 现绿；该 digest 路径不含 MuClass，与 G2 无因果。）

**GOLDEN/维度断言诚实处理**：lib 内单测全走 `from_certificate`（σ_higher=None 常量分量 ⟹ 分桶不变）
⟹ 1418 基线零翻转，无需重算任何 μ GOLDEN。runner 两个手建 est 的 χ 测试补 `sigma_higher: Some(0)`
（合成闭包空塔 ⟹ 查询侧 `sigma_higher_at(&[],..)=0`，与 H=Some(First) 同款口径对齐，变化来源=查询侧
z 现携带塔真值）。文档维数订正：mu_estimator 头部枚举 +σ_higher 条目；wverify"7 维"→"8 维桶键+第 9 维
不进 prereg 桶键"（7 维本已过期于 force_state 第 8 维落地时）。

## 3. 边界条件（结论翻转条件）

- 裁定 G2 翻转条件原文：若 PDF 后续拆分 z_state/z_alpha 两粒度且 σ_higher 只属前者；或实测证明
  σ_higher 可由 z 既有维度确定性推出（无新信息量）——则第 9 维应回退。

  （assemble_gamma 对单级分类产出跨级候选）——单一来源前提破裂，须停下上浮而非改断言。
