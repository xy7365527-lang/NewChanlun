## 1. 结论

MuClass 从 9 维扩至 **13 维**（新增 `cand_channel`/`nest_depth`/`origin_level`/`risk_mode`，
均 `Option` 诚实 None 口径），每个新维数据源**真接**（无常量占位）；§6 其余条目按「已接/
代数派生/分解承载/诚实缺口」四类逐条裁定（见 §3 对照表）。`cargo test --lib` **1438 passed / 0
failed**（基线 1436 + 新增 2）；`cargo check --all-targets` 绿。

接入架构（G2 先例完全沿用）：

- **装配参数 `ZExt`**（selector.rs）：新维数据源在调用方语境（准入门证书在 econ 统计层、账本态在
  runner π fill loop），经 `ZExt` 显式携带进 `z_of_candidate*`——**签名强制**（G2 tower/bars 护航点
  同款），无源路径显式传 `ZExt::NONE`（可 grep 审计的诚实声明），静默遗漏在类型层不可构造。
- **训练/查询同口径**：runner fill loop 中**同一 `ext_i` 变量**同时喂 χ 查询（filter_gamma）与训练
  登记（entry_z）——同口径由共享变量保证，「训练 Some/查询 None 全表 miss」（G2 修过的静默退化）
  不可构造。
- **canonical vs selection 分层**（约束②）：新维只进 canonical z；`UClass::project_to_u` 不读新维
  （新增测试断言）——抗碎裂 + i_class×δ 共线教训。
- **置换/perm 桶键不动**（约束③）：perm_test fullz 输出键 + wverify 判定键四新维**显式 None**
  （防 stratum 代表值经 `..*c` 泄漏——risk_mode 随 bar 变、同 stratum 可异值，泄漏真实存在非防御
  性；G2 同款修法）。分层裁定统一留 #135 prereg。

## 2. 定义依据

- **PDF §6（页4）z 完整清单原文**：`z=(ℓ, e, δ, I_γ, Ndepth, CandType, ForceState, Jchain,
  σ_higher, σ_p, role, posState, shortDiff, H, TStage, ηBucket, RiskMode, CostBucket, MarginState,
  ExitType)`，逐维解释行：「ℓ,e：起始级别、执行级别」「Ndepth：区间套递归深度」「CandType：
  LiveCand/SettledCand/Force 口径」「Jchain：区间套包含链」「TStage：CostReduction/
  CapitalRecovered/EarningShares」「RiskMode：正常/去杠杆/强平」等。
- **执行级/起始级语义**：econ_positive collect_signals 有效域注释「执行级 e=lvl，rungs 从
  tower[lvl+1..] 收集上级语境」——现 `MuClass.level` 自始装执行级 e，§6 缺的是链顶起始级 ℓ。
- **Ndepth=rungs.len() 前缀定理**：econ_positive `effective_nest_depth` 文档——n_delta 逐级
  `cand ∧ is_sub` 短路 ⟹ **通过门的证书所有 rung cand=true ⟹ effective_nest_depth==rungs.len()**。
- **Jchain 连续性**：nest.rs `NestCertificate` 结构——「rungs 从高到低：rungs[0]=级ℓ，
  rungs[last]=级e+1」「结构上不可表达 e>ℓ（无负梯级）」——链逐级相邻无跳级。
- **RiskMode/MarginState**：margin-design §2.4-§2.7（risk.rs M0-M4 状态机，equity 对
  {0, MM, MM+B1, MM+B2} 阈值完整划分）。
- **F_t 可测铁律**：mu_estimator.rs 模块头因果性硬约束（alpha2 §5 / zero-lookahead）。
- **G2 终裁**：codex-q1-spec G2（PDF §6 权威 > codex #81 误读；σ_higher 先例=分层模式模板）。

## 4. 边界条件（结论翻转点）

1. **#124 GAP3 桥落地** ⟹ TStage/ηBucket 缺口关闭条件成立，须经 ZExt 通路接入（不接=违本表
   证明义务）。
2. **CandType 读法被异质审计推翻**（若 codex 裁定 PDF 字面 Live/Settled/Force 必须为独立维而
   非门通道轴）⟹ `cand_channel` 需重命名+Live 候选生产者升级为实装缺口上浮。
3. **出场侧 μ(z,exit) 实装** ⟹ ExitType 须进出场时刻 z 构造点（当前该构造点不存在）。
4. **margin 注入 run 中非 Normal bar 的 χ 行为**：G3 后查询键携 risk_mode ⟹ 训练段未见的
   mode 值落 treat_empty 分支——这是第 13 维**有意的账本态条件化语义**（不同风险区不共享 μ 证
   据），非 bug；但意味着 margin 注入跑批的 ΔN/ΔR 可能与 G3 前不 bit-exact——**#135 重冻结基线
   时必须重跑**。无 margin 注入（当前全部 l3 跑批现状）equity>0 ⟹ mode 恒 Normal ⟹ 行为
   bit-exact（1438 绿佐证）。
5. **恒等式 `origin_level = level + nest_depth`**（Nest 通道）破 ⟹ z_of_candidate debug_assert
   崩=装配 bug 信号。
6. l3 诊断（三路分解/假设4/两源分解）经 `project_mu_for_enum_diag` 投影表查询（样本级精确边缘
   化，条件均值塔性质）——若未来诊断需按账本态条件化归因，须去掉投影并给枚举侧补账本态源。
