## 1. 结论

`build_mu_from_bars`（喂 χ 选择器/W-VERIFY/econ_positive 全部 alpha 判定的核心统计管线）的出场口径从 PDF §9 点名废弃的 τ^reverse（下一个任意反向信号，不限同 level/同腿）**替换为生产 π fill loop 的 typed exit**——训练阶段跑真实 `pi_theta_fill_loop`（interpret/coverage_step_from_buckets/KThetaRiskGate/延迟成交/censored 全链），输出不可变 `TypedTradeLedger`，再从 ledger 构造 `MuObservation`/`ResidualTrade`。τ^reverse 平行简化状态机整体删除，不留 fallback（no-patch）。

**架构落点**（严格遵守分歧A 裁决——`interpret(gamma, active) -> Buckets` 签名不变，∃! 证明锚 `ℛ_Θ(Γ,A)` 不动）：

**exit_type 判定全分类**（PDF §9 五枚举全定义，BTC 冒烟断言计数守恒）：
- 反向关闭（interpret 规则2）→ `reverse_exit_type`（P5/P6/P7）
- 静默离场（§13 AncOK 连带剪/Stale prune，无触发信号）→ 子声部（入场 role.v≠Ambient）=CloseShortDiff，根腿=CloseRoot
- 窗口终点未离场 → Hold（censored 到末可交易 bar close，与旧 censored 语义一致，不偷看窗外）
- RiskExit → 现恒 0（见边界条件③）

**L2 冒烟证据**（BTC prereg OOS 窗前半 16K bar，--release）：ledger 18 腿——CloseRoot 6 / ReduceCore 11 / CloseShortDiff 0 / RiskExit 0 / Hold 1；μ 表 8 类 / 18 残差记录。诊断测试 `typed_ledger_btc_smoke`（#[ignore]）固化跑法。

**★核心语义后果（必读）**：入场口径随出场同步收敛——μ 观测对象 = 生产 π **真正开腿**的信号（interpret open 桶 + AncOK 准入），record 桶/slot 冲突/AncOK 被剪候选不再入 μ。旧口径为生产永远不会入场的候选估 μ = 训练/生产分布错配；新口径 = treatment-on-the-treated。代价：**μ 样本量下降约两个数量级**（16K 半窗：旧≈数百信号 → 新 18 腿；每 (level,σ) slot 同时至多一腿）。这是生产 π 语义的忠实镜像，非本工位简化。

## 2. 定义依据

- 《完整的策略.pdf》§9：`Exit_Θ(v,x_t) ∈ {CloseRoot, ReduceCore, CloseShortDiff, RiskExit, Hold}` 类型化出场语义；`X_i^old`（τ^reverse）明令废弃。输入特征满足：ledger 每腿 exit_type 恰为五枚举之一（守恒断言），出场时点由生产解释器规则2/AncOK/censored 决定。
- codex-q1-spec G4 终裁：「不在 build_mu_from_bars 里重造 typed exit 状态机。最小正确路径是复用 π fill loop / interp::interpret / KThetaRiskGate，让训练阶段的生产 π 循环直接输出一份不可变的 TypedTradeLedger」——逐字兑现（typed_ledger_from_bars 就是生产 fill loop，χ≡1）。
- 裁定4 + 补记分歧A（team-lead 裁决）：typed 语义在 interpret 与 coverage_step_from_buckets 之间的组合层产生，interpret 签名不变——`pi_theta_step_traced` 即该组合层。
- G5 映射 §6.1/§6.2（g5-interpreter-mapping-20260703.md）：P5/P6/P7/P1/P0 ≡ 五枚举；G4/G5 共用单源（reverse_exit_type 放 interp.rs 供 #124 复用）。
- G7 后 K_Θ 语义（#133 f1c9700332）：fill loop 重接经 `pi_theta_step_traced` → `coverage_step_from_buckets(..., risk: Option<&RiskConfig>, ...)`——G7 的 apply_gross_cap（legs 折叠前）在 ledger 腿事件观测的同一路径内，`enforce_gross_cap` 默认 false 时 bit-exact。

## 3. 边界条件（结论翻转条件）

① **二类反向归 CloseRoot**：PDF §9 五枚举无二类单列；本实装取"二类=一类的次级确认，同属根反转语义；三类=中枢离开确认=减仓语义"读法。若 ws-g5interp/编排者裁定二类应归 ReduceCore（或其他），改 `reverse_exit_type` 一处即可（单源），μ 表按新判据重算。已向 ws-g5interp 征求意见（msg 054c72fd）。
② **silent drop 归置**：AncOK 连带剪/Stale prune 在 PDF §7 无直接谓词对应（§13 结构剪枝）。本实装归最近语义（子声部→CloseShortDiff/根→CloseRoot）。若 G5 真统一后解释器为结构剪枝产独立事件类型，ledger 判定移至该事件源。
③ **RiskExit 恒 0 的有效域**：现架构 `force_flat` 只 clamp p*，不清活动腿（幽灵腿缺口，补记裁决归 #124 P1 短路修）——ledger 忠实记录生产语义，不提前堵（避免与 ws-g5interp 双改）。#124 落地「P1 成立 ⟹ prev_active 逐条 RiskExit 清空」后，本 ledger 经 StepTrace closed/silent 通道自动产 RiskExit——**若 #124 的 P1 短路绕过 StepTrace 层另起通道，则 ledger 会漏记 RiskExit，须同步接线**（已在征求意见中声明接缝）。
④ **价格口径**：entry_px/exit_px = 决策 bar close（名义单位，与旧口径同价格语义；G4 只改出场时点规则）。若未来裁定 X_i 应用 exec bar fill 价（延迟成交语义入统计层），改 ledger 登记点即可（腿级无独立成交这一约束不变）。
⑤ **G4 翻转条件**（codex 原文）：若逐笔对照证明 τ^typed ≈ τ^reverse 且 μ/χ/W-VERIFY/L3 结论两口径稳定，旧口径可复活为合法近似——BTC 冒烟已初步反证（18 腿 vs 数百信号，出场结构完全不同），正式对照在 #135。
