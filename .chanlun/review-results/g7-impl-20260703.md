## 1. 结论

生产 K_Θ 现在包含最大毛头寸约束，实装在 codex 终裁钉死的位置——`coverage_step_from_buckets` 中 legs 折叠成 `net_target_units` **之前**（净标量已丢失毛敞口信息，事后诊断门被 #122 拒绝）：

1. **激活开关**：`RiskConfig.enforce_gross_cap: bool`（config.rs），default `false` = 不激活 = frozen Θ v0 bit-exact；毛 cap **复用** `gamma×base_units`（与净 cap 共用同一 Θ_risk 参数，#122 裁定暂不拆 gross_gamma/net_gamma）。
2. **判定接入 risk.rs**（codex decide 附带确认项2，条件 confirm 的执行）：新增 `risk::gross_units_cap` / `risk::gross_units_ok`——strict §11 毛杠杆约束 `L^G≤L̄^G` 在单标的 units 空间的精确等价形式（`base_units=E/px` ⟹ px 两侧对消）。生产 `coverage::apply_gross_cap` 调用 risk.rs predicate，coverage 不私写同义比较；既有美元空间 `gross_notional/leverage_metrics/leverage_ok/LeverageCaps` 保留为 Lean 镜像，两空间等价由测试 `gross_units_ok_iff_leverage_ok` 锁死（激活/违反/边界三侧 iff）。
3. **缩放语义**（codex decide 5b46 裁定方案B）：**逐根子树 KKT 投影（water-filling）**——`min Σ_r A_r(c_r−1)² s.t. Σ_r G_r·c_r ≤ Ḡ, c_r∈[0,1]`（`G_r=Σ|units|`、`A_r=Σunits²` 按根子树聚合），闭式 `c_r=max(0,1−μ/t_r)`（`t_r=2A_r/G_r`），μ 由排序后缀和扫描取约束等号。子树内全腿同 c_r（同单位数/κ/depth_weights 比率约束保持），跨根非均匀（spec 无跨根比例绑定）。**单根退化为等比例 `c=Ḡ/G`**。根分组按 `parent_id` 结构映射（与 AncOK 同判据，非 per-bar 索引链）。
4. **生产穿线**：`pi_theta_step`/`pi_theta_step_prebuilt`（runner 生产路径）传 `Some(risk)`；`coverage_step_classification/prebuilt/from_buckets` 增 `risk: Option<&RiskConfig>` 参数；l3_fullwindow 探针传 `Some(&cfg.risk)`（675号：探针走生产路径）；incremental 性能 parity 与纯结构测试传 `None`。

## 2. 定义依据

- **strict §11**（risk.rs 镜像，Lean `Origin.LeverageCapital` GREEN）：毛 `G_t=Σ|n_v|` 与净 `N_t=|Σn_v|` **必须同时约束**（line 359 同单位数双开反例：净杠杆低、总杠杆仍高）；§12 K_Θ 17 项约束含杠杆上界。
- **互斥分类 spec M18**（=完全分类 C33/C34）：`p*=LexArgmin_{p∈K_Θ}J_t(p)`，主键 `‖p−p̃‖²_W`——毛约束触发后的处置不是自由缩放规则，而是 J_t 主键在 K_Θ 上的投影。K_Θ 成员约束含同单位数（C04 `q_v=q_{p(v)}`）/κ（§6 `s_e=κ_e·s_p`）/祖先闭合 ⟹ 每根子树只剩整体尺度一个自由度 ⟹ 等权 W 下投影 = 逐根 water-filling（推导链在 `apply_gross_cap` doc + decide 5b46 交互全文）。
- 输入数据满足条件：`LegTarget.units = base_units×w_depth`（比率 Θ 钉死）；活动集可含多独立根（多 bsp 候选各开根腿）⟹ 多根情形真实存在，spec 未钉跨根分配 ⟹ 按工位指令落 codex decide，未自选。

## 3. 边界条件（结论翻转条件）

- `G=0` 或 `G≤Ḡ`：不缩放（未触发路径逐位不变）；`Ḡ=0`（γ=0 或 U_ℓ=0）：全腿归零（毛可行集退化 {0}）。
- 若 rust 后续引入真 per-voice `w_v` 或腿级 lot 网格：`A_r=Σunits²` 须升级为对应主键权重/离散 LexArgmin（decide 5b46 翻转条件①②）。
- 若 spec 后续明确要求跨根比例保持：方案B 翻转为全腿等比例（decide 5b46 翻转条件③）。
- #122 G7 豁免条件（生产硬禁 ShortDiff+测试锁死）未满足——`VoiceConfig::default().disable_shortdiff=false`，多空双开是默认生产场景，约束不可豁免。
- **诚实声明**：default `enforce_gross_cap=false` ⟹ 当前 frozen 口径生产仍无毛 cap（codex decide 风险项明示）。这是 #122"约束未配置=不激活"+frozen bit-exact 的钦定组合，非遗漏；π^full 收口跑批（#135）必须显式 `enforce_gross_cap=true`，否则 PDF §11 一致性声明不成立。
