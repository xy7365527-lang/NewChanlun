```
z⁺ = (level, bsp_class, parent_dir, force_state, σ^H)
```

- 前 4 维 = prereg-rev2/A1 冻结的 δ-free 主裁决键（`deltafree_verdict` 现键，verified 版 §3 确认在线实装）。

  - `Some(0)`：上级持平或无上级——**0 是计算结果非未知**，作为独立层保留（对照层）；
  - `None`：无 tower/bars 源（裸证书口径），诚实缺失——**从跨级别主张样本剔除**，仅入描述性报告（231号不伪造，同 horizontal/force_state 的 None 处置）。

### 1.3 δ-合法性：σ^H 进聚合基的先验依据 + 强制前置检验

- **先验（L0）**：σ^H 由上级塔真值算（`sigma_higher_at`），**不读 δ，置换 δ 时恒定**（mirror-invariant）——与 ForceState 同类，理论上不与 δ 共线。
- **σ^H⊥δ 前置实证检验（强制，仿 prereg-rev2 §1.2）**：跑数时对 `sigma_higher.is_some()` 的 records，按 σ^H 各态（+1/−1/0）统计 δ∈{+1,−1} 分布。
  - **PASS**：每个出现的 σ^H 态内 min(n_δ+1, n_δ−1) ≥ 1 ⟹ 置换有交换自由度。
  - **FAIL**：任一 σ^H 态 δ 完全单向 ⟹ σ^H **不进**聚合基，退为报告桶维，GAP-3 本轮判 FALSIFIED-as-designed 并停下上浮（fail 条件 2）。
- **明文禁止（本 prereg 最重要的负面条款）**：对齐指示子 `A_i := 1[δ_i = σ^H_i]` 及任何 δ×σ^H 交互维**禁止进聚合基**——A 是 δ-baked（置换 δ 时 A 翻转），进基即重演 i_class×δ 置换自毁（memory `iclass_delta_collinearity_perm_degeneracy`：perm_p 退化 1.000 + pooled 符号翻转）。"顺上级方向执行是否赚钱"由 Y 的 δ-编码 + σ^H 条件化**已经可检**，不需要也不允许 A 显式进键。A 分解仅允许作桶内**描述性**报告（不参与任何判定）。

## 2. 要素二：H0/H1 精确陈述

### 2.1 桶级（继承单侧检验，z_α=1.645，perm_α=0.05）

对每个 σ^H∈{+1,−1} 的桶 z⁺、每个 estimand 独立：

- **H0(z⁺)**：μ(z⁺) ≤ 0（该 σ^H 条件桶无正残差 alpha）
- **H1(z⁺)**：μ(z⁺) > 0

### 2.2 GAP-3 总命题（区辨判据——防"重检出既有桶"的声明膨胀）

记基线表 = σ^H-池化的 4 元组 δ-free 表（同一冻结 HEAD 同批重跑产出，不引用历史数字）。z⁺ 的池化父桶 z = 去掉 σ^H 维。

- **H1_G3（跨级别条件化携带信息）**：存在 Holm 校正后 VALIDATED 的 σ^H∈{+1,−1} 桶 z⁺，且满足**区辨条件之一（(a)∨(b)，§7 裁定 3）**：
  - (a) **解锁**：其池化父桶 z 在基线表非 VALIDATED（σ^H 细分让池化下不可见的 alpha 显形）；或
  - (b) **分辨**：存在同父 sibling z⁺′（σ^H 取值不同、powered）判 FALSIFIED（σ^H 区分了同一结构桶内的好坏方向态）。
- **H0_G3**：无任何 z⁺ 满足上述条件——包括"有 VALIDATED 桶但全部是既有 VALIDATED 父桶的均匀细分（所有 powered sibling 同判 VALIDATED）"的情形，该情形判 **NO-INFO**（σ^H 条件化无信息增量），不判 PASS。

**Holm 全族**：{raw μ^×, μ_R^×} × {z⁺ 实测去重桶集}。桶集 = records 实测 `(level,bsp_class,parent_dir,force_state,σ^H)` 去重集，**不事后挑桶**（关于背驰.pdf §9.2）。

## 4. 要素四：样本量功效门（继承 prereg-rev2 §3，三态判据原文不动）

对每桶 z⁺ × 每 estimand 独立算 `(mean, lcb, ucb, cv, n_eff, perm_p)`：

| 桶态 | 条件 |
|------|------|
| **VALIDATED** | `μ̂>0 ∧ powered ∧ LCB_OOS>0 ∧ perm_p<0.05` |
| **FALSIFIED** | `powered ∧ UCB_OOS≤0` |
| **INCONCLUSIVE** | `¬powered` **或** `LCB≤0<UCB` |

`powered(z⁺) := n_eff(z⁺) ≥ (1.645·CV(z⁺))²`；n_eff = Geyer IPS；两 estimand 各自在各自序列（Y 与 Y/d）上算。

**GAP-3 总判定三态**：
- **G3-VALIDATED**：≥1 桶过 Holm 且满足区辨 (a) 或 (b)；
- **G3-FALSIFIED**：fail 条件 4 或 5（NO-INFO 归此档的降级支）；
- **G3-INCONCLUSIVE**：其余（欠功效主导）——走提功效链，不 PASS 不 161。

**功效预期（诚实预登记）**：基线 δ-free 桶 25 个（records=2256，verified 版实测），σ^H 细分至多 ×4（+1/−1/0/None；667/codex-q1 实测 no_higher≈0.02% ⟹ None/0 层预期近空）⟹ 预期桶数 25→≤100 且**绝大多数桶 INCONCLUSIVE**；既有唯一 VALIDATED 桶（L0 bsp3 σ+1）细分后可能自身失 powered。这是样本量客观边界，照实报，不放宽门、不换判据。区辨判据 (b) 要求 sibling powered——预期 (b) 很难触发，主要出路是 (a)；此预期本身预登记，防事后"意外之喜"叙事。
