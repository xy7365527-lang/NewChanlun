## Q2: D∞ 完整导出（τhτ⁻¹=h⁻¹） — CONDITIONAL PASS

### 质询要点

group-rebuild-B §3.2 断言 τhτ⁻¹=h⁻¹ 从「做空逆转走势发展方向」导出（h 已构造后）。质询：这个导出是否严格，还是过陈述了「完整导出」？

### 对审推导（L0 精确分析）

**步骤分解**：

```
τhτ⁻¹ = [翻到空书] ∘ [走势推进 φ+1] ∘ [翻回多书]
```

group-rebuild-B 的论证链：
1. 先翻空：多书 → 空书
2. 空书推进一步：下跌走势长一个次级别子走势
3. 翻回多书：这在多书坐标里应该是「退一步」= h⁻¹

**关键问题：步骤3 的推导缺口**

步骤3 要求：「在空书推进 φ+1（下跌子走势+1） 翻回多书后 = 多书坐标里 φ-1」

这需要额外条件：**φ 坐标在多书/空书之间是反号统一的**（即 φ_short = -φ_long 在统一 ℤ 坐标里）。

这个条件**并不直接从 walk development 导出**，而是群论结构的**代数定义选择**：D∞ = ℤ⋊ℤ/2 中，ℤ/2 通过 n ↦ -n 作用在 ℤ 上——这是 D∞ 的定义关系，而不是走势发展的必然推论。

**承认的 caveat 的实际深度**：

group-rebuild-B §3.2 的 caveat 说：「此导出依赖语义绑定 顶↔多/底↔空（手性 ε 与方向的对应）。这是额外声明。」这是诚实的但**低估了结构意义**。

语义绑定给出：
- τ 对应 ε ↦ -ε（顶↔底对合，已从分型完整导出，§3.1）

但 τhτ⁻¹=h⁻¹ 需要**额外**：
- 「空书的 φ 增进 = 多书的 φ 退减」（signed-φ 统一约定）

这是 Ax-4（精化版）：不再是「h 未定义所以 τhτ⁻¹=h⁻¹ 不可导出」（deriv-75 状态），而是「h 已定义，但 τhτ⁻¹=h⁻¹ 仍需要 signed-φ 统一约定作为额外公理」。

**有没有 gap？** 有，但性质变了：

| 状态 | Ax-4 状态 |
|------|-----------|
| deriv-75（h 未定义） | Ax-4 完全不可导出 |
| group-rebuild-B（h 定义后） | Ax-4 精化为「signed-φ 约定」(lighter axiom) |
| 最严格描述 | D∞ 从 (h + τ²=e + signed-φ 约定) 三件导出 |

**结论**：group-rebuild-B 的 D∞ 导出是**有效的，但「完整导出」的声明应更精确**：

> 正确声明应为：「D∞ = ⟨h,τ⟩ 从走势发展递归（h）+ 分型对偶（τ²=e）+ 手性绑定（signed-φ 约定，Ax-4 精化）三件导出。相比 deriv-75，从四个独立公理减少到一个残余公理（签号约定），这是实质进步。」

这不是失败，是「过声明了完整性」的小缺口。D∞ 作为缠论走势结构的代数化**高度自然**，Ax-4 精化版（signed-φ约定）是可以显式公理化的。

> **要求**：§3.3 的 D∞ 导出结论框应改写为：
> 「D∞ 三构件全从 (走势发展递归) + (分型对偶) + (手性signed-φ绑定) 导出，其中第三件是精化 Ax-4：不再是 deriv-75 的完全不可导出，而是一个轻量的符号约定（空书φ增进 = 多书φ减减），在缠论做空镜像语义下高度自然但需显式声明。」
