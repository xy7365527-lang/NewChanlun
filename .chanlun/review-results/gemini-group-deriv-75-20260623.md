## 二、四项形式化推导

### §2.1 τ²=e 可导出性

**定理 D1（τ²=e 从分型顶/底对偶导出）**

**引理**：设分型类型集合 F = {Top, Bottom}（fractal.rs S5 守卫 `assert!(!(is_top && is_bottom))` 确保互斥+完备，第62课双条件定义确保非空）。定义翻转映射 Φ: F → F 为：

```
Φ(Top)    = Bottom
Φ(Bottom) = Top
```

**命题**：Φ∘Φ = id（F 上的恒等映射）。

**证明**：
- Φ(Φ(Top)) = Φ(Bottom) = Top ✓
- Φ(Φ(Bottom)) = Φ(Top) = Bottom ✓
  
故 Φ²=id（Φ 是 F 上唯一的非平凡对合）。

**导出**：τ 在 D∞ 中的代数性质是 τ²=e（对合）。F = {Top, Bottom} 与 {+1,-1}（ε 手性坐标）通过 Top↔+1（多）、Bottom↔-1（空）建立对应。Φ 与 τ 均为"二元集上唯一的非平凡对合"，故 **τ²=e 从顶/底二值对偶结构导出成立（L0 严格）**。

**边界条件**：此导出成立当且仅当：
1. 分型类型确实二值互斥（S5 守卫保证）
2. 顶=多、底=空 的对应关系固定（这是额外的语义绑定，本身需要显式声明，不自动从分型导出）

**结论**：**τ²=e 可从分型顶/底对合导出，严格成立。** 但 τ 的完整定义（包括 τhτ⁻¹=h⁻¹ 关系）还依赖 h 的定义——见 §4.1。

### §2.2 σ=h²³ 可导出性

**定理 D2（σ=h²³ 不从递归尺度不变性导出——反证法）**

**背景**：
- 第65课原文：aₙ=f(aₙ₋₁)，算子 T（find_centers + segment_into_trends + judge_divergence + encapsulate）对所有 k≥1 形式相同。
- 尺度不变性：T 在所有级别是同一个函数，这是缠论递归的核心。
- σ=h²³ 在 orbit doc §1.1 定义：σ := h²³，作用 σ:(φ,r,ε)↦(φ, r+1, ε)，即相位不变、级别 +1。

**反证论证**：

**前提 P1**：aₙ=f(aₙ₋₁) 定义了一个**序列**（S₀, S₁=T(S₀), S₂=T(S₁), ...）。
**前提 P2**：σ=h²³ 是 D∞ 中的**群元素**，要求坐标空间 (φ,r,ε) 预先存在。
**前提 P3**：坐标 φ 是模 23 的周期角 (ℤ/23ℤ)。
**前提 P4**：h 是"推进一个相位角"的群生成元。

**问题1（23 从哪里来）**：aₙ=f(aₙ₋₁) 中没有"23"。T 算子的四步循环（center detection / trend classification / divergence judgment / encapsulation）不产生任何自然的"23 步周期"。orbit doc 显示 23 来自 D₂₅₃ 有限化（h 阶 = 23×R = 253，R=11 级别数），但 23 本身是独立的结构参数——它对应"一圈走势的步数"的编码，**不从 aₙ=f(aₙ₋₁) 的形式不变性推导**。

**问题2（h 生成元从哪里来）**：T 算子作用在走势序列 S_k 上，产出 S_{k+1}。这定义了一个**自然的级别提升算子 L: S_k ↦ S_{k+1}**（即 T 本身）。但 h（推进一个 φ 角步）≠ L（推进一个完整级别）。要有 h，需要在走势内部引入"进度"坐标 φ——这在 T 的定义里完全缺席（T 的输入/输出是走势序列，不是 φ 坐标点）。

**问题3（描述性 vs 生成性）**：
- **描述性（成立）**：σ 描述"已建成的 H⁰ 塔中，从 k 级走势看 k+1 级的关系"。这是事后描述。
- **生成性（不成立）**：σ 能"生成"H⁰ 塔（即递归升级的操作）。但实际生成是 T（四步循环），T 不等同于 σ。

**形式化区分**：
```
描述性σ：(φ, r, ε) ↦ (φ, r+1, ε)  [坐标空间中的位移]
T算子（生成性）：S_k ↦ S_{k+1}  [走势序列的功能变换]
```
这两者的类型不同（坐标位移 ≠ 走势序列变换），不可等同。σ 是 T 的事后坐标化，而非 T 的先验导出。

**结论**：**σ=h²³ 不从递归尺度不变性（aₙ=f(aₙ₋₁)）导出，为独立公理（不可约额外结构）。** audit §7.4 原话"描述性不变量，非生成元"的形式化判决成立。

### §3 σ-轴分段形式化：范畴错误的严格陈述

**定理 D3（σ 均匀施于 r=0..10 是范畴错误）**

设以下算子：

| 区段 | 轴标 | 实际算子 | 数学结构 |
|------|------|---------|---------|
| K线→笔（r=0→1） | — | `classify_fractal` + 包含处理 | 序运算 max/min（局部极值检测）|
| 笔→线段（r=1→2） | — | 特征序列包含处理 | 格运算 max/min（包含合并）|
| 线段→走势（r=2→3） | T的首次应用 | `find_centers`(lattice meet) + `segment_into_trends` | 格运算 ∩（重叠算子）|
| 走势→更高（r≥3） | T的递归 | 同上 | 同上 |

**范畴错误证明**：

**命题**：把 σ 均匀施于 r=0..10 要求 σ 对所有 r 都有语义。

**反例（r=0→1，K线→笔）**：
- σ:(φ,r,ε)↦(φ,r+1,ε) 的语义是"相位不变、级别+1"
- 相位 φ 是"走势进度（环形）"的坐标
- K线→笔 的"升级"是由 `classify_fractal(h_prev, h_curr, h_next, l_prev, l_curr, l_next)` 决定的——这里完全没有"相位"概念
- K线不存在"走势进度"——K线是 bar 数据，不是走势状态
- 因此 σ 在 r=0 处语义空洞（(φ,0,ε) 中的 φ 无定义，因为 K线没有"走势相位"）

**结论**：
- σ 的有效域（有意义的级别范围）= **r≥2**（走势递归层，T 算子作用域）
- σ 的定义域（orbit doc 的 r=0..10）超出了有效域
- **把 σ 施于 r=0..2 是有效域膨胀（222号谱系）= 把不同范畴的算子混淆**

**两套合并算子的正式区分**（对应 T doc §0.3）：

```
Merge_fractal: K线³ → {Top, Bottom, None}       [分型检测，序运算]
Merge_stroke:  Fractal × Fractal → Stroke         [笔构造，形态合并]
Merge_segment: Stroke × Stroke × ... → Segment    [特征序列，包含处理]
Merge_center:  Move × Move × Move → Center?       [中枢检测，lattice meet ∩]
T: Move_sequence_k → Move_sequence_{k+1}          [T算子，四步循环]
σ: (φ,r,ε) → (φ,r+1,ε)                          [坐标位移，仅描述 r≥2 的 T 作用]
```

这五个算子类型签名不同，σ 不等同于任何一个 Merge_*，且 Merge_fractal/stroke/segment 不在 σ 的有效域内。

### §4 核心判决：D∞ 可从分型完整导出？

**定理 D4（D∞ 不能从分型扎根的 H⁰ 递归完整导出）**

**D∞ 的完整呈现**：
$$D_\infty = \langle h, \tau \mid \tau^2=e, \tau h \tau^{-1}=h^{-1} \rangle$$

**可导出的部分**：

| 元素 | 导出来源 | 严格性 |
|------|---------|--------|
| τ 的存在（二值对合） | 分型 {Top, Bottom} 二值集 | L0（§2.1）|
| τ²=e | 分型 Φ∘Φ=id | L0（§2.1）|
| 级别提升操作 L 的存在 | aₙ=f(aₙ₋₁) → T: S_k↦S_{k+1} | L0（§2.2）|

**不可导出的独立公理**（分型递归导不出的部分）：

| 公理 | 内容 | 为什么导不出 |
|------|------|------------|
| **Ax-1：h 的定义** | h 是"推进一个相位角"的群生成元 | 分型和 T 算子中不存在"相位"概念；T 的输入输出是走势序列，不是相位坐标点 |
| **Ax-2：23-周期** | φ ∈ ℤ/23ℤ（走势进度有 23 步周期） | 23 是独立的结构参数，不从 {Top,Bottom}、T 四步循环或任何分型机制推导 |
| **Ax-3：σ=h²³** | σ 作为 h 的 23 次幂 | 依赖 Ax-1（h）和 Ax-2（23），两者均不可导出 |
| **Ax-4：τhτ⁻¹=h⁻¹** | D∞ 的关系式（手性翻转逆转行进方向）| 依赖 Ax-1（h），h 不可导出 |

**说明**：τhτ⁻¹=h⁻¹ 有直觉解释（做空时买点/卖点互换，上涨/下跌方向逆转），但这个直觉解释依赖 h 已被定义。**直觉不等于导出**（090号严格性规则）。

**核心结论**：

```
D∞ = ⟨h, τ⟩
         │         │
         │         └── τ²=e 可从分型顶/底对合导出 ✓
         │             τ 的全定义（含 τhτ⁻¹=h⁻¹）依赖 h ✗
         │
         └── h 和 σ=h²³ 是独立公理，分型递归导不出 ✗
             23-周期是独立参数 ✗
```

**D∞ 中可从分型递归导出的子结构**：

$$\mathbb{Z}/2 = \langle \tau \mid \tau^2=e \rangle$$

仅此。这是 D∞ 被分型递归支撑的最大子群。

## 三、边界条件（六要素 3）

以下条件翻转上述判决：

1. **τ²=e 导出翻转**：若 Top/Bottom 对应不固定（如 Top 可以对应多或空取决于上下文），则 Φ ≠ τ，导出关系断裂。
2. **h 不可导出判决翻转**：若能在缠论体系内找到自然的"相位进度"定义（φ = 某种走势完成比例），且其周期自然给出 23，则 h 可被地基化。但目前无此构造。
3. **23 的独立性翻转**：若 23 被证明从缠论定义（如某种拓扑/组合计数）自然涌现，则 Ax-2 消失。目前 orbit doc 对 23 的解释仅是"有限化参数"。
4. **范畴错误翻转**：若在 r=0→2 层引入相位坐标，让分型机制适配 (φ,r,ε) 坐标空间，则 σ 的有效域可能扩展——但这需要**额外结构**，不是"导出"而是"扩展"。
