## §1 h 构造：走势发展进度生成元（成功）

### 1.1 走势发展的"基本步"是什么

编排者的候选清单：笔的延伸 / 中枢的形成 / 中枢延伸 / 新中枢 / 背驰段。逐一筛：

| 候选 | 是否走势发展的基本量子 | 否决/采纳理由 |

### 1.2 h 的定义（L0，从走势分解定理二 + 递归恒等式 540）

> **定义 h（走势发展进度生成元）**：对级别-(k+1) 的一个走势发展，
> $$h:\ \varphi \mapsto \varphi+1 \quad=\quad \text{"完成一个次级别走势类型 }M_k\text{（推进父走势发展一步）"}$$

**缠论依据链**（三段原文逐字）：
1. **走势分解定理二**（第17课，`blog/017` L58）：「任何级别的任何走势类型，都至少由三段以上次级别走势类型构成。」⟹ 走势发展 = 次级别走势类型的有序累积，**次级别走势是其离散步**。
2. **递归恒等式**（谱系540，T doc §1.2 L87-93）：`M_k^i ≡ Level-(k+1) 的一根"笔"`。⟹ 完成一个 Move(k) = 父级别 (k+1) 走势长出一根笔 = 走势发展推进一步。
3. **走势中枢定理一**（第18课）：「连接两相邻同级别走势中枢的一定是次级别以下级别的走势类型。」⟹ 走势发展的进度由次级别走势类型的连接序列承载。

**φ 的语义**：φ = 自走势离开前一中枢（走势发展起点）以来，已完成的次级别走势类型数。φ=0 = 走势刚离开前中枢（轨道唯一奇点候选，对应离开中枢的第三类买卖点）；φ 递增 = 走势发展推进。

### 1.3 h 是从缠论结构自然定义，非假设（对照 gemini-deriv-75 Ax-1）

gemini-deriv-75 §4 Ax-1 判 "h 不可导出"，根因是「分型和 T 算子中不存在'相位'概念；T 的输入输出是走势序列，不是相位坐标点」。**方案B 的突破**：相位 φ **不需要外加**——它就是 T 输入 `S_k=[M_k^1,…,M_k^m]` 这个**序列本身的索引**。T 把 S_k 映到 S_{k+1}，而 S_k 的元素 M_k^i 是父走势发展的第 i 步。**φ = 序列位置 i**，是 T 的输入数据里已有的结构，不是坐标空间的外加假设。

> gemini-deriv-75 的盲区：它把 T 看成"走势序列→走势序列"的黑箱，看不见序列内部的有序累积。方案B 打开黑箱：**走势序列 = 走势发展的相位轨迹**，序列索引 = 相位 φ。h = 序列向前推进一格 = `push(M_k^{i+1})`。

### 2.3 判决：σ=h²³ 失败（L0 反证）

> **定理 N1（σ=h²³ 不可从走势发展导出，L0）**：一个完整走势发展的 h 步数 N（从离开前中枢 φ=0 到背驰/转折 = 走势终完美）**是 regime 变量、无上界，不存在固定值**。故 σ（级别提升）**不是 h 的固定幂**，σ=h²³ 失败。

**反证**：
- 设 σ=h^N（N 固定）。则每个走势恰好 N 个次级别走势后背驰升级。
- 但盘整 = 1 中枢（最少 3 段次级别），趋势 = ≥2 中枢（≥6 段次级别），且中枢延伸/新生**无上界**（§1.4 引理 H1 + 第20课）。
- ⟹ 背驰（走势终完美）发生的相位 N 取决于 regime（震荡市 N 小、强趋势市 N 大、无界），**不是常数**。
- ⟹ 不存在固定 N 使 σ=h^N。特别地 N≠23（23 无来源）。∎

### 2.4 23 的真实身份：有限化参数，非缠论结构

orbit doc §1.2 + §2.1：23 来自 D₂₅₃=23×R 有限化，R=MAX_LADDER=11（`types.rs:26` 工程常量），h 阶=23×11=253。**23 = 253/11 是把无限 ⟨h⟩≅ℤ 人为商成有限循环时选的角向周期**，纯粹是 Burnside 要求"有限群作用于有限集"时引入的环面紧化参数（orbit doc §1.2 明言"mod R 回绕是人为引入的"）。**它活在环面 S_cyc（正面枚举域），不活在有界阶梯 S_bd（真实走势域）**。撤掉人为回绕（恢复真实无界走势发展），23 消失，σ 在顶层无像（orbit doc NR-5）。
