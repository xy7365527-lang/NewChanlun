## 1. 估计量形式化

### 1.1 定义

条件化估计量（区间套的统计版本）：

```
μ̂(z_L0 | D_hi = d) := (1/n_{z,d}) · Σ_{i : z_i = z_L0 ∧ D_hi(t_i) = d} Y_i
```

- **样本** Y_i = δ_i·(H_i − B̂_i) − C_i：wverify 残差口径（alpha分离.pdf §1，`ResidualTrade::y`），
  来自生产 π fill loop typed ledger（`build_mu_from_bars`），BTC wf_anchored 12 窗
  walk-forward OOS（`prereg_windows`，test_start ≥ 2023-01-01），**过滤 level==0**（L0 执行样本）。
- **执行桶** z_L0 = (bsp, δ, σ_p)：生产 4 元组桶键 (ℓ, bsp, δ, σ_p) 在 ℓ=0 上的截面
  （σ_p = `parent_dir` 持仓树父声部方向，与 σ^H 塔上级方向**并列独立**，#81 不合并裁定）。
- **条件** D_hi(t_i)：高级别方向/容器状态，在信号 bar t_i 的 σ-代数 F_{t_i} 上可测（见 §1.3）。

### 1.2 条件维（本预注册冻结两维，独立分层报告、不做笛卡尔交叉——防桶碎裂）

| 维 | 定义 | 生产者 | 值域 |
|----|------|--------|------|
| **D1 σ^H_tower** | 执行级上一级（tower[1]）末走势端点价净差符号 | `selector::sigma_higher_at`，z 装配点（`z_of_candidate`）从入场时塔快照填（666/667 号） | {+1 上级净涨, −1 上级净跌, 0 持平或无上级}；None 若出现单列报数不判定（生产链签名强制填 Some，预期无 None） |
| **D2 nest_anchor** | 区间套 N^δ 锚存在性 | `MuClass.nest_depth`（NestCertificate.rungs.len()，G3 #138 第 11 维） | {anchored: Some(·), unanchored: None} |

**D2 退化预声明**：wverify 残差链走 π fill loop 路径，候选不过 Nest/Xzd 门（`cand_channel`
字段文档：「runner π 路径候选不过 Nest/Xzd 门 → None」）——D2 可能全 None。若坐实，
D2 维在本样本链**无生产者**，照实报维退化，不判定、不硬造。这是实装缺口事实
（与 memory「区间套已接入但 95% 退化」同族），非本工位可静默修补的范围。

**排除声明（231 诚实缺口，不臆造）**：任务候选条件维中「高级别一类/二类信号在场 ± 窗口」
「高级别中枢相对位置」在 `ResidualTrade` 上**无生产者字段**（记录无逐笔信号时间戳可对齐
高级别信号窗口；中枢相对位置无逐笔装配点），且窗口宽度是自由参数（臆造风险）。本预注册
显式排除这两维；如需纳入须先在 z 装配点新增因果字段（超出本工位裁量，属新 prereg）。

**σ^H 不进桶键**（codex-q1 G2 裁定，694 号注记明文）：D1 作为**切片/分层条件**，不进入
δ 置换的输出桶键——切片先于置换固定，置换在切片内进行。

**δ-free / 657 共线免疫论证**：σ^H 与 nest_depth 均不是本笔 δ 的函数（上级末走势净差 /
门证书深度，与本笔方向无关）→ 层内 shuffle δ 不改变切片归属 → 无 i_class×δ 式置换自毁。

### 1.3 条件可测性（零前视，硬约束）

σ^H 由 `sigma_higher_at(tower_i, bars, lvl)` 在**入场时刻**的塔快照计算（econ_positive.rs:339
注释「666 号：入场时上级方向态」；z_of_candidate 签名强制携塔，selector.rs:195）。塔由
≤ t_i 的确认 bar 构成（确认-bar 部署）⟹ D_hi(t_i) ∈ F_{t_i}。残差 Y_i 的实现（exit）严格晚于
t_i ⟹ 条件严格先于结果，因果对齐成立。nest_depth 来自信号时已 pass 的 GateCertificate，同理。

### 1.4 有效域声明（231）

σ^H 生产者定义域 = 执行级的**相邻上一级**（tower[level+1]）。对 L0 样本，D1 = L1 方向态。
「更高级别（L2+）方向条件」无逐笔生产者——本结果的有效域是「相邻上级方向条件」，与区间套
逐级相邻结构（Jchain 强制逐级相邻，nest.rs）同构，**不外推**到跨级方向条件。

## 2. 预注册（跑数前冻结；本节先于任何跑数落盘）

1. **统计口径与 wverify_full 完全同源**：Welford 逐桶 (n, mean, m2)；LCB/UCB = mean ± 1.645·se；
   perm_p = 切片子集内 `stratified_delta_perm_p`（分层键 (ℓ, h_bucket, time_block, σ_p) 不变，
   N_PERM=200，seed=20260701 冻结）；n_eff = `decontam::effective_n`（665 自相关校正）；
   三态 = `decontam::classify_bucket`（z_α=1.645, perm_α=0.05，先功效门再三态）；
   删尾 = `drop_top_k_mean(·, 3)` 照报。
2. **格 = (D 值) × (L0 执行桶)**，D1、D2 两维分别独立出表。每格报
   n / n_eff / mean / lcb / ucb / cv / perm_p / 删尾mean / 翻转 / state。
3. **基线对照**：同批 L0 records 不切片的无条件桶表（同口径），附「条件格 state vs
   无条件同执行桶 state」对照列（条件化是否改变判定）。
4. **功效门照实**：欠功效格 = INCONCLUSIVE，不硬判（660/661 第三态）。
5. **beta 漂移探针**（memory oddeven / final-alpha 教训，预注册写死）：任何 Validated 格
   须检查同 (D, bsp, σ_p) 反 δ 格的 mean 符号——**两 δ 同号 ⟹ 标 BETA-DRIFT-SUSPECT**，
   不计入 alpha 证据。
6. **停机条款**：出现 powered ∧ LCB>0 ∧ perm_p<0.05 且**非** BETA-DRIFT-SUSPECT 的条件格
   → 停下 SendMessage main 上浮（可能翻转终局判定）。
7. 不允许跑完后新增/删除条件维或改判据。产出照实全表列出，不挑格。

## 5. 结果包六要素

1. **结论**：条件化估计量 μ̂(z_L0 | D_hi) 已形式化+实装+跑数（L2）。BTC 全历史 wf OOS 下，
   高级别（相邻上级 L1）方向条件不产生任何非 beta 漂移的 Validated 格——**acc-highlow-power
   路线在现有样本链上未翻转终局 INCONCLUSIVE/无方向 alpha 判定**；其信息增量是把基线唯一
   Validated 桶的正残差定位为「σ^H=+1 条件承载的 beta 漂移」。D2（区间套锚）维在 π fill
   loop 样本链无生产者（anchored=0），退化坐实。
2. **定义依据**：估计量定义见 §1.1（694 号 elevated 环节的字面实装：「高级别方向条件下
   低级别执行的 μ̂」）；条件可测性 §1.3（`sigma_higher_at` 入场时塔快照，F_t 可测零前视）；
   σ^H 不进桶键、作切片分层（codex-q1 G2 / 694 注记）；三态判据 = decontam 冻结口径。
3. **边界条件（结论翻转）**：(a) 若 econ 门路径样本源接入（nest_depth 有生产者）且有锚切片
   出现非 suspect Validated → D2 结论翻转；(b) 若 σ^H 生产者扩展到跨级方向（L2+ 逐笔装配）
   且高阶条件切片出现非 suspect Validated → 有效域外推成立；(c) 若残差口径变更（B̂ 估计器
   / typed exit 语义再改）→ 全表过期须重跑；(d) σ^H=0 切片 n=9 近空——若数据源变更使该
   切片增样，其判定可变。

   方向条件下的 μ̂」已产出且**无稳健增量** ⟹ 按 694 号结算路径，进入「回 645 wrong-object
   检查」分支（高级别 alpha 假设本身受质疑）。终局 q4/final-alpha INCONCLUSIVE 判定不变。
