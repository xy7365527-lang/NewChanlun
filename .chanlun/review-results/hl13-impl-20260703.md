## 2. 定义依据

- **裁定 A**（codex-decide-20260703）：「每个级别都有独立的一/二/三类买卖点。高级别一/三类应由高级别 units + centers + trend 判定，不应从 L0 标签继承。」→ 级别-N 直接判定，非 (B) relabel。
- **趋势门控忠实性**（codex 约束 iii「一类只在该级 classify_move==Trend(dir) 时生成」）：`extract_signals_with_hist` 内部 `divergence::trend_class(centers)` 与本级 `level::classify_move(centers)` **逐分支同构**——两者均 `all_same_relation`/`all_adjacent` 经 `center::classify_relation`，0/1/≥2 分支一致（`Degenerate`≡`HigherCenterCandidate` 均映射 trend_dir=None）。故复用即忠实 codex 门控，无第二套趋势引擎。
- **端点价忠实性**（codex「end_price 忠实性必须单测」，标注最大实现风险）：`unit_to_segment` 向上单元 end_price=hi（终点=高点）、向下 end_price=lo，与 `segment_to_unit` 互逆（L0 段 round-trip bit-exact）。单测 `unit_to_segment_endpoint_faithful_and_roundtrips` 锁定。
- **A/C 段力度**（codex「复用 sublevel_diverges 同族 + AreaCache，禁第二套力度引擎」）：内部 `AbcDivergence`/`locate_trend_seg_a` 复用 `divergence.rs` 的 `segment_macd_area`/`is_divergence`——与 `sublevel_diverges` 同一面积原语族。未引入新力度引擎。
- **三类（reference:36 + judge_third）**：级别-N 离开单元终点（外缘 hi/lo）相对几何中枢 [zd,zg] 的位置判据（buy3: retest 低点 > zg 严格不重入；sell3: retest 高点 < zd）。抽样核验（§4）全部满足严格不重入不变量。

## 3. 第一类零触达 = 水平线依赖的市场事实（L2，非实现缺陷）

**全历史 BTC：type1 = 0 于所有级别（含 L0）。** 根因：`trend_class`/`classify_move` 作用于**该级完整中枢链**——4.61M bar / 各级中枢链在全历史上**全局非单调**（BTC 涨跌交替）⟹ `Degenerate`/`HigherCenterCandidate` ⟹ trend_dir=None ⟹ 不产一类。这与 audit #116 坐实的「L0 一类=0 是市场事实」**同构**——现一致地延伸到所有级别（codex 裁定 A 明确规定整级 `classify_move==Trend` 门控）。

L4: centers=2 moves=1(trend=1) | sell1=2  ← 该级 2 中枢构成 Trend(Up)，产 2 个顶背驰卖点

  L4 type1#1: src_idx=278196 sell1 break_dir=Short pivot_high=6150000000000 (≈$61,500)

L4（高周期）在牛市窗内 2 中枢单调上移 ⟹ Trend(Up) ⟹ C 段向上破最后中枢 + 顶背驰 ⟹ 2 个一类卖点，**落在 BTC 2021-04 历史高点区（~$60K/$61.5K）** = 结构合法的高级别趋势力竭顶背驰。**证明**：(a) 一类机制在真实数据上真能触达（非死码），(b) 触达是**水平线依赖**的——全历史 0（全局混合）vs 单向窗 >0（局部单调）。

## 5. 边界条件（结论翻转条件）

- **type1 触达翻转**：任一级完整中枢链在观测窗内单调（≥2 依次同向中枢）⟹ 该级 type1 可 >0（牛/熊窗坐实）。全历史 0 非架构死码，是全局非单调的市场事实。跨品种/更长趋势窗可产更多 type1。
- **若形式化规格改判**「高级别一类须由 L0 一类标签继承」⟹ 推翻裁定 A（改回 relabel）。当前谱系未见此规格。
- **memo soundness**：level≥1 的 bsp_key 结构长度键从 `0` 改为 `units.len()`（见 §6）——若 units 前缀非单调（回缩/frontier 改写）由 cascade_reset 兜底；三情形（append/shrink/同长改写）全覆盖，`incremental_tower_per_segment_append_matches_full` 逐 bar 对拍锁定。
- **性能**：每 memo-miss O(units_L) 全扫（units_L 随级别几何衰减），struct 变化次数 ≪ bar 数 ⟹ 摊还 O(sum level_moves)，同 L0 memo 特性。未引入 O(n²)（`incremental_tower_scaling_dominates_full_synthetic` 通过）。
