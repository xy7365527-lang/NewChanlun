## 第 2 部分：严格数学证明

### 2.1 力度的递归定义（L0，替换 MACD 的严格形式）

**定义 2.1（递归背驰）**。设级别序列 …> ℓ_n > ℓ_{n−1} > … > ℓ_0（ℓ_0 = base level = 笔/1min）。
对级别-n 的一段趋势走势 M_n：

$$
\text{背驰}_n(M_n) \;\overset{\text{def}}{\Longleftrightarrow}\;
\begin{cases}
\text{盘整背驰}(M_0) & n = 0 \text{（base case，纯几何：中枢前后力度比较）}\\[4pt]
\text{背驰}_{n-1}\big(\text{last-同向-次级别}(\text{离开段}(M_n))\big) & n \geq 1
\end{cases}
$$

其中 `离开段(M_n)` = M_n 的最后一个中枢之后的那一段（第29课"c 段"/"背驰段"），
`last-同向-次级别(·)` = 把该离开段分解到级别 n−1 后**最后一段与 M_n 同向**的次级别走势。

**这个定义是缠师原文的直译**（第29课 An+1=F(An) + "5分钟背驰段…通过1分钟以下级别精确定位"）：
n 级背驰 = 把 n 级离开段下钻一层，看 n−1 级的同向末段是否也背驰，递归到底。base case（ℓ_0）
不能再下钻（第17课"级别之次不可能无限……对最后不能分解的级别……定义为至少三个该级别单位K线
重叠"），退化为纯几何盘整背驰（本级中枢前后的力度比较，无下层可递归）。

**关键**：定义 2.1 **不含 MACD**。力度递归靠"是否存在下层同向背驰"这个**结构谓词**判定，
MACD 面积只是 base case 处力度比较的一个数值代理（可换成任意力度度量）。这形式化了第17课
"没有 MACD 也能判断背驰"。

### 2.2 区间套 = 递归背驰的闭区间序列（L0）

**定义 2.2（背驰闭区间）**。对级别-k 的背驰_k 判定过程，定义其**定位闭区间**

$$
R_k \;\overset{\text{def}}{=}\; [\,t^{\text{start}}_k,\; t^{\text{end}}_k\,] \times [\,p^{\text{low}}_k,\; p^{\text{high}}_k\,]
$$

为"级别-k 背驰段所占据的时空盒"（第29课 D=[dn, gn] 中枢震荡区间在时间轴上的投影 +
背驰段价格范围）。缠师原文（第29课）的 `An+1=F(An)` 中，F 就是"取离开段 → 下钻 → 定位子背驰段"
这个映射；R_k 是该映射第 k 步的定位盒。

### 2.3 引理 L1（R_n ⊇ R_{n−1}）：嵌套包含是定义 2.1 的直接展开（L0）

> 编排者点名要求"严格证"的命题：**为何大级别背驰段必含次级别背驰段**。
> **诚实标注（异质审计 codex-hundred-percent-proof-audit-20260701 采纳）**：这**不是**非平凡定理，
> 而是定义 2.1 的**直接展开**——把"背驰_{n−1} 的判定对象从 R_n 内部取出"写进递归定义后，包含关系
> 是读出定义的结论。原文档曾称其"构造性定理"= 夸大（把定义重述包装成定理）。这里如实降级为引理。

**陈述**。对定义 2.1 的递归背驰，其定位闭区间序列满足
$R_n \supseteq R_{n-1} \supseteq \cdots \supseteq R_0$。

**（定义展开，非独立证明）**。定义 2.1 规定：背驰_n 的判定对象 = 把 R_n 的离开段（背驰段）
**分解到级别 n−1** 后的"最后同向次级别走势"。由走势分解定理二（017:58：任何级别走势类型至少由
三段以上次级别走势构成），该次级别走势是 R_n 离开段的一个**子段**，其时空盒
$[t^{\text{start}}_{n-1}, t^{\text{end}}_{n-1}] \subseteq [t^{\text{start}}_n, t^{\text{end}}_n]$。
故 $R_{n-1} \subseteq R_n$——这一步在定义 2.1"从父窗内取子对象"处已经写定，展开即得。□

**非平凡内容在哪里（实装侧，非数学侧）**：数学上包含关系是同义反复，但它对应一个**真实的实装
约束**——R_{n−1} 必须"取自 R_n 内部"（沿父级 c 段窗钻取），而非独立地取"各级别全局当前走势"。
谱系 554/555 实证此约束的必要性：若错取"各级别全局当前走势"（异步、任意相位）做事后几何内含检验，
链坍缩 21/24（实装范畴错误 `rec_driver.rs:102-105`）；修正为"沿父级 c 段窗钻取"后 0→数百贯通
（555 §五）。**引理 L1 的价值是钉住这条实装契约（取自父窗），不是贡献数学定理**——这也正是缠师
第29课"5分钟背驰段…通过1分钟以下级别精确定位"的字面含义（1分钟定位**在**5分钟背驰段**之内**做）。

### 2.4 定理 T2（有限步递归 + Sel_Θ 选择器 ⟹ 唯一定位见证）（L0）

> **异质审计致命修正（codex-hundred-percent-proof-audit-20260701，verdict=fail 的两个致命点）**：
> 原文档此处用 **Cantor 闭集套定理 + Banach 压缩映射**证收敛——**这是错误的数学工具，已删除**。
> 原因（codex 逐点，我逐条核对成立）：
> 1. **不需要 Cantor / 完备性**：级别链有下界 ⟹ 递归**有限步**停止。有限个闭集的递减交集非空是
>    **平凡**的（$\bigcap_{k=0}^{n} R_k = R_0$，最小那个），不动用完备性、不动用闭集套定理。
> 2. **不能写 diam→0**：有限步停止**不是**无穷极限。$\operatorname{diam}(R_k)\to 0$ 的无穷极限
>    符号在有限链上无意义；$\operatorname{diam}(R_k)/\operatorname{diam}(R_{k+1})\geq\lambda>1$
>    的统一压缩常数 λ **无原文依据、无证明**（价格范围未必严格缩小）。
> 3. **Banach 是修辞非依据**：缠师 030:26"就如同压缩影射不动点……一样"是**类比修辞**（"就如同…
>    一样"），把它升格为"数学依据"= 声明膨胀（090号）。
>
> 正确表述（codex 给出，且恰与 `nest.rs`/606 号真实内容一致）：**唯一性来自有限步递归 + Sel_Θ
> 选择器，不来自 Cantor 收敛**。

**陈述**。设 (i) $R_n \supseteq R_{n-1} \supseteq \cdots \supseteq R_0$（引理 L1），
(ii) 级别是严格递减的整数且有下界 ℓ_0（笔/1min），(iii) **∀k∈{0,…,n}，候选集 $C_k$ 非空且有限，
且 Sel_Θ 的排序 key $(end\_time, start\_time, idx)$ 在 $C_k$ 上为严格全序（idx 唯一）**，故 Sel_Θ
在每级选出唯一 chosen 候选。则递归**有限步**终止于 R_0，且定位见证（各级 chosen 键序列）**唯一**。

> **前件 (iii) 的完备性说明（异质审计 codex-hundred-percent-proof-audit-r2-20260701 采纳）**：R2 指出
> v2 的原前件仅写"Sel_Θ 选出唯一候选"，隐含假设了**候选集非空**而未显式声明。base level 无 BSP 时
> 候选集 $C_0=\varnothing$，选择器选不出 $p^\star$，$p^\star$ 不存在——原前件封堵不住这个情况。故 (iii)
> 补全为"每级候选集非空且有限、key 严格全序（idx 唯一）"，闭合前提链（no-patch，非标注糊过）。
> 这也划出结论的边界：$p^\star$ 的唯一性是**条件命题**——前件 (iii) 的"非空"不成立时无 $p^\star$，
> 与 §5.2 的 existence 边界一致（区间套不保证每级候选非空）。

**证明**（有限归纳 + 选择器，不需要完备性）。

1. **有限终止**：级别序列 $\ell_n > \ell_{n-1} > \cdots > \ell_0$ 是严格递减整数且有下界，故递归
   在有限步（$\leq n+1$ 步）到达 base case ℓ_0，不能再下钻（017:40"级别之次不可能无限……对最后
   不能分解的级别……三根 K 线重叠"）。**这就是 well-founded 递归终止，不涉及无穷极限。**
2. **交集非平凡地非空**：由 L1，$\{R_k\}_{k=0}^{n}$ 是**有限个**递减集，$\bigcap_{k=0}^{n} R_k
   = R_0 \neq \varnothing$。**这是有限交，平凡成立**（无需 Cantor 闭集套 / 完备性）。
3. **定位唯一**：递归终点 R_0 内可能有多个 base 候选（同级多个 BSP）。Sel_Θ 是严格全序字典序
   （`nest.rs` `sel_order`），在每级选出唯一 chosen 候选。故整条下钻路径的 chosen 键序列唯一 ⟹
   定位见证 p⋆ 唯一。**唯一性依赖 Sel_Θ 固定——缠论结构公理单独给不出唯一定位**（`nest.rs`
   doc 逐字）。□

**形式依据（Lean machine-checked，谱系 606，与本表述精确对应）**：`Formal/DivergenceNesting.lean`
证 `Nested(inner.level < outer.level)` + `nested_level_decreases` ⟹ **有限链终止**（chain 非空，
至少含 D_1）；与 Phase1 r* 终余代数有限下降 `generatedStep_strictly_decreases` **同构**（"严格
单调整数 ⟹ 有限"，方向相反结构同）。**606 证的正是"有限下降终止"，不是 Cantor 收敛**——原文档
搬 Cantor/Banach 是绕道去引了 606 本就不需要、也没证的重机械。

**L1 + T2 合起来 = 缠师"100%"的严格形式（修正版）**：从大级别背驰段 R_n 出发，逐级下钻（子取自
父窗，L1），级别严格递减且有下界，**有限步**终止于 base level，Sel_Θ 定出唯一见证 p⋆。**p⋆ 的
位置由结构 + 选择器共同决定，无自由度** —— 这是"100% 绝对"的数学内容（**有限递归 + 选择器唯一，
非 Cantor 收敛**）。

### 2.5 base level 的残余结构比较（存在论边界的种子）

L1/T2 证明了：**若** R_n 存在（大级别确有背驰），**则** p⋆ 唯一且由结构决定（location 100%）。
但 base case（ℓ_0）的背驰_0 判定本身，仍是一次**结构比较**：

$$
\text{背驰}_0(M_0) \;\Longleftrightarrow\;
\big[\text{创新高/新低}\big] \;\wedge\; \big[\text{中枢前后力度衰减（本级几何度量）}\big]
$$

这一步是**几何判定**（是否创新高低 × 本级中枢前后力度对比），**不是神谕**——它读取已发生的
价格结构，不预言未来。这是 §5 诚实边界的种子：location 100% 是**条件命题**（若 R_n 存在则 p⋆
唯一），existence（背驰_0 到底成不成立）是**当下的结构读数**，其"100%"是"结构决定性"（给定价格
轨迹，判定唯一），不是"背驰必然出现"的先验保证。

### 4.1 判据分层

## 第 5 部分：诚实有效域边界（强制，`formalization-validity-domain.md`）——"100%" 到底 100% 什么

> **这是本文档最重要的否定性贡献**：严格划定"100%"的边界，防止把 location 的 100% 膨胀成
> existence 的 100%（声明膨胀 = 090号）。

### 5.1 location 100% ✅（**条件命题**，L0；非无条件定理）

**成立（条件命题，异质审计点4 采纳）**：**若** R_n 存在（大级别确有背驰）**且**递归各级合法
（每级取自父窗、**每级候选集非空且可选**、Sel_Θ 固定），**则** p⋆ 的**位置**由 L1（定义展开的嵌套）
+ T2（有限步递归 + 选择器）**唯一决定，无自由度**。（"每级候选非空且可选"是 T2 前件 (iii) 的
同一条件——R2 指出 v2 曾漏此项，此处与 T2 同步补全，闭合条件命题的前件。）**这是一个条件命题，不是无条件"100%"**——前件（R_n 存在 + 递归
合法）不成立时无 p⋆。原文档 v1 把它标为"无条件 L0 几何定理"= 边界模糊（codex 点4），已修正。
唯一性可机器验证（谱系 606 Lean `nested_level_decreases`），**但机器验证的是"有限下降终止"，
不是"Cantor 收敛"**。缠师第30课的 Banach 类比是修辞非依据（§1.3/§2.4）。

### 5.2 existence 不是 100% 神谕 ❌（结构读数，非先验保证）

**边界**：区间套**不保证** R_n 存在——即"大级别此刻是否真的背驰"这一 existence 判定，在 base
level 仍是一次**当下的结构比较**（§2.5：是否创新高低 × 本级力度衰减），是几何读数，**不是**
"背驰必然出现"的神谕。三个精确的边界：

1. **base case 仍需一次结构比较**（§2.5）：背驰_0 的成立与否读取已发生价格，不预言。"100%"
   在此是"给定轨迹判定唯一"（结构决定性），不是"轨迹必然背驰"。

2. **高层背驰 ⟹̸ 低层完整 type1**（谱系 606 Q1 + `covering_space_interval_nesting_proof.md`
   Q5a/Q5b，L0）：区间套"递归到底"在**理论**上要求每级背驰，但**实操**中高级别背驰时低级别
   常表现为**盘背**（盘整背驰，力度弱）甚至"势变弱但未到自己背驰点"。covering_space 文档
   Q5a/Q5b 已 L0 证明：
   $$
   \underbrace{\text{低层必有方向变化（分型/笔）}}_{\text{下界，必然}}
   \subsetneq \text{高层背驰在低层的表现} \subsetneq
   \underbrace{\text{低层完整 type1（背驰∧反转）}}_{\text{上界，不必然}}
   $$
   故区间套**不保证套到最低级别每级都趋势背驰**。缠师原文（第29课）也说最弱情况可以只是"盘背"
   或"势变弱直接转"。**"递归到底"的终止级别是否含盘背，是一个语法记录候选**（606 §6.3 + 已
   上浮 source-auditor）——若严格要求每级趋势背驰，则系统性排除盘背级联，收缩有效域。

3. **settle ≠ 走势完美**（606 Q1 + `necessity_derivation.md` T₂ 状态~，L0）：结构完成（settle）
   是 type1 的**必要不充分**条件。"238 settled" ⊋ "recL2 type1"。把 settle 计数当 type1 计数
   会系统性高估——PH settle 是纯拓扑无动量维度，结构上触不到背驰。

### 5.3 经验有效性 = L2 未做（零调用，最诚实的边界）

**最硬的边界**（谱系 `project_interval_nesting_not_called_in_backtest`，L0 代码事实）：

**区间套 100% 定位的大转折 buy/sell 点，在本项目回测中从未被测过。** N^δ 完整证书零生产调用
（§3.3），所有 alpha 否证（奇偶交替 / σ_higher / (ℓ,q) / 夏普）覆盖的是 **bsp 端点方向投影**，
**不含区间套递归定位**。

**"零调用"的精确外延**（异工位审查独立核到的调用点，消歧义）：`n_delta()` **并非从未在真实
数据上跑过**——`econ_positive.rs:2190 if !cert.n_delta()` 确实调用完整 `NestCertificate`，但它在
`#[cfg(test)]` 块内（`fn acc_classification_level_hole_dx`），是**门通过率频数诊断探针**
（`highlevel_hits` push），**不接 P&L / 不检验 alpha**。故"零调用"精确指 **下单回测主循环 +
alpha 检验链零调用**；test 探针已在真实 BTC 数据调 `n_delta()` 做门滤除计数，但门通过率 ≠ alpha
检验。两者都成立且不矛盾——区间套定位的**可交易性**从未被测。

⟹ **假否证风险**：我们否证的是端点方向投影的 alpha，**不是**区间套定位的 alpha。缠师 100%
法的**经验有效性（L2/L3）在本项目是空白**——理论 L0 严格（本文档 L1/T2 + 606 Lean），但从未
在真实数据上执行区间套定位并检验其交易有效性。**location 100% 是 L0 几何真理；它是否转化为
可交易 alpha 是 L2 未决问题**（两者不可混淆——这正是形式化有效域规则的核心）。

### 5.4 边界总表

| "100%" 的主张 | 成立性 | 等级 | 边界 |
|--------------|-------|------|------|

## 第 6 部分：结果包六要素

### 1. 结论

**缠师"100%背驰法" = 中枢结构 + 区间套递归，不是任何单级 proxy——命题确证（L0），但"100%"
严格限定为 location（精确定位）的**条件性**结构决定性（若 R_n 存在且递归合法），非 existence 的
神谕。**

- 力度的严格形式 = 递归背驰（定义 2.1，不含 MACD，缠师第29课 An+1=F(An) 的直译）。
- 区间套的唯一定位 = **有限步 well-founded 递归 + Sel_Θ 选择器**：L1（R_n⊇R_{n−1}，定义 2.1 的
  直接展开）+ 级别严格递减整数有下界 ⟹ 有限步终止 + Sel_Θ 字典序定唯一见证 p⋆。**不需要 Cantor
  闭集套、不需要 Banach 压缩映射**（异质审计致命修正：有限递归的交集非空平凡成立，diam→0 无意义，
  缠师第30课 Banach 是类比修辞非依据）。
- MACD 面积/振幅/速度/DIF **全是 base case 力度代理**（辅助层），共同上位是"力度减弱"结构判据，
  完整形式是区间套递归。100% 是结构性质，不是 proxy 性质。

### 2. 定义依据

- 背驰本体 = "后者比前者走势力度减弱"（第17课 017:90/250，MACD 非必需）。

- 缠师第30课 030:26"就如同压缩影射不动点……一样"= **类比修辞**（表达唯一性直觉，**非**援引 Banach
  定理作证明依据——异质审计已否 v1 的升格）。
- 走势分解定理二（任何级别走势至少三段次级别，第17课 017:58）= L1 "子取自父窗"的定义依据。

### 3. 边界条件（结论翻转）

- **若** L1 的包含关系被实现为"事后几何检验两个异步区间"（而非"子取自父窗"构造）⟹ 链坍缩
  （554/555 实证 21/24=0），此时 R_n⊇R_{n−1} 几乎从不成立——但那是**实装范畴错误**，非命题假。
- **若**缠师原文裁定区间套终止级别**必须每级趋势背驰**（不含盘背）⟹ §5.2(2) 的有效域收缩，
  低层盘背级联被系统排除；**若**含盘背 ⟹ 当前严格 confirm 标准过严（语法记录，已上浮 source-auditor）。
- **若** base level 有多个候选定位但 Sel_Θ 未固定 ⟹ **定位见证不唯一**（p⋆ 不唯一）——需选择器
  字典序（`nest.rs` 已实现）。这是 T2 唯一性的**核心依赖**，非边缘情况。
- **若**把 location 100% 当 existence 100% 或当"必然可交易 alpha" ⟹ 声明膨胀（§5.3 零调用，
  经验有效性 L2 未做，假否证风险）。
