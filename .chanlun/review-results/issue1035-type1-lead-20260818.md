## 0. 统计口径

```
# 数据：Binance 公开归档 BTCUSDT 1m 月度 klines，2017-08-17 .. 2024-12-31，
#   3,870,470 bar（与 data.rs SYMBOLS 表 btc_1m_full.json 的 parallel-array schema 同形）。
# 全量单趟：parse_layer + classify_with_tower（非 per-bar incremental；frontier 尾段未确认点可能
#   少计，量级不影响直方图结论）。
# release 构建，cargo run --release --features backtest_bin --bin p1035_type1_lead -- BTC
# 口径：对每个 bits.buy1/sell1 置位的一类点，按 (level, side) 分桶。
```

三条 lead 定义（全部 = **anchor − 极值 bar**，单位 bar，≥0）：

- `lead_C`：anchor − **C 走势单元窗口**（`find_move_by_end_index(tower[lvl], anchor)` 命中的
  C 段，`[C.start_index, C.end_index]`）内 buy1→argmin(low) / sell1→argmax(high) 的**极值 bar**。
  这是「背驰极值 bar」的主读数。
- `lead_sub`：anchor − **C 的末子段**（`C.sub_moves` 中 `end_index==anchor` 的那段，即下钻首步
  会取到的那段）窗口内同侧极值 bar。
- `lead_center`：anchor − **中枢窗口**（`OwnerRef::Center(c)` 的 `[c.start_index, c.end_index]`）
  内同侧极值 bar。

## 2. 机制（代码事实，非推断）

1. **anchor 的来源**：一类点 `source_index = seg_end(seg).source_index = seg.end_index`
   （`signal.rs` `judge_first_cached` / `make_first_point`）。L≥1 的 `seg` 由 `unit_to_segment`
   投影自走势单元，`end_index = u.end_index`；上级走势 `end_index` 又由 `compose_level`
   `end_index = subs.last().end_index` 给出（`recursive_tower.rs:202-203`）——**点锚 = C 走势
   单元的末子段终点**（回抽段终点）。
2. **破中枢判据用的却是另一个量**：`first_structural_gates` 的 broke/extreme 用 `end.price`，
   而 `unit_to_segment` 对 Down 单元取 `end_price = lo`、Up 单元取 `end_price = hi`（全局极值价）。
   ⟹ **判据用 C 的全局极值价（lo/hi）判破中枢，点锚却落在 C 的末子段终点**——两个 bar 不是同一根。
3. **逐级放大的成因**：L0 的 C 是单线段，末子段终点≈线段端点分型，极值偏离仅来自「线段端点
   ≠ 段内原始 K 极值」（中位 16–20）；L≥1 的 C 是 Compose（多段），末子段常是**回抽反趋势段**，
   其终点离 C 的全局极值（在更早的同向子段里）越来越远。
4. **下钻方向失败的同一根**：`descend_type1_anchor_depth` 以 `find_move_by_end_index(subs,
   source_index)` 对齐，永远取「end==点锚」的那段 = C 的末子段；该段 `rmove_dir` 常为反趋势
   （1.4），`div_cand` 条件1（方向）即败——与 #1034 的 H1「下钻对齐恒取反趋势段」同机制，
   但「恒」不成立（本样本首步 counter 49%，非 100%）。

## 3. 判定（判定≠裁定）

- **事实成立**：一类点点锚系统性晚于 C 走势单元的背驰极值 bar，且偏移逐级放大（L0 中位
  16–20 → L1 180–210 → L2 ~1250 → L3 ~1500+）。「点锚=回抽段终点、非背驰极值」是结构后果，
  不是偶发。
- **「点锚该不该移到背驰极值 bar」**：从「点锚应标记背驰极值发生处」的语义看，**该移**——现锚
  在 L≥1 已不标记极值（偏移中位数百到数千 bar）。但这是**语义级变更**，动的是
  `BspPoint.source_index` 的点身份坐标，波及 BSP 去重键、nest 终端绑定、交易层触发 bar、
  结构止损 pivot 读取，并直接改写 #870/#1034 的下钻对齐键——**裁定权不在本票**。
- **建议的最小下一步**（供编排层）：① #1034 对照臂用「C 窗口极值 bar / departure 单元终点」
  两个对齐键重跑 Type1 cond1 桶，量化改锚后方向桶残余（本票已备好极值 bar 坐标口径）；② 改锚
  前先厘清「点锚=身份坐标」与「背驰极值=判据价格」两层在 `BspPoint` 里是否要拆字段（单字段
  双语义是当前错位的根），拆字段比「把 source_index 改成极值 bar」更可逆。
- **诚实边界**：L1–L3 样本 n=6/19/15/7，直方图方向稳但分位数细节受小样本扰动；单标的 BTC；
  frontier 末段未确认点可能少计（量级不影响结论）。
