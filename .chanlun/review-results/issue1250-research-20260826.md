## 1.2 当前教义正本对 R3 读法的后续约束

当前 `.chanlun/definitions/beichi.md:261-303` 是后于 R3 的正本。其 #814 D-3 在 `:263-273` 定出两层顺序，并在 `:265` 明写盘整背驰统一规则：这次冲出中枢段，应与「往回最近的一次**同方向跨界段**」比；**首次离开 = 进入段，反复震荡 = 上一次冲出去的段**；中枢内部震荡段不参与。该规则标作 `[新缠论:推论]`，并由 `:266-268` 的 061/049/053 原文支撑。

这与历史 R3 的关系须分层读，不能混成一个既成结论：

- **首次离开**：R3 的「中枢前最近同向单段 A′」可对应 D-3 所说的进入段，二者有可对齐的解释空间。
- **反复震荡**：D-3 指向「上一次冲出去的段」；R3 旧候选集同时保留中枢后前次离开与 A′。因此，后续正本已把「上次离开」写成统一规则，而不是单纯以「窄锚优先、失败才 A′」表达。
- **明确的静态代码差口**：`front_anchor` 的 `a_prime` 筛选只有 `direction == dir && end_index <= c.start_index`（`cert.rs:229-232`）；它没有检查该段价格是否跨过中枢边界，也没有证明它确为 D-3 所说的「进入段」。所以「A′ 可对应进入段」只是解释可能，**静态代码不保证 A′ 就是 D-3 的同方向跨界进入段**。
- **待裁张力**：R3 的 A′ 单段、候选集与回退顺序，是否完全等价于 D-3 的「最近同方向跨界段」，不能只凭两个文本并列断言。应以合成结构分别测试 A′ 跨界/不跨界、首次离开/反复震荡，以及此时 `judge_pan_div`、provider、lifecycle 的输出；再由 grilling 决定需不需要改定位器或只改注释。本报告不裁。

## 2. 两个定位器：可核代码事实

共同前提：生产 policy 下，当前 `seg` 端点须向下 `< zd` 或向上 `> zg`（`cert.rs:93-113`）；两者均用同一个 `departure_move_c_start` 计算 C 的当前离开 episode 起点 λ_C（`cert.rs:152`、`:226`；helper 定义 `divergence.rs:896-913`）。该 helper 对「失败离开→回中枢→重新离开」取最后回中枢后的 episode，不是旧的首个同向段。

| 定位器 | 额外命中条件（逐代码） | 产出的 A 区间 |
|---|---|---|
| 窄锚 `locate_pan_div_structure`，`cert.rs:106-185` | 在中枢后至当前 C 之前窗口中：存在反向且回中枢的段（`:141-151`）；存在早于 λ_C、同向且破核心的 `a_anchor`（`:153-160`）；A 与 C 之间还须有回中枢段（`:161-166`）。随后从 λ_A 到该 A episode 的最后同向段端点 ρ_A 取完整 `I(A)`（`:167-183`）。 | `seg_a=(λ_A, ρ_A)`：中枢后的前一次同向离开 episode。 |
| 前锚 A′ `locate_pan_div_structure_front_anchor`，`cert.rs:197-240` | 仍要求同一 C 端点条件和 λ_C；再取**最近**满足 `direction == dir && end_index <= c.start_index` 的段（`:223-232`）。它不检查中枢后「前一次破核心 A」、也不另要求 A-C 间回中枢段。 | `seg_a=(a_prime.start_index, a_prime.end_index)`：中枢前最近同向段，仅该单段。 |

因此两个集合并非单纯的「宽 vs 严」包含关系：A′ 省掉了窄锚的中枢后 A / 回中枢条件，却新增了「中枢前存在同向段」条件；窄锚也可在没有中枢前同向段时命中。这个「**静态前提集合不可直接证明单向包含**」是代码事实的逻辑后果，不是教义结论。

### 2.1 `or_else` 的实际回退点与结果层

1. `judge_pan_div`（`cert.rs:284-312`，由合并生产扫描 `scan.rs:990-998` 收集）在 `:293-294` 先做 `窄锚.or_else(A′)`，**仅当窄锚定位返回 `None`** 才调用 A′；随后不论来源，只在 `:303` 对选中的 `seg_a/seg_c` 调用一次不变的 `segments_diverge_or`。
2. `segments_diverge_or` 本体是唯一的三通道 OR：同色柱面积、DIF 峰、同向柱峰中任一个 `C<A` 即真（`divergence.rs:343-364`）。R3 没有复制或放宽该函数；改变的是其 `a_idx` 输入（由不同 `seg_a` 映射而来）。
3. `level_view/pan_provider.rs:398-410` 则先对窄锚 `filter(pan_div_structure_extreme)`，故 A′ 在「窄锚定位 None **或** 窄锚 Extreme 失败」时才会被算。两者之一通过结构+Extreme 后，`provider.rs:443-453` 才以同一 `segments_diverge_or` 填 `PanEventCore.divergence_confirmed`；`false`（包括映射失败的 `unwrap_or(false)`）**仍照常构造并 materialize event**，不是 provider 当场 `None` 拒发。因此 provider 的 OR 值是事件字段，不与 `judge_pan_div` 的 PanDivCert 准入混称为终判；但 `false` 同样不会触发 A′ 重判。
4. `nest_lifecycle/pan.rs:45-60` 与 `:280-305` 只做「窄锚 `locate∧Extreme` → A′ `locate∧Extreme`」后产 `PanLiveWindow`，在此函数内**不读取 Weak/OR**；力度三值化发生在后续生命周期处理，不能把它与 provider 的 `divergence_confirmed` 写成同一即时门。
5. 已有单测 `signal.rs:3744-3782` 只锁住「中枢后无回中枢段，窄锚不可得；A′=(1,3) 救回并产证」；未发现它构造「两锚同时可定位、分别喂入 Weak 后得相反 PanDivCert / event 字段」的对拍。

对「同一候选会不会给不同结果」须分三个语义层回答：

- **PanDivCert 层（`judge_pan_div`）已证事实**：两个定位器若各自命中，会按不同规则构造 `seg_a`，并把该 `seg_a` 传入同一个力度谓词；静态代码不禁止同一 `(c, seg, segments)` 同时满足两者。若窄锚成功，`judge_pan_div` 不计算 A′，所以该调用的证书准入固定采用窄锚，且 Weak=false 直接 `None`（`cert.rs:303-305`）。
- **provider 事件层已证事实**：provider 在 `locate∧Extreme` 层选锚；随后无论 `divergence_confirmed` 真/假都构造 event。故它没有与 `judge_pan_div` 同义的「Weak=false 终端拒发」。
- **尚未实测**：尚无本次构造或既有测试证明「两个定位器同时成功时，`segments_diverge_or(A,C)` 与 `segments_diverge_or(A′,C)` 必相反」；代码也不会在窄锚成功时比较这两个值。故不能把“会给不同证书准入或不同事件字段”写成已证事实。
- **待 grilling 的可测命题**：给定同一 `c/seg/segments/hist/dif`，四格对拍：`narrow.locate`、`front.locate`、各自 Extreme、各自 `segments_diverge_or`；并分别断言 `judge_pan_div` 的证书结果、provider 的选锚及 `divergence_confirmed` 字段、lifecycle 的产窗结果。这会把「结构选择」与「Weak 真值」分开，不预设裁定。

特别是 provider/lifecycle 的回退会发生在「中枢后上次离开段已可定位、但它的 Extreme 失败」时，此时它改用进入段 A′ 再判 Extreme；而 #814 D-3 的现行文字说反复震荡应取上一次冲出去的段。两者是否冲突，取决于 D-3 的「上次离开」是否同时把 Extreme 失败排除出可比较对象；正本文字在此未写该例外，代码则已实现回退。**这是本题最小、可判的 grilling 缺口，不是本报告的结论。**

**事实结论**：一级原文确实支持「最近段是最标准而非唯一」以及「围绕同一中枢的两段可以比较」，并有中枢两头比较实例；080:364 不是正文，且含两处行内编辑注。实装确实把「中枢后前次离开 episode」和「中枢前最近同向单段」作为两个不同 A 构造，以 `or_else` 排序后共用同一个 Weak/OR 函数；不同调用面将 Extreme 放在不同的回退位置。
