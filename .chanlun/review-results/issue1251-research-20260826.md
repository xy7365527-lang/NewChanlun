# #1251 原文考据：窄锚 vs A′——宽严两档，还是同一判据的定位步骤？

> 研究票：#1251（对应后续 grilling；本报告只 research，不作裁定）  
> 范围：同 #1250 三面——原文面、既有裁定/纪律面、代码行为面

## 0. 结论先行（研究建议，非裁定）

1. **原文没有给出“窄锚判负，再用 A′ 放宽重判”的两套背驰判据。**原文给出的顺序是先定比较哪两段，再比较力度；“前面最近同向段”只是“最标准的情况”，并非排他定义。原文还展示了首次离开与反复震荡时参照段位置会不同。
2. **既有教义正本已经把两种位置收成一条 D-3 规则**：往回取最近的同方向跨界段；首次离开时是中枢进入段，反复震荡时是上一次同向离开段。按这份已结算正本，窄锚与 A′ 最有力的名分是**同一取段规则的两个互斥结构情形**，不是严格/宽松两档。
3. **但当前代码并非只有一种消费形状，不能笼统说“都是定位步骤”。**
   - `cert.rs::judge_pan_div`：先用 `narrow.or_else(A′)` 定出唯一结构，再且仅再跑一次 `segments_diverge_or`；窄锚已经定位但 Weak 判负时，不会让 A′ 重判。该形状支持“定位步骤”。
   - `level_view/pan_provider.rs` 与两处活窗入口：`narrow.filter(Extreme).or_else(A′.filter(Extreme))`；窄锚已定位但 Extreme 判负时，会换 A′、换 `seg_a`，再判同一个 Extreme。该形状在生产准入上确实是“第一档失败后第二档接管”，正面触及 #799。
4. **“窄/宽”不是两个谓词的数学单调关系。**A′ 换了比较对象；它可能让 Extreme/Weak 更容易，也可能更难。它之所以在现代码中表现为“宽档”，是因为 `or_else` 扩大了可准入集合，不是因为 A′ 对所有输入都更宽。
5. **建议 grilling 把裁定问题拆成两问，并先裁第一问：**
   1. A 的唯一定位规则是否就是 D-3 的“首次离开取进入段／反复震荡取上一次离开段”，且情形归属必须在看 Extreme/Weak 之前确定？
   2. 若是，所有生产路径都应先一次性定位 A，再跑一次 Extreme/Weak；不得因 Extreme 或 Weak 失败切换 A。若不是、而是要裁成“对多个合法 A 作存在量化”，则应把合法 A 集合和量词明写成一份统一判据，不能继续以“窄锚失败，A′ 救回”的隐式两档形状存在。

**本报告的倾向性建议**：保留“定位步骤”名分，但只限于**首次离开／反复震荡这两个结构上互斥的 case**；把 `pan_provider`/活窗当前“Extreme 失败后换锚重判”的形状列为待收敛项。`judge_pan_div` 已接近目标形状，provider 一线尚未对齐。此为 research 建议，不替后续 grilling 下裁定。

这一建议并非无反侧：历史 R3 代理裁定曾明写“A 候选集扩展为并集”，是支持“多 A 候选搜索”而非互斥 case 的最强仓内材料；但它的名分、原文误引与后来 #814 D-3 的关系必须先分清，见 §3.4。

## 2. 原文面：支持哪一种读法？

### 2.1 049：最近是“最标准”，不是“唯一”；先定位，再区间套

`docs/chanlun/text/blog/049-第49课.md:36`【正文】：

> “对于第二种第1类，由于中枢震荡依旧，因此，先找出该中枢前面震荡的某段，与之用类似背驰比较力度的方法，用MACD辅助判断，找出向下离开中枢的当下该段走势，看成背驰判断里的背驰段，然后再根据该段走势的次级别走势逐步按区间套的办法去确定尽量精确的买点。”

`049-第49课.md:38`【正文；止于行内注之前】：

> “注意，用来比较的某段，最标准的情况，当然是前面最近向下的，一般情况下，中枢震荡都是逐步收敛的，这样，如果继续是中枢震荡，后面的向下离开力度一定比前一个小。”

能严格读出的只有：

- 比较对象先被定位，力度比较在后；
- 最近同向段是“最标准的情况”，原文没有说“仅此一段”；
- “前面最近向下”在反复震荡时自然落到上一次向下离开；在首次离开时，前面可供比较的同向段会落到中枢另一侧。

它支持“同一定位程序有标准优先级”，**不直接支持**“标准锚判据失败后，可以用另一档判据把同一候选救活”。

### 2.2 061：围绕同一中枢可比较；正文实例确有两种位置，但没有“先后兜底”原句

`docs/chanlun/text/blog/061-第61课.md:26`【正文】：

> “要比较力度，发现背驰，首先要搞清楚是哪两段比较，其实，只要是围绕一中枢的两段走势都可以比较力度。显然，对于60-65这个1分钟中枢，55-60与65开始的一段之间就可以比较。”

这句话明确把“先搞清楚哪两段”置于力度判定之前；其例子是中枢两侧的进入段与首次离开段。

`061-第61课.md:28`【正文；剔除行尾娇注】：

> “对于65开始背驰段的内部走势，当下走到69时，并不构成任何背驰，为什么？因为背驰如果没有创新高，是不存在的。”

同一行稍后【正文；仍止于娇注之前】：

> “而在实际中，不难发现，71点开始的走势力度明显比不上69-70段，而对于65-66段，69开始的走势力度也明显比不上，这从两者下面对应的MACD红柱子面积之和可以辅助判断。”

作者正文自身已经包含两组比较：`71开始 ↔ 69-70` 与 `69开始 ↔ 65-66`。这支持“参照位置取决于当下所处的嵌套结构”，也支持进入段/前次离开段两种位置都可能合法。但作者没有说：第一组 Extreme/Weak 判负后，再换第二组把同一个候选重判一次。

### 2.3 080：否定“只看最近一段”，但不能单独推出当前 A′ 算法

`docs/chanlun/text/blog/080-第80课.md:364`【答疑；只引第一个行内注之前的完整作者句】：

> “比较力度，用盘整背弛一招也不是光比较最近这一段的。以前有课程专门说过中枢震荡中的力度比较问题。你必须从96开始看，101没出来前，只能先看96-99这个中枢的震荡。这震荡没破97这点，就意味着震荡的力度有限，所以一定只是中枢震荡。”

同一答复的另一个无注完整句：

> “另外，柱子面积也比不上。”

这条答疑有力否定“机械地永远只比最近一段”，但上下文同时在谈：

- 从 96 开始看整个 96-99 中枢震荡；
- 100/101 内部黄线结构与柱面积；
- 线段下没有中枢时不能照套中枢概念（`:368`）。

因此它只能作为“最近不是排他口径”的补强，**不能独自证明**当前 `front_anchor` 的精确算法——“在所有窄锚失败情形下，取 `end_index ≤ c.start_index` 的最近同向段”——就是缠师原句。

### 2.4 原文合读

三课合在一起，最稳的原文级结论是：

1. 先识别围绕哪个中枢、比较哪两段；
2. 再判 Extreme 与力度；
3. 最近同向段是标准选择，但不是一句排他公理；
4. 首次离开与反复震荡的参照位置可以不同；
5. 原文没有授权“力度/创新极值判负后换参照段再判一次”的控制流。

这组证据更支持“定位步骤／结构 case”而非“同一背驰判断的宽严两档”。但它仍留下一个必须由新缠论裁定填的空白：合法参照是唯一 case 选择，还是多个合法配对的存在量化。

## 3. 既有正本与纪律面

### 3.1 #814 D-3 已结算的统一取段规则

`.chanlun/definitions/beichi.md:261-278` 是教义正本中的“两层结构”。其中 `:263-272` 把结构层先于度量层，并在 `:265` 明写：

> 盘整背驰拿“这次冲出中枢的那一段”与“往回最近的一次同方向跨界段”比较；首次离开时是进入段，反复震荡时是上一次冲出去的那段；中枢内部震荡段不参与。

该段名分是正本层，文件头 `beichi.md:3-8` 明写最后裁定含 #814 D-3，状态已结算。它还在 `:272` 点名：`locate_pan_div_structure` 的“只定位不判力度”形状是结构层/度量层分离的正确形态，但取段边界需对齐 D-3。

因此本研究不能另起一份口径推翻 D-3。就当前任务而言，D-3 给出的最直接解释是：

```text
若存在已经完成、且与 C 分属两次离开 episode 的同向跨界段
    A = 最近一次这样的离开段          // 反复震荡
否则
    A = 中枢形成前的进入段            // 首次离开
然后一次性判断 Extreme(A,C) 与 Weak(A,C)
```

它是**按结构事实分 case**，不是按 `Extreme/Weak` 是否失败分 case。

### 3.2 #799：控制流失败触发器比函数名字更承重

`AGENTS.md:46-58` 的已裁通则是：同一个判断不得有宽严两档，更不得让宽松档接管严格档失败；“严格版判不出来 → 换宽松版再判 → 放行”违规。三项限定词是：

1. 不同判断；
2. 诊断模式 vs 生产模式（诊断不得参与准入）；
3. 已声明、且不产生交易决策的独立对照臂。

套到本题：

- “定位 A”与“判断 Extreme/Weak”若严格分层，是不同判断，定位内部的首次/反复 case 可以合法；
- `judge_pan_div` 与 `pan_provider` 是生产路径，不受诊断限定词保护；
- 窄锚/A′ 也不是独立对照臂；
- 一旦 `Extreme=false` 成为切换 A 的触发器，就不再只是定位层内部的 case 分派，而是同一准入条件失败后换参照重判。

### 3.3 #804：不直接构成“跨级分缝”，但禁止用代码外形掩盖语义差异

`AGENTS.md:64-82` 的总缝规则针对“同一判定每一级必须跑同一个判定”，判别式是相同数据输入时输出逐位相同，强调语义而非 `if`/函数名外形。

本题两条 locator 在现状下被各级共用，并非 `L0` 与上级各跑一套，所以 #804 的“跨级分缝”不是最直接病名。但其语义判别仍有两点约束：

- 同一输入喂给两条 locator，可能返回不同 `seg_a`，故二者不能被宣称为“两份等价实现”；
- 它们若共存，必须有明确的不同 case／不同职责名分；若只是两个可互换的准入实现，则仍回到 #799。

## 4. 代码面：两种 locator 到底差在哪里

### 4.1 共同部分

`rust/src/theta_v0/classifier/signal/cert.rs:90-100,128-184,216-240` 显示两支都：

- 用同一个 `pan_div_side_with_policy` 判 C 的方向与破核心；
- 用同一个 `departure_move_c_start` 得到 `λ_C`；
- 返回同一个 `PanDivStructure {side, center, seg_a, seg_c}`；
- 不在 locator 内消费 MACD 力度。

所以差异全部集中在“谁是 A”以及 A/C 是否被认为是两次离开。

### 4.2 窄锚 `locate_pan_div_structure`

`cert.rs:128-184`：

1. 搜索窗只取中枢结束后到当前 C 之前的段（`:138-140`）；
2. 要求存在反向段回到中枢核心（`:141-151`）；
3. A 锚是窗内最近的同向且自身破核心段（`:153-160`）；
4. A 锚与 `λ_C` 之间还必须有回中枢段，证明 A、C 不是同一次离开（`:161-166`）；
5. `seg_a` 扩成该次离开 episode 的 `[λ_A,ρ_A]`，并非只取锚段（`:167-183`）。

其自然有效域是**反复震荡**：中枢后已经有一次同向离开，并且后来回到中枢，再次形成当前 C。

### 4.3 A′ `locate_pan_div_structure_front_anchor`

`cert.rs:216-240`：

1. 不搜索中枢后的前次离开；
2. 直接在全段列中逆序取 `direction == dir && end_index <= c.start_index` 的最近段（`:229-232`）；
3. `seg_a` 就是该单段的起止（`:233-238`）；
4. 不另验 A′ 自身是否是 D-3 所说的“进入段/跨界段”，也不验中枢后回中枢；代码把“整个中枢位于 A′ 与 C 之间”当成分隔。

其自然有效域是**首次离开**：中枢后还没有另一只已完成的同向离开 episode，比较对象只能落在中枢形成前。但当前函数签名本身没有“首次离开”布尔前提；只要调用方走到它，就会尝试前锚。

### 4.4 同一候选能否给出不同终判？能，而且原因可由公式直接证明

同一 `(center,C,segments)` 可以同时存在：

- 中枢后的窄锚 `A_n`；
- 中枢前的 A′ `A_f`。

两条 locator 会给出不同 `seg_a`。下游 `pan_div_structure_extreme`（`cert.rs:242-263`）和 `segments_diverge_or`（`divergence.rs:343-364`）都显式读取 `seg_a`，所以终判可不同。

以 Long 为例：Extreme 是 `low(C) < low(A)`。若市场恰有

```text
low(A_n) ≤ low(C) < low(A_f)
```

则窄锚 Extreme 为假，A′ Extreme 为真；反向不等式可令 A′ 更严。Weak 同理：A 段同色柱面积、DIF 峰、同向柱峰都随 `seg_a` 改变。故 A′ 不是恒定更松的谓词，但“失败后再试另一 A”会扩大组合准入集合。

## 5. 关键分水岭：当前代码有两种不同消费形状

### 5.1 `judge_pan_div`：强支持“先定位、后一次判力”

`cert.rs:284-312`：

```rust
let structure = locate_pan_div_structure(...)
    .or_else(|| locate_pan_div_structure_front_anchor(...))?;
// 映射唯一 structure 的 A/C
if !segments_diverge_or(..., a_idx, c_idx) {
    return None;
}
```

行为含义：

- `or_else` 只消费 locator 的 `Option<PanDivStructure>`；
- 一旦窄锚返回 `Some`，A 固定，A′ 不再执行；
- 后续区间映射失败或 Weak 判负，直接 `None`，不会用 A′ 重判 Weak；
- `segments_diverge_or` 始终是同一函数、只跑一次。

因此在这条证书路径里，窄锚/A′ 可以被解释为**结构定位的优先 case**。它不是“严格 Weak 失败后宽松 Weak 接管”。需要继续 grilling 的边界仅是：A′ 是否只会在“真正首次离开”时触发，还是也会吞掉 locator 的其他技术性 `None`。

### 5.2 `pan_provider`/活窗：Extreme 失败直接触发换锚，构成反面证据

`rust/src/theta_v0/classifier/level_view/pan_provider.rs:398-411`：

```rust
locate_pan_div_structure(...)
    .filter(|s| pan_div_structure_extreme(s, ...))
    .or_else(|| {
        locate_pan_div_structure_front_anchor(...)
            .filter(|s| pan_div_structure_extreme(s, ...))
    })
```

同形还在：

- `nest_lifecycle/pan.rs:45-57`（已完成段参照活窗）；
- `nest_lifecycle/pan.rs:280-291`（active C frontier，生产活窗）。

这里 `filter(Extreme)` 位于 `or_else` **之前**。所以：

1. 窄锚可以已成功定位；
2. 只因 `Extreme(A_n,C)=false`，整个第一支变成 `None`；
3. A′ 换成 `A_f`，重判同一个 Extreme；
4. 若 `Extreme(A_f,C)=true`，候选/活窗被准入。

这不是单纯“找不到 A 才走首次离开 case”，而是**同一结构准入判断失败后换比较对象再判**。它位于生产 provider/活窗路径，既非诊断，也非独立对照臂；按 #799 文义，这是当前最强的“宽严两档”证据。

若按历史 R3 的“A 候选集并集”读法，它也可以被解释为：在两个合法 A 中寻找一个通过 Extreme 的见证，而非严格/宽松两套 Extreme。问题在于当前正本 D-3 未明写这个存在量词，代码也没有构造完整候选集，只硬编码两只历史特例。因此 **R3 能解释代码来源，但不能自动解除 #799 风险**。

provider 随后在 `pan_provider.rs:441-447` 对已选结构计算同一 `segments_diverge_or`，但 Weak 结果只写 `divergence_confirmed`。真正的分档已在前面的 Extreme 准入发生，不能用“后面 Weak 同源”消掉。

### 5.3 仓内已有的单规则对照：`div_cand` 没有这条缝

当前同仓另一条已按 #814 D-3 收口的实现位于 `cand_predicate.rs:263-384`：

- `:328-351` 用一次 `rfind` 取最近同方向跨界段；有中枢后离开段时取它，否则落到中枢前进入段；
- `:353-360` 对选定的唯一 `s_prev` 判一次 Extreme；
- `:362-384` 再对同一 `s_prev` 判一次 Weak；
- Extreme/Weak 失败均直接返回失败，不换参照。

对应测试已把两个结构 case 分开锁住：

- `cand_predicate.rs:1477-1506`：首次离开比较进入段；
- `cand_predicate.rs:1508-1548`：反复震荡比较上一次离开段；
- `cand_predicate.rs:1448-1475`：中枢内部震荡段不得作参照。

这说明“两个位置、一份取段规则、一次 Extreme/Weak”在当前数据类型上已有可执行形状，不需要把 A′ 保留成 Extreme 失败后的补救档。

## 7. 对后续 grilling 的结论建议（非裁定）

### 7.1 建议先钉死的定义句

建议 grilling 优先确认或否定以下句子：

> **A 的位置由 C 所处的结构阶段唯一决定：首次离开取进入段，反复震荡取上一次已经完成且与 C 分属不同 episode 的同向跨界段；阶段判定不得读取 Extreme 或 Weak 的结果。**

若确认，这句话正好把窄锚/A′定为同一定位程序的两个互斥 case，并给出 #799 可机械检查的边界。

### 7.2 对当前代码的建议分级

1. **`judge_pan_div`：保留形状，补 case 前提审计。**重点证明 A′ 的每次触发都等价于“没有可用的上一次独立离开 episode”，而不是任意内部 helper 失败。
2. **`pan_provider` 与活窗：列为必须收敛。**应先定结构，再在所选结构上判一次 Extreme。最小语义形状应与 `div_cand` 一致；具体改法归后续实施票，本 research 不改代码。
3. **订正原文溯源。**所有“061:28 中枢两头比较”的注释须在后续实施中移除该作者归属，改引 061:26/28 的真实作者句，或直接指向 `.chanlun/definitions/beichi.md` D-3；娇注可作为历史注者意见保留在考据说明里，但不得标成【正文】。
4. **补一组判别性测试。**同一输入同时有 `A_n` 与 `A_f`，构造 `Extreme(A_n,C)=false`、`Extreme(A_f,C)=true`；期望值由 grilling 裁定决定。它能直接锁住“Extreme 失败可否换锚”，比 grep `or_else` 更符合 #804 的语义测试纪律。

### 7.3 若 grilling 选择“多个合法 A 的存在量化”

这是一条可辩护但不同的路：把原文“围绕一中枢的两段走势都可以比较力度”形式化为合法配对集合，并定义

```text
∃ A, Comparable(A,C) ∧ Extreme(A,C) ∧ Weak(A,C)
```

这样扫描不同 A 不是宽严两档，而是同一存在量词的候选枚举。但要成立，必须同时做到：

- 正本明确改写/补充 D-3 的“最近一段”唯一性；
- 一次性定义完整合法 A 集，而非只保留“窄锚 + A′”两个历史特例；
- 生产代码以同一个集合谓词实现，不再用“rescue/fallback”描述；
- 明写多 A 证书的身份与生命周期规则。

在这些条件未裁前，不能把当前 provider 的 `or_else` 事后解释成完整存在量化。

## 8. 最终研究判断

**原文与既有正本倾向“定位步骤”；当前实现则是混合态。**

- `judge_pan_div`：定位步骤形状基本成立；
- `pan_provider`/活窗：当前确有同一 Extreme 判断的换锚兜底，属于 #799 高风险形状；
- 两者不能用一句“窄锚优先、A′ 回退”统称为同序同判，因为回退触发器不同：一处是定位 `None`，另一处包括 Extreme 判负。

因此后续裁定不应问抽象的“A′ 要不要留”，而应问更窄、更可执行的问题：

> **A′ 是否只能由“首次离开”这一结构事实触发，并且一旦 A 已定位，Extreme/Weak 失败是否必须诚实判负、禁止换锚？**

本报告建议回答“是”；但该回答仍须由 grilling 正式裁定后才能进入教义正本或实施链。
