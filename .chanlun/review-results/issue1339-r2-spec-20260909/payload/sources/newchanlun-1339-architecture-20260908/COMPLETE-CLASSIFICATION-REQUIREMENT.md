# 用户补充：必须完全分类

用户在范围确认后再次明确：**“我们是完全分类的全互斥定义，所以你必须完全分类。”**

本要求作为后续架构的硬约束；不是仅列全概念、代表分支或丰富展示字段。对各已声明对象/分类轴和良构输入域，必须给完整分支及判据，并以无遗漏、两两互斥、唯一归类验证。多个独立轴或可并存现象，要显式给允许的组合及约束，不能靠全局优先级/first-match消灭事实。状态和事件的合法转换也必须列清。

数据不足、适用域外、诊断用途及结果有效性另列；不能把定义域内尚漏掉的类别塞进Unknown、Other或宽松兜底。已有正本如果对某边界尚未裁定或没有完整性证明，必须指出具体缺口及来源，不由本轮设计作者静默补一条定义，也不宣称已证明全分类。

第一阶段80行是聚合需求目录，不是叶分支枚举或完全分类证明。本阶段必须补完全分类目录：完整叶分支/公式化分支族、定义域与边界、组合/转换、不漏不重的验证方法、后端输出与前端展示。目录按正本逐项取证，不能仅用80这个条目数当作覆盖证据。

本补充为用户明确要求，无需重复确认范围；后续设计和独评均以第一阶段批准范围＋本补充为准。当前不增加实现或新语义批准。
