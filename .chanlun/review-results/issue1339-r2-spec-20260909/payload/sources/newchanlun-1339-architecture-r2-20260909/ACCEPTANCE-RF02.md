# RF-02 修订的验收义务

依据为同目录 USER-DECISION：交易因公共经济安全故障停止新增时，结构仍要产出正式结果。以下是本体给修订与独评使用的验收合同，尚未执行；不构成 SPEC 或新资金政策。

## 前件与两个独立结论

结构输入与适用规则齐备、结构计算/自身持久记录/结构查询可用，受控输入前缀有限且能获得公平调度。向共同经济安全域注入故障或网络分区，不能故意关闭结构自身依赖后把结果归为结构故障。失败的经济组件与正常结构组件须能按最终技术方案分别定位、隔离和测量。

1. 结构后台持续实际计算并正式持久发布分类实例、对象、关系、修订、撤回与真实获知前沿；正常的结构消费者获得这些结果。
2. 不可核的共同约束仍禁止新增交易。结构新鲜不等于资金或执行已恢复；旧经济结果不能改写成由最新结构生成。

结构输出正确性仍受原目录/44 ST 的全部义务约束，本轮仅增加故障独立性。该前件不保证无限速率输入下的固定时延或无限存储，也不豁免由经济等待产生的死锁与反压。

## 必须逐项观察的故障场景

| ID | 故障或交错 | 必须观察到的结果 |
|---|---|---|
| RA-01 | 共同经济日志在新结构输入到来前停止读写 | 同一正式运行代际继续发布新增结构，已有结构订阅可见；交易不得使用内存中的旧 Open 状态取得新发送能力。 |
| RA-02 | 经济域在结构计算中途或发布前故障 | 当前结构修订完成自身正式提交，不等待经济 Begin/End、receipt 或经营轮结束；恢复不能重复发布同一逻辑修订。 |
| RA-03 | 结构与经济之间双向分区，结构自身与前端正常 | 结构快照、分页、变化、续接均可使用；隔离经济写者不能用缓存结构证明生成新的发送资格。 |
| RA-04 | 故障期间结构相继修订和撤回，撤回波及已准备/已承诺交易 | first_known_at 保持真实顺序；未越合法外效边界的旧命令失去发送能力。确已越界者保留可能全量责任与查询/退出路径，不能假定撤回消除在途外效。 |
| RA-05 | 先检查财务有效，随后结构撤回；或先检查结构有效，随后 Capture 未核财务事件 | 协议分别解释两种交错的唯一线性化点；两次独立读到新值不能当作共同有效证明。不得把普通缓存许可更名为已发来消解反例。 |
| RA-06 | 结构已发布，经济收件延迟/重复/丢失/乱序 | 结构无须回滚或停发；经济按依赖和已消费前沿核对，不能用收到通知的时间替换结构首次获知。重试不产生第二条命令身份。 |
| RA-07 | 经济在许可持久化、结构核验、最后发送、回报 Capture 等各边界崩溃 | 恢复明确区分确定未发与可能已发，保留潜在责任；记录丢失或不确定不能触发自动重发。每个跨域待决状态均有可核去向。 |
| RA-08 | 旧经济或执行写者恢复，带旧 epoch/游标/令牌重试 | 旧代际不能取得新外效。若声称远端已不可执行，必须给实际可核的 fencing/身份假设，不依赖本地自觉退出。 |
| RA-09 | 共同经济域不可用，汇合观察无法取得当前经济账 | 结构范围是正式且完整的结果；界面独立显示经济侧缺失或可信旧版本及 consumed_structure。不能等待全系统 JoinCut 才发布结构，也不能标整个系统当前完整。 |
| RA-10 | 在故障期浏览、分页、断线续接及 AsKnown 回放 | 固定结构切面分页不漂；连续流与相同切面快照逐字段相等；结构修订史和当时已知关系可查。故障时不存在的经济新事件不得事后补造为当时已发生。 |
| RA-11 | 经济恢复而结构已推进多个版本 | 先重建责任/Pending/源连续性，再核当前结构及尚存资格；不按历史候选逐条补发。旧责任、成交、更正继续归原身份，P7 冻结总量不重测。 |
| RA-12 | 恢复后 RF-01：A 重账仍坏，界仍可核，B 健康且合规 | B 实际产生新的 Committed；不能只返回可交易标签，也不能因重放 A 或等待全体经营完成而持续挡住 B。 |
| RA-13 | 结构输入持续，经济消费者慢或故障 | 结构调度不等待经营轮；满足前件的经济工作恢复后得到公平机会。不得靠永远停结构或永远停交易使另一项表面成立；不以队列处理顺序默认分配资金。 |
| RA-14 | 同一行情既供结构计算又供经济估值，经济解析或接纳故障 | 正式结构仍可获知并发布；相应估值/共同约束若未核则交易关闭。不能以经济 Capture 是唯一市场入口，使经济故障从输入端再次阻断结构。 |

## 证据要求

文档复核须逐条给协议条款、故障状态、恢复路径和未证假设。未来实现验收须从实际生产入口施加故障，观察权威记录和前端结构消费，而非只测试纯结构函数，亦不能通过改称诊断模式通过。

目前所有 RA 项均为待执行验收义务；稿件反例闭合和任何有限模型只支持其所声明范围，不表示真实场所、完整分类或生产验收已经完成。
