### FG-001 N个持久重与专属筹码身份

支持N个同时存在的持久重；每重有标的S、操作级别ℓ和专属筹码Q，跨越多次建仓不终结；没有专属筹码的从属操作不冒充独立重。

边界：N个持久重并存的能力来自既有要求；不在本草案另加最低测试数量。持久性不等于无限运行授权，旧类名或账本布局不从重的三要件推出。

必须可观察：重身份、标的、操作级别、专属筹码来源、开户/退出时点、历次Voice与经营事件链。

验收：多个独立重可在不同操作级别并存；重经历再次建仓后仍保有自身身份和完整经营史。具体样例数量由需要证明的行为确定，不成为产品门槛。

反例：只有一个总账户复制N个图层；清仓后把该重与成本史删除。

对应完整场景：FE-01、FE-02。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-002 独立资金和权利与共同上限同时成立

各重开户取得自己的钱与筹码，独立经济权利，不把N重解释成一份钱的递归等式切片；共同总保证金/总名义采用不等式约束。

边界：不同重的资金不得因另一重平仓/闲置自动释放；物理净额省下保证金不扩大任何重权利。总上限的数值和资金政策仍待定。

必须可观察：逐重权利/已用/预留/可用、投入和回收、共同毛上限及每次受限依据。

验收：一重有闲置资金而另一重请求增用时，仍按各自权利和共同毛上限判定。

反例：因为总净头寸小，把另一重闲置或相反腿省出的额度再部署。

对应完整场景：FE-02、FE-06。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-003 目标、一个成本与一个TStage随重持久

每重有自己的经营目标、总体成本和三阶段状态；该重内部各结构级的短差进入该重同一个成本，不能每塔层各造一份TStage。

边界：目标/成本状态是状态而非身份键；当前文字语义键为(S,操作级别)，其软件唯一性和额外ID不在本票选择。

必须可观察：目标版本、TStage前后值、成本基/数量/已回收本金、触发事件与结构版本、归属重。

验收：同重两个不同结构级短差产生不同损益但更新同一成本；其他重成本不变。

反例：全局一个TStage，或因成本过零换成一个全新重。

对应完整场景：FE-01、FE-04。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-004 一次Voice的生命周期与不可变开局依据

Voice表示一次建仓生命周期，一经建立其载体、证书、方向和代际身份不可变，出场终结；重包含多次Voice而不随Voice死亡。

边界：不得把重的持久Q与campaign开局冻结量混为一件事；这里不规定持久化格式。

必须可观察：Voice身份、所属重、开局结构/证书/数量依据、parent关系、开/平事件、终结后只读历史。

验收：同重反复操作保留两次独立Voice，成本史不断；重新送达旧开局事件不能创造新Voice。

反例：为追随重基/新价直接改写既有Voice的开局证书或方向。

对应完整场景：FE-01、FE-09。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-005 重内有向合成且不穿零

同一重内不同结构级操作合成后处于该重自身方向的[0,Q]区间，不能穿零；要同时持多与持空须独立专属筹码。

边界：子级反向操作可以是减持/回补或形式腿，不能被误解为本重获准翻方向；Q/可用量的账目语义须先有据。

必须可观察：各结构级贡献、合成前后目标、方向界、持有量/可减量、被拒的越界原因。

验收：两个子级同时减量时检验总减量不超过本重可用筹码；回补只恢复许可量。

反例：每条子信号单看未超量，合成后却穿零；用净额遮住本重越界。

对应完整场景：FE-02、FE-03。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-006 重间不作方向仲裁

独立重相反动作并存，各按自己的信号经营；不能设大级别优先或因高层退出消灭另一重的预算。

边界：共同毛约束/资源不足可以限制经济准入，但不能伪装成结构方向仲裁；同slot资金不足的具体协调规则仍是后续设计/政策项。

必须可观察：两重原始意图、各自依据、资源判定、独立结果及净额合成关系。

验收：高操作级别持多并退出时，较低级别独立空重可继续；共同限额紧张时保留两项有效语义及经济拒因。

反例：把低级别相反信号标成无效，或高层平仓自动cascade清掉独立低重。

对应完整场景：FE-02、FE-06。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-007 结构级别、操作级别、Voice代际和区间套深度分开

结构级别属于构造，操作级别属于重的经营视角；Voice代际是相对父链位置，区间套深度是定位收缩层数。需要共同解释时显式给参照系。

边界：现有根级别-depth关系的有界实测不等于全球身份方案；不得用分钟时间周期或裸depth代替所有轴。

必须可观察：每项输出附适用的轴与参照系；结构对象、重、Voice、定位链相互可追。

### FG-027 订单身份、冻结量、当前挂价与旧框清算区分

可辨同一订单续挂/新挂/撤销。既有回测口径按中枢起点+方向识别，量冻结、当前挂价随核心修订，清算仍用首次冻结旧框。

对应完整场景：FE-03、FE-07。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-028 回测成交假设与真实外部成交不能混证

对应完整场景：FE-03、FE-08、FE-10。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-029 部分成交、重复和乱序事实的完整接纳

验收：两个客户端断线不同时间后续接到相同版本，能解释当时未知、后续修订与真实成交。

对应完整场景：FE-09。证据状态：需求取证/静态；未跑程序、成交、回放或性能验收。

### FG-035 未定钱规则和软件组织保持显式未定

## 完整经营端到端情景

以下为架构无关的验收情景草案。每个完整候选须解释全部步骤；若钱规则尚未批准，应使用显式标明的测试参数或说明被阻塞处，不能将未定值变成生产默认。逻辑fixture通过不证明市场有效性。

### FE-01 持久重的完整经营过程

起点：多个操作级别的独立重，分别已有资金、筹码、成本和结构版本。经济参数须标为测试输入；场景中的具体数量不成为产品定义或生产授权。

1. 主动选段并真实下钻，建立许可满仓目标，允许分批成交完成。
2. 同重不同结构级先后做至少两次短差，含一次盈利、一次亏损及费用；成本逐项归因。
3. 出现中枢完成移动，维持该重基线；新中枢到来恢复合法经营。
4. 一重完成整次退出又重新建仓，Voice变化而重与成本史连续。

验收断言：三方向均有真实调用/结果证据。；逐重权利和经营史不互串；实现回收事件可沿成本轨迹逐项核对，空账不能证明这些行为。；结构、决策、外效、账目和前端展示同源相连。。

不能缩减成：只造N个空Book、只渲染marker、只跑单根同向持仓均不满足。

### FE-02 相反独立重、净零和共同毛约束

起点：示例：重甲持多Q1、重乙持空Q2，取Q1=Q2观察净零；另设丙请求新权利，以检查净省禁复用。甲乙丙仅说明事件关系，不规定最低重数。

1. 甲乙依据不同级别合法事实同时提交相反意图。
2. 记录两份毛权利与实际净额外效。
3. 净零期间丙请求使用被净抵消省下的额度。
4. 甲先退出、乙继续存活，再接外部成交。

验收断言：净零不抹掉甲乙毛账、TStage或未来退出义务。；丙不能复用净省。；甲退出不仲裁乙；单边变化产生可追外效。。

不能缩减成：仅比较净NAV/净仓位不能验各重独立性。

### FE-03 短差全生命周期和部分成交

起点：已有多头基线、合法中枢震荡和两个相对深度动作。

1. ZG上方减持，部分成交40%，继续成交20%。
2. ZD下方回补，重复/乱序回报去重；一次回补为亏损。
3. 核心修订使挂价变化但量不重算；清算旧框保留。
4. 随后出现第三类卖点，旧回补域终止；处理仍在途部分。

验收断言：Q基冻结、合成不穿零、回本前同量回补。；盈利亏损费用完整，动作量不随NAV漂。；旧依据退出与真实尾成交同时存在并被追踪。。

不能缩减成：全成全撤两态、丢负样本、撤marker即撤账均不满足。

### FE-04 本金回收、赚股与空头非对称

起点：至少一重临近回本、一独立空重尚有未平义务；使用注明测试用的本金/费用/增长政策。

1. 费后已实现回收使多头进入回本状态，剩余非零筹码。
2. 执行回本后的抛出再回补，展示增长所得和量基关系。
3. 空头回本，仍保留空头债务和风险敞口。
4. 再发生费用/亏损，展示成本状态是否需重评及待定规则。

验收断言：不能靠价格上涨直接把成本清零。；多头赚股完整，不仅画零成本线。；空头不伪造第三相；未定跨阶段规则显式暴露。。

不能缩减成：手工给TStage=3而无本金回收事件链不算覆盖。

### FE-05 多级别联立、主动定位和知识不足

起点：同一结构版本同时被两个操作级别的重使用，包含可下钻≥2级的构造fixture及一例判据不足。

1. 分别作横向分解与向下定位。
2. 沿途存在不同BSP类型或暂缺证据。
3. 引入高延迟/交易制度差异，使结构结论不变但经济可行性变化。
4. 回放到证书尚未知时点。

验收断言：记录每一步收缩、依据、停止原因；不要求每级一类。；操作视角不反写结构。；不足不被弱判据接管，不获交易资格。。

不能缩减成：仅有塔包含关系/一层is_some不算主动定位。

### FE-06 容量、频率、两类换档与资金并发

起点：旧重已有持仓、费用和成本历史；给出分别可判、稀疏、未知的容量和频率输入。

1. 开局从最低可行层承载；低频层不能只因容量大开重。
2. 场景A由更高级行情走好触发换档、部分保留。
3. 场景B由已实现增长超容量触发原层留满、溢出向上。
4. 新重建立同时发生另一重增用请求、共同毛cap收紧或额度不足。

验收断言：两类触发与权利流可区分，旧重不被改名抹史。；未知量不填默认，空仓不挪钱。；并发协议必须解释资源结果；当前未选定协议时明确待设计而不判通过。。

不能缩减成：单重更换level字段或硬编码溢出比例不能代表N重生长。

### FE-07 结构撤回、经营退出与迟到尾账

起点：一重部分成交中，另一重持有反向权利；存在将被重切/撤回的结构依据。

1. 后端获得修订/撤回，影响本重目标。
2. 本重停止新准入并进入退出，另一重继续。
3. 退出后到达迟到成交、手续费或取消失败。
4. 同标的/操作级别出现新经营实例或新Voice。

验收断言：迟到事实归原责任实体，不塞给新实例。；未决数量/权利持续保留直到事实结清。；历史显示当时依据、后来撤回及已成不可逆外效。。

不能缩减成：把撤回当从未发生或把停止经营当责任已清均不满足。

### FE-08 持仓和未决外效的故障恢复

起点：多个重已有经营史；测试输入分别覆盖成本变化、订单部分成交、已退出但尾账未清，可分案例验证，不要求固定三个重。

1. 在预留后未发送、发送后未确认、部分成交后未入本地账、撤单未确认四个边界分别模拟崩溃。
2. 恢复并重接外部快照/游标，送重复和乱序回报。
3. 重新开放准入前对账。

验收断言：既有权利/毛占用/TStage/未决尾账无丢失或重复。；未知结果显式保留，不被timeout当取消。；每个边界都比较完整经济状态与外部效应计数。。

不能缩减成：只复原空仓或最后净头寸不算恢复验收。

### FE-09 一致快照、断线续接与按当时可知回放

起点：两个客户端处于同一经营会话不同游标，后端继续产生结构修订、资金变化、部分成交。

1. 客户端甲断线，乙继续消费。
2. 甲按游标续接；超出保留窗时显式补快照。
3. 回放早期时点，再推进至撤回获知时点。
4. 建立新会话/代际并向其发送旧回报。

验收断言：客户端最终同版本同状态；途中不拼错结构/账目版本。；回放不使用未来确认；旧会话消息不污染新会话。；所有重的历史可追，不局限当前活动marker。。

不能缩减成：最终态重画历史、refresh清空再画不算语义续接。

### FE-10 源头、模型、权限与场所失败

起点：同一结构源，模拟执行与一个受控外部接口fixture；权限设观察/待批，不进行真实交易。

1. 回测检查严格穿越、开盘取优与GTC。
2. 构造同slot相反开仓及市价/限价并存。
3. 模拟断流、拒单、停牌、强制结算、费率未知。
4. 区分配置的隔离条件与已证明的实际隔离。

验收断言：结构源不受执行价差改写。；每项真实/模拟/假设/未测标签可见。；未批交易权限保持关闭，场所未选不冒充部署成功。。

不能缩减成：用旧场所文档或回测模型证明真实爆仓隔离/成交概率不算。

### FE-11 经营与资金验收证据边界

起点：含正负成本事件及费率事件的数据fixture；另备稀疏样本和不重叠窗不足fixture。

1. 保留全部原始经济事件并列取样规则。
2. 逐窗按已裁方法出读数，显示不足或待定边界。
3. 毛净账逐项对账并显示杠杆。
4. 分开报告软件行为覆盖、经济指标检验和真实场所验证。
