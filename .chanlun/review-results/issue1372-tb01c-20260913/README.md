原r1受Q故障截断，r2未进入预声明准备门，r3无Q故障仍超过30s，均保持未验证；最终AC3没有覆盖或改写它们。R5故障窗口里的修订/AsKnown失败同样保留，通过来自另行声明的有效正控。
