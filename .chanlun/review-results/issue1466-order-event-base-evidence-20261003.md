## 订单事件实际增加什么

[Nasdaq TotalView-ITCH 5.0 官方规范](https://nasdaqtrader.com/content/technicalsupport/specifications/dataproducts/NQTVITCHSpecification.pdf) 的 §1.3、§1.4 和 §1.5 区分订单新增、执行、部分撤销、删除、替换及成交报告。只收新增委托不足以维护显示订单簿。非显示订单在进入时没有对应 Add 消息，可在成交时报告；因此公开订单簿不是全部潜在流动性，也不能把单场所数据视作全市场。

**思想实验，非实测**：初始买一99.99、卖一100.01，两个世界拥有相同的已报告成交流。在下一笔成交之前，世界A撤去卖一的大部分数量，世界B维持原样。成交序列相同，买卖盘数量状态不同。如果卖一全部撤掉且下一卖价为100.02，报价还可在没有新增成交时改变。因而成交序列不能唯一恢复订单状态。这个反例不预测下一笔方向，也不证明交易有利润。

`[新缠论:候选]` 可研究订单事件驱动的报价路径、队列补撤/耗尽结构或完整多变量结构。尚未选择其中任何一种。观察函数是分析入口，不构成丢弃原始事件及组成关系的授权。

`[新缠论:推论]` 若候选转到数量或不平衡量坐标，必须重新说明其方向、区间和重叠的含义；数量区间不能未经论证被当作价格中枢。若沿用价格坐标，也须说明 f1 为什么产生符合 f2 前提的对象。仅保证程序确定性不足以完成这项证明。

## 下游需要裁定与验证的事项

以下为工程验收建议，待 HITL 裁定，不冒充原文定理。

1. **合法性**：冻结输入域与顺序、f1、单位、唯一分解和完成规则；证明输出满足 f2 前提，并检查上层闭合及完全分类。保留原始事件与上下层组成关系。
2. **因果性**：区分结构端点的发生时刻和确认时刻；测历史每一前缀在当时可知数据下的输出。记录未完成状态，不能用未来确认回填可交易信号。
3. **稳定性**：在候选明确忽略的、语义等价的编码变化下检查结果。真实的订单拆分可能改变队列优先权，不能无条件视为等价。
4. **增量对照建议**：A为逐笔成交基线；B为A加直接盘口特征；C为B加订单递归结构。先比较B与A，再比较C与B，分别识别订单信息与递归表达的贡献。三者共享可见时间、成本、执行限制及可比的选择预算。
5. **指标选择**：结构识别、短期价格预测、执行改善是不同目标；由用户选主用途。经济实验须考虑费用、点差、队列、部分成交、撤单竞争、逆向选择及延迟，使用按时间隔离的样本外比较。
