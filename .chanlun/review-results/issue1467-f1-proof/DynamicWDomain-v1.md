## 观察函数与输入域

对每个当前真实订单簿状态 B，取其实际最优买卖价 b、a，以及对应档位的实际聚合买卖量 q、k：

```
W(B) = (a*q + b*k)/(q+k)
```

价量按原始十进制文本转为 10^8 定点 BigInt；最终 W 使用约分 BigInt 有理数，以价格单位输出。所有相等、方向和区间比较都用精确交叉乘法，未转为浮点。合法观察要求双边存在、b>0、a>b、q>0、k>0；每个实际重建状态计算并核 `b < W(B) < a`。没有缺失侧补零、前值填充、跳过缺口、重排或重启。

`D_W_dynamic` 的组合条件保留 PlateauBaseCandidate-v2 §2.1、§3 的原关系，仅将观察函数换成上述 W：

1. B0 为首次 ready 的真实双边状态，不是种子。空前缀允许；非空前缀仍要求 `W(B0)=W(B1)`。
2. e1…en 每个真实簿变产生恰一个模型观测，即使 W 相同也保留；只在这些事件后观测上计平台。
3. 已被后继不同值封口的最大常值平台须至少有三个观测；开放末平台可有一个或两个。
4. 仅成熟核心之间产生边；最大同号成熟边块必须由下一反向成熟核心的前三观测确认，最后同号块保持活动尾部。

此处不固定 b/a/k，也不从 Q 保序定理推导 W 平台等价。最优价或量变化是否导致 W 改变，由真实状态精确计算。固定 W 和动态 W 是两个事先具名的观察合同；本脚本从同一首次 ready 重新独立检验新 profile，没有在旧 profile 失败后自动切换判据或接续其对象。

订单协议采用冻结 stage42 探针的有限重建路径：open 加入实际正量，canceled done 删除已核残量，match 扣 maker 的实际残量；received 与 nonresting done 保留为连续性记录但不计种子。冻结适配器也有 size-change 分支，本首段未触及，不能据此声称协议全覆盖。适配器错误、缺失双边/当前报价、非 ready/pending、源序号缺口、capture 行缺口均为显式观察域停止。输入指纹或重建对账不符属于检验失败，直接报错，不写成功摘要。
