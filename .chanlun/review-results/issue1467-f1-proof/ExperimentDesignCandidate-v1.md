# 订单递归增量实验候选合同 v1

日期：2026-10-04。绑定 [订单递归增量价值的用途与实验对照](https://github.com/xy7365527-lang/NewChanlun/issues/1468)，承接研究图及 GoalReframe-v4。AFK 证据备料，尚非主确认实验的冻结合同，也不裁定用户最终用途。

## 三种用途的可检验性

| 用途 | 外部验收对象 | 现有数据能准备什么 | 尚缺什么 |
|---|---|---|---|
| 走势结构识别 | 具名原义关系、独立构造和来源证书 | 用既有合成路径、真实前缀及恢复结果查错 | 完整 F₁/F₂ 与独立语义审查；用候选自己的中枢数当标签会循环自证 |
| 短期报价变化判断 | 与候选结构无关的未来已发布双边报价 | Stage35 已在现有分钟上生成外生决策网格及具名方向标签 | 合格 C、共同特征、未见样本、训练/选择预算与确认方案 |
| 既有信号执行改善 | 同一意图下的成交率、逆向选择、成本及成交后价值 | 可保留原事件、成交、到达顺序和恢复边界 | 意图样本、初始队列优先级、订单插入/撤单竞争、延迟与费用；不能把报价命中当作限价成交 |

因此，本轮选择第二项作为**标签可行性探针**。这不把 BTC-USD、100ms 网格、1秒预测期选成最终市场或最终用途，也不启动候选优劣选拔。

[Gould 与 Bonart](https://arxiv.org/html/1512.03492v1)研究队列不平衡与下一次中间价变化，提供了外部目标和非递归对照的原始文献依据；其第5.1节在相邻价格变化之间随机取样，第5.2节随机划分合并样本。本项目要检验实时共同决策与时间外泛化，因此不照搬该采样/划分。这个差异不等于本轮推翻论文结论。[Cont、Kukanov 与 Stoikov 的论文摘要](https://arxiv.org/abs/1011.6402v3)支持将订单流不平衡纳入直接订单信息对照；不据其结果推断本项目递归有效。

## 已实现的探针目标

profile 为 `published-mid-first-change/2`。已发布视图按供应商采集时间排序；同一采集时间的全部记录组成一桶，采用末状态。一个桶只有在观察到更晚的采集时间后才算封闭，文件最后一桶不提前确认。

共同决策时刻 t 落在 UTC 100ms 网格上。特征截止只允许 `capture<t` 的完整桶，时间恰等于 t 的记录不进入特征。标签基准是截止 t 之前最后一个可用双边报价的中间价，计算时使用整数 `bid+ask`，不作浮点除法。

目标 Y(t) 是 `[t,t+1秒]` 内第一个已封闭时间桶中的中间价变化方向，取 up/down。若直到 t+1秒确无变化，且观察水位严格超过 t+1秒，取 none。若在变化发生前遇到连续性边界，或样本结束尚不足以决定目标，取 censored。决策当时盘口不可用的记录标 ineligible，仍留在结果中。

连续性边界包括不可用视图、快照及补应用批次。即使同一桶先缺口后恢复，跨入该桶的旧目标也不能接着标方向；桶封闭后，恢复的末状态可成为下一决策的起点。已在边界前观察并确定的第一次变化不受后来边界影响。

这是**发布后报价**目标；不覆盖批内原生路径、同时间桶内部瞬时变化或未观测场所。时间恰等于 t 的变化可能使标签与决策同刻，程序保留并单列计数，不据此声称有正的反应时间。供应商采集时刻也没有包含本机处理延迟。

## 四臂与信息边界

| 臂 | 允许的历史输入 | 要回答的比较 |
|---|---|---|
| A | 同场所逐笔成交及其当时可知时间 | 成交信息基线 |
| B | A＋同一截止点可见的原生订单、报价历史；允许多尺度摘要及历史模型 | B−A 的订单信息/表示作用 |
| B_seed | B＋与 C 相同、同版本的完整 F₁ 输出与活动状态 | B_seed−B 的底层构造作用 |
| C | B_seed＋获资格的 F₂ 表示 | **C−B_seed 为递归增量的主要比较** |

所有臂共用外生网格、标签和按当时可知条件确定的资格域。不能在订单到达时才调用 A，也不能把 `prefix_end_line`、盘口刷新次数、标签状态或标签确认时间当成 A 的特征。网格记录里的这些字段是审计元数据。

共同的“可用盘口”资格条件仍使评价总体限定于可恢复报价时段，须公开覆盖率。不能声称这是未经条件化的全市场成交信息实验。某臂预测缺失或 C 暂无已完成对象不能成为事后删除该行的理由；候选合同应事先说明活动状态、未知值和缺失预测怎样处理。

B 不能只有一张当前快照，而 C 可以读取更长历史。所有臂共享历史起点、可用时间与观察范围；不同表示对同一历史的压缩效果可以被比较。预热、缺口后重置和历史不足的含义还须与真实 F₁/F₂ 合同一起冻结。本轮569个可标目标不等于569个已具备共同完整特征的训练样本。

## 主确认前必须实际冻结的项目

1. **候选与数据**：一个获资格的 F₁/F₂ 版本及源码/声明哈希；场所、产品、日期清单、协议版本、初始化和缺口规则。当前已看的一分钟及本轮输出只属探索，不能进入未见确认集。
2. **时间划分**：训练早于验证、验证早于确认。训练标签所需时间必须在训练分区内；跨分区或未知目标保留记录但不进入该分区损失。归一化、特征选择与模型拟合只消费训练数据。禁止将同一未来变化驱动的相邻网格行随机拆入训练和确认。
3. **主要指标**：建议三类概率预测的平均对数损失，定义增量 `Δ=loss(B_seed)−loss(C)`，正值表示 C 更好。Brier 分数、校准、分日表现和资源成本作为辅助，不在确认后从中挑一个宣布成功。
4. **实质效应与误差估计**：在确认标签揭盲前给出 δ_min 及其用途/成本理由。对同一决策的损失作配对比较；按时间块而非逐行独立重采样，块长/单位与数据跨度事先固定。当前一分钟无法估出可信的跨日不确定性，309个变化也不是已测有效样本量。
5. **模型与选择预算**：给 B 足够的非递归历史表达能力；冻结模型族、参数/内存上限、训练与搜索预算、全部已尝试配置及选模准则。计算递归本身的历史处理、状态内存和推理开销；不能只对预测头报成本，也不能把更多搜索所得当作递归效应。
6. **停止与解释**：仅在预注册的主要比较和实质阈值上判断，区分有意义改善、上界已排除所需改善、统计不足。失败后更换构造或用途要另立版本和未见样本，不复用本轮确认数据继续选优。

这些冻结项依赖候选资格和样本预算，当前仍有实质缺项。没有在本轮给 δ_min、市场或费用填默认值。若最终研究只采用报价预测用途，结果仅限预测；若主张执行/交易价值，另外完成费用、成交、排队、处理延迟及容量实验。

## 最小架构含义

当前实际运行的路径为 `已保存的因果视图 → 精确时间桶 → 外生网格截止点 → 离线外部标签`。特征构造、四臂训练及交易执行均未运行。

后续需要两条权限分离的数据路径：特征只读决策截止前的记录，离线标签才可读后续记录，按稳定决策身份对齐。标签文件禁止供实时候选状态机读取；每个数据分区保存源哈希、参数和代码版本。既有前缀/恢复检查可复用，新增检查针对结构与标签的真正接口，不重复重建相同分钟。

这支持事件日志、准确可用时钟、持续性边界和离线评价器的需求；尚不足以选择线程模型、内核旁路、FPGA、托管或替换生产引擎。应在合格候选上测事件率、递归处理/排队延迟、内存与机会存续时间，再作条件性架构判断。
