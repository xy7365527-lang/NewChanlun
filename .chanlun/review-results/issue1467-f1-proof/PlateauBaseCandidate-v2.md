## 2. 输入域 D_Q 与 D_W

### 2.1 原始事件与 Q

输入是完整初态 B0 与同一品种、同一连续源序号 epoch 内的真实事件 `e1,…,en`。每次事件按已声明的订单簿状态规则产生 Bi。订单 ID、买卖方向、价位、数量、顺序和原始载荷保留；初态不是一个事件，也不计入平台的三次观测。

本探针的合法簿规则是新增正量、ID 不冲突，撤量为正且不超过相同 ID/方向/价位的残量；序号连续。它只重建这次新增/撤单见证，不声称实现所有交易所、改单或成交协议。丢序号、未知前态或非法残量不属于本构造的连续有效输入，不能补零或重排。

固定研究价位 b=100，`q_i=Bi 在 100 档的买量总和`，Q 轴为数量。令 `x_i=q_i`。D_Q 是符合下列条件的有限历史，包括空事件前缀：

1. `n=0` 时只给 B0，不要求不存在的 x1；`n>0` 才要求 `x0=x1`。
2. 只在 `x1,…,xn` 上取最大常值平台。已由后继不同值封口的平台必须至少有三个事件后观测。
3. 最后开放的平台可以只有一个或两个观测，也可以已有三个以上。每次计数必须来自不同原始源事件。

数量可为零；D_Q 不将“固定观察的 100 档”与“始终是最优买档”混为一谈。D_Q 是窄域，并非所有合法订单历史。最短域外证据是某个少于三次的平台被下一次转值封口；该事件及之后的记录不能删除后重新拼接。

### 2.2 W 的域条件

一般固定参数版本要求 `a>b`、`K>0`、`q_i>0`，所有观测时刻含初态均满足：实际最优买价为同一个 b，实际最优卖价为同一个 a，a 档实际卖量为同一个 K，b 档实际买量为 q_i。再与 D_Q 的平台条件相交，定义 D_W。

本报告的具体 D_W 固定 `b=100,a=102,K=10`。因此下面确实是同一个观察函数作用于所有时刻：

```
W(B_i) = (102*q_i + 100*10)/(q_i+10)
       = 100 + 2*q_i/(q_i+10).
```

K 是实际卖量，不是在实际盘口变化后仍假装不变的标签。例：保持 q=10，向 102 卖档新增 10，使实际 K 从 10 变成 20，实际加权观察价从 101 变成 302/3，而 Q 没变。这是合法簿事件，却离开 D_W；不能沿用固定函数的等值平台证明。q=0 同样离开本 D_W，因为 100 档此时没有支持其最优买价角色的正量。

对 D_W 中任意 `u<v`，

```
W(v)-W(u) = 20*(v-u)/((v+10)*(u+10)) > 0.
```

所以 Q/W 的相等、方向、平台分组与成熟时点双向对应。W 是价格量纲的盘口观察价，本例无实际成交；D_W 不因此给予成交价或原义走势资格。

## 3. 所有有效有限前缀上的输出关系

### 3.1 平台与核心的时间标记

对长度 n 的前缀，唯一的最大常值平台依次为 `P_i(n)`，起点为 s_i，当前已观察末端为 `u_i(n)`。若 i 不是最后平台，它已封口，定义最终末端 `t_i=u_i(n)`；最后平台只有观察末端 u_i(n)，不得称为最终 t_i。

平台具有至少三次观测时核心 K_i 出生，出生时刻 `birth_i=s_i+2`，种子证据固定为 `e_(s_i),e_(s_i+1),e_(s_i+2)`。核心值是 c_i，底层核心为候选 `[c_i,c_i]`。同值延长只更新平台已观察末端，不另造核心。

D_Q 保证已出生核心恰是平台序列的一个连续前缀 `K0,…,K_(m-1)`。只能有最后一个平台尚未成熟，且其长度为 1 或 2。n=0 时无平台，m=0。

### 3.2 只在成熟核心间造边

若 m≥2，定义 `d_i=sign(c_i-c_(i-1))`，`1≤i≤m-1`。所有 d_i 非零。合法边块划分覆盖整条成熟边序列，块内同号，相邻块异号；记其唯一最大同号块为 `H1,…,Hk`。

若 m=0 或 m=1，不存在边，不造非空块，不推定方向。m=1 时单独保留无方向启动核心 K0。

有边时，**仅 H1,…,H_(k-1) 对应已完成对象；最后的 Hk 只是成熟边尾块 E**。当 k=1 时没有完成对象。这样不会从未成熟的平台值提前生成反向边。

### 3.3 完成对象与证据

对于一个已完成边块 `[a,b]`：

- 它若是首块，拥有 `K0,…,Kb`；否则只拥有 `Ka,…,Kb`。后块以 `K_(a-1)` 的末端坐标作起点，但不拥有这个核心。
- 首块原始事件域为 `(0,t_b]`；后块为 `(t_(a-1),t_b]`。这些 t 都确已封口，因为反向成熟核心存在。
- 方向是块符号；一个自有核心的块按本候选记盘整，两个及以上自有核心记同向趋势。未获原义分类资格。
- 端点读原始前后状态，range 为包含起终状态的观测极值区间；不在跳变间补事件。
- 完成支持是 `K_(b+1)` 最初三个事件、其值，以及 `d_(b+1)=-d_b`。结束位置为 t_b，**确认时间为 `s_(b+1)+2`**。

完成证据不含外置 Bool，不把还会延长的反向平台全体复制进前对象。它引用的事件可以归后对象或未消费后缀，证明引用不等于成员归属。

### 3.4 总输出及原始后缀

整个输出是唯一确定的元组：

```
O_n = (C, R, E, S, P, K)
```

C 是有序完成对象列表；K 是已出生核心目录，记录值、起点、观察末端、是否封口与出生证据。

令 T 是 C 最后一个对象的事件末端；C 为空时 T=0。**R 恰好是未消费的原始后缀 `(T,n]`，包含原始事件引用，并保存起点状态 B_T。R 不要求单调，不赋方向，不声明是一份走势类型。**

E 是可空成熟边尾块，保存边索引、方向、自有成熟核心 ID、锚核心 ID、末成熟平台的观察末端与是否封口。E 只是 R 内的结构引用，不额外拥有事件。

S 是可空无方向启动核心：恰在 m=1 时为 K0，其余情况为空。它也只是 R 内的结构引用。

P 是可空待定末平台：恰在末平台只有 1/2 次观测时存在，保存实际值、起点与观察末端。不为它造 K、不为它造 d。它的全部事件属于 R。

不强迫 E 和 P 覆盖 R 的每一事件；R 本身已经给出完整原始归属。E/S/P 用于说明后缀当前观察到了什么，不是另一份事件分区。

### 3.5 域外诊断不是 F1 的延拓

若第 f 个事件第一次使一个短平台封口，`H_(f-1)` 仍在 D_Q，`H_f` 离开 D_Q。诊断输出标记 `outside_D`，冻结 `H_(f-1)` 的已完成列表和结构元数据，记录失败平台与 f，并保留从最后完成端点到当前 n 的全部原始后缀，其中 `[f,n]` 明确标为未分析。

它不宣称域外已有 F1 对象，不尝试删除短平台恢复接续。首观测不同于初态时也按 f=1 报域外，分析到 0。有效后续稳定性定理只量化到仍在 D 的扩展；上述冻结是探针对域外证据的保留策略。

## 4. 存在、唯一性与覆盖的数学推导

**存在性。** 每个有限观测列都有最大常值平台分解。D 保证核心目录是一个连续前缀。成熟边序列为空时按 S/P 规则给空边输出；非空时按全部变号位置切开，得到块内同号、相邻异号的划分。除末块外，每块均有一个反号的下一条成熟边，因此有三次观测完成见证，且其事件末端已封口。按第 3 节定义 C/R/E/S/P/K，所有组成均有值。

**唯一性。** 等值关系强制平台边界；三次门槛强制每个核心的出生与待定状态；相邻边同号处不能切，异号处必须切，故边块唯一。完成对象恰为除最后块以外的全部块，没有可选子集。核心归属、事件区间、方向、分类、观测极值与完成种子随之唯一。最后完成端点 T 固定后 R 固定；最后边块 E、唯一可能的 S/P、核心目录 K 也固定。这里证明了整个元组的存在唯一，不只证明切点，不借程序确定性作证明。

**事件覆盖。** C 的第一事件区间从 1 开始；相邻完成对象的界为同一个已封口 t，一个止于 t，另一个从 t+1 开始。故 C 恰覆盖 `[1,T]` 各一次，R 恰覆盖 `[T+1,n]` 各一次，二者不交且合起来为所有原始事件。共享 B_T 或在完成证明中引用后继种子不改变事件拥有者。启动状态同样成立：T=0，全部事件归 R；n=0 时两边都为空。

**成熟核心归属。** 每个成熟核心恰归 C 的某个对象、E 的自有核心列表或 S 之一。E 的锚核心可引用上一完成对象的末核心，但不列入 E 的自有列表。P 没有成熟核心，不参与这项计数。

**D 内扩展稳定性。** 任何已完成对象都已有反向核心的三事件种子；种子的首事件已经封定前块末端。D 内追加不能改变已封口平台、已有核心值、种子和过去变号位置。由唯一分解关系，旧完成对象仍是新 C 的同一前缀，所有字段不变。E/S/P 可随追加成熟、封口或迁移，此变化不等于旧完成对象重绘。无限同向延伸仍可能只有活动尾部，定理不保证每份尾部终将完成。
