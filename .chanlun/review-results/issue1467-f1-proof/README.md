## 1. 已有机器证明究竟证明什么

以下逐项按源码的命题与证明体核对，不仅按注释或定理名字判断。

| 入口 | 已核类型/证明形态 | 本研究可继承的边界 |
|---|---|---|
| `formal/Origin/ChanlunElements.lean:131–161` | `ElementPipeline`各阶段是函数参数；`parse_total_unique`针对`P.parse bars = out`，证明为`total_unique_of_fun P.parse` | 给定函数管线输出确定；不证明独立合法分解关系只有一个解 |
| `formal/Strict/Parse.lean:186–225` | θ中`baseParse/recogStep`为函数，`parse_unique`的目标仍是`parse θ h ℓ = D` | 条件化的函数确定性；不能据此免除具体F₁的语义义务 |
| `formal/Strict/Recursive.lean:126–176` | `moveDecomp`的历史对象已是`Move`，`d=id`，树与该Move互逆 | 已生成对象的结构树可重构且唯一；不是原始bars/订单如何生成该Move的定理 |
| `formal/Origin/SegmentAutoConstruct.lean:325–358` | 具体`segmentsOfComplete`从`List Stroke`构造段，终止及函数图唯一性 | 给定笔流的构造事实；不自动覆盖原始订单→观察→包含→分型→笔的复合关系 |
| `rust/src/theta_v0/parser/mod.rs:316–326` | 本体明确Rust解析吃raw bars，Lean `Origin.Pipeline`吃strokes/candidates，输入域不同 | 不能直接把两者当同一个函数对拍，或借后者消掉前者全部证明义务 |

这是对已查入口的有限审计，不是“全仓绝无更强证明”的穷举结论。历史640号谱系提示过函数性与结构性唯一性的区别；本轮重新核了实际命题，没有把历史记录直接当证明。

一个独立Lean反例展示：定义合法关系`R(x,u) := u=0 ∨ u=1`，确定选择0且该选择合法，仍无法推出R唯一。另有条件引理表明，若独立语义关系R已经有唯一结果，则与观察映射φ复合可继承这个性质。该条件引理没有替我们证明其前提。

## 2. 候选R_W：数量加权观察路径后的规范解析

这是一份操作性构造卡。它精确定义当前研究对象；不把被调用程序的确定性冒充语义资格。

| 项 | 定义 |
|---|---|
| 输入域 | 一个标的、一个具名显示订单簿视图；从已知初态开始，有序、无缺口的最佳买卖价及数量更新。每个取值点满足整数`b<a`及正整数`q_b,q_a`。未知初态、空侧、跨价或缺口退出本有效段并记录缺项，不猜补 |
| 原始对象与来源 | 保留原始有类型事件和状态轨迹；此候选只观察L1价量。映射表保存原事件序号、观察序号和当时可知时间；不声称L1恢复了全部订单身份或深度 |
| 观察时钟 | 本版本采用L1状态变化时钟；每个有效的L1状态更新产生一次观察。源消息重发须按协议识别；深层事件与同值观察是否发样本必须由版本决定，不能事后变动。合成见证中每次只改变一侧数量，均为L1更新 |
| 数值与单位 | b、a先位于已声明的观察价格单位；`n=a*q_b+b*q_a, d=q_b+q_a`，取`w=round(n/d)`。正数半值向上，参考计算用精确整数中间值。生产实现需另验溢出和实际浮点入口；该w不是可执行成交价 |
| 初始构造 | 每次观察构造`O=H=L=C=w`的结构专用Bar；volume=0，untradable=true，表示该记录不提供交易资格。按固定源码版本和θ，用`ParseLayerIncr::append`推进包含、分型、笔、线段和尾部；θ.parse.new_stroke_min_gap=3。原始成交信息另存，不能被这种Bar替代 |
| 完成与暂定 | 候选使用解析器提供的稳定前缀长度区分代码所声明的稳定段与可修订部分，并保留tail及来源。需要进一步证明该证书符合独立的语义完成条件；“代码声明稳定”不自动等于已获语义资格 |
| 上层契约 | 段带方向、原始索引及整数端点，映射到现有`UnitRange`；复用`center_from_segments`的方向交替和严格交集判据。本轮只实际驱动该三段中枢构造，不宣称已运行整座递归塔 |
| 已知代价和失败边界 | 数量比例投影不保留绝对深度或所有价差信息；保留原始载荷不等于这些维度已进入递归。观察时钟、量化规则和θ影响结果。语义唯一性/完整闭合未证；不能把w按成交价格用于收益计算 |

对于给定的观察单位、时钟、θ和完整有效事件前缀，上述操作产生确定结果。这只是操作性确定性。待证明的是：在不以“等于本程序输出”为定义的合法分解关系下，该结果是否健全、完备且唯一。

### 非空见证与有限前缀检查

`projection_probe.rs`生成固定`bid=10000, ask=10200`的合成整数坐标。初始数量为`(25,175)`；按源码列出的16个目标数量、每段6步、4轮循环生成757个状态。每步仅改变一侧正数量，可解释为显示队列的增加或减少；没有订单ID或排队模型，不当作真实场所MBO回放。所有价格单位在此只作合成坐标，不作费用标定。

| 输入 | bar数 | 分型 | 笔 | 段 | 最后一步代码标记的稳定段 | 稳定段中的合格三段窗口 |
|---|---:|---:|---:|---:|---:|---:|
| 数量加权路径 | 757 | 62 | 61 | 7 | 6 | 4 |
| 相同事件时钟、中间价恒定 | 757 | 0 | 0 | 0 | 0 | 0 |

第一个段为`Down, source 12→72, 10185→10015`。第一个合格窗口的核心为`[10015,10185]`，外缘`[10015,10195]`，来源索引12→264。窗口计数不是完整中枢生命周期或全塔对象数。

每个前缀都比较真实批量解析与真实增量解析的结构字段，并检查上一步已标记的稳定段前缀没有改写。加上下面两种时钟样例，共1594个前缀检查通过。两条实现共享部分生产核，因此这只是有限一致性证据，不能作为独立语义oracle。未测试实际持久化恢复、原始MBO重建或经济结果。

### 观察时钟反例

对同一组16个点价格，每点出现一次时：14个分型，0笔，0段；每点重复四次并重新连续编号时：仍有14个分型，却有13笔、1个暂定段，稳定段数为0。包含合并后的点数都为16。

原因入口在`rust/src/theta_v0/parser/stroke.rs:60–67`：成笔间隔使用原始`source_index`。该反例否定的是“可以无声改变观察时钟，而结构不受影响”这一主张。它不是同一有效事件流上的批量/增量分歧，也不是网络重传可以重复计数的授权。R_W必须把时钟写进定义。

## 3. 候选R_D：直接供需同向块与强一维桥接

| 项 | 定义 |
|---|---|
| 输入域 | 固定最佳报价下，正整数队列状态及有序单侧非零数量更新；新增或撤减的原因类型、数量和来源全部保留。暂不包含价格变化、空侧和跨场所状态 |
| 原始对象 | 买量增加/卖量减少标为供需方向`+`，买量减少/卖量增加标为`−`。方向指这个研究中的数量作用，不预称缠论价格方向 |
| 时钟 | 每个上述有效单侧更新一个事件；零变化不属于此研究域，源重发按协议去重 |
| 基本单元 | 方向序列的极大同号连续块；每块保留全部原事件、起止状态和买卖数量的二维外包范围 |
| 完成规则 | 第一条反向事件到达时，前块结束被确认；最后一个块为活动尾部。端点发生时间与反向确认时间分别记录 |
| 独立唯一性论证 | 相邻符号不同处必须切，否则块内不同号；相邻符号相同处不能切，否则两块可合并而不极大。因此边界恰为全部符号变化位置，覆盖整个有限前缀的分块唯一。最后块的完成状态另记。这是关于同向块的数学证明，不是缠论线段资格证明 |
| 强桥接要求 | 若想无损保留自然供需比较，并直接进入现有整数价格全序，要求存在`f:Qty→Int`使所有正数量状态满足`f(x)≤f(y) ⇒ x.bid≤y.bid ∧ y.ask≤x.ask`。完整保序且反映次序的嵌入必满足此要求 |
| 结果 | 强桥接不可能；见下一段机器证明。故这条“同向块＋无损自然次序桥”的完整候选无法按原目标接入F₂。可以研究有损投影或别的关系，但必须注明新构造，不能称该强桥已成立 |

取`x=(1,1), y=(2,2)`。按上述自然供需关系，x不小于等于y，y也不小于等于x。两状态均正且可由单侧增加依次达到。然而任意整数f(x)、f(y)必有一个不大于另一个；若要求比较反映自然供需关系，即得矛盾。`OrderBaseBoundary.lean`已在正数量条件下证明这个结果。

结论范围仅是这个特定关系及无损全序桥。强桥是本轮为检查“无损复用”而明确提出的附加条件，**不是第84课或现有教义要求的必要条件**；不能据此关停直接多变量路线。它不否定“买卖数量有用”，不否定订单同向块存在，也不否定允许信息损失的加权报价/OFI等投影。更不构成所有订单F₁不可能的证明。

## 4. 新机器证明与复现

`OrderBaseBoundary.lean`只导入Std，不修改`formal/`，不依赖项目假定的市场有效性。所查五条定理：

- `semantic_unique_composes`：有独立语义唯一性前提，复合观察可继承它。
- `selector_does_not_supply_semantic_uniqueness`：确定且合法的选择不能替代语义唯一性。
- `no_exact_scalar_order_reflection`：正数量自然供需偏序不可能被整数全序完全反映。
- `weighted_numerator_bounds`：有序报价下加权分子位于两端价格乘分母之间；正分母时得到加权值的区间约束。
- `pulse_observation_changes`：一个固定报价数量脉冲确实改变精确观察值。这不是结构存在证明，后者由Rust有限见证另给。

Lean检查通过，无`sorryAx`或新增假定公理。部分证明使用Lean基础逻辑`propext`、`Quot.sound`，没有声称所有定理均零基础公理依赖。日志见`lean-stdout.txt`。
