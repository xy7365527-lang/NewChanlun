## 来源证书证明什么

[SourceHullSpec.lean](SourceHullSpec.lean)中的Part保留角色标签、起点、长度。Cover为独立归纳关系：空余段只能在当前位置等于终点时结束；非空片段必须长度为正，后继分配从本片段结束位置继续。它没有使用“等于某程序输出”作为定义。

对任何`Cover start finish parts`，证明：

```text
start ≤ finish
positions(parts) = [start, start+1, …, finish-1]
positions(parts) 没有重复
```

当实际调用绑定`start=0`、`finish=源列表长度`及该列表版本时，每个源位置恰好出现一次。位置表示原单元，不是价格端点；相邻原单元共享一个端点并不违反此条件。

候选、保留和活动角色都占有明确位置，不能把未上送部分从账本里删掉。已有六单元反例的消费序列`[0,1,2,1,2,3]`不同于完整源位置序列`[0,1,2,3,4,5]`，故不能满足新关系。

正面见证包括三块各三位置、第三块保留，以及在后面另记两位置活动尾部的完整覆盖。根同时读取旧Retile的`[true,true,false]`局部判定，但本轮没有证明从任意Retile输出自动生成这些角色标签。十一位置账本是位置关系的数学例子，不声称另取得了十一条已完成市场单元。

**角色标签不是资格证书。**Cover只核给定分配，不能证明某片段应当完成、属于哪一级、是不是合法连接或真的NoCore；它也没有证明所有合法分配只有一种。观察来源、版本与时间仍须由调用者及后续时序关系绑定。共享的确认/证明依赖可以另作只读引用，不能因此重复消费独占的原单元。

## 外缘证书与计算的对应

给定成员区间列表xs，`ExactHull xs h`要求：

- 每个成员的下界不低于h.lo，上界不高于h.hi；
- 存在一个成员，其下界恰为h.lo；
- 存在一个成员，其上界恰为h.hi。

“包含”之外加两项可取得的极值，排除了随意扩大区间。计算`hull`在非空时从真实成员开始递归合并，分别取min/max；空列表返回none。已证明：

| 命题 | 证据范围 |
|---|---|
| `hull xs = none ↔ xs = []` | 任意有限整数区间列表 |
| `hull xs = some h ↔ ExactHull xs h` | 计算的健全性与完备性 |
| 两个满足ExactHull的结果相等 | 独立关系的唯一性，不只函数确定性 |
| 全部成员严格且有结果时，结果严格 | 任意整数范围，不要求价格为正 |

因此结果的每条边界都来自输入成员。正价下界不能凭空变成0；负价上界也不能凭空扩到0。根包含`[-9,-6]`与`[-8,-3]`合成`[-9,-3]`的检查，空列表为none。

**这保证的是给定输入区间的极值忠实。**如果调用者已经传入错误的子区间，hull不会自行发现来源造假。逐层使用时仍需每个子对象自己的真实区间证书，不能把Stage19旧0哨兵读出当作已合格输入。任意分组后的逐级极值组合、层级资格与完成语义也不因本轮结果自动全部获证。
