## 退出关系及成员分配

[CenterExitSpec.lean](CenterExitSpec.lean)保留旧`CenterFrame.pair`，另要求原成员数小于9，避免绕开已有重切优先门。ExitRecord逐字段规定：

```text
frozen = 原Frame
departure = 本次离开单元
remaining = 本次回抽单元 :: 其余已给定后继
availableAt = max(Frame.knownAt, leave.knownAt, ret.knownAt)
nextOffset = 原成员数 + 1
```

nextOffset是当前局部成员序列中的相对单元位置，不是观察序号、交易所序号或时间戳。原Frame的最后相对位置是成员数−1，因此该偏移对应Z-5的last+2；调用者使用全局位置时仍须绑定原起点。

已证明新分配恢复`原成员 ++ leave :: ret :: rest`，不把离开段吞入原中枢，也不丢弃它。Returned不能同时满足该退出关系，失败后没有用另一档判据兜底。这里的唯一性针对明示字段契约，不是全F₂语义分解唯一性。

ExitRecord没有Move.completed、最终趋势类型或上送资格字段。输入是否合法、是否同级、首对是否确已确认，以及rest是否来自当时可见前缀，仍须由调用者提供；一般字段定理不制造这些前提。下面见证实际绑定旧Whole与visible。

## 不能从当前视图偷取未来答案

根证明不存在一个仅以观察6的已确认视图为输入的确定性函数，同时输出T的上涨延续和E的扩张关系。原因是两份输入逐项相同，而要求的两个输出构造子不同。

这为生命周期给出具体边界：当前可记录成功退出及其成员去向，下一局部中心关系仍应等待相应证据。实验可以把后续关系作为预测标签，但不能把后来确认的关系回填进当前输入。这个定理不排除概率预测，也不取代四臂增量实验。
