# Stage23：直接订单块的变价读出与整侧耗尽边界

日期：2026-10-03，#1467，候选扩展`R_D-Q-moving-v1`。接续[开工卡](Stage23WorkCard.md)。本轮扩展Stage15固定报价候选，旧构造、退化结果和触价反例保留。

## 结果与对象

在具名的可见价量簿记模型中，已证明单侧新增/删除对最优报价的方向约束，并把它用于变价的报价边选择读出。原价量事件按极大同向块唯一分解，完整载荷保留。相邻反号块的端点在同一个边界盘口状态上接续；固定报价时读出与Stage15相同。

单档耗尽后可由下一档提供报价。整侧耗尽时，原事件与符号块保留，缺少有效报价的区间不生成Segment。模型见证中，一个已按反号事件确认的符号块仍没有几何资格，恢复报价不会填补其历史空端点。

本轮没有建立完整F₂语义，也没有真实行情适配或收益结果。报价边选择路径仍是声明的新观察对象，不是原事件触价或成交路径。

## 有效域与模型边界

[MovingQuoteSpec.lean](MovingQuoteSpec.lean)中的Event保留side/action/amount/price。Book用逐数量单位的价格列表作数学表示；每笔amount>0，新增插入指定数量的同价单位，取消/执行删除由匹配价格连续块见证的数量单位。这个列表用于证明，不是建议生产逐份存储数量。

BestBid/BestAsk以成员关系和全体上下界定义真实极值，QuoteOf还要求bid<ask。相同Book的有效Quote唯一已证。几何合法输入要求事件转换符合Step，提供的报价与相应Book满足QuoteOf；一个可读同向块由Flow关系逐事件保留这些前提。

本模型没有订单身份、FIFO、隐藏流动性、跨场所信息或全部撮合优先规则；任意原生变更/复合消息不能仅凭名称套进Step。真实适配还须证明其消息投影与价量状态符合本域。当前也未证明任意初始簿/消息列都会唯一重建整条报价轨迹，不能把“同一Book报价唯一”扩大为整个场所重建已证。

## 从价量变化得到方向与连接

压力记号沿用Stage15：加买、撤卖、卖侧执行为正；撤买、买侧执行、加卖为负。它不直接声明成交价格涨跌。

在一次合法Step前后都有有效双边报价时，已一般性证明：

| 记号 | 最优买价 | 最优卖价 |
|---|---|---|
| 正 | 不降低 | 不降低 |
| 负 | 不升高 | 不升高 |

新增侧原价格单位仍在新列表中，删除侧剩余单位属于原列表，结合实际极值定义得到这些不等式；不是预先把报价单调性当作输入假设。Flow归纳再把单步结论传到整个同向块。

对事件块[s,e)，报价状态q_s在第一成员前，q_e在最后成员后、第一反号事件前：正块读`bid(q_s) → ask(q_e)`，负块读`ask(q_s) → bid(q_e)`。非空Flow给出严格相应方向及有序端点。相邻反号块共享q_e，故前块终价等于后块起价，报价可以变化。

第一事件到达后才知道应选哪条报价边，firstKnown=s+1；第一反号事件在e+1确认前块。q_s的历史来源不等于其被选择为起点的发布时间。这里的序号是模型事件时钟，不是交易所时间、供应商捕获时间或本机发布时间。

## 完整载荷、构造接口及拒绝语义

独立Runs关系给出任意有限价量事件列的分块存在唯一、全事件解码相等、块内同号及相邻异号。分块证明文本复用Stage15并在新的含price事件类型上重新编译，复用指纹见[记录](stage23-proof-reuse.json)。事件价格没有被抹掉后冒称无损。

[MovingQuoteWireSpec.lean](MovingQuoteWireSpec.lean)定义construct：要求n事件对应n+1报价状态，将每块的原载荷、start/finish、firstKnown、knownAt与geometry放入输出。几何读出检查整段报价序列均有效、跨度非空且端价方向正确。原始输出载荷解码恰等于输入，已一般性证明。

外层none表示事件/状态长度不匹配，输入被拒绝；有效输出中geometry=none表示该块没有可读几何，原事件仍在。不能过滤这些块后把前后有效Segment当作原本相邻。

construct是证书域内的组装器，不是完整市场数据验证器：长度匹配及局部价格检查不能替代Step/QuoteOf的来源证据。它也没有证明局部几何就取得缠论完整走势身份。

## 六事件见证

初始买量只有100价位的一单位，卖侧102/104各一单位。所有事件量为1，价量簿始终符合模型的非交叉条件：

| 事件 | 事件后报价 |
|---|---|
| 撤去102卖量 | 100/104，单档耗尽切到104 |
| 加入103卖量 | 100/103 |
| 加入101买量 | 101/103 |
| 撤去101买量 | 100/103 |
| 执行掉100买量 | 买侧为空，无双边报价 |
| 重新加入100买量 | 100/103 |

五个符号块的长度为`[1,1,1,2,1]`，firstKnown为`[1,2,3,4,6]`，确认时刻为`[2,3,4,6,None]`，有几何的标记为`[true,true,true,false,false]`。全部六事件原样恢复。

第四块在事件6时被反号确认，但它结束于买侧为空的状态，不能生成价格端点；第五块开始于同一空状态，即使后来报价恢复，起点也不能回填。EOF不确认最后块。

前三个已确认几何单元满足实际Origin局部谓词，核心为[100,103]。第一正块结束于104，下一负块从同一历史状态的104开始；若误用该负事件后的当前卖价103作起点，会产生104≠103的断开。该错误读出也在根中检查。
