# Stage27：递归分块不能只上送一个力度数值

日期：2026-10-04，#1467，`FORCE-PARTITION-TRANSPORT-v1`。本轮补动力学传递的必要条件；独立语义审查为 `not_reviewed`。

## 结果

对现有 `Origin.ForceVelocity.impulse` 已证明：任意列表分块可用原首末笔值组成的摘要合成；合成满足结合律，任意分组读出的力度与完整原列表相同。单独保存每块的力度 `L` 则不够：不存在只读 `L(A),L(B)` 就能对所有受测定义域给出正确 `L(A++B)` 的函数。

这解决了一个上层递归必须面对的传递问题。它没有决定哪一段真正完成，也没有把 DC 单元或报价块认定为原公式所需的缠论笔。

## 依据及接缝区别

正本 [beichi.md](../../../.chanlun/definitions/beichi.md) 第338–357行固定力度为首末速度的差，并要求各层共享时间坐标；名分为既有 `[新缠论:推论]`。实际实现 [ForceVelocity.lean](../../../formal/Origin/ForceVelocity.lean) 第29行用价格增量除以序号增量，第60行对非空笔列取末笔速度减首笔速度。

已有 `impulse_append_tail` 第70行证明的是两段**共享同一笔**时的可加性，拼接时去掉第二段的重复首笔。本研究的来源分块还会遇到另一种情况：输入切片没有重复成员，仅前一块末笔与后一块首笔的几何端点接续。两笔不相同，速度也未必相同，不能直接继承旧定理的可加结论。

本轮不修改正式力度定义、不指控旧定理错误。新的 [声明](ForceTransportSpec.lean) 与 [证明](ForceTransportProof.lean)直接引用该定义，区分其实际前提。

## 非重叠切片的正确公式

对于非空列表 A、B，记它们的首末速度为 `a_first,a_last,b_first,b_last`。直接由实际定义得到：

```text
L(A ++ B) = L(A) + (b_first - a_last) + L(B)
```

中间项是跨块接缝的速度变化。省略它一般不成立；前后几何端点相同也不能推出该项为零。对于包含相同末/首笔的旧定理，速度相同使此项消去，与本轮结论相容。

摘要 `Ends` 保留两份原始 Stroke 值，`summarize []=none`。合成两个非空摘要时取左边的 first 和右边的 last；空摘要是单位元。已证明：

| 目标 | 机器检查的量词与结论 |
|---|---|
| 原定义读回 | 对任意列表，摘要读出的值等于实际 impulse |
| 拼接 | `summarize(xs++ys)=join(summarize xs,summarize ys)` |
| 结合律 | 任意三个摘要的左右分组相同 |
| 分块 | 任意列表的列表 parts，合成摘要等于 parts.flatten 的摘要 |
| 分组无关 | 两种分块只要 flatten 后是同一列表，读出力度相同 |
| 接缝 | 任意两个非空列表满足上述带速度差的公式 |

这允许将首末笔值随递归对象上送，而不在每一级重新把对象的外缘包络压成一根平均速度笔。这里的 Stroke 没有独立来源 ID；摘要保存的是值，不自行认证身份。真实来源、完整覆盖、是否重复、成员资格与确认依赖仍需另绑。定理不保证调用者给出的 parts 就是原历史的合法分解。

## 为什么只有力度标量不够

两个左块分别只有一笔，右块使用同一笔：

| 输入 | 起止位置 | 价格 | 速度 | 单块力度 |
|---|---|---|---:|---:|
| 左块 A₁ | 0→2 | 100→104 | 2 | 0 |
| 左块 A₂ | 0→2 | 96→104 | 4 | 0 |
| 右块 B | 2→4 | 104→102 | −1 | 0 |

两条拼接链都具有正价、正时长、连续时间/价格端点和方向交替。`L(A₁++B)=−3`，`L(A₂++B)=−5`，而合成函数在两种情况下只能看到相同输入 `(0,0)`，不可能同时输出两个正确值。因此失败不限于“直接求和”这一种写法，而覆盖仅以这两个 L 值为输入的任意确定性合成函数。

另有一般定理：任意单笔列表的力度都是零。由此不能推导原始走势没有动力学变化，也不能据它把所有单元的背驰都设为 false；缺失的变化正可能在相邻笔的速度差里。空块也不会破坏首末摘要的合成，具名见证 `[[A₁],[],[B]]` 读出仍为 −3。

反例的 `ValidChain` 只检查上述数据载体条件，不证明这些 Stroke 是由 K 线包含/分型算法生成的合法缠论笔，也没有把两个块当成合格背驰比较对。它否定的是在该明示载体域上仅传 L 的普遍合成主张，不声称排除了所有额外限制下的完成走势算法。

## 对候选构造的影响

先前 `CandidateMove.divergenceConfirmed` 的外部前提不能由几何分类或随手赋值补齐。本轮给出的正面结果是：一旦候选有了合法原子列、共同时间坐标和结构选定的首末笔，就能以相同摘要规则逐层保留原力度，分组本身不会改变比较值。

仍需明确：R_W 的 DC 单元、R_D 的报价块各由什么原子计算速度；那些原子为什么符合原义力度载体；发展中的末笔何时可知；哪两段满足同级、跨界、Extreme 及其他结构前提；何时真正取得完成/连接证书。此次没有替换原子或时钟，没有把比较数值相等当作完整背驰确认。

下一项可核查问题因此收敛为**具体候选的原子与端点选择**，而不是继续给 completed 增加无来源布尔值。完整 F₂、独立审查及四臂增量实验仍开放。
