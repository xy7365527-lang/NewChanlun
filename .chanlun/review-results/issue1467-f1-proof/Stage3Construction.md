# 订单基底第三轮：端点、确认时刻与方向变换候选

关联：[订单基底候选构造与合法性证据](https://github.com/xy7365527-lang/NewChanlun/issues/1467)。日期：2026-10-03。名分为该票的研究工作草稿。生产源码基线为 `6f99b36c64e0560febdb08e5d1f8e781d2af9299`；未改生产代码、教义正本或 `formal/`。

本轮增加 R_W-DC-v0 候选，并保留 R_W-v0、R_W-v1 的既有结论。新候选在独立首次命中语义下有唯一构造的数学论证，有限枚举和新进程输入重放通过；完整缠论 F₁ 资格、上层完全分类和市场价值仍未证明。

## 一、既有段入口的字段与时间不能混用

`segment_evidence_probe.rs` 只向既有段构造器输入 R_W-v1 的稳定笔前缀。757 条合成数量观察对应758个含空前缀的检查，最终产生7个段签名，本样例未观察到签名撤回或改写。

首段字段为跨度 `12→72`、价格 `10185→10015`，但观察12的真实投影价格为10155，10185实际出现在观察36。因此 `(start_index,start_price)` 不能自动视作同一真实点。源码 `rust/src/theta_v0/parser/segment.rs:331–368` 的跨度取首末笔边界，价格取范围方向极值，两套含义不同。本例仍有有序极值见证 `(36,72)`，不能进一步宣称“此段没有真实端点见证”。后6段恰好两套坐标配对。

第一组三段的跨度末端为264，子段首次可见时刻为 `[121,205,313]`。依赖信息的可用下界为313，晚于跨度末端49个观察步。这是构造等待信息的距离，不是CPU耗时。`ClockAndGeometry.lean` 证明“组成信息均已出现”等价于其时刻最大值不晚于当前；它没有证明最大值就是充分确认时刻，也没有证明本例首次可见等于永不撤回。

因此后续对象需分开携带跨度、价格极值见证与 `known_at`。这是一项实验数据契约需求，尚非生产架构改造裁定。

## 二、直接供需块的限定反例

R_D-v2 的构造卡如下。它用于检验一个明确适配假设，不覆盖全部直接多变量路线。

| 项目 | 本轮定义 |
|---|---|
| 输入域 | 固定 bid=100、ask=102；两侧正数量；只允许买卖侧新增和撤走，不能撤至非正 |
| 原始对象 | 有序事件 `(序号,操作,数量,触价)`，保留完整事件列和块成员 |
| 时钟与精度 | 单事件序号，全序；整数价与数量；没有撮合或场所时间推断 |
| 基本单元与连接 | 撤卖/加买为正，撤买/加卖为负；极大同号连续块；成员区间无重叠、无遗漏，活动尾块保留 |
| 方向与区间 | 方向是供需符号；区间是成员触价的最小/最大价格，二者量纲语义分开 |
| 完成与确认 | 第一条反号事件出现时确认前块；其序号为 `known_at`，新事件归新块 |
| 拟议上层桥 | 把供需正负复制成价格 Up/Down，并把触价范围送入既有中枢核 |
| 失败边界 | 无符号或复合事件、空侧、跨价位、断档尚未定义；拟议上层桥已被以下有效域内反例否定 |

从两侧数量100开始，循环“撤卖10、加买10、撤买10、加卖10”三次。共5个完成块，所有队列量保持正且最终回到100。正向块触价顺序为 `[102,100]`，反向块为 `[100,102]`。5块都没有与复制价格方向一致的有序端点见证，但三段中枢核接受其前三块。

这否定的是“供需方向可以直接当价格方向”的适配。极大同号分段本身唯一，直接多变量研究也没有被否定。`ClockAndGeometry.lean` 另证明两触价序列不能倒排出相反方向的端点见证。代码输出见 `direct-flow-bridge-stdout.txt`。

## 三、R_W-DC-v0 构造卡

第84课正文52/54/56行允许改变起始构造，并要求分解唯一。它不自动批准下面的具体定义。下述均为 `[新缠论:候选]`；DC单元不称为已裁的缠论笔或线段。

方向变换思想参考 [Glattfelder 等的原论文](https://arxiv.org/html/0809.1040v2)。原文使用百分比变化；此处采用固定绝对整数阈值，是自定变体，不是论文算法复现，也不援引其经验缩放规律证明缠论递归。

| 项目 | 本轮定义 |
|---|---|
| 输入域 | 因果重建的双边L1观察，`0<b<a`，两侧量为正；排序、初始化与连续段已确定；δ为正整数 |
| 原始对象 | L1行与来源序号完整保存；真实事件接入时还必须保存原消息及重建来源，不可把L1行冒称完整订单事件 |
| 时钟与精度 | 每次合格状态更新一条观察；价格以固定整数单位表达；`w=(a*q_b+b*q_a)/(q_b+q_a)`，半值向上量化到整数；同价观察保留 |
| 基本单元与连接 | 首次区间振幅达δ后定方向；运行极值受到反向δ变化时完成单元；相邻完成单元共享真实极值点 |
| 方向与区间 | Up/Down由端价不等式给出；闭区间由两端价确定，量纲为投影价格；它不表示可成交报价 |
| 完成与确认 | 端点发生在极值观察；`known_at`为首次反向命中δ的观察，两者不可混用 |
| 上层契约 | δ只用于底层构造，上层使用原 `compose_level/decompose/project_to_units`；不通过逐层放大δ造级别 |
| 失败边界 | 未初始化、无反转时保留活动状态；空侧/交叉簿/断档不拼接；整数运算溢出需拒绝；δ改变、观察合并或时钟改变构成新profile |

`dc_replay_probe.rs` 对正数投影使用 checked i128 乘加，超界拒绝。数学投影域比机器数值域宽，不能把数学有定义误写成全部i64输入都可执行。合成序列远离边界。δ=20只用于本轮见证，未以收益选择，也未冻结为真实市场实验参数。

## 四、独立语义与唯一性论证

给定有限整数观察列 `p₀,…,pₙ` 和 δ>0。令 `max[a,b]`、`min[a,b]` 分别取区间最大/最小值的最早索引。这是极值与次序的关系定义，不引用Rust状态机。

1. 令τ₀为首个前缀振幅至少δ的时刻。不存在则输出无完成单元和未初始化尾部。存在时，新点必为严格新高或严格新低；否则前一前缀已达到δ，与最早性矛盾。首方向由此确定，起点为前缀另一端最早极值。
2. 对上行起点s，令 `e(t)=max[s,t−1]`。首个满足 `p_e(t)−p_t≥δ` 的t是确认时刻，完成单元为 `(Up,s,e(t),t)`。若无此t，保存从s开始的活动上行。下行用最早最小值及 `p_t−p_e(t)≥δ` 镜像定义。
3. 完成后从e(t)取反方向重复。前导片段、完成单元和活动尾部均保留；端点共享不表示丢弃或重复统计原消息。用于确认的事件可以位于下一单元的几何跨度里，故几何成员与确认依赖分别记录。

**存在与唯一。** 有限非空整数区间的极值存在，最早索引唯一；有限候选时刻集非空时存在唯一最小元。初始τ₀唯一，首方向互斥。给定一个起点与方向，完成条件的最早命中及其最早极值唯一；不存在命中时，活动状态也由区间极值唯一确定。递推时后一次确认严格晚于前一次：以上行完成为例，峰e至旧确认t之前全部回落小于δ且不高于峰，不可能提前形成反向单元的δ回升；在t上它是该区间新的低值，亦不能同时完成回升。下行镜像。确认时刻严格递增且不超过n，构造有限终止。对完成单元数归纳，任意两份满足上述关系的分解逐项相同，前导和尾部也相同。

**因果与稳定前缀。** 某单元在t确认，只使用不晚于t的观察；扩展后缀不能改变已发生的首次命中或其之前极值。因此完成单元只追加。极值发生时还不能确认它，禁止在历史端点处提前放置信号。

**几何。** 初次方向建立时幅度已达δ。以后每次反向确认同时使下一活动单元具有至少δ的幅度。完成端点因而严格晚于起点，端价方向明确。首次反转前若观察越过起点的反向边界，会先触发反转；所以单元几何跨度内所有观察处于端价闭区间。相邻单元端点由构造共享，方向交替。

这里证明的是自定 DC 关系的唯一分解及其几何性质，不能偷换成“已证明原文语义只有这一个定义”。论证目前为纸面证明；`DirectionalChangeLemmas.lean`只机器证明首次命中唯一、最早最大值存在及唯一、初始上下命中互斥。尚未把上述整个递归关系与终止/因果证明搬入Lean，更未完成Rust精化证明。
