## 独立关系怎样对应冻结的文字定义

`DCSemantics.lean` 在开始证明前编译并固定SHA256：

`a2fbd4becc7a692ba10b6aff6c84dd511ccb5062dae734c9a56616324db0a972`

随后只在独立证明文件工作，该定义文件没有改动。它不调用Rust，不通过 `parse(p)=result` 定义合法性。

| 关系 | 含义及与Stage3的对应 |
|---|---|
| `Extreme` | 在给定闭区间内满足方向极值不等式，并无更早同价极值。上行取最大、下行取最小 |
| `Wide` | 某前缀有两个观察相差至少δ。首次成立即Stage3的首次振幅命中 |
| `Initial` | 首次Wide、该前缀反方向的最早极值、当前点距起点的正向幅度≥δ，联合确定初始化时刻、起点及方向 |
| `Drop` | 当前点相对区间内某个较早点反向移动至少δ。等价于相对运行方向极值回撤至少δ：极值不小于任意早先方向分值；反向由极值本身提供见证 |
| `Run.next` | 取首次Drop及其之前最早极值，生成完成单元，从该极值反向继续；确认时刻记录首次Drop |
| `Run.stop` | 直到输入末端确实无Drop时才允许停止，必须返回活动方向、起点和最早极值，不能随意截断 |
| `Whole` | 长度0为空结果；未Wide时返回等待状态的两极值；已初始化时返回初始化信息、完整Run和活动尾部 |

路径以 `p : Nat → Int` 加长度表示有限序列。所有观察读取都被界在长度之内，长度外的值不参与相应关系。Result保留初始起点，故原始路径的前导片段由 `[0,initialStart]` 定位；它不是额外需要猜测的分解。原始事件本体和报价重建来源仍由外层保存，本定理不把价格函数当作全部事件数据。

`Run.next`要求起点严格前进。这个条件没有被塞进最终定理的假设：`initial_seeded`从合法初始化建立不变式，`turn_progress`由首次回撤与已达到δ的正向幅度推出严格前进，`turn_seeded`证明反转后不变式继续成立。`run_exists`因此按剩余索引数 `n−s`做良基归纳，最终存在性不依赖额外“每步能前进”的假定。

## 证明的承重步骤

存在性先证明有限区间最早极值存在，以及某性质在有限范围内“存在首次命中或全无命中”的二分。初始化方向不可能同时上下成立，否则更早的前缀已达到δ。每次反转后的下一次反转必更晚，完成端点也严格前进，故有限路径不会产生无限分解。

唯一性比较两份满足关系的分解。初始化时刻由最早性相同，方向由互斥性相同，起点由最早极值唯一性相同。逐单元比较时，首次回撤时刻与其最早极值必须相同；停止分支与继续分支不能同时成立。对分解关系归纳后，整个单元列及活动尾部相同。这比“程序只能返回一个值”更强，但只针对已明确的DC关系，不是所有可能起始构造的唯一性。

因果证明先把截至t前缀的极值、回撤和初始化关系在两条路径之间搬运，再比较完整Run。t之后的首次回撤产生的单元及后续单元都不进入已确认列表；t之前的首次回撤与极值在两边相同。几何证明另给出确认时刻严格递增，所以按 `knownAt≤t` 过滤确实得到完成单元前缀。

`knownAt`是本规则定义的首次反向阈值命中序号。这里未证明交易所消息的接收时刻、CPU处理完成时刻，或任何其他知识模型下的最早可预测时刻。

## 非空见证与实现边界

`DCWitness.lean`直接构造关系证明：整数路径 `[0,3,0]`、δ=2在序号1初始化，产生上行单元 `0→1`，确认序号为2；活动尾部为下行 `1→2`。完成单元数等于1也有Lean证明。因此一般定理并非靠永远返回空完成列成立。

新 `dc_formal_witness_probe.rs` 使用同一三点输入，实际Rust增量实现与独立参考均与上述端点、初始化、确认和活动尾部一致。这个单点桥接检查不替代DC-REFINE-v0的全域实现精化。该抽象整数见证自身也不冒充正价格L1事件流；合法固定报价/数量更新的非空有限证据继续引用Stage3的757条样本，本轮没有重跑。

## 接下来真正剩下的义务

DC-CANON/CAUSAL/GEOMETRY的上述形式化目标已成立。DC-REFINE仍只有有限对拍及一个正式见证对照，未证明Rust对所有机器有效输入等于此独立关系。

更关键的下一步是F₂资格：把已证的端点、方向、幅度、接续和区间性质逐项与原义上层输入要求对接，检查完全分类、递归闭合及发展/完成状态是否还需要其他条件。几何类型转换 `RMove::Segment` 不提供教义身份，已有62→20→6→1样例不提供全域闭合。

真实订单消息的观察重建、断档/重发、确认时钟和恢复仍按具名数据协议验收。P3实验数据和任务尚未冻结，P4架构采用尚无结论。其他投影候选和直接多变量路线的反例/未决状态保留，不能用本轮DC证明覆盖它们或关闭整张候选票。
