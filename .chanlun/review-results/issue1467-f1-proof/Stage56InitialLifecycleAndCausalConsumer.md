## 初始生命周期的可证部分

[作者稿](stage56/initial-p-lifecycle.md)把 D54 的原始来源关系扩充为 Ω56-L、δ56-L：以三条已封原始腿的最早正宽交集登记一个候选核心；接触核心时保留发展记录，首次合格数值外离时释放非seed L的最终成员身份，whole X 仍拥有 L，R 只作确认支持并留给后继。每个已发对象在该目录内恰有一核，标为 P⁰；核身份、退役和分类都是具名初始选择，尚未认证为原义。

[生命周期独评](stage56/independent-lifecycle-review.md)直接核了这一部分模型的单值步骤、有限终止、全来源覆盖、真实端点接续与已发稳定。它与 Stage55 的点核配对重启不同，不靠替 U 改名消解相邻 U/U。数值 P⁰/P⁰ 的接续已定义，原义 P/P 仍须另证。

新增 **L56**：成功 whole X 内，任意完整连续三条原始腿的正宽交集 J，都与固定核心 C 闭交非空。首次 L 的好角色或首次接触的交替端点保证 L 触核；后续各腿都曾是触核 R。对 seed 右侧三窗，记 J=[a,d]、C=[α,β]，各腿触 C 得 `a≤β`、`d≥α`，故 `max(a,α)≤min(d,β)`。seed 左侧的完整窗，包括跨 seed 起点的窗，均已由最早搜索拒绝正宽。

这一证明量化非空有限精确实数历史按固定规则产生的腿。它排除片内存在完全分离的另一份正宽三腿成核见证；只触边也算相交，不能据此证明 J=C、原义核同一、真正 Zn 或完成 P。任意原状态窗、非连续腿组及跨 whole 的确认 R 不在量词内；普通证明也不等于 JavaScript 的全域精化。

两个新控制共22笔合成成交、24个含初态前缀，独立重算及原样重放一致：

| `0³,10³,5³,15³,4³` | AwaitPair | seed/H 拥有 e1…e12，C=[5,10]；未封腿拥有 e13…e15；全部15笔在未发whole尾部 |
| `0³,1,0³` | NoCore | 只有一条已封腿，全部7笔保留为尾部 |

原稿第28行混淆了第一项的 seed 与 whole 来源，记为 LC56-01。当前采用四组进入 seed/H、第五组属于未封腿的准确归属；e13虽提供封定/可知支持，不因此变成 seed/H 拥有事件。旧字节保留，订正见上述采用说明。两个控制均无输出，不能提供非空固定 F₂ 见证；既有 D54 数值成功也不能替代该资格。

## 按时点交付的实际消费者

[消费者报告](stage56/causal-consumer.md)与[独评](stage56/independent-consumer-review.md)新增了可信宿主 `packetAt` 和实际 stdin 探针进程。宿主读取既有文件，消费者只收到独立 JSON：当前身份、固定协议常量、Stage44 A/B 特征，以及严格 `capture < t` 的原始接收、发布、应用和成交历史。应用另按 `available_capture < t` 与可用行约束；已收到但未应用的原文可以保留，派生状态不能回填。

全文件路径、摘要、总长、末时间、未来标签、标签可知时点、分区及剔除标志均不进入载荷。7个时点实际通过独立子进程 stdin 消费；独评用不导入作者 MJS 的 Python 从源文件重组7个完整载荷并重算特征，全部字节摘要匹配，保存的3份 gzip 解压字节也匹配。

43条迟应用的精确边界另被实际检查：在 `available_capture` 当刻不入应用载荷，到 +1ns 才出现，合计1个 anchor 加43条应用。对应原消息在此前已收到时仍可见。这保持了接收、可应用和发布三种时序的区别。

三组未来对照使用同一已存 BTC-USD 探索分钟的原始字节前缀，双方都保留决策后的非空后缀。短/长输入分别为73/20868、7282/20868、20777/20868行，模型载荷逐字节相同；后两组的短标签为 EOF 删失，长标签分别 down/up。没有改价、改序号或冒充独立市场样本，EOF也不封闭末桶。

这证明具名探针路径的有限输入契约，未接入真实训练模型。子进程仍有宿主文件权限，未提供 OS 沙盒或敌意代码防护；七点验证也不是任意上游实现的全域因果证明。Stage35/44 已审的目标、特征和投影合同继续作为明确依赖。

## 标签发生与可知必须分开

新增评价器区分 `resolved_at_ns` 与封桶 `label_known_ns`。具体反例：变化发生于0.2s，0.3s才出现封桶见证；训练区间为 `[0,0.3s)` 时，虽然 resolved_at 已在区间内，标签仍须排除。若区间末端后移1ns，才可按该合同纳入。none目标同样要等 deadline 之后的更晚 capture；未知、连续性删失和 EOF未封闭不补零或 none。

全部572个决策身份留在评价侧，两套切分共1144行经独立逐字段重算：普通20s/40s切分有569个可用标签、3个初始化不可用、0个跨界排除；3.5s压力切点有565个可用、3个初始化不可用、4个跨界排除。方向标签按后续事件分组，损失行没有同组跨分区；309组不是统计独立样本数。压力切点只作工程检查，未冻结最终训练或确认划分。

作者13项检查被独立复跑，9项列明输出逐字一致、共3,666,147字节；另有8个定向时钟用例。只保存3份完整载荷 gzip，未落盘572份完整历史。早期作者错误断言及改用合法删失前缀的过程保留；现役冻结结果为 run-v4。没有重跑旧恢复矩阵、旧枚举或训练。
