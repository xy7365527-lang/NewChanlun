## 3. leaveA、retA 与 c 的发生/可知范围

`DCSemantics.lean:45-49` 明确 `Unit` 四字段依次为方向、start、finish、knownAt；`:63-66` 把首次 δ 回撤时刻放进 knownAt。`DCOriginBridge.lean:13-15` 把 start/finish 作为 `Segment` 起止索引，且明确这里只是几何载体。`CenterAttemptSpec.lean:11-13` 则以 `knownAt ≤ t` 过滤可见单元。

从 `CenterAttemptSpec.lean:59-77` 直接得到：

| 单元 | 发生区间 | 起止值 | 可知时刻 |
|---|---|---|---|
| a0 | [0,1] | 10040 → 10020 | 2 |
| a1 | [1,2] | 10020 → 10032 | 3 |
| a2 | [2,3] | 10032 → 10024 | 4 |
| leaveA | [3,4] | 10024 → 10050 | 5 |
| retA | [4,5] | 10050 → 10042 | 6 |

固定种子 a0/a1/a2 的核心为 `[10024,10032]`。retA 的低点为索引 5、价 10042，严格高于 ZG=10032。这些数值已在本轮用 Python 从源码字面定义提取并复算。时刻 5 只有前四个单元可见，retA 到时刻 6 才进入 `visible`；与冻结的 `WITNESS_TARGET:90-97` 一致。

| 主张 | 判断 | 理由 |
|---|---|---|
| 当 c 仅等于 leaveA，这次回抽低点位于 c 内 | 反驳，有具体反例 | c 的发生范围为 [3,4]，点在 5，`5 > 4`。无论公共边界按闭区间或半开区间处理，都不能把索引 5 放进截至 4 的范围。leaveA 在 5 时可知不改变其 finish=4。 |

扩大 c 后必须重新核定起终点、方向、成员、内部中枢、完成来源、确认时刻以及围绕 B 比较的 b/c 范围。一个立即可见的变化是，如果新 c 仅取 [3,5]，端点价是 10024 与 10042，但内部在索引 4 达到 10050；因此不能直接沿用“端点包围内部极值”的几何表示。若改用真实区间包络或再延长 c，也要给出相应定义及证明，不能把旧端点值原样搬过去。

旧 DC 单元的数值事实、原固定种子的 `UpPair` 几何事实、旧 `visible` 的定义内因果关系可以保留为原对象的结论。它们不自动成为新 c 的结论。需要暂停继承的是任何以旧 c 边界计算的力度、Extreme、T3-in-c、内部中枢计数、成员映射和完成时点。`firstPairUp` 还只表示固定三成员种子之后的紧邻两项，见 `:28-32`；不能不经生命周期证明，就把它解释成一般发展中中枢的首个真正次级别回抽。

## 4. 第 35 课后继中枢与动力学完成之间的缺口

支持“这里仍缺桥”，但不能把缺桥写成“不可能构造”。

`beichi.md:317-323` 允许在进行中的 c 上计算力度，否定先从“不再同向延续”取得完成再拿来证明背驰的循环；`:338-357` 要求在结构给定边界与共享时间轴上度量。`035:16` 则在具体最低构造中用后继中枢不再沿原方向更高/更低描述趋势结束。当前需要证明的是两种叙述在所选候选的哪些对象上、以什么边界和什么可知时刻对应。

这里至少有三个不同命题：

1. 某段已经具备盘整/趋势的构成条件，可以结束。
2. 这一走势实例确实停止延伸，并让位于一个新实例。
3. 到某时刻 τ 已有足够证据确认第二项，可能确认的是早于 τ 的端点 e。

第 18 课 `:40-44` 直接区分第一项与第二项，`:24` 又要求上级中枢的前三个次级别走势类型已完成。`exact_root` 的局部中枢几何不同时证明这三项。`ReferenceBaseSpec.lean:100-102` 的索引界 38、66、86 也没有定义 τ，更没有证明最早可知或未来稳定性。

还要限制“完成由背驰定义”的使用范围。`beichi.md:834-847` 明确本级别背驰是充分非必要条件，`level_recursion.md:331-340` 采用 settled 作组件完成标记并排除活动尾部。因此，“每个完成都必须先找到本级趋势背驰”不符合完整的现行文本。相反，给一个 settled 布尔值也不提供完成来源；正本保留其他触发机制，不代表本候选已经实现或证明了这些机制。本轮不消除这些正本文句之间的张力，只给出不会越过任何一方的最窄用法：禁止循环自证，允许不同级别的已证完成来源，逐一说明其消费关系。

建议的最小证明依赖是：原始可见前缀 → 已独立确认的下层对象及其来源 → 合格的后继中枢 → 当前级别旧新实例的完成/让位证据 → 上级消费。严格下层若有级别下降，可以作为依赖终止依据；同层证据须另给良基顺序，时间“≤”或证书名字不同本身不够。F₁ 的初始证书可以由非递归规则生成，第 84 课 `:54` 明确允许这一点，不应要求无限下钻。

这条链仍有正面义务：底层证书独立存在不等于它已能终结父级；必须证明级别、方向、真实成员、原始时间范围和父级触发条件对应。若确认借用了端点之后的回抽/新中枢，就保留 `e < τ`，发布不得早于 τ。动态速度或力度如使用观察价与事件时钟，应冻结单位及度量关系；不能把自然数索引界直接称为真实确认时间，或默认为现行笔/K 线度量已原样适用。
