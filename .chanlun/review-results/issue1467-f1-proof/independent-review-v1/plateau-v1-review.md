## 2. 可保留的一般数学结果

给定至少两个已出生核心，即至少一条边，最大同向分解的证明成立：相邻符号相同处不能切，符号不同处必须切。切点完全由符号序列决定，且取所有这些切点确实给出合法分解。这里同时有存在性和唯一性，不能将结论扩写为“任何合理 F1 的答案都相同”。

设相邻边块为 `[a,b]`、`[b+1,c]`。首块拥有 `K0,…,Kb`，下一块拥有 `K(b+1),…,Kc`，核心索引不重叠；事件域分别止于 `t_b`、始于 `t_b+1`，事件也不重叠。后一块轨迹读取 `B_(t_b)`，只共享边界状态，不使前一核心成为后一对象的成员。确认前块时引用下一核心最初三事件的事实，与将这些事件归属下一对象并不矛盾。

已经确认的对象不会因 D 内扩展改动：确认需要 `K(b+1)` 出生，其首事件已经封定 `t_b`；后来的同值事件只延长反向平台，不能改变此前切点和成员。证明可只保存反向核心 ID、前三次见证及符号，不需要把仍会延长的平台全体成员复制成前块成员。

本次另枚举长度 1–9 的全部 1,022 条 `±1` 边序列，并枚举每条的全部候选切法：恰有一份满足块内同号、相邻块异号的分解；按首块/后块规则，每个成熟核心恰有一个拥有者。此有限计算用于核对组合论推导，不承担空边序列或全体订单域的证明。

## 4. W 的适用域、精确值与度量边界

固定 `a>b`、`K>0` 时，

```
f(q) = (a*q+b*K)/(q+K)
f(v)-f(u) = (a-b)*K*(v-u)/((v+K)*(u+K)) > 0
```

在正队列量域上严格递增，因此相等关系、符号、平台长度、成熟时间、边块和成员规则双向保留。每个有限观测集合的范围端点也按 `f(min),f(max)` 映射；三范围的严格相交条件随之保持。报告所用 `a=102,b=100,K=10` 正是这一情形。

独立使用有理数重新计算得到：

```

W:       101,304/3,1112/11,403/4,101,1316/13,2122/21
range1:  [101,304/3]
range2:  [403/4,304/3]
range3:  [403/4,1316/13]
交集:    [101,1316/13]
宽度:    3/13
```

**严重性：中，输入域声明应补齐，有限算例不受影响。** 第 60 行的 D 只约束固定 100 档数量平台，尚不是一个已完整声明的 W 保真域。第 210 行和第 289 行已经给出/承认固定参数限制，下一版应将它们提升为显式 `D_W`：例如 D 内同时满足全程最优价 100/102、102 档卖量 10、100 档买量为正。正量条件使“100 是最优买价”有对应的实际队列；若取 q=0，固定公式仍可算出 100，但其最优买价解释要重新定义。

一个可复核的域边界例：保持 `q=10`，向 102 卖档合法新增 10，使 `K:10→20`，则 Q 不变，而按当前盘口卖量计算的 W 从 101 变成 `302/3`。因此一般 D 上不能沿用平台同构。该限制已被报告承认；这里补的是形式化输入域，不将变参情形报成新发现的反例。若坚持常数 K=10 而不读真实卖量，那是另一观察函数，不能同时称它反映变更后的该盘口权重。
