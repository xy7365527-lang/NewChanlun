## 2. 单点基底与严格 F2 可以怎样同时成立

承重条文是 `zhongshu.md:71–77` 的 Z-2，以及 `:132–146,178–190` 的 S-5 和第 35 课解释。

Z-2 要求 `ZD < ZG`，否定“严格失败再走宽松版”。S-5 保留“三根单位 K 线”和“三笔同价交易”为合法备选，现仓选择线段基底。后者“合法但未选用”的地位，说明不能把“当前生产未采用”直接改写为“原文禁止研究”。但它也没有将挂单平台预先批准为当前正式基底。

本候选可采用下面的类型区分，符号仅表达契约，没有修改任何源码：

```text
BaseCore[axis] = (c, seed_events, birth_at)   // 表示单点 [c,c]
CompletedBaseMove[axis] = (owned_cores, raw_span, range, completion_witness)
StrictRecursiveCore[axis] = (ZD, ZG, proof ZD < ZG, three_child_refs)
```

F1 的种子只按其出生关系产生。F2 核心只按三份合格子走势的全范围严格重叠产生。既不把 `BaseCore` 强制转换为 `StrictRecursiveCore`，也不令 F2 在 `<` 失败时改用 `≤`。

对候选的每份完成块，由 `PlateauBaseCandidate-v2.md:76–94` 的定义，它至少含一条非零成熟核心边，块内同号。其首末状态不同，全程极值恰为这两个端点。因此 `lo < hi`。事实上，正宽范围不要求“两个自有核心”；单自有核心块仍包含从前一块末核心出发的非零连接边。两个自有核心决定的是候选的趋势标签，而非范围正宽的最低条件。父核心则继续计算

```text
ZD = max(lo₁,lo₂,lo₃)
ZG = min(hi₁,hi₂,hi₃)
只在 ZD < ZG 时成立。
```

所以“从单点种子产生正宽父核”没有代数矛盾，也没有软化父核边界。真正会踩边界的是以下动作：把每个 `[c,c]` 直接登记为 F2 已确认中枢；把原义 `Move` 的中枢计数悄悄换成任意 token 数；或者用父核存在倒推子走势的完整分类、完成与原义身份。

`qushi.md:78–91,124–144` 仍约束原义层：盘整恰含一个相应级别中枢，趋势须有至少两个依次同向中枢，同向由外缘分离判。F1 点种子若另行设 `DD=ZD=ZG=GG=c`，则不同 c 的单调性确实会退化为外缘分离。但这个外缘赋值属于初始对象定义，不能从只给 `[c,c]` 自动读出来，更不能把这个退化比较推广成正宽递归中枢只比 c。

## 3. Q／W 的严格保序桥：已经能证明的部分

在 D_W 内，固定 `a>b`、`K>0`、`q>0`，实际最优买卖价与卖量确为 b、a、K。定义

\[
w(q)=\frac{aq+bK}{q+K}=b+(a-b)\frac q{q+K}.
\]

若 `u<v`，则

\[
w(v)-w(u)=\frac{K(a-b)(v-u)}{(v+K)(u+K)}>0.
\]

所以 w 在该域上保留并反映 `<`、`=`、`≤`。其反函数为 `q=K(w-b)/(a-w)`，值域在 `(b,a)`。这不是把观察值宣布为真实成交价，而是建立两个观察坐标之间的数学同构。

**一般命题 `ORDER-INTERVAL-BRIDGE`。** 设 A、B 是线性序集，`f:A→B` 是同一个严格递增函数。所有事件、所有单元和所有层都用这个 f；不能逐对象挑不同函数。对任意有限非空族 `xᵢ`，有

```text
f(min xᵢ) = min f(xᵢ)
f(max xᵢ) = max f(xᵢ)
```

证明是有限极值必由某个成员取得，而 f 保留并反映大小与相等。若 `Iᵢ=[lᵢ,hᵢ]` 且 `lᵢ≤hᵢ`，定义端点映射 `f_*Iᵢ=[f(lᵢ),f(hᵢ)]`，就有

```text
max(l₁,l₂,l₃) < min(h₁,h₂,h₃)
  ↔ f(max(l₁,l₂,l₃)) < f(min(h₁,h₂,h₃))
  ↔ max(f(l₁),f(l₂),f(l₃)) < min(f(h₁),f(h₂),f(h₃)).
```

若方向由起终点大小决定，f 保留其方向；若方向作为二元标签携带，则桥要求原标签一并透传。两种情形下相邻标签不等的谓词 `DirAlternates` 都在映射前后等价。所以“方向交替且严格三交”这一合取谓词也等价。点核 `[c,c]` 映成 `[f(c),f(c)]`，仍属初始点核；严格核 `[ZD,ZG]` 映成 `[f(ZD),f(ZG)]`，仍属严格核，不发生跨类型升级。

这个一般命题只涉及端点表示，不要求 f 连续，也不声称任意严格递增函数的集合像 `f([l,h])` 填满 B 中的整个区间。当前 W 可以连续延拓到正实数，其数学实区间像与端点映射一致；实际事件只采到有限状态，这不表示跳变间发生过额外事件。由此三个 Q 范围严格相交当且仅当其 W 范围严格相交，且对应核心是 `[w(ZD),w(ZG)]`。单点依然是单点；不相交依然不相交。W 不会凭空替失败的 Q 严格核心造出正宽。

对平台候选，这进一步给出以下确切结果：

- 最大同值平台、三事件成熟时点、成熟核心边方向、边块切分、原始事件拥有者与反向三事件完成见证全部对应。
- 对同一份已经给定的子单元序列，`CenterConfirmedComplete` 所用的方向交替和严格三交接受结果对应。
- 若外缘、核心各自按同一批成员的有限 min/max 构造，则外缘分离、核心分离与扩展不等式也对应。此结论不帮算法决定应该选择哪些成员。
- 若把同一个纯顺序公式构成的递归算子参数化到 Q／W，两边可以逐层归纳对拍。前提必须是同一个算子及相同成员选择、确认关系，不能以“都用了 min/max”替代这些前提。

这个桥不证明原义走势身份，不证明存在一份完整的上层走势，也不证明两轴的力度度量相等。`PlateauBaseCandidate-v2.md:190–208` 已有非线性换轴改变速度净增量比较的坐标反例，应继续保留。范围重叠是纯顺序事实；速度大小与实际成交能力不是。

Q 轴的直接障碍是它目前给出数量区间，而 `035:18` 及 `level_recursion.md:29–31` 使用价格区间。把 `price` 字段填成 q 属于解释变化，数值类型恰好都是整数不能解除这个变化。W 避开了量纲不一致，却仍需说明这个特定盘口函数为什么能承担原义价格区间的角色。量纲正确是必要检查，不是原义身份的证明。

## 5. 当前 Lean 契约及固定 tick 舍入的域内反例

按指定入口沿 import 读取源码，未调用构建或改动 formal 文件：

- `formal/Origin/CenterComplete.lean:147–160` 的实际谓词只有 `DirAlternates ∧ computeZD < computeZG`。`:168–171` 的等价证明是 `Iff.rfl`，不会检查事件历史或 F1 身份。
- `formal/Origin/CenterConstruction.lean:51–57,92–117` 用段首末端计算范围，再作严格三交。候选块内部单调，因此本见证的全程范围确实等于端点范围；这里不是以端点范围擅自替换有内部超调的范围。
- `formal/Origin/ChanlunElements.lean:13,43–49` 的 `Tick` 实为 `Int`，`Segment` 中没有原始事件、基底来源或完成见证字段。`:51–56` 的 `Center.valid` 仍只是 `zd≤zg`。存储类型能装下单点，不等于严格确认谓词批准单点。

因此把一个值装进 `Segment`，再通过名为 `TrueCenterCore` 的谓词，只证明该编码的两个局部条件。原义合格子走势身份必须来自调用者，现有类型没有替调用者证明它。

还存在一个具体可达数值问题。把上一节完整历史 H 中初态及全部 100 档买量同时乘 `T=1000`，99 档事件和 A0 的卖量 10 保持原状，得到 H₁₀₀₀。这是完整原始历史的变换，不是随意替换三段结果。所有合法残量、三个观测的平台、连续序号和固定最优价条件保持，仍属 D_W。

精确 Q 核心变成 `[10000,19000]`；精确 W 核心为

\[
[102100/1001,\;193900/1901],
\]

宽度 `1800/(1001·1901)>0`。八个 W 平台仍互不相等，三份完成块及确认时间都不变。

但 `w(q)=102−20/(q+10)`，而 H₁₀₀₀ 最小 q 为 7000。所以每个 W 距 102 小于 0.005。若适配器四舍五入到 0.01，则所有 25 个状态，包括初态，全部编码为 `10200` 分，八个平台合成一个。此时无原来的三份完成块，更无严格父核。

这否定的是“W 有价格量纲，故可直接按固定 tick 舍入后无损接入”的接口主张。它没有否定精确 W，也没有要求 W 变回实际报价或成交价。实际仓库是否已有这种适配器不在本次主张内；这里只否掉一个具体接口方案。

更一般地，以下四个要求不能同时满足：① 有效域覆盖全部 D_W，包含 q 为正整数且无上界的子域；② 使用事先固定的有限分辨率网格，例如固定 `δ>0` 的 `p₀+δℤ`；③ 编码输出仍留在同一个有界报价带 `[b,a]`；④ 对整个有效域保留所有不同观察值，并保留严格大小关系。因为域内有无限多个不同 `w(q)`，而该网格与 `[b,a]` 的交只有有限个点，鸽巢原理即给出碰撞。这个否证甚至不需要额外要求编码数值恰等于 W。

若进一步要求精确价格数值，也会失败。有限历史可以用公分母精确整数化，但公分母必须随未来量值增长或另存比例；不能把某一个样例的整数化称为覆盖全域的固定 tick 接口。直接把 q 当作 W 的秩编码能保序，却使整数标签离开有界价格带；它放弃了上述③，也不再直接表达价格数值。

该命题不排除自适应编码、扩大数值表示域、限制 q 的有效域，或从头定义量化后的 F1。这些方案分别改变了前提，必须按各自契约验证，不属于被否证的固定网格无损接口。

## 6. 两种精确接口模型及同一历史的后果

现有证据不支持把两种模型的语义后果合并。它们都不要求和成交塔强等价。

| 项目 | 模型 O：明确参数化的观察轴接口 | 模型 P：保留原义输入资格的接口 |
|---|---|---|
| 输入类型 | `CompletedBaseMove[axis, origin=OrderPlateauV2]`，axis 为 Q 或精确 W | `CertifiedOriginalMove`，有价格解释、相应级别中枢及完成身份的来源证明 |
| 初始选择 | 挂单残量平台与三事件成熟属于新增 F1 选择 | 可研究同一 F1，但候选身份不能直接强转成 `CertifiedOriginalMove` |
| 上层局部消费者 | 方向交替＋严格三交，参数化到该 axis | 同样坚持严格三交；仅在输入资格成立后调用 |
| H 在 e24 的结果 | 得到 `StrictObservedCore[Q]=[10,19]` 或 `StrictObservedCore[W]=[101,2938/29]` | 接口返回 `UnqualifiedBase(OrderPlateauV2,Q/W)`；不能据此输出原义父中枢 |
| 结果解释 | 已证明的顺序区间对象，尚不声称父走势、原义买卖点或完整 F2 | 此处拒绝的是未获资格的转换，不断言市场上原义父中枢不存在 |
| H₁₀₀₀ | 精确接口依然通过；固定 0.01 舍入接口失败 | 未获资格状态不因舍入或换单位消失 |

模型 O 需要新增“本次递归承载的是这个观察轴的区间结构”的解释。这可以作为具名研究选择，不是第 84 课逐字给出的定理。模型 P 的“只有完成资格证明才能转换”是对既定接口的保守实现选择，也不冒充原文规定了某个证书格式。两者的共同原文前提是 F1 可替换、分解须唯一、F2 规则保持；共同已裁前提是 F2 严格 `<`、相关级别计数和同向判据保持。

P 模型不能偷加“资格证明必须是与成交塔相等”。证明可以针对该 F1 自己的原义角色，而非另造一座成交塔作参照。O 模型也不能以通过这个局部消费者为由宣布 `F2-SEMANTICS-v0` 通过。要把 O 的结果用于原义声明，正是要解决 P 保留的资格问题。

据此，本次实际解决的接口选择是：保留 `BaseCore`、`CompletedBaseMove[axis]` 和 `StrictObservedCore[axis]` 的独立身份，用精确数值计算，允许它们在研究层完成严格区间消费；不把单点种子判为 Z-2 违规，也不通过类型强转获得原义资格。这使后续研究可以继续追问原义角色，而无须反复争论“单点能否生成正宽”，更不需要恢复成交塔强等价这个已排除目标。

## 7. 两条可执行的研究后续路径

**精确有理数参考。** 在仓外研究包中定义 `ObservedRange[axis, ℚ]`、初始点核与严格递归核，沿用本候选的原始事件引用及 `known_at`。把第 3 节一般命题落成隔离的引理，验证同一严格递增函数下 min/max、方向交替及严格三交等价，先用本报告两条完整历史验收。这条路径应显式记录轴与来源，以有理数承载精确 W；不适配到生产 Tick，也不声称产物已经是原义 Move。义务是保持严格边界、完整保留原事件和确认关系，以及对已使用的顺序公式逐项提供桥；原义分类与上层完成身份仍须独立解决。

**量化后重新定义 F1。** 另命名 `PlateauQuantized-v1`，冻结 tick 大小、原点、舍入方式、半格规则、量化发生时点和有效域，以 `xᵢ=quantize(W(Bᵢ))` 重新定义最大平台、成熟、边块及完成关系。不能先沿用精确 W 的完成块再只舍入端点。H₁₀₀₀ 应明确验收为“一个持续平台、没有原来的三份完成块”，而不是让实现偷偷修补旧结果。新候选可重新证明唯一分解、覆盖、因果确认和扩展稳定性；这可能复用关系层证明，但不继承精确 W 与 Q 的严格双向桥、原先核心数量或市场价值。仍不得把量化导致的消失解释成原义市场中枢不存在。

两条路径都在现有生产之外，均不需要先批准成交塔强等价。选择精确参考可以保留本次已证的区间结果；选择量化重定义则接受有意识的信息合并，并把它当成新候选的实质变化。本报告只给出这两条路径的接口与验收后果，没有自行实施、修改教义或收窄原 F2 目标。
