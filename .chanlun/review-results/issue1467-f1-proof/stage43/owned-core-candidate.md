题设建议可以落实为一份新的、全有限前缀有值、核心独占、事件全覆盖且已完成前缀不重绘的关系，以下称 OC-v1。它消除了 v2 的“单核心加入口方向反转就完成盘整”，也没有 v3 的共享构成核心。本轮给出正面构造和实际计算，不只是研究计划。

代价已经实算出来：`10³,20³,10³,20³,10³` 在第 15 个事件时产生两份相邻完成上涨对象，第二份从 20 出发、回到 20，内部最低到 10。正确范围是 `[10,20]`。第二对象方向来自自己的核心 10→20，与原始起终价格差不是同一个量。

## 2. 输入与总关系

### 2.1 域没有缩小

输入仍为 v2 的完整初态 B0 与连续合法订单事件 e1…en。每个事件产生 Bi，取固定研究价位 100 的买量 `x_i=Q(B_i)`；初态不是事件。

D_Q 含空历史；非空历史要求 x0=x1。在 x1…xn 上取最大常值平台，已经被不同值封口的平台至少有三个不同源事件后的观察，最后开放平台可只有一或两次观察。数量允许零。短平台被封口即离开域，不能删除后拼接。

D_W 另要求固定最佳买价 b、最佳卖价 a、卖量 K 且 q>0。具体参数仍为 b=100、a=102、K=10，`W(q)=100+2q/(q+10)`，在此域严格递增。Q/W 的核心身份、生辰、方向、归属相同，数值范围由严格递增映射得到。W 没有因此取得成交价资格。

平台 P_i 从事件 s_i 起、值 c_i；观察末端 u_i 随当前前缀变化，封口后最终末端记 t_i。第三次观察时出生唯一核心 K_i，固定生辰 `β_i=s_i+2`、固定种子 `e_(s_i)…e_(s_i+2)`。同值延长不重复出生。成熟核心为 K0…K_(m−1)，最多只有末平台未成熟。

这些平台事实沿用明示定义；对象划分与通过状态全部重新建立。

### 2.2 自有核心重启规则

从第一个尚未分配的成熟核心索引 a 开始，初始 a=0。

1. 无成熟核心：没有活动核心对象，事件全部留在 R。
2. 只剩 K_a：保留无方向活动对象，拥有 K_a，不发射“已完成盘整”。
3. 有 K_(a+1)：用 `d=sign(c_(a+1)−c_a)` 建立方向。不同平台相邻值不等，d 非零。
4. 令 b=a+1。只要下一成熟核心满足 `sign(c_(b+1)−c_b)=d`，便纳入并递增 b。
5. 若核心到此为止，对象保持活动。若出现第一份变号成熟核心，完成 K_a…K_b，然后从 a=b+1 重启。

新对象方向只由自己的前两个核心决定，上一对象末核心至新对象首核心的符号不决定新方向。这是与 v2 的实质区别。这条入口连接对应的原始事件全部保留。

每份完成对象至少拥有两个核心，内部严格同向，候选 kind 为 Up/Down；没有完成盘整分支。一个活动核心仍被保留，但不预称已取得原义资格的盘整。

### 2.3 来源、发生区间、确认

设完成核心块为 K_a…K_b，上份完成对象止于事件 T，首对象取 T=0。

| 字段 | 定义 |
|---|---|
| 独占核心成员 | K_a…K_b，每个核心的平台源事件都在本对象内 |
| 独占原始事件 | `(T,t_b]`，即 e_(T+1)…e_(t_b) |
| 几何发生时段 | 状态 B_T 至 B_(t_b) |
| 实际起终值 | x_T、x_(t_b)，允许相等或净变动与核心方向相反 |
| range | `[min{x_j:T≤j≤t_b}, max{x_j:T≤j≤t_b}]` |
| 结束位置 | t_b，末平台已被下一平台首事件封口 |
| 完成见证 | K_(b+1) 的 ID、值、固定三事件种子，以及变号关系 |
| 确认时点 | β_(b+1)，第三个真实源事件到来才发射 |

时序使用源事件序号。若有交易所时戳，同样保存原时戳；不假设一时戳一事件，也不以墙钟代替源序。确认通常晚于结束位置。

后继种子属于下一对象或 R，只作前对象的证明支持，不能重复计入前对象的核心数或原始事件。range 包含 B_T，但状态不是新增事件；跳变中没有发生的观察不会被补出。

### 2.4 前导、活动尾部与原始归属

输出 `O_n=(C,R,A,P,K)`。C 是完成列表；K 是成熟核心目录；P 是可空未成熟末平台；A 是可空活动对象，保存自有核心 ID，一个核心时无方向，至少两个时保存核心方向。A 不是另一份事件所有权表。

T 为最后完成末端，无完成对象取 0。R 精确保留 `(T,n]` 全部事件与状态 B_T，不要求单调。未成熟的反向平台也留在 R，不用于提前完成。

没有丢弃或永久隔离的三事件前导。启动期无核、单核时，全部前导事件就是 R；第一对象完成后从 e1 开始拥有它们。若界面另列 leading，它只能是 R 的只读视图，不能在分区中再数一次。

`owned(C_1) ⊎ … ⊎ owned(C_r) ⊎ R = {e1,…,en}`。

成熟核心恰属于 C 中一对象或 A，P 尚无成熟核心。原始尾部被保存，不等于已经有完成走势覆盖它。域外只报告不属于 D 并保留记录；冻结最后域内完成前缀可作诊断，不能宣称为域外延拓。

## 3. 唯一性、覆盖与不重绘草证

最大常值平台唯一，第三事件出生唯一，故核心目录唯一。给定首未分配索引 a，第二核心是否存在唯一；存在时方向 d 唯一，此后第一变向核心的位置唯一。不能同向未尽就切，也不能跨过首次变向。因此完成块及下一起点被强制确定。a 严格递增归纳给出唯一完成列表与唯一活动尾部；每步至少消费两核心，有限前缀必停止。零核、单核分支均有定义，所以总关系有值。

K_a…K_b 完成时，K_(b+1) 已成熟，其首事件已经封定 `t_b=s_(b+1)−1`。过去平台起点、封口、值、种子和第一变向位置在 D 内追加时不变。完成对象范围只读 B_T…B_(t_b)，也不变。按完成顺序归纳，旧 C 永远是新 C 的相同字段前缀。

上份核心不含 K_(b+1)，下份从它开始。上份事件止于 t_b，下份从 t_b+1 开始，故事件与核心分别不重不漏。尚未完成对象的全部事件归 R，不因方向未定而消失。

证明不要求相邻完成对象方向交替，也不要求对象原始路径单调。额外加入任一条件将改变关系，不能继续借用此证明。

## 7. 原义桥的精确边界

### 7.1 趋势计数与局部结束的条件性证明

条件 H：本 F1 的成熟平台已取得最低级别中枢资格，且其原义外缘确由该平台支持确定为 `DD_i=GG_i=c_i`。H 是尚未完成的基底语义桥，不能由命名取得。

在 H 下，每个完成对象至少有两个自有核心，严格同向。向上即 `DD_(i+1)>GG_i`，向下对称，满足 `035:16` 的最低级别计数/方向，也满足 `qushi.md:128` 的外缘分离。平台核心的点外缘与对象的全程 range 分别保存，没有混用。

首次反向成熟核心满足 `035:16` 的最低级别趋势结束条件。证据到第三事件才可观测，前平台已封口，完成确认与稳定性均有实物支持。这个局部证明不需要单核心完成或核心公用。

H 不能静默升级为事实。原文三笔成交与这里挂撤单 Q/W 观察不同；若某原义外缘必须包含平台周围波动，其外缘未必仍是点，就必须重新验证，不能只用 c_i 单调替代外缘判据。

### 7.2 同向接续的最早压力点

镜像 `10³,5³,10³,5³,10³` 给：

- M1 自有 K0=10、K1=5，Down，e1…e6，确认 9。
- M2 自有 K2=10、K3=5，Down，e7…e12，确认 15；原始路径 5→10→5。
- K4=10 留 R。

这不是以缺少 P 标签为由，而是相邻且已完成的 Down→Down。`017:60` 写“对于下跌的走势来说，一旦完成，只能转化为上涨与盘整”；`018:38` 同样规定判明下跌结束后面对盘整与上涨。均已核为作者正文、无编注。它们比任意形式化 `017:36` 的“其他类型”更直接。

如果 M1/M2 就是原文的相邻原义完成走势，关系没有给出 M1 后须有的上涨/盘整对象，却把覆盖后继事件的整份 M2 标为下跌。这是直接继承原义接续的反例。原始事件不漏，不意味着语义类型不漏。

不能直接援引结合律修补：需先构造可合法结合的原义类型及边界，不能把允许结合当作任意路径可归任意类型的证明。也不能把 M2 的入口 5→10 单独命名为上涨，它没有两个独占核心；命名盘整又回到未证的单核心完成。

第 84 课允许 F1 不同。因此此反例针对直接继承原义完成与接续，不是所有初始程序的不可能定理。若允许该原生 a1 接续，必须证明原文连接约束只在别的层成立，并说明与固定 F2 的一致关系。本轮未找到该来源。

### 7.3 不因无完成盘整或无限活动单独裁错

“输出标签来自 {P,U,D}”不要求每个输入域上三类标签都非空。OC-v1 完成集合只有 U/D，本身不能推出分类不完备。

存在无限合法 Q≡10 历史，只在 99 档循环新增/撤销辅助订单；它永远只有平台 K0。R 保留全部事件，A 一直单核心，不产生完成对象。

`018:40` 允许盘整无限延伸，`084:60` 拒绝级别生长的时间承诺，故永不发射不能单独否定其处理。`017:36`、`018:30` 的“终要完成”与无限延伸之间应区分随时可完美、实际结束事件及无限历史量词，本轮不偷选一边。

本轮也没有证明全体无限历史的原义完备性。有限前缀事件全覆盖、唯一活动尾部与原义走势分解定理不是同一命题，尾部尚无完整原义标签必须保留。

## 10. 有限的家族级推论

取交替两值成熟核心 `H,L,H,L,…`，H>L。考察这样一类候选：每份完成对象拥有至少两个连续、严格同向的自有核心，核心不能共享；从首核心起的完成前缀不漏核心、不插入另类完成对象。

交替序列的任何三个连续核心都不严格单调，所以每份完成对象恰好拥有两个。第一份只能是 H,L，第二份只能是随后的 H,L；故任何两份相邻完成对象都为 Down。相应上涨镜像 L,H 同理全为 Up。

因此，只要出现至少两份完成趋势的连续前缀，该纯趋势修补家族就会出现与 `017:60` 的直接原义接续冲突。这比 OC-v1 单一实现的短例更强，但量词只管上述有限完成前缀与上述候选家族。不要求每份尾部最终完成，不反对保留无限活动，也不否定所有可能的 F1。
