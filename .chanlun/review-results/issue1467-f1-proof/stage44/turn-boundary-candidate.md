## 1. 本轮结论及新问题

本轮给出一份不同于 v2 和 OC-v1 的完整有限前缀关系 RT-v1。它将转折极值平台核心整枚留给右对象，同时把原始事件切点前移到极值平台之前。所有真正发射的对象至少含两个独占核心，方向严格交替，真实路径与原始尾部完整保存。完成谓词直接由成熟核心的首个转折计算，没有外置完成布尔量，也不引用尚未证明的盘整完成。

这份关系有非空结果。30 事件见证给出 Up/Down/Up 三份候选完成对象，三个全路径范围的严格交集为 `[15,20]`。固定 W 下交集为 `[506/5,304/3]`。方向与严格交集满足当前 Z-3/Z-2 的数值部分，但尚未证明这些新初始对象取得原义 a1 资格，更没有证明父走势完成或全递归闭合。

代价也是关系的一部分。在首次转折前只能消费一个核心时，RT-v1 进入永久阻点，保留全部余下原始事件，不再发射对象。15 事件交替例、18 事件左吸收例、21 事件旧长例及其镜像，均在 e9 进入这一状态，完成列表均为空。允许活动尾部没有消除这个适用性代价；这些历史没有取得完整走势分解。

本轮新增的实质结果是一个可复算的分界选择及其准确代价：**整枚极值核心留右能修复 OC 的同向接续，但要同时接受“结束位置前移”和“首个单核段永久阻断”两项后果。** 第 84 课允许研究独立 F1，不代表这两项后果已经通过 a1 的语义验收。后文把待检验条件钉到具体区间，而不再泛称“语义未证”。

## 3. 不依赖执行程序的有限前缀关系

固定任意域内有限历史。成熟核心目录为 K0…K_(m−1)，可能为空；最多只有最后一个平台未成熟。若 m≥2，令

`δ_i = sign(c_i − c_(i−1))`，`1≤i≤m−1`。

相邻平台值不同，故每个 δ_i 非零。令所有已被成熟后继确认的转折索引为

`τ_1 < … < τ_r`，其中 `1≤τ_j≤m−2` 且 `δ_(τ_j+1) = −δ_(τ_j)`。

设 τ_0=0，长度 `ℓ_j=τ_j−τ_(j−1)`。这里 ℓ_j 是“把右端极值核心留给下一段后，本段剩余自有核心数”，不是事件数。

定义 k 为满足下式的最大整数：

`0≤k≤r`，且 `∀1≤j≤k，ℓ_j≥2`。

如果 r=0，k=0。如果第一个不满足条件的 j 存在，则其 ℓ_j=1，这个 j 是永久阻点；不能跳过它去选择后续较长的一段。k 是从首核心开始的连续合格前缀长度，不是任意满足条件转折的计数。

对于 `1≤j≤k`，关系唯一给出完成候选 M_j：

| 字段 | 精确定义 |
|---|---|
| 自有核心 | `K_(τ_(j−1)) … K_(τ_j−1)` |
| 类型、方向 | 核心严格同向，至少两枚，记候选 Up/Down；方向 `d_j=δ_(τ_(j−1)+1)` |
| 结束位置 | `T_j=t_(τ_j−1)`；T_0=0 |
| 自有原始事件 | `(T_(j−1),T_j]` |
| 边界状态 | `B_(T_(j−1))` 与 `B_(T_j)` |
| 实际范围 | `[min{x_u:T_(j−1)≤u≤T_j}, max{x_u:T_(j−1)≤u≤T_j}]` |
| 转折支持 | `K_(τ_j−1),K_(τ_j),K_(τ_j+1)` 的固定种子、值与 `δ_(τ_j+1)=−δ_(τ_j)` |
| 确认时点 | `β_(τ_j+1)` |

每份 M_j 的末自有核心是 K_(τ_j−1)，极值核心 K_(τ_j) 明确属于右侧。不是只把核心 ID 改给右侧而仍让左侧拥有它的全部原始事件。

完整输出为 `(C,R,K,A,P,Z)`：

- C 为 M1…Mk，T=T_k，无完成对象时 T=0。
- R 精确拥有 e_(T+1)…en，并保存 B_T。n=T 时 R 为空。R 不带同向要求，也不承诺是一份已取得原义类型的走势。
- K 为全部成熟核心目录。C 之外的成熟核心，恰为 `K_(τ_k)…K_(m−1)`；k=0 时起于 K0。
- A 是 R 内成熟核心及观察状态的只读目录，不另计事件归属。
- P 是可空的一/二事件末平台，全部事件留 R，没有为它提前造核心或转折。
- Z 是状态。没有阻点时为无核、单核或等待转折；有阻点时，保存首个 ℓ_j=1 的 a=τ_(j−1)、b=τ_j 和已观察时点 β_(b+1)，记 `BlockedThinTurn`。

`Complete_RT(M_j,h_n)` 的定义正是上述核心连续块、首转折、前缀准入、原始成员、边界和确认时点共同成立。全部量由原始已观察前缀计算。定义中没有 `Complete(P)`、外置 Bool、父中枢或将来事件，也没有将条件改名为 Boundary 便视为已证明。

这个定义同时给出程序之外的独立判定关系。脚本按首转折扫描实现它；关系唯一性由下一节证明，不能仅由程序返回唯一值推断。

### 域外与阻点是不同状态

若首次短平台封口发生在 f，F1 的定义域在 f−1 结束。诊断冻结 f−1 时的 C，保留最后完成端点后的全部事件，f…n 明标未分析。它不声称把 RT 延拓到域外。x0≠x1 也按 f=1 处理。

`BlockedThinTurn` 则发生在 D 内。它不是数据坏了，也不是暂时缺一个未来核心；转折已确认而左侧核心不足二。RT-v1 不包含重分或恢复条款，故以后的任意域内追加都不能解除它。该状态保留 R 中的所有新事件和核心，不能称“完整走势已经分解，只是暂未显示”。

## 4. 可证明的性质与准确适用范围

**存在与唯一。** 最大平台分解、核心成熟时点、δ 串及转折目录分别唯一。每个 ℓ_j 固定，首个 ℓ_j=1 的位置固定，故 k 唯一。M_j 的核心区间、事件区间、范围和支持全由它决定；零核、单核、无转折及 n=0 分支均有值。这证明有限前缀总输出关系唯一，不证明原义走势完备。

**原始成员及核心独占。** M_j 的事件区间在 T_j 处首尾相接，C 恰好覆盖 e1…e_T 各一次，R 恰覆盖其余各一次。M_j 的核心索引块首尾相接，C 的核心并集恰为 K0…K_(τ_k−1)，A 则保存剩余全部成熟核心。末自有平台已封口，因为极值平台和其后继都已成熟。核心的整个平台原始事件均在同一个拥有者内。读取相邻边界状态及后继证明种子不改变这个分区。

**每份完成对象的自有核心同向。** 两个连续转折之间 δ 不变；M_j 只去掉右端极值核心，剩余至少两个核心，故仍严格同向。条件性承认平台点核心后，其同向外缘严格分离可以直接验算。

**完成对象方向交替。** M_j 的方向为转折前的 δ，M_(j+1) 从被留右的极值核心开始，其第一边正是转折后的 δ。两者相反。这是在同一输入上的一般论证，不借旧 Segment 的交替保证，也没有重标方向。

**前缀稳定。** M_j 确认时，涉及的首转折、固定种子、全部成员平台末端及 T_j 都已确定。域内追加不能修改它们。由 j 归纳，既发射 C 始终是后来 C 的相同字段前缀。阻点同理永久存在。活动目录、R 及末开放平台可增长。

**有限停止。** 每次发射至少消费两枚核心，k≤⌊m/2⌋。原始事件尾部不因停止而消失。这里证明的是一次 F1 有限求值停止，不是 F2 塔的递归终止。

**运行段长度刻画。** 在任意有 r 个成熟转折的历史上，RT 发射数量恰是首个长度为 1 的转折段之前的转折数；如果没有该段，就恰为 r。于是，∀H>L，对于任意以 H,L,H 或 L,H,L 开头且平台均至少三事件的域内历史，C 永远为空，即使后来接任意多次长同向核心链也不会恢复。这个量词只针对 RT-v1，不能用来否定所有 F1。

此刻画是新关系的精确能力边界。它没有缩小 D，却把非空适用域压到从起点起每一段都至少留下两个核心的历史前缀。若未来研究要解除阻点，须更换具名关系并说明如何处理单核成员；RT-v1 本轮到此冻结，不追加未经审查的补丁。

## 5. 区分新完成约定与第 35 课旧结束条件

取合法 12 事件输入 `10³,20³,30³,25³`。每个数字是 Q，每个平台三次观测均由不同真实新增/撤单源事件产生。

M1 恰拥有 K0/K1、e1…e6，边界为 B0/B6，end=6，range=`[10,20]`，确认=12。支持读取 K1=20、K2=30、K3=25；K2/K3 不计入 M1 的构成。

差别不只是确认晚了。`20<30` 表明极值 K2 按 `035:16` 的原逐核心规则仍是上涨延续；25 虽低于 30，却仍高于 M1 的末自有核心 20。该课的局部反向条件针对扩展后的核心串 `10,20,30`，没有证明只含 `10,20` 且止于 e6 的那个指定对象在 e6 结束。

所以不能声称 RT-v1 完成是旧 035 证书的推论。如果坚持同一平台目录、同一最低级别逐核心最大延续算法，RT 的前移终点不符合那个算法。RT 唯一可能的正面路线是第 84 课下的独立初始完成合同，明确接受这种成员切界，随后重新证明 a1 与原义 F2 的衔接。

这一合同至少须确认下列**具名切分律**，不能只写“允许不同 F1”：

> 对上述 §3 的每个可观察首转折，允许把 `K_a…K_(b−1)` 的整个源事件区间认作一个初始层已完成对象，把仍沿旧方向的 `K_b` 和到它的入口运动整体归入右对象，并保持这些对象在原义 F2 中作为连续、完成、同级成员的资格。

RT 已给出切分律的可计算前件和独占成员结果，没有证明后半的原义资格。所欠不是一枚无法计算的 Boundary 布尔量，而是上述“提前一枚核心切界”在 a1 合同中的合法性。若该律被原义条件否定，RT 应被淘汰；若能由独立 F1 合同承接，才继续检验父级分类、完成和递归闭合。

## 7. 非空完成与父层几何见证
