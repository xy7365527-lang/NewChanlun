# Stage45 条件、记号与验证范围订正

日期：2026-10-04。绑定 #1467，研究工作草稿。两份作者报告与机器原件保持冻结。本说明依两份独评订正引用口径，不更改 RT、P/E 构造或已验证结果，不裁定原义资格。

## 1. 延伸关系与对象归属的条件不能合并

[延伸独评](independent-extension-ownership-review.md)采用带类型的量词：历史取声明域的有限合法前缀，核心索引取该前缀已成熟且具所讨论同级身份的目录；对象 X 和历史 h 不是核心索引。不同历史的实例带历史身份，表示映射 φ 对对象固定，不可为每一对核心临时另选。

EXT-rel 保存同一全目录中的外缘方向关系，EXT-own 则要求已确认、拟上送对象与独立语义实例同级、同型且完成，结束点与已知核心归属逐项相符。这里同型须保留 Up/Down 等方向类型，不能只保留“趋势”一位标志。EXT-own 本身不建立独立语义载体 S 的合法性，也不单独证明完整源事件覆盖或所有对象的构成独占。

桥 J 另行假定：原义实例 X 已有两枚同级相邻同向核心时，若下一同级核心仍按真实外缘同向，则仍由 X 承接。J 是待证的具名前提。点外缘合同 P 还条件性假定平台核取得同级核心身份并有 DD=GG=c；不能只凭核心交集是点就取得它。

因此本轮准确拒绝结论是：**P及同一目录成立时，对每份已确认且拟以上升/下降完成成员上送的 RT 发射 M，不存在 S、φ 使 J 与该 M 的 EXT-own 同时成立。** 不是仅由 P 就证明所有 S 都违反 J，也不是无条件否定 RT 原义资格。若不作完成成员上送，EXT-own 前件未成立；未发射的活动尾部亦不在否证对象中。

四核 Join/Split 只证明 J 相对于显式有限 Γ₄ 独立。Γ₄ 没有涵盖全部原文、整个历史域或固定 F₂。两种与已发射 C 核心成员相容的分格，只是 R 内未消费核心的额外语义解释，不是 RT 完整关系有两个解。

## 2. 开放平台末端与机器字段

每个平台用 `u_i(n)` 表示当前观察末端；仅在封口后使用最终末端 `t_i`。e12 时 K3=25 已成熟但仍开放，追加两次25会令 u₃ 从12增到14，不能预先把12写作最终 t₃。事件成员界限对开放核最多使用当前已知末端。已归属核心的源事件如何进入对象，仍需独立的源成员合同。

RT 拒绝证明使用的极值核 K_b 在 K_(b+1) 成熟前已封口，故其 t_b 有定义。核心对应与 J 已足以产生“既拥有又不拥有 K_b”的矛盾；端点不等式只是一项附加读回，不依赖最后开放尾核已经封口。

作者脚本中的 `EXTown` 字段主要检查完成核块是否等于某语义格，`gamma` 主要检查有序穷尽与格内同向。它们不是通用的完整 EXT-own/Γ 验证器。独评为本轮 Join/Split 另补固定 φ、类型、有限完成解释、end、源事件及 q≤n 检查，并以错误类型和错误 end 作负控制。这项补核归独评，不追称作者原断言已经执行；有限模型中的完成解释也不成为原义完成证书。

## 3. 有限端点集与区间几何载体

[外缘独评](independent-primitive-core-extent-review.md)指出：有限个非退化闭区间的并，通常含无限多个点。不能将 `S_E=∪I_j` 称为有限点集。统一采用如下记号：

- 来源原子族 `A_B(K,n)` 有限、非空，由带来源的点或闭有界区间组成；点视为退化区间。
- `T_B(K,n)` 是这些原子的端点值集合，有限、非空；原子身份、事件顺序和归属另存，不能用去重端点集恢复来源。
- 几何载体 `U_B(K,n)=∪A_B(K,n)` 可以含无限多个点；其极值与 T_B 的极值相同。
- `DD=min T_B`、`GG=max T_B`。在核心值 c 属于载体的条件下，`DD=GG=c ⇔ T_B全部端点等于c ⇔ U_B={c}`。

P 的端点集是 `{x_j:s_i≤j≤u_i(n)}`，E 的端点集是 `{x_(j−1),x_j:s_i≤j≤u_i(n)}`。这不改变原 P/E 的外缘数值、相邻共点证明、初始化前提或 W 保序计算，也不把区间内部的几何点说成实际发生过的成交/事件。

## 4. 计数、证据与结论范围

762个坐标串共有5376次平台访问；长度3至9共7种取值，合计37632次支撑检查。其中5376次是长度3基线，32256次是非零延长检查。它们不是37632次实际追加操作或互异订单历史。相邻核对为4614，P两向各2307，E的4614对均满足扩展数值式。

E的差异在出生时即存在，不是未来重绘。E拒绝旧趋势标签的结论限定于同一每成熟平台一核目录、E支撑与M-2；真正原义核心、升级以及另行重分是否可行，均未由数值式证明。P保持点外缘也只在其指定成员域内成立；候选ID不同不证明原义实例不同。

两侧证据不能混用：P下J的前件成立且与RT精确完成归属冲突；E下这些前件可消失，但RT自身多核U/D的外缘分离也消失。E不能作为同一次判断的宽松兜底，更不能反过来证明P原义合格。当前仍缺原义实例与归属证明、J对一般新F₁的原义必然性或合格反例，以及完整a₁/F₂闭合。
