# Stage46：活动前件、端点与 L1 合同的采用口径

日期：2026-10-04，绑定 #1467。研究工作草稿。作者原稿、声明锁和旧机器回执保持原字节；本说明与两份独评一并限定可继承结果，不修改教义或候选。

## 1. T43 与 J_live 不能省略的条件

[来源独评](independent-turn-sources-review.md)接受的 T43 只覆盖第43课明示的小转大场景：原上涨 X 中本级背驰未成立、仅有低级别背驰，之后形成的同级 C 与旧末核 B 分离。在所查上方分离分支中，原文直接否定旧 X 已在 C 之前完成，并将 C 接回 X。这里“本级背驰未成立”不是程序里没有找到证书，C 也须有真实同级身份与外缘；不能将平台 ID 或缺失标志代入。

T43 不是所有新 F₁ 的 J_all。它也没有把原文 C 的形成时刻自动对齐到任意构造的成熟时刻 β_C，或证明真实结束一定严格晚于 β_C。归属与同刻时点须另证。

J_live 使用独立事实 `Active_S(X,β_k)`，按作者严格解释为 X 在 β_k 仍未真实终结；若真实结束在该时刻或此前，guard 为假。它不同于未确认、候选 `¬Closed` 或尚未分配核心。

设 EXT-own 将候选结束 T_M 精确映成同一 X 的真实结束 τ_X。若已经独立证明 `Active_S(X,β_k)` 且 `T_M<β_k`，则 τ_X=T_M 与真实活动直接矛盾，**不需要再经 J_live 的归属结论**。RT12 的对应是6/9，RT30还有15/18与24/27。J_live 可以承担仍活动实例的身份承接，但不能证明自己的活动前件，也不能靠改guard解除完成义务。J_all与J_live的一般原义必然性均未由本轮证明。

## 2. 标准形式与证书点位的限域

052答疑给的是所论合法分解可经结合取得高低点标准形式，不是所有既有切分已标准化，也不是任意新F₁可保持成员与结果不变。E-NORM只在双方已声称Norm、同原边界相接、方向Up/Down的条件下要求共同极值。

E-CERT只约束借用原文某种点位完成证书且保持其语义的情况，所借证书的级别、结构与点位资格本身仍须成立。三点几何、背驰与相应级别完成不是同一命题。RT支持点晚于且异价于原结束点，阻止的是原样借用该点位证书，不否定所有独立初始完成定义。

本轮8个RT对象的自身结束极值通过只是这4份指定历史的数值结果，不是所有RT或所有完成走势的一般定理。4个已完成接点不符合原边界标准形式；未完成R没有计入该接点数。

两个30事件改切点对照只改变指定历史的边界和成员：结束改为9/18/27，仍等到原观察证据12/21/30。新三交均为[10,30]，不同于原[15,20]与镜像[20,25]。它不是已获资格或唯一的normalizer，不证明所有标准化都改变三交；它只反驳该具体改切点是保持原结果的显示修复。

## 3. DirectHull 的模型、来源与数值域

[独立冷读](direct-hull-readback.md)及[比较](independent-direct-hull-comparison.md)接受的是声明内几何合同：有限同号Flow在每个状态都有有效双边QuoteOf；Support取所有兼容事件切分见证的闭合整数spread区间；其最小闭区间外包络等于原leg范围。

Flow含模型Step和报价前提，不含行情序号、物理时间、订单ID或消息完整性字段。明确无报价、锁定或交叉的状态不能给QuoteOf；**未建模丢包却可能留下另一条合法抽象Flow**，因此不能借本定理排除feed缺口。价格是Int，数量由Step要求正自然数；不预设货币单位、正价格、FIFO或交易所适配正确性。

Support的事件参数和存在见证关联原Flow，但`Support … x`仍是价格成员谓词，不能由它恢复唯一轨迹、来源重数、顺序或订单身份。Runs/decode的来源无损是另一个命题。ExactHull只证明两端取到且全体有界，不证明每个包络内值都在Support，更不说内部价位发生过成交。

HULL包括空Flow和活动同号尾，不要求maximal或Completed；空流仍有当前spread包络，却不能据此生成非空或已完成走势。实际construct接受报价长度和可空读出，本新根未完成其每个输出到原Step/QuoteOf来源的普遍接线证明。

两事件反例属于抽象模型：第一事件索引0为bid add90，第二事件索引1为ask add110。已确认首块仅拥有[0,1)，在观察数2时确认；110只是确认事件，不属于首块。leg=[100,102]不含自有深价90，足以否定全触价/全簿范围继承，但不是实际市场采集，也不否定L1合同。

## 4. 编译、冷读与数学对应分账

作者与独立冷读各fresh编译7个本地研究模块；7个Origin formal模块由已记录源码/olean哈希的预编译产物导入，未从源码重建formal。精确根类型与semantic hash相同，根实际依赖公理仅标准三项，无sorryAx或unsafe依赖。该结论不覆盖所有导入模块中未使用的声明。

独立比较另行接受此锁定声明与本轮L1意图的对应。作者/冷读机器回执的`semantic=not_reviewed`保持历史值，不将新比较倒写进去；semantic hash只标识抽取内容。此数学对应通过也不授予原义核心、完整走势、EXT-own、F₂或实盘资格。
