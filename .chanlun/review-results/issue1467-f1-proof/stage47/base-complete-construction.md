## 2. EV-P-v1 的完整候选合同

### 2.1 有效历史、观察与原子核心

沿用 v2 的具名增撤簿协议：完整初态，唯一订单 ID，正量新增，撤量不超过同 ID/方向/价位的残量，连续源序号。保留原消息和每次事件后状态。非法残量、序号缺口或未知初态结束当前 epoch；域外后缀标明未知，不删除后拼接。此处不是交易所全部消息类型的实现。

在整个有效 epoch 固定实际最优买卖价 100/102、实际卖量 10、最优买量 `q_i>0`；观察轴为 `Q_i=q_i` 或固定 `W_i=100+2q_i/(q_i+10)`。`W(v)-W(u)=20(v-u)/((v+10)(u+10))`，所以正量域的严格次序、等值平台及有限极值保持。原始事件仍是成员，W 不是新增成交。

新域 `H_EV` 包含空前缀，非空时 `x0=x1`。**第一个最大常值平台在封口前至少有 3 个不同事件后观测；此后所有平台长度可为任意正整数。** 起始尚未满 3 次而仍未封口的前缀有效并保持活动。与旧 D 相比，新域只撤销“后续短平台封口即永久出域”；没有按失败结果删事件。它仍是明定的初始化域，不声称覆盖所有原生历史。

最大常值平台 `P_i=[s_i,t_i]` 的值为 `c_i`。已封口平台有确定 `t_i`，开放末平台只保存当前末端 `u_i(n)`。当且仅当平台已至少三观测，产生候选核心 `K_i`：

- 生辰 `β_i=s_i+2`，固定种子 `e_(s_i)…e_(s_i+2)`；整个最大平台是其事件成员。
- 候选核心及外缘均为 `[c_i,c_i]`，仅采用 Stage45 的 P 解释。短平台没有该核；不得用邻接证据替它补成员。
- 同值延长同一平台不另造核；经非等值短平台分开的两个同值成熟平台是两个候选 ID，**ID 分立不自动证明原义核心身份分立**。

为了给新候选最有利的检验，下文零核心否决甚至暂时承认所有成熟平台核已经合法；它仍然成立。故否决不依赖尚未解决的点核资格或完整 GoodΩ。

### 2.2 程序之外的有限关系

给定前缀原始平台目录 `P0,…,P_(r−1)`，令 `δ_i=sign(c_i−c_(i−1))`。**不先过滤短平台**。所有相邻平台异值，故 `δ_i≠0`。

取全部且仅取满足 `1≤i≤r−2`、`δ_(i+1)=−δ_i` 的转折索引，按顺序记 `τ1<…<τm`。令 `p0=0`、`p_j=t_(τj)`。每个转折必须产生一个封定的候选片段 `M_j`，没有“第一个薄段后永久停机”分支。

| 字段 | 定义 |
|---|---|
| 事件成员 | `OwnEv(M_j)={e_u:p_(j−1)<u≤p_j}`；唯一归属 |
| 状态与真实范围 | 共读 `B_(p_(j−1))`，取 `x_(p_(j−1)),…,x_(p_j)` 的 min/max；不复制前一事件 |
| 自有核心 | 所有且仅有平台整体落在 `(p_(j−1),p_j]` 内的成熟 `K_i` |
| 路径方向 | `δ_(τj)`；仅指该单调路径的方向 |
| 类型候选 | 自有核恰 1 为 P；至少 2 为 U/D，按路径方向；0 为显式 NoCore |
| 概念方向 | U 为 +，D 为 −；P、NoCore 为无。路径方向另存，不能填成 P 的概念方向 |
| 连接 | 相邻片段共用状态 `B_(p_j)`；中间每个原始事件都在其中一片段，零核片段不得跳过 |
| 发生端点 | `end(M_j)=p_j`，取该极值平台最后一次事件后状态 |
| 可知/确认 | `q_j=p_j+1=s_(τj+1)`：首次看到反向后继事件，才知道该极值平台已封口且前后符号相反 |
| 证明支持 | 前平台、极值平台的已封定值与区间，以及后继首事件和值；相邻证明可重叠读取 |
| 发布 | 不早于 `q_j` 的实际接收可知时刻；探针无额外延迟，明确记录同一接收时刻为确认和发布 |
| 活动尾 | 最后边界后全部事件 `(p_m,n]`，保存共享起态和全部成熟/短平台目录；m=0 时保留全部历史 |

完成候选谓词是上述关系字段全部成立，**没有外置 `Completed:Bool`**，也不引用父核、父完成或将来事件。发生时刻与第一次可知时刻分别保存，后来的确认不回标为端点当时已知。

候选原本拟接受的强命题为：

`EV-A1：∀h∈H_EV，所有上述已封定 M_j 都是可连续上送的完成 a1。`

零核时程序保留 NoCore 是诊断的诚实性；它并不把 NoCore 改称完成走势来“满足” EV-A1。`EV-A1` 与“关系总有唯一原始分块输出”是不同命题。

### 2.3 一般关系性质与其限度

平台分解和全部符号变号位置被原历史唯一确定；“每处变号必须切、其余不得切”给唯一边界串，再逐字段给唯一对象和尾部。这是独立关系的存在唯一论证，不由确定性程序代替。

相邻转折之间的原始非零增量同号。故每一片段的端点确为其完整路径低/高点；相邻反向片段的公共点确为共同极值。区间 `(p_(j−1),p_j]` 严格不交，与尾部构成全部事件分区；核心平台整体只在一个区间内。支持窗口重叠不改变这项成员归属。

每份片段在后继首事件到来后，平台末端、前后符号、成员、核数、类型和支持均已封定；追加有效事件不能修改它们，已封定列表是以后列表的字段级前缀。有限求值最多有 `r−2` 个转折，故终止。**以上证明的全部是候选关系性质，未证明原义完成、完整 F2 分类闭合或递归塔终止。**

在原 D 的全成熟平台历史上，新候选与 v2 的端点/核心归属相同，但确认提前到首个反向事件；v2 等到后继平台第三事件。新候选的真正新风险是：未成核的短反转已经触发封定。

## 4. 八事件反例与确认延迟不变性

更强的 `10³,20³,10,20` 先形成双核 U，避免把问题归咎于首份 P 的完成争议：

| 输出 | 事件 / 核心 | end / confirm |
|---|---|---|
| M1=U | e1…e6 / `{K10,K20}` | 6 / 7 |
| M2=NoCore | **仅 e7** / 空 | 7 / 8 |
| R | e8 | 活动 |

初态与前六条操作同样逐订单合法；完整流在 `results/examples.json:priorTrend8`。两枚不同自有核至少占六事件，后面的零核片段至少占一事件，再至少一事件确认它，因此最少八事件；样例达到下界。

**延迟不变性定理。** 对任何以后前缀 `h_N`，若 M2 的成员仍严格是 `{e7}`、核心定义仍要求三份不同成员事件，则 M2 永远没有自有核心。把确认从 e8 延迟到 e10、e100 或任意以后位置，都不能改变这个计数事实。e8…e10 后来产生的新核属于右侧事件，不能回填给只拥有 e7 的旧对象。

探针对 `10³,20³,10,20³` 做到 e10 的直接检查。一般结论来自成员集合大小证明，不是由这一次延长试验概括。

v4 允许把 e7 保留成 NoCore 或活动结构；这不会违反 v4。但如果仍把该一事件区间称为已完成 a1，或跳过它让左右对象假相邻，则分别违反核数或真实连续成员合同。

## 5. 自然合并究竟改变了什么

在上述八事件例，M1 已在 e7 确认。到 e8 才明确第二极值段零核：

1. **向后合并 M1+M2** 将原 end=6 改成 end=7，成员也增加 e7。它撤销了 e7 已发布的完成边界，不是单纯推迟 M2 的确认。若从一开始只保留未确认候选，允许这样改，则是新的完成关系。
2. **向前合并** 可以保持旧 M1，但必须从一开始不把零核 raw leg 封成完成 a1；否则也要撤销原来的 M2 封定。本轮只测试局部必要条件，不把这种合并宣布为修复。

具体扩展流 `10³,20³,10,20³,10³,20³` 中，固定旧边界 e6 后：

| 试分区 | 自有核心 | 共读入口→结束 / 完整范围 | 实际说明 |
|---|---|---|---|
| 合并其后 2 条 raw leg：e7…e10 | `{20}` | 20→20 / `[10,20]` | 核数缺口消失，但这已不是严格方向单调腿；P 本无方向，不能仅因端点同价判 P 非法，也不能直接继承 EV 的路径方向/Z-3 证明 |
| 合并其后 3 条 raw leg：e7…e13 | `{20,10}` | 20→10 / `[10,20]`，后继 e14 可见 | 这份试区间满足核数、核心向下、共同极值和成员独占等局部必要条件，保留旧 U；**尚无独立完成证书或完整 a1 资格** |
