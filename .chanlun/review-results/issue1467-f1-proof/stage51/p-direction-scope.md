## 1. 对象与量词先固定

令 `X^k=[s,t]` 是一个待检验的 k 级走势对象。`x_s…x_t` 为实际完整来源状态，`R(X)=[min x,max x]`。下面五种东西不同：

| 名称 | 对象及含义 | 本轮能使用的地位 |
|---|---|---|
| 概念方向 `χ(X)` | 趋势的同向中枢链给 U/D；P 没有这项方向 | `031:386` 的作者答复与当前 `qushi.md:200,209` |
| 表示或遍历方向 `δ(X;w)` | 一份具体有序表示及见证 w 的上下运动 | 必须定义、重算并另证适合 Z-3，不能把它改称概念方向 |
| 类型下标 `P^U/P^D` | 程序对 P 的额外索引 | 下标本身不产生见证；改名不把 P 变成趋势 |
| 核形成方向 `η(C)` | 形成某个核心的初始三单元的回升/回调方向 | 是核心 C 的形成角色，不能直接成为含 C 的整个 X 的方向 |
| 初始构件的方向 | F₁ 使用的线段、订单腿等构件的方向 | 构件交替不推出完整 P 对象的任意方向字段交替 |

`Complete_k(X)`、`kind(X)=P`、`δ(X;w)` 是三份不同义务。“若完成则恰一核，故分类为 P”也不能被缩写成已经得到 `Complete_k(X)`。

`084:52–56` 把初始构造 `f₁(a₀)=a₁` 与后续递归 `f₂(a_n)=a_(n+1)` 分开。允许改变初始函数，并不把初始构件直接赋予完整次级走势的角色。`035:14–24` 的递归中，三份下层走势类型与其经过的完整价格区间是输入对象；“层号填 k”或“核生成腿有方向”均不能代替该角色。

## 3. 029 的 P/P 到底围绕谁

### 3.1 原问答与带层级的关系

[029:340–362](/Users/silencehan/.codex/worktrees/order-event-base-research/NewChanlun/docs/chanlun/text/blog/029-第29课.md:340)的作者块在340，提问者在342。358明确问“离开和返回中枢的两个次级盘整走势”，360是答复分隔，362回答三买前提与后一个盘整不回“前面中枢”。356是编注，本稿不采用；364是下一作者块，不用作本答复署名。

采用问题自身指定的对象，有：

```text
既有中枢 C^(k+1)，核心区间 [ZD_C,ZG_C]
       │                         │
       │ 向上离开               │ 回试且不回 C
       └──── L^k = P ──────────── R^k = P
             │                    │
             自有核 A^k           自有核 B^k

判断所比的是 R^k 的低点与 C^(k+1) 的核心边界。
它没有改成 R^k 的低点与 A^k 的核心边界。
```

L、R 是彼此同级的两个 P，同时是 C 的次级走势；“次级离开/回抽”与“两个同级 P”这两种描述本身并不冲突。**错误发生在把参照中枢 C 换成 L 的自有核 A。** `level(C)=k+1`，`level(A)=k`，不能因为它们都在时间上“前面”就识别成同一对象。

作者答复没有逐字重标 C 的层号，但它正面回答358的问题，没有引入另一座中枢、也没有宣布更换问题对象。这是本稿关于代词的上下文判读；018:64 的中枢破坏定理与020:60的三买结构进一步固定了该角色。它不是根据旧报告的对象命名反推原文。

### 3.2 原文支持的条件命题

以严格不回核心的数值情形避免触边争议，可以写：

```text
Center_(k+1)(C)
∧ Complete_k(L) ∧ Complete_k(R)
∧ kind(L)=P ∧ kind(R)=P
∧ L、R依次担当C的合格次级向上离开与回试
∧ ThirdBuy_C(L,R)
  ⇒ 此处不能继续按C的延伸解释。
```

三买、不回 C 和 Z 段指标必须指同一 C。原文362给的是这一带语境的澄清。它不能被扩大为下列任何命题：

1. 任意相邻同级 `P₁,P₂`，都要求 `low(P₂)>ZG(OwnCore(P₁))`。
2. 任意 P/P 都合法或都非法。
3. 任意 P/P 若没有原中枢 C 的具名三买证据，就已经证明它不可能完成。
4. 后一个 P 没回前 P 的自有核，就已取得固定自然 F₂ 的完成或方向资格。

还应保留一个源义张力：`018:66` 将破坏中枢的两个次级走势组合列为三种而没有 P/P；029 是后来明确限定三买语境的答复。把029视为对此讨论的限定/澄清，足以要求按具体角色重审；它没有交付“一切 P/P 皆可构造”的存在定理，也没有给一项对任意输入可执行的 P/P 完成算法。本稿不在这两行之间替教义作新裁定。

### 3.3 035、038、033 分别约束不同角色

`035:20–28` 以5分钟和30分钟展示“单个下级走势”与“三个下级走势连接构成一个上级走势”的区别。因而一个 `P^k+P^k+P^k` 被整体分析为高一级 P，不等于每个 P 自身含高一级中枢，也不等于二者可在同一固定级别混称。

`038:18–28` 先指定固定操作级别的同级分解。在该分解中可关闭本级延伸/扩展，把六段次级过程读成两个本级 P；其下级可以继续允许延伸，其上级则不在此操作视图内。量词是“存在/选定这种分解规则后”，不是“任意递归分解都可用 P/P 作为上送输入”。`038:36` 的上下交替还具有从背驰点开始、按相应内部结束点连接的操作前提，不能缩成给已有任意分段补符号。

`033:192` 是读者明确提出三个5分钟 P 对应30分钟中枢的问题；`033:196` 的作者答复强调“加多了”后的盘整级别会变。它排除把 P/P 的类型标签当作级别不变的代数闭包律，却不单独证明每个任意三 P 都形成上级核。`033:30` 允许围绕同一中枢的连续同向离开，所说的“离开方向”也不能直接替代完整相邻次级走势的 Z-3 方向。

## 5. 各种方向候选保证什么

以下都在保留完整源状态、完整 range 的前提下定义，0与未定义均不自动转为U/D。

| 候选 | 可检验关系 | 实际保证 | 不蕴含 |
|---|---|---|---|
| 端价净号 `δ_net` | `sign(x_t−x_s)` | 两个端点的净变化；可能为0 | P概念方向、完成、相邻交替、两端是全域极值 |
| 首个严格方向 `δ_first` | 忽略相等状态后的首个非零增量 | 初始局部运动 | 整段净方向、末方向、Z-3 |
| 最后严格方向 `δ_last` | 最后一个非零增量 | 末端局部运动 | 整段净方向、概念结束或Z-3 |
| 核形成方向 `η` | 自有核实际生成三腿首向 | 核初始形成的方向 | 含该核的P方向；连接腿并入后仍同向 |
| 首次/末次全域高低点顺序 | 比较所选极值发生时刻 | 该选点约定下的时间先后 | 极值重复时的唯一选择、实际端点资格、完成 |
| 全部极值一致顺序 | 所有低点早于所有高点，或反之 | 避免首/末选点歧义 | 端点就是两极值、三片交替或合法P |

例如连续路径片 `[0,4,1]`、`[1,5,2]`、`[2,6,3]` 三交为 `[2,4]`，净号与全部极值顺序都为 U/U/U，首向也是U/U/U，末向D/D/D。它反证这些**数值条件单独**保证交替的命题。它没有自带原义中枢和完成证书，所以本稿不把它宣称为原义三完成走势的反例。

## 6. 可证明的条件桥：标准端点表示

对固定、连续、共享实际端点的三片 `X₁=[t₀,t₁],X₂=[t₁,t₂],X₃=[t₂,t₃]`，定义 `Std(X,δ)`：range有正宽度，且实际首末价分别为其完整range的两端，U按低→高，D按高→低。

**引理 SB。** 若三片分别满足 Std，且三个完整range的交集有正宽度，则三个遍历方向必为U/D/U或D/U/D，并且三交等于第一、三片的range交集。

**证明。** 若两个相邻片都向上，前片range为 `[x_(i−1),x_i]`，后片为 `[x_i,x_(i+1)]`，二者交集只有共享端价 `x_i`；都向下同理。正宽三交包含在每对相邻range交集中，因此相邻不能同向。二元方向下即得到交替。以U/D/U为例，中间range为 `[x₂,x₁]`，第一、三片交集的下界不低于x₂，上界不高于x₁，故该交集已经包含于中间range；D/U/D对称。证毕。

这个引理完全是有序实数与连续分段的普通证明，**无需假定P拥有趋势概念方向**。若以后给三份原义完整P提供同一合法分解下的 Std 证书，`δ` 可作为有源状态证明的表示方向。它还解释了020公式化简需要的共享高/低连接点。

但是 `052:310–328` 作者回答的是通过结合律可归入相应标准形式，不能改成“所有已经冻结的分区都标准”，也不能改成“在固定当前目录、成员、前缀和不可撤销发布条件下，总有一个保持它们的在线标准化算法”。这是从 `∃合法重分` 到 `∀当前切分` 的量词差别。它也没有凭几何给未完成片段完成证书。

因此可供后续研究的桥合同是：

```text
原义Complete_k三孩子 + 同一合法相邻分解
+ 保留/明确重分来源与真实range的Std见证
+ range严格三交
  ⇒ 有证据的二元遍历方向交替。
```

将“这份遍历方向就是Z-3所要求的方向”正式接到 P 的上送接口，仍需教义/接口层确认其适用范围。引理已经证明的是右侧几何事实，不替现有正本补一次未发生的裁定。另一方向也不成立：已有δ交替并不反推Std、完成或P资格。

q:    1040 1040 1000 1030 1010 1140 1100 1130 1110 1140 1135 1138 1136

两组仍只是 `kindIfCompleted=P/P/P`。来源K0/K1/K2的原义中心资格也没有因重算被额外认定。实际方向为：

## 8. 相对数值交集H的穿越见证

另检一个比任意补字段更具体的关系。先算三片真实range交集 `H=[L,U]`，仅称数值交集，不称原义父核。定义：

```text
UpWitness(X,H)   ⇔ ∃ i<j 属于X源状态，x_i≤L 且 x_j≥U。
DownWitness(X,H) ⇔ ∃ i<j 属于X源状态，x_i≥U 且 x_j≤L。
Cross(X,H) ⊆ {U,D} 为具有实际见证的方向集合。
```

由于每片完整range包含H且H有正宽度，有限路径必有一个方向的穿越见证：取一个达到片内最小值的时刻和一个达到最大值的时刻，比较其先后即可。它可能两个方向都有。这是**相对H的关系**，不是每个P自带的唯一函数。

| 分区与H | 第一片 | 第二片 | 第三片 | 交替选择全集 |
|---|---|---|---|---|
| `0→5→8→12`，H=`[1110,1140]` | `{U}`，如B0→B5 | `{D}`，如B5→B6 | `{U}`，B8→B9 | `{(U,D,U)}` |
| `0→5→9→12`，H=`[1135,1140]` | `{U}`，如B0→B5 | `{D,U}`，如B5→B6及B6→B9 | `{D}`，B9→B10 | 空 |

程序穷举片内全部有序状态对，并穷举三集合所有选择，不依赖表内只展示的一组见证。第二行第一片只能U、第三片只能D；任何长度3的二元交替串首末相同，因此无解。镜像对应 `{D}/{U}/{D}` 与 `{D}/{U,D}/{U}`，结论相同。

**它保证什么？** 一次真实的相对H的上下穿越，并可具体判定是否有交替选法。Std保证其自身遍历方向属于Cross，并由SB取得一个交替选择；但Std允许内部往返，不能进一步声称Cross是单元素集合。例如标准U片`0→3→1→4`相对H=`[1,3]`同时有两向穿越。

**它尚不保证什么？** 020的Z段按既有核心形成方向选取，不是明文把任意片内一次跨越定义成完整次级走势方向。035的真实range、052的标准重分、038的具名分解也没有直接证明此关系等价于Z-3。该关系会随所检父候选H改变，且同一片可有双向见证；若将它作为F₂接口，需要证明这种父候选相对关系符合所需语义，并给双向选择、跨窗口一致性与重分后的处理规则。不能在查无桥时用存在穿越的宽关系接管原方向判据失败。

因此第一份分区的“交替穿越成立”是一个有用、可复验的新必要候选事实；第二份在该候选关系下被数值排除。两者均未获P完成、原义父核或递归闭合。
