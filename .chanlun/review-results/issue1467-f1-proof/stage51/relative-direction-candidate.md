## 2. RDW-v1 的对象与判断

设一份有限路径为 `x₀,…,xₙ`，三个片段由 `s₀<s₁<s₂<s₃` 给出。片 r 的独占事件是 `(sᵣ,sᵣ₊₁]`，价格支撑是包含两端的真实状态 `x_(sᵣ),…,x_(sᵣ₊₁)`。这允许两片共读同一边界状态，不重复消费边界事件。

先取每片完整范围 `Iᵣ=[lᵣ,uᵣ]`，算数值带

```
H=[L,U]=[max(l₀,l₁,l₂), min(u₀,u₁,u₂)]，要求 L<U。
UWᵣ(H)={(i,j): sᵣ≤i<j≤sᵣ₊₁，xᵢ≤L，xⱼ≥U}；
DWᵣ(H)={(i,j): sᵣ≤i<j≤sᵣ₊₁，xᵢ≥U，xⱼ≤L}。
Dᵣ(H)={U:UWᵣ(H)非空}∪{D:DWᵣ(H)非空}。
S(H)={d∈D₀(H)×D₁(H)×D₂(H):d₀≠d₁且d₁≠d₂}。
```

每个见证保存实际全局状态索引、q/W 数值及该点可用时刻。条件只有不等式，**没有虚构一笔恰好位于 L 或 U 的订单、成交或插值状态**。H 此时只是全部 range 的数值交集；尚未声明其原义成核。程序也不读取 `父已成立` 来决定见证。

该定义构造的是依赖三片范围的**关系**，并非给每份 P 永久加一个二值属性。同一 P 对不同 H 可以有不同见证集合；§6 给出实际例子。若原义接口要求一个与邻居无关的方向，须另证这种关系怎样满足该接口。计算上没有读父成立布尔值，不能据此推导语义上已经没有循环。

对真正有 U/D 概念方向证书的对象，兼容约束可另写为 `D_cert(X,H)=D(X,H)∩{概念方向}`。**本轮不将此条件冒充已裁规则，也不实际启用它**：输入没有原义 U/D 证书，手填 `type=U` 或旧候选签发不算证书。其是否应当成为完整桥的必要条件，是后续源义问题。P 的 `conceptDirection` 始终为 null；双向遍历也不改变此项。

## 5. 三种局部结果与普通证明

**每片方向集合非空。** 假定有限非空路径范围包含严格带 H。取实际全最小值点 i 与全最大值点 j；二者数值不同，所以 i≠j。若 i<j，则 `(i,j)` 满足 UW；若 j<i，则 `(j,i)` 满足 DW。这个证明只保证每片至少一种见证，不保证三个集合之间存在交替选择，§4 就给出三个集合全为 {U}。

更强地，固定一对按时间排列的全最小/最大实际点，它会给**该路径范围内每个严格子带同一种方向见证**。若全极值重复，可以两个方向都存在。不能任取 First/Last 极值后把其方向宣称唯一。也不能从每片各有一个贯穿全部子带的方向，推断三片自动交替。

**局部解集完全刻画。** 二值三词交替当且仅当该词是 UDU 或 DUD，故

```
S≠空 ⇔ (U∈D₀∧D∈D₁∧U∈D₂) ∨ (D∈D₀∧U∈D₁∧D∈D₂)。
```

这给存在/无解的充要条件。恰一个析取支成立时方向词唯一；两个均成立时恰有两个方向词，也恰好要求三片均为 {U,D}。最多两个词，不是最多两个点对证书。固定方向词 d 的证书数是 `|W₀(d₀)|×|W₁(d₁)|×|W₂(d₂)|`；所有集合有限且各点对都保留，笛卡尔积给全部证书。此处程序的确定性只是枚举的实现性质，不是语义解的唯一性。

**双解实物。** 路径 `0,10,0,10,0,10,0`，切点0→2→4→6，每片都是 `[0,10,0]`，H=`[0,10]`，每片都有先低后高及先高后低。UDU、DUD 均成立。加1000后用六条单ID add/reduce 消息合法实现，见 [two-selections.json](direction-evidence/results-v1/two-selections.json)。这是对程序“不暗选唯一”的正控制，无走势资格声明。

**严格递增坐标变换不变性。** 设 f 在所有源值及数值端点上严格递增。有限最小、最大与 f 交换，所以每片的新范围为 `[f(lᵣ),f(uᵣ)]`，新的共同数值带为 `[f(L),f(U)]`，仍严格。对任意实际点对，`xᵢ≤L ⇔ f(xᵢ)≤f(L)`、`xⱼ≥U ⇔ f(xⱼ)≥f(U)`；下行亦同。索引顺序未变，故全部 UW/DW 点对、D、S 以及点对证书笛卡尔积逐一保持。此证明不要求连续性：说的是变换后有限极值的包络，**未声称 f 的整个区间像等于一个区间**。严格递减 f 则把 H 换成 `[f(U),f(L)]`，全部 U/D 对调，解数和证书数保持。

对 Q>0，若 q₂>q₁，则

`W(q₂)−W(q₁)=20(q₂−q₁)/[(10+q₂)(10+q₁)]>0`。

因此 Q 与 W 的全部见证相等是一般代数结论，有限代码核对是其本次实现证据。探针用 BigInt 分子分母交乘核80事件两份41状态中的全部有序值对，共3362次比较；无浮点相等容差。

这些命题只谈具名数值关系。来源、原义核、完成、同级与 Z3 适用性不会由坐标保序自动传递。

## 6. RDW 与端点、核形成方向均不同

端点净方向取 `sign(x_t−x_s)`；“首末严格增量”取 `x_t>x_s`，就是前者的向上分支，不是另一份语义证书。二者都只读首末。RDW 读全路径及 H，允许同一片双向。

一个实际区分例是三片 `[0,10,5] / [5,10,0,6] / [6,0,10]`，连续全路径 `0,10,5,10,0,6,0,10`，切点0→2→5→7。所有端点严格增加（0<5<6<10），净方向 U/U/U；三片全范围都 `[0,10]`，RDW 却为 `{U}/{D}/{U}`。中片先达到最高10，后到最低0；最后6不足以给覆盖 `[0,10]` 的上行见证。正平移后的合法七事件及精确结果见 [net-direction-mismatch.json](direction-evidence/results-v1/net-direction-mismatch.json)。

“形成方向”本轮仅作具名诊断 η：所拥有冻结 RC49 核的实际形成三腿首向。从 K0、K1、K2 的真实支撑压掉零增量，分别都得到 D/U/D，η 均为 D；脚本重算后才与 `startDirection=Down` 对照，没有把字段自身当证明。因此第一分区的核形成诊断为 D/D/D，RDW 为 U/D/U。η 描述候选初始核的几何形成；不是整个 P 的概念方向，也未证明是原义 Z3 所需方向。并行源义工位关于原文角色的判断是协作输入，不计对本稿的独评。

**H 依赖的具体代价。** 同一全路径 `[0,10,5,8]` 对其全范围带 `[0,10]` 只有 U，而对内含带 `[5,8]` 同时有 U/D；D 由实际10→5见证。精确结果见 [band-dependence.json](direction-evidence/results-v1/band-dependence.json)。缩窄 H 只会增添或保留见证：若 `[L′,U′]⊆[L,U]`，旧上下不等式必推出新不等式。但 RDW-v1 的 H 已固定为完整三交，**不得为了救无解人为缩窄 H**。若更换邻居、切点或 range 导致 H 改变，应记为另一个输入窗口；不能把旧方向留作稳定对象属性。

本轮不使用 `029:362` 证明前一 P 的自有核约束。该处被离开的 C 的层级和两个 P 的关系由源义工位另查；未将其塞入 RDW 前提。

## 7. 可用时刻和未闭合义务

RDW-v1 没有自读“父已成立”，只证明了一个无该布尔依赖的数学构造。它仍待回答：为何相对**候选** H 的往返能承担 Z3；同一片参与不同窗口时的相对方向是否合乎原义；对真实 U/D 是否必须受概念方向限制；三 P 何时完成且确在同级序列连续。随后还须交付父实例的完整成员、延伸/新生、分类、完成及下一层同合同闭合。

因此本轮可以接受为待审数学结果的是局部关系、具体解集、几何蕴含的反例及保序证明；不得报告 P-Z3 桥已补齐、完整 F₁/F₂ 成立或市场价值为正。下一步只有获得方向语义及完成关系的新可检验证据，才能把它推进成合法输入；给字段换名字或让“不查方向”的入口接管无解均不能推进。
