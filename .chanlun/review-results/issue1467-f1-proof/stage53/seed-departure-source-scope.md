## 2. 018 的两条规则如何兼容

`018:24` 解决 C 的构造前提；`018:64` 解决合格 C 的破坏关系。单读这两句，不能仅由汉语“离开”推导精确索引条件 `L.start > C.knownAt`。第61课补的是同一次合格分解里的**对象位置**，其最低长度的模式是：

`X₁ + X₂ + X₃ + L + R`，其中 `C=Core(X₁,X₂,X₃)`，L和R是后面的第四、第五个次级对象。

因此没有必要让第三段尚未完成时先造一个原义中枢供它离开。C的形成位置在第三段完成端点；一个后来结束的第四段可从此端点出发。获知第三段完成可能稍晚，离开段的真实起点可以早于该获知时刻。**顺序约束落在构成对象的源区间，不落在电脑何时得到完成证书。**

这里不把“至少五段”解释为任何中枢都只能有三段、或破坏总由整段历史中的第4/5段实施。若前面已有延伸，破坏可能更晚；本稿只需要并证明最低三段种子的第三成员不能在同一证书中占据后续离开角色。所有延伸成员能否承担其他证据角色，不由这一最小判例一概裁完。

`101:20` 的正文直接给“第三类买卖点就是中枢破坏点”。本仓 [S-3裁定](https://github.com/xy7365527-lang/NewChanlun/issues/812#issuecomment-5148740332) 与 `.chanlun/definitions/zhongshu.md:300–316` 明确采用这一等价。因此在本轮的**同一中枢、同一级别、已完成的原义次级 L/R**假设下，不能逃开061的角色条件而说“我不叫三买，只叫018式原义Break”。若 `BreakΩ` 只是新 F₁ 的数值内部事件，则它尚未进入上述等价的定义域，可以另存，但不能借其名字取得 S-3 身份。

## 4. 可检验的条件命题与四个时间

**命题 S53-S1，固定种子身份下的四对象否定。** 设层级为 k，D是合法的同一 `(k−1)` 级分解；相邻非空已完成对象 Xᵢ 具有来源区间 `(tᵢ₋₁,tᵢ]`，`t₀<t₁<t₂<t₃<t₄`。C的身份绑定 X₁、X₂、X₃，且这三者的真实范围有合法核心。给定 L=X₃、R=X₄，即使数值上L穿过C的边界、R严格留在该侧核外，`(C,L,R)` 也不能作为C的原义三类点证书；按S-3同样不能作为C的原义破坏证书。

**证明。** 061要求支持同一三类点的分解至少有种子三项及其后的离开、回抽两项。此候选保留种子身份，L的来源是第三项 `(t₂,t₃]`，不是第三项之后的第四对象。把它列两次只有四个不同源对象，并且角色顺序错误；只列一次又缺一个离开对象。原文的70–73/74正给出同型否定。L的数值越界不能改变其对象位置；后续再追加X₅也不能把已指定的X₃变成第四项。由101:20及S-3，否定传至同身份的原义Break。证毕。

这是 `[新缠论:推论]` 的条件化表达，前提中的原义资格必须独立成立，不能用本命题反向认证原始腿。它不要求**严格**时间间隙，允许第四段的起点等于第三段的终点；也不声称原文给出了电脑事件编号。

需要分别记录：

1. `start(L)=tL⁻`、`end(L)=tL⁺`，整个次级对象的源区间。
2. `exitObs(L,C)`，在实际观察网格上第一次越过核边界的状态时刻。离散跳变只给事件序号，不插值出未观测成交。
3. `formed(C)=max occurredComplete(Xᵢ)`，构成前提在对象史上齐备的位置。在“完成发生于对象终点”的约定下为t₃。
4. `known(C)≥max knownComplete(Xᵢ)`，在线足以认识这份构造的时刻；在没有额外检查延迟的纯三成员构造中取该最大值。

原文给完成前提和对象次序，没有给所有市场数据模型统一的 `knownComplete` 算法。上述时间字段是本研究的显式信息合同。Z-6不设中枢候选态，也不能消灭下层对象本已有的“发生/获知”差别；此处不另加中枢等待阈值。

**可行顺序的必要检验**可以写成 `end(X₃)≤start(L)<end(L)≤start(R)<end(R)`，在相邻对象上相应端点相等。其价域离开/回抽角色与原义完成是另外的门。此式不是原文穷尽算法，更不是只要满足它就签发三类点的充分条件。

**反证“开头必须晚于获知中枢”的小例。** 令第三段端点为t₃，完成证据到κ₃>t₃才出现；合法第四段从t₃起。于是 `start(L)=t₃<known(C)=κ₃`，但它完全符合前三段/第四段的角色次序。Stage52主例的原始时钟实际呈此形状，见下一节。因此 `start(L)<known(C)` 本身不能判非法。

**反证“实际越界晚于形成即可授权”的小例。** 六事件里把L取为X₃时，实际观察越界在它的末事件，恰与假定形成端点相等。这通过 `exitObs≥formed` 这一弱时间条件，却违反S53-S1。所以只检查越界时间也不足以补角色。依赖图无环同样只解决计算顺序，不解决对象资格。

## 6. 原文给出的重锚路线及其在本诊断中的边界

第61课不止排除一个身份，还给出较早的合法归属。在同一原始走势中，**只把来源窗口向前移一条对象**，相同L/R可以从“种子末项+后项”变为“种子之后的第四/第五项”。这一启发可以精确检验，不能只改C的ID。

**条件重锚命题 S53-S2。** 若在X₁之前另有一个已完成同级对象X₀，且 `(X₀,X₁,X₂)` 构成合法中枢C′、L=X₃从C′离开、R=X₄是其合格首次不返回回抽，则本来的L/R不再受S53-S1针对C的排除。由018/020及S-3可以对**C′**申请原义破坏资格。C′须有自己的完整来源、级别、核心、成员及形成/可知时间。不能把这份新证书仍写作原来C的证书。

如果C′与C的数值核心碰巧相同，判定仍须保留来源身份；一个区间值不足以确定“它是谁的三类点”。037/027还要求，重锚后不能在同一消费表达式里把两枚共享X₁/X₂的中枢同时当作互斥组成项。比较候选分解或留下历史证据，不等于同一列表同时消费。

当前六事件从B0初始化，没有给出X₀的源事件或完成证据，故不能直接使用S53-S2。若在B0之后向右移三段窗口，下一候选 `(X₂,X₃,X₄)` 的数值三交为空 `[111,110]`；再下一窗口 `(X₃,X₄,X₅)` 的数值三交是[111,112]，但到e6之后的第六腿尚未封定，尚无这个新种子之后的完整L/R。上述只是本数据的有限查验，不是禁止未来重构，也不是由有交推出原义中枢。
