## 普通数学论证

以下结论量化[合同第 7 行](candidate-evidence/contract-v1.md#L7)规定的**任意非空有限精确实数状态序列**及其按规则导出的腿，不量化任意人工腿表。审阅依据为[普通证明](candidate-evidence/ordinary-proofs-v1.md)第 7–82 行，归纳和几何推理可独立完成，不依赖枚举。

| 命题 | 核验要点与结论 |
|---|---|
| 关系内存在唯一、终止 | 初始平台归首腿、转向前平台归旧腿消除平台归属歧义。三窗候选及最小起点有限且唯一；上离/下离/触闭核互斥穷尽；触核及成功后游标严格增加，坏角色与缺对立即停止。单值步归纳成立，包括单状态、全等值及空输出。通过。 |
| 最终成员连续与 seed 永留 | 未触核时 `j=s+3,H=[s,s+2]`；已触核时 `H=[s,j]`。成功时两种情况均给 `M=[s,j−1]`。因 `j≥s+3`，三 seed 保留且 `memberEnd=L.start`。只有曾入 H 的非 seed L 才产生释放记录。通过。 |
| MemberConflict 不可达、事件覆盖 | 下轮从旧 R 起扫且其起点为旧切点 b，故 `b≤memberStart≤memberEnd=L.start<L.end`。X 的 `(b,L.end]` 包含 M、完整 L 及跳窗前事件；各次 X 与末尾 tail 连成 `1…n` 的不重不漏分区。证书读取 R 与后继拥有 R 是不同关系。通过。 |
| 确认因果、已发稳定 | 全部依赖腿已封，且最终 R 的封定时刻最晚；`R.knownAt` 是合同内发布时间，晚于事件切点。追加无法改变已封腿、已拒早窗、已选 seed、触核记录或首外离对，故已发证书逐字段保持。BadRole 不能靠追加绕过。发展态 H 与尾部未被误称稳定终值。通过。 |
| 与 C53 同切点/时序/停止 | 两关系 seed、起扫、步长、外离角色和下轮游标相同，C53.members 等于 D54.H；两者成员包含门在此域均不会失败。归纳给出同一发布投影，成员差异仅为成功时排除曾吸入的 L。通过。 |
| 触核后 BadRole 不可达 | 此时 L 即前一次触闭核的 R。若现 R 全在上侧，则 L.end>hi；L 向下会使 L 全在 hi 上方，与它触核矛盾，所以 L 向上且 L.start≤hi；R 因交替向下。下侧对称。仅首次候选仍可坏。通过。 |
| 释放外缘精确式 | **须有 L 曾入 H**。M 末端含 L.start，弱单调 L 只额外贡献末值 v，故 `C.outer=developmentOuter=hull(D.outer∪{v})`。首次 L 不在 H 时直接 `C.outer=D.outer`，不能无条件附加 v。通过。 |
| 严格收缩充要条件 | 在上述释放分支，上离时 v>core.high 且 D.outer 覆盖 core，故下界不变，严格收缩当且仅当 `v>D.outer.high`；下离同理，当且仅当 `v<D.outer.low`。成员删除不推出几何严格变小。通过。 |
| 相邻 wholeOuter 必交 | 相邻 X 的事件拥有开左闭右，但完整状态范围均含共同切点状态；该值见证两闭包络相交。释放改变最终核子集，不能推翻 whole X 命题。通过。 |

“唯一”仅为此确定关系内部的唯一结果；“首次可知”仅为固定规则允许的最早发布时间。均未被升级成原义分解唯一性或所有可能算法的信息论界。最终成员连续也不表示其每腿与 core 同交集，或全部成员的交集等于 seed core。
