## L56 的独立推导

量词固定为同一 Ω56-L、δ56-L 在任意非空有限精确实数历史上生成的一份成功证书。腿必须由该历史按平台归属规则导出，不能换成任意人工区间表。设该周期游标为 c，最早正宽 seed 为 s，成功离开腿为 j，核心为 `C=[α,β]`，`α<β`。

1. **首次 L 即成功。** 此时 `j=s+3`，三条 seed 的范围都包含 C。上离好角色给 `L.startValue≤β<L.endValue`，故 L 包含 β；下离好角色给 `L.startValue≥α>L.endValue`，故 L 包含 α。因此首次 L 无需先有触核记录，已经满足与 C 闭交非空。此分支不可省略，不能仅以“L 是上一触核 R”代替。

2. **至少触核一次。** 首次触核对是 `L=s+3,R=s+4`。若 seed 末腿向上，其终点 v 是该腿上端且 `v≥β`。相邻 L 向下，R 向上。R 与 C 相交使 R 的起点 u 满足 `u≤β`，而 u 正是 L 的终点；所以 L 的闭范围包含 β。末腿向下时，v≤α，R 向下的上端 u≥α，故 L 包含 α。此后各条 `s+4,…,j` 都曾作为触核 R，其中最终 j 是最近一次触核 R。故所有 `I_i`，`s≤i≤j`，均触闭 C。这个论证没有假设它们的共同交集恒等于 C。

3. **seed 及其右侧的完整三腿窗。** 对 `k≥s`，记三个区间交为 `J=[a,d]`，`a=max l_i`、`d=min u_i`。前件正宽给 `a<d`。每腿触 C 给 `a≤β` 及 `d≥α`。结合 `α≤β`，有 `max(a,α)≤min(d,β)`，因此 `J∩C≠∅`。该式只产生非严格结论；本审查不把它提升为正宽相交，也不提升为 J=C 或实例身份相等。

4. **whole 前导及跨 seed 窗。** 对 `c≤k<s`，该三腿窗的终腿最晚为 `s+1`，选中 s 时已经封定，且属于此前逐窗检查过的范围。最早性意味着其交集不是正宽，因此命题前件不成立。`k=s−2` 与 `k=s−1` 若存在，也适用同一理由；跨 seed 并非漏项。

5. **whole 端点与穷尽。** 初始 b 是腿0起点；后续 b 是上一 L 末点，也是上一 R及当前腿c起点。成功 whole 正好包含完整腿 `c,…,j` 的全部原事件，闭状态还读其左边界。最后的三腿窗为 `j−2,j−1,j`，已由上述分类覆盖。证据 R=`j+1` 不归本 whole 所有，因此跨到 R 的窗不在 L56 的量词内。
