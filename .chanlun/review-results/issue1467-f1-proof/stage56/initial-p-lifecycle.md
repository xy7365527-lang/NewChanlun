## 1. 对象与冻结选择 Ω56-L、δ56-L

`[新缠论:选择]` 数学输入是任意非空有限精确实数状态串 `h=(x₀,…,xₙ)`，保留每个状态与事件 ID。这里不删坏形状，不把“至少产出三个 P”写进输入域。订单协议到状态串的映射没有在本轮另行认证；两个控制只是合成成交模型，实际价格为展示坐标加100，不是市场样本，也不是将订单状态当成交。

原始腿、成核搜索及数值停止关系完全采用冻结 D54 v1。为使本候选可独立理解，约定如下：

1. 原始腿是最大弱单调游程，首末严格不同；首个反向严格事件封定前腿。平台归旧腿，初始平台归第一腿。已封腿记为 `ℓᵢ=[aᵢ,bᵢ]`，拥有事件 `(aᵢ,bᵢ]`，闭数值范围 `Iᵢ=[lowᵢ,highᵢ]`，封定可知时刻 `κᵢ`。相邻已封腿共端点且方向交替。原始腿没有原义次级走势身份。
2. 上次已发边界为 `b`，下一未消费腿为 `c`；初次 `(b,c)=(0,0)`。取最小 `s≥c`，使三个已封腿 `s,s+1,s+2` 的闭范围交为 `C=[α,β]` 且 `α<β`。较早失败窗保留为 NoCore 前导；无 seed 时全部未发事件留尾。
3. seed 三腿的原始来源共同指定一个初始**候选**实例 `K=(Ω版本,源命名空间,周期号,三腿源ID)`。它在 `κ_(s+2)` 登记，核心 C 冻结。ID 不以区间值代替；同值 C 不使不同周期同一。发展记录 `H={s,s+1,s+2}`。登记不是原义核认证。
4. 从 `j=s+3` 起逐邻检已封 `L=ℓⱼ,R=ℓ_(j+1)`。若 R 触闭 C（含只触边），记录完整接触事实，令 `H={s,…,j+1}` 并 `j←j+1`。首次 R 严格在 C 上方时，须 L 向上且 `L.startValue≤β<L.endValue`、R 向下；下方对称。首次数值外离角色坏即 BadRole，全尾停止；不跨过坏对另找成功，不把 seed 末腿当第四腿。缺封定对即 AwaitPair。
5. 首次角色好外离给出 `M={s,…,j−1}`，L 不作最终核成员，已有 H/接触事实均保留。候选实例成员源是 M 各腿事件并。成员外缘由这些腿的完整范围取包络；它不是已经认证的 DD/GG，M 也不是原义 Zn。该实例的数值生命周期在本步退役，此后不加成员、不复活同一 ID。
6. 输出完整来源片 `X=(b,bⱼ]`，闭状态范围必须是 `range(X)=[min_(b≤t≤bⱼ)xₜ,max_(b≤t≤bⱼ)xₜ]`。X 包括 NoCore 前导、完整 seed/M 与离开 L；**“seed 到外离”只指核心生命周期，不准把 whole X 截成 seed 起点，也不准漏掉前导或 L。** 证书引用 R，R 的事件留给右侧。下一周期 `(b,c)=(bⱼ,j+1)`。X 的候选目录只拥有本 K；前后周期没有同式双计。

定义 `RawClose56(h,X,w)` 为满足以上六项的原始证书关系，其中 w 列出 seed、M、H、全部接触对、首次合格 L/R、端点及原事件；证书不读父成立、已完成 P 或未来类型。定义数值模型内的 `BaseComplete⁰_P(X)` 当且仅当存在这种 w。`⁰` 明指本候选的初始数值语义，**不写为已经证明的原义 BaseComplete_P**。给它概念分类 `P⁰` 的依据是本目录恰一 K，绝不根据原始腿的上涨符号叫 U。

δ56-L 是这些已关闭 X 按时间的连接，加唯一未发尾部；闭状态边界可共读，原事件所有权开左闭右。全部 X 都用同一 Ω56-L、同一初始等级0；活动、NoCore、BadRole 分别保留其状态。BadRole 不签完成、不删除尾部。候选的“不可继续成为同一实例成员”由固定生命周期规则给出，尚不是原义走势不能延伸的独立定理。

时钟也分开：seed 末端发生时刻 `b_(s+2)`、seed 可知 `κ_(s+2)`、X 拟结束 `bⱼ`、数值闭合可知及发布 `κ_(j+1)`。原义完成/可用时刻仍未取得。不能把 L 端点回填成当时已知的完成时刻。

这份选择与旧 δR 在承重处不同：不用三笔常价游程当作点核目录，不按两枚核价的符号配对、不用下一反向点核终结趋势，也不从未分配点核重启 U/D。五个旧候选点核价可以只落在同一个新初始 seed 的来源内；这不是把旧五枚已证原义核偷偷合成一枚，因为旧目录没有取得那项独立实例资格。

## 2. 可直接验证的部分模型

本节只量化固定 Ω56-L、δ56-L 及其全部有限标量历史，不比较别的合法读法。D54 普通关系证明及独评已证明原始关系的存在唯一、有限终止、已封腿稳定、已发证书稳定和完整来源覆盖；本轮没有重跑旧枚举或重新宣称一般程序精化。

新增身份/类型解释对原关系作保守扩充：为每周期附上唯一 K、对每个成功证书附 `P⁰`，不改搜索、边界、成员或时钟。因此：

- **模型内唯一核心身份及核数。** s 与周期号唯一，seed 源 ID 唯一，故 K 唯一；实例目录只在周期开始登记一次，只在退出后允许下个周期，故每个已发 X 恰有一份本目录初始核。这里证明的是明示初始定义，不是“任何相交窗口必为同一原义核”。
- **全覆盖与接续。** 最终 `M={s,…,j−1}` 的事件都在 X 内；后继从 R 开始且 `R.start=L.end=bⱼ`，所以相邻 X 的真实状态端点完全一致；已发拥有区间与尾部把 `1,…,n` 无重无漏分完。前导虽不在 M 内，仍在 X 内，不曾消失。该证明给出原始来源接续，尚不独立认证原义连接单元。
- **不可撤回及同层。** 关闭证书只用已封腿；追加不改 seed、此前失败窗、首个合格 L/R、M、边界或完整范围。附加 ID 和等级都是这些稳定字段的函数。下一层不得再把其 raw seed 腿重当同层完成成员；固定 F₂ 要消费的是 whole X。
- **分类与 P/P 的模型含义。** 在这份目录内，所有已关闭对象核数为1，所以 P⁰/U⁰/D⁰ 分类穷尽，U⁰/D⁰ 为空。完全分类不要求三类均非空；但空类不是合法 P 的证据。相邻 `P⁰/P⁰` 只有原始边界及同目录等级已经证明，原义 P/P 还要满足第5节的相容性命题。

这构成一个有限前缀、来源、身份与分类约束的部分数学模型。它正面验证了一些共同约束，未将“原文未给现成算法”当成反证；也未假称部分模型已满足全部原义完成和固定 F₂。

## 3. 新引理：成功 whole X 内的成核窗都碰到原核心

**命题 L56。** 取任意成功 RawClose56 证书，沿用 c、s、j、C。whole X 恰由完整腿 `c,…,j` 及这些腿内所有原状态组成。对其内每个完整三腿窗 `k,k+1,k+2`（`c≤k≤j−2`）：若窗交集 J 正宽，则 `J∩C≠∅`。不声称这个交集正宽，不声称 J=C。

**证明。** 先证所有 `Iᵢ`（`s≤i≤j`）都与 C 相交。

三条 seed 的范围都包含 C。若首个候选对即成功（`j=s+3`），L 的好角色明确给出它横跨 C 的相应边界，故 L 也触 C。这处理了“L 尚未经历一次触核”的分支。

若发生过触核，首次接触是 `R=ℓ_(s+4)`。当 seed 末腿向上，`x_(b_(s+2))≥β`；紧邻 `ℓ_(s+3)` 向下，`ℓ_(s+4)` 向上。后者接触 C 迫使其起点 `x_(b_(s+3))≤β`，所以 `I_(s+3)` 从不低于 β 走到不高于 β，包含 β。seed 末腿向下时，完全对称地包含 α。此后每条 `s+4,…,j−1` 都曾作为接触 C 的 R；最终 L 若已在前一次接触中出现，也同样触 C，若直接用成功角色亦可得同样结论。于是所称各腿全触 C。

现在取 `k≥s` 的三腿窗，写 `Iᵢ=[lᵢ,uᵢ]`、`J=[a,d]`，其中 `a=max lᵢ`、`d=min uᵢ`，且 `a<d`。各腿触 C 给出 `a≤β`、`d≥α`；加上 `a≤d` 和 `α≤β`，得 `max(a,α)≤min(d,β)`，所以 J 与 C 相交。这里只有非严格不等式；不能把触边升级为正宽重叠。

剩余 `c≤k<s` 的三腿窗都已在选择最小 s 时被检验并拒绝，其交集非正宽。即使其中某窗跨过 seed 起点（最多到 `s+1`），也仍是当时实际检过的完整窗。whole X 左边界 b 恰是腿 c 起点，因此没有一条被截掉左半的腿遗漏；右边界是腿 j 末点，证书 R 不在 whole X 内。穷尽两类窗，命题得证。

**能得与不能得。** 固定这个原始成核谓词，whole X 内没有与 C 完全分离的另一份正宽三腿核见证；包括离开腿 L 的最后窗口也覆盖在命题内。它给“把该生命周期内的成核见证归一个初始实例”提供几何相容性检查，而不只报目录计数。可是，相交成核见证与实例同一是不同命题；038 的合法同级分解本来就可有重叠的不同核。故本引理既不证明本实例的原义资格，也不否定另一 δ 中的重分。它不计算真正 Zn、DD/GG，不要求所有 M 的共同交集恒为 C，不把 fullRange 缩成 C。
