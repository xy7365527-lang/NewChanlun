## 3. D54 成功到 RawTerminal 的普通证明

从 `stage54/candidate-evidence/contract-v1.md` 的原始数学关系出发。三 seed 的完整范围包含正宽 C=[a,b]，所以 s、s+1、s+2 均触 C。成功给 j≥s+3、r=j+1、R 已封、完整范围严格上离或下离。

首次检查成功时 j=s+3。上侧好角色是 L.start≤b<L.end，故 b 在 L 的完整闭范围内；下侧是 L.start≥a>L.end，故 a 在该范围内。这里不依赖 L 先前进入 H，也没有遗漏第四腿。

发生至少一次触核时，第一次 R₀ 是 s+4。若 seed 末腿向上，其终值 v≥b；紧邻 s+3 向下，s+4 向上。向上的 R₀ 触 C，迫使其低端即起值 u≤b。真实共端点把 u 识别为 s+3 的终值，因此第四腿从 v≥b 到 u≤b，必含 b。seed 末腿向下时，R₀ 向下且触 C 给其起值 u≥a，第四腿从 v≤a 到 u≥a，必含 a。平台不破坏这些端点与完整范围事实，首末严格不同及首反向封腿仍成立。

其后 j 每次只加一；从 s+4 到最终 j 的每条腿都曾是一个触核 R，最终 L 正是最后一次这样的 R。因此 s…j 全部触 C。结合 j≥s+3，得到 TouchSpan 所需 j≥s+2；再合并相邻、封定时间和外离项，得到 RawTerminal。

这证明的是任意 D54 成功证书的条件蕴含。首次坏角色停止、AwaitPair、NoCore 都没有成功前件；没有把它们判成原义失败，也没有偷偷加入全历史必有输出的活性条件。证明不读 published、retired、RawClose 或 Completed 字段，M/H 只用于解释算法，未用其标签证明接触。

只采用这个单向蕴含，不采用 RawTerminal→D54 成功或两者等价。RawTerminal 只要求 j≥s+2；D54 成功另要求 j≥s+3、从首个候选对开始逐邻扫描、首外离好角色及对应发布条件。因此原始最大性不能使 seed 末腿取得 D54 离开腿资格，也不能把任意独立 RawTerminal 都交作可发布证书。作者没有声称这个逆命题，此处是采用边界，不是新增 finding。

whole X 与原始接触片必须分开。若上次切点 b₀ 后有 NoCore 前导，whole X 仍拥有 `(b₀,L.end]` 的全部事件及完整状态范围；TouchSpan 从 s 开始，不声称前导每腿触 C。L 属于 whole，R 只是确认支持，R 的事件属于右侧。故本结果没有证明 whole 本身是“从 b₀ 开始全部触核的片”，也没有删掉前导来制造那种结论。

## 4. 最大性、保留与解释桥

给定 RawTerminal，设 k>j。由 r=j+1 和 j≥s+2 得 s≤r≤k。若 TouchSpan(C,s,k)，它在索引 r 的全称分量要求 Iᵣ 触 C，与证书不交项矛盾。此反证不读 r 后任何数值，适用于任意 k。未来再次触 C 不影响结论，因为连续片仍含已知的不触核腿 r。

两个终点按 Nat 三分律比较。若 q>j，j 的最大性否掉 q；若 q<j，q 的最大性否掉 j；因此 q=j。保留到 r 后，旧接触事实、不触核事实和 κᵣ 全保留，可在 h′ 原样组装 RawTerminal，再用同一全称反证和唯一性。这里固定同一 K/C/s；没有比较不同 seed 或不同合法分解 δ′。

实数解释成立。对有效闭区间 I=[l,u]、C=[a,b]，公共点 p 给 l≤p≤b 与 a≤p≤u，从而 l≤b 且 a≤u。反向取 p=max(l,a)：由 l≤u、a≤u 得 p≤u；由 l≤b、a≤b 得 p≤b，且 p≥l,a，故 p 同时属于两区间。于是泛型 Touch 在 α=ℝ、le=≤ 的解释中恰是非空闭交。对实数线序，不触等价于 u<a 或 b<l，与 D54 的严格外离一致，触边仍算触。

有限前缀到总 Tape 的桥也成立，但需要把数值延拓与真实未来区分。将作者第 97 行的论断展开如下。设在时刻 τ 已封腿恰为 0…m，至少包含证书 r。保留这些腿的原 range、sealAt=κᵢ、endAt=bᵢ。令 B=max(τ,κₘ)。对 i=m+d、d≥1，任取固定有效范围 C，并置 sealAt i=B+d、endAt i=B+d−1。原段内部时钟严格递增，原末 κₘ≤B<B+1，新段也严格递增，且每个补齐 endAt<sealAt。于是得到一个合法总 Tape，新增项全部在 τ 以后，不会被当作当前已封腿。

这只是形式载体的补齐，补齐行不声称是原历史产生的腿。任何真实有限追加都能先保留其全部新真实行，再按同式补齐；它与旧载体在 0…r 上相等。根的阻断仅用到 r，因此结论对所有这种补齐一致，也适用于追加后任意真正出现的更大索引。并不需要假设真实历史永远产生新腿，也没有把合成尾部算成市场事件。空已封前缀不可能提供当前 RawTerminal，其情形不参与这个应用。

已封腿的严格递增 κ 与 bᵢ<κᵢ 来自 D54 封腿规则：首反向严格事件晚于前腿终点；下一条腿的封定要等更后的另一个严格反向事件。追加不可能移动已经出现的首反向事件，所以旧完整腿的范围和时钟保持。由此可交付 Tape 的两个结构证据和真实追加到 PreservesThrough 的前提。这仍是原始数学关系的解释，不是整个 JS 程序的全域精化。

RawTerminal 的阈值项直接给 κᵣ 时成立、t<κᵣ 时不成立。j<r 与两项 Tape 证据给 bⱼ<κⱼ<κᵣ。这一首次时点只属于当前关系；没有推出别的算法在 κᵣ 前绝无任何知识，也未把发布/可知时间回填成 L.end。
