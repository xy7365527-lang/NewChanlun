## 2. 可实例化的初始规则 R62-PB（新选择）

这是给共同模型的明确候选合同，不是从038逐字推出的唯一初始算法。以原始历史 h、同一观察函数 W、同一时钟 t、具名线段关系 Seg(h) 为底。只讨论给定初始窗口的双边有效域；起点和窗口外事件归属必须记录。

固定参数 `ρ=(start-policy, seed-offset=1, Pan-role-rule, publish-policy)`，运行前固定，正负控制相同。ρ是初始程序，不是看到不等式后更换的 δ。每个周期起点 s 之后取真实连续线段 b,s₁,s₂,s₃,c；前三个“核成员”固定为 s₁/s₂/s₃，b是同一周期内的前导，c是其后离开。允许 c 尚在发展；段证书的确认支持可以超出 c 的自有区间。

定义独立于本次 End/F₂ 的结构谓词：

```text
Shapeρ(X,b,K,c) :=
  Own(X) = Own(b) ⊔ Own(s1) ⊔ Own(s2) ⊔ Own(s3) ⊔ Own(c)
  ∧ source order b,s1,s2,s3,c with equal shared endpoints
  ∧ K.members = [s1,s2,s3]
  ∧ Core(K) = ⋂ Range(sj), with positive width
  ∧ q(X)=q(K)=0; s1/s2/s3 are initial segment material
  ∧ the initial catalogue/lifecycle admits exactly this K in X
  ∧ Leftρ(X,s).

InternalPBρ(X,b,K,c;u) :=
  Shapeρ(X,b,K,c)
  ∧ b,c are same-direction external-to-K comparison roles inside X
  ∧ b is the latest eligible preceding role after excluding K members
  ∧ real boundary crossing and applicable Extreme
  ∧ L(c;u) < L(b), using the same original clock and #873 atoms.

DynEndρ(X,e;k) :=
  InternalPBρ(X,b,K,c;k)
  ∧ End067(c,e;k)
  ∧ k is the first publish time satisfying the fixed evidence policy.

EndInitρ(X,e;k) ↔ DynEndρ(X,e;k).
NextInitρ(X) starts at the same raw state e and owns only events after e.
```

`L(b)`读取已封 b 的真实首末笔；`L(c;u)`在发展态允许有值，严格弱化候选可修订。End067在这里定位并封定 c 的尾端，不能独自给 X 完成。最终发布是动力学与段尾的合取；负控制说明两者并非同义。GeneralDiv若在新初始域定义为这个 DynEnd，不天然循环：所有右侧数据都来自 raw/Seg/结构角色，不读取“X已完成”或“父核成立”。但同构只证明定义可执行，**不能证明下列来源义务全部相容**。

这是一份最小初始接口；若共同模型另加“离开后不回”或真正后继证书，应写成新的具名前件并绑定实际来源，不能悄悄回写为 Stage60 已有证书。不能把所有原始 sⱼ、b、c 都强塞为037标准趋势的真正次级 c；037:18/22只在其趋势及 B/T3角色前件内适用。

### 2.1 Leftρ与完整性

Leftρ有两种证据状态，不能混同：

1. **内部周期边界**：s 是上一份同一ρ输出的真实 EndInit 点；其所有权按左开右闭接续。要按038:300取得原义全历史分解，还须共同证明这一 EndInit 的来源语义。
2. **第一周期的窗口边界**：显式声明从某局部低/高点开始研究，窗口以前为外部/支持，不能反称该点已有原义 q 结束。084允许制定初始程序，故它不是被禁的初始定义；但这种相对窗口定理的结论只能覆盖窗口。若目标是全历史唯一分解，需由同一 f₁ 指定首周期初始化或给内部前驱构造，不能新设一个预存 Iref 黑箱。

`Whole=b+K+c`恰适用于本角色合同，因为 b、核成员与 c 都内部拥有源；若删 b 只取 K+c，b/c盘背即不再是 X 的内部比较。若把 whole 限为核包络，则漏掉真正源范围。反之，确认 c 的后续数据不能吞入 Whole，否则 End 的事件点和范围同时改变。

## 3. 同一 Ω 内的关系图：不可混成一条链

Ω的数据载体只建一次：原始事件、价格/时钟、源区间、线段、初始对象、各级核、各级活动/完成走势以及具名表达式。每个对象保存唯一 Own、Range、grade、核目录和完成证书；表达式ID与对象ID分离。

至少保留四种关系：

```text
SrcNext(X,Y)          : end(X)=start(Y)，两自有事件区间连续且不漏重。
MemberNext(K;X,Y)     : X,Y是具名父K的成员表中相邻项。
Adj(E;X,Y)           : X,Y是具名表达式E中的直接相邻独立项。
Contains(W,X)        : X作为子结构留在W内；不等于X是E的一项。
```

`δop_q`是固定q的同级表达式；`δc_q`若被合同要求，同样必须写明它的确切对象列表、来源覆盖、grade和是否包含活动尾。NoPP只能写为

`∀X Y, Adj(δc_q;X,Y) ∧ Complete(X) ∧ Complete(Y) → ¬(P(X)∧P(Y))`。

它不是 `∀K X Y, MemberNext(K;X,Y)→¬(P(X)∧P(Y))`。也不是凡共享端点的任意两对象都受禁。反过来，固定同层完整分解中的相邻是对象关系，不能按需要改 δc_q 或临时把对象换成其包络。

### 方案A：初始同级生成，父成员保身份（可实例化研究合同）

给同一 h 的三个真实 EndInit 周期 X₀,X₁,X₂，原始区间 `(t₀,t₁]、(t₁,t₂]、(t₂,t₃]`，均为q0、一核、完成；技术走向按实际端点/既定映射验证，概念类别均为无方向P，不把技术方向等同U/D。定义

```text
α0 = δop_0 = [X0, X1, X2]          // f1直接从原料生成；固定且不回写
SrcNext = {(X0,X1),(X1,X2)}
K1.members = [X0, X1, X2]
MemberNext(K1) = {(X0,X1),(X1,X2)}
Core(K1) = ⋂ WholeRange(Xi); q(K1)=1
Own(K1-material)=⊔ Own(Xi)
Contains(K1,Xi)=true
```

F₂是否真产生K1，须由三个完整range、适用方向、原义完成、同级和连接等全部前件判断，不由图上手写K1决定。035:18和039:28提供这种源连续同级对象上成高核的来源形状；084允许这些对象由新f₁产生。**α0不是“消费既有生产塔”的旁路δop；此处同级分解是新初始程序的输出性质，代码和调用方向仍是raw→f₁→固定F₂。** 命名相同不等于挪用ADR的现成模块。

该图保留Xᵢ的源、级别及证书，绝不把三个P合成一个仍叫P的W0来隐藏邻接。它容许另一指定表达式δc只把上层走势Y1作为一项、其内部保留K1及孩子；Y1若还活动就不能称完成P1。该表达式的grade是1，**它不是δc_0**。NoPP在δop_0不施加，在指定δc_1中的量词按真实项判断；初始源链和上层成员链都已实赋值。

这给出了“存在上层成员结构而不必出现某个NoPP表达式中的P/P”的精确关系模型，反驳裸推理 `MemberNext→Adj_δc`。**它不自动满足“每级另有一个完整NoPP表达式δc_q”的更强合同。** 若共同模型声明这个全级合同，必须继续交出δc_0；不能把它留空、只挑δc_1或把高层Y1当作q0项来声称共同模型完成。Stage60现有事实只有X₀一份，X₁/X₂必须来自其他工位真正的新构造，不能从此图的变量计数生成三份实证。

### 方案B：保守地接回同层NoPP主干（有精确障碍）

若要求三个Xᵢ全部保身份、保Own、保q0、保完成且各作为固定δc_0独立项，源连续迫使该段δc_0就是 `[X0,X1,X2]`；于是NoPP失败。以下证明不借盘口样本或上级父成立。

**相邻保持引理。** E是同层、按源序排列、不漏重的区间表达式，项均拥有非空源。X/Y在E中且 `Own(X)=(a,b]、Own(Y)=(b,c]`。若两者不直接相邻，则存在中间项Z；由顺序与不重计，`start(Z)≥b`且`end(Z)≤b`，故Own(Z)为空，矛盾。证毕。全覆盖只用于保证表达式无未记源；非空中间项已足够产生矛盾。

因此三P直接消费与NoPP并非必然冲突，但**“三P都是同一固定同层完整NoPP表达式的独立项”**确实冲突。去掉HAdj名称却保留引理全部假设，不能解除冲突。

把三者折成W也有可核的代价：若W保留三份自有核目录，W不能仅靠改名仍是一核P；若F₂的高一级K1在同一解释内被保留为W内部核，035:20禁止W继续是q0单一走势。把W标q1能解决这个级别问题，却改变了δc_0的固定层要求。若另作重新结合使某些旧核不再是W的内部核，须把新括号、核目录运输和源覆盖具体写出，这已是另一个映射而非保守折叠。

039:28不是对这种任意折叠的授权。它明确列了无回分支才可把a+A₁+A₂+A₃仍当同级a′；另一讨论分支承认A₁/A₂/A₃成高核。不能同时采用后者高核身份和前者同级a′标签而不核分支条件。
