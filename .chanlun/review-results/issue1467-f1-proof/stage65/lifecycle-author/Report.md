# Stage65：六核到生命周期的两种实际映射

研究票 #1467；2026-10-06；作者报告，等待另行独评。唯一写域为本目录。原仓、生产、formal 与 tracker 均未修改。

**结果：已构造并执行一种不读取 Completed 标记的材料方向映射 M65-pol；它在 H2 得到两个有明确桥段的几何关闭和一个开放组。它尚未取得源义生命周期资格。另一个明确映射 M65-mono 在运输旧结束证时被实际材料包含关系反证，首失败为 278。** 两者都不是完整 F₁/F₂ 成功；也没有把 035 解释成 K2 必属旧 X0。

## 1. 输入、方法与验算范围

仅使用 Stage64 H2 的 583 观察、582 数量事件、144 份已保存 R_W 笔、28 个所选段和六个核的成员索引。没有生成新历史，没有运行 R_W，也没有再次枚举所有可能段或中枢。脚本从各核的实际三段成员重算 core、outer、材料区间和方向，复算六次已确认 c 的力度比较；原解析结果的合法性依赖已完成的 Stage64 动态独评。

`node check.mjs` 对 H2 的 583 个前缀执行新映射，**4,292 个作者断言通过，exit=0**。这验证具名有限计算，不证明任意历史上的完备性、语义唯一性或 NE。输入字节绑定在 `run/input-bindings.json`，完整结果在 `run/mapping.json`、`run/polarity-timeline.json` 与 `run/first-failures.json`。

**重要依赖限制：** M65-pol 函数本身不读取 LocalDyn64 的弱化值、对象 Owner、end 或 Completed；但它消费的这份六核目录来自 Stage64 的所选构造。这里尚未证明“目录选择本身独立于 LocalDyn64”，也未证明六核穷尽原义中枢。因而后文的独立性只指**固定这份目录之后两个函数的数据依赖分离**，不能被扩大为完整生成链的独立源义验证。

## 2. M65-pol 的具体定义及实际映射

### 2.1 三种关系分开定义

本候选只在所选目录按时间排序、每核三段严格交替、同方向组内外缘方向一致、组间连接恰含两段的域内定义；域外返回未适用，不换宽松判据。

对核 K 定义材料方向 `p(K)=U` 当成员为 DUD，`p(K)=D` 当成员为 UDU。这是 `[新缠论:候选]`，不宣称缠师曾把该方向指定为生命周期归属。把有序目录分成 p 恒定的极大连续组 Yᵢ：

- `Owner_pol(K,Yᵢ)`：K 位于第 i 个方向恒定组。这是核到组的单值关系；不输入结束 Bool。
- `WithinMoveNext_pol(Yᵢ,K,K′)`：K、K′ 同属 Yᵢ，且在该组核序相邻。它用于检验组内同向核延续，不能单独给末核的结束见证。
- `SourceNext_pol(Yᵢ,Yᵢ₊₁,u)`：观察到下一组首核；前组末核与下一组首核之间**恰有两段** c、a′，方向依次为 p(Yᵢ)、p(Yᵢ₊₁)，两段及核材料首尾连续，u=c.end=a′.start。此时产生前组几何关闭及下一活动身份 I(u)。这里“SourceNext”是候选关系的名字，其原义直接接续资格仍待证。

首锚点为 state1。已关闭组的 `Own=(start,u]`；下一锚点递推取 u。末组没有下一首核时不强封尾，不把 buffer 当已完成 Whole。

### 2.3 与实际弱化扫描的交叉检验

另从实际笔重算 M65-force：每个声明比较以 `L=v末−v初`、严格弱化和真实极值为准，接受后递增 start，完全不读取旧 Completed Bool。

| 候选 | b/c | L(b)/L(c) | 发生/弱化证齐 | M65-pol 同端点证齐 |
|---|---|---|---|---|
| X0 | S4/S8 | 200/50 | 181/198 | 278 |
| X1 | S13/S17 | 150/−300 | 361/378 | 458 |
| X2 | S22/S26 | 200/50 | 541/558 | EOF 仍无 |

单核比较仍是三次失败，双核比较三次成功。六次判断时 b/c 的笔已在该前缀 stable 中，相关核已知；这里只重核端点证，不扩称全前缀进行中 L。

在固定六核上再问“弱化端点以后，还有没有属于对应 Yᵢ 的核发生”：三个答案均为零。**这不是直接按 Completed 删核**——Owner_pol 先由核材料方向独立算出，若此目录后面实际还有同方向组内核，检查会看到它。但它仍只是一条目录条件下、截至 582 的有限一致性结果；第三组尤其右删失。目录穷尽、原义 Owner、合法延长中的保持均未证明，**不能据此宣称 NE 成立**。

此外，具体命题“198 发布 X0 时，M65-pol 的同端点关闭证已经可得”是假的：该前缀关闭列表为空，证齐时刻为 278。这是此算法的精确提前发布反例，不是否定 181 可能是真实结束。

## 3. M65-mono：真正同对象映射的材料反例

为检验另一条清楚的桥，定义不共享核的外缘单调运行：首核启动；第二核确定方向；以后同向核加入该对象；反向核启动下一对象。新对象再用自己的第二核确定方向。仍不输入 Completed，也不把所有后续目录核都归首对象。

实际结果为：

| 对象 | Own 核 | 组内后继 | 类型投影 |
|---|---|---|---|
| M0 | K0,K1,K2 | K0→K1→K2 | U |
| M1 | K3,K4 | K3→K4 | D |
| M2 | K5 | 无 | 单核 P，尾部待定 |

检验的明确联合合同是：**将旧 X0 的完成记录原样运输给 M0，包括 u=181、Whole Own=E2…181，同时要求每个自有核的全部成员事件属于该 Whole。**

到 278，M0 的同对象归属规则已经纳入 K2，K2 的材料为 E202…261。于是要求 `261≤181`，直接为假；首个越界事件是 E202。该反例即 `run/first-failures.json.primary`。

这比原 A64-global 的反例多了一个实际对象解释：K2 的归属由 M65-mono 规则确定；K3、K4、K5 不再全归 M0。否定的是**这个单调 Owner 与旧结束证的原样运输**，不能将其改写成“035 已证明 K2 属 X0”。

若改 u 来装下 K2，则至少 u≥261，原证的 c=S8 却结束于 181，因此不是同一份结束证。实际相邻所选段端点 261/281 的价格是 78800/58000，旧峰为 80000；它们也不能冒充原证中 c=S8 的 80000 端点。这不证明所有重新选择的动力学证都不存在，只证明**旧证无法运输**；新对象、新 c 和新端点必须重新取证，不能保留原 Div Bool。

另一种常见改法是让转折核共享：核运行变成 `{K0,K1,K2}`、`{K2,K3,K4}`、`{K4,K5}`。它可以作为重叠分析窗口的关系，但不是单值 Owner：实际重复的是 K2 的 E202…261 和 K4 的 E382…441。若两窗口同时被当作该同层源序列的完整 Whole，就出现双计，不满足固定 F₂ 要消费的连续且不重用源对象合同。改称“诊断窗口”可保留它，不能照原名交给 F₂。

## 5. 良基依赖：计算已给，源义未冒领

三个程序的计算依赖都有限且有显式下降量，可用下列阶段加自然数索引的字典序理解：

1. 冻结观察/笔/段是输入叶；核 geometry 与材料方向只依赖较早阶段叶。
2. 核分组状态 i 只依赖本核叶和 i−1 状态；相同阶段的核序号严格下降。
3. 第 n 个桥切点只依赖已完成分组计算、两个桥段和第 n−1 个起点；相同阶段的对象序号严格下降。实际 start 是 1→181→361。
4. 力度数值只依赖冻结笔端点；第 n 次弱化重置只依赖当前比较材料、先前重置 start；已接受 u>start，前缀上势能 k−start 严格下降。

这给的是实际有限程序总性，**没有调用 End oracle，也不要求任何外部 Iref**。但程序能终止不等于其产出有源义。若后续在同一模型证明 `Role/Div(I(s),u) ⇒ End(I(s),u)`，就能对已证明的第 n−1 个 End 归纳推进第 n 个 start；这是合法的“先前端点”。相反，若当前核目录或比较角色须假设当前 `End(I(s),u)` 才能确定，再用该角色推出同一个 End，就是循环，不能用“n 在增加”掩盖。

本次 M65-pol 的先前端点只获几何桥证，M65-force 的先前端点只获数值弱化证。它们没有冒称已证明源义 End。其原义解释仍需 H4/H6 类桥；C64v2/v3 的条件总性和规范表示不能给本次 H2 补上 H3/H4/H5/H6。程序先算出候选边界再接受独立的语义审查，是允许的；把 End 定义为程序恰好输出则不能完成审查。

## 6. 本轮可采用的结论与剩余对象

成立的有限结果：材料方向 Owner 和三个 WithinMoveNext 可复算；前两个几何 SourceNext 的端点/证齐分别为 181/278、361/458；不读旧 Completed 的力度重置复得旧三候选；两个映射在已有六核上的分组相合但发布和尾部不相合；M65-pol 的已关闭 Own 与 buffer 在全部 H2 前缀不重不漏。

明确否定：M65-mono 将旧 X0 完成证原样运输到 `{K0,K1,K2}`；将 M65-pol 的关闭证提前到 198；把共享 K2/K4 的重叠窗口作为单值 Owner。

未决：六核目录的源义穷尽和无当前 End 循环生成；M65-pol/force 的真正生命周期解释；全部合法延长上的 NE；一般完成覆盖；Y2 的真实结束；父生命周期和递归闭合。

**固定 F₂ 的实际状态：** M65-pol 到 558 以及 EOF 都只有两个几何关闭对象，三个完成孩子的候选链尚不齐；原义完成孩子仍为 0，所以原义 F₂ 三元组仍为 0。Stage64 的 `[40000,80000]` 三交数值不变，但不能用它补齐上述对象资格。本轮没有再次运行固定函数，没有新增父完成，没有生产、Lean、交易或收益结论。
