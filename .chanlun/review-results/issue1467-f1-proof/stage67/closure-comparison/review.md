## 2. 前提强度、空域和边界

H 本身可满足：令 C 恒假即可。α 为空时 H 与结论都为空域全称命题；α 非空而 C 为空时 H 条件空真。这些情形不削弱定理，因为定理的承重结论恰是 C 不能非空。

对给定 α、rank、C，H 与 `∀ x, ¬ C(x)` 在普通数学上等价：正向为本根，反向由假前件消去得到。原文件没有另给反向的具名定理。本结果没有建立任意应用中的 H；它只能否定“C 非空且 H 成立”的联合合同。

以下条件不能在应用中省略或替换：

- **同一谓词及同一全称范围。** b 必须仍属 C，随后才可再次使用全域 H。换成 RawClosed 或只对某些派生对象要求 H，会改变命题。
- **严格下降。** 若改为 `≤`，任何非空 C 都可用 b=x 作见证，结论不再成立。
- **自然数良基秩。** 编译目标仅覆盖 Nat。它没有建立对任意时钟或任意严格序的结论；例如整数上的恒真 C 可用 b=x−1 形成下降，不能套用本根。这是说明前提必要性的普通数学例子，不是本次新增 Lean 根。

## 3. 非空边界模型的量词

`ClosureRoots.lean:20–31` 固定在同一个 Nat 类型上定义 `RawClosed(n) ↔ n=0`、`MovementClosed(n) ↔ n=1`。边界声明同时证明：

1. `MovementClosed 1`；
2. 对**每个**自然数 x，只要 `MovementClosed x`，就存在 b，使 `RawClosed b ∧ b<x ∧ ¬MovementClosed b`。

唯一满足前件的 x 是 1，见证是 0；其他 x 的蕴含式条件空真。首项明确给出非空见证，所以整个模型没有靠 MovementClosed 为空来通过。

将 rank 取为恒等函数，该模型不满足 `NeedsEarlierClosed Nat id MovementClosed`：所需同谓词见证只能是 1，却不能小于 1。它也没有声称 RawClosed 的根 0 还要有更早的 RawClosed。因而模型与主引理相容。

`Proof.md:11` 与这一具体模型一致。可接受的推论是：把“同 C 前驱”换成“不同谓词的前驱”，确实存在一个非空的纯逻辑模型。不能把它读成所有不同类型依赖都能成功。Lean 实际使用的是**同一个 Nat 上的两个谓词**，没有编译跨类型构造、任意根集合、任意秩或任意缠论对象的全称定理。边界模型没有证明 RawClosed 具有缠论已完成比较臂资格。

## 4. 初始化、对象结束秩与领域应用

`Proof.md:9` 在其上下文中是在说明 H 的覆盖边界，没有声称已经构造出所有列举方案。但“有原始根、外部既有证书、其他完成方式或不同类型依赖”本身不是本引理的自动豁免：

- 导入对象若仍在同一个 α、满足同一个 C，并且 H 对所有 C 对象成立，该导入对象仍被定理覆盖；缓存来源和证书名字不改变结论。
- 根若在 α 中却不属 C，就不能充当 H 要求的同 C 见证。
- 根若不在 α 中，就不能充当 H 的存在量词见证。
- 若只约束初始化后的派生对象，而给根免除 H，得到的是不同的量词合同；本根不直接适用，也没有因此证明这个新合同可实现。

建议在转写或单独援引 `Proof.md:9` 时使用以下精确措辞：

> 本结论只排除“C 非空且 H 对全部 C 对象成立”的联合合同。原始根、导入证书、其他完成方式或异类依赖只有在使 H 不成立，或明确改动对象域、谓词、量词范围时，才不受本引理直接排除；这些标签本身不构成例外，本引理也未证明相应方案可实现。

这属于传播时的收窄要求，不是要求修改已经冻结的 Lean 证明或契约。当前 Proof 紧接着要求核对初始化对象的全称范围与 rank 域，已提供关键限制。

`Proof.md:7` 把 rank 解释为本地事件结束索引是一个**有待应用方举证的解释**。要套到对象结束，必须给出对象到 Nat 的同一 rank 映射，并证明每个 C 对象所需的同 C 见证严格降低该值。确认时钟更早、对象在更低级别、名字含“前一个”，均不能自动推出该不等式。相同结束索引但不同确认时刻也不满足严格下降。这里没有证明对象结束、确认时钟与级别之间任何映射。
