## 这次实际改变了什么

初始对象不再按旧P0/P1/P2/c0的五段周期预定。先固定一个独立有限关系，再枚举所有满足语法的whole、核和归属：

`b + K₁(三raw段) + bridge₁ + K₂(三raw段) + … + bridgeₖ₋₁ + Kₖ(三raw段) + c`。

每个核用其三份raw整段范围的严格交。原始段证书和笔端点沿Stage66已审数据，禁止重跑R_W。初始`Outer⁰=core`是本轮明示的新选择，不是已证明的020原义外缘；`k=1`为候选P，P没有概念方向；`k≥2`须这些新外缘严格依次同向，并与末臂方向一致，才给候选U/D。

q₀游标固定于state21，输入为S1…S20。S0仍是Own E2…21、端21/证齐38的原始根，E1是前导观察。没有把S0升成q₀，也没有利用057同一视点授它和P0/P1同种消费资格后又排除末221的早期三元组。每个长度5/9/13/17、每个可容纳的起点都核：16+12+8+4=40个窗口。这里释放的是**该语法内的全部切点**，不是所有数学上可能的初始F₁。

比较围绕最后核进行，`b_ref`是最后核之前紧邻的raw臂，`c`是最后raw臂。它们不属于最后核材料；核间bridge仍属于whole。Up入臂要求`start<ZD≤end`，出臂要求`start≤ZG<end`；Down取对称不等式。该严格边界是本版选择，不宣称穷尽所有原义跨界。力度从实际首末结构笔的斜率相减，统一用事件时间差和带号比较；whole创新极值重新遍历该whole到c开始前的真实观察。

`RootArm68`是新增候选前提：具备raw封口、真实结构笔与本次外部跨界几何的臂，可以给固定的比较值，而不先被断言为同类已完成Movement。**这只是待检初始解释，来源相容未证。** raw根不要求再找更早同类Movement，因此候选依赖无环；标签本身不提供原义资格。

`JEnd68`联立类型、核、外臂、whole极值、力度及raw c封证。发生点取该c真实原始端点，可知点取所用raw证书的最大时刻。它不读取父成立或已完成字段，也不运输旧局部证。但将这一联合条件解释为whole完成，仍是本版待审的语义选择：raw c结束究竟足以结束whole，不能仅由定义自身证明。模型把`Completed68`与`MovementCompleted_original`分开，后者保持unknown。

## 覆盖所有放开切点的有限无解证

令n个独立因子的核数为kᵢ≥1。总raw长度为`4Σkᵢ+n`，每个单核项是P，多核项至少长9。NoPP要求非P项至少有`⌊n/2⌋`个，故总长至少

`5n + 4⌊n/2⌋`。

本例只有20段：n≥4的下界至少28，排除；n=3若全P不合格，因此恰有一个双核项，且必须居中。其长度唯一为5+9+5；固定起点及源连续性遂固定三项：

`W68:S1–S5 + W68:S6–S14 + W68:S15–S19`，S20留作活动尾。

中项D候选是实际新whole：Own E122…301，whole=[60000,72000]；第一核由S7/S8/S9给[66000,68800]，第二核由S11/S12/S13给[62000,64000]。两新初始外缘严格下降，末臂S14也Down，结构类型通过。b_ref=S10，c=S14，两臂同向并满足本版跨界。

但是：

- S14末价60800，whole此前最低60000，`60800<60000`为false。
- S10的L=−1200，S14的L=−300，`−300<−1200`为false。

这两个事实在318取得所需raw证齐。它们分别否掉JEnd68的必要项，故唯一可能的三因子NoPP长度型无解。该证书不靠旧末221，也不靠把原P2排除；即使放宽部分跨界或承认RootArm，两个具体失败仍在。重开本候选需要改变语法、动态解释或切点集合之一，并另立版本；单改类型tag没有作用。

该语法不合并核计数，因此上述P iff单核前提确实兑现。证明只覆盖这一个冻结语法和20段预算，不是所有F₁/所有来源分解的限制。它也不说明未来历史不会产生合格路径。
