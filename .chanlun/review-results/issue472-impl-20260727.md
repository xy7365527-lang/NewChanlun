## 0. 结论先行

本票代码改道已完成：

1. `Reset` / `RebaseVanished` 的 `TerminationSettlement` 均从已删除的 `Forfeit`
   改为 `WriteOffUnclosed`。
2. `Forfeit` 已无构造点，枚举变体、match 分支、witness `"forfeit"` 标签和过期注释已删除；
   `rg 'Forfeit|forfeit' rust/src rust/tests` 零命中。
3. 来源可分辨性保留：`suspension_by_source` 仍分别产 `reset` /
   `rebase_vanished`。
4. debug / release 两侧 `cargo test --lib` 全绿；wf8 关臂 dump 与金标准逐字节一致；
   开关臂四层报告逐字节一致；`other_violation_count=0`。

但票面预期“前三个实际核销桶获得原 Forfeit 的货/钱读数”**未满足**：

- 75 条原静默终局（`reset=67`、`rebase_vanished=8`）确已全部变成
  `settlement_by_side.write_off_unclosed`；
- 这 75 条请求进入 `campaign_book.write_off_unclosed` 后全部返回 `Ok(None)`，
  因而全落 `unclosed_write_off_nothing_to_settle={"long":48,"short":27}`；
- `unclosed_write_off_count` / `_units_gap` / `_cash_booked` 仍全空。

当前产物只能判定 `Ok(None)`，不能区分“该 `(级别, 侧)` 无 campaign”与“有 campaign
但该来源中枢无挂起批次”。本票按边界不改归属链/anchor 门，不把 #473 内容硬塞进来。
