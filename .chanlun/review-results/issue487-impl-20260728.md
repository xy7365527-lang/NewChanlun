## 实装

### 1. 挂起框冻结与候选传递

`CenterOscillationBook` 的挂起键仍为 `(VoiceSide, CenterId)`；值侧新增首次绑定时的完整
`Center` 快照。`CenterId` 不含会随延伸改变的 `end_index`，所以不能替代四边框。

生产触发从既有接线点把当时 `alive_center()` 的完整框写入挂起簿。两侧对同一身份共用首次冻结
框；旧 API 产生的无框挂起不冒充四边证候选。

classifier 不读取 strategy 或账户状态。接线层只把 `suspended_frames()` 的候选集合传给
`classifier::historical_bound_third_cert`，保持“无门”边界。

### 2. 四边配对证

对每个挂起旧框：

1. 从 `center.end_index` 右侧开始；
2. 同向续行不是 leave/retest 对，可越过；
3. 取第一组方向相反的相邻走势，前项为 leave、后项为紧随的 retest；
4. 第一组反向相邻对一旦价格失败，不再向后滑窗；
5. 价格只交给既有 `signal::judge_third_cert`，相对该框冻结的 `ZG/ZD` 严格判定。

因此，同价格带的新时间框穿越不能回填旧框；中间已经出现一组 leave/retest 后，远期相邻对也不能
回填。L0 与 L≥1 都复用本级生产投影的结构方向；九段升级同核心没有特例分支。

既有“最近中枢”三类点判定未改。挂起旧框证与同 source/侧的普通最近中枢点相撞时，旧框证改写
该事件的唯一 Owner，并抑制普通副本，避免同一三类事件先后破坏两个中枢。

### 3. historical-bound 路由

`CenterEventMachine` 新增显式 `KillResolution::HistoricalBound` 和
`push_point_historical_bound`：

- 只授权三类点；
- 目标必须是接线层给出的精确完整框；
- alive 与 `prev_slot` 仍先走原分支；
- 只有目标已在 consumed 历史链、且滑出主格/容读格时才命中 historical-bound；
- 只产该历史实例的 `Broken`，不移动当前 alive/prev；
- 无配对授权的普通点仍走原 `push_point`，历史目标仍为 `Stale`。

审计新增：

- `historical_bound_by_level`；
- `center_mis_kill_by_level`。

### 4. 事件去重和 #466 D0

历史证书按 `(level, CenterId, source_index, bits)` 去重；Owner 进入键，避免把不同框错误合并。
同 source/侧再按事件键唯一化，禁止双杀。

生产循环仍使用原 `step_center_oscillation_impl`。`OPSEM_DUMP_DIR` 开启时只把
`observe_rebase=true` 传入同一实现，#466 D0 的“重基前抓挂起表、决策后落盘”顺序未改。最终 wf8
