### 1.3 指纹（离线可复算，不依赖 optional 依赖）

三层 **FNV-1a 64**（`sha2` 在本 crate 是 `backtest_bin` optional feature，`--lib` 构建拿不到；
FNV-1a 是 20 行纯算术，Python verifier 逐字节复现）：

- `SourceRef.revision_ref` = `fnv(src|{lv}#{ord}|{start}|{end}|{lo}|{hi}|{center})`
- `TxnNode.revision_digest` = `fnv(node|…|{四边框}|{窗口}| + 各源 canonical 以 "," 连)`
- `source_order_digest` = `fnv(order| + 各节点 side + 其有序源 "{lv}#{ord};" )`（**源顺序变即变**）
- `txn_digest` = `fnv(事务头 + 各节点 revision_digest + 各边 + source_order_digest)`

规范串格式写在 `rebase_txn.rs` 各构造函数文档里；verifier（§5 附录）逐字段照抄，实测失配 0。

## 2. 变换边判定算法（`algorithm_version = d1a-edge-classify-v1`）

1. **先折窗口实体**：同一父窗口产出的 k 个节点（`emitted>1` 且 `win_start/win_exit` 逐值相同）
   折成一个实体，键取头节点的**有序种子三元组**（前三个源的 `lineage_id`）。
   不折就会把九段升级的 t≥1 子中枢误判成凭空 `created`。
2. **旧侧键经下级连续边重映射**：`lower_txn_id` 指向同 bar 紧邻下一级的事务；
   下级判 `continued_1to1` 的源做 old→new 换号；下级判非连续（`split`/`removed`/…）的源
   **打洞**（映到不可能相等的键位）——这就是"证明源 X 是同 lineage 的修订而非 ordinal 复用"。
3. **实体按键配对**：`1↔1` ⟹ `continued_1to1`（四布尔全 true，D0 §6.1 唯一可过继形态）；
   `1↔k` ⟹ `split`；`k↔1` ⟹ `merge`；`a↔b`（均 >1）⟹ 逐位配对、每对各按自己的种子三元组判
   （不因同组邻居的延伸吸收而连坐），配不上的记 `removed`/`created`；键在同侧重复出现 ⟹ 整片 `unknown`。
4. 旧侧无配对 ⟹ `removed`（新侧 null）；新侧无配对 ⟹ `created`（旧侧 null）。
5. `bijective := continued_1to1 ∧ functional ∧ injective ∧ unique`——D0 §6.1 的"全 true 才可过继"
   是一条可机检的布尔表达式，verifier 独立重算，失配 0。

### 5.3 差异归因：seq=24 / seq=55 的第三个种子源在下一级被九段重切

以 seq=24（bar 85532）为例，同 bar 有两条事务，`txn-00001457`（L1）的 `lower_txn_id`
指向 `txn-00001456`（L0）：

```text
L0 事务 txn-00001456（frontier_pop）：
  OLD L1#178  sources = 738,739,740 | 741..745（8 段，一个延伸中枢）
  NEW L1#178  sources = 738,739,740          ┐
  NEW L1#179  sources = 741,742,743          ├ 共享父窗口 (738,747)，emitted=3
  NEW L1#180  sources = 744,745,746          ┘
  edges: 178→178 / 178→179 / 178→180，全 relation=split

L1 事务 txn-00001457（cascade_prefix，dirty_e=84606）：
  OLD L2#45  seed = 176,177,178（旧 178 = 上面那个 8 段对象）
  NEW L2#45  seed = 176,177,178（新 178 = 只有 3 段的分裂头子对象）+ absorbed 179,180
  lower_edge_refs: [{old_ordinal:178, new_ordinal:null, relation:"split"}]
  edges: L2#45 → removed；null → L2#45 created
```

关键：新旧 `L1#178` 的 `CenterId (start_index, zd, zg)` **完全相同**（升级重切的子中枢按
第 33 课裁定继承 seed 三段交的核心），所以调研当时的临时探针（比"源 ID + 第三源 CenterId"）
看不出差别，判为"同 seed 修订"；本 seam 的递归链接看得出：那是一个 8 段对象被切成 3 个，
新 `#178` 只是其中的头三分之一——**同 ordinal、不同对象**，正是调研 §5.1 点名的 ordinal 复用假证。
seq=55 同型（`397` 在下级 `split`）。seq=66 的 `496` 也被下级判 `split`，但它在两种读法下都非连续
（种子右移），结论不受影响。

### 5.4 这需要一条裁定（本票不替裁）

- **严格读法**（当前生产默认）：父对象的种子源若在下一级未被证明是同一个对象，就不声明 1:1，
  按 D0 §6.2「`split` ⟹ 拒绝自动过继、`ambiguous` ⟹ 保持既有行为」的保守方向。
- **宽读法**：承认"下级分裂的**头子对象**延续父种子"（它保住了窗口起点与核心），
  于是 24/55 可过继，八条回到 7/1。

两条都**不需要改证书**——`seed_source_refs` 是原始 ordinal、`lower_edge_refs` 带真实下级关系，
verifier 两种读法都能算（§4 的 E 与 E′ 两节即两读法的机检产出）。D1b 接线时按裁定取一条即可。
诚实提示：若取宽读法，`RebaseVanished 8→1` 成立；若取严格读法，落地目标是 `8→3`，
其中 24/55 需要另一条"分裂头子继承"裁定才能进一步下压。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""#543 D1a 离线 verifier：对 wf8 转储复算 RebaseTransformTxnV1 构造证书。
用法：python3 i543_verify.py <dump_dir> [<rebase_observability.jsonl>]
A. schema/algorithm_version + 七组字段齐全；B. FNV-1a 三层指纹重算；
C. 四布尔与度数自洽；D. rebase_observability 覆盖；E/E'. D0 八条严格/宽两读法。"""
import json, sys, collections
MASK = (1 << 64) - 1; FNV_OFFSET = 0xCBF29CE484222325; FNV_PRIME = 0x100000001B3

def fnv1a64(s):
    h = FNV_OFFSET
    for b in s.encode("utf-8"):
        h ^= b; h = (h * FNV_PRIME) & MASK
    return "%016x" % h

def src_canonical(s):
    c = "-" if s["center_id"] is None else "{}:{}:{}".format(
        s["center_id"]["start"], s["center_id"]["zd"], s["center_id"]["zg"])
    return "src|{}#{}|{}|{}|{}|{}|{}".format(
        s["lineage_id"]["level"], s["lineage_id"]["ordinal"], s["start"], s["end"],
        s["envelope"]["lo"], s["envelope"]["hi"], c)

def node_canonical(n):
    w = n["window"]; read_end = "-" if w["read_end_src"] is None else str(w["read_end_src"])
    head = "node|{}#{}|{}|{}|{}|{}|{}|{}|{}|{}|{}|{}|".format(
        n["node_ref"]["level"], n["node_ref"]["ordinal"], n["full_center"]["start"],
        n["full_center"]["end"], n["full_center"]["zd"], n["full_center"]["zg"],
        n["full_center"]["dd"], n["full_center"]["gg"],
        w["win_start"], w["win_exit"], read_end, w["emitted"])
    return head + ",".join(src_canonical(s) for s in n["direct_source_refs"])

def order_canonical(nodes):
    out = "order|"
    for n in nodes:
        out += n["side"] + "|"
        for s in n["direct_source_refs"]:
            out += "{}#{};".format(s["lineage_id"]["level"], s["lineage_id"]["ordinal"])
        out += "|"
    return out

def txn_canonical(t, nodes):
    dirty = "-" if t["dirty_e"] is None else str(t["dirty_e"])
    canon = "txn|{}|{}|{}|{}|{}|{}|{}|{}|".format(
        int(t["txn_id"].split("-")[1]), t["bar"], t["level"], t["cause"],
        t["cascade_reason"], dirty, t["resume_start"], t["prefix_count"])
    for n in nodes:
        canon += "{}:{};".format(n["side"], n["revision_digest"])
    canon += "|"
    for e in t["transform_edges"]:
        o = "-" if e["old_node_ref"] is None else "{}#{}".format(
            e["old_node_ref"]["level"], e["old_node_ref"]["ordinal"])
        nn = "-" if e["new_node_ref"] is None else "{}#{}".format(
            e["new_node_ref"]["level"], e["new_node_ref"]["ordinal"])
        canon += "{}->{}:{}:{}{}{}{};".format(o, nn, e["relation"], int(e["functional"]),
            int(e["injective"]), int(e["unique"]), int(e["bijective"]))
    return canon + "|" + t["source_order_digest"]
```
