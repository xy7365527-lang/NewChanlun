## 2. D1：T3-in-c 固定首对分级器

判定锚 = **最后中枢 `last_center` 右边**（`start_index >= last_center.end_index`，含等值即紧邻，补充十五同源）——**不是** `λ_C`/`c_start`。leave = 该锚之后固定第一条段，retest = 紧随一条；方向互反；价格严格对该框 ZG/ZD（Up：`leave.end_price > zg ∧ retest.end_price > zg`；Down 镜像 `< zd`）。任一失败即 `Missing`，**不后扫**——`trend_third_class_in_c`（全 c 窗后扫取首个成功对）不复用，两者不是同一谓词。

五桶：`missing_leave` / `missing_retest` / `same_direction` / `leave_not_outside` / `retest_reentered`。

单测（8 条，`signal.rs::tests`，全部通过）：

- `t3_in_c_fixed_first_pair_present`（Up/Down 各一）
- `t3_in_c_fixed_first_pair_missing_leave`（空段列 + 锚右边无段两案）
- `t3_in_c_fixed_first_pair_missing_retest`（连续缺口单腿 c）
- `t3_in_c_fixed_first_pair_same_direction`（同向续行）
- `t3_in_c_fixed_first_pair_leave_not_outside`（leave 未破核心）
- `t3_in_c_fixed_first_pair_retest_reentered`（retest 重回核心）
- `t3_in_c_fixed_first_pair_does_not_rescan_past_first_pair_failure`（首对失败远对不认领，与 `trend_third_class_in_c` 同段列对照——扫描器会认领延迟三买，固定首对分级器不认领）
- `t3_in_c_fixed_first_pair_anchor_is_b_right_edge_not_lambda_c`（固定首对锚非 λ_C 坐标案例：锚取值不同给出不同判定）

**本票不切 bit 生产**：`judge_first_cached` 判据本体未改一行，`extract_signals`/`extract_signals_with_hist_anchored`/`extract_first_third_resume` 均未接触新分级器——否则域照置 buy1/sell1。

**解法**（不穿透调用链传参，且验证后 `mod.rs`/`recursive_tower.rs` 保持零改动）：

   取走当帧捕获、用**同一帧**返回的 `classification.levels[lvl].bsp` 反查补齐 `level`（同一
   `classify_at` 调用内产出，天然一致，非跨帧对照），随即为下一帧重开捕获槽；`runner.rs` 只在
   `pi_theta_fill_loop_overlay` 闭包内追加一行 `otherwise_domain_sidecar.observe_frame(&cls)`，
   `classify_at` 调用本体不变。
3. **为何要逐帧取走而非只读末帧**（关键教训，先试后订正）：先试了"只读末帧 `classification`"
   的简化设计——直接调用一个新增的 `classifier::grade_first_class_points_against_t3_in_c`
   （曾短暂加进 `mod.rs`，读 `classification.levels[lvl].bsp` + `TowerCache.projected_units`
   重建 segments）——wf8 全窗实测仅 **21/59**。根因：on2w3-07a frontier-resume 下，未确认前缀
   （tail）段每帧重判——某些一类点只在中间某帧短暂 `buy1/sell1=true`（触发 Reset 广播），随后
   段前缀增长后该段的 `judge_first_cached` 重判为 `false`（不再是一类点，几何被后续段改判），
   末帧 `bsp` 里已看不到它。Reset 广播本身是"读到 bsp 里瞬时 true 就广播"的即时语义，只读末帧
   系统性漏记这类点。改为逐帧取走 + 按身份键 upsert（同键覆盖，保留最新一次分级）后，记录数与
   `center_lifecycle.jsonl` Reset 行数逐一对应（见 §8.4）。此教训已从 `mod.rs` 撤回（该临时函数
   从未提交，仅本票返工过程内部试验态），最终版 `mod.rs`/`recursive_tower.rs` 零改动。
