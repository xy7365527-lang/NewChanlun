## 3. F6（低）处置：消费自动正确见证补记

**CloseRoot 改读面为零 = 结构保证，非缺锁**：主策略全平路径（`compose.rs`/`interp.rs`）的消费逻辑只读一类 bit（`buy1`/`sell1`）触发 CloseRoot；D2 生效后否则域点（Quasi）恒零一类 bit——CloseRoot 的触发条件本身不成立，不是"少了一把锁去挡住否则域点"，而是"否则域点从未拥有能开锁的钥匙"。这个保证由 bit 语义单向推出：`below_last_center: diverged && t3_in_c_present`（signal.rs），`t3_in_c_present=false` ⟹ 该 bit 恒 false ⟹ `endpoint_to_bsp` 六 bit 全零（S1/S2 报告已证）⟹ 下游一切按 `pf.bits.buy1||sell1` 或六 bit 任一位判断"是否第一类"的消费点自动排除否则域点。**未新增任何 guard/if 分支** —— 因为 bit 驱动架构下这类分支本就不该存在：新增一条"检查否则域并跳过"的显式锁反而是对同一约束的重复表达（双重来源，D2 设计说明 §2 明确拒绝"BspBits 旁载"正是同一纪律）。

**二类父母无 Quasi 自动不产真二类**：二类判据（`third_class_in_c`/二类分档逻辑）以父母是否携带一类 bit 为前提输入；Quasi（否则域零 bit 候选）不满足该前提，二类判据的合取项自然为假，不产真二类。同上，无需新增校验——这是同一 bit 语义单向传播的第二个消费点。

**证据锚**：wf8 全窗 `broken_by_level={1:47, 2:9, 3:1}` 合计 57、`cross_side_termination_count=6`、`center_mis_kill_by_level={}`、`other_violation_count=0`——D2 生效前后（关臂 `THETA_T3INC_SKIP=1` vs 开臂）**逐位不变**（impl 报告 §4/§5.2/§5.3），证明二类/三类/跨侧/MisKill 消费路径确未被 D2 触碰、也未因否则域点混入而产生虚假计数。这组 ignored 读数行（`m8_e2e_all_systems_oos --release --ignored`）即为"消费自动正确"的可复现见证——本节把这层因果（为什么不变）显式写出，此前报告只给了"不变"的读数，未给"为什么必然不变"的结构论证。
