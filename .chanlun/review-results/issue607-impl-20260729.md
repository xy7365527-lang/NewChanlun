## 2. D2：否则域不置一类 bit（大闸核心）

**接入点**：`judge_first_cached`（signal.rs），`diverged`（MACD C<A 背驰确认）计算之后、`EndpointSituation` 构造之前——

```rust
let t3_grade = t3_in_c_fixed_first_pair(sorted, last_center, trend_dir);
let t3_in_c_present = t3_in_c_skip_enabled() || matches!(t3_grade, T3InCGrade::Present { .. });
...
below_last_center: diverged && t3_in_c_present,
```

`struct_break_dir` **无条件置**（P2-R2 先例不变）——否则域点仍以零 bit 结构候选继续走既有候选流（`class_index()==0`，消选择偏差语义不变）。`judge_first_cached` 被两条调用路径共享：生产 `judge_segment`（`level=Some`，incremental resume）与诊断 `level_cand_delta`（`level=None`，#529 塔地盘不参与 D4 捕获，同 #606 S1 既有边界）——两条路径统一走同一大闸，无第二套判据分叉。

**无 BspBits 旁载**：名分 = bit 本身，未新增任何附件字段（grilling 裁定落地）。

## 3. D4：观测面挂点迁移（S1 遗留问题的必然后果修复）

S1 报告 §8.3 已述：D4 观测 sidecar 挂在 `judge_segment` 调用点，读 `pf.bits.buy1 || pf.bits.sell1` 判断是否捕获。**D2 生效后这个判断失效**——否则域点的 bit 已被二次门控清零，仅凭 `pf.bits` 观测会系统性漏记否则域点（无法与 #585 对拍）。本票把捕获逻辑挪入 `judge_first_cached` 本体，改用 `diverged`（背驰确认，T3-in-c 门控前的值）触发捕获，`side` 改由局部变量 `is_sell` 派生（不再读 `pf.bits.buy1`，因其在否则域点上恒为 false）。

## 5. D5：counterfactual 反证（env-gated `THETA_T3INC_SKIP`）

```rust

fn t3_in_c_skip_enabled() -> bool {
    *T3_IN_C_SKIP.get_or_init(|| {
        std::env::var("THETA_T3INC_SKIP")
```
