### 1.1 `LineageBook`（`lineage_book.rs`）

- **thread_local + 单 bar**：生产循环里 `classify_at(i)` 与 `step_center_oscillation_*(i, ..)`
  同线程紧邻，簿见到新 bar 即整簿重置；查簿时 bar 不符 ⟹ `BarMismatch`（fail closed，不做跨 bar 猜测）。
  多窗并行各线程独立成簿。
- **两套映射并存**：`strict`（追下级 lineage）与 `wide`（只比原始种子 ordinal）——两读法各自成簿、互不串味。
- **入簿门槛**：`relation == continued_1to1` **且** `functional ∧ injective ∧ unique ∧ bijective`
  全真（D0 §6.1 逐字），`old == new` 的恒等边不入簿。
- **冲突即歧义**：同 bar 同级同旧身份被判到第二个后继 ⟹ 永久置 `Conflict` ⟹ 拒绝过继。
- 计数：`migrated` / `kept` + 五条 fail-closed 归因（`no_cert` / `target_absent` / `ambiguous` /
  `bar_mismatch` / `duplicate_claim`）。

### 1.2 双层身份（`center_oscillation_trade.rs`，调研 §4.2 方案 C）

挂起表的键是**稳定锚**（首次绑定时的身份），不随重基改写；重基后的新身份经 1→1 证书
**别名**回该锚（`anchor_of` / `current_of` 一对互逆表）。触发、生命周期事件、挂起查询三条路径
全部先经 `resolve` 归一。

选这条而不是"直接改写挂起表的键"的理由（这是本票最重要的设计判断）：改键会同时要求
① 首次绑定冻结的四边框、② campaign 挂起归属账的来源中枢标签（`SuspensionBatch::center`）、
③ 历史绑定三类证书的去重键（`HistoricalSeenKey::owner`）三处**在同一事务里并发迁移**。
任何一处漏迁，减出腿记旧标签、核销走新标签，账就会静默错位成"无主欠账"——比不迁移更坏。
锚不动则三者天然自洽，一次迁移只改一张别名表。锚在两侧挂起都消失后随别名一起回收（`gc_anchor`）。

**冻结框不动**由单测 `migrated_suspension_keeps_frozen_frame_and_settles_on_the_stable_anchor`
逐字段锁死（迁移前后 `suspended_frames()` 恒等）。

### 1.3 fail closed（票面第 3 条）

`on_chain_rebase_lineage` 的判据分三层，第三层兜住一切：

| 情形 | 处置 | 分桶 |
|---|---|---|
| 当前身份仍在新链上 | 原样保留（既有"跟随迁移"，无需证书） | — |
| 有 1→1 证书 ∧ 新身份在新链上 ∧ 无第二个锚认领 | **迁移身份锚** | `migrated` |
| 证书指向的新身份不在新链上 | 保持 `RebaseVanished` | `target_absent` |
| 同一旧身份多候选后继 | 保持 `RebaseVanished` | `ambiguous` |
| 簿 bar 与本次重基不符 | 保持 `RebaseVanished` | `bar_mismatch` |
| 两个旧锚认领同一新身份（非单射） | 两者都保持 `RebaseVanished` | `duplicate_claim` |
| 无证书 / `lineage = None`（SKIP 臂） | 保持 `RebaseVanished` | `no_cert` |

**口径订正（评审条目⑤）**：`kept` 按 **(侧, 锚)** 计，五个 fail-closed 子桶（`no_cert` /
`target_absent` / `ambiguous` / `bar_mismatch` / `duplicate_claim`）按**锚**计——子桶之和是
去重锚数，只在没有锚双侧同时挂起时才与 `kept` 相等（wf8 单侧样本下恰好相等，见 §5，不能当
通用不变量外推）。不变的是**每个拒迁锚都有确定归因**，不留"无归因的核销"；`RebaseMigrationTally`
doc（`center_oscillation_trade.rs:424-436`）已同步改为此口径。

### 1.4 与 `OPSEM_DUMP_DIR` 解耦的代价与对冲

`rebase_txn::enabled()` 从"只看 `OPSEM_DUMP_DIR`"改为"谱系簿要建 **或** 要落盘"，
默认 ⟹ seam 在生产判径常开。对冲：**JSON 序列化改为按需**（只在落盘/捕获时做）——
它是 D1a 的开销大头（wf8 38.5 MB / 4172 行）。指纹计算保留（票面要求"带证书 digest 见证"）。
