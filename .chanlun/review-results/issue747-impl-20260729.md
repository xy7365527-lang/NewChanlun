## 1. 单源 API（`classifier/bsp.rs`）

生产 4 处手写规则先核语义是否逐字同构——**三处不同构，不强并**，故族内落地为 3+1 个函数（非
单一函数）：

| 函数 | 签名 | 语义（对应原手写形态） |
|---|---|---|
| `bsp_at` | `(bsp: &[BspPoint], source_index: usize) -> Option<&BspPoint>` | 纯等值 find-first，无 side 过滤（`signal.rs`/`fill.rs` 并集）——原 `bsp_at_by_id` newtype 入口修复轮已删（见 §3 降级裁决），二处调用点直调本函数 |
| `bsp_bit_at` | `(bsp: &[BspPoint], source_index: usize, pred: impl Fn(&BspBits) -> bool) -> bool` | 等值 + bit 谓词求**存在性**（find-first 换 any——同锚点多类点共存，与 `bsp_at` 不可互换；`econ_positive.rs::xzd_type2_confirmed` 单源） |
| `bind_turn` | `(bsp: &[BspPoint], turn_source: usize, side: Side) -> Option<&BspPoint>` | 等值 + `confirm_side` find-first（`nest.rs:690` 的 `TerminalMatch::Exact` 分支字面同构单源；该分支仅诊断/单测可达，生产恒走 `CWindow` 窗口臂，**非**「生产绑定规则原型」——订正见下 §3；nest.rs 自身不改调） |
| `bsp_all_at` | `(bsp: &[BspPoint], source_index: usize) -> impl Iterator<Item = &BspPoint>` | 等值取全部命中点（诊断枚举用，`p112:656` 单源） |

第 4 处（`admission.rs:883`）**类型不同构**：作用于 `TripleAnchorEntry`（跨级组锚回执），非
`BspPoint`——不进 `classifier::bsp` 族，改在 `classifier/projection.rs` 新增并行成员
`CrossLevelConfirmationQuery::entry_at(&self, source_index: usize) -> Option<&TripleAnchorEntry>`
（同一「source_index 等值 join」模式在不同类型上的并行实现，照实登记不强并）。

## 3. newtype 范围（「时刻分组键」vs「身份 join」类型层分开）——**修复轮：执行降级，不做**

评审 review-747.log 条目④裁定初版试点（`BspSourceIndex(pub usize)` 覆盖 `bsp_at_by_id` 两处生产
身份 join 调用点）「照实但名义化」——字段公开、两处均在同一表达式内 wrap 后立即解包、零跨边界传
递，spec #756 C1「时刻分组键 vs 身份 join 用 newtype 在类型层分开」未达成。

**二选一裁决**：选 **(b) 降级**，理由——

- 「时刻分组键」侧的真正同步定型点是 `Candidate.source_index`（`strategy/interp.rs`），该字段在
  全仓 **88+ 处**消费点上身兼「时刻分组键」（`strategy/mod.rs:543/759` 的分组过滤）与「身份 join」
  （本票 `bsp_at` 系列调用点）两种语义，要在类型层真正分开二者，需改 `Candidate.source_index`
  的字段类型并触达全部 88+ 处消费点——改动面远超两处 wrap/unwrap 的字面覆盖；
- 已试点的两处覆盖（`signal.rs::entry_structural_stop` / `fill.rs::entry_stop_reverse_dump_row`）
  本身零跨边界收益（同表达式内 wrap 即解包，未传递到任何签名边界），跨边界收益不抵改动面；
- 执行结果：删除 `BspSourceIndex` 与 `bsp_at_by_id`，两处调用点回改直调 `bsp_at(&lvl.bsp,
  c.source_index)`（裸 `usize`，与其余 15 处同形），`classifier/bsp.rs` 族头注释同步登记降级
  决定及理由；`bsp_at_by_id_matches_bsp_at`（自反空转测试，评审条目④/⑤指出的瑕疵）随函数一并
  删除，非「换非自反断言」——降级后已无该函数可测；
- spec 同步：`gh issue edit 756` 已把 Implementation Decisions 下 C1 该句标注降级登记（见 issue
  #756 正文，本报告提交前已执行，理由同上）。
