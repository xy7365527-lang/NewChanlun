- **方法论订正（评审 FAIL 核心成因，须固化为后续通用判据）**：本票初稿对 `RecStream`/
  `PyRecStream` 的核查复用了 Rust 侧类型名（`\.RecStream(`）grep python 调用面，但 PyO3
  `#[pyclass(name="RecTStream")]`（`ffi.rs:291`）对该类做了导出 rename，Rust 内部名在

  假阴性。后续一切"python 零调用⟹deprecated"判定，核查步骤须显式写出"经 `lib.rs` 导出名表
  逐一核对，非 Rust 内部名 grep"，否则不予采信。
