## Q1：原文怎么定义「同向」？

### 1.1 定义原句 [旧缠论]

`docs/chanlun/text/blog/017-第17课.md:46`（逐字，自 grep 核对）：

> 缠中说禅趋势：在任何级别的任何走势中，某完成的走势类型至少包含两个以上依次同向的缠中说禅走势中枢，就称为该级别的缠中说禅趋势。该方向向上就称为上涨，向下就称为下跌。

「依次同向」全博文 **只在 3 个课号出现**（`017:46,718,720,766`；`018:28,42`；`031:918`），其中 `017:718,766` 与 `018:28` 是同句复述、`017:720` 与 `031:918` 是读者引用提问。⟹ **定义句只有这一句，没有第二处独立表述。**

### 1.2 定义句本身不含判据——判据在紧随其后的一句限定里

`018-第18课.md:28`（同句复述 + **缠师自己补的限定**，逐字）：

> 缠中说禅趋势：……至少包含两个以上依次同向的缠中说禅走势中枢，就称为该级别的缠中说禅趋势。该方向向上就称为上涨，向下就称为下跌。**注意，趋势中的缠中说禅走势中枢之间必须绝对不存在重叠。**

⟹ **「同向」的可判定内容 ＝ 相邻中枢之间不存在重叠**。「绝对不存在」是强化词，不是对冲词。

### 1.3 ★ 承重最重的一条：读者直接问了「轻微重叠算不算」，缠师直接答了

`017-第17课.md:1146`（读者问，逐字）：

> ２、两个同向中枢能否的轻微重叠，假如是一个向上的趋势，第二个中枢的下边与第一个中枢的上边有重叠，这种情况会不会出现？

`017-第17课.md:1150`（缠师答，逐字）：

> 这将会构成高一级别的中枢。而在本级别中，也将这看成一个中枢。在一个趋势中，中枢之间是绝对不重叠的。

**这一问一答把 M-2 的争点逐字问掉了**：核心已分离（「第二个中枢的下边」高于「第一个中枢的上边」）但边缘有重叠 ⟹ **不是趋势，是高一级别的中枢**，而且在本级别上**看成一个中枢**（＝ M-1 已裁的「盘整＝该级别恰 1 中枢」）。

### 1.4 定量形式：中心定理一给歧义、中心定理二消歧义

`020-第20课.md:56`（中心定理一，逐字）：

> 缠中说禅走势中枢中心定理一：走势中枢的延伸等价于任意区间[dn，gn]与[ZD，ZG]有重叠。换言之，若有Zn，使得dn>ZG或gn<ZD，则**必然产生高级别的走势中枢或趋势及延续**。

`020-第20课.md:58`（中心定理二，逐字）：

> 缠中说禅走势中枢中心定理二：前后同级别的两个缠中说禅走势中枢，后GG<前DD，等价于下跌及其延续；后DD>前GG等价于上涨及其延续。后ZG<前ZD且后GG>=前DD，或后ZD>前ZG且后DD=<前GG，则等价于形成高级别的走势中枢。

**逐句读出三件事**：

1. **核心分离（`dn>ZG` / `gn<ZD`）在原文里是歧义信号**——定理一给的是**析取**「高级别中枢 **或** 趋势及延续」，它本身**判不出**是趋势还是扩展。
2. **消歧义的是外缘**——定理二用 `GG`/`DD` 把析取劈成两半：外缘也分离 ⟹ 趋势；外缘还重叠 ⟹ 高级别中枢。
3. **定理二是「等价于」（⟺），不是「往往是」**。⟹ 「后DD>前GG」既是充分条件也是必要条件。

⟹ **原文的「同向」判据 ＝ 外缘分离 `后DD>前GG`（向上）/ `后GG<前DD`（向下）。核心分离只是它的必要条件，不是判据。**

### 1.5 对冲词检查（本图两次栽在这上）

- `017:46` 定义句、`018:28` 限定句、`020:56` 定理一、`020:58` 定理二、`017:1150` 答疑 —— **五处逐字核过，零对冲词**（无「一般来说 / 往往 / 大致 / 通常」）。`018:28` 的「绝对」、`017:1150` 的「绝对」是**强化**方向，不是软化。
- **唯一带对冲词的相关句在 `035-第35课.md:16`**，且它是本组唯一能给 ③ 撑腰的原文，必须照实摆出来（逐字）：

  > 有两个最低级别中枢的走势，就是最低级别的趋势走势类型，**如果第二个中枢比第一个高，那就是上涨走势类型**，反之就是下跌走势类型。**一般来说**，假设依次存在着N（N>2）个中枢，只要依次保持着**第N个中枢比N-1个高**的状态，那么就是上涨走势类型的延续；依次保持着第N个中枢比N-1个低的状态，就是下跌走势类型的延续。

  **这句不能拿来支持 ③，三条理由**（不是因为它带「一般来说」，而是因为语境）：
  1. **它讲的是 `a₀` 最低级别**——上文 `035:16` 同句定义「连续三笔相同价位的交易，就构成最低级别的中枢」。#812 S-5 已裁这里的「笔」＝**成交笔**，其中枢是**同一价位**的点，**没有宽度**⟹ `ZD=ZG=DD=GG`，「比前一个高」在该级别上**四个口径全同**，不构成对有宽度中枢的口径主张。
  2. 「一般来说」这个对冲词**挂在 N=2 推广到 N>2 这一步上**，不挂在「高」的定义上。
  3. 有宽度时的精确式，缠师在 `020:58` 已经另给，且用「等价于」。⟹ `035:16` 是**在退化级别上的口语复述**，不是第三套判据。

### 1.6 「同向」是位置关系，不是中枢自带的方向属性

原文的「同向」只由**相邻中枢的相对位置**决定（`018:28` 不重叠 + `020:58` GG/DD 式），走势的方向是**从中枢序列读出来的**（`017:46`「该方向向上就称为上涨」）。缠师另有一句直接否认中枢自带方向标签（`031-第31课.md:390`，M-1 已收录）：「中枢就是中枢，哪里有什么盘整中枢、趋势中枢之分？」

⟹ **仓内 `Center.direction`（Z走势段方向，`a_center_v0.py:73-74`）不是「同向」的那个「向」。** 实查确认它也没被用在 `_centers_relation` 里（`a_trendtype_v0.py:113-139` 只读 gg/dd/high/low）——**这条是「没被误用」的正面核实，不是发现。**

### 1.7 中心定理二/三与「同向」的关系

| 定理 | 出处 | 与「同向」的关系 |
|---|---|---|
| 中心定理一 | `020:56` | 给出**核心分离**这个信号，并明写它是**歧义**的（趋势 or 高级别中枢） |
| **中心定理二** | `020:58` | **就是「同向」的判据本体**——把定理一的析取用外缘劈开 |
| 中心定理三 | `018-第18课.md:64` | 讲**单个中枢怎么被破坏**（离开 + 回抽不回），与「两个中枢之间怎么算同向」是**不同的问题**。#812 S-3 已把它裁成「中枢破坏 ≡ 第三类买卖点」。⟹ **定理三不参与 M-2**，但两者在同一个接口上：三类点后要么扩展成高级别中枢、要么新生成趋势（`021-第21课.md:34`，#812 S-3 推论二已裁） |

### 1.8 chan99 旁证（编纂版，仅作旁证）

`docs/chanlun/text/chan99/0011-第九节 走势及走势类型.md:9` 收了同一句趋势定义，但**删掉了 `018:28` 那句「必须绝对不存在重叠」的限定**（全 chan99 目录 `绝对不存在重叠`/`绝对不重叠` **零命中**）。⟹ **编纂版在这一点上比博文弱**，若有人只读 chan99 会读不出判据。照实记，不作判据用。

### 2.1 接受集：不是「互不包含」，是严格链 ② ⊊ ① ⊊ ③

**前提（构造保证，逐处核实）**：任一中枢满足 `DD ≤ ZD < ZG ≤ GG`。
- `rust/src/theta_v0/classifier/center.rs:216-227`：`zd=compute_zd(a,b,c)`（三段低点取 max）、`dd=compute_dd(a,b,c)`（同三段低点取 min）⟹ `dd ≤ zd`；`zg=compute_zg`（三段高点 min）、`gg=compute_gg`（三段高点 max）⟹ `zg ≤ gg`。`ZD<ZG` 由 `:219` `if zd >= zg { return None }` 硬保证（#812 Z-2 裁定）。
- `src/newchan/a_center_v0.py:150`（`_zseg_interval` 取 max/min）＋ `:262-263`（`gg=max(s1.high,s3.high)`、`dd=min(s1.low,s3.low)`）⟹ 同上。
- `src/newchan/a_zhongshu_v1.py:98-99` / `a_zhongshu_level.py:88-89`：gg/dd 在三段基础上**只会更外扩**（`:106-107`/`:97-98` 的 max/min 累积）⟹ 包含关系只会更松。

**推导**：
- **② ⟹ ①**：`next.zd ≥ next.dd > prev.gg ≥ prev.zg`。
- **① ⟹ ③**：`next.zd > prev.zg > prev.zd` ⟹ 下沿升；`next.zg > next.zd > prev.zg` ⟹ 上沿升。
- 反向都不成立（下面给反例）。

⟹ **② ⊊ ① ⊊ ③。票面「三者接受集互不包含」这句判据错，须订正。**

### 2.2 反例一：落在 ① 里、不落在 ② 里 —— 这一整块正是原文的「扩展」

```
前中枢 C1: DD=5,  ZD=10, ZG=20, GG=25
后中枢 C2: DD=21, ZD=22, ZG=30, GG=32
```
- ①（`c2.zd > c1.zg`）：`22 > 20` ✓ ⟹ **判「上涨趋势」**
- ②（`c2.dd > c1.gg`）：`21 > 25` ✗ ⟹ 判 `LevelExpansion`
- **原文**（`020:58` 第二支）：`后ZD(22) > 前ZG(20)` ∧ `后DD(21) ≤ 前GG(25)` ⟹ **「等价于形成高级别的走势中枢」**，即**扩展，不是趋势**。`017:1150` 逐字答的就是这个形状。

⟹ **① 与 ② 的差集，恰好等于原文中心定理二里「扩展」那一支的全部。** 这不是边界毛刺，是原文点名过的一整个语义类。

### 2.3 反例二：落在 ③ 里、不落在 ① 里 —— 核心公然重叠

```
前中枢 C1: ZD=10, ZG=20
后中枢 C2: ZD=15, ZG=25
```
- ③：`25 > 20` ∧ `15 > 10` ✓ ⟹ 判「up」
- ①：`15 > 20` ✗；②：更不成立
- **原文**（`018:28`）：「趋势中的中枢之间**必须绝对不存在重叠**」——这两个中枢核心重叠区间是 `[15,20]`，**连中心定理一的延伸/分离门都没过**。

⟹ **③ 接受的是原文明确排除的形状。**

### 2.4 ③ 那条链现在是什么状态

`_centers_relation_by_zg_zd` 只在一个地方被调用——`a_trendtype_v0.py:142-155` `_centers_relation` 的 else 分支，闸门是 `:150-153`：

