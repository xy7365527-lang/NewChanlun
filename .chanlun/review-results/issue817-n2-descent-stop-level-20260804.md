### 1.1 说法① —— 停执行级 e，partial chain 合法

判据表达式逐字（`:1031-1047`）：

```rust

    let mut rung_buf: Vec<NestRung> = Vec::new(); // 从低到高先收集，最后反转
```

### 1.2 说法② —— 末级必须恰为 ev

**真实位置**：`rust/src/theta_v0/strategy/nest.rs`，函数 `chi_bool`（`:126-146`）。**票面给的 `:120` 是 docstring 的那条 bullet，判据在 `:129`。** #809 原票写 `:129`，**是对的**；本票转述时用了 docstring 行号。

docstring（`:118-122`）逐字：

```
/// 输入：执行级 `ev`、级别链 `chain`（ℓ₀ 在表头，级别严格递减）。按结果包 §6 递归：
/// - **空链** ⟹ `false`（无级别 = 无候选 = 0）。
/// - **末级 ℓ** 且 `ℓ.lvl == ev` ⟹ 终端 `Confirm^δ` = `ℓ.confirm_ok`（且本级有候选）。
/// - **链头 ℓ + 次级 + 余链**（`ℓ.lvl > ev`）⟹ `Candidate^δ ∧ [次级 ⊆ 本级] ∧ 次级严格低一级 ∧ 递归`。
/// - **级别不匹配 / 链反向** ⟹ `false`（链不良构 = 无定位 = 0）。
```

判据表达式逐字（`:126-146`）：

```rust
pub fn chi_bool(ev: u32, chain: &[NestLevel]) -> bool {
    match chain {
        [] => false,
        [last] => last.lvl == ev && last.chosen().is_some() && last.confirm_ok,
        [head, next, rest @ ..] => {
            if head.lvl == ev {
                // 已到执行级却还有下级链 ⟹ 链不良构（执行级应是末级）⟹ 0
                false
            } else if head.lvl > ev {
                // 操作级/中间级：候选成立 ∧ 次级严格低一级 ∧ 次级套本级 ∧ 递归
                let mut tail = Vec::with_capacity(rest.len() + 1);
                tail.push(next.clone());
                tail.extend_from_slice(rest);
                head.candidate_ok && next.lvl < head.lvl && sub_b(next, head) && chi_bool(ev, &tail)
            } else {
                // head.lvl < ev：链反向（违反 o_v > … > e_v）⟹ 0
                false
            }
        }
    }
}
```

**停止条件三重封死**：① 末级必须 `lvl == ev`；② 到了 ev 还有下级链 ⟹ `false`；③ 链头低于 ev ⟹ `false`。**是四说法里对「底」约束最严的一条（在「底必须恰好是 ev」这个意义上），但它不要求 ev 是任何具体数值** —— `ev` 是入参，谁调用谁定。

### 1.3 说法③ —— 必须降到 a0

**真实位置**：`rust/src/recursive_t/divergence.rs`，函数 `nest_chain_complete`（`:547-586`）。

docstring 逐字（`:546`）：

```rust
/// 区间套链贯通：cc 层背驰(段)成立 ∧ 向下逐层 c 段钻取到 a0 各层皆有相应子背驰(段)。
```

判据表达式逐字（`:567-585`）：

```rust
    for k in (0..cc).rev() {
        let candidates = match level_trends_all.get(k) {
            Some(c) => *c,
            None => return false,
        };
        let child_win = match select_child_in_window(
```

**停止条件**：`for k in (0..cc).rev()` —— 从 `cc-1` 一路遍历到 **`k = 0`**，**每一层都必须找到子背驰段**，任一层 `None` 即 `return false`。**这是全仓最严的一条：不允许 partial chain，底硬钉在 `k=0`。** 与说法① 的 `partial chain 合法` **直接对立**（不是同端点的两种口径，是同一件事的相反规定 —— 但注意①管的是顶、③管的是底，所以对立体现在「链断算不算失败」这个共通维度上）。

配套的子窗判据（`:532-536`）逐字，说明它是**真区间套**（两端都收）而非单边收缩：

```rust
        if !(plo <= lo && hi <= phi) {
            continue; // 子窗须内含于父窗
        }
        if (lo, hi) == (plo, phi) {
            continue; // 链坍缩到同一段不算钻取一层（no-patch：宁断不放松）
```

## 3. 两套（实为三套）Lean 证书的终止条件对勘

> **本节只问终止条件 + 是否与 Rust 某说法同构。N-4 的「刻意不合并／无等价证明」只引原文，不裁。**

### 3.1 `formal/Origin/NestingCertificate.lean` —— Nat 级别差递归

递归定义逐字（`:185-190`）：

```lean
def nestCert (δ : Dir) (f : Nat → LevelData) (e : Nat) : Nat → Bool
  | 0 => Conf δ (f e)
  | d + 1 =>
      candOf δ (f (e + d + 1))
        && subB (jOf δ (f (e + d))) (jOf δ (f (e + d + 1)))
        && nestCert δ f e d
```

**终止条件**：递归变量是**级别差** `d`，基例 `| 0 => Conf δ (f e)`。包装器 `:199-200`：`def N (δ) (f) (ℓ e : Nat) : Bool := nestCert δ f e (ℓ - e)`。

`Conf`（`:123-126`）：`| .buy => d.b1 || d.b2 || d.b3` / `| .sell => d.s1 || d.s2 || d.s3`。

**「0」的语义**（`:167-170` 逐字）：

```
★递归骨架（与 IntervalNestCertificate 的列表链递归区分）：按级别**差** d = ℓ-e 归纳。
      d = 0 ⟺ ℓ = e ⟹ 基例 Conf^δ_e。
```

**⟹ `0` 不是 level 0，不是 a0，不是 level 1 —— 是「级别差为零」即「当前级 = 执行级 e」。** 机器见证 `N_base`（`:207-211`）：`N δ f e e = Conf δ (f e)`。

**无硬编码最小级别常量**：`e` 是自由参数；平移不变定理 `N_translation_invariant`（`:303-308`）正是「不依赖绝对级别」的机器见证。`:196` 逐字登记了一个边界：「★前置约束 `e ≤ ℓ`（spec P4 §6）：当 ℓ < e 时 Nat 截断 `ℓ - e = 0`，N 退化为基例 Conf^δ_e」—— **链反向被静默吞成基例，不报错**。

**无 `termination_by`/`decreasing_by`**（Nat 结构递归，Lean 自动）。

### 3.2 `formal/Origin/IntervalNestCertificate.lean` —— 列表链递归

递归定义逐字（`:416-431`）：

```lean
def nestCertB (ev : Nat) : List NestLevel → Bool
  | [] => false
  | [ℓ] =>
      -- 末级：必须恰好是执行级 ev，且本级有候选（chosen 非 none）+ 确认成立。
      decide (ℓ.lvl = ev) && (ℓ.chosen.isSome) && ℓ.confirmOK
  | ℓ :: ℓ' :: rest =>
      if ℓ.lvl = ev then
        -- 已到执行级却还有下级链 ⟹ 链不良构（执行级应是末级）⟹ 0
        false
      else if ℓ.lvl > ev then
        -- 操作级/中间级：候选成立 ∧ 次级套本级 ∧ 次级严格低一级 ∧ 递归
        ℓ.candidateOK && decide (ℓ'.lvl < ℓ.lvl) && subB ℓ' ℓ
          && nestCertB ev (ℓ' :: rest)
      else
        -- ℓ.lvl < ev：链反向（越下钻级别越高，违反 o_v > … > e_v）⟹ 0
        false
```

**终止条件：两个基例**（不是一个）—— `[] => false`（空链）与 `[ℓ] => decide (ℓ.lvl = ev) && (ℓ.chosen.isSome) && ℓ.confirmOK`（单元素）。

**有** 「末级级别必须等于 ev」的相等约束，且**双向封死**（`:420` 末级相等 / `:422-424` 已到 ev 还有下级拒 / `:429-431` 链反向拒）。

Prop 侧镜像 `NestCertPartialCorrect`（`:499-508`）同样两基例。

### 4.7 §4 汇总判定

**原文给的是「够用即止」，不是硬要求。三层理由：**

1. **「直到最低级别」这句里的「最低级别」不是绝对级别**，是使用者设定的塔底（`017:40`／`035:16`／`060:42`／`057:28`，全【正文】；`084:52/:54` 给出这件事的形式化根据，见 §4.8）。
2. **缠师对「钻到理论底」逐条自我否定**：`027:40`「只是最理想的情况」「不能证明极限点状」；`027:48`「意义不大」「已经足够精确了」「基本没什么用处」；`035:20`「太麻烦也没多大意义」；`033:18`「相当累，也没这个必要」；`060:42`「根本不具有操作性」。**五条，全【正文】。**
3. **停止判据在原文里是经济的，不是结构的**：`027:32`（资金规模）＋ `035:30`（交易成本/误差 vs 波幅）＋ `060:42`（成本/通道/资金规模）。**全【正文】。**

**⟹ 「必须钻到最低级别」在 110 课里找不到任何一条无对冲词的正文支持。** `级别`＋`停` 共句 9 条全部无关（涨停/跌停）⟹ **原文根本没有「下钻在哪停」这个提法**，只有「够用了就别再钻」。

### 4.8 ★ `084-第84课.md` 核实（#830/#850 的基底自由，marker `:68`）

**在案说「`084:52`／`084:54` 允许基底自由」——行号与结论都成立**，两条皆 **【正文】**（52 < 68、54 < 68）。逐字：

> **`084:52`【正文】** 「其次，分型只是中枢与走势级别递归定义的一个启始程序，甚至可以说，并不是本ID理论中必然需要的东西，其目的，不过是为了中枢等的递归性定义中给出其最开始的部分，**完全可以用别的定义去取代**。例如，我们可以用收盘的价位去定义顶分型、低分型结构，也可以用成交量给出相应的递归开始部分，**只要能保证分解的唯一性，就可以**。」

> **`084:54`【正文】** 「本ID关于中枢等的定义，其实一直没有改变过，因为中枢定义的关键，在于定义的递归性。一般的递归定义，由两部分组成，一、f1(a0)=a1；二、f2(an)=an+1；关于第二条的中枢过程规则，是一直没有任何改变的，**而关于第一条，其实，可以随意设置任何的，都不会改变中枢定义的递归性**。而且，任何有点数学常识的都知道，f1(a0)=a1之前是不需要再有什么递归性的，也就是，一和二之间的f1、f2可以是完全不同的两个函数。」

**本轮补出在案未登记的第三条（同段，同为【正文】）**：

> **`084:56`【正文】** 「例如，可以用分型、线段这样的函数关系去构造最低级别的中枢、走势类型，也就是一中的a1，而在二中，也就是**最低级别以上**，可以用另一套规则去定义，也就是有着和f1完全不同的f2。」

**⟹ 「基底自由」判定成立**：递归第一步 `f1(a0)=a1`「可以随意设置任何的」，唯一约束是「**分解的唯一性**」。

**★ 对 N-2 的四条后果（这是本票要的那个「后果」）**：

1. **「直到最低级别」不指定任何绝对级别** —— 它指当前所选级别塔的**底元素 a1**，而 a1 由你选的 `f1` 决定（分型+线段／收盘价／成交量／每笔成交／3 根 1 分 K……）。
2. **它是一个相对句，换基底整体平移** —— 加上 `084:60`「级别，本质上不对任何时间结构有任何绝对的承诺」，连「1 分钟」这种时间口径都不是级别定义的一部分。**⟹ 说法④「降到 level 1 停」被 `084:54` + `084:60` 两条【正文】直接反对：它把一个参数化的底钉成了字面量。**
3. **说法③「必须降到 a0」的措辞恰好用了 `084` 的记号，但意思反了** —— `084:54` 里 `a0` 是 `f1` 的**输入**（原始素材），`a1` 才是塔底元素。「降到 a0」若严格按 `084` 读，是要降到**原始 K/成交**那一层，而 `084:52` 明说这一层的构造函数**可以随意换** ⟹ **「a0」不是一个固定的级别，「必须降到 a0」这句话在 `084` 的记号系统里没有确定含义。** `recursive_t` 里的 `a0` 实际指「塔的底座单元（segment 或 stroke，可配置）」（`.chanlun/roadmap.yaml:972` 逐字「E1 受控 A/B（唯一变量=a0 来源）：BTC a0=段→笔」）—— **⟹ 说法③ 的 `a0` ≡ 说法⑥ 的「塔底」，两者在同一基底配置下重合。这两条说法的真差异不在「底在哪」，而在「中途断链算不算失败」。** （已在 §6.2 登记。）
4. **⟹ 任何把停止级钉成常数的候选（③④）都与 `084:52/:54/:56` 冲突；把停止级定成「塔底」（⑥/X2）或「经济判据」（X0）的候选与之相容。**

### 6.3 「实测钻不下去」是不是让四说法的分歧变成不可达的伪分歧

**是，但要分两层说，不能一句话糊过去。**

**第一层：分歧在生产上不可达 —— 成立，已举证到行（§2）。**

不是因为「钻不下去」，而是因为**四条载体里三条根本不在生产路径上，第四条（说法②）在生产上被单元素链字面量塌缩成一个 bit**。**举证行**：`interp.rs:580/:581/:586`（②的塌缩）、`econ_positive.rs:239` + `:1814`（①⑤ 只在 test）、`rec_stream.rs:399` + `rec_engine.rs:361/:363`（③ 门控默认关）、`server.py:432`（④ 默认关）。

**依 Notes N-1 预授权判定：①③④⑤⑥ 之间的停止条件差异 ＝ 伪分歧（生产产生不出能区分它们的输入）。**

**第二层：#852 的 d≥2=0 不能用来支持「伪分歧」这个判定 —— 这里必须自己拦一下。**

理由三条：

1. **#852 量的是「若开启会怎样」，不是「生产在做什么」。** 那个诊断 `nesting_descent_and_type1_reach_dx` 在 `#[cfg(test)]` 里（`econ_positive.rs:1814` 起的 test mod 内，展开循环在 `:7916-7930` 区间），它**主动**调用了生产默认不走的路径。⟹ 它证明的是「**开了也钻不动**」，这比「没开」更强，但**逻辑上是另一件事**。
2. **d≥2=0 是 ⑥ 的读数，不是 ①②③④ 的读数。** 拿 ⑥ 的深度分布去说 ③「必须降到 a0」是伪分歧，中间缺一步：③ 走的是完全不同的窗口链（`recursive_t/divergence.rs`，双端收缩、判据 `select_child_in_window`），**它的断链率没在本轮测过**。在案的只有 `settled/552:130` 那条 L3 否证（`n_a_path_switches` 21/24 = 0，@ a0=segment）—— **那条读数方向一致（③ 也钻不动），但它是 2026-06 的旧读数且只在一个基底配置下**。
3. **#852 自陈的最大未测口径会翻这个判定**：「**同坐标是探针的选择，不是原文字面要求**」——若允许**邻域**（次级别一类点落在背驰段区间内而非与 `src` 端点重合），窄口径的 0 可能变非 0。**邻域口径没测。** 若一改口径钻得下去了，①③④ 的分歧**立刻变成真分歧**。

**⟹ 照实的结论**：**「四说法分歧在当前生产配置下是伪分歧」这句成立，承重的是 §2 的可达性举证（六行代码），不是 #852 的 d≥2=0。** 「因为钻不动所以无所谓」这个说法**不成立** —— 钻不动是 ⑥ 一条链上、一种坐标口径下、一个基底配置下的读数，它撑不起对四说法的判定。
