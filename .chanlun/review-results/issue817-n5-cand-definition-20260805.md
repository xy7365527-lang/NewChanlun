## 摘要（先给结论，全部是事实层）

**票面前提「教义空洞 / 无定义式」是错的。** 全仓有**两份逐字定义式**和**两份人裁裁定**，而且它们互相不完全一致：

| # | 出处 | 名分层（ADR 0012） | 说什么 |
|---|---|---|---|
| A | `docs/formal-chain/区间套.pdf` **p4**（页眉 2026/7/1 19:40） | 形式化链（见 §2.1 名分说明） | **`Cand^δ_k(J_{k-1},t) := [C^δ_k(J_{k-1},t) ≠ ∅]`**，其中 `C^δ_k(J_{k-1},t) = {c ∈ C^δ_k(t) : J_{k-1} ⊆ I(c)}`，`C^δ_k(t) = {c : DivCand^δ_k(c,t)=1}` |
| B | `docs/formal-chain/关于背驰.pdf` **p10 §9.1**（页眉 2026/7/1 18:32） | 同上 | **`Cand^δ_ℓ = StructEligible^δ_ℓ`**，`StructEligible^δ_ℓ(s,s') = dir(s)=−δ ∧ Comparable(s,s') ∧ Extreme^δ(s,s')` ——并**逐字写了「而不是 `Cand=MACDdiv`」** |
| C | `chanlun/escalate/nest-migration-ruling-20260716.md` §五（人裁已签字） | 裁定文书 | **D1：Cand = 纯结构宽候选（dir ∧ Comparable ∧ Extreme），力度判据留在②** |
| D | `docs/adr/0006-n0-native-cand-and-sub-edge.md` 裁定文本 1（#537，2026-07-28） | **正本层** | **原生 `Cand^δ_ℓ` = 结构宽候选**（破中枢 ∧ A 配对 ∧ 映射成立）；**力度确认不进候选身份** |

**所以 N-5 的真题面不是「没有式子」，是三件别的事**：

1. **两个符号被当成一个。** A 里 `Cand^δ_ℓ`（= 候选集非空的**门**）与 `DivCand^δ_ℓ`（= 候选集的**元素谓词**）是两层。票面把 `cand_predicate.rs` 的四条件当成 `Cand^δ_ℓ` 的定义式——那份代码自己的文件头第 1 行写的是 `DivCand^δ_{Θ,ℓ}(s,t)`，**它实现的是内层元素谓词，不是 `Cand^δ_ℓ`**。
2. **四条件里的条件 4（Weak/MACD 面积）在「进不进 Cand」这一位上被三处明文否掉**（B 逐字「而不是 Cand=MACDdiv」、C 的 D1 人裁、D 的 ADR-0006 正本），而代码 2026-07-01 落地后**从未跟随**。条件 4 本身的判据有原文出处（027:32），但**它作为 Cand 合取项的位置无出处，且有反向裁定**。
3. **`Cand^δ_ℓ` 的定义式（A 式）全仓没有任何一处实装。** 四套 Rust 实装 + 一套 Lean 骨架，全部把它当成一个**独立的裸 Bool 字段/参数**，没有一处把它算成「候选集非空」。`strategy/nest.rs` 与 `formal/Strict/Nest.lean` 甚至**同时**持有候选集 `cands` 和一个与之无关的 `candidate_ok`/`Candidate` —— 两个字段本该是一个（后者 = 前者非空）。

**★原文侧另有一条本轮新找到的承重（§6.3）**：`061-第61课.md:26`【正文】（marker `:56`）逐字「**只要是围绕一中枢的两段走势都可以比较力度**…都可以**先假设是进入背驰段**。而当走势实际走出来，**一旦力度大于前者，那么就可以断定背驰段不成立**…在没有证据否定背驰之前，就要观察…其内部结构中的背驰情况，这种方法可以逐次下去，**这就是区间套的定位方法**」。⟹ 原文（1）给了 `Comparable` 的判据（围绕同一中枢的两段，且是「**都**可以」不是「取一个」）；（2）把**力度写成可撤销的否证门而不是候选构成条件**；（3）明说下钻发生在力度**尚未被否证**时。**这三条独立支持 B/C/D 那条路线（力度不进 Cand），且是原文级而非转述级。**

**生产可达性**：`Cand^δ_ℓ` 在两条生产链上**都没有被真正求值**。live 链（`strategy/interp.rs:580-586`）把它硬编码成 `true`，且链长恒为 1 ⟹ `chi_bool` 连读它的那条分支都进不去（双重不可达）。四条件那条（`econ_positive.rs`）的入口 `decompose_capturable_spread` 全部消费者在 `#[cfg(test)]` 内 + 一个 `rust/tests/` 集成测试。**⟹ 本组按预授权举证到行判为伪分歧：当下裁任何一支，零行为改动。**

### 3.2 条件 2（Comparable）—— **判据有出处；实现自加的「取最近」无出处**

- **形式化链**：`关于背驰.pdf` p10 §9.1 逐字 `Comparable(s,s')`（仅符号，本 PDF 未展开）。展开式见已归档的 `formal-criteria-20260705.md:60-70`（§3.4 逐字），引 `关于背驰.pdf §4.2`「同一上级趋势语境」：`∃ 上级容器 C, s',s⊑C ∧ s' 与 s 是 C 中可比的前后同向推进段`，并加一句用途说明「**排除『拿两个完全不在一个结构语境里的走势段比较力度』**」。
- **缠论原文**：`027-第27课.md:20`【正文】逐字：「一般来说，第二、三类的买点，都有一个三段的走势，第三段往往都破点第一段的极限位置，从而形成盘整背驰。注意，**这里是把第一、三段看成两个走势类型之间的比较**，这和趋势背驰里的情况有点不同，这两个走势类型是否一定是趋势，都问题不大，两个盘整在盘整背驰中也是可以比较力度的。」——「**两个走势类型之间的比较**」＝ Comparable 的原文承重。趋势背驰侧的跨中枢 C/A 配对口径，各裁定统一引 `0016:62`（本轮**未**独立复核 016 课行号与 marker，**照实登记为未验**）。

### 6.3 ★`061-第61课.md:26`【正文】—— 本轮找到的最承重一条，原文直接把两层制写成「区间套的定位方法」

marker `:56`（与票面已知界一致），`26 < 56` ⟹ **【正文】**。逐字全句：

> 「要比较力度，发现背驰，首先要搞清楚是哪两段比较，其实，**只要是围绕一中枢的两段走势都可以比较力度**。显然，对于60-65这个1分钟中枢，55-60与65开始的一段之间就可以比较。在实际操作中，65开始的走势，由于没实际走出来，所以在和55-60比较时，**都可以先假设是进入背驰段**。而当走势实际走出来，**一旦力度大于前者，那么就可以断定背驰段不成立**，也就不会出现背驰。**在没有证据否定背驰之前，就要观察从65开始的一段其内部结构中的背驰情况，这种方法可以逐次下去，这就是区间套的定位方法**，这种方法，可以在当下精确地定位走势的转折点。」

**这一句一次给出三件，全部落在 N-5 的靶心上：**

1. **`Comparable` 的原文判据式**：「**只要是围绕一中枢的两段走势都可以比较力度**」。⟹ 条件 2 从「有出处但要推」升为**原文近乎逐字**（`[旧缠论]`）。注意它比实现宽：原文说「**都**可以」（围绕同一中枢的任意两段），实现取的是「前序**最近**同向段」（§3.2 的无出处项）——**原文这里正面反对「只能取一个」**。

**照实登记的残余**：`027:22` 的字面（背驰段 ≔ 构成背驰的走势类型）仍是「力度进定义」的唯一原文依据，本轮**不判它作废**——但它是**术语定义**，`061:26` 是**该术语在区间套里的操作方式**，后者更贴 `Cand^δ_ℓ` 的语义位置。
