### 3. 丢弃率（口径 R 下 `ZD>=ZG` 不产出）

- 升级重切分支总共产出的子窗数（分母，= 触发窗口的 k 之和）：4,583。
- 其中 `ZD>=ZG` 被丢弃：**294**（丢弃率 = 294/4,583 = **6.41%**）。
- 分级别丢弃：L0=227、L1=58、L2=9、L3=0、L4=0（触发数=0，无从谈丢弃）。

具体例子（探针输出，前5条，价格单位 = tick×1e-8 美元，如 428909000000 tick = $4,289.09）：

1. `L0 win=(i=5,j=19) 子#1 segs[8..=10]`：段8 lo=$4,289.09 hi=$4,369.69；段9 lo=$4,134.61 hi=$4,309.92；段10 lo=$4,242.75 hi=$4,286.53 → ZD=max(lo)=$4,289.09，ZG=min(hi)=$4,286.53，ZD>ZG，丢弃。
2. `L0 win=(i=333,j=352) 子#5 segs[348..=351]`：段349 lo=$3,612.11 hi=$3,650.00 vs 段350 lo=$3,678.22 hi=$3,731.00 → ZD=$3,678.22 > ZG=min(hi)=$3,650.00，丢弃。
3. `L0 win=(i=493,j=507) 子#3 segs[502..=506]`：ZD=max(lo)=$4,312.01（段506）> ZG=min(hi)=$4,309.00（段502），丢弃。
4. `L0 win=(i=583,j=594) 子#2 segs[589..=593]`：ZD=$4,615.00（段592/593）> ZG=$4,600.00（段589），丢弃。
5. `L0 win=(i=630,j=652) 子#4 segs[642..=644]`：ZD=$5,670.49（段644）> ZG=$5,649.99（段642），丢弃。

共同特征：这些三段窗口的极值区间在 3 段范围内**彻底错开**（没有公共重叠区间）——口径 R 的"严格三段交"判据在这些点上是空集，与母中枢仍有核心（母中枢是 seed 三段交，覆盖更长窗口）并不矛盾：子窗只取窗口内某 3 段，局部可能确实无交集。

### 4. 下游翻转（部分可测，已如实标注未做部分）

**做到的部分（同级本地翻译，非级联）**：把触发级别的中枢序列按口径 R 替换（丢弃项跳过、保留项区间替换、其余中枢原样保留），直接喂生产 `decompose::decompose()` 读 Trend/Consolidation 块计数：

|---|---|---|
| L0 | 882 / 950 (+68) | 443 / 478 (+35) |
| L1 | 386 / 410 (+24) | 197 / 209 (+12) |
| L2 | 140 / 142 (+2) | 73 / 74 (+1) |
| L3 | 47 / 47 (0) | 26 / 26 (0) |

同级本地看：口径 R 因为丢弃了一部分子中枢（相邻子中枢合并/消失），走势分解切法跟着变，block 数和 trend 块数**都是净增**（中枢变少 → 原本被中枢隔开的走势段变少 → 更多段被 decompose 判成一个连续走势块，Trend 块数上升）。

**没做的部分（如实标注，不硬凑）**：
- **跨级级联未做**：口径 R 改变本级中枢数会经 `project_to_units` 改变下一级输入单元序列，逐级复算等价于另起一条平行完整管线（每级都要重跑 compose_level + project_to_units + 后续级别的 detect），超出本票探针预算。上表的 L1/L2/L3 数字仍是"生产 units 输入 + 本级替换"的本地读数，不是"L0 换成口径 R 之后级联到 L1/L2/L3"的读数——不能把这几行当作跨级传导的证据链。
- **买卖点（BSP）计数未做**：`extract_signals_with_hist`/`extract_first_third_for_level`/`extract_second_for_level` 参数面广（需要 MACD hist/dif、closes_tick、close_src、pan_div 等多个协同输入），且第二类信号依赖递归塔 `RMove::Compose` 的 subs 结构（口径 R 替换后 subs 与新核心不再自洽），接不通，未做。

- 保留的口径 R 子中枢样本数：**4,289**（= 触发子窗 4,583 − 丢弃 294）。

## 结论摘要（供 #812 Z-4 裁决用）

1. 升级重切分支**不是死代码**——占全部中枢产出的 38.5%，14.1% 的扫描窗口触发。
2. 口径 R 比口径 I 少产 294 个中枢（全历史 -2.5%），其中 6.41% 的子窗因三段无公共重叠区间被丢弃。
3. 同级本地看，口径 R 会让 Trend 块数上升（L0 +35，L1 +12，L2 +1）——跨级级联效应未测，如实标注未做。
4. 保留的口径 R 子中枢里，**48.8% 的核心区间落在继承来的母核心之外**——这是继承口径在近半数触发点上的结构性错位，不是口径差异的边缘噪声。
