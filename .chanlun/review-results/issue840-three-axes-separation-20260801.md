## 0. 一句话结论

**H-A 成立、H-B 否证、H-C 部分否证。三者确实不在同一根轴上，但不是票面猜的那三根。**

- **立体性 ＝ 纵向（级别轴）** —— 三条独立正文互证，H-A 成立。
- **多重赋格 ＝ 也是纵向（级别轴）** —— H-B「多重赋格＝横向」**被否证**。「多重赋格」里那个「多重」数的是**级别**，不是同一级别内的段。`038:30` 是独立第二证人，`100:20/:22` 是缠师本人给「层次」下的定义。
- **三阶段 ＝ 时间轴为主轴，但「与级别无关」不成立** —— 它被**操作级别门控**（`049:60` 明说小级别根本到不了成本为 0），且它的**实例单位是标的**（`031:30`「针对每只股票」），不是级别，也不是全局。

**⟹ 本票被要求正面裁的那个解释（#832「35 课与 40 课两幅图从未对齐」是因为两者在不同轴上）——否证。** 两者在**同一根轴**（级别轴）上，不对齐是真的，不是维度混用造成的假冲突。假冲突只消掉了「三阶段 vs 另外两个」这一对。

**副产物（本票最干净的一条）**：在缠师笔下，**份额只挂纵向轴，节奏只挂横向轴**。

## 2. `040:20`「N 重层次」判定 —— 本票最承重的一问

> `040-第40课.md:20`【正文，正文界 `:24`】
> 「对于大资金来说，这种级别的操作可以一直延伸下去，可以变成 **N 重层次的操作，每一重都对应着一定的资金与筹码**，而相应对应着不同的节奏与波动。……简单的动机、旋律在 **N 个层次上**根据不同的转位、移位、对位等原则运动着，合成统一的乐曲。……可以有机地统一在**多层次的同级别分解操作**中。」

### 判定：**「N 重层次」＝ N 个不同级别，每个级别各配一份资金筹码（纵向）。不是同一层内切成 N 段各配筹码。**

### 依据（四条，互相独立）

**依据 1 —— 缠师本人给「层次」下的定义（决定性）**
`100-第100课.md:20`【正文，正文界 `:50`】：「本ID的理论最重要的特点之一，就是自然给出了**分类的层次，也就是不同的自然形成的级别**。」
`100-第100课.md:22`【正文】：「例如，**30、5、1分钟的三个层次**所构成的系统里……」
⟹ 在缠师语汇里「层次」＝「级别」，是他**自己下的等式**，且举例即 30/5/1 分钟。中文里「层次」的双关（层内分段 vs 不同级别）**在本语料内被作者本人消解了**。这一条单独就能定案。

**依据 2 —— 同段下一句直接同义改写**
`040:22`【正文】：「可以在**任何级别**上进行操作，而且都遵守**该级别**的分解节奏与波动，只是在**不同级别中投入的筹码与资金不同**而已。」
⟹ `:20`「每一重都对应着一定的资金与筹码」＝ `:22`「不同级别中投入的筹码与资金不同」。逐词对位：**每一重 ↔ 不同级别**。

**依据 3 —— 独立第二证人：`038:30` 的分区卷钱机械是「N 重」的二分区版**
`038-第38课.md:30`【正文，正文界 `:44`】：「你可以设定**某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作**，这样，就如同开了一个**分区卷钱的机械**。」
⟹ 筹码分区的维度被明文写死为**级别**，且「另一个**更大**级别」直接排除了同层分段读法。`040:20` 的「N 重」是把 `038:30` 的二分区推广到 N。此证人在 40 课之外，与依据 2 不共源。

**依据 4 —— `:20` 的上文是「换档」，即沿级别轴上行**
`040:16`【正文】「一个小级别的操作是可以按一个自动模式**换档成一个高级别的操作**」；`040:18`【正文】「A0+A1+….+At=B1+B2，后者是 **30 分钟级别**的同级别分解……是否**换档**成后一种级别的操作」。
⟹ `:20` 开头「**这种级别的操作**可以一直延伸下去」的「这种」回指 `:18` 的换档；「一直延伸下去」＝沿级别阶梯继续上行 ⟹ N 重＝N 级。

### 副产物：横向轴在缠师笔下**不承载筹码分配**

`038:36`【正文】把同级别分解的操作程式写全了（第一段判背驰先卖出／第二段两种情况回补／第三段判盘背……「向上段的运作，都是**先买后卖**的……向下段的运作刚好相反，是**先卖后买**」），全程**没有任何筹码按段分配**——横向轴承载的是**节奏（买卖次序）**，不是**份额**。`108:36`【正文】同构（「底的时候要先买后卖，顶的时候要先卖后买」），与 #839 已产出的空头镜像一致。

⟹ **份额只挂纵向轴，节奏只挂横向轴。**

### 对 #828 的回答

#828 已裁「N 层并行持仓是本仓自主扩展」。本票查明：**扩的是纵向（级别轴）**。且**在「按级别分配筹码」这一点上其实不是扩展**——`038:30` + `040:20` + `040:22` 三处正文已明文给出骨架。若 #828 的「自主扩展」指的是层间对冲、净额化、ladder 相邻反向等，那部分仍是自主扩展；但「N 个级别各持一份仓位、各配一份筹码」这个骨架**有原文**。建议 #828 据此收窄措辞。

## 3. 「35 课与 40 课没对齐」——「因为在两根不同轴上」这个解释**否证**

#832 已判：`035:32` 是**主从**（一个主操作级别 + 次级别以下「部分操作」，功能限定为降成本），`040` 是 **N 重并列**，「缠师从未对齐过这两幅图」。本票被要求正面验证或否证「没对齐的成因＝两者本来在两根不同轴上」。

### 否证。两者在**同一根轴（级别轴）**上。

- `035:32` 的「次级别」「次级别的次级别」是**级别阶梯向下**；
- `040:20/:22` 的「N 重层次」「任何级别」是**级别阶梯向上/全域**；
- 两者都在级别轴上分配筹码（`035:32`「部分操作」＝部分筹码；`040:20`「每一重都对应着一定的资金与筹码」）。

同轴，故不是维度混用；#832 的「从未对齐」是**真分歧**。

### 那么真正的不对齐是什么？三条具体差异

| # | 差异 | `035:32` | `040:20/:22` |
|---|---|---|---|
| D1 | **有无特权锚点** | 有。「**在你的操作级别上，你是不参与任何调整或下跌走势类型的**」——主级别全进全出，其余级别只是「部分操作」附庸 | 无。「**可以在任何级别上进行操作**，而且都遵守该级别的分解节奏与波动」——各声部对等 |
| D2 | **展开方向** | 只向下（次级别、次级别的次级别） | 向上换档（`040:16/:18`），并「**一直延伸下去**」（`:20`） |
| D3 | **从属层的功能** | 被限定为**降成本**（「当然要操作一下来**降低自己的成本**」「只有当成本为0时，才算真正脱离风险」） | 无功能限定，是**独立完整**的一份操作（`040:22`「每一层次的操作都是**独立**又在一个整体的操作中」） |

**关键补正：`040:14` 本身也是主从。**
`040:14`【正文】：「二、**升级为大级别操作基础上部分保持小级别操作**」——形状与 `035:32` 同（一主 + 若干部分）。
⟹ **不对齐发生在 40 课内部**：`:14` 主从 → `:20/:22` 并列，缠师没交代这一步推广的合法性。#832 结论成立，但成因是**同一轴上从主从到并列的未加论证的推广**，不是维度混用。

## 4. 三阶段跨不跨级 —— 原文查证

### 4.1 三阶段的原文形态是**两阶段 + 一个边界事件**，不是三阶段

`031-第31课.md:24`【正文，正文界 `:32`】：「一个最简单又最有效的管理，就是当成本为0**以前**，要把成本变为0；当成本变成0**以后**，就要挣股票，直到股票见到历史性大顶，也就是至少出现月线以上的卖点。」
`048-第48课.md:22`【正文，正文界 `:32`】：「在成本为0**前**不断降低成本，在成本为0**后**不断挣筹码。」

⟹ 两处正文都是**两段**（降成本 / 挣股票），分界＝「成本为 0」这个**事件**。

仓内第二阶段「退本金」的原文对应是 `031:28`【正文】：「还要在股票达到1倍升幅附近找一个**大级别的卖点出掉部分**，把成本降为0。这样，**原来投入的资金就全部收回来了**。」——这是**达成「成本为 0」的那一个动作**，缠师没把它单列为阶段。

**⚠️ 名分警告**：`031:36`「成本为0前用机动资金做短差……股票翻倍后出掉部分仓位成本为0后……一直到大级别上涨结束全部卖出」——这段最接近仓内三阶段紧凑表述的文字，位于 `---------↑正文---------`（`031:32`）**之后**，以「注：资金管理的方法」（`031:34`）起头，**是编注，不是缠师本人用词**（#830 判例）。`.chanlun/definitions/fengkong.md` 权威链把第 31 课列为「资金管理三阶段——降成本→归零→挣股票」，其中「三阶段」这个切法的直接文字支撑落在编注上。
**⟹ 仓内三阶段把「退本金」单列为一段 ＝ 本仓自主细分，非缠师原句。**

### 4.2 跨级：**三阶段被操作级别门控** —— H-C「与级别无关」否证

`049-第49课.md:60`【正文，正文界 `:78`】：「保证成本降低以及筹码不丢失（成本为0后是筹码增加，当然，**对于小级别的操作，不会出现成本为0的情况**）」

⟹ 决定性。三阶段**能否走完取决于操作级别**：小级别操作永远停在第一阶段，到不了归零、更到不了增股数。这不是「与级别无关」。

同向证据（皆【正文】）：
- `031:24` 终止条件「至少出现**月线以上**的卖点」——终止判据本身是级别判据
- `031:28` 「除了途中**利用小级别**不断弄短差外，还要……找一个**大级别的卖点**出掉部分」——降成本的**机制**是纵向的（小级别短差服务于大级别持仓），与 `035:32` 立体性是同一件事
- `031:30` 「一直游戏到**大级别上涨结束**以后」

**H-C 的正确形式**：三阶段的**推进语义**在时间轴（单向不可逆，与级别无关）；但它的**可完成性**被级别门控，**执行机制**借纵向轴，**实例单位**在标的轴。是**跨轴**表述，不是纯时间轴。

### 4.3 有没有「大级别先归零、小级别后归零」？

**确认原文没有**（区别于「我没查到」）。对 110 课全量 grep `成本为0|0成本|零成本`（命中 30 余处逐条读过）以及 `退本金|收回本金|本金退`，**无任何一处把归零的先后顺序与级别高低挂钩**。最接近的是 `049:60`「小级别不会出现成本为0」——它讲的是**能不能归零**，不是**先后顺序**。

### 4.4 名称撞车警告（新发现）

`108-第108课.md:38`【正文，正文界 `:44`】：「而有技术的，根本就不需要什么小板凳，**按操作级别，分清楚目前是三阶段中的哪一段**」——此处「三阶段」回指 `108:36`【正文】的**底 / 中间连接过程 / 顶**（走势节奏三段），**不是**降成本/退本金/增股数。

⟹ 缠师原文中「三阶段」以术语形式出现的地方（`108:38`），指的**不是**仓内那个三阶段。另有 `000:60`/`019:290`/`037:86`/`064:496`（牛市成分股→成长股→重组股）与 `091:40`（未病/欲病/已病）两组同名异指。**仓内 `TStage` 这个命名在原文里是三重撞车的。**

## 5. 三者在 #805 四层里的落位 + 有没有实现在错误的层上

#805 四层：L-构造 `apply_t` / L-判定 `descend`（区间套） / L-操作 `sink` / L-选标的（算子 N）。

### 5.1 立体性 —— 层对了，但必须与区间套分名

| | |
|---|---|
| 原文该落的层 | **L-操作**（`035:32` 用次级别以下**部分操作**降成本，不是找精确点位） |
| 仓内落点 | `rust/src/recursive_t/t_engine.rs:612` `fn sink(&mut self, parent, sub, bar, c)`；`rust/src/recursive_t/rec_engine.rs:1637/:1648/:1652` `sink_guarded`/`sink`/`sink_impl`；守卫 `rust/src/recursive_t/prove_guards.rs:253-263` `prove_sink_descends`（「sub 必严格低于 parent」，违反即 panic；`:257` 注明父子 Δr 不恒 = −1，可跨级——**与 `035:32`「次级别的次级别」相容**） |
| 裁定 | ✅ **层对了** |

⚠️ **但立体性 ≠ 区间套。** 区间套（L-判定）在 `rust/src/theta_v0/classifier/descend.rs:65-80`（`enum RMove { Segment | Compose }`）、`:115` `pub fn descend(parent) -> &[RMove]`，调用者是 `rust/src/theta_v0/classifier/signal.rs:1394`（第二类买卖点结构判定）与 `rust/src/theta_v0/classifier/mod.rs:1848` `descend_leveled`。

（另有同名无关项：`rust/src/theta_v0/classifier/chain_cert/mod.rs:536` `fn descend`，链证书路径枚举，非区间套。）

### 5.2 多重赋格 —— 轴对了，但原文唯一明确要求的那一项 default 关闭

| | |

## 6. 剔除假冲突后剩下的真分歧（喂 #839）

### 已消掉的假冲突（维度混用）

- **F1（消）**「三阶段 vs 多重赋格谁包含谁 / 谁是谁的特例」——**问法本身不成立**。三阶段主轴在时间×标的，多重赋格在级别轴，可同时成立：N 个级别各持一份，每份各跑自己的三阶段。
- **F2（消）**「三阶段 vs 立体性冲突」——立体性是三阶段第一段的**执行机制**（`035:32` 一句话内两者相连：次级别部分操作 → 降低成本 → 成本为0脱离风险），不是竞争者。
- **F3（消）**「多重赋格是不是同级别分解（横向）的产物」——不是。「多重」来自级别轴；同级别分解只是每一重**内部**的运行规则（`040:20`「统一在多层次的同级别分解操作中」）。

### 剩下的真分歧（逐条，#839 复活时该裁的东西）

**R1｜主从 vs 并列：缠师两幅图不兼容，且断裂发生在 40 课内部。**
`035:32` + `040:14` ＝ 一个特权操作级别（全进全出）+ 从属级别（仅降成本、仅部分仓）；`040:20/:22` ＝ N 个对等声部各配资金各守节奏。差异三条：D1 有无特权锚点 / D2 向下 vs 向上无界 / D3 从属层功能是否限定为降成本。缠师从未论证 `:14`→`:20` 这一步。**仓内把两幅图合并进同一个 `layers`/`legs` 结构（`t_engine.rs:214` + `sink` 的 parent/sub），等于替缠师选了并列，且没记这笔账。**⟵ 首要待裁。

**R2｜三阶段的实例单位：逐标的（原文）vs 逐(级别,侧)（θ_v0）vs 全局单例（recursive_t / closed_loop）。**
三份实装互不一致，且没有一份是原文的单位。这不是术语分歧，是**建模单位错配**：多标的组合无法表达（`031:30` 明写这是常态）。且 θ_v0 把它按级别分——**分在了原文明说与它无关的那根轴上**。

**R3｜三阶段能否走完是否该被操作级别门控。**
`049:60`「对于小级别的操作，不会出现成本为0的情况」是明文约束；仓内 `TwState` 无级别维、`advance_to`/`tw_step` 无门控。要么补门控，要么明记「本仓自主放宽 `049:60`」。**不许默认为「不受影响」。**

**R4｜按级别分资金：有原文骨架，仓内 default 关闭，且注释把它整个归为无原文。**
存在性有原文（`038:30`/`040:20`/`040:22`）；数值无原文（量词只有「一定的/某个量/另一个量」）。仓内 `w_ℓ` 实装齐备但 `config.rs:229 enforce_level_cap: false`，且 `level_risk.rs:39-42` 注释称「缠论……不定义『每个级别该给多少资金』」——**订正为「不定义数值，但定义了这件事本身」**，并决定 default 是否该开。

**R5｜`depth_weights` 这条轴无原文对应物，却是当前唯一生效的资金分配轴。**
`voice.rs:206` default `[0.60, 0.30, 0.10]`。既然 `w_ℓ`（有原文骨架的那条）默认关闭，生产上实际按声部深度分钱。需给它立名分：是 Θ_risk 自设，还是应当让位给 `w_ℓ`。

**R6｜「N 重」的重数上界与分配律，原文只给骨架不给参数。**
`MAX_LEVEL = 8`（`rec_engine.rs:81`）、`MAX_LADDER`（`t_engine.rs:477/482`）是本仓自定。**确认原文没有**给重数上限、比例、大小资金分界值（#832 独立复核同结论）。任何比例规则必须挂「本仓自设参数」名分。

**R7｜立体性（配仓用的次级别）vs 区间套（定位用的次级别）在定义层未分名。**
仓内已分实现（`sink` @ L-操作 vs `descend` @ L-判定），但概念层共用「次级别」一词。#805「自相似 ≠ 递归」的同类问题再现。

**R8｜`TStage` 命名三重撞车。**
缠师原文「三阶段」实指：走势底/中/顶（`108:38`）、牛市成分股/成长股/重组股（`064:496` 等）、未病/欲病/已病（`091:40`）。**降成本/退本金/增股数从未被缠师称为「三阶段」**，且其三分切法的紧凑表述出自编注（`031:36`，正文界 `:32` 之后）。属命名卫生，不影响语义，但引文溯源会误伤。
