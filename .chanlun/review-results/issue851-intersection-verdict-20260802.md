## 1. ★ 交集计数（核心，第 1 件）

### 1.1 票面点名的四格（Type1，分母 = 34 例「坐标确有次级别条目」）

### 1.3 三条读数

1. **交集不是 0，但也远不是 100%。** 命题若成立，预测同侧命中 ≈ 100%；实测**同侧 2/34 = 5.88%**
   （全 66 例口径 **6/66 = 9.09%**）。#848 的窄口径「恒 0」确实是口径伪影——交集口径下有 2 个，
   不是 0 个；但 2 个离命题要的量级差两个数量级。
2. **★「标三类 ∧ 有盘背」= 0，且是硬零。** Type1 8/8、Type2/3 759/759，合计 **767 个「只带三类 bit」
   的坐标上，`pan_div` 命中 0 次**（同侧、反侧都是 0）。这不是稀疏，是**几何互斥**：三类 = 离开中枢后
   回抽**不重回**，`pan_div` 的 C 段 = **破核心**离开（`pan_div_side_with_policy`，
   `classifier/signal.rs:1076-1083`），两者在同一坐标上不可能同时成立。
3. **两群分不开。** Type1 同侧交集 5.88% vs Type2/3 6.36%，差 −0.48pp，**z ≈ −0.12**。
   换了第三把尺子（交集口径），#846 §7.1 / #848 §6.3 的「两群无分离」仍然复现。

### 1.4 编排者的原假设：**部分成立，但小，且它们本来就没被记成失败**

编排者的怀疑是「那 34 例里标成二买的，很可能相当比例同时挂着 `pan_div`，却被记成了失败」。

- **「相当比例挂着 pan_div」——任意侧成立**（26 个带二类 bit 的坐标里 10 个挂着，38.46%），
  **同侧不成立**（2 个，7.69%）。
- **「被记成了失败」——不成立**。#848 §3.2 的**宽口径**（BSP 层一类 ∨ `pan_div` 同侧）已经把这
  6 个同侧命中算成**成功**了（Type1 lvl≥1 层认 = 6，9.09%）。#848 从来没把它们记成失败；
  没做的是**把这 6 个与 bit 分布交叉**——那正是本探针补的，答案是「6 个里 2 个落在带二类 bit
  的坐标上，4 个落在压根没有次级别 BSP 条目的坐标上，0 个落在只带三类 bit 的坐标上」。

### 2.1 指示计数（同坐标可多格并计）

| Type1 | 同侧二类 | 1 | 8 | 4 | **13** |
| Type1 | **反**侧二类 | 1 | 0 | 12 | **13** |
| Type1 | 同侧三类 | — | — | — | **0** |

| Type2/3 | 同侧二类 | 38 | 62 | 259 | 359 |
| Type2/3 | **反**侧二类 | 54 | 49 | 230 | 333 |
| Type2/3 | 同侧三类 | 0 | 0 | 469 | 469 |
| Type2/3 | **反**侧三类 | 0 | 0 | 482 | 482 |

**#848 「侧向常是反的」这句要收窄。** 二类 bit 侧向是 **13 同 / 13 反，恰好一半一半**，不是「常是反的」。
真正一边倒的是**三类**：Type1 的 10 个三类 bit **全部反侧**（同侧三类 = 0）。#848 §4 第 3 条把
「lvl3 那 19 例 δ 全 short、次级别 buy2×11 + sell2×8」读成「连方向都对不上」——按本表，
那 19 例里 sell2 是**同侧**的，只有 buy2 那 11 个是反侧。原句成立但概括过头了。

### 2.2 唯一一个「全部对上」的样本

逐例 dump（原始数据 §4）里，**只有第 27 行**三项全部同侧对齐：

```
| 27 | lvl=1 | src=507767 | δ=+1(buy1) | 次级别 buy2(同侧) | 盘背同侧=是 | 二类锚 type1_src=507626 |
```

这正是 `101:32` +（ADR 命题）要的那个形状：大级别一类点坐标上，次级别标着**同侧二买**，
且同坐标挂着**同侧盘整背驰**。全窗 66 例里，**1 例**。

另一个同侧盘背命中（第 4 行，`src=380822`, δ=−1）配的是**反**侧 `buy2`。

### 2.3 有效样本量远小于 34（必须先说）

34 例按 `src` 聚成约 **9 簇**，最大一簇 19 例（`src` 442071–446503，跨度 4.4K bar，
全部 lvl3 单向 sell1 —— 与 #848 §6.3 点名的同一次行情事件）。**56% 的样本来自一次事件。**
按簇算，2 个同侧命中落在 2 个不同簇里 ⟹ 簇级命中 **2/9 ≈ 22%**。

两个数（5.88% 逐例 / 22% 逐簇）都不接近命题预测的 ~100%，但**它们之间差 4 倍**，
说明这个分母本身很软。**本轮的百分比不承重到小数点后一位。**

## 3. ★ 本仓有没有「类一类点」的载体？（第 3 件）

### **答：有。不是「无法被表达」，但表达是残缺的、且分成互不相通的两半。**

`027-第27课.md:66`（逐字复核）正式命名：「这时候就要用到这因为盘整背驰而形成的**类第一类买点**了」。
本仓 `CONTEXT.md:106-108` 有该词条，且标注为「★实装完成态（2026-07-29，#606/#607/#608）」。

实读代码，载体有三个，**没有一个会产出任何买卖点 bit**：

| # | 载体 | 位置 | 是否可按坐标查 | 产 BSP bit? |
|---|---|---|---|---|
| 1 | **`PanDivCert`**（真盘整背驰：同一中枢两次同向离开 + 面积 C<A） | `classifier/signal.rs:1044-1056`（结构）、`:1266` `judge_pan_div`（唯一构造点）；挂在 `LevelState.pan_div` | ✅ **可以**——本探针量的就是它 | ❌ `signal.rs:1032` 自陈「**不是买卖点**：本证书**不置任何 six-bit、不产 BspPoint**——盘整背驰不冒充同级 B1/S1」 |
| 2 | **否则域 / `T3InCGrade::Missing`**（`037:18` 的「趋势的壳、盘背的名」） | 判据 `signal.rs:466-467`；大闸 `signal.rs:506` `below_last_center: diverged && t3_in_c_present` | ❌ **不可以**——记录体 `FirstClassGradeRecord`（`:765`）只存在于 **thread_local 诊断 sidecar** `GRADE_SIDECAR`（`:787`），env 门控，仅 `opsem_dump.rs:363/383` 打开；**不进 `Classification` / `LevelState`** | ❌ 反而是**扣掉** bit：背驰成立但 T3-in-c `Missing` ⟹ 一类 bit 归零，降级为零 bit 结构候选 |
| 3 | `PanDivSubtype` / `PanDivShortRetraceObservation`（#639 短差档→盘背观测通道） | `signal.rs:838-869` | ❌ 观测投影，不挂级别态 | ❌ |

三条必须照实说的限制：

1. **生产 `pan_div` 要求 C 段破中枢核心。** `pan_div_side_with_policy`（`signal.rs:1076-1083`）
   生产路径 `allow_unbroken_c=false`；「C 端点严格落在核心内」那一支只供
   `judge_pan_div_observation`（`:1304`，#483 观测），**不进生产**。⟹ 本探针量到的是
   「破核心的盘整背驰」，不是盘整背驰全集。
2. **否则域那一半在坐标查询里是隐形的。** 它没有持久载体，只能间接表现为
   `mask=0 ∧ struct_break_dir=Some` 的零 bit 候选。所幸这 34 例里 **Type1 的 `mask=0` 计数 = 0**
   （Type2/3 = 3），所以本轮读数没被这个盲区吃掉；但**换一批数据它会**。
3. **`027:68` 的「类第二类买点」在本仓完全没有载体。** `grep quasi_second / QuasiSecond / 类第二类`
   在 `rust/` 与 `formal/` 全仓 **0 命中**。这一半是真的「无法被表达」。

⟹ 对命题「次级别一类点**或类一类点（盘整背驰）**」：**前半有载体（BSP 一类 bit）、后半有一个残缺
载体（`pan_div`，只覆盖破核心那一支）+ 一个查不到的载体（否则域）**。所以本轮**测得出来**，
但**测的是命题的一个下界**——真值只会 ≥ 9.09%，不会更低。

## 4. 二类点判据的口径（第 4 件）—— ★ 与原文直接冲突，实装缺陷候选

### 4.1 本仓写死了「不破一买」

单一控制点，逐行实读：

| 环节 | 位置 | 内容 |
|---|---|---|
| 几何判据 | `classifier/rmove_compose.rs:80-82` | `no_new_low(m1, m2) = m1.lo() <= m2.lo()` |
| 同上（卖侧） | `:88-90` | `no_new_high(m1, m2) = m2.hi() <= m1.hi()` |
| 按方向分派 | `:95-100` | `retrace_no_break(side, m1, m2)` |
| **硬闸** | `:160` | `if retrace_no_break(side, m1, m2) { return Some(SecondTypeStructure{..}) }` —— 在 `for i2` 内层循环里；**若无任何 `i2` 满足，整个函数 `return None`** |
| 唯一消费者 | `classifier/signal.rs:1390` | `let Some(structure) = find_second_type_structure(..) else { return Vec::new(); }` |
| 唯一产点函数 | `classifier/signal.rs:1415` | `make_second_point(..)` —— 全仓**只有这一个调用点** |

`m1` 由 `sub_level_type1`（`classifier/descend.rs:167-173` = 破中枢 ∧ 背驰）选出 = **次级别第一类离开走势**，
故 `m1.lo()` = 该次级别一类买点的价位。⟹ `no_new_low` ≡「二买价 ≥ 一买价」≡ **不跌破一买**，
且是 `None` 语义的硬闸：破了就**根本不产二类点**，不是打个标记。

### 4.2 与 `101:32` 正面冲突

> **`101-第101课.md:32`（逐字复核）**「(二)、最弱的情况 ／ 第二类买点跌破第一类买点，也就是
> 第二类买点比第一类买点低，**这是完全可以的**，这里一般都构成盘整背驰……」

原文把「二买跌破一买」列为第二类买点的**三种情况之一**（(一) 最强 = 二三类合一；(二) 最弱 =
跌破一买；(三) 一般性走势）。本仓的闸把 (二) 整类**判为不存在**。

**⟹ 实装缺陷候选（不是本票裁定）。** 归 #850 / SPEC #847 处置。

### 4.3 这个缺陷污染了第 1 件的读数（必须说）

`101:32` 的完整句是「跌破一买这种二买……**这里一般都构成盘整背驰**」。也就是说：
**原文认为「二买 ∧ 盘整背驰」最集中的那一群，恰好是本仓二类判据整类扔掉的那一群。**

⟹ §1 的「标二类 ∧ 有盘背 = 2 同侧 / 10 任意侧」这个**联合**格子，其低值**部分可由本仓自己的
二类闸解释**，不能干净地读成「二买和盘背在市场上不共现」。

**但这个污染不触及命题本身的读数**：命题问的是「该坐标上有没有同侧一类点或类一类点」，
不引用二类 bit。那个数是 **6/66 = 9.09%**（= §0 对拍过的宽口径），与二类闸无关。

## 5. 观察陈述（不是裁定）

**三条同时部分成立，按承重排序：**

### 5.1 交集比例低 ⟹ 「命题在本仓当前判据下不成立」这个结论**站得住，但 #848 的表述要改两处**

- 命题预测同侧命中 ≈ 100%（66/66 或至少 34/34）；实测 **6/66 = 9.09%**（逐例）／簇级约 2/9。
- **要改的第一处**：#848 §4 的「一类 bit 0 个 ⟹ 归类半句不成立」这个**论证路径**作废——那个 0
  是窄口径伪影。正确的承重数据是 §3.2 早就给出的**宽口径 9.09%**，而不是 §4 的 0。
  结论不变，**论据换了**。
- **要改的第二处**：#848 §4 第 3 条「侧向还常常是反的……连方向都对不上」概括过头。
  二类 bit 是 13 同 / 13 反，**恰好对半**；一边倒的只有三类（10/10 全反）。

### 5.2 本仓的「类一类点」载体残缺 ⟹ 9.09% 是**下界**，不是真值

- 生产 `pan_div` 只覆盖「C 段破核心」那一支；否则域那一半在坐标查询里查不到；
  `027:68` 的类第二类完全没有载体。
- ⟹ **补全载体后这个数只会涨，不会跌。** 但要从 9.09% 涨到 ~100%，需要漏掉的那部分占
  60 例中的 54 例——**本轮没有任何证据支持这个量级**，也没有证据排除它。**照实：未测。**

### 5.3 有一个格子是硬的，且它不受上面两条影响

**「只带三类 bit 的坐标 ∧ 盘整背驰」= 0 / 767**（Type1 8/8 + Type2/3 759/759，同侧反侧全零）。
这不是稀疏度问题（767 个样本，`pan_div` 全窗证书 2780+750+159+19+1 = 3709 条），
是**几何互斥**：三类 = 回抽不重回中枢；`pan_div` 的 C = 破核心离开。
⟹ **凡是次级别标了三类点的那些坐标，命题的「或类一类点」这条后路在本仓是结构性关闭的。**
34 例里有 8 例落在这个格子，那 8 例**没有任何口径能救**。

### 5.4 一句话

**交集指向「命题在本仓当前判据下不成立」——但它同时指出，本仓的判据本身有两个已定位的缺口
（二类闸与原文 `101:32` 冲突；类一类点载体只覆盖破核心一支且否则域不可查），
所以这次否证的强度弱于 #848 原先的表述，而不是更强。**

## 6. 没测到 / 跑不完 / 自相矛盾

- **窗口 26%，未跑全史。** 百分比不得外推——#846 已实证同类差异的符号在全史上会翻。
  200K 副窗 Type1 lvl≥1 = 0 例，无法作独立复现，只作代码路径冒烟。
- **有效样本量远小于 34**（约 9 簇，最大簇 19 例 = 56%）。逐例 5.88% 与逐簇 22% 差 4 倍，
  这个分母很软。**本轮不给置信区间**（给了也是假精度）。
- **没测**：补上「C 不破核心」的盘背支（`judge_pan_div_observation` 已有形状）之后交集是多少。
  该支在生产路径被明确挡住，本探针**不改判据**，故不测。
- **没测**：否则域点（`T3InCGrade::Missing`）落在这 34 个坐标上的量。载体是 thread_local
  诊断 sidecar，不进 `Classification`，**按坐标查不到**——这是载体形态问题，不是数据问题。
  间接证据（Type1 `mask=0` 计数 = 0）提示本轮没被它吃掉，但那是间接的。
- **没测**：把二类闸从「不破一买」放开之后，§1 的联合格子会变成多少。改判据出本票边界。
- **未解释**：8 个「同侧二类 ∧ **仅反侧**盘背」（逐例 dump 第 19–26 行，全部 lvl3、
  `src` 444969–446503、δ=−1、次级别 `sell2` 同侧、`pan_div` 却是 Long）。同一坐标上
  「同侧二类」与「反侧盘背」共现是什么几何，本轮**没有追**。它是 34 例里第二大的一个格子。
- **口径勘误（顺带）**：#848 与 ADR 0013 均引「`signal.rs:505`」指一类 bit 大闸；
  实读该行是 `retrace_not_reenter: false`，大闸在 **`:506`**。差一行，不影响任何结论。
