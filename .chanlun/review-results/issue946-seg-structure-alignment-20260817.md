## 方法（与 #944 同骨架，换测量对象）

结构层组装**逐字复用** `p944_bsp_layer_mismatch.rs::run_arm` 的生产口径：confirmed 线段
→ `zhongshu_from_segments` → `moves_from_zhongshus(Some(n_seg))` → `attach_persistence`
（对应 `orchestrator.rs:887-895`；`compute_bsps` 同一条结构链，`macd_ctx=None`、
`level_id=1`，生产默认）。**不接 `divergence`/`buysellpoint`**——BspKind 层不进测量面
（第二问裁定：样本天花板绕不开）。

中枢字段挂钟化注意点（易错，已按源码核实）：`zhongshu_from_segments`
（`zhongshu.rs:303-315`）先过滤 `confirmed && kind==Settled` 再扫描，故
`Zhongshu.seg_start/seg_end/break_seg` 索引的是**过滤后数组**；探针用同一过滤式重建
组件数组取段，中枢 bar 跨域 = `conf_segs[seg_start].i0 .. conf_segs[seg_end].i1`
（merged idx 经 `merged_to_raw()` 换挂钟）。

两层对齐判据（贪心一对一、gap≤tol、primary_tol=2h、环形平移 29/57/89/113/151 天——
全部逐字沿用 #940/#944）：

- **中枢本体对齐**：相容 = 时间 gap ≤ tol **且**价格区间相交（`max(zd) ≤ min(zg)`，「同区间」）；
- **离开结构对齐**：A 臂已破位中枢（`break_direction != None`）→ C 臂同破位方向；
  另报**条件读数** = 本体已配对且 A 侧已破位的中枢对里破位方向一致的比例。

## 对 #946 第三问（重裁）的输入

1. **结构层 A/C 远比买卖点层接近**：中枢本体 88.9%（剔 LLY 数据退化后 94.1%）、
   离开方向 90.9%，vs #944 笔中枢层买卖点 43.4%。失配的物理源头**更多在
   「结构 → 买卖点」判定链的下游**（背驰确认/买卖点构造对扰动的放大），而非线段中枢
   结构本身——与 C-窄裁定的假设（测结构对齐更贴近失配源头）一致地**证伪了
   「结构层已大幅发散」这一可能**。
2. **残余失配的长相**：2 例本体失配中 1 例是数据退化、1 例是中枢合并方式分歧
   （3 vs 2）+ 方向反转；没有「个别标的全烂」的集中模式（9/10 标的本体全对）。
3. **样本纪律照 090**：n=18 中枢 / n=11 破位，单窗、点估计，不够格当阈值判据
   （五件事纪律）；wide 档同向复现（75.0% / 71.4%，基线 61.3% / 48.6%）。
4. **本数据环境的可复制性已变**（见前置节）：#944 的精确复跑今日起不可能
   （HL 5000 根滑窗 + Yahoo 洞 + Binance 上线晚），后续探针要么接受左端漂移、
   要么由有 #944 原始数据的工位归档 `data/` 原件。
