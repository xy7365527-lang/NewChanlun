## 一、T6 精确定义（来自共识文档）

> Layer 3（搁置）: T6
> Leray R¹=0 条件——无 sheaf 工程基础，不可计算
> 保留为"未来规范接口"（Codex 建议，Gemini 同意）

T6 的数学含义：递归层级构造 f: Level_k → Level_{k+1}（粗粒化映射）上，
Leray 谱序列的 R¹f_* = 0（高阶直像层消失），即层级间无拓扑信息丢失。

这是对递归一致性的**范畴论表述**——比 T7 的组合学检查严格得多。

## 二、实现可行性分析

### 2.1 数学前提——需要定义但尚未定义的对象

实现 T6 需要先回答四个数学问题：

| 问题 | 当前状态 |
|------|---------|
| 递归层级构成什么拓扑空间/范畴？ | 未定义。RecursiveLevel 是组合对象，不是拓扑空间 |
| 粗粒化映射 f 的精确定义是什么？ | 未定义。build_recursive_levels 是算法，不是连续映射 |
| 在什么上定义层（sheaf）？ | 未定义。需要先有拓扑空间才能谈层 |
| R¹f_* 如何数值计算？ | 无现成方案。谱序列计算需要链复形和微分 |

这四个问题中任何一个都是独立的数学研究课题。在它们未解决之前，T6 没有可编码的规格。

### 2.2 工程基础设施

| 需求 | 当前状态 |
|------|---------|
| 层论（sheaf theory）库 | Python 生态无成熟库。sheaf-theoretic 计算极少有工程实现 |
| 谱序列计算 | 无现成库。需要手写链复形 + 微分 + 逐页计算 |
| 同调代数基础 | persim 只提供持续同调，不提供层同调 |
| 范畴论框架 | 无 |

### 2.3 复杂度评估

即使数学定义全部就位，实现 T6 需要：
1. 构造递归层级上的 CW 复形结构
2. 定义粗粒化映射的纤维
3. 在每个纤维上计算局部同调
4. 组装为谱序列并计算 E₂ 页
5. 验证 R¹ = 0

这不是工程任务，是数学研究。

## 三、T7 已覆盖的递归一致性需求

T7（已实现，已通过 Gemini×Codex 审核）提供的递归一致性保证：

```
B_{k+1} ⊆ Trim(B_k, τ)
```

即高级别条形码是低级别条形码经阈值修剪后的子集。这是 T6 Leray 条件的**组合学近似**：

| 性质 | T6 (Leray R¹=0) | T7 (条形码偏序) |
|------|-----------------|----------------|
| 数学层次 | 范畴论（层同调） | 组合学（集合包含） |
| 表达力 | 完整的信息无损条件 | 条形码层面的包含关系 |
| 可计算性 | 不可计算（当前） | 已实现，O(n²m) |
| 实际效用 | 理论上更强 | 实践中已足够检测递归异常 |

T7 检测的是：如果高级别出现了低级别修剪后不存在的条带，说明递归构造引入了虚假结构。
这正是 T6 想要排除的核心场景——只是用组合学语言而非层论语言表达。

## 四、替代方案评估

### 方案 A：Interleaving Distance（交错距离）

用持续模块之间的交错距离量化层级间一致性：
- 数学基础成熟（代数稳定性定理）
- 可用 GUDHI 计算
- 但仍需定义"层级间的持续模块态射"——回到 2.1 的问题

**判定**：比 T6 简单，但核心数学问题（态射定义）未解决。

### 方案 B：Mayer-Vietoris 检查

验证层级间的长正合序列：
- 需要定义层级的"交"和"并"
- 递归层级不是空间的覆盖，Mayer-Vietoris 不直接适用

**判定**：数学上不适配。

### 方案 C：保持 T7，增强诊断

在 T7 基础上增加：
- 未匹配条带的统计分析（已有 unmatched_bars 字段）
- 跨层 bottleneck 距离趋势
- 条带长度分布的 KL 散度

**判定**：工程可行，增量收益明确，不需要新的数学基础设施。

## 五、建议

**继续搁置 T6。**

理由：
1. T6 的四个数学前提均未定义——没有可编码的规格
2. Python 生态无层论计算库——工程基础设施不存在
3. T7 已覆盖递归一致性的核心需求（条形码偏序 + 真单射匹配）
4. 替代方案（交错距离、Mayer-Vietoris）同样面临"态射定义缺失"问题

如果未来需要更强的递归一致性保证，建议路径：
1. 先在数学层面严格定义递归层级的范畴结构（这是数学研究，不是编码）
2. 定义完成后评估是否需要 Leray 还是更简单的同调工具即可
3. T7 + 方案 C（增强诊断）作为当前的递归一致性守卫已经足够
