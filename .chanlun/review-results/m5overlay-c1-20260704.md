## 3. 边界条件（结论翻转条件）

1. **overlay=None ⟹ 净额路径 bit-exact**：`pi_theta_fill_loop_overlay` 的 overlay hook 是 sep_legs 的
   **只读旁路**——不改 cash/units/trade_pnls/equity。所有现有臂（17 个 `pi_theta_fill_loop` 调用点）
   传 None ⟹ 逐字节不变（测试 `run_theta_v0_pi_overlay_reconciles_and_bit_exact_net` 断言
   net_result.{n_orders,trades,strat_return} == run_theta_v0_pi）。**翻转**：若 overlay 反写净额 fill
   ⟹ 现有数字变 ⟹ 违 no-workaround 污染禁令。
2. **对账残差 < eps 依赖步序**：价格 PnL 必须用**本 bar rebalance 前**持有的 N/q_v 累计（先累计后
   rebalance），否则 [t−1,t] 区间头寸错配 ⟹ Σpnl_v ≠ N·ΔP。**翻转**：步序颠倒 ⟹ 残差爆炸。
3. **取整退化**：`q_units < lot/2` 的声部 round→0 ⟹ 不进 P^sep（未达最小手数，诚实退化非 bug）。
   base_units=NAV/px≈10⁴（默认无 gross cap）⟹ 实测无此退化；小 NAV 下声部可能全归 0 ⟹ N≡0。
4. **首轮 PnL 未归一化**：pnl_v/account_price_pnl 是**原始价格 PnL**（overlay sizing 单位 × ΔP，
   base_units=NAV/px），非按保证金/毛名义归一化的 overlay IR（PDF §6.3 `Π^overlay/M^overlay`）——
   量级大（72M on 1M NAV）是 sizing 口径，非 alpha。经济有效层（IR/回撤/尾部）是 M6+ 范畴。
5. **成本未入对账**：PDF §11 对账是**价格 PnL 净口径**（fee/funding/borrow/liquidation 是 M6）——
   本模块 pnl_v 不含成本 ⟹ 与净额账户**价格** PnL（非费后 PnL）对账。**翻转**：若加成本入 pnl_v
   但账户侧不加 ⟹ 对账破。
