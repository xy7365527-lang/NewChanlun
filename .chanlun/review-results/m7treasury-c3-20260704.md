## 1. 结论

### 1.1 L2 witness（真实 BTC 数据三阶段可达性）——**照实否定（161号合格）**

测试 `m7_l2_witness_treasury_reach_real_btc`（rust/src/theta_v0/backtest/runner.rs）喂真实 BTC（10万 bar 足量窗口，`M7_WITNESS_BARS=100000`）给生产 π 路径 `pi_theta_fill_loop`（与 `run_theta_v0_pi_inner` 逐字节同款调用），读生产真值源 `tw_final.stage`。窗口口径：任务明示「461万 bar 或足量窗口」——10万 bar 产 14472 真实订单（is_l2=true）即 L2 合规；全量 461万 bar 用 env 未设时跑（O(n²) 小时级，本轮用窗口出信号）。

- **is_l2 = true**（n_orders = 14472，真实交易流）
- **Reach(Stage=II)  > 0 : false**
- **Reach(Stage=III) > 0 : false**
- 终 TStage = **CostReduction**（rank=0，全程未推进）
- Q_T = 1000000（=Q_0）｜W_T = 0（<I_0=1000000）｜η_T = 437057（<η_*=1000000）
- free/holding = 261325 / 175732｜open_legacy_legs = 13｜**Σ已实现PnL = −562943**（TW 从 100万漂移到 43.7万）

**精确归因（差多少、卡在哪）**：stage 恒 CostReduction，卡在 **P3 RecoverCapital 门**（进 Stage II 的前置）——双重不满足：(a) holding=175732 < notional_in=1000000（持仓市值未累积过名义基线）；(b) free=261325 < recover_target=1000000（可退现金不足额）。**根因**：这 10万 bar 窗口生产策略 **Σ已实现PnL = −562943（净亏损）**——已实现利润为负 ⟹ TW 不增反减 ⟹ 无法累积持仓过名义基线、无足额 free 退本金 ⟹ 退本金门永不满足 ⟹ 三阶段停在降成本期。

**这是数据层否定，不是架构不可达**：合成 witness `pi_loop_realized_profit_reaches_earning_shares`（L1）已证机制在足额已实现利润下可达；本 L2 witness 证真实 BTC 该窗口 + frozen Θ **不产足额已实现利润**（净亏损），故三阶段自然不推进。与 memory `project_type1_goal_closed_final_inconclusive`（signal 层无方向 alpha）一致——signal 无 alpha ⟹ 已实现 PnL 无正累积 ⟹ treasury 三阶段不可达是 signal 层结论的下游必然。

### 1.2 κ 风险政策裁定（codex decide，选择类）

**冻结 κ = 0**（M7 正式最小风险政策口径，非 workaround）：η_* = L^wc，只验证三阶段机制在最低合法 barrier 下是否真实可达。

- **网格**：{0, 0.5, 1.0, 2.0} 作为 L2 敏感性诊断，但**不作为 M7 通过门槛**；L3 跨标的/OOS 的 κ 选择推迟到 M8。
- **关键实现约束**（codex 明确）：`RiskPolicy.kappa` 是 i64，**不能诚实表达 κ=0.5**。不允许静默改成 {0,1,2}——要么补 fixed-point 语义，要么标「0.5 实现未支持，网格未完成」。M7 当前只冻结 κ=0，网格实装是 M8 前置。
- **阶段边界**：M7 冻结 κ=0 + L2 单标的敏感性诊断；M8 做 L3/OOS 跨标的 κ 选择，正 κ 只能在 M8 裁成生产风险政策。
- 裁定全文：`.chanlun/review-results/.kappa-ruling-output-20260704.txt`（gpt-5.5 xhigh）。

## 3. 边界条件（结论何时翻转）

- **L2 witness（本轮结论=否定）**：结论翻转为「可达」的充要条件 = 真实 BTC 该窗口产**正**且**足额**的已实现 PnL（≥notional_in 使 holding 累积过名义基线 + free≥recover_target）。本轮 Σ已实现PnL=−562943（净亏损）⟹ 否定。翻转触发点：换 signal 层有 alpha 的 Θ / 换有正 drift 的窗口/标的 / 加杠杆使名义基线相对 NAV 更低。否定性结果照实合格（161号），不改实现凑 PASS。
- **κ 裁定**：若 L2 witness 显示 κ=0 都不可达，则任何 κ>0 更不可达，正 κ 扫描无意义（codex 依据）；若可达，M7 只能声明「最小 barrier 下可达」，不能外推为「风险稳健」（需 M8 L3）。
- **守卫**：debug_assert 在 release 下不生效（codex R3 §9.3 已把 OQ-9/cash-sound gate 从 panic 改 Result）——本 assert 是 debug 可观测断言，恒真（enter_ready 蕴含），不承重生产错误处理。
