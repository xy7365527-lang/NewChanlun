## 1. 结论：SHIP

07a（`extract_signals_with_hist{,_anchored}` 一/三类提取）从「每 memo-miss 全量重判全部 S 段」
改为「confirmed 前缀段的点缓存复用 + 只重判 frontier tail」——**07a O(n²) 主导项已消除**。

doc①（on2-fix-classifier-signal-rs）Q3 的 NO-SHIP 是 **signal.rs 单域**裁定（asymptotic 状态只能挂
mod.rs::LevelCache）；H2 裁定 Q1=B（resume 属 mod.rs 域）。本件按 handoff 落地：resume 状态全在
`LevelCache`，signal.rs 提供纯函数 resume 入口（doc① 边界条件翻转达成）。

### 核心机制

- **诊断先行（on2w3 实测，BTC 前 1M bar，HEAD=548698be5f）**：07a 仍超线性（400K=588ms→1M=4422ms，
  **exp≈2.20**，doc① NO-SHIP 的 2.25 在旧 HEAD 复现）。分解：
  - **逐段判定循环 = 94%**（1M loop=5517ms，ΣS=48M ∝ n²）——**真 O(n²) 靶**。
  - **setup = 4%**（1M=234ms，decompose 15ms + gate/kind/first_match O(C) 数组），也是 O(C)×miss=O(n²)
    但 25× 小。
  - **`pos == c_idx` 恒真**（实测 0/7.17M 分叉）——中枢 end_index 严格递增 ⟹ 三元组唯一 ⟹
    `first_match_idx` 冗余。
- **sound 冻结锚（doc① Q2 handoff 精化）**：段 i 可封 ⟺ `seg[i].end_index < e_src`，
  `e_src = min(centers[prefix_count-2].end_index, dirty_e)`。证明充分性：
  - **seg 不可变**：end < confirmed 中枢终点 ⟹ 落 confirmed 段前缀（§16）。
  - **趋势门冻结**：最近中枢 c_idx ≤ prefix_count-3（seg.start < centers[prefix_count-2].end）⟹
    关系 R_j (j<m-2) 已 sealed（decompose 冻结不变量）⟹ gate/kind 值稳定；rightward run 延伸不改内部
    中枢门值。
  - **A/C 窗口 + hist**：全后向（< c.end < seg.start）+ append-only ⟹ 冻结。
  - **cascade 兜底**：`dirty_e`（on2w2 生产的最小改变源坐标）取 min，frontier 改写时 e_src 左退。
- **bit-exact 铁律（构造性，非巧合）**：缓存按 push 序（段 i 序：type1→type3；pan_div 分开）存前缀点，
  `cache ++ advance[cached..stable] ++ tail[stable..S]` == full 路径 pre-sort `points` 向量**逐元素相等**
  ⟹ 同一 `sort_by_key(source_index)` 稳定排序逐字段 bit-identical。
- **setup 线性化**：`blocks` = caller 已增量续折的 `decompose_resume` 输出（**不重 decompose**）；门/类别用
  pointwise `center_own_dir_at`/`center_block_kind_at`（O(log C)/段，不 materialize O(C) 数组）；
  `first_match_idx` 删除（pos==c_idx 恒真）。

## 4. 边界条件（结论翻转）

- 若 `bit_exact_per_bar`（含 resume 神谕 debug_assert）任一 bar 增量 != 全量 ⟹ 冻结边界/push 序/
  pointwise 门不变式被违反 ⟹ 回滚。**实测 50K 全绿**。
- 若 e_src 常态坍缩到 0（prefix_count<2 或 dirty_e 恒为 0）⟹ 退化全判，无收益但仍 bit-exact
  （守卫 `cached_count>stable_seg→clear`）。**实测 exp 2.20→1.63 ⟹ 前缀复用生效，前提成立**。
- 若中枢 end_index 非严格递增（三元组重复）⟹ pos==c_idx 假设破 ⟹ resume debug_assert panic。
  非重叠扫描恒保证严格递增，debug_assert 守护。
