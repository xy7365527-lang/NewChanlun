### 第二层（语法层）：对抗验证否决故事族时揭示的真实代码语义

故事族未存活，但对抗验证在否决过程中逐条核实了代码锚点，反而**揭示了实装的语法事实**——这些事实是本次诊断真正交付的操作语义诊断，方向与故事族声称相反：

**(a) 第一类 bsp 有趋势门控（F1 否决依据）**：`signal.rs:1074` `if let Some((pos, dir)) = gate_dir`——gate_dir 由 `center_trend_gate`（decompose.rs）给出，仅在段所在走势块 ≥2 同向中枢（Trend(方向)）时为 Some。盘整/扩张/mixed 块 ⟹ gate_dir=None ⟹ Type-1 分支整体跳过。这正是关于背驰.pdf p1 引第37课「A、B 必须是同级别中枢所构成的趋势语境」的严格实装（task #143 已结算）。故事族 F1 声称"bsp 在全定义域触发无前置过滤"与此**相反**。故事族把 `signal.rs:586`（`judge_pan_div` 内部子检查）误标为 bsp 检测锚点。

**(b) 三类点定义域检查存在（F3 否决依据）**：`signal.rs:389-427` `judge_third` 的 match guard 硬编码：
- 3买：`(Some(Up), Down) if leave.price > c.zg && retest.price > c.zg`
- 3卖：`(Some(Down), Up) if leave.price < c.zd && retest.price < c.zd`
- 兜底：`_ => None`（line 424）拒绝所有触及中枢的情形。

leave 段端点必须在中枢外，retest 段端点也必须在中枢外——结构上不可能在 entry_px ∈ [zd,zg] 时产出三类点。故事族 F3 声称"未拦截 inside-center 触发"是误读，定义域检查是先决条件非缺失。

**(c) 级别扩展不使证书失效（F2 否决依据）**：`interp.rs:133-138` `op_parent` 字段注释明文：「区分 pop(e)（操作父，开腿时用，驱动持仓生命周期）vs pstr_i(e)（结构父，当前 snapshot，可变）。**更高级别涌现时 pstr 变，pop 不变 → 腿不 Stale（§6）**」。`EntryCertificate`（line 155-160）字段 `level`/`source_index` 明注「入场时刻值，冻结不漂移」。实装不仅没有"bsp 证书随级别扩展失效"的机制，反而**主动用 pop/pstr 分离来防止**这种失效。故事族 F2 的"走势级别扩展使低级别 bsp 证书失效是缠论递归结构的必然推论"——三份被引 PDF（级别容器.pdf/关于背驰.pdf/递归完全分类买卖点.pdf）均无此命题（grep "证书失效|bsp.*失效|invalidat" 全空），且被代码直接否决。

**(d) 生产路径消除 orphan frontier（F4 否决依据）**：`interp.rs:402-407` `tree = extract_carrier_forest(tower)`——K_i 操作 carrier forest，endpoint-complete（∀g∈B_i ∃!c∈K_i: ρ(c)=s(g)）。`interp.rs:640-641` A12 双视图切换（648 裁决 D，settled）——生产操作路径的元素宇宙从 T_i 切到 K_i。子声部.pdf §10 明确将 Route A（T_i' = T_i ∪ F_needed）列为合法路线。故事族 F4 声称"实装允许 parent_id=null 的 voice 开仓"——但 `runner.rs:555-566`（被引为 564）的注释明文说 Ambient 在旧口径下「候选恒空 ⟹ 零订单」，方向与声称相反。生产 K_i 路径下 orphan frontier 不存在。

**(e) 父子同向叠加是 PDF 允许的 SubFollow 语义（F5 否决依据）**：`interp.rs:1147-1232` `interpret_with_close_triggers` 的 fold slot key = `(level, dir)`（line 1218 `(lv, d)`），非 source_index。父子不同 level ⟹ 不同 slot ⟹ 可同时入 ℬ_x（开仓桶）。买卖点.pdf §7.4 SubFollow（p5/15，line 114-129）verbatim：「次级别顺父方向，可以作为同向子腿；不是短差」+「ℓg < ℓα(g), δg = σα(g)」——原文显式允许父子同向独立开仓。故事族 F5 声称"父子同 source_index 同向应去相关为单一动作"，直接否定 §7.4。F5 把 AncOK（孤儿过滤器）误读为去相关算子——范畴错误。

**(f) 背驰实装是单指标标量比较，非支配序（F6 否决依据，真实缺口）**：`src/newchan/a_divergence.py:195` `if force_c < force_a:`、`a_geometric_momentum.py:302` `is_div = ... force_c < force_a`、`a_nested_divergence.py:200/275` 同模式——全部实现单指标标量比较（MACD 面积或价格振幅×持续时间），无任何位置实现关于背驰.pdf p5-6 定义的支配序（s≺_A s' ⟺ ∀m∈A_l, m(s)≤m(s') ∧ ∃m∈A_l, m(s)<m(s')）。关于背驰.pdf p3-4 明文警告：「如果用 M_MACD 作为唯一背驰判据，就会把很多'结构力度弱化但 MACD 不弱化'或者'MACD 弱化但结构力度不弱化'的段误分」+「M_MACD is not a sufficient statistic for F_ℓ」。**这是真实的实装偏差**，但它是已知理论缺口（PDF 明文禁止的弱判据被使用），非本批故事族的新发现，且故事族 F6 把它误判为"原文语法理论边界"——PDF 中"反转"一词出现次数为零，"非反转保证"是判定者自己的推论被错误归因为 PDF 明文。
