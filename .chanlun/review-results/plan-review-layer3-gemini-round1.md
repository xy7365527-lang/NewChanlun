## 审核要点逐项判定

### 1. 数学正确性：三个指标是否是 R¹f_*=0 的合理必要条件？

**判定: APPROVED**

R¹f_*=0 意味着推前映射 f: Level_k → Level_{k+1} 保持所有上同调信息。在持续同调语境下：

- **W₁ 单调性**：如果无信息丢失，粗粒化后总持续量不应增加。合理——信息丢失会表现为虚假条带的创建（增加 W₁）。
- **Bottleneck 有界**：如果 R¹=0，相邻层级的持续图应"接近"。合理——bottleneck 稳定性定理保证连续映射下持续图的连续性。
- **KL 散度有界**：如果 R¹=0，条带长度分布不应漂移。合理——捕获 W₁ 和 bottleneck 可能遗漏的分布形状变化。

三者是必要条件（非充分），docstring 正确声明为"可计算近似"。

### 2. 实现正确性

**判定: APPROVED**

- `_bar_length_distribution`: Laplace 平滑（+1.0）正确避免 log(0)。归一化到概率分布。空条形码返回均匀分布（最大熵——无信息时的正确默认）。长度归一化（除以 max_len）使分布尺度无关——比较的是形状而非绝对值，这是正确的。
- `_kl_divergence`: KL(P||Q) = Σ p_i * log(p_i / q_i) 公式正确。调用方向 KL(dist_high || dist_low) 正确——度量"从低级别分布看高级别数据的惊讶度"。
- `check_cross_level_leray`: 遍历相邻层级对，三指标合取判定。逻辑正确。

### 3. 边界条件

**判定: APPROVED**

| 边界情况 | 处理 | 正确性 |
|---------|------|--------|
| 空条形码 | 均匀分布 + W₁=0 + bottleneck=0 | ✓ 两空层级 → passed=True |
| 单层递归 | 循环不执行，返回空列表 | ✓ |
| 相同条形码 | KL=0, bottleneck=0, W₁ 相等 | ✓ passed=True |
| 零长度条带 | max_len=0 → 均匀分布 | ✓ 防御性处理 |

### 4. 参数选择

**判定: CONCERN**

- δ=5.0（bottleneck 上界）：以价格单位计。对 10-1000 元的股票数据，5.0 是合理的起始值。但与 T1 的 ε 一样，应从真实数据校准。
- κ=1.0（KL 上界）：1.0 nat 是中等阈值。KL=0 表示相同分布，KL=1 表示中等偏离。合理的起始值。

两个参数都是可配置的，默认值作为起始点可接受。建议后续像 T1 ε 一样从 15 只 A 股数据校准。

### 5. T6 与 T7 一致性

**判定: APPROVED**

- T7 pass + T6 fail：可能。B_{k+1} ⊆ Trim(B_k) 但存活条带长度分布剧变 → KL 超标。
- T7 fail + T6 pass：可能。新条带出现但足够小 → W₁ 仍单调、bottleneck 仍有界。

两者互补而非矛盾：T7 是离散的集合包含检查，T6 提供连续的信息损失度量。不存在逻辑矛盾。

### 6. 声明与能力一致性

**判定: APPROVED**

- docstring 声明"可计算近似"——准确
- docstring 声明三个条件是必要条件——准确
- 未声明充分性——正确
- 未声明等价于 Leray 条件——正确
