## 一、D∞ 半直积 → 极性协变级别：群论推导

### 1.1 能指消歧（强制——orbit doc 已警告 σ 能指碰撞）

编排者命题 `D∞ = ⟨r,s | s²=1, srs=r⁻¹⟩`，r="该级别走势方向"，s="极性（多/空）"。
对接 `docs/orbit_enumeration_completeness.md` 的规范命名（D∞=⟨h,τ | τ²=e, τhτ⁻¹=h⁻¹⟩）：

| 编排者符号 | orbit doc 符号 | 缠论语义 | 群论身份 |
|---|---|---|---|
| **s（极性）** | τ | 多/空 = 手性 ε∈{±1} | 阶-2 对合（反射）；s²=1 = T₂₄ = M=N 翻转定理 |
| **r（走势方向）** | h（角向走势进度） | 该级别走势的展开方向（Up=前向/Down=反向） | 无限阶平移生成元（正规子群 ⟨r⟩≅ℤ 的生成元） |
| （级别本身） | σ=h²³（径向） | 级别阶梯 r∈{0..10} | σ 升一级别——**与编排者 r ≠ 同物，勿混** |

> **能指碰撞处置**：编排者用 "r" 指"走势方向"（= orbit doc 的 h，角向），不是 orbit doc 的径向
> σ=h²³。本文 r ≡ h（角向走势进度生成元）。τ 同时共轭 h→h⁻¹ **和** σ→σ⁻¹（因 σ=h²³），故
> srs=r⁻¹ 在角向和径向两个投影上都成立——这是协变的双重根源（角向 T₅₇ 镜像 + 径向莫比乌斯扭）。

### 1.2 srs=r⁻¹ 本身给出什么：T₅₇ 镜像（强，但不是协变）

半直积 ℤ⋊ℤ₂ 与直积 ℤ×ℤ₂ 的唯一区别 = ℤ₂ 对 ℤ 的作用：
- **直积 ℤ×ℤ₂**（srs⁻¹=r）：s 与 r 对易 ⟹ **s 是真正独立自由度**，可全局固定极性而不与走势方向交互。
- **半直积 ℤ⋊ℤ₂=D∞**（srs⁻¹=r⁻¹）：s 把 r 共轭为 r⁻¹ ⟹ **翻极性 = 反转走势取向（镜像）**。

读为缠论：`srs=r⁻¹` ⟺ **做空是做多的镜像**（翻极性后，盈亏方向相对走势反号）= **T₅₇**
（orbit doc NR-3 共轭面 / `project_bidirectional_accounting` 方向协变传导 `basis←basis−d·π/units`，
d=±1 是同一守恒律两极性面）。**这是 srs=r⁻¹ 的直接、强、字面读法。**

**但 T₅₇（镜像）≠ 协变（s_k=d_k）。** 关键诚实区分（两个不同逻辑类型）：
- **srs=r⁻¹** 是**群呈现中两生成元的代数关系**（关于群结构）。
- **协变 s_k=d_k** 是**状态上的约束/截面**（选出合法 (r,s) 子集，或函数 s=f(r)）。

群 D∞ 含全部元素 {rⁿ, rⁿs}。`rⁿs` = "在走势位置 n、极性翻为空"——这是**完全合法的群元素**。
所以**裸呈现关系不禁止任意级别自由翻转 s（整仓翻转）**。结论：

> **srs=r⁻¹ 单独不蕴含协变。** 它给镜像（T₅₇），是协变的**必要前提**（直积下极性可全局独立，
> 故必须半直积），但**不充分**——不锁定 s 何时改变。编排者"协变是 srs=r⁻¹ 的必然推论"的
> 字面表述**定位偏移**（声明膨胀风险，formalization-validity-domain 模式 3：把代数关系直接
> 当成状态约束）。

### 1.3 协变的真正群论根源：P2 合法性谓词（作用 groupoid 层）

协变由 orbit doc §3.2 的**四类分类合法性谓词 P2** 钉死（已 L0 结算）：

> **P2（手性翻转相位）**：τ（极性翻转）**仅在 φ=0 合法**；φ≠0 翻手性非法（orbit doc §3.2 非法操作）。
> 依据：T₅₁（莫比乌斯缝——手性只在背驰点翻）+ NR-3（多空两书角向不连通，唯一通道 φ=0 手性缝）+
> 第30课延异（交易不可逆/有时间性）。

φ=0 = 背驰点 = **走势完成/转折点**（角向圈闭合的奇点，orbit doc §1.1：唯一奇点 φ=0 = 背驰 ∧ 手性翻转）。

**协变不变量的群论证明（L0）**：

1. 设级别 k 当前走势方向 d_k，持仓极性 s_k。初始锚定 s_k = dir_to_polarity(d_k)（根恒多 = 541
   莫比乌斯丛初始截面；走势上行→多）。
2. 唯一能改变 s_k 的操作是 τ（手性翻转）。由 P2，τ 仅在 φ=0 合法。
3. φ=0 = 走势完成点 = d_k 翻转点（走势走完一段，反向新段开始，d_k→d_k.flip()）。
4. 故 τ 改变 s_k 的**同一时刻** d_k 也改变 ⟹ 协变 s_k=dir_to_polarity(d_k) 在 τ 前后**同步保持**。
5. 任何在 φ≠0 翻 s_k（走势中途翻转，d_k 未变）= **非法 τ@φ≠0**（违 P2）⟹ 破坏协变。

> **定理 PC1（极性-级别协变不变量，L0）**：在合法操作下，s_k = dir_to_polarity(d_k) 是
> **守恒不变量**——因唯一改变 s_k 的操作（φ=0 手性缝 τ）与 d_k 的改变同时发生。
> 破坏协变 ⟺ 中途翻转 τ@φ≠0 ⟺ P2 违反。**协变 = 镜像结构（T₅₇）在 P2 约束下的唯一一致截面。**

**这是必然推论，不是新约束**：PC1 不引入任何 P2/NR-3/T₅₁/541 之外的新公理；它是这些已结算 L0
事实在"持仓极性"这一可观测量上的**重新表达**。协变是 D∞ 覆盖作用的莫比乌斯丛**唯一无矛盾截面**
（541：根恒多 = 莫比乌斯丛无全局截面 ⟹ 极性不能全局固定独立于走势相位 ⟹ 必须协变 + 在缝翻转）。

### 1.4 引擎已编码协变映射（决定性证据：协变是必然，非新约束）

`rust/src/recursive_t/rec_engine.rs:152`：
```rust
/// 走势几何方向 → 操作极性（Up=Long / Down=Short）。
pub fn dir_to_polarity(d: Direction) -> Polarity {
```

by construction）。**缺的不是映射，是把它作为核心仓的强制不变量**——核心级翻转当前违反它（§三）。

## 二、unn 第 9 prove 设计：`prove_polarity_covariant_with_level`

### 2.1 规范函数（仿 `prove_self_level_symmetric` 的"规范 + make-observable"模式，137号）

```rust
/// **协变规范（PC1，L0）**：级别 k 持仓极性的协变期望 = 该级别走势方向的极性。
/// = dir_to_polarity(node.direction)，已是引擎既有映射（rec_engine.rs:152）。
fn covariant_polarity_standard(level_trend_dir: Direction) -> Polarity {
    dir_to_polarity(level_trend_dir)   // Up→Long, Down→Short
}
```

### 2.2 prove 函数（violation = panic）

```rust
/// **N9（极性-级别协变，PC1）**：每个活跃级别 k 的持仓极性 s_k 必 == 该级别走势方向极性
/// dir_to_polarity(d_k)——**除 φ=0 缝翻转断面**（合法 τ@φ=0：走势完成同时翻 s 与 d，测度零过渡）。
/// 违反 ⟺ 中途翻转 τ@φ≠0（持仓极性与本级别走势方向反号、且非缝 bar）= P2 违反 = 539/553/560
/// 整仓翻转穿仓的架构根源。violation = panic（make-decision-observable，137号）。
fn prove_n9_polarity_covariant(
    instances: &[TInstance; MAX_LEVEL],
    is_seam_bar: &[bool; MAX_LEVEL],   // 级别 k 本 bar 是否处 φ=0（走势完成/背驰确认断面）
    bar: i64,
) {
    for k in 0..MAX_LEVEL {
        let inst = &instances[k];
        if !inst.is_active() { continue; }
        if is_seam_bar[k] { continue; }   // φ=0 缝：合法翻转断面（测度零过渡，非状态），豁免
        let standard = covariant_polarity_standard(inst.node.direction);
        assert_eq!(
            inst.direction, standard,
            "N9 协变违反@bar {bar} level {k}：持仓极性 {:?} ≠ 本级别走势方向极性 {:?}\
             （走势 dir={:?}）——非缝 bar 持仓与本级别走势反号 = 中途翻转 τ@φ≠0（P2 违反）\
             = 整仓翻转吃跌死域（539/553/560）。合法翻转仅在 φ=0 缝（走势完成同时翻 s 与 d）。",
            inst.direction, standard, inst.node.direction
        );
    }
}
```

### 2.3 精确判据 + violation 条件

| 维度 | 内容 |
|---|---|
| **不变量** | ∀ 活跃级别 k：`instances[k].direction == dir_to_polarity(instances[k].node.direction)` |
| **豁免** | `is_seam_bar[k]`（级别 k 本 bar 处 φ=0：走势完成/背驰确认断面）——合法 τ@φ=0，测度零过渡（`project_bidirectional_accounting`：FLAT=测度零过渡非状态；翻转=会计断面 cascade settle） |
| **violation** | 非缝 bar，活跃级别 k 持仓极性与本级别走势方向**反号** = 中途翻转 τ@φ≠0 = P2 违反 |
| **panic 信息** | 暴露 (bar, level, 持仓极性, 走势方向, 规范极性) ——使协变违反在架构层可观测（137号） |
| **非重言** | `inst.direction`（持仓状态，由 enter/flip/sink 写）独立于 `node.direction`（走势测量）——二者反号是运行时可观测事件，非永真断言（仿 prove_self_level_symmetric 的内联 gate 独立性） |

> **认识论层级区分（codex 异质质询精化，§八）**：**PC1 定理本身 = L0**（协变是必然不变量）；
> 但 **N9 在工程层的捕获能力 = L2/L3 依赖**——N9 区分"合法缝翻转"vs"违规中途翻转"完全依赖
> `is_seam_bar[k]` 的判定精度（"级别 k 此刻是否真在 φ=0"）。该判定精度正是 555/553「精确走势完成
> 识别」、539「A′/A″ 事件闸门」要解决的问题。若 `is_seam_bar` 不精确（漏标/错标 φ=0），N9 退化为
> 噪声守卫。**故"PC1 是 L0 必然"与"N9 能有效捕获违反"是两个等级，不可混同**（前者 L0，后者 L2/L3）。
