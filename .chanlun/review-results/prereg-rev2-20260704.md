## 2. A6：μ_R co-primary 双门

### 2.1 estimand 定义（codex X/d 在残差框架的落点）

codex-ruling-696 裁定 B：`μ_R = E[X/d | z,a]` 作 raw μ 的 co-primary，桶键不加 d。

**残差框架落点（实施订正，非绕过 codex）**：本框架全部 alpha 检验在**残差** `Y_i=δ_i(H_i−B̂_i)−C_i` 上（alpha分离.pdf §1「所有后续 alpha 检验只看 Y」；final-prereg §3.2 主判据在 Y 上，raw μ 本就是 `E[Y]` 不是 `E[X]`）。故 co-primary 的两个门都在**残差空间**：

- **raw μ**（既有）：`μ̂ = E[Y]`，`Y_i = δ_i·resid_base_i − cost_i`
- **μ_R**（新，co-primary）：`μ̂_R = E[Ỹ]`，`Ỹ_i = Y_i / d_i = δ_i·(resid_base_i/d_i) − (cost_i/d_i)`

codex 的 `X/d`（generic per-trade return 除止损距离）在本框架的具体实现 = `Y/d`（去 beta 的残差除止损距离）——**不是**订正 codex，是 codex 抽象裁定的残差空间落点。**为什么不能用字面 X/d**：`X=δ·H−C` 是 δ-baked（把 δ 烘进值），进置换检验会重演 §82 修过的**虚假显著 bug**（perm_test.rs:506 自检固化：X_γ 置换即使 r 无结构也虚假显著）。μ_R 必须在 δ-free 残差基上归一化，perm 检验才不失效。

**实现路径（复用 σ̂ 归一化 bit-exact 模式，wverify_cross_symbol :398）**：克隆 records，逐笔 `resid_base /= d; cost /= d`，喂**同一** `deltafree_verdict` + **同一** `stratified_delta_perm_p_deltafree`（含 A1 force_state 键）——perm/decontam/Welford 透明消费归一化 records，零新统计逻辑。

### 2.2 d 的 ex-ante 可得性 + 计算（risk.rs:74-105，codex 复核确认）

`d_i = |entry_px_i − stop_px_i|`（美元），`stop_px = structural_stop(side, bits, StopInput)`：
- 1/2 类买 = `pivot_low`；3 类买 = `center.zg`（多类取 min，更宽）
- 1/2 类卖 = `pivot_high`；3 类卖 = `center.zd`（多类取 max）

**ex-ante**：`structural_stop` 在**决策 bar** 用该 bar 因果分类（`classification_i`）的 BspPoint（`source_index==c.source_index`）即可确定，`d` 在开腿前已知（非回看拼接）。计算点 = `typed_ledger_from_bars` 的 `step_trace.opened` 循环（runner.rs:880，`classification_i` 同作用域可见）。

### 2.3 d 防护（codex 开放项 1，冻结写死）

- **最小合法止损距离** `D_MIN = tick_size`（1 tick 的美元值，`config.tick.tick_size`）。`d_i < D_MIN` ⟹ 该笔从 **μ_R 样本剔除**（诚实剔除，不兜底放大分母）；raw μ 样本**保留**该笔（raw μ 不依赖 d）。
- **d 无法计算**（BspPoint 缺失 / structural_stop 返 None——非该方向交易点）⟹ `d=None` ⟹ μ_R 样本剔除，raw μ 保留。
- **异常值（大 d）不设上界**：大 d 只缩小 `Y/d`（保守），不放大，无灾难风险；近零是唯一风险，`D_MIN` 守护。
- **两 estimand 样本集可不同**：raw μ 样本 = 全部 records；μ_R 样本 = `{i : d_i ≥ D_MIN}`。逐桶两 estimand 的 n 可不等，各自在各自样本上判三态。结果包须并列报两 estimand 的 n。

### 2.4 不可比声明（codex 开放项 2，#135）

μ_R co-primary 报告与既有 raw-only 报告（终局/dfonline-a2）**不可直接比较**：(a) μ_R 是新 estimand（除以 d）；(b) μ_R 样本集经 D_MIN 过滤；(c) A1 使桶键含 force_state。本轮双 estimand 表是**新口径重估**，旧 raw-only 结论作差分档案不作基线。

### 2.5 前瞻约束（codex 开放项 3，写入本冻结）

当前 `X`（本框架 = Y）是 qty=1 单位边际收益（未按仓位缩放，codex 复核亲验 `mu_estimator.rs`/`l3_delta_r_alpha.rs:197` 确认 X 与 sizing `qty` 无关，两条独立路径从未合流）。**若未来 `X` 定义改为 position-sized PnL（qty 缩放版）**，`Y/d` 的 co-primary 地位须**重新评估或降级为诊断项**（`1/d` 已在 sizing 层，double-count）——此约束写入本冻结，触发条件 = `mu_estimator.rs` 出现 qty 合流进 X 的路径。

## 3. 判据（双 estimand 各自过门，Holm 校正——继承 final-prereg §3.2 扩展）

对每桶 `z`（δ-free 4 元组含 force_state），**每个 estimand 独立**算 `(mean, lcb, ucb, cv, n_eff, perm_p)` 并判三态（终局 §3.2 表不变，z_α=1.645，perm_α=0.05）：

| 桶态 | 条件 |
|------|------|
| **VALIDATED** | `μ̂>0 ∧ powered ∧ LCB_OOS>0 ∧ perm_p<0.05` |
| **FALSIFIED** | `powered ∧ UCB_OOS≤0` |
| **INCONCLUSIVE** | `¬powered` **或** `LCB≤0<UCB` |

`powered(z) := n_eff(z) ≥ (1.645·CV(z))²`；`n_eff` = Geyer IPS；两 estimand 各自在各自序列（raw μ 用 `Y`，μ_R 用 `Ỹ=Y/d`）上算 n_eff/CV/perm_p。

**全局 acceptance（Holm/α-split 跨全假设族校正）**：假设族 = {estimand ∈ {raw μ, μ_R}} × {δ-free 桶} × {方向不对称 β 路径}。任一 estimand 任一桶 VALIDATED（Holm 校正后仍显著）**或** β 路径显著 ⟹ acceptance PASS（候选可交易 alpha）。全族无检出且**全部** powered-FALSIFIED ⟹ 纯 beta（161 照实）。存在 INCONCLUSIVE 且无 VALIDATED 无 β 显著 ⟹ acceptance INCONCLUSIVE（走提功效链，不 PASS 不 161）。

**功效预期（终局 §6.2 继承）**：typed exit n≈2209，一类桶 n=1..11 结构性欠功效；A1 force_state 细分 + A6 μ_R 的 D_MIN 过滤**进一步降 n** ⟹ **预期绝大多数桶 INCONCLUSIVE**。这是样本量客观边界，不放宽门、不换判据。
