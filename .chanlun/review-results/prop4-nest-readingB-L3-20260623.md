## 1. 实装摘要（L0，file:line）

忠实实装命题4 读法乙（区分于读法甲全 a0 穷尽），三处核心：

### 1.1 删/旁路单核心 cc 锚
- `rec_engine.rs:on_bar` 新增 `A^NEST` 分支（`enable_nest` 时）：**取代** OFF 路径的 `A''(trend_done_clear) / A'(emergence) / B(route_bsp loop)`，直接调 `nest_step`。route_bsp 的 `nearest_active_parent` 单核心锚 + sink/recover 借仓在 NEST 下**完全不执行**。强平块 A 保留（诚实会计）。
- `rec_engine.rs:nest_step`（新方法）：单一全仓位，无 cc 锚、无 sink/recover。

### 1.2 大级别背驰段触发（自顶向下，背驰段 ≠ 走势完成）
- `divergence.rs:trend_diverging_segment(t, mode)`（新函数）= **走势完美判据 `judge_divergence` 去掉几何门 G 的「c 创新高/新低」分量**。趋势分支（≥2 中枢 + c 段 + F∧S/mode）∨ 盘整分支（单中枢 + 离开段 + 力度衰减/mode）。与产 type1 的 `judge_divergence(t, mode)` **同 F∧S/M/mode 组合**，唯一差 = 省去 `new_extreme`（创新高）⇒ 背驰段 ⊋ 走势完成。**这是 src-prop13「区间套前提=背驰段（未完成趋势最后段）⊊ 走势完成」的形式化**。
- `rec_stream.rs:push_bar` 重跑块：取 `tree.levels` 最高有走势级别的当前走势 → `trend_diverging_segment` → 武装操作极性（上涨顶背驰段→Short / 下跌底背驰段→Long），注入 `LevelView.top_diverge`。
- **关键修正**（避免测量伪影）：`trend_candidate`（旧函数，AND 模式硬编码 MACD）在 Structural 模式下 MACD 门恒否 → 背驰段恒空 → 假性 556 冻结（W=0）。改用 mode 一致的 `trend_diverging_segment` 后才正确。**并补盘整背驰段分支**——涌现塔最高级别绝大多数是盘整（首形成形态，nest_diag 实测 CL 36021/36036 重跑为盘整），其 type1 由盘整背驰产生，背驰段判据必须同口径覆盖盘整否则 W 假性为 0。

### 1.3 a0 区间套定位操作（每窗口一次 = 读法乙非读法甲）
- `nest_step`：武装下找**最低级别**与武装极性一致的 type1（顶背驰段找 type1_sell / 底背驰段找 type1_buy）= 区间套向下定位最接近 a0 的精确点。
- **每背驰段窗口仅翻一次**（`nest_consumed` 守卫）：新窗口（top_diverge 极性变 / top 反转去武装）⇒ 重置；翻转后骑走势到窗口结束。**这是区分读法乙（区间套定位一个转折点）与读法甲（全 a0 穷尽机械翻转）的关键**——否则 45% 宽武装窗口内会在每个 a0 type1 翻转（实测删此守卫 OKLO nest_flip 64→7）。
- 操作：定位点 ∧ 当前持仓 ≠ 武装极性 ⇒ `clear_all`（close 多/cover 空）+ `enter`（整仓做多/做空）。

### 1.4 ANCHOR 对照变体（552号 HOLD_ANCHOR 移植）
- `rec_engine.rs`：`TInstance.anchor` 字段 + `enter` 划 `m×2/3` 趋势底仓 + `sink/drain` 配额作机动仓 `u−anchor` + `clear_all` 清 anchor。`enable_hold_anchor=false`（OFF/NEST）时 anchor 恒 0 ⇒ bit-exact OFF。

### 1.5 受控实验架构 + bit-exact 守住
- `EngineConfig{earning,three_stage,trend_done_clear,hold_anchor,nest}` + `EngineConfig::{off,anchor,nest}()`；`TRoot/RecDriver/RecStream::new_with_config`——单进程三变体受控对照（同一数据加载）。

## 3. 判决：src-prop13 vs recursive-bsp 哪个被 L3 证实

### 3.1 命题4 读法乙是否解 556？——**是，但无收益（解冻暴露 539）**

- **顶层解冻（confirmed）**：背驰段 gate 开 14–50% 的重跑，NEST 翻转 2–20 次。顶层**不冻结**。556 的根因（等 type1 走势完成 → 跨年稀疏 → 顶层不动）被背驰段闸门解除——背驰段是「走势完美去掉创新高门」的**宽状态**（44% 重跑），不是稀疏的完成事件（0.2–1.7%）。
- **但解冻无收益**：NEST 1/8 超 BH（DX 震荡），7/8 灾难。**解 556 ≠ 解吃跌**。

### 3.2 收益 regime

- **NEST = regime 函数（与本项目一切吃跌探索同构，第 N 例）**：
  - **震荡/平盘（DX +6.3% 超 BH）**：少量整仓方向赌恰好对齐，空腿不失血（pnl +0）。
  - **强牛（BRN/GC/ES/QQQ/BTC/OKLO，−100%~−105%）**：整仓做空腿（由顶层上涨背驰段武装）在相对不停的牛市中失血 → 穿仓。
  - **区间震荡含趋势段（CL −62.9%）**：空腿打平（pnl +0）但多头腿在 whipsaw 中亏。
- **NEST vs OFF**：7/8 NEST 劣于 OFF（仅 DX 反超）。整仓翻转放大了方向暴露。
- **NEST vs ANCHOR**：ANCHOR 是强牛 regime 分离器（GC+85/ES+302/BTC+1080 救踏空），NEST 在强牛全部穿仓 ⇒ 几乎处处劣于 ANCHOR（仅 DX 反超）。

### 3.3 vs 539：千刀凌迟？——**否，是整仓长持死扣穿仓（539 被放大）**

- recursive-bsp §4 候选假设「命题4 下 539 改形态：长持死扣 → 高频短持小亏（千刀凌迟）」**被 L3 证伪**。
- 实测：NEST 做空腿是**少（2–20）、整仓、长持（1–2 年）**的方向赌，每条强牛空腿失血 10⁵ 量级 → 穿仓。**不是高频小亏**，而是**整仓豪赌长持死扣**——比 OFF 的几何衰减 sink 死扣（分数仓）**更严重**（整仓 vs 分数仓）。
- 根因：读法乙「卖点 close+做空」= 整仓翻转，无几何衰减保护；顶层上涨背驰段（armed 44%）在强牛频繁误判顶 → 整仓做空 → 牛市续涨 → 穿仓。

### 3.4 ★决定性贡献：src-prop13（背驰段≠完成，不假消解）vs recursive-bsp（假消解）

**两者在不同轴上各自成立——这是 formalization-validity-domain 的又一实例：**

| 主张 | 轴 | L3 判决 |
|------|-----|--------|
| **src-prop13**：背驰段 ≠ 走势完成，背驰段真比完成频繁（不假消解） | **频率/解冻轴** | ✅ **证实**：背驰段 gate 开 44%（状态）vs 完成 0.2–1.7%（事件），22–194×。顶层真解冻，NEST 真动作。背驰段识别**不需要**知道完成——它在完成前的整个 c 段（去创新高）即触发。 |
| **recursive-bsp**：识别 a0 重合点需顶层走势结构 = d_top[top] 等价稀疏 → 换名非消解（假消解） | **频率/稀疏轴** | ❌ **证伪**：背驰段状态 44% ≠ 完成 0.2%。识别背驰段所需的顶层结构（≥2 中枢趋势 ∨ 盘整离开段）**不与完成等价稀疏**。 |
| **recursive-bsp 深层悲观**：消费级别 ⊥ 贯通级别，解冻无济于事 | **收益/有效域轴** | ✅ **证实**：解冻 556 不产生吃跌收益（1/8 超 BH），539 regime 税不可约且被整仓翻转放大。 |

**综合（本工位决定性贡献）**：
> **src-prop13 在「背驰段≠完成」的形式化/频率层面被 L3 证实——读法乙的两前提（推论2 不用等完成 ∧ 推论3 先识别大级别背驰段）确实不矛盾，背驰段是 44% 宽状态而非稀疏点，556 顶层冻结被真解冻。recursive-bsp 的「假消解=背驰段与完成等价稀疏」在频率轴被证伪。但 recursive-bsp 的深层悲观（解冻无收益）在收益轴被证实：解 556 不解吃跌，因为它暴露并放大 539——556 的冻结一直在掩盖 539。**
>
> **有效域 ≠ 定义域（231号）**：背驰段闸门在定义域（频率：触发顶层动作）上有效（22–194× 解冻），但在有效域（收益：吃跌盈利）上失效（7/8 穿仓）。「背驰段真解冻 556」与「读法乙真盈利」是两个不同命题，前者 L3 真、后者 L3 假。

## 4. 六要素结果包

1. **结论**：命题4 读法乙（大级别背驰段闸门 + a0 区间套定位整仓翻转）忠实实装（删 cc 锚 + 背驰段触发 + 每窗口一次定位）。L3 8 标的：1/8 超 BH（DX 震荡），7/8 灾难（强牛全穿仓 −100%~−105%）。556 顶层**真解冻**（背驰段 gate 开 14–50% ≫ 完成 0.2–1.7%，22–194×）但**无收益**。

2. **定义依据**：
   - 第27课区间套定理（`blog/027:42-46,36`）：「先找到背驰段，然后在次级别图里找相应背驰段，反复进行直到最低级别」= 自顶向下 + 背驰段前提。
   - src-prop13 源头审计（`source-audit-prop1-prop3-20260623.md` §3.2）：区间套前提 = 大级别**背驰段（未完成趋势最后段）⊊ 走势完成**——形式化为 `trend_diverging_segment` = `judge_divergence` 去几何门 G 创新高分量。
   - 第37课趋势背驰 5 条件 + 第24课力度（`divergence.rs:judge_trend_divergence`）：背驰段 = 5 条件 ∧ 力度衰减，省创新高。
   - 第65课 `aₙ=f(aₙ₋₁)`：a0 = 最低级别定位点。

3. **边界条件（结论翻转处）**：
   - (a) 若**整仓翻转改为分数仓位 sizing**，强牛穿仓可缓解——但**方向 regime 依赖不变**（牛市中做空腿仍净负），收益符号判决鲁棒于 sizing。
   - (b) 若**背驰段闸门限趋势背驰段（去盘整背驰段，≥2 中枢）**，gate 收窄（armed% 大降），翻转更少——但仍方向性、仍 regime-bound；解冻幅度降、收益判决方向不变。
   - (c) 若**严格逐级区间套（每级别背驰段嵌套校验，非仅 top 武装 + a0 最低定位）**，定位点更少更精——可能减少误判顶的整仓做空，缓解部分穿仓。**这是唯一可能翻转「7/8 灾难」的开放轴**（本实装的有效域边界，未实装严格逐级嵌套）。
   - (d) 若 PerfectionMode 改 And/Or，背驰段口径随 mode 变（`combine_modes` 一致）——已验证 mode 一致性，但仅跑 Structural（canonical）。

4. **下游推论**：
   - 解 556 ⟹ 暴露 539：顶层冻结是 539 的掩盖机制。任何「解冻顶层让顶层动作」的方案都会暴露 539（做空腿趋势失血）⇒ **吃跌的核心难点不是顶层冻结，是做空腿 regime 依赖**（539 不可约，跨 8 标的 + 多读法二次确认）。

   - 开放轴 (c)（严格逐级区间套）是唯一未关闭的吃跌路径。
