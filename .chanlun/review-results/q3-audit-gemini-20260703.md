## 2. 具体发现（定义依据 + 边界条件）

### 2.1 CONCERN：假设6 数学陈述与 PDF 压缩公式 signature 不一致

**定义依据**：文档 §A 假设6 (a) 陈述：`I_Θ(A_t, Γ_t) = (D_t, O_t, L_t)`——2 输入、3 输出。
PDF 第10页压缩公式（§16）给出的实际 signature：
`(D_t,O_t,L_t,TWEvent_t) = I_Θ(A_t, {γ:N^δ_{ℓ↓e}(γ)=1}, TW_t, Risk_t)`——4 输入、4 输出。

**边界条件**：这个 signature 缺口在文档 §D-5（P1..P4 生产接线：`coverage.rs:2435`
`pi_theta_step_traced` 消费 `tw: Option<&TwStepCtx>` 与 `risk: &RiskConfig`，输出经
`stage_progression` 派生 `TWEvent_t`）中被正确弥补——即**实装侧**没有缺失 TW_t/Risk_t 输入或
TWEvent_t 输出，缺失的只是 §A 假设6 "(a) 数学陈述" 这一行的**简化表述**与 PDF 权威压缩公式脱节。
若把假设6 的陈述按字面理解（仅 2 输入 3 输出），则"由 6 ⟹ 全互斥类别唯一"这一步的论证链
不能覆盖 TWEvent_t 的唯一性——需要额外引用假设8（TStage/TW 事件全定义）才能补全，而 §A 的
证明链原文（"由 8 ⟹ 三阶段事件唯一"）恰好是分开列的一步，说明作者实际上**知道**这是两件事，
只是假设6 的正式数学陈述行没有同步更新为 4 元组。

**下游推论**：不影响 ∃! O_{t+1} 结论本身（因为 TWEvent_t 唯一性由假设8 独立覆盖，链条仍然完整），
但违反"数学陈述精确性"的审计要求——建议把假设6 (a) 改写为 4 元组以消除表述层面的内部不一致。

### 2.2 CONCERN：§C.2 生命期包含"直接推论"缺失连接性前提

**定义依据**：文档称 `v∈A_{t+1} ⟹ Anc(v)⊆A_{t+1}` 是"生命期包含不变量的直接推论"。

**边界条件**：AncOK(S)={e∈S: Anc(e)⊆S} 保证的是**集合成员资格**闭包（结构性：祖先必须在场），
不是**区间数值**闭包（`[λ_e,ρ_e]⊆[λ_a,ρ_a]`）。这两者的等价需要一个额外的连接前提：
"元素被移出活动集 D_t 的时刻，恰好与其生命期区间的右端点 ρ 同步"（即 active-set 状态机的
去激活时机与结构区间的实际终点严格对齐，不早不晚）。文档把这个连接前提当作隐含真理，
未在假设 7 中显式声明。若该同步性因实装 bug 出现漂移（例如某元素结构上已过 ρ 但因调度延迟
仍留在 A_t 一拍），AncOK 的集合闭包依然成立（因为它只检查集合成员资格），但区间包含的
经验保证就会被悄悄破坏而不触发任何断言——这正是文档自己提到的 Q4 修复史
（"LiveDetached 误判 Stale ⟹ depth>0 腿被系统性剪掉"）的镜像风险方向（该修复是"提前剪掉"，
这里指出的是"该剪未剪"这一互补方向未见对应机器证明覆盖）。

**下游推论**：不否定 AncOK 本身的正确性（它对其定义范围内的性质是精确的），但建议在假设7
或 §C.2 补充这条连接性前提的显式陈述，并检查是否存在覆盖"该剪未剪"方向的 property test
（当前锚点 `mod.rs:57-58` 只列了不变量 I1-I5，需确认其中是否含时序同步项）。

### 2.3 CONCERN：§C.4 守恒等式的可数域未消歧（候选 vs 活动腿）

**定义依据**：`|open|+|record|+|关闭触发|=|Γ|`。文档同时说明"open ⊎ record over 候选；
close over 活动腿"——即 close 操作的对象论域是活动腿（Active Legs），而非候选 Γ。

**边界条件**：若"关闭触发"计数的是**被关闭的活动腿数量**，而非**触发关闭的候选数量**，
则等式右端 |Γ|（候选总数）与左端"关闭触发"项的计数论域不一致——除非严格保证
"一个候选恰好触发关闭一条活动腿"（1:1 映射，无候选同时触发多腿关闭、无零候选触发关闭
的情形）。文档未明确说明这个映射比例是否恒为 1:1。若某个候选（如根仓一类反向点）
同时触发多条子声部（短差腿+根腿）的连锁关闭，则"关闭触发"若按腿计数会超过按候选计数，
等式会失衡；若按候选计数（不管触发几条腿关闭都记 1），等式才严格成立。

**下游推论**：`interp.rs:1385` 的断言文本是"候选守恒：open + record + 关闭触发 = |Γ|"——
从措辞看，"关闭触发"更像是按候选计数（与"候选守恒"的表述一致），此 CONCERN 更可能是
文档措辞层面的可读性问题而非实际代数错误，但审计要求"是否有遗漏项"时不能仅凭措辞假设
正确，应在 `interp.rs:1372-1385` 源码层面确认"关闭触发"计数变量的实际论域后再销号。

## 3. 无异议部分（PASS，详细论证见质询附件）

- **§B 互斥定理完整性**：构造 `C_j=P_j∧⋀_{k<j}¬P_k` 对任意有限 m（含退化 m=0：空谓词集，
  C_0 由空合取式恒真兜底，Σ=1 平凡成立）严格穷尽 P∈{0,1}^m 的所有情形；`r=min{j:P_j=1}`
  的论证不依赖 m 的具体取值。`mutex_total_exhaustive_2pow10`（`mutex.rs:296`）独立重算
  `1[C_j]`（不调 `mutex_class`）避免循环论证，这是恰当的机器证明设计。
- **§A/§B 与 PDF 逐字对照**：文档 §A 的证明链（"由1-4⟹Γ_t唯一；由5⟹z_t唯一；..."）与
  PDF §13 逐字一致，无遗漏步骤；§B 与 PDF §14 逐字一致，且文档版本比 PDF 原文更显式
  （多一条"C_0=0：含合取项¬P_r=0"的独立步骤），是加强而非削弱。
- **§C.5 新旧不变量的退化关系**：若事件流不含 Realize，"非 Realize 七构造子守恒"直接退化为
  旧的"全构造子守恒"单一定理，是严格推广而非另立门户；d_pi 符号无关的非负性风险由
  `transition_adapter` 出口的 cash-sound gate 独立拦截（raw 层全函数 + 独立合法性过滤的
  架构分层），职责边界清楚。
