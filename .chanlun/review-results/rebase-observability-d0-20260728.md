`continued / split / genuinely_removed / ambiguous`

## 6. 对 D1 双层身份的具体输入

### 6.1 允许过继

仅当塔构造层提供可复核的稳定谱系边，并满足：

1. 一个旧稳定身份只指向一个新构造身份；
2. 一个新构造身份只被一个旧稳定身份声明；
3. 每条映射 `functional=true / injective=true / unique=true / bijective=true`；
4. 事务级映射与构造见证一致。

对本次 8 条而言，前 7 条“同 start 的唯一新增候选”只能进入上述谱系核验队列；取得精确 1→1 构造见证后才可过继。

### 6.2 必须拒绝自动过继

- `split`：旧稳定身份映射到多个新构造身份时，禁止默认复制挂起；须先有明确的分裂继承裁定。
- `genuinely_removed`：稳定谱系明确终止时，保持既有终结/告警，不得过继。
- `ambiguous`：缺少谱系、映射非唯一或双射失败时，保持既有 `RebaseVanished` 行为，不得用 start/zg/zd 几何近似复活。
- `rebase_seq=66`：没有同 start/core 候选；除非构造谱系明确给出跨 start 的连续边，否则应拒绝过继。
