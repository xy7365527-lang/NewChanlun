# #69 判决：做空吃跌 alpha = 区间套确认深度分级 + 次级别做空（L3，8标的）

> 工位 #69（做空吃跌 alpha）。编排者最终目标「要让做空腿也是赚的，我们就基本稳了」。
> 认识论等级：L0（源码/缠论定义）+ L3（8标的真实数据交叉验证，4 变体对照）。
> 诚实声明：**不 over-claim**。做空腿到底「不亏」还是「吃跌赚」——看 short_pnl 符号 + max_gross。结论分级如实标注。

## 一、结论（一句话）

把开空腿门控从 `d_top`（背驰链贯通=走势完成=过稀疏⇒空腿冬眠）改为 **`t3sell`（第三类卖点=突破中枢+回试不回=快且准真顶转折）+ 严格次级别（`k<核心级别`）**，核心多腿 churn 仍用 `d_top`（最深区间套确认保护主力骑牛）：

- **8/8 净正维持**（baseline 也 8/8，但空腿从**冬眠**变**活跃且净赚**）。
- **做空腿组合层净赚 +9623**（8标的 short_pnl 求和），**逐标的 5/8 短腿正域**（BTC +9773 / CL +3145 / ES +1779 / GC +85 / OKLO +85），3/8 强趋势有界小负（BRN −3386 / DX −137 / QQQ −1721）。
- **主力多腿 alpha 保留/增益**（BTC long_pnl +632102→+728095）；**liq=0 全标的、max_gross<1×（零杠杆）、守恒零违反**——567「冻结空腿=穿仓+杠杆同根」**结构性消除**。
- **诚实降级声明**：max_gross **全 8 标的 <1×**（0.69–0.91×）。profitable 空腿是**小额次级别短差**，非大额方向做空。大额做空（max_gross>1×）唯一来源=核心/高级别翻空，在 net-up regime 灾难（变体1 坐实），故**结构性禁止**。⇒ 结论是「**次级别短差吃跌净赚（小额）**」，**不是**「大额做空敞口吃跌赚」。

## 五、边界条件（结论翻转处）

1. **做空吃跌赚的有效域 = 震荡/大回调 regime**：短腿正域 5/8（CL/GC/ES/BTC/OKLO 有真实回调可吃）；强趋势 3/8（BRN/DX/QQQ）短腿有界微负——强上涨趋势中**升跌完备性**（21:40）使无真顶，次级别回调短差被趋势恢复涨破 ZG 止损（确认滞后残余）。**翻转条件**：若标的转入持续下跌 regime，次级别短差应转大幅正域（无 bear 标的可 L3 证伪）。
2. **`k<核心` 牺牲 OKLO 核心级别短差**：变体1 OKLO L2 核心短 +13136（真实 −59% 下跌），变体4 被 k<core 屏蔽⇒OKLO +91.5→+88.0。即**核心级别做空在真 bear 是对的、在 net-up 是灾难**——纯结构判据无法区分（539 不可约：真顶/假顶之别只在反转后显形）。`k<core` 选择保护 7 net-up 标的（灾难 −40928 量级 ≫ OKLO 让利 +13136）。
3. **max_gross<1× 翻转**：若放开 k<core 允许大额做空 ⇒ max_gross>1× 但 net-up 灾难（变体1）。「max_gross>1× 的吃跌赚」**有效域 ⊂ 真 bear regime**，8 net-up 标的无法证实⇒结构性禁止（非声明能力）。
4. **核心 churn 信号**：d_top（稀疏）保护趋势骑牛；改频繁信号（t1sell/t3sell）踏空趋势（变体3/3b 坐实 BTC/GC/ES/QQQ 多腿崩）。⇒ 核心 churn **必须**最深区间套确认。

## 六、下游推论

1. **567（冻结空腿=穿仓+杠杆同根）修法 L3 确证 + 结算就绪**：567 §五提的修法（区间套关闭信号替代 d_top + 升跌完备性父级门控）本任务**实装并 L3 验证**：liq=0、max_gross<1×（杠杆消除）、无高级别冻结空腿（穿仓消除）。567「d_top=错误代理」**精化**：d_top 对**空腿**是错误代理（稀疏⇒冬眠/冻结），对**核心主力 churn** 恰是正确信号（需稀疏骑牛）⇒ 错误不在 d_top 本身，在「绑错持仓尺度」。567 status 生成态→可结算（修法 L3 + 门控vs556相对贡献已测：门控防开错=主，关闭信号=次）。

3. **最终目标「做空腿也赚=基本稳」**：组合层达成（short_pnl 求和 +9623，5/8 正域，8/8 净正，主力增益）。但**逐标的非 8/8 短腿正**（3/8 强趋势有界负），且为**小额次级别短差**（max_gross<1×）。「基本稳」≈ 主力骑牛 + 次级别短差净赚 + 穿仓消除；非「大额做空吃跌」。
