## 一、诊断坐实（阶段1-2）

### 1.1 平空走止损现象（L3 数据）

### 1.2 牛熊切换不对称（L0 源码）
LegPair 是**多头偏置**架构（`核心 = highest_active_long`）：
- 核心多腿 churn：走势完成（d_top）平多到**现金**，**从不开核心空腿**（#69 `k<核心` 显式禁核心翻空）⇒ **牛转熊不完整**（平多 ✓ / 大级别做空 ✗）。
- **无熊转牛**（核心不能为空 ⇒ 无「核心空→核心多」镜像）。
- 编排者「牛转熊处理不好，熊转牛也处理不好——共用同一切换机制」：当前根本无对称切换机制，核心只能 long↔cash，不能 long↔short。

## 二、区间套定位提前平 L3 否证（阶段3-4，**两变体均否证**，强否定性结果）

**实装**（自相似 no-hardcode，三轴）：第27课区间套——次级别(k−1)买卖点嵌套确认本级别 k 走势完成 ⇒ **提前平**腿（解确认滞后，止损降兜底）。核心多腿绝不被次级别信号平（547 隔离 ⇒ `!is_core`）。测两变体：
- **变体A（任意次级别买卖点）**：`平空 short[k] = buy[k] ∨ buy[k−1]`；`平多次级别 long[k] = sell[k] ∨ sell[k−1]`。
- **变体B（次级别背驰=含破极值否定）**：`平空 = buy[k] ∨ t1buy[k−1]`；`平多次级别 = sell[k] ∨ t1sell[k−1]`（t1=背驰=动能竭尽=走势真完成，nest_forward 第三项破极值否定）。

2. **提前平多踏空强趋势**（致命，两变体皆然）：BTC long 踏空（A −140pp / B −119pp），变体B（背驰）踏空 CL long **更严重**（+3897→+1775）——因 t1sell[k−1] 恰在次级别顶 fire = 下一上涨腿起点，提前平次级别 long = 精确踏空。
3. **regime 分裂**：震荡/高波（OKLO/GC/BRN）提前平捕反转有益；强趋势（BTC/ES）踏空灾难。同一提前平规则无法两全（539 regime 函数第 N 例）。

## 三、根因 = 确认滞后逻辑不可约 + 次级别多腿在趋势中本不该提前平

变体B 加了「破极值否定」（背驰确认）仍踏空 ⇒ 否证根因**不是**缺破极值否定，而是更深的两点：
1. **确认滞后不可约**（缠论认识论，547/[[project_1min_resolution_irreducible]]）：方向只在走势走完才确认。止损% 不随提前判定下降证实——价格反转**快于任何级别的走势完成信号**（背驰也是滞后确认）。这是逻辑性的，提前判定/细粒度都换不掉。
2. **次级别多腿在趋势中不该被次级别信号平**（与 547 同构推广）：BTC 牛市中次级别 long 是趋势腿的一部分，次级别顶（背驰/卖点）是**回调起点非走势完成**，提前平=踏空。正解应是**次级别 long 也享 churn 保护**（回调不平，只在次级别走势真完成才平）——但「次级别走势真完成」= d_top[k]（次级别区间套链贯通），又退回稀疏信号。**提前 vs 不踏空 是同一确认滞后的两端，不可兼得**（提前⇒踏空 / 不踏空⇒滞后走止损）。

## 四、牛熊对称核心翻转 = 大架构缺口 + 有效域受限（不擅自实装）

编排者要求牛熊镜像对称（牛转熊⟺熊转牛共用切换机制）。LegPair 多头偏置无此机制。严格实装需：核心可 long∨short，最高活跃走势级别走势完成（d_top）时 long↔short 翻转。**但两条有效域障碍（formalization-validity-domain）**：
1. **牛转熊核心做空在 net-up regime 经验亏损**（#69 变体1 L3 坐实：t3sell 核心翻空 CL short −57435 / L4 单笔 −40928；539 不可约——上涨趋势中真顶=假顶不可实时区分，21:40 升跌完备性=上涨无真顶可空）。
2. **熊转牛无法 L3 证伪**：8 标的全 net-up，无持续 bear 窗口 ⇒ 实装熊转牛核心翻多=不可证伪的有效域膨胀（231 号禁止）。

⇒ 牛熊对称核心翻转**结构可写但 L3 不可验证**（缺 bear 标的）。不擅自实装（避声明膨胀）。**这是真 539**：核心级别大额吃熊需 bear regime，net-up 8标的无法证。

## 五、结果包六要素

1. **结论**：编排者三纠正（平空错/牛熊不对称/三轴）诊断全部坐实。但两个候选修法 L3 否证/不可验证——(a) 简单区间套定位提前平**踏空强趋势净负**（BTC −140pp），(b) 牛熊对称核心翻转**有效域受限**（核心做空 net-up 亏 + 熊转牛无 bear 数据）。committed #69（次级别短差，开空门控）仍为当前最优。走止损 40% 是**不可约确认滞后**（净负修法证实）。
2. **定义依据**：第17课买卖点（平空=买点）、第27课区间套定位（次级别嵌套确认）、走势完全分类（下跌完成必转盘整/上涨）、21:40 升跌完备性（上涨无真顶）。输入满足：平空路径埋点（总平/买点平/止损平 per 标的）+ per-level pnl + long/short_pnl bit-exact 观测。
3. **边界条件（翻转处）**：(a) 提前平在**震荡 regime 有益**（OKLO +77/GC/BRN），强趋势踏空——若加「破极值否定」（走势未完成不平）可能消除踏空，使提前平在两 regime 都成立（未实装，下一轮关键）。(b) 牛熊对称核心翻转若有 bear 标的可证伪熊转牛、且核心做空判据足够稀疏准确（走势完成而非单 bar t3sell），可能成立。(c) 走止损若 a0 粒度更细使买点更快 fire——已被 1s a0 否证（确认滞后是逻辑非粒度，547/[[project_1min_resolution_irreducible]]）。
4. **下游推论**：平空严格性的关键缺口 = **「破极值否定」（走势完成判据）**，非区间套定位级别错配（级别 buy[k] 已对）。下一轮重心 = 实装 per-leg 走势极值跟踪 + 背驰确认的「下跌走势完成」判据（走势完全分类的操作显形），替代「任意买点平」。牛熊对称需 bear 标的入库（如 2022 加密熊、原油 2014/2020 崩）才能 L3 闭环。
5. **谱系引用**：547（[[project_cascade_level_misattribution]]：次级别信号干预趋势腿=踏空同构，本轮提前平多 BTC 踏空复现）；[[project_deadlock_dual_open_target]]（三个半：核心翻转只在最高级别走势完成——本轮坐实次级别提前平违反之）；539（[[project_t_short_leg_regime_function]]：做空/平空 regime 函数，提前平 regime 分裂第 N 例）；[[project_interval_nesting_forward]]（nest_forward 三项，本轮缺破极值否定=否证根因）；567（冻结空腿，本轮平空路径埋点深化其「平空走止损」机制侧）；[[project_1min_resolution_irreducible]]（确认滞后逻辑非粒度）。
6. **影响声明**：rec_engine.rs 提前平改动已 **revert**（L3 净负，no-patch 不留否证代码）。保留 rec_stream.rs 平空路径诊断埋点（6行纯观测，坐实走止损）。committed #69 不变。未实装牛熊对称（有效域不可证）+ 破极值否定（下一轮）。
