# 源头审计：第二类买卖点定义与背驰/区间套的关系

## 0. 结论速览（供 Cand^δ A/B 裁决）

原文**能**找到第二类买卖点与背驰的关系，但关系是**分层**的，不是单一挂钩：

| 层 | 第二类买卖点与背驰的关系 | 原文依据（逐字已验证） |
|----|----------------------|---------------------|
| L1 存在性/安全性 | **不由背驰保证，由"走势不患/完备性"保证** | 第17课L60、第21课L44、chan99 0025 L45/L64 |
| L2 次级别回抽确认判据 | 次级别回抽结束 = **"不创新高/新低" 或 "(盘整)背驰"**（择一，非强制门） | 第53课L28、第54课L143/L166、第107课L66、chan99 0025 L63、chan99 0046 L87 |
| L3 统计性质 | **多数**第二、三类买点**由盘整背驰构成**；第一类多由趋势背驰构成 | 第27课L18、第29课L392 |
| L4 精确定位 | 定律一（Type2@N = 次级别第一类背驰点）+ 区间套（下次级别找第一类） | 第17课L66、第29课L396、第27课L60、chan99 0016 L82 |

**对 A/B 的支持度**（不裁决）：
- **A（Type2 换走势完备性判据）**：L1 强支持。Type2 的**存在性/安全性判据**在原文中就是走势完备性/不患，与背驰无关。
- **B（Type2 免 N^δ 背驰段门）**：取决于"背驰段门"约束的是**存在性**还是**精确定位**。
  - 若门约束**存在性** → 原文强支持免门：Type2 的存在不需要该级别趋势背驰段（第53课L28：Type2 正是为补充"小转大、该级别无一类买卖点"而设）。
  - 若门约束**精确定位** → 原文**不**支持完全免除：Type2 精确点在原文中确由盘整背驰 + 区间套（下次级别找第一类背驰点）定位（第27课L60、chan99 0016 L82、第29课L396）。
- **关键区分交给编排者**：N^δ 背驰段门锁的是 Type2 的"是否存在"还是"落在哪根 bar"。

## 1. 考古问题 1：第二类买卖点定义原文逐字

### 1.1 结构性定义（存在性层，不含背驰）

**第17课L60（博文一级权威，缠师原文）**：
> "在第一类买点出现后第一次次级别回调制造的低点，是市场中第二有利的位置……上涨和盘整在图形上的要求，是必须包含三个以上的次级别运动，因此后面必须还至少有一个向上的次级别运动，这样的买点是绝对安全的，**其安全性由走势的'不患'而保证**，这，就是在前面反复强调的第二类买点。"

**第52课L516（博文，缠师答疑，最凝练）**：
> "第二类买点的定义很明确，就是例如一个30分钟的第一类买点，一个5分钟次级别上去后，**一个5分钟回试不破低点**，那就是第二类买点。"

**chan99 0025 L13/L15（编纂版）**：
> "第二类买点：某级别中，第一类买点的次级别上涨结束后再次下跌的那个次级别走势的结束点。"
> "第二类卖点：某级别中，第一类卖点的次级别下跌结束后再次上涨的那个次级别走势的结束点。"

**第21课L44（博文，完备性）**：
> "第二类买点是和第一类买点紧密相连的……第一买点出现后的第二段次级别走势低点就构成第二类买点，**根据走势必完美的原则，其后必然有第三段向上的次级别走势出现，因此该买点也是绝对安全的**。"

→ 结构性定义：**第一类买点后第一次次级别回抽的结束点**。安全性依据 = 走势必完美/不患，**未挂钩背驰**。位置可在中枢上/中/下（第21课L44）。

### 1.2 出处课号
- 首次提出（正式）：**第17课**（第一、二类买卖点 + 定律一 + 趋势转折定律）
- 均线系统预形式化：**第14课L28/L54**（"女上位第一吻后出现的下跌构成" + 买点定律）[旧缠论:早期均线口径]
- 完备性封闭：**第21课**（完备性定理 + 升跌完备性 + 互斥/重合）
- 编纂版凝练定义：**chan99 0025**（第四节 走势中枢与买卖点）

## 2. 考古问题 2：原文是否把第二类买卖点与背驰/背驰段/区间套挂钩？

**答：挂钩，但仅在 L2（次级别回抽确认判据）和 L3/L4（统计+定位），不在 L1（存在性/安全性）。**

### 2.1 次级别回抽确认 = "不创新高/新低 或 (盘整)背驰"（择一）

**第53课L28 / chan99 0025 L63（缠师原文，标准表述）**：
> "一般说，高点一次级别向下后一次级别向上，**如果不创新高或盘整背驰，都构成第二类卖点**，而买点的情况反过来就是了。"

**第54课L143/L145（博文，缠师答疑）**：
> "一个5分钟中枢形成，必须是先一个1分钟向下，然后一个1分钟向上，**不创新高或背驰**，这就构成第二类卖点。"

**第107课L66（博文，缠师原文）**：
> "第一次次级别回拉**不破顶或盘整背驰**将构成最好的第二类卖点，这类卖点往往是突发事件中最好的逃命点。"

**chan99 0046 L87（编纂版）**：
> "根据第二类卖点的定义，就知道，一旦一个1分钟以下级别的向上过程**不能创新高或背驰**，都将构成第二类卖点。"

**第28课L876（博文）**：
> "然后有一个反抽，一个5分钟级别的向上走势……**第二个5分钟的背驰就构成了第二类卖点**。"

→ 背驰在此是次级别回抽结束的**充分确认条件之一**（与"不创新高/新低"并列，用"或"连接），**不是必要门**。缠师明确（第54课L168）：次级别回抽"创新高但形成盘整背驰"也可构成 Type2（"当然有可能，虽然很少见"）——即"不创新高"可失败而"盘整背驰"独立成立。

### 2.2 MACD 力度辅助（0轴回抽）——Type2 的动力学判据
- 第25课L649："第二类买点……MACD对应双回抽0轴站稳"
- 第51课L220 / 第52课L276 / 第26课L219："MACD黄白第一次上0轴然后横在0轴上形成第二类买点"
- chan99 0016 L72："第一段……形成相应的第一个走势中枢，同时形成第二类买点……这段一般在一个次级别的背驰中结束"

→ 既有审计 `cc-coverage-orbit-type2-20260623.md` 把"Type2 力度判据"溯源到第19/21课；本次穷尽检索确认力度判据更集中在 **MACD 回抽0轴（第25/26/51/52课）+ chan99 0016**，且属 L2 层（次级别确认），不是 L1 存在性判据。

### 2.3 存在性/安全性 = 走势完备性（与背驰无关）

**chan99 0025 L64（编纂版，缠师操作指导）**：
> "第二类买卖点，站在走势中枢形成的角度，其意义就是必然要形成更大级别的走势中枢，因为后面至少还有一段次级别走势且必然与前两段有重叠。**所以，无论如何，当出现第二类买卖点时，绝对可以操作。**"

**第53课L28 / chan99 0025 L63**（Type2 的存在理由 = 补充"小转大、无该级别一类"）：
> "第一类买卖点，就是该级别的背驰点……但有一种情况是不可以的，就是……小级别转大级别……当小级别背驰时，并未触及该级别的第一类买卖点……**对这种情况，就需要第二类买卖点来补充**……在小级别转大级别的情况下，第二类买卖点就是最佳的，因为在这种情况下，没有该级别的第一类买卖点。"

→ Type2 的存在性判据是走势完备性；且 Type2 恰恰是为**该级别趋势背驰段不存在**（小转大）的情形而设。这是"Type2 存在性免该级别趋势背驰段门"的最强原文依据。

## 3. 考古问题 3：区间套（第27课/第29课）的对象范围——是否涵盖第二类？

**答：涵盖。原文明文把区间套用于第二买点确认。**

**第27课L60（博文，图例标题，缠师原文）**：
> "600685 **第二买点的确认方法（区间套）**"

**chan99 0016 L82（编纂版，第27课对应节）**：
> "类似的，在大级别里，如果不出现新低，但可以构成**类似第二类买点的买点**，在MACD上，显示出类似背驰时的表现，黄白线回拉0轴上下，而后一柱子面积小于前一柱子的。"（配合 L80"盘整背驰构成的类第一类买点"的区间套逐级定位法）

**第29课L396（博文，缠师答疑，定律一的定位版）**：
> "所有买点，归根结底都是第一类买点，**要找第二、三类，其精确的，都要下次级别以下找第一类**。"

**区间套定理本体（第27课L43 / chan99 0016）**：
> "定理：某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。"
> 背驰段定义（第27课L21 / chan99 0016 L11）："在某级别的某类型走势，如果构成**背驰或盘整背驰**，就把这段走势类型称为某级别的背驰段。"

→ 区间套的对象是"转折点/买卖点"的**精确定位**，其构件"背驰段"**包含盘整背驰**。区间套明文覆盖第二买点（第27课L60）。定律一（第29课L396）保证：第二类@N 的精确点 = 次级别第一类背驰点，故第二类经"下次级别找第一类背驰段"接入区间套。

**注意范围边界（缠论知识库.md L410-411）**：
> "小转大是用区间套和背驰不可解释的情况的一种补充；小转大没有标准的一类买卖点，通常需要等待第二类买卖点确认。"
→ 即：小转大情形下，该级别没有可供区间套锚定的趋势背驰段，Type2 是这种情形的确认手段。这与 L1（Type2 存在性免该级别趋势背驰段门）一致。
