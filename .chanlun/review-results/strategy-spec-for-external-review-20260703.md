# 缠论全互斥定义策略——完整规格与实证报告（供外部评审）

日期：2026-07-03。本报告自包含，面向外部评审者（无需访问代码库）。所有数字来自真实数据回测，测试基线 1402 个单元测试全绿。

## 一、系统概述

基于缠论（禅师 108 课）的全自动交易系统，Rust 实装。核心思想：把行情递归分解为多级别结构（分型→笔→线段→中枢→走势类型，逐级递归成 L0–L5 级别塔），在每个时刻对每个候选交易事件给出**完全互斥的状态分类 z**，估计每个状态的条件期望收益 α(z)=E[Y|Z=z]，只在统计确认 α>0 的状态下交易。

## 二、状态分类 z（完全互斥、穷尽，有机器证明看守）

每个候选事件的状态 z 是 7 维向量：

| 维 | 含义 | 取值 |
|----|------|------|
| ℓ | 级别 | L0（最小，1 分钟塔基）…L5 |
| δ | 方向 | 买 +1 / 卖 −1 |
| I_γ | 买卖点类别 | 6-bit 掩码（一/二/三类买卖点及其重合态，64 类不压扁） |
| σ_p | 父声部方向 | −1/0/+1（该事件所处的高级别走势方向；0=无父方向） |
| 仓位态 | 根声部/子声部 | Root（独立开仓）/ Child（在父仓位下的子操作） |
| 短差标志 | 是否逆父方向的短差操作 | bool |
| H | 同级别前兄弟关系 | First / 顺前兄弟 / 逆前兄弟 |

买卖点定义（锚定原文）：
- **一类**：走势末端背驰（次级别 MACD 面积对比，第 29 课定律一）
- **二类**：一类之后次级别回抽不创新极值（第 14/15 课）
- **三类**：中枢突破后回抽不回中枢区间
- **第四类 StructBreak**：以上都不是的结构破坏信号——门恒拒不交易（对应原文"保持原状态、只记录不操作"）。补上它后分类才**穷尽**。

互斥+穷尽有两重看守：分划数学证明（经异质 AI 审计）+ 运行时守恒断言（任何信号漏分类/双分类当场断言失败）。裁决优先级（如同一时刻"风险平仓"与"顺势加仓"冲突时取谁）与原文 P1..P8 谓词优先级的一致性有 property test 机器证明（9 场景桶级等价，零分叉）。

## 三、准入门（信号≠交易，过门才交易）

两条互斥门通道：
- **区间套门 N^δ**：高级别信号沿次级别递归下沉定位精确入场点（第 29 课区间套）。实测 BTC 全历史：95% 情形退化为单级（下沉深度=1），深度≥2 几乎为 0——经测量确证这是市场几何事实（"小转大"占 92%），非实现缺陷。
- **小转大通道 XZD**：次级别转折放大为高级别转折的确认判据（C2 回抽确认；C3 新中枢突破判据在 level 1 实测 0/84 命中，已确证为市场几何、该通道在 L1 实践关闭）。

## 四、Alpha 检验框架（防自欺设计）

1. **残差口径**：不看原始收益 X（混入市场 beta——牛市里任何买信号都赚钱）。检验对象是残差 **Y_i = δ·(H_i − B̂_i) − C_i**：持有窗涨跌减因果估计的市场漂移（B̂=入场前扩张窗漂移×持有时长，无前视）再减双边成本。实测主桶原始 +262/笔中约 84 是 BTC 上涨搭车。
2. **预注册冻结**：每次回测前把估计对象（分桶键/品种池/窗口/置换种子/判据）写死并 git commit，之后才准跑数——防"看结果改口径"的数据挖掘。本轮共三次冻结，无一违反。
3. **显著性**：分层置换检验（层内重排方向标签，层键=级别×持有时长桶×时间块×父方向）+ 单边 95% LCB + 删尾稳健性（删最大 3 笔均值不得翻转）。
4. **功效门**：n_eff ≥ (1.645·CV)²（事件聚集自相关校正后的有效样本），不够格的桶只能判 INCONCLUSIVE 不许宣布有效。
5. **三态判定**：VALIDATED / FALSIFIED / INCONCLUSIVE。

## 五、策略 π（多级别声部并行，"赋格"结构）

π = Schedule[LexArgmin_{p∈K_Θ} J − p]：每时刻所有过门候选按（级别,方向）分声部槽位并行裁决（关/开/记录三桶），聚合成目标持仓向量 p̃=Σ 各活跃声部带符号敞口，在风控约束集 K_Θ 内选最优持仓，差额生成订单。多空双记于声部树逻辑账本（高级别多单+低级别短差空单并存），执行层轧差为净头寸。μ̂ 估计器经 **χ 门**（LCB>0 才准入）注入选择。

## 六、实证结果（BTC 461 万根 1 分钟 bar ≈8.8 年 + 7 品种，walk-forward OOS）

**信号级 alpha（四口径全部 INCONCLUSIVE，无一 VALIDATED）**：

| 口径 | 结果 |
|------|------|
| BTC 残差 4 元组（28 桶） | 主桶 L0/三类/买：+178.66/笔，置换 p=0.005，删尾稳健，但 n_eff=166<290 欠功效 |
| 7 品种池化（29 桶） | n_eff 提至 700 过门，但品种异质性使 CV 升至 22.58 反超；**主桶正号仅 BTC 独有**，ES/GC/QQQ 主桶被够功效 FALSIFIED |
| 完整 7 维 z（52 桶） | V=0/F=9/I=43；发现 i_class 与 δ 共线使置换检验结构性退化（大样本桶 p 0.005→1.000） |
| 降维 UClass（15 桶） | V=0/F=2/I=13，p=0.050 |

其他确证事实：L1 卖腿显著强于买腿（bootstrap p=0.002，与原文预注册的卖腿方向一致）；L1/L3 部分买桶被 FALSIFIED（负 alpha 确证）。

**策略级 P&L（完整 π 组合回测，6 月 OOS）**：

| | 带 χ 门 μ̂ | 无门基线 | 差分 |
|--|--|--|--|
| BTC 总盈亏 | −113 万 | −1568 万 | **+1455 万** |
| BTC 最大回撤 | 6.9% | 95.2% | −88pp |
| 订单数 | 838 | 33067 | 降 40 倍 |

**结论：μ̂ 门的经验价值是风险控制（防灾难性过度交易、大幅减损减回撤），不是产生正 alpha——两口径均净负，与信号级无 VALIDATED 自洽。**

## 七、已知边界（诚实声明）与在建

- 高级别（ℓ≥2）信号天然稀疏（分形递归：L0 千级样本、L2 十位、L3 个位）——统计确认集中于 L0 是数学必然。
- 曾发现并修复增量解析的真 bug（level≥2 增量/全量发散），修复后 bit-exact 且全部结论复核零翻转。
- 风控保证金/强平输入未建模（占位诚实声明）；背驰强度连续量未进桶键。
- **在建**（新目标）：高级别定方向+区间套下沉 L0 定买点的显式联动通道、三类买卖点全用于下沉入场、多级别声部并行（多重赋格）回测。
