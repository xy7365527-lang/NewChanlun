## 1. 同级别分解的多重赋格（第 40 课 / chan99 0014:47-55）

### 1.1 所属课与文本关系

- 博文正本：`blog/040-第40课.md`，标题「同级别分解的多重赋格」，正文仅 `040:14–22` 五段（`040:24` 之后全是每日解盘与回帖）。
- chan99 把 blog 第 38 课 + 第 40 课合并进 `chan99/0014-第二节 走势分解.md`；赋格段落落在 `0014:47–55`。
- 前置课：`blog/039-第39课.md`（同级别分解再研究）给出 A_i 记号系统，其正文与 `chan99/0014:39-45` 对应。

### 1.2 判别单元是什么

【原文】`blog/038:18`：「所谓同级别分解，就是把所有走势按一固定级别的走势类型进行分解。根据"缠中说禅走势分解定理"，同级别分解具有唯一性，不存在任何含糊乱分解的可能。」

【原文】`blog/038:20`：「以30分钟级别为操作标准的，就可用30分钟级别的分解进行操作，对任何图形，都分解成一段段30分钟走势类型的连接，操作中只选择其中的上涨和盘整类型，而避开所有下跌类型。」

→ **判别单元 = 固定级别的「走势类型」段**（上涨/下跌/盘整三选一），记作 A_0, A_1, …, A_t。

【原文】`chan99/0014:43`（= `blog/039` 同段）：「Ai与Ai+2之间就可以不断地比较力度，用盘整背驰的方法决定买卖点。……这种机械化操作，可以一直延续，该走势中枢可以从30分钟一直扩展到日线、周线甚至年线，但这种操作不管这么多，只理会一点，就是Ai与Ai+2之间是否盘整背驰」

→ 单元上做的**判别动作**有二：(i) 同向相邻段 A_i 与 A_{i+2} 之间比力度（盘整背驰）；(ii) A_{i+3} 是否跌破 A_i 高点 / 升破 A_i 低点。

【原文】`blog/038:22`：「在这种同级别的分解中，是不需要中枢延伸或扩展的概念的……如果这5分钟次级别延伸出（延伸成）6段，那么就当成两个30分钟盘整类型的连接，在这种分解中，是允许盘整+盘整情况的。」

→ 同级别分解是一套**自带判别规则的坐标系**：在该级别上关掉「中枢延伸/扩展」，代价是允许「盘整+盘整」。

### 1.3 赋格比喻在原文里说明的是什么

【原文】`blog/040:16`：「上节中的"Ai与Ai+2之间盘整背驰"，将演化出"当i为偶Ai+3跌破Ai高点"或"i为奇数Ai+3升破Ai低点"；因而相应演化出高一级别的中枢，例如在该例子里，Ai+1、Ai+2、Ai+3就是30分钟的中枢，而所有更大的中枢，当然是先有高一级别才可能有，否则连30分钟的中枢都没有，哪里来日、周、月的？但这个现象就保证了，在同级别分解下，一个小级别的操作是可以按一个自动模式换档成一个高级别的操作。」

【原文】`blog/040:18`：「只要从A0开始到某个At，使得A0+A1+….+At=B1+B2，后者是30分钟级别的同级别分解，这时候就可以继续按后一种分解进行相应的操作。」

【原文】`blog/040:20`：「对于大资金来说，这种级别的操作可以一直延伸下去，可以变成N重层次的操作，每一重都对应着一定的资金与筹码，而相应对应着不同的节奏与波动。……这如同赋格曲，简单的动机、旋律在N个层次上根据不同的转位、移位、对位等原则运动着，合成统一的乐曲。」

【原文】`blog/040:22`：「在这种同级别分解的多重赋格操作中，可以在任何级别上进行操作，而且都遵守该级别的分解节奏与波动，只是在不同级别中投入的筹码与资金不同而已。……而每一层次的操作都是独立又在一个整体的操作中」

【归纳】赋格比喻承载的是**同一套判别规则（"动机"）在 N 个级别上同时、独立运行**：每一重级别用同一判别规则（A_i vs A_{i+2} 盘整背驰 + 是否破前段高低点）判自己那一层的结构，各层独立，合成一个整体。`040:16` 的「换档」不是操作技巧，而是**低级别判别结果自动生成高级别判别对象**的机制：低级别的盘整背驰 → 演化出 A_{i+1}A_{i+2}A_{i+3} 三段 → 这三段就是高一级别的中枢。这是一条**自下而上的结构生成链**，且原文明说方向不可逆（「所有更大的中枢，当然是先有高一级别才可能有」）。

### 1.4 是操作口诀还是结构判别

【裁定】**是结构判别，不是操作口诀。** 依据：`040:16` 全段在讲中枢如何被生成（判别层面），`040:18` 的换档判据 `A0+…+At = B1+B2` 是一个**分解等式**（结构层面），`040:22` 明说「每一层次的操作都是独立」——独立性是判别的独立性，资金分配只是它的副产品（「只是在不同级别中投入的筹码与资金不同而已」）。

【原文没有】第 40 课正文（`040:14–22`）自始至终**没有出现「第一类/第二类/第三类买卖点」任何一处**。

【原文·出自回帖】`blog/040:36`（缠师答读者，台海比喻）：「这就像一个中枢震荡，向上突破代表和平统一，向下突破代表战争统一，问题是出现第三类买点还是卖点。而这个买卖点是当下的，是合力的结果，预测这些没意义，因为不可预测。**唯一可以断定的是，只要有第三类买卖点，目前的中枢震荡一定结束。**」

→ 这是第 40 课范围内唯一一处三类点承重句，且**出自回帖不出自正文**。引用时必须带此限定。

## 2. 利润率最大的操作模式（第 49 课 / chan99 0042）

### 2.1 判别起点 = 中枢，不是买卖点

【原文】`blog/049:16`：「进到市场，打开走势图，首先要找什么？就是找当下之前最后一个30分钟中枢。」

【原文】`blog/049:26`：「注意，这最后的30分钟中枢，是一定可以马上确认的，无须任何预测」

【原文】`blog/049:18–24`：「显然，这将会出现三种情况：1. 当下在该中枢之中 (ZG-ZD)。2. 当下在该中枢之下（小于ZD)。3. 当下在该中枢之上（大于ZG)。」

### 2.2 三类买卖点在此课是**分类算子**

【原文】`blog/049:28`：「第一种情况：显然，这中枢在延伸中，而后两种情况，**分别可以用第三类买卖点分为两小类**。」

【原文】`blog/049:30`：「第二种情况(分两类)： 1、当下之前未出现该中枢第三类卖点。2、当下之前已出现该中枢第三类卖点」
【原文】`blog/049:32`：「第三种情况(分两类)：1、当下之前未出现该中枢第三类买点。2、当下之前已出现该中枢第三类买点。」

【裁定】这是全部原文里对「三类点先于其他判别、且用于给局面分类」**最直接的一处**。完全分类树是二层的：第一层「相对最后一个中枢的位置」（三分），第二层「三类点是否已出现」（二分）。三类点在此不是一个买入时机，是一个**判别算子**。

### 2.3 三类点是背驰语义的分水岭

【原文】`blog/049:62`：「这里必须注意，中枢震荡中出现的类似盘整背驰的走势段，与中枢完成的向上移动出现的背驰段是不同的，**两者分别在第三类买点的前后**，在出现第三类买点之前，中枢未被破坏，当然有所谓的中枢震荡，其后，中枢已经完成就无所谓中枢震荡了，所以这问题必须清楚，这是有严格区分的，不能搞糊涂了。」

【裁定】这句是本次考据里对 3-1-2 命题分量最重的一条。它说明：**同一个「背驰」信号的语义，取决于三类点是否已经出现**。三类点之前的背驰 = 中枢震荡里的盘整背驰（差价用）；三类点之后的背驰 = 走势类型完成的背驰（即一类卖点，清仓用）。也就是说，**要判定"这个背驰是不是一类点"，必须先判定三类点在哪**。这是一条真实的**判别依赖**，不是排序偏好。

### 2.4 模式的完整定义与「利润率最大」的结构依据

【原文】`blog/049:46`：「显然，对于一个中枢来说，最有价值的买点就是其第三类买点以及中枢向下震荡力度出现背驰的买点。前者，最坏的情况就是出现更大级别的中枢，这可以用其后走势是否出现盘整背驰来决定是否卖出，一旦不出现这种情况，就意味着一个向上走势去形成新中枢的过程，这种过程当然是最能获利的。至于后面一种，就是围绕中枢震荡差价的过程，这是降低成本、增加筹码的。」

【原文·第一利润最大定理】`blog/049:58`：「缠中说禅第一利润最大定理：对于任何固定交易品种，在确定的操作级别下，以上缠中说禅操作模式的利润率最大。」

【原文·模式本体】`blog/049:60`：「该模式的关键只参与确定操作级别的盘整与上涨，对盘整用中枢震荡方法处理，保证成本降低以及筹码不丢失（成本为0后是筹码增加，当然，对于小级别的操作，不会出现成本为0的情况），**在中枢第三类买点后持股直到新中枢出现继续中枢震荡操作，中途不参与短差。最后，在中枢完成的向上移动出现背驰后抛出所有筹码，完成一次该级别的买卖操作，等待下一个买点出现。**」

【原文·第二利润最大定理】`blog/049:72`：「缠中说禅第二利润最大定理：对于不同交易品种交易中，在确定的操作级别下，以上激进的缠中说禅操作模式的利润率最大。」

【原文·激进模式】`blog/049:68`：「还有一种更激进的操作方法，就是不断换股，也就是不参与中枢震荡，**只在第三类买点买入，一旦形成新中枢就退出**。……因为后面一定会出现一个新的30分钟中枢，用这种方法，往往会抛在该级别向上走势的最高点区间。」

【原文·利润率的定义】`blog/049:74`：「这里所说的利润率，是指每次操作的平均利润/需要占用资金的平均时间」

【裁定·为什么利润率最大，结构依据是什么】把 `049:60`、`049:68`、`049:74` 合起来读，原文给的依据是**结构性的、不是统计性的**：利润率 = 平均利润 / 平均占用资金时间。分母由「不参与什么」决定，分子由「在哪一段持仓」决定。

- 分母：`049:60` 明说「只参与确定操作级别的盘整与上涨」；`049:40` 明说「没必要参与操作级别及以上级别的下跌与超过操作级别的盘整，这种习惯，必须养成」。规避掉的正是**结构上被判定为不可能盈利的时段**。
- 分子：`049:46` 明说三买之后「就意味着一个向上走势去形成新中枢的过程，这种过程当然是最能获利的」。
- 激进版把分母压到极限：`049:68` 只在三买持仓，一形成新中枢就退出，即只占有「中枢与中枢之间的那一段」。

【归纳】所以「利润率最大」判别的结构，是**中枢与中枢之间的连接段**。三类点是这一段的起点判据，向上移动的背驰（= 一类卖点）是终点判据。中枢震荡本身在第一定理里被降格为「降成本/增筹码」的辅助（`049:46` 末句），在第二定理里被完全剔除。

【原文】`blog/049:34`：「如果你技术好点，可以判断出次级别的第二类买点，这些买点很多情况下都是在中枢中出现的，那当然也是可以参与的。」
→ 二类点在本课出现一次，位置是「中枢之中」，且是**次级别**的、可选的。

## 3. 分区卷钱的程序（第 38 课 / chan99 0014:69）

### 3.1 「分区」分的是什么

【原文】`blog/038:30`（= `chan99/0014:69`，逐字一致）：「注意，这种方法或分解是可以结合在更大的操作系统里的。例如，你的资金有一定规模，那么你可以设定某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作，这样，就如同开了一个分区卷钱的机械，机械地按照一个规定的节奏去吸市场的血。这样不断地机械操作下去，成本就会不断减少，而这种机械化操作的力量是很大的。」

【裁定】**「分区」= 筹码/资金按操作级别分区，不是走势结构分区。** 依据是句子的主语链：「某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作」——被分的是筹码，分区的**依据**才是级别。

【归纳】但需注意二者不可切开：级别是结构量，所以「资金分区」是**结构分区诱导出来的**。这与第 40 课 `040:20`「每一重都对应着一定的资金与筹码」是同一件事的两种说法——分区卷钱就是多重赋格的资金侧表述。

### 3.2 程序的每一步在判别什么

## 6. 原文显示的另外三种序（照实登记，不迎合）

命题成立的同时，原文里还并存另外三种序，它们**不能被 3-1-2 吸收**：

**(1) 定义罗列序 = 1 → 2 → 3。** `chan99/0025:9–19` 按一、二、三顺序罗列定义，与定义字面依赖（二类引用一类）一致。教材体的书写顺序是 1-2-3，不是 3-1-2。

**(2) 时间出现序 = 1 → 2 → …（中枢震荡）… → 3。** `blog/020:62`：「第三类买卖点比第一、二类要**后知后觉**」；`blog/053:32`：「在第二、三买卖点之间，都是中枢震荡」。在一段实际走势里，三类点是**最后**出现的，不是最先。

**(3) 阶段互斥 —— 这是对 3-1-2 最实质的张力。**
- `blog/021:40`：「一个上涨趋势确定后，**不可能再有第一类与第二类买点，只可能有第三类买点**。」
- `chan99/0025:80`：「只有在这回升的中阴状态下才有第一、二类买点，中阴状态结束后，所有的走势中枢震荡只存在第三类买卖点以及走势中枢震荡的买卖点，就**不存在第一、二类买卖点了**。」

【裁定】按这两条，一/二类点与三类点分属**互斥的走势阶段**，而不是同一局面里可以依次施加的三道判别。这直接反驳「3-1-2 是一条对同一局面依次执行的判别流水线」这一读法。

命题要在原文里站住，必须限定为**跨阶段的结构生成/依赖序**，而不是同一时刻的判别流水线：

> 三类点判定中枢已死（`0025:17`、`053:32`）→ 中枢已死是趋势得以成立的前提（`021:34`、`blog/107`）→ 趋势成立才使一类点有定义域（`0025:9/11`）→ 一类点判出趋势转折（`0025:23`）→ 一类点存在才使二类点有定义（`0025:13`）。

这条链是**"谁的存在先决于谁"**的链，每一环都有逐字原文。它与「时间上三类点后知后觉」不矛盾，因为二者说的不是一回事：前者是定义/语义依赖，后者是同一段走势内的出现次序。

**(4) 归约到一类的反向压力。** `blog/038:16`：「站在纯操作的角度，由于**任何买卖点，归根结底都是某级别的第一类买卖点**，因此，只要搞清楚如何判断背驰……就一招鲜也足以在市场上混好了。」缠师在纯操作角度把三类**归约为一类（背驰）**，而不是把一类归约为三类。这与 §5 的判别序不冲突（一个是操作角度，一个是结构角度），但说明**在原文里"最基础的那一类"是第一类，不是第三类**。凡称「三类点最基础/最先」，须限定在「结构判别」这一角度，并同时列出 `038:16`。

## 7. 结论

1. **「3-1-2 是结构判别序而非操作顺序」在原文中成立**，且有一处逐字形态证据（第 21 课完备性推导序 3→1→2，`021:32/42/44`）与一处硬判别依赖（第 49 课背驰语义分水岭，`049:62`）。
2. **三块中，第 49 课是唯一直接、成体系支撑该命题的一块。** 第 40 课（赋格）与第 38 课（分区卷钱）的正文**不点名任何一类买卖点**，它们支撑的是「同级别分解 = 判别坐标系」「判别规则在 N 级别上同构复用」这一层，属于**该命题的前提**，不是该命题的证据。第 40 课唯一的三类点承重句出自回帖（`040:36`）。
3. **两处措辞需订正**：三类点是「中枢终结证 + 趋势的必要条件」，不是无条件的「趋势出生证」（`020:62` 反例）；一类点原文口径是「趋势转折点/背驰点」，「走势类型终结点」这一短语原文只用于三类点。
4. **一处实质张力**：`021:40` 与 `0025:80` 显示一/二类与三类分属互斥阶段。命题必须表述为跨阶段的**存在依赖链**，不能表述为同一局面的判别流水线。
5. **chan99 第二十一节对本命题基本无效**：第 49 课的全部承重句（分类算子、背驰分水岭、两条利润最大定理）编纂版一条未收。建议登记进 chan99 已知遗漏清单。另发现 `chan99/0041` 十类走势表、`chan99/0044` 第 2/3 条在 blog 语料中查无出处，属编纂增补。
