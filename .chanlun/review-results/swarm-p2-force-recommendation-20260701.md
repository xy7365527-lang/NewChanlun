## 待判点 B：第34课背驰力度三层判据的组合语义（原文推理，L0）

### 结论

**词典序（主从优先级），不是 AND，不是 OR，也不是加权。** 且原文在三层之上还有一层**元判据**——
「各级别配套」——它凌驾于黄白线/柱子面积/级别结构三层之上，是决定"哪个背驰力度大"的最高裁决。

精确表述缠师第34课的组合语义：

1. **黄白线（DIF/DEA）> 柱子面积 > 级别结构**，这个**排序是"重要性递减"，不是"判定顺序"**。
   任务描述里给的排序方向（「级别结构 > DIF > 面积」）需要修正——见下方原文逐字核对：缠师原文
   把**黄白线**列为三者中"最重要"，柱子面积次之，**且明确说"这都不是最关键的"**。
2. 真正的最高判据是**级别配套**（各级别综合看），它不在三层力度指标序列内，而是**元层**——
   决定这个背驰"算不算数、力度多大"的是级别关系，不是任何单一 MACD 分量。

组合语义是**带 fallback 的主从词典序 + 级别配套元门**，不是布尔 AND/OR：
- 先看级别配套（元门）：若级别不配套，单看任何 MACD 分量都无意义（"每个1分钟背驰都动会累死"）。
- 级别配套确认后，力度强弱的**主判据是黄白线**（是否回抽0轴、是否创新高）；
- 黄白线**平了**（都回抽/都不创新高，无法区分）才看**柱子面积之和**（"复杂走势里重要"）；
- 面积是最末位的辅助。

### 定义依据（逐字原文）

**第34课答疑（034-第34课.md:72,74，缠师直接回答"MACD 三层优先次序"提问，这是最强证据）**：

> 「一般来说，最重要的是黄白线，柱子面积之和一般在复杂走势里重要。**当其实这都不是最关键的，
> 最关键是要各级别配套地看，才能知道哪个背驰的力度大**，否则，每一个1分钟以下的背驰都要动，
> 那就会累死。」

逐句拆解：
- 「**最重要的是黄白线**」→ 黄白线是力度主判据（第一优先级）。
- 「柱子面积之和一般在**复杂走势里**重要」→ 面积是**条件性**次判据（只在复杂走势、即黄白线不足以区分时上位）。这正是词典序的"平了才看下一层"语义，不是 AND（面积不是每次都要满足）也不是 OR（面积不能单独顶替黄白线）。
- 「**这都不是最关键的，最关键是各级别配套**」→ 三层力度指标整体**从属于**级别配套这个元判据。级别配套是"哪个背驰力度大"的最终仲裁。

**提问者的原始场景（034:72 上文）**坐实了词典序而非 AND/OR：
> 「红柱子也比…高，黄白线却没创新高，背驰段红色柱子面积相比A部分减少了。好像不符合缠理论的
> 限制条件：红柱子、黄白线没有创新高。我怎么选择优先次序？」

提问者遇到的正是**三层指标互相冲突**（面积减少=背驰，但红柱子更高=不背驰，黄白线未创新高=背驰）。
如果是 AND，缠师会说"必须全满足"；如果是 OR，会说"任一即可"。缠师的回答是给**优先次序**
（黄白线 > 面积）+ 上推到级别配套——这是词典序 + 元门的标准结构。

**第17课（017:90 作业二 + 017:248,250）确立"MACD 是辅助非判据"的元前提**：

> （017:248）「用均线或MACD看背驰都是辅助性的，都不是最重要的」
> （017:250）「走势--级别--趋势--前后趋势比较-背驰-用均线等辅助判断背驰…难道没有均线、
> 没有MACD就判断不了背驰？显然不是。那只是辅助。」

这条给出了**判据的真正主干**：`走势→级别→趋势→前后趋势力度比较→背驰`。MACD（含黄白线/面积
两层）整体挂在这条链的**末端辅助位**。所以第34课的"黄白线>面积"词典序，本身是在"辅助工具内部"
排序，而级别结构（趋势前后比较）是**判据主干**，不与 MACD 两层并列——它在更高层。

**第24课（024:22-24,50）给 A/B/C 结构判据的独立性**：

> （024:24）「C段的走势类型完成时对应的MACD柱子面积…比A段对应的面积要小，这时候就构成标准的背弛」
> （024:50）「光用MACD辅助判断…准确率也应该在90%以上。而配合上中枢，那是**100%绝对的**，因为
> 这可以用纯数学的推理逻辑地证明」

「MACD 90% / 中枢 100%」的分裂再次坐实：级别结构（中枢关系）是**充要**判据（100%），MACD 是
**充分近似**（90%）。这不是 AND（若 AND，合取只能 ≤ min=90%）；是**主从**——中枢结构是主，
MACD 是主判据不可得（一般人搞不懂中枢）时的**降级替身**。

**第27课（027:314 娇注 + 027:676）补充：黄白线内部还有"斜率/速度"细判据**：

> （027:314）「力度上也没有特别的减少(娇注：看MACD上回来0轴后的下跌黄白线的**斜率和速度**）」
> （027:676）「MACD只是辅助，不是全部。你首先要分清楚趋势，…关键是先找到大一点级别的背驰段」

第27课把"黄白线"这一层进一步细化为"回抽0轴 + 斜率/速度"，并再次把"先分趋势、先定大级别背驰段"
置于 MACD 之上。这与第34课"级别配套是最高判据"完全一致。

### 组合语义的精确形式（推荐给下游编码的语义）

```
背驰力度判据 = 级别配套元门(L0结构) ∘ 词典序[ 黄白线主判据 ▷ 面积次判据 ]

其中：
  级别配套元门：先确定"在哪个级别比较、大级别背驰段是否成立"（第17/27课主干）。
                元门不成立 ⟹ 该 MACD 背驰不算数（无论黄白线/面积如何）。
  词典序 ▷    ：黄白线能区分力度 ⟹ 用黄白线定论；黄白线平（都回抽/都不创新高）⟹ 降级看面积。
                面积**不能**单独顶替黄白线（非 OR），也**不是**每次必须满足（非 AND）。
```

注意：这里的"级别结构"作为**元门**，与 P2 代码里 `judge_first_cached` 用的"趋势 τ 门控 +
破最后中枢几何"是**同一个东西**——即结构判据（L0 整数几何）本就应该是主干，MACD 面积（现状唯一
实装）只是那个"90% 辅助替身"。这与待判点 A 的路线 B 精神吻合（见下）。

### 反方（哪种读法也说得通，为什么不选）

**反方1：AND（三层都要满足）**。
- 支持理由：第24课说"两个都满足就更标准了"（027:30 万科例："只要其中一个符合就可以是一个背弛
  的信号，两个都满足就更标准了"）——似乎暗示多层合取。
- 为什么不选：027:30 原文恰恰是**反 AND 的铁证**——「**只要其中一个符合就可以**是一个背弛的信号」。
  这是显式 OR-或-词典序（任一充分），"两个都满足更标准"只是说合取时置信度更高，**不是**判定必须
  合取。若 AND，缠师不会说"其中一个符合就可以"。故 AND 被原文直接否证。

**反方2：OR（任一层满足即算背驰）**。
- 支持理由：027:30「只要其中一个符合就可以是一个背弛的信号」字面像 OR。
- 为什么不选：这句的语境是**黄白线不创新高 vs 面积变小**这两个**同属"背驰确认"的证据**之间的 OR，
  是"背驰在不在"的**存在性**判定；而第34课问的是"哪个背驰**力度更大**"的**强弱排序**问题。
  存在性可以 OR（任一证据即确认背驰存在），但**力度排序**是词典序（黄白线主导强弱）。两个问题
  不同层：OR 管"有没有背驰"，词典序管"背驰多强 + 该不该动"。第34课问的是后者，答案是词典序 +
  级别配套元门。纯 OR 会丢掉缠师明确给出的"黄白线最重要"这个主从信息。

**反方3：级别结构与 MACD 两层并列做三元词典序**（即任务描述的"级别结构 > DIF > 面积"）。
- 支持理由：把三者拉平成一个三层词典序，实现简单。
- 为什么不选：原文的层级不是"三者并列"，而是**两层架构**——级别配套是**元门/主干**（第17课"走势→
  级别→趋势→背驰"链，MACD 挂末端），黄白线/面积是元门内部的**辅助工具二层词典序**。把级别结构降
  到与 DIF/面积同一序列里，会丢失"级别配套是元判据、凌驾于所有 MACD 分量"这个第34课最强论断
  （034:74"这都不是最关键的，最关键是各级别配套"）。故推荐是**元门 ∘ 二层词典序**，不是三元
  平铺词典序。

## 待判点 A：P2 选择偏差消除路线（A / B / A+B，技术权衡）

### 结论

**推荐路线 B（走势力度：ForceMeasure 增非-MACD 实例），并明确一个关键更正：B 与 A 不正交——B 能
自动解决 A。** 任务描述里标为"关键"的疑问（"Flat 丢弃跟 force measure 是否正交"）经代码考古坐实：
**不正交**。Flat 候选被丢弃的**直接充分原因**就是 MACD 面积判据不满足（`macd_c_lt_a=false`），
不是一个独立于力度判据的"选择器方向门"问题。因此走 B 升级力度判据后，原本因 MACD 面积不足而变成
Flat 的破中枢候选会重新获得方向（Long/Short），自动进入 μ 样本，**无需碰 μ-key（MuClass 六维
分桶键）、无需碰任何 bit-exact 核心不变量**。B 严格优于 A。

### 定义依据（代码考古，bit-exact 可追溯的因果链）

**核心因果链**（Flat 丢弃的完整机制，从 MACD 判据到样本排除）：

```
① judge_first_cached (signal.rs:309)：
     macd_c_lt_a = abc.diverges(hist, a_idx, c_idx)      // C段面积 < A段面积（MACD 面积比，唯一力度判据）
② signal.rs:318：
     EndpointSituation.below_last_center = macd_c_lt_a    // MACD 背驰确认才置端点语义；否则 false
③ bsp.rs:57,83：
     is_first() = below_last_center && !after_first_buy && !left_center
     bits.buy1 = is_first()                               // macd_c_lt_a=false ⟹ buy1=false（零 bit）
④ interp.rs:171,206-211 candidate_dir：
     dir = root_sel(conf_plus=..., conf_minus=...)        // 零 buy/sell bit ⟹ VoiceSide::Flat
⑤ selector.rs:214 filter_gamma / econ_positive.rs:258 采集：
     if c.dir == VoiceSide::Flat { continue/return true } // Flat 候选被 μ 门跳过，从不进 μ 样本
```

**关键结论：② 是唯一注入点。** `below_last_center`（决定 buy1/sell1 的唯一"背驰"分量）在
`judge_first_cached` 里**只**由 `macd_c_lt_a` 赋值（signal.rs:318），别无他源。所以"破中枢候选
变成 Flat"⟺"MACD 面积 C≥A"。这就是 A 与 B 不正交的**代数证明**：force measure（现状=MACD 面积）
的输出直接决定候选是不是 Flat。

**StructBreakFeature 是未接入生产的死代码（坐实 codex#15）**：
- 生产入口 `extract_signals`（signal.rs:557）调 `extract_signals_with_hist_features(...).0`——**用 `.0`
  丢弃了 features sidecar**（只取 BspPoint，扔掉 `Vec<StructBreakFeature>`）。
- `extract_signals_with_hist`（signal.rs:538，另一个生产包装）同样 `.0` 丢弃。
- `StructBreakFeature.macd_c_lt_a` 字段的**唯一读取者是测试**（signal.rs:958,992）——生产路径无消费者。
- 结论：StructBreakFeature 作为"让 Flat 候选进样本、下游 χ 可学习 MACD"的设计**没有接通**——
  features 从没到达 selector/μ 采集。P2 声称的"MACD gate→feature，破中枢候选全进样本消选择偏差"
  在 BspPoint 层面确实产出了零 bit 候选，但**零 bit 候选 = Flat = 被 μ 门丢弃**（链⑤），所以
  "消选择偏差"实际未兑现——候选进了 BspPoint 序列，但没进 μ 样本。这正是 codex#15"假消除"的准确
  含义：BspPoint 层加了候选，μ 采样层照样丢。

**μ-key（MuClass 六维分桶键，mu_estimator.rs:69-75）**：`level / delta / i_class(bits.class_index) /
parent_dir / position`。路线 A 说的"碰 bit-exact 的 μ-key"= 要改这六维的桶定义（如把 Flat 也分个
桶、或改 class_index 布局）——这是受保护核心不变量，动它触发大面积 bit-exact 回归。

### B 不碰 μ-key 的验证（回答任务标"关键"的疑问）

路线 B（ForceMeasure 增实例：PriceAmplitudeForce=|Δ价| L0整数、PriceSpeedForce=|Δ价|/Δbar）改的是
**链① `abc.diverges` 内部用什么力度度量**，即"什么条件下 `macd_c_lt_a`（应改名 `force_diverged`）为
true"。它的效果：

- 破中枢候选若满足**新力度判据**（如价格振幅背驰）→ `below_last_center=true` → `buy1=true` →
  `candidate_dir` 返回 **Long**（非 Flat）→ **不被链⑤丢弃**，正常进 μ 样本，按 (level, δ=+1,
  i_class含buy1, ...) 分桶。
- **MuClass 六维分桶键完全不动**：改的是"候选是否置 buy1"，不是"buy1 候选如何分桶"。`from_certificate`
  （mu_estimator.rs:84）的输入 bits 变了（buy1 从 false 变 true），但 class_index 的**布局/权重**
  没动，delta/level/parent_dir/position 的推导（z_of_candidate, interp.rs:144-155）没动。
- **ForceMeasure 接口已抽象好**（force_conformance.rs:50-141）：`measure/strength/mono/faithful`
  公理已定义，当前唯一实例 `ForceMeasureAdapter` 硬编码 = MACD 段面积（force_conformance.rs:83-84
  `measure` 直接调 `divergence::segment_macd_area`）。增 PriceAmplitudeForce 只需实现同一组
  measure/strength，满足 mono/faithful（|Δ价| 对价格振幅天然单调，公理平凡成立）——**接口层零改动**。

**所以：B 能自动解决 A，且严格不碰 μ-key。** 任务描述里"若 Flat 丢弃与 force measure 正交，那 B 并
不能自动解决 A"这个 if 分支**不成立**——它们不正交（链②坐实），B 直接覆盖 A 的问题。

### 三条路的 bit-exact 风险面

| 路线 | 改动点 | bit-exact 风险面 | 是否碰 μ-key/核心不变量 |
|------|--------|------------------|------------------------|
| **A（碰 μ-key）** | MuClass 六维分桶键（如给 Flat 分桶 / 改 class_index） | **高**：class_index 布局是 seen-set 键 + Gamma bit-exact 输入 + selector 分桶键，动它全链回归；`bit_exact_battery_digest` 测试直接锁 | **是**（受保护核心） |

### 边界条件（结论何时翻转）

1. **若存在破中枢候选，其被丢弃的原因不经过 `below_last_center`**（即除了 macd_c_lt_a=false 之外，
   还有其他路径把它变成 Flat），则 B 不能覆盖那部分，A 或额外修复才需要。**核实结果：不存在**——
   judge_first_cached 里 buy1/sell1 的唯一"背驰"来源是 below_last_center=macd_c_lt_a（signal.rs:318），
   破中枢几何（broke）不足时直接 return None（signal.rs:288-289，根本不产候选，不是变 Flat）。故
   进入"产 BspPoint 但零 bit=Flat"的候选，其零 bit **必然**因 macd_c_lt_a=false。边界不触发。
2. **若下游真的想让"零 bit struct_break 候选"进 μ 样本做 MACD 有效性 χ 检验**（P2 原设计意图），
   那 B 不是唯一解——也可以让 μ 采集不按 Flat 丢弃、而给 struct_break 候选一个"无方向记录桶"。
   但这**必然碰 μ-key**（要新增一个 Flat/record 桶维度）= 落入 A 的风险面。B 的优势正是**回避这个
   意图**：B 不追求"让零 bit 候选进样本"，而是让**本该有方向的候选**（价格振幅确实背驰的破中枢点）
   **恢复方向**——从根上减少 Flat 候选的产生，而非事后给 Flat 候选补桶。这更符合原文（待判点 B：
   力度判据本就该是级别结构主干 + 词典序，MACD 面积只是末位辅助）。
3. **若真实数据上 PriceAmplitudeForce 与 MACD 面积高度共线**（改了力度度量但几乎不改变哪些候选置
   buy1），则 B 对 A 的"消除选择偏差"效果趋近于零（换汤不换药）。这是 **L2/L3 才能判定**的经验问题
   （本推理是 L0/L1 结构分析，不声明经验有效性）。翻转条件：L2 验证显示 |价格振幅背驰 XOR MACD 面积
   背驰| 的破中枢候选集为空 ⟹ B 无增量，退回需要 A 或组合。

### 认识论等级

**L0/L1（结构/管线分析）**。本推荐基于代码因果链的**结构**追溯（L0：哪个字段决定哪个字段，纯逻辑）+
接口契约（L1：ForceMeasure 增实例不改分桶键，管线正确性）。它**不**声明"路线 B 能提升回测 alpha"
——那是 **L2/L3**（需 walk-forward μ + 真实数据否证，delta-r-alpha 工位）。B 优于 A 的判断是**风险面
+ 正交性**的结构结论，不是 alpha 结论。

### 下游推论

1. 若结论成立，task #17（编排者方向决定）的选项应收敛为：**B 单独即可**，A（碰 μ-key）无必要
