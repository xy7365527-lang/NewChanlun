**第6章在全书的位置与编排逻辑**：

全书是一条 **心态 → 时机 → 行情 → 理论 → 买卖点 → 知行 → 风控 → 人心 → 战例 → 格局** 的递进链。第6章处在**理论与买卖点讲完之后、资金管理与风控之前**的枢纽位：

- **第4章「走势密码」**（正文 102–233，30 节）是全书的**结构理论层**：中枢、级别、走势类型、背驰、区间套、同级别分解都在这里定义。
- **第5章「明辨买卖点」**（正文 234–283，15 节）是**买卖点定义层**：「100% 安全的买卖点只有三个」「买卖点是有级别的」「大级别的第二类买点由次一级别相应走势的第一类买点构成」「第二、三类买卖点之间，都是中枢震荡」「动态把握第三类买卖点」。
- **第6章「知行合一」**（正文 284–349，35 节）**不是新的结构定义章，而是「已定义结构如何在当下被应用」的应用/纪律章**。章扉页导语（PDF p302，编者撰）点题：

  > 「"知行合一"思想是由明朝嘉靖年间的王阳明提出的……掌握"知行合一"，不仅要靠学习知识，更要在实践中磨炼，并最终悟道。**在资本战场上，股票是用来操作而不是用来预测的。**"知行合一"同样是缠师理论的特点，是成功的四字诀。」

### 3.5 与 080 课「知行合一」句的对照（任务指定）

**E-1 博文正本**：`docs/chanlun/text/blog/080-第80课.md:318`
> 「股票是用来操作而不是用来预测的，必须明白本 ID 理论知行合一的特点。现在十分简单，就是等待这 1 分钟走势类型的凋谢，具体的理论与操作，在课程里都反复说了，就不一一重复了。」

**080 课全文语境**（该课 2007-12 解盘，`080-第80课.md:310–324`）：该句出现在一段**三买主导的当下操作**叙述之后——
> （:312）「今天的走势十分正常……周五的分析中已经很明确了，**只要形成 1 分钟的第三类买点，那么新高就是绝大可能**。今天早上 11 点多的那个第三类买点（后面有更正 3 买为 10:26），极为教科书，后面的走势，就是本 ID 理论所 100% 保证的活动，没什么可说的。」
> （:316）「真能有效战胜市场的，还是要学会用本 ID 的理论去当下的操作……从那 5025 点的 93 开始，一个 1 分钟中枢类型都没完成，但你明白本 ID 的理论的，就可以看着他按照理论的规范一步步地**生长**出来。」

→ **语境判定**：080 课「知行合一」句的紧邻上下文，正是**用三买判定「新高绝大可能」= 走势能否继续生长**。这与 A-3/A-4 的三买=中枢生死判别在**同一语义轴**上，构成对待判洞察中「3 = 出生证」一支的**旁证**。但 080 课本身**没有**把三类点排序，也未论及一类点终结或二类点确认。

**E-2 编纂本对该句的改写**（PDF p323 / 正文 305，6.12 节）
> 「"知行合一"是明朝思想家"三不朽圣人"之一王阳明先生在 500 年前提出的。要有效战胜市场，就要学会在缠中说禅股票投资理论的观照下去做当下的操作。**股票是用来操作的而不是用来预测的，所以必须明白缠中说禅股票投资理论知行合一的特点。**」

### 4.2 章中另有的秩序（照实给，不迎合）

**秩序 A：1-2-3 生成序（同一轮转折内三类点的发生次序）—— 该章唯一明文成序的文本**

D-1（PDF p317 / 正文 299，博文 `028-第28课.md:874–878`）给出的是一条完整的时间链：

> 30 分钟背驰 → **第一类卖点** → 5 分钟级别向下走势完成 → 反抽（5 分钟向上） → 第二个 5 分钟背驰 = **第二类卖点** → 盘整、盘不住、跌破中枢、次级别反抽不上中枢 = **第三类卖点**

这是全章**唯一**一处把第一、二、三类点连续排序的文本，其序为 **1 → 2 → 3**。编纂本把它整段收在 6.7 节。

**与 3-1-2 的关系**：两者**不在同一层，不构成直接冲突**——
- 1-2-3 是**同一次转折内三类点的发生（时间/生成）顺序**；
- 3-1-2 是**每一类点各自承担哪个结构判别任务**的功能分派。
但必须照实指出：**章中明文成序的是 1-2-3；3-1-2 是从散落于 6.4/6.6/6.7/6.27/6.28/6.29 的语句归纳出来的读法，该章本身没有以任何形式陈述它。**

**秩序 B：1、2 类点在跨级别上先于分型 —— 与「3 最先」构成张力**

D-4（PDF p346 / 正文 328，6.26 节）：
> 「注意，利用顶分型进行操作时，必须配合小级别的图。**本质上，分型都是在某小级别的第一、二类买卖点成立后出现的。**」

→ **博文可回溯**：`079-第79课.md:98`。博文原文作「分型都是**某**小级别的第一、二买卖点成立后出现的」，编纂本增「在」「类」二字（语义不变）。
→ **张力所在**：本句把**一、二类点**置于**更基础**的位置（小级别一二类点成立 → 大级别分型出现）。若把 3-1-2 读成「三类点在任何意义上最先」，则本句与之相抵；若把 3-1-2 严格限定为「同级别内的功能分派」，则本句属跨级别轴，可并存。**该章未提供任何文本消解这一张力。**

**秩序 C：三买的判别力有中枢序号限定 —— 对「出生证」的范围约束**

B-2 与 A-1 共同限定：**只有第一中枢后的三买签发趋势诞生证**。「一般第二个中枢以后的第三类买点都没有介入的价值」（B-2）、「在**第一**中枢后出现第三类买点并形成非背驰类向上」（A-1）。
→ 待判洞察若表述为「三类买卖点判别中枢生死/趋势诞生」而不加限定，**在该章文本下属于过度概括**。

### 4.3 总判定

> **该章对 3-1-2 结构判别序：分支支撑、整体未成文。**
>
> 三支中，「3 = 中枢生死/趋势诞生」有该章最强的博文级证据（107 课的「上升趋势形成的最精确定义」）；「3 先于 1」有唯一但硬的结构依据（91 课「顶背驰必须发生在中枢第三类买点之后」）；「1 = 趋势类型终结」支撑；「2 = 新方向确认」仅部分支撑，因二买可出现在中枢震荡内部。
>
> 但**「3-1-2」这一序本身，该章从未陈述**。章中明文成序的是 **1-2-3 生成序**（28 课），且另有一条 **1、2 类点先于分型** 的跨级别秩序（79 课）与「3 最先」构成未消解的张力。三买的「出生证」资格还受「第一中枢后」的严格限定。
>
> **结论：该章可作为 3-1-2 各分支的引文出处，不可作为 3-1-2 判别序本身的教义依据。** 且因本书为辅助层编纂本，上述所有引文的定义效力一律回溯至其博文正本（107 课 / 91 课 / 32 课 / 49 课 / 28 课 / 52 课 / 79 课），本书仅作索引与线索价值。
