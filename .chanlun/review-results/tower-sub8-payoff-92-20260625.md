## 一、payoff 纤维构造：从塔投影出逐分量 P&L（构造性，非参数）

### 1.1 payoff 纤维的载体 = 塔 ⊕_k(H⁰_k⊕H¹_k)（#80/#82 已给）

塔的完整对象（骨架 〇）：
```
仓位 = ⊕_k [ d_k(逐级方向) × 角色(H⁰_k 骑本级 / H¹_k 操作次级) × α*_k(内在配额) ]   over k=a0..r*
```

每级 k 是同一个 #35 上同调单元（中枢 Z_k≃S¹，H*(S¹)=H⁰⊕H¹，#80 §1.3）。payoff 纤维**不是新对象**——它是这个塔的**收益侧投影**：每个仓位分量（一份 units 在某级某腿某方向上的持有）随价格运动产生一个 P&L 流，纤维把这些 P&L 流按 (k,leg,dir) 索引收集起来。

**为什么 payoff 是纤维而非标量（编排者 E⊗F 类比的精确含义）**：
- 节点轴 E⊗F（576号）：转折节点 = E（中枢拓扑事件）⊗ F（力度公理），是一个**纤维**（每个节点带 E 坐标和 F 坐标），不是一个标量"该不该动"。
- 仓位轴 H⁰_k⊕H¹_k（#80）：仓位 = 逐级逐腿的纤维，不是一个标量"多大仓"。
- **payoff 轴（本任务）**：收益 = 逐级逐腿逐方向的 P&L 纤维 π(k,leg,dir)，不是一个标量"赚多少"。payoff 标量（总收益数字）= 把纤维**沿所有索引求和拍扁** = 丢掉"哪级哪腿哪方向赚/亏"的结构。**0/8 超 BH 的诊断失败正源于只看 payoff 标量（拍扁），不看纤维分量。**

### 1.2 纤维的三个轴由塔的三个内在结构生成（非任意笛卡尔积）

payoff 纤维的索引集 = **级别轴 K × 腿轴 L × 方向轴 D**，三轴各有内在生成源：

| 轴 | 取值 | 生成源（内在，非参数） | 谱系 |
|----|------|----------------------|------|
| **级别轴 K** | k ∈ {a0, a0+1, …, r*} | 中枢递归语法 `find_centers(units,level)` 逐级生成；长度 = 走势树非空层数 = 递归迭代自然终止处（#82 §3.2） | #80 §5.2 自相似 / #82 d_k 向量 |
| **腿轴 L** | leg ∈ {H⁰, H¹} | S¹ 上同调强制 dim H⁰=dim H¹=1，无 H^{≥2}（#80 §4.1）；恰好两腿，不可增减 | #80 §1.3 / #35 |
| **方向轴 D** | dir ∈ {R+, R−} | Z₂ 镜像 τ 强制走势方向二值（#81 §1.1，Direction enum 二元）；R−=τ(R+) | #81 / 576号 D∞ τ |

**关键（非任意笛卡尔积）**：三轴不是我们"选了三个维度叉乘"，是塔的三个**正交内在结构**（级别递归 / 上同调腿 / 镜像方向）。这与 #81 §5.4 的群论分解一致：方向轴 D=Z₂=⟨τ⟩（−1/+1 本征），级别轴 K=⟨σ⟩（σ^∞ 平移），半直积 Z₂⋊ℤ=D∞（576号节点对称群）；腿轴 L=H⁰⊕H¹（τ 的 +1 本征，#81 §2.3 角色不变）。**payoff 纤维的索引集 = D∞ 作用 × 上同调腿分解**——内在生成，非参数化维度。

### 1.3 逐分量 P&L 的构造（每个 π(k,leg,dir) 是什么）

对每个三元组 (k,leg,dir)，P&L 分量 π(k,leg,dir) 由该分量的**开-平买卖点配对**构造（纯操作语义，zero 外在量）：

```
π(k, H⁰, dir) = 核心腿在级别 k 骑 dir 方向走势的 P&L
             = Σ over (k级买卖点开 → k级type1反向买卖点平) 的配对 pnl
             开：dir=R+ → k级买点开 long 核心 / dir=R− → k级卖点开 short 核心  (#81 §3.2 τ-协变)
             平：k级 type1 反向 fire（顶背驰平多 / 底背驰平空，#80 §2.2"何时变"）
             pnl：long: m(c−basis) / short: m(basis−c)  (rec_engine.rs:457-458, τ-协变)

π(k, H¹, dir) = 机动腿在级别 k 沿 (k−1) 区间套做 dir 反向操作的 P&L
             = Σ over (k−1级买卖点开 → k−1级配对反向买卖点平) 的绕环循环 ∮ pnl
             开：dir=R+(主升浪) → (k−1)级卖点开 short 回调腿 / dir=R−(主跌浪) → (k−1)级买点开 long 反弹腿
             平：dir=R+ → (k−1)级买点平空回升 / dir=R− → (k−1)级卖点平多回落  (#81 §3.2)
             pnl：绕 S¹ 一周 ∮≠0 留下 (k−1) 回调/反弹幅度的 pnl 痕迹 (#80 §3.2)
```

**构造性保证（非参数）**：
- π(k,H⁰,dir) 的开/平**全由级别 k 的买卖点钉住**（k级买卖点开、k级type1平），不引入外部阈值。
- π(k,H¹,dir) 的开/平**全由级别 (k−1) 的买卖点配对钉住**（绕环一圈的 ∮，#80 §3.2），不引入外部阈值。
- dir=R−=τ(R+)：R− 的每个分量 = τ(R+ 对应分量)（#81 §3.3 一套覆盖两向）⇒ **不为做空腿单独构造 P&L 公式**，τ 镜像自动生成（R− 核心 short=τ(R+ 核心 long)，R− 机动 long=τ(R+ 机动 short)）。

### 1.4 gap-to-BH = 全分量求和（payoff 标量是纤维投影）

```
总收益 = Σ_{k=a0}^{r*} Σ_{leg∈{H⁰,H¹}} Σ_{dir∈{R+,R−}} π(k, leg, dir)
gap-to-BH = 总收益 − BH收益
          = [Σ π(k,H⁰,dir) − BH] + Σ π(k,H¹,dir)
            └─ 核心腿相对 BH ─┘   └─ 机动腿净贡献 ─┘
```

**两项的认识论分层（编排者硬约束的核心结论）**：
- **核心腿项 Σπ(k,H⁰,dir) − BH**：核心骑对方向时 ≈ BH（满仓骑住），drag 来自固定 split 把核心切走一截给机动（#80 §5.4 塔顶单格拍扁 = MOBILE_FRAC=1/3 抽走 1/3 核心）。O6 溶解踏空后核心 H⁰ 8/8 正（payoff-regime #75 L3），此项 ≈ 0 或微正（匹配 BH）。
- **机动腿项 Σπ(k,H¹,dir)**：这是 gap-to-BH 的**决定性项**——若全部机动分量为正 ⇒ 超 BH；若高级别孤儿空腿失血 ⇒ 拖到 0/8 超 BH。**失血全在此项的孤儿分量**（§2）。

**payoff 标量拍扁的精确形式**：只看总收益数字 = 把上面三重求和压成一个标量 = 丢掉"哪个 (k,leg,dir) 分量正/负"。诊断 0/8 超 BH 必须**展开纤维**（看每个 π(k,leg,dir) 的符号），不能只看标量。这是 §1.1 "payoff 是纤维非标量" 的操作后果。

## 二、孤儿诊断：失血分量的内在因（纯买卖点配对，零外在量）

### 2.1 失血分量的内在判据 = 孤儿腿（编排者硬约束："穿透到内在因"）

**核心命题**：π(k,leg,dir) < 0（失血）的内在因 = **孤儿腿**——在级别 k 的转折节点 X 开了一条腿（买卖点开仓），但级别 k 上**无配对的闭合转折节点 Y**（无反向买卖点平仓）⇒ 该腿无内在闭合信号 ⇒ 孤儿 ⇒ 失血。

**形式化（纯操作语义，零 bar/价格/强平/z）**：
```
孤儿(k,leg,dir) ⟺ ∃ 开仓转折节点 X at level k (买卖点 fire)
                   ∧ ¬∃ 配对闭合转折节点 Y at level k (反向买卖点 fire)
                   ⇒ 腿无配对闭合 ⇒ 失血源

失血 bleed(k,leg,dir) = #{孤儿腿 at (k,leg,dir)} = 未闭合转折节点对计数 at level k
                       （零 bar 计数 / 零价格% / 零强平线 / 零统计相关）
```

**为什么 X 无配对 Y（内在根因 = d_k 读错）**：
- H¹_k 空腿（dir=R+ 配置下机动做空回调）由级别 (k−1) 卖点 X 开，应由级别 (k−1) 买点 Y 配对平（绕环 ∮ 闭合，#80 §3.2）。
- **若级别 k 实际是 R−**（d_k=Down，下跌走势）而塔顶单一 top_trend_dir 误读为 R+（#82 §3.3 拍扁）⇒ 在该级开了"R+ 才合法"的机动 short，但级别 k 是 R− ⇒ 该级永不产生使空腿盈利平掉的配对买点 ⇒ **空腿成孤儿 ⇒ 死扛失血**。
- 镜像对偶（#81 §4.1）：dir=R+ 配置的孤儿空腿 ↔ τ → dir=R− 配置的孤儿多腿（在 R− 主跌浪逆势裸多）——**同一 d_k 读错病理在镜像两侧的表现，不是两个独立 bug**。

### 2.2 外在量是孤儿的代理/症状，不是内在因（剔除论证）

骨架零件2 + #82 §4 + #89 §5.3 已确立（纳入不重推，本任务在 payoff 纤维层重申其逐分量形式）：

| payoff-regime #75 原诊断量（外在） | 内在因（孤儿，本任务穿透） | 为什么外在 |
|---|---|---|
| 僵尸持仓 >10万 bar | 无配对闭合转折节点 Y at level k | "持仓久" = "无闭合信号"的 bar 计数代理 |
| 强平 2×basis 够不到 | 缺结构出场、外在价格兜底失效 | "强平够不到" = "缺配对买卖点"的价格症状 |
| z≈100% 相关 | 孤儿腿与亏损同源（同一 d_k 错） | "统计相关" = 孤儿与失血共因的事后测量 |

**穿透的意义（编排者硬约束）**：用外在量诊断 = 又拍扁一次 = 仍不知道**结构上什么出问题**。穿透到孤儿 = 内在的因 = **转折节点对未闭合** ⇒ 内在的修 = **不开孤儿腿（仅 d_k 正确时开 H¹_k）≠ 调强平线/bar 阈值**（#89 §5.3）。

### 2.3 核心腿 H⁰ 全正（O6 溶解踏空非失血源）— 构造性证明

**命题**：π(k,H⁰,dir) ≥ 0 当 d_k 正确（核心骑对方向）。核心腿不是失血源。

**证明（构造性，三步，纳入 payoff-regime #75 L3 锚定）**：
1. **核心骑对方向必正**：H⁰_k 骑级别 k 走势 dir 方向（#80 §2.2），dir=R+ → long 核心、dir=R− → short 核心（#81 §3.2 τ-协变）。骑对方向 ⇒ 价格沿 dir 运动 ⇒ pnl=m(c−basis)（long, dir=R+ 涨）或 m(basis−c)（short, dir=R− 跌）≥ 0。
2. **核心不被机动触动**：由直和 by construction（#89 §1.2，π_{H⁰}∘(H¹算子)=0），机动 H¹_k 的 sink/recover 结构上不碰核心 units ⇒ 核心 P&L 不被机动孤儿污染。
3. **核心减仓涌现条件化（非无条件不减，非死扣）**：真顶（无更高级别接，d_k 翻 R−）时核心条件化减仓（#89 §2.3 分支 B），不扛跌 ⇒ 核心在真顶不变成失血源（死扣 anchor 才扛跌，#89 §4.2）。
4. ∴ 核心 H⁰ 骑对方向 + 直和保护 + 涌现条件化减仓 ⇒ π(k,H⁰,dir) ≥ 0。**payoff-regime #75 L3：核心 H⁰(long) 8/8 全正，坐实 O6 溶解踏空、核心非失血源。□**

**踏空 vs 失血的区分（#80 §6.3 / 561号）**：踏空 = 核心腿被拍扁（只读塔顶单级别 R_k，d_k 向量坍缩 → 核心没骑住中间级别走势）= **核心项 < BH**（赚得少，O6 已溶解）；失血 = 机动孤儿腿净负 = **机动项 < 0**（亏出去）。二者是 gap-to-BH 两项的不同病理：踏空在核心项（#80 解），失血在机动项（本任务 §2.1 孤儿）。

### 2.4 失血 = 高级别孤儿腿（d_k 错 + 区间套确认未下沉够深）

**命题（编排者指定的失血定位）**：失血集中在**高级别**孤儿 H¹ 腿，因为高级别的 d_k 最容易读错（区间套确认未下沉够深 ⇒ 身份未定 ⇒ 孤儿）。

**推导（纳入 #82 §3.3 + 骨架 §★★顶部不特殊）**：
1. **d_k 错的来源 = 单一 top_trend_dir 拍扁**（#82 §3.3）：top_trend_dir 只读走势树最高非空层 d_{tl}，中间级别 d_k(k<tl) 全用塔顶单一方向代理 ⇒ 高级别（接近 r*）的实际方向最易与塔顶单一值错配。
2. **区间套确认未下沉够深 ⇒ 身份未定 ⇒ 孤儿**（骨架 §34）：高级别腿的方向身份（d_k=Up/Down）须用区间套定位下沉看低级别确认（574号确认深度）。下沉不够深 ⇒ 该级走势是回调还是真顶未定 ⇒ H¹_k 腿在身份未定时开仓 ⇒ 无法判定配对闭合点 ⇒ 孤儿。

### 3.2 无遗漏证明：每个 P&L 分量可证是某轨道

**命题**：任意仓位产生的任意 P&L 流，可证属于某个 π(k,leg,dir) 轨道，无逃逸。

**证明（穷尽性，三轴各穷尽）**：
1. **级别轴穷尽**：任一仓位变动由某级买卖点触发（#80 §4.2 张成证明：级别 k 仓位变动要么 k 级买卖点 → H⁰_k，要么 (k−1) 级买卖点 → H¹_k）。买卖点必属某级 k∈{a0..r*}（走势树非空层穷尽）⇒ 每个 P&L 流有确定级别 k。
2. **腿轴穷尽**：由 S¹ 上同调 H*(S¹)=H⁰⊕H¹ 无 H^{≥2}（#80 §4.1），任一仓位分量要么 H⁰（绕环不变=核心）要么 H¹（绕环循环=机动），无第三腿 ⇒ 每个 P&L 流有确定腿 leg。
3. **方向轴穷尽**：走势方向类型 = {R+,R−} 二值（#81 §1.1 Z₂ 穷尽，盘整非趋势走势=无方向类型=H¹ 振荡底空间本身，不产生方向分量）⇒ 每个 P&L 流有确定方向 dir。
4. ∴ 任一 P&L 流 = (确定 k, 确定 leg, 确定 dir) → 属于唯一 π(k,leg,dir) 轨道，无逃逸。**□**

**逆否验证（no-patch 自检）**：若存在一个 P&L 流不属于任何 π(k,leg,dir) ⇒ 它由非买卖点触发（违反张成）或在 S¹ 第三腿（违反上同调维度）或第三方向（违反 Z₂ 二值）——三者都与已证结构矛盾。故无遗漏。
