**一个转折节点可操作 ⟺ 该转折所属回调的「移动级别 L_move」与「区间套确认级别 L_confirm」满足 L_confirm ⪯ L_move（确认级别不高于移动级别 = 确认在移动完成前到达 = 确认够快相对于移动）。** 这个判据从「中枢(k):=次级别(k-1)走势重叠」+「第27课区间套逐级定位」两条递归语法**唯一生成**，零外部幅度/摩擦门。它是 H¹_k 机动腿「非孤儿（有配对闭合转折节点）」的充要条件，因此是 α*_k > 0 的充要条件（可操作性是配额的布尔前驱：α*_k > 0 ⟹ 可操作，可操作 ⟹ α*_k 可正）。生成函数 G(L_move, L_confirm) 机械吐出全部 case——可操作（深移动 ∧ 快确认）/ 孤儿失血（浅移动 ∨ 慢确认），**无边界例外，顶部 r* 与任意级别 k 自相似**（顶部 type1 背驰 + 区间套确认是同一判据在 k=r* 的实例，非不可约墙）。

## 一、构造的出发点：可操作性不是配额，是配对闭合的充要条件

### 1.1 从 H¹_k 的循环结构读出"可操作性"的形式（非新引入）

子1（#80 §3）已构造：**H¹_k = 级别 k 上沿次级别 (k-1) 区间套做一个完整开-绕-平循环的机动仓**。H¹(S¹) 的代数本质是「绕环一周的闭合循环类」——一个**完整的 sink→持有→recover 闭环**（∮≠0 留下回调幅度 pnl 痕迹）。

关键（编排者零件2，payoff-regime #75 经内在纠正）：**一个 H¹_k 腿要成为合法的 H¹ 类（闭合循环），必须有配对的开-平转折节点**：
- sink（开空 / 开多）由级别的一个买卖点触发（转折节点 X）
- recover（平空 / 平多）由级别的**配对**买卖点触发（转折节点 Y）

若级别 k 上 X 开了腿但**没有配对的闭合转折节点 Y**，则这个腿**不是 H¹ 类**（不闭合 = 不是 1-上闭链 = 留在 1-链层永不模掉边界）= **孤儿腿** = 失血源（项目记忆 project_isolated_fugue_forest_verdict「孤儿不可能定理」已结算 L3：父仅经后序 close 关闭 ⟹ 子必先关 ⟹ 合法森林无孤儿；失血 = 违反孤儿不可能）。

**因此可操作性的形式 = 转折节点 X 开的 H¹_k 腿是否能闭合成 H¹ 循环类（是否有配对 Y）。** 这不是外部判断，是 H¹(S¹) 的"闭合循环"代数结构本身对腿的要求。

### 1.2 配对闭合的内在条件 = 确认在移动完成前到达

H¹_k 腿在哪开、在哪平，由第27课区间套逐级定位决定（子1 §3.2，rec_engine.rs:113-121 严格逐级区间套）。问"X 开的腿能否配对闭合 Y"= 问"区间套能否在该次级别移动内**及时**给出反向同侧证据触发 recover"。

把这个"及时"严格化，引入两个**纯级别量**（都是同一级别尺度上的读数，自相似，无外部尺度）：

- **移动级别 L_move(X)**：转折节点 X 所属的次级别回调本身是什么级别的走势。回调是 segment 级（最浅）/ move 级 / recL2 级 / recL3 级（最深）。**这是"回调多大"的内在尺度**（级别 = 幅度的内在尺度，自相似），非"回调幅度 > θ"（外部）。
- **确认级别 L_confirm(X)**：捕获 X 的反向并触发配对 Y，区间套需要在哪个级别给出第一个同侧证据。k-1 层快速触发 = 低 L_confirm；须深层 recL3 链贯通才确认 = 高 L_confirm。**这是"确认多慢"的内在尺度**，非"成本 < 收益"（外部 574 成本门）。

**N5 实测锚定（project_interval_nesting_forward，L2/L3，八标的一致）**：确认滞后是级别的阶梯函数——segment 中位 12bar → move 120bar → recL2 3000bar → recL3 50000bar（每升一级 ×10-25）。这个阶梯**就是 L_move 与 L_confirm 的共同尺度**：两个量都落在 {segment, move, recL2, recL3, ...} 这同一条级别阶梯上，可直接序比较。

### 1.3 可操作性判据（从两条递归语法唯一生成）

```
可操作(X) ⟺ L_confirm(X) ⪯ L_move(X)
                （确认级别不高于移动级别 = 确认在移动完成前到达 = 配对 Y 在 X 的循环内闭合）
```

**推导（为何是 ⪯ 而非别的关系，非断言）**：

1. H¹_k 腿要闭合成循环，需在该次级别移动**结束前**得到反向确认 Y（移动结束后回调已走完，再确认已错过整段 = 腿被套在移动尽头 = 退化为孤儿，见 §1.1）。
2. 移动走完一个 L_move 级别走势耗时 ≈ 该级别的 N5 阶梯时长 T(L_move)。
3. 区间套在 L_confirm 级别给出确认耗时 ≈ T(L_confirm)（同一阶梯）。
4. N5 阶梯单调：L_confirm ⪯ L_move ⟹ T(L_confirm) ⪯ T(L_move) ⟹ 确认在移动完成前到达 ⟹ Y 在 X 的 H¹ 循环内 fire ⟹ 腿闭合 ⟹ **非孤儿 = 可操作**。
5. L_confirm ≻ L_move ⟹ T(L_confirm) ≻ T(L_move) ⟹ 确认在移动已走完后才到 ⟹ Y 落在 X 循环外（下一个移动里）⟹ 腿不闭合 ⟹ **孤儿 = 失血**。**□**

**逆否自检（no-patch）**：若可操作性用"回调幅度 > θ_abs"判定（外部门），则 θ 是外部绝对标量，跨标的/级别量级失配 21×（project_p0_p1，θ=1% 第五次量级失配）——某些级别误杀、某些漏放。⪯ 是**级别序比较**（两个量在同一级别阶梯上），无外部绝对尺度，自相似——这是它非拍扁的根据。

## 二、可操作性 vs 配额 α*_k 的分离（可操作性是布尔前驱）

编排者要求"可操作性独立推导"——本节证明可操作性比 α*_k 更基本，不是 α* 的别名。

| | 可操作性（本任务） | 配额 α*_k（#83，orbit9-reassess #76） |
|---|---|---|
| 类型 | **布尔**（可操作 / 孤儿） | **标量**（配多少机动份额 ∈ [0, 配额上限]） |
| 问题 | H¹_k 腿能否内在闭合（有无配对 Y） | 给定可操作，配多少仓捕获 |
| 判据 | L_confirm ⪯ L_move | α*(L_pullback, L_confirm) 大小 |
| 依赖序 | **前驱**：不可操作 ⟹ α*_k 应 → 0（开了也是孤儿） | **后继**：在可操作集上才有非平凡取值 |

**分离定理**：α*_k > 0 ⟹ 可操作(对应级别 k 的回调转折)；可操作 ⟹ α*_k 可正（但仍可因 L_pullback 浅而 → 0）。即 **可操作性是 α*_k > 0 的必要条件，非充分**。

证明：
- (必要) α*_k > 0 means 开了 H¹_k 机动腿。若该腿不可操作（L_confirm ≻ L_move），则它是孤儿（§1.3 step 5）⟹ 失血 ⟹ 这不是合法的 α*_k > 0 配置（违反孤儿不可能定理）⟹ 合法 α*_k > 0 必蕴含可操作。
- (非充分) 可操作但 L_pullback 浅（回调级别低，捕获跌幅小）⟹ α*(L_pullback↓, ·) → 0（orbit9-reassess #76 v3：L_pullback 低 ⟹ α* → 0）。即可操作 ≠ 必然配仓。**□**

**下游推论**：诊断量 bleed_k（零件2，子2#82/子4#83）= "每个 H¹_k 是否有配对闭合转折节点" **恰是可操作性判据的否定**——孤儿 ⟺ 不可操作 ⟺ L_confirm ≻ L_move。三分量在诊断层统一：d_k 错（方向）⟹ 该级永不产生平腿买卖点 ⟹ L_confirm = ∞（确认级别不可达）⟹ 不可操作 ⟹ 孤儿。**方向错是不可操作的一个极端实例（L_confirm 发散），不是独立失血机制。**

## 三、顶部自相似证明（顶部 r* 不是不可约特例）

编排者纠正（骨架 §★★）：r* 顶部由 type1 背驰 + 区间套确认自相似解决，非不可约墙。本节证明顶部可操作性与任意级别 k 同构。

### 3.1 顶部 type1 背驰产生 type1（"恒不产"是流式前沿假象）

l4_consoldn"最高级别恒不产 type1"= **流式前沿假象**（project_l4_consoldn_no_leave_falsified 已结算：最高涌现级别恒生长中 ⟹ 流式累加下恒不结束 ⟹ 看似不产 type1）。真相：顶部走势完成时**有** type1 背驰（顶背驰），它触发 r*+1 涌现。所以 k=r* 与 k<r* 一样有 type1 转折节点 X。

### 3.2 顶部可操作性 = 判据在 k=r* 的实例（无新分支）

把 §1.3 判据施于 k=r*：
- 顶部 type1 背驰 = 转折节点 X at level r*（k 级走势完成信号）。
- L_move(X) = r* 级移动（最深，N5 阶梯顶端）。
- L_confirm(X) = 区间套定位确认 X 真顶所需级别。由 §1.3：
  - **若 L_confirm ⪯ r***（区间套在 r* 移动完成前贯通确认真顶）⟹ 可操作 ⟹ 配对结果二选一（**同一自相似过程，非两特殊分支**）：
    - 背驰触发 r*+1 涌现 ⟹ 核心 H⁰_{r*} 重角色为 H¹_{r*+1} 衬底（涌现重读，子2#82），回调交 H¹_{r*+1} 操作 — 这与"k 级 type1 触发 k+1 涌现"完全同构。
    - 背驰未触发更高涌现（本级清仓）⟹ 核心 H⁰_{r*} 减仓 — 这与"k 级 type1 本级清仓"完全同构。
  - **若 L_confirm ≻ r***（区间套未下沉够深，确认滞后超过 r* 移动）⟹ 不可操作 ⟹ 孤儿 ⟹ 失血。**这就是"真顶失血"的内在因**——不是顶部不可约，是**区间套未下沉够深**（与任意级别孤儿同源，可更深区间套解决）。

**关键（无边界例外）**：上面**没有一个"无更高级别"的特殊 if 分支**。"真顶减仓"是 §3.2 第二子情况（背驰未触发更高涌现），它是 type1 背驰处理在 k=r* 的自然结果，与 k<r* 的本级清仓**字面同构**。编排者证伪的 Lead"r* 顶部不可约边界"提法 = 把"是否涌现更高级别"误当顶部特例——实则它是 type1 背驰的两个自然出口，每个级别 k 的 type1 都有这两个出口（k<r* 时"涌现更高"恰好总成立因为上面有级别；k=r* 时两出口都可能，取决于背驰是否够强触发新级别）。**出口集相同，只是 k=r* 时第二出口的概率非零——这是连续谱，非离散特例。**

### 3.3 唯一下界 = a0 分辨率（全级别同一，非顶特例）

判据 L_confirm ⪯ L_move 的递归向下终止在哪？终止在 **a0 基础分辨率 1bar**（project_1min_resolution_irreducible，L2/L3 已结算：1min 分辨率不可约，细 a0 补到 0 被否证——σ 非退化但贪心停 2.074 bits，细化反放大熵）。

- L_confirm 最低 = a0 级（1bar 即确认）—— 这是确认能多快的下界。
- L_move 最低 = a0 级（1bar 走势）—— 这是移动能多浅的下界。
- **a0 下界对所有级别 k 同一**（包括 r*）——不是顶部特例。574（区间套确认深度）= 内在操作（确认能下沉到多深），非不可约墙；其下界就是 a0，全级别共享。

**因此：判据自相似到底（a0 终止），顶部 r* 与底部 a0 与中间任意 k 共享同一判据 L_confirm ⪯ L_move 和同一下界 a0。无任何级别是特例。□**

## 四、生成性完备：G 生成所有可操作性 case（无边界例外）

编排者最高约束（骨架 §★★★）：构造必须**吐出**所有 case，能主动枚举一个编排者未指出的 case。本节给出生成函数并验证完备。

### 4.1 可操作性生成函数 G

```
G : (转折节点 X) ↦ (L_move(X), L_confirm(X)) ↦ 可操作性 case
  输入域 = 全部转折节点 X（每个涌现级别 k 的每个买卖点，由"中枢(k):=次级别(k-1)走势重叠"递归生成）
  两个内在读数 (L_move, L_confirm) ∈ 级别阶梯 L = {a0, segment, move, recL2, recL3, ..., r*}（同一阶梯，N5 实测）
  输出 = sign(L_move ⊖ L_confirm) 的三值商：
     L_confirm ⪯ L_move（且 L_move 深）  → 可操作·有效捕获   （深移动 ∧ 快确认）
     L_confirm ⪯ L_move（但 L_move 浅）  → 可操作·近平凡     （浅移动：可闭合但 α*→0，捕获跌幅小）
     L_confirm ≻ L_move                  → 孤儿·失血          （慢确认：腿不闭合）
```

G 是**生成性**的（非断言性）：它不是"先列三类再断言完备"，而是 (L_move, L_confirm) 在级别阶梯 L×L 上的**序比较的商**——L×L 的每一点被 ⪯ 关系机械分到三个区（⪯深 / ⪯浅 / ≻）。任何转折节点 X 经递归语法生成后，其 (L_move, L_confirm) 必落在 L×L 某点，必被 G 分类，**无逃逸**。

### 4.2 无遗漏证明（每个 X 可证属某 case）

- 全部转折节点 X 由中枢递归语法生成（每级 k 买卖点 = 第27课区间套定位的 fire 点），输入域穷尽。
- 每个 X 有确定的 L_move(X)（其所属回调级别，走势树读出）和 L_confirm(X)（区间套确认链状态，rec_engine.rs:113-121）—— 两者都落在级别阶梯 L 上（N5：L 是离散有限阶梯 + a0 下界 + r* 上界）。
- ⪯ 是 L 上的全序（级别阶梯线性）⟹ L_confirm 与 L_move 必可比 ⟹ 必落 {⪯深, ⪯浅, ≻} 之一。
- **无第四区**：⪯ 全序的三值商穷尽（< 严格小 / = 相等并入"近平凡或有效按 L_move 深浅" / > 严格大）。**□**

### 4.3 主动枚举一个未被指出的 case（完备性证据）

编排者要求 G 吐出一个**连编排者都没指出的 case**。生成函数吐出：

**Case「等级回调」（L_confirm = L_move 的对角线 case）**：当次级别回调的移动级别**恰等于**区间套确认级别（L_confirm = L_move，落在 G 的对角线上）。此前所有讨论是 ⪯严格（确认更快）或 ≻（确认更慢），**对角线 L_confirm = L_move 是边界 case**：确认恰在移动完成的**同一级别**到达。

G 的判定：L_confirm = L_move 满足 ⪯（弱序含等号）⟹ **可操作**，但配对 Y 在 X 循环的**末端**到达（T(L_confirm)=T(L_move)，恰好不超时）⟹ 腿勉强闭合但 pnl 痕迹 ∮ 退化（绕环但回调已几乎走完，捕获跌幅 → 0）⟹ **可操作但 α* → 0 的临界**（与 §4.1"可操作·近平凡"合并，但这里是**级别相等**触发而非移动浅触发——两条不同的 α*→0 路径）。

**为何这是真 case 非补丁**：它是 ⪯ 全序商的对角线，被 G 机械吐出（L×L 的对角线必然存在）。它揭示 α*→0 有**两个内在源**：(a) L_move 浅（回调小），(b) L_confirm = L_move（确认恰好赶上但无余量）。这两者在 orbit9-reassess #76 的 α*(L_pullback, L_confirm) 里是**两个不同自变量的边界**，此前 report 只讨论了 (a)，对角线 (b) 是生成函数自己吐出的——**完备性证据：构造吐出了一个未被手工列举的边界 case。**

下游：实装诊断量须区分"孤儿失血（L_confirm ≻ L_move，腿不闭合）"vs"对角线退化（L_confirm = L_move，腿闭合但捕获→0）"——前者是失血（开了就亏），后者是 no-op（开了≈不开），**两者都该 α*→0 但内在因不同**（孤儿要诊断方向 d_k，对角线要诊断确认余量）。这是给 #83 配额 / #82 诊断的新接口（生成自完备分类，非补丁）。
