## 0. 改判结论（分级）

- **Level0 一类**：机制存在（`signal::judge_first_cached`）、已接线（`extract_signals_with_hist`）、忠实第24课。0 触达 = **市场事实 (a)**：破 L0 中枢∧A/C 可配对∧MACD 背驰(C<A) 的合流在 BTC 300K 经验为空。**非候选生成缺口**。

## 1. (i) is_first 三子条件 vs 第24课忠实性 —— ✓ 忠实

`is_first() = below_last_center ∧ !after_first_buy ∧ !left_center`（bsp.rs:56），生成器 `judge_first_cached`（signal.rs:262-340）填值：

| 子条件 | 生成器实现 | 第24课原文对应 |
|---|---|---|
| （几何前提）破最后中枢∧趋势方向 | `end.price < last_center.zd`（1买，下跌趋势向下破）/ `> zg`（1卖）（line 274-283） | 一类=趋势末段向下突破最后中枢下沿 ✓ |
| （趋势前提）A/C 可配对 | `a_seg`=前中枢同向离开段（line 285）——**要求 ≥2 同向中枢** | 趋势=至少两个同向中枢（第24课趋势定义）✓ |
| below_last_center | `= macd_c_lt_a`：C 段面积 < A 段面积（`abc.diverges`，line 306/314） | 背驰=力度衰减（第24课:24 MACD 面积）✓ |
| !left_center | 恒 false（line 312：一类是破中枢非离开后回抽） | 区分第三类（离开中枢回试）✓ |
| !after_first_buy | 恒 false（line 310） | 区分第二类（一买后回调）✓ |

**判据无偏差**：is_first 逐条对应第24课「趋势(≥2同向中枢) + 破最后中枢 + MACD 背驰」。零 bit struct_break（C≥A 未背驰）不冒充一类（line 307-308 语义纪律），正确。排除「判据偏差」态。

## 2. (ii) 候选端点生成覆盖 —— level0 覆盖，level≥1 缺口

**Level0**：`judge_first_cached` 对**每个 L0 线段终点**评估「破最后中枢∧A/C配对」（signal.rs:691-694 在 `extract_signals_with_hist` 循环内）。**趋势末端背驰段终点 = C 段终点（破最后中枢段），正是 judge_first 的锚点**——team-lead 质疑的「一类典型位置不在候选集」对 L0 **不成立**：位置在集内，被评估。0 结果 = 合流（几何破中枢 ∧ A/C配对 ∧ C<A）经验为空。

**关键佐证（合流哪一环空）**：#116 level0 `bsp_pre=721` 全第三类，**无零 bit 冗余**（721=721 三类，无 struct_break 点）。而 judge_first_cached 只要 `broke ∧ A/C 可配对` 就返回 Some（含 C≥A 的零 bit 点）。故零 bit 点也=0 ⟹ **瓶颈在几何环**（`broke ∧ A/C pairable` 在 L0 罕见触发），非仅背驰子条件。L0 线段相对 L0 中枢的「趋势方向破最后中枢+前中枢可配对」在 BTC 分钟数据罕见。

**Level≥1**：`mod.rs:256-262` `else { Vec::new() }`——**级别≥1 的 L0 线段层第一/三类判定被跳过**。高级别买卖点仅靠 `extract_second_for_level`（B2/S2 递归组装）。故**级别-N 趋势背驰段终点(级别-N 一类)从不进候选集** = 候选生成缺口。

## 3. (iii) mod.rs:256「上级层只产二类」出处 —— 实装架构（部分原文依据，部分待谱系确认）
