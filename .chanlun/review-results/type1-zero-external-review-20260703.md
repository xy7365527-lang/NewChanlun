> 缠中说禅趋势：在任何级别的任何走势中，**某完成的走势类型**至少包含两个以上依次同向的缠中说禅走势中枢，就称为该级别的缠中说禅趋势。

**原文对照**（第18课，走势分解定理一）：

> 缠中说禅走势分解定理一：任何级别的任何走势，**都可以分解成同级别"盘整"、"下跌"与"上涨"三种走势类型的连接**。

**原文对照**（第20课，中心定理二——实装 `classify_relation` 的 GG/DD 口径与此逐字一致）：

> 缠中说禅走势中枢中心定理二：前后同级别的两个缠中说禅走势中枢，后GG<前DD，等价于下跌及其延续；后DD>前GG等价于上涨及其延续。后ZG<前ZD且后GG>=前DD，或后ZD>前ZG且后DD=<前GG，则等价于**形成高级别的走势中枢**。

### 环 1.5（趋势门的上游）：中枢链构造——每 3 段新建、无延伸吸收

```rust
// mod.rs:196-216（逐字）
fn detect_centers_with(
    units: &[UnitRange],
    build: fn(&UnitRange, &UnitRange, &UnitRange) -> Option<Center>,
) -> Vec<Center> {
    let mut centers = Vec::new();
    let mut i = 0usize;
    while i + 2 < units.len() {
        match build(&units[i], &units[i + 1], &units[i + 2]) {
            Some(c) => {
                centers.push(c);
                // 成立支：前进 3 段（已确认中枢不回写，reference:16）。

            None => {

            }

    }
```

实装自陈的诚实范围声明（mod.rs:176-178，逐字）：

> ★诚实范围：v0 用**非重叠三段窗口**识别中枢（连续三段成真枢则前进 3 段）。**延伸中枢（同一中枢吸收后续段）的完整 start/finish 区间识别留待后续**（Origin `centersOf` 当前亦三段窗口）。

**原文对照**（第20课，中心定理一——中枢延伸的判据）：

> 缠中说禅走势中枢中心定理一：**走势中枢的延伸等价于任意区间[dn，gn]与[ZD，ZG]有重叠**。换言之，若有Zn，使得dn>ZG或gn<ZD，则必然产生高级别的走势中枢或趋势及延续。

**原文对照**（第18课，走势类型的延伸）：

> 例如一个盘整，三个重叠的连续次级别走势类型后，盘整就可以随时完成……但这可以不结束，可以不断延伸下去，**不断围绕这缠中说禅中枢上上下下地延伸下去**直到无穷都是可以的。

**代码事实**：按中心定理一，围绕同一中枢的持续震荡是**同一个中枢的延伸**；实装则每凑满 3 段重叠就新建一个中枢。后果（§2 实测）：震荡区被拆成大量外缘互相重叠的同级别「中枢」，相邻关系 94.4% 落入 `LevelExpansion`——而按中心定理二，波动区间重叠的前后两中枢「等价于形成高级别的走势中枢」（应升级/合并，而非作为同级别链上的两个元素参与「依次同向」检验）。

### 环 4：A/C 段配对（A = 前一中枢的同向离开段）

```rust
// divergence.rs:579-596（逐字）
pub fn locate_trend_seg_a(
    segments: &[Segment],
    prev_center: &Center,
    last_center: &Center,
    trend_dir: Direction,
) -> Option<(usize, usize)> {
    // A 段 = prev_center 之后、last_center 之前、方向 = trend_dir 的离开段（相邻前中枢的离开段）。
    // 取该区间内**最后一个**同向段（最接近后一中枢=离开 prev_center 进入 last_center 的趋势腿）。
    segments
        .iter()
        .filter(|s| {
            s.direction == trend_dir
                && s.start_index >= prev_center.end_index
                && s.start_index < last_center.end_index
        })
        .next_back()
        .map(|s| (s.start_index, s.end_index))
}
```

**原文对照**（第24课，A/B/C 框架）：

> 用MACD 判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，把这三段分别称为A、B、C 段。……用MACD 判断背驰的前提是，A、B、C 段在一个大的趋势里，其中A 之前已经有一个中枢，而B 是这个大趋势的另一个中枢，……而C 段的**走势类型完成时**对应的MACD 柱子面积（向上的看红柱子，向下看绿柱子）比A 段对应的面积要小，这时候就构成标准的背弛。

**代码事实**：实装的 A 段与 C 段都是**单一线段/单元**（`Segment`），原文的 A/C 段是「次级别走势类型」（可含多段结构，「C 段的走势类型完成时」）。

```rust
pub fn segment_macd_area(hist: &[f64], start: usize, end: usize) -> f64 {
    if start > end || end >= hist.len() {
        return 0.0;
    }
    let mut area = 0.0;
```

### 三跑对照的含义（事实陈述）

同一份数据、同一套代码：全历史 0；切窗且窗内某级链恰好全同向时产出结构合法的一类信号且落在真实历史顶部。**产不产一类不取决于市场是否有趋势力竭点，而取决于观测窗起点选在哪**——趋势门的输入是「从数据起点累积的完整链」，历史越长越必然 Degenerate。因果重放中该性质表现为：数据头几天后趋势门永久锁死，此后任何真实趋势顶底都不再评估。

## 3. 嫌疑点自查（每条：代码事实 + 原文对照；结论留给外审）

**(a) 趋势门的作用域：全历史链 vs 走势分解后的当前走势类型。**
代码事实：`trend_class(全级中枢链)` 每级一次全局判定；每级走势裁决至多产 1 个走势类型；无任何把链切分为「盘整、下跌、上涨的连接」的机制（环 1 引文）。原文：第17课趋势定义作用于「某**完成的走势类型**」；第18课分解定理一「任何走势都可以分解成三种走势类型的**连接**」；第17课「走势终完美」——每种走势类型完成后转化为其他类型。漏斗坐实该环是全历史唯一死点。

**(b) 中枢延伸缺失 → 中枢链被重叠碎片污染。**
代码事实：每 3 段重叠即新建中枢（环 1.5 引文），无中心定理一的延伸吸收；L0 全历史 94.4% 相邻中枢外缘重叠。原文：中心定理一（触及 [ZD,ZG] = 同一中枢延伸）；中心定理二（前后中枢波动区间重叠 = 形成**高级别**中枢）。后果链：本应为「1 个延伸中枢」的震荡被记为 N 个重叠中枢 → 任何真实趋势段的链上都夹杂重叠对 → 「全链同向」几乎不可能。注意：即使趋势门改为局部判定（嫌疑 a 修复），链上 94.4% 的重叠关系仍会把局部同向段切得极短（L0 最长仅 3 个中枢）——(a)(b) 是叠加的两层。

**(c) 相邻关系口径 GG/DD。**
代码事实：`classify_relation` 用外缘完全分离（`next.dd > prev.gg`）。原文对照：与第20课中心定理二**逐字一致**（「后DD>前GG等价于上涨及其延续」）——该口径本身忠实。但定理二的对象是「前后同级别的两个缠中说禅走势中枢」（延伸/合并处理完成后的规范中枢）；实装喂给它的是 (b) 所述未延伸、未合并的三段窗口碎片。口径忠实、对象存疑。

**(d) 级别≥1 的方向占位（fold_direction）。**
代码事实（recursive_tower.rs:195-208，逐字节选）：

```rust
pub fn fold_direction(&self, prev: Option<&LeveledMove>) -> Direction {
    match prev {
        // 首单元无前驱 ⟹ 缺省 Up（几何路径不读取，结构占位）。
        None => Direction::Up,
        // 外缘上移（hi 升）= Up，下移 = Down（与 classify_relation 外缘判据同源）。
        Some(p) => {
            if self.rmove.hi() >= p.rmove.hi() {
                Direction::Up
            } else {
                Direction::Down
            }
        }
    }
}
```

级别≥1 的「线段方向」由相邻单元外缘 hi 比较派生（自陈「外缘占位」「不冒充 §6.1 意义的线段方向交替」），而环 3 的破中枢几何要求 `end.dir == trend_dir`。牛市窗 L4 七环全活证明该环在链单调时可工作；方向占位在混合链下与真实走势方向的耦合程度未测（趋势门全灭使其从未在全历史被触及）。

**(e) A/C 段粒度：单线段 vs 次级别走势类型。**
代码事实：C 段 = 破中枢的**单一**线段/单元；A 段 = 前中枢之后**最后一个**同向单段；面积 = 单段 bar 区间 Σ|hist|。原文第24课：「C 段的**走势类型**完成时对应的 MACD 柱子面积」——A/C 是次级别走势类型（可为多段的趋势/盘整）。若次级别离开走势由 3 段构成，实装只取其中 1 段的面积。

**(f) 盘整背驰被完全排除于一类之外。**
代码事实：τ=Consolidation（恰 1 中枢）→ `trend_dir=None` → 不产一类；盘整背驰无独立信号通道（第三类与「小转大」通道存在，但盘整背驰点本身不产任何一类 bit）。原文对照：第24课「背驰都指最标准的趋势中形成的背驰」支持一类=趋势背驰；但第24课背驰-买卖点定理：「**任一背驰都必然制造某级别的买卖点**，任一级别的买卖点都必然源自某级别走势的背驰」；第17课趋势转折定律：「任何级别的上涨转折都是由某级别的第一类卖点构成的」。走势终完美下，盘整走势类型的终结点在实装中没有任何一类信号承接（是否应由「某级别」一类/小转大/三类承接，属需外审裁定的定义问题）。

**(g) MACD-area-only 力度判据。**
代码事实：背驰唯一判据 = MACD 柱面积严格变小（环 5-6 引文；实装自陈 gap）。原文第17课：「背驰是两相邻同向趋势间，后者比前者的**走势力度**减弱所造成的」「用均线或MACD等判断其力度」是辅助。此环在全历史从未被触及（死点在环 1），不影响零触达归因，但影响修复后的信号质量。

## ⚠️ 确定性发现（显著标出）

以下两条不是「嫌疑」而是可复算的代码结构事实，且与原文定理**直接矛盾**（是否定性为 bug 由编排者/外审最终裁定）：

1. **趋势门要求「全历史 = 单一走势类型」**。`trend_class` 作用于整级累积中枢链且无走势分解，等价于：只有当从数据第一天起的**全部**中枢依次同向时才可能产生任何一类信号。这与第18课走势分解定理一（任何走势 = 三种走势类型的**连接**）矛盾——按原文，历史不是一个走势类型，趋势定义无法作用于整段历史。漏斗证明该门在数据第 1-17 天永久锁死，是全历史零触达在所有级别上的**充分**死因。实装注释（mod.rs:1944-1945）自认此性质但此前被归因为「市场事实」。
2. **中枢延伸（中心定理一）未实装**，且实装自陈「留待后续」（mod.rs:177）。直接后果实测：94.4% 相邻中枢关系为外缘重叠——按中心定理二这些重叠对「等价于形成高级别的走势中枢」，它们本不应作为同级别链元素参与「依次同向」检验。该缺口独立于(1)，即便修复(1)也会把局部趋势切得远短于真实（L0 最长局部同向段仅 3 中枢）。
