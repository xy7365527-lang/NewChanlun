## 0. 一句话结论

小转大**没有本级别的一类买卖点**（原文反复强调），所以它不可能走区间套通道（区间套的对象是本级背驰段，小转大恰恰缺这个段）。原文给的确认手段是**第二类买卖点 + 次级别结构确认**，其判据是**结构性的（次级别中枢/三买卖/反向突破）**，不是**力度性的（本级 MACD 背驰）**。因此小转大通道 = 「本级无背驰锚 → 转为次级别结构确认」的一条**独立于区间套的确认通道**，语义上是「等待确认」而非「精确定位」。

## 1. 原文考古（一级权威链，行号溯源）

### 1.1 定义句：什么是小转大

> **`053:28`**「第一类买卖点，就是该级别的背驰点，这足以应付最大多数的情况，但有一种情况是不可以的，就是前面反复强调的小级别转大级别的情况。为什么？因为当小级别背驰时，并未触及该级别的第一类买卖点，所以就无须操作。对这种情况，就需要第二类买卖点来补充。」

> **`043:198`**「属于段间没有盘背小转大下的转折，跌破 Ai+K 高点」——小转大 = **段间无（本级）盘整背驰**却发生转折。

> **`069:38`（娇注）**「转折分两种。常规转折与非常规转折。常规转折即标准级别对应形态学背离。**非常规转折即为小转大**。通常非常规转折都具有非常规空间换时间之特性。」

**语义锚定**：小转大 = 次级别（小）背驰引发本级别（大）转折，但**本级别自身没有背驰段**。这与代码 `descend_type1_anchor_depth` 返回 `None` 是同一件事：本级 Type2/3 信号的精确回抽段在次级别找不到一类背驰锚点（`econ_positive.rs:524/553`）。**代码的 None 域 = 原文的小转大域**——已在 L2 报告 §2 对齐。

### 1.2 处理定理：背驰-转折定理（小转大的理论出口）

> **`029:16`**「缠中说禅背驰-转折定理：某级别趋势的背驰将导致该趋势最后一个中枢的**级别扩展**、该级别更大级别的**盘整**或该级别以上级别的**反趋势**。」

> **`043:14`**「转折必然由背驰导致，但背驰导致的转折并不一定是同一级别的。」

即：次级别背驰 → 本级别（或更大级别）转折，且必然进入「中枢扩展 / 更大盘整 / 反趋势」三分类之一（29课完全分类）。小转大对应的是「次级背驰导致的**跨级别**转折」这一支。

### 1.3 确认手段一（权威）：第二类买卖点

> **`053:28`**「在小级别转大级别的情况下，第二类买卖点就是最佳的，因为在这种情况下，没有该级别的第一类买卖点。」

> **`chan99/0025:21`（买卖点定律一）**「任何级别的第二类买卖点都由次级别相应走势的第一类买点构成。」

> **`chan99/0025:63`**「一般说，高点的一个次级别向下、再一个次级别向上，如果不创新高或盘整背驰，都构成第二类卖点。」（买点反向）

**这是最硬的可编码判据**：小转大的确认 = 等本级第二类买卖点。第二类买卖点定义清晰、已在缠论知识库有编码定义，可直接复用。

### 1.4 确认手段二（娇注细化，实盘四点）

> **`044:52`（娇）**「小转大实盘注意点：1 本级别或者次级别中枢反向突破；2 次级别中枢出现3买卖；3 本级别3买转2卖，3卖转2买；4 调整或者反抽的位置超过正常最后个次级别走势的位置到达第二个中枢 GGDD——形成同分3买卖的高低点从而扩展大中枢前走势类型结束。」

> **`044:56`（娇注·注意点2）**「这个该级别走势最后个次级别中枢是动态的，不一定为小级别背驰点前的中枢。」

> **思维导图定理 `128`**「小转大（小背驰-大转折）定理：小级别背驰引发大级别反向的**必要条件**——该级别走势的最后一个次级别中枢出现第三类买卖点。」

**娇注四点是二类买卖点在小转大场景的结构化展开**，其中「次级别中枢出现3买卖」与思维导图「最后一个次级别中枢出现三类买卖点」互相印证——这是小转大最可编码的必要条件。

### 1.5 时机手段：小平台确认（线段级小转大）

> **`066:198`**「一般来说，小转大都有一个小平台，等小平台确认向上再介入更好，因为小转大的平台，是可以往下突破的。」

> **`098:18`**「（注：这个背驰非区间套，1分级别小转大）……回拉之后如何，这涉及预测。正确的思维是，把回拉后出现的情况进行完全的分类，根据每种分类对应的后果，决定你自己的对策。」

**「小平台可以往下突破」= 小转大信号本身可失败**，必须等平台（=次级别盘整中枢）向上确认。这是「等待确认」语义的原文根据，也是**不可精确定位、只能事后确认**的诚实边界。

## 2. 可编码判据设计

### 2.1 通道位置（接入点）

现状（`econ_positive.rs:570 build_nest_certificate`）：Type2/3 信号 → `descend_type1_anchor_depth` → `None`（小转大）→ **证书 None → 门直接拒**（`:1134`）。1353 条信号在此**只有拒、没有出口**。

设计：在 `None` 分支不直接丢弃，改为进入**小转大确认通道** `xiaozhuanda_confirm(...)`，返回一个**区别于区间套证书的确认凭据** `XzdCertificate`（或 `NestCertificate` 的一个 `kind: Xzd` 变体）。语义分离是硬要求——小转大凭据**不携带区间套 depth**，因为它本级无背驰段可套（不可把 depth 字段挪用，见 no-patch-mentality）。

### 2.2 判据主链（按原文权威递减排序）

小转大信号 S（本级 lvl、方向 δ、精确点 source_index、`descend=None`）的确认凭据成立，当且仅当以下**第二类买卖点结构**成立：

| # | 判据 | 原文依据 | 可编码性 | 复用 |
|---|------|---------|---------|------|
| C1 | S 是 Type2/3 且本级 `descend_type1_anchor_depth==None`（=小转大域） | `053:28`/`043:198` | ✅ 完全 | 已有（L2 报告的 None 域） |
| C2 | 本级出现**第二类买卖点**：高点后「一次级别向下 + 一次级别向上，不创新高（或盘整背驰）」；买点反向 | `chan99/0025:63`、`053:28` | ✅ 完全 | 复用 2 类 bsp 定义 |
| C3 | S 所在本级走势的**最后一个次级别中枢出现三类买卖点**（必要条件） | 思维导图 `128`、`044:52`·点2 | ✅ 结构可判 | 复用 3 类 bsp + 次级中枢 |
| C4 | 本级/次级中枢**反向突破** OR 回抽/反抽位置到达**第二个次级别中枢**（GGDD 同分3买卖高低点） | `044:52`·点1、点4 | ⚠️ 部分（GGDD 位置需中枢序列） | 复用中枢序列 |

**主判据 = C1 ∧ C2**（二类买卖点是原文钦定的最佳确认，`053:28`）。C3 是思维导图给的**必要条件**（可作为 C2 的前置过滤，降低误报）。C4 是娇注的加强项，作为凭据的**置信度标注**而非硬门（GGDD 位置判定依赖完整中枢序列，边界见 §3）。

### 2.3 凭据结构（最小设计）

```
XzdCertificate {
    source_index: usize,        // 本级信号精确点
    level: usize,               // 本级
    side: Side,                 // δ 方向
    type2_confirmed: bool,      // C2：本级二类买卖点成立
    sub_last_zs_type3: bool,    // C3：最后次级中枢出现三类买卖点（必要条件）
    reverse_break_or_gg: u8,    // C4 置信标注：0=无 / 1=中枢反向突破 / 2=到第二中枢GGDD
}
```
门通行判据：`type2_confirmed && sub_last_zs_type3`（C2∧C3）。`reverse_break_or_gg` 仅作分级/统计，不参与硬门（诚实：C4 的 GGDD 分支不可完全编码，不能冒充硬门）。

### 2.4 与区间套通道的关系（架构分离）

| 维度 | 区间套通道（现有） | 小转大通道（本设计） |
|------|-------------------|---------------------|
| 对象 | 本级有背驰段的 Type1/可下沉 Type2/3 | 本级无背驰锚的 Type2/3（`descend=None`） |
| 定位方式 | 精确定位（逐级下沉锁范围） | 等待确认（次级别结构 + 二类点） |
| 判据性质 | 力度（MACD 背驰递归） | 结构（中枢/三买卖/二类点） |
| 凭据 | `NestCertificate`（带 depth） | `XzdCertificate`（**无 depth**） |
| 认识论 | 大→小终结 | 小→大生长确认 |

两通道**并列互补、输入域不相交**（`descend=Some` 走区间套，`descend=None` 走小转大），这正是 `053:28`「第一类最佳，小转大时二类最佳」的架构映射。

## 3. 诚实的语义边界（不可编码 / 待裁项，照实标注）

原文明确、但**当下无法精确编码**的部分，照 `no-patch-mentality` 与 llm-role-boundary 照实呈现，不做模糊化：

1. **「没有标准的一类买卖点」是定义性质，不是缺陷**（知识库 L410 / `053:28`）。小转大通道**本质上不能给出精确入场点**，只能给「确认成立/不成立」。任何试图给它安一个「精确 depth」的做法都是把区间套语义硬套（违反 §2.1 分离要求）。

2. **「小平台可以往下突破」= 信号可失败**（`066:198`）。小转大确认是**事后确认**，存在「平台向下突破 → 信号作废」的合法失败路径。通道必须允许「确认失败」这个终态，不能强行给每条 `descend=None` 信号派一个通行凭据。

3. **C4 的 GGDD/「第二个中枢」位置判定依赖完整中枢序列与「动态最后次级中枢」**（`044:56`：最后次级中枢是动态的，不一定为背驰点前中枢）。这一动态性使 C4 在**当下（信号首成形时）**可能尚未定形——与 L2 报告 §3.3「首次出现即计 vs 最终塔回看」的口径分歧同源。**待裁**：C4 用「首次成形塔」判还是「最终塔」判，涉及零前视约束，需上浮或经 codex 审。

4. **6124 案例（`069:38`）**：缠师本人当年把小转大误判为常规转折——**说明小转大 vs 常规转折在事前（ex-ante）本身就有不可消除的模糊性**。这不是判据不够精，是对象本身的性质。通道输出应带「小转大候选」而非「小转大确定」的措辞，避免声明膨胀（090号）。

5. **线段级小转大的背驰判据退化**（`066:198`：「线段上的只能是类背驰……不能光靠 MACD，时间太短不够灵敏度」）。若本级是线段级（level 低），C2 的「盘整背驰」子判据灵敏度不足，应优先走「不创新高/新低」的几何子判据而非 MACD 子判据。**这是 level 相关的判据切换**，阶段2实装需按 level 分叉。

## 4. 结果包六要素

1. **结论**：小转大通道 = 独立于区间套的「二类买卖点 + 次级别结构」确认通道；主判据 C1∧C2∧C3（§2.2），凭据 `XzdCertificate` 无 depth（§2.3）；输入域 = 1353 条 `descend=None` 信号。
2. **定义依据**：`053:28`（二类点补充小转大）、`chan99/0025:21/63`（二类点定律一 + 结构）、思维导图`128`（最后次级中枢三类点必要条件）、`044:52`（实盘四点）、`029:16`（背驰-转折定理三分类）。代码域对齐 `econ_positive.rs:524/553/570`。
3. **边界条件（结论何时翻转）**：若阶段2实测 C1∧C2∧C3 通过率极低（如 <1%），说明「二类点确认」在 BTC 1m 上过严，需回到 C4 或 66课「小平台确认」的更宽判据；若通过域与区间套 120 条重叠，则通道分离假设（输入域不相交）被证伪，需重审 §2.4。
4. **下游推论**：区间套证书门（acc-optB）之外新增小转大门，Type2/3 的总可交易域 = 120（区间套）+ C1∧C2∧C3 命中数（小转大），二者不相交并集；`build_nest_certificate` 的 `None` 分支需改为分派而非丢弃（`:1134` 处的「None⟹门拒」逻辑要拆）。
5. **谱系引用**：606号（区间套有效域=Type1）、673号（Cand^δ 范围误用，同 nest 区，实装等 673split 落地）、知识库 L410（小转大补充定位）；本设计新增「小转大通道」概念，阶段2实装时应由 genealogist 起谱系条目。
6. **影响声明**：本文件仅为设计稿，**零代码改动、零 git 操作**。阶段2实装将改动 `econ_positive.rs`（`build_nest_certificate` None 分支 + 新增 `xiaozhuanda_confirm`/`XzdCertificate`），影响 acc-optB 门吞吐与 W-VERIFY（task #13）重测口径。实装排程：等 673split 落地（同 nest 区，避免冲突）。
