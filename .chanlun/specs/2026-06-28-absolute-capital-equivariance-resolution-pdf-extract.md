### §1 不相容定理（P1 起，续 P2）

逐字推导链：

> 设级别平移算子为

    S_k.

> 假设它对头寸空间的作用不是平凡的，而是会缩放头寸规模：

    p ↦ S_k p.

> 设存在一个头寸规模函数

    N(p) ≥ 0

> 满足齐次性（方框）：

    N(S_k p) = a_k N(p),     a_k ≠ 1.

> 例如把一个低级别结构上移为高级别结构后，目标头寸规模、风险单位或名义资金需求随之放大。

> 如果资本可行集含有固定绝对上限 `B`（方框）：

    𝒦_B(x) = {p : N(p) ≤ B},

> 而 `B` 在 `S_k` 下不变：

    S_k B = B,

> 则要求可行集等变（方框）：

    𝒦_B(S_k x) = S_k 𝒦_B(x)

> 一般不可能。

> 证明很短。取任意 `p` 满足

    N(p) = B.

> 则（续 P2）

    p ∈ 𝒦_B(x).

### §1 不相容定理（证明完成）

逐字：

> 如果等变成立，则应有

    S_k p ∈ 𝒦_B(S_k x).

    a_k B > B,

> 若 `0 < a_k < 1`，反向用 `S_{-k}` 得到同样矛盾。除非：

    a_k = 1,

> 或者

    B = +∞,

> 或者策略永远只允许零头寸。

> 所以你的判断成立（方框）：

    固定绝对资本引入了特权尺度，破坏严格自相似。

> **结果包（§1 不相容定理）★核心定理**
> - **结论**：设级别平移 `S_k` 非平凡地缩放头寸（头寸规模函数 `N` 满足齐次 `N(S_k p)=a_k N(p)`，`a_k≠1`），固定绝对资本可行集 `𝒦_B(x)={p:N(p)≤B}` 且 `S_k B=B`，则可行集等变 `𝒦_B(S_k x)=S_k 𝒦_B(x)` 一般不可能。**证明（witness 构造）**：取 `p` 使 `N(p)=B` ⟹ `p∈𝒦_B(x)`；若等变则 `S_k p∈𝒦_B(S_k x)`；但 `N(S_k p)=a_k B`，`a_k>1` ⟹ `a_k B>B` ⟹ `S_k p∉𝒦_B(S_k x)`，矛盾；`0<a_k<1` 反向用 `S_{-k}` 同样矛盾。**例外仅三**：`a_k=1`（平凡尺度）∨ `B=+∞`（无上限）∨ 策略永远只允许零头寸。结论：固定绝对资本引入特权尺度，破坏严格自相似。

## P4（页 4/12）—— §3 严格等变定理（完成）

逐字：

> 而约束边界也协变（方框）：

    b_j(S_k Θ) = a_k^{d_j} b_j(Θ).

> 那么（方框）：

    𝒦_{S_kΘ}(S_k x) = S_k 𝒦_Θ(x).

> 证明如下。若

    p ∈ 𝒦_Θ(x),

> 则

    Ψ_j(x,p) ≤ b_j(Θ).

> 对 `S_k p` 有

    Ψ_j(S_k x, S_k p) = a_k^{d_j} Ψ_j(x,p) ≤ a_k^{d_j} b_j(Θ) = b_j(S_k Θ).

> 所以

    S_k p ∈ 𝒦_{S_kΘ}(S_k x).

> 反向用 `S_{-k}` 即得集合相等：

    𝒦_{S_kΘ}(S_k x) = S_k 𝒦_Θ(x).

> 若目标头寸等变：

    p̃(S_k x) = S_k p̃(x),

> 且目标函数满足（方框）：

    J_{S_k x}(S_k p, S_k p̃) = J_x(p, p̃),

> 则唯一投影也等变（方框）：

    p*(S_k x) = S_k p*(x).

> 因此订单等变（方框）：

    π_{S_kΘ}(S_k x) = S_k π_Θ(x).

> 如果进一步把 `Θ` 本身定义成无量纲参数包，使得

    S_k Θ = Θ,

> 则得到你想要的强形式（方框）：

    π_Θ(S_k x) = S_k π_Θ(x).

> 这就是严格修复版。

> **结果包（§3 协变资本版严格等变定理）★核心定理**
> - **结论**：协变可行集 `𝒦_Θ(x)={p:Ψ_j(x,p)≤b_j, j=1..n}`，若每约束齐次等变 `Ψ_j(S_k x,S_k p)=a_k^{d_j}Ψ_j(x,p)` 且边界协变 `b_j(S_k Θ)=a_k^{d_j}b_j(Θ)`，则可行集等变 `𝒦_{S_kΘ}(S_k x)=S_k 𝒦_Θ(x)`。**证明**：`p∈𝒦_Θ(x)` ⟹ `Ψ_j(x,p)≤b_j(Θ)` ⟹ `Ψ_j(S_k x,S_k p)=a_k^{d_j}Ψ_j(x,p)≤a_k^{d_j}b_j(Θ)=b_j(S_k Θ)` ⟹ `S_k p∈𝒦_{S_kΘ}(S_k x)`；反向 `S_{-k}` 得集合相等。**再加**目标头寸等变 `p̃(S_k x)=S_k p̃(x)` + 目标函数等变 `J_{S_k x}(S_k p,S_k p̃)=J_x(p,p̃)` ⟹ 唯一投影等变 `p*(S_k x)=S_k p*(x)` ⟹ 订单等变 `π_{S_kΘ}(S_k x)=S_k π_Θ(x)`。**最后**把 `Θ` 定义为无量纲参数包使 `S_k Θ=Θ` ⟹ 强形式 `π_Θ(S_k x)=S_k π_Θ(x)`。这是严格修复版。

- **纯 core 下游约束照旧**：`S_k` 为 ℤ 加法作用（`Int`）；约束族用 `List` 逐条合取 + `decide`；**禁 `Fintype`**（头寸/约束不需有限枚举，约束是实值/比值谓词）。`a_k^{d_j}` 用标量幂，等变证明用 `linarith`/`nlinarith`/单调性。`LotCost` 离散取整是潜在残余尺度破缺点（`[需人工确认]` 是否需 `decide` 处理离散颗粒，§5 边界条件已标注）。

### 四、与 codex「C+A」裁决的关系

- **codex 立场**：按**实盘现实**排序 `C+A > B`——实盘是有限账户（绝对资本真实存在），既需 C 的「全定义、完全互斥、风控真实闭合」（binding regime 保证任何账户状态下都有唯一合法订单），又需 A 的「级别协变」（多级别策略尺度一致）。codex 视绝对资本为实盘不可消除的事实，故在 C 的全定义闭合骨架上叠加 A 的协变单位。
- **本 PDF 立场**：按**20 页核心严格性**钦定**纯 A**——目标固定为「去根化、无特权尺度、全域自相似递归」，绝对资本是必须消除的特权尺度（§1 定理：绝对资本 = 特权尺度 = 破坏自相似），故全资本无量纲化 `S_k Θ=Θ`，全域强形式自相似。
- **裁决：权威源胜出（纯 A）**。理由：
  1. **本 PDF 是编排者提供的权威裁决源**，明确以「20 页版核心严格性」为目标函数；codex 是异质审查工位，以实盘现实为目标函数——**两者目标函数不同，非同层冲突**。20 页 spec 的顶层目标已锁定为全域自相似（§18/§19/§20 五条件之二、三），故采用与该目标一致的源。
  2. **合 `no-patch-mentality` / 161 号**：codex 的「C+A」含「保留绝对资本 + binding 分类」成分（C），本质是「实盘够用就行」的务实路线——把「绝对资本破坏自相似」的矛盾留在 binding regime 里分域处理。161 号「务实 = 妥协 = 把矛盾和缺口留到后面」被禁。纯 A 是唯一**不留矛盾**的方案（资本协变后矛盾在定义层消失，非分域回避）。
  3. **C 的 binding regime 并非废弃**：在纯 A 下，资本约束**仍然存在**（协变形式的 `𝒦_Θ`），binding 仍可发生——但 binding 不再破坏自相似（协变边界 `b_j(S_k Θ)=a_k^{d_j}b_j(Θ)` 随尺度同步，binding 状态本身平移等变）。即 **A 吸收了 C 的风控闭合需求而不付出自相似代价**——这正是 A 优于 C+A 的严格性根据。
- **协调结论**：实盘工程层若需 binding regime 的细分（codex 的 C 成分），应在**方案 A 的协变框架内**实现（binding 模式作为协变分类轴），而非保留绝对资本。这样 codex 的实盘关切（风控闭合、有限账户）与本 PDF 的严格性要求（全域自相似）**在 A 内统一**，无需 B/C 的绝对资本。
