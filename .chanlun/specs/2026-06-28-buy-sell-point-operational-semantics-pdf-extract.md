## §C. 完备性论证（PDF 如何论证「完全互斥分类」无遗漏无重叠）

本 PDF 的「**完全互斥分类**」分**两个互斥分类**（区别于互斥分类 spec 单一角色互斥 + 完全分类 spec 单一覆盖归属）：

**1. 买卖点状态分类（非互斥层，穷尽）**（P02）：每级 `b_ℓ(x)∈{0,1}^6` 的 64 种向量穷尽——`Σ_{u∈{0,1}^6} 1[b_ℓ(x)=u]=1`。**这一层不互斥**（买卖点可重合），但**穷尽**（64 态覆盖所有重合情况）。这是本 PDF 处理「买卖点本身可重合」的关键：把非互斥的买卖点编码为穷尽的状态向量。

**2. 操作角色互斥分类（互斥穷尽层）**（P10）：每信号事件 g 的 `Role_x(g)` 唯一为 5 类之一——`Σ_{R∈{RootDir,SameFollow,SameReverse,SubFollow,ShortDiff}} 1[Role_x(g)=R]=1`。三层支撑：
   - **级别关系侧三分**（P07）：`Rel∈{Root,Same,Sub}` 互斥穷尽。
   - **方向关系侧二分**（P08）：Same 内 δ=σ_α/δ=−σ_α 二分（→SameFollow/SameReverse）；Sub 内 δ=σ_α/δ=−σ_α 二分（→SubFollow/ShortDiff）。
   - **角色指示函数和=1**（P10）：5 角色互斥穷尽。

**3. 动作分类互斥化（动作层）**（P16）：10 动作谓词 P_1..P_10 经优先级前缀否定 `A_i=P_i∧⋀_{j<i}¬P_j` 互斥化——`Σ_{i=0}^m 1[A_i(x)]=1`。处理同时刻多动作冲突。

**4. 整体分类函数不相交分解**（P21）：`C_Θ(x)` 作为函数⟹`X_Θ=⊔_{c∈im C_Θ} C_Θ^{−1}(c)` 不相交并——函数单值性直接给出整体状态空间的完全互斥分类。

**本 PDF 的「完全互斥分类」三段式 = 买卖点穷尽（64 态，非互斥）→ 角色互斥穷尽（5 类，Σ指示=1）→ 动作互斥化（优先级原子，Σ指示=1）→ 整体函数不相交分解**。**核心方法论**（P25）：互斥不发生在买卖点层（买卖点可重合），互斥发生在「级别关系+父方向→角色」层与「优先级→动作」层。

**「互斥全定义策略」的完备性**（P20 定理）：策略对每个合法状态 x **唯一给出动作** O_{t+1}（∃!）——9 前提覆盖从买卖点谓词到订单的完整链条。

**有效域诚实标注（231号）**：本 PDF 自划有效域 < 定义域——
- 定义域：所有状态 x。
- 有效域：仅**覆盖可行域 X^cover_Θ**（P23），仅**内在分账本操作语义**（P11/P23：多空腿独立坐标非净额；G^sep>0 是腿级毛收益非净资产收益），仅**操作语义可判定可执行的元素边界**。

## §E. 与互斥形式化 / 缠论已结算定义的冲突分析（no-workaround）

**逐项核对本 PDF 与 ① 互斥分类形式化（commit a9d8000f40 / spec M01–M30）② 缠论已结算 maimai.md 买卖点定义 是否有定义冲突。**

### E.1 角色 4 分 vs 5 分（互斥分类 M09 4 角色 vs 本 PDF P08 5 角色）——**非冲突，是细化**

- **互斥分类 M09**：`Role∈{RootDir,SameDir,SubFollow,ShortDiff}`（4 角色），同级别同向与反向**合为 SameDir 一角色**，M25 命题层证「同级别反向≠短差」。
- **本 PDF P08**：`Role∈{RootDir,SameFollow,SameReverse,SubFollow,ShortDiff}`（5 角色），把 SameDir **拆为 SameFollow(δ=σ_α)+SameReverse(δ=−σ_α)**。
- **判定：非定义冲突，是分类粒度细化（refinement）**。理由：(a) 两者在 `{RootDir,SubFollow,ShortDiff}` 三角色上**完全一致**；(b) M09 的 SameDir = 本 PDF 的 `SameFollow ⊔ SameReverse`（M09 的 SameDir 不区分同级别同向/反向，本 PDF 区分）——这是**同一划分的更细分割**，不是矛盾分割；(c) M25（互斥分类）已在命题层承认「同级别反向」与「同级别同向」语义不同（M07 原文「同向=延续/反向=关闭/反手」），本 PDF 只是把这个**已承认的语义差异提升为独立角色**；(d) 操作语义一致：M07 的 SameDir 操作语义（同向延续 / 反向关闭切换）= 本 PDF SameFollow（§7.2 同向继续）+ SameReverse（§7.3 关闭原声部再建新方向）逐字对应。
- **下游处理**：实装时统一用本 PDF 的 **5 角色**（更细，可向下兼容 M09 4 角色：SameDir = SameFollow ∪ SameReverse）。Lean `OperationRole.lean`(MW3) 与 rust `coverage.rs::operation_role` 须从 4 角色扩为 5 角色（GAP-6）——这是**精化非重写**（M09 的互斥穷尽证明 M12/MW4 在 Same 侧加一个二分即得 5 角色版 P10，骨架复用）。

### E.2 买卖点谓词层 vs 互斥分类元素五元组——**非冲突，是入口补全**

- **互斥分类 M04**：元素五元组 `e=(I_e,ℓ_e,ε_e,α_e,ρ_e)`，把 `ε_e`（元素方向）当**原始输入**，不论证方向来源。
- **本 PDF P01**：买卖点谓词 `B_{i,ℓ}/S_{i,ℓ}` ⟹ 信号事件 `g=(v,ℓ,δ,i)`，`δ_g`（信号方向）由买卖点判定。
- **判定：非冲突，是入口补全**。本 PDF 的 `δ_g`（信号方向）= 互斥分类的 `ε_e`（元素方向）的**来源**——买点⟹δ=+1、卖点⟹δ=−1。互斥分类预设方向已知，本 PDF 论证方向来自买卖点判定。两者是**同一方向量的「来源（操作语义）」与「使用（内在语法）」两端**，无矛盾。

### E.3 第三类买卖点 `>ZG`/`<ZD`（严格）vs maimai.md/reference 含等号——**本 PDF 不引入新冲突（既有冲突仍待裁决）**

- **既有已知冲突**（记忆 `theta-v0-type3-boundary-reference-lean-conflict`）：theta_v0 第三类临界 `retest==zg`：reference §36 含等号（`>=`）+ rust `>=` 一致，但 Lean `IsType3Buy` 严格 `<`（相反）——属定义冲突非 rust bug。
- **本 PDF 对此的态度**：P01 只声明买卖点谓词「**全定义、单值、可判定、因果**」，**不规定第三类的 ZG/ZD 边界用 > 还是 >=**——本 PDF 把「第三类判据的精确边界」留给买卖点谓词的**实装**（B_{3,ℓ} 的具体定义），自身不取定 >/>= 。
- **判定：本 PDF 不引入新的 type3 边界冲突**，但**也不解决既有冲突**——既有 reference/rust(`>=`) vs Lean(`<`) 的 type3 临界冲突仍是待裁决项（不属本工位 escalate 范围，已在记忆中标记）。本 PDF 的要求是「B_{3,ℓ} 必须全定义因果」，无论取 > 还是 >= 都能满足（只要一致），故**与本 PDF 无冲突**。

### E.4 买卖点完备性（maimai.md 三类穷尽）vs 本 PDF 6 谓词 + 64 态——**一致，本 PDF 是 maimai.md 的形式化扩展**
