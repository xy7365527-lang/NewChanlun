## §C. 完备性论证（PDF 如何论证「完全互斥分类」无遗漏无重叠）

互斥分类的「**完全互斥分类**」= **每个缠论元素的操作角色的完全互斥分类**（不同于完全分类 spec 的「每元素覆盖归属的完全分类」）。三层完备性论证：

1. **级别关系侧三分完备**（M05/M06/M07/M08）：每元素的 ρ_e 唯一判定为 Root / Same / Sub 之一——**穷尽**（操作语义必须唯一判定，无第四种级别关系）+ **互斥**（Root/Same/Sub 两两不相交）。
2. **方向关系侧二分完备**（M08）：若 ρ_e=Sub，方向关系必为 ε_e=σ_{α_e}（顺势）或 ε_e=−σ_{α_e}（短差）之一——**互斥穷尽二分**（方向只能同/反）。
3. **角色指示函数和=1**（M12）：`Σ_{R∈{RootDir,SameDir,SubFollow,ShortDiff}} 1[Role(e)=R]=1`——四类角色**互斥**（每元素恰一个 R 使指示函数=1）且**穷尽**（和=1 即至少一个、恰一个）。

**互斥分类的「完全/完备」= 级别三分穷尽 × 方向二分穷尽 → 四类角色互斥穷尽（Σ指示=1）**。这是标准「分类完全」三要素（穷尽 + 互斥 + 唯一归属）在**操作角色维度**的实现。

**关键的两个角色不混同证明**（互斥性的具体支撑，防止四类塌缩）：
- §17 / M25：**同级别反向 ≠ 短差**（Same 与 Sub 不可混淆，因短差严格要求 ℓ_e<ℓ_{α_e}）——保证 SameDir 与 ShortDiff 互斥。
- §16 / M27：**短差 ≠ 普通做空**（短差是相对父级反向 Side(e)=−σ_{α_e}，非绝对等同做空）——保证 ShortDiff 的绝对方向由角色（相对父级）决定，与 RootDir 的绝对方向（独立）区分。

**「互斥全定义策略」的完备性**（M20 定理1）：策略对每个合法状态 x_t **唯一给出动作** O_{t+1}（∃!）——这是前言第二个证明目标。互斥（角色分类）+ 全定义（策略唯一）共同构成 goal「严格完全互斥分类 + 互斥全定义策略」。

**有效域诚实标注（231号）**：互斥分类自划有效域 < 定义域——
- 定义域：所有缠论元素 / 所有状态。
- 有效域：仅**覆盖可行域 X^cover_Θ**（M21），仅**操作语义可判定可执行的元素边界**（M23 前提），仅**分账本腿级/声部级**（非净资产级，M30/M24 声明）。
- 风险阻断状态下策略仍全定义但**优先风控不承诺吃每笔**（M21 原文）——这是互斥分类自带的「有效域≠定义域」声明，与 222/223/230号谱系同构，与完全分类 C15/C22/C23/C24/C40 的有效域声明**完全一致**。
