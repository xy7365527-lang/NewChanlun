状态：理论实验（待检验）
谱系依据：ontology-v2-push.md 六3, 六6.2; config_space.py

## 1. 问题定义

### 1.1 K4 完全图的六条边和四个顶点

K4 完全图有四个顶点（`graph.py:Vertex`）：

- **E**（动产/Equity）：股票、基金
- **C**（商品/Commodity）：大宗商品、黄金
- **R**（不动产/Real estate）：房地产
- **$**（现金/Cash）：主权信用/流动性复合体

六条边分为两类（`graph.py:EdgeType`）：

| 类型 | 边 | 代码引用 |
|------|-----|----------|
| 独立边（INDEPENDENT） | E/$, C/$, R/$ | `graph.py:71-75` |
| 派生边（DERIVED） | E/C, E/R, C/R | `graph.py:78-83` |

### 1.2 为什么选 E/$, C/$, R/$ 作为三条独立边

K4 有 4 个顶点、6 条边。圈秩 = 6 - 4 + 1 = 3，独立边数 = 6 - 3 = 3（`ontology-v2-push.md` 六6.2）。

选取连接 $ 顶点的三条边作为独立边，理由是代数的：

任意派生边可由独立边表达：
```
E/C = (E/$) / (C/$)
E/R = (E/$) / (R/$)
C/R = (C/$) / (R/$)
```

即 log 空间中：`ln(E/C) = ln(E/$) - ln(C/$)`。

$ 是共同分母——这个选择使得三条独立边共享同一个度量基准。这正是独立性问题的来源。

### 1.3 独立性假设

`config_space.py` 的 `Configuration` 类（第 33-49 行）将配置定义为三元组 `(sigma_e, sigma_c, sigma_r)`，每个分量独立取值于 `{UP, FLAT, DOWN}`。27 种配置的枚举（`ConfigurationSpace.__init__`，第 156-166 行）隐含了一个前提：

**三条独立边的走势方向互相不影响。**

即 `sigma_e`、`sigma_c`、`sigma_r` 是三个独立的自由度。配置空间是 `{+1, 0, -1}^3` 的直积——直积结构预设了因子之间的独立性。

**问题**：这个前提在什么条件下成立？当 $ 的走势同时影响三条边时，三个分量通过 $ 发生耦合，直积结构退化。

## 2. 独立性的形式化条件

### 2.1 独立性的严格定义

设 `sigma_e(t)`, `sigma_c(t)`, `sigma_r(t)` 分别为三条独立边在时刻 t 的走势方向（`config_space.py:WalkDirection`）。

**概率独立性**（最强条件）：

```
P(sigma_i = a | sigma_j = b) = P(sigma_i = a)   对所有 i != j, 对所有 a, b in {+, 0, -}
```

等价地，联合分布分解为边际分布的乘积：

```
P(sigma_e = a, sigma_c = b, sigma_r = c) = P(sigma_e = a) * P(sigma_c = b) * P(sigma_r = c)
```

如果独立性成立，27 种配置的概率由 3+3+3 = 9 个参数决定（减去归一化后为 6 个）。
如果独立性不成立，需要 27-1 = 26 个参数。

### 2.2 $ 介导的耦合机制

三条独立边共享 $ 顶点。设资产 X 的绝对收益率为 r_X，现金的绝对收益率为 r_$（可理解为无风险利率的变化率加上货币购买力变化率）。则：

```
r(E/$) = r_E - r_$
r(C/$) = r_C - r_$
r(R/$) = r_R - r_$
```

即使 r_E, r_C, r_R 互相独立，三条边的收益率也通过 r_$ 发生耦合：

```
Cov(r(E/$), r(C/$)) = Cov(r_E - r_$, r_C - r_$)
                    = Cov(r_E, r_C) - Cov(r_E, r_$) - Cov(r_C, r_$) + Var(r_$)
```

**关键项**：即使 `Cov(r_E, r_C) = 0`（动产和商品本身独立），共同分母 $ 仍贡献 `Var(r_$)` 的正相关。

### 2.3 因子模型分解

引入 $ 因子的显式建模。设：

```
r(E/$) = alpha_E + beta_E * f_$ + epsilon_E
r(C/$) = alpha_C + beta_C * f_$ + epsilon_C
r(R/$) = alpha_R + beta_R * f_$ + epsilon_R
```

其中：
- `f_$` = $ 的共同因子（美元强弱、全球流动性等）
- `beta_X` = 资产 X 对 $ 因子的敏感度
- `epsilon_X` = 资产 X 的特质性收益（互相独立，与 f_$ 独立）

则：

```
Cov(r(E/$), r(C/$)) = beta_E * beta_C * Var(f_$) + Cov(epsilon_E, epsilon_C)
```

若特质性收益独立（`Cov(epsilon_E, epsilon_C) = 0`），则边间相关性完全由 $ 因子介导：

```
Corr(r(E/$), r(C/$)) = (beta_E * beta_C * Var(f_$)) / (sigma(E/$) * sigma(C/$))
```

### 2.4 独立性成立的充分条件

**条件 I1（$ 因子可忽略）**：
```
beta_E * beta_C * Var(f_$) << Var(epsilon_E), Var(epsilon_C)
```
即 $ 的共同因子对各边收益率的贡献远小于各边的特质性波动。

**等价表述**：各边的 R-squared（对 $ 因子回归的决定系数）足够低：
```
R^2_E = beta_E^2 * Var(f_$) / Var(r(E/$)) << 1
R^2_C = beta_C^2 * Var(f_$) / Var(r(C/$)) << 1
```

**条件 I2（$ 因子方向中性）**：
```
beta_E * beta_C approx 0
```
即至少有一条边对 $ 因子不敏感。这比 I1 弱但仍有意义——如果商品对美元不敏感（beta_C approx 0），则即使美元剧烈波动，E/$ 和 C/$ 的相关性也很低。

**条件 I3（$ 因子已被走势结构吸收）**：
这是缠论特有的条件。走势方向 sigma 不是瞬时收益率，而是走势完成后的结构性判定（`ontology-v2-push.md` 三3.2-3.3）。$ 因子的短期波动不影响走势方向的判定——只有当 $ 因子的变化量大到足以改变走势类型时，才会影响 sigma。

形式化：设边 e 的走势从 tau_i 转为 tau_{i+1}，需要在支配级别上完成一个完整的走势周期。$ 因子的影响必须在该级别上产生可观测的结构变化（形成分型、构造笔），才能改变 sigma。

**推论**：支配级别越高，$ 因子需要越大的变化量才能影响走势方向。高支配级别下的独立性比低支配级别下更容易成立。

### 2.5 独立性失效的充分条件

**条件 D1（全局流动性事件）**：
```
|f_$| >> max(|epsilon_E|, |epsilon_C|, |epsilon_R|)
```
即 $ 因子的变化主导了所有边的收益率。

典型场景：美联储紧急加息、全球流动性危机、美元急剧升值/贬值。
此时所有 beta_X * f_$ 项同号，三条边同向运动——独立性完全失效。

**在 ConfigurationSpace 中的体现**：配置被限制在极性指数 |S| 接近 3 或接近 -3 的角节点附近，27 种配置中的大部分不可达。

**条件 D2（风险情绪主导）**：
```
Corr(r_E, r_C) >> 0 且 Corr(r_E, r_R) >> 0
```
即资产本身的收益率（去掉 $ 因子后）也高度相关。

典型场景：risk-on/risk-off 轮动——所有风险资产同涨同跌，与 $ 反向。
此时不仅 $ 因子介导耦合，资产端本身也耦合。

## 3. 独立性检验方案

### 3.1 标的选取

理论实验需要具体标的来实例化 K4 的四个顶点。标的选取本身就是 K4 拓扑的实例化判断——不同的标的选取对应不同的 K4 实例，独立性条件可能不同。

**方案 A（美国经济体的 K4）**：

| 顶点 | 标的 | 理由 |
|------|------|------|
| E | SPY（S&P 500 ETF）| 美国动产市场的总量代理 |
| C | GLD（黄金 ETF）或 DBC（商品 ETF）| 商品角代理；黄金与大宗商品代表不同的 C 子结构 |
| R | VNQ（房地产 REIT ETF）| 美国不动产市场代理 |
| $ | 以美元计价 = 隐含美元为 $ | 三条独立边 = SPY, GLD, VNQ 的美元价格序列 |

注意：SPY 的美元价格就是 E/$ 的比价序列。当 $ = 美元时，以美元计价的资产价格本身就是比价线。

**方案 B（跨国的 K4：中国经济体）**：

| 顶点 | 标的 | 理由 |
|------|------|------|
| E | 沪深300指数 | 中国动产市场总量代理 |
| C | AU9999（黄金）或南华商品指数 | 中国商品角代理 |
| R | 中国房价指数（若可获取）或相关 REIT | 不动产代理 |
| $ | 人民币 | 三条独立边以人民币计价 |

**标的选取中的 K4 拓扑判断**：

选 GLD 还是 DBC 作为 C 的代理？这不是任意选择——黄金在 `ontology-v2-push.md` 七7.3 中属于结算锚定物子图的成员，它同时是商品和货币（黄金是 C 和 $ 的交集）。DBC 是纯商品。选择哪个取决于分析目标：如果关注 C 对 $ 的独立性，DBC 更合适（它不携带货币属性）；如果关注锚定物子图的结构，GLD 更合适。

### 3.2 检验方法

#### 方法 1：偏相关系数

计算去除 $ 因子后的边间相关：

```
rho(E/$, C/$) | f_$ = Corr(epsilon_E, epsilon_C)
```

其中 f_$ 的代理可用 DXY（美元指数）。

- 先对 DXY 回归各边收益率，取残差
- 计算残差之间的相关系数
- 如果残差相关仍显著 -> 独立性不成立（存在 $ 之外的耦合）
- 如果残差相关接近 0 但原始相关显著 -> $ 介导的耦合（条件 I1 的检验对象）

#### 方法 2：条件独立性检验

直接检验走势方向层面的独立性：

```
H0: P(sigma_E = a | sigma_C = b) = P(sigma_E = a)  对所有 a, b
```

使用卡方检验或 Fisher 精确检验（样本量小时）。

数据构造：
1. 对三条独立边分别运行缠论管线，获取各边的走势完成事件序列
2. 在每个时间窗口内记录 `(sigma_e, sigma_c, sigma_r)` 的配置
3. 统计联合分布与边际分布乘积的偏离程度

#### 方法 3：Granger 因果检验

检验一条边的走势方向变化是否能预测另一条边的走势方向变化：

```
sigma_E(t) = f(sigma_E(t-1), ..., sigma_E(t-p), sigma_C(t-1), ..., sigma_C(t-p)) + noise
```

如果 sigma_C 的滞后项系数显著 -> E/$ 的走势方向受 C/$ 的历史影响（通过 $ 或其他机制耦合）。

#### 方法 4：滚动窗口独立性

独立性是时变的。使用滚动窗口计算偏相关系数：

```
rho_t = Corr(r(E/$), r(C/$))_{[t-w, t]}
```

- w 的选取需要与边层走势的支配级别匹配
- 当 |rho_t| 超过阈值时，标记为"独立性失效期"
- 统计独立性失效期的频率、持续时间、与市场事件的关联

### 3.3 预期结果

**独立性成立的市场状态**（假设，待验证）：

1. **各资产有独立的供需驱动**：E 被企业盈利驱动，C 被供给冲击驱动，R 被人口/政策驱动。$ 因子（利率、流动性）在背景中缓慢变化，不主导任何一条边。
2. **$ 处于盘整态**（sigma_$ = 0）：美元/利率在中枢内震荡，不产生趋势性拉动。
3. **高支配级别**：大级别走势的方向由资产端的长期结构决定，$ 的短期波动被走势构造吸收。

**独立性不成立的市场状态**（假设，待验证）：

1. **全球流动性紧缩/扩张**：美联储快速加息/降息，$ 因子主导所有边。三条边同向运动（加息 -> 所有资产对现金下跌 -> sigma 全为 -）。
2. **Risk-on/Risk-off 切换**：恐慌事件导致所有风险资产同跌，现金为王。配置从分散状态收缩到角节点。
3. **低支配级别**：小级别走势更容易被 $ 的短期波动影响。

## 4. 与缠论的联系

### 4.1 配置空间退化

当独立性不成立时，`ConfigurationSpace` 的 27 种配置不再等概率可达。

设独立性失效时三条边的相关系数为 rho > 0（通过 $ 的正相关），则：

- **高概率配置**：三个分量同号的配置（如 (+,+,+), (-,-,-)），以及部分同号的配置
- **低概率配置**：三个分量异号的配置（如 (+,-,+), (-,+,-)）

极端情况（rho -> 1）：配置空间从 3^3 = 27 种退化为有效维度 1 的空间——只有 `(+,+,+)`, `(0,0,0)`, `(-,-,-)` 及其附近配置有意义。极性指数 S 几乎等于 3*sigma（所有边同向），27 种配置退化为 3 种。

**在代码中的体现**：`ConfigurationSpace` 的结构（`config_space.py:148-166`）不会改变——27 种配置始终存在于拓扑结构中。但配置转换事件序列的统计性质改变了：某些转换路径的出现频率远高于其他路径。

### 4.2 转换拓扑的路径约束

独立性失效对转换拓扑（`transition.py`）的影响：

- **路径偏好**：从角节点 (+,+,+) 到 (-,-,-) 的 90 条最短路径（`transition.py:shortest_path_count`）不再等概率。$ 介导的耦合使得"三条边同步变化"的路径更频繁——即经过 (0,0,0) 中心节点的路径比偏离中心的路径更常见。
- **4-环频率**：两条边交替变化构成的 4-环（`ontology-v2-push.md` 三3.9.1 围长分析）在独立性失效时频率降低——因为一条边变化时另一条边也倾向于同向变化，而非反向交替。
- **引理5（停留时间）的修正**：独立性失效时，配置停留时间不再仅由单条边的走势完成速度决定。多条边同步完成走势（同时性事件，`ontology-v2-push.md` 三3.5 同时性处理）的概率增加，引理1的 k >= 2 情况不再是"概率极低"。

### 4.3 极性指数的分布

独立性成立时：S = sigma_e + sigma_c + sigma_r 的分布接近三个独立离散随机变量的卷积。S 的分布近似对称、在 0 附近集中（中心极限定理的离散版本）。

独立性失效时：S 的分布向边界值 +3 和 -3 偏移。S 的方差增大（因为分量正相关时和的方差大于独立时的方差）。

```
Var(S) = Var(sigma_e) + Var(sigma_c) + Var(sigma_r)
         + 2*Cov(sigma_e, sigma_c) + 2*Cov(sigma_e, sigma_r) + 2*Cov(sigma_c, sigma_r)
```

独立时 Cov 项为 0，Var(S) = sum(Var)。
耦合时 Cov 项为正，Var(S) > sum(Var)。

### 4.4 对交易决策的含义

1. **独立性成立时**：ConfigurationSpace 的 27 种配置都有实际意义，配置层的缠论分析提供高分辨率的全局视角。区间套从配置层下钻到边层到标的层，每一层提供独立信息。

2. **独立性失效时**：ConfigurationSpace 的指导意义下降。配置层的走势方向和边层的走势方向高度冗余——知道一条边的方向就大致知道其他边的方向。此时的正确策略是：
   - 识别独立性失效的状态本身（这是信号，不是噪声）
   - 在独立性失效期间，降低对配置空间分辨率的依赖，回退到单条边的分析
   - 独立性恢复（$ 因子退出主导地位）时，重新启用配置空间分析

## 5. 边界条件

### 5.1 独立性是分段时变的

独立性不是全局常数。它是市场状态的函数，随时间变化。

```
I(t) = 独立性度量（如 1 - max_pairwise_abs_correlation）
```

- I(t) 接近 1：独立性强，ConfigurationSpace 的 27 种配置都有效
- I(t) 接近 0：独立性失效，配置空间退化

需要动态监测 I(t)，而不是静态假设独立或不独立。

### 5.2 级别依赖

独立性的强弱依赖于分析的支配级别（`ontology-v2-push.md` 四4.1）：

- **低支配级别**（日线级别以下）：$ 的短期波动（如日内利率变化、汇率波动）更容易同步影响三条边。独立性较弱。
- **高支配级别**（周线/月线级别以上）：各资产的长期结构性因素（盈利增长、供给周期、人口趋势）主导，$ 因子被走势构造吸收。独立性较强。

**推论**：ConfigurationSpace 在高支配级别上比在低支配级别上更有效。

### 5.3 经济体依赖

不同经济体的 K4 独立性条件不同：

- **美国**：$ = 美元，同时是全球储备货币。$ 因子（美元走势）对全球资产价格有广泛影响，但对美国国内资产的影响可能相对中性（美国资产以美元计价是自然的）。
- **新兴市场**：$ = 本币，而本币相对美元的波动可能很大。$ 因子（本币汇率）可能主导所有以本币计价的资产价格——外资流入时所有资产涨，外资流出时所有资产跌。独立性更容易失效。

### 5.4 本形式化的局限

1. **走势方向的离散性**：独立性检验基于连续收益率的相关分析，但最终目标是走势方向（离散变量 {+, 0, -}）的条件独立。连续层面的弱相关不一定导致离散层面的条件独立性检验通过——需要在走势方向层面直接验证。

2. **因果方向**：偏相关系数和 Granger 检验只能检测统计关联，不能确定因果方向。$ -> (E/$, C/$, R/$) 的因果链是理论假设，不是统计推断。

3. **非线性耦合**：因子模型（2.3节）是线性的。如果 $ 的影响是非线性的（如"$ 温和变化时不影响，$ 剧烈变化时主导一切"的阈值效应），线性偏相关可能低估耦合强度。

4. **回测偏差**：历史数据上的独立性检验结果不能直接外推到未来。市场制度（monetary regime）变化可能改变独立性条件。

## 6. 已验证 vs 待验证

### 已验证（代数/逻辑层面）

- K4 的六条边中只有三条独立（代数约束 A/B * B/C * C/A = 1），见 `ontology-v2-push.md` 六6.2
- 选取连接 $ 的三条边作为独立边的合法性（`graph.py:71-75`）
- $ 作为共同分母引入 Var(r_$) 耦合项（2.2节的代数推导）
- 独立性失效时配置空间退化的逻辑必然性（4.1节）
- 转换拓扑的图论性质不随独立性变化（拓扑结构是代数的，不依赖概率）
