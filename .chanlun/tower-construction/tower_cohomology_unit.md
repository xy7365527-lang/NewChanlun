## 一、构造的出发点：中枢的递归语法（不是参数，是定义）

### 1.1 中枢 = 次级别走势重叠（center.rs 实装的递归定义）

第17/18课中枢递归定义（`rust/src/recursive_t/center.rs:1-16` 逐字实装）：

> 中枢(k) = 被至少三个连续 (k-1) 级走势类型所重叠的部分。核心区间 [ZD, ZG]，
> ZD = max(d₁,d₂,d₃)，ZG = min(g₁,g₂,g₃)，成立条件 ZG > ZD（`center.rs:55-58`）。

关键性质（`center.rs:13-16` 严格性标注，谱系536）：**重叠 = 区间交集 ∩ = 格运算（lattice meet），不是群运算。中枢是 k 级走势重叠涌现的新对象。**

这给我们构造的两个不可协商的事实：
- **中枢是涌现对象**：它由 (k-1) 级走势重叠"生出来"，不是 k 级的内部参数。⇒ 任何在级别 k 上定义的结构（包括仓位单元）必须从中枢的拓扑读出，不能外部赋值。
- **中枢有两套边界**：核心 [ZD, ZG]（前三段交集）+ 外缘 [DD, GG]（全部参与段并集，`center.rs:65-77`）。这两套边界**就是**下面 H⁰/H¹ 的几何载体（不是新引入的量）。

### 1.2 中枢的拓扑模型 = 圆环 S¹（#35 的来源，不是类比）

为什么中枢的拓扑是 S¹？**这是从中枢的动力学语义构造出来的，不是借喻**：

- 走势"在中枢里"= 价格在 [DD, GG] 外缘内来回穿越核心 [ZD, ZG]（`same_direction_step` 返回 None 的盘整延伸态，`center.rs:99-113`）。一次完整的"穿越核心再回来"= 中枢振荡的一个周期。
- 把中枢的相位空间记为：价格相对核心区间的位置 ∈ {下沿 → 穿核心 → 上沿 → 穿核心回 → 下沿}。起点=终点（回到同一相位）⇒ 相位空间是**闭合回路 = S¹**。
- 中枢由"≥3 段重叠"成立（`center.rs:58`），三段构成最小闭环（上-下-上 或 下-上-下），这正是 S¹ 的最小三角剖分（3 个 1-单形）。λ=3（中枢三段）= S¹ 最小胞腔数。

⇒ **中枢 Z_k ≃ S¹**（拓扑等价，由"绕核心振荡不离开"的回路结构定义）。这是 #35"中枢=H⁰ S¹环"的**构造来源**：S¹ 不是贴上去的标签，是中枢振荡回路的拓扑型。

### 1.3 S¹ 的上同调（纯代数事实，给出仓位的两个分量）

圆环 S¹ 的奇异上同调（标准代数拓扑事实，L0）：

```
H⁰(S¹) = ℝ   （0维：连通分量 / 全局常值截面 / 不变量）
H¹(S¹) = ℝ   （1维：绕环一周不可缩的循环 / 障碍类）
H^n(S¹) = 0  （n≥2）
```

**这是构造的枢纽**：中枢 ≃ S¹ ⇒ 在中枢 Z_k 上可定义的仓位上同调**恰好**有两个分量，dim H⁰=dim H¹=1。不是"我们选了两个分量"，是**S¹ 的上同调结构强制只有两个非零分量**。这就是"⊕ 不是任意配比"的根据（§4 详证）。

## 二、H⁰_k 构造：本级核心 = 0维上同调（不变量截面）

### 2.1 从 H⁰ 的代数含义读仓位语义

H⁰(S¹)=ℝ 是 S¹ 上的**全局常值截面**（0-上闭链 = 在整个圆环上取常值的函数，模 0-上边界）。它的语义：**与"绕到环上哪一点"无关的不变量**——无论中枢振荡到哪个相位，这个量不变。

翻译成仓位：**H⁰_k = 在级别 k 的整个中枢振荡周期中保持不变的仓位份额 = 骑 k 级走势的核心仓**。

### 2.2 H⁰_k 的构造性定义（骑什么、何时建、何时不动）

**定义 H⁰_k**：级别 k 上骑中枢 Z_k 所属 k 级走势的常值仓位分量。

由递归语法逐项构造：

### 2.3 为什么"骑本级走势"对应 H⁰（编排者要求的推导，非断言）

完整推导链：

1. H⁰(S¹)=全局常值截面 = 与环上相位无关的不变量（§1.3 代数事实）。
2. 中枢 Z_k ≃ S¹，环的相位 = 次级别 (k-1) 振荡的位置（§1.2 构造）。
3. ⇒ H⁰_k = 与 (k-1) 振荡相位无关的仓位 = **次级别怎么回调都不动的份额**。
4. "次级别怎么回调都不动" = 骑住 k 级走势本身、只在 k 级走势完成时才动 = **核心仓**。
5. ∴ 骑本级 k 走势的核心仓 = H⁰_k。**□**

逆否验证（no-patch 自检）：若核心随次级别回调而动（被次级别卖点 sink 减仓），则它依赖环上相位 ⇒ 不是常值截面 ⇒ 不是 H⁰ ⇒ 它就是 H¹（机动）。实装中 OFF/旧路由把核心当机动减（`rec_engine.rs:170-172` 踏空根因①④"主升浪回调处砍核心=踏空"）= **把 H⁰ 误读为 H¹ = 上同调维度坍缩**（这是 539 失血/纤维拍扁在单格内的精确形式）。O6 门控正是恢复 H⁰≠H¹ 的区分。

## 三、H¹_k 构造：本级机动 = 1维上同调（循环/障碍）

### 3.1 从 H¹ 的代数含义读仓位语义

H¹(S¹)=ℝ 是**绕环一周不可缩的循环类**（1-上闭链模 1-上边界；生成元 = 绕 S¹ 一圈的回路）。它的语义：**一个完整的"出发-绕行-返回"循环**——不是常值，而是一个闭合操作链，绕完回到原点但留下了"绕过一圈"的痕迹（积分 ∮ ≠ 0）。

翻译成仓位：**H¹_k = 在级别 k 的一个中枢振荡周期内"开-绕-平"的循环仓位 = 在 (k-1) 区间套上做次级别操作的机动仓**。

## 四、⊕ 直和：H⁰_k ⊕ H¹_k = 级别 k 的完整仓位（配比由结构内在决定）

### 4.1 直和的代数根据（不是任意比例）

中枢 Z_k ≃ S¹，其总上同调（庞加莱多项式）：

```
H*(Z_k) = H*(S¹) = H⁰(S¹) ⊕ H¹(S¹) = ℝ ⊕ ℝ
```

这是 S¹ 上同调的**完整分解**——没有 H^{≥2}（S¹ 是 1 维流形）。⇒ 级别 k 上的仓位空间**恰好**分解为两个 1 维分量，无第三分量。**这就是"⊕ 不是任意比例"的第一层根据：分量个数（2 个）由 S¹ 拓扑强制，不可增减。**

### 4.2 正交性证明（H⁰_k ⊥ H¹_k）

要证 H⁰_k 与 H¹_k 在级别 k 的仓位上是**直和**（独立分量，互不重叠、互不触动）：

**证明（构造性，三步）**：

1. **维度互补 / 无交**：H⁰=常值截面（与相位无关），H¹=绕环循环（绕相位一周）。一个仓位份额若同时是 H⁰ 又是 H¹，则它既"与次级别相位无关"又"绕次级别相位一周"——矛盾（常值函数的环积分 ∮=0，循环类生成元 ∮≠0）。⇒ H⁰_k ∩ H¹_k = {0}。

2. **张成**：级别 k 的任一仓位变动事件，要么由 **k 级买卖点**触发（改变核心 = H⁰_k 事件），要么由 **(k-1) 级买卖点**触发（机动 sink/recover = H¹_k 事件）。这两类买卖点穷尽了级别 k 能消费的所有信号（574号买卖点触发接口 + 第21课买卖点完备性）。⇒ H⁰_k + H¹_k 张成级别 k 全仓位。

3. **互不触动（直和的操作形式）**：由 1（无交）+ 2（张成）得直和 V_k = H⁰_k ⊕ H¹_k。直和的关键操作后果：**H¹_k 的 sink/recover 作用在 H¹ 分量上，结构上不能改变 H⁰_k 分量**（投影 π_{H⁰}∘(H¹算子)=0）。实装即 O6 anchor=核心整仓 ⇒ 机动配额作用于零机动 ⇒ 核心 units 不减（`rec_engine.rs:173-174`）。**□**

⇒ **级别 k 完整仓位 V_k = H⁰_k ⊕ H¹_k**，且这是真直和（互补、独立、机动不动核心）。

### 4.3 配额是级别结构的函数（本任务只定义形式，函数本身留给子4）

固定 MOBILE_FRAC=1/3（`rec_engine.rs:38-39`，= f=1/λ，λ=3 中枢三段）把 split 钉成常数 2/3⊕1/3。**本任务的判定：这个固定配额 = 只读塔顶单格的退化特例 = 拍扁**（memory：固定 2/3⊕1/3 = 只读塔顶一格）。

构造性形式（本任务交付的形式，具体函数读出 = 子4 task#83）：

```
配额 α_k = α*(L_pullback, L_confirm)
```

其中两个自变量**都是级别结构的内生量，无外部参数**：
- **L_pullback** = 次级别回调的级别（H¹_k 操作发生在哪个 (k-1)）——由中枢递归深度读出。
- **L_confirm** = 区间套确认的级别（第27课区间套逐级收窄到哪一级确认走势完成）——由区间套链读出。

**为什么配额必须是这两个量的函数（内在性论证）**：
- λ=3 是 S¹ 最小胞腔数（中枢恰需 3 段成立，`center.rs:58`），所以 f=1/λ=1/3 是**单个中枢**的机动配额下界——一个中枢振荡周期内，机动最多动 1/3（三段中的一段反向）。
- 但塔有多级（多个嵌套中枢），每级一个 S¹。固定 1/3 只读了塔顶那一个 S¹ 的 λ=3。**真实配额 = 所有参与级别 S¹ 的 λ 的函数**（回调级别 L_pullback 决定动哪几级、确认级别 L_confirm 决定动到哪级停）。

## 五、自相似性：塔由单一构造在所有级别生成（编排者硬约束4）

### 5.1 自相似性命题

**命题**：每个级别 k 的上同调单元 H⁰_k ⊕ H¹_k 是**同一个** S¹ 上同调构造在级别 k 上的实例；跨级别 k 同构。⇒ 整座塔 ⊕_k(H⁰_k⊕H¹_k) 可由**单一构造**生成，不需要为每级单独定义。

### 5.2 证明（从递归语法的级别无关性）

**证明（构造性）**：

1. 中枢定义是**级别参数化的同一函数**：`find_centers(units, level)`（`center.rs:53`）对任意 level 调用**同一段代码**——级别 k 的中枢由 (k-1) 级走势重叠定，级别 (k+1) 的中枢由 k 级走势重叠定，**递归语法在每级完全相同**（只是输入的 units 级别不同）。第65课统一递归算子 aₙ=f(aₙ₋₁)：每级是同一 f 的迭代。

2. ⇒ 每级中枢 Z_k 都 ≃ S¹（§1.2 的构造只用了"≥3段重叠振荡回路"，与 k 无关）。

3. ⇒ 每级的上同调 H*(Z_k)=H⁰⊕H¹（§1.3 的 S¹ 上同调，与 k 无关）。

4. ⇒ 每级的仓位语义（H⁰_k=骑本级核心 / H¹_k=操作次级机动）由**同一推导**（§2.3 / §3.3）得出，只是"本级"= k、"次级"= k-1 随级别平移。

5. ∴ H⁰_k⊕H¹_k 是单一构造的级别 k 实例，跨级别同构（差一个级别平移 k↦k）。**□**

### 5.3 自相似性给塔的根据（与子2纵向链接的接口）

自相似性是**塔可用单一砖块生成所有级别**的根据：
- 因为每级是同一构造，塔 = ⊕_k(H⁰_k⊕H¹_k) 不需要 N 个不同定义，只需一个砖块 + 递归生成规则。
- 关键递归链接（**子2 task#82 的职责，本任务只声明接口**）：H⁰_k = H¹_{k+1}——级别 k 的核心（骑 k 级走势）在级别 (k+1) 视角下**就是** (k+1) 的机动（k+1 把 k 级走势当作自己的次级别回调来操作）。这是同一份走势在相邻两级的双重身份（memory：每级既上级机动又下级核心；谱系558 嵌套构成）。本任务**定义了单格 H⁰_k/H¹_k 使这个链接有良定义的两端**，链接本身的构造交给子2。

### 5.4 固定 2/3⊕1/3 = 塔顶单格（拍扁的精确形式）

由自相似性，固定 MOBILE_FRAC=1/3 的意义被精确定位：
- 它是**塔顶那一个 S¹（最高活跃级别 r*）的 λ=3 配额**。
- 把它当全塔的配额 = 假设塔只有一格（只有 r* 一级在动）= **拍扁掉塔下层的所有 H⁰_k/H¹_k（k<r*）**。
- 这与 memory 完全一致："固定 2/3⊕1/3 = 只读塔顶一格 = 拍扁"。

⇒ 本任务的单格构造是**反拍扁**的基础：每级都有自己的 H⁰_k⊕H¹_k，不是只有塔顶一格。

## 八、结果包六要素

### 1. 结论
逐级上同调单元 H⁰_k⊕H¹_k = 中枢 Z_k≃S¹ 的上同调 H*(S¹)=H⁰⊕H¹ 的仓位实现：**H⁰_k**=骑 k 级走势的核心（0维不变量截面，次级别回调不动）；**H¹_k**=在 (k-1) 区间套上开-绕-平的机动（1维循环，由 k-1 买卖点触发 sink/recover）；二者真直和 V_k=H⁰_k⊕H¹_k（dim 各 1 由 S¹ 拓扑强制，机动不动核心由直和正交性强制）；自相似（同一 S¹ 构造跨级别同构，单砖生成全塔）。E⊗F 转折节点触发 H⁰_k/H¹_k 开闭（type1→H⁰_k 翻 / k-1 买卖点→H¹_k 开闭 / E0→确立 S¹）。

### 2. 定义依据
- **中枢=次级别重叠**：第17/18课（`center.rs:1-16`，ZD=max/ZG=min，ZG>ZD 成立）；重叠=格运算非群运算（谱系536）。
- **中枢≃S¹**：从"≥3段重叠绕核心振荡回路"构造（λ=3=S¹ 最小胞腔，`center.rs:58`）。
- **S¹ 上同调=H⁰⊕H¹**：标准代数拓扑（dim H⁰=dim H¹=1）。
- **H⁰=不变量 / H¹=循环**：奇异上同调标准语义。
- **买卖点触发**：第17课买卖点定律 + 第27课区间套 + 574号（买卖点=H⁰→H¹ 触发接口）。
- **#35**：中枢=H⁰ S¹环 / 区间套=H¹（dag.yaml related + memory）。

### 3. 边界条件（结论翻转）
- 若中枢拓扑型**不是** S¹（例如某市场结构使中枢振荡不闭合成回路）⇒ H*(中枢)≠H⁰⊕H¹，分量个数变（当前"≥3段重叠成回路"`center.rs:58` 直接给 S¹，无反例）。
- 若存在第三类仓位分量（既非骑本级也非操作次级）⇒ S¹ 只有 H⁰/H¹ 两分量被否，须升维拓扑模型（当前 S¹ 是 1 维流形，H^{≥2}=0 强制无第三分量）。

- 若配额是外部量（θ 幅度门）而非级别结构函数 ⇒ 内在性翻转（memory：θ 第五次量级失配，外部量=拍扁）。
- 若机动 H¹_k 净盈利可被证明（无 regime 依赖）⇒ 本任务"H¹ payoff=L3 未决"收紧为 L0（当前主动 hedge 强牛 L3 否证，未达成）。
