## 一、区间套确认深度连续轴 δ 的定义（从第27课区间套链构造，非参数）

### 1.1 δ 是什么：type1 背驰的区间套定位确认级别

**背景（骨架 §★★顶部不特殊 + memory 行29/31）**：r\* 顶部 type1 背驰**可解**——用区间套定位确认（第27课逐级区间套链 `rec_engine.rs:113-121`），唯一下界 = a0 分辨率 1bar 且全级别同一非顶特例。回调-vs-真顶的歧义不是"有/无更高级别"的离散判断，是 type1 背驰下沉确认到**哪一级别**的连续判断。

**定义（区间套确认深度 δ）**：在级别 k 出现 type1 背驰时，区间套定位从级别 k 向下逐级下沉（k → k-1 → … → a0），在每一级检查低级别走势是否**确认了反转**（低级别走出反向走势 = 该级别确认下跌）。区间套确认深度 δ 是**确认反转首次成立的级别**（或下沉到 a0 仍未确认反转则 δ=a0⁻，记为"未确认下沉到底"）：

```
δ(k) = 区间套从级别 k 下沉，首次确认低级别反转的级别索引
     δ ∈ [a0, k]  连续轴（离散化的级别索引，但下界 a0 全级别同一）
  δ 越浅（接近 k）：低级别快速确认反转 ⇒ type1 背驰是真转折（趋势完成）
  δ 越深（接近 a0）：须下沉很深才确认 ⇒ type1 背驰可能只是 k 级内部回试（中枢内振荡）
  δ 下沉到底未确认反转（停在中枢内）：低级别始终在 k 级中枢 [DD,GG] 内振荡 ⇒ 回调（非真顶）
```

**δ 是连续轴上的位置，不是离散二值**：δ 在 [a0, k] 上取值，每一级都是一个确认深度位置。回调-真顶是 δ 轴上**阈值 δ\*（"确认反转 vs 停中枢内"的临界）两侧的连续区域**，不是两个离散轨道。

### 1.2 δ 从递归定义构造（构造性，零外部参数）

δ 不是引入的新参数，是第27课区间套链的**读数**：

| δ 的分量 | 取值来源（递归定义读出） | 实装锚点 |
|----------|--------------------------|----------|
| 下沉起点级别 k | type1 背驰发生的级别（rec_stream.rs:453,467 t1sell[k]） | 走势树 tree.levels[k] |
| 逐级下沉链 | 第27课区间套：k 级走势的次级别 = k-1 级，逐级套娃 | rec_engine.rs:113-121 区间套链 |
| 每级"确认反转"判据 | 低级别 j 走出反向走势（j 级 direction 翻转，离开 k 级中枢 [DD,GG]） | tree.levels[j].direction + zg/zd（694-699） |
| 下界 a0 | 基础分辨率 1bar（递归底，全级别同一，project_1min_resolution_irreducible） | aₙ=f(aₙ₋₁) 的 a0（第65课） |

**关键（内在）**：δ 纯由"级别 × 区间套"读出（确认反转 = 低级别 direction 翻转 + 离开中枢），零 bar 计数 / 价格% / 强平线 / 统计相关（剔除 payoff-regime 外在量，骨架零件2 纠正）。δ = 区间套确认级别 = 第27课逐级套娃链上"反转确认首次成立"的位置。

### 1.3 离散二值是 δ 在阈值 δ\* 的投影（拍扁证明，元判据4 应用）

**命题**：子7 G 的"涌现状态 emerg_k ∈ {有更高级别 k+1, 无更高级别}"离散二值 = δ 连续轴在阈值 δ\* 的二值投影 π_{δ\*}，丢失 δ 轴结构 = 拍扁。

**证明（构造）**：
```
定义投影 π_{δ\*} : δ 连续轴 → {有 k+1, 无 k+1}
  π_{δ\*}(δ) = 有更高级别 k+1（回调）   若 δ 停在中枢内（未确认反转，低级别仍在 [DD,GG] 内振荡）
            = 无更高级别（真顶）       若 δ 确认反转（下沉到某级别 j 确认下跌）
```

- **"有更高级别 k+1 接成回调" = δ 停在中枢内**：低级别区间套下沉到底仍未确认反转（始终在 k 级中枢内振荡）⇒ k 级 type1 背驰只是内部回试 ⇒ 该 k 级走势被 k+1 重叠成构成单元（回调），核心重角色 H⁰_{k+1} 持有。**"有更高级别 k+1"是 δ 停中枢内的结果，不是独立的离散判断**——k+1 涌现（结构长一格）正因为 k 级走势没真完成（δ 未确认反转），它成了 k+1 中枢的构成单元。
- **"无更高级别真顶" = δ 确认反转**：低级别区间套下沉确认了反转（某级别 j 走出反向走势，离开中枢）⇒ k 级 type1 背驰是真转折 ⇒ k 级走势终完美完成，核心 H⁰_k 减仓。**"无更高级别"是 δ 确认反转的结果**——k 级真完成了，它不会再被更高级别重叠成回调（因为它自己已经走出了 S¹ 到新中枢方向）。

**∴ 离散二值 {有 k+1, 无 k+1} = π_{δ\*}(δ)**：二值是 δ 连续轴经阈值 δ\* 的投影。**投影丢失了 δ 轴上 δ\* 两侧的连续结构**（δ=k-1 浅确认 vs δ=a0 深确认都被投成"无 k+1"，但它们的确认深度不同 ⇒ 减仓的时机/级别不同）。这正是元判据4 的"边界例外"：把连续的 δ 轴切成两个离散分支 = 用例外（δ\* 阈值二分）打补丁 = 没构造到底。

**等涌现=等 type1 背驰确认（同一性，编排者第二次纠正核心）**：
- 之前（子6/子7）把"等涌现"（有无 k+1）和"type1 背驰确认"当**两个独立判断**：先判涌现状态（有/无 k+1），再判 type1 背驰。
- 真相：r\* 顶部背驰产的 type1 **正是**触发 r\*+1 涌现的东西——k 级 type1 背驰被区间套确认（δ 停中枢内）⇒ k 级走势成为 k+1 构成单元 ⇒ k+1 涌现。涌现（结构长一格）和真顶确认（操作减仓）是**同一个 type1 背驰事件在不同深度 δ 的读出**：δ 停中枢内 → 涌现（回调）/ δ 确认反转 → 真顶（减仓）。**不是两个判断，是一个 type1 背驰 + 一个 δ 读数。** 这消除子7/子6 里"涌现状态"与"type1 背驰"的双重判断。

## 二、证：等涌现 = 等 type1 背驰确认 = 同一件事（消除双重判断）

### 2.1 r\*+1 涌现的触发条件 = r\* type1 背驰被区间套确认（δ 停中枢内）

**子2 §2.2 的涌现事件（已读，不重推）**：r\* → r\*+1 涌现 ⟺ 级别 r\* 走势**终完美 completed**（types.rs:267 rposition completed），重叠成 r\*+1 中枢构成单元，emergent_ceiling 升 r\*→r\*+1。

**子6/子7 把这当作独立于 type1 背驰的"涌现状态"判断。本任务证它们同一**：

```
r* 走势 completed（涌现触发）
  ⟺ r* 走势走完一个完整的趋势/盘整单元（types.rs completed）
  ⟺ r* 出现 type1 背驰（趋势力度衰竭，走势完成 = type1 的定义，rec_stream.rs:453）
       —— "走势完成"和"type1 背驰"是同一件事（第19课：走势完成由背驰判定）
  ⟺ 该 type1 背驰被区间套确认为"停中枢内"（δ 停中枢内）
       —— 若 δ 停中枢内：r* 走势是 r*+1 内部回试 ⇒ 被 r*+1 重叠成构成单元 ⇒ r*+1 涌现
       —— 若 δ 确认反转：r* 走势走出 S¹ 到新中枢 ⇒ 不被重叠 ⇒ 真顶（无 r*+1 涌现，r* 自己完成）
```

**∴ "r\*+1 涌现"⟺"r\* type1 背驰 ∧ δ 停中枢内"**：涌现不是独立判断，是 type1 背驰 + δ 读数（δ 停中枢内）的**结果**。"等涌现"= 等"r\* type1 背驰 + 区间套确认 δ 停中枢内"= 等 type1 背驰确认（δ 读数）。同一件事。□

### 2.2 消除双重判断：一个 type1 背驰事件 + 一个 δ 读数

**旧建模（子6 §二 / 子7 §3.3-B 双重判断）**：
```
判断1：涌现状态 emerg_k ∈ {有 k+1, 无 k+1}    ← 离散二值（假例外）
判断2：type1 背驰是否 fire                      ← 独立判断
组合：有 k+1 → 回调（relabel）/ 无 k+1 → 真顶（减仓）
```

**新建模（连续轴统一，单一事件+单一读数）**：
```
事件：级别 k 出现 type1 背驰（k 级走势力度衰竭，rec_stream.rs:453 t1sell[k]）— 唯一事件
读数：区间套确认深度 δ(k) ∈ [a0, k]                                    — 唯一读数
       δ 停中枢内（未确认反转）⇒ 回调（H⁰_k 重角色 H⁰_{k+1} 持有，=k+1 涌现）
       δ 确认反转（下沉到 j 级确认下跌）⇒ 真顶（H⁰_k 减仓）
       —— 回调-真顶是 δ 轴上阈值 δ* 两侧的连续位置，不是两个独立轨道
```

**双重判断消除**：涌现状态不再是独立维度——它是 δ 读数的投影（§1.3）。判断只有一个：type1 背驰 + δ 下沉确认。**"是否有更高级别 k+1"不再被独立查**（emergent_ceiling 检查），它由 δ 读数自动得出（δ 停中枢内 ⟺ 有 k+1 接 = 回调）。这是编排者第二次纠正"不是两个独立判断"的形式化兑现。

### 2.3 自相似到底：δ 轴对所有级别 k 同一（顶部不特殊）

**元判据4（无边界例外）的最深应用**：δ 连续轴对所有级别 k 同构——k=r\*（最高级别）**不是特例**。

```
对任意级别 k（含 k=r*）：
  k 级 type1 背驰 → 区间套从 k 下沉（k→k-1→…→a0）→ δ(k) 确认深度
  δ 停中枢内 ⇒ k 级回调（H⁰_k 重角色 H⁰_{k+1} 持有）
  δ 确认反转 ⇒ k 级真完成（H⁰_k 减仓）
```

- **k=r\* 不特殊**：r\* 顶部 type1 背驰用同一区间套下沉（r\*→r\*-1→…→a0），δ(r\*) 同一判据。所谓"真顶减仓"= δ(r\*) 确认反转的实例，与 k<r\* 的 type1 处理**自相似**（同一 δ 轴判据）。
- **顶部 type1 存在（不是 l4_consoldn 流式前沿假象）**：最高级别**有** type1（骨架 §★★ + memory 行29）。顶部背驰产 type1 且其 δ 读数决定 r\*+1 涌现（δ 停中枢内）或真顶（δ 确认反转）。
- **唯一下界 a0 非顶特例**：δ 下沉的底 = a0 分辨率 1bar，全级别同一（project_1min_resolution_irreducible）。a0 是 δ 轴的下界（递归底），不是顶部留的特殊边界——任何级别 k 的 δ 下沉都到同一个 a0。

**∴ δ 连续轴自相似到底，顶部不特殊，无离散 if 分支。** 574 = δ 选择（区间套确认深度，内在操作）非"等涌现"的不可约墙——失血 ≠ 顶部不可约残留，是 δ 未下沉够深 ⇒ 高级别腿没确认身份 ⇒ 孤儿（可更深 δ 解决，与诊断量孤儿同源，骨架零件2）。
