## 一、印钞机溶解 = H⁰⊕H¹ 直和 by construction（不需 anchor 外加守恒）

### 1.1 印钞机的精确根（必须直面的矛盾，no-workaround）

矛盾报告 escalate §一矛盾1 / §六问题1 坐实的无界爆仓，形式化为**两个必要条件**：

```
设主动 hedge 版 sink：核心 realized=0（核心不减）+ 开空腿 short_u + recover 归还核心 give。
印钞机 ⟺ (P1) ∧ (P2)：
  (P1) 核心不减无条件 ⇒ 配额基 quota(u_p) 恒定（u_p 永不衰减）⇒ 每次 sink 用同一 u_p 算 short_u
  (P2) 机动操作碰核心 units：sink 减核心 units（realized>0）但 recover 归还核心 units（give 加回 instances[parent]）
       ⇒ 若 give 与核心耦合，每 sink→recover 循环可净增核心 ⇒ 指数膨胀 → CL ON −1165404%（#567 无界空腿）
```

**关键诊断（撤 anchor 死扣的根据）**：(P1) 和 (P2) 都源于**把"核心不减"当无条件** + **机动碰核心 units**。死扣 anchor 试图关 (P1)（mob_base=u_p−anchor 把配额基降一截），但它**用固定 2/3 死扣**——这只是把"无条件不减"换成"无条件死扣 2/3"，仍然不读"该不该减"（涌现条件）。**真顶时（无更高级别）该减仓却死扣 2/3 扛跌 = 爆亏**（552号 L3 实测：CL/BRN/DX 震荡 regime anchor S 翻深负，死扣底仓在反转时套牢强平）。**死扣 anchor 是 (P1) 的拍扁解，不是结构解。**

### 1.2 直和 by construction 关闭 (P2)（机动不碰核心 units）

子1 §4.2 已证 H⁰_k ⊥ H¹_k 是**真直和**（tower_cohomology_unit.md §4.2 三步证明）：H⁰=常值截面（绕环不变量）∩ H¹=绕环循环 = {0}（无交）+ 两级买卖点张成全仓位（张成）+ **直和的操作形式：投影 π_{H⁰_k}∘(H¹算子)=0**（机动算子作用在 H¹ 分量，结构上不能改变 H⁰_k 分量）。

**印钞机溶解定理**：塔的直和 (子1 §4.2) ⇒ 机动 H¹_k 操作（sink/recover）作用在 H¹_k 分量上，**结构上不碰核心 H⁰_k 的 units** ⇒ (P2) 关闭。

**证明（构造性，三步）**：
1. **机动是 H¹_k 分量**：sink 开空腿 short_u（rec_engine.rs:1429）+ recover 平空腿 m_sub（rec_engine.rs:1471）都作用在次级别 sub 实例（instances[sub]），是 H¹_k 的循环（绕环开-平，子1 §3.2）。
2. **核心是 H⁰_k 分量，独立**：核心 H⁰_k = instances[parent] 的 units。由直和正交投影 π_{H⁰_k}∘(H¹算子)=0，机动对 sub 的操作**结构上不改变 parent 的 units**——除非显式调 rec_reduce(parent)（那是核心 H⁰ 事件，由涌现条件②决定，非机动 H¹ 事件）。
3. **recover 的 give 不凭空加核心**：recover 归还 give=m_sub·sb/pb（rec_engine.rs:1463）来自**平掉空腿释放的名义资本**（M_returned=m_sub·sb，子1 §3.2 + project_sink_capital_sizing），不是凭空印钞——give 加回 parent 是机动腿真实盈亏的资本回流，受会计守恒 M_released=M_returned 约束（§1.3）。
4. ∴ 机动 H¹_k 在自己 H¹ 分量内循环，核心 H⁰_k units 不被机动操作触动（仅被涌现条件②的真顶减仓改变）。**(P2) 由直和 by construction 关闭，不需 anchor。□**

**这就是编排者"直和本身就是守恒"的精确含义**：anchor 死扣是**外加**一个"不参与配额"的份额来人为切断 (P2)；直和是**by construction** 切断 (P2)——机动算子的正交投影到核心分量恒为 0，是代数必然，不是事后约束。

### 1.3 sink↔recover 对称资本守恒 ⇒ 每循环净增 give=0（无指数膨胀）

(P2) 关闭后，机动在 H¹ 预算内的循环还须**守恒**（不在 H¹ 内部自膨胀）。这由同资本 sizing 保证：

资本守恒链 **M_released = m·pb = short_u·sb = give·pb = M_returned**（project_sink_capital_sizing）：

| 步骤 | 操作 | 资本流 | 实装锚点 |
|------|------|--------|----------|
| sink 开空 | short_u = m·pb/c | 开空名义资本 = short_u·c = m·pb = M_released | rec_engine.rs:1404 |
| recover 平空 | 平整条 m_sub=u_sub | 平空释放名义资本 = m_sub·sb（sb=开空价） | rec_engine.rs:1453,1461 |
| recover 归还 | give = m_sub·sb/pb | 归还核心资本 = give·pb = m_sub·sb = M_returned | rec_engine.rs:1463,1472 |

**对称守恒定理**：sink 与 recover 是同资本的两半（M_released = M_returned），∴ 每个 sink↔recover 配对的净资本流 = M_returned − M_released = 0 ⇒ **无 sink→recover 循环净增**（give 与 reduce 的差仅反映机动腿真实盈亏，deploy_earning 降本后 give>m 是真实收益按资本恢复，非印钞）。**□**

**这对应 prove_sink_recover_balance 守卫（rec_engine.rs:1200,1438,1480 + prove_guards.rs:198-209）的构造性根据**：守卫检查 campaign 内 sink 总数 == recover 总数（每个卖点开的空腿必有买点回补）。**守恒定理给出守卫为何应成立**：sink↔recover 资本对称守恒 ⇒ 走势完美时每 sink 必有配对 recover ⇒ sink_d == rec_d。守卫的失衡计数（n_sink_recover_imbalance）= 测量"有 sink 无配对 recover"（空腿被 clear/强平而非 recover 平掉）= 印钞机风险可观测信号。**守恒定理 = 守卫断言的构造性证明；守卫 = 直和守恒的运行时验证（编排者"直和的运行时验证"）。**

### 1.4 印钞机两条件均关闭（直和①溶解，涌现条件②管 P1）

- **(P2)（机动碰核心 units）**：由直和 by construction 关闭（§1.2），不需 anchor。
- **(P1)（核心不减无条件 ⇒ 配额基恒定）**：由涌现条件化核心减仓关闭（§二）——核心不减不再无条件，真顶时核心 H⁰_{r*} 减仓 ⇒ 配额基随真顶减仓衰减 ⇒ 不恒定。**注意：(P1) 不靠 anchor 死扣关，靠涌现条件②的真顶减仓关。**

∴ 印钞机两个必要条件 (P1)(P2) 分别由涌现条件② + 直和① 关闭 ⇒ 无界爆仓的充分条件不再满足 ⇒ **无印钞机，无需 anchor**。**□**

## 三、"核心不减 ∧ 机动有界"从不可兼得变可兼得

### 3.1 健全定理陈述

> **健全定理（直和 + 涌现条件化）**：塔（H⁰_k⊕H¹_k 直和 by construction + 涌现条件化核心减仓两分支）⇒ **无界爆仓不可能**。具体地：核心有界（涌现条件②：有更高级别→relabel 守恒 / 无更高级别→真顶减仓，非无条件不减）∧ 机动有界（直和①：机动 H¹_k 在自己 H¹ 预算内对称循环，不碰核心 units + 资本守恒净增=0），**且两者兼得**（非 O6 no-hedge 退化解 H¹_k→0，是 α*_k>0 主动健全；非死扣 anchor 真顶扛跌，是涌现条件化减仓）。

### 3.2 健全定理证明

**证明（综合 §一直和 + §二涌现条件，构造性）**：

设塔满足：(C1) H⁰_k⊥H¹_k 直和 by construction（子1 §4.2）；(C2) 涌现条件化核心减仓（§二，分支 A relabel 守恒 / 分支 B 真顶减仓）；(C3) 同资本 sizing 对称守恒（§1.3）。

**(I) 机动有界（由直和①）**：
- 由 §1.2：机动 H¹_k 操作作用在 H¹_k 分量（sub 实例），直和正交投影 π_{H⁰_k}∘(H¹算子)=0 ⇒ **机动不碰核心 units**（(P2) 关闭）。
- 由 §1.3：每 sink↔recover 配对净资本流=0（M_released=M_returned）⇒ 机动在 H¹ 预算内**不自膨胀**。
- ∴ 机动暴露被钉在 H¹_k 预算内（α*_k·u_p 量级，子4 配额），且循环守恒不累积 ⇒ **机动有界**。

**(II) 核心有界（由涌现条件②）**：
- 分支 A（有更高级别）：核心 relabel 守恒（units 不变，子2 §2.3）⇒ 核心 units 常值（重角色持有）。
- 分支 B（无更高级别真顶）：核心对称减仓/清仓（units 单调有界减，§2.3 第3点）⇒ 核心 units 有界减。
- ∴ 核心 units 在两分支下均有界（分支 A 常值，分支 B 有界减）⇒ **核心有界**。

**(III) 两者兼得（关键，矛盾解除）**：
- §1.1 的"不可兼得"前提是 (P1)∧(P2)：核心不减无条件 ⇒ 配额基恒定（P1）+ 机动碰核心 units（P2）。
- 引入直和① (C1) ⇒ (P2) 关闭（机动不碰核心 units，§1.2）。
- 引入涌现条件② (C2) ⇒ (P1) 关闭（真顶时核心真减 ⇒ 配额基衰减，§2.4）。
- ∴ (P1)∧(P2) 两个充分条件均被关闭，"不可兼得"的前提消失 ⇒ 核心有界 (II) ∧ 机动有界 (I) **同时成立**，矛盾解除。**□**

**修复 §1.1 隐含错误推理**：旧 bug 的链 "核心不减 ⇒ quota(u_p) 配额基恒定 ⇒ 无界" 有两处错——(a) "核心不减"非无条件（涌现条件②，真顶减仓）；(b) 即使核心不减（分支 A relabel），机动也不碰核心 units（直和①），配额基的恒定不导致无界因为机动在 H¹ 预算内守恒。**两处错分别由涌现条件②和直和①修复。**

### 3.3 这不是退化解（α*_k>0 主动健全 vs O6 no-hedge / 死扣 anchor）

**必须证明这不是回避矛盾**（no-workaround）。三个解对照（§四完整对比）：

| | O6 no-hedge 退化（rec_engine.rs:1389-1390,1422-1430） | 死扣 anchor（已撤销） | 直和+涌现条件化（本定理） |
|---|---|---|---|
| H¹_k | →0（不开空腿，机动死掉） | >0 但核心固定 2/3 死扣 | >0（机动在 H¹ 预算内主动循环） |
| 有界来源 | 瘫痪（不开空腿无空腿累积） | 死扣份额人为切 (P1) | 直和 by construction 切 (P2) + 涌现条件切 (P1) |
| 真顶处理 | 不开空腿（无方向性） | **死扣扛跌爆亏**（不读"有无更高级别"） | **涌现条件减仓**（无更高级别→真顶减仓） |
| 矛盾处理 | 回避（H¹_k→0） | 拍扁（固定 2/3 无条件死扣） | **解除**（直和+涌现条件，α*_k>0 有界） |

**O6 退化解有界性来自"不开空腿"（瘫痪）= α*_k≡0；死扣 anchor 有界性来自固定 2/3 死扣（拍扁，真顶扛跌）；本定理有界性来自直和（机动不碰核心）+ 涌现条件（核心条件化减仓）= 结构，机动 α*_k>0 主动。** 这与子4 的 α*_k 同源：α*_k = H¹ 预算比例（机动循环的份额），α*_k>0 时机动主动循环在 H¹ 预算内，α*_k→0 时退化为纯核心（匹配 BH）——O6 退化解只是 α*_k≡0 特例。

**诚实标注（formalization-validity-domain）**：本定理证的是**健全性**（无界爆仓不可能 = L0 构造 + L1 实装 bit-exact）。**"健全后机动主动 hedge 是否净盈利/超 BH" 是 L3 未决**——escalate / 子1 §3.3 / 子2 §6 已记录：当前实装的主动 hedge 在强牛被 L3 否证（BTC −132468%/CL −677%，short_pnl −60M），O6 才退回 no-hedge。**本定理不声明"健全后超 BH"**（那是 payoff 有效域，子4 α*_k 自适应 + L3 回测的事）。本定理只证：**若机动 α*_k>0 开空，直和+涌现条件保证它不无界爆仓**——把"机动主动"从"必然无界"降为"有界但 payoff 待测"。**不声明膨胀。**

## 四、三种处理对比（撤 anchor 死扣论证）

任务 #89 硬约束要求证三种处理：(a) 核心无条件不减 / (b) 死扣 anchor / (c) 直和+涌现条件化。

### 4.1 (a) 核心无条件不减 = 印钞机（旧 bug）

主动 hedge 版核心 realized=0 无条件 ⇒ (P1)(P2) 同时满足 ⇒ CL ON −1165404%（escalate §一实测）。**(a) 是印钞机源，被 escalate 坐实否证。**

### 4.2 (b) 死扣 anchor = 真顶扛跌爆亏（上版被证伪）

死扣 anchor 用 mob_base=u_p−anchor（固定 anchor=2/3·u_p）切 (P1) 一截，但：
1. **u_p 仍无条件不减**：anchor 部分（2/3）永不减仓（死扣）⇒ 真顶（无更高级别）时核心 2/3 死扣**扛跌** ⇒ 552号 L3 实测震荡 regime（CL/BRN/DX）anchor S 翻深负（CL +22.2→−71.7，liq=19 强平死亡）。
2. **固定 2/3 不读"有无更高级别"**：死扣是塔顶单格固定常数（子1 §5.4），不区分分支 A（回调，该持有）vs 分支 B（真顶，该减仓）⇒ 对两分支用同一死扣 ⇒ 分支 B 扛跌。
3. ∴ **(b) 死扣是 (P1) 的拍扁解**——把"无条件不减"换成"无条件死扣 2/3"，仍不读涌现条件，真顶爆亏。**死扣 anchor 被上版证伪（任务 #89 编排者纠正撤销）。**

### 4.3 (c) 直和+涌现条件化 = 唯一非拍扁结构解

1. **直和切 (P2)（结构，非死扣）**：机动不碰核心 units 是直和正交投影的代数必然（§1.2），不是人为划一个死扣份额。
2. **涌现条件切 (P1)（内在，非常数）**：核心减仓读"级别顶∧无更高级别"（涌现条件②），真顶减仓 ⇒ 配额基衰减（§2.4），不扛跌。
3. **(c) 优于 (b)**：(b) 死扣是固定常数（拍扁，不读涌现）；(c) 核心减仓读涌现条件（级别顶∧无更高级别）= 内在（纯涌现读出）。**(c) 在真顶正确减仓（分支 B），(b) 在真顶死扣扛跌——这是 (c) 优于 (b) 的决定性差异。**
4. **(c) 优于 (a)**：(a) 无条件不减导致 (P1)，(c) 涌现条件化关 (P1)。
5. ∴ **(c) 是唯一非拍扁结构解**——(a) 印钞机，(b) 真顶扛跌，只有 (c) 用直和（结构切 P2）+ 涌现条件（内在切 P1）同时关两条件且不扛跌。**□**

## 五、与三分量 + 诊断同源（anchor 概念退场，健全由直和+涌现条件承载）

骨架 §二要求证三分量（d_k 方向 / 角色 H⁰_k/H¹_k / α*_k 配额）同源。本任务证**健全条件（直和+涌现条件）与三分量同源**——健全不是第四个独立分量（anchor 退场），是三分量正确读出的结构后果：

### 5.1 直和 = H⁰⊥H¹ 操作形式（角色分量同源）

- 角色 H⁰_k/H¹_k（子1）= S¹ 上同调 H⁰（核心）⊕ H¹（机动）的仓位实现。
- 直和（机动不碰核心 units）= H⁰⊥H¹ 的**操作形式**（π_{H⁰}∘(H¹算子)=0，子1 §4.2）。
- ∴ **印钞机溶解（直和①）= 角色分量（H⁰/H¹）的操作侧读数**——不是外加 anchor，是角色分解本身的代数必然。anchor 概念退场：健全的 (P2) 关闭由角色直和承载，非 anchor 死扣。

### 5.2 涌现条件化减仓 = 涌现重读（分支 A）+ 真顶减仓（分支 B）（角色平移同源）

- 分支 A（有更高级别→relabel）= 子2 涌现重读算子 ⤊（H⁰_{r*}→H¹_{r*+1} 衬底，沿递归链接边平移，units 守恒）。

- ∴ **涌现条件化核心减仓 = 角色分量在涌现动态下的两分支**（A 重角色平移 / B 真顶了结），由"是否有更高级别 r*+1"（涌现读出）内在决定。健全的 (P1) 关闭由涌现条件承载，非 anchor 死扣。

### 5.3 d_k 决定该不该开 H¹_k（方向分量 + 孤儿诊断同源）

- d_k（子2）= 逐级方向分量 = top_trend_dir 的逐级读出。
- 涌现条件②的两分支判别用 d_k（子2 §3.4：is_rstar_pullback_leg 读 d[rstar]）：分支 A d_k 同核心向（主升浪延续，relabel 持有）；分支 B d_k 反核心向（真顶转向，减仓）。

- ∴ **d_k 决定该不该开 H¹_k**（d_k 错→孤儿→该级 α*_k 应→0 不开 H¹_k，子2 §4.2）。直和（不碰核心=不无界）+ 涌现条件（核心减不减）+ d_k（该不该开 H¹_k）是健全的三个维度。

### 5.4 α*_k = H¹ 预算比例（配额分量同源）

- α*_k（子4/零件1）= 可循环比例 = α*(L_pullback(k), L_confirm(k))（内在，零外部参数）。
- α*_k = **机动 H¹_k 的预算比例**——机动在 (α*_k·u_p) 这个 H¹ 预算内对称循环（直和①的 H¹ 分量大小）。α*_k 越大=H¹ 预算越大=机动循环空间越大；α*_k→0=退化为纯核心（匹配 BH，O6 退化解=此特例）。
- ∴ **α*_k 是机动有界（直和①）的预算尺度**——机动有界 = 机动钉在 α*_k·u_p 内 + 守恒。α*_k 与直和同源：直和给"机动不碰核心"（操作），α*_k 给"机动预算多大"（尺度）。

### 5.5 同源结论（anchor 退场）

```
健全 = 直和① (机动不碰核心 units, P2 关闭)        ← 角色分量 H⁰⊥H¹ 操作形式（§5.1）
     + 涌现条件② (核心减仓条件化, P1 关闭)         ← 角色分量涌现两分支 A/B（§5.2）

```

**健全不是第四个独立 patch（anchor 退场），是三分量（角色/方向/配额）正确读出的结构后果**——直和=角色操作形式，涌现条件=角色涌现两分支，d_k=方向门控该不该开 H¹_k，α*_k=配额给 H¹ 预算尺度。全部从同一套缠论级别内生量（top_trend_dir/d_top/区间套链/emergent_top/L_pullback/L_confirm）读出。这与骨架 §二"三分量同源、非三独立 patch"一致——**anchor 概念退场，健全由直和+涌现条件承载，是三分量的结构后果非外加分量。**

## 七、结果包六要素

### 1. 结论
