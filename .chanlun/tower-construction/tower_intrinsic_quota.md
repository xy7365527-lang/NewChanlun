## 二、可操作性轴 G（三因子全内在合取，纳入零件2 + 子9 ⪯ 判据）

### 2.1 可操作性是 α*_k>0 的布尔前驱（子9 分离定理，纳入不重推）

子9 已证：**可操作性比 α*_k 更基本**——它先于配额（不可操作 ⟹ 无论配多少都是孤儿失血）。α* 答"配多少机动"，可操作性答"机动腿能否内在闭合"。

```
分离定理（子9 §2）：α*_k > 0 ⟹ 可操作(级别 k 的回调转折)；可操作 ⟹ α*_k 可正（但仍可因 L_pullback 浅而 →0）
  即：可操作性是 α*_k > 0 的必要非充分前驱。
```

因此塔的操作语义判据是两层：**先判可操作性（布尔前驱，本节 G）→ 再判配额量（α*_k，§一）**。H¹_k 该不该激活，第一关是 G。

### 2.2 可操作性轴 G 的三因子全内在合取

H¹_k 该不该激活的主判据 = 三因子合取（全从买卖点/级别/区间套读出，禁外在量）：

```
H¹_k 可激活 ⟺ ①级别-方向对齐 ∧ ②闭合转折节点存在性（⪯ 判据）∧ ③（次轴）回调可操作捕获
```

**① 级别-方向对齐（d_k，纳入子2 d_k 向量）**：
- H¹_k 空腿方向 vs 级别 k 走势方向 d_k：**仅 d_k=Down 才开 H¹_k 空腿**（级别 k 真出下跌段）。
- r* 主升浪中高级别空腿 = 逆势失配（d_k=Up 却开空 = payoff-regime §2.2 高级别逆势僵尸失血源，与僵尸 100% 重合）。
- **OKLO 正例**：OKLO 有下跌段（某级别 d_k=Down）时，同 (seg, short) 分量 +70k 正——d_k=Down 时空腿正确对冲下行=赚（payoff-regime §2.2）。

**② 闭合转折节点存在性（孤儿判据，⪯，替代外在 574/强平）**：
- 级别 k 上 H¹_k 空腿是否存在**配对的闭合转折节点**（开空于卖点 X ⇒ 须级别 k 有可达的买点 Y 闭合）。
- 子9 充要判据（纳入不重推）：**可操作(X) ⟺ L_confirm(X) ⪯ L_move(X)**（确认级别 ⪯ 移动级别 = 确认在移动完成前到达 = 配对 Y 在 X 的 H¹ 循环内 fire = 腿闭合 = 非孤儿）。
- **d_k=Up 时级别 k 永不产生平空买卖点 ⇒ L_confirm 发散（确认级别不可达）⇒ ≻ ⇒ 孤儿 ⇒ 不开**（子9 §2 末：方向错是不可操作的极端实例 L_confirm=∞，非独立失血机制）。

**③ 浅回调幅度轴（次轴，低级别 osc 短差次分量，标注为次）**：

## 三、split 自适应定理（L0 构造完备，"超 BH" L3 未决）

### 3.1 定理陈述

> **split 自适应定理**：塔的 split（每级配额 α*_k）是「纯牛 vs 结构化」的**完全分类函数**——
> - **纯牛 case**（所有级别 k-1 无可操作回调结构 = ∀k: L_pullback 低 ∨ L_confirm 高）⇒ 全部留 H⁰=核心 full ⇒ 每级 α*_k→0 ⇒ 匹配 BH（消 drag）。
> - **结构化 case**（存在可操作回调 = ∃k: L_pullback 高 ∧ L_confirm 低 ∧ d_k=Down ∧ L_confirm ⪯ L_move）⇒ 该级 H¹_k 激活 α*_k>0 ⇒ 捕获该级回调跌幅 ⇒ 超 BH。
>
> 固定 split（α≡1/3）是这个完全分类函数的**拍扁**（对所有级别/标的/regime 用同一配额，丢 L_pullback/L_confirm/d_k 三读数）⇒ 0/8 超 BH。

### 3.2 定理证明（构造性，三步）

**1. 纯牛 case → 核心 full = 匹配 BH（消 drag）**：
- 纯牛 = 主升浪无可操作回调结构。形式：∀ 级别 k，要么 L_pullback 低（t3sell 浅，无深回调可捕获）要么 L_confirm 高（须深层 recL3 确认，滞后大，腿不闭合 L_confirm ≻ L_move）。
- 由 §一配额函数：L_pullback 低 ∨ L_confirm 高 ⇒ α*_k→0 ⇒ 每级核心 H⁰_k full（不开机动）。
- 核心 H⁰_k full 骑主升浪（O6 已溶解踏空，核心腿 8/8 全正，payoff-regime §2.1）⇒ 等价于 buy-hold ⇒ **匹配 BH 无 drag**。
- **关键**：固定 split 在纯牛仍削 1/3 开机动（α≡1/3）⇒ 机动在纯牛是逆势孤儿（L_confirm ≻ L_move，无回调可闭合）⇒ drag。自适应 split 读出「纯牛=无可操作回调」⇒ α*_k→0 ⇒ 消 drag。

**2. 结构化 case → H¹_k 激活 = 超 BH**：
- 结构化 = 存在可操作回调。形式：∃ 级别 k，L_pullback 高（d_top 深，深回调）∧ L_confirm 低（k-1 快触发）∧ d_k=Down（方向对齐）∧ L_confirm ⪯ L_move（腿闭合非孤儿）。
- 由 §一配额函数：L_pullback 高 ∧ L_confirm 低 ⇒ α*_k>0 ⇒ 该级 H¹_k 激活。
- 由 §二可操作性：d_k=Down ∧ L_confirm ⪯ L_move ⇒ 非孤儿 ⇒ H¹_k 空腿有配对闭合转折节点 ⇒ 捕获该级回调跌幅（OKLO seg-short +70k 正例）。
- 核心 H⁰_k 骑主趋势 + 机动 H¹_k 捕获回调跌幅 ⇒ **超 BH**（核心不失血 + 机动加 alpha）。

**3. 固定 split 是完全分类的拍扁**：
- 固定 α≡1/3 对纯牛 case（该 α→0）和结构化 case（该 α>0）用**同一配额** ⇒ 纯牛 drag（机动孤儿失血）+ 结构化未充分捕获（配额不随 L_pullback 调大）。

**这是 hold26 BTC+1247/nested+2301 超 BH 的构造性解释**：hold26（中枢极性内在驱动 L_pullback）/nest_forward（区间套确认内在驱动 L_confirm）4/8 超 scco/BH，正因它们读了 L_pullback/L_confirm（自适应 split），而 orbit9 固定 split 0/8 没读（拍扁）。**□**

### 3.3 诚实标注（formalization-validity-domain，不声明膨胀）

- **split 自适应是 L0 构造**：完全分类函数（纯牛→α→0 / 结构化→α>0）从级别结构内在读出，定义域=有效域（分类层）。

## 四、逐级内在诊断量 bleed_k（纯内在孤儿诊断，零外在量）

### 4.1 诊断量定义（孤儿 = 未闭合转折节点对，纳入零件2纠正）

**编排者关键纠正（纳入）**：payoff-regime #75 的诊断量「僵尸>10万bar / 强平 2×basis 够不到 / z≈100%」**全是外在量**（bar 计数/价格%/强平线/统计相关）。用外在量诊断 = 又拍扁一次 = 仍不知道结构上什么出问题。**剔除，穿透到内在的因**：

```
诊断量 bleed_k = 每个 H¹_k 操作是否有配对闭合转折节点 at level k
  孤儿(k) = 在转折节点 X（级别 k 卖点）开 H¹_k 空腿，但级别 k 上无配对闭合转折节点 Y（买点）
          = ¬可操作(k) = L_confirm(k) ≻ L_move(k) ∨ d_k=Up（L_confirm 发散）
  bleed_k = 级别 k 上孤儿空腿计数 = 未闭合转折节点对计数 at level k
```

**纯操作语义量，零 bar/价格/强平/z**：
- 「持仓 10 万 bar」=「无闭合转折节点（L_confirm 发散）」的外在代理 → 剔除，用 ¬可操作。
- 「强平 2×basis 够不到」=「缺结构出场、外在价格兜底失效」的外在症状 → 剔除，用孤儿（无配对闭合）。
- 「z≈100% 相关」=「孤儿空腿浮亏到 eod」的统计代理 → 剔除，用未闭合转折节点对计数。

### 4.2 逐级指认（哪级哪条腿孤儿、因哪级 d_k 错）

诊断量逐级指认两类失血（实现编排者硬约束2"知道什么出问题"）：

```
(a) 哪级 H¹_k 开了孤儿空腿：
    级别 k 实际 d_k=Up（R+）却开 H¹_k 空腿 ⇒ 永无平空买卖点 ⇒ L_confirm=∞ ⇒ ≻ ⇒ 孤儿
    根因 = 该级 d_k 读错（用塔顶单一 top_trend_dir 代理了级别 k 的方向，但级别 k 实际 d_k≠塔顶）
    （子2 §3.3：单一 top_trend_dir 拍扁的失血形态 = 高级别空腿建主升浪，与僵尸 100% 重合）

(b) 哪级 H⁰_k 骑错方向：
    d_k 与持仓方向不符（如 H⁰_k=Long 但 d_k=Down 真下跌，核心未减仓扛跌）
    根因 = 核心减仓未由 type1 背驰确认触发（子94 δ 连续条件未执行）
```

**子9 对角线 case（纳入，区分两类 α*→0）**：子9 生成函数 G 吐出对角线 case（L_confirm = L_move）——腿闭合但捕获→0（no-op，开≈不开）。诊断量须区分：
- **孤儿失血**（L_confirm ≻ L_move，腿不闭合）：开了就亏 ⇒ 诊断方向 d_k（是否 d_k=Up 误开）。
- **对角线退化**（L_confirm = L_move，腿闭合但捕获→0）：开≈不开 ⇒ 诊断确认余量（L_confirm 是否恰好赶上无余量）。
- 两者都该 α*→0 但内在因不同（孤儿要诊断方向，对角线要诊断确认余量）。

### 4.3 诊断层统一（d_k 错 → 孤儿 → α*_k 应→0）

三分量在诊断层统一（骨架§一零件2 结论 + 子9 §2 末）：

```
d_k 错（方向分量误读）
  ⇒ 级别 k 实际 R+，永不产生平空的配对买卖点
  ⇒ L_confirm 发散（确认级别不可达）
  ⇒ ≻ L_move ⇒ 不可操作 ⇒ 孤儿（可操作性轴 G 失败）
  ⇒ 该级 α*_k 应→0 不开 H¹_k（配额分量应读出"不开"）
```

**方向错是不可操作的一个极端实例（L_confirm 发散），不是独立失血机制**（子9 §2 末）。诊断量 bleed_k = 可操作性判据的否定的逐级实例化。**内在的修 = 不开孤儿腿**（仅 d_k=Down ∧ L_confirm ⪯ L_move 时开 H¹_k），同源「孤儿不可能定理」——不是调强平线/bar 阈值（外在），是修 d_k 读出（逐级 d_k 向量，子2/子5）使配对闭合转折节点存在。

## 五、三分量同源（配额分量侧，骨架§二统一推导链）

骨架§二要求证「d_k（方向）、角色 H⁰/H¹、α*_k（配额）三者同源 = 同一套级别量的不同读法」。本任务负责**配额分量 α*_k 侧**的同源证（方向 d_k = 子2 已证 / 角色 = #80+子2 链接已证）。

**同源命题**：三分量都从**同一个节点纤维 (E_k, F_k, R_k)** 在仓位侧读出（骨架§二）：

```
对每个涌现级别 k，从节点纤维读三个仓位侧分量：
  1. d_k       ← R_k 方向极性 + 级别 k 末走势方向         [子2=方向分量]
  2. 角色H⁰/H¹ ← k 在塔中位置：骑本级=H⁰ / 操作次级 k-1=H¹  [#80+子2=角色分量]
  3. α*_k      ← (L_pullback(k)=d_top 深浅, L_confirm(k)=区间套确认级别)  [本任务=配额分量]
```

**配额分量侧同源证（本任务交付，三步）**：

1. **α*_k 和 d_k 共享同一份走势**：α*_k 读 `tree.levels[k]` 的 d_top/区间套链（L_pullback/L_confirm）；d_k 读 `tree.levels[k].trends.last().direction`（子2 §3.1）。**二者都从同一级 `tree.levels[k]` 读出**，只是读不同字段（回调级别+确认级别 vs 方向）。⇒ 同源。

2. **α*_k 和角色共享同一份走势**：角色 H⁰_k = 骑级别 k 末走势的核心（#80 §2.2）；α*_k = 操作级别 k 回调需分多少机动仓（H¹_k 预算）。**二者都关于级别 k 的走势**——角色读「是否骑」，α*_k 读「操作它需多少机动」。⇒ 同源。

3. **同源 vs 拍扁的对应（核心洞察，与子2 方向轴侧对称）**：
   - 配额轴拍扁 = 固定 2/3⊕1/3（只读塔顶 α，#80 §5.4）。
   - 方向轴拍扁 = 单一 top_trend_dir（只读塔顶 d_{r*}，子2 §3.3）。
   - 涌现轴拍扁 = 离散二值（只读阈值 δ*，子94）。
   - **三个拍扁同构**（都是「只读塔顶一格/单值，丢中间级别」），因为 α*_k、d_k、δ_k 同源（读同一套级别量）。⇒ **反拍扁也同构**：逐级 α*_k（本任务）+ 逐级 d_k（子2）+ δ 连续轴（子94）是同一个「读全纤维」操作的三个轴。这是「三分量同源、非三独立 patch」的配额轴侧构造性根据。**□**

**健全层同源（与子6 直和衔接）**：α*_k = 机动 H¹_k 的预算比例（子6 §5.4）——机动在 (α*_k·u_p) 这个 H¹ 预算内对称循环（直和①的 H¹ 分量大小）。α*_k 越大=H¹ 预算越大=机动循环空间越大；α*_k→0=退化为纯核心（匹配 BH，O6 no-hedge 退化解=α*_k≡0 特例）。α*_k 与直和同源：直和给"机动不碰核心"（操作形式），α*_k 给"机动预算多大"（尺度）。**健全不是第四个独立 patch（anchor 退场），是三分量正确读出 + 直和的结构后果。**

塔的操作语义层 = 三层内在读出（全从级别结构+买卖点+区间套生成，零外部阈值）：**①可操作性布尔前驱**（H¹_k 该不该激活 ⟺ d_k=Down ∧ L_confirm⪯L_move = 非孤儿，子9 充要判据，替代外在 574/强平/z）；**②配额量** α*_k=α*(L_pullback,L_confirm)（激活后配多少机动，纳入零件1 v3，两自变量是级别尺度内部读数=自相似 λ 级差非外部绝对阈值，禁 θ 振幅门）；**③核心减仓连续条件**（核心 H⁰_k 减仓 ⟺ type1 背驰确认 via 区间套定位 δ，全级别自相似，非"无更高级别"离散 if，子94）。**split 自适应定理**（L0）：纯牛（∀k:L_pullback 低∨L_confirm 高）→全留 H⁰=核心 full=匹配 BH（消 drag）；结构化（∃k:L_pullback 高∧L_confirm 低∧d_k=Down∧L_confirm⪯L_move）→该级 H¹ 激活=超 BH；0/8 超 BH=固定 split 拍扁（丢 L_pullback/L_confirm/d_k 三读数，与方向 d_k 拍扁/涌现 δ 拍扁三轴合流）。**孤儿诊断量 bleed_k**（纯内在零外在量）=每级 H¹_k 是否有配对闭合转折节点（孤儿=未闭合转折节点对计数=L_confirm≻L_move∨d_k=Up），逐级指认哪级 H¹_k 孤儿（因 d_k 读错）/哪级 H⁰_k 骑错方向，剔除 bar/价格/强平/z 外在代理。**三分量同源**（α*_k 和 d_k/角色读同一份 tree.levels[k] 不同字段，反拍扁=三轴「读全纤维」）+ **诊断层统一**（d_k 错→L_confirm 发散→孤儿→α*_k 应→0）。

1. **α*_k 和可操作性 G 是否真两层（布尔前驱 + 量），还是 α*_k=0 已蕴含不可操作？** 子9 称可操作性是 α*_k>0 的必要非充分前驱（α*_k 可因 L_pullback 浅而→0 即使可操作）。质询：「可操作但 α*→0」（对角线/浅回调）与「不可操作 α*→0」（孤儿）在配额输出上都是 α*_k→0——两层在输出端塌成同一个 α*_k→0，是否「两层」只是诊断时的区分而非配额读出的区分？若配额读出不需要先判可操作性（直接 α*(L_pullback,L_confirm) 算出→0），G 是否冗余于 α*？
