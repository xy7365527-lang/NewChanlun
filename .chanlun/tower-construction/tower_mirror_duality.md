## 一、构造的出发点：走势类型的方向二元性（不是参数，是定义）

### 1.1 上涨走势 / 下跌走势 = 第17课走势分解的方向二值

第17课走势分解定理一（走势=中枢序列）+ 断言U（顺势/逆势两角色）给出走势的**方向类型**是严格二值的：

> 一个级别 k 的走势 r* 要么是**上涨走势 R+**（中枢依次抬高，方向 d_k=Up），要么是**下跌走势 R−**（中枢依次降低，方向 d_k=Down）。盘整不是趋势走势（无方向类型，是 H¹ 振荡的底空间 S¹ 本身，#80 §1.2）。

这给我们构造 τ 的**唯一不可协商的事实**：走势类型空间在方向轴上是 **Z₂ = {R+, R−}**——只有两个元素，且二者由"方向反转"互相生成。这不是我们选了 Z₂，是走势方向类型**本身**只有两个值（Direction enum 在 `types.rs:15-18` 逐字实装为二元 `{Up, Down}`，`flip` 在 20-28 行是其唯一非平凡自同构）。

### 1.2 镜像 = 走势方向反转（缠论内在对称，非外部赋予）

为什么 R+ 与 R− 互为镜像？**这是从走势定义构造出来的，不是类比**：

- 上涨走势 R+ 的中枢序列 [ZD_i, ZG_i] 依次抬高（中心定理二，`center.rs`）。把价格轴做**反射**（p ↦ −p，或等价地把所有 ≥ 换成 ≤、max 换成 min），则"依次抬高"变成"依次降低"——R+ 的镜像**恰好**是 R−。
- 中枢定义 ZD=max(d₁,d₂,d₃)、ZG=min(g₁,g₂,g₃)（`center.rs:55-58`）在价格反射下 max↔min 互换，ZD↔ZG 互换——中枢这个对象**在镜像下封闭**（仍是合法中枢，只是上下沿互换）。
- ⇒ 价格反射 = 把上涨走势的全套结构（中枢序列 + 买卖点 + 区间套）整体搬到下跌走势，**结构同构、方向相反**。这就是镜像 τ 的几何来源。

**形式化**：定义镜像作用 τ 为"价格轴反射诱导的走势类型空间自映射"。在方向轴上 τ: Up↔Down（= `Direction::flip`）。下面证它提升为整个仓位上同调单元的 Z₂ 作用。

### 1.3 Z₂ 群（τ²=id 的代数事实）

镜像 τ 满足 **τ²=id**（对合）——这是 Z₂ 群的定义性质，由价格反射的对合性直接得到：

```
τ²(p ↦ −p) = (p ↦ −(−p)) = (p ↦ p) = id        [价格反射两次=恒等]
τ²: Up → Down → Up = id                          [Direction::flip 两次=id，types.rs:22-27]
τ²: Long → Short → Long = id                     [flip_pol 两次=id，rec_engine.rs:425-429]
```

⇒ **群 ⟨τ | τ²=id⟩ = Z₂**。这是塔的横向对称群（与纵向的级别平移 k↦k+1 正交，见 §5.2）。实装锚点：`flip_pol`（`rec_engine.rs:425-429`）是 Polarity 上的对合，`Direction::flip`（`types.rs:22-27`）是 Direction 上的对合——二者就是 τ 在两个表示上的矩阵，皆 τ²=id。

## 二、τ 的精确定义：作用于上同调单元 (H⁰_k, H¹_k)

### 2.1 τ 翻转什么、保持什么（逐分量定义）

τ 作用于级别 k 的上同调单元 V_k = H⁰_k ⊕ H¹_k（#80 §4）。**τ 不是一个标量翻转，是一个同时作用于多个分量的群元**。逐分量定义：

| 量 | τ 下的变换 | 本征值 | 实装锚点 | 推导依据 |
|----|-----------|--------|---------|---------|
| **级别 k** | k ↦ k（不变） | +1 | `level` 字段不动 | 镜像是横向（方向）对称，不动纵向（级别）结构 §1.2 |
| **方向 d_k** | Up ↔ Down | −1 | `Direction::flip` (`types.rs:22`) | 走势类型方向反转 §1.1 |
| **仓位极性 pol** | Long ↔ Short | −1 | `flip_pol` (`rec_engine.rs:425`) | dir_to_polarity 同态下方向翻转诱导极性翻转 §2.2 |
| **价格不等式向** | ≥ ↔ ≤，max ↔ min | −1 | ZD=max↔ZG=min (`center.rs:55-58`) | 价格反射 §1.2 |
| **H⁰/H¹ 角色分配** | 核心仍核心、机动仍机动（位置不变，方向翻） | +1（位置） | anchor 语义不动 | τ 不改"谁是核心"，只改核心的方向 §2.3 |
| **配额 α*_k** | α*_k ↦ α*_k（不变） | +1 | MOBILE_FRAC / α*(L_pullback,L_confirm) 不动 | 配额是级别结构标量，对方向反射不变 §2.4 |
| **区间套深度链** | 链结构不变，逐级方向翻 | +1（结构）/ −1（方向） | 第27课区间套链 (`rec_engine.rs:113-121`) | 区间套是级别嵌套，深度对镜像不变 §2.4 |

**核心区分（编排者硬约束"翻什么/保持什么"的精确回答）**：
- τ 翻转的是**方向类**（d_k / 极性 / 不等式向）——三者**绑定同步翻转**（不能只翻一个，§2.2 证同态）。
- τ 保持的是**结构类**（级别 / 配额 / 区间套深度 / 核心-机动的角色位置）——这些是方向无关的不变量。

### 2.2 方向类三量绑定翻转（τ 是良定义群作用的关键）

**命题**：d_k、仓位极性 pol、价格不等式向**必须同步翻转**，否则 τ 不是良定义的群作用（会产生 R+ 结构配 R− 方向的非法杂合态）。

**证明（从 dir_to_polarity 同态）**：
1. `dir_to_polarity`（`rec_engine.rs:417-421`）是同态 φ: Direction→Polarity，φ(Up)=Long, φ(Down)=Short。
2. τ 在 Direction 上是 flip_D，在 Polarity 上是 flip_pol。同态相容要求 φ∘flip_D = flip_pol∘φ：
   - φ(flip_D(Up)) = φ(Down) = Short；flip_pol(φ(Up)) = flip_pol(Long) = Short ✓
   - φ(flip_D(Down)) = φ(Up) = Long；flip_pol(φ(Down)) = flip_pol(Short) = Long ✓
3. ⇒ **τ∘φ = φ∘τ**（τ 与方向→极性同态交换）。这意味着"先翻方向再读极性 = 先读极性再翻极性"——两者绑定。
4. 价格不等式向：pnl 公式 `Long: m(c−basis) / Short: m(basis−c)`（`rec_engine.rs:457-458`）在 Long↔Short 下 (c−basis)↔(basis−c) 即价格差反号——极性翻转**强制**不等式向翻转，否则 pnl 会计错误。**□**

⇒ 方向三量是**一个 −1 本征子空间**（同步翻），不是三个独立翻转。实装中 `flip_pol` + pnl 双重会计已经把这个绑定写死（Long/Short 分支镜像对称）——τ 协变性在 NAV 中性会计层已 present-by-construction。

### 2.3 H⁰/H¹ 角色在 τ 下不变（核心还是核心，机动还是机动）

**命题**：τ 不交换 H⁰_k 与 H¹_k——核心经 τ 仍是核心（只是方向翻），机动经 τ 仍是机动（只是方向翻）。

**证明（从上同调维度）**：
1. H⁰_k = 0维不变量截面（绕 S¹ 相位不变），H¹_k = 1维循环类（绕 S¹ 一周），#80 §2-3。
2. τ 是价格反射，作用在 S¹ 上是一个**对径/反射同胚** S¹→S¹。反射诱导的上同调映射 τ*: H*(S¹)→H*(S¹)。
3. 上同调映射**保持维度**（H⁰ 映到 H⁰，H¹ 映到 H¹——同调维数是同伦不变量，反射是同胚不改维数）。⇒ τ*(H⁰)=H⁰，τ*(H¹)=H¹。
4. ⇒ τ 在 H⁰/H¹ 角色位置上是 +1 本征（不交换），只在每个分量内部翻方向。**□**

**操作语义对应**：
- H⁰_k（核心）在 R+ 下是 long（骑涨），τ 后在 R− 下是 short（骑跌）——**仍是核心**（绕环不变量份额），只是骑的方向反了。实装 anchor=核心整仓的语义（`rec_engine.rs:512-516`）在 τ 下不变（anchor 量不变，只 direction 翻）。
- H¹_k（机动）在 R+ 下是 short 回调腿（在 r*-1 下跌段做空），τ 后在 R− 下是 long 反弹腿（在 r*-1 上涨段做多）——**仍是机动**（绕环循环份额），只是循环方向反了。

这正是 memory O6 正解的镜像对：R+ 机动=做空回调（r*上涨的r*-1下跌段），R− 机动=做多反弹（r*下跌的r*-1上涨段）。

### 2.4 配额 / 区间套深度在 τ 下不变（结构标量对方向对称）

**命题**：配额 α*_k = α*(L_pullback, L_confirm)（#80 §4.3 / 骨架零件1）在 τ 下不变。

**证明**：
1. L_pullback（次级别回调级别）、L_confirm（区间套确认级别）都是**级别量**（嵌套深度），不是方向量。
2. 价格反射不改变级别嵌套结构（k 级中枢由 k-1 级走势重叠定，重叠关系对价格反射不变——max/min 互换但"≥3段重叠成立"的逻辑不变，`center.rs:58`）。
3. ⇒ L_pullback、L_confirm 是 τ 不变量 ⇒ α*_k 是 τ 不变量。**□**

⇒ 配额是 τ 的 +1 本征。这给 §3"一套覆盖两向"一个关键支撑：**配额逻辑（子4 的 α* 函数体）只需写一次，R+/R− 共用**——不需要为做空腿单独调配额（单独调 = 破坏 τ 协变 = 失血根源，§4）。

## 三、镜像协变性证明 + 一套覆盖两向

### 3.1 协变性的精确陈述

设 Ops(R+) 是 R+ 配置下 H⁰_k⊕H¹_k 的全套操作语义（开/平/sink/recover/止损/会计），Ops(R−) 同理。**协变性命题**：

```
Ops(R−) = τ ∘ Ops(R+) ∘ τ⁻¹ = τ ∘ Ops(R+) ∘ τ        [因 τ⁻¹=τ，对合]
```

即：R− 的任一操作 = 把状态用 τ 搬到 R+ 视角、执行 R+ 操作、再用 τ 搬回。**等价说法**：操作语义对 τ 共轭不变（equivariant）。

### 3.2 逐操作验证（构造性，非断言）

对 H⁰_k⊕H¹_k 的每个操作原语，验证 τ-协变：

| 操作 | R+ 形式 | τ 作用后（应=R− 形式） | R− 直接形式 | 协变？ | 实装锚点 |
|------|---------|----------------------|-------------|--------|---------|
| **H⁰ 开仓** | 买点 fire → long 核心 | τ: 买点→卖点、long→short | 卖点 fire → short 核心 | ✓ | LegPair 开 `rec_engine.rs:571` |
| **H⁰ 平/翻** | k级type1卖点(顶背驰)→平多/翻空 | τ: type1卖→type1买、多→空 | k级type1买点(底背驰)→平空/翻多 | ✓ | d_top闸门 `rec_driver.rs:408` |
| **H¹ sink（机动开）** | k-1卖点→机动short回调腿 | τ: 卖→买、short→long | k-1买点→机动long反弹腿 | ✓ | sink/route_bsp `rec_engine.rs:1374` |
| **H¹ recover（机动平）** | k-1买点→平空回升 | τ: 买→卖、平空→平多 | k-1卖点→平多回落 | ✓ | recover `rec_engine.rs:1447` |
| **止损（否定线）** | 多腿 stop=进场ZD(跌破) | τ: ZD↔ZG、跌破↔涨破 | 空腿 stop=进场ZG(涨破) | ✓ | long_stop/short_stop `rec_engine.rs:585/591` |
| **pnl 会计** | long: m(c−basis) | τ: c−basis ↔ basis−c | short: m(basis−c) | ✓ | rec_reduce `rec_engine.rs:457-458` |
| **现金 free** | long 减仓 free+=mc | τ: += ↔ −= | short 减仓 free−=mc | ✓ | rec_reduce `rec_engine.rs:461-462` |

**每一行的 τ 作用列 = R− 直接形式列**——这就是协变性的逐项证明。关键：每个操作的 R− 形式都不是独立设计的，而是 R+ 形式经 τ（翻方向三量、保结构）机械生成的。**□**

### 3.3 一套覆盖两向（从协变性 + 对合推出）

**定理（一套覆盖两向）**：只需形式化 R+ 一向，R− = τ(R+) 完全确定，无信息损失、无需第二套代码。

**证明**：
1. τ 是 Z₂ 群作用（τ²=id，§1.3）⇒ τ 是双射（自身的逆）。
2. Ops 对 τ 共轭等变（§3.1-3.2）⇒ Ops(R−) = τ∘Ops(R+)∘τ 由 Ops(R+) 唯一确定。
3. 走势方向类型只有 {R+, R−} 两个元素（§1.1，Z₂ 穷尽）⇒ R+ 与其 τ 像 R− 覆盖全部方向类型，无第三向。
4. ∴ 形式化 R+ + 群作用 τ = 形式化全体。**□**

**实装形式（消除两段镜像硬编码，no-patch 核心交付）**：

当前实装是"两段镜像硬编码"的反面教材——long_units/long_basis/long_stop 与 short_units/short_basis/short_stop 是**两套平行字段**（`rec_engine.rs:579-598`），`enable_pair_core_short` 是**单独的 bear 分支**（`face_a` 注释 §5.2），`T_PAIR_SHORT_*`/`pair_short_entry` 是开空的**独立触发口径**（`rec_engine.rs:141-145`）。这是 τ 的影子被拆成两套——**违反 τ 协变的 present-by-construction**。

τ-协变的正确形式（一套）：

```
单一参数化腿 Leg{ level, pol: Polarity, units, basis, stop }     // 不分 long_*/short_*
操作 op(leg, signal, view):
    // 全部用 pol 参数化，R+/R− 共用同一函数体
    pnl = match leg.pol { Long: m(c−basis), Short: m(basis−c) }   // 已 τ-协变 (rec_engine.rs:457)
    stop = match leg.pol { Long: view.zd[k], Short: view.zg[k] }  // ZD/ZG 由 pol 选，τ-协变
    on bsp: open/close 由 (signal 极性 ⊗ leg.pol) 读出，无 if bear 分支

R− 配置 = τ(R+ 配置)：把 pol 全翻、ZD↔ZG、买卖点信号翻 —— 同一 op 函数自动给出 R− 行为
```

实装中 `flip_pol` + pnl 双重会计 + rec_add/rec_reduce 的 Long/Short 对称分支**已经是 τ-协变的原语**。τ-协变的 LegPair 应该是**单腿 + pol 参数 + 镜像信号读取**，而非 long/short 双字段 + bear 专属分支。把 bear 分支（`enable_pair_core_short`）写成 τ(bull 分支) 而非独立逻辑——这是反拍扁。

### 3.4 破坏 τ 协变 = 失血根源（与 539/#567 咬合，L3 锚点）

**命题（τ 协变是失血诊断的形式根据）**：539号"做空腿 regime 失血"、#567"无界空腿"的根因 = **做空腿写成破坏 τ 协变的独立逻辑**。

推导（衔接骨架零件2"孤儿腿"诊断）：
1. τ 协变要求：R− 的机动 long 反弹腿 = τ(R+ 的机动 short 回调腿)。R+ 机动 short 回调腿由 k-1 卖点开、k-1 买点配对平（闭环 H¹，#80 §3.2）。
2. τ 像：R− 机动 long 反弹腿应由 k-1 买点开、k-1 卖点配对平——**配对闭合转折节点由 τ 自动给出**（τ 把 R+ 的配对结构搬过来）。
3. 若做空腿写成**独立逻辑**（不是 τ(做多腿)）：开空的触发（`pair_short_entry`=T3）与平空的触发口径**不再是 τ 配对**——开空用 t3sell，但没有 τ 对应的平空配对点 ⇒ **孤儿空腿**（骨架零件2：无配对闭合转折节点 = 失血）。
4. ⇒ 骨架零件2"孤儿腿=失血"的**形式根据 = τ 协变破坏**。"高级别逆势空腿死扛"（payoff-regime #75）= 在 R+ 级别（d_k=Up）开了不该开的空腿，且因非 τ 配对而无闭合点。
5. **内在的修 = 强制 τ 协变**：做空腿 = τ(做多腿)，开/平配对由 τ 镜像自动给出 ⇒ 无孤儿（每条 τ 生成的空腿继承做多腿的配对闭合结构）。这与骨架"内在的修=不开孤儿腿（仅 d_k 正确时开 H¹_k）"一致——**τ 协变正是"d_k 正确"的群论形式**：只有当级别 k 真是 R−（d_k=Down）时，τ(R+机动) 才生成合法的 R− 机动空腿；级别 k 是 R+ 时强行开空 = 非 τ 像 = 孤儿。**□**

**认识论诚实（formalization-validity-domain）**：τ 协变是 **L0**（群作用形式）。"强制 τ 协变 ⇒ 失血实际溶解到净收益改善"是 **L3 未决**（继承 539/#567/骨架；payoff-regime L3 显示 OKLO 有下跌段空腿赚 = G 轴 regime 函数）。本号给失血的**结构形式根据**（τ 协变破坏），**不声明**强制 τ 协变就能预测净收益改善（那是子4 payoff + L3 回测的事）。**不声明膨胀。**

## 四、镜像下的孤儿诊断对偶（编排者要求的第三件）

### 4.1 孤儿空腿 ↔ 孤儿多腿（τ 对偶）

τ 协变给孤儿诊断一个**对偶对**：

| | R+ 配置（d_k=Up） | τ → R− 配置（d_k=Down） |
|---|---|---|
| **合法机动** | H¹ short 回调腿（机动做空 k-1 下跌段，有 k-1 买点配对平） | H¹ long 反弹腿（机动做多 k-1 上涨段，有 k-1 卖点配对平） |
| **孤儿（失血）** | **孤儿空腿**：机动 short 了非回调（在 R+ 主升浪逆势裸空，无配对买点平 = 死扛） | **孤儿多腿**：机动 long 了非反弹（在 R− 主跌浪逆势裸多，无配对卖点平 = 死扛） |
| **孤儿根因** | d_k 读错：级别 k 实为 R+ 却开了"R− 才合法"的逆势空腿 | d_k 读错：级别 k 实为 R− 却开了"R+ 才合法"的逆势多腿 |

**对偶性（τ 把一种孤儿映到另一种）**：τ(孤儿空腿 in R+) = 孤儿多腿 in R−。二者是**同一个 d_k 读错病理在镜像两侧的表现**——不是两个独立 bug。这正是骨架§三对偶表"诊断：哪级 H¹ 错 d_k"的 Z₂ 镜像展开。

### 4.2 孤儿不可能定理的 τ 形式（与 isolated_fugue_forest_verdict 咬合）

memory `project_isolated_fugue_forest_verdict`「孤儿不可能定理」（已结算 L3）：父仅经后序 close_voice 关闭 ⇒ 子必先关 ⇒ 无孤儿。

τ 形式：**孤儿不可能 = τ 协变保证配对闭合**。
- R+ 下：每条 H¹ short 回调腿由 k-1 卖点开、k-1 买点闭（配对在 #80 §3.2 的"绕环一圈 ∮"循环里，闭环 by construction）。
- τ 像（R−）：每条 H¹ long 反弹腿由 k-1 买点开、k-1 卖点闭——**配对结构 = τ(R+ 配对结构)**，闭环自动继承。
- ⇒ 只要做空腿 = τ(做多腿)（τ 协变），孤儿不可能定理在镜像两侧同时成立。**破坏 τ 协变（独立空腿逻辑）= 引入 τ 不像的孤儿 = 违反孤儿不可能定理 = 失血。**

⇒ 孤儿诊断量（骨架零件2 的 bleed_k）的**镜像对称形式**：bleed_k = "H¹_k 操作是否是 τ(合法 R+ 机动) / τ(合法 R− 机动)"——是 τ 像则有配对闭合（不失血），非 τ 像则孤儿（失血）。零外在量（bar/价格/强平/z），纯 τ 协变判别。

## 五、与 576号 E⊗F 的关系：同一个 τ 的两个切面

### 5.1 D∞ 群结构回顾（576号 + #39）

576号节点轴 + #39 给出走势发展的对称群是**无限二面体群 D∞**：

### 5.2 本号 Z₂ = D∞ 的反射子群 ⟨τ⟩

**命题**：本仓位轴的镜像 Z₂ = ⟨τ⟩ 是 D∞ 的反射子群——**不是独立的新 Z₂，是同一个 τ**。

**证明**：

3. ⇒ 本号 Z₂ = D∞|_{σ=id} = ⟨τ⟩。**同一个手性反射 τ**，限制在单级别仓位纤维上。**□**

### 5.3 同一个 τ 的两个切面（节点轴 / 仓位轴）

τ 是 D∞ 的一个群元，作用在不同空间给不同切面：

| τ 作用对象 | 切面 | 谱系 | τ 的具体形式 |
|-----------|------|------|-------------|
| **节点空间**（转折节点 E⊗F） | 节点轴 | 576号 | 买卖点手性翻转：type1 买点 ↔ type1 卖点（顶背驰↔底背驰）；E 轴拓扑事件镜像（离开向上↔离开向下） |
| **仓位纤维**（H⁰_k⊕H¹_k） | 仓位轴 | 本号 #81 | 极性翻转：R+(核心long/机动short) ↔ R−(核心short/机动long) |

**咬合机制（同一 τ 在两轴交换）**：节点轴的 τ（买点↔卖点）触发仓位轴的 τ（long↔short）——因为买卖点是 H⁰→H¹ 操作触发接口（574号）。具体：
- 节点轴 τ: type1 卖点（顶背驰，E2离开×F衰竭，R+ 走势完成）↔ type1 买点（底背驰，R− 走势完成）。

- ⇒ **节点轴 τ ∘ 触发接口 = 触发接口 ∘ 仓位轴 τ**（τ 与 #80 §6.2 的咬合机制交换）——这是"同一个 τ"的精确含义：两轴的 τ 经触发接口共轭相等。

### 5.4 为什么是 Z₂ 而非更大群（穷尽性）

走势方向类型 = {R+, R−} 二值（§1.1）⇒ 横向对称恰好 Z₂，无更大群。区别于纵向：纵向是 σ 的 ℤ 平移（级别无上界 r*，可涌现升级）⇒ 纵向是 ℤ（σ^∞）。横向（方向）× 纵向（级别）= Z₂ ⋊ ℤ = D∞（半直积，因 τστ=σ⁻¹ 非直积——反射翻转平移方向）。

⇒ **本号 Z₂（横向方向对称）⋊ 子2 的 σ 级别平移（纵向）= 576号 D∞**。本号交付横向因子 Z₂=⟨τ⟩，子2 交付纵向因子 ⟨σ⟩，二者半直积重构整个 D∞ 节点对称群。三分量同源（骨架§二）在群论层 = d_k(方向，τ 的 −1 本征)/角色(H⁰/H¹，τ 的 +1 本征)/α*_k(配额，τ 的 +1 本征)同属一个 τ 的本征分解。

## 七、结果包六要素

### 1. 结论
镜像对偶 τ = Z₂ 群作用（τ²=id），由"上涨/下跌走势互为价格反射"定义生成。**τ 翻转方向三量**（d_k Up↔Down / 极性 Long↔Short / 价格不等式向 ≥↔≤，三者经 dir_to_polarity 同态绑定同步翻，−1 本征）、**保持结构类**（级别 k / 配额 α*_k / 区间套深度 / H⁰-H¹ 角色位置，+1 本征）。操作语义对 τ 共轭等变（逐操作验证 §3.2）⇒ **只需形式化 R+，R−=τ(R+) 唯一生成**（消除 long_*/short_* 两段镜像硬编码）。本号 Z₂=⟨τ⟩ 是 576号 D∞ 的反射子群（D∞|_{σ=id}），与节点轴 τ 是**同一个手性反射的两个切面**（节点轴买点↔卖点 诱导 仓位轴 long↔short）。孤儿空腿(R+)↔孤儿多腿(R−) 是同一 d_k 读错病理的 τ 镜像；强制 τ 协变 ⇒ 配对闭合自动继承 ⇒ 孤儿不可能（失血结构根因）。

### 2. 定义依据
- **走势方向二值**：第17课走势分解定理一 + 断言U（顺/逆两角色）；`types.rs:15-18` Direction enum 二元。
- **镜像=价格反射**：中枢 ZD=max/ZG=min（`center.rs:55-58`）在反射下封闭（max↔min 互换）。
- **τ²=id**：`flip_pol`（`rec_engine.rs:425-429`）/`Direction::flip`（`types.rs:22-27`）对合。
- **方向三量绑定**：`dir_to_polarity`（`rec_engine.rs:417-421`）同态 + pnl 双重会计（457-458）。
- **协变原语已实装**：rec_reduce/rec_add Long/Short 镜像分支（455-490）。
- **D∞**：576号（E⊗F + D∞ τσ）+ #39（D∞ Burnside）+ 574号（type1=τ）。
- **#80**：H⁰_k/H¹_k 单元（τ 作用对象）；O6 正解机动镜像对。

### 3. 边界条件（结论翻转）
- 若走势方向类型**非二值**（存在第三方向类型，如"中性趋势"）⇒ 横向对称非 Z₂，τ²=id 失效（当前第17课走势严格二值 {上涨,下跌}，盘整非趋势走势=无方向类型，无反例）。
- 若价格反射**不保中枢**（某结构使 max↔min 反射后非合法中枢）⇒ τ 非走势类型自映射，镜像不封闭（当前 ZD=max/ZG=min 对称，封闭）。
- 若 H⁰/H¹ 角色在 τ 下**交换**（核心经镜像变机动）⇒ §2.3 上同调保维翻转，τ 不是单纯方向翻（当前反射保上同调维数，角色位置不变）。
- 若方向三量**可独立翻转**（极性翻而方向不翻）⇒ dir_to_polarity 同态相容破坏，产生非法杂合态（当前同态强制绑定）。
- 若配额 α*_k **依赖方向**（做空腿需单独配额）⇒ §2.4 配额 τ 不变翻转，"一套覆盖两向"对配额失效（当前 α* 是级别量，方向无关；做空腿单独配额=破坏 τ 协变=失血）。

1. **τ 是构造还是命名？** §1.2 用"价格反射诱导走势类型自映射 + 中枢 max↔min 封闭"构造 τ。质询：是否存在走势结构使价格反射后**非合法走势**（如不对称的中枢形成规则），使 τ 不是走势类型空间的自映射？
2. **方向三量绑定（§2.2）是否真必然？** 质询：dir_to_polarity 是 Up↦Long 的**约定**（也可 Up↦Short）。若约定不同，同态相容是否仍强制三量绑定，还是绑定依赖这个约定？τ 协变是否对 dir_to_polarity 的具体约定鲁棒？
3. **H⁰/H¹ 角色 τ 不变（§2.3）的上同调论证** 质询：反射诱导的 τ*: H¹(S¹)→H¹(S¹) 是否真是 +id？反射对 H¹ 生成元的作用可能是 −1（反射改变定向）——若 τ*|_{H¹}=−1，"机动还是机动"是否仍成立（−1 是方向翻，仍同分量；但需确认不是映到 H⁰）？
4. **一套覆盖两向（§3.3）vs 涌现非对称** 质询：牛市/熊市在真实市场**非对称**（涨缓跌急，波动率 regime 不同）。τ 协变是**形态**对称（L0），但 payoff 非对称（L3）。声明"一套覆盖两向"是否偷渡了 payoff 对称（声明膨胀）？§6 已分层声明只覆盖形态——质询此分层是否守住。
5. **本号 Z₂ = D∞ 反射子群（§5.2）的半直积** 质询：τστ=σ⁻¹（反射翻转平移方向）在仓位轴的具体含义是什么？τ（方向翻）后 σ（级别升）的方向是否真反转？若不反转，则是直积 Z₂×ℤ 而非半直积 D∞——这会与 576号 D∞ 冲突（需子2 验证）。
6. **孤儿对偶（§4）vs 实装 pair_short_entry** 质询：实装 `pair_short_entry`=T3（开空用 t3sell）而开多用 buy——这**本身就是非 τ 对称的触发口径**（T3≠τ(buy)）。是否意味着当前实装的做空腿**结构上就是孤儿**（非 τ 像）？这是 §3.4 的实装证据还是反例？
