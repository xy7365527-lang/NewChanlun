## ★★★ 最高约束：生成性完备判据（编排者方法论纠正 2026-06-25，凌驾所有其它要求）

**根问题（编排者诊断，命中本塔形式化的元层缺陷）**：之前两轮（anchor 死扣 → 直和+涌现条件化）都是**被编排者指出 case 后才补**。"核心在 r* 顶部"（真顶减仓）这个 case 是被指出的，不是构造**吐出**的。**矛盾（印钞机）和漏掉的 case（真顶）是同一症状 = 分类没被构造**——这是 090号声明膨胀在分类层（声称"由构造完备"实际打补丁，有效域 < 定义域，formalization-validity-domain）。

**完备性判据（硬约束，加到塔的形式化，所有子任务遵守）**：
1. **构造必须生成所有 case 作为递归定义的必然**——像 E⊗F 从"中枢:=次级别走势重叠"+D∞ Burnside 推导出每个轨道。**不是先有结构再补 case，是构造吐出 case。**
2. **检验 = 构造能否生成一个编排者还没指出的 case**。如果还需要被指出 case，构造就不完备。
3. **r* 顶部边界 + 涌现两子情况（涌现 r*+1=回调 / 无更高级别=真顶）+ 直和无印钞机** 必须**从递归定义被推导生成**，不是事后补的节点。
4. **塔的自检（#85 审查）必须枚举**："这个构造会漏掉哪些 case？枚举构造未覆盖的 (转折节点 × 级别 × 方向 × 涌现状态) 组合"——漏掉的就是构造不完备的证据，回去推导，不是补丁。

**生成性 vs 断言性的判定标准**（每个子任务自检）：

## 〇bis、塔的构造性健全条件 — 直和 by construction + 涌现条件化核心减仓（编排者纠正：撤死扣 anchor）

**★编排者纠正（2026-06-25，撤上一版"死扣 anchor"硬约束）**：死扣 anchor（固定 2/3 死扣）**也是拍扁**——处理不了"r* 出下跌走势但无更高级别"（=真顶，死扣=扛跌爆亏）。健全条件不是 anchor 死扣守恒，是**直和 by construction + 涌现条件化核心减仓**。

**矛盾（escalate-o6-report-data-fabrication-and-unbounded-short，o6-finalize #74 实测坐实）**：
**"核心不减"无条件假设 → 印钞机**。主动 hedge 版（核心不减 realized=0 + 开空腿 + recover 归还核心）→ 核心**无条件**不减 ⇒ quota 配额基恒定 ⇒ 每 sink→recover 循环净增核心 give = 指数膨胀 → CL ON −1165404%。**矛盾的根 = "核心不减"被当作无条件**（σ-cap escalate 的"核心不减∧机动有界不可兼得"正源于此无条件假设）。

**解（两层，均纯内在）**：

**① 核心 H⁰_k 减仓 = type1 背驰 + 区间套确认深度（连续轴，非两分支）**：
```
核心 H⁰_k 减仓 ⟺ 级别 k 出现 type1 背驰（k 级走势完成）   [纯内在：type1 背驰，全级别自相似]
type1 背驰 → 区间套定位下沉看低级别（连续确认深度轴，下界 a0，全级别同一）：
  停中枢内（低级别未确认反转）⇒ 回调 ⇒ 核心重角色 H⁰_{k+1} 持有，k 级回调交 H¹_{k+1}（=涌现重读,子2）
  确认反转（低级别区间套确认下跌）⇒ 真顶 ⇒ 核心 H⁰_k 减仓（对称 sink↔recover）
```
**★编排者第二次纠正（撤"两分支"残留）**："等涌现" = "等 r* type1 背驰确认" = **同一件事**（顶部背驰产的 type1 正是触发 r*+1 涌现的东西）。回调-vs-真顶**不是离散二分（有/无更高级别）**，是**区间套确认深度的连续轴判定**（type1 背驰下沉看低级别：停中枢内=回调 / 确认反转=真顶）。"有更高级别接/无更高级别"二分措辞 = 残留假例外（把连续区间套确认深度切成两特殊分支），须统一为同一 type1+区间套机制。574=确认深度选择（内在操作）非"等涌现"的不可约墙；下界 a0=1bar 全级别同一非顶特例。
**关键（元判据：无边界例外）**：这对所有级别 k 同构——k=r*（最高级别）**不是特例**。最高级别**有** type1（l4_consoldn"恒不产type1"=流式前沿假象；顶部背驰产 type1）。所谓"真顶减仓"=type1 背驰在 k=r* 的**自相似实例**，与 k<r* 同构。**不写成"无更高级别"特殊 if 分支**（=假例外破坏完备性，编排者已证伪 Lead 此提法）。"核心不减"由 type1 背驰条件化（非无条件，故非印钞机；非死扣，故真顶不扛跌）。

**② 印钞机溶解 = H⁰⊕H¹ 直和 by construction（不需 anchor 外加守恒）**：
```
印钞机根 = 机动操作碰核心 units（sink 减核心 units 但 recover 归还 = 违反直和）
塔的直和 ⇒ 机动 H¹_k 在自己预算内循环（对称,不碰核心 units）+ 核心 H⁰_k 独立（持有/减仓由涌现①定）
```

**关键区分（no-workaround）**：σ-cap（held_core_equiv 封顶）是 workaround（escalate §五否决）；死扣 anchor 是另一种拍扁（真顶扛跌）；**直和 by construction + 涌现条件化减仓**是唯一非拍扁结构解（机动不碰核心=守恒 by 直和；核心减不减=涌现条件，非死扣非无条件）。
