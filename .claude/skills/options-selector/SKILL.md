# Options Selector — 缠论结构驱动的期权仓位构建

## 核心设计原则

**期权结构的三个 strike 全部落在缠论关键位置上。杠杆是结构派生变量，不是事前设定的目标值。仓位默认满。**

这不是对期权定价理论的修正，而是一个完全不同层次的设计：期权书讨论"给定市场是随机游走，怎么选 strike"；本 skill 的逻辑是"给定市场有缠论结构，怎么让 strike 对齐结构"。

## 建仓前四个必答问题

每次建仓前，必须从用户处获取四个缠论位置。缺任何一个，不建仓。

1. **当前级别缠论买/卖点在哪？** → 决定入场时机
2. **当前级别缠论止损位是多少？** → 卖 put strike（做多时）/ 卖 call strike（做空时）
3. **下一个更大级别的支撑/阻力结构在哪？** → 买低 put strike / 买高 call strike
4. **当前级别中枢上沿/下沿或结构立足点是多少？** → ITM call/put strike（验证 delta）

## Strike 映射规则

### 做多结构（买入方向）

| 腿 | Strike 来源 | 缠论含义 |
|---|---|---|
| 卖 put（收权利金） | 当前级别缠论止损位 | 买点失败位——跌到这里说明判断错了 |
| 买低 put（保护腿） | 下一个更大级别支撑 | 大级别结构破坏位——保护腿封顶"大级别崩溃"的损失 |
| 买 ITM call（方向腿） | 当前级别中枢上沿/结构立足点 | call strike 以上是利润区，strike 本身是结构性立足点 |

### 做空结构（卖出方向）

| 腿 | Strike 来源 | 缠论含义 |
|---|---|---|
| 买 ATM/ITM put（方向腿） | 当前价附近或结构立足点 | 主要获利工具 |
| 卖低 put（降成本） | 更大级别支撑位 | 目标区域——跌到这里收益封顶但概率最高 |
| 买更低 put（尾部保护，可选） | 更更大级别结构位 | 防止极端行情下卖出的 put 变成无限风险 |

### 纯方向做空（put spread）

| 腿 | Strike 来源 | 缠论含义 |
|---|---|---|
| 买 put | 当前级别卖点附近（ATM/slightly ITM） | 卖点确认后的方向腿 |
| 卖 put | 目标位或更大级别支撑位 | 到这里就够了——收益在这里封顶 |

## 派生杠杆

杠杆 = 名义敞口 / put 距离（卖 put strike - 买低 put strike）

**不事前设定杠杆目标。杠杆是结构决定的。**

- 缠论结构清晰紧凑 → put 距离小 → 杠杆高 → 自动重仓
- 缠论结构松散模糊 → put 距离大 → 杠杆低 → 自动轻仓
- 缠论结构找不到 → 不建仓

**市场结构本身就是风控。**

## Agent 职责（严格限定）

### 允许做的

1. 验证 ITM call/put strike 对应的 delta 在目标区间（call: 0.85-0.95, put 方向腿: 按用户指定）
2. 如 delta 不在区间，报告用户，要求重新选择结构位或放弃建仓
3. 计算派生杠杆
4. 查询 TWS 真实报价（bid/ask/IV/Greeks）
5. 生成完整订单参数（LMT 单，买 MID/BID，卖 MID/ASK）
6. 计算到期日（T_target_上限 + 30-60天 buffer，默认45天）

### 禁止做的

1. **自行选择 strike**（包括任何"优化"或"建议"）
2. **按杠杆目标倒推 strike**
3. **按 delta / IV / premium / 凸性标准选择 strike**
4. **在用户回答"找不到明确缠论位"时仍然生成订单**
5. **用 MKT 单**（绝对禁止）
6. **推断 T_target_上限**（必须用户提供）

## 安全阀

| 条件 | 动作 |
|---|---|
| 派生杠杆 > 20× | 警告：检查大级别支撑位判断是否把同级别小支撑当成了大级别 |
| 派生杠杆 < 3× | 建议：检查是否值得建仓（结构太散） |
| 用户无法回答任何一个缠论位置 | 拒绝生成订单 |
| ITM call delta < 0.85 | 报告：结构立足点太远，要求用户重选或放弃 |

## 到期日规则

到期日 = T_target_上限 + T_theta_buffer

- T_target_上限：用户给出的"走势最晚完成时间"区间上限（必须用户提供）
- T_theta_buffer：30-60 天，默认 45 天
- 事件驱动额外约束：到期日 ≥ 事件完成日 + 45 天，取较大者
- 禁止：到期日贴着事件完成日、到期日贴着 T_target_上限、用凸性最大化反推到期日

## Roll / Earning Contracts 机制

Roll 时重新询问用户当前的四个缠论位置，重新选择三个 strike。

- 不做单纯的时间延展式 roll
- Roll 是整个结构在新的缠论位置上的重建
- 降成本账户记录保持（net credit + 次级别 swing 差价）

## 订单规则

- 买入用 LMT：从 MID 往 BID 方向让 0.05-0.10
- 卖出用 LMT：从 MID 往 ASK 方向让 0.05-0.10
- **绝对禁止 MKT 单**
- 组合单（spread）用 LMT combo order，净价从 MID 让 0.05-0.15

## 责任分配

**用户（编排者）**：所有缠论判断——买卖点识别、止损位、大级别支撑、结构立足点。
**Agent**：翻译——把缠论判断翻译成期权订单参数，验证 delta 合规，报告派生杠杆。

Agent 不替用户做任何缠论判断。

## 输出格式

每次建仓输出：

```
## 缠论输入
- 买/卖点：[用户提供]
- 止损位：[用户提供] → 卖 put/call strike
- 大级别支撑/阻力：[用户提供] → 买低 put/高 call strike  
- 结构立足点：[用户提供] → ITM call/put strike

## 订单参数
- [腿1]: [strike] [类型] [到期] bid/ask/mid=[真实报价] delta=[值]
- [腿2]: ...
- [腿3]: ...

## 派生指标
- 杠杆：[X]×
- 最大亏损：$[值]
- 到期日：[日期] ([DTE]天 = T_target [N]天 + buffer [M]天)
- 安全阀状态：[通过/警告]
```
