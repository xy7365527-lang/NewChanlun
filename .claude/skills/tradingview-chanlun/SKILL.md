## Label格式解析

TV缠论指标的label文本格式：

**买卖点标注**：
- `" 1买 -4"` — 第一类买点，MACD面积-4
- `" 2卖 10"` — 第二类卖点，MACD面积10
- `" 1卖(趋势) 116"` — 趋势背驰一卖，MACD面积116
- `" 1卖(盘整) 0"` — 盘整背驰一卖
- `" 3买 -44"` — 第三类买点，MACD面积-44
- `" 2卖预期 53"` — 二卖预期（未确认）

**纯动能标注**：
- `"  106"` — 上升笔/段端点的MACD面积（正数=上升动能）
- `"  -50"` — 下降笔/段端点的MACD面积（负数=下降动能）

## 缠论核心概念（原文依据）

### 中枢（第17课）
至少三个连续次级别走势类型的价格重叠部分。
- 中枢区间 [ZD, ZG]：ZG = min(各段高点), ZD = max(各段低点)
- ZG > ZD 才构成有效中枢
- 中枢延伸：第四段及之后的走势仍在 [ZD, ZG] 内则中枢扩展
- 中枢破坏：走势突破 ZG 或跌破 ZD

### 走势类型
- **盘整**：含且仅含一个中枢的走势
- **趋势**：含至少两个同向中枢的走势（上涨趋势/下跌趋势）

### 背驰（第9课 + 第29课）
**趋势背驰**：趋势中最后一个中枢之后的走势段（C段）力度 < 该中枢之前的走势段（A段）力度。
- 力度度量：MACD柱面积
  - 上涨看正面积(area_pos)
  - 下跌看负面积绝对值(|area_neg|)
- **判定**：C段MACD面积 < A段MACD面积 → 背驰
- TV指标中：后一个同向label的数字 < 前一个同向label的数字 = 背驰

**盘整背驰**：盘整中当下同向离开段力度 < 前一次同向离开段力度。

### 买卖点（第29课）
- **第一类买点**：下跌趋势中，最后一个中枢之后的下跌段出现底背驰
- **第一类卖点**：上涨趋势中，最后一个中枢之后的上涨段出现顶背驰
- **第二类买点**：一买之后的上涨→回调不跌破一买低点
- **第二类卖点**：一卖之后的下跌→反弹不突破一卖高点
- **第三类买点**：中枢破位后的回调不跌回中枢区间
- **第三类卖点**：中枢跌破后的反弹不回到中枢区间

### 区间套（第27课）
从高级别到低级别逐级确认背驰，收缩精确转折点范围。
- 高级别背驰 → 确定C段区间 → 在C段内找低级别背驰 → 进一步缩小范围
- 区间套确认级别越多，转折点越精确

## TV指标设置（已结算）

基于缠论原文演化链（第62课→第77课→第81课→答疑）的结算结论：

| 设置项 | 选择 | 原文依据 |
|--------|------|---------|
| 笔模式 | **宽笔（新笔）** | 第81课答疑："那无所谓，只要是独立的就可以" |
| 特征序列包含 | **优化包含** | 第67课（非包含处理=标准特征序列）+ 第71课（同序列内滚动合并） |
| 特征序列延续 | **严格延续** | 第67课（有缺口必查第二特征序列）+ 第78课（硬约束） |

**概念结算**：只有两种笔——旧笔（第62课严版）和新笔（第81课宽版）。方向K线约束是推论不是额外约束。

## 标准看盘流程

### 单标的深度分析

1. **确认品种和周期**：调用 `chart_get_state`
2. **读取中枢结构**：调用 `data_get_pine_boxes` (verbose: true)
   - 按 bgColor 分类：872064120=线段级别，856729599=趋势级别
   - 找到最近的线段级别中枢 [ZD, ZG]
   - 找到最近的趋势级别中枢
3. **读取买卖点**：调用 `data_get_pine_labels` (max_labels: 100)
   - 解析label文本提取买卖点类型和MACD面积
   - 识别最近的买卖点
4. **读取实时报价**：调用 `quote_get`
   - 当前价相对最近中枢的位置（中枢内/上方/下方）
5. **背驰判定**：
   - 找到同方向相邻的两个动能标注
   - 后者 < 前者 = 背驰，计算背驰比(后/前×100%)
   - <50% = 强背驰，50-70% = 中背驰，70-100% = 弱背驰
6. **输出结构报告**

### 多标的扫描

1. 准备标的列表
2. 对每个标的：
   a. `chart_set_symbol` 切换
   b. `chart_set_timeframe` 切到日线("D")
   c. 等待数据加载
   d. 读boxes和labels
   e. 提取：最近买卖点、背驰强度、中枢位置
3. 汇总排序：按区间套确认级别 × 背驰强度排序

### 多周期区间套

1. 高级别分析：日线("D")读结构
2. 切换低级别：`chart_set_timeframe` 到 "240" 或 "60"
3. 在高级别背驰C段的时间范围内找低级别买卖点
4. 多级别同时出现同方向买卖点 = 区间套确认

## 结构阶段判定

| 阶段 | 条件 | 操作含义 |
|------|------|---------|
| 区间套趋势背驰 | 高级别趋势背驰+低级别确认 | 最高优先级信号 |
| 单级别趋势背驰 | 含≥2中枢，C段力竭 | 高概率转折 |
| 盘整背驰 | 含1中枢，离开段力竭 | 中等概率 |
| 中枢震荡 | 价格在中枢内 | 等待方向选择 |
| 中枢破位 | 价格突破ZG或跌破ZD | 新趋势可能开始 |

## 注意事项

- TV指标的MACD面积数字只作参考，严格背驰判定以NewChanlun引擎为准（方向性力度，非振幅力度）
- 两个同名Chan Theory指标实例是同一套逻辑，下面那个只是单独摘出某一层显示
- 缠论买卖点只在缠论卖点处退出——到期日的功能是为"等待卖点出现"提供时间空间
