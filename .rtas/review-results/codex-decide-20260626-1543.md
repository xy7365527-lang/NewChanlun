- C 的精确形状是：  
  `composeStep` total；  
  泛型 theorem 写成 `WindowComposable n xs → MovesComposedFrom xs n (composeStep n xs)`；  
  无此前提时，只允许证明 `UpperMoveSound` / canonical window 结构，不许声明 `WellFormed`。
- `canG := []` 不能用于完成 `WellFormed` 层。要证明 `WellFormed`，每个窗口必须带真实派生的非空 centers，并证明 `CenterDerivedAt` / `CentersDerivedFrom`。

禁止的 theorem 形状：

```lean
theorem composeStep_sound_all (n : Nat) (xs : ChanD n) :
  MovesComposedFrom xs n (composeStep n xs)
```

这是假的，因为任意 `xs` 不保证三段公共重叠，也不保证 lower moves 本身 WellFormed / level 正确。

允许的 theorem 形状：

```lean
theorem composeStep_sound_of_windowComposable
    (n : Nat) (xs : ChanD n)
    (h : WindowComposable n xs) :
    MovesComposedFrom xs n (composeStep n xs)
```

并且必须另给具体见证：

```lean
theorem xs9_movesComposedFrom :
  MovesComposedFrom xs9 0 uppers3
```

**(2) "≥3 个不同下级 witness"表述：选 W**

X/Y/Z 都不能单独作为绑定表述。

- X：三个不同 `segment` 只适合具体反退化例子，不适合作为通用语义。
- Y：`StrictlyIncreasing starts` 只说明多个上级窗口的起点有序，不说明每个上级内部有三段下级。
- Z：`CenterDerivedAt` 的 starts 是中枢派生起点，不是上级走势消费下级走势的 witness。
- W：正确 witness 是 `UpperMoveWitness` 的窗口位置语义：`w.len ≥ 3` + `windowSlice lowerMoves w` + `UpperMoveSound`。若要更强地证明 canonical 反退化，就固定 `len = 3` 和 starts `[0,3,6]`。
