## 裁定（2026-07-30，HITL 两轮 batch grill，用户逐轮拍板）

### 订正开票前提：**没有两型，是一条轴被硬切成两段**

开票时问的是「乙型合法吗，还是 #756 是漂移」。AFK 普查（31 张真 SPEC 票，报告见本票另一评论 / `.scratch/wayfinder-767/775-spec-taxonomy.md`）先把这个二选一推翻为三态（6 甲 / 13 乙 / 8 中间态），本轮再把三态归约掉：

- **「作废/被取代」那 3 张（#73、#258、#421）根本不在同一维度上**——它们说的是**票怎么死的**，不是 spec 交不交棒。把它当第三种形态，等于把「关票结局」混进了「形态」。剥离，不进本口径。
- 剥掉之后剩 5 张（自交付 #232/#304/#443，混合 #467/#526）**全部落在同一条轴上**：轴 = 下游实施票落在图里还是图外。自交付（0 张下游）→ 不出图（全在图内）→ 混合（两头都有）→ 出图（全在图外）。

**所以三成中间态不是第三种用途，是二分法在一条连续轴上留下的接缝。** 与 [#771](https://github.com/xy7365527-lang/NewChanlun/issues/771) 同构第二例：本仓实际用法是渐变的，二分是外部施加的。

### 五裁

**① 不设第三个类名，改按轴描述。** 「甲型/乙型」这对代号在正本里**整个去掉**——代号本身诱导二分类。正本只讲「出图 / 不出图」，中间点（自交付、混合）合法，按声明里更贴近的那句写。

**② 形态不是选出来的，是被图的实装声明决定的**——[#770](https://github.com/xy7365527-lang/NewChanlun/issues/770) 的直接推论，默认值由此**推导而来，不靠拍脑袋、也不按频率投票**：

- 图 Notes **没有**带实装声明 = 纯决策图 → 实装必须去图外 → spec **出图**，牵新实施票，首行写「本 spec 由 map #N 交棒而来，产新实施票」。
- 图 Notes **声明了**带实装 → 实装票留图里 → spec **不出图**，是实施总单，首行写「本 spec 是 map #N 的实施总单，实施票在图内」。

载体 = 声明制（首行一句话），不是判据制。判据（「看下游票在不在图的子票清单里」）只有**事后**才判得了，开票当下用不上。写反了会和图正面打架（同一批实装出现在两处），肉眼可见，**不设巡查/CI 硬门**——与 #770/#771/#772 同款。

**据此结案原问题①**：[#756](https://github.com/xy7365527-lang/NewChanlun/issues/756) **不是漂移**。#743 声明了带实装，它的 spec 只能不出图——这是必然推论，不是错误。反方在开票时的猜测被坐实。

**③ 溯源密度按「链有没有离开图」分，不按形态分。**

- 出图的 spec **必须逐条挂裁定票**（范本 [SPEC：交付纪律规范 #480](https://github.com/xy7365527-lang/NewChanlun/issues/480)）——链一旦断在图外就再也接不回来。
- 不出图的 spec 只要求首行 `Part of #N`，图本身即完整溯源链，逐条背书是冗余。

**据此结案原问题④**：#756 现在只在正文提票号、没逐条背书，**按此判据是合规的，不用补**。

**④ spec 是非持久件，关票判据 = 它指向的交付点全部落地。** 出图的等新票全关；不出图的等图内对应那批子票全关——**所以不出图的 spec 天然活不过它的图**。存量 3 张还开着的老 SPEC（[#169](https://github.com/xy7365527-lang/NewChanlun/issues/169)、[#485](https://github.com/xy7365527-lang/NewChanlun/issues/485)、[#620](https://github.com/xy7365527-lang/NewChanlun/issues/620)）按此各随自己的实装链关，**不作为本图的动作**——本图只写规则，不动存量（与 map Out of scope 一致）。#756 随 #743 走完关。

**⑤ 长驻总账图（📒）按批次交棒，不按图的终点交棒**——接收 #771 转来的残雾「长驻总账图的交棒时机」，本票结清。

Matt 的模型里交棒发生在图走完那一刻；长驻图按 #771 本来就不关，那一刻永不到来。裁定：**判据 = 一批决策的下游实施彼此有依赖、且不再依赖任何还开着的子票**，这批即可出 spec，图继续开着走下一批。

长驻图**不需要额外规则**——②已经覆盖：声明带实装的长驻图，每批实施票留图里；纯决策长驻图，每批出图牵新票。本图新增的只有一句：**把交棒点从「图终点」换成「批次边界」**。

反方过了：也可裁「长驻图不交棒，实装一律留图里」，规则更少——但那等于强制所有长驻图声明带实装，把 #770 的声明制在这一族上架空，不取。

### 与 destination 的接口（原问题⑤）
