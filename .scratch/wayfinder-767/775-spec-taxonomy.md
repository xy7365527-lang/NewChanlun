## 1. 校准样本核验

- **#480**（📋 SPEC：交付纪律规范，map #445 /to-spec 交棒件）：`gh api .../issues/480/parent` 返回 404（不是任何 map 的原生子票）；票体首行声明"本 spec 由 map #445 交棒而来（wayfinder `/to-spec`）"；关票决议原文"SPEC 已消费，唯一切片 #482 落地"——`#482` 经检索确认是一张全新开的实施票（标题"交付纪律规范落 docs/agents + CLAUDE.md 指针（#480 单片）"），且 `#482` **不在** map #445 的原生子票清单（#436/440/444/476/477，五张全是 grilling 裁定票）里。判别标准在这张上成立：**甲型**。
- **#756**（📋 SPEC：端到端模块化，map #743 实施总单）：`.../parent` 同样 404（非原生子票）；票体正文列出的执行序列 `#744→#745→#746→#747→#748→#749→#753`，经核对**全部已经是** map #743 的原生子票清单成员（#743 的 12 张原生子票为 #744-749/753/760-764）；对 `#756` 做标题引用检索无任何新票命中。判别标准同样成立：**乙型**。

两个锚点样本用同一套判别法（"关联/下游票是否落在原图既有子票清单之外"）可清楚分开，下面把该判别法套到全部 31 张。

## 2. 方法说明

对每张 SPEC 票查四件事：
1. **titlemark**：标题是否显式写"交棒件"或"to-spec"（不含泛泛提到 spec 的情形）。
2. **归属**：`gh api .../issues/<n>/parent` 判定是否为某张 map 的原生子票；若是，记录父 map 号。
3. **首行声明**：body 开头是否有"由 map #N 交棒而来"类declares。
4. **关票证据链**：读关票决议/最后一条评论，提取其中点名的"交付证据"票号，逐个用 `gh api .../issues/<n>/parent` 及各 map 的原生子票清单核对——**落在原图（或任意已知 22 张 map 之一）既有子票清单内**记为"回指既有票"，**清单外的全新票号**记为"牵出新票"。

局限：本仓 271+ 张已关子票里，只对 22 张 map 的原生/checklist 子票名单做了核对（覆盖 #771 报告统计的全部 22 张图），未对更早期、不属于这 22 张任何一张的孤立票再往上溯源，因此"回指既有票 vs 牵出新票"的判断只在这个已知集合范围内可靠；小概率存在"回指的票其实是另一张更早、未纳入本次统计的图的子票"而被误判为"新票"的情况。

## 4. 甲乙分类汇总

- **甲型**（真正牵出图既有子票清单之外的新票）：**#84、#268、#274、#455（弱，牵出的是影子评审审查票而非功能实施票）、#480（锚点）、#572** —— 共 6 张。
- **乙型**（不产生新票，回指/复用某张 map 已有的子票或裁定序列）：**#109、#129、#156、#193、#215、#219、#249、#385、#386、#547、#589、#660、#756（锚点）** —— 共 13 张。
- **中间态/难判**：**#73、#232、#258、#304、#421、#443、#467、#526** —— 共 8 张，理由分三类：
  - 作废/被取代型（#73、#258、#421）：SPEC 本身在关闭时被判定"过期"或"被后续裁定取代"，既没有产生新票，也没有明确回指某个既有子票清单，是甲乙之外的第三种关票方式。
  - 自交付型（#232、#304、#443）：SPEC 票直接在票体内完成交付（commit 落地），既没有分裂出子票，也没有"复用图既有子票"这个动作——它就是自己的唯一交付单元。其中 #443 标题写着"map #390 /to-spec 交棒件"，但实测走向更接近"自交付"而非"产生新票"，标题自称与实证证据不完全一致，如实标注不强行归甲。
  - 混合型（#467、#526）：既牵出了不在任何已知 map 子票清单内的新票（多为"影子评审"审查票或连带缺陷票，不是功能实施票），又回指了某张 map 的既有 checklist 票，两种证据同时存在，无法单一归类。
- **未定**（票仍 OPEN，尚无关票证据）：**#169、#485、#620** —— 共 3 张。
- **排除**（非 SPEC 本体，检索误命中或非典型）：#582（是 map）、#404/#544/#550/#551/#552/#553（是引用 SPEC 号的实施票）、#775（本讨论票自身）—— 共 8 张。

## 5. 一句话结论

31 张真 SPEC 票里，能干净套进"甲型交棒件"或"乙型总说明书"两分类的合计 19 张（6 甲 + 13 乙），另有 8 张落在"作废/自交付/混合"这三种都不完全符合原有两分类描述的中间态、3 张因票仍开着无法判断；如实报告：本仓 SPEC 的实际形态不是两型干净可分，而是**两个锚点类型之外确实存在规模不小的中间态**（约占已关闭且可判定样本的三成）。
