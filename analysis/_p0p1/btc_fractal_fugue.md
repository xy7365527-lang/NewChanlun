工位：BTC 分型递归回测（2026-06-11）。驱动脚本
`analysis/recursive_fugue_depth1_backtest.py`（BTC 加性注册 + BT_VARIANTS env），

## 结论

**BTC 投出 F1 的第二张 O_sub1 正票（+14.56pp）——站 BRN 侧，否定"高波动
⇒ OKLO 型否证"的假设**：OKLO 与 BTC 同为高波动标的却判决相反，高波动不是
O_sub0/O_sub1 分裂的决定轴；决定轴更符合 38课原文预言的"REV 窗口落在震荡
regime"（OKLO 否证根因是单边强趋势中分型确认滞后，BTC 10.7 年全历史含长熊
与宽幅震荡，444 个子腿窗口主要展开在非单边段）。**成本门在 BTC 上双重失效
（−18.43pp vs 裸 F1，且过门子集本身净负）**，"亏损有界化"声明的有效域收缩
为 OKLO 单标的。**意外发现：S1（中枢域 depth1）首张正票**（+3.16pp，39 对
66.7%），打破在册"O_sub0 两票收敛"。

### 五个预注册问题的一行答案

1. **F1 depth1 = O_sub1（正票）**：Δ+14.56pp ∧ sub 净现金 +18,806 ∧ rev
   胜率不降（58.3%→58.3%）；BTC 波动结构判决上**站 BRN 侧**——高波动
   单独不解释 OKLO 否证，分裂轴是 REV 窗口的震荡/单边性质。
2. **depth2 不再域稀疏但被否证**：d2 增量 169 对（vs BRN 仅 1 对的域稀疏），
   首次在丰域上可求值——结果净负（−5,327 现金，43.8% 胜率，Δ−4.65pp）；
   "深度=entry−3"链在分型模式下延长为"d2 域丰但质劣"。
3. **成本门触发率 92.6%、方向为负且双重失效**：与 OKLO（+73.8pp 亏损有界化）
   方向相反；且 F1c（−23.30%）< V2of（−19.42%）——不是"关回 V2of"，因为
   实测分支首次非平凡激活（35 评 2 拒 33 过）且过门子集净负。"参照不可
   定义⇒保守拒"在 BTC 上的代价 = 让出 bi 级 +22.8K 正贡献，收益 = 无。
4. **41课门触发率 0.45%（2/444），非死门判据勉强通过**（非零非 100%，但
   趋零）；"双 regime 不恶化"在第三标的上**边际存活**（−0.25pp，噪声级）
   ——但其有效域声明被触发率稀释，"默认位升级"论据未获增强。
5. **θ_depth=1% 第四次量级失配**：REV 候选拒绝率 97.2%（14,719/15,143），
   与 BRN（99.0%）同级——θ 相对化第一序修复的必要性在第四标的上复确认。

## 定义依据

- **38课**（裸 F1 语义）：向下段程式"顶卖底买"笔级直读 = SubMode::Fractal
  （`rust/src/trading/config.rs` V2ofF1/F2 注册）。BTC 444 个子腿窗口全部
  挂在 REV（DownLeg）窗口内，满足"次级别向下段中反向短差"的结构前提。
- **35课**（成本门）：θ_eff = max(θ_q, k×friction_rt)，θ_q = 因果滚动
  P50 中枢相对振幅（DepthRef，window=50/min_obs=10），k=2、friction_rt=10bps。
  BTC 首次出现实测分支非平凡求值（35 次）：2 拒 33 过——"级别波幅可测"
  的定义域在 BTC 上非空（OKLO/BRN 均为空）。
- **41课**（41课门）：父级别相邻同向（Down）段创新低 ∧ 窗口内无盘整背驰
  ⇒ 拒开（`trend_exhaustion.rs`）。BTC 触发 2 次。
- 预注册判据（脚本 docstring，双侧）：O_sub1 ⟺ Δ复利>0 ∧ sub 净现金>0 ∧
  rev 胜率不降。F1/S1/F2 各自独立求值；0 配对 ⇒ 域空（P0-b 引用纪律，
  本次脚本已显式实现该分支）。

## 边界条件

1. **零摩擦是 F1 正票的承重墙**：sub 均差 **0.0425%/对 < 10bps 往返摩擦**
   ——扣实际摩擦后 444 对的 +18.8K 大概率翻负，O_sub1 判决可能整体翻转。
   S1 的 0.2351%/对可扛 10bps；F1 不能。**F1 正票是零摩擦读数**，与 BRN
   票（0.186%/对，扣半存活）质地不同。
2. **成本门"双重失效"的翻转条件**：若 33 个过门对的净负是采样噪声
   （N=33，胜率 42.4%），实测分支的逆向选择结论降级；但"让出 bi 级正贡献"
   部分（409 无参照拒 → −18.4pp 主因）不依赖该子集。
3. **41课门 N=2**：触发样本过小，方向读数（−0.25pp）无统计效力；只有
   触发率本身（0.45%）是稳健读数。
4. **共享库构建状态**：本次 .so 由 2026-06-11 09:05 工作树构建，**含并行
   θ 工位的未提交改动**（config.rs/types.rs 等）。可比性不由"干净树"保证，
   而由四道复现守卫保证：cargo test 106/0 + BRN V2of/V2ofF1/V2ofF2 逐位
   复现在册（p0a 脚本，磁带指纹 bsp63977/div46751/flips117573 一致）+
   BRN 三门变体逐位复现 P1 表值（+48.94/+58.67/+48.94，
   `_brn_gate_xcheck.py`）+ BTC O0≡P5 PASS（1462 笔/2281 trace 行）。
   若 θ 工位后续改动触及默认路径，本结果与未来跑批不可直接混表
   （磁带指纹 bsp118412/div96663/flips265893 已入册供 fail-fast）。
5. **绝对收益为负**（全配置 < BH +1380%）：本实验测的是通道间 Δ，不是
   择时 alpha——BTC E 版先例（E +2194% ≫ BH）与本框架（P5 −45%）不可
   同表比较（数据同、框架异）。
6. 数据清洗显式审计：raw 4,625,119 行，nan=0、非正 OHLC=0、
   spike-and-revert 坏 tick=0——**清洗管线激活但零行删除**（Binance 归档
   质量好于 databento 期货），clean=4,625,119 全量入回测。

## 下游推论

1. **O_sub0/O_sub1 分裂轴修正**：F1 票型现为 OKLO（−73.8pp）vs BRN
   （+10.7pp）+ BTC（+14.6pp，零摩擦）——"高波动 regime"假设被否定，
   分裂轴收敛到"REV 窗口的震荡/单边性质"（38课有效域=震荡的第三证）。
2. **成本门不可升级为默认位**：三标的方向 +73.8/−9.8/−18.4pp，正贡献仅
   OKLO 一例；其"亏损有界化"保险价值在 F1 通道为正的标的上是纯代价。
   若要门控 F1，方向应是 regime 判别（震荡/单边），不是成本判别。
3. **41课门维持"不恶化"但价值未增**：三标的 +26.4/−0.06/−0.25pp——唯一
   双向安全的门，但 BTC 触发率 0.45% 说明其判据（相邻同向段创新低∧无盘整
   背驰）在 24/7 高翻转标的上几乎不可满足，升级默认位的证据不足。
4. **S1 首张正票改变递归赋格结论结构**："O_sub0 两票收敛、SubLou 休眠"
   的在册结论出现反例 regime——BTC 的 REV 窗口深/长到足以让次级别中枢
   存活（无中枢拒 137 vs 开腿 39，拒绝率 77.8%，低于 BRN 的 74%? 注：
   BRN 为 74% 拒后 1 腿亏，BTC 拒后 39 腿净正）。若后续在油链（CL/BRN
   厚域）复验 S1 为正，"语法性矛盾"（父腿前提否定子腿前提）需要限定为
   regime 性而非语法性。
5. **θ 相对化第一序的第四票**：97.2% 拒绝率与 BRN 同级——θ_depth 固定
   1% 在 1min 塔底的失配现在覆盖股票/期货/加密三资产类。

## 谱系引用

- **递归赋格深度1双标的否证**（在册 memory + `recursive_fugue_depth1.json`）：
  O_sub0 两票（OKLO 域空型 / BRN 负样本型）——本实验 S1 首张正票构成反例，
  收敛结论需 regime 限定。
- **笔级分型递归赋格**（P0 前置）：OKLO −73.8pp vs BRN +10.7pp 分裂；
  有效域=震荡 regime（38课）——BTC 第三票支持该有效域判定。
- **P1 双门四格消融**（`analysis/_p0p1/p1_dual_gate.md`）：成本门=亏损
  有界化、41课门=双 regime 不恶化——前者有效域收缩至 OKLO，后者边际存活。
- **P0-a depth2 域稀疏**（`p0a_brn_depth2.md`，BRN 仅 1 对）：BTC 169 对
  打破域稀疏，depth2 首次在丰域上被否证。
- **P0-b 引用纪律**：0 次求值 ⇒ 域空≠否证——本次已将该纪律实装进
  `_verdict`（sub 0 配对 → "域空"判决分支）。
- **θ相对化第一序**（theta_adaptive / 期货普查 L3）：绝对 θ 三次失配
  → 本实验第四次（97.2%）。
- **形式化有效域规则**（222/223/230/231号）：成本门实测分支在 BTC 上
  定义域首次非空（35 评）——但有效域读数为负，按规则显式分离
  无参照（409）与实测（2 拒 33 过）两分支报告。
- 不确定是否存在"加密资产 regime"专门谱系；BTC 全历史 V-I 回测
  （在册 memory）是最近的相关记录，此处显式声明不确定性。
