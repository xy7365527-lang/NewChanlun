# P0-b — CL 秒级分型模式 depth=1 回测（V2of vs V2ofF1）

日期：2026-06-11　工位：P0-b　认识论等级：**L2**（CL 单标的、秒级单时段、真实数据）

## 1. 结论

**O_sub0[V2ofF1]（否证）——但否证形态是"域空型"，且域空是 θ=1% 固定深度门的量级伪影，
不是秒级结构本身的空域。**

数据：`analysis/data_cache/cl_1s_databento_1y.json`（databento GLBX.MDP3，
ohlcv-1s，continuous .v.0，2024-06-01→2025-06-01，5,959,343 bars）。
格式 = parallel-array（opens/highs/lows/closes/volumes + timestamps_ns），
`load_ohlc` 原生兼容（无 dates 键 → years=None）。
**清洗量 = 0 行**：判据为任一 OHLC 为 None/NaN/≤0（BRN 13.5% 空行先例的同判据），
全量扫描 0 命中；spike-and-revert 孤立坏 bar 清洗 0 命中；min_low=55.12 / max_high=84.52，
量级正常。BRN 空行陷阱在 CL 上不成立（推测拉取脚本已在落盘前过滤非定价成交行）。

主对比（floor=LADDER_SEG，O0≡P5 守卫 PASS，715 笔 / 1648 trace 行）：

| 变体 | 复利% | Δ(vs P5)pp | rev对 | sub开 | sub对 | sub净现金 | 耗时 |
|---|---|---|---|---|---|---|---|
| V2of (depth=0) | −7.06 | +0.0 | 0 | — | — | — | 0.24s |
| V2ofS1 (depth=1 中枢域) | −7.06 | +0.0 | 0 | 0 | 0 | 0.0 | 0.24s |
| V2ofF1 (depth=1 分型) | −7.06 | +0.0 | 0 | 0 | 0 | 0.0 | 0.24s |

BH=−20.93%；P5=V2of=−7.06%（超额 +13.9pp 来自空仓避跌）；信号层 55.4s（5.96M bars，
分钟级时间内完成，无内存/时长故障）。三变体逐位相同：**Δ复利=+0.00pp，子腿配对=0，
胜率无定义（无样本）**。

根因（counters）：`n_rev_open=0`，`n_rev_depth_rejects=19,669`——全部 19,669 个
REV 开腿候选被深度门 `(ZG−ZD)/c ≥ θ_depth=1%`（`level_operating_unit.rs`
~L1005）拒绝。父 REV 腿域为空 → F1/S1 子腿定义域为空 → depth=1 与 depth=0
bit-identical。

→ 秒级 REV 域**非结构性空**：相对化 θ 下宿主丰富（6,396 腿）。域空纯属 θ=1%
绝对阈值在秒级中枢振幅量级上的失配——**θ 绝对阈值第四次失配**（前三次：
ZN/DX 空域、QQQ 清空、振幅 P50 量级失配 L3）。

## 2. 定义依据

- 分型子腿（SubMode::Fractal）：38课"向下段内顶分型卖、底分型买"直读，不需要
  k−1 中枢做域（`config.rs` V2ofF1 注释；`rev_sub_depth=1, sub_mode=Fractal`，
  其余逐位继承 V2of）。
- 宿主前提：子腿只在父 REV 腿（DownLeg）开放窗口内激活（递归赋格设计
  `analysis/recursive_fugue_ultimate_design.md` §2.4/§3.3）。本数据上宿主集合为空集，
  分型直读条件从未被求值——满足的是"无宿主"而非"有宿主但分型不盈利"。
- 深度门定义：震荡型开腿要求 `(ZG−ZD)/c ≥ θ_depth ∧ c > ZD`（零利润空间并入深度拒）。
- 预注册判据（双侧，`recursive_fugue_depth1_backtest.py` 头注）：O_sub1 需
  Δ>0 ∧ 子腿净现金>0 ∧ rev 胜率不降；本结果 Δ=0 ∧ 子腿净现金=0 → O_sub0。

## 3. 边界条件（结论何时翻转）

1. **θ 相对化落地后必须重测**：F1×自适应 θ 的组合变体（如 V2oa25F1）当前未在
   `config.rs` 注册——已安装 newchan_rust 无此接口（按工位约束不重建，报告缺口）。
   V2oa25 在秒级开出 6,396 条 REV 腿且复利转正（+0.43% vs V2of −7.06%），宿主
   非空后 F1 子腿才有定义域，届时本否证可能翻转为实质判决（正或负）。
2. floor 改变（如 LADDER_MOVE 或 bar0）会改变 REV 候选集与中枢振幅量级，
   19,669 拒绝数与域空结论不可外推到其他 floor。
3. 本结论限 CL 单标的、2024-06→2025-06 单时段（该年 CL 76→61 下行 −20.9%，
   震荡偏空 regime）；其他秒级标的（BRN）须独立判决。
4. 若拉取端清洗策略改变（保留非定价成交空行），0 清洗行结论失效，须按
   OHLC None/NaN/≤0 判据重新清洗。

## 4. 下游推论

- **本结果不构成"分型模式在秒级无效"的证据**——它是 θ 门的上游否决，分型逻辑
  从未被执行（0 次求值）。引用本判决时禁止写成"秒级分型短差被否证"（声明膨胀，090号）。
- θ 相对化第一序修复（在册待办）的优先级证据 +1：固定 1% 门现在在
  ZN/DX（1min）、QQQ、振幅 P50、CL（1s）四处失配，且失配方向一致（量级越细越失配）。
- 秒级数据管线（load_ohlc parallel-array + timestamps_ns、5.96M bars 全链 ~2 分钟）
  已验证可复用——P0 后续秒级实验无需再做加载适配。
- depth=1 递归在 1min 上已两票否证（OKLO 域空型 + BRN 负样本型）；CL 1s 本票是
  第三种形态（θ 伪影域空型），不延长"更细短差先验为负"链——该链要求子腿被执行过。

## 5. 谱系引用

- 秒级 a0 可行性判决（L3 成立，~1笔/分钟，膨胀19×非60×；BRN 13.5% 空行陷阱）——
  本工位数据基底的合法性来源；CL 清洗 0 行补充该判决的标的差异面。
- 分型模式有效域 = 震荡 regime（BRN +10.7pp vs OKLO −73.8pp L3 分裂；38课原文预言；
  中枢=域 vs 分型=点的范畴分离）——本票因域空未对该有效域命题产生信息增量。

  三次失配 → θ 相对化第一序（本票为第四次失配实例）。
- 222/223/230/231号：有效域 ≠ 定义域——本报告按 L2 标注，不声明跨标的/跨θ模式有效。
