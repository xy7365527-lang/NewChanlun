# P0-c — 逐 ladder 中枢振幅 / 交易成本比值表

工位：P0-c（2026-06-11）。脚本 `analysis/p0c_ladder_cost.py`，数据
`analysis/data_cache/p0c_ladder_cost.json`，日志 `analysis/data_cache/_p0c_run.log`。

## 结论

**"在哪个级别做短差划算"在 10bps 往返成本下的答案是标的依赖的**：高波动
单股（OKLO）最浅到笔中枢层（ladder2）都划算；ETF/期货（QQQ/BRN/CL）的
笔中枢层全部应被成本门关闭（比值 0.91–1.95 < 2），最浅划算层是走势级
（ladder3）；BTC 是第三种形态——ladder2 在 10bps 口径下开（比值 2.55）
但贴线，归类为**条件性 OKLO 型**：分类结果是摩擦假设的函数（临界
f=12.75bps，现实 crypto taker 费率即翻关，见边界条件）。每升一个递归级别，
中枢振幅 P50 约 ×2.0–2.4，比值单调递增——成本门只在塔底起作用，ladder4+
全部远离门槛；该标度律在 BTC 上部分成立（ladder3→4 仅 ×1.64，见下）。

### BTC 是 OKLO 型还是指数/期货型？

**两者都不是的中间形态，10bps 口径下归 OKLO 型（塔底开），但定性不同**：

- **与 OKLO 的差**：OKLO ladder2 比值 8.05，余量 4 倍门槛，对任何现实摩擦
  假设鲁棒（翻关需 f ≥ 40.3bps）；BTC 比值 2.55，距门仅 27%，翻关只需
  f ≥ 12.75bps。OKLO 的"塔底即划算"是波动性事实，BTC 的是**摩擦假设的
  产物**。
- **与期货的差**：QQQ/BRN/CL ladder2 在 10bps 下关（0.91–1.95），BTC 开
  （2.55）——BTC 1min 笔中枢振幅（P50 0.255%）确实系统性高于 ETF/期货
  （0.091–0.195%），约 1.3–2.8 倍，这部分是真实的波动性差异。
- **判定**：条件性 OKLO 型。在本表统一 10bps 口径下塔底开；但 crypto
  现货零售费率（Binance VIP0 taker 10bps/边 = 20bps 往返）下比值 1.27 →
  关，退化为期货型。BTC 是五标的中唯一一个**门状态落在现实摩擦区间
  之内**的标的（期货/ETF 现实摩擦 < 临界值故稳关，OKLO ≫ 临界值故稳开）。

比值随级别单调递增的定性结论在 BTC 上完整成立。

## 定义依据

- **35课**："交易成本+交易误差相对波幅不够小的级别，长期操作没有意义。"
  本表把"波幅"操作化为该级别中枢振幅 (ZG−ZD)/中点（短差单回合的理论
  兑现上界——ZD 买 ZG 卖恰好吃满中枢区间），"不够小"操作化为
  P50/成本 < 2（成本占中位可兑现波幅的一半以上）。
- 中枢 ZG/ZD 由前三构件固定（中枢定义，第20-22课口径），生长延伸改
  GG/DD 不改 ZG/ZD——故振幅对 settled/未 settled 中枢同样良定义，全量
  计入（每层至多 1 个生长中尾中枢，N 大时不影响分位数）。
- 中枢读取口径：ladder2 = confirmed strokes → `zhongshu_from_strokes`
  批量（与 `_c_seg_fix_capture.py` 同口径）；ladder3 =
  `orch.current_zhongshus()`；ladder4+ = `orch.current_recursive()`
  （ladder = lid+2）。退化中枢（ZG≤ZD 或中点≤0）剔除（四标的实际剔除
  数 = N_raw − N ≈ 0）。

## 边界条件（10bps 假设的翻转点）

门状态翻转条件：往返摩擦 f 越过 P50/2。各 ladder 的开/关临界摩擦（bps）：

| 标的 | ladder2 临界 f | ladder3 临界 f | ladder4 临界 f |
|------|---------------:|---------------:|---------------:|
| OKLO | 40.3 | 96.0 | 212.3 |
| QQQ | **4.6** | **10.7** | 22.8 |
| BRN | **9.2** | 22.7 | 46.1 |
| CL | **9.7** | 21.7 | 40.7 |
| BTC | **12.75** | 31.6 | 51.8 |

- f < 4.6bps（顶级期货费率+零滑点）：五标的 ladder2 全开，本表的"关"
  结论全部翻转——成本门退化为空门。
- f ∈ [4.6, 9.2)bps：仅 QQQ ladder2 关。
- f ∈ [9.2, 10.7)bps：QQQ/BRN/CL ladder2 关、BTC/OKLO 开（本表基准情形，
  10bps 在此区间）。
- f ≥ 10.7bps：QQQ ladder3 也关——QQQ 在 1min a0 下只剩 ladder4+ 可操作。
- **f ≥ 12.75bps：BTC ladder2 翻关**——这是 BTC 分类（OKLO 型 vs 期货型）
  的翻转点，且落在现实 crypto 费率区间内：Binance 现货零售 taker
  10bps/边 = 20bps 往返 > 12.75 → 关（期货型）；BNB 折扣+maker 或 VIP
  阶梯可压到 ~7.5–15bps 往返，恰好横跨临界值。**BTC 行的"开"对摩擦假设
  不鲁棒，使用前必须先定费率档**。
- f ≥ 40.3bps（零售级摩擦）：OKLO ladder2 也关，"高波动单股例外"消失。
- 其他翻转源：(1) 本表是全历史 pooled 分布，未分 regime 分层——若震荡
  regime 的 ladder2 振幅显著高于 pooled P50（中枢密集期振幅大），临界
  标的（CL 1.95/BRN 1.83）可能在震荡 regime 内翻开；(2) ladder5/6 的
  N=1–47，分位数不稳定，但其比值余量 ≥7×，结论（开）对采样误差鲁棒；
  (3) 兑现率 < 100%：比值用满振幅兑现上界，实际 ZD→ZG 兑现率（V2r 逐笔
  行为分解：zd 触线几何兑现×存活率）约 0.5–0.7，等效再除 1.4–2——若按
  有效兑现折算，QQQ ladder3（2.14）跌破 2，CL/BRN ladder3 余量收窄到
  2.2–3.2 但不翻转。

## 下游推论（P1 成本门 k×friction 设计的预期作用域）

若 P1 取 θ = max(θ_q, 2×friction)（k=2，friction=10bps → θ_floor=0.20%）：

1. **预期作用域恰好是塔底一层**：被 θ_floor 关闭的只有 QQQ/BRN/CL 的
   ladder2（P50 0.091/0.183/0.195% < 0.20%）和 OKLO 的无（0.805% ≫ 0.20%）。
   ladder3+ 四标的 P50 全部 ≥ 0.214%，θ_floor 不触碰——成本门**不会**
   误伤走势级以上的操作。
2. **门是标的自适应的**：同一条 k×friction 规则在 OKLO 上放行笔中枢
   短差、在 QQQ/期货上自动关闭它——不需要 per-symbol 配置。这正是
   θ 相对化要达到的形态：绝对阈值 θ=1% 会把 QQQ 整个 ladder3（0.214%）
   和 ladder4（0.455%）也误杀，而 2×friction 只杀真正不划算的层。
3. **QQQ ladder3 是门的边界测试用例**（比值 2.14，距门 7%）：P1 落地后
   应验证该层在 k=2 时开、k=2.5 时关——这是门的灵敏度探针。
4. 递归赋格 S_sub 子腿的经济终止条件（振幅 ≥ 2×sub_friction_rt，
   `level_operating_unit.rs` SubLou 已实现）与本表一致：子腿挂在 k−1
   级别，若父声部在 ladder3，子腿在 ladder2——对 QQQ/BRN/CL 该层中位
   振幅不过门，印证递归 depth1 大量 amp_rejects 与"更细短差先验为负"链。

## 谱系引用

- **θ=1% 绝对阈值三次失配 → θ 相对化第一序**：REV 配对修复（QQQ 被
  θ=1% 清空）、期货 7 标的普查（ZN/DX 空域）、θ 自适应深度门（因果滚动
  P25 三标的判决优于固定 1%）。本表给出失配的机理定量：四标的 ladder2–3
  P50 范围 0.091%–1.919%，跨 21×，任何绝对阈值必然在某些标的上误杀整层。
- **振幅 P50 0.93/0.10/0.20%（OKLO/QQQ/BRN）量级失配 L3**（θ 自适应
  深度门工位）：本表 ladder2 P50 = 0.805/0.091/0.183%，同量级复现
  （口径差异：该工位测 REV 腿窗口内振幅，本表测全历史笔中枢振幅），
  交叉验证通过。
- **35课成本-波幅原则**首次被逐级定量化——此前蜂群引用该课均为定性
  （"太小级别短差有害"，共享仓位赋格 bar 级 22814 次噪音短差爆仓先例）。
- 不确定是否存在"成本门"专属谱系条目；θ 相对化链（上引）是最近谱系。

## 认识论等级

**L3**：五标的（OKLO/QQQ/BRN/CL/BTC）真实 1min 数据交叉，跨三个资产类
（单股/ETF/期货/crypto），含一项与独立工位（θ 自适应深度门）的量级交叉
验证。含否定性结果（QQQ/BRN/CL ladder2 被成本门否定；"×2.0–2.4 标度律
全域成立"被 BTC ladder3→4 ×1.64 部分否定）。窗口声明：OKLO ~2.4y / QQQ
全量 / BRN、CL 10y 全量 / BTC 4.63M bar Binance 全历史（~2017-08 起），
**无降采样、无窗口截断**（递归塔流式 O(N) 化后 CL 5.53M bar 引擎 6s、
BTC 4.63M bar 6s，任务预设的 O(N²) 陷阱已不存在）；分布为全历史 pooled，
未做 regime 分层（见边界条件 (1)）。
