# 嵌套递归赋格配额架构的原文调研：B（振幅加权分层）vs C（区间套借slice）vs B+C

> 认识论等级：**L0**（纯原文考据，零数据验证；所有工程推论标注"需回测"）。
> 原文权威链：全部引文逐字摘自 `docs/chanlun/text/blog/`（一级权威），附文件行号锚。
> 任务来源：NRF 配额公式的架构分岔（2026-06-12）。在册 L2 背景：hold26 BTC +1247% 成立 /
> cycle45 否证（`analysis/nested_recursive_fugue_results.md`）。

## 0. 判决摘要

1. **原文支持 B+C 合体，且不是两个架构的拼接**——B 与 C 在原文中是同一结构的两个轴：
   **B 管层间（量按级别分配、各层只响应本级别买卖点），C 管层内（每层配额同股数进出、
   目的=降成本）**。26课的恒仓模型本身就是这个合体的原文形态（§2.1）。
2. **铰链条款在 44课**：同一笔低级别卖出，事后走势决定它是"短差"（回补，C 路径）还是
   "减仓第一步"（出清，B 路径）——"权当弄了一个短差"（§1.2）。短差与减仓在原文中
   **不是事先架构选择，是同一笔操作的两种事后归类**。
3. **44课禁令的精确对象是"响应量与信号级别的错配"，不是仓位的物理归属**（§2.2）。
   仓位按级别物理分开持有（B 强形式）是 38课"分区卷钱"授权的一种机械化方式（"可以"），
   不是 44课强制的唯一形式。
4. **配额的量化公式原文无依据**：53课明文留白（"这就涉及仓位调配控制的问题了，这问题
   以后再说"，已逐字核对）。振幅加权 vs 均分 vs 任何其他公式都是工程合成，只能由回测裁决。
5. 17/20/49课的中枢操作描述全部假设**单一操作级别下的单一仓位**；49课结尾明示大资金
   "很多级别的操作不可能全仓参与"且把瓶颈突破推迟（"以后会说到"）——多级别配额体系
   是原文承认必要但未给出方案的区域（§2.4）。

### 1.1 第26课：级别=买卖量 + 恒仓极性（`blog/026-第26课.md`）

正文核心段（026:34）：

> "市场的无论涨还是跌，对于你来说永远是机会，你永远可以在买卖之中，只要有卖点，就要卖出，
> 只要有买点就买入，**唯一需要控制的，就是量**。即使对于本ID这样的资金量来说，1分钟的卖点
> 本ID也会参与，只是可能就只卖5万股，跌回来1分钟买点买回来……所以，对于本ID来说，任何的
> 卖点都是卖点，任何的买点都是买点，本ID唯一需要控制的只是买卖的量而已。**级别的意义，
> 其实只有一个，基本只和买卖量有关**，日线级别的买卖量当然比1分钟级别的要多多了，本ID可以
> 用更大的量去参与买卖，例如100万股，1000万股，甚至更多。"

同段紧接的恒仓声明（026:34，权证例）：

> "注意，**本ID的仓位是一直不变的，最开始多少就是多少，上上下下，卖点的时候变少，买点的
> 时候又回复原来的数量，但绝对不加仓，一开始就买够**。"

十条原则之第2条（026:80）：

> "级别必须配套来看……短线是让你把成本将下来，而且确保持有的安全性，除了日线的单边上扬
> 走势，短线必须坚持。**但仓位可以控制，例如用其中的1/3**。"

答疑（026:447）：

> "另外，一定要灵活，不能光会先买后卖，也应该学会先卖后买。还有，**该以什么比例运用也是
> 一个关键，不熟练的情况下，如果仓位不太大，1/3或1/4是比较合适的**。"

**读出**：
- "级别的意义基本只和买卖量有关" = **级别 → 单次操作量的映射**（1分钟卖点 5万股 vs 日线
  级别 100万/1000万股）。这是 B 的量语义。
- 但仓位结构是**单一池**："一开始就买够"、卖点削减、买点"回复原来的数量"、绝对不加仓
  ——同股数进出，这是 C 的仓位语义（hold26 极性的原文出处）。
- "用其中的1/3"做短线 = 从主仓中**切出部分**做短差，不是独立资金——C 的 slice 语义。
- **26课本身就是 B+C**：量按级别定（B），结构是单池借出还回（C）。

### 1.2 第44课：级别错配禁令 + 短差/减仓的事后分岔（`blog/044-第44课.md`）

大资金条款（044:50）：

> "当然，对于有一定量的资金来说，即使按30分钟操作，当见到1分钟的顶背驰时，**也可以把部分

必要条件声明（044:24-30）：

> "缠中说禅小背驰-大转折定理：小级别顶背驰引发大级别向下的必要条件是该级别走势的最后一个

**读出**：

  30分钟级别的全部量），不是清仓动作本身（按1分钟操作的人全清自己的1分钟仓位完全合法）。
- 044:44/50 两段是低级别信号**部分响应**的正面授权：低级别卖点 → 出一部分 → 事后两条路：

  (ii) 不恶化 → 回补，"**权当弄了一个短差**"（事后归类为 C 路径）。
- **短差与减仓不是两个事先架构，是同一笔卖出的两种事后路径**——这正是任务描述中
  "高级别视角看次级别直接开单只是短差"的原文形态，也是 B+C 不可拆分的原文根据。

## 2. 五个调研问题的逐一回答

### 2.1 问题1：多级别资金分配——26课"买卖量"的精确含义

**"买卖量" = 单次响应某级别买卖点时允许动用的量，级别越大量越大**（1分钟卖点5万股 vs
日线级别百万股，026:34）。这是一个 **级别→操作量的映射**，不是"每级别一个独立账户"。

26课的完整模型：总仓恒定（"一开始就买够……绝对不加仓"）+ 各级别买卖点各动各的量 +
买点"回复原来的数量"。即：**仓位结构是 C（单池、同股数振荡），量纪律是 B（按级别定量）**。
26课既不是纯 B 也不是纯 C，它就是 B+C 的原文原型——这与在册 hold26 判决
（恒仓极性 BTC +1247%，L2）精确互证：hold26 实现的正是 026:34 这一段。

### 2.2 问题2：44课禁令禁止的精确对象

逐字（044:48）："你不可能按30分钟操作，而一见到1分钟顶背驰就**全部**扔掉，这就变成按
1分钟级别操作了。"

- 禁止的**不是清仓动作本身**（按1分钟操作者全清自己的仓完全合法——"按1分钟操作，操作的
  程序和按30分钟的是一样的"）；
- 禁止的**也不是低级别信号触发任何操作**（044:44/50 明文授权低级别卖点"先出一部分"）；
- 禁止的是**响应量与信号级别的错配**：级别 k 的信号动了级别 k+n 配额的量。

**对架构的推论**：44课只约束响应映射（k 级信号 ≤ k 级的量），**不强制仓位物理按级别分开
持有**。B 的强形式（独立 per-level FSM/账户）是满足该约束的一种充分实现，38课分区卷钱
给了它正面授权（"可以设定"）；但单池+量纪律（26课形态）同样满足约束。两者都原文合法，
区别是工程选择（可审计性/故障隔离 vs 记账复杂度），由回测与实现约束裁决，不由原文裁决。

**附带发现**：044:44 的事后分岔条款是任务核心描述的原文形态——低级别卖出在当下
**不携带**"短差还是减仓"的身份，身份由后续走势（是否跌破3买回试高点）事后授予。
任何要求"开单时刻预先声明短差/减仓身份"的实现都比原文更强，是工程附加假设。

### 2.3 问题3：38课"同股数进出"的归属

**38课程式本身没有"同股数"表述**——它的程式是该配额的全进全出（"先卖出……重新买入"），
且分区卷钱（038:30）的每个分区是"某个量的筹码"独立按该级别操作，**更接近 B（独立配额）**。

同股数语义的逐字出处在别处：
- 26课："买点的时候又回复**原来的数量**，但绝对不加仓"（026:34）；
- 49课："在中枢上方全部抛出筹码，在下方**如数接回**"（049:64）；
- 26课原则2 + 答疑："用其中的1/3"（026:80/447）——从主仓**借出一部分**做短差。

即：**"借出还回"（C）是单一操作级别语境下短差的原文形态；"独立的一笔资金"（B）是
多级别机械化系统语境下的原文形态**。两个语境在原文中并存不矛盾：38课分区内部每个分区
照样跑"先买后卖/如数进出"的运作——分区间是 B，分区内是 C。

### 2.4 问题4：17/20/49课的中枢操作假设单一还是多层仓位

**全部假设单一操作级别下的单一仓位**：
- 17课：资金量是**选择**操作级别的参数（017:1084），一人一级别；
- 20课：买卖点响应全部以单仓为主语（"第一、二类卖点时为什么不卖"，020:414）；
- 49课：两条利润最大定理的约束条件明文是"**在确定的操作级别下**"（049:58/72），
  满仓/增减/全抛全部是该级别配额内的动作。

唯一指向多层的缝隙是 049:76：大资金"很多级别的操作不可能全仓参与"→ 跨级别参与是

### 2.5 问题5：递归结构的资金归属——"不同资金"还是"同一笔资金不同操作方式"

原文两种表述都有，且各有明确语境：

| 表述 | 出处 | 语境 |
|------|------|------|
| **不同的量的筹码按不同级别独立操作**（B） | 038:30 分区卷钱 | 资金有一定规模、机械化系统 |
| **同一仓位，各级别买卖点动不同的量、买点回复原数量**（C 结构 + B 量纪律） | 026:34 恒仓 | 缠师自述的实际操作 |

**没有任何一处原文说"不同级别必须用不同的资金"**；也没有任何一处禁止。原文的不变量只有
三条：(i) 量与级别匹配（26/44/53课）；(ii) 总筹码守恒——卖出的要回补、"筹码不丢失"

降成本/挣筹码，不是独立利润源（35/53课）。

## 4. 明确结论

### 4.1 原文支持哪种架构

**B+C 合体，且合体方式有原文规定**：

1. **层间 = B**：量按级别分配（26课），级别 k 的卖点最多清级别 k 的净配额（44课禁令的
   正面形式），顶层配额只被顶层卖点清算（47课正面 + 44课反面）。
2. **层内 = C**：每层净配额内部，借出部分（26课"1/3"）按次级别买卖点做同股数短差
   （49课"如数接回"），目的函数 = 该层 cost_basis 下移（35/53课），可向次次级别递归
   （35课立体性）。
3. **B/C 边界是动态的（44课铰链）**：层内的一笔 C 卖出，若后续走势恶化（跌破构成3买的
   回试高点），事后升级为该层 B 配额的减仓第一步（"在出清"）；不恶化则回补归还
   （"权当弄了一个短差"）。**实现中给开单预先打"短差/减仓"标签是工程附加，原文身份是
   事后授予的。**

任务直觉（"高级别用B、每层内部用C"）**被原文验证成立**，并且 44课补充了直觉没有的
第三条：B 与 C 之间存在原文规定的动态转化通道。
