# 第六轮数学推导：价格充分有效与有限纵向定位链（#868）

> 方法说明：按 research 技能把权威原文、数学命题和实装观察分层。前五轮文件仅作为推论线索，不充当本轮依据。本轮只读，未修改仓库文件。

## 结论先行

1. **“价格充分有效”与“路径空间在前缀距离下完备”不等价，且一般情况下互不蕴含。**两者只是都能用前缀语言描述，逻辑对象不同：
   - 价格充分有效约束一条历史如何形成：成交按时间排序，已经发生的记录不得撤销或回写。
   - 完备性约束一组可能路径：任意柯西路径序列的极限仍属于该组。

2. **真正完备的是前缀树的无限分支空间或其闭包，不一定是前缀树节点本身，也不一定是实际市场允许的路径集合。**把“所有相容的无限分支都算作合法路径”写进定义以后，完备性成立；但这是一条额外的路径闭包假设，不是价格充分有效的同义改写。

3. 完备性只保证柯西极限不逃出空间。它不保证：
   - 每个当前前缀都有未来；
   - 未来唯一；
   - 任意嵌套非空集合交非空；
   - \(\operatorname{Div}_q\Rightarrow\operatorname{Turn}_q\)；
   - \(\operatorname{Div}_q\Rightarrow\neg\operatorname{Ext}_q\)；
   - 压缩映射、迭代收敛或唯一不动点。

4. 对有限链
   \[
   I_q\supseteq I_{q-1}\supseteq\cdots\supseteq I_0
   \]
   而言，
   \[
   \bigcap_{k=0}^{q}I_k=I_0
   \]
   **是纯集合论同义反复，而且严格包含、有限性、度量、测度、完备性全都不需要。**

   它没有证明 \(I_0\) 存在，也没有证明 \(I_0\neq\varnothing\)，更没有证明 \(I_0\) 是单点或不同候选链会落到同一个 \(I_0\)。

5. 真正有缠论内容的命题应当是：逐级候选是否存在、候选是否满足相应的 \(\operatorname{Div}_{q-1}\) 谓词、是否能选出唯一候选、是否能一直走到最低级别。公开原文和当前实装都没有给出这条全称总性定理。

6. 五项跨级测度主张——不交并、共用测度空间、保测度投影、逐级归一化、递归聚合兼容 \(\sigma\)-可加性——**没有一项由测度公理或原文免费给出**。

7. 因有限链命题本身是 L0 级平凡命题，本轮**不值得新进 Lean，也未运行 `lake build`**。仓内已有 Lean 文件已经诚实地把同类结果标成“纯结构归纳／同义反复”。

# 一、价格充分有效是否等价于路径空间完备

## 1.1 原文到底给了什么

第30课的约束依次是：

- 交易层只研究价格及其时间轨迹，而非“价格是否反映全部信息”，`030-第30课.md:14`；
- 交易能够按时间排序，时间不可逆；若今天的交易能够改成昨天，或事后取消，理论前提即失效，`030-第30课.md:16`；
- “价格充分有效市场”被定义为：交易以时间不可逆为前提，完全反映在价格轨迹上；若交易能事后更改，就不满足该定义，`030-第30课.md:18`；
- 数学研究对象因此是价格轨迹，`030-第30课.md:20`。

可以把它最低限度形式化为历史编码的一致性。若 \(h_t\) 是截至时刻 \(t\) 的成交历史，\(P(h_t)\) 是对应价格记录，则应有：

\[
P(h_{t+1})\!\upharpoonright_t=P(h_t).
\]

也就是新成交只能追加或扩展记录，不能改写已经结算的前缀。

这是一个关于**历史更新关系**的性质。它回答：

> 一条已经形成的路径，在下一时刻能不能改写过去？

完备性则是一个关于**路径集合与度量**的性质。它回答：

> 一列彼此越来越难区分的完整路径，其极限是不是仍在允许路径集合中？

前者的量词在一条历史内部，后者的量词跨越一列不同路径。二者从对象层已经不同。

---

## 1.2 “前缀树配前缀距离必完备”需要拆成三个对象

设 \(A\) 是成交或价格记录的字母表，\(0<\rho<1\)。对两条不同记录 \(x,y\)，令 \(\ell(x,y)\) 为最长公共前缀长度，定义

\[
d_\rho(x,y)=\rho^{\ell(x,y)},\qquad d_\rho(x,x)=0.
\]

需要区分：

### 对象 A：有限前缀节点集合 \(T\subseteq A^{<\omega}\)

这是所有有限历史组成的树。

**它一般不完备。**

若树中有一条无限分支，其长度为 \(n\) 的前缀记为 \(s_n\)，则

\[
d_\rho(s_m,s_n)=\rho^{\min(m,n)}\longrightarrow 0.
\]

所以 \((s_n)\) 是柯西序列。但其极限应当是整条无限路径，而无限路径不属于有限节点集合 \(T\)。

因此：

> “前缀树节点 + 前缀距离”本身通常是不完备的；它的完备化会加入无限分支。

### 对象 B：树的全部无限分支空间

定义

\[
[T]=
\left\{
x\in A^\omega:
\forall n,\ x\!\upharpoonright_n\in T
\right\}.
\]

则 \([T]\) 在前缀距离下完备。

证明很直接：若 \((x_m)\) 是柯西序列，则对任意前缀长度 \(n\)，从某个 \(m_n\) 开始，所有 \(x_m\) 的前 \(n\) 个坐标都一致。用这些稳定坐标定义 \(x\)。于是 \(x_m\to x\)，且 \(x\) 的每个有限前缀均属于 \(T\)，故 \(x\in[T]\)。

也可以说：\(A^\omega\) 完备，而 \([T]\) 是其中的闭集，所以 \([T]\) 完备。

### 对象 C：实际允许的完整市场路径集合 \(X\subseteq A^\omega\)

令 \(T_X\) 为 \(X\) 中所有路径的有限前缀组成的树，则

\[
\overline X=[T_X].
\]

因此：

\[
X\text{ 完备}
\quad\Longleftrightarrow\quad
X\text{ 在前缀拓扑下闭}
\quad\Longleftrightarrow\quad
X=[T_X].
\]

最后一个等式的含义是：

> 只要一条无限路径的每个有限前缀都分别曾经出现在某条合法路径上，就必须把整条无限路径也认作合法路径。

第30课没有提出这条闭包公理。

## 1.3 两个方向都不成立

### 反例一：价格充分有效不推出完备

取

\[
X_{\mathrm{fin}}
=
\left\{
x\in\{0,1\}^{\omega}:
x\text{ 中只有有限个 }1
\right\}.
\]

规定每条历史严格追加、已经写入的坐标不得修改。于是该系统完全可以满足第30课的时间不可逆和不可回写要求。

但令

\[
x^{(m)}=1^m0^\omega.
\]

则 \((x^{(m)})\) 是前缀距离下的柯西序列，并且

\[
x^{(m)}\longrightarrow 1^\omega.
\]

而 \(1^\omega\notin X_{\mathrm{fin}}\)。所以 \(X_{\mathrm{fin}}\) 不完备。

这里每条实际历史都不可回写；缺失的是“所有相容极限路径也必须合法”的闭包条件。

因此：

\[
\text{价格充分有效}\centernot\Longrightarrow\text{路径空间完备}.
\]

### 反例二：完备不推出价格充分有效

取完整二进制路径空间

\[
X=\{0,1\}^{\omega}.
\]

它在前缀距离下完备。

现在给系统增加一条操作规则：允许交易机构事后修改已经写入的第 \(k\) 个坐标，或撤销过去的成交。允许路径的状态集合仍然是 \(X\)，其完备性没有变化；但第30课要求的不可回写性质已经失败。

因此：

\[
\text{路径空间完备}\centernot\Longrightarrow\text{价格充分有效}.
\]

### 第一问裁断

\[
\boxed{
\text{价格充分有效与前缀路径空间完备一般互不蕴含。}
}
\]

两者至多“形状像”：都能用前缀语言表达；但一个是历史协议不变量，一个是路径集合的拓扑闭性。

若额外规定“实际允许路径集合就是所有无限分支 \([T]\)”，路径空间才完备。此时成立的是：

\[
\text{全分支闭包假设}
\Longrightarrow
\text{路径空间完备},
\]

而不是价格充分有效本身推出完备。

## 1.4 完备性本身能给什么

| 可得结论 | 是否由完备性单独给出 | 额外条件 |
|---|---:|---|
| 每个柯西路径序列在空间内收敛 | 是 | 无，这是定义 |
| 前缀逐渐稳定的完整路径序列存在空间内极限 | 是 | 该序列必须确为柯西序列 |
| 闭子空间仍完备 | 是 | 子空间须闭 |
| 不完备路径空间可以加上“理想极限路径”得到完备化 | 标准构造 | 新增路径未必有市场语义 |
| 嵌套非空闭集交非空且为单点 | 否 | 还需直径趋于零等条件 |
| 每个当前前缀都有无限未来 | 否 | 需树无终端节点或逐层可扩展 |
| 路径极限唯一 | 对给定收敛序列是 | 来自度量空间极限唯一，不等于未来唯一 |
| 空间紧致 | 否 | 还需全有界；前缀树场景常由有限分支提供 |
| 存在概率测度 | 否 | 需额外概率模型 |
| 存在最优路径或最优交易 | 否 | 需目标函数、紧致性或其他存在条件 |
| \(\operatorname{Div}_q\Rightarrow\operatorname{Turn}_q\) | 否 | 需要动力学桥 |
| \(\operatorname{Div}_q\Rightarrow\neg\operatorname{Ext}_q\) | 否 | 仍然需要 \(EM_q\) 或同等内容 |
| 唯一不动点 | 否 | 需要自映射及压缩常数等条件 |

尤其要注意：

\[
F_n=[n,\infty)\subset\mathbb R
\]

是一列嵌套非空闭集，\(\mathbb R\) 完备，但

\[
\bigcap_{n=1}^{\infty}F_n=\varnothing.
\]

所以“完备 + 嵌套 + 非空”本身都不足以保证交非空，更不保证交为单点。

## 1.5 `030:28` 不能承担任何不动点证明

`030-第30课.md:28` 使用的是：

> “这种绝对性就如同压缩影射不动点的唯一性对完备的距离空间一样。”

承重词是“**如同**”。原文没有给出：

- 一个自映射 \(F:X\to X\)；
- 一个压缩常数 \(0<c<1\)；
- 一列迭代 \(x_{n+1}=F(x_n)\)；
- \(F\) 与逐级定位、市场更新或级别塔之间的对应；
- 不动点与某个买卖位置之间的语义等式。

因此本句只能说明作者用一个数学定理类比“理论绝对性”，不能反向抽取出 Banach 不动点证明。

即使人为补出完备路径空间，也仍然没有压缩映射。完备性只是 Banach 定理的一项前提，不是整条定理。

第一节最终裁断：

\[
\boxed{
\begin{aligned}
&\text{价格充分有效}\not\Longleftrightarrow\text{路径空间完备};\\
&\text{完备性只提供柯西极限闭合};\\
&\text{它不产生动力学、压缩映射或唯一未来。}
\end{aligned}}
\]

# 二、有限纵向链能证到多弱

## 2.1 集合论命题

设已经给定一列集合：

\[
I_q\supseteq I_{q-1}\supseteq\cdots\supseteq I_0.
\]

则：

\[
\bigcap_{k=0}^{q}I_k=I_0.
\]

证明只有两步。

由 \(I_0\subseteq I_k\) 对所有 \(k\) 成立，

\[
I_0\subseteq\bigcap_{k=0}^{q}I_k.
\]

另一方面，\(I_0\) 本身就是参与求交的集合之一，所以

\[
\bigcap_{k=0}^{q}I_k\subseteq I_0.
\]

故相等。

这条证明甚至不使用：

- 严格包含；
- 区间结构；
- 非空性；
- 有限性；
- 度量；
- 完备性；
- 测度。

只要集合族中有一个最小成员 \(I_0\)，任意多个包含它的集合与它求交，结果就是它。

因此票面命题的交集部分确实是平凡命题。

---

## 2.2 “存在且唯一”究竟证明了什么

若再假设

\[
I_0\neq\varnothing,
\]

则交集非空。

这里的“唯一”最多表示：

> 对这条已经选定、已经完整构造到 \(I_0\) 的链，交集这个集合唯一等于 \(I_0\)。

它不表示：

1. \(I_0\) 内只有一个点；
2. 最低级别只有一个候选区间；
3. 不同候选链产生相同的 \(I_0\)；
4. 算法必然能够构造到 \(I_0\)；
5. 当前在线时刻已经有一个完成、可确认的 \(I_0\)。

即使每一步都是严格包含

\[
I_{k-1}\subsetneq I_k,
\]

\(I_0\) 仍可包含很多时间点、成交或 K 线。

原文对此限制写得很清楚：

- `027-第27课.md:40`：“当然，这只是最理想的情况”，因为级别不能无限向下，所以不能证明极限式点状结果；
- `027-第27课.md:48` 只在“**如果这个最低级别是可以达到每笔成交的**”这一条件下，讨论精确到一笔；
- `027-第27课.md:50`：“**当然，由于级别不是无限可分的，不可能达到数学上唯一一点的精度。**”

所以正确结论是：

\[
\boxed{
\text{有限链的终点是最低级别区间，不是数学上的唯一点。}
}
\]

---

## 2.3 包含关系从哪里来

原文确实提供了纵向包含的形态依据：

- 在万科实例中，月级对应段“**一定在**”季度对应段中，“而且区间比之小”，`027-第27课.md:38`；
- 该定位程序被概括为不同级别对应段“逐级收缩”，`027-第27课.md:44`；
- 方法要求重复进入下一层，“反复进行下去，直到最低级别”，`027-第27课.md:46`；
- 任意 \(q\) 级走势类型至少由三个 \(q-1\) 级走势类型组成，`017-第17课.md:58`；
- 高级别走势由低级别走势连接构成，并可重组为次级别连接，`035-第35课.md:22-24`。

这些依据足以支持一个**条件式形态命题**：

> 若已经选中了父走势内部的某个真实子走势，并把父子映射到同一原始时间坐标，则子走势的支持区间包含于父走势的支持区间。

但它不能单独支持更强的动力学总性命题：

\[
\operatorname{Div}_q
\Longrightarrow
\exists\,\operatorname{Div}_{q-1}.
\]

原因是：

1. 走势由次级别走势组成，只证明**子走势存在**，不证明那个子走势满足 \(\operatorname{Div}_{q-1}\)；
2. 第72课明确把所有 \(\operatorname{Div}_q\) 判定划入动力学，形态学不自动赠送，`072-第72课.md:32-40`；
3. `017-第17课.md:70-72` 只说 \(\operatorname{Turn}_q\) 由“某级别”第一类点构成，并明确限制“**不一定是次级别**”；
4. 教义正本已经把一般化命题
   \[
   \operatorname{Div}_q\Rightarrow\operatorname{Div}_{q-1}
   \]
   降为 `[新缠论:选择]`，即区间套算法的工作假设，而非原文已证明定理，见 `.chanlun/definitions/beichi.md:349-356`。

因此必须拆开：

\[
\underbrace{\text{父走势中存在端点对齐的子走势}}_{\text{形态结构}}
\]

和

\[
\underbrace{\text{该子走势满足 }\operatorname{Div}_{q-1}}_{\text{动力学分类}}.
\]

第一句有较强结构依据；第二句不是免费的。

## 2.4 严格包含是否成立

证明交集等于 \(I_0\) 根本不需要严格包含。

若要证明

\[
I_{q-1}\subsetneq I_q,
\]

至少还需要：

1. \(I_q\) 和 \(I_{q-1}\) 使用同一原始时间或索引坐标；
2. 子对象确实是父对象的组成部分；
3. 子对象不是整个父对象本身；
4. 当前级别存在满足语义谓词的候选；
5. 多候选时已经固定选择规则；
6. 选中对象已经完成，而不是在线未完成片段。

原文的万科实例和“逐级收缩”表达了严格缩小的意图，`027-第27课.md:38-46`；但它没有把上面六项写成一个全称形式定理。

当前实测显示的是更窄的实现不变量：

- #852 的 3970 个对齐步骤全部满足子区间包含于父区间；
- 左端点全部严格右移；
- 右端点全部相等，因为查找键就是相同的 `source_index`。  
  见 `.chanlun/review-results/issue852-nesting-descent-20260802.md:99-116`。

所以当前实现形成的是：

\[
[a_0,b]\supsetneq[a_1,b]\supsetneq[a_2,b]\supsetneq\cdots,
\]

即右端固定、左端单调右移的单边收缩。它是有效的嵌套形状，但主要由端点查找键结构性保证，不是动力学总性定理的证据。

---

## 2.5 下钻何时停止，何时失败

### 正常停止

1. **达到人为或结构选定的最低级别。**  
   第17课明确说级别不能无限向下，最低级别须改用单位 K 线定义，`017-第17课.md:38-40`。

2. **低于真正能够定义 \(\operatorname{Div}_0\) 的结构层。**  
   第65课明确区分：最低中枢/走势类型以下只能做类似力度比较，不能继续当作真正的 \(\operatorname{Div}_0\)，`065-第65课.md:94`。

3. **实际操作主动在较粗级别停下。**  
   `027-第27课.md:48` 说明一分钟范围通常已经足够；`065-第65课.md:94` 也说大资金通常无须钻到线段以下。这是操作停止，不是数学失败。

### 失败或提前终止

逐层过程可在 \(e>0\) 停止，原因包括：

- 找不到端点或时间坐标对齐的子走势；
- 子走势存在，但不满足 \(\operatorname{Div}_{e-1}\) 谓词；
- 同一级有多个候选，而没有选择器；
- 候选尚未完成，在线状态不能确认；
- 父子使用不同坐标或不同分解，无法证明包含；
- 当前塔的最低层只是实现基底，未必等同教义上的最低可操作层。

若实际只构造出

\[
I_q\supseteq\cdots\supseteq I_e,
\]

那么能证明的只有

\[
\bigcap_{k=e}^{q}I_k=I_e.
\]

此时根本没有 \(I_0\)，不能继续写“最精确区间等于 \(I_0\)”。

### 第二节裁断

有限链命题应分成两层：

\[
\boxed{
\text{给定完整链后，交集等于最小成员：平凡且成立。}
}
\]

\[
\boxed{
\text{完整语义链必然存在并走到 }I_0\text{：公开原文和当前实装均未证明。}
}
\]

# 三、五项跨级测度主张逐条裁断

设每一级可能有测度空间

\[
(\Omega_q,\mathcal F_q,\mu_q).
\]

原文从未直接定义这组对象，因此以下命题只能逐项作为建模选择审查。

| 主张 | 本仓塔上的裁断 | 额外假设 | 原文依据及限制 |
|---|---|---|---|
| 父走势等于子走势的不交并 | **一般不成立；最多可在原始时间原子层条件成立** | 统一原子坐标、半开区间边界规则、完整覆盖、无重叠 | `017-第17课.md:58`、`035-第35课.md:22-24` 只给连接和分解；`017-第17课.md:38` 的中枢恰由多个子走势的重叠部分构成，不能把价格区间直接说成不交并 |
| 父子级共用同一测度空间 | **不免费** | 共同样本空间 \(\Omega\)、各级结构为同一空间上的可测映射、共同 \(\sigma\)-代数 | `030-第30课.md:14` 可把成交看成最低时间单位上的重复事件，但没有定义 \((\Omega,\mathcal F,\mu)\) |
| 跨级投影保测度 | **不成立，除非另行定义** | 投影 \(\pi_{q-1,q}\)、可测性，以及 \(\mu_q=(\pi_{q-1,q})_*\mu_{q-1}\) 或其他权重守恒规则 | 多个子对象聚合成一个父对象是多对一映射；普通计数测度通常不会被保留 |
| 各级重新归一化 | **没有原文依据，也不是测度公理要求** | 明确每一级的条件样本、分母和权重 | 若每个父对象和每个子对象都独立归一为质量 1，就不再是同一测度；要兼容需条件概率或混合权重 |
| 递归聚合兼容 \(\sigma\)-可加性 | **一般不成立** | 聚合必须退化为同一测度空间内对两两不交可测集合的并 | 走势聚合还使用重叠、极值、方向、完成状态等非线性结构；`035-第35课.md:24` 只证明连接运算结合，不证明加法性 |

## 3.1 父对象不是简单集合并

若把一段父走势视为原始成交索引集合，在边界采用

\[
[t_0,t_1),[t_1,t_2),\ldots
\]

这样的半开区间，则可以人为构造不交并：

\[
\operatorname{support}(P)
=
\bigsqcup_j\operatorname{support}(C_j).
\]

但父走势还包含：

- 方向；
- 中枢；
- 完成状态；
- 级别；
- 极值；
- 连接次序。

所以作为缠论对象，

\[
P\neq\bigsqcup_j C_j.
\]

至多是其原始时间支持可以这样分割。

## 3.2 共同原子空间可以建，但不是原文结论

可以选择所有成交或最低级 K 线为共同原子空间 \(\Omega\)，然后把各级走势定义为

\[
F_q:\Omega\longrightarrow S_q
\]

或定义为 \(\Omega\) 上的可测分区。

这是一条合理的现代形式化路线，但它是本仓新增建模，不是第17、30、35课已经证明的内容。

## 3.3 “定义成推前测度”不等于发现保测度定理

若有跨级投影

\[
\pi:\Omega_{q-1}\to\Omega_q,
\]

可定义

\[
\mu_q(B)
=
\mu_{q-1}\!\left(\pi^{-1}(B)\right).
\]

此时 \(\mu_q=\pi_*\mu_{q-1}\) 由定义成立。但这只是选了推前测度，不能反过来说原始级别塔天然保测度。

特别地，三个子对象聚合为一个父对象时：

- 子级计数质量可能是 3；
- 父级计数质量是 1。

普通计数测度显然不保。

## 3.4 分级归一化会改变测度

若每级都规定

\[
\mu_q(\Omega_q)=1,
\]

则不同级别拥有各自概率测度。这不与建模冲突，但需要写出跨级权重：

\[
\mu_q(P)
=
\sum_{C\in\operatorname{children}(P)}
w(C\mid P)\mu_{q-1}(C).
\]

缺少 \(w(C\mid P)\) 时，逐级归一化和跨级加法之间没有自动兼容性。

## 3.5 有限级别不需要“无限细分免费”

即使每个 \(\mu_q\) 都是标准测度，\(\sigma\)-可加性也只在**同一个测度空间内、两两不交的可测集合族**上工作。

它不会自动跨越：

- 不同 \(\Omega_q\)；
- 不同 \(\mu_q\)；
- 非线性的走势聚合；
- 相交的中枢结构；
- 有限级别塔的层间关系。

本票研究的是有限级别塔。对应的层间聚合即使能够测度化，主要需要的也只是有限加法。它不产生任何无限下钻极限。

第三节总裁断：

\[
\boxed{
\text{五项均非测度论免费结论；每一项都需要额外结构。}
}
\]

# 四、与当前实装对账

## 4.1 结构下钻已经实现

Rust 的 `RMove` 分为：

- `Segment`：递归底；
- `Compose { subs, ... }`：封装真实次级别对象。

`descend` 对 `Compose` 返回 `subs`，对 `Segment` 返回空序列，见：

- `rust/src/theta_v0/classifier/descend.rs:107-120`；
- 对应测试 `rust/src/theta_v0/classifier/descend.rs:239-284`。

Lean 侧同样证明：

- `descend_compose` 为定义等式；
- `descend_segment` 返回空；
- 良构 `Compose` 下钻后级别减一。  
  见 `formal/Origin/SubLevelDescent.lean:95-137`。

因此以下结构事实已经锁住：

\[
\text{良构父对象}
\Longrightarrow
\text{存在组成它的子对象序列},
\]

以及：

\[
\operatorname{level}(\text{child})
=
\operatorname{level}(\text{parent})-1.
\]

但这仍然没有证明选中的子对象满足 \(\operatorname{Div}_{q-1}\)。

---

## 4.2 区间证书证明的是条件式良构

Rust 的 `nest.rs` 定义：

\[
\operatorname{Sub}(J',J)
\iff
J'.start\ge J.start
\land
J'.end\le J.end,
\]

见 `rust/src/theta_v0/classifier/nest.rs:68-73`。

空候选返回 `None`；唯一选择依赖字典序 `Sel_\Theta`，见 `nest.rs:75-95`。证书只检查已给链中相邻区间的包含关系，见 `nest.rs:128-140`。

文件头已经明确承认：

- 唯一定位依赖 `Sel_\Theta`；
- 缠论结构公理本身不给唯一候选；
- 该唯一性是 L0 纯结构归纳和同义反复。  
  见 `nest.rs:16-26`。

Lean 侧同样写明：

- 没有选择器时同一级可以有多个候选；
- 唯一性只是固定选择器后的结构结论；
- 不代表真实行情定位有效。  
  见 `formal/Strict/Nest.lean:24-44`。

`NestCertificate` 本身还把每级 `Candidate` 当作字段/前提，而不是从包含关系中推出，见 `formal/Strict/Nest.lean:195-222`。

所以当前证书表达的是：

\[
\left(
\begin{array}{c}
\text{每级候选已经存在}\\
\text{选择器已经选定}\\
\text{相邻包含已经成立}
\end{array}
\right)
\Longrightarrow
\text{链结构良构且定位键唯一}.
\]

它不表达候选生成的总性。

## 4.3 当前实测：结构不断，语义标签大量失败

#846 已把失败拆成三类：

- A：到达递归底；
- B：找不到端点对齐子段；
- C：子段存在，但 `div_cand` 判为 `DivFalse`。

全历史读数中：

- 36,175 条链、37,689 次尝试，B 恒为 0；
- Type1、`lvl≥1` 为 301 条；
- 277/301 在第一步落入 C，即 92.03%；
- 24/301 至少成功一级；
- 11/301 到达塔底。  
  见 `.chanlun/review-results/issue846-type1-descend-continuity-20260802.md:144-183`。

这说明：

\[
\boxed{\text{结构对象取得到，但 }\operatorname{Div}_{q-1}\text{ 标签多数判不出来。}}
\]

不过不能立即把 C 类解释成市场事实，因为当前判据至少有两个已登记缺陷候选：

1. `rmove_dir` 对 `Compose` 只比较 `hi()`，不比较 `lo()`；
2. `div_cand` 缺少 \(\operatorname{Div}^{pan}_{q-1}\) 入口。

见 `docs/adr/0013-partition-machine-bidirectional-form.md:163-165`、`:296-298`。

#852 的较窄窗口进一步显示：

- `lvl≥1` Type1 只有 3/66 真正走到 L0；
- 没有一条成功下钻两级以上；
- 所有中断均为 `DivFalse`，`NoAlign=0`；
- 形式包含成立，但重复语义下钻没有发生。  
  见 `.chanlun/review-results/issue852-nesting-descent-20260802.md:51-116`、`:179-194`。

因此当前数据不能证明完整纵向链，也不能干净证明该链在市场中不存在。它证明的是：

> 现有递归塔的结构对齐良好；现有 \(\operatorname{Div}_{q-1}\) 分类器没有把这些结构对象普遍识别为下一层候选。

## 4.5 对不上究竟是谁的问题

分层回答：

### 集合论定理没有被实装反驳

一旦实装真的生成完整证书

\[
I_q\supseteq\cdots\supseteq I_0,
\]

则交集等于 \(I_0\)。`nest_valid` 正是在检查这个条件式结论。

### 票面命题的问题

票面把 \(I_0\) 写进前提，再从中推出 \(I_0\) 存在，相当于把最难的部分预先假设掉。它没有覆盖候选生成失败、标签失败和多候选选择。

### 实装的问题

当前实装也没有实现或证明完整语义链：

- Type1 生产路径结构性不下钻；
- 默认门关闭；
- `div_cand` 语义面不完整；
- 已知方向启发式可能错配；
- 证书主要验证传入候选，不证明候选必然产生。

所以不是二选一：

- **数学命题的问题**：命题太弱，假设了它想证明的存在性；
- **实装的问题**：即使采用更强的语义目标，当前实现也尚未满足其前提。

# 五、是否进 Lean

## 5.1 平凡命题可以怎样写

可以写成类似：

```lean
theorem inter_eq_bottom
    (I : Fin (N + 1) → Set α)
    (hbottom : ∀ i, I 0 ⊆ I i) :
    (⋂ i, I i) = I 0 := by
  apply Set.Subset.antisymm
  · intro x hx
    exact Set.mem_iInter.mp hx 0
  · intro x hx
    exact Set.mem_iInter.mpr (fun i => hbottom i hx)
```

若要交非空，还必须另加：

```lean
hne : (I 0).Nonempty
```

注意：

- `N` 的有限性没有承担实质工作；
- 严格嵌套没有承担实质工作；
- 级别结构没有承担实质工作；
- \(\operatorname{Div}_q\) 谓词没有出现在证明中；
- 子候选存在和选择总性被完全藏进 `I` 已经定义这一前提。

这只是把两行集合论证明交给 Lean 重复检查。

## 5.2 仓内已有更诚实的同类形式化

`formal/Strict/Nest.lean:24-40` 已明确写出：

- 唯一性依赖 `Sel_\Theta`；
- 证明是 L0 纯结构归纳；
- 信息增量是同义反复；
- 不冒充真实行情有效性。

`formal/Origin/SubLevelDescent.lean:123-137` 只证明良构结构下级别递减和递归终止，不证明每一级存在合格的 \(\operatorname{Div}_{q-1}\) 候选。

因此再增加一个 `inter_eq_bottom` 不会提升形式化覆盖面。

## 5.3 真正值得进 Lean 的命题

未来若要进 Lean，应该证明的是证书生成器的部分正确性：

\[
\operatorname{buildCert}(x)=\operatorname{some}(\chi)
\Longrightarrow
\begin{cases}
\text{每一级 Candidate 谓词成立};\\
I_{k-1}\subseteq I_k;\\
\operatorname{level}_{k-1}<\operatorname{level}_k;\\
\text{终端候选已确认};\\
\text{选择结果满足 }Sel_\Theta.
\end{cases}
\]

更强的总性命题则是：

\[
\forall x\in\mathcal D_q,\quad
\exists\chi,\ 
\operatorname{buildCert}(x)=\operatorname{some}(\chi).
\]

当前实测和判据缺口尚不支持后一条；形式化它只会把尚未成立的业务假设写成 Lean 前提。

### Lean 裁断

\[
\boxed{
\text{本轮有限交集命题过于平凡，不值得新增 Lean 文件或运行 lake build。}
}
\]

这符合票面允许的退出条件：“若第二节判下来命题平凡，则不值得进 Lean，如实说明。”

# 六、#868 最终裁断

## 第一节

“价格充分有效”与前缀路径空间完备：

\[
\boxed{\text{不等价、一般互不蕴含，只是形式形状相似。}}
\]

完备性需要的是实际路径集合对前缀柯西极限闭合；第30课只给历史不可回写，没有给全分支闭包。

`030-第30课.md:28` 仍然只能按修辞处理，不能接压缩映射或唯一不动点。

## 第二节

\[
\bigcap_{k=0}^{q}I_k=I_0
\]

成立，但它是纯集合论平凡命题。非空性完全来自额外前提 \(I_0\neq\varnothing\)，不是该等式的推论。

纵向真正有内容的命题——逐级 \(\operatorname{Div}_{q-1}\) 候选存在并一直到 L0——没有被原文形态分解、测度论或当前实装证明。

## 第三节

五项跨级测度主张全部需要额外假设；没有一项是测度公理免费赠送。有限级别约束尤其排除了用无限细分极限兜底。

## 第四节

当前实装与条件式嵌套命题在结构面相容：

- `descend` 真正返回子对象；
- `is_sub` 检查包含；
- `Sel_\Theta` 给确定选择；
- Lean/Rust 都锁了级别递减和结构良构。

但完整语义链并未成立：

- 标签失败率高；
- 判据存在已登记缺件；
- Type1 生产路径不下钻；
- 三条生产消费链默认关闭。

## 第五节

不新进 Lean。已有形式化已经覆盖了这条 L0 结构同义反复；真正值得证明的证书生成总性目前没有可成立的前提。

## 最终一句话

\[
\boxed{
\text{本轮纵向路线没有得到新的非平凡存在唯一性定理。}
}
\]

得到的有效负结论是：

> 价格充分有效不等于路径空间完备；有限链的交集结论只是“最小成员已经存在”之后的集合论同义反复。缠论和实装真正尚未解决的是：每一级合格候选是否存在、如何唯一选取，以及该语义链能否实际走到最低级别。

本轮全程只读，未修改任何文件。
