## 0. 判决摘要

1. **账本存在论**：每层一本**带极性的账本**（多头书 = 在册 `OrganicLedger` 逐字；空头书 = 新类型 `ShortBook`），

2. **方向协变传导公式**：短差利润 π 对宿主账本的传导是单一公式 **basis ← basis − d·π/units**

   但其会计后果被 31 课禁加仓否决 ⇒ 不实装（声明=能力）（§2.4）。
4. **同股数定理**：方向翻转时 M = N（单位数跨翻转连续）——26:34"最开始多少就是多少"的量纲是单位数，
   配额轴与杠杆钳制轴正交（§2.5）。

   双向的全部新内容在**极性翻转位**（净暴露穿越 0），不在嵌套机制（§3.3，防声明膨胀）。

## 2. 双向会计体系（问题 A）

### 2.1 账本存在论：每层一本带极性的账本，物理净额执行

**裁决：双账本（按层、按极性分离），不是单一净额账本。** 三条理由：

1. **会计需要段归属**：绩效 = Σ|各段|要求每段涨跌有归属账本（哪一层、哪个方向捕获了它）。
   单一净额账本只有净暴露轨迹，段归属不可重建——净额是**执行表示**，不是**会计表示**。
2. **守恒律是极性专属的**（§2.4 非对称定理）：多头二相/空头单相不可折叠进同一状态机。
   在 `LedgerPhase` 上加方向位 = 允许"空头 EarningShares"这一 L0 不可构造状态可表示——违反"非法状态不可表示"
   （types.rs 模块设计原则）。
3. **符号污染禁令**：`total_shares: f64` 允许负值 + 下游 `max(0,·)` 截断/`was_earning` 分支 = 降成本提款机 bug
   的精确同型（v2 §9.3 在册警告）。类型层分离（`enum` 两变体）使污染编译不可达。

```
DirectionalBook ::= Long(OrganicLedger)        # 在册类型逐字，零改动
                  | Short(ShortBook)            # 新类型，§2.2

物理头寸(t) = Σₖ dₖ(t)·nₖ(t)                    # 净额执行（IBKR 强制净额化 / perp 单向持仓）
```

载体路由承接 v2 §0 载体表：同一工具双开**否决**在册；净额执行是默认形式；本文全部"多空并存"均指**虚拟账本层**。

### 2.2 空头书的严格定义 [镜像推导]

```rust
ShortBook {
    units: f64,                  // 空头单位数 U > 0（合约张数/借出股数），恒为正
    proceeds_basis: f64,         // 开空均价 B_s（多头 cost_basis 的极性镜像）
    cumulative_recovered: f64,   // 已实现短差利润累计（载体条件相的观测量，§2.4）
    legs: Vec<(SlotKey, OpenLeg)>, // 短差腿；空头书内的降成本腿 side = DiffSide::Long（先买后卖）
}
```

- **开空**：U 张 @ p₀ ⇒ B_s = p₀。现金流按载体显式声明：股票卖空收 proceeds（cash += U·p₀）；
  永续合约零现金流（保证金占用 U·p₀/L）。**虚拟账本统一用 proceeds 口径**（cash += U·p₀ 入账 + 等额买回负债），
  载体差异在执行层适配——两口径 NAV 恒等（§4.3 验证）。
- **空头利得**：平 u 张 @ p ⇒ realized = u·(B_s − p)。逐段归属：`ClosedCycle.profit = (sell−buy)·shares`
  在册公式两极性通用（字段按 side 赋值，ledger.rs:270-281 已实现）。
- **空头的"成本"**：B_s 是**单位收入基**——它越高，空头越有利。多头风险解除方向 = cost ↓，空头 = proceeds ↑。
  "降成本"在空头侧的精确含义 = **抬高开空均价**（§2.3 公式统一）。
- **空头的"挣股数"**：任务问"同样的资金能开更大的空头名义"——被 **31 课禁加仓直接否决**
  （「该买多少一开始就应该研究好，投入以后就不能再增加」，方向无关的名义上界条款）。
  严格形式 = 杠杆三元组浮盈三分法的镜像：**名义轨 fixed，已实现利润进缓冲轨**（改善保证金占用率/抬远强平价，
  等效降杠杆），名义扩容唯一合法入口 = 级别升级（triad §3.4）。

### 2.3 守恒律的方向协变形式（核心公式）

在册多头股数守恒（ledger.rs:292-310）：腿利润 π ⇒ cost_basis −= π/S，股数不动。空头镜像：
反弹段短差（先买后卖）利润 π ⇒ proceeds_basis += π/U，张数不动。两者统一为：

> **basis ← basis − d·π/units**，d ∈ {+1（多）, −1（空）}
>
> 利润恒使 basis 向**风险解除方向**移动一个 π/units：多头向 0（直至相变），空头向 ∞（无不动点，§2.4）。

腿循环方向与宿主极性的关系（嵌套符号交替塔的双向延拓）：

| 宿主极性 d | 降成本腿循环 | DiffSide | 在册状态 |
|---|---|---|---|
| +1（多） | 先卖后买（高抛低吸） | Short | ledger.rs 在册全部路径 |
| −1（空） | 先买后卖（反弹低买高卖） | Long | `open_sub` Long 侧算术已实现（sub_long_cycle 测试在册），**宿主接入缺位** |

即：空头书的会计原语**已经存在**（DiffSide::Long 腿 + ClosedCycle 双向 profit），缺的是 ShortBook 宿主类型
与 LayerState::Short 承载位（v2 §4.1 四层不可表示的第①②层）。

### 2.4 非对称定理：空头书单相单律

**定理（L0）**：多头书的二相守恒律结构在空头书无镜像。证明分两支：

1. **相变不动点不存在**：多头 EarningShares 的存在论基础 = 损失有界于成本（c→0 时损失 ≤ cost_basis·S，
   cost_basis ≤ 0 ⇒ 任意路径不亏）。空头损失无界（c→∞）⇒ "无论价格怎么走都不亏"的状态对任何有限 B_s 不可达。
   B_s 单调上移无不动点。
2. **金额守恒算术未定义**：多头金额守恒 = 卖 V 买 V ⇒ 股数净增（现金↔股数双向可换，换率 = 现价）。
   空头开仓不是现金换单位（是保证金担保的负债创设）：买回 V 名义再开空 V 名义 @更高价 ⇒ 张数 V/p₂ < V/p₁
   反而**减少**——"金额守恒增单位"在空头侧符号反转且与负债创设机制不符。
   这与在册 `open_sub` 对 `EarningShares × Long 腿` 的显式拒绝（ledger.rs:240「金额守恒对 Long 循环的
   total_shares 算术未定义」）同根源——在册代码已经在腿层面碰到并正确拒绝了这条非对称。

**载体条件相（不实装）**：逐仓载体上损失有界于 posted_margin ⇒ 存在条件性不动点
cumulative_recovered ≥ posted_margin（最坏强平也不伤本金）。但该相的唯一会计后果候选（用利润扩名义）
被 31 课禁加仓否决 ⇒ **相变即使可构造也无消费者**。处置：`cumulative_recovered` 作纯观测量保留，
相不进类型系统（声明=能力；T5 疑点计数器同先例）。

### 2.5 26 课"同股数进出"与 49 课"满仓"的双向精确化

**同股数进出三形态**：

| 操作 | 多头侧（在册） | 空头侧 [镜像推导] |
|---|---|---|
| 短差 | 卖 N 股 → 买回 N 股（股数守恒） | 平空 N 张 → 再开空 N 张（张数守恒） |
| 削减/回复（hold26） | 卖点清 slice → 买点如数接回 | 买点（反弹起）平部分 → 卖点（反弹顶）回复空仓 |
| **方向翻转** | 平多 N → 开空 M | 平空 M → 开多 N |

**同股数定理（M = N）**：翻转时新书单位数 = 旧书平仓单位数。推导：
(i) 26:34「本ID的仓位是一直不变的，最开始多少就是多少」的记账量纲是**单位数**（权证份数/「100万股」）；
(ii) 31 课禁加仓 ⇒ 翻转不得成为变相扩名义（M·p_flip ≤ N·p_flip ⇒ M ≤ N）；
(iii) 无任何原文给出翻转缩量义务 ⇒ 取等号是与全部锚相容的最强读法。
单位数恒定下名义随价格的被动漂移不是加仓（26:34 权证案例：价格上上下下、份数不变）。
**正交钳制**：杠杆约束可使 M < N（空头侧 L_max 用空头 D_struct 解出，§6）——配额轴给 M = N，
存活约束轴向下钳，两轴不混表。

**49 课"满仓"空头侧**：满仓 = 名义配额打满（leverage 前研三读法裁决在册，读法 iii），方向无关：
|qₖ| = Qₖ。空头满仓的保证金 = Qₖ/L_max_short(k,t)，L_max_short 见 §6。
满仓**义务**的相位条款镜像：49:52「中枢向上移动时就应该满仓」⇒ [镜像] 中枢向下移动时（MoveDown 锁定相）
应满空仓、停止反弹短差回补——这恰是 P6 相位机 `LayerPhase::MoveDown`（positional_fusion.rs:120，
confirmed Sell3 锁定）的现成消费者：**在册代码已经会算 MoveDown 相，只是当前无人消费它的空头侧含义**。

## 3. 嵌套层间方向交替（问题 B）

### 3.1 层方向规则：hold26 极性域的对称延拓

> **dₖ(t) = 层 k 最近一次 confirmed 买/卖点的极性**（买点 → +1，卖点 → −1）。
> 仓位状态空间：{+Qₖ, −Qₖ}（+ 铰链部分态），取代在册 {+Qₖ, 0}。

- 震荡相（Osc）无方向 ⇒ 极性**滞回保持**（与在册一致：仓位穿越震荡持有，削减/回复不改极性）。
  这消解了"永远有方向"与"盘整无方向"的表面冲突：方向是**仓位极性**（上一信号的奇偶），
  不是当下走势的方向读数——盘整中仓位极性 = 进入盘整前的方向，正是 38:36 程式的字面行为
  （向上段运作直到卖出条件，才进入向下段运作）。
- 走势方向的正典来源 = 中枢（走势方向代理陷阱在册）：翻转词汇 = confirmed 买卖点 + P6 相位机三值，
  不用 swing 代理。
- 创世前（首个 confirmed 信号未到）：无操作对象，配额未部署——这不是 FLAT 状态，是定义域外。

每层 FSM 形状与 hold26 完全同构（二态 + 信号翻转 + 铰链中间态）——**双向不是新状态机，是状态空间的
极性反射加倍**。

### 3.2 净暴露与部分对冲的身份

> E(t) = Σₖ dₖ(t)·nₖ(t) ∈ [−N_top, +N_top]（嵌套守恒 Σ|nₖ| = N_top 不变，triad 定理 2）

层间方向分歧（高层 +Q₅、中层 −Q₃）的物理形态在净额执行下是**净头寸缩小**——不存在物理对冲持仓
（同工具双开否决在册）。"部分对冲"只在虚拟账本层存在，其身份：

- **不是 bug（不减利润）**：望远镜恒等式（v2 §5.4）保证各层收割 TV⁽⁰⁾ 的不相交分量——层 k 的捕获只依赖
  本层段端点，与其它层持仓零交互（零摩擦）。层 k 翻空收割的 2Rₖ 反向流恰是层 k+1 看不见的抵消分量。
- **是结构（38 课短差的双向延拓）**：单向系统中层 k 卖出持币 = 净暴露从 N_top 降到 N_top − nₖ；
  双向系统中层 k 翻空 = 再降 nₖ 到 N_top − 2nₖ。原文的短差**本来就是**净暴露的部分削减，
  双向只是让削减穿越每层配额的零点。
- **真实成本在保证金维度**：虚拟保证金 Σ nₖ/Lₖ 按总量计提（§6.3），方向分歧不减少计提
  （层间独立性的物质前提，triad 推论三）——净额化的保证金节约全部进机动池缓冲轨。

### 3.3 净额等价警告：嵌套不是双向的载体（防声明膨胀）

**任务句式"上层持多 → 次级别开空 → 空头利润降多头成本"在 m ≤ N 域是在册机制的会计重述。**
净额等价定理（v2 §2，L0）：上层持多 N、次级开空 m ≤ N 的 P&L/净暴露/摩擦轨迹与"削减 m 再回补"
逐点相同。在册的 SubOut 铰链（fusion）、osc/rev 腿（organic）、SubLou 符号交替塔（organic，休眠）
**已经是**这个机制。把它重新实现一遍并称为"双向嵌套"= 090 号声明膨胀。

**双向的全部新内容压缩在两处**：

1. **极性翻转位**（本文主对象）：层 k 的削减穿越 0 到 −Qₖ——这是 m > N 域（v2 推论 2），
   嵌套守恒不覆盖，需要新会计（§2 空头书）。
2. **奇数深度子腿的宿主延拓**：空头宿主内的反弹腿（DiffSide::Long）从"REV 窗口内的探索变体"
   升格为空头书的标准降成本腿——算术已在册（ledger.rs:417 测试），宿主缺位。

### 3.4 层间会计传导：降成本路径 vs 权益路径

次级别短差利润 π 的两条传导路径（NRF 层内 C 机制分岔的双向延拓，在册分岔未裁决）：

| 路径 | 会计动作 | 改什么 | 不改什么 | 在册载体 |
|---|---|---|---|---|
| **A. 降成本传导** | basis ← basis − d·π/units | 宿主 basis（推进多头相变时点/空头风险解除深度） | units、pool | organic 族（cost_basis 串行递推） |
| **B. 权益传导** | pool += π；宿主 entry 重锚到回补点 | 可部署资金、trade 行归因 | 宿主 basis 概念（fusion 无 basis） | fusion 族（try_restore 重锚，positional_fusion.rs:232-239） |

零摩擦下两条路径 NAV 轨迹恒等（π 都进了净值）；差异全在下游耦合——A 推进守恒律相变（was_earning 切换），
B 推进配额再部署。**双向不新增第三条路径，也不裁决 A/B**（那是 NRF 分岔的事）；
双向加入的唯一新条款：**空头宿主下路径 A 的符号由 §2.3 协变公式给出**（B_s 上移），
路径 B 的重锚语义极性无关（entry 重锚对空头书同样成立）。

### 4.2 层间守恒（嵌套守恒的双向延拓）

> **总名义守恒**：Σₖ |dₖ·nₖ| = N_top（极性不进绝对值外——翻转不产生名义，triad 定理 2 极性无关）
> **净暴露域**：E(t) = Σₖ dₖnₖ ∈ [−N_top, +N_top]（在册 [0, N_top] 的对称延拓）
> **子腿预算**：budget(子腿) = 父腿在本节点域内释放的敞口（open_sub 在册，极性无关）——
> 子腿名义 ≤ 父腿名义恒成立 ⇒ 嵌套永不放大 Σ|nₖ|

### 4.3 NAV 恒等式（双向）

> **NAV(t) = pool + Σ_{k∈多头层} Sₖ·c + Σ_{k∈空头层} [marginₖ + Uₖ·(B_{s,k} − c)] + Σ escrow**

proceeds 口径下等价形式：NAV = cash + Σ Sₖ·c − Σ Uₖ·c（空头是负资产，开空所得已在 cash）。
两口径恒等（差一个 marginₖ + Uₖ·B_{s,k} 的左右移项）。**逐 trade 行重建 = final_nav 的在册 assert

## 5. 方向翻转的精确时序（问题 D，44 课铰链）

### 5.1 铰链三岔：渐进翻转的原文机制

44:44 原文（verbatim 在册）：「就必须先出一部分，然后在出现上一段所说的情况时在出清。当然，如果没有出现
上一段所说的情况，就可以回补，权当弄了一个短差。」

双向延拓后同一笔卖出的事后路径从两岔变三岔：

```
+Q ──次级别卖点：先出 q（身份未决）──→ +Q−q
        ├─ k−1 买证据先到 ⇒ 如数接回 → +Q          （短差，C 路径，在册 try_restore）
        ├─ 趋势相（MoveUp）开始 ⇒ 强制回补 → +Q     （满仓义务，在册）
        └─ 本级别卖点 confirmed 先到 ⇒ 出清 Q−q 并**反手开空 Q'=Q（同股数定理）** → −Q
                                                    （hinge_escalate 的双向延拓：升级=减仓→翻转第一笔）
```

**翻转是渐进的，确认是原子的**：铰链卖出（q）是翻转的试探性第一笔（身份事后授予，在册判决同构）；
本级别卖点 confirmed 的那个 bar，剩余翻转一步完成（平 Q−q + 开空 Q）——依据 38:36 向下段运作起点全量
（背驰点开始先卖）+ 26:34「一开始就买够」的镜像。物理执行 = 单笔净额单 −(2Q−q)；
会计分解为两行 trade（平多行 + 开空行）——段归属核算（Σ|段|）的硬要求，不可合并记账。

### 5.2 翻转 = 会计断面（cascade settle 定理）

**任务 D4**：高级别翻空时，正在做"降成本短差"的次级别空头腿变成与新方向同向——它的身份是什么？

**裁决：翻转点是会计断面，全部子腿 cascade settle，不做 sign-label 原地翻转。** 推导：

1. 子腿预算基 = 旧父腿释放的敞口（open_sub 语义）——父腿消灭 ⇒ 预算基消灭 ⇒ 腿的存在前提消灭。
   保留腿并改签方向标签 = 腿的名义失去预算锚（嵌套守恒不可审计），且其利润归属（旧书 basis）与
   新书无桥——同一笔腿钱进两本书 = 重复计账。
2. 在册同构先例：`cascade_close`（父腿闭合强平未决子树，n_sub_forced_close 计数）+ 升级负债定理
   "并入不独立保留"（triad §3.2：独立保留 = 同一物理持仓挂两个否定价的构造性矛盾）。
3. settle 后若新书的次级别条件独立成立（空头宿主 + 次级反弹起点），按新书谓词**重新开腿**——
   新腿预算基 = 新父腿，账目从零开始。重开不是延续：开腿价 = 当下价，旧腿利润已落袋进旧书。

时序（翻转 bar 内的强制顺序）：①子树 cascade settle（利润按 §2.3 进旧书 basis / 按路径 B 进 pool）→
②旧书平仓（realized 进 pool，trade 行落账）→ ③新书开仓（M = N）→ ④新书子腿按各自谓词惰性实例化。
①②③ 同 bar 同价（净额单一次成交），会计上严格分序——逐 trade 重建 NAV 的前提。

### 5.3 "无 FLAT"的严格形式

master FSM 状态空间不是 {LONG, SHORT} 两点集，是：

> **{+Q} ∪ {+Q−q : 铰链在外} ∪ {−Q} ∪ {−Q+q : 空侧铰链在外}**
> 0 ∉ 状态空间——零仓位只在翻转 bar 内作为执行中间值出现（测度零过渡），无任何 bar 以 0 收盘驻留。

例外路径穷举（声明=能力）：强平事件（杠杆失格 ⇒ 仓位归零是违规态进入，fail-fast 非状态）；
成本门/容纳量把某层配额判 0（该层定义域外，非 FLAT）；创世前（§3.1）。
对照在册 runner.rs 三态（FLAT/ARMED/LONG）：双向 master 删除 FLAT 与 ARMED 驻留
（fusion 族已无 ARMED——confirmed 直接消费，positional_fusion.rs:850 unreachable 在册）。
