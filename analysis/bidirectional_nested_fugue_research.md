## 0. 判决摘要

用户命题（"次级别反向线段=直接空单，反向线段内部反向=次次级别直接多单，对高级别只是短差"）
经形式化分解为**三个正交成分**，三者命运不同：

| 成分 | 内容 | 判决 |
|------|------|------|
| **(a) 层内虚拟双向** | 嵌套层的空腿/多腿符号交替塔 | **已实现**——`DiffSide::Short/Long` + `SubLou` 符号交替塔 + `SubMode::CounterSeg`。物理执行净额化与"双开"在 P&L 上**严格等价**（§2 净额等价定理） |
| **(b) 净空头暴露** | 空头量 > 多头持仓（总暴露为负） | **真实缺口**——当前架构 L0 三层不可表示（类型系统/FSM/守恒律）。原文有间接支持（38课镜像程式 + 84课做空程序）但 hold26 恒仓语义无空侧对称形式的原文锚 |
| **(c) 物理双开** | 同标的同时持有多头和空头两腿 | **操作层不可行且无意义**——IBKR 期货同合约强制净额化（美式期货账户 net 模式）；即使可行（加密 hedge-mode），P&L 与净额模式逐分相同而保证金双倍占用，是纯成本 |

**核心定理（§2）**：单标的、空头量 m ≤ 多头持仓 N 时，"持 N 多 + 开 m 空"与
"卖出 m 股后回补"的 P&L、净暴露轨迹、摩擦成本**三者全部逐点相同**。用户直觉中
"次级别直接的空单"在账本语义上已经由现有 REV 腿实现——每条 REV 腿就是一条虚拟空单
（开腿=卖出记 Short 腿，闭腿=买回平腿），区别仅是会计表述，不是机制缺口。

**唯一真实的新自由度是 (b)**：把"卖点削减到 0（空仓）"延伸为"削减穿过 0（净空）"。
其有效域 = 确认的下跌趋势主干（84课做空程序的形态），alpha 上界可在不写引擎的前提下
用磁带级理论上界先行估计（§7 阶段 1），上界不显著则不实装——这是严格性要求下的
低成本否证路径。

## 1. 原文穷举（任务 A 节）

### 1.1 理论的方向对称性——双向操作的最强原文锚

**38课（已验证，行 28-34）**：

> "这里，无所谓牛市熊市，例如，如果分解的级别规定是30分钟，那么只要30分钟上涨就是牛市，
> 否则就是熊市，完全可以不管市场的实际走势如何。"

> "向上段的运作，都是先买后卖的。一旦向上段的运作结束后，就进入向下段的运作。向下段的运作
> 刚好相反，是先卖后买，从刚才向上段结束的背驰点开始，**所有操作刚好反过来就可以**。"

"所有操作刚好反过来"是双向程式的直接原文形态：向下段的运作是向上段的**严格镜像**。
在 A 股 T+1 无融券语境下，"先卖后买"要求先持有筹码（卖出后回补）；在期货/加密双向市场，
同一句话的字面执行就是开空后平空。**原文给出的是镜像程式本身，市场制度决定其物理实现形式。**

**26课（已验证，行 34）**：

> "无论是先买后卖与先卖后买，效果是一样的，但很多人就只会单边运动，不会来回动，这都是坏习惯。
> 市场的无论涨还是跌，对于你来说永远是机会。"

形式对称性的第二处直接表述。但同一段落的恒仓语境必须完整引用：

> "本ID的仓位是一直不变的，最开始多少就是多少，上上下下，卖点的时候变少，买点的时候又回复
> 原来的数量，但绝对不加仓，一开始就买够。"

——hold26 基座的原文锚。注意：恒仓的"仓"是**多头股数**，卖点削减的下界是 0，
原文从未给出"削减穿过 0 进入净空"的表述。空侧恒仓（恒空头股数，买点削减空头/卖点回复）
是镜像推导（L0），**无原文逐字依据**。

并立、操作形态是机构级的"点火制造分化"而非融券卖空。这是 (b) 净空头暴露的原文存在性证明：

**57课（行 237）**：

### 1.4 38课短差的性质（任务 A.2）

38课操作程式（已验证，行 34）通篇是持券者语境："先卖出，然后必然有向下的第二段……
不跌破第一段低点，重新买入。"短差 = 卖出后回补，**原文层面无融券开空语义**。
但按 §1.1 的镜像条款，向下段程式在双向市场的字面执行即开空平空——这是制度变换下的
同一程式，标注为 declared 近似（与 44课铰链审计的两处 declared 近似同范畴）。

### 1.5 26课"同股数进出"在双向下的含义（任务 A.3）

原文恒仓的不变量是**多头股数在 {0, …, N} 内波动且峰值锚定 N**（"最开始多少就是多少"）。
双向扩展下的两种读法：

- **读法一（净额读法，与原文相容）**：恒仓不变量作用于**净暴露**——卖点时净暴露从 N 降到
  N−m（无论会计上记为"卖出"还是"虚拟空腿"），买点回复 N。空腿量 m ≤ N 是恒仓语义的
  内生约束。当前架构（SubOut 回补义务 + DiffSide 虚拟腿）就是此读法的实现。
- **读法二（双账本读法，原文沉默）**：多头账本恒 N，空头账本独立波动于 {0, …, M}。
  净暴露 = N − s(t) 可为负（s > N 时）。这就是成分 (b)，需要空侧恒仓锚——原文没有。

### 1.6 44课铰链在期货语境下（任务 E 节）

**44课（已验证，行 44）**：

> "就必须先出一部分，然后在出现上一段所说的情况时在出清。当然，如果没有出现上一段所说的
> 情况，就可以回补，权当弄了一个短差。"

任务假设""出"在期货语境可以是开反向仓位"——按 §2 定理，**该等价成立但不是扩展，

（bc_architecture_research 在册）对两种会计表述不变。

## 2. 净额等价定理（核心形式化）

**定理（L0，代数）**：设单一标的，多头持仓 N，在 t₁ 以价 p₁ 执行规模 m ≤ N 的"反向操作"，
t₂ 以价 p₂ 结束。两种会计形式：

- **回补式**：t₁ 卖出 m 股，t₂ 买回 m 股。期间持仓 N−m。P&L = m(p₁−p₂)，摩擦 = 2 笔。
- **双开式**：t₁ 开空 m 股（多头 N 不动），t₂ 平空。期间净暴露 (N) + (−m) = N−m。
  P&L = m(p₁−p₂)，摩擦 = 2 笔。

二者的 P&L、净暴露轨迹、摩擦成本逐点相同。差异仅在：

1. **保证金**：双开式占用 N+m 规模的保证金，回补式占用 N−m——双开式纯劣（除非交易所
   提供完全 offset，此时退化为净额=回补式）。
2. **物理可行性**：美式期货账户（IBKR 含）同合约强制净额，双开式的"开空"指令物理执行
   即为平多。双开只在 (i) 加密 hedge-mode (ii) 跨到期月合约 (iii) 期权对冲现货/期货
   三种载体上物理可分。
3. **会计粒度**：双开式天然给出每条腿的独立账目——但这正是当前架构 `SubOut`/`DiffSide`
   虚拟腿已经提供的（虚拟双向记账 + 物理净额执行）。

**推论 1**：m ≤ N 域内，"双向嵌套递归赋格"与"嵌套递归短差降成本"是同一对象的两种
坐标表示。alpha 增量恒等于 0。

**推论 2**：双向形态的全部真实新内容压缩在 m > N 域（净空头暴露）——即把恒仓削减的
下界从 0 移除。

**推论 3**：用户原话的逐层验证——"反向线段内部的反向线段，又在次次级别是一个直接的多单"：
该多单的资金 = 上一层空腿（虚拟卖出）在外的现金，先买后卖、金额循环、结束时不增股数。
这正是 `SubLou` 奇数深度 `DiffSide::Long` 反弹腿的既有语义（`level_operating_unit.rs`
符号交替塔：`depth % 2 == 1 ⇒ Long`）。**用户描述的嵌套形态在虚拟账本层已是在册架构**，
NRF 判决（`nested_recursive_fugue_results.md`）已给出其 L2 证据：CounterSeg 深度真实涌现
（BTC depth2=288）、E×S×Q OKLO 正交互 +2301%（探索性）。

## 5. 双向嵌套递归赋格的精确形式化定义

设递归塔层级 k ∈ A(t)（涌现集），每层带符号配额 q_k(t) ∈ ℝ（正=多，负=空）。

```
基座层 k_top：  q_top ∈ {0, +Q}（现行 hold26）或 {−Q, 0, +Q}（净空头扩展后）
              方向由 k_top 级别自身的买卖点程式决定（38课镜像条款：
              向上段先买后卖 ⇒ q>0 域；向下段先卖后买 ⇒ q<0 域）

嵌套层 k<k_top：腿方向 = (−1)^depth · sign(父腿方向)（符号交替塔，已实现）
              腿规模 ≤ |父层在外量|（虚拟腿约束，= §2 的 m≤N 净额域）
              腿生命周期 ⊂ 父腿生命周期（cascade_close，已实现）
              对父层账目 = 一次降成本短差（44课铰链，会计表述无关）

净暴露：      E(t) = Σ_k q_k(t)·leg_sign_k(t)
现行架构：    E(t) ∈ [0, Q]（削减下界 0）
净空头扩展：  E(t) ∈ [−Q, Q]（移除下界；E<0 仅当基座层处于向下段程式）
```

**与当前纯多头架构的差异 = 一个不等式约束的移除**（E ≥ 0），其余全部结构
（嵌套、符号交替、回补义务、铰链记账）双方相同。"双向"不是新架构，是现有架构
定义域的扩张。

## 6. 与相位递归路由的关系（任务 D 节）

统一配置调研（`unified_config_regime_research.md` §3）的相位递归路由：对锚层 k 自下而上
找第一个满足 ①¬in_trend(j) ②θ_q(j) 过门 ③强震荡 的级别 j 开 osc 腿。方向问题的回答：

1. **j 层震荡相内**（路由的准入域）：震荡无方向（盘整定义），osc 腿方向由进场侧决定——
   现行"先卖后买"（ZG 侧卖出、ZD 触线回补）对持仓基座是唯一合法形式：26课恒仓禁加仓
   ⇒ 先买后卖腿在多头基座上不可开（买入即超 N）。**双向路由在震荡域是伪问题**：
   93:22（E2 判据，已在册）"利用震荡进行短差操作，由于都是先卖后买"——原文直接钉死
   震荡短差的方向为先卖后买。
2. **j 层趋势相**（路由的拒绝域）：¬in_trend 门拦截，不开腿——双向扩展**不改变此门**。
   "j 层在下跌趋势 ⇒ 开空"不属于 osc 路由的管辖：下跌趋势中的操作是基座层程式切换
   （38课向下段运作 = 净空头域，成分 b），不是短差层路由。把它塞进 osc 路由会重演
   "门相位信息含量是 regime 函数"的混表（ledger_voice_regime 在册）。
3. **任务 D.2 的修正**：任务描述"双向路由应该方向=跟随 j 级别走势方向"不成立——
   j 由 ¬in_trend(j) 选出，j 层**没有**走势方向（震荡相）。方向自由度在基座层，
   不在路由层。路由层唯一的双向内容是反弹子腿（成分 a，SubLou Long 腿），其准入
   已由符号交替塔给出，与路由正交。

## 7. 实装方案（分阶段，每阶段独立可否证）

### 阶段 0（零代码）：成分 (a) 的激活判决——已有判决覆盖

### 阶段 1（磁带级，不写引擎）：成分 (b) 的理论上界估计——本调研建议的下一步

在现有磁带上计算"完美净空头"上界：对每个 confirmed 向下趋势段（trend_state ∧ dir==Down

fusion_t 基座的 equity 上（摩擦调整口径，10bps/侧）。产出：8 标的的净空头 alpha 上界表。

- 上界判据（预注册）：若 8 标的中位上界增益 < 在册最优的 10%（与 P1 的 90% 让步对称），
  净空头轴**关闭**，不进入引擎实装——确认滞后、空侧无停削保护、保证金成本只会让真实值
  远低于上界。
- 在册先验（压低预期）：fusion_t 熊市 α 6/6 全正且 bear 容差 0/5 破——卖点削减已经捕获
  熊市 alpha 的一部分（削减到 0 = 熊市零暴露），净空头的增量只是 0 与 −Q 之间的部分，
  且要付出牛市误判时无缓冲失血的对价（多头基座误判有持仓垫，净空头误判是裸亏）。

### 阶段 2（仅当阶段 1 过门）：净空头引擎实装

最小严格形式（拒绝补丁式"加个负号"）：

1. `LedgerPhase` 重写为带方向的三态代数（Long{cost} / Flat / Short{cost}），空侧 earning

   永久停留 CostReduction 相，且此限制显式声明）；

3. 基座程式切换 FSM：做多程序 ⇄ 做空程序是**串行切换**（84课形态），切换事件 =

## 9. 风险分析

1. **对冲效应（任务 C.5）**：上层 LONG + 下层 SHORT = 净暴露减少——既非 feature 也非 bug，
   而是 38课操作程式本身（避开向下段）的会计重述。真正的风险在把它误认为"新机制"而
   实装物理双开，付出保证金双占的纯成本。
2. **净空头的失血几何**：多头基座最大亏损有界（−100%），期货净空头名义亏损无界；
   现有 MDD 口径（hold26 系 −53.9%～−67.8% 在册）在净空头下需重新定义（空头浮亏可
   超过本金）。
3. **守恒律污染**：负股数进入现有账本会静默破坏 was_earning 守恒、cost_basis 相变、
   `max(0,…)` 截断（降成本提款机 bug 的教训在册：符号错误污染全部回测 alpha）。
   阶段 2 的三层重写是不可绕过的，任何"先加个负仓位字段"的渐进路径都是 no-patch 违规。
4. **原文权威风险**：空侧恒仓、空侧 earning、做空配额全部无原文锚。若实装，这些机制
   必须以"镜像推导（L0，无原文）"身份标注，不得声明为缠论机制——否则是声明膨胀（090号）。

## 10. 结果包（六要素）

1. **结论**：双向嵌套递归赋格三分解——(a) 层内虚拟双向已由 DiffSide/SubLou/CounterSeg
   实现且与物理双开 P&L 严格等价（净额等价定理）；(b) 净空头暴露是唯一真实新自由度，
   走阶段 1 磁带上界先行否证路径；(c) 物理双开零增量纯成本，否决。相位递归路由不需要
   方向参数（方向自由度在基座层）。
2. **定义依据**：38课行 28/34（分解无所谓牛熊 + 镜像条款"所有操作刚好反过来"，已验证）、
   26课行 34（恒仓 + 先买后卖/先卖后买等效，已验证）、44课行 44/142（铰链短差 + 先卖后买
   打短差，已验证）、84课（中期做空程序 + 期货对冲论反驳）、81课（减仓优于对冲）、
   57课（对冲风险废话）、35课（做空只为买回来）、40课（本ID做空假设）、93:22（震荡短差
   方向钉死先卖后买）。代码依据：`ledger.rs:26-29/220-242`、`level_operating_unit.rs:40-45/
   627-636`、`positional_fusion.rs:86-100`、`runner.rs:93-95`。
3. **边界条件**：(i) 净额等价定理的前提是单标的同合约——跨月合约/期权载体下双开物理可分，
   等价性不覆盖（期权轴独立）；(ii) "IBKR 期货同合约净额化"是经纪商制度事实，若改用
   hedge-mode 账户，物理双开可行但 §2 推论 1（零增量）仍成立；(iii) 阶段 1 上界若显著
   （≥在册最优 10%），成分 (b) 的怀疑立场翻转，进入阶段 2；(iv) 若原文权威链补录发现
   缠师对融券/双向的直接表述（来源不完备 002号先例），§1 沉默域表需重审。
4. **下游推论**：(a) "双向"作为研究轴从架构问题降格为定义域扩张问题（移除 E≥0 约束），

   脚本是下一个可执行工位（零引擎改动）；(c) 若阶段 2 启动，"空侧 earning 存在论"将
   触发矛盾上浮（挣负股数=债务清偿 L0 不可构造在册）；(d) 期权（COIL）作为唯一物理
