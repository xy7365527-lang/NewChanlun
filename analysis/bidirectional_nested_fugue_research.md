## 0. 判决摘要（v2 两轴重构）

v1 的"三个正交成分"被完备性质询否证（major）：(a)/(b) 是**暴露轴**上的分划（同一变量 m
的互补区域），(c) 是**载体轴**上的单个取值——两轴混排不是正交分解。v2 重构为两轴直积
（231号标注：此直积是 L0 整理，两轴在数据下的独立性未验证，禁止声明直积的经验有效性）：

**暴露轴**（线性同标的暴露 E 的分划，26课恒仓锚 E ≤ Q 下穷尽；E > Q 由"绝对不加仓"排除）：

| 区域 | 内容 | 判决 |
|------|------|------|
| **(a) E ∈ [0, Q]**：层内虚拟双向 | 嵌套层的空腿/多腿符号交替 | 净额等价定理域内与物理双开逐点等价（§2，有效域见修订后条件）；架构状态 = **organic 族已实现但默认休眠 + fusion 主线无嵌套承载位**（§4.2，v1"已实现"声明降级） |
| **(b) E ∈ [−Q, 0)**：净空头暴露 | 削减穿过 0 | 唯一的线性暴露轴新自由度；原文地位 = **完全沉默 + 一条条件性否定（84:316）+ 纪律性回避（26:22）**（v1"84课存在性证明"被 fatal 否证，§1.4）；架构 L0 **四层**不可表示（§4.1，v1 三层审计补报告/聚合层）；处置 = 阶段 1 因果基线 + oracle 夹逼（§8，v1"上界"标签双向失真已修正） |

**载体轴**（执行工具五值路由，v1 只判决了前两值——231号"定义域 > 有效域"谱型）：

| 载体 | 判决 | 依据 |
|------|------|------|
| 同一工具净额（IBKR 期货同合约） | **默认执行形式** | 净额等价定理（§2）；经纪商强制净额化 |
| 同一工具双开（加密 hedge-mode 同合约） | **否决** | 零增量 + 保证金双占 + 强平路径单向劣化（§2 修订差异 4） |
| 跨到期月双开（近月多+远月空） | **不在否决域，独立价差轴待路由** | P&L = 基差/期限结构损益 ≠ 净头寸损益；保证金有 SPAN 跨月抵扣非双倍；合法读法 = 价差序列自身作为 a0/走势分解对象（与金油比同范畴） |
| 同标的跨工具（现货多 + 永续空） | **不在否决域，新开放轴：REV 腿执行载体选择** | 物理可分（任何场所不互相净额）；增量 = 资金费 × 重叠名义 × 时长 + 基差项，正 funding regime（牛市主导态）下非零非负——"零增量"在此子域被构造性否证（§2.3） |
| 期权/权证（负 delta 暴露） | **升级：原文唯一被第一人称实操示范的空头方向暴露载体**（§1.3），独立轴（theta/vega 超出走势-暴露同构） | 15课五粮液认沽两次实操完整账；80:471 满仓+对冲并持自述；74:46 必要的对冲准备 |

**修订后的核心命题**：在线性同标的暴露轴上，"双向"的全部新内容 = 移除 E ≥ 0 约束（成分 b）；
该限定词"线性同标的暴露轴上"不可省略（v1 省略 = 过度声明）——载体轴上存在三个未被净额
等价覆盖的真实自由度（跨月价差、跨工具 carry、期权凸性），其中期权载体有原文实操锚。

## 1. 原文证据体系（109 文件穷举重审后的三层格局）

v1 的"沉默域"判决被穷举推翻两次（74/80/96/98/99 课权证对冲正面背书被遗漏；15/14/31 课
理论普适性宣称被遗漏）。修订后的格局是**三层精确分层**——每层的边界恰好是一种载体：

### 1.1 层一：理论普适性——直接原文宣称（任何 K 线品种，含空头方向工具）

- **14:420-424**（答疑）：「你的定理在估权上有效吗？？=====只要有K线图的都有效,但估权
  风险太大,又有时间限制,所以最好用短线的K线.」
- **15:1160-1162**：「为什么要用权证的例子，首先这都是实战的例子，其次，权证而且还是
  认沽的，都能符合要求，**就更证明了本ID这套方法的适用范围**。」——用认沽（负 delta
  工具）作为理论普适性的证明案例，缠师本人的修辞选择。
- **31:887**（答疑）：「请问缠主炒期货外汇什么的也是完全套用这理论嘛？==前面那课不是
  说了两个前提条件，你觉得他们不符合吗？」——两前提 = 交易延续 + 交易算数（26:24），
  期货/外汇满足即适用。
- **序篇:22**：「真明白市场的，就无所谓牛熊，市场永远都是提款机。**当然，如果市场只能
  是单边的，那么唯一的区别就是在熊市中，投入的资金以及摆动频率要小。**」——"如果市场
  只能是单边的"条件分句：单边性被表述为市场制度属性而非理论属性；双向市场下牛熊的
  程式差异消失。这是 v1 试图从 38 课镜像条款挤出的"制度决定物理形式"命题的**真正原文
  位置**（38课读法已被否证，见 §1.4.2）。
- **21:412-418**（答疑）：「我猜测是不是……熊市里期货可以做空，这时候更能派上用场==
  **你怎么知道本ID不玩期货？**股票的风险小……但期货不一样，**期货是不能说的**。一旦
  火星碰地球，那一定要死人才能完事的。」——承认参与双向市场，拒绝展开空头程式。

### 1.2 层一边界：38课的精确读法（v1 major 否证后的修订）

v1 把 38:36「所有操作刚好反过来就可以」读为"双向操作的最强原文锚、字面执行即开空平空"
——**被原教旨质询否证（major，已独立验证）**：

- 38:36 程式起点 =「不妨从一个下跌背驰开始」（隐含买入建仓），全部动作词汇 = 先卖出/
  重新买入/继续持有/继续观望，全课 grep 无任何开空词汇；按声明起点执行，库存恒在 [0,N]。
  镜像的对象是**判断-动作序列**（背驰判定方向、创新高↔创新低、买卖角色互换），镜像后
  状态空间仍是同一库存的持仓↔空仓循环——**镜像不含状态空间扩张**。
- **38:20**（v1 遗漏的同课反向证据）：「操作中只选择其中的上涨和盘整类型，**而避开所有
  下跌类型**」——同级别分解操作的正典选择规则是回避下跌类型。A 股语境下与镜像条款相容
  （向下段运作 = 持券者卖出回补 = 不持有下跌类型）；双向市场镜像读法（开空收割下跌段）
  与此正典指令冲突，是镜像扩张的额外反向证据。
- 38:28「无所谓牛市熊市」的语境是**分解级别内生定义牛熊**（分析对称性），不是暴露对称性。
- **26:34「无论是先买后卖与先卖后买，效果是一样的」**（v1 列为"方向对称性第二处直接
  表述"，被否证为 major）：「效果」被同句前分句「让凭证最终变成负数的活动」钉死 = 同一
  库存内两种短差**次序**对降成本的贡献等效——次序对称性，非方向对称性。其正确征用位置
  是成分 (a)（层内短差的次序自由），它支持的恰是已实现部分。同课行 92 条目 8「先卖后买
  也是可以挣钱的，不要光知道先买后卖」同属持券短差语境。

**修订后层一的净结论**：方向对称性的原文支持 = 分析/判断层全称（14/15/31课普适性宣称 +
38:28 分解对称 + 序篇:22 条件分句），**操作/暴露层在 38/26 课均不含状态空间扩张**。

### 1.3 层二：负 delta 暴露的第一人称实操——载体恒为权证/期权（v1 全部遗漏）

- **15:954-976**：五粮液认沽权证 038004 **两次实操完整操作账**——「10月23到25日是本ID

  7日两天……昨天根据5分钟线的背弛出了」。买卖点程式（二买/三角形第五波/背驰出）逐项
  作用于负 delta 工具。同时发废纸警示（「该权证风险极大，最终要变成废纸……绝对不要买」）。
- **80:471**：「本ID从3600点开始都是100%的满仓」+「都会有一定比例的对冲风险操作……
  **纯多纯空都是风险级别的，一定要有一定的对冲**」——满仓多头 + 对冲仓位**并持**的

- **74:46**：「七、必要的对冲准备，例如权证等，最近，认沽热销，也和一些资金的对冲预期
  有关。」（政策风险应对清单第七条，正面背书）
- **96:118 / 98:64-66 / 99:86**：580989（南航认沽）节前对冲实操——「一个稳健的大资金，
  当然要这样进行有效的对冲，很多时候，不确定因素是要靠对冲来解决的」（98:64）；
  「完全和大盘对冲着搞」（99:86）。条件化二分同段给出：「对于小资金来说……不一定要
  对冲了……先走一部分」（98:66）。
- **6:22 / 10:376-384**：认购认沽行权价差作安全底线结构；沽证「等待一次大盘转折时的
  大爆发」——认可借空头工具兑现下跌行情。

**层二的净结论**：「持多同时开空（物理双持反向暴露）」不是沉默域，是**条件化背书域**
——条件 = 大资金 + 权证/期权载体；散户/期货侧的对应物 = 减仓（81:484）。v1 §1.3 的
"缠师明确反对对冲"叙事被修正为条件化立场：反对的是散户用衍生品对冲 + "对冲可消风险"
的迷信（57:237/84:326/81:484，此读法经质询存活 rejected_self）；背书的是大资金的权证
对冲准备（74/80/96/98/99）。84:326 同段被 v1 截断的句子须补全：「世界证券历史一再证明，
最大的风险从来都不在现货市场，而是高比例透资以及期货等衍生品」——该句对本系统**既有
多头期货载体（BZ）同等适用**（风险口径非方向口径），引用时不得只取反 (c) 的一面。

### 1.4 层三：净空头线性头寸——沉默 + 条件性否定 + 纪律性回避

#### 1.4.1 84课做空程序的精确身份（v1 FATAL 修订）

v1 称 84 课「中期做空程序」为"(b) 净空头暴露的原文存在性证明"——**被语境质询否证
（fatal，已独立验证，证据比攻击声称的更强）**：

- 引文逐字恢复（核验 minor 修正）：「**今天，本ID开始宣布，从3600点开始的做多以及持有
  程序将开始终结**，本ID将开始选择性地展开中期做空程序。」（84:104）
- 做空程序的全部操作词汇排除负暴露：「别以为做空就是砸，那是最笨的手段」「做空开始的
  时候，经常要比多头还要多头」（84:126，起手是买入拉抬）；「四处点火……做空程序的
  第一步」「吸精大法」（84:160/200）；**「空头现在的策略可以大公开：在震荡中先买后卖，
  逢反弹必抢，然后再抛出」（84:488——缠师对做空程序操作内容的直接自述就是先买后卖）**；
  「当空头，就是要下跌中还要赚钱……底背驰抄进去，然后上去砸」（84:554）。
- 失败预案全在多头词汇内：「反手做多」（84:148）、「大不了就再玩一次今年初的游戏，
  低价革命一次」（84:168）、「多多去PE」（84:492）。
- 「大资金做空，其实没有任何风险」（84:168）——与净空头读法不相容（净空头名义亏损
  无界，§9），只在持券者/现金程序读法下自洽。
- **84:316（v1 遗漏的同课直接否定）**：「目前没有任何的现货卖空……**任何在期货中的
  空头头寸，最终都会被疯狂的逼空走势所吞没……任何的空头头寸最终都是死路一条**」
  （《谨防A股被挟持，股指期货应缓行》，84:306-328）——语料中缠师对字面期货空头头寸
  的唯一直接判决，为负（条件域：低流通量 + 无现货卖空 + 资金过剩的逼空市况，非普适
  教义）。做空程序宣布之时，建立净空头头寸的工具在其市场不存在且被其本人反对引入。
- 习语印证：35:58「汉奸做空也只为了买回来」；40:78（v1 行号 40 误，正确 78）「特别
  如果是本ID来做空……拉一条长阴」。「做空」在缠师词汇中恒 = 持券出货砸盘 + 低位回补。

**84课真实证明的**：做多程序 ⇄ 做空程序的**串行意向切换**（战役相位切换）存在且被
执行——头寸词汇恒非负。程式切换结构可保留引用；头寸符号切换不可挂靠 84 课。

#### 1.4.2 26:20-22：327 国债期货亲历（v1 遗漏，语料中唯一第一人称双向市场操作史）

「（327事件中）高位平掉多仓→147.5 全仓开多→**幸亏当时守纪律，不贪小便宜开空仓**」
——缠师本人在双向市场（国债期货）实操多头，并把机会主义开空定性为**破纪律对象**。
双向切割：既证明理论作者亲历双向市场（与 21:412"你怎么知道本ID不玩期货"互证），
又显示其纪律中空仓侧的克制。语境限定 = 327 结算风险（交易不算），非一般做空判决。

#### 1.4.3 层三的净结论

净空头线性头寸：**直接操作示范 = 零；直接讨论 = 一条条件性否定（84:316）+ 一条纪律性
回避（26:22）+ 一条拒绝展开（21:418"期货是不能说的"）**。空侧恒仓、空侧 earning、
做空配额全部为镜像推导（L0，无原文锚），任何实装必须以此身份标注（090号）。

## 2. 净额等价定理（v2：有效域收窄 + 载体边界显式化）

## 5. 利润上限定理（独立推导工位产出，全程 L0，每步标注依据类别）

> unified_config_regime_research.md §3.6 对账见 §5.6。

### 5.1 单循环三式（原文锚 + L0 代数）

循环 = 向上段（振幅 aᵢ）+ 向下段（振幅 bᵢ）（38:36 同级别分解，唯一性 38:18）。
恒仓约束 x(t) ∈ [0, N]（26:34）；满仓语义：向上段内 x ≡ N（49:52）；m = N 端点合法性：
49:64「在中枢上方**全部**抛出筹码，在下方**如数**接回」。完美预知口径（无锚假设，
显式声明：上界 oracle，背驰判别是其近似实现，永不超过此界）。

```
Π_long(i; m)  = N(aᵢ − bᵢ) + m·bᵢ ,  m ∈ [0, N]   →  max = N·aᵢ          （m = N）
Π_bidir(i; m) = 同式延拓至 m ∈ [0, 2N]            →  max = N(aᵢ + bᵢ)    （m = 2N）
ΔΠ(i) = N·bᵢ
```

**结构解读**：纯多 m=N 已把向下段从 −N·bᵢ **规避**到 0（卖出躲过下跌，上限是损失归零）；
净空头把同一段从 0 转为 +N·bᵢ——**同一道反向流被收割第二次**。每循环双向溢价恰等于
向下段振幅 × 满仓量。

### 5.2 "利润与时间成正比"（38:32）的严格条件

(H1) 循环到达率 λ ≥ λ₀ > 0（「足够活跃」）；(H2) E[a] ≥ α > 0、E[b] ≥ β > 2c（「上下
震荡大」，c = 单侧摩擦，35:30 成本门）。利润率表（μ ≡ λ·E[a−b] 为标的漂移率）：

| 策略 | 利润率 |
|------|--------|
| buy-hold | N·μ |
| 纯多恒仓机械 | N·λ·E[a] = N(μ + λ·E[b]) |
| 双向机械 | N·λ·E[a+b] = N(μ + 2λ·E[b]) |

三者均线性于 T；实质内容 = 零漂移纯震荡标的上仍线性增长（利润源从漂移切换为震荡流
λ·E[b]，26:36「吸血机器」的速率形式）。「比任何单边上涨更大」⟺ 速率支配 λ·E[a] > μ′
——原文自己的选股判据恰是该条件的最大化算子（38:32「选择一组历史上某级别平均震荡幅度
最大的股票」= max λ·E[a+b]，强一致性核验）。成本归零时刻 T₀ = P_entry/(λ·E[捕获/股/循环])
< ∞（53:34 目的函数、26:32「足够长的时间内变成负数」的严格形式）。

### 5.3 成本门（35:30）的进入方式

逐段截断算子：Π_long(i) = N(aᵢ−bᵢ) + N·(bᵢ−2c)⁺，双向第二份同付 2c。级别准入 ⟺
λₖ·E[(b⁽ᵏ⁾−2c)⁺] 实质为正；最优级别 k* = argmax——**这就是在册 H4 滚动振幅准入门的
理论形式**。

### 5.4 多层嵌套：全变差望远镜恒等式（嵌套上界论的核心裁决）

层 k+1 的一个段在层 k 分解为交替子段（35:22 分解定理二），振幅恒等式 Σaⱼ − Σbⱼ = |A|。
记 TV⁽ᵏ⁾ = 层 k 全变差、Rₖ = 层 k 反向段被层 k+1 段内部吸收的回撤流总量：

```
TV⁽ᵏ⁾ = TV⁽ᵏ⁺¹⁾ + 2Rₖ    ⟹    TV⁽⁰⁾ = D⁺ + D⁻ + 2·Σₖ Rₖ
```

（D± = 顶层向上/向下段振幅和；0 = 最细过门级别。53:20 显微镜原则=各层段族不相交性的
原文表述：「次级别不在该级别的观察中」。）

**同一波动会被多层重复捕获吗？** 盯市流意义上会（同一 b 波动同时移动两本账）；**净捕获
意义上不会**——层 k+1 的捕获只依赖段端点（内部震荡对其净贡献为零），层 k 收割的恰是
层 k+1 看不见的抵消分量 2Rₖ。望远镜恒等式保证各层收割 TV⁽⁰⁾ 的**不相交分量**——前提是
每层只交易自己级别的段（违反 = 在册 H3"槽竞争"病理）。资金约束下：捕获可加 ≠ 资金可加
（保证金按 Σ|xₖ| 逐点共同占用——与在册 C 轴"负交互是概念性非资源性"一致）。

**总上界是各层之和吗？否**：分区筹码下 Σ Nₖ·TV⁽ᵏ⁾ ≤ M·TV⁽⁰⁾，等号当且仅当全资金压在
最细可入级别。**零摩擦下嵌套塔不增加上界——它是同一个 M·TV⁽⁰⁾ 的资金分配方式**。嵌套
的严格存在理由全部来自约束：(i) 35课成本门杀死过细级别；(ii) 容量帽 Nₖ ≤ Kₖ（53:34
「与该级别能容纳的资金量有关」、49:76「资金越大，利润率显然越低」）使单点集中不可行。
**嵌套塔 = 容量约束下达成 M·TV 界的唯一可行结构，而非对界的加法扩张。**

44:44 铰链的形式角色：同一笔卖出的层归属是事后可测的路径泛函（收复 ⟹ 计入 Rₖ 短差；
