# BRN（BZ=F）上涨分量 settle 阶梯 —— "涨到 $120 的上涨结束了没？"

> 引擎：`analysis/brn_upleg_settle.py`（镜像树对偶，复用 `qqq_soxx_settle.py` 同款 superlevel 引擎）
> 数据：`analysis/data_cache/BRN_1d_2y.json`（yfinance BZ=F 2y 日线，n=503，2024-05-30 → 2026-05-29）
> 产出：`analysis/data_cache/brn_upleg_settle.json`

## 方法（与之前 sublevel 分析的对偶关系）

之前 `brn_settle_ladder.py` 跑的是**原 close 序列的 sublevel merge tree**——追踪**下跌分量**（买点视角，读"反弹升破即止跌"）。

本次对 **`-close` 序列**跑同一棵 OnlineMergeTree（镜像树对偶），sublevel(-close) ≡ superlevel(close)，追踪的就是**上涨分量**（卖点视角）。输出时全部还原为真实价格：

| 镜像空间（-close 的下跌分量） | 真实空间（close 的上涨分量） |
|---|---|
| valley 诞生 `birth_price` | 上涨腿的顶 → 真实顶价 = `-birth_price` |
| death 屏障 `death_price` | 回调低点 → 真实跌破价 = `-death_price` |
| `persistence = death-birth` | = `peak-valley` = 上涨腿幅度（恒正） |
| 被更高峰合并而 settle | 价格回调跌破鞍点 valley → 上涨腿被杀死 |
| 全局最低 valley（settle=None） | 全局最高峰 → 永不被回调 settle |
| `gap_to_settle`（镜像） | 当前价还需**下跌**多少才触发该上涨腿 settle |

## 结论（六要素 · 完整版）

### 1. 结论

**全局市况**：当前 **92.05**（2026-05-29），距全局主峰 118.35（2026-03-31）已回撤 **−22.2%**，τ(ATR14)=5.01。

**分三层回答"涨势结束了没"**：

#### (a) 已 settled 被回调杀死的上涨腿：117 条（12 条 >τ）—— 顶部级联已部分瓦解

| 顶价(日期) | 涨幅 | 回调跌破价(日期) |
|---|---|---|
| 77.01 (2025-06-20) | 16.78 | 60.23 (2025-05-05) |
| 82.03 (2025-01-15) | 12.84 | 69.19 (2024-09-10) |
| **112.19 (2026-03-20)** | 12.25 | **99.94 (2026-03-23)** |
| **112.10 (2026-05-18)** | 12.04 | **100.06 (2026-05-07)** |
| **109.77 (2026-04-06)** | 8.61 | **101.16 (2026-04-01)** |
| **114.44 (2026-05-04)** | 6.27 | **108.17 (2026-05-01)** |
| 80.93 (2024-10-07) | 9.89 | 71.04 (2024-11-15) |

**关键**：主峰区域（$110+）附近的 4 条上涨腿（112.19 / 112.10 / 109.77 / 114.44）**全部已被回调杀死**——主升浪顶部的涨势已在小级别上逐级 settle，是"次级别卖点已现"的拓扑证据。

#### (b) 仍 alive 可被回调 settle 的上涨腿：10 条（3 条 >τ）—— 现价下方的逐级跌破防线

| 顶价(日期) | 涨幅 | 跌破价(还需跌) | 距现价 | 级别 |
|---|---|---|---|---|
| **118.03 (2026-04-29)** | 27.65 | **90.38（还需跌 1.67）** | **−1.8%** | 近端（最先触发）|
| 98.96 (2026-03-09) | 11.16 | 87.80（还需跌 4.25） | −4.6% | 中段 |
| 87.34 (2024-07-03) | 28.42 | 58.92（还需跌 33.13） | −36.0% | 深层（≈全局）|

**最临近卖点信号**：现价 92.05 距最近端上涨腿（顶 118.03）的跌破线 **90.38 仅差 1.67（−1.8%）**。**一旦收盘跌破 90.38 → 该近端涨势 settle，"涨到 $118 这一波"在可证伪意义上确认结束。**

#### (c) 主导上涨分量（$58→$118 那条大腿）的 settle 状态

- 顶 **118.35 @ 2026-03-31**，自全局谷底 58.92（2025-12-16）起涨，涨幅 **59.43**。
- 作为镜像树的**全局 elder**（settle_price=None），**定义上永不被回调 settle**——它"alive"是 trivial 的，**不构成"涨势仍在"的有效信号**（090号声明膨胀禁令）。
- 它只能被**反向（下跌）结构对象否定**：反向幅度需 > **59.43**，即价格跌破 **58.92（−36.0%）**，整条大腿才算被对象否定（§17.3 规则3，对象否定对象）。
- 当前状态：**自顶回撤 22.2%，处于"涨势级联瓦解中、但主升浪结构尚未被对象否定"的中间态**。

**综合回答**：
> **"涨到 $120 的上涨"在近端已经结束了**——顶部多条次级别上涨腿已被回调杀死，最近端 alive 涨腿距跌破线只剩 1.67（跌破 90.38 即坐实）。
> **但 $58→$118 这条主升浪大腿尚未被对象否定**——要到价格跌回 58.92（−36%）才算整条主升结构死亡。当前是"主升浪顶部确认 + 级联回落中"，不是"主升浪被证伪"。

### 2. 定义依据

- **上涨腿 settle 判据**：`a_settle_trigger.SettleTrigger`——镜像树中一个 alive 上涨分量被"更高的峰"（镜像中更深的 valley，真实为更低的回调低点）合并 → settle。`settle_price` 还原为真实跌破价 = `-mirror_settle_price`。输入数据满足：n=503 根真实日线在 -close 上构成完整 sublevel 滤流。
- **全局分量不可反弹 settle**：`a_settle_trigger` 顶部 §7.5"栈底永远 alive"——全局最高峰对应镜像最深 valley = elder，`can_settle_by_rebound=False`，只给 `reversal_amplitude`。
- **级别（涨幅）口径**：`persistence = death−birth = peak−valley`（因果屏障定级别，绝不用 cap−valley）。

### 3. 边界条件（结论翻转条件）

- **(b) 近端结论翻转**：若价格**不跌破 90.38** 而是反身升破 118.03，则最近端 alive 上涨腿 cap 抬升、跌破线上移，"近端涨势结束"判断作废。
- **(c) 主导大腿翻转**：当且仅当价格**跌破 58.92**，$58→$118 主升大腿才被对象否定；在此之上的任何回调都不改变它"全局 alive"的拓扑事实。
- **数据窗口边界**：本分析锚定 2y 窗口。若拉更长窗口（含 2022 年 $139 峰），全局 elder 会改写为更早的更高峰，本处 118.35 的"全局"身份会降级为局部分量。
- **充分性边界（L1→L2）**：上涨腿 settle 是**必要**的形态条件，缠论顶背驰的**充分**确认需 MACD 动力学层（521号），本脚本未含动力学层，故"卖点确认"是形态侧读出，非完整背驰判定。

### 4. 下游推论

- 操盘上：**90.38 是近端卖点确认线**（跌破=近端涨势 settle）；**58.92 是主升浪死亡线**（跌破=$58→$118 大腿被对象否定）。两线之间（58.92 ~ 90.38）是"顶部已确认、主升未否定"的回落区间，对应缠论"顶分型成立后、趋势级别中枢未破"的持有/减仓地带。
- 对 `brn_settle_ladder.py`（买点视角）的互补：那边读"反弹升破即止跌"的下跌腿，这边读"回调跌破即结束"的上涨腿——两棵树（原树 + 镜像树）共同给出双向 settle 阶梯，是同一标的的卖点/买点对偶完整呈现。

### 5. 谱系引用

- **镜像树对偶**：直接复用 `qqq_soxx_settle.py` 的 superlevel 对偶（卖点视角 = OKLO/700 买点模板的对偶），无新概念分离。
- **全局分量不可 settle 的诚实点**：090号（声明膨胀禁令）——不把全局最高峰伪装成"回调到 X 即结束"；§17.3 规则3（对象否定对象）的量化读出。
- **认识论分级**：formalization-validity-domain 规则——见下方等级标注。
- 不确定是否存在"上涨分量 settle ↔ 缠论卖点充分性"的更深谱系；已知 521号标注该同构为 L1（需动力学层补充充分性）。
