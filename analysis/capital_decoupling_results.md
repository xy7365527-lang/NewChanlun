## 1. 方案选择（三候选的严格性筛选）

| 候选 | 裁决 | 理由 |
|------|------|------|
| A 轴级独立资金池 | **不可构造** | C 轴卖出的就是基座仓位那笔 slice 本身（049:64"全部抛出筹码"）——两轴操作同一对象，物理分池要求对同一笔股票预先劈分所有权，且需任意分割参数（违 231号零新参数纪律） |
| B 优先回补权 | **采纳其严格形式 = earmark** | bar 内优先已在册（阶段 A 先于阶段 C）；跨 bar 优先权的严格形式 = 义务资金预留：短差卖出所得不入共享池，锁定为该层回补专款——049:64"如数接回"义务语义的资金面物理化，零新参数 |
| C 动态配额（中枢振幅比例） | 不采纳 | 引入配额映射新参数 = 53课留白区的参数化猜测；且 §5.2 文档自身候选即 earmark |

资金守恒：escrow 计入 NAV；义务消灭点（44课铰链升级 / eod）专款释放入池；
追价 deficit 由池补差（topup 观测）。5 个新单测（防挪用对照 / 追价补差 /
池不约束 NAV 恒等 / 铰链释放 / eod 守恒），195 全绿。

## 3. 核心判决：负交互是概念性的，不是资源性的

**D5 三标的全否是本判决的中心读数**。earmark 完全消除了"挪用"（义务资金
物理锁定，跨 bar 不可动用），但回补推迟不降反升（+20~32%）。"T 轴满仓占资
⇒ C 轴回补义务推迟 ⇒ 踏空追价"的资源耦合假设**被否证为机械根因**。

机械解剖（fusion_obs 观测面）：

| 观测 | BTC fusion→fusion_e | OKLO | CL |
|------|------|------|----|
| 回补推迟 bar | 874K → 1061K | 25.9K → 31.1K | 144.7K → 190.9K |
| topup（追价回补：专款不足池补差）/总回补 | 4544/9014 = **50.4%** | 566/1110 = 51.0% | 3557/6806 = 52.3% |
| 短差净现金 | −2268K → **−1691K** | +104K → **+154K** | −207K → **−189K** |

1. **推迟的真根因 = 追价本身，不是挪用**：回补成本 = shares×c，专款 =
   shares×sell_price，强趋势中 c 持续 > sell_price ⇒ deficit =
   shares×(c−sell_price) 无论专款是否预留都必须从池里出。topup 占回补的
   半数（三标的 50-52%）——追价是 C 轴在强趋势 regime 中的**结构属性**。
2. **defer 反升的机制 = 共享池流动性互助的消失**：耦合下其它层的现金周转
   （它们的卖出/削减所得）可临时垫付追价 deficit；解耦把专款锁死后池更穷，
   deficit 等不到补差。"挪用"的对偶面是**流动性互助**——消灭前者必然消灭
   后者。53课"该级别能容纳的资金量"留白区的第二次显形：义务保障 = 占用
   容纳量。
3. **净现金改善但 NAV 不对应改善**（CL D2 ✗ 是直接证据）：专款保障让回补
   更早执行、追价幅度更小（三标的 net_cash 全改善，BTC +577K），但 escrow
   锁定挤压其它层入场暴露，强趋势中暴露减量的机会成本吞掉短差账面改善。
   这是 osc 僵尸腿判决"追价失血"同构的第四次出现，且首次在**资源语义消融
   下复现**——失血与资金语义无关，与 regime 有关。

## 4. "OKLO 特异"判决升级：真 regime 函数，非资源伪影

在册边界条件 (d)（`hold26_counterseg_fusion_results.md` §6.3）问：若解耦后
BTC/CL 翻正，"OKLO 特异"需改写为"资源约束伪影"。**回答：不翻正——OKLO
特异是真的**。

- OKLO 是唯一 D1 ✓ 标的，且解耦使正交互**增强**（+452.4 → +496.8，短差
  净现金 +104K → +154K）：震荡域中价格围绕中枢回落，回补多数发生在卖出价
  下方（escrow 自足，追价占比虽同为 51% 但 deficit 小），earmark 是纯增益。
- BTC/CL 负交互在资源语义消融后存活 ⇒ 根因在概念层：强趋势 regime 中
  k−1 级卖证据开出的短差窗口本身是失血的（38课"足够活跃，上下震荡大"
  的反面），35课成本门管不住——成本门看的是震荡幅度可操作性，不看 regime。
- C 轴 = 震荡域 regime 函数（第八例族）从"会计定位"升级为**资源消融下的
  鲁棒结论**：osc/co/sc/scco 白名单家族的准入逻辑（基线符号判别）适用。

## 结果包（六要素）

1. **结论**：C 轴资金解耦（earmark）实装（`capital_decoupled`，
   fusion_e/fusion_se，零新参数）并三标的 L3 判决——**资金池耦合作为
   负交互机械根因被否证**（D5 三标的全否：推迟 +20~32% 不降反升；追价
   占回补 50-52% 是结构属性，挪用消除无效且消灭流动性互助）；D1 正交互
   仅 OKLO（496.8 > 378.9，解耦增强 +44.4pp），BTC/CL 负交互在资源消融
   下存活 ⇒ 负交互是概念性的（强趋势 regime 中 C 轴短差结构性失血）；
   任务约束全过（fusion_t 三标的全胜零接触、OKLO 改善、资金守恒）。
2. **定义依据**：049:64（"全部抛出筹码……如数接回"——义务语义，earmark
   是其资金面物理化）、053:34（"该级别能容纳的资金量……以后再说"——
   留白区资金语义，本判决裁决两种读法：耦合（共享池）与解耦（义务专款）
   各有 regime 有效域）、026:34（恒仓基座——候选 A 不可构造的根据：C 轴
   操作对象就是基座 slice）、044:44（铰链——义务消灭点专款释放）、
   035:32（成本门常数复用，231号零新参数）。
