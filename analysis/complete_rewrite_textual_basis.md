## 设计点 1：多级别同时短差（多重赋格=多声部）有无原文依据？

### 原文依据

**第40课《同级别分解的多重赋格》（一级权威，`blog/040-第40课.md`，缠中说禅 2007-03-27）**，标题即"多重赋格"。正文逐字：

> （第14行）"投资，往往碰到这样两难的事情，就是一个小级别的进入，结果出现大级别的上涨，这时候怎么办？这时候有两个选择：一、继续按小级别操作……；二、**升级为大级别操作基础上部分保持小级别操作**。对于资金比较大的投资，后者是比较实用的。"

> （第20行）"对于大资金来说，这种级别的操作可以一直延伸下去，**可以变成N重层次的操作，每一重都对应着一定的资金与筹码**，而相应对应着不同的节奏与波动。……这如同赋格曲，简单的动机、旋律在N个层次上根据不同的转位、移位、对位等原则运动着，合成统一的乐曲。市场的走势，其实就是这样的**多重赋格**……"

> （第22行）"在这种同级别分解的多重赋格操作中，**可以在任何级别上进行操作，而且都遵守该级别的分解节奏与波动，只是在不同级别中投入的筹码与资金不同而已**。……而**每一层次的操作都是独立又在一个整体的操作中**……"

**第二节《走势分解》（二级权威，`chan99/0014`，第53/55行）** 逐字复述同一内容：

> "对于大资金来说，这种级别的操作可以一直延伸下去，可以变成N重层次的操作……这如同赋格曲……市场的走势，其实就是这样的多重赋格。"
> "在这种同级别分解的多重赋格操作中，可以在任何级别上进行操作……**每一层次的操作都是独立又在一个整体的操作中**，对这种操作如果没有什么直观感觉，那就去听听巴赫的音乐。"

### 设计裁决

**多级别同时操作有明确原文依据，且就是缠师称为"多重赋格"的东西。** 多重赋格 = N 重层次同时操作，每层独立遵守本级别节奏、各自分配资金筹码、合成统一整体。把"每个级别独立 FSM 同时降成本"建模为多声部，**与原文同构，不是过度引申**。

**但有两条原文硬约束必须写进设计**：

1. **每层资金/筹码独立且不同**（第20/22行"每一重都对应着一定的资金与筹码""只是在不同级别中投入的筹码与资金不同"）——多重赋格不是同一笔仓位在多个级别同时被操作，而是**不同层次分配不同的筹码/资金额度**。若代码让所有级别共享同一仓位池并同时短差，违反"每一层次独立"。
2. **换档是条件触发，非全程全级别并行**（第14/16/18行）——缠师的范式是"小级别进入 → 出现大级别走好 → 换档升级为大级别操作，同时部分保持小级别"，由当下情况（行情/资金/风格）决定是否换档（第18行"根据当下的情况去决定是否换档，就如同开车时根据路况等决定档位"）。**默认不是所有级别永远全开**；是按资金量定主操作级别（见设计点3），高低层按需叠加。

## 设计点 2：每次短差比例 sub_ratio = 0.3 vs 1/10 哪个有据？

### 原文依据

**唯一出现的固定比例是"1/10"，且语境是"留作机动的资金占比"，不是"每次短差动用比例"。**

第31课（`blog/031`，第26行）/ 第十二节（`chan99/0033`，第21行）逐字：

> "可以用部分机动的资金去弄点短差（**注意，针对每只买入的股票，都要留部分机动的资金，例如 1/10**），让成本降下来。但每次短差，一定不能增加股票的数量。"

注意"例如 1/10"修饰的是**留多少机动资金**（机动仓占总仓 ~1/10），而非每次短差吃掉多少。第31课答疑（`blog/031` 第128行）再次确认 1/10 是练习用的小参与量：

> "例如特别不熟练的，用 1/10 操作，这样也是一个很好的练习方法。"

短差量的原文原则是**"唯一需要控制的就是量"，但量本身不固定、由级别决定**（`chan99/0033` 第11行）：

> "对于本理论来说，任何的卖点都是卖点，任何的买点都是买点，**唯一需要控制的只是买卖的量而已**。级别的意义，其实只有一个，基本只和买卖量有关，日线级别的买卖量当然比 1分钟级别的要多多了。"

答疑（`blog/031` 第357行）："如果资金不大，一次 30分钟级别的操作，基本能把成本至少降 10% 以上。"——量随**操作级别**而变，不是固定 0.3。

### 设计裁决

**0.3 无任何原文依据，应删除该硬编码。** 原文中：
- 机动仓占比 ≈ 1/10（"例如"，非硬性）；
- 每次短差吃掉的量**不是固定比例**，而是**由该次短差所在级别决定**（级别越大量越大）。

裁决：把 `sub_ratio=0.3` 替换为**机动仓上限 ≈ 1/10 总仓**的约束，单次短差量绑定到该级别（不是固定 0.3 的全仓比例）。若必须保留单一标量参数，其默认值应为 1/10（0.1）而非 0.3，并标注"原文为'例如 1/10'，是机动仓占比的示例值，非每次短差比例的硬性规定"。

**严格性提示**：把"留 1/10 机动"和"每次短差吃 1/10"混为一谈是概念混淆——前者是仓位结构约束，后者是单笔操作量。重写须区分这两个量。

## 设计点 3：bar 级（最细级别）是否应参与降成本？缠师有无"最小操作级别"约束？

### 原文依据

**缠师同时给出两条看似张力的陈述，但答疑里给出了明确裁决：有最小操作级别约束，按资金量定，1分钟以下不作为主操作级别。**

一方面，第十二节（`chan99/0033` 第11行）原则上说任何级别买卖点都参与：

> "即使对于很大的资金量来说，**1分钟的卖点也应参与**，可能只卖 5万股，跌到 1分钟买点买回来……这样的操作能让总体成本降低即使是 0.000000001 分，也必须这样做。"

另一方面，第31课答疑（`blog/031` 第243/245行，缠师亲答）给出**操作级别下界**：

> "最好就是**先按资金量定好操作的级别，例如 30分钟，只在 30分钟进入背驰段后，用 5、1 以及 1 以下的背驰精确定位后卖出，这样就不用一见 1分钟背驰都很紧张去卖，那太累了**。"

第40课答疑（`blog/040` 第77行）："请教禅主……就是如果定下 30分钟为操作级别，当下 1分 K图出现背驰，怎么才能确定，参与还是不参与？==**关键要看 5、30分钟当下在走什么，如果正在主跌段中，当然没必要参与**。"

第31课答疑（`blog/031` 第594行）："5分钟是标准的主跌段，所以 **1分钟上任何的走势，其实意义不大**，要找背驰点，一定要至少 5分钟进入背驰段，这样才有意义。"

最低级别本身的存在性：第17/18课（`blog/017` 第40行 / `blog/018` 第58行）定义最低不可分解级别——"对实际操作，都把这最低的不可分解级别设定为 1分钟或 5分钟线"。bar 级（单根 K 线级别）**低于**这个最低操作级别。

### 设计裁决

**bar 级（最细级别 / 单 K 线级别）不应作为独立的降成本操作级别参与。** 原文裁决链：
1. 1分钟以下的走势"意义不大"（`blog/031` 594行）；
2. 1分钟级别只用作**精确定位工具**（"用 5、1 以及 1 以下的背驰精确定位"，`blog/031` 245行），不是独立操作级别；
3. 操作主级别**按资金量定**（"先按资金量定好操作的级别，例如 30分钟"）。

裁决：bar 级（最低不可分解级别）**只参与区间套精确定位**（见设计点5），**不作为独立 FSM 发起短差**。降成本短差的最小操作级别应是配置项（按资金量），原文示例为 30分钟 / 5分钟，**不是 1分钟以下**。

**注意张力的正确解读**："1分钟的卖点也应参与"（`chan99/0033`）与"1分钟意义不大"（答疑）并不矛盾：前者讲的是大资金在 1分钟买卖点上做量、且该买卖点必须经区间套确认（大级别已进背驰段）；后者否定的是"孤立的、未经大级别确认的 1分钟背驰"。bar 级（比 1分钟更低）连"参与"资格都更弱，只能是定位器。

## 设计点 4：三段式买卖法 / 挣股数（成本为负后）

### 原文依据

**第31课（`blog/031`）/ 第十二节（`chan99/0033`）给出完整的"成本→0→负→挣股票"三阶段定义。**

阶段定义（`blog/031` 第24行 = `chan99/0033` 第21行）：

> "一个最简单又最有效的管理，就是**当成本为 0 以前，要把成本变为 0；当成本变成 0 以后，就要挣股票，直到股票见到历史性大顶，也就是至少出现月线以上的卖点**。"

三阶段的精确操作（`blog/031` 第28行 = `chan99/0033` 第23行）：

> "股票开始上涨后，一定要找机会把股票的成本变成 0，除了途中**利用小级别不断弄短差外**，还要在股票达到 **1倍升幅附近找一个大级别的卖点出掉部分，把成本降为 0**……当股票成本为 0 以后，**就要开始挣股票。也就是利用每一个短差，上面抛了以后，都全部回补，这样股票就越来越多，而成本还是 0**。"

两阶段的**仓位语义区别**（`blog/031` 第36行，娇注归纳缠师原意）：

> "成本为 0 前用机动资金做短差，**买入多少就是卖出多少不增加仓位**。股票翻倍后出掉部分仓位成本为 0 后，**卖出多少资金就买入多少资金做短差赚股票，仓位是增加的**。"

缠师亲口确认两阶段守恒量不同（`blog/031` 第169行）：

> "**成本为 0 前，只补进相同的数量，仓位不增加。成本为 0 后，抛出后，跌回来，就把抛出的钱，全补进去，这样买回来的数量一定多了，股票才会越来越多。**"

第43课答疑（`blog/043` 第134/136行）再次确认挣股票阶段是"先卖后买、回收等额本金"："成本为 0 后，可以用先卖后买的方法，例如 20卖 1万，19 就可以回补 1万多股了，这样股数越来越多。"

成本为负即"真正的利润/血"（`blog/040` 第64行）："关键是能本成本降低为 0 才是真正的安全，**0 以下的，才是真正的利润，才是真正的血**。"终点是超大级别卖点（`chan99/0033` 第23行）："等待一个超大级别的卖点，一次性把他砸死。"

### 设计裁决

**挣股数阶段定义清晰，三段式必须是有序状态机，且两阶段的守恒量不同——这是重写必须严格区分的核心：**

- **阶段一（降成本，成本 > 0）**：守恒量 = **股数**（"买入多少就是卖出多少不增加仓位""只补进相同的数量"）。短差回收现金压低 cost_basis。
- **阶段二（挣股数，cost_basis ≤ 0）**：守恒量 = **本金/现金**（"卖出多少资金就买入多少资金""把抛出的钱全补进去"），股数单调增加。
- **终止**：超大级别（月线以上）卖点，一次性全清。

裁决：FSM 必须有 `REDUCING_COST`（股数守恒）和 `EARNING_SHARES`（金额守恒）两个**互斥状态**，切换条件是 `cost_basis ≤ 0`。当前若两阶段共用同一短差逻辑（同一守恒量）则错误。中间还有一个**"1倍升幅出掉部分把成本降为0"**的离散事件（大级别卖点），不是连续短差——重写应建模为独立的 take-profit 事件。

## 设计点 5：区间套精确定位

### 原文依据

**第六节《区间套》（`chan99/0027`）给出完整定义**（编纂版；博文对应第58课等多处运用，定义最集中在编纂版本节）：

> （第5行）"**区间套：就是根据背驰段从高级别向低级别逐级寻找背驰点(即买卖点)的方法。**"
> （第7行）"**精确大转折点寻找程序定理：某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。**"
> （第11行）"某大级别的转折点，先找到其背驰段，然后在次级别图里，找出相应背驰段在次级别里的背驰段，将该过程反复进行下去，**直到最低级别**，相应的转折点就在该级别背驰段确定的范围内。"
> （第15行）"区间套寻找背驰点的理论依据：**低级别背驰是本级别背驰的必要条件而非充分条件**……我们说某个级别的走势背驰了，那么**必须确定它以下所有级别都转折了，这是所有背驰的前提**。"
> （第19行）"具体方法就是本级别进入背驰段后，到次级别去寻找背驰点，然后逐级找下去，**直到所有的级别都在背驰段，最小的级别最终背驰**。"

博文中的运用（一级权威，`blog/031` 第276/309行，缠师亲答）：

> "进入背驰段，要找精确的卖点的，就看 1分钟以及以下的，**这叫区间套方法，前面有一个课是专门说这个的**。但对小级别的背驰，是否能引发大的调整，必须要看大级别是否进入背驰段。"

### 设计裁决

**区间套定义明确，定义在编纂版第六节，博文第58课等运用。设计裁决：**

1. 区间套是**从高级别向低级别逐级收缩**确定精确买卖点，不是某单级别独立判断。
2. **低级别背驰 = 高级别背驰的必要非充分条件**——这是 bar 级/最低级别在系统中的**唯一合法角色**：作为高级别背驰的精确定位器，而非独立操作发起者（呼应设计点3）。
3. 触发短差/买卖点前，**必须确认本级别以上已进入背驰段**（"必须确定它以下所有级别都转折了"的逆否：不能只凭最低级别背驰就操作）。

裁决：重写中任何级别的降成本/买卖点触发，**入场确认应实现区间套链**：高级别进背驰段 → 次级别背驰 → … → 最低级别背驰，全链成立才确认。最低级别（bar 级）只在此链末端充当定位器。**孤立的低级别背驰不可作为操作信号**（`chan99/0027` 第15行 + `blog/031` 594行）。

谱系引用：与 MEMORY 中"PH settle 用途边界"一致——PH settle 是 candidate 层（形态学必要条件），confirmed 需 MACD 背驰；区间套正是"必要条件逐级收缩"的缠论原型。

## 设计点 6：多重赋格的"赋格/多声部"隐喻——项目自创还是缠论原文？

### 原文依据

**"多重赋格"是缠师本人的术语，不是项目自创隐喻。** 全语料命中：

- **第40课标题即《同级别分解的多重赋格》**（`blog/040-第40课.md` 第1/8行）；
- 正文（`blog/040` 第20行）："这如同**赋格曲**，简单的动机、旋律在 N个层次上根据不同的**转位、移位、对位**等原则运动着，合成统一的乐曲。市场的走势，其实就是这样的**多重赋格**。"
- 编纂版前言（`chan99/0001` 第19行）："进行**多重赋格性的同级别分解操作**，尤如行船、尤如开车，以不同档位适应不同情况。"
- 编纂版第二节走势分解（`chan99/0014` 第53/55行）逐字复述。
- 第15课/踏准节奏（`blog/041` 第34行 / `chan99/0036` 第23行）："市场就是**巴赫的赋格曲**，那里有生命的节奏。"

### 设计裁决

**"多重赋格 / 多声部 / 对位"有完整缠论原文依据，是缠师术语，不是项目引申——本设计点的原始假设（"可能纯属项目隐喻"）被原文否证。**

但**必须区分隐喻的合法部分与越界部分**：

- **合法（有原文）**：N 重层次同级别分解、每层独立操作、每层独立分配资金筹码、合成统一整体——直接对应缠师"转位/移位/对位""每一层次独立又在整体中"。
- **越界风险（需标注）**：若把"赋格"形式化为"每个级别一个完全对称、参数相同、永远全开的 FSM"，则**超出原文**——缠师的多重赋格是(a) 资金量驱动的换档（不是全级别恒开，设计点1/3）、(b) 每层资金筹码**不同**（不是对称）、(c) "转位/移位/对位"是音乐隐喻而非可直接代码化的算子。把音乐术语"对位法"硬塞为具体算法是**形式化有效域膨胀**。

裁决：保留"多重赋格"作为架构命名（有原文背书），但代码注释中**不得声明缠师定义了具体的"对位算子/转位规则"**——这些是音乐隐喻，缠论原文未给出可编码定义。多声部 = "多级别独立 FSM + 各自资金额度"，到此为止；超出此的"对位/转位"算法须标注为 **L0 项目形式化引申，无原文算法定义**。

## 结果包六要素

**1. 结论**：6 个设计点的原文依据已逐字考据完成（见汇总表）。关键裁决：(a) sub_ratio=0.3 无原文依据须删除/改为 1/10 机动仓约束；(b) bar 级不应作独立降成本级别，只作区间套定位器；(c) 多重赋格**有**缠师原文依据（第40课），原假设被否证；(d) 三段式须实现两个守恒量不同的互斥 FSM 状态。

**2. 定义依据**：第40课《同级别分解的多重赋格》（多级别+赋格术语）、第六节《区间套》`chan99/0027`（区间套定义+必要非充分条件）、第十二节《回避市场风险》`chan99/0033` / 第31课（机动仓1/10、成本→0→负三阶段、两阶段守恒量、操作级别按资金量定）、第17/18课（最低不可分解级别=1分钟或5分钟）。每条均给逐字片段。

**3. 边界条件**（结论翻转条件）：
- 设计点2 裁决翻转：若在博文/编纂版其他处发现缠师给出"每次短差吃 X 比例"的固定数字（本次考据未发现），则 0.3 可能有据。
- 设计点3 裁决翻转：若发现缠师明确说"最低级别(bar级)可独立发起短差且无需大级别确认"——但 `blog/031` 594行与 `chan99/0027` 必要非充分条件直接否定此可能。
- 设计点6 裁决翻转：本点不可翻转（第40课标题白纸黑字）；可细化的是"对位/转位"是否有更具体原文——本次未发现可编码定义。

**4. 下游推论**：重写的 FSM 必须 (a) 区分降成本/挣股数两个守恒量不同的状态；(b) 把 sub_ratio 硬编码替换为机动仓占比(~1/10)+级别驱动的单笔量；(c) 把 bar 级从"操作级别"降级为"区间套定位器"；(d) 多级别 FSM 各自独立资金额度，非对称恒开。这直接影响 fugue 重写的状态机定义、参数层、级别调度层。
