# 盘整背驰卖的递归正则化调研报告

> 调研任务：盘背卖（盘整背驰卖点）REV 腿 payoff 0.73/0.77（赔大赚小、净负）vs type1 卖 1.66/1.86 的根因，
> 以及"递归正则化"（用次级别把握）的严格方案。
> 纯调研产出，不改代码。认识论等级：**L0**（原文定义 + 代码结构推导，方案未经数据验证）。

---

## 0. 结论（先行）

核心假说"盘背卖低 payoff 的根因是没有经过递归正则化"**部分成立，但不完整**。调研发现根因是**两个独立缺陷的合取**，递归正则化只覆盖其中一个：

1. **闭腿锚越出原文保证域（几何缺陷，主因）**：原文（第24课/编纂版第四节）对盘整背驰的全部保证是
   "**理论只能保证其回拉原来的走势中枢**"——即价格回到 ZG 下方（回入 [ZD, ZG] 区间）。
   当前引擎震荡型 REV 腿的兑现锚是 **ZD 触线**（`c <= zd`），要求价格穿越**整个中枢**才兑现；
   而止损（T6/T7 三买逃逸）就在中枢上沿附近确认。目标远、止损近——payoff < 1 是这个几何结构的**内生性质**，
   加任何开腿确认门都救不了它。
2. **开腿无次级别背驰收缩（精度缺陷，次因）**：盘背判定是本级别"最后两个同向离开段"的单段力度直比，
   触发即开腿。27课区间套定理（"所有买点归根结底都是第一类买点，要找精确的，都要下次级别以下找第一类"）
   要求的逐级背驰段收缩完全缺位。现有 G1 sub_anchor 只是"前一级方向==Down"的存在性核对，不是背驰段收缩。

对应的递归正则化方案是三个**独立消融位**（§5）：
- **R1（开腿）**：盘背 DivEvent → 次级别 Sell 侧背驰/卖点落在 C 段窗口内才开腿（区间套一步收缩）
- **R2（闭腿）**：震荡型兑现锚 ZD → **ZG**（对齐原文保证域），ZD 降为条件性延伸目标
- **R3（尾部）**：candidate Buy3 预逃逸（t6，唯一大负槽）替换为次级别"回跌不重回"证据确认

预注册判据：若 R1+R2+R3 全开后盘背腿 payoff 仍 <1 且净负，则"盘背卖可作为独立开腿信号"被否证，
原文口径回归——盘背卖的正典角色是**持仓出场+条件回补**（33课中枢震荡降成本），不是反向开腿信号（§4.4）。

## 1. 原文中的盘整背驰：定义、后续结构、操作方法

### 1.1 定义与力度比较对象

编纂版第四节（`docs/chanlun/text/chan99/0016-第四节 背驰与盘整背驰.md`）：

> 盘整背驰：盘整中当下笔或线段比前一笔或线段力度要弱，就形成了盘整背驰。

第24课（`docs/chanlun/text/blog/024-第24课.md`）：

> 对于背驰与盘整背驰，前者是有着最基础意义的，而后者，只是利用前者相应的力度分析方法进行的一个推广用法，
> **主要用在与走势中枢震荡相关的力度比较中**。注意，a+B+c 中，a 和 c 的盘整背驰，其实都可以看成是 B 的走势中枢震荡。

盘整背驰是背驰力度分析法的**推广用法**，本体是中枢震荡的力度比较——不是趋势的结束标志。

### 1.2 后续走势结构：与趋势背驰的根本不同（payoff 差异的原文根源）

**趋势背驰的保证**（第24课）：

> 背驰是最重要的，一旦出现背驰，其回跌，**一定至少重新回到 B 段的走势中枢里**。

**盘整背驰的保证**（编纂版第四节）：

> 一个背驰后，无论是盘整背驰还是真正的背驰，**理论只能保证其回拉原来的走势中枢**……
> 如果在第一个走势中枢就出现背驰，那不会是真正意义上的背驰，只能算是盘整背驰，
> 其真正的技术含义，其实就是**一个企图脱离走势中枢的运动，由于力度有限，被阻止而出现回到走势中枢里**。

**盘整背驰的尾部风险**（第24课，原文明确指出）：

> 注意，**盘整背驰出来，并不一定都要大幅下跌，否则怎么会有第三类买点构成的情况**。
> ……其后的次级别回跌并不重新回到前面的中枢里，就……构成了标准的第三类买点，这时候就该重新回补了。

三句话合起来就是 payoff 1.66 vs 0.73 的原文解释：

| | 趋势背驰（type1 卖） | 盘整背驰（盘背卖） |
|---|---|---|
| 反向幅度下界 | 一定**重新回到**最后一个中枢（深目标有保证） | 只保证**回拉**到中枢（浅目标，回到 ZG 下方即兑现完毕） |
| 尾部情形 | 趋势已终结，继续上冲需新生长 | **三买突破继续上涨是定义内合法情形**，且原文要求此时回补 |
| 利润空间 | 宽（跨中枢） | 窄（单中枢边缘到中枢区间） |

### 1.3 操作方法（第24课标准程式）

> 如果 C 段不破中枢，一旦出现 MACD 柱子的 C 段面积小于 A 段面积，其后必定有回跌。
> 比较复杂的是如果 C 段上破中枢，但 MACD 柱子的面积小于 A 段的，这时候的原则是**先出来**，其后有两种情况：
> **如果回跌不重新跌回，就在次级别的第一类买点回补，刚好这反而构成该级别的第三类买点，反之就继续该盘整**。

注意原文动词：**"先出来"+"回补"**——盘背卖在原文程式中是**持仓的出场动作**（附带条件回补），
不是开反向仓的择时信号。第33课中枢震荡操作同构：

> 每次向下离开中枢只要出现底背驰，那就可以介入了，然后看相应回拉出现顶背驰的位置是否能超越前面一个
> 向上离开的顶背驰高点，不行一定要走，行也可以走，但次级别回抽一旦不重新回到中枢里，
> 就意味着第三类买点出现了，就一定要买回来。

第29课给出了次级别精确化的操作版本：

> 完全可以**在突破的次级别走势背驰时先出掉**，然后看回试是否形成第三类买点，形成就回补，不形成就不回补。

### 1.4 区间套：递归正则化的原文依据

第27课区间套定理：

> 某大级别的转折点，可以通过**不同级别背驰段的逐级收缩范围**而确定。
> ……先找到其背驰段，然后在次级别图里，找出相应背驰段在次级别里的背驰段，将该过程反复进行下去。

第24课答疑（直接回答"盘背构成的二三类买点要不要下次级别"）：

> 所有买点，归根结底都是第一类买点，**要找第二、三类，其精确的，都要下次级别以下找第一类**。

区间套对盘整背驰**同样适用**——盘背卖的严格形式是：本级别盘背段内，次级别走势出现（趋势或盘整）顶背驰段，
转折点落在两级背驰段的区间交集内。原文没有为盘背豁免次级别确认。

## 2. 引擎现状：盘背卖的实现链路

### 2.1 判定（`rust/src/divergence.rs`）

- `detect_consolidation_divergence`（`divergence.rs:469`）：盘整 Move 内，`collect_exit_segments` 收集
  超出 [ZD,ZG] 的段 + 中枢后到 Move 终点的段，按方向分组，取**最后两个同向段**做单段力度直比
  （A=C=单段，T2 振幅×时长 ∨ T6 DIF ∨ T7 HIST）。
- **有中枢位置约束**（离开段必须越出 [ZD,ZG]），**无任何次级别结构参与**。
- 判定在 L1/L2 各层独立进行，层间无区间套收缩。

### 2.2 信号与开腿（`rust/src/buysellpoint.rs`、`rust/src/trading/level_operating_unit.rs`）

- 盘背**不构造 BSP 事件**（`bi_zhongshu_bsp.rs:183`），以 `DivEvent{kind: Consolidation}` 直接进交易层。
- rev_paired 模式下 `rev_open_signal`（`level_operating_unit.rs:393`）：
  `Consolidation ∧ Direction::Up` 单独成开腿触发源（位掩码 bit1），开**震荡型（Oscillation）**REV 腿。
- 开腿前守卫 G1/G2/G3a 对盘背卖与 type1 卖**完全一致**（共享 `rev_open_verdict`）。
  G1 sub_anchor 最强档（CenterFormed）也只是"前一级方向==Down ∧ 前一级有存活中枢"的**存在性核对**——
  不是 27 课的背驰段收缩：它不检查次级别是否出现**卖侧力竭证据**，更不检查区间交集。

### 2.3 闭腿配对（`level_operating_unit.rs:541` `step_down_paired`）

震荡型腿的闭腿集（穷举）：
1. **T7**：confirmed Buy3 → 全平（硬逃逸）
2. **T6**：candidate Buy3 → 全平（预逃逸）——已知唯一大负槽（胜率≈30%）
3. **T5**：同锚（`e.cs == anchor_cs`）confirmed Buy1
4. **ZD 触线**：`c <= zd` → 全平（震荡型专属兑现锚）

**与 type1 卖（逃逸型）的差异仅在 T5 配对范围（同锚 vs 任意锚）和 ZD 触线的有无**；
T6/T7 止损规则两者相同。

### 2.4 深度门 θ

`theta_depth`（`trading/config.rs:95`）：开腿要求 `(ZG−ZD)/c ≥ θ`（初值 1%），震荡型/逃逸型一视同仁，
仅 rev_paired 路径消费。**门的语义是中枢全振幅**，与震荡型腿的实际利润空间（开腿价到兑现锚的距离）不对应——见 §4.3。

### 2.5 type1 卖的"递归正则化"现状（对照）

- **信号层：没有**。`detect_type1`（`buysellpoint.rs:169`）纯本级别：Trend div + 力竭比
  `force_c/force_a ≤ 0.9` 确认，无次级别查询。
- **交易层闭腿侧：有**。`RevClose::Nested` 模式下 Buy1 闭腿要求 `sub_buy`（次级别买点，27课区间套，
  `nesting_buy_level` 读 `rows.buy_any[l-1]`）。
- **type1 高 payoff 的来源由此判明**：不是确认精度（信号层同样没有次级别），而是
  **趋势背驰后反向幅度的原文下界保证**（"一定至少重新回到最后一个中枢"）+ B2 越界极值机制让
  C 段锚定真实转折点。type1 卖的对手情形（趋势背驰后继续上冲）需要新走势生长，概率结构上劣势；
  盘背卖的对手情形（三买突破）是**中枢离开的定义内合法路径**，概率结构上不劣势。

## 3. 根因诊断：赔大赚小的几何分解

V2r 逐笔行为分解已给出现象：盘背卖一致净负，MDD 集中在**中枢离开阶段**。结合 §1/§2，机制链条：

```
开腿点：向上离开段力竭处（价格在 ZG 上方或中枢上部）
兑现锚：ZD 触线 —— 需要价格走完 (开腿价−ZG) + (ZG−ZD) 全程
止损点：T6/T7 三买逃逸 —— 在中枢上沿外侧即确认（candidate Buy3 更早）
原文保证：只到 ZG（回拉中枢）
```

- **赚的一侧被砍短**：原文保证的兑现段是 开腿价→ZG；引擎要求多走 ZG→ZD 一整个中枢振幅，
  这段**没有任何理论保证**——盘整背驰的定义恰恰是"企图离开被阻止**回到中枢里**"，回到中枢里
  ≠ 跌穿中枢。在中枢内震荡若干段后向上三买离开，是完全合法路径，此时腿被 T6/T7 在高位止损。
- **赔的一侧是定义内事件**：三买突破不是黑天鹅，是盘整背驰的两个正典出口之一（第24课明示）。
  t6（candidate Buy3 预逃逸）止损成本是已确认的唯一大负槽。
- **所以 payoff 0.73 的分解 = 兑现目标超出保证域（存活率低）× 定义内尾部高频止损（止损快）**。
  这解释了为什么单纯加开腿确认门预期改善有限：确认门提高的是"盘背为真"的概率，
  但盘背为真也只保证回 ZG，不保证触 ZD。

## 4. 递归正则化方案

### 4.1 R1 — 开腿的次级别背驰收缩（27课区间套，一步收缩）

**严格形式**：本级别（ladder k）盘背 DivEvent 触发后，开腿要求次级别（ladder k−1）在
**本级别 C 段的 bar 窗口内**出现 Sell 侧力竭证据：

```
sub_confirm(k) := ∃ d ∈ devs[k−1] ∪ {Sell1 ∈ evs[k−1]}:
    d.side == Sell ∧ d 的信号 bar ∈ [C段起点, 当前bar]
```

- 这是区间套的**一步收缩**（不递归到最低级别）：转折点定位精度从"本级别单段直比"
  收缩到"两级背驰段区间交集"。第29课"在突破的次级别走势背驰时先出掉"是这一步的原文操作版。
- 与现有 G1 的关系：G1（Direction/CenterFormed）是次级别**反向结构存在性**核对，R1 是次级别
  **卖侧力竭证据**核对——两者正交，R1 不取代 G1。
- 实现锚点：`rows.devs[k-1]` / `rows.evs[k-1]` 已在 `BarRows` 中逐层可得（`nesting_buy_level`
  对买侧已有同构读法 `rows.buy_any.get(l-1)`），卖侧对称补 `sell_any` 即可——架构无障碍。

### 4.2 R2 — 闭腿锚对齐原文保证域：ZD → ZG（主修正）

**严格形式**：震荡型腿的兑现锚改为 **ZG 触线**（`c <= zg`，即价格回入中枢），分两档：

- **基础兑现**：`c <= ZG` → 平腿（原文保证域内的全部利润）。
- **条件延伸**（可选第二档）：触 ZG 时若次级别（k−1）回拉走势**尚未出现底背驰/买点**
  （即次级别下跌仍在生长），保留部分仓位以 ZD 为延伸目标；次级别买侧证据出现即全平。
  这是区间套在闭腿侧的对称应用——**和 type1 买回侧 `RevClose::Nested` 完全同构**。

R2 是对 payoff 几何的直接手术：兑现目标从"无保证的全中枢穿越"收缩到"有保证的回拉段"，
存活率（兑现频率）预期显著上升；代价是单笔兑现幅度下降——这正是盘整短差的本性（第33课：
盘整震荡反复做、积小成多，不是单笔大赚）。

### 4.3 R2 附属 — 深度门语义修正

θ 门当前度量中枢全振幅 `(ZG−ZD)/c`，但震荡型腿在 R2 下的利润空间是 `(开腿价−ZG)/c`（离开段回拉空间）
+ 条件延伸。严格的门应是**利润空间对执行摩擦的覆盖比**：

```
depth_ok := (c_open − ZG)/c_open ≥ θ'    （震荡型，R2 口径）
```

原 `(ZG−ZD)/c ≥ θ` 保留为延伸档的独立门。盘背发生在中枢边缘、振幅本身较小的疑虑由此解除：
门量的不再是中枢大小，而是**这笔腿真实可兑现的段**。第33课"振幅超过10%……减低成本的好机会"
说明盘整短差的有效域就是振幅充分的中枢——门的方向正确，语义需对齐兑现锚。

### 4.4 R3 — 尾部止损的次级别确认（t6 负槽收紧）

三买的正典定义（第24课）："**次级别回跌不重新回到中枢里**"。当前 t6 用本级别 candidate Buy3
预逃逸，假阳性高（胜率≈30% 唯一大负槽）。递归正则化版本：

```
预逃逸条件 := candidate Buy3 ∧ 次级别(k−1)回拉走势已完成（次级别买点/底背驰已出现且回拉低点 > ZG）
```

即用次级别结构判断"回跌不重回"是否**已经成立**，而非用本级别 candidate 状态猜测它将要成立。
confirmed Buy3（T7）保留不动——它已是定义内确认。

### 4.5 消融设计（预注册）

R1/R2/R3 互相独立，三位掩码消融，基线 = 当前 V2r 震荡型：

| 配置 | 检验的假说 |
|---|---|
| R2 only | 几何根因假说：闭腿锚越界是 payoff<1 的主因 |
| R1 only | 精度根因假说（编排者原始假说）：开腿无次级别确认是主因 |
| R1+R2 | 两缺陷合取 |
| R1+R2+R3 | 完整正则化 |

**预注册判据**：
- 若 R2 only 即转正而 R1 only 不转正 → 几何根因成立，递归正则化假说（开腿侧）被否证为次因；
- 若 R1+R2+R3 全开仍净负 → "盘背卖作为独立反向开腿信号"被否证，回归原文口径：
  盘背卖降级为**持仓出场触发 +三买回补**（仓位管理动作，第24/33课原文程式），不再开 REV 腿。
  这不是关掉盘背卖（补丁思维），而是把它放回原文给它的存在论位置。

## 5. 与区间套反向应用的关系

区间套反向应用的两半在盘背卖上的精确落点：

- **高级别中枢定义操作域**：盘背的锚中枢 [ZD, ZG] + 离开段就是操作域。域的约束 =
  原文保证域（回拉至 ZG）——这直接规定了 R2 的兑现锚。域的边界事件（三买离开）规定了 R3 的止损语义。
  当前实现的域约束只用了"离开段越出 [ZD,ZG]"（判定侧），没有用"回拉保证到 ZG 为止"（兑现侧）——
  域被用了一半。
- **次级别走势类型定位操作点**：开腿点 = 次级别卖侧背驰段 ∩ 本级别盘背 C 段（R1）；
  闭腿延伸/终止点 = 次级别买侧证据（R2 延伸档、R3）。第24课答疑"要找第二、三类，其精确的，
  都要下次级别以下找第一类"——盘背卖的操作点严格形式就是**次级别第一类卖点**。

买侧已有的同构先例：`RevClose::Nested`（Buy1 闭腿 ∧ 次级别买点）和区间套配对修复（P1-P7）证明
这条链路在引擎里架构可行且已在买侧验证过方向——本方案是它的卖侧对称延拓 + 兑现锚修正。
