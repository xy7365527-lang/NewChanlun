# 跨国 K4 汇率层深挖：残差·领先性·黄金计价三合一

数据：`analysis/data_cache/*_1m_databento_10y.json`（ES/GC/CL/ZN/6E/BRN/DX）

**残差定义**（254/517 号货币层和乐）：
$$r = \log DX + 0.576\cdot\log EURUSD = \log DX - 0.576\cdot\log\,\mathrm{usd6e}$$
（usd6e = USD 强度 = 1/EURUSD；EUR 在 DX 篮子权重 57.6%）。
r = DX 中**无法被单条 EUR 腿解释**的部分 = 非欧元货币篮子的独立运动。

## ⚠ 数据约束（诚实标注，no-workaround）

- 请求的 regime（2010-2015 / 2015-2020 / 2020-2025）中，**残差 r 仅 2019+ 可算**——
  2010-2018 的 DX 不存在，残差在该域**不存在**（非省略，是数据边界）。
- 故 Part 1 regime 在 DX 可得域内重切：2019-2021 / 2021-2023 / 2023-2026。
- 顶点映射沿用 528/529 分歧标注（C=CL≡油、R=ZN≡利率，非正典）——见
  `k4_1min_lib.py` 模块头注。本报告 σ 全部 L2 真实数据。

### Part 1 判定（混合结果，可证伪）

- **日度**：残差-金相关在所有 regime **更强（更负）**于 DX-金——非欧元美元篮子
  携带的金价相关信号略强于完整 DX。
- **分钟**：相反——DX-金更强。移除 EUR 腿削弱了分钟级 FX↔金的同步共动
  （金与 EUR 在日内对美元紧耦合，EUR 腿正是该共动主因）。
- **稳定性**：残差 **不更稳定**（日度 corr 跨 regime 标准差更大）。
- 结论：残差**非一致更优**——日度更强但更不稳定、分钟更弱。计价层的非欧元
  篮子信息只在**日度尺度**对金略有增量，且以稳定性为代价。

## Part 2：残差变化率对 K4 配置转换的领先性

|------|-------|------|------|

### Part 2 判定（否定性结果，L2 有信息）

- **滞后相关全部微弱**（|corr|≤0.08），且最强滞后多在 **k=0 同期**而非 k>0 领先。
- **Granger 因果 Δr→σ切换 全部 p>0.05**（sw_any p=0.47、swP 0.23、swC 0.18、swR 0.78）
  → **无法拒绝 H0**：残差变化率**不 Granger-领先** K4 配置切换。
- 反向 σ切换→Δr 同样 p>0.05（0.53）——两向皆无，非反向因果掩盖。
- **否定性结论**（formalization-validity-domain：否定缩小有效域）：
  残差变化率与 K4 配置切换在日频上**仅有微弱同期关联、无领先预测力**。
  残差不是 K4 regime 切换的先行指标。

## Part 3：黄金计价 K4 → K3 折叠重构

### ⚠ 概念修正：金计价不是简单除以金价

**254号定理3 + 开放问题4（自测不可能性）+ 529号折叠重构**：黄金 ∈ Σ∩C 是
结算尺空间中**唯一既是尺子（∈Σ）又是被测物（∈C）的节点**。当黄金成为计价
单位（尺子），它**无法测量自身** → C 顶点与 M（\$）顶点在黄金截面合并为同一
节点 → **自由度减一 → K4 退化为 K3**。这是互测网络闭合的拓扑必然，不是代数
巧合。布雷顿森林体系（黄金=唯一结算尺）= K3 截面的历史实例。

| 维度 | 美元计价（K4） | 黄金计价（K3） |
|------|---------------|----------------|
| 顶点 | M(\$),P,C,R | Au(=C=\$合并),P,R |
| 计价单位 | M（\$=usd6e） | Au（GC，吸收进所有边） |
| 独立边(DOF) | P/M,C/M,R/M（**3**） | P/Au,R/Au（**2**） |
| 配置态数 | 27 | 9 |
| \$ 的角色 | 计价基准顶点 | **降为边 M/Au=USD/GC=1/GC**（影子金价裂缝） |
| C/M 轴 | 商品配置轴 | **塌缩**（C 黄金分量=计价单位=1） |
| 折叠通道 | Au=C↔M, Oil=C→P | Au→吸收为计价单位; Oil=Au→P(=CL/GC) |

> 我原始 Part 3 把 σ(ES/GC),σ(CL/GC),σ(ZN/GC) 当 3 个独立配置轴是**概念错误**：
> CL/GC 在金计价下是 **Oil 折叠通道观测量**（C→P），不是配置轴；C 顶点已并入
> 计价单位。修正后金计价配置空间 = **2-DOF**：Γ_Au=(σ(P/Au),σ(R/Au))。

### Part 3 判定（修正后）

- **拓扑退化（L0，254号定理3 + 529号）**：金计价 → Au 折叠塌缩为计价单位、
  \$ 降为边、C 与 \$ 合并 → **K4（3-DOF/27 态）退化为 K3（2-DOF/9 态）**。
  自由度减一是黄金自测不可能性的拓扑必然，非代数巧合。
- **存活轴 numeraire 非中性（L2）**：P（ES）κ=+0.338（中度正一致，σ 部分
  numeraire-稳健）；R（ZN）κ=+0.072（近随机，σ 几乎 numeraire-独立）。
  即使在存活的 2 个配置轴上，换计价单位也显著改写 σ。
- **K3 配置分布总变差 = 0.519**：金计价与美元计价在同维
  (σ_P,σ_R) 上仍是显著不同的分布。
- **降格美元 M/Au（DX/GC）↓55%**：美元在黄金尺下长期贬值——这是『\$ 从计价
  基准降为被测边』的直接可观测（254号影子金价裂缝）。
- 校正主张（254号开放问题4）：原报告的『σ-和乐残差』框架被撤回——254号已

## 结果包（六要素）

**结论**：(1) 残差-金相关日度更强但更不稳定、分钟更弱——非一致更优；
(2) 残差变化率**不 Granger-领先** K4 配置切换（否定性，p>0.05）；
(3) **金计价 → K4 退化为 K3**（254号定理3：黄金自测不可能 → C 与 \$ 合并 →
自由度 3→2，27态→9态；\$ 降为边 M/Au=1/GC）；存活轴 numeraire 非中性
（P κ=+0.34 中度稳健 / R κ=+0.07 近随机），K3 配置总变差 0.5+；降格美元在金尺下 ↓55%。

**定义依据**：254 号 Σ=法定货币群∪黄金、层0 货币边 M_i/M_j；517 号和乐=
闭合循环(2-Simplex)；527 号 σ=走势方向态；a_move_v1 走势(盘整1中枢/趋势2+)；
对数包络比价构造；残差 r=logDX−0.576·log usd6e。

**边界条件**：① DX 仅 2019+ → 残差不存在于 2010-2018，Part1/2 仅 2019-2026；
② σ 取最高涌现级别 → 可观测量随级别漂移；③ 期货连续合约未 back-adjust，
换月在比价处引入跳变；④ 若顶点映射改回正典(C=DBC,R=VNQ)，σ 语义翻转，
结论不可比；⑤ Part2 否定结论可被更高频（周内/事件窗）或非线性领先检验翻转；
⑥ Part3 金计价 K3 退化是 254号定理3 的结构推论（L0）——若黄金丧失 C 顶点属性
（公理0 结算尺演化）则折叠解体、退化失效；⑦ C 代理用 CL（油）非黄金本身，故
无法直接验证『C=\$』边合并（259号/528号代理张力），只能验证自由度退化的结构性。

**下游推论**：① 残差不能用作 K4 regime 的先行择时信号（Part2 否定）；
② 计价单位是拓扑选择，不是除法：金计价下 K4→K3、自由度减一 → 黄金计价的
『K4 配置』根本不存在（只有 K3 的 2-DOF Γ_Au），跨国选股/配置须显式声明 numeraire
**及其对应的图结构**；③ 降格美元 M/Au（DX/GC）↓55% = 美元对黄金长期贬值的可
观测，是 254号『影子金价裂缝』的直接度量；④ 油（CL/GC）作为 Oil 折叠通道在金
计价下观测于 P/Au 边，金油比 ω 的拓扑位置在此明确。

**谱系引用**：254 号（黄金∈Σ∩C / **定理3 黄金截面 C=\$ K4退化为K3** / 开放问题4
**自测不可能性**——黄金是Σ中唯一既是尺子又是被测物的节点）、529 号（折叠通道重构：
Au=C↔M 观测于C/M、Oil=C→P 观测于P/C、M既顶点又度量尺）、292 号（折叠拓扑本体论）、
