## 0. 执行摘要

1. **38课循环 voice 已完整实装**：宿主趋势态暴露（三层 kind accessor + 磁带 trend_flips 行）、VoiceUnit CYCLE38 模式（趋势存续期循环短差）、35课成本门逐腿集成、41课门改绑 master。默认关（`rev_cycle=Single`），全部在册变体零接触。
2. **判决：循环假设两标的一致否证**。V2oa25C38 vs V2oa25 基线：OKLO **−472.8pp**、BRN **−70.4pp**。循环短差对的中位 payoff 两标的皆负（OKLO −154 / BRN −46 现金），胜率 36.4% / 33.2%——显著低于基线单次 REV 配对腿（中位 +51 / +13，胜率>50%）。
3. **死因不是开腿端，是买回端**：循环用"次级别（k−1）任意买点"买回，比基线的配对闭腿（同锚 Buy1 / ZD 触线）显著过早——把有深度的回调短差切成浅尝辄止的高频 churn（OKLO 基线 294 对 rev、均值 +200.7；循环 185 对、均值 +25.8）。这与"等待型确认=纯延迟"谱系的方向**相反**：买回侧的问题不是太慢而是太快。
4. **否证有效域声明**（090号）：本否证的对象是**循环的事件流近似形态**（k 卖点开 × k−1 买点闭 × 趋势态存续），不是38课原文程式本身——原文买回分支有位置约束（"不跌破第一段低点"∨"跌破但与前向下段盘整背驰"），本实现对次级别买证据不加位置区分（调研报告 §1.2 的近似边界在数据上被击中）。

趋势态语义：`is_trend ⟺ 该层尾 move kind=="trend"`（≥2 同向中枢，17课趋势定义的 move 层读数）。**ladder3 趋势态行有判别力**：尾 move 是 pending 态——新 move 以 1 个中枢起步时 kind=consolidation，第 2 个中枢出现才翻 trend（OKLO 趋势态翻转 2,680 行 / BRN 15,904 行，非常数行）。

### 1.2 CYCLE38 FSM（`level_operating_unit.rs::step_cycle38`）

```
RIDE(UpLeg) ∧ 宿主(k+1)趋势态(kind==Trend ∧ dir==Up) → 进入循环
循环内：本级别卖点(confirmed Sell1 ∨ 盘背卖) → 短差开（成本门+冻结门）
        次级别(k−1)买点(buy_any) → 短差闭 → 回到循环
宿主趋势态翻落 → 未决腿强闭（38课程序内置追价买回）→ 退出循环回 RIDE
```

- 配置：`rev_cycle: Single(默认) | Cycle38`；变体 `V2oa25C38`（基线 V2oa25 + Cycle38 + `rev_l41_gate=false`）。
- 模式互斥：Cycle38 替换单次 REV 的全部相位路径（T1/T5/T6/T7/T4b/递归子树不运行）；osc 域腿正交（C2）照常。
- 同 bar 优先级：终止强闭 > 买回 > 卖出。
- 账本共享：循环腿 = `SlotKey::rev(k,k)` 同槽逐次开闭，与单次 REV 同守恒律（同股数进出、降成本）。
- 组合守卫（fail-fast）：Cycle38 × {tranche, rev_sub_depth>0, 无 trend_flips 行, 无 dir_flips 行, rev_mode=false} 全部显式拒绝。

### 2.3 死因分解

1. **买回过早**：k−1 买点的事件密度远高于本级别回调段的真实深度节奏——中位短差被切到负现金（买回价高于卖出价的对占 ~2/3）。基线配对闭腿（同锚 Buy1 = 本级别回调段终结本体；ZD 触线 = 几何兑现锚）等的是**本级别**结束证据，循环等的是**次级别**任意买证据，级别错配一档。
2. **替换损失**：Cycle38 是模式替换不是叠加——基线那批高质量配对 REV 腿（OKLO 均值 +200.7）被循环腿（+25.8）整体替换，rev 槽净现金 OKLO 从 ~59K 降到 ~4.9K。
3. **强闭不是主因**：强闭仅 9/16 次（5%/2%），趋势态终止条件本身工作正常。
4. **重尾掩盖**：c38_cash 两标的皆正（+4.9K/+6.3K）但中位为负——均值被少数深回调大赢拉正，churn 主体亏损。复利口径下叠加敞口时序效应，总账两标的一致恶化。

### 2.4 与 SubLou 分型模式（近似实现前案）对照

笔级分型递归（V2oa25F1，REV 窗口内 k−1 分型直读）：BRN +10.7pp 首张有效票 / OKLO −73.8pp（regime 依赖，有效域=震荡 regime）。Cycle38 与之不同构（宿主趋势窗口 × 买卖点进出 vs REV 窗口 × 分型进出），但**两标的一致负**——比分型模式更弱：分型模式至少在震荡 regime 有正票，循环模式在趋势 regime（其设计域！）本身就亏。这强化了死因诊断：问题不在窗口选择，在买回判据的级别错配。

## 3. 结果包六要素

1. **结论**：38课循环 voice（事件流近似：k 卖点开 × k−1 买点闭 × 宿主趋势态存续）完整实装且默认关；OKLO/BRN 双标的回测一致否证该近似形态（−472.8/−70.4pp vs V2oa25），死因 = 买回判据级别错配（次级别任意买点 ≪ 本级别回调段终结）。
2. **定义依据**：第38课同级别分解程式（循环结构+终止条件"不创新高或盘整背驰"）、38课课间答疑（"不跌破靠次级别内部结构确认"——买回判据的原文出处，本实现取其无位置约束近似）、第17课趋势定义（≥2 同向中枢 → trend_flips 行语义）、第35课成本门、第41课门（改绑 master 的语义裁决）、moves.rs:124 kind 判定。
3. **边界条件**：①否证有效域 = 本近似形态（无位置约束的 k−1 买点买回）；若买回端改为原文位置分支（不破第一段低点 ∨ 跌破后盘整背驰）或本级别结束证据（同锚 Buy1/ZD 触线），结论可能翻转——循环结构本身（重复开闭）未被单独否证，与买回判据纠缠；②floor=2 单口径；③宿主趋势态在 ladder3 的判别力依赖 pending move 的中枢计数语义，若 move 分组规则变化数字全变；④成本门用 SUB_COST_Q=0.5 中位数口径（与 F1 子腿门同构，非 θ 自适应 q25 口径）。
4. **下游推论**：①38课循环方向若续做，下一步唯一值得测的轴 = 买回判据消融（k−1 买点 → 同锚 Buy1/ZD 触线保持循环结构）——把"循环结构"与"买回判据"的因果分离；②trend_flips 行已是磁带常备能力，其他趋势态消费者（如 49课豁免区门）可零成本接入；③`rev_cycle` 轴与 tranche/递归正交性已显式拒绝，未来组合需先定义语义。
5. **谱系引用**：532号（seg-end trigger 轴分离）、267号（多重赋格）、090号（近似声明义务）；记忆谱系：REV 配对修正（同锚 Buy1+ZD 触线闭腿——本判决反向确认其买回判据是循环缺的那块）、次级别确认否证（"等待型确认=纯延迟"——本案方向相反：买回不是太慢是太快，二者合取把买回判据的正确位置钉在"本级别结束证据"）、笔级分型递归赋格（近似实现否证先例）、太小级别短差有害（共享仓位赋格——churn 主体亏损同构）。
6. **影响声明**：Rust 改动 `bi_zhongshu_bsp.rs`（+last_move_kind）、`lib.rs`（2 个 kind accessor + from_columns trend_flips 参数 + c38_net_cash marshal）、`tape.rs`（trend_flips 行）、`config.rs`（RevCycle 轴 + V2oa25C38 变体）、`types.rs`（11 个 c38 计数器）、`level_operating_unit.rs`（BarRows.trend_row + step_cycle38/c38_close_leg/step_osc 抽出）、`runner.rs`（6 项 capability guard + 趋势态滚动）；Python 改动 `organic_signals.py`（trend_flips 收集器，默认 None 零行为变化）、`organic_fugue_rust_check.py`（pack_tape 透传）；新增 `cycle38_voice_backtest.py` + 本报告。在册磁带指纹不变（trend_flips 是加法行）；全部在册变体行为逐位不变（零接触守卫）。
