# 双书独立逐仓 voice × 区间套递归到 a0——2×2 消融八标的判决

任务（2026-06-12 编排者）：两个核心实装——1）每级别 voice 独立逐仓头寸
（非净额合并），可同时持多空；2）区间套从特定级别递归到 a0（非一层 nest）。

**同源分岔声明**：同一编排者决断存在两种读法并行实装——
- **合一读法**（nrf，`nested_fugue.rs`，并行工位）："逐仓独立头寸和递归
  区间套是同一件事"——区间套递归 = voice spawn 时序机制，子层开反向
  独立头寸，父仓不动；
- **分离读法**（本判决，fusion_vd/vn/vdn，`dual_voice.rs`）：fusion_v
  基座上两个正交轴的 2×2 消融——双书（每级别多空两本独立逐仓书）×
  递归 nest（链式贯通到 a0 端 bi 翻转沿）。

分离读法的消融价值：分离两个机制的独立贡献与交互项；合一读法是单一
机制不可分解。跨读法对比见 §6。

- 认识论等级：实装守卫 L1（bit-exact + 单测）；八标的回测 **L3**
  （1min 全史真实数据，可否证）。

## 1. 实装形式（严格声明）

### 1.1 dual_book 轴（fusion_vd）

在册 fusion_v 每层单一 `LayerState`（Long XOR Short），卖点确认经翻转
断面 M=N（开空 units = 平多股数，margin = 平多所得）——同级别多空互斥
即**净额合并的存在方式**。dual_book 拆为两本独立书：

| 书 | 状态载体 | 入场 | 出场 | 门 |
|----|---------|------|------|----|
| 多头书 | `LayerState`（在册） | 买点 enter_or_defer（026:34） | 卖点出清 | MoveUp 停削（049:52）/ Osc r2 c≥ZG |
| 空头书 | `ShortState`（新增） | 卖点 θ 配额开空（1x 虚拟逐仓） | 买点平空 | MoveUp 不开仓+强制平空 / MoveDown 停回补 [镜像] / Osc r2 双侧 |

- 同一卖点确认（门放行）同 bar 驱动：多头出清 ∧ 空头开仓——两个独立
  会计动作。M=N 让位于配额对称（空头开仓量 = 该级别 θ 配额全量）。
- **同级别多空可共存**（如 MoveDown 中持空 + 买点驱动多头入场而空头
  停回补拦截）——`bidirectional_nested_accounting.md` v2 §4.1"m>N
  翻转位不可表示"的承载位补全。共存 = 双份配额占用（逐仓本质）。
- T2W 第二窗口为市场性质锁存，双书共享；卖侧任一书消费后统一清。
- MoveUp 强制平空后多头书 Flat ⇒ 同 bar enter_or_defer（满仓义务与
  在册翻多对齐——义务一致性，最小差分）。

### 1.2 nest_deep 轴（fusion_vn）

在册 nest 一层截断（k 武装 → k−1 任意同侧证据触发）；
`interval_nesting_forward_positioning.md` §4.2 显式登记多层递归为开放轴。
nest_deep 实装 0027:11 字面程序（"反复进行下去，直到最低级别"）：

```
fire(k, side) ⟺ win[k] 同侧活动
              ∧ ∀j∈[FIRST_BSP_LADDER, k)：win[j] 同侧活动（区间嵌套贯通）
              ∧ bi 层同侧方向翻转沿（a0 端最低结构词汇）
```

- 退化一致性：k==FIRST_BSP_LADDER 时判据 ≡ 在册一层截断 bi 分支。
- 同时性语义：fire 判定基于本 bar 武装/否定完成后的窗口快照——bi 翻转
  沿到达时所有贯通链同 bar 同时触发（027课区间套定理的多级别同时显现；
  实装层修复了循环顺序消费 bug：低层 fire 清窗不得击穿高层链检查）。
- 否定词汇不变（027:25 逆否：各层窗口各自破极值作废——链上任意层破 ⇒
  贯通失败，自然承载"区间套破裂"）。
- 诚实声明：a0（bar 层）无结构事件行，递归下界 = bi 层翻转沿（其定义域
  是 a0 K 线序列）。

## 4. 机制解剖

1. **双书失血源 = 空头书在确认滞后词汇上的轧空税**。vd 的
   cover_moveup（MoveUp 满仓义务强制平空）与 nest_sell 开空数同量级
   （BTC 1163 vs 1295）——空头开在卖点确认（滞后）后，过半在下一个
   MoveUp 窗口被强制回补 = 系统性买高平空；short_cash_total 全标的
   为负。这是"字面做空死域"的第四次独立复现（fusion_v 字面翻空 6/8 负
   → 双向 S1-S4 ES/QQQ 全形态负 → nrf v3 根翻空 6/8 负 → 本判决
   vd 0/8）。同级别多空共存真实出现但属过渡相位，无独立 alpha。
2. **递归 nest 的正增量与 nrf 侧跨实装印证**。vn 的 nest_sell 出场从
   vd/fv 的 ~1295 降到 611（贯通判据更严 ⇒ 触发更少更准）——链贯通
   过滤掉一层截断的噪声触发。nrf v4 侧 deep_fires 271~2946 全激活且
   贡献为正：**区间套递归到 a0 是两种读法下唯一双正的机制轴**。
3. **MDD 面**：vd/vdn 普遍浅于 fusion_v（OKLO −67.4 vs −76.8、BRN
   −33.6 vs −46.1）——空头书对冲压回撤但代价是收益腰斩；vn 的 MDD
   ≈ fusion_v（同暴露结构）。

## 5. 边界条件

- 双书共存的物理执行：账本层不折叠；若实盘载体强制净额（IBKR 同工具），
  执行层需拆载体（如现货+永续、或期权腿）——部署层动作，不入 FSM。
- nest_deep 的链贯通要求全部中间层 candidate 同侧武装——事件稀疏时
  贯通概率随塔高指数衰减，覆盖率由回测裁决。
- 空头书开仓门复用削减门（MoveUp/r2）——更严的空头准入（如 anc 镜像门）
  未预注册，列开放轴。

## 6. 与 nrf 合一读法的跨读法对比

nrf 侧当日完成三段演化（v2 合一基线 → v3 根翻转否证 → v4 严格会计，
见 `analysis/nrf_v4_strict_accounting.md`），与本判决可对比的轴：

| 机制轴 | 分离读法读数 | 合一读法读数 | 跨读法结论 |
|--------|-------------|-------------|-----------|
| 区间套递归到 a0 | vn 5/8 ≥ fv，BTC +1447 新高 | v4 deep_fires 全激活、贡献正 | **双正——升基座候选的唯一机制轴** |
| 同级别/根级做空 | vd 0/8 全负（轧空税） | v3 根翻空 6/8 负、BTC 强平归零 | **双负——字面做空死域第三/四次复现，关闭** |
| 暴露基座 | fusion_v 满仓义务（MoveUp 翻多） | v4 不清仓 + θ 配额释放 | v4 P1 3/8 正域 {OKLO,QQQ,GC}=趋势域；本判决 P1 4/8 正域 {BTC,BRN,CL,DX}≈BH 弱域——**两读法正域近似互补（合计 7/8，缺 ES）** |

正域互补是本对比最重的结构发现：合一读法（恒仓+配额短差）赢在趋势域，
分离读法（满仓义务+递归 nest）赢在震荡/深回撤域——regime 函数第十余例
的跨读法形态。白名单路由（按域挂臂）可作开放轴，但属 regime 条件化，
须独立预注册。
