> 生成时间：2026-05-31  
> 数据：QQQ 日线，yfinance 全量（1999-01-01 起，6848 根原始 K 线）  
> 认识论等级：L2（真实数据，可否证）

---

## 0. 核心结论

**引擎并非"只出1个 confirmed 信号"——而是出了 4 个 confirmed 买卖点，但全部来自 2000-2003 年（价格 $27-$43）。从 2010 年至今，confirmed 买卖点 = 0。**

TV 出 137 个买卖点（两个 CZSC 实例分别出 505 + 244 labels）。

差距的根本原因不在笔层（引擎笔反而更多），而在**尺度选择**：引擎把 25 年数据当成单一级别计算，产出月线/季线级结构；TV 对同一数据做多时间框架分析，产出日线级信号。

## 2. 笔层：引擎多出约 47% 的笔

### 2.1 数量

- 引擎 (mode=new): **554 笔**
- TV 753 lines 中包含笔 + 线段 + 其他标注，实际笔数估算：~300-400 条

### 2.2 gap 分布（引擎）

```
raw_gap=3: 68笔（TV 宽笔可能不认）
raw_gap=4: 63笔（TV 宽笔可能不认）
raw_gap≥5: 423笔（主流有效笔）
中位数 raw_gap: 7
```

### 2.3 差异来源

引擎 `mode="new"` 的 gap 条件：
```python
merged_gap >= 2  AND  raw_gap >= 3
```

TV "宽笔"设置的推测条件：`merged_gap >= 4 AND raw_gap >= 4`（或 `raw_gap >= 5`）。

引擎多出的 131 笔（raw_gap=3-4）是 TV 不认的"噪声笔"。这些噪声笔进入线段算法后，会干扰特征序列，导致有效线段变少。

### 2.4 包含处理差异

引擎 `a_inclusion.py` 的包含方向：
- `dir_state=None` 时，用上一根 merged bar 的 `close >= open` 推断方向（阳线→UP，阴线→DOWN）
- `reset_dir_on_fractal=False`（默认），长趋势下方向状态被锁定

TV "优化包含" 的含义通常是：包含方向在分型形成后重置，防止长趋势锁死（对应 `reset_dir_on_fractal=True`）。

**引擎当前未启用 `reset_dir_on_fractal=True`**，这可能导致部分合并偏差。

## 3. 线段层：552笔→58线段，压缩比 9.5:1（过高）

TV 115 个中枢意味着至少 115×3=345 条有效线段（每个中枢至少需要 3 条反向线段才能形成）。

引擎 58 条线段产出 14 个中枢，合理（14×4≈56）。

**但 58 条线段 vs 需要的 345+ 条相差约 6 倍。**

压缩比过高的原因：
1. **噪声笔干扰三笔重叠条件**：131 条 gap 过短的噪声笔参与特征序列，使有效的三笔重叠段被切断
2. **结算锚验证过严**：`_try_trigger_segment` 中要求新段起点后第 k, k+1, k+2 三笔有重叠才能触发断段，这是额外的双重验证
3. **25 年尺度的几何压缩**：日线 25 年对应月线级的 3-5 个大结构，正确压缩

## 4. 中枢层：14 vs 115（差距 8 倍）

引擎的 14 个中枢覆盖 25 年：
- 2000-2002 熊市：3 个中枢（s0=0, s2, s6）
- 2002-2009 牛市：4 个中枢（s10, s15, s22, s27）
- 2009-今 牛市：7 个中枢（s31-s55）

价格区间 $16-$537，完全是月线/季线级别的大结构。

TV 115 个中枢来自两个 CZSC 实例（82+33），这些是日线级和周线级的细粒度中枢。

**尺度不匹配是核心问题：引擎在日线数据上产出月线级结构，TV 在日线数据上产出日线级结构。**

## 5. 走势与背驰：0 背驰信号

引擎 3 个走势：
1. 下跌趋势 (segs 0-9)：settled=True（2000-2002 熊市）
2. 上涨趋势 (segs 10-21)：settled=True（2002-2008 牛市）
3. 上涨趋势 (segs 22-57)：**settled=False**（2008-今，仍在进行中）

背驰 = 0。

Type1 买卖点需要背驰，而背驰需要：
1. 走势 settled=True（当前大级别走势未 settled）
2. MACD 数据（引擎调用 `divergences_from_level` 时未提供 `df_macd`）

**2008年以来的15年上涨趋势，在引擎的月线级视角下，是一个未结束的走势——没有背驰，没有 Type1 买卖点。**

## 7. 根本差距分析

### 7.1 尺度错位（首要原因）

引擎是单级别引擎，在 25 年日线数据上直接运行，自然产出月线/季线结构。

TV CZSC 指标在 TradingView 的两个实例（Study1: 505labels/82boxes，Study2: 244labels/33boxes）很可能是：
- Study1：日线级（短窗口或近5年数据）
- Study2：周线级（更短窗口）

或者是同一数据的两个级别递归（次级别 + 本级别）。

### 7.2 笔定义不完全匹配

| 参数 | 引擎 mode=new | TV 宽笔（推测） |
|------|---------------|-----------------|
| merged_gap | ≥ 2 | ≥ 4 |
| raw_gap | ≥ 3 | ≥ 4 或 ≥ 5 |
| 结果 | 554 笔（含 131 条噪声） | ~350-450 笔 |

### 7.3 包含处理方向锁定

引擎默认 `reset_dir_on_fractal=False`，TV "优化包含" 对应 `reset_dir_on_fractal=True`。

### 7.4 背驰计算未接入 MACD

`divergences_from_level` 支持 `df_macd` 参数，但当前调用链未传入。退化为纯价格振幅 fallback，检出率极低。

## 8. 修复建议

### 优先级 1：窗口截断（立竿见影）

不要把 25 年全量数据喂给单级别引擎。对日线买卖点分析，取近 2-3 年（500-750 根日线）：

```python
df = df.iloc[-600:]  # 取最近 600 根日线
```

期望效果：线段从 58 → ~200，中枢从 14 → ~40，买卖点从 4 → ~50+。

### 优先级 2：启用优化包含

```python
df_merged, merged_to_raw = merge_inclusion(df, reset_dir_on_fractal=True)
```

### 优先级 3：收紧笔 gap 阈值

在 `strokes_from_fractals` 的 `_check_gap` 中，"new" 模式改为：
```python
# 当前：merged_gap >= 2 and raw_gap >= 3
# 建议：merged_gap >= 4 and raw_gap >= 4（与 TV 宽笔对齐）
return merged_gap >= 4 and raw_gap >= 4
```

预期从 554 笔 → ~450 笔，过滤 131 条噪声。

### 优先级 4：接入 MACD 数据

```python
from newchan.a_macd import compute_macd
df_macd = compute_macd(df_merged)
divs = divergences_from_level(moves, zhongshu, ..., df_macd=df_macd)
```

### 优先级 5：多级别递归（中期）

TV 用两个 CZSC 实例覆盖不同级别。引擎需要在日线级别递归运行，以线段作为下一级别的"K 线"喂入，产出本级别的笔/线段/中枢/买卖点。

## 9. 结论（结果包六要素）

**结论**：引擎在 QQQ 25 年日线数据上产出 4 confirmed 买卖点（全在 2003 年前），近 15 年零信号，vs TV 137 个买卖点。

**定义依据**：
- 引擎 `confirmed=True` 含义：买卖点所在走势 `settled=True`，即该走势结构已被后续走势证伪/确认。当前大牛市走势（2008-今）`settled=False`，其内的一切买卖点都是 `confirmed=False`。
- TV 的 "confirmed" 含义推测为：分型/中枢出现即可标注（不需要后续走势完结）。

**边界条件**：
- 如果截取近 3 年数据（~750根），引擎会产出日线级结构，买卖点数量会显著增加（估算 30-80 个）
- 如果缩短数据窗口至 2 年，中枢数量预期 ~20-40，买卖点 ~20-50

**下游推论**：
- 背驰检测（Type1）依赖 MACD，目前完全缺失；所有信号仅靠 Type3（第三类买卖点），信号稀少是必然结果
- 多级别递归缺失意味着现有引擎只能产出单一大级别视角，无法生成 TV 那样的多时间框架信号
