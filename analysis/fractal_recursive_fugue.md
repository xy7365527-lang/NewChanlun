# 笔级分型递归赋格 — 调研 + 实验报告（V2ofF1）

> 任务（2026-06-11 编排者）：用笔级分型做递归赋格的进出点，而不是中枢域。
> 背景：递归赋格 depth=1（中枢域模式 V2ofS1）在 OKLO 与 BRN 上双票否证
> （O_sub0），根因 = "父 REV 腿趋势运行中，次级别无存活中枢 → 域不可定义"。
> 认识论等级：**L3**（OKLO 447K + BRN 2.4M bar 双标的真实数据，预注册判据双侧）。

## 1. 调研：第38课原文的短差操作点

来源：`docs/chanlun/text/blog/038-第38课.md`（缠师原始博文，一级权威）。

### 1.1 操作程式原文（正文买卖段）

> "不妨从一个下跌背驰开始……必然首先出现向上的第一段走势类型，**根据其内部
> 结构可以判断其背驰或盘整背驰结束点，先卖出**，然后必然有向下的第二段，这里
> 有两种情况：1、**不跌破第一段低点，重新买入**，2、跌破第一段低点，如果与第
> 一段前的向下段形成盘整背驰，也重新买入……向上段的运作，都是先买后卖的。
> ……**向下段的运作刚好相反，是先卖后买**，从刚才向上段结束的背驰点开始，
> 所有操作刚好反过来就可以。"

### 1.2 关键问答（2007-03-22 16:47:52，touchnet 提问）

> 问："1、不跌破第一段低点，重新买入——这个'不跌破'是靠次级别判断吗？"
> 答："**对，需要该段内部结构的确认。**"

### 1.3 调研结论：分型/段终点定位进出，中枢只定义方向

| 问题 | 原文答案 |
|---|---|
| 短差进出用分型还是中枢？ | **段的转折点**（背驰/盘整背驰结束点 + "不跌破前低"的内部结构确认）。中枢在程式正文中只出现在第2种情况的盘整背驰比较里，**从未作为进出点的前置条件** |
| 在每一笔/段的顶底做，还是在中枢边界做？ | 每一段的顶底。"先卖出→重新买入→再卖出"逐段循环，没有等中枢成形的步骤 |
| 范畴区分 | **中枢定义操作方向（域）**——同级别分解视角下"只选择上涨和盘整、避开下跌"；**分型/段终点定位具体进出（点）**。旧 SubLou 把"点"的定位错配到了"域"的范畴上 |

**原文还预言了本机制的有效域**（38课正文）：

> "其实，根本无须关心个股的具体涨幅有多少，**只要足够活跃，上下震荡大**，
> 这种机械化操作产生的利润是与时间成正比的。"

——机械化短差的有效域是**活跃震荡标的**，不是单边暴涨标的。本实验结果（§5）
逐字印证了这一预言。

注：操作级别上 38 课程式以"段"（次级别走势类型）为单位；本任务的子腿操作对象
是次级别（k−1 层）的 move/笔方向翻转，即把同一程式镜像复制到递归子层——
"顶分型确认"在 D3 方向行上的可观测形式 = 翻 Down（新向下笔/move 被引擎接纳），
这是无前视的最早确认时刻。

## 2. 旧实现的范畴错误（O_sub0 根因复述）

旧 SubLou（V2ofS1）复用 P5 域腿逻辑：开腿要求 `book.alive(k−1)` 存活中枢 +
ZG/ZD 有限 + 振幅经济门 + 兑现空间。但父 REV 腿的前提是"本级别向下段正在
运行"——趋势运行中次级别中枢恰恰大概率不存活（被终结/未形成），导致：

- BRN：34 宿主 → 74% 无中枢拒，仅 1 腿成交且亏损（−0.94pp）；
- OKLO：域空型，塔顶零买点（本次重跑磁带上 5 次无中枢拒 + 1 次振幅拒，0 开腿）。

这是**语法性矛盾**：父腿开腿前提（向下段）否定子腿开腿前提（次级别中枢存活）。
中枢域模式下递归子腿的定义域接近空集——判决否证的是"中枢做域"，不是"短差本身"。

## 3. 设计：fractal 模式（38课向下段程式的笔级直读）

```
开腿（先卖）：次级别 D3 方向行 Up→Down 翻转（顶分型确认）→ 卖出 parent_shares
闭腿（后买）：次级别 D3 方向行 Down→Up 翻转（底分型确认）→ 买回
方向：恒 Short（38课"向下段的运作……是先卖后买"）
预算基：父腿敞口（不变）；同股数进出，不改总仓位（ShareConserving 不变）
级联：父腿闭合 → 子树同价强闭（不变）
递归终止：深度预算 ∧ 存在论下限 = bi 级（ladder 1）——bi 没有内部分型，自然停
```

与中枢域模式的三点拆除：

1. **无"存活中枢"前置**——子域恒可定义（`n_sub_nocenter_rejects ≡ 0`）；
2. **无 ZG/ZD 边界与振幅经济门**——分型即信号，短差幅度由市场给出；
3. **符号交替塔 (−1)^n 不适用**——它是中枢域读法（反弹腿做多）的产物；
   38课向下段程式在所有递归深度上都是顶卖底买（Short）。

设计诚实声明（090号）：D3 方向行是 bar 末状态——同一 bar 内确认多个笔端点
（顶+底）时中间翻转折叠不可见，该往返短差不被捕获（**漏单非错单**）。
首个观测只建立 last_dir 基准不触发：开腿恒等待一次完整 Up→Down 翻转，
不在陈旧方向上行动。

## 6. 判决（预注册判据：Δ>0 ∧ sub净现金>0 ∧ rev胜率不降）

- **OKLO：O_sub0[V2ofF1] 否证** — Δ=−73.79pp，sub 净 −8448.6，胜率 39.4%。
- **BRN：O_sub1[V2ofF1] 成立** — Δ=+10.71pp，sub 净 +6153.5，胜率 54.2%。
  **这是递归赋格链上的第一张有效票**（此前 S1 两标的 + F1 OKLO 共三票全否）。

### 解读：定义域缺口已消除，剩下的是真经济判决

1. **机制修复被数据确认**：两标的 `无中枢拒` 从 5/20 → 0，子腿从"开不出"
   （OKLO 0 腿 / BRN 1 腿）变为"正常运转"（236/59 腿）。判决的对象从
   "域不可定义"（语法层）变成了"短差有没有钱赚"（经济层）——这正是
   本任务要达成的范畴矫正。
2. **regime 依赖与38课原文预言一致**：BRN（原油，震荡 regime，rev 腿胜率
   58.4%）短差转正；OKLO（单边 +307% BH 强趋势）短差为负——原文"只要足够
   活跃，上下震荡大"的有效域声明逐字应验。这与本谱系链上的多次先例同构
   （bar 级 churn 毁 alpha、太小级别短差有害）。
3. **OKLO 负值的结构**：236 对中 97 对（41%）是父腿闭合时的同价强闭——
   分型确认滞后（翻转在新笔被接纳时才可见）使开腿点偏离真实反弹顶；强趋势
   中反弹短促，确认到位时反弹已耗尽。胜率 39.4% < 50% 说明信号在该 regime
   下系统性迟到，不是摩擦问题（回测零摩擦）。

## 7. 结果包（六要素）

1. **结论**：fractal 模式（D3 方向行翻转做进出点）实装并通过守卫；L3 双标的
   判决分裂——BRN O_sub1 成立（+10.71pp，递归链首张有效票），OKLO 否证
   （−73.79pp）。递归短差的有效域 = 震荡 regime 标的，与38课原文预言一致。
   不建议无差别全量投入；建议有效域门控后再扩样本（见下游推论）。
2. **定义依据**：第38课原始博文（一级权威）——"向下段的运作……是先卖后买"
   + "不跌破……需要该段内部结构的确认"（touchnet 问答）；操作锚是段/笔转折
   点而非中枢边界。D3 方向行翻转 = confirmed 笔端点的无前视读出
   （`organic_signals.py` LADDER_BI 行）。
3. **边界条件**：(a) 若 D3 同 bar 翻转折叠显著（高波动 bar 内顶+底同现），
   漏单率上升，结论的样本基础变化；(b) 零摩擦回测——BRN sub 均差 +0.186%
   名义上覆盖 10bps 往返摩擦但余量薄，加真实摩擦后 BRN 票可能翻转；
   (c) BRN 票仅 59 对样本，单标的单 regime——第三标的（震荡型股票或另一
   期货）反向即推翻"regime 依赖"解读；(d) 若分型确认滞后可被更早的确认形式
   替代（如 candidate 笔端点），OKLO 否证可能不成立——本实验只判决了
   confirmed 形式。
4. **下游推论**：(a) 递归赋格不再被"域不可定义"钉死，SubLou 不必休眠——
   但激活需 regime 门（震荡型判别在 REV 开腿时已有：rev 腿本身仅震荡型开）；
   (b) 下一个最小实验是把 sub 开腿挂在父腿锚中枢振幅或 rev 腿 kind 的
   regime 代理上，或直接第三标的扩样本；(c) θ 相对化工位（在跑）与本机制
   正交，可叠加。
5. **谱系引用**：O_sub0 两票（递归赋格深度1否证，OKLO 域空型 + BRN 负样本
   型）——本实验扬弃其根因（中枢域错配）而非推翻其数据；090号（诚实声明：
   同 bar 折叠漏单）；231号（L 级标注）；532号（段终结触发轴先例）。
   涉及概念分离：**中枢=域（方向）vs 分型=点（进出）**的范畴分离，建议
   genealogist 工位入谱。
