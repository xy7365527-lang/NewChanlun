# 多层赋格仓位管理回测

## 设计原理

从 PH merge tree 结构完全派生，零人工参数：
- **方向裁决**：双树 rank-1 settle（tree_up rank-1 settle→翻空, tree_down rank-1 settle→翻多）
- **多层仓位**：alive components 按 persistence 排序 = 级别阶梯
- **降成本比例**：persistence_k / persistence_1（纯结构派生）
- **进场门控**：chanlun candidate + PH rank-1 settle（525号+§7.5）

注：原设计假设"dominant settle"在实践中因 elder rule 约束不可能发生（见下方分析）。
修正为 rank-1 settle（第2大 alive component 被 settle）作为方向翻转信号。

## 三对比组

| 组 | 操作层数 | 逻辑 |
|----|---------|------|
| E | 1（仅 dominant） | 方向翻转时全仓进出，无降成本 |
| F | 2（dominant + 第2大） | E + 次级别降成本（减仓/回补） |
| G | 全部 alive | F + 所有子级别递归降成本 |

## 关键发现：Elder Rule 约束与方向裁决修正

**原设计假设**："dominant（max_alive_persistence 最大的 alive component）被 settle → 翻方向"。

**实际发现**：OnlineMergeTree 的 elder rule 保证 dominant（最低 valley = persistence 最大）**永远不会在 cascade merge 中死亡**。它是所有合并操作的 elder（幸存者）。只有 `finalize()`（序列终止）才能封顶它。

这不是 bug——这是 merge tree 的数学属性：
- Merge 发生在屏障 peak 处，younger（valley 更高 = persistence 更小）被合并掉
- Dominant = valley 最低 = 所有 merge 中永远是 elder

**修正方案（零参数）**：用 **rank-1 settle**（第2大 alive component 被 settle）作为方向信号：
- tree_down(close) rank-1 settle = 第2大下跌腿被吞噬 → 翻多
- tree_up(-close) rank-1 settle = 第2大上涨腿被吞噬 → 翻空

QQQ 1500日线检验：rank-1 settle 频率 = 78次翻多 + 85次翻空（合理信号密度）。

## 三重否定性结果

### 否定1：所有标的所有组 << buy-and-hold

| 标的 | 策略最优% | BH% | 差距 |
|------|----------|-----|------|
| QQQ | +5.90 (F) | +199.86 | -194% |
| SPY | -21.14 (E) | +137.14 | -158% |
| GLD | -19.63 (E) | +155.01 | -175% |
| BRENT | -91.35 (F) | +142.74 | -234% |

**诊断**：2020-2026 是全球资产普涨窗口。rank-1 settle 频率高（每 ~20 bars）导致持仓期极短（均 8-65 bars），频繁翻方向在趋势市中反复止损。特别是空方向在牛市中系统性亏损（QQQ 空头 14 笔总计 -4.57%，BRENT 最后一笔空头 -96.49%）。

### 否定2：F/G 与 E 无实质差异

| 标的 | F-E 增量 | G-E 增量 | 有CR交易数 |
|------|---------|---------|-----------|
| QQQ | +0.27% | +0.27% | 1/22 |
| SPY | -0.10% | -0.10% | 0/23 |
| GLD | -0.69% | -0.69% | 3/13 |
| BRENT | +5.39% | +5.39% | 1/7 |

**根因**：持仓期太短（均 8 bars），在此窗口内 trim+add_back 配对几乎不发生。降成本需要次级别 settle → 减仓 → 等待回补 → 次次级别 settle → 回补，这个序列需要 ≥20 bars 才能完成一个循环。日线级别的 rank-1 settle 翻转太快，降成本逻辑没有执行空间。

### 否定3：BRENT 灾难性空头（-96.49%）

最后一笔空头从 bar 1069 到 bar 1466（397 天），价格从 70.34 涨到 138.21（翻倍）。
rank-1 settle 在这段时间未触发翻多——说明 tree_down 的 rank-1 在整个上涨段保持稳定（没有被 settle），方向裁决失灵。

**结构性解释**：当价格持续上涨不回头时，tree_down 的 alive bars 一直增加（每个回调创建新分量），但没有足够深的回调来触发 rank-1 的 settle。

## 结果包六要素

**结论**：
1. 多层赋格仓位管理在日线颗粒度/2020-2026 牛市窗口**无法跑赢 buy-and-hold**（L2 否定）
2. 降成本层（F/G）在日线级别**几乎无效**——持仓期太短，trim/add_back 无配对空间
3. Elder rule 修正（rank-1 settle 替代 dominant settle）是数学必然——原设计假设不成立
4. 空方向在普涨市中系统性亏损——双向操作在单边市无优势

**定义依据**：
- 方向翻转 = rank-1 alive component 被 settle（elder rule 约束下的唯一因果信号）
- 级别阶梯 = alive_bars 按 persistence 降序（OnlineBarcode 天然属性）
- 降成本比例 = persistence_k / persistence_1（结构内蕴，零参数）

**边界条件**（翻转条件）：
- 若持仓期延长至 ≥50 bars → 降成本层可能显著（需 5min 或更高频数据验证）
- 若去掉空方向（只做多 + 降成本）→ 可能改善牛市表现（但失去双向对称性）
- 若在震荡市/熊市 → 空方向可能贡献正 alpha（本窗口无法验证）

**下游推论**：
- 多层赋格的价值不在方向择时，而在**持仓期间的成本优化**
- 有效域假说：5min/30min 级别（持仓期 >>100 bars）才有足够的降成本空间
- 方向裁决需要额外过滤：只在 rank-1 settle persistence > 结构性阈值时才翻方向，避免噪声翻转

**谱系引用**：
- §7.5：在线因果 merge tree → alive/settled 二分
- 521号：PH settle 用途边界（必要条件，非充分确认）
- Elder rule：merge tree 的数学属性（dominant = global elder，永不被 merge 杀死）
- 本回测 L2 结果与前序回测（candidate_settle_backtest_qqq）一致：日线级别择时 < buy-and-hold

**影响声明**：
- 本回测不修改任何已有模块，仅消费现有 API
- 发现 elder rule 约束——修正了"dominant settle"的设计假设
- 建议后续在 5min 数据上验证降成本层的有效域

**认识论等级**：L2（真实数据，4标的日线，2020-2026；产出三重否定性结果——比确认性结果更有价值）。
