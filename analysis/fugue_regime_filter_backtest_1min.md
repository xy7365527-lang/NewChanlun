### 分析

**Regime 几乎全程 NEUTRAL**：三标的 96-99% 的 bars 处于 NEUTRAL regime。
严格单调性要求（每对相邻中枢的 ZG/ZD 都必须单调）使得 UP/DOWN 判定极稀少。

**OKLO 负面影响**：regime filter 在 DOWN 阶段过滤了 37 个 buy candidate，
减少了 1 笔交易（可能是盈利交易），复利从 +72.25% 降至 +23.74%（-48.51pp）。

**QQQ/HK700 零影响**：过滤的候选数（2-21个）均未命中实际进场窗口。

**结论**：当前严格单调性判据过于保守，regime 覆盖率太低。
可能的改进方向：放宽为"最近 N 个中枢的趋势"或用中枢中心价均线代替严格单调。

## 结果包六要素

**结论**：在多级别 PH 分层 FSM 基础上增加 regime filter，利用最高有效级别中枢序列的 ZG/ZD 单调性约束操作方向。

**定义依据**：
- Regime 判断 = 最高有效级别（≥2 中枢的最高递归层）的中枢序列 ZG/ZD 单调性
- ZG 依次递增 = 上升趋势（中枢抬高）→ 只做多
- ZD 依次递降 = 下降趋势（中枢降低）→ 只做空
- 缠论原文：大级别走势类型方向约束操作方向

**边界条件**：
- 若最高级别始终 <2 中枢 → regime 始终 NEUTRAL → 退化为无 filter 版本
- 单调性检查严格（任一对不满足即 NEUTRAL）→ 震荡市大部分时间 NEUTRAL
- regime 判断滞后：中枢形成需要时间，趋势初期可能仍为 NEUTRAL

**下游推论**：
- 若 regime filter 减少亏损交易数 → 有效过滤了逆势交易
- 若胜率提升但交易数大幅减少 → filter 过于保守，需放宽条件
- 若无改善 → 中枢单调性不是有效的趋势判据，需其他方法
