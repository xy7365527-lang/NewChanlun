## 0. TL;DR（结论先行）

用户的假设**成立**：深亏不是"强单边 H¹ 失效"的市场命运，而是 **recover 的级别锚定错误**——

> recover 用 `nf_buy[k]`（核心仓本级别买点）触发，但空头物理上在 `k−1` 层（次级别）。
> 平一个次级别的空头，却去等本级别的买点。本级别（尤其 recL2/recL3）买点比次级别稀疏一个数量级
> ⟹ recover 死锁 ⟹ 空头僵尸化（持有 100 万~500 万 bar）⟹ 牛市价涨 100%~160% ⟹ 单笔巨亏。

**正确锚定（缠论次级别降成本，17/26 课）**：空头在 `k−1` 层，应用 **`nf_buy[k−1]`（次级别买点）** 回补——
即用户精确指出的 `nf_buy[k-1]`。

## 1. sink 触发时机（operate.rs:259-292, cycle.rs:26-56）

### 代码事实
```rust
// E. sink（Long root）
for k in PENDING_LO..MAX_LADDER {        // k 从 3=move(L1) 起
    let sub = k - 1;                      // 下沉目标 = 次级别
    let signal = obs.nf_sell(k);          // ← 触发 = 本级别 k 卖点
    if signal.is_none() { continue; }
    match h0.theta(sub) { ... sink_chunk(k) }  // ← 成本门用 θ(k−1) 次级别势幅度
}
// sink_chunk: reduce_at(k, m) 减 k 层 1/3 + add_at(k−1, flip(d_k)) 在次级别开反向 chunk
```

| 维度 | 级别 | 说明 |
|------|------|------|
| 触发信号 | `nf_sell[k]` = **本级别 k 卖点** | k 级别 type1 顶背驰向心 confirm（signal.rs:243-249，母线 [k..FIRST_BSP] 嵌套贯通） |
| 操作源层 | k | 核心仓所在层减 1/3 |
| 操作目标层 | k−1（次级别） | 开 flip(d_k) 空头 chunk |
| 成本门 | `θ(k−1)` = **次级别势幅度** | morphology.rs:112 |

**内部不一致已现**：触发用 k 级别（nf_sell[k]），成本门用 k−1 级别（θ(sub)）。
触发级别与操作级别错位一级——这是级别混淆的第一条内部证据。

### 缠论对照
sink = "本级别卖点 → 次级别做空"。开空时机（本级别卖点触发）**部分合理**：本级别顶背驰附近减仓符合
缠师"大级别卖点附近高抛"。但 sink 不触发只是核心仓继续顺势持有（无损害），故 sink 侧错配是
**机会成本**（少做差价），非实际亏损。

## 2. recover 触发时机（operate.rs:237-257, cycle.rs:63-98）——**核心错配**

### 代码事实
```rust
// D. recover（Long root）
for k in PENDING_LO..MAX_LADDER {
    let sub = k - 1;
    if self.layers[sub].units <= 0.0 { continue; }   // 空头在 sub=k−1 层
    let signal = obs.nf_buy(k);                        // ← 触发 = 本级别 k 买点
    if signal.is_some() && recover_chunk(k, ...) { }  // 从 k−1 升回 k
}
```

| 维度 | 级别 | 问题 |
|------|------|------|
| 空头物理位置 | **k−1（次级别）** | sink 把它放在这里 |
| 平仓触发信号 | `nf_buy[k]` = **本级别 k 买点** | ✗ 应为 `nf_buy[k−1]` |
| 操作 | k−1 空头 → k 多头 | 升回核心仓级别 |

**错配的本质**：sink 和 recover 不是"同一级别的对称操作"，而是**两个不同主体**的操作：
- sink = 核心仓（k 级别）减仓 → 看 k 级别信号（可论证）
- recover = 空头 chunk（**k−1 级别**）平仓 → **应看 k−1 级别信号**，但引擎看了 k 级别信号

空头 chunk 在 k−1 层，它押注的是"k−1 级别的一段下跌走势"。这段下跌结束 = **k−1 级别买点**。
引擎却要等 k 级别买点（k 级别走势的底），等于把次级别短差绑死在一个高一级的周期上。

### 用户假设 `nf_buy[k-1]` 验证
用户假设 recover 应触发于 `nf_buy[k-1]`。**完全正确**：空头在 k−1 层 ⟹ 用 k−1 级别买点 nf_buy[k−1] 平。
当前代码用 nf_buy[k]（高一级），是错配的直接位置。

## 4. 对比缠论原意

### 缠论次级别降成本（缠师 17 课 / 26 课 / 区间套）
> 持有本级别(k)核心仓时，用**次级别(k−1)的买卖点**做差价：
> 次级别卖点 → 减仓/做空；次级别买点 → 回补。**两个信号都是次级别 k−1 的。**

### 引擎实际
| 步骤 | 缠论应用级别 | 引擎实际级别 | 偏差 |
|------|------------|------------|------|
| sink 触发（减仓做空）| nf_sell[**k−1**] 次级别卖点 | nf_sell[**k**] 本级别卖点 | 高一级（机会成本）|
| recover 触发（回补）| nf_buy[**k−1**] 次级别买点 | nf_buy[**k**] 本级别买点 | **高一级（致命）** |

引擎的降成本操作**整体高了一级**——用核心仓本级别的买卖点做"次级别差价"。
其中 recover 侧致命：空头在 k−1 层却等 k 级别买点，强趋势中等不到 ⟹ 僵尸化。

时序对照（缠论 "本级别卖点→次级别做空→次级别买点→回补"）：
- "本级别卖点→次级别做空"：引擎 nf_sell[k] 触发 + 空头落 k−1 层 ✓（开空时机/落点对）
- "次级别买点→回补"：引擎用 nf_buy[k]（本级别）而非 nf_buy[k−1]（次级别）✗（**回补级别错**）

## 5. 信号层级别索引（unified_necessity.rs / spiral signal.rs）

fugue_v3 消费的是 **`crate::spiral::signal::GroupEventFrame`**（observe.rs:14），非 unified_necessity.rs
（后者是独立的 unn 引擎，逻辑同构：unn 1156-1227 ≈ spiral signal 205-258）。

`nf_sell[k]` / `nf_buy[k]` 定义（signal.rs:243-258）：
```rust
if w.since_bar < bar && helix_centripetal_confirm(&type1_hist, k, Side::Sell, w.since_bar) {
    nf_sell[k] = Some(w.extreme);   // k 级别 type1 卖点向心 confirm
}
```
- `nf_sell[k]` = **k 级别**顶背驰，区间套母线 [k, k−1, …, FIRST_BSP=2] 嵌套向心贯通后 confirm。
  归属 **k 级别**（标记 k 级别走势完成），层级越高需越深嵌套 + 越长 since<bar ⟹ 越稀疏。
- `nf_sell[3]`=move(L1) 卖点；`nf_sell[4]`=recL2 卖点；`nf_sell[5]`=recL3 卖点（个位数）。

ladder 命名（types.rs:40-45）：`2=segment, 3=move(L1), 4=recL2, 5=recL3, 6=recL4`。
`PENDING_LO=3`（move/L1 是 sink 源最低层，segment 非势源）。

**sink 用 `nf_sell[k]`，recover 用 `nf_buy[k]`——都是本级别 k 信号。** 用户问"sink 在 k，recover 应在 k−1"：
- sink 落点确实在 k−1（操作目标对），但 sink 触发用 k 级别信号
- recover 触发用 k 级别信号（应为 k−1）——这是错配位置

## 结果包六要素

### 1. 结论
fugue_v3 的 sink/recover 级别锚定**不精确对应缠论次级别买卖点**。recover 的触发信号 `nf_buy[k]`
是核心仓本级别买点，而被平的空头在次级别 k−1 层——应使用 `nf_buy[k−1]`。该错配在强趋势标的
（核心仓涌现至 recL2/recL3）致命：高级别买点稀疏一个数量级 ⟹ recover 死锁 ⟹ 空头僵尸（持有
100 万~500 万 bar）⟹ 牛市浮亏 100%~160% ⟹ 单笔巨亏，构成 ES/GC/QQQ/BRN 深亏的 86%~100%。

### 2. 定义依据
- 缠论 17/26 课"次级别买卖点降成本"：持本级别核心仓，用**次级别**买卖点做差价（两端同为次级别）。
- `nf_sell[k]`/`nf_buy[k]` 定义（signal.rs:243-258）：第 k 级别 type1 BSP 向心 confirm，归属 k 级别。
- 空头物理位置（cycle.rs:40,51）：sink 把 chunk add_at 到 `sub=k−1`，故空头属 k−1 级别走势。

### 3. 边界条件（结论翻转条件）
- 若把 recover 改为 `nf_buy[k−1]` 后 L3 回测仍深亏 ⟹ 本诊断的"机制充分性"被否证（降级为"必要不充分"）。
- **诚实标注**：即使级别修正，空头腿在上行 regime 仍逆势（OKLO recover 健康但空头腿仍 −160K）。
  级别修正消除的是**灾难性僵尸单笔**，**不**保证空头变正 alpha。修正后可能引入新问题：nf_buy[k−1]
  更频繁 ⟹ 过早回补 ⟹ 踏空次级别下跌延续。本报告是 L0 概念诊断 + L3 现状证据，**修正效果需 L3 验证**。
- sink 侧 `nf_sell[k]` 是否也应降为 `nf_sell[k−1]` 是开放问题（sink 错配是机会成本非实际亏损，
  不属本诊断的致命链）。

### 4. 下游推论
- 若结论成立：深亏标的的"P1 不达 BH"被重新归因——从"强单边市场 H¹ 失效（不可改命运）"转为
  "recover 级别错配（可改代码）"。这与 `project_constitutive_throughput_falsified` 的"清仓频率
  regime 函数不可约"形成张力：本诊断主张僵尸亏损的 regime 依赖**有可约部分**（级别锚定）。
- 强平线 2×basis 对高级别空头无效（need 价涨 100%+ 才触发）⟹ 空头止损机制独立缺失，需单列。
