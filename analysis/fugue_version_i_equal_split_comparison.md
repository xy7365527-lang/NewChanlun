## 3. 否定性结论（L2，信息增量为正）

### 3.1 均分**没有改善**，部分**恶化**

同基底（共享版同一文件上下轮）对比：

| floor | 非均分 | 均分 | 差 | 解读 |
|-------|--------|------|----|------|
| bar0 | −99.88 | −100.00 | ≈0 | 都爆仓，无差 |
| seg2 | +283 | **+224.27** | **−59** | 均分把 segment 单笔 0.25→1.0，**放大了负 alpha** |
| move3 | +290 | +290.28 | ≈0 | floor=3 时 `active_levels` 为空、降成本笔=0 → 均分无作用面 |

**机理**：降成本短差本身是净负 alpha 源（见 3.2）。均分在 `N_sub` 小时把单笔规模从 0.25
**放大**到 0.5~1.0，于是放大了一个本就为负的量 → I_seg2 反而更差。均分修正的是
*操作规模分配的概念严格性*（归一化、消除魔数），不是 alpha——经验上无正贡献。

### 3.2 爆仓根因 ≠ 操作规模（与单笔大小无关）

I_bar0 爆仓 −100% 的机制（FSM 贡献度实测）：

| 级别 | 短差次数 | 累计 profit |
|------|---------|-------------|
| bar | 22,814 | **−1,048,873**（亏 10× 本金） |
| bi | 2,230 | −13,110 |
| segment | 547 | −6,858 |

- 降成本阶段是**虚拟价差收集层**（股数守恒、不减 `total_shares`），其盈亏独立叠加于满仓
  敞口且**无下限**；
- bar 级 PH settle 在波动中高抛低吸经常做反 → 单笔小亏 × 2.3 万次 → 累计击穿本金；
- 这是**信号层 + 守恒律建模**的问题，仓位规模层（均分/固定/slice）改不了。
  slice 版 I_bar0 之所以 +279 而非爆仓，是因为 slice 限额（~10% 机动仓）**掩盖**了这个
  负 alpha，不是消除它——共享满仓诚实暴露了它。

### 3.3 缠师原文经验印证

- 第53/35/31课主张降成本最小级别 ≥5分钟（≈线段/走势级），反对 bar 级短差。
- 实测 `I_bar0`(−100) ≪ `I_seg2`(+224) < `I_move3`(+290)：**floor 越高越好，bar 级毁灭性**。
  → 数据经验印证缠师"太小级别短差无意义/有害"。

### 3.4 降成本全面拖累 alpha（强趋势标的）

E(+1006) ≫ BH(+307) > I_move3(+290) > I_seg2(+224) ≫ I_bar0(−100)。

- I_move3 降成本笔=0（纯满仓 + segment/move type1 出场），仍略 < BH：**频繁 type1 出场
  在强趋势中踏空**（220 笔 vs E 的 6 笔大波段）。
- 出场级别越高、交易越稀疏越好（承 project_best_combo_version_i / 版本I动态级别归属）。
- OKLO 是史上最强单边之一 → "满仓持有到顶背驰"（E）压倒一切降成本变体。

## 4. 结果包六要素

1. **结论**：均分操作规模在概念上更严格（归一化、消除魔数），但经验上对 alpha **无正贡献**，
   且在 segment floor 上**恶化**收益（+283→+224）。降成本短差全面拖累 alpha；bar 级爆仓；
   E 满仓大波段压倒一切。三版本同基底确认。

2. **定义依据**：缠论降成本（第31/35课多重赋格、第27课次级别短差）；缠师反对过小级别短差
   （第53/35/31课）；type1 买卖点（第33课底背驰介入）。均分 = 第40课"每一重对应一定资金"
   的归一化形式化（Σ=100%）。

3. **边界条件（结论翻转条件）**：
   - 若标的为**震荡/弱趋势**（非 OKLO 强单边），降成本短差可能转正 → I 变体可能 > E；
   - 若降成本改为**真实减仓-回补**（动 total_shares）而非虚拟价差层，无下限失血消失 →
     bar 级可能不爆仓（但这是守恒律建模变更，超本次范围）；
   - 若 segment 短差信号源从 PH settle 换为 MACD 背驰（非 O(N²) 力度口径），seg 层负 alpha 可能改变。

4. **下游推论**：M1 回测的 Version I 主线应以 **E（满仓 + 最高级别出场，零降成本）** 为基准；
   降成本作为可配置层（floor≥segment）仅在震荡标的有效域内启用；bar/bi 级降成本应默认关闭
   （floor≥2），均分 vs 固定单笔规模在该有效域内不是决定性变量。

5. **谱系引用**：本结论处于「降成本有效域」反复结算的谱系链上——
   project_shared_position_fugue（slice→共享，共享劣于 slice）、
   project_costreduction_moneyprinter_bug（降成本 alpha 污染）、
   project_complete_fugue_v2（降成本负 alpha）、project_best_combo_version_i（出场级别主因）。
   本轮新增：**均分操作规模 = 概念严格化但非 alpha 改善**；爆仓根因落定在信号层+守恒律建模、
   非仓位规模层（缩小了"操作规模能否救爆仓"的有效域至空）。

6. **影响声明**：仅改 `analysis/fugue_version_i.py`——删 `_level_trade_fraction`、
   `_SharedFugue` 加 `level_frac` 字段、`_open` 算均分、open_diff 调用改用 `pos.level_frac`、
   同步修正文档注释（移除"均分杜绝爆仓"的错误声明 → 诚实声明"均分不防爆仓"）。
   未动：信号层、出场逻辑、守恒律、`_SharedFugue` 守恒分支、下游 Rust 回测消费的 JSON 键
   （`slice_net_gain` 保留）。`fugue_version_i_slice.py` 未动（slice 对比基准保留）。
