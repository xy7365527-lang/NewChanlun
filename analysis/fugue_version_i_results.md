# 版本 I — 全仓 + 中枢门 + 级别归属动态出场 + 多重赋格降成本

> 基线 E（`run_swing_trading`）。I 设计：全仓进场 + 中枢门(zs≥1) + confirmed 底背驰 + 区间套 + 级别归属；持仓多重赋格降成本(persistence 过滤次级别背驰短差→挣股数)；出场=归属级别卖点全仓清出。脚本 `analysis/fugue_version_i.py`。认识论 **L2**。

> 521号口径：每层第一类买卖点 = move settle + 背驰（走势级 MACD，高层 persistence）。高层力度为 PH 纯拓扑代理（521号边界）。降成本在强趋势为负 alpha（拖累 I<E，实测）。
