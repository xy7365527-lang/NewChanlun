# 期货 Version I（slice / I_none）交易行为诊断报告

> 标的：ES / CL / GC（三大标的，各 5.5M bar 全历史 1min）。变体：`I_none`（无止损，主口径）。
> 引擎：全 Rust O(N) `compute_i_signals_rust` → slice 版 `run_version_i`（git HEAD bit-exact）。
> 认识论 **L2**（真实数据，含否定性结果）。生成：2026-06-09。
> 数据：`_i_diag_summary.json` + 全量逐笔磁带 `_i_diag_tape_{ES,CL,GC}.json`。

## 0. 分解口径（关键方法）

全仓核心 = `INITIAL_CAPITAL / entry_price` 股；清仓总市值 = 核心市值 + 各降成本声部 slice 净增益。
故每笔可严格分解为两部分（`run_version_i._close` 的恒等式）：

```
dir_pct   = (exit_price / entry_price − 1) × 100     # 方向核心贡献（全仓骑乘）
slice_pct = pnl_pct − dir_pct                         # 多重赋格降成本机动仓净贡献
```

**自洽校验**：各声部 slice 现金净增益之和 = `slice_pct` 总和 × INITIAL_CAPITAL，逐标的精确吻合
（ES: bar−8244 + bi+4378 + seg+2329 = −1537 现金 = −1.54%；CL = −2.27%；GC = +3.44%）。
分解可信，下游可质询。

## 1. 三标的总览

| 标的 | BH% | I_none% | 笔数 | 胜率 | Σdir(简单加总) | Σslice(降成本净) | 拖累笔 |
|------|-----|---------|------|------|---------------|-----------------|--------|
| ES | +594.3 | +178.7 | 2464 | 62.46% | **+119.58** | **−1.54** | 2 |
| CL | +28.2 | +11.1 | 2680 | 59.33% | **+120.28** | **−2.27** | 3 |
| GC | +257.3 | +121.4 | 2791 | 59.08% | **+91.84** | **+3.44** | 5 |

**第一诊断**：`Σdir ≈ Σpnl`，`Σslice ≈ 0`。降成本机动仓在三标的上**净贡献近零**（ES/CL 微负、
GC 微正）——I 跑输 E 的全部差距来自**方向信号被切碎**（2464–2791 笔 churn 各骑一小段，
vs E 13–36 笔骑整段大趋势），**不是**降成本拖累。降成本既没救场，也没毁掉总收益，它基本是
一个零和的高频空转层。

## 2. 亏损原因分类

四类（每笔按 `dir_pct` / `slice_pct` 符号归类）：

| 类别 | 含义 | ES | CL | GC |
|------|------|----|----|----|
| `win` | pnl>0 | 1539 | 1590 | 1649 |
| `loss_both_neg` | 方向亏 **且** 降成本也亏 | **913** | **1068** | **1126** |
| `loss_dir_slice_cushion` | 方向亏，降成本部分缓冲但不足 | 10 | 19 | 11 |
| `loss_slice_dragged` | 核心方向**盈利**，被降成本短差拖入亏损 | **2** | **3** | **5** |

**第二诊断**：亏损 98% 是 `loss_both_neg`——**方向性亏损主导**。入场是中枢承载层 confirmed
type1 买点（底背驰，假设均值回归），但在强下跌趋势中底背驰反复在更低位重新形成，价格继续
下行，持仓被套到 entry 层 type1 卖点（顶背驰）才在**更低位**清出。

**`loss_slice_dragged` 仅 2/3/5 笔（占亏损 0.2–0.4%）**——这条**否证了"降成本提款机把赢家
变输家"的最坏担忧**（[[project_costreduction_moneyprinter_bug]]）在 slice 模型 + per-trade
层面**不成立**：降成本几乎从不把一笔盈利的方向交易拖成亏损。降成本的伤害是分散的微量
churn，不是灾难性翻转。

## 3. 降成本逐笔分解（多重赋格各声部贡献）★ 核心发现

按 ladder 声部拆 slice 净增益（现金，INITIAL_CAPITAL=100000）+ 短差笔数：

| 声部 | ES 净增益 / 短差笔 | CL 净增益 / 短差笔 | GC 净增益 / 短差笔 |
|------|------|------|------|
| **bar (ladder0)** | **−8244 / 240580** | **−9489 / 255687** | **−2428 / 254833** |
| bi (ladder1) | +4378 / 18942 | +4658 / 23310 | +3240 / 25029 |
| segment (ladder2) | +2329 / 5103 | +2560 / 6174 | +2625 / 6115 |
| **声部净和** | **−1537** | **−2271** | **+3437** |

**第三诊断（数据经验裁决 bar 级 = 噪音，印证缠师原文）**：
- **bar 级声部是唯一的净摧毁者**：三标的 slice_net_gain 全负，且产生**绝对主导**的短差量
  （~24–26 万笔 ≈ 总短差的 89–91%）——海量空转，负净值。
- **bi / segment 声部全部净正**（segment 最稳健，三标的 +2329/+2560/+2625）。
- 全局净值 ≈ 零，正是因为 **bar 级的破坏 ≈ bi+segment 的增益**，相互抵消。

`fugue_version_i_slice.py` docstring 预设的经验判据——"若 bar 级贡献为负 → 经验印证缠师
第53/35/31课'最小不应小于5分钟''太小级别没有意义'"——**被本数据证实**。缠师反对 bar 级
短差是对的：bar 级降成本是负 alpha 的噪音泵。**可执行推论**：设 `BT_FLOOR_LADDER=1`（去
bar）即可消除该负值，I_none 预期改善 ≈ +8244/−9489/−2428 现金（ES/CL ≈ +1.5–2.3% 起步，
GC 反降 2.4% 因其 bar 损失最小而抵消增益最多）。

## 5. ladder 归属与持有时间不对称

| 标的 | segment 入场（笔 / 均持 bar） | move(L1) 入场（笔 / 均持 bar） |
|------|------|------|
| ES | 2156 / 784 | 308 / 5199 |
| CL | 2322 / 763 | 358 / 5184 |
| GC | 2430 / 721 | 361 / 5332 |

**第五诊断**：入场 ~87% 来自 segment 级（短持、高频），但 **move(L1) 入场持仓 ~7× 长**
（~5200 vs ~760 bar），且**最大亏损几乎全部来自 move(L1) 出场**（CL −44%/−32%/−28% 全是
move type1sell，套 1.5–4.2 万 bar）。move 级深度套牢是尾部风险的集中来源：高层 type1 底背驰
一旦在强趋势中失效，持仓被锁数万 bar 直到顶背驰确认。segment 级是高频 churn 源，move 级是
深度回撤源——两种 floor 各自的病理不同。

## 结果包六要素

**1. 结论**：Version I（slice / I_none）在 ES/CL/GC 的交易行为诊断给出三条可证伪结论：
- **降成本机动仓净贡献近零**（Σslice：ES −1.54 / CL −2.27 / GC +3.44），I 跑输 E 的全部差距
  来自方向信号被切成 2400–2800 笔 churn，而非降成本拖累。
- **bar 级声部是唯一净摧毁者**（slice_net_gain −8244/−9489/−2428，占短差量 89–91%），bi/segment
  声部全部净正——经验裁决 bar 级降成本 = 噪音泵，**印证缠师"太小级别没有意义"**。
- **亏损 98% 是方向性 `loss_both_neg`**；"降成本把赢家变输家"仅 2–5 笔（否证最坏担忧）。盈亏
  幅度不对称（最大盈利 +5.4% vs 最大亏损 −44%）是 I < BH 的机制。

**2. 定义依据**：
- 入场 = 中枢承载层（segment 笔中枢 525号 / move L1 线段中枢）confirmed type1 买点（底背驰，
  `缠论知识库.md` 买卖点定义 + 第33课"向下离开中枢底背驰介入"）。
- 出场 = entry 层 confirmed type1 卖点（顶背驰）。
- 降成本声部 = 第40课多重赋格（"每一重对应一定资金与筹码"），各 ladder 独立 FSM 追踪 cost_basis。
- bar 级冲突 = 第53/35/31课（降成本最小级别 ≥5分钟，反对 bar 级）vs 指令#3（纳入 bar）——
  本诊断的 fsm_contribution 即 docstring 预设的"让数据经验裁决"判据。

**3. 边界条件**（结论翻转条件）：
- 若设 `BT_FLOOR_LADDER=1`（去 bar 声部），bar 级负值消除，Σslice 转正（ES/CL）——降成本"净零"
  结论是 **floor=0（含 bar）特有**，非降成本机制本身的性质。
- 若数据切换为强震荡 regime（无持续单边趋势），方向性 `loss_both_neg` 占比下降、底背驰均值回归
  假设成立率上升，I 可能反超 E（[[project_backtest_benchmark_falsifiability]]）。
- 若力度口径换 MACD（当前价格振幅 fallback，因 O(N²) 不可行），type1 背驰判据收紧 → 假信号
  减少，方向性亏损可能下降（有效域边界，521号）。

**4. 下游推论**：
- M1 期货支柱：I 的降成本短差层应**砍掉 bar 级**（floor≥1），保留 bi/segment——这是数据支持的
  唯一改进方向，不是全盘否定降成本。
- 与 [[project_shared_position_fugue]]（OKLO bar churn 毁 alpha）、[[project_version_i_complete_rewrite]]
  （segment 最优 floor）跨标的一致——bar 级有害是鲁棒结论（OKLO + ES + CL + GC）。
- IBKR 执行：move(L1) 入场的深度套牢（套数万 bar）是尾部风险源，需级别感知止损（但 I_stopA 在
  CL 反而 +161%、在 BRN/DX 爆仓，止损 regime-dependent，见 `p3_futures_final.md`）。

**5. 谱系引用**：
- [[project_costreduction_moneyprinter_bug]]（降成本提款机 bug）——本诊断 per-trade 层**否证**其
  最坏形态（dragged 仅 2–5 笔），但确认 bar 级净负（弱形态成立）。
- [[project_shared_position_fugue]] / [[project_version_i_complete_rewrite]]（bar churn 毁 alpha、
  segment 最优 floor）——本诊断以 fsm_contribution 提供 ES/CL/GC 的微观证据。
- [[project_complete_fugue_v2]]（中枢门空有效域、多重赋格）；521号（纯拓扑无动量，力度口径边界）。
