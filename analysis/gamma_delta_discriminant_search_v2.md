## 核心解读

**目标**：v1 停在 2.074 bits；问成交量能否进一步压低剩余熵（→0 则 k4_path_c 六边各自跑可被推翻）。

**实测裁决：成交量降低剩余熵 = **边缘弱正**（L2，落在 floor-SE 噪声带，非稳健——见精度边界）；补到 0 = **否**（结构性结论不变）。**

1. **成交量单变量最大真实增益 = +0.026 bits**（>0.005 阈值，成交量携带 Γ,ω 之外的交叉边信息）。

2. **贪心终态 H(X|Γ,选中)=1.387 bits**（选中 ['ω', 'volDX', '6E']）；其中成交量入选：['volDX']。补到 0 = 否——变量再扩充（含成交量）仍到不了 0。

3. **机制**：交叉边 σ 自身在 1min 上熵大（v1 已证 σ 翻转 638–984 次）；成交量是**力度的量维**（缠论「力度=价格振幅+成交量」），但日级成交量 regime 与交叉边方向的**同日**互信息有限但非零——Γ→交叉边的一对多（294号 D 算子非线性、527号 σ 不保比值同态）是**结构性**不可约，非缺成交量这一观测维度所致。

**下游影响**：成交量可作 k4_path_c 交叉边读数的弱辅助维度（限本有效域），但不足以替代直接读交叉边。


## ⚠️ 精度边界与跨版本可比性（强制，承 v1 531号裂隙3/4）

1. **终态 1.387 ≠ 可与 v1 的 2.074 直接比较**：v2 贪心公共样本 N=1805（成交量 tercile 60 日 warmup + 多候选联合非缺口），v1 为 N≈1856；起点 H(X|Γ) 亦不同（v2=2.756 vs v1≈2.763）。1.387<2.074 中，volDX 的步进增益是同一 v2 样本内的真实增益，但「v2 比 v1 压得更低」这一**跨版本绝对值比较不成立**——样本、候选集、cell 数（588 vs v1 的 234）全异。**可比的是步进真实增益（shuffle 扣减后），不是终态绝对值。**

2. **成交量增益落在 floor-SE 噪声带**：最大成交量真实增益 +0.026，量级与 v1 已判定为可忽略的 slope(+0.016)/VIX(+0.008) 同档。贪心内 shuffle n=20 的 floor 标准误差 ~0.004–0.009（531号裂隙3）→ 成交量增益约 2–6×SE（边缘至弱显著），**非稳健确认**。升级需 n≥200 shuffle + 置信带停机。

3. **过拟合在阈值边缘**：终态 588 cell / 样本均 3.07（v1 为 234 cell / 7.93）。加入成交量候选（3 态）使 cell 膨胀、样本/cell 逼近临界 3.0。shuffle floor 控每步伪增益，但**不控 cell 稀疏对终态绝对 H 的累积低估**——终态 1.387 的绝对值比 v1 的 2.074 更不可信。

4. **volDX = numeraire 自身成交量**：DX 是计价物，交叉边 ES/GC、ES/CL 不含 DX。DX（美元）成交量 regime 对不含美元的交叉边有边缘信息，机制上是「美元流动性 regime ↔ 跨资产 risk-on/off」的**间接**通道，非直接构成。

**净结论**：成交量**未推翻** v1 的结构性否定（补到 0=否，Γ→交叉边一对多不可约）。它至多贡献边缘弱正信号（volDX/volES_chg），落在噪声带，且不改「不能从 Γ+regime+成交量恢复交叉边」的下游结论。


## 结果包（六要素）

**1. 结论**：
(a) 基线 H(X)=3.165，H(X|Γ)=2.762，H(X|Γ,ω)=2.517（ω 增益 0.245）。
(b) **成交量单变量最大真实增益 +0.026 bits**（>0.005 阈值）。
(c) 全候选（v1 + 成交量）贪心选中 **['ω', 'volDX', '6E']**，终态 H(X|Γ,选中)=**1.387 bits**（**未到 0**）；成交量入选 ['volDX']。
(d) **剩余熵补到 0 = 否**。


**2. 定义依据**：Γ=(σ(ES/$),σ(GC/$),σ(CL/$)) 折叠通道期货实例 {ES,GC,CL,$=DX}（528号）；σ=L1 走势方向（`current_moves()[-1]`，O(N) day-batch 引擎，与 v1 bit-exact）；X=(σ(ES/GC),σ(ES/CL))，GC/CL 剔除（=ω 防循环）；成交量候选=各标的**清洗后网格日成交量求和**的trailing-60d tercile（3 态，因果）/ ES 日量 log 变化方向（deadband 0.05）/ {ES,GC,CL} 高量 breadth（4 态）。

**3. 边界条件**：
- σ 与 v1 bit-exact（同 day-batch 引擎、同清洗）→ Γ/X/ω 数值与 v1 一致；新增量仅成交量候选；
- a0=1min，M=DX 期货；窗口 2018-12-26+；7 标的交集 1,878,657 bar；
- 成交量 regime 用 **trailing 窗口**（因果，无前视）→ 前 60 日为 None，减少 ~60 个样本；
- 日成交量为**连续合约**口径（.c.0/databento），换月跳跃可能引入量级阶跃 → tercile 用相对窗口已部分吸收；
- 多变量条件熵含有限样本伪增益（已 shuffle 扣减，真实残余 ≥ 报告值；Miller-Madow 偏差使报告残余是**下界**）；
- 自相关：日采样相邻日 σ/成交量高度自相关，样本/cell 是**名义上界**，Neff 校正后更低（承自 v1 裂隙4）；
- **结论翻转条件**：若成交量改用 RTH-session 口径 / 换月对齐 / 更细 regime 分箱后真实增益 >0.005，则成交量辅助维度成立——当前否定限于「连续合约日成交量 tercile/变化方向/breadth」这一离散化族。

**4. 下游推论**：
- 成交量真实增益 +0.026>0.005：可作交叉边读数弱辅助维度（限本有效域），但 H 未到 0 → 仍不能替代直接读交叉边。

**5. 谱系引用**：527（σ 走势方向态）、k4_path_c（六边各自跑）、482（ω 部分分辨）、294（D 算子非线性，Γ→交叉边一对多根因）、528（折叠通道顶点）、beichi（力度=振幅+成交量，成交量候选的领域依据）、project_recursive_orchestrator_rust、project_bi_zhongshu_on2_two_walls；承 v1（`gamma_delta_1min_discriminant_search.md`）；不确定是否有「成交量分辨」专门谱系——若结论稳定建议新建。
