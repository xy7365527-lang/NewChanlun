## P1：流量度规不在宏观数据里，在缠论走势结构的方向导数里

### 被组合的两条链

**链 A — 残差=曲率但缺度规**（`project_residual_to_flow_no_bridge` + 209号 gauge-invariant-hierarchy）：
- 否定：规范场论框架下"残差 = 曲率 F"是**严格的**（L0），但 `d⋆F = J`（曲率→流量）缺**金融度规**——没有独立的可观测量充当 Hodge star ⋆。CIP 偏离污染 33.8% 残差。
- 保留：残差=曲率严格成立；流量 J 必须有独立源（COT / 守恒律 / 缠论走势结构三候选）。

**链 B — 流量源的三候选被逐一否证，只剩缠论**（`project_cot_not_leading_flow` + `project_residual_flow_velocity_l2`）：
- 否定：COT 净持仓不领先残差/价格（7/7 配对全否定；6E/ES 反向 Granger p=0.0000）；守恒律 net 在 222号被证为离散拓扑恒等式（永真，无方向信息）；残差**流速**（级别涌现）空信号（2020 饱和 L3）。
- 保留：残差**流量**（振幅）信号在**内生反转点**有效（2022-09 美元顶 L1 振幅 −29% 力度衰竭）；缠论残差走势结构是唯一通过 L2 的流量代理。

### 否定的精确边界
"流量可独立观测"在**宏观数据域**（COT/守恒律）有效域为空；在**缠论走势结构域**有效域 = 内生反转点（< 全 regime）。

### 保留部分的组合 → 新命题

**P1：`d⋆F = J` 中的 Hodge star ⋆ 不是缺失的，⋆ = 离散化算子 D（233号）。** 流量 J 不是独立可观测量，而是残差曲率 F 经 D 算子的方向投影：

- 残差曲率 F ∈ ker(D)（纯幅度，233号 D 系统性滤除幅度）
- 流量 J ∈ image(D)（方向，D 保留并放大方向，235号三态之"放大"）
- ⋆ = D：把幅度（ker）映射为方向（image）的算子，正是缠论的笔→线段→中枢递归

因此"金融度规"从来不在 COT/守恒律里——它**就是缠论走势结构本身**。流量信号 = 残差走势的力度衰竭（背驰），且仅在 image(D) 放大的内生反转点可见。

### 推导链
209（残差=曲率/规范场）+ 233（ker D = 纯幅度，联络 ω = D 余像）+ 235（D 三态：吸收/保留/放大）+ `project_residual_to_flow_no_bridge`（缺度规）+ `project_cot_not_leading_flow`（COT 否证）+ `project_residual_flow_velocity_l2`（流量仅内生反转点）

### 认识论等级
- L0：⋆ = D 的代数对应（从 233号 ker/image 结构推导）
- L2 已确认：COT 否证、流速空信号、流量仅反转点有效
- **L3 待验证**：⋆ = D 的经验等价（"残差经 D 的方向 = 独立流量方向"）

### 可验证方案
在残差序列上应用 D 算子（跑 BiEngine→segment→zhongshu→move），取 image(D) 的方向（239号方向性力度 ∉ ker(D)）。检验：内生反转点处的方向性力度放大，是否与价格反转方向一致。
- **翻转条件**：若方向性力度在反转点无信号（落入 ker(D) 被吸收），则 ⋆ = D 否证，"度规=缠论结构"假说失败。
- 数据：现有残差缓存（`residual_chanlun_flow_velocity.py --analyze-only`）+ 239号方向性力度模块，可立即跑。

### 下游推论
若 P1 成立：(1) 放弃一切寻找"独立流量源"的努力（COT/COT 替代口径/守恒律均无效）；(2) 流量分析降维为缠论背驰检测在残差上的应用；(3) 强化 `project_residual_to_flow_no_bridge` 的"禁 Hodge star 声明"——⋆ 不需要外部声明，它就是引擎。

### 谱系引用
209/222/233/235（曲率-ker(D) 链）；`project_residual_to_flow_no_bridge`、`project_cot_not_leading_flow`、`project_residual_flow_velocity_l2`。涉及残差/曲率领域，曾发生概念分离（222号守恒律范畴错误）。

### 影响声明
统一了残差流量链与 K4 ker(D) 链——两条原本独立的链通过 ⋆ = D 接合。

## P3：回测 alpha 来源是暴露守恒，不是门控确认（判决实验已就绪）

### 被组合的两条链

**链 A — 门控全面毁 alpha**（`project_divergence_gate_entry_exit_falsified` + `project_m2_k4_selection_gate` + `project_backtest_benchmark_falsifiability`）：

- 关键洞察（benchmark_falsifiability）：在超长上行数据上"逊于 buy-hold"不可证伪、信息增量为零；少动门控与"趋近 buy-hold"同义反复共线——**需随机门控对照才能证伪**。

**链 B — 定位器作主轴 + segment 是最优 floor**（`project_divergence_locator_entry_exit` + `project_version_i_complete_rewrite`）：
- 保留：买卖点定位器作**主轴**（非附加过滤器）E > A > D；segment 级是最优 floor（bar 级 churn 17424 次毁 −11973；OKLO E+1006 ≫ I_seg+352 > I_move+318 > I_bar+279）；出场级别 L2 vs L1 是强趋势主因（`project_best_combo_version_i`）。
- 220（缠师正典）：降成本=把成本降为 0 甚至负数，风控是买卖点内在属性。

### 否定的精确边界
门控的有效域 = "reduce false entry"。但在**强趋势标的**上，false entry 的成本 < 错过暴露的成本，故门控有效域为空甚至负。门控在**震荡市/高假信号标的**可能有效（未否证）。

### 保留部分的组合 → 新命题

**P3：回测 alpha 来源是暴露守恒（持续在场），不是门控确认信号。** alpha 只能来自两条路径：
1. **定位器作主轴改变出场级别**（L2 vs L1，version_i）——不是过滤入场，是延长持仓守恒暴露；
2. **降成本**（挣股数，220 正典）——在守恒暴露内降低成本基。

任何"确认后才入场"的门控必然减暴露 → 在趋势市跑输 buy-hold。**门控类策略的有效域 = 震荡市/高假信号标的；趋势市有效域为空（甚至负）。**

### 推导链
divergence_gate_falsified（D<A<BH）+ m2_k4_selection_gate（门控毁 alpha）+ backtest_benchmark_falsifiability（门控≈buy-hold 同义反复，需随机对照）+ divergence_locator_entry_exit（定位器主轴 E>A>D）+ version_i_complete（segment floor / 出场级别是强趋势主因）+ 220（降成本正典）

### 认识论等级
- L2 已确认：多标的门控否证
- **L2→L3 待判决**："alpha = 暴露守恒"需随机门控对照实验证伪

### 可验证方案（判决实验，现有引擎可立即跑）
对同一标的（OKLO + QQQ）跑三组：
- (a) 真实门控（MACD 背驰 / K4 选股）
- (b) **随机门控**（同入场频率，随机选时点）
- (c) 无门控 buy-hold

判决：
- 若 (a) ≈ (b) ≈ (c)：**P3 成立**——门控无信息增量，只是减暴露的同义反复（benchmark_falsifiability 预言兑现）。
- 若 (a) > (b)：门控有真实 alpha，P3 否证。
- 若 (a) < (b) < (c)：门控负 alpha（主动伤害），P3 强化。

这是 benchmark_falsifiability 记忆明确要求的"随机门控对照"，**一个实验同时证伪/确认整条门控链**。

### 下游推论
若 P3 成立：(1) M2 K4 选股门控应从"入场门控"改为"震荡市标的筛选器"（限定有效域）；(2) 所有 fugue 版本的 alpha 归因重写——alpha 列在出场级别+降成本，门控列贡献置零；(3) 强化 pending-004（engine.py 删策略评价属性）——回测不产策略排名，因为 alpha 来源是结构性暴露非择优。

### 谱系引用

2.074 bits 的"分辨率不变"被否（降为"细化放大"）；转换矩阵的"配置粘滞"被自身缺陷削弱（48% 异级别 + 自相关 Neff）。两条链各自的强结论都被收窄到方向性 L2。

### 保留部分的组合 → 新命题

**P4：K4 配置空间存在内禀信息下界（intrinsic floor）——Γ→交叉边映射的不可约残余熵（531，2.074 bits）与转换矩阵平稳分布的条件熵是同一对象的两个测度。** 

经验观察：平稳分布的边际熵 H(π) ≈ 3.35 bits（24 态实测，max log₂27=4.755），残余条件熵 = 2.074 bits（1min）。若在**固定级别**下两者 co-vary，则配置空间有内禀度规——存在无论分辨率多细都无法分辨的配置对（230 的"有效自由度<3"是其代数对应：3 个 σ 维度中有 >1 维不可独立分辨）。

**关键诚实标注**：两条链共享**同一混杂源**——48% 异级别（k4_config 缺陷）+ 自相关 Neff（531 裂隙4）。所以"内禀度规"假说的判决**必须先消除这两个混杂**，否则 2.074 与 3.35 的关系可能是混杂伪影而非内禀结构。

### 推导链
531（2.074 不可约，294/527 Γ→交叉边）+ `k4_config_transition`（平稳分布/驻留/切换）+ 230（K4 有效自由度<3）+ 232（纤维丛非平坦联络）+ 233（ker D 内在选择性）+ 527（σ 走势方向态）

### 认识论等级
- L2：531 残余熵（方向性）、transition matrix 驻留分布
- **L3 假说**：内禀度规（残余熵 ≡ 平稳条件熵）

### 可验证方案（一个实验关闭两个 pending）
**固定全六边为 L3**（消除 48% 异级别混杂），重算：
1. Γ 残余熵（531 的贪心 floor）
2. 平稳分布的条件熵 H(σ | 前一日 Γ)

判决：
- 若两者都收敛到 ≈2 bits 且 co-vary → **内禀度规支持**（配置空间有固定信息下界）。
- 若残余熵不变（仍 ~2.074）而平稳熵随固定级别显著变 → 二者独立，**内禀度规否证**（2.074 只是 Γ→交叉边映射的局部性质，与转移动力学无关）。
- 同时用 block-bootstrap（block = 自相关长度）估 Neff，校正自相关（531 裂隙4 升级条件）。

**这一个实验同时**：(a) 回答 531 的 derived_followup（裂隙2/4 干净隔离），(b) 验证 k4_config 的 48% 缺陷可证伪命题（"固定全 L3 重跑，若驻留分布显著变则异级别混合是主因"），(c) 判决 P4 内禀度规。

### 下游推论
若 P4 成立：(1) K4 配置预测的信息上限被钉死（2 bits ≈ 4 个可分辨宏观状态），任何声称"预测 27 态"的模型都越界（有效自由度<3）；(2) 强化 230/232 的纤维丛退化；(3) k4_path_c"六边各自跑"获信息论奠基（不可约性是内禀的，不是分辨率不足）。

## P5（跨链涌现）：⋆ = D 统一残差度规与 ker(D) 选择性

### 推导
P1 提出 ⋆ = D（Hodge star = 离散化算子）。233号独立地说"联络 ω = D 的余像结构"，235号说"C-R 避险通道是缠论递归构造产物而非原始数据反映"。两者指向同一结构：

**P5：金融规范场的 Hodge 对偶算子 ⋆ 不是几何度规给定的，而是缠论离散化算子 D 内禀定义的。** 残差曲率 F ∈ ker(D)（幅度），其 Hodge 对偶 ⋆F = J ∈ image(D)（方向），对偶操作 = 笔→线段→中枢递归。这解释了为什么"金融度规"在宏观数据里找不到（P1）——度规不是数据的属性，是**观测算子（缠论引擎）的属性**。这与 526号"a0 确认层 vs 递归层"同构：度规在递归层（an = f(an-1)）生成，不在 a0 确认层。

### 认识论等级
L0（代数对应：⋆ ↔ D，从 233/235 ker/image 结构推导）+ L3（经验：⋆F 的方向 = 独立流量方向，与 P1 共享验证）

### 可验证方案
检验 D 算子是否满足 Hodge star 的对合性质：D∘D 在残差上应近似 ±identity（⋆⋆ = ±1）。即"对残差跑两次缠论递归"是否回到原方向结构。**翻转条件**：若 D∘D 不对合（信息单调流失），则 ⋆ = D 仅是类比非严格对偶，P5 降为启发式。

### 谱系引用
233/235（ker D/联络=D 余像）；526（a0 层 vs 递归层）；与 P1 共链。

### 影响声明
将 P1 的 ⋆=D 从"残差专用"提升为"金融规范场的一般对偶结构"。

## P6（跨链涌现）：最优持仓周期 = 配置驻留时间，门控应门 regime 切换而非入场

### 推导
P3 说 alpha = 暴露守恒（持续在场）。P4 说配置有内禀驻留（均值 55 天/中位 14 天）。组合：

**P6：最优持仓周期 = K4 配置驻留时间；门控的正确位置是 regime 层（配置切换）而非信号层（入场确认）。** 

理由：alpha 来自在场（P3），配置切换（89 次非对角转移）= regime 转折 = 真正的出场点。门控被否证是因为它门错了对象——门"入场信号确认"减暴露（毁 alpha），但门"配置切换"（驻留态结束）= 在暴露守恒内捕捉 regime 转折。这把门控从被否证的信号层救到 regime 层。转换路径偏好（§7：(──↑)↔(↑─↑) 各 0.5 互转 = σ_P 翻转）给出具体切换信号。

### 认识论等级
L3 假说（组合 P3 的 L2-L3 + P4 的 L3）

### 可验证方案
对同一标的跑两组出场信号：(a) 配置切换点（89 次非对角转移）作出场，(b) 缠论买卖点作出场，(c) buy-hold。比较暴露守恒 alpha。
- **P6 成立**：(a) 的 alpha > (b)，且 (a) 的换手率 ≈ 配置切换率（1.8%/天）。
- **翻转条件**：若配置切换点出场 alpha < buy-hold，则"配置切换=出场点"否证，P6 失败（regime 层门控同样毁 alpha，则 alpha 纯粹来自不出场）。

### 谱系引用
P3（暴露守恒）+ P4（配置驻留）+ `k4_config_transition`（切换路径偏好）+ 482（配置切换=regime 转折）。

### 影响声明
为门控找到唯一可能有效的位置（regime 层），同时给暴露守恒（P3）一个具体的出场判据。
