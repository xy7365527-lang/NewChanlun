# H2 力度收敛门判决——参照系空集：49课行38 在 H1 窗口测量仪下不可观测

任务（2026-06-12 编排者）：实装 H2 力度收敛门，补位 BRN 等 H1 无效的
负域标的（设计预注册 analysis/h2_strength_convergence_design.md）。

认识论等级：**L3**（五标的真实数据交叉验证，14.9M bar，否定性结果）。

---

## 0. 判决摘要

1. **H2 被否证，且否证形态比预注册的任何预案都深**：不是"新生保守
   默认拦截深回调盈利腿"（设计已知风险），而是**收敛/扩张分支结构性
   不可达**——五标的全程 `n_sg_pairs = 0`（没有任何一个中枢在生命
   周期内积累到 2 条可比对的向上离开段力度样本）。门退化为无条件
   全拒：五标的 osc 腿全部消灭（141/743/1352/1412/1056 → 0）。
2. **机制诊断（测量仪假设否证）**：设计 §3 的核心假设——"H1 的
   pending_departure 窗口恰好框定每个离开段，零 surfacing"——被
   数据否证。力度样本的生成被双重过滤：(a) 只有触发 candidate type3
   的离开段才有窗口（普通中枢震荡的离开-回归不产生 candidate）；
   (b) 只有被**价格否定**的窗口才入历史（91% 窗口随中枢死亡/新中枢
   解除——H1 在册读数）。两重过滤后样本生成率 < 1 条/中枢生命周期
   （OKLO 3,072 窗口 → 150 条 Buy 侧样本 → 0 个可比对）。49课行38
   的参照系（"中枢震荡都是逐步收敛的"——同一中枢的离开段序列）在
   该测量仪下是**空集**。
3. **判据3（OKLO 保护）重度否证**：Δosc(h1h2 vs h1) = **−87,859**
   （界 −10K 的 8.8 倍）——H1 在 OKLO 收复的全部 osc alpha 被 H2
   全拒抹掉。
4. **判据1/2/4 字面满足但判别力为零**：时序靶拒绝率 100%（≥50%）、
   负域 Δosc 缩减 100%（≥50%）、腿数+尾部亏损同步消灭——全部经由
   "门=常数拒绝函数"的退化路径成立，与"力度历史识别僵尸"的判据
   实质内容无关。预注册判据体系隐含"门是选择性的"前提，放行集为空
   时判据失去判别力（n_sg_pairs=0 是这一点的直接证据）。
5. **负域"全关"对照单元格的意外产出**：H2 ≡ osc 总开关，给出负域
   osc-off 上界——BTC +608.9% / CL +255.1% / ES +297.4%，与在册
   scco（+629.8 / +250.4 / +303.9）几乎打平、无支配关系。即使把
   osc 全关，也不优于结构白名单形态 ⇒ "负域单边轴"预案（设计判据3
   否证预案）**无增量内容**：H2 的负域形态既非选择性也不优于在册。
6. **白名单消除判决**：H2 关闭后，零参数结构门方向只剩 H3（级别
   上移）/ H4（结构白名单）——与设计判据1 否证条款的预言一致
   （成立路径不同：不是"<50%"而是"假设的可观测前提崩塌"）。

## 4. 机制定位：历史性判据对"结构滞后"的平方级敏感

"确认层/结构层错位"谱型（H1 判决 §4 确立三层：confirmed 不可达 →
candidate 滞后 → 价格事件即时）的**第四例，且引入新维度**：

- H1（当下性判据）：需要 1 个 candidate 事件在场——滞后使负域覆盖
  不足（拦截率 1.7–6.8%），但 OKLO 上工作；
- H2（历史性判据）：需要同一中枢**2 个** candidate 事件且各自被价格
  否定——四事件合取（candidate₁∧否定₁∧candidate₂∧否定₂）在中枢
  生命周期内概率趋零。**历史性判据对结构滞后的敏感度是当下性判据的
  平方级**：单事件到场率 ~9%（价格否定/窗口），两次独立到场且同中枢
  ≈ 不可观测。
- 原文层面的精确定位：49课行38 的参照系是中枢震荡的**全部**离开段
  （每一次"向上离开又回拉"），不只是产生三类点候选的离开段。candidate
  type3 门控的测量仪系统性漏采普通震荡段 ⇒ 行38 在此测量仪下不可
  观测。**行38 判据本身未被否证**——被否证的是"复用 H1 窗口机器 =
  零 surfacing 即可测力度"的设计假设（设计 §3"O(S²) 风险被 H1 基础
  设施消解"——消解掉的恰好是判据的可观测性前提）。
- 严格形式的代价回到原点：测量"每个离开段"需要次级别段级结构
  surfacing（研究 §4 H2 原估方向），其 O(S²) 风险需独立设计——不在
  本任务范围内补做（预注册的就是窗口复用版，其否证是本任务的合法
  产出；硬补 = 在否证现场重新设计实验）。

## 5. 结果包六要素

1. **结论**：H2 力度收敛门否证关闭。机制：参照系空集（五标的
   n_sg_pairs=0，14.9M bar）——收敛/扩张分支结构性不可达，门退化为
   osc 总开关；判据3（OKLO 保护）−87,859 重度否证；负域"全关"形态
   与在册 scco 打平无支配 ⇒ 对偶并集预案不采纳。零参数白名单消除
   只剩 H3（级别上移）/H4（结构白名单）。
2. **定义依据**：49课行38（"中枢震荡都是逐步收敛的……后面的向下
   离开力度一定比前一个小"——收敛判据与扩张预警）、行52（"用中枢
   震荡力度判断的方法，完全可以避开"——事前性）、38课答疑"能回到
   中枢就不是第三类买点"（价格否定=震荡依旧样本的判定）。输入数据
   特征与定义条件的关系：行38 判据要求同中枢 ≥2 条同向离开段力度
   ——输入磁带在 candidate 门控测量仪下该特征恒空（n_sg_pairs=0）。
3. **边界条件**：(a) 本判决限 floor=2、1min 磁带、candidate 门控
   测量仪——若改用次级别段级 surfacing 直测全部离开段，参照系可能
   非空，行38 判据须重新实验（H2' 开放轴）；(b) 若改 floor（中枢
   生命周期变长）或低频磁带，sg_pairs 可能 >0，本否证不外推到那些
   配置；(c) 容量 2 历史窗不是死因（样本饥饿发生在 1→2，扩窗只会
   更饿）；(d) "全关优于基线"仅在负域成立且不优于 scco——不得引为
   "删 osc 模块"的依据（OKLO/BRN 正域 osc 是 +14K/+20K 正贡献）。
4. **下游推论**：(a) 实盘配置表零变更（正域 _ht_h1 / 负域 _scco
   维持）；(b) 任何**历史性**结构判据（需同对象 ≥2 个历史事件）在
   挂 candidate/confirmed 层时，先验失败概率是当下性判据的平方级
   ——设计阶段必须先估样本生成率（n_sg_pairs 型读数应成为预检）；
   (c) H3/H4 成为白名单消除仅存方向；(d) osc_strength_gate 保留为
   否证在案配置位（NRF 先例），默认 false 零接触。
5. **谱系引用**：533号（BRN 僵尸时序裁决——H2 的目标域定位来源）、
   H1 判决（"确认层/结构层错位"三层谱型——本判决第四例扩展：
   历史性判据平方级敏感）、o41 段对悖论（参照系不可定义的先例——
   本例更深：参照系定义良好但样本生成率为零）、231号形式化有效域
   （测量仪的有效域 ⊂ 判据的定义域——行38 定义域非空、该测量仪下
   有效域空集）、SC 判决（等待型判据僵尸 regime 不可达——历史性
   判据是其跨时间累积形态）。"历史性判据样本饥饿"无在册专属谱系，
   候选新条目。
6. **影响声明**：新增 osc_strength_gate 配置位 + V2oa25_ht_h2 /
   _h1h2 变体（默认 false，O0≡P5 零接触面）；CenterBook 新增
   pending_excursion / up_strength 状态 + sg_records / sg_pairs
   计数（不消费时零行为差，190 测试全过）；counters 新增 4 计数 +
   1 日志；在册判决零改动；磁带零改动（tape_fp 五标的全部与 scco
   缓存一致）。产出缓存：analysis/data_cache/h2_sg_{OKLO,BRN,BTC,CL,ES}.json
   （含逐腿时序靶探针明细）。
