## 1. 机制（零新参数）

osc 开腿前提 = 锚层典型中枢相对振幅 θ_q ≥ theta_cost_k × friction_rt：

- **θ_q** = DepthRef 因果滚动 P50（window=50 个中枢，min_obs=10，零前瞻）
  ——窗口长度从结构涌现（N 个中枢，非 bar 数），与 θ 自适应深度门同口径
  同机器（DepthRef 复用，零新观测代码）。
- **门槛** = theta_cost_k(2.0) × friction_rt(10bps) = **0.2% 相对振幅下限**
  ——`sub_cost_gate`/`ledger_cost_gate` 在册常数对原样沿用（35课成本门的
  osc 准入形态，第三个消费点）。
- **warm-up**（参照 <10 中枢）⇒ 保守拒绝独立计数（"不静默放行"先例）。
- 只挡开腿，闭腿零接触（僵尸腿教训）。

原文依据：38课行32"可以对所有股票按某级别走势的幅度进行数据分析，把所有
历史走势都计算一次，选择一组历史上某级别平均震荡幅度最大的股票，不断操作
下去，这样的效果更好"（标的筛选条款的运行时形态）；35课行30"级别越小，
平均的买卖点间波幅也越小……不足以让交易成本、交易误差等相对买卖点间波幅
足够小，这样的操作，从长期的角度看，是没有意义的"（准入下限 = k 倍摩擦）。

## 4. 核心判决：口径分裂第一例

**零摩擦复利面（在册判决可比口径）**：Δ(h4−ht) 3/5 正
（OKLO+169 / BTC+59 / ES+54 vs BRN−111 / CL−21）——**G1 不达，
零摩擦口径下 h4 不消除白名单**。

**摩擦调整 osc 面（门自身的存在论口径）**：**5/5 全正**
（+8,078 / +11,354 / +65,532 / +35,958 / +96,646）——门假设 10bps 摩擦
真实存在，在同一假设下记账，h4 在全部五标的上改善 osc 腿面，**无需白名单**。
这不是巧合而是构造自洽：门删除的恰是"振幅不覆盖摩擦"的腿，这类腿在摩擦
记账下每标的都净负。

**实盘推论**：实盘摩擦真实存在 ⇒ 实盘语境的有效口径就是摩擦调整口径 ⇒
h4 可作为实盘 osc 准入默认。零摩擦回测判决与含摩擦实盘判决在此首次系统性
分裂——并揭示在册"正域"标签的脆弱性：**BRN 的 osc 正域身份是零摩擦伪影**
（35课口径下 BRN segment 级中枢振幅 P50≈0.10% 不覆盖 0.2% 成本下限，
"长期操作没有意义"逐字应验）。

## 5. 与 H2 的本质区别：判别力非零

H2 死因 = 参照系空集（五标的 n_sg_pairs=0）⇒ 门退化为 osc 总开关
（判别力零）。H4 的参照系（滚动中枢振幅）**恒非空**（warm-up 后），
判别力 per-asset 自适应**内生涌现**：同一个 0.2% 全局门槛——

- OKLO 拦 3 次（0 thin——振幅厚域自动全准入）
- ES 拦 2,768 次（腿 1056→133——振幅薄域自动近关闭）
- 时序靶梯度 6.7% → 77.4% 与拦截强度同序

零标的级参数，分化全部来自各标的自身的滚动振幅分布——这正是 38课行32
"按某级别走势的幅度进行数据分析"的形态：选股判据从回测盈亏符号
（不可在线、不可证伪）换成结构量×物理摩擦（事前可读、逐 bar 可审计）。

## 7. 结果包六要素

1. **结论**：H4 滚动振幅准入实装完成（osc_amp_gate，零新参数）。零摩擦
   口径 G1 不达（3/5），不能以"全局默认"消除白名单；摩擦调整口径 5/5
   全正，h4 是 35课口径下的全域改善——白名单问题被重定位：在册正负域
   二分本身携带零摩擦伪影（BRN 案）。
2. **定义依据**：38课行32（震荡幅度选股，逐字核验 docs/chanlun/text/blog/
   038-第38课.md:32）；35课行30（成本相对波幅下限，035-第35课.md:30）；
   代码判据 = DepthRef.theta(k, None, 0.5, 10) ≥ 2.0×0.001
   （level_operating_unit.rs osc_amp_admitted）。
3. **边界条件**：(a) 摩擦调整面是 osc 腿面口径（腿盈亏 − 10bps×名义额），
   非全成本复利重放——后者需所有腿类统一收摩擦，独立工作量；(b)
   friction_rt=10bps 是股票量级锚定（卖飞修复 be9.7bps），期货真实摩擦
   1-3bps——per-asset 物理摩擦常数表（交易所费率，非盈亏拟合）会放松
   BRN/CL 门槛（BRN P50 0.10% 在 2bps 摩擦的 0.04% 门槛下通过），五标的
   结论在"10bps 全局"假设下成立；(c) regime 稳定性边界与 scco 同型
   （滚动窗口自适应缓解但不消除跨时段翻号风险）；(d) 38课行32 原文语境
   是 A 股全仓机械化，期货/币杠杆做空语境是范围外推（调研报告在册
   边界条件 (d) 继承）。
4. **下游推论**：(a) 实盘 osc 准入默认候选（实盘口径=含摩擦口径，5/5
   正）；(b) per-asset 物理摩擦表是 H4 完整形态的开放精化轴；(c) 在册
   osc 正负域白名单的"正域"标签需加零摩擦伪影警示（BRN）；(d) 若 H3
   级别上移（并行工位）成立，H3×H4 正交可组合（H3 重路由床位，H4 判
   床位可操作性）。
5. **谱系引用**：osc操作域严格化判决（10/10 反相关——白名单的发生地）、
   H2力度收敛门否证（参照系空集退化总开关——H4 判别力非零是其对照）、
   θ自适应深度门（因果滚动分位先例）、P0+P1双门判决（成本门=亏损有界化
   先例）、231号形式化有效域规则（零摩擦面与摩擦面的有效域分裂本身是
   规则的实例：同一形式化判据在不同度量下结论翻转）。未发现"回测口径
   vs 实盘口径系统性分裂"专属谱系——本判决可作首条。
6. **影响声明**：新增 OrganicConfig.osc_amp_gate 字段 + V2oa25_ht_h4
   变体 + Counters 双计数/逐事件日志 + runner 两条 guard + lib.rs
   marshal + LOU osc_amp_admitted/开腿链准入分支；O0≡P5 零接触面不变
   （默认 false，h1/h2 同先例）；新增回测脚本与本文档；未改动任何在册
   变体语义（h4 变体单测断言除 osc_amp_gate 外与 ht 逐位相同）。
