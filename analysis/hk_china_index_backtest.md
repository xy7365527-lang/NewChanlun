## 边界条件与方法论声明

1. **L2 等级限制**：所有结论均为单标的单时段假设检验，否定性结果（B<A）有效；正确性不外推到未测标的/时段。
2. **intraday 数据极短**：1分钟7天/5+30分钟60天——统计量依赖于此窗口，不代表长期有效性。
3. **信号重绘风险**：TV 实时指标的历史标注可能在 bar close 前重绘，当前数据仅代表最终收盘后状态。
4. **港股/A股 yfinance 限制**：000001.SS 的 intraday 数据质量差；^HSTECH 可能回退至 3032.HK ETF。
5. **L3 需求**：若要得出稳健结论，需要跨标的 + 跨时段 + 跨时间段的交叉验证（本报告为 L2 起点）。
