## 边界条件与有效域

1. **信号来源**：TV 缠论指标实时标注，非历史回放——标注存在未来重绘风险（replay check 未执行）。
2. **价格映射**：TV bar_index → yfinance OHLCV 基于价格锚点匹配，复权口径可能不一致，偏差 >5% 的信号结论可靠性下降。
3. **intraday 数据限制**：yfinance 1分钟 ≤7天 / 5/30分钟 ≤60天——覆盖的历史极短，backtest 统计量置信度低（bar 数不足 → 可能翻转）。
4. **PH settle 过滤**：settle 是「右侧确认」；极端底部的右侧确认滞后于价格底部，B 组可能在关键买点处漏单（QQQ 回测已有 L2 否证）。
5. **翻转条件**：若信号数 <4×2 则统计无效；若市场处于单边大趋势，胜率可能因基准漂移而虚高。
6. **认识论等级**：daily=L2（全历史）；30min/5min=L2（短窗口）；1min=L2（极短窗口，可信度最低）。L3 需多标的/多时段交叉验证。
