## 1. 实装形式（严格声明）

```
in_trend(k) := ∃ j > k: trend_state[j] ∧ dir_state[j] == Up
```

- `TrendScope::Ancestor`（`hold26_anc`，M1 主臂）：纯祖先窗口**替换**自层
  KindDir 判据（26:80"如果有更大级别的单边上扬，短线的可以不必坚持小转大
  的原则"的配额层下沉）。
- `TrendScope::SelfOrAncestor`（`fusion_ta`，M3 对照臂）：自层 ∨ 祖先
  （49:52 ∪ 26:80 全字面并集）。
- 单调性语义：祖先层 `kind==Trend`（17课"≥2 同向中枢"= 中枢序列单调上移的
  引擎直读）∧ `dir==Up`；祖先 trend 翻落或 dir 翻 Down ⇒ 窗口即关、削减
  恢复（35:16"只要也只有出现第N个中枢不再高于第N-1个才可说上涨结束"）。
  35:16 的**严格收紧版**（新中枢 ZD > 前中枢 ZG 逐对校验）= 预注册 V2
  条件臂，见 §5。
- 零新参数、零新磁带行、无年度 regime 标签、无前视；非 SelfLayer 与
  counter_sub/TrendAxisOpts/r2_gate/osc/phase_clock/nest_forward 的合取
  入口显式拒绝（仅 M1/M3 两臂预注册）。
- 在册零接触：`SelfLayer` 为缺省，全部在册模式行为逐位不变（guard-a/b
  八标的全过，容差 0.05pp）；单测 6 项（解析/守卫/祖先停削/单调性打破
  恢复/熊市零接触/ta 并集语义）+ 全库 201 测试绿。

## 4. 机制解剖

### 4.1 ES 修复的本体（与调研代理对齐）

bull 赤字 −1.0246 → −0.4563 nats（回收 **+0.568**，代理预测 +0.517 同向
同量级——链式效应在 ES 上几乎中性）。交易数 18339 → 2718（85% 削减消失
= 豁免窗口内卖点不出清）；MDD 反而从 hold26 −21.4 → anc −21.6 几乎不变，
**远浅于 fusion_t −32.4**：祖先窗口在祖先趋势终结时同步关闭，比自层窗口
更早恢复削减，下行保护更好。这是"满仓修复"与"回撤控制"首次不互斥的配置。

### 4.2 GC 否证的本体（P3 破的死因）

GC 伤害不在 bull（−0.351→−0.253，回收 +0.10）而在 **range 桶
+0.262 → +0.122（−0.14 nats）**——正是调研 §4.3 预言的风险：「GC 的
range 桶 +0.146 解释了为什么 anc 必须建在 hold26 上」。建在 hold26 上
仍然不够：GC 九年长 range 中存在零星祖先趋势窗口（occupancy seg 0.773），
窗口内压制的恰是 hold26 正盈利的 range 削减引擎。**配对代理的边界（§5.3
诚实性条款）第二次显形：E0 桶 wα +0.013（近零）→ 实跑 −34pp，链式效应
（压制改变后续配对链）是一阶项，代理只能定方向排序不能定量级。**

### 4.3 fusion_ta 对照臂（M3）——开放轴首位

ta = 自层 ∨ 祖先，在 BH 域全面超 anc（ES +497.9 vs +394.5；QQQ +129.5
vs +108.8），BTC +4126.4 ≈ fusion_t +4174.6（−48pp 近零接触），BRN +86.0
≈ BH +87.4（声部标的首次贴平 BH）。但 GC +218.8 / DX +5.8 双重伤害——
与调研预言「M2（fusion_t+anc）对 GC/DX 双重伤害」同构（ta 含自层窗口）。
ta 的白名单域与 anc 相同但增益更大：**{ES, QQQ} 部署应以 ta 与 anc 并列
候选，由 MDD 偏好裁决（ta ES MDD −36.0 深于 anc −21.6——增益换回撤）。**

### 4.4 regime 函数家族第十例

Δ(anc − 在册最优) 的符号 = f(标的)：正域 {ES +25.4, QQQ +6.5} / 负域
{BTC −1742.8, CL −78.9, GC −34.0, OKLO −178.8, BRN −11.3, DX −3.7}。
二分线与 BH 域标签（hold26 L3 在册）重合 8/8——**anc 正域恰是 BH 域**，
这不是巧合：豁免窗口回收的是"祖先趋势中自层削减"的失血，该失血只在
慢牛标的（豁免域宽 + 自层削减亏损）上是主导项。

## 5. P4 BTC 破限与 V2 条件臂的归位

BTC bear α 泄漏 −0.258 nats（界 −0.25，超 0.008）——熊市反弹段的低层
上行趋势触发豁免（调研 §4.3 预言的泄漏通道，代理上界 −0.24 低估 8%）。
预注册 V2 条件臂（豁免时钟收紧为 35:16 严格中枢上移）的触发条件字面满足。
但 V2 的对象域推导：P4 破限标的仅 BTC，而 BTC 已由 P2 归属 fusion_t
（anc 不部署于 BTC）；部署域 {ES, QQQ} 内 P4 全过（ES ✓，QQQ 不可测但
无熊市年标签依赖）。**V2 当前无部署对象，列开放轴而非立即执行**——若
后续 anc 域扩张触及有熊市年标的且 P4 破，V2 升执行。

## 6. 与并行工位的交叉印证

- 空头条件轴工位（同日 commit 89da391d1d）已消费 anc 判据作 B5 门：
  BTC +230pp 开 / CL −203.6pp 关——anc 窗口作为空头门控同样是 regime
  函数，与本判决的正负域结构互证。

  nest×anc 合取列其开放轴；本判决的 ES gap 收窄 50.1%（anc）vs 14.5%
  （nest）确认削减失血是 ES 的主导项。

## 7. 结果包六要素

1. **结论**：anc 豁免 L3 判决=白名单部署 {ES, QQQ}（regime 函数第十例），
   不升统一基座；ES +394.5%（gap 收窄 50.1%，G4 复活）、QQQ +108.8%
   （超 fusion_t 但 gap 收窄 36.8% 未达半）；GC P3 破（−34pp，range 削减
   引擎被吃）；fusion_ta 对照臂 BH 域更优列开放轴首位。
2. **定义依据**：26:80（豁免授权）、49:52（满仓义务/自层窗口）、17课
   （趋势=≥2 同向中枢）、35:16（单调性终结判据）、44课（级别隔离）；
   引擎映射：祖先层 trend_flips×dir_flips 行合取。
3. **边界条件**：(a) 判据依赖 trend/dir 磁带行的级别涌现——a0 改变则
   全部数字失效；(b) 零摩擦 close 口径——anc 削减频次比 hold26 低 4-7×，
   摩擦面只会扩大 anc 优势，但未实测；(c) gap 收窄 0.501 恰过线——数据
   重拉漂移可翻转 P1 ES 分量；(d) GC 否证依赖其九年长 range 结构，趋势化
   后可能翻正；(e) QQQ 无时间戳，P4 永不可测。
4. **下游推论**：positional 部署矩阵更新为四分：{BTC,CL}=fusion_t /
   {ES,QQQ}=hold26_anc（或 ta，待 MDD 偏好裁决）/ {GC,DX}=hold26 /
   {OKLO,BRN}=V2oa25_ht；空头 B5 门、nest×anc 合取两条并行轴获得 anc
   的正负域先验。
5. **谱系引用**：regime 函数家族（fusion_t 第九例→本判决第十例）；
   §5.3 配对代理边界第二次显形（GC 符号同向量级 26×）；002号源不完备
   （26:80 豁免条款此前未进语料）；090号（代理数字不构成收益预测的
   诚实性条款执行）。
6. **影响声明**：Rust 引擎 +`TrendScope` 枚举与两 mode（在册模式逐位
   零接触，guard 8/8 过）；`PositionalResult` +2 观测字段；新增
