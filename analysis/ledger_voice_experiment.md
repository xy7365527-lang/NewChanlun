## 1. 实验设计

### 1.1 命题（Part II §12 中心命题的可否证形式）

> 控制状态（相位/配对槽/锚记忆）是（结构 × 账本）的可失效缓存，可全部消除；
> voice 的严格形式是"有门的账本"。

最小化检验连门都不留（**裸账本**），把"相位 + 门"的联合信息含量一次性显形：

```
VoiceMode::Ledger（VL）：
  confirmed Sell@k 且槽空 → open_diff(frac_k)   （清 slice = 卖出）
  confirmed Buy@k  且槽开 → close_diff           （填 slice = 买回）
  无相位过滤、无锚比较、无门谓词、无配对记忆。唯一状态 = 腿槽占用（资源状态）。
```

### 1.2 递归建仓教训的规避（范畴隔离）

recursive_position_experiment.md 否证的死因 = **从零建仓** + BSP 事件全清 ⇒ 暴露塌缩
（slice 占用时间 ≪ 趋势长度，OKLO 暴露 0.12-0.21）。本实验 **master 满仓持有逻辑零接触**
（Full 入场 + Signal 出场在册路径，与 V2oa25 同 195/910 笔 trade 逐位同构）——暴露由
master 兜底，唯一自由度 = voice 短差的消费方式。结果证实隔离成功：四臂 trade 数全同，
全部差异来自 cost_basis 改善路径（短差 net_cash）。

### 1.3 臂与对照锚

| 臂 | voice 形式 | 隔离的因果 |
|----|-----------|-----------|
| V2oa25 | FSM 全机制（main 带门带锚 + REV 相位/配对/θ门/41课门） | 在册基线（OKLO +1623.09% 逐位复现 = 磁带零漂移锚定） |
| O0 | main 腿 = 带门带锚的账本（center_gate + 同锚闭腿 + open_kinds 词汇） | O0 − VL = 门+锚 vs 裸 |
| VL | 裸账本（全词汇全消费） | 主实验臂 |
| VLs1 | 裸账本 + 卖侧仅 Sell1 开 | 卖侧词汇宽度（递归建仓 s1 臂镜像） |

预注册判据：VL ≥ V2oa25 ⇒ Part II 命题确认；VL < V2oa25 ⇒ 差额 = 控制状态+门的信息含量。

## 3. 判决与归因

**Part II"控制状态是冗余缓存"命题：作为全称命题被否证；regime 条件化后部分成立。**
（regime 依赖第三例，与 REV 三标的三排序、递归建仓 s1 臂同构。）

1. **强趋势域（OKLO）：控制状态+门携带 −1146pp 量级的信息。** 分解：
   - FSM 相位/配对/θ门/41课门（V2oa25 − O0）= +534pp——REV 腿净现金 +59,017、
     587 次 gate 拒绝是信息含量的直接计数；
   - 门+锚 vs 裸（O0 − VL）= +612pp——同为账本，center_gate + 同锚闭腿 + 词汇
     限制把短差从 737 对/wr 40%/净 −48k 修剪到 317 对/wr 60%/净 +86k。
   - 死因与递归建仓同构：中枢震荡中每级别反复发买卖点，全消费 = 噪声交易
     （wr≈40%、p50=0 两标的同构——这是裸账本的**结构常数**，不是标的性质）。
2. **震荡域（BRN）：裸账本超基线 +24.1pp 且 MDD 砍半（−59.9%→−34.8%）。**
   FSM 的 osc 腿在 BRN 净 −51,925（带门带锚仍亏），V2oa25 靠 REV 腿 +48,635 救回；
   裸账本以 5,574 对微小正期望（mean +3.16/对）的大数定律取胜。**门与相位在震荡域
   不仅无信息，其结构（osc 腿）是负贡献。**
3. **卖侧词汇收缩（VLs1）双标的与递归建仓 s1 反向**：OKLO −20pp、BRN −18pp 均劣于
   VL——在 master 满仓兜底下，Sell2/3 开腿的"打断"代价不存在（master 不被打断），
   收缩只减少兑现机会。s1 教训的有效域 = 从零建仓形态，不外推到满仓短差形态。
4. **噪声常数读数**：裸账本短差 wr 40.1-40.3%、p50 = 0.00 在两个 regime 完全相同——
   全事件消费的短差质量与 regime 无关；regime 决定的是这串噪声交易叠加在持仓上的
   **几何效应**（强趋势中卖出窗口踏空 = 失血；震荡中卖出窗口避险 = MDD 改善+微利）。

## 4. 概念发现

**"门与相位的信息含量是 regime 的函数"**——deep_think §13 把门列为无条件保留项、
相位列为无条件删除项，本实验显示两者都不是无条件的：强趋势域中相位+门联合携带千 pp
级信息（保护 master 不被噪声短差失血）；震荡域中同一套机制是 −76pp 的负贡献结构。
"控制状态 = 可失效缓存"的正确形式可能是：**缓存的失效方向随 regime 翻转**——
强趋势中 FSM 缓存了"不要交易"（正确），震荡中 FSM 缓存了"按相位交易"（错误，
裸账本的无差别消费反而更好）。

MDD 读数独立有值：BRN VL 的 −34.8% 是该磁带上所有在册变体中最低回撤之一，
且不以收益为代价——若 regime 可判，"震荡域切裸账本"是一个真实的候选改进轴。

## 结果包

1. **结论**：(a) 实装——`VoiceMode::Ledger` 裸账本 voice（VL/VLs1 变体 +
   guard + n_ledger_* 计数器），master 路径零接触（四臂 trade 数逐位同构），
   cargo test 132 项全过；(b) L2 判决——控制状态剥离在 OKLO 否证
   （VL −1146pp）、在 BRN 反向成立（VL +24.1pp 且 MDD −59.9%→−34.8%）：
   "控制状态是冗余缓存"不是全称命题，门与相位的信息含量是 regime 的函数；
   (c) 裸账本短差质量是结构常数（wr≈40%、p50=0 两 regime 同构），regime 决定
   的是噪声交易叠加在满仓上的几何效应符号。
2. **定义依据**：deep_think Part II §11（控制/资源状态范畴二分）、§12（缓存
   失效命题）、§15（voice=有门的账本）；26课恒仓守恒（买回填至原量——
   open_slot 槽语义直接实现）；38课全点消费的字面形式（VL 的事件词汇）；
   引擎事实 `runner.rs` voice 循环（main/osc/rev 三腿结构）、
   `ledger.rs::open_diff/close_diff`（开=卖/闭=买的账本原语）。
3. **边界条件**：(a) 判决有效域 = 零摩擦 × confirmed-only × master 满仓兜底
   ×{OKLO 强趋势, BRN 震荡}——VL 的 BRN 优势在现实摩擦下需重检（5,574 对
   ≈ V2oa25 的 2.9 倍换手）；(b) 若 regime 条件化臂（开放轴1）在第三标的
   否证，"信息含量随 regime 翻转"降级为两标的巧合；(c) OKLO 的 −1146pp 中
   门与相位的分解依赖 O0 作中介（O0 与 VL 还差闭腿锚与词汇两轴，非纯门轴）。
4. **下游推论**：(a) deep_think §13 的"门无条件保留/相位无条件删除"表需要
   regime 列——修订其判别标准；(b) 41课门 v2（rev_l41_gate）的方向正确性
   获得侧面支持（OKLO 强趋势中拒开反向腿 = FSM 信息含量的组成部分）；
   (c) BRN MDD 砍半提示风险预算视角的变体选择维度（不只看复利）；
   (d) V2oa25 仍是在册最优默认，未被触及。
5. **谱系引用**：project_recursive_position_bsp_falsified（暴露塌缩死因——
   本设计的范畴隔离动机）；project_rev_paired_fix / project_theta_adaptive_gate
   （V2oa25 基线谱系）；regime 依赖先例：REV 三标的三排序
   （project_multilevel_fugue_cross_asset）、递归建仓 s1 臂——本实验是第三例；
   project_cycle38_voice_falsified（循环 FSM 否证——本实验从相反方向逼近同一
   问题：那里加控制状态无增量，这里删控制状态 regime 依赖）。
