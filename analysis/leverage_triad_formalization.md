# 杠杆 × 名义敞口 × 操作级别——三元组的严格缠论形式化

> 任务性质：思考与组装，非调研。原文穷举已在 `analysis/notional_exposure_leverage_research.md` 完成；
> 本文把已确立的约束件组装为完整、自洽、可计算的框架。
> 认识论等级声明：框架本体为 **L0**（定义推导，零新回测）；引用的实证结论逐处标注在册等级。

## 0. 摘要（五个组装定理）

1. **派生量定理**：层间权益分配 E_j 不是分配变量，是派生量——E_j = N_j / L_max(j,t)。三元组的自由度结构是：杠杆零自由度（影子价格）、名义一个自由度（顶层配额）、权益分配零自由度（前两者反解）。"E_j 的分配规则从哪里来"这个问题被消解而非回答。
2. **嵌套守恒定理**：多层嵌套塔的总名义守恒于顶层配额 N_top。子层名义来自父层卖点削减的释放再部署（ledger `open_sub` 绝对股数预算，已结算），不是新增敞口。"满仓"在多层下不会加总爆炸。
3. **单调性定理**：P_neg 在结构事件之间是常数，且同一持仓前提下单调非降（中枢只上移不下移）。逐仓强平价 P_liq 开仓后固定 ⇒ 开仓时满足 P_liq < P_neg 则约束终生自动保持。**杠杆维护是事件驱动的，逐 bar 调整在结构上不必要。**
4. **升级负债定理**：级别升级（仓位归属上移）使 P_neg 跳降至高级别否定价、D_struct 跳大、L_max 跳低——同一名义的保证金需求跳升。级别升级首先是负债事件，不是加仓机会。26:26 取反函数的动态形态：持仓级别越升，资金期限要求越长，杠杆必须主动降。
5. **单边律**：对同一持仓，杠杆调整只降不升。L_max 上升（中枢上移）时提取保证金 = 主动上移强平价 = 零收益纯尾部，禁止（与 26:32 杠杆零正贡献论证同构）。"杠杆上升"唯一合法形态 = 卖点释放的名义在低层腿的再部署（新腿，非同一持仓）。

## 1. 三元组约束方程组（问题 A）

### 1.1 变量表

| 符号 | 含义 | 来源 | 自由度 |
|---|---|---|---|
| E | 总权益 | 账户 | 外生 |
| j | 操作级别（递归塔层标号） | 引擎级别涌现 | 结构读数 |
| c(t) | 当前价 | 行情 | 结构读数 |
| P_neg(j,t) | 级别 j 持仓前提的结构否定价（相位依赖，§1.2） | 引擎 ZD/ZG + PhaseView | 结构读数 |
| θ_q(j,t) | 级别 j 中枢相对振幅的因果滚动分位（[depth_ref.rs:90](rust/src/trading/depth_ref.rs:90)） | 在册估计器 | 零（因果、排除自身） |
| mm(N) | 维持保证金率，名义的递增阶梯函数（风险限额分档） | 合约规格 | 零 |
| N_j | 层 j 名义敞口 | 配额（§1.4） | **唯一自由度在顶层** |
| L_j | 层 j 杠杆 | 影子价格 | 零 |
| E_j | 层 j 逐仓保证金 | 派生：N_j / L_j | 零 |
| r_reserve | 机动资金比例 | [25:168] 1/4–1/3，恶劣时 1/2 | 原文离散惯例值 |

### 1.2 每层约束（三条）

**(i) 存活约束（杠杆上限，L0 核心不等式，承自前研 §3.1）**：

> D_struct(j,t) ≔ (c(t) − P_neg(j,t)) / c(t) + θ_q(j−1, t)
>
> **L_j ≤ L_max(j,t) = 1 / (D_struct(j,t) + mm(N_j))**

第二项 θ_q(j−1) 是确认滞后垫（53:56 答疑：离开与回抽均必须次级别——确认到达时价格已在否定水平下方约一个次级别振幅），有结构出处，不是安全系数。

P_neg 的相位定义（与 P6 相位机 PhaseView 三值接口对齐，[positional_fusion.rs:100](rust/src/trading/positional_fusion.rs:100)）：

| PhaseView | 持仓前提 | 结构否定 | P_neg |
|---|---|---|---|
| MoveUp（[Buy3, settle(C')] 区间，049:60） | 离开段不回新中枢 | 回抽跌破新中枢上沿 | ZG_new |
| Osc（中枢震荡依旧，49:52 前提条款） | 中枢震荡依旧 | 第三类卖点 | ZD |
| MoveDown | 多头持仓前提已不存在 | — | 多头 P_neg 无定义：MoveDown 相多头名义应已为零（49:52 "一旦出现第三类卖点，就不能回补"），残余持仓属违规态非约束对象 |

**(ii) 容纳量约束（53:34 / 49:76 / 26:36）**：N_j ≤ N_cap(j)。市场化形态 = 交易所风险限额分档（名义越大 mm 越高、交易所杠杆上限越低）。低层 N_cap 小（操作窗口短、可成交量小）而 L_max 高；高层反之——**高杠杆与大名义在层间天然互斥**，结构给出，非规则给出。

**(iii) 成本下限约束（35:30，对偶面）**：θ_q(j) ≥ K × friction_RT（在册 ②门，[positional_fusion.rs:85](rust/src/trading/positional_fusion.rs:85)）。合约域 friction_RT 须含资金费率项（开放实装面，前研 §6）。该门从下方淘汰太低级别，与 (i) 从上方压缩高级别杠杆构成同一个量 θ_q 的双向钳。

### 1.3 派生量定理：E_j 的"分配规则"被消解

任务问 "E_j 的分配规则从哪里来？——26 课级别→量的具体形式"。严格答案：**26:34 给的是 N 的偏序，不是 E 的分配函数**。

26:34 原文："级别的意义，其实只有一个，基本只和买卖量有关，日线级别的买卖量当然比 1 分钟级别的要多多了"——这是名义量 N 对级别 j 的单调偏序：

> j > k ⟹ N_j ≥ N_k（高级别名义大）

把它与 (i) 合成：L_max 随级别递减（θ 大 ⇒ D_struct 大），N 随级别递增 ⇒ **E_j = N_j / L_max(j) 随级别超线性递增**——高级别不仅名义大，每单位名义的保证金占用也深。保证金分配天然向高级别倾斜，这不是分配规则，是两条约束的乘积。

自由度盘点：给定顶层配额 N_top（§1.4），各层 N_j 由嵌套守恒（§1.5）派生，L_j 由 (i) 钉死，E_j 由前两者反解。**整个三元组只剩一个真自由度：顶层配额占总权益的比例。** 该比例是 53:34 原文留白（"这就涉及仓位调配控制的问题了，这问题以后再说"——全 108 课未兑现，两轮扫描确认），纯回测裁决域，与在册 BC 配额判决同状态。原文给出的离散惯例先验：1/3（26:80 短线）、1/4–1/3 机动（25:168）、半仓（105:84 震荡市）。

### 1.4 总约束

> Σ_j N_j / L_j ≤ E × (1 − r_reserve)

机动资金在保证金账户中物理三合一：原文机动（25:168）+ 强平缓冲 + **级别升级的保证金补给池**（§3 升级负债定理的资金来源——这是本文为 25:168 惯例值找到的第三个结构功能，见 §3.3 的数量级校验）。

### 1.5 嵌套守恒定理（问题 C 的代数基础）

已结算构件：子腿名义 = 父腿在本节点域内释放的敞口（[ledger.rs:217](rust/src/trading/ledger.rs:217) `open_sub`，递归赋格设计 §3.3，零参数）。hold26 语义下：父层卖点削减 q ⇒ 子层短差预算恰为 q ⇒ 任意时刻

> 塔总名义 = (N_top − Σ削减) 父层 + Σ削减 子层 = **N_top（守恒）**

推论一：多层嵌套不是杠杆放大器。"每层独立满仓"不会使 ΣN_j 超过顶层配额——满仓的多层含义见 §4。
推论二：保证金流向。父层（低 L）释放 q/L_parent，子层（高 L）占用 q/L_sub < q/L_parent ⇒ **每次向下释放-再部署净归还保证金入机动池**；买点回复时反向流出。机动池随塔的呼吸节律涨落，r_reserve 是其下限。
推论三：逐仓是层间独立性的物质前提（前研 §6 已裁决）——全仓模式把各层强平价耦合为单一账户事件，删除守恒定理赖以成立的隔离。

## 2. 单调性定理与事件驱动维护（问题 D、E 的理论核）

### 2.1 P_neg 是事件间常数

D_struct(t) = (c−P_neg)/c + θ_q(j−1) 中，c 逐 bar 变，但 **P_neg 只在结构事件处跳变**（新中枢完成、相位转移、级别升级），事件之间是常数（ZD/ZG 是已完成中枢的边界，不随 bar 漂移）。

### 2.2 同一持仓前提下 P_neg 单调非降

中枢上移过程中 ZD、ZG 序列单调上行（49 课中枢向上移动的定义本身）；相位 Osc→MoveUp 的切换把 P_neg 从旧 ZD 抬到 ZG_new（上移）。唯一使 P_neg 下移的事件是**持仓前提本身的更换**——级别升级（否定价降为高级别 ZD，§3）或 MoveUp→Osc 回落（新中枢 ZD 低于旧 ZG_new）。

### 2.3 维护定理

逐仓多头的 P_liq 由开仓时的 L 与初始保证金固定。合成 2.1 + 2.2：

> **开仓时 P_liq < P_neg(t₀) 成立，且其后无前提更换事件，则不等式终生自动保持。**

这就是问题 E "理论上 L_max 逐 bar 变，实盘不能每秒调杠杆"的严格消解：**不需要每秒调。约束的维护点恰好是（且仅是）P_neg 跳变的结构事件**，事件清单见 §5。bar 间的 L_max 波动（来自 c 的漂移）只朝安全方向松弛或被开仓时刻的不等式覆盖。

### 2.4 单边律与浮盈三分法（问题 D）

**杠杆上调禁止**：中枢上移 ⇒ L_max ↑，代数上允许提取保证金。但名义不变时提取保证金的唯一效果是强平价上移——零收益、纯尾部增量。26:32 论证（杠杆对成本变负机制零正贡献、纯负尾部）逐字适用 ⇒ 对同一持仓，**杠杆只降不升**。

**浮盈的三分处理**（缠论原文对未实现/已实现的区分是隐式的，此处显式化）：

| 利润形态 | 处置 | 原文依据 |
|---|---|---|
| 未实现浮盈 | **禁止**折算为加名义的权益基（"浮盈加杠杆"是爆仓主路径） | 31课："买股票……绝对不往上加码。该买多少一开始就应该研究好" |
| 未实现浮盈 | **允许且应当**留存于逐仓保证金内改善强平距离（等效降杠杆） | 26:26 方向一致（延长资金期限），零原文冲突 |
| 已实现利润（卖点兑现） | 进入成本基核算（cost_basis 下降直至负成本）+ 机动池；买点回复时使用，回复到**原名义** | 26:32（成本变负是唯一彻底解除）+ 26:34（"卖点的时候变少，买点的时候又回复原来的数量，但绝对不加仓"） |

**权益基判决**：名义配额记账用**恒定配额**（开仓时定，fixed），风险/保证金记账用**当前权益**（growing）。这正是权证案例的记账法——份数恒定、成本基下降——缠师在杠杆品种上的唯一正面证词已经隐含了这个双轨制。"reinvest vs fixed capital" 的问题在缠论内的答案是：**名义轨 fixed，缓冲轨 reinvest**。

配额本身的扩容只有一个合法入口：**级别升级**（操作级别变了，26:34 的级别→量映射给出新的、更大的配额上界）——见 §3.4 与 31 课的张力处理。

## 3. 小级别建仓 → 级别升级的动态过程（问题 B）

### 3.1 升级负债定理

时刻 t_k：持仓归属级别从 j 升至 j+1（在册归属机制：买点归属最高涌现层，master 出场判决）。效果链：

> P_neg：级别 j 否定价（近） → 级别 j+1 否定价（远） ⇒ D_struct 跳大 ⇒ L_max 跳低 ⇒ 同一名义 N 的保证金需求 E = N/L 跳升

**级别升级是 §2.2 单调性定理唯二的前提更换事件之一，且方向是收紧。** 直觉上"级别升级 = 走势更确定 = 该加仓"；结构上恰好相反的事情先发生：你欠保证金了。26:26 的取反函数在这里不是静态映射而是动态义务——持仓活得越久、级别长得越高，资金的期限承诺越深。

升级时刻的两个动作（一个无条件、一个留白）：

1. **无条件**：补保证金 ΔE = N(1/L_max(j+1) − 1/L_max(j))，使 L ≤ 新上限。资金出自机动池（§1.4 第三功能）。不补则强平价落入新否定价之内 = 44 课级别错配禁令的违反态（按 j+1 建仓、按强平引擎分辨率出场）。
2. **留白**：是否把名义补足到新级别配额 N_cap(j+1)。原文唯一的名义增加指令是 49:52 满仓义务（"中枢向上移动时，就应该满仓"）——它是相位法则，故名义补足的合法窗口 = 升级后的 MoveUp 相位（含新级别买点），不是升级事件本身。

### 3.2 已有仓位的归属：并入，不独立保留

段级仓位在 L1 涌现后**并入 L1 voice**（改归属标签，非平仓重开）。依据：
- 在册归属机制（买点归属最高涌现层）已是这个语义；
- 权证案例的名义连续性（"最开始多少就是多少"——名义不因结构生长而重置）;
- 独立保留 = 同一物理持仓挂两个否定价，低级别否定触发时卖出会违反高级别 hold26 义务，构造性矛盾。

并入的代价就是 §3.1 的保证金跳升——归属升级与负债同体。

### 3.3 数字推演（BTC，参数为量级示意）

设 E = 100,000 USDT，BTC 永续逐仓，mm = 0.5%。建仓 voice 顶层配额初值取原文惯例先验 1/3（26:80），目标终态 = 恒仓主仓。

| 时刻 | 结构事件 | 操作级别 | D_struct（距离+确认垫） | L_max | 名义 N | 保证金 E_j | 备注 |
|---|---|---|---|---|---|---|---|
| t₀ | 30min 段级买点 | 段级 | 3% + 0.7% ≈ 3.7% | 1/(0.037+0.005) ≈ **23.8x** | 43,300（=130k×1/3） | 1,820 | 段否定即离场；高杠杆 = 近否定价的忠实反映，非激进 |
| t₁ | 5min 中枢完成，L1 买点确认 | L1 | 8% + 2% = 10% | 1/0.105 ≈ **9.5x** | 43,300（不变） | 4,560（**+2,740 补缴**） | 升级负债定理第一击 |
| t₂ | 日线中枢，L2 确认 | L2 | 25% + 5% = 30% | 1/0.305 ≈ **3.3x** | 43,300→可于 MoveUp 相补足配额 | 13,120 | 名义补足留白：若补至 130k 则保证金 39,400 |
| t∞ | 恒仓极性（hold26 床位） | 高级别 | 75%（历史回撤包络，L3 在册） | 1/0.755 ≈ **1.3x** | 130,000（满配额） | **100,000 = 全部权益** | 自洽闭合：L_max=1.3x 时满配额 1.3E 恰好用尽权益 |

三条读出：

1. **杠杆沿级别涌现单调衰减**（23.8x → 9.5x → 3.3x → 1.3x），名义可保持恒定，保证金单调加深。终态收敛于前研 §3.4 的恒仓算术 1.3x——动态过程与静态上限在 t∞ 闭合，框架自洽。
2. **小级别建仓的结构含义** = 用近否定价买廉价的试错期权：t₀ 错了，损失 ≈ N × D_struct(seg) ≈ 43,300×3.7% ≈ 1,600（权益的 1.6%）；对了，级别涌现、保证金逐级加深至恒仓。高杠杆出现在风险最小处（否定最近处），这是框架的非平凡输出。
3. **机动池数量级校验**：t₀→t₁ 补缴 2,740 ≈ 初始保证金的 1.5 倍但仅权益的 2.7%；t₁→t₂ 补缴 8,560 ≈ 权益的 8.6%。单次升级的补缴量 ≈ N(θ_{j+1}−θ_j) ≈ N·θ_{j+1}（级别间 θ 比典型 3–5×，θ_{j+1} 主导）。以 N = E/3 初配，全程升级累计补缴 ≈ E/3 × 0.75 ≈ E/4 —— **25:168 机动资金 1/4–1/3 恰好覆盖一条完整升级链**。这是该惯例值的第一个结构性解释候选（标注：数量级吻合，非推导；θ 比与回撤包络代入的是在册典型值）。

### 3.4 31 课与升级加仓的张力（诚实标注）

31 课"绝不往上加码"与"升级后于 MoveUp 相补足新配额"存在表面冲突。消解读法：31 课语境是**同一配额内**的价格驱动加仓（"该买多少，一开始就应该研究好"——配额按操作级别定）；级别升级使配额本身扩容，新买点按新配额配置不是"加码"是新级别的首次满仓（49:52 义务）。

此读法是**解释而非逐字**，列为边界条件。在册经验侧写（L2/L3）：master 入场侧递归建仓否证——"低级别先建 + 高级别追加"的追加 buy1 事件稀缺（满仓率 1.5–20%，6/6 全负）。注意该否证的域是股票无杠杆、名义=暴露；本框架下升级的首要动作是补保证金（名义不动），与被否证的"追加名义"路径不同构——但"等新级别买点补足配额"的事件稀缺性警告直接适用：**名义补足窗口在实盘大概率不来，框架对此的预期应是 t₂ 行名义停在初配、终态低于满配额**。49:76（资金越大利润率越低、很多级别不可能全仓参与）预言的正是这个形态。

## 4. "满仓"在多层嵌套下的含义（问题 C）

前研 §2 已裁决单层定义（满仓 = 名义配额打满 + 强平价在否定价外，非保证金语句）。多层组装：

1. **逐层语义**：满仓(j) 各层独立判定，逐仓隔离。MoveUp 相位的满仓义务（49:52）作用于该相位所在层，不是账户级语句。
2. **守恒钳制**：嵌套守恒定理（§1.5）⇒ 即使每层同时满仓，ΣN_j ≡ N_top。"所有层名义加总 = 权益 × 最大杠杆"这种读法在本框架中**不可表示**——子层名义不是新增的，无从加总爆炸。
3. **账户级检查只有一条**：Σ N_j/L_j ≤ E(1−r_reserve)。由守恒 + L 层间排序，最深保证金占用出现在全部名义集中于顶层时（L_top 最低）——即恒仓终态，§3.3 t∞ 行 已验证其恰好闭合于 1.3x。
4. **反向腿（counter / MoveDown 削减对应物）**：守恒定理覆盖同方向释放-再部署。反向敞口的载体裁决在册（双向嵌套递归赋格判决：净空头走磁带上界先行否证、物理双开否决、期权为原文唯一实操空头载体），不在本框架扩张——若未来开放，其名义须挂独立配额轴，不得与多头塔共享 N_top 记账。

## 5. 实盘杠杆调整规则（问题 E）

由 §2 维护定理，调整点 = P_neg 跳变事件的穷举。每行给出无条件动作（L0）与留白动作的分离：

| # | 触发事件（引擎可观测） | P_neg 变化 | 无条件动作 | 留白/相位动作 |
|---|---|---|---|---|
| 1 | 新中枢完成，同级别上移（ZD_new > 旧 ZD） | 上移 | **无**（P_liq 已在更远的旧 P_neg 外，约束自动加强）；禁止提取保证金（单边律） | — |
| 2 | PhaseView Osc→MoveUp（Buy3 confirmed，049:60 区间开启） | ZD→ZG_new（上移） | 无 | 满仓义务检查：名义未达层配额 ⇒ 此相位是唯一合法的名义补足窗口（49:52） |
| 3 | PhaseView MoveUp→Osc（alive.seg_start>anchor / Up背驰 / settle(C')） | ZG_new→新 ZD | 重估 D_struct：若新 ZD 使 D_struct 变大且 L_current > 新 L_max ⇒ 补保证金 | 进入 osc 上减下增节律（名义在配额内波动，49:64） |
| 4 | PhaseView →MoveDown（Sell3 confirmed） | 多头前提消灭 | 多头名义清零（49:52 "不能回补"）；杠杆问题随对象消灭 | — |
| 5 | 级别升级（归属上移至 j+1） | **下移**（j+1 否定价） | **补保证金 ΔE = N(1/L_max(j+1) − 1/L_max(j))**，出自机动池；机动池不足 ⇒ 减名义至可负担（卖点窗口执行，非市价砍） | 名义是否向 N_cap(j+1) 补足 → 事件 2 窗口 |
| 6 | 卖点（osc 上沿 / 一二类卖点） | — | 名义削减 q，释放保证金 q/L 回机动池；子腿可按 `open_sub` 预算 q 开启（若该域在册为正） | 削减比例 = hold26 在册词汇 |
| 7 | 买点（osc 下沿 / 回复点） | — | 名义回复至原配额（26:34 "如数接回"），保证金按**当前** L_max(t) 计提（事件间 P_neg 已可能上移，回复腿享受更高 L_max——新开仓适用当下影子价格，不违反单边律：单边律约束同一持仓，回复是新计提） | — |

**调整方向总结**：加名义只在事件 2（相位义务）与事件 7（回复义务）；减名义只在事件 4、6（卖点词汇）与事件 5 的机动池不足分支；保证金只进不出（事件 1 禁提取），唯一流出 = 事件 6 的结构性释放。整张表无一处需要"判断"——每行都是引擎已有可观测量（PhaseView、中枢完成、归属升级、买卖点事件流）的确定性函数。

## 6. BTC 合约具体计算示例（静态参数版）

声明：本节为 L0 算术 × 在册结构典型值，**未读取实时走势**；实时数值需引擎在当前 bar 输出 (PhaseView, ZD, ZG, θ_q(j−1), 归属级别) 五元组后代入。资金费率取典型基准 0.01%/8h ≈ 11%/年。

**场景**：E = 100k USDT。假设当前 BTC 价格 c = 100,000，引擎读数：日线级别 alive 中枢 [ZD=86,000, ZG=92,000]，PhaseView = Osc，θ_q(j−1)（4h 层）≈ 4%，持仓归属 = 日线层，风险限额低档 mm = 0.5%。

```
P_neg = ZD = 86,000（Osc 相）
D_struct = (100,000 − 86,000)/100,000 + 0.04 = 0.14 + 0.04 = 0.18
L_max  = 1/(0.18 + 0.005) ≈ 5.4x
```

- 该层若为操作床位（非恒仓主仓）：名义上限 = 5.4 × 分配保证金；强平价校验：L=5.4 ⇒ P_liq ≈ 100,000×(1−1/5.4+0.005) ≈ 82,000 < 86,000 ✓（注意 P_liq < P_neg 留有 θ 垫，因为垫已并入分母）。
- 若 PhaseView 切 MoveUp（Buy3 于 92,000 上方确认，新中枢 ZG_new = 95,000）：D_struct = 5% + 4% = 9% ⇒ L_max ≈ 1/0.095 ≈ 10.5x —— 相位转移自动放宽上限，但单边律禁止已有持仓提保证金，放宽只作用于事件 2 的名义补足腿。
- **恒仓主仓（hold26/fusion_t 床位）不适用本节算术**：其 D_struct = 穿越义务的历史回撤包络 ~75% ⇒ 1.3x，载体裁决已在册（现货 / 1x 永续逐仓——合约对恒仓零正贡献，费率 11%/年×L 与强平双纯负）。本节的 5.4x/10.5x 是**日线层短差/配对腿**的存活上限，且该域是否开腿由在册 alpha 判决先行（负 alpha 域上讨论杠杆是范畴错误，前研 §5.1）。
- 费率摩擦核验（35:30 门的合约扩展）：日线层持仓典型周期数周，11%/年 ≈ 0.2%/周 × L。L=5.4 时 ≈ 1.1%/周权益流失，对 θ_q(日线)≈6–14% 的振幅：单次震荡兑现 ≈ θ_q × L ≈ 32–75% 权益，费率占比 <5% ✓ 通过成本门；若持仓拖长至月级，费率项把有效兑现压薄 ⇒ 成本门应以**预期持仓期 × 费率 × L** 进入 friction_RT（开放实装面）。

## 8. 结果包（六要素）

1. **结论**：三元组的完整约束方程组为——每层 L_j ≤ 1/(D_struct(j,t)+mm)（零参数影子价格）、N_j 受容纳量与级别偏序约束且塔内守恒于顶层配额（嵌套守恒定理）、E_j = N_j/L_j 是派生量（分配问题被消解）。动态核心是升级负债定理（级别升级 ⇒ 保证金跳升，先于任何加仓考虑）与维护定理（P_neg 事件间常数 + 单调非降 ⇒ 杠杆维护纯事件驱动，七事件表 §5 穷举且每行为引擎可观测量的确定性函数）。浮盈三分法：未实现浮盈禁加名义、应留存改善强平距离；已实现利润走成本基；名义轨 fixed、缓冲轨 reinvest。唯一真自由度 = 顶层配额比例（53:34 留白）。
2. **定义依据**：26:26（有限期资金，轴心）、26:34（量唯一控制变量 + 级别→量偏序 + 权证恒仓记账）、31课（配额入场前固定）、49:52/64（相位前提-否定结构 + 满仓义务）、53:34/49:76/26:36（容纳量与留白）、35:30（成本下限对偶）、44:48（级别错配禁令 = 强平的存在论）、53:56（确认垫的次级别分辨率）、25:168（机动资金）。全部承自前研逐字核验，本文零新引文。
3. **边界条件**：(a) 嵌套守恒定理依赖 hold26 释放-再部署语义——若未来结算的层内 C 机制（NRF 分岔）允许子腿名义独立于父腿释放，守恒被破坏，§4 须重审；(b) §3.4 的 31 课消解读法是解释非逐字——若源头审计裁定 31 课禁令覆盖级别升级语境，则名义补足窗口（事件 2）关闭，配额终生钉死于建仓初值；(c) 维护定理依赖逐仓 P_liq 固定——若交易所逐仓实现将未实现亏损自动侵蚀维持保证金水平（不同所规格差异），P_liq 漂移，须加逐所规格核验；(d) §3.3 机动池校验用的 θ 比 3–5× 与回撤包络 75% 是在册典型值——标的或级别结构变化时数量级结论须重算；(e) MoveDown 相多头 P_neg 无定义依赖"Sell3 后不回补"的强读法——若 P6 相位机最终结算的 MoveDown 语义允许残余多头，第 4 行须补否定价定义。
4. **下游推论**：(i) §5 七事件表可直接实装为 fusion 引擎的 margin-control 层——全部触发量（PhaseView、中枢完成、归属升级、买卖点事件）已是在册 marshal 面，新增的只是 L_max 计算与机动池记账（纯下游，零信号层改动）；(ii) friction_RT 须扩展为持仓期×费率×L 的合约形态（§6 末）；(iii) 回测裁决域收窄为单参数扫描（顶层配额比例）——53:34 留白的实证成本从多维降为一维；(iv) §3.3 的机动池-升级链数量级关系给出 25:168 惯例值的可检验预测：若回测中升级补缴累计显著超过 E/3，则 1/4–1/3 先验不足，须升 1/2（25:168 自带的恶劣分支）。
5. **谱系引用**：090（声明膨胀——§3.4 解释与逐字的区分标注）、136（成本收益消解禁止——升级补保证金是无条件动作）、161（务实否定——单边律不因"操作麻烦"松弛）、231（形式化有效域——全文 L0 标注，§3.3/§6 数字为典型值代入非验证）、435/436（Kelly 不引入，承自前研）；在册判决：hold26 恒仓极性、master 入场侧递归建仓否证（§3.4 域差异引用）、master 出场归属（§3.2 并入依据）、BC 配额架构（53:34 留白同状态）、双向嵌套递归赋格（§4 反向腿边界）、BTC 杠杆实验 7/7（杠杆下游于信号层）。无既有"杠杆三元组"谱系条目——前研与本文构成该领域的两步结算序列，若结算为定义须走谱系写入。
