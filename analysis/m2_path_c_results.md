## 结果包六要素

**结论**：见上述对比表（E vs E+C vs Buy&Hold）+ C 路径诊断。

**定义依据**：
- 六条边 = 主边 ES/$,GC/$,CL/$（生成树）+ 派生边 ES/GC,ES/CL,GC/CL（资产三角的弦），各自独立跑 RecursiveOrchestrator。
- 单边 σ = level-0 settled-move 方向（缠论走势方向，31 课盘整→FLAT）；买卖点 = 17/20/24 课 type1/2/3（candidate/confirmed）。
- 圈闭合纠错 = K4 每资产对 3 条估计路径多数表决（k4_path_c.closure_consensus）。
- 联合读数 = ES-incident 边（ES/$,ES/GC,ES/CL）方向票+买卖点票之和（k4_path_c.joint_reading，target=EQUITY，OKLO 是动产）。
- E = run_swing_trading(MODE_NONE)：底背驰买入、L2 趋势顶背驰清仓，纯多头。

**边界条件**：
- 六边建立在 ES/GC/CL 公共时间戳交集上，圈闭合恒等式价格层精确成立。
- 派生边 OHLC 用比值包络（h=numH/denL, l=numL/denH）。
- 投票权重（type1>type2>type3、confirmed>candidate）是 [新缠论:选择] 可调常数；改权重会移动 favored 临界 → 翻转门控结果。
- 门控仅作用于入场，不强制平仓（E 引擎自身 L2 顶背驰离场）。
- 无前视：date X 仅用 date<X 的 C 路径 favored（滞后一日）。

**下游推论**：
- 若 E+C < E：缩小'六边联合读数对单股票择时有价值'的有效域——与 M2 极性压缩路径同向的否定性结论（门控在牛市削减暴露）。不得包装为 C 路径'有效'。
- 若 E+C > E 且优于 M2 路径：六边不压缩（保留个体身份 + 圈闭合纠错）相对极性 S 压缩有信息增益——但需 L3 多标的/多时段交叉验证才可声明。
- 圈闭合 dissent>0 的天数量化了'六边冗余 vs 三边推导'的检错增益（结构性产物，独立于收益方向）。
