# MOS 卖点视角分析：上涨走势如何被逐级 settle 掉

> 脚本：[`analysis/mos_sellpoint_settle.py`](mos_sellpoint_settle.py)　数据：[`analysis/data_cache/mos_sellpoint_settle.json`](data_cache/mos_sellpoint_settle.json)
> 数据源：yfinance MOS 日线 max（1988-01-26 → 2026-05-29，n=9658）　当前价 **$23.90**
> 视角：与买点分析（"下跌何时结束"）相反——本文看**"上涨何时结束了"**（上涨分量被回调逐级 settle）。

## 0. 数据纠正（必读）

用户假设 MOS ATH ≈ 2022 年 $78。**真实数据：MOS 历史最高收盘 = 2008-06-17 的 $161.08**（农产品超级周期顶），盘中高 $163.25（2008-06-18）。**$78.15（2022-04-18）是次级峰**（俄乌钾肥行情）。

因此本文跑两个口径：

| 口径 | 起点 | 窗口内全局上涨顶 | 用途 |
|------|------|----------------|------|
| **W_full** | 1988（全历史） | 2008 $161.08（超级周期顶） | 完整级别层级，看 $78 在全史中的位置 |
| **W_cycle** | 2020-03（COVID 低 $7 起） | 2022 $78.15 | 隔离 $7→$78→$24 完整涨落弧 = 操盘关心窗口 |

## 1. 方法：卖点是买点的严格对偶（取负价）

`OnlineMergeTree` 追踪 **sublevel set**（谷=下跌分量，靠**反弹** settle）。把价格序列**取负** `q = −p` 喂进同一棵树，得到精确对偶（superlevel set ≅ 取负的 sublevel set，非 workaround）：

| 买点视角（原） | 卖点视角（取负后） |
|--------------|------------------|
| 谷 = 下跌分量诞生 | **峰 = 上涨分量诞生** |
| 反弹 settle（价涨破屏障） | **回调 settle（价跌破屏障）** |
| settle = 那段下跌确认结束 | **settle = 那个级别上涨走势确认结束** |
| 全局分量 = 历史最低谷（永不被反弹 settle） | **全局分量 = 历史最高峰（永不被回调 settle）= 最大牛市结构残余** |
| alive 下跌分量 = 跌势未确认结束 | **alive 上涨分量 = 牛市结构残余（顶未被确认结束，可能再创新高）** |

persistence（幅度）与 gap 量值在取负下不变。**全局分量翻转**是关键：卖点视角下，历史最高峰永不被回调 settle，只在序列终止封顶——把它伪装成"跌到 X 即 settle"= 声明膨胀（090号 / formalization-validity-domain）。

> settle 条件的精确形式：一条上涨腿（峰 P）被 settle，**不是**"价格跌破 P"，而是"价格跌破该腿与相邻结构之间的**回调屏障谷**"（< P 的某个低点，elder rule 下该腿作为 younger 被合并）。这正是缠论"顶分型需后续 K 线确认"的拓扑形式。

## 4. 操盘含义

1. **次级别卖点已逐级兑现**：日线、周线/月线级的每一波反弹涨势都已被随后下跌 settle。最近的是 **2026-05-08 周线/月线级**（2025 年 $22→$37.8 反弹确认结束）。
2. **价格回到 2022 涨腿的启动平台**：$78 这条超级腿从 **2021 平台 $23.67（2021-01）** 启动；当前 $23.90 正好回到启动平台，2026-05-19 以 $21.40 **首次略破**。结构上这是"超级牛市腿回踩启动位"。
3. **最高级别未 settle = 双刃**：
   - 牛市未被彻底否定（年线腿 alive）→ 理论上仍可能有超大级别反弹；
   - 但要**确认牛市彻底终结**，需一个反向下跌结构幅度 > **$71.14**（W_cycle）/ 跌破 **$7.01**（W_full）。当前回撤幅度（$78→$21.4 ≈ $56.7）尚未达到否定全局顶所需。
4. **当前 alive 的牛市残余**：仅全局顶 $78 + 14 条 30 分级小腿。**没有任何日线及以上级别的 alive 上涨残余**——意味着任何反弹若要成立，必须从 30 分级重新逐级向上构筑，目前无中大级别向上结构支撑。

## 六要素结果包

1. **结论**：MOS 从 $78 下跌中，**60分/日线/周线-月线级的上涨走势已逐级全部 settle（确认结束）**，最近一次是 2026-05-08 的周线/月线级（$37.81→跌破$22.76）。唯一仍 alive 的大级别上涨残余 = 全局顶 $78（年线/超级周期，永不被回调 settle）+ 14 条 30 分级小腿。价格 $23.90 已回到 2022 超级腿的 2021 启动平台并略破。

2. **定义依据**：
   - settle 判据 = `a_online_persistence` §10 因果 settle 定理（merge tree 合并配对在右侧出现 ≥ 屏障价时因果确定），取负对偶后 = 上涨腿被回调跌破屏障谷而 death 确定。
   - 级别 = `a_level_detection.adaptive_gap_boundaries`（MAD 离群 log-gap，n_mad=3，先经 ATR τ 噪声过滤，L0 稳健统计）。
   - 全局分量永不 settle = `a_settle_trigger` 顶部约束（栈底 elder，settle_price=None）。

3. **边界条件（结论翻转条件）**：
   - 若 MOS 反弹重新逐级构筑日线及以上 alive 上涨腿 → "无中大级别向上残余"结论翻转。
   - 若价格跌破 $7.01（W_full）/ 反向下跌结构幅度 > $71.14（W_cycle）→ 全局顶 $78 被否定，"牛市最高级别结构残余仍在" 翻转为"牛市彻底终结"。
   - 若改用不同窗口起点（如 2015 起），窗口全局顶与级别带边界会改写阶梯（窗口依赖性，已在两口径间显式对照）。
   - settle 判据基于 close 序列；改用盘中高低点会微调屏障价（数据口径边界）。

4. **下游推论**：若结论成立——所有日线及以上向上结构已 settle、仅余永不 settle 的全局顶——则任何看多的次级别买点（区间套向上收敛）目前**缺乏中大级别向上结构支撑**，需从 30 分级重新逐级确认；卖点侧则已逐级兑现至周线级，下一个可被否定的目标是全局顶 $78（需跌破 $7 / 反向幅度 > $71）。

5. **谱系引用**：
   - 取负对偶 = OKLO 买点 settle 阶梯（[`oklo_settle_ladder.py`](oklo_settle_ladder.py)）的方向反转，复用同一 merge tree，未发生新的概念分离。
   - 全局分量诚实标注遵循 090号（声明膨胀禁止）/ formalization-validity-domain（有效域 ≠ 定义域）。
   - 级别↔周期映射 L2，需 MACD 力度确认充分性（521号：纯拓扑动量不存在）。

6. **影响声明**：新增 [`analysis/mos_sellpoint_settle.py`](mos_sellpoint_settle.py) 与 [`mos_sellpoint_analysis.md`](mos_sellpoint_analysis.md)、缓存 [`MOS_1d_max.json`](data_cache/MOS_1d_max.json)、[`mos_sellpoint_settle.json`](data_cache/mos_sellpoint_settle.json)。**未改动任何 `src/` 模块或既有定义**——纯复用现有 A 系统接口（OnlineMergeTree / settle_triggers / score_buypoint / detect_zhongshu）。
