## 0. 问题与核心命题

BTC vs BH 结构分解（L3，`analysis/btc_vs_bh_structural_analysis.md`）判决：V2oa25 系对 BH 的
−750pp 赤字**全部**来自 top5 踏空 gap（空仓期错过牛市主升），且短差形式的并发赋格结构上不可达
（voice 只在 master LONG 期存在）；HoldTrend 门双向失效（牛市放行 15% / 2025-26 恒拦截）。
判决给出的解法方向 = **仓位级别分层**。E 版升级别出场 BTC +2194% 是存在性证明。

NRF 的核心命题（编排者原话的形式化）：

> "一个趋势级别的反向线段在次级别，可能就是一个直接的空单。而反向线段内部的反向线段，
> 又在次次级别是一个直接的多单。然而在高级别的视角看，次级别直接的开单对他只是一个短差。"

即：**同一笔操作在级别 k 是该级别的直接买卖点操作，在级别 k+1 的账目上是一次降成本短差**。
这是符号交替塔 (−1)ⁿ 的存在论：

```
L_top（最高涌现级别）: 持本级别配额，只响应本级别买卖点 → 暴露穿越低级别 gap（positional）
  └ L_top−1          : 操作父级别趋势的反向段 = 本级别空腿 = 父层账目上的短差
       └ L_top−2     : 操作上层反向段内部的反向 = 本级别多腿 = 上层账目上的短差
            └ …      : 直到 35课成本门终止（递归深度从结构涌现）
```

每一层既是 positional（持本级别配额、按本级别买卖点进出）又是短差（对父层降成本）。
这不是两个架构，是一个递归塔的两个视角。

## 1. 缠论原文依据（逐机制课号锚定，引文均已核对原文文件）

### 1.1 级别 = 资金量轴 — 26课

> "基本只和买卖量有关，日线级别的买卖量当然比1分钟级别的要多多了，本ID可以用更大的量去参与买卖。"（26课）

每层对应一个级别、控制一份配额；大级别配额大（吃趋势主干），小级别配额小（短差）。

### 1.2 操作的立体性 = 嵌套递归的直接原文授权 — 35课

> "制定了相应级别，是否按照次级别以下进行部分操作，那是操作风格问题，而实际上是应该安排这种操作的，
> 特别当进入一个你的操作级别的次级别盘整或下跌……如果你的操作级别很大，那么其次级别的次级别，
> 也可以用来部分操作的。这样，整个操作就有一定的**立体性**，从而更降低其风险。"（35课）

"次级别的次级别也可以用来部分操作" = voice spawn 子 voice 的原文形态；"部分操作" = 配额分层。

### 1.3 禁止低级别信号清高级别仓位 — 44课（塔的脊柱）

> "你不可能按30分钟操作，而一见到1分钟顶背驰就全部扔掉，这就变成按1分钟级别操作了。"（44课）
> "小级别顶背驰引发大级别向下的必要条件是该级别走势的最后一个次级别中枢出现第三类卖点。"（44课，
> 注意原文明示"只有必要条件，而没有充分条件"）

L_k 的卖点只触发 L_k 配额的操作，不触及 L_{k+1} 的持仓——§3 master 级别配额门的依据。

### 1.4 操作对象 = 同级别分解段；各级别分解规则独立 — 38课

> "所谓同级别分解，就是把所有走势按一固定级别的走势类型进行分解。"（38课）
> "同级别分解的次级别分解是否也是同级别分解的。答案是，不需要。"（38课——嵌套各层规则独立的许可）
> "你可以设定某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作……
> 就如同开了一个分区卷钱的机械。"（38课——多声部配额分层的原文出处）
> "向上段的运作，都是先买后卖的。一旦向上段的运作结束后，就进入向下段的运作。向下段的运作刚好相反，
> 是先卖后买。"（38课——每层 voice 的两相 FSM）

操作对象的范畴声明（前置调研 `trend_counter_segment_research.md` §1.1，L0 考据）：38课"段"=
**同级别分解下的该级别走势类型段**，不是特征序列法线段。工程近似 = 引擎 ladder k 的走势对象
（segment/move/recL*），近似声明必须显式携带（避免重演分型模式的范畴错位）。

### 1.5 操作级别的相对性：高级别操作无须理会低级别震荡 — 47课

> "如果是按日线级别操作，那这些震荡根本无须理会。如果真按日线操作的，就应该从1000多点一直拿到现在，
> 因为日线级别的卖点并没有出现，等出现再说。而用周线级别操作的大资金，那就更无所谓了。"（47课）

47课从正面给出 §3 的语义：高层配额的去留只看高层自己的买卖点。BTC 踏空的原文诊断正是
"按段级卖点清掉了本应按更高级别持有的仓位"。

（统计侧注：记忆中"47/53 分割跨资产不变"指 L3 统计——趋势内反向运动振幅总量约 47% 以同级别
反向线段存在、53% 藏在顺向线段内部的反向笔里（`trend_counter_voice_design.md` §2.2，三标的差
<2pp）。后者结构上不可安全捕获，是 voice 栈理论暴露上限的折扣，与课号 47/53 是两件事，此处显式消歧。）

### 1.6 低级别买卖点参与中枢震荡 + 显微镜原则 — 53课

> "在第二、三买卖点之间，都是中枢震荡，这时候，是不会有该级别的买卖点的，因此，如果参与其中的买卖，
> 用的都是低级别的买卖点。"（53课——子 voice 用 k−1 级别 BSP 事件的原文授权）
> "当你用一个级别的显微镜时，就等于先把次级别的当成线段了，也就是说次级别不在该级别的观察中。"（53课）
> "而在趋势的情况下，一般小级别的买卖点并不一定要参与，但如果技术特别好或大资金，同样可以参与，
> 这只是为了提高资金的利用率，加快成本变0或增加筹码的过程。"（53课——短差目的函数：非独立利润源）

显微镜原则 = C1 级别隔离的原文形态：每层 voice 只消费本层判据，次级别结构委托给子 voice。

### 1.7 中枢向上满仓、三卖不回补 — 49课

> "中枢向上移动时……就应该满仓，这才是最正确的仓位。而在围绕中枢差价时，在中枢上方仓位减少，
> 在中枢下方仓位增加……一旦出现第三类卖点，就不能回补了。"（49课）

每层配额的 RIDE 语义 = 49课满仓；49课豁免按级别局部化（k 层禁令不约束 k−1 层，53课明文授权
次级别参与——`trend_counter_voice_design.md` 已消解此张力，与 275号局部依赖原则同构）。

### 1.8 递归终止 = 成本门 — 35课

> "级别越小，平均的买卖点间波幅也越小，因此，那些太小的级别，不足以让交易成本、交易误差等
> 相对买卖点间波幅足够小，这样的操作，从长期的角度看，是没有意义的。"（35课）

递归不是无限的，被经济约束截断——深度由数据涌现，不是外部参数。

### 1.9 笔 = a0（递归构成性例外）— 77/78课

> "线段必须至少有三笔"（77课）；"都把线段当成一个没有内部结构的基本部件"（78课）

线段是最低的走势类型部件；笔不进入"走势类型→中枢"递归 → **塔的存在论 floor = segment
（ladder 2 = FIRST_BSP_LADDER），bi（ladder 1）不可作操作床位**。与"反向段多级别 voice 栈设计"
结论（笔级不可开，结构缺失）和"递归赋格深度1"bi 级 a0 例外一致。

## 2. 六机制架构规格（每机制：触发条件 / 状态机 / 数据流）

### 2.1 级别涌现（非外部参数）

**已就位，零新机制**。引擎 `RecursiveOrchestrator` 逐 bar 生长 bi→seg→zhongshu→move→recL2…，
marshal 进 `SignalTape`（`tape.rs`）：`bsp_events[ladder]` / `dir_flips`（稀疏方向翻转行）/
`trend_flips`（尾 move kind 翻转行）。ladder 编码 `0=bar 1=bi 2=segment 3=move(L1) 4..=recL2..`。

- **涌现集** `A(t) = { k ≥ FIRST_BSP_LADDER : CenterBook 在 k 有存活中枢 }`——由 BSP 事件流
  维护（`center_book.rs`），逐 bar 只读。深度 = A(t) 的最大元，由数据决定（OKLO 447K 实测 L4）。
- 交易层只消费不重新读出级别结构（级别结构单一真相源 = 引擎递归塔）。

### 2.2 操作对象 = 趋势级别反向段

每层 voice@k 的操作对象：**父层（k+1）趋势走势内部的、k 级别的反向走势段**。可观测判据（无前视）：

| 要素 | 数据流 | 判据 |
|------|--------|------|
| 父层方向 | `dir_flips` 滚动态 `dir_state[k+1]` | 38课"向上段/向下段"时相 |
| 父层趋势态 | `trend_flips` 滚动态 `trend_state[k+1]` | 17课趋势定义（≥2 同向中枢）；非趋势 ⇒ 反向段对象不存在 |
| 反向段存在陈述 | `bsp_events[k]` confirmed type1（方向与父层反）∨ 盘背事件 | 38课"内部结构的背驰或盘整背驰结束点"——力度判据，段终结前可见 |

进出点必须是 k 级别**自己的买卖点事件**：不是 bar 末方向行翻转（分型递归否证死因）、
不是 CenterBook 域查询（递归赋格深度1 域空型死因）、不是次级别任意买点（38课循环 voice 否证死因）。

### 2.3 voice spawn 子 voice

**基础设施已存在**（`level_operating_unit.rs` SubLou：child / cascade_close / 符号交替塔 /
RevPath 路径键），当前休眠（`rev_sub_depth: 0` 默认）。NRF 的 spawn 链：

```
出生触发（全部合取，同 bar 求值序即守卫序）：
  G1 voice@k 的 REV 腿开放（自身级别确认后：confirmed type1/盘背开腿已成交）
  G2 k−1 ≥ FIRST_BSP_LADDER          （存在论 floor，§1.9）
  G3 quota(k−1) > 0                   （35课成本门，§2.4/§2.6——经济归零层不实例化）
  G4 path.depth() < rev_sub_depth 上限（深度预算；预算只是安全阀，期望由 G3 先触发）
⇒ get_or_insert SubLou(k−1, parent_path.child(k−1))   （惰性实例化，不预建）
```

子 voice 方向 = (−1)·父腿方向（符号交替塔：奇数深度反弹腿先买后卖，偶数深度短差先卖后买）。
子 voice 开腿 = **k−1 级别 BSP 事件驱动**（`bsp_events[k−1]` confirmed type1 三岔镜像 ∨ 盘背，
现行 `SubLou::open_trigger` 形态保留）——这是子腿严格形式的唯一合法触发源（task 3 实现约束）：
非中枢域（Zhongshu 模式：递归赋格深度1 否证有效域 = "CenterBook 中枢 × 离开段"，74% 无中枢拒）、
非分型（Fractal 模式：有效域 = 震荡 regime，38课原文预言，强趋势 OKLO −73.8pp）。
全部触发为**信号型**（事件 bar 即行动）——不附加任何"次级别再确认"（SC 六位否证：confirmed
已含次级别完成判定，再确认 = 纯延迟）。

### 2.4 结构涌现配额（非固定 slice）

配额由涌现级别集 + 中枢振幅决定，公式精确如下（主方案，26课"级别=买卖量"的连续化）：

```
amp_k  = (ZG_k − ZD_k) / c          k ∈ A(t)，取 CenterBook 该层最新存活中枢
gate_k = [ amp_k ≥ 2 × friction_rt ]  （35课成本门：不过门的层配额归零）
quota_k = amp_k·gate_k / Σ_j amp_j·gate_j   （归一化；Σ=0 ⇒ 全部归 A(t) 最大元）
```

- **基础设施已存在**：`allocator.rs::SizeAllocator` 正是 amp 归一化分配（version 门控避免逐 bar
  churn）；NRF 只需把它的定义域从 osc 声部扩展到层配额。
- **重算时机** = `CenterBook.version` 变化 bar（结构事件触发，非逐 bar）。
- **消费时机** = 腿开/闭 bar：quota 是开腿规模上限，**不再平衡已开腿**——与 26课"绝对不加仓"
  相容（配额变化只约束未来开腿，存量腿按其开腿时配额持有到自身闭腿事件）。
- **涌现性的两个来源**：层数 |A(t)| 来自级别涌现（2.1），层间权重来自中枢振幅（结构量），
  归零来自成本门（35课）。没有任何固定百分比参数。
- 顶层中枢振幅最大 ⇒ quota 最大 ⇒ 自动实现"顶层持续暴露穿越 gap"（BTC 解，§3）。
- 消融轴（预注册，task 4）：A=等暴露+成本门（`ledger_cost_gate` VLc 已有 L2 落地，作对照）、
  B=本节振幅加权（主方案）。两臂同守卫同磁带。
- 诚实声明：53课明文将"仓位调配控制的问题"留白（"这问题以后再说"，且后续仅 49课给出中枢
  震荡上减下加的定性语义）——**配额公式没有原文逐字依据**，是 26课买卖量轴 + 49课定性语义的
  工程合成，标注 L0 推导，由 §7 判据裁决。

### 2.5 子 voice 生命周期

| 事件 | 触发（精确） | 动作 |
|------|------|------|
| 出生 | §2.3 G1∧G2∧G3∧G4 | 惰性实例化 SubLou(k−1)，槽键 `SlotKey::rev_path(home, path)` |
| 开腿 | `bsp_events[k−1]` confirmed type1（符号交替方向）∨ 盘背 | `open_sub`，规模 = quota(k−1)，同股数记账 |
| 闭腿 | hard type3 > pre type3 > 同锚 type1 > 边界触线（现行优先序） | 平腿；闭腿是义务，门永不挡闭腿（osc 僵尸腿判决） |
| 死亡（正常） | 父腿闭合（父层反向段终结） | `cascade_close_children`：子树全腿强制平仓后回收节点 |
| 死亡（强平） | master 该层配额槽清算 ∨ eod | 同上级联 |

层内守恒：子层开腿股数 = 闭腿股数；对父层账目 = 一次降成本短差（cost_basis 下移），
父层净暴露不变（区别于递归建仓：子层不承载暴露构建）。

### 2.6 35课递归终止（三范畴，全部从结构/数据读出）

```
存在论：k−1 < FIRST_BSP_LADDER（bi=a0，77/78课）          → 节点不实例化
经济  ：amp_{k−1} < 2×friction_rt（35课成本相对波幅）       → quota=0，G3 拒
结构  ：A(t) 在 k−1 无存活中枢（级别未涌现）               → k−1 ∉ A(t)，对象域空
```

递归深度 = 三门联合的涌现结果。`rev_sub_depth` 仅作 RevPath 容量安全阀（MAX_REV_DEPTH=4），
不是深度的决定者——若实测深度恒由预算截断而非成本门截断，即判"深度未涌现"（§7 否证侧）。

## 3. master 出场级别错配修复：段级 sell1 只触发段级配额

**死因（BTC 结构分解 L3）**：在册 master 是单一全仓 FSM——entry 级（段级）confirmed sell1 ⇒
全仓清算。段级卖点把本应按更高涌现级别持有的仓位一并清掉 ⇒ top5 踏空 gap = 全部 750pp 赤字。

**修复（44课/47课的机械化）**：master 从单一全仓 FSM 改为 **per-level positional 槽集合**。

```
入场（零改动，避开入场侧否证）：
  区间套确认 bar 一次性满仓（在册 O0 路径，同 bar 同价）；
  NRF 变体下仅记账拆分：按 quota_k 把满仓拆进 SlotKey::main(k)，k ∈ A(entry_bar)。
  暴露不塌缩（开仓 bar 即满仓）——与 entry_mode=Recursive（等待追加 buy1，满仓率 1.5-20%，
  6/6 全负）的可证伪区分点：NRF 入场 bar 满仓率恒 100%。

出场（每层独立，44课）：
  ∀k: sig.sell1.get(k) ⇒ MasterExitSignal::from_sell1_row(...) 只清 SlotKey::main(k)。
  更高层槽继续持有，直到各自级别的 sell1。532号类型隔离保留（每层独立构造布尔行信号，
  无事件流构造路径）。空仓 ⇔ 所有层槽各被本级别 sell1 清算。

涌现归属（与 emht 合成，可选轴）：
  槽的级别归属可按 Emergent 判据动态上移（dir_state 连续 Up 的最高层 ∧ anchor≥entry_bar）
  ——emht 五标的全正（BTC +170.8pp）是涌现归属可行的存在性证明；NRF 把它从
  "整仓出场级别"细化为"逐槽归属"。
```

数据流：只消费已有磁带行（sell1 LadderMask / dir_flips）——**不需要新引擎事件**。

## 5. 实现落点（task 3 直接消费）

**改三处，不改引擎层**（全部磁带行已存在：bsp_events / sell1 / dir_flips / trend_flips）：

1. **`config.rs`**：新类型 + 变体注册
   - `pub enum MasterQuota { Full, Emergent }`（Full=在册全仓单槽；Emergent=§2.4 配额分槽）
   - `pub enum ExitScope { Whole, LevelQuota }`（Whole=在册全清；LevelQuota=§3 段级 sell1 只清段级槽）
   - `OrganicConfig` 增字段 `master_quota: MasterQuota`（默认 Full）、`exit_scope: ExitScope`
     （默认 Whole）、`nrf_sub: bool`（默认 false，开启 §2.3 spawn 链）
   - `variant()` 注册 `NRF1`（= 基线 + Emergent + LevelQuota + nrf_sub + rev_sub_depth=1）
     及消融臂 `NRFq`（配额轴 A 对照）
2. **`runner.rs`**：master 循环改造
   - 入场 bar：`MasterQuota::Emergent` 时按 quota_k 拆 `SlotKey::main(k)`（同 bar 同价记账拆分）
   - 出场：`ExitScope::LevelQuota` 时 sell1 LadderMask 逐层匹配清对应槽（每层独立构造
     `MasterExitSignal::from_sell1_row`，532号类型隔离不破）
   - capability guard：`nrf_sub ∨ Emergent` 要求 dir_flips/trend_flips 行在磁带（缺行 fail-fast）
3. **`level_operating_unit.rs`**：spawn 守卫改造
   - `step_sub_tree` 的实例化守卫从纯深度预算改为 §2.3 G1-G4 合取（G3 接 SizeAllocator 层配额）
   - `SubLou` 开闭谓词零改动（现行 BSP 事件三岔镜像即 §2.3 严格形式）

`types.rs` 不改（RevPath/SlotKey::main(k) 容量与编码已够）；`allocator.rs` 复用（定义域扩展由调用方传参完成）。

### O0≡P5 零接触守卫（强制，新变体注册的语法前提）

所有新轴默认值 = 在册行为（`Full` / `Whole` / `nrf_sub=false`）。注册 NRF1 后必须重跑在册守卫：
基线变体（V0/P5/V2oa25 全谱）在同一磁带上的 trades/equity/计数器输出**逐位不变**（tape_fp 指纹
+ 逐字段 tape-equality，磁带混表事故先例）。任何基线漂移 = 实现违规，不进入回测评估。

## 8. 结果包（六要素）

1. **结论**：NRF = 符号交替递归塔——每层既持本级别配额（positional，按本级别买卖点进出，
   §3 级别配额门）又对父层做短差降成本（§2.3/2.5 子腿）；配额 = 涌现级别集上的中枢振幅归一化
   ×35课成本门（§2.4）；floor=segment（笔=a0）；深度由三范畴终止涌现（§2.6）。实现 = 三文件
   改动 + 两新枚举一新标志，零引擎改动，O0≡P5 守卫强制（§5）。
2. **定义依据**：26课（级别=买卖量）、35课（立体性=嵌套操作授权；成本相对波幅=递归终止）、
   38课（同级别分解段=操作对象；分区卷钱机械=配额分层；各级别分解独立）、44课（禁低级别清
   高级别仓+小背驰大转折必要条件）、47课（操作级别相对性：日线操作无须理会低级别震荡）、
   49课（中枢向上满仓、三卖不回补）、53课（低级别买卖点参与中枢震荡+显微镜原则+短差目的函数）、
   77/78课（笔=a0）。全部引文已核对 `docs/chanlun/text/blog/` 原文文件。
3. **边界条件**：(a) 操作对象是"同级别分解段"的工程近似（ladder 对象），若裁决要求严格原文
   对象则 §2.2 判据需在递归层重做；(b) 配额公式无原文逐字依据（§7.1），判据 1/4 否证即翻转；
   (c) 子腿轴独立可否证（§7.2），其否证不连带 §3 级别门；(d) 高层确认滞后的 MDD 成本超过踏空
   收益时核心命题翻转（判据 1 否证侧）；(e) 49课满仓语义仅在中枢向上移动且非盘背时成立；
   (f) 振幅配额依赖 CenterBook 中枢口径，中枢定义变更使 §2.4 全部数字失效。
4. **下游推论**：(a) BTC 踏空的解从"门的修补"（HoldTrend 点态门已双向失效）转为"对象域分层"
   ——状态范畴胜点态门的第六例候选；(b) master 从单 FSM 变 per-level 槽集合，在册全部
   master 出场轴（HoldTrend/emht/SCm）需重述为槽级语义；(c) SizeAllocator 定义域扩展后 osc
   配额与层配额共享振幅口径，需在实现时声明两者归一化分母独立；(d) 磁带指纹不变（零新行），
   在册回测 JSON 无需重跑——只有新变体新增输出。
5. **谱系引用**：532号（出场/开腿双通道类型隔离）、267号（多重赋格原文）、275号（局部依赖

   标注）；记忆谱系 14 条见 §4 差异表首列。未发现"层配额涌现"专门谱系——§2.4 是新概念区，
   若实装产生定义分离应新开谱系记录。
