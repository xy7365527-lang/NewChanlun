## 修改内容（两处，零 flag）

### 修改1：根翻转（第23环字面：出场=翻转=新建仓）

v2：根 confirmed 卖点 ⇒ 全链清算 ⇒ 空仓等待下一个买证据（物理暴露
0.37-0.53）。v3：根走势完美（confirmed 反向点@root）⇒ 全链清算 ⇒

- 根空头 = **真实 1x 逐仓空头**（保证金 = 锁定现金 = units×basis，
  损失有界于保证金，A 强平为物理事件）[镜像推导]。
- 正则化：空根链与长根链完全镜像——物理暴露 = f(尾方向×根方向)，
  同向满暴露（长根 +1 / 空根 −1）、异向 flat（0）；根空头可 spawn
  子多 voice（物理 = 回补平空，同一笔交易双层身份的镜像），子多再
  spawn 孙空（重开空头）。实装为统一 `phys_align`。

  （再入场词汇从"买证据∨nest触发"收窄为"仅confirmed"）已经是净伤害。

### 修改2：递归区间套（第14环完整实现）

v2：candidate@k 只看 k−1 一层证据。v3：从 k−1 逐层下探**直到 a0**
（bi 层方向翻转沿），任何一层出现同侧直接证据即触发。

- **武装窗口链门控读法被否证（域空）**：第一版要求 k−1 同侧窗口武装

  （confirmed 同侧让位），武装链在真实数据上不存在。任务终止条款
  "直到a0或找到证据"裁决下探无条件。
- 生效读法下深触发真实涌现：271（OKLO）~ 2946（GC），全部集中在
  lad≥3 窗口（低层词汇密度远高于高层——递归收益 = 高层窗口借低层
  词汇提前触发）。

### 3. DX = 纯根翻转增量的干净归因样本

DX 零 spawn（成本门全拒：θ 量级 < 摩擦门）、零 negate、零级联——
exit_reasons 只有 sellpt/buypt/eod。**v3−v2 = +18.7pp 全部来自根翻转**，
且 MDD −9.4% 优于 BH −16.8%。CL 同理主要靠 recL3 双向长持腿（long
+251K / short +106K）。递归 nest 的 P&L 增量在 spawn 路径上（OKLO 41
spawn / BTC 103 spawn），量级被根翻空主导——本判决对修改2的 P&L 归因
不可分离（见边界条件）。

### 4. 强平的回归

v2 零强平 8/8（027:25 否定线先于保证金线）的前提是：所有空头 voice 都
出生于 spawn（出生相否定线武装）。v3 根翻空出生于 confirmed（与 D 翻转
同律，否定线退役 None）——**根空头没有否定线，唯一出口 = confirmed 买
∨ 2×basis 强平**。BTC lad5 根空头在确认滞后窗口内被翻倍行情物理强平，
NAV 归零。第23环字面实现与 027:25 否定线体系存在结构性缺口：翻转入场
没有"否定我的极值线"词汇。

## 边界条件（何种条件下结论翻转）

1. **第14环读法歧义**：任务句"k-1有candidate则检查k-2"存在窗口链门控
   读法（已实证域空、deep=0）与无条件下探读法（已采用，依据终止条款
   "直到a0或找到证据"）。若编排者本意是门控读法，则修改2应回滚为
   v2 单层（域空 ⇒ 行为等价），本判决的 deep 读数作废，但 P1 结论
   不变（DX 零 spawn 仍 +18.7pp、主导项是根翻空）。
2. **载体读法**：根空头实现为真实 1x 逐仓空头。若编排者本意是 A股
   语境"翻空 = 持币"（第一版现金读法），则 OKLO 读数为 +59.2%（仍
   < v2，再入场词汇收窄本身为负），BTC 不会强平，但"物理暴露提升到
   接近 1.0"的任务前提不成立。
3. **若加 regime 条件化**（如 anc 豁免域、bear 年门控、否定线武装），
   空头腿正域可能扩大——但那是新任务（条件化翻空），不是第23环字面。
4. 摩擦为零口径；空头腿引入借券/资金费后负域只会更深（结论单向稳健）。

## 下游推论

1. **第23环需要扬弃而非字面**：出场=翻转=新建仓的"新势"必须区分趋势
   与盘整（38课两中枢同级别分解 vs 中枢延伸）——无条件翻空把盘整税
   交满。条件化方向：confirmed 卖 × 新势已证实为下跌走势（如次级别
   中枢序列向下）才翻空，否则退回 v2 清算等待。
2. **根空头需要否定线词汇**：spawn 出生相有 027:25 极值线，翻转出生相
   没有——结构性缺口直接导致 BTC 强平。候选：翻转时用触发 confirmed
   的走势极值作否定线。
3. **v2 仍是 NRF 当前最优形态**（MDD 8/8 全称改善 + 零强平），开放轴
   维持 v2 判决的"嫁接恒仓基座"方向；v3 证明开放轴不在字面翻空。
4. CL/DX 白名单内 v3 严格优于 v2（收益+MDD 双改善）——若按 regime
   白名单部署（在册先例第十余次 regime 函数），{CL,DX} 可挂 v3。
