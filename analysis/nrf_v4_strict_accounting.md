v2 判决"alpha 集中根爬升长持腿"在 v4 保留且放大（不清仓 ⇒ 长持腿不再
被根卖点截断）；**短差 slice 从 v2/v3 的全层失血转为正贡献**——θ 配额
（~22% 仓位）把空头 slice 的确认滞后税限制在小切片上，027:25 否定线
（negate 49-148 次）以缩水形式兑现有界损失。

### 2. 死因解剖：旧正域坍塌的两种机制

- **CL（−218.8pp vs v2）**：v2 在 CL 的 +221% 本质是"根卖点清仓"避开了
  原油 −94% 的三次崩盘——清仓恰好是 CL 域的 alpha 来源。v4 不清仓原则
  按穿全部崩盘（recL2 长持腿持全史、MDD −86.9%）。**清仓频率是 regime
  函数**：趋势域要少清（OKLO +524pp），深崩域要多清（CL −219pp）——
  与 hold26/fusion_t 系列"正域=regime 函数"第十余例同构。
- **DX（−14.4pp）**：成本门全拒（θ 量级 < k×friction，spawns=0）⇒ v4
  退化为带 7 次清仓的 BH 复制品（+3.9 vs +4.1）。v2/v3 在 DX 的小额
  alpha 来自清仓-再入场时点，恰是 v4 删除的机制。

### 3. §6 合取词汇的判别力

清仓 = confirmed Sell1@top（背驰词汇，type2/3 非背驰不算）∧ 区间套定位
记忆在场（nf 触发后未被破极值否定）。单条件版本（任意 confirmed
sell@top）OKLO 清仓 77 次、收益 +225%；合取版本清仓 3 次、收益 +695%
——**合取的第二个条件（区间套递归确认）贡献 +470pp**，且这正是规格
§6.2 的字面要求。

### 4. earning 重定基首次激活

OKLO 22 次增仓 +373 单位（N 从 ~4400 增至 ~4800 量级波动）、BTC 71 次。
触发路径：根 cost_pool 被反复回补利润磨穿 → 纯利润在回补买点买入 Δ
（§7 时机约束字面实现）。空头 earning 命中 0/8——规格 §7"多空对称"
声明在数据上零接触，挣负股数 L0 不可构造的在册结算未被挑战。

## 边界条件（何种条件下结论翻转）

1. **m 配额读法**：m = 在手 × θ_sub/θ_total 是 53课配额留白的本判决
   裁决（hold26 θ 配额表在册先例）。规格只说"35课成本门决定"——零摩擦
   口径下成本门与 m 无关（振幅/摩擦比 m 不变），量的自由度必须由配额
   承接。若编排者裁定其他配额（如固定 1/3、θ_sub/θ_parent），数值会动，
   但 P1 方向性（正域=趋势域）预计稳健（slice 占比小）。
2. **词汇分工读法**：confirmed@own = 回补、nest 定位@own = spawn 是
   §3"或区间套定位"与 §5 冲突的唯一自洽消解。若 nest 定位也允许回补，
   §5 孙 spawn 域被吞，递归嵌套退化为单层。
3. **空头 earning**：规格 §7 声明多空对称；实装空头侧不增仓（在册 L0
   结算"挣负股数构造性不可表示"优先），命中计数 0/8 ⇒ 分歧零实际影响。
   若未来数据出现命中，须上浮裁决。
4. **清仓词汇**：Sell1∧located 合取。若编排者本意含 type3 背驰延伸或
   要求更高层（仅 recL3+），清仓更少，CL 更差、OKLO 类似。
5. 摩擦为零口径；slice 短差引入摩擦后正贡献会缩水（OKLO slice +9.6K
   对 266 次往返是薄利）。

## 下游推论

1. **嵌套递归赋格的正确基座 = 恒仓 + 配额短差**——v2 判决"开放轴=嫁接
   恒仓基座"在 v4 闭环：不清仓原则就是恒仓基座的实现，26课恒仓与
   spawn 机制在严格会计下兼容（B+C 合流的 NRF 形态）。
2. **清仓条件是下一个开放轴**：{CL,BRN} 需要"深崩域提前清仓"词汇
   （如 anc 豁免的镜像——大级别趋势向下证实门），但那是 regime 条件化，
   不是会计规则——须独立预注册。
3. **DX 类（θ < 成本门）标的 NRF 无增量**——白名单准入判据候选：
   spawns > 0（成本门通过率非零）。
4. MDD 8/8 全优 + 零强平 + 守恒不变量 ⇒ v4 是 NRF 系首个同时满足
   风险面全称改善与收益面多数改善的形态——**升格为 NRF 默认基座**，
   v2/v3 退役为对照臂。
