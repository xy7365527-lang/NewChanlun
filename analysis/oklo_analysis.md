## 4. 核心问题：为什么 OKLO "递归得很好" 而 MOS 不行？

### 4.1 拓扑根源：递归丰富度 ≈ 波动率结构 ≈ 多尺度往返

| | OKLO | MOS |
|--|--|--|
| 走势性质 | 高 β 主题股，**大开大合**（5.59→174→45→67，多次 31×/腰斩级摆动） | **单边阴跌**（35.9→24，−33%，少回头） |
| persistence 分布 | **宽**（6.0~168.5 跨 4 个量级，多簇） | **窄+断层**（一个 16.41 巨 bar + 一堆 <1 噪声，缺中间层） |
| 自适应级别簇数 | **7** | 3 |
| 相空间往返 | 大幅往返 → **H1 loop 显著（pers 11.2）** | 单边推进 → **无 loop（pers 0.56）** |
| 中枢 | 低位有 1 个盘整平台中枢 | 0（下跌段无重叠） |
| 买点几何乘积 | 28（无短板） | 0.01（两维坍塌） |

**机制**：log-gap 级别检测把 persistence 分布在对数轴上按"间隙"切级别。
- OKLO 大开大合 → 各尺度都有显著摆动 → persistence 在多个量级聚簇 → log-gap 切出多级别 → "**递归层次分明**"。
- MOS 单边阴跌 → 只有"全年大跌"一个大摆动 + 微小日内噪声 → persistence 两极分化、中间空 → 只切出粗/细两层，**缺中间级别** → "**递归塌缩**"。

H1 同理：往返才有相空间环（中枢的拓扑本质），单边推进没有环。

### 4.2 但"递归得好"≠"当前是买点"（关键纠偏）

用户直觉**在历史结构层面正确**：OKLO 的多级别 + 中枢 + loop 确实是清晰的缠论递归结构。**但 PH 引擎同时揭示一个反面**：

- OKLO **当前状态**与 MOS **完全同构**：主导下跌分量 alive（174→45 的回撤未被封顶 settle）、不可反弹 settle、growth=0、healthy=False。
- 即 OKLO 当前处于"**结构清晰的高级别下跌的反弹中段**"——**递归越清晰，越能确认这是一个大级别回撤而非小回调**。丰富的递归结构在这里是**看空的精度提升**，不是看多的理由。
- 近端 settle 仅需 +1.21（到 68.09）确认最近微型腿；但全局主导下跌（valley 45.58）reversal_amplitude=128.56，**否定门槛极高**。当前 67 的反弹要"翻盘"需走到 94→174 一路 settle，空间巨大。

> ⚠️ **框架纠正（见 §6.0，2026-05-30）**："翻盘需走到 174"混淆了两件事——大级别底反转（需回天价，不指望）vs 次级别区间套逐级确认（近端 68→78→80，操盘相关）。二买/三买本就发生在大级别未反转时，"大级别未 settle"不是看空理由，而是二买的构成条件。详见 §6.4。

**结论**：OKLO "递归得很好"——成立，且 PH 量化了它（7 级 / 2 loop / 乘积 28）。但这恰恰让 PH 更有把握地判断：**当前 67 的反弹大概率是 174→45 大级别回撤中的次级别假收敛**（§17 规则3），与 MOS 同结论。是否真买点仍取决于**动力学层力度背驰确认（未采集）** + 全局下跌分量 settle。

### 6.4 【问题4】缠论买卖点定位 —— "周线三买的天线二买"

**关键区分（用户命题的兑现）**：
- **全局/主回撤腿 settle**（需回 $174）= 大级别走势"重来"≈ 大级别底反转 → **不相关**（不指望）。
- **近端分量逐级 settle**（68→78→80…）= **区间套自下而上逐级确认** → **操盘相关**，这是次级别买点的拓扑前提。

**两层结论不矛盾，恰好统一**：
- §2.5/前报告："周/月线级下跌分量未 settle → 不是大级别底反转" —— **仍成立**（6.3 显示周/月线级 0 settled / 2 alive）。

- **二买/三买的定义本就是"大级别未完成时介入次级别的买点"**——所以"大级别未反转"与"次级别买点成立"**不是矛盾，是二买/三买的构成条件本身**。

**对应用户的"周线三买的天线二买"**：
- "周线级"未被向上分量彻底 settle（6.3：周/月线级 alive）= 周线级仍在大中枢/下跌未反转的格局中——与"三买发生在突破周线中枢后、整体趋势尚未走完"的位置吻合。
- "天线二买"（次级别在上沿的二买）= PH 阶梯显示**近端小级别已逐级 settle 向上**（区间套向上收敛），价格站在小级别确认完成、贴近上一档屏障（68.09/68.70）的位置 = 次级别二买的拓扑签名。

- 若价格**跌破近端 valley 67.82（2026-05-27）/ 更关键 55.88（2026-05-19，日线级中腿底）**，则最近的小级别向上确认被否定，二买证伪——这正是缠论"二买被跌破前低即失败"的拓扑形式。

### 6.5 诚实边界（formalization-validity-domain）

1. **级别带↔缠论级别名是 L2 启发映射**：本节用 persistence 量级（自适应 log-gap 带）贴"周/日/60分"标签，是 §2.2 同一口径的延伸，**非**真实多周期 K 线验证。用户的"**周线**三买"严格成立需 **TV 周线级中枢结构**（多周期），单周期日线 PH **不能唯一锁定**到"周线三买"——PH 只能说阶梯**方向一致**（小级别向上确认 + 大级别未反转），不能替代周线中枢确认。
2. **充分性仍缺动力学层**：二买成立的**充分条件**需 MACD 力度（次级别背驰/不破前低 + 力度，第24课/521号），PH 定义上不产生（纯拓扑动量不存在）。本节是**形态学必要条件**层。
