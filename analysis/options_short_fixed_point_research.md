## 1. 核心定理：凸性载体上非对称定理的两支消解（问题 A）

### 1.1 在册非对称定理回顾（线性载体，零改动）

双向会计 §2.4（已实装于 [ledger.rs ShortBook](rust/src/trading/ledger.rs) 文档注释）：

1. **相变不动点不存在**：多头 EarningShares 的存在论基础 = 损失有界于成本（cost_basis ≤ 0 ⇒
   任意路径不亏）。线性空头损失无界（c→∞）⇒ 该状态对任何有限 proceeds_basis 不可达。
2. **金额守恒算术未定义**：线性空头开仓是保证金担保的**负债创设**（borrow-and-sell），
   不是现金换单位；"卖 V 买 V 增单位"在空头侧符号反转且与负债机制不符。

本文**不推翻**此定理——它对线性载体（期货空头/融券/永续空仓）仍逐字成立，ShortBook
单相单律与 S1-S4 条件轴判决零改动。本文改变的是**载体轴路由**：空头侧存在一个凸性载体，
其上两支前提同时不成立。

### 1.2 两支消解（L0 证明）

设空头暴露由**买入认沽期权**承载：U 张认沽，行权价 K，单张权利金 π₀，到期 T。

**第一支消解（损失有界性）**：期权买方支付权利金后无任何追加义务，
任意价格路径下损失 ≤ U·π₀（最坏 = 到期价值归零）。设短差累计回收使
premium_basis ≤ 0，则即使持仓认沽全部归零，战役总账 ≥ 0——
**"无论价格怎么走都不亏"的状态对认沽持仓可达**。不动点存在。∎

**第二支消解（金额守恒算术恢复）**：认沽是可自由买卖的资产——卖出 U′ 张得现金 V = U′·p，
回调后用 V 买回得 V/p′ > U′ 张（p′ < p）。现金↔合约双向兑换、换率 = 当下认沽价，
与股票的"卖 V 买 V ⇒ 股数净增"**逐字同构**。无负债创设环节，AmountConserving
算术有定义。∎

**存在论根源**：线性卖空把"空头暴露"实现为负债；认沽把它重新参数化为
**做多一个与标的反向联动的凸性资产**。在认沽价格坐标系下，标的的下跌走势 = 认沽的
上涨走势——空头会计 = 认沽坐标系下的**多头会计**。非对称的根子（负债 vs 资产）被
载体替换直接拔除，而不是被会计技巧绕过（no-workaround 合规：这是载体层的存在论替换，
不是在 ShortBook 上加补丁）。

### 1.3 同构定理：PutVoice ≅ OrganicLedger

**定理**：以（单位 = 认沽合约张数，价格 = 认沽权利金）为坐标，认沽 voice 的会计
与在册 `OrganicLedger` 逐字同构，四前件核验：

| OrganicLedger 前件 | 认沽侧核验 |
|---|---|
| 单位数恒正（total_shares > 0） | 张数 U > 0 ✓（买方持仓恒正） |
| 股数守恒腿：π ⇒ cost_basis −= π/S | 张数守恒腿：高抛低吸认沽，π ⇒ premium_basis −= π/U ✓ |
| 损失有界于成本 ⇒ cb ≤ 0 单向相变不亏 | 损失 ≤ 权利金 ⇒ pb ≤ 0 任意路径不亏 ✓（§1.2 第一支） |
| 金额守恒：卖 V 买 V ⇒ 单位净增 | 现金↔合约双向兑换 ✓（§1.2 第二支） |

⇒ **账本层零新类型**。`DirectionalBook` 不需要第三变体：认沽 voice = `Long(OrganicLedger)`
on put-bars。新增的全部内容在账本之外的三层：**映射层**（认沽价格 ← 标的价格的坐标变换，
即 Greeks）、**摩擦层**（theta/spread 进成本门）、**生命周期层**（到期/roll）。

**原文实操锚**（此同构不是纯推导，缠师在两个方向上都实际跑通了它）：

- 多头方向（认购权证）：26:34「本ID最终在最后几天上涨到1块多完全出掉时，当时的**成本是
  负的2块8毛多**，注意，本ID的仓位是一直不变的，最开始多少就是多少」——认购权证上
  cost_basis < 0（EarningShares 深处）+ 份数恒定记账的完整证词。
- **空头方向（认沽权证）**：15:968-976「昨天根据5分钟线的背弛出了大半，**把剩下的成本是0了**。
  本ID作权证，特别是认沽，第一轮上去都会这样减仓操作，**只持有成本是0的仓位等待第二波**，
  第二波是否有，这已经问题不大了，**这样就绝对立于不败之地了**」——premium_basis = 0
  的相变达成 +「立于不败之地」= earning 不动点的不亏性质的原文命名。

双向会计 §1 把全部空头侧条款标注为 [镜像推导]（L0 无原文锚）。本文修正其标注域：
**该标注对线性载体维持；对认沽载体，空头 earning 是 [原文实操] 级**——语料中空头方向
唯一的第一人称完整操作账（见仓/减半/回补/加仓/背驰出/成本归零）恰好就在认沽上。

**锚的效力精确化（防声明膨胀，质询修正）**：[原文实操] 标签证成的是**存在性与原文
合法性**——earning 不动点"可达"是存在命题，n = 1 的实操记录恰是存在量词所需的全部
样本；它**不证成**达成概率或期望符号（那是 §9 矛盾 2 的 L2 域）。定理效力的本体来自
§1.2 的 L0 推导，原文锚是可达性的历史见证，不是统计证据。

### 1.5 残余非对称：有限期不败

必须诚实声明 earning 恢复的精确范围：

- **恢复的**：损失有界 ⇒ pb ≤ 0 后任意路径不亏（不动点的"不败"性质）。这是非对称定理
  否定的那个性质，现已可构造、可达、有实操记录。
- **不恢复的**：免费持仓的**永续性**。多头免费股票是无限期权利；免费认沽在到期日蒸发
  （机会成本，非亏损）。15:976 的语义精确到这个边界：「等待第二波」——在权证存续期内等待，
  「第二波是否有，这已经问题不大了」——等不到也不亏，但等待本身有期限。
- **载体选择的非对称**：多头侧线性载体（现货）已自足（earning 可构造），认购期权是可选
  增强；空头侧认沽是 earning 的**唯一可构造载体**（线性空头被 §1.1 定理排除）。
  载体必选性的不对称是非对称定理在载体轴上的残影。

### 2.3 同张数定理（"同股数进出"的认沽精确化）

> **认沽 voice 的配额单位 = 合约张数（行权名义 U·multiplier），不是 delta 等价数。**

三条推导：

1. **26:34 量纲**：缠师在权证上的记账就是份数（「最开始多少就是多少，上上下下……
   又回复原来的数量」）——权证份数对应认沽张数，字面一致读法。
2. **31 课禁加仓的可执行性**：配额必须事前可固定。delta 时变（价格变 ⇒ delta 变）⇒
   "同 delta 张数"逐 bar 漂移 ⇒ 配额不可固定 ⇒ 与 31 课不相容。
3. **概念命名纪律（436 号同型）**：delta 等价是**对冲范式**的词汇（目标 = 净 delta 平 ⇒
   隐含连续再平衡义务），缠论范式的词汇是配额恒定 + 买卖点（目标 = 结构捕获）。
   用 delta 命名配额会把连续再平衡前提渗入设计，而连续再平衡正是 theta + spread 摩擦的
   最大放大器——命名渗入直接通向负 alpha 形态。

delta 的合法身份 = **派生观测量**：名义敞口换算（N_eff = U·|Δ|·S·multiplier，杠杆三元组
对接读数）与结构保真度核验（§4.2）。买卖单位、守恒律、配额全部以张数计。

### 2.4 theta 的会计位置（三层处理，问题 A3）

**裁决：theta 不是会计项，是摩擦项。** premium_basis 是已付现金的会计量——theta 侵蚀的是
认沽**市值**，不是你付出过的成本。账本对 theta 零感知（它只见成交价序列）。theta 全部
进入账本之外两层：

1. **成本门层（35:30 的认沽扩展）**：
   > friction_put(腿) = 佣金 + bid-ask spread + **Θ·T_hold(腿)**
   >
   > 短差腿准入：θ_q(认沽自身 K 线) ≥ K_friction × friction_put
   
   与杠杆三元组 §6 的合约费率核验（预期持仓期 × 费率 × L 进 friction_RT）同范畴——
   theta 是认沽载体的"资金费率"。注意 θ_q 直接在认沽自身 K 线上计算（认沽自身振幅
   对自身摩擦），不需要从标的换算。
2. **战役层（earning 竞速条件）**：
   > premium_basis 归零事件须先于时间价值耗尽：T(Σπ_短差 ≥ π₀) < T_expiry − buffer
   
   theta 不直接阻止 basis 下移（短差 π 是已实现现金），但 theta 单调压低认沽价格水平 ⇒
   压低后续短差的可兑现振幅 ⇒ basis 下移**减速**。竞速失败的形态：短差兑现速率衰减到
   低于零（spread 吃掉振幅）而 basis 仍 > 0 ⇒ 战役以净损 ≤ 已付权利金告终（损失有界，
   不是爆仓是 decay-out）。
   
   **首波兑现律（原文操作形态）**：15:970「本ID作权证，特别是认沽，**第一轮上去都会这样

### 3.1 对冲式 vs 翻转式：原文背书的是并持

高级别 voice 持现货多、本级别卖点出现时，认沽载体提供两种形态：

theta/vega 超出走势-暴露同构）：与削减 m 的差异是真实的——
(i) 凸性：下跌中 |Δ| 0.4→1.0 渐进增空（捕获深于固定削减量）；

增量符号 = 凸性价值 − 租金，是 regime 函数（IV 水平 × 实际波动实现），须 L2 裁决（§9）。

**gamma = 44 课铰链的自动化（新命题）**：44:44 铰链——「先出一部分，然后在出现
上一段所说的情况时再出清。如果没有出现……就可以回补，权当弄了一个短差」——是
**人工渐进翻转 + 事后身份授予**。认沽的 gamma 动力学把这个过程内置为连续自动版本：

**新读出**：杠杆三元组的 P_neg 在线性载体上是**影子价格**（约束计算量）；认沽结构把它
变成**显式合约参数**（卖 put strike = 目标位 = 收益封顶位）。结构否定价/目标价从风控层
对象升格为头寸构造参数——「市场结构本身就是风控」（skill 原文）的形式化根据。

### 4.2 delta = 结构保真度参数（新形式化）

认沽 K 线要可读缠论结构（§3.2 的前提），认沽价格变动必须由标的结构分量主导：

> dP_put = Δ·dS（结构分量） + Θ·dt（衰减噪声） + ν·dσ（IV 噪声）
>
> **保真度 ≈ |Δ·ΔS| / (|Θ·Δt| + |ν·Δσ|)** ——|Δ| 是唯一随 strike 选择单调可控的分子项。

- ITM/ATM（|Δ| ≥ 0.5）：高保真——认沽 K 线近似标的镜像 + 杠杆，缠论结构可读。
  15 课实操与 skill 的 ITM delta 0.85-0.95 验证规则落在此域。
- 深 OTM（|Δ| → 0）：K 线被 theta/vega 噪声主导，结构不可读——**废纸域**。
  原文三重警示恰好全部落在此域：15:958「该权证风险极大，最终要变成废纸……绝对不要买」、
  96:118「认沽可不要乱玩，你没这本事，就注定要倾家荡产的」、96 课「这东西最后的命运是 0」。

⇒ **delta 下界是结构可读性门，不是风险偏好参数**：方向腿 |Δ| ≥ 0.5（ATM~ITM）。
"从缠论结构选 delta = 从走势结构决定杠杆"的严格形式：strike 落在结构立足点 ⇒ delta
随之确定 ⇒ 杠杆（名义/权利金）是第三位派生量——选择链是 结构 → strike → delta → 杠杆，
任何反向推导（按杠杆/delta 目标倒推 strike）被 skill 在册禁令覆盖。

### 4.3 存活约束换维定理（与杠杆三元组的精确接口）

| 杠杆三元组（线性载体） | 认沽载体对应物 |
|---|---|
| 存活约束：P_liq < P_neg（价格维） | **无强平维度**（max loss = 已付权利金，开仓即付定） |
| D_struct = 价格距离 + θ_q 确认垫 | **D_time = T_target 距离 + theta buffer**（时间距离 + 确认垫） |
| L_max = 1/(D_struct + mm) 影子价格 | 杠杆 = 名义/权利金，由 strike 结构派生（§4.2），上界来自废纸域回避而非强平 |
| 升级负债定理：级别升级 ⇒ 补保证金 | **级别升级 ⇒ roll 至更远到期**（T_target 变长 ⇒ DTE 须覆盖）——时间负债替代保证金负债 |
| 单边律：杠杆只降不升 | 镜像：DTE 余量只增不减（不向更近到期 roll 省权利金——那是用尾部换 theta，26:32 同构禁止） |
| 维护定理：事件驱动非逐 bar | 同构保持：roll 触发 = 结构事件（§3.4 表），非日历事件 |
