## 1. 核心定理：凸性载体上非对称定理的两支消解（问题 A）

### 1.1 在册非对称定理回顾（线性载体，零改动）

双向会计 §2.4（已实装于 [ledger.rs ShortBook](rust/src/trading/ledger.rs) 文档注释）：

1. **相变不动点不存在**：多头 EarningShares 的存在论基础 = 损失有界于成本（cost_basis ≤ 0 ⇒
   任意路径不亏）。线性空头损失无界（c→∞）⇒ 该状态对任何有限 proceeds_basis 不可达。
2. **金额守恒算术未定义**：线性空头开仓是保证金担保的**负债创设**（borrow-and-sell），
   不是现金换单位；"卖 V 买 V 增单位"在空头侧符号反转且与负债机制不符。

本文**不推翻**此定理——它对线性载体（期货空头/融券/永续空仓）仍逐字成立，ShortBook
单相单律与 S1-S4 条件轴判决零改动。本文改变的是**载体轴路由**：空头侧存在一个凸性载体，
其上两支前提同时不成立。

### 1.2 两支消解（L0 证明）

设空头暴露由**买入认沽期权**承载：U 张认沽，行权价 K，单张权利金 π₀，到期 T。

**第一支消解（损失有界性）**：期权买方支付权利金后无任何追加义务，
任意价格路径下损失 ≤ U·π₀（最坏 = 到期价值归零）。设短差累计回收使
premium_basis ≤ 0，则即使持仓认沽全部归零，战役总账 ≥ 0——
**"无论价格怎么走都不亏"的状态对认沽持仓可达**。不动点存在。∎

**第二支消解（金额守恒算术恢复）**：认沽是可自由买卖的资产——卖出 U′ 张得现金 V = U′·p，
回调后用 V 买回得 V/p′ > U′ 张（p′ < p）。现金↔合约双向兑换、换率 = 当下认沽价，
与股票的"卖 V 买 V ⇒ 股数净增"**逐字同构**。无负债创设环节，AmountConserving
算术有定义。∎

**存在论根源**：线性卖空把"空头暴露"实现为负债；认沽把它重新参数化为
**做多一个与标的反向联动的凸性资产**。在认沽价格坐标系下，标的的下跌走势 = 认沽的
上涨走势——空头会计 = 认沽坐标系下的**多头会计**。非对称的根子（负债 vs 资产）被
载体替换直接拔除，而不是被会计技巧绕过（no-workaround 合规：这是载体层的存在论替换，
不是在 ShortBook 上加补丁）。

### 1.3 同构定理：PutVoice ≅ OrganicLedger

**定理**：以（单位 = 认沽合约张数，价格 = 认沽权利金）为坐标，认沽 voice 的会计
与在册 `OrganicLedger` 逐字同构，四前件核验：

| OrganicLedger 前件 | 认沽侧核验 |
|---|---|
| 单位数恒正（total_shares > 0） | 张数 U > 0 ✓（买方持仓恒正） |
| 股数守恒腿：π ⇒ cost_basis −= π/S | 张数守恒腿：高抛低吸认沽，π ⇒ premium_basis −= π/U ✓ |
| 损失有界于成本 ⇒ cb ≤ 0 单向相变不亏 | 损失 ≤ 权利金 ⇒ pb ≤ 0 任意路径不亏 ✓（§1.2 第一支） |
| 金额守恒：卖 V 买 V ⇒ 单位净增 | 现金↔合约双向兑换 ✓（§1.2 第二支） |

⇒ **账本层零新类型**。`DirectionalBook` 不需要第三变体：认沽 voice = `Long(OrganicLedger)`
on put-bars。新增的全部内容在账本之外的三层：**映射层**（认沽价格 ← 标的价格的坐标变换，
即 Greeks）、**摩擦层**（theta/spread 进成本门）、**生命周期层**（到期/roll）。

**原文实操锚**（此同构不是纯推导，缠师在两个方向上都实际跑通了它）：

- 多头方向（认购权证）：26:34「本ID最终在最后几天上涨到1块多完全出掉时，当时的**成本是
  负的2块8毛多**，注意，本ID的仓位是一直不变的，最开始多少就是多少」——认购权证上
  cost_basis < 0（EarningShares 深处）+ 份数恒定记账的完整证词。
- **空头方向（认沽权证）**：15:968-976「昨天根据5分钟线的背弛出了大半，**把剩下的成本是0了**。
  本ID作权证，特别是认沽，第一轮上去都会这样减仓操作，**只持有成本是0的仓位等待第二波**，
  第二波是否有，这已经问题不大了，**这样就绝对立于不败之地了**」——premium_basis = 0
  的相变达成 +「立于不败之地」= earning 不动点的不亏性质的原文命名。

双向会计 §1 把全部空头侧条款标注为 [镜像推导]（L0 无原文锚）。本文修正其标注域：
**该标注对线性载体维持；对认沽载体，空头 earning 是 [原文实操] 级**——语料中空头方向
唯一的第一人称完整操作账（见仓/减半/回补/加仓/背驰出/成本归零）恰好就在认沽上。

**锚的效力精确化（防声明膨胀，质询修正）**：[原文实操] 标签证成的是**存在性与原文
合法性**——earning 不动点"可达"是存在命题，n = 1 的实操记录恰是存在量词所需的全部
样本；它**不证成**达成概率或期望符号（那是 §12 矛盾 2 的 L2 域）。定理效力的本体来自
§1.2 的 L0 推导，原文锚是可达性的历史见证，不是统计证据。

### 1.5 残余非对称：有限期不败

必须诚实声明 earning 恢复的精确范围：

- **恢复的**：损失有界 ⇒ pb ≤ 0 后任意路径不亏（不动点的"不败"性质）。这是非对称定理
  否定的那个性质，现已可构造、可达、有实操记录。
- **不恢复的**：免费持仓的**永续性**。多头免费股票是无限期权利；免费认沽在到期日蒸发
  （机会成本，非亏损）。15:976 的语义精确到这个边界：「等待第二波」——在权证存续期内等待，
  「第二波是否有，这已经问题不大了」——等不到也不亏，但等待本身有期限。
- **载体选择的非对称**：多头侧线性载体（现货）已自足（earning 可构造），认购期权是可选
  增强；空头侧认沽是 earning 的**唯一可构造载体**（线性空头被 §1.1 定理排除）。
  载体必选性的不对称是非对称定理在载体轴上的残影。

## 2. 认沽 voice 的完整会计规则（问题 A）

### 2.1 账本与路由

```
DirectionalBook ::= Long(OrganicLedger)    # 在册，现货/期货多头 + 认沽 voice 共用
                  | Short(ShortBook)        # 在册，线性空头专属（S1-S4 条件轴）

PutVoice = { book: Long(OrganicLedger),     # 单位=张数，basis=权利金均价
             instrument: PutContract{underlying, K, T, multiplier},

```

### 2.3 同张数定理（"同股数进出"的认沽精确化）

> **认沽 voice 的配额单位 = 合约张数（行权名义 U·multiplier），不是 delta 等价数。**

1. **26:34 量纲**：缠师在权证上的记账就是份数（「最开始多少就是多少，上上下下……
   又回复原来的数量」）——权证份数对应认沽张数，字面一致读法。
2. **31 课禁加仓的可执行性**：配额必须事前可固定。delta 时变（价格变 ⇒ delta 变）⇒
   "同 delta 张数"逐 bar 漂移 ⇒ 配额不可固定 ⇒ 与 31 课不相容。
3. **概念命名纪律（436 号同型）**：delta 等价是**对冲范式**的词汇（目标 = 净 delta 平 ⇒
   隐含连续再平衡义务），缠论范式的词汇是配额恒定 + 买卖点（目标 = 结构捕获）。
   用 delta 命名配额会把连续再平衡前提渗入设计，而连续再平衡正是 theta + spread 摩擦的
   最大放大器——命名渗入直接通向负 alpha 形态。

delta 的合法身份 = **派生观测量**：名义敞口换算（N_eff = U·|Δ|·S·multiplier，杠杆三元组
对接读数）与结构保真度核验（§4.2）。买卖单位、守恒律、配额全部以张数计。

### 2.4 theta 的会计位置（三层处理，问题 A3）

**裁决：theta 不是会计项，是摩擦项。** premium_basis 是已付现金的会计量——theta 侵蚀的是
认沽**市值**，不是你付出过的成本。账本对 theta 零感知（它只见成交价序列）。theta 全部
进入账本之外两层：

1. **成本门层（35:30 的认沽扩展）**：
   > friction_put(腿) = 佣金 + bid-ask spread + **Θ·T_hold(腿)**
   >
   > 短差腿准入：θ_q(认沽自身 K 线) ≥ K_friction × friction_put
   
   与杠杆三元组 §6 的合约费率核验（预期持仓期 × 费率 × L 进 friction_RT）同范畴——
   theta 是认沽载体的"资金费率"。注意 θ_q 直接在认沽自身 K 线上计算（认沽自身振幅
   对自身摩擦），不需要从标的换算。
2. **战役层（earning 竞速条件）**：
   > premium_basis 归零事件须先于时间价值耗尽：T(Σπ_短差 ≥ π₀) < T_expiry − buffer
   
   theta 不直接阻止 basis 下移（短差 π 是已实现现金），但 theta 单调压低认沽价格水平 ⇒
   压低后续短差的可兑现振幅 ⇒ basis 下移**减速**。竞速失败的形态：短差兑现速率衰减到
   低于零（spread 吃掉振幅）而 basis 仍 > 0 ⇒ 战役以净损 ≤ 已付权利金告终（损失有界，
   不是爆仓是 decay-out）。
   
   **首波兑现律（原文操作形态）**：15:970「本ID作权证，特别是认沽，**第一轮上去都会这样
   减仓操作**，只持有成本是0的仓位等待第二波」——缠师的程式是**第一波主跌段即把成本
   搞到 0**，不依赖多波累积。竞速条件的原文解 = 把 earning 达成压缩在 theta 最便宜、
   动能最强的首波。若首波减仓回收不能覆盖大部分权利金，后续波在加速 theta 下达成
   earning 的概率快速衰减——该战役应按普通止损纪律处理（损失已有界）。
   
   **theta 截面声明（质询修正）**：短差 π 的现金中混有 **theta 兑现分量**——高抛与
   低吸之间流逝的时间价值使低吸价系统性更低，该差额是自身持仓时间价值的左右口袋兑现
   （市值降低换现金），不是结构 alpha。会计层无须分离（premium_basis 是现金口径，
   归零 ⇒ 不败的推导链不受影响——剩余持仓的 theta 蒸发本就在 §1.5 有限期不败的语义内）；
   但**竞速条件是会计条件，不是 alpha 条件**——§8 "短差兑现 > theta 流失"的边际解读
   不得引为对冲式增量符号的证据，alpha 中结构分量与 theta 回收分量的分离唯 §12 矛盾 2
   的 L2 三臂对照可判。

### 2.5 roll 的会计：合约级断面 + 战役级连续观测量（问题 B4）

roll = 平旧认沽 + 在新缠论位置重建结构（options-selector 在册：「Roll 是整个结构在新的
缠论位置上的重建」，禁止单纯时间延展）。会计形态：

- **合约级（账本层）= 断面**：每张合约一本 OrganicLedger。roll 时旧书全腿 cascade settle
  （双向会计 §5.2 四步序同构）→ 旧书 realized 落袋 → 新书以新权利金全额开账
  （premium_basis = π₀_new）。理由与翻转断面相同：新合约 = 新工具，旧书 basis 与新书
  无桥，跨书传递 basis = 重复计账风险。
- **战役级（观测层）= 连续**：cumulative_recovered 跨 roll 累计。
  > **战役级 earning（自由滚动条件）**：Σ realized（全部 roll 链）≥ Σ premium_paid
  
  达成后整条认沽战役在用已赚出的现金滚动——序篇「利用波动把成本干到零」的战役级形态。
  该量是纯观测量不驱动状态转移（T5 同纪律）；options-selector「降成本账户记录保持
  （net credit + 次级别 swing 差价）」即此口径。两级不混表。

到期前处置词汇穷举（声明 = 能力）：**平仓 | roll**。行权不进操作词汇表——系统不建模
行权后的交割链（缠师权证实操全部为到期前卖出，无行权记录；options-selector 同样无行权
流程）。深 ITM 临近到期的美式提前行权风险按"强制 roll/平仓触发器"处理（DTE 门，§3.4）。

### 3.1 对冲式 vs 翻转式：原文背书的是并持

高级别 voice 持现货多、本级别卖点出现时，认沽载体提供两种形态：

| 形态 | 动作 | 原文地位 |
|---|---|---|
| **对冲式** | 现货不动 + 买入认沽（负 delta overlay） | **条件化背书**（80:471 满仓+对冲并持自述；74:46 必要的对冲准备；96/98/99 南航认沽节前对冲实操；条件 = 大资金） |
| **翻转式** | 平现货 + 买入认沽 | [镜像推导]（双向会计 §5 翻转断面的认沽载体版）——但载体改善：翻转后空头书从 ShortBook（无 earning）换为 PutVoice（有 earning） |

**对冲式的结构功能（80:471 全文新读出）**：「对于大资金来说，在那兵荒马乱的早上，
一个第二卖点，**也走不了多少，但有对冲，就不同了**」——对冲是**容量门（49:76）的对偶解**：
当资金规模使卖点物理不可执行（走不掉）时，认沽是卖点的执行载体。这把对冲式从
"风险偏好选项"升格为容量约束下的结构必需品。对小资金，98:66 给出对偶条款
（「不一定要对冲了……先走一部分」= 削减优先）——见 §12 矛盾 4 的载体可得性讨论。

**净额等价警告的凸性逃逸**：双向会计 §3.3 警告"m ≤ N 域的次级别开空 ≡ 在册削减-回补，
零新 alpha"。该定理前提 = **同一工具 + 线性**。认沽对冲不在其定义域（v2 载体表已声明
theta/vega 超出走势-暴露同构）：与削减 m 的差异是真实的——
(i) 凸性：下跌中 |Δ| 0.4→1.0 渐进增空（捕获深于固定削减量）；
(ii) 上行保留：反弹时损失钉死于权利金（削减则错失回升部分由接回纪律承担）;
(iii) 租金：theta + spread（削减零此项）。
增量符号 = 凸性价值 − 租金，是 regime 函数（IV 水平 × 实际波动实现），须 L2 裁决（§12 矛盾 2）。

**gamma = 44 课铰链的自动化（新命题）**：44:44 铰链——「先出一部分，然后在出现
上一段所说的情况时再出清。如果没有出现……就可以回补，权当弄了一个短差」——是
**人工渐进翻转 + 事后身份授予**。认沽的 gamma 动力学把这个过程内置为连续自动版本：
下跌每深一段，|Δ| 自动增大（= 自动"再出一部分"）；反弹则 |Δ| 自动回退（= 自动回补，
认沽高抛过的部分自然成为短差）。**theta = 这个自动铰链的市场租金**。
两种实现的选择是成本门裁决：次级别确认错判率 × 错判成本 > theta ⇒ 认沽更优；反之手动铰链更优。

### 3.6 组合结构全词汇表派发（问题 B 补全：不限于买 put）

任务要求穷举多腿组合在嵌套递归中的角色。派发不引入新公理，由两条已立定理直接驱动：

**覆盖律（非对称定理推论）**：任何卖腿必须被同 voice 内的买腿或现货覆盖——裸卖方
损失无界 ⇒ 非对称定理回归适用（矛盾 5），earning 不可构造。覆盖律是组合词汇表的准入门。

**组合 earning 判据（§1.2 的组合强化，新定理）**：纯买 put 的不败条件 pb ≤ 0 隐含依赖
其到期 payoff ≥ 0（min_payoff = 0）。对多腿组合，判据强化为：

> **pb ≤ min_payoff**（组合最坏到期价值；各腿 strike 已定 ⇒ 开仓即可计算的常数）

纯买方结构 min_payoff = 0 退化回原判据。该强化暴露一个单腿视角不可见的精确条件：
**成本归零 ≠ 不败**，当组合存在负 payoff 区时（backspread 谷底是显形例）。

**任意时点一致性引理（质询补强）**：min_payoff 虽以终端 payoff 定义，但它同时是组合
**任意时点市值**的下界——欧式组合市值 = 贴现期望 ≥ 贴现后的 payoff 下确界 ≥ min_payoff
（负下确界贴现后更浅）；美式卖腿被提前指派时，多腿内在价值包络仍 ≥ 同一下确界。
bear spread / calendar 的任意时点 0 下界更直接：strike 单调性 / 到期单调性的无套利推论。
⇒ 判据对**提前退出**（roll / 拆除 / 相位切换）一致有效，不依赖持有至到期——
战役在到期前任意时点结束都不破坏不败性。

## 4. strike / delta / 到期日与缠论结构的映射（问题 C）

### 4.1 options-selector 在册映射的对接

skill 在册规则（三 strike 全落缠论位，杠杆是派生结果）直接承接，缠论结构量对应：

| 腿（做空结构） | skill 在册 strike 来源 | 引擎结构量 | 杠杆三元组对应 |
|---|---|---|---|

| 卖低 put（降成本/目标） | 更大级别支撑位 | 下一级别中枢 ZG/ZD（目标区） | **P_neg_short 镜像表的显式合约化**：MoveDown 锁定相目标 = 新中枢 ZD |
| 买更低 put（尾部，可选） | 更更大级别结构位 | 高级别中枢边界 | 极端 regime 保护 |

**新读出**：杠杆三元组的 P_neg 在线性载体上是**影子价格**（约束计算量）；认沽结构把它
变成**显式合约参数**（卖 put strike = 目标位 = 收益封顶位）。结构否定价/目标价从风控层
对象升格为头寸构造参数——「市场结构本身就是风控」（skill 原文）的形式化根据。

### 4.2 delta = 结构保真度参数（新形式化）

认沽 K 线要可读缠论结构（§3.2 的前提），认沽价格变动必须由标的结构分量主导：

> dP_put = Δ·dS（结构分量） + Θ·dt（衰减噪声） + ν·dσ（IV 噪声）
>
> **保真度 ≈ |Δ·ΔS| / (|Θ·Δt| + |ν·Δσ|)** ——|Δ| 是唯一随 strike 选择单调可控的分子项。

- ITM/ATM（|Δ| ≥ 0.5）：高保真——认沽 K 线近似标的镜像 + 杠杆，缠论结构可读。
  15 课实操与 skill 的 ITM delta 0.85-0.95 验证规则落在此域。
- 深 OTM（|Δ| → 0）：K 线被 theta/vega 噪声主导，结构不可读——**废纸域**。
  原文三重警示恰好全部落在此域：15:958「该权证风险极大，最终要变成废纸……绝对不要买」、
  96:118「认沽可不要乱玩，你没这本事，就注定要倾家荡产的」、96 课「这东西最后的命运是 0」。

⇒ **delta 下界是结构可读性门，不是风险偏好参数**：方向腿 |Δ| ≥ 0.5（ATM~ITM）。
"从缠论结构选 delta = 从走势结构决定杠杆"的严格形式：strike 落在结构立足点 ⇒ delta
随之确定 ⇒ 杠杆（名义/权利金）是第三位派生量——选择链是 结构 → strike → delta → 杠杆，
任何反向推导（按杠杆/delta 目标倒推 strike）被 skill 在册禁令覆盖。

### 4.3 存活约束换维定理（与杠杆三元组的精确接口）

| 杠杆三元组（线性载体） | 认沽载体对应物 |

| 升级负债定理：级别升级 ⇒ 补保证金 | **级别升级 ⇒ roll 至更远到期**（T_target 变长 ⇒ DTE 须覆盖）——时间负债替代保证金负债 |

## 9. 三元组 × 期权：杠杆的完整形式化（编排者补充指令 2）

### 9.1 杠杆降格定理

线性侧三元组：(级别 j, 名义 N_j, 杠杆 L_j)，L_max = 1/(D_struct+mm) 影子价格，
E_j = N_j/L_j 派生（triad 定理 1）。期权侧逐轴变换：

| 三元组轴 | 线性侧 | 期权侧 |
|---|---|---|
| 级别 j | 操作级别 | 不变——决定 strike 结构位（§4.1）与 τ_q 时间锚（§10） |
| 名义 | N_j（单一量纲） | **双名义**：行权名义 N_K = U·mult·K（配额量纲，26:34，事前固定）+ delta 等价名义 N_Δ = U·mult·\|Δ\|·S（暴露观测量，时变，N_Δ ≤ N_K） |
| 杠杆 | L_j 选择变量，受 L_max 钳制 | **Λ = N_Δ/premium = \|Δ\|·S/P 纯派生观测量**——权利金已付定 ⇒ 无强平 ⇒ 价格维存活约束空置 ⇒ Λ 失去约束变量地位（编排者判断"L_max 不需要外部计算"的严格形式） |
| 保证金 E_j | N_j/L_max(j)，随级别**超线性**加深 | **权利金预算** premium_j = U·P(K,T)：ATM P ≈ 0.4σ√T·S，T ∝ τ_q(j) ⇒ premium ∝ **√级别时间尺度（次线性）**——期权侧高级别资金占用浅于线性侧保证金，代价转移到 theta 绝对额与 vega 噪声（√T 同步增长，§10.6 窗口上界） |

约束角色的三分转移：(i) **strike 选择** = D_struct 的合约化——moneyness (K−S)/S 就是
结构距离的合约参数；内在/时间价值比 = 结构已确认分量/仍在赌分量（编排者第 3 条的精确化）；
(ii) **DTE 选择** = 时间维存活（§10 全章）；(iii) **权利金预算** ≤ 机动池配额（§3.5）。

**派生量定理的镜像**：线性侧"E_j 分配被消解"（N 与 L_max 反解）；期权侧"杠杆选择被消解"
（strike/DTE 从结构出 ⇒ Λ 是结果）。两侧同一句话：**杠杆从来不是自由变量**。
options-selector 在册"杠杆是派生结果，不事前设定" = 派生量定理在期权域的形态。

### 9.2 五定理逐条镜像核验

| triad 定理 | 期权侧形态 | 成立性 |
|---|---|---|
| 1 派生量 | Λ 由 strike/DTE/IV 反解，自由度仍只在配额（张数） | ✓ |
| 2 嵌套守恒 | 行权名义 ≤ 层配额；卖腿预算 = 宿主让渡敞口（覆盖律 = open_sub 预算同构，§3.6） | ✓ |
| 3 单调性/事件驱动维护 | Greeks 快照与 roll 评估均为结构事件驱动（开仓/roll/升级/相位转移），非逐 bar | ✓ |
| 4 升级负债 | 级别升级 ⇒ τ_q(j+1) ≈ 9-11×τ_q(j)（§10.1 实测）⇒ **roll 至更远到期 + strike 移到高级别结构位 ⇒ 新权利金 > 旧残值 ⇒ roll 补权利金 = 升级补保证金的精确镜像**（时间负债替代保证金负债），机动池支付 | ✓ |
| 5 单边律 | (a) 禁止向更近到期 roll 省权利金（用尾部确认风险换 theta——时间维杠杆只松不紧，26:32 同构）；(b) **盈利方向自动降杠杆**：put 深入 ITM ⇒ P → K−S、\|Δ\| → 1 ⇒ Λ = \|Δ\|·S/P → S/(K−S)，下跌中 S 降、K−S 增 ⇒ Λ 单调降——单边律（浮盈不加名义、缓冲增厚）的**自动执行版**，与 gamma = 铰链自动化（§3.1）同族：线性侧的手动纪律在凸性载体上是内置动力学 | ✓ |

亏损方向（OTM 化）Λ 上升的无害性：风险载体是剩余权利金（绝对值缩小）而非名义——
弹性变大但最大损失已大部分实现。这正是"存活约束已内化"的体现。

**组合杠杆表（编排者第 4 条核验）**：bear spread Λ = max_payoff/净 debit（封顶杠杆，
开仓即常数）；collar ≈ 现货 1x（对冲后净暴露带）；ratio backspread 非线性
（谷底负、深跌高 Λ——§3.6 受限词汇的杠杆面）；synthetic short Λ = S/净 premium 但
损失无界 ⇒ 杠杆语义回归线性侧 L_max 约束（再次印证其 ShortBook 路由）。

### 9.3 26:34 级别→量偏序的期权对接（编排者方向的修正）

编排者预设"高级别 → 低 delta/远期/价差组合；低级别 → 高 delta/近期/裸认沽"。逐项核验：

- **DTE 随级别 ✓**：τ_q(j) 单调（BTC 实测 9-11×/级）⇒ 高级别远期。
- **"高级别低 delta" ✗ 须修正**：保真度门 |Δ| ≥ 0.5 是**级别无关**的可读性下界——
  方向腿在任何级别都取 ATM/ITM。低 delta 对应的是 **spread 卖腿/目标腿**（该级别目标位
  随级别变远 ⇒ 该腿 delta 随级别变低 ✓）。⇒ 修正后映射：**级别决定 spread 宽度**
  （= 结构目标距离）——高级别 voice 自然形态 = 宽 spread（远目标卖腿）或裸 put 持有；
  低级别 voice = 目标近、价差结构不值得构造 ⇒ 裸 put + 早平。
- **名义偏序 ✓**：N_K(j) ≥ N_K(k), j>k（26:34 逐字延拓）。
- **成本门（编排者第 5 条的量纲修正）**：编排者式"权利金/delta 等价名义 ≥ 摩擦阈值"
  量纲反置；正确形式 = 兑现相对摩擦（§10.6 无量纲门）——35 课门衡量的是操作收益
  覆盖成本，不是成本占名义比。

### 10.1 τ_q：结构持续时间的因果分位估计器（θ_q 的时间维镜像）

> **τ_q(j, p, t) = quantile_p { dur(Z) : Z ∈ settled 中枢(级别 j), end(Z) ≤ t }**
> **τ_m(j, p, t) = quantile_p { dur(M) : M ∈ settled 走势(级别 j), end(M) ≤ t }**
> dur = end − start（日历时间）。因果纪律：只用已完成对象、排除 alive——与在册 θ_q
> （[depth_ref.rs:90](rust/src/trading/depth_ref.rs)）同滚动窗口纪律、同因果排除，
> 实装为同一估计器族的第二读数维。

**这是走势结构的内在量度，不是统计预测**（编排者原话采纳）：τ_q 不预测当前走势何时
结束（结构决定论保持——终结由买卖点决定），它度量该级别结构的**特征时间尺度**，
与 θ_q 度量特征振幅尺度完全同构。θ_q 在册用于确认垫与成本门而不构成价格预测，
τ_q 同理用于到期覆盖与 roll 调度而不构成时间预测。

### 10.2 到期日推导链（六步——结构骨架零日历参数 + 显式登记项，质询修正版）

设 t₀ 时刻级别 j 卖点 confirmed，空头战役开启，alive 中枢年龄 age：

1. **战役的结构任务**（首波兑现律，15:970）：期权须覆盖**首波** = alive 中枢完成 +
   向下离开段 + 次级别确认。不是覆盖全战役——earning 达成后免费仓到期蒸发无损失
   （15:976「第二波是否有，这已经问题不大了」）。
   **有效域条件（质询修正——L3 循环矛盾的消解）**：「D_min 止步首波」的豁免以
   **首波 earning 可达**为前提（首波回收 ≳ 权利金的量级，038004 程式 = 减半量级）。
   该前提是级别 ×（标的×IV regime）的函数，须用 §11 式竞速预算**先行核验**——
   前提不成立的级别（如 BTC@DVOL41 的 L3 裸 ATM，首波回收下界仅 28%），首波豁免
   失效，D_min 须覆盖至 pb 归零所需的多波 ⇒ 时长向整个 move（τ_m(j) ≫ 首波）膨胀
   ⇒ 大概率撞容量帽。**首波兑现律不可达的级别 = 期权 voice 程式失效域**，
   不得用"边际/待修正"措辞掩盖（§11 判决遵此口径）。
2. **各项的结构时间**：alive 中枢剩余 ≤ max(0, τ_q(j,P50,t₀) − age)；向下离开段 =
   一个次级别走势 = τ_m(j−1,P50)；确认垫 = τ_m(j−1,P50)（53:56 的时间镜像：
   离开与回抽均须次级别）。
3. **结构下界**：
   > **D_min(t₀) = R_p(j, age) + (1+κ)·τ_m(j−1, p)**
   >
   > 其中 R_p(j, age) = quantile_p(dur − age | dur > age)——alive 中枢的**条件剩余
   > 分位数**（质询修正：原 max(0, τ_q−age) 截断对右偏分布系统性低估——中枢已超
   > P50 时长恰是长尾中枢的证据，条件剩余不归零；L3 实测 P90−P50 ≈ 2×(P50−P25) 强右偏）；
   > κ = 确认滞后系数——确认垫的严格量 = 次级别走势 candidate→confirmed 的滞后分布
   > 读数（在册区间套滞后实测可作宿主，commit bae484e76b），κ=1（确认垫 = 一个完整
   > 次级别走势）是其**保守上界**而非结构精确值（偏长方向 = 远离致命失效模式，安全侧）。
4. **网格离散化**：到期日 = min{T ∈ 市场到期网格 : T − t₀ ≥ D_min}。网格由市场给定
   （§6.2 实测），选最近满足点。
5. **网格选择细则**（D_min 与 τ_m(j,p) 之间存在多个网格点时）：比较「更远到期的
   时间价值差价」vs「期望 roll 次数 × roll 摩擦」——两个市场可观测量，取总摩擦小者
   （35:30 成本最小化语法授权）。
6. **分位 p 的诚实地位（质询后降级——原"P50 零参数钉定"声明撤回）**：
   "典型 = 中位数"不是结构推导，是统计常识的借用；两侧兜底论证（右尾 roll/左尾
   平仓兑现）对任何分位同样成立，因此**兜底机制证明的是系统对 p 鲁棒，不是 p 被
   结构唯一确定**。且两侧代价不对称（右尾 = roll 摩擦 ∝ spread regime；左尾 =
   多付 TV ∝ √T 定价）⇒ 最优 p* 是（σ_IV × spread regime）的函数。严格表述：
   > **p 是一个有界后果的留白参数**（53:34 配额留白同状态）——D_min 的结构骨架
   > （= 三个结构对象的时长之和）零参数；把每个对象时长塌缩为哪个分位，是回测
   > 裁决域的一维扫描，本文推演取 P50 作初始猜测并显式标注。
   分位角色区分（消解质询指出的 P50/P75 不一致）：D_min 用中心分位（初始覆盖猜测，
   错误由 roll/平仓兜底）；§10.4 中枢老化判据用上分位 P75（尾部检测问题，问的是
   "是否已异常老"而非"典型多长"）——两处是不同问题的不同统计量，非同一量的两个取值。

**自检（修正后）**：D_min 的**结构骨架**（覆盖对象 = alive 中枢剩余 + 离开段 + 确认垫，

options-selector 在册"T_target_上限 + 45 天 buffer"被取代：T_target = 首波结构时间，

这是 49:76 容量帽的**时间维形态**——6 课「盘子都太小……容纳不了太大的资金」是

### 10.4 roll 触发的精确结构判据（DTE 三区 × 相位 × 账本相）

DTE 三区（全结构涌现）：

- **操作区**：DTE > 2·τ_m(j−1, P50)
- **垫区**：τ_m(j−1, P50) < DTE ≤ 2·τ_m(j−1, P50)——剩余时间够一个次级别走势 + 确认，
  不够再等一个完整中枢周期
- **禁区**：DTE ≤ τ_m(j−1, P50)——连一个次级别走势的确认都等不起（22 课「别碰快到期
  的权证」的形式化）

| 相位 ＼ DTE | 操作区 | 垫区 | 禁区 |
|---|---|---|---|
| MoveDown 锁定 | 正常操作（短差/满空义务） | **roll**（结构延续 + 时间不足）。CostReduction 相 = 义务评估；Earning 相 = 自由滚动条件检查（新权利金 ≤ Σrealized 则滚，否则兑现离场亦不亏） | 强制平仓 → 立即按当下结构重建新合约（被动 roll，两笔，多付一次 spread；n_forced_roll 计数可观测） |
| Osc（中枢震荡依旧） | 短差节律 | roll 评估：alive 中枢 age ≫ τ_q(j,P75) ⇒ 中枢老化、离开临近 ⇒ 持残值待方向；否则 roll | 强制平仓；持币等待方向 |
| candidate 反向买点 | 停开新腿，持仓观察 | **不 roll**（candidate + 时间不足 ⇒ 战役大概率终结），垫区底线平仓 | 强制平仓 |
| confirmed 反向买点 | **平仓**（战役终，残值含时间价值全兑现） | 平仓 | 平仓 |

**roll 是结构事件而非日历事件的严格表述**：触发条件 = （DTE 区间转移）∧（相位值），
两个输入都是引擎可观测量的确定性函数——与 triad §5 七事件表同语法。
**固定周期 roll（日历驱动）违反维护定理，禁止。**

**禁区的 Earning 相豁免（质询修正，26:34 实证驱动）**：矩阵禁区列的强制平仓条款
**适用域 = CostReduction 相（pb > 0 的有成本仓位）**。Earning 相（pb ≤ 0 免费仓）
在禁区持仓合法——免费仓的最坏结局 = 到期蒸发 = 零损失，「任何等待都等不起」的
论证前提（等待有成本）对它不成立。原文实证恰是此形态：26:34 缠师持**负 2.8 元成本**
的认购权证到「最后几天」借末期上涨完全出掉——禁区内持仓操作的唯一在册记录，
其前提正是成本深度为负。豁免不改变禁区对开新腿/回补的禁止（短差循环仍不可开——
循环本身有成本）。

### 10.5 走势 × 到期的全场景穷举（处理规则）

1. **走势延续 + 垫区触发** → 主动 roll（原子 combo 双腿同时成交，零裸露期）。
   roll 净成本（新权利金 − 旧残值）进战役级 Σpremium_paid——**结构持有成本的物质形态**
   （编排者裁定采纳）。roll 不是短差（§2.5：跨工具断面，非同一对象的守恒循环）；
   roll 两腿的拆分择时（平旧在认沽高点/开新在回调底）= 收益机会 + 战役方向裸露期，
   默认禁止，列开放轴（§12 矛盾 11）。
2. **走势延续 + 跳空进禁区**（流动性中断/缺口）→ 强制平仓 + 重建 = 被动 roll。
3. **走势延续 + earning 已达成** → 自由滚动条件检查：Σrealized ≥ Σpremium_paid +
   新权利金 ⇒ roll（战役以已实现利润滚动，零净投入）；否则兑现离场（亦不亏——
   有限期不败的战役级形态）。
4. **走势提前终结（confirmed 反向买点）+ 大量剩余时间价值** → **立即平仓**。
   剩余时间价值是**可回收资产**，随平仓价兑现 = 利润组成部分（编排者问题"利润还是
   沉没成本"的裁决：已付权利金才是沉没的，残值是市值资产；让它自然消耗 = 主动放弃
   资产，违反严格性）。15 课「根据5分钟线的背弛出了」= 背驰点兑现全部残值的原文示范。
   **唯一合法的"自然消耗"域**：残值 < 平仓摩擦（深 OTM 废纸，卖出 spread 成本超过
   所得）——此时放弃是严格最优。
5. **战役终结判断错误（平仓后走势又延续）** → 重新开仓 = 新战役（结构重新给卖点；
   与在册"卖点后又有卖点"同语法）。重入成本 = 双倍 spread，由确认纪律（confirmed
   而非 candidate 触发平仓）钳制频率。

### 10.6 theta 成本门 = 35:30 的第三个载体实例（同构证明）

**35:30 在册形式**（线性）：θ_q(j) ≥ K_f · friction_RT（[positional_fusion.rs:85] ②门）。
triad §6 已扩展至合约载体：friction_RT 须含持仓期 × 资金费率项。

**期权侧推导**：级别 j−1 短差腿在期权 K 线上的一个循环——
兑现（期权坐标）= Λ·θ_q(j−1)·P（标的级别振幅经弹性放大）；
摩擦 = spread_RT·P + Θ·τ_cycle(j−1)。两边除以 P，得无量纲门：

> **θ_q(j−1) · Λ ≥ K_f · (spread_pct + tv_burn(j−1))**，
