## P0-a：BRN depth=2 分型模式（L2，BRN 单标的）

depth=2 入口——已追加 `V2ofF2`（config.rs 配置表 4 行，零引擎逻辑改动）。
双守卫过：磁带指纹逐字相等 + V2of/V2ofF1 在册值逐位复现。

## P1：成本门 + 41课门四格消融（L2×2 标的；门机制结论 L3 与 P0-c 互证）

实现（纯 Rust，默认全关，cargo test 104 过 0 败，O0≡P5 四面对账 PASS，裸格在册值逐位零漂移）：
- **成本门** `sub_cost_gate`：θ_eff = max(θ_q, sub_cost_k×sub_friction_rt)，θ_q 为该层中枢振幅
  DepthRef 因果滚动中位数（零前瞻）；参照不可定义（bi 级/warm-up）保守拒绝并独立计数。
- **41课门** `sub_l41_gate`：新模块 `trend_exhaustion.rs`——父级别相邻同向段创新高/新低 ∧
  段窗口内无盘整背驰 = 趋势未完 = 拒开（38课可编码形式）。
- 变体 `V2ofF1c` / `V2ofF1g` / `V2ofF1cg`。

**四格表**（Δpp vs 裸 V2ofF1）：

| 标的 | 裸 | 仅成本门 | 仅41课门 | 双门 |
|------|-----|------|------|------|
| OKLO | +1425.41%（236对/39.4%/净−8448.6） | +1499.20（**+73.8pp**，0对） | +1451.81（**+26.4pp**，225对） | ≡仅成本门 |
| BRN | +58.72%（59对/54.2%/净+6153.5） | +48.94（**−9.8pp**，1对） | +58.67（−0.06pp，52对） | ≡仅成本门 |

**门触发率**：成本门 OKLO 100% / BRN 98.3%——全部走"参照不可定义⇒保守拒"分支
（F1 子腿主战场是 bi 级，无中枢事件流），可观测作用 ≡ bi 级关闭，与 P0-c
"BRN ladder2 比值 1.83<2"互证（BRN bi 级实得毛短差 0.186%/对 ≈ P0-c ladder2 P50 0.183%）。
41课门 OKLO 4.7% / BRN 11.9%——**非恒开非恒关，死门判据不成立**（41课门时效错配恒开先例首次被超越）。

**判决**：
- 成本门 = **亏损有界化开关**（OKLO 短差全亏 −8448.6 被全额收复 / BRN 正贡献上界 ~10pp 且零摩擦高估），
  不是 alpha 增强器——与 35课原文角色一致（排除无意义级别，不挑选有意义交易）。
- 41课门 = **唯一在两个相反 regime 都不恶化的门**（负 regime +26.4pp / 正 regime 中性 −0.06pp），
  值得 CL/GC 下一票复验。
- 承重边界：成本门效果几乎全部来自保守拒分支——若改为参照不可定义时放行，效果归零。

## 下游推论（执行序更新）

1. **θ 相对化升为第一序中的第一位**：P0-b（第四次失配）+ P0-c（机理定量：跨标的 21× 量级差）
   双向收敛。P1 的 θ_q 因果滚动中位数基础设施已落地，可直接复用到父 REV 腿的 θ_depth。
2. **深度轴关闭**：depth=2 不投入（N=1 域稀疏）；若再裁决在 CL 做 L3，但优先级低于 θ 相对化。
3. **CL 秒级重测排队**：θ 相对化落地后重跑 P0-b（需注册 V2oa25F1 组合变体）。
4. **41课门 CL/GC 复验**：唯一双 regime 不恶化的门，下一票在油链/金上裁决。
5. **成本门默认开启的条件**：仅当接受"参照不可定义⇒保守拒"的语义（bi 级一律关闭）。
   P0-c 表明这恰好是正确语义（QQQ/BRN/CL 塔底确实不划算，OKLO 例外由 θ_q 分支自然放行——
   但当前触发数据中 θ_q 分支几乎未被行使，OKLO 例外的放行路径尚未被真实数据检验）。
