## 0. 一句话结论

5 个假说中**0 个确认成立、3 个否证、2 个待定**。这是一组**以否定性结果为主的诚实 L2 输出**——按 `formalization-validity-domain` 规则，否定性结果缩小有效域边界，比未能否证的"成立"更有价值。最有信息量的两个发现：(a) **缠论级别不是 persistence 的离散簇，而是连续谱**（h1 否证，跨绝对/对数尺度稳健）；(b) **alive 分量数 = 盘整/震荡分化度，与 MACD 力度负相关**（h4 否证原方向，ρ=−0.418，p≈2e-55），L2 实证支持了 §14「alive 是结构量非动量量」。

## 1. 理论先验（决定结果解读）

`docs/persistence_theory.md` §5/§13/§14 已**先验地**证明一个有效域边界：persistence ≈ **幅度** ∈ ker(D)（时间盲、动量盲），而"背驰/力度" = **MACD 动量**，落在 PH 框架之外（§14「纯拓扑动量不可能」定理）。

| 假说 | 先验预期 | 实测是否符合 |
|------|---------|-------------|
| 1 级别 | 幅度的分层是纯幅度量，在有效域内，可能成立 | ✗ 否证（连续谱，非离散簇）|
| 2 中枢 | 震荡=环，几何形态不依赖动量，可能成立 | ~ 方向支持未显著 |
| 3 背驰 | W 捕幅度非力度 → 弱信号/部分否证 | ✓ 待定（≈随机）|
| 4 力度 | alive=结构量≠动量量 → 弱/无相关 | ✓✓ 否证且反向（强负相关，揭示语义）|
| 5 量价 | 探索性，无强先验 | — 否证（不可分）|

## 3. 逐假说：方法 / 结果 / 解读

### 假说 1：级别 = persistence 聚类 — **否证（稳健）**

**方法**：全历史 close 跑 `OnlineMergeTree` → finalize 收集 1703 个 settled persistence。τ(ATR) 过滤噪声 → 去重 log 值 → Hartigan dip 多峰检验。**控制混淆变量**：persistence 用绝对价格差，而 QQQ 价格 20→738，绝对幅度跨 regime 差几十倍 → 同时在**对数价格**（收益率尺度 = 级别的尺度不变量）下重测。

**结果**：
- 绝对价格：n>τ=401，τ=2.70，**dip_p=0.485 → 单峰（连续谱）**。
- 对数价格：n>τ=482，τ=0.0206，**dip_p=0.760 → 单峰（连续谱）**。

**解读**：两种尺度下 persistence 分布都**不可拒绝单峰**（dip p≫0.05）。级别**不是数据里的离散 persistence 断层**，而是连续谱。这与缠论级别的本性相容——**级别是相对/递归的**（由观察者选择的尺度决定，缠师："级别是相对的"），不是绝对的幅度簇。首轮的"成立"是 log-gap 判据在大量近重复微值上退化（median_gap→0）造成的**假阳性**，已用 dip 检验推翻。

> **诚实修正记录**：首轮因 `median_gap≈5e-6` 导致显著性比值虚高 31 万倍 + 簇大小 `[20,1680,2,1]`（主簇+离群，非级别带）误判"成立"。修正：τ 过滤 + 去重 + IQR 稳健 gap + dip 多峰检验 + 对数尺度对照。

### 假说 2：中枢 = H1 persistent cycle — **待定（方向支持，未显著）**

**方法**：从 GT 笔线按缠论定义（连续 ≥3 笔，重叠区间 ZD=max(各笔低)<ZG=min(各笔高)）贪心构造 51 个中枢，测试其中 span 足够的 29 个。每个中枢区间 close 子序列做 **Takens 延迟嵌入**（dim=3，delay 扫 {1,2,3,5} 取最大）→ ripser H1 max-persistence。对照：等长度随机趋势窗口（避开中枢）。单边 Mann-Whitney U。

> **方法修正（关键）**：初版用 `(t, price)` 点云，得到中枢/趋势 H1 **均为 0**——因时间轴单调使点云永不闭环（§8「单调路径 H1 恒空」）。中枢的"环"只在**相空间**显现：Takens 嵌入把"价格回到先前水平"的震荡变成闭轨（极限环 → H1≠0）。改用 §2 规定的 Takens 方法后信号出现。

**结果**：中枢 H1 中位数 **0.156** > 趋势 H1 中位数 **0.083**（约 1.9 倍），**方向支持假说**；但 MWU p=0.225，**未达 0.05 显著**。

**解读**：中枢区间的相空间确实比趋势更"成环"（H1 更高），符合"震荡=环"的拓扑直觉，但 n=29 样本 + 笔构造中枢的不纯净（笔级中枢 ≠ 标准次级别走势中枢）使其未达显著。**信号方向正确但证据不足以确证**——这是最有希望在更大样本/更纯中枢定义下转为"成立"的假说。

### 假说 3：背驰 = Wasserstein 距离递减 — **待定（≈随机）**

**方法**：GT 笔线 → 每笔 close 子序列的 sublevel H0 diagram。同向三腿 A→B→C（A、C 同向，B 反向回调），比较 diagram Wasserstein-1 距离 d(A,B) vs d(B,C)（含对角线最优匹配，`linear_sum_assignment`）。二项检验递减率 vs 0.5。

**结果**：59 个同向三元组，递减率 **0.576**，**二项检验 p=0.298（不显著）**。

**解读**：递减率略高于随机但不显著。符合理论先验（§13/§14）：Wasserstein 度量 persistence diagram 的**幅度差异**，捕捉不到"力度衰竭"（MACD 动量）——而背驰的本质是力度衰竭。**边界**：用 GT **笔级**测背驰是**级别错配**（背驰本属段/走势级），这是弱结果的一个已知混淆。

### 假说 4：力度 = alive 分量数量 — **否证（原方向相反，揭示语义）**

**方法**：流式 merge tree，在每个 settle 事件（1282 个）记录当时 alive 分量数 与 |MACD hist|（标准 12/26/9）。Spearman 相关，按**方向**判定（原假说预期正相关：alive 多=力度强）。

**结果**：**ρ=−0.418，p=2.2e-55**（极强显著的**负**相关）。alive 分量数 1~50。

**解读**：原假说"alive 多=力度强"被**方向性否证**——实际是 alive 多时 MACD 柱**更小**。这揭示了 alive count 的真实语义：**alive 多 = 多个未完成下跌分量并存 = 盘整/震荡分化剧烈 = MACD 动量小（柱接近 0 轴）**；alive 少 = 单边推进 = MACD 柱大。**这是 L2 实证支持 §14**「alive 是结构量（盘整度）非动量量（力度）」——alive count 与力度负相关，正因为它度量的是**结构的横向分化**而非**纵向动量**。这是本报告信息量最高的发现。

### 假说 5：量价联合拓扑 — **否证（不可分）**

**方法**：close+volume 30 根滑窗 → 2D 归一化点云 → ripser H1。量价背离窗口（价/量斜率反号，287 个）vs 正常窗口（168 个）的 H1 可分性（MWU）。

**结果**：背离 H1 中位 **0.211** vs 正常 **0.208**，**MWU p=0.775（完全不可分）**。

**解读**：close+volume 联合 H1 在背离/非背离窗口几乎无差异。**边界**：本"背离"是粗糙操作化（30 窗内价/量斜率反号），不是缠师/技术分析意义的量价背离（顶背离需价创新高而量缩）；且 H1 度量的是 (close,volume) 平面的环结构，与"量价配合度"无明确理论联系。此否证针对**这个特定操作化**，不否证"存在某种量价联合拓扑信号"的更一般命题。

## 4. 讨论：有效域边界

本验证把缠论 5 概念投射到 PH 拓扑量上，结果**系统性地落在 §5/§13/§14 预言的有效域边界内**：

1. **纯几何/幅度概念**（级别、中枢）落在 PH 有效域**内**，但：
   - 级别（h1）虽是幅度量，却是**连续谱非离散簇**——PH 能度量幅度，但"级别"作为离散分层不是数据的内禀属性，是观察者施加的相对尺度。
   - 中枢（h2）的"环"在相空间可见（方向支持），是 5 个里最接近成立的——震荡的拓扑环是真实的几何信号。
2. **力度/动量概念**（背驰、力度）落在 PH 有效域**外**：
   - h3 W 距离 ≈ 随机、h4 alive 与力度负相关——都印证 persistence/alive 是**幅度/结构**量，捕捉不到 MACD 动量。h4 的强负相关进一步**正向刻画**了 alive 的真实语义（盘整度）。
3. **量价联合**（h5）在当前粗糙操作化下无信号。

**总命题"缠论概念=PH 拓扑量"在 L2 上被显著削弱**：对应关系存在但**不是同构**——PH 捕捉缠论的形态学/幅度半边（级别的尺度、中枢的环），系统性地丢失动力学/力度半边（背驰、力度）。这与 §19.1.1「买卖点 = settle 阶梯转折点（形态学，PH 内）× 背驰（动力学，MACD，PH 外）」完全一致。

## 5. 结果包六要素

1. **结论**：QQQ 日线 L2 检验下，缠论 5 概念与 PH 拓扑量的对应关系：级别**否证**（连续谱）、中枢**待定**（相空间 H1 方向支持未显著）、背驰**待定**（≈随机）、力度**否证且反向**（alive=盘整度）、量价**否证**（不可分）。无一确认同构。

2. **定义依据**：
   - 级别/中枢/笔/买卖点的 ground truth 来自 TV「Chan Theory - CHANLUN \| CZSC」指标（缠论标准定义的第三方实现）。
   - PH 量：H0 settled persistence（`a_online_persistence` 因果 merge tree，settle 判据 = §10.1 分型确认拓扑形式）；H1 = ripser Vietoris-Rips（§2 Takens 嵌入）；MACD = 标准 12/26/9（§5 动力学基线）。
   - 中枢定义依据缠论"≥3 次级别走势重叠"（此处用笔近似，ZD=max 低 < ZG=min 高）。

3. **边界条件（结论翻转条件）**：
   - h1：若改用按 regime 分段的 τ、或非 ATR 的级别先验、或更长跨度标的使各级别样本充分分离，连续谱可能转为多峰 → h1 可能翻转为成立。
   - h2：若用更大样本（多标的/更长史）、或用标准线段级中枢（非笔级近似）、或优化 Takens (dim,delay)，p 可能跌破 0.05 → 转成立。
   - h3：若用**段/走势级**腿段（非笔级）对齐背驰的真实级别，或改用含时间轴的力度代理，递减率可能显著。
   - h4：方向已极稳健（p=2e-55）；翻转需 alive 语义重定义。
   - h5：若用缠论标准量价背离定义（价新高量缩）替代斜率反号，可能出现信号。

4. **下游推论**：
   - 「缠论概念 = PH 拓扑量」**不是同构**，是**形态学半边的投影** → 任何用 PH 单独复现缠论买卖点的尝试都会丢失力度半边（印证 §19.1.1 + pending-013「PH 不能扬弃 MACD」）。
   - alive count 可作为**盘整度/震荡分化**的独立指标（与 MACD 负相关，提供正交信息），但**不可**作为力度指标（声明膨胀禁止）。
   - 级别检测**不能**靠 persistence 的绝对聚类（连续谱）→ 级别必须由递归/相对尺度定义（§7.3「树深度=级别」已被否证，本报告进一步否证「persistence 簇=级别」）。

5. **谱系引用**：
   - §5/§13/§14（PH vs MACD 不可约分野）、§7.3（树深度≠级别）、§8（单调路径 H1 恒空）、§10.1（settle=分型确认）、§19.1.1（买卖点=形态学×动力学）。
   - 231 号 formalization-validity-domain（有效域≠定义域）：本报告 5 个否定/待定结果是有效域边界的 L2 实测。

## 6. 可塑形的决策点（learning mode）

以下是结论依赖、但有多种合理实现的真实决策点——如需用领域知识塑形，可改对应函数后重跑：

- **h1 级别聚类方法**（`cluster_levels`）：当前 = τ 过滤 + Hartigan dip。替代：按价格 regime 分段归一化后再测、KDE 谷值、GMM+BIC。关键问题：「级别」应是数据内禀断层，还是观察者施加的相对尺度？本报告结果倾向后者。
- **h2 Takens 嵌入参数**（`takens_h1`）：当前 dim=3，delay∈{1,2,3,5}。中枢震荡周期未知 → 嵌入维度/延迟的选择影响 H1 灵敏度。这是 h2 从"待定"转"成立"的最可能突破口。
- **h3 背驰的级别口径**：当前用 GT 笔级三元组（级别错配）。改用段/走势级腿段是修复弱结果的方向。
