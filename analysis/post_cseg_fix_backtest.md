1. **O0≡P5 守卫三标的全 PASS**（修复后磁带上 trades/trace/counters 逐位对账）——
   C段修复对 legacy 路径零侵入，基线锚定成立。
2. **V2r（只接 type1/盘背卖开 REV + 振幅 θ=1% 门 + kind 配对闭腿）≡ V2of**：
   任务规格与在册 V2of 配置逐位相同，落为 `config.rs` 显式别名（O0/V0 同一先例），
   三标的重跑数字与 V2of 逐位一致（确定性引擎 + 同 tape_fp）。
3. **V2r 三标的判决：OKLO 强正 / QQQ 中性偏负 / BRN 弱正**——非全域正，
   有效域 = REV 腿稀疏且锚中枢振幅大的标的（OKLO 185 腿 Δ+410pp；
   QQQ 深度门近乎清空 3 腿 Δ−3.5pp；BRN 77 腿 Δ+19.8pp）。
4. **逃逸型开腿在修复后磁带上继续被否证**：V2f（含逃逸型）vs V2r（关逃逸型）
   三标的一致 V2r > V2f（OKLO +1499 vs +516；QQQ +97 vs +94；BRN +48 vs +74 例外，
   但 BRN V2f 的逃逸腿现金 +11.9K 是修复后唯一转正样本，见 §4）。
5. **C段修复重排了 REV 的全口径**：P5 基线本身漂移（OKLO 741→1089 / QQQ 108→101 /

## 5. 判决

- **V2r（=V2of）是修复后磁带上 OKLO 的最优 REV 形态**（+410pp，仅次于无门 V2o
  +537pp），但**不是全域改进**：QQQ 的 θ=1% 门与 1min 中枢振幅量级失配（腿数清空），
  BRN 的弱正不敌 V2f（逃逸型 BRN 转正的单点效应）。
- **REV 配对修正的核心主张在修复后磁带上存活**：震荡型胜率 51.7–58.4%（三标的
  全 >50%），逃逸型 OKLO/QQQ 仍为负——与修复前同向，结论对 C段修复鲁棒（L3）。
- **V2f（含逃逸型 + θ门）不可作为默认变体**：OKLO −573pp 是三标的最深负值，
  逃逸型 −142K 现金主导。默认 REV 形态推荐 V2r。

## 6. 结果包六要素

1. **结论**：见 §1/§5。O0 守卫 PASS；V2r≡V2of 别名落地；V2r 判决 OKLO 强正/
   QQQ 中性/BRN 弱正；逃逸型继续否证（BRN V2f 单点例外存疑）。
2. **定义依据**：REV 开腿 = confirmed Sell1（type1 卖）∨ DivKind::Consolidation
   盘整背驰卖（`level_operating_unit.rs` rev_paired_open，第38课 RIDE↔REV）；
   深度门 = (ZG−ZD)/price ≥ θ_depth（中枢振幅，第20课中枢区间）；kind 配对闭腿 =
   同锚 confirmed Buy1（震荡型）/趋势衰竭 Buy1（逃逸型），异锚拒闭。
3. **边界条件**：①θ=1% 门的有效域排除 QQQ 类低振幅 1min 标的——若 θ 改为分位数
   自适应，QQQ 判决可能翻转；②BRN 逃逸型 +11.9K 若在其他期货标的复现，
   "逃逸型一致为负"的否定翻转；③结论绑定修复后引擎代次（tape_fp bsp=10706/24941/63978），
   引擎再变更则全表作废；④P5 基线漂移（尤其 BRN 488→28）意味着 Δ 的分母本身
   不稳定——若后续修复再改 BSP 语义，Δ 符号可能翻转。
4. **下游推论**：①M2 信号层若消费 REV 变体，默认应取 V2r 而非 V2f；②BRN 旧
   P5 alpha 大部分是 C段伪背驰伪影，所有引用修复前 BRN 数字的在册文档需要标记
   代次；③QQQ 需要 θ 自适应实验（新工位候选）。
5. **谱系引用**：532号（seg-end 触发轴分离）；`project_bsp_gap_root_cause`
   （C段恒空根因）；`project_c_segment_fix_b2`（B2+修复A）；`project_rev_paired_fix`
   （配对修正首跑：θ量级失配、逃逸型三标的全负）；090号（声明=能力：V2r 不复制
   配置而用别名）；231号（认识论等级标注）。
