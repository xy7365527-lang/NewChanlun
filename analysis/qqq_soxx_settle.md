## 0. 方法论：镜像树对偶（卖点 = 上涨分量 = 喂 −price）

`OnlineMergeTree` 是 **sublevel-set H0 merge tree**，本质追踪**下跌分量**：valley 诞生、
price 上升越过鞍点 peak 时 settle（下跌腿被反弹吸收）。OKLO 模板正是这个**买点视角**。

本任务是**卖点视角**——「主导上涨分量是否 alive、牛市结构是否 intact」。要读上涨分量，
用 sublevel/superlevel 的**精确对偶**：喂 `mirror = [−p for p in closes]`。

| mirror（−price）空间 | price 真实空间 | 还原 |
|---|---|---|
| 下跌分量 | **上涨分量** | — |
| valley（诞生） | −price peak（上涨腿的顶） | 真实顶价 = −birth_price |
| 屏障 peak（settle 价） | −price valley 屏障 | 真实**跌破价** = −settle_price |
| 「反弹 settle」 | 「**回调跌破鞍点 valley 而 settle**」 | 上涨腿确认完成 |
| 全局最低 valley | **全局最高 peak**（牛市主峰） | **永不被回调 settle** |
| gap_to_settle | 当前价还需**下跌**多少触发该上涨腿 settle | 符号自洽（见脚本 docstring 推导）|

**判读纠正（避免把 trivial 当信号）**：全局上涨主峰（settle_price=None）定义上**永远 alive**
直到序列终止——它 alive 是 trivial 的，**不是**「牛市还在」的有效信号。真正的大级别卖点信号
是**最深的可被回调证伪的上涨腿**是否被 settle，以及**主峰日期是否新鲜**。

**认识论等级**（formalization-validity-domain）：
- 镜像树 + settle 阶梯算法 + sublevel/superlevel 对偶：**L0**（确定性，零信息增量）
- 「上涨腿 settle ↔ 缠论卖点」：**L1**（PH↔缠论同构，需 MACD 动力学层确认充分性，521号）
- 「QQQ/SOXX 当前牛市 intact」：**L2**（单标的真实 5y 日线，可否证）

## 4. 形式化有效域标注（必读）

**级别命名缺陷（L0 在宽幅度谱上失效）**：`adaptive_gap_boundaries`（MAD log-gap）在 ETF 5y
数据上失效——QQQ 上涨腿幅度跨 6 个数量级（0.06 ~ 144），最大 gap 出现在极端值之间，
中段无显著 gap → 幅 0.8 与 42 的腿被挤进同一「周线级」带，而 <$0.5 的噪声腿被虚假分成多个
「日线级」带。SOXX 更甚（36 腿挤进单一「月线级」带）。

**本报告的补偿（无 workaround，明确声明）**：
- 上涨阶梯一律先用 **τ(ATR 噪声阈)过滤**噪声腿（QQQ 12/42、SOXX 7/39、MOS 1/1 存活）。
- 级别档改用**回撤百分比人为标尺**（RETRACE_BANDS：0-3/3-10/10-20/20-35/>35%）呈现，
  **明确标注这是操盘标尺，非数据内生级别**。中枢的 period_label 仍来自算法，仅作参照。

此缺陷不影响核心结论（主峰日期、中枢数、买点腿数、跌破价均不依赖级别命名）。

## 5. 结果包（六要素）

1. **结论**：QQQ/SOXX 主导上涨分量均 alive 且主峰新鲜（牛市 intact），大级别卖点未确认；
   QQQ 卖点线 558（−24%）、SOXX 卖点线 496（−13%）；两者方向同步但 SOXX 结构脆弱（断崖阶梯/单中枢）；
   MOS 与两者脱钩，处熊市/筑底。

2. **定义依据**：
   - 上涨分量 = sublevel/superlevel 对偶（喂 −price），`a_online_persistence.OnlineMergeTree` +
     `a_settle_trigger.settle_triggers`：全局上涨主峰 `settle_price=None`（`alive_settle_thresholds`
     栈底幸存者），**永不被回调 settle** → 其 alive 为 trivial；有效信号取**主峰日期新鲜度** +
     **最深可证伪上涨腿 settle 状态**。
   - 中枢 = `a_ph_zhongshu.detect_zhongshu`（同层 ≥3 重叠摆动），≥2 同向中枢=趋势（缠论第17-19课）。
   - 顶背驰前提 = `score_buypoint` 镜像树 amplitude_decay（**形态层振幅收窄，非 MACD 力度背驰**，521号）。
   - 近端回调买点 = 原树 `settle_triggers` 可反弹 settle 的下跌腿（反弹升破 settle_price = 次级别买点确认）。

3. **边界条件（结论翻转条件）**：
   - QQQ 牛市结束 ⟸ 收盘**跌破 558.28**（月线级上涨腿被回调 settle）；日线级预警 ⟸ 跌破 701.53。
   - SOXX 牛市结束 ⟸ 收盘**跌破 495.87**（周线级，且破位后易加速至 310 区）。
   - 「同步」翻转 ⟸ 任一标的出现顶背驰（amplitude_decay 显著 >0）或主峰日期停止更新（不再创新高）。
   - 级别命名结论**不**因 adaptive_gap 缺陷翻转（核心量不依赖级别名，见 §4）。

4. **下游推论**：若 QQQ/SOXX 主导上涨分量 alive 成立 → 当前所有回调在跌破各自卖点线前是买点机会；
   SOXX 因断崖结构应作为「大级别卖点的早期预警标的」（比 QQQ 更早确认）；
   MOS 熊市结论 → 不应以「金油比下降/资本旋转」叙事在 MOS 上做多上涨结构（其上涨分量已 settle）。

5. **谱系引用**：
   - 本分析的**镜像树对偶**（卖点=上涨分量=喂 −price）是 OKLO settle_ladder（买点视角）的对偶，
     属同一 §7.5 在线因果 merge tree 框架，**无新概念分离**，是已知 sublevel/superlevel 数学对偶。
   - 521号：形态层振幅 ≠ MACD 力度背驰（amplitude_decay 仅 L1 必要条件，真顶背驰需动力学层）。
