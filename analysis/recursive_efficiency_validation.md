## 五、递归深度分析

### 为何未达 3 层？

递归深度公式（近似）：
- L1 走势 = L1 线段数 ÷ ~20（每个走势平均含 ~20 线段）
- L2 走势 = L1 settled 走势 ÷ ~5（每个 L2 走势平均需 ~5 个 L1 走势）
- L3 走势 = L2 settled 走势 ÷ ~5

**到达 L3 的估算**:
- 需要 ≥3 settled L2 走势
- 需要 ≥15 settled L1 走势（当前 1min: 10, 5min@30K: 14）
- 1min 数据需要 ~6-9 个月（当前 3 个月）
- 5min 数据需要 ~50K-70K bars（当前 30K 产出 14 settled L1 走势）

**结构性限制**: QQQ 长期上涨趋势使得 L1 走势虽然方向交替，但递归到 L2 后倾向于形成一个大趋势——除非有足够大的回调（如 2025 年 1 月以来的下跌段 ~596→555）来打破 L2 级别的单边性。

## 边界条件

- 本报告基于 `stroke_mode="new"`, `min_strict_sep=5` 参数
- 笔中枢路径（HK700）使用自定义 `StrokeAsComponent`，不经过 `RecursiveOrchestrator`
- 性能数据受机器状态影响，ms/bar 值仅供参考
- bar 索引映射：笔的 i0/i1 指向原始 bar 索引，但价格来自包含处理后的 K 线（缠论正确行为）
