# 反向走势内部次次级别递归赋格——终极形态设计调研

> 任务：纯设计调研（不改代码）。voice 的 REV 腿当前是"一根整腿"（开→闭），
> 反向走势自身的次级别结构未被操作。本文回答：递归肢解的严格形式是什么、
> 缠论原文依据何在、现有架构离它多远、递归到哪里停。
>
> 调研输入：第38课/第40课博文原文（一级权威）、`rust/src/trading/runner.rs`、
> `level_operating_unit.rs`、`master.rs`、`types.rs`（SlotKey）、`config.rs`（θ门）。

---

## 0. 结论先行

1. **38课程式本身就是递归的**——不需要外加递归概念。程式的方向对称性
   （"向下段的运作刚好相反……所有操作刚好反过来就可以"）+ 每段判定依赖
   "内部结构"（区间套）⇒ 程式在任意方向、任意级别上是同一个程式。
   当前 REV 腿是38课向下段程式的**双重截断**：纵向截断（次级别反弹未被操作）
   + 程式截断（只做一个卖买来回，原文要求"这个过程可以不断延续下去"）。
2. **自相似性已在代码中存在但未被命名**：`MasterState::Ride/Rev` 与
   `VoicePhase::UpLeg/DownLeg` 是同一个二态 FSM 在相邻级别的两个实例。
   递归赋格 = 把这个已存在的同构显式化为单一的方向参数化节点类型。
3. **递归深度由数据自动有限**：深度 = `k − FIRST_BSP_LADDER`。entry_ladder
   典型 4-5 ⇒ 最深 voice (k=4) 的递归深度为 2。"任意深度"在当前数据上是
   深度 ≤ 2 的有限集——递归定义不需要人为深度上限。
4. **θ_depth 不是完整的终止条件**。严格的终止是三个范畴不同的条件的合取：
   存在论下限（FIRST_BSP_LADDER，无中枢=域不可定义）、经济下限（振幅<往返
   摩擦=必亏）、结构门（θ_depth=可兑现空间）。θ 只是第三个。
5. **架构改动评估：中等偏大**，分解为三块：SlotKey 路径化（大）、LOU 方向
   参数化+子节点递归（中）、runner 组装（小）。但在投入大改前存在一个
   **必须先做的 L2 实验**——已有的否定性证据链（bar 级 churn 毁 −11973、
   shared fugue bar0 爆仓、降成本层多次负 alpha）表明"更细的短差"先验上
   更可能是负的。递归第一层（深度1反弹腿）的经验有效性未被验证前，
   全量架构递归化是无验证的形式化（formalization-validity-domain：L0 代数
   成立 ≠ L2 经验成立）。

## 1. 缠论原文的递归操作（38课/40课精读）

### 1.1 第38课："分区卷钱的机械"是什么结构

原文（38课正文）：

> "你的资金有一定规模，那么你可以设定某个量的筹码按某个级别的分解操作，
> 另一个量的筹码按另一个更大级别的分解操作，这样，就如同开了一个**分区
> 卷钱的机械**，机械地按照一个规定的节奏去吸市场的血。"

结构读出：

- **分区是资金维度的并行，不是级别维度的嵌套**。每个分区 = (一份筹码,
  一个固定级别, 该级别的同级别分解程式)。各分区独立运转，无主从关系。
- 机械性来自同级别分解的唯一性（"缠中说禅走势分解定理"）：每个分区内
  不存在判断歧义，操作完全由该级别的分解节奏决定。
- 利润来源声明："利润是与时间成正比的"——卷钱机的 alpha 是振荡兑现，
  不是方向判断。这与本仓库 P3 判决（alpha 来自暴露非择时）方向一致，
  但缠师声称的是另一个利润源：**同一段行情在 N 个级别上被各兑现一次**。

### 1.2 第38课操盘程式的递归性（关键文本）

38课"（买卖）"段给出的程式（向上段）：

> "先卖出，然后必然有向下的第二段……在第二段重新买入的情况下，然后出现
> 向上的第三段……**这个过程可以不断延续下去**，直到下一段向上的走势类型
> 相对前一段出现不创新高或者盘整背驰为止……一旦向上段的运作结束后，就
> 进入向下段的运作。**向下段的运作刚好相反，是先卖后买……所有操作刚好
> 反过来就可以**。"

三个递归要素全部在原文中：

| 要素 | 原文位置 | 含义 |
|------|---------|------|
| 方向对称 | "刚好反过来就可以" | 程式 P(d) 与 P(−d) 互为镜像，同一程式 |
| 循环延续 | "这个过程可以不断延续下去" | 程式不是单次买卖对，是循环直到段终结 |
| 区间套判定 | "根据其内部结构可以判断其背驰或盘整背驰结束点" | 每段操作点由次级别结构定位（27课区间套） |

第三点是纵向递归的入口：程式中每个操作点本身要在次级别上定位，而次级别
定位本身又是一个（更小的）程式。38课答疑进一步确认（stone 问 ABC 段判定）：

> "比较当然是 A 和 C 比，当然还可以参考 C 内部结构确定精确位置，这个
> **背驰段的区间套方法**是一个道理。"

### 1.3 第38课的组合规则自由度（递归设计的合法性来源）

> "同级别分解的次级别分解是否也是同级别分解的。答案是，**不需要**。……
> 只要不违反连接的结合律以及分解的唯一性，就是允许的，而问题的关键在于
> 是否明晰且易于操作。"

这一段给递归赋格的实现以原文级授权：**每一层可以选择自己的分解规则**。
递归塔不要求各层规则同质，只要求各层规则自身保证分解唯一性。当前架构
voice 层用 BSP 事件流 + 中枢账本、master 层用 sell1 布尔行——异质规则的
分层组合是38课显式允许的。

### 1.4 第40课："N重"怎么递归、每一重做什么

40课正文三个关键句：

> "对于大资金来说，这种级别的操作可以一直延伸下去，可以变成 **N重层次的
> 操作，每一重都对应着一定的资金与筹码，而相应对应着不同的节奏与波动**。"

> "在这种同级别分解的多重赋格操作中，可以**在任何级别上**进行操作，而且
> 都**遵守该级别的分解节奏与波动**，只是在不同级别中投入的筹码与资金不同。"

> "**每一层次的操作都是独立又在一个整体的操作中**。"

结构读出：

- **每一重做的是同一件事**：该级别的38课程式（同级别分解 + 向上段先买后卖
  / 向下段先卖后买）。N重之间的差异只有三个参数：级别、资金份额、节奏。
- **"独立又在整体中"**：各重决策独立（每重只看自己级别的分解），但筹码
  在同一个总账上（成本互相影响——某重的兑现降低总成本，改变其他重的
  风险预算）。这正是"仓位共享、各自独立决策"的原文形态。
- **递归的方向是双向的**。40课开头给出的是**向上换档**：
  "A0+A1+…+At = B1+B2"——小级别操作流的累积涌现出大级别分解时，升级为
  大级别操作基础上部分保持小级别操作。当前架构的 `n_exit_upgraded`
  （earning 后出场升级）是这个机制的一个片段。向下肢解（本任务的方向）
  是同一句话的逆读：大级别的一段 B1 内部 = 小级别若干段 A0..At，每段
  都可按小级别程式操作。

### 1.5 原文结构与当前架构的概念差

**40课的 N重是按级别并行（partition），当前架构是嵌套（nesting）。**
缠师的卷钱机里，5分钟分区不知道30分钟分区的存在——两者只共享市场和总账。
当前架构的 voice 只在 master LONG 时存在（`open_position` 创建 voices，
`close_position` 销毁），是 master 的从属。

这个差异不是实现错误，是**单仓位约束下的投影**：当总筹码必须保持
"master 持有"这一前提（股票 long-only、无独立空头账户），并行分区退化为
嵌套——子层只能操作父层敞口的子集。嵌套保留了40课"独立决策 + 共享总账"
的核心，丢掉的是"任何时刻各级别都在操作"（FLAT 时无任何 voice 在场）。
递归赋格设计沿用嵌套投影——这是约束下的严格形式，不是妥协（理由：
子层的操作预算在存在论上就是父层敞口，见 §3.3）。

## 2. 当前架构的递归瓶颈

### 2.1 已存在的自相似性（递归的种子）

```
master:  MasterState::Ride ──sell1@entry──▶ MasterState::Rev ──buy回──▶ Ride
voice:   VoicePhase::UpLeg ──段终结三触发──▶ VoicePhase::DownLeg ──T5/T6/T7/ZD──▶ UpLeg
```

两个 FSM 同构：二态、相位语义相同（顺向持有 ↔ 反向敞口）、转换事件同类
（反向 type1/段终结 ↔ 回补证据）。master 的 earning 反作用 REV 腿
（`runner.rs:431` `SlotKey::rev(entry_ladder, entry_ladder)`）实质上就是
entry 级别的一个 voice DownLeg——代码已经在 master 层复用了 voice 的腿语义。

**但同构未被类型化**：master 与 voice 是两个独立类型，触发谓词各自硬编码
方向（`seg_end_trigger` 只认 Sell 侧、`buy_trigger_at` 只认 Buy 侧）。
递归化的第一障碍不是缺机制，是**方向被硬编码进谓词**。

### 2.2 次级别当前的角色：证据，不是操作者

现有代码里次级别（k−1）出现在四处，全部是**证据消费**：

| 机制 | 代码位 | 次级别角色 |
|------|--------|-----------|
| G1 sub_anchor | `rev_open_verdict` | 开腿前提（k−1 方向行 Down） |
| 区间套关腿 | `nesting_buy_level` / `buy_trigger_at(sub_buy)` | 闭腿确认（k−1 buy_any） |
| R1/R2/R3 | `sub_sell_bar`/`sub_buy_bar`/`sub_up_anchor` | 窗口判据记忆 |
| T4b(c) 加码 | `t4b_addons` | 级别涌现直读（加码方向与 REV 同向） |

没有任何代码位让 k−1 级别在 REV 窗口内**反向操作**（反弹段低买高卖）。
T4b tranche 是唯一的"REV 内多级别"机制，但它是同方向加码（卖出更多），
不是次级别赋格（反弹段的先买后卖）。

### 2.3 REV 腿对38课程式的双重截断

38课向下段程式（先卖后买，循环）：卖出 → 反弹段顶部再卖出?不——向下段
程式是：在段起点卖出，次级别反弹完成处**买回**，下一段下跌起点**再卖出**，
循环直到向下段终结（底背驰）。逐段对照当前实现：

| 38课向下段程式 | 当前 REV 腿 |
|---------------|------------|
| 段起点卖出 | ✓ T1/配对开腿 |
| 第一次级反弹底部买回 | ✗（持腿穿越反弹） |
| 反弹顶部再卖出 | ✗ |
| …循环… | ✗ |
| 向下段终结处最终买回 | ✓ T5/T6/T7/ZD 触线 |

**当前 REV 腿只实现了程式的首尾两个操作**。中间的循环——正是"吃到每
一笔"的部分——整体缺失。这个循环有两种等价的实现视角：

- **横向视角**：REV 腿自身在 k 级别上循环开闭（38课程式直读）。
- **纵向视角**：REV 窗口内挂一个 k−1 级别的 mini-fugue，反弹段是
  mini-master 的顺向腿，反弹内的回落是 mini-voice 的 REV 腿。

两个视角在38课文本中是同一件事（程式的每个操作点由次级别定位 ⇒ 横向
循环的操作点集 = 纵向 mini-fugue 的事件集）。纵向视角是严格形式，因为
它显式保留了级别坐标（横向循环把 k−1 级别的事件冒充为 k 级别的操作点，
违反级别隔离——P6 否定 osc_buy_sub 的同型错误）。

### 2.4 mini-master + mini-voice 的精确形态

voice k 进入 DownLeg（REV 腿开出）后：

```
voice k DownLeg = mini-fugue 的根：
  mini-master：REV 腿本体。持有"反向敞口"（已卖待买回的股数）。
    出场（=买回）信号：k 级别配对闭腿集（T5/T6/T7/ZD）——不变。
  mini-voice (k−1)：在 REV 窗口内运行 38课程式的镜像：
    UpLeg'（=反弹腿）：k−1 级别买侧三岔触发（底背驰/Buy1/Buy2）→ 用
      REV 敞口的一部分买回（先买）；
    DownLeg'：k−1 级别卖侧三触发 → 再卖出（后卖），回到 UpLeg'。
    腿的方向与 master 同号（+），与 voice REV 反号。
```

符号交替塔：depth 0 (master) = +，depth 1 (voice REV) = −，
depth 2 (sub-voice 反弹腿) = +，depth n = (−1)ⁿ。每层的"开腿"动作恰好
是父层敞口的部分平仓，"闭腿"恢复父层敞口——**子层操作 = 父层敞口上的
短差**，与现有 ledger 的 open_diff/close_diff 语义完全一致，只是键空间
要区分归属。

### 2.5 532号 C1 隔离的递归推广（强约束）

532号结算（L3）：master 出场判定与 voice 反向腿触发是两个概念——
`MasterExitSignal` 只接受 confirmed Sell1 布尔行，类型上不可表示三触发。

递归形式下这个分离**在每层复制，不是被消除**：

- 每个节点的"自身终结"（mini-master 出场）= 本级别反向 type1 点（一类
  买卖点是走势终结的本体陈述）；
- 每个节点的"子节点开腿"= 段终结三触发（三触发是子级别反向段的存在
  陈述，不是本级别终结陈述）。

若递归统一把两者合并为一个谓词，等于在每一层重新引入 M-a（master 消费
三触发，−562.5pp 的教训）。**递归节点类型必须携带两个隔离的信号通道**，
这是 532 的直接推论，也是"LOU 是否天然支持递归"的答案：FSM 骨架天然
支持（二态自相似），信号通道需要按 532 双通道化后才支持。

## 3. 递归赋格的拓扑结构

### 3.1 层级塔

```
L_master (entry_ladder, d=+)
└─ L_voice[k] (k ∈ [floor, entry), d=−)        ← 现有 voices 平坦层
   └─ L_sub[k−1] (d=+)                          ← 本设计新增
      └─ L_subsub[k−2] (d=−)                    ← 数据允许时自动出现
         └─ … 直到 k−n < FIRST_BSP_LADDER 终止
```

注意现有 voices 本身是**并行多实例**（floor..entry 每级一个），递归塔
不取代它——每个 voice 都是一棵子树的根。整体结构是"并行根 × 各自递归"，
正好对应40课"每一重独立"（并行）+ 38课"内部结构定位"（递归）的叠加。

### 3.2 域的嵌套（时间×价格双重收缩）

| 层 | 时间域 | 价格域 |
|----|--------|--------|
| master | [entry_bar, exit_bar]（LONG 区间） | 全域 |
| voice k REV | [open_bar, close_bar] ⊂ LONG 区间 | [锚中枢 ZD, 开腿价] |
| sub-voice k−1 反弹腿 | [反弹起点, 反弹终结] ⊂ REV 窗口 | [反弹起点价, k−1 中枢 ZG'] |

域严格嵌套且每层收缩——这是27课区间套的操作化：区间套原本用于定位
（背驰点的逐级收缩），这里用于操作（每个收缩区间本身被兑现一次）。
缠师"同一段行情在 N 个级别上各兑现一次"的利润源，几何形式就是嵌套域
的振幅逐层求和。

### 3.3 仓位共享与预算守恒（INV-1 的递归形式）

单账本（OrganicLedger）+ 路径键。预算约束递归化：

```
budget(node) = 父层在本节点域内释放的敞口
  master:        INITIAL_CAPITAL 买入的股数
  voice k REV:   frac_of(k) × 总股数（卖出 = 释放为现金敞口）
  sub-voice k−1: REV 腿卖出所得现金的一部分（买回 = 重建股票敞口）
```

不变式：任意时刻 `Σ 各层敞口 = 总持仓 + 总现金`（金额守恒，
EARNING_SHARES 态先例）。子层爆预算在 open_diff 的 INV-1 检查处天然
拒绝（G3b 路径已存在）——预算守恒不需要新机制，只需要键空间正确归属。

**每层独立决策**的边界：决策独立 ≠ 预算独立。子层决策只读本级别事件流
（级别隔离，结构域架构），但开腿能否成交受父层敞口约束。这正是40课
"独立又在一个整体的操作中"的代码形态。

### 3.4 与 master 升档机制的对偶

递归塔向下肢解与 earning 升档（`n_exit_upgraded`）向上换档是同一个
结构的两个方向（40课 A0+…+At=B1+B2 的两个读向）。完整的递归赋格里
两者应当对称存在：子层兑现积累 → 父层 cost_basis 下降 → earning →
父层出场级别上移。当前升档只在 master 层有；递归形式下每个节点的
earning 状态都可以触发其自身出场判定的级别上移。这是设计自由度，
不在本调研裁决（标注为开放问题 Q3）。

## 4. 终止条件

### 4.1 三个范畴不同的下限

| 下限 | 性质 | 当前代码位 | 越过的后果 |
|------|------|-----------|-----------|
| `k−1 < FIRST_BSP_LADDER` (=2) | **存在论**：bi/bar 级无中枢 ⇒ 域不可定义 ⇒ 38课程式的前提（中枢、买卖点）不存在 | `runner.rs` guard | 不可表示（不是亏损，是无意义） |
| 振幅 < 往返摩擦 | **经济**：(预期兑现幅度) ≤ 2×(spread+fee+slippage) ⇒ 期望必负 | 无显式代码位 | 必亏（卖飞修复结论：有效域=回调幅度≫执行摩擦） |
| (ZG−ZD)/c < θ_depth | **结构**：可兑现空间门 | `theta_depth`（默认 0.0） | 低质量腿（churn） |

### 4.2 "θ 本质上就是递归终止条件？"——部分是

θ_depth 是结构门的实现，且具有自然的递归终止性质：中枢振幅随级别下降
几何收缩，固定 θ ⇒ 递归在振幅跌破 θ 的层自动停止。**但 θ 不是完整答案**：

1. θ 当前默认 0.0（V2o 变体 0.01）——作为终止条件时必须 > 0，且其值
   应当锚定经济下限（θ_min = 2×摩擦/c），否则是无量纲的自由参数。
   θ=1% 量级失配已有否证先例（QQQ 清空）——θ 的正确量级是标的相关的。
2. θ 是**开腿门**（事前判定），经济下限是**期望条件**（事前不可直接
   观测，只能用振幅代理）。两者在实现上合一（θ ≥ 2×摩擦/c 时结构门
   蕴含经济门），但概念上必须分开声明——否则 θ 调参时会无意识越过
   经济下限。
3. 存在论下限独立于 θ：θ 再大也不能让 bi 级长出中枢。

**严格表述**：递归终止 = FIRST_BSP_LADDER 硬下限 ∧ (θ_depth 门, 其中
θ ≥ θ_min(标的) = 2×往返摩擦/c)。θ 是终止条件的可调部分，不是全部。

### 4.3 实际深度的数据界

```
depth(voice k) = k − FIRST_BSP_LADDER
floor=2, entry 典型 4-5：
  voice k=2 → depth 0（无 sub-voice，k−1=1 是 bi 级）
  voice k=3 → depth 1
  voice k=4 → depth 2
```

加上信号密度现实（OKLO 447K 实际涌现 L1-L4，高层 BSP 稀疏），**有效
递归深度 ≤ 2，且深度 2 仅在 entry_ladder ≥ 5 的 trade 中出现**。
"理论上无限递归"在当前数据上是深度 ≤ 2 的有限集——这意味着：

- 递归定义不需要人为 max_depth 参数（数据自动终止）；
- 但也意味着任何"任意深度"的架构投入，其有效域只有 1-2 层——
  formalization-validity-domain 规则直接适用：为深度 ≤ 2 的有效域
  建造无界深度的机器，定义域膨胀超出有效域。

### 4.4 否定性证据链（为什么终止条件比开腿逻辑更重要）

已结算的经验证据全部指向同一方向——**过细的短差是负 alpha 的主要来源**：

| 证据 | 结果 |
|------|------|
| version_i bar 级 churn | 17424 次短差毁 −11973（数据裁决 segment 为最优 floor，印证缠师） |
| shared fugue bar0 | 22814 次噪音短差 −666803 爆仓 |
| 降成本层（多实验） | E>I 反复复现：降成本拖累 +455 vs +416/+320 |
| 38课原文 | "小级别操作……对精确度要求比大级别高，而且资金容纳程度低" |

递归赋格把短差层级再往下推一层，先验上处于这条否定链的延长线上。
**设计的重心必须放在终止条件和窗口约束（域嵌套的严格执行）上，而不是
开腿触发的丰富化**——这是与直觉相反但被数据反复确认的优先序。

## 5. 与现有架构的兼容性

### 5.1 SlotKey：深度 2 编码，不支持任意深度

```rust
pub enum LegClass { Main, Osc, Rev(usize) }     // Rev(level) = 1 个递归参数
pub struct SlotKey { ladder: usize, leg: LegClass }
```

`Rev(level)` 是为 T4b tranche 设计的一层参数化（home × tranche level）。
sub-voice 的腿需要表达"voice k 的 REV 腿之下、k−1 级别的反弹腿"——三个
坐标（home, rev_level, sub_ladder），现有键空间放不下。任意深度的严格
形式是**路径键**：

```rust
// 概念形态（非实现承诺）
pub struct SlotPath {
    segs: [u8; MAX_DEPTH],   // 每段 = ladder；定长保 Copy
    len: u8,
    leg: LegClass,           // 叶子腿类别
}
```

连带影响（这是改动规模的主要来源）：
- `py_key()` 投影失效——递归层无 Python oracle，Python parity 边界
  必须显式重划（O0≡P5 守卫只覆盖非递归配置，磁带指纹守卫不变）；
- `leg_contribution` / trace / 归因报告全链按路径键重写；
- `open_keys()` 插入序清仓语义需对路径键重新声明（父腿平仓必须级联
  平掉全部子树腿——新不变式，现有代码无对应物）。

### 5.2 LOU：FSM 骨架天然支持，信号通道需双向化

| 组件 | 递归兼容性 | 所需改动 |
|------|-----------|---------|
| `VoicePhase` 二态 | ✓ 天然（与 MasterState 同构） | 无 |
| 触发谓词 | ✗ 方向硬编码 | `seg_end_trigger`/`buy_trigger_at` 镜像化为 `trigger(d)`——BspClass 六变体是 Buy/Sell 对称的，镜像是机械变换，C6 穷举保证编译期完备 |
| 532 C1 双通道 | ✗ 仅 master 层有类型隔离 | 每个递归节点复制双通道（§2.5），`MasterExitSignal` 的构造纪律推广为 `NodeExitSignal(d)` |
| RevLeg tranche | △ 与递归正交 | tranche（同向加码）保留在节点内部；rev_paired × tranche 的未定义组合问题原样继承 |
| 区间套证据记忆 | ✓ 复用 | sub_sell_bar 等记忆按节点实例化（每节点看自己的 k−1） |
| `step` 借用结构 | ✓ | 树形递归沿调用栈传递同一 `&mut ledger`，Rust 单一可变借用天然成立 |

### 5.3 runner：改动最小的一层

voices 平坦循环改为对每个 voice 根调 `step`，递归在节点内部展开。
capability guards 新增一条：递归深度 ≥ 1 的配置要求 D3 行（dir_flips）
——sub-voice 的反弹段窗口判定依赖次级别方向行，与 tranche 同一数据依赖。

### 5.4 改动规模汇总与路径裁决

| 块 | 规模 | 风险 |
|----|------|------|
| SlotKey 路径化 + 报告链 | 大 | Python parity 边界重划（守卫面收缩需谱系结算） |
| LOU 方向参数化 + 双通道 + 子节点 | 中 | 532 推广的正确性；T6 陷阱纪律在镜像谓词上的复检 |
| runner 组装 + guards | 小 | 低 |

**路径裁决（no-patch 与 validity-domain 的合取）**：

- 固定深度 2 展开（在 RevLeg 里塞 `sub: Option<Box<VoiceUnit>>`）是
  补丁形态——它把递归结构硬编码为特例，违反 090号。**不采纳为终态**。
- 但全量递归化在递归第一层的经验有效性（L2）未验证前，是为未验证假设
  建造的机器——违反 231号。**不采纳为首步**。
- 严格的顺序是：**先以最小可弃实验验证深度 1 的 alpha 存在性，再决定
  是否建造递归机器**。实验形态：单独的 ablation 变体（新配置位
  `sub_rebound`），在 RevLeg 内以现有 SlotKey 的 Osc 类比方式开一条
  k−1 反弹腿（键可临时用 `SlotKey::rev(k, k−1+OFFSET)` 类的保留区——
  实验代码显式标注为可弃，不进入主路径）。预注册判据（双侧）：
  - O_sub1：sub 反弹腿聚合现金 > 0 且 REV 腿本体胜率不降 ⇒ 假设存活，
    投入递归化；
  - O_sub0：聚合现金 ≤ 0 或 REV 胜率受损 ⇒ 否证，递归赋格的有效域为空，
    本设计文档转为否定性结算（与 bar churn 证据链合并）。

  实验与"终态架构"的关系不是"先修一半"：实验是假设检验装置（可整体
  删除），终态是检验通过后的完整重写——两者无共享代码路径。

## 6. 开放问题（不在本调研内裁决）

- **Q1 反弹腿的开腿谓词选型**：买侧三岔直用（对称镜像）vs 仅盘整背驰
  （对称于 V2o 的"震荡型独占"裁决）。盘背卖消融判决（R1/R2/R3）显示

- **Q3 节点级 earning 升档**（§3.4）：递归对偶的完整形态 vs 仅 master
  层保留。建议在 O_sub1 成立后作为第二消融轴。
- **Q4 θ_min 的标的校准协议**：摩擦项的估计来源（be9.7bps 先例）与
  per-标的 θ 下限表。

## 结果包

1. **结论**：见 §0。核心：递归赋格的严格形式 = 方向参数化的自相似节点
   （双信号通道，532 每层复制）× 路径键账本 × 三范畴终止条件；实施
   顺序受 231号约束——深度 1 的 L2 实验先于架构投入。
2. **定义依据**：38课程式（方向对称+循环延续+区间套定位，原文逐句引于
   §1.2）；40课 N重层次（每重=级别×资金×节奏，"独立又在整体中"）；
   38课组合规则自由度（次级别分解不必同级别分解，§1.3）；27课区间套
   （域嵌套的定位本体）。代码侧：runner.rs 状态机、LOU T1-T7、
   master.rs C1 隔离、types.rs SlotKey。
3. **边界条件**：(a) 若 O_sub0（深度1反弹腿 L2 否证）⇒ 全部架构设计
   作废，文档转否定性结算；(b) 若未来数据出现 entry_ladder ≥ 6 的
   regime（深度 3+ 可达）⇒ §4.3 的"深度≤2"界失效，需复核架构容量；
   (c) 若 532 被推翻（master 可消费三触发）⇒ §2.5 双通道约束解除；
   (d) θ_min 锚定假设依赖摩擦模型——期货/加密的摩擦结构不同，
   终止条件表不可直接移植。
4. **下游推论**：(a) SlotKey 路径化将收缩 O0≡P5 守卫的覆盖面（Python
   oracle 无递归对应物）——磁带指纹守卫的角色上升为唯一全量守卫；
   (b) D3 行从可选依赖变为递归配置的硬依赖；(c) 若 O_sub1 成立，
   "降成本层负 alpha"的历史结论需要重新分期检验（旧降成本无域嵌套
   约束，混入了窗口外短差——递归形式的域约束可能是缺失的正则化项）；
   (d) M2 信号层工位的 run_high 行产出优先级不受本设计影响。
5. **谱系引用**：532（seg-end-trigger 轴分离——本设计将其推广为每层
   双通道）；525（FIRST_BSP_LADDER 中枢承载层——存在论终止下限）；
   267（多重赋格为缠师术语的确认）；090/161（实施路径裁决中拒绝固定
   深度补丁）；231（L2 先于架构投入的依据）；027课区间套相关谱系
   （interval_nesting_pairing_fix 工作记录）。不确定是否存在"递归
   操作深度"专项谱系——已检索 .chanlun/genealogy 未做全量扫描，
   明确声明此不确定性。
6. **影响声明**：纯调研产出，零代码改动。新增本文档
   `analysis/recursive_fugue_ultimate_design.md`。不改变任何已结算
   定义；提出但未结算的新概念：符号交替塔、域嵌套操作化、三范畴
   终止条件、SlotPath 路径键、NodeExitSignal 双通道推广。
