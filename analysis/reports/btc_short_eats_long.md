## 2. displacement 会计（做空吃掉的多头利润）

- **long-only-root**（受控，root 不做空，H¹ 短差仍在）：多头 L0=+907,362，短差 SS0=-5,673，总=+901,690（+901.7%）
- **nf 加 root 做空**：多头 L1=+247,243，空头 S1=-218,489，总=+28,754（+28.8%）
- **displacement = L0 − L1 = +660,119**（root 花时间做空→错过上涨腿→多头利润缩水 +660.1pp）
- **root 做空直接增量亏损 = S1 − SS0 = -212,816**（-212.8pp）
- **总损失 = +872,935（+872.9pp）** = displacement(+660.1) + 直接亏损(-212.8)
- ⟹ **主因是 displacement**（多头被挤掉），不是空头直接亏损。修做空必须先解决「root 做空时多头停摆」。

## 5. 「空头僵尸化」假设被数据反驳（FUGUE_DBG recover 成功率）

> operate.rs DBG 计数器实测（FUGUE_DBG=1 跑 BTC）：recover=把次级别空头平回核心。
> 若空头僵尸（开了不平），recover 成功率应很低。实测两版本几乎相同 ~97%：

| 版本 | recover attempt | ok | 成功率 | 失败分类 |
|------|----------------|-----|--------|---------|
| long-only (+901.7%) | 4715 | 4576 | **97.1%** | L4 wrongdir=139 |
| nf (+28.8%) | 5038 | 4899 | **97.2%** | L4 wrongdir=139 |

- 两版本 recover 成功率几乎相同（97.1% vs 97.2%），L4 wrongdir 都恰好 139 笔（结构性，非 root 做空引起）。
- ⟹ **「空头僵尸化」不是踏空机制**——空头覆盖率两版本一致。差异全部来自 root 翻空的 displacement + 短差在 short-root 模式下的 P&L 崩坏，不是覆盖失败。

## 6. 机制结论（修做空的方向）

**做空吃掉了 873pp，拆成两个通道：**
- **displacement −660pp（76%，主因）**：加 F-entry-short 后 root 在 secular bull 的回调处翻空，
  多头核心停摆 → 多头 P&L 从 +907k 崩到 +247k。root 每空一段 = 错过一段上涨腿。
- **短差 P&L 崩坏 −213pp（24%）**：H¹ 短差在 **root 做多时盈利 +18k**（long-only）/ +185k（T-struct），
  但 root 翻空后整套 sink/recover 在 short-root 模式下运作 → 翻成 −180k。

**对抗验证修正（重要诚实性，B 验证 holds=False）：做空机制本身没有 edge。**
- long-only 短差 +18k **是噪声不是盈利**：胜率 49.8%、median≈0、删 top1% 翻 −463k、bootstrap P(sum>0)=0.52 与零不可区分。
- nf 短差 −180k 则是**稳健为负**（删 top1% 仍 −152k）——root 可翻空后短差从「零 edge」退化为「稳健亏」。
- 对比：多头 P&L 是**真实 edge**（long-only 胜率 55.3%/median+96/删 top1% 仍 +701k）。
- ⟹ **做空（次级别顶背驰 sink/recover）是 50/50 硬币翻转，没有方向 edge**；杀手是 root 整仓翻空
  （displacement 挤掉真实多头 edge + 整核心强平爆仓，C 验证：T-and root 强平 = 总亏损 211%）。

**修做空的真实难度（诚实）**：当前做空构造（`root_dir=Down`→翻空 + 次级别顶背驰 sink）在 secular bull 里
既无 edge（硬币翻转）又有害（displacement）。`root_dir=Down` 多数是回调噪声非趋势反转。
**让做空真正赚钱不是调参，而是需要一个真实的做空 alpha 源**——现有 sink/recover 机制净期望≈0。

**修复方向**：①最低限度——root 维持多头底仓、做空仅作受限次级别 overlay（消除 660pp displacement，
把真实多头 edge 还回来）；②若要做空盈利——需给空头注入真实下跌 edge（更高级别确认的下跌 regime，
非对称门槛），而非依赖当前零 edge 的 sink/recover。详见对抗验证 + 修复方案评审。
