# 残差缠论流量/流速实验报告

- 残差定义：`r = log(DX) - 0.576*log(USD6E)`（占 DX 方差 33.8%）
- 引擎：`newchan_rust.RecursiveOrchestrator max_levels=6 stroke_mode=wide`
- 样本：2,028,891 bar，2018-12-26 01:00:00+00:00 → 2026-06-05 20:59:00+00:00
- 认识论等级：**L2**（真实数据，单残差构造=单标的/单时段）

## 算子定义

- **流量算子（力度）**：amplitude=high-low (all levels); impulse=amplitude*duration_bars (L1 only)
- **流速算子**：settle events per calendar month + cumulative highest level
- L2+ 时间锚定：L2+ settle bar via settled-count polling (resolution=poll_interval_bars)

## 边界条件（结论翻转条件）

- 若 regime 转折月 ±3 月窗口内**力度（振幅）与流速（settle 密度）无系统性变化** → 残差缠论结构不携带 regime 信息，假设被否证。
- 若变化方向与三个转折点**不一致**（加息/见顶/降息表现互相矛盾）→ 力度/流速不是 regime 的单调函数，仅为噪声。
- L2+ 锚定分辨率 = 200 bar；若转折效应尺度小于该分辨率 → 高级别结论不可靠（仅 L1 有效）。
