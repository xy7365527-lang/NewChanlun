## 一、结论（结果包要素1）

**配对修正成立，深度门槛 θ=1% 被否证，逃逸型开腿被否证。**

1. **判据(a)（rev 胜率 45%→>50%）：达成。** V2p 三标的 51.3 / 49.0 / 50.3%
   （V1f：45.6 / 45.2 / 43.5%）；V2o（仅震荡型）53.3 / 49.9 / 52.8%。
   震荡型单独看 53.5 / 49.9 / 52.6%——QQQ 差 0.1pp 到线，OKLO/BRN 明确过线。
2. **判据(b)（QQQ/BRN 翻正或接近零）：BRN 翻正，QQQ 收敛到接近零但未翻正。**
   BRN Δ(vs P5)：V1f −125.6 → V2p **+139.8** → V2o **+308.1pp**（摆动 +433.7pp，
   rev 腿净现金 −32,113 → +46,434）。QQQ：V1f −9.3 → V2o −6.3 → V2of −3.5pp。
3. **深度门槛 θ=1% 在 1min 数据上量级失配**：QQQ 3131 次深度拒（4 开，有效域
   清空）、BRN 8784 次（68 开）；OKLO 上 V2p→V2f Δ 损失 441pp。θ=1% 不是
   "过滤浅反转"而是"过滤几乎一切"。
4. **kind 标注（震荡型/逃逸型）产出判决性分解**：逃逸型三标的一致为负
   （OKLO −4.4K / QQQ −10.1K / BRN −35.1K），震荡型三标的中两正一平
   （+57.9K / −3.6K / +47.1K，胜率 53.5/49.9/52.6%）。**V2o（关逃逸型）是
   聚合最优变体**：ΣΔ = +758.6pp（V1f +472.6 / V2p +629.3），且最差单标的
   −6.3pp（V1f 最差 −125.6）。

## 四、机制发现

1. **"同锚 confirmed Buy1" 闭腿条件近空定义域**（BRN V2o：t5 关 = 0 / 2514 对）。
   原因在定义层：confirmed Buy1 的 cs 是下跌走势自己的中枢，而锚 cs 是开腿时
   存活的上涨中枢——两者结构上不可能相等。震荡型腿的闭腿实际由
   **ZD 触线（486）+ Buy3 回补（t6 1228 + t7 800）** 承载。任务闭腿三规则中
   规则1（同锚 Buy1）形同虚设，规则2/3 是承重结构。这不是实现 bug——是
   "同锚"概念在 kind 配对下的有效域为空（formalization-validity-domain：
   定义域≠有效域的又一例）。
2. **kind 不匹配拒绝的反事实计数**（n_rev_mismatch_holds）：V2p 三标的
   283/436/1485 个 bar 上 legacy 谓词（Buy2/盘背买/异锚Buy1）会闭腿而配对谓词
   持仓——这些持仓延后兑现为 ZD 触线/Buy3 闭腿，是胜率 +5~9pp 的直接来源。
3. **Δ 与腿现金可背离**（OKLO V1f Δ+607.5/现金+53.2K vs V2o Δ+456.8/现金
   +56.0K）。逐 trade 诊断（`_rev_v2_delta_vs_cash_diag.py`）：trade 边界
   逐位一致（master 不动确认）、零 earning 相变，差异纯粹是**同量现金落在
   不同 trade 上的复利权重效应**（log 复利差 top5 trade 占主导）。V1f 在
   OKLO 的优势是 regime 特定的分布运气，不可与其 QQQ/BRN 的 −9.3/−125.6
   分离评价。
4. **深度门的残余信号**：BRN V2of（深中枢震荡型，34 对）胜率 61.8%、净 +14.8K
   ——深度与胜率正相关的方向存在，但 θ=1% 把分母砍到不可用。θ 的工作点
   扫描（如 0.2-0.5%）是独立工位，需另行预注册（一次只验一组轴）。
