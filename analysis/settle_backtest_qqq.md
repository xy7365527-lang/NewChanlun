## 3. 解读（过滤器与离场规则的效力）

**缠论中枢过滤器（中枢≥2）是否有效？**
- **对称settle 下**：中枢≥2 过滤后胜率 48% → 42%（-6pp，下降），笔数 23→19（-4），总收益 +659.7%→+153.6%（-506.1pp）
- **否定出 下**：中枢≥2 过滤后胜率 43% → 45%（+2pp，提升），笔数 42→31（-11），总收益 +163.6%→+70.2%（-93.4pp）

**两种离场规则对比？**
- 对称settle vs 否定出（无过滤）：胜率 48% vs 43%；平均持有 204 vs 51 日；总收益 +659.7% vs +163.6%；最大回撤 −54.1% vs −30.4%
- 总收益最高变体：**S1 对称settle·无过滤**（+659.7%），对比 buy-and-hold +1345.9%（暴露仅 69%）

## 结果包（六要素）

1. **结论**：QQQ 1999-03-10→2026-05-29 在线回测，PH settle 右侧确认信号共触发买入 90 / 卖出 68 次。四变体总收益区间 [+70.2%, +659.7%]，buy-and-hold 全期 +1345.9%。胜率见 §2 表。
2. **定义依据**：
   - 买入信号 = `OnlineMergeTree(close).update()` 返回非空且 persistence≥τ （下跌腿 settle = 底分型因果确认，a_online_persistence §10 定理）。
   - 卖出信号 = `OnlineMergeTree(-close).update()` 返回非空且 persistence≥τ （上涨腿 settle = 顶分型确认，sublevel 对称）。
   - 否定出 = `stop_signal.reason∈{reverse_exceeds,both}`（入场后新生下跌腿 persistence 超入场确认底幅 = 对象否定对象，005b号）。
   - 中枢过滤 = `detect_zhongshu`（min_members=3, ratio=3.0, overlap）计数≥2。
3. **边界条件**（结论翻转条件）：
   - τ 倍数变化（当前 multiple=1.0）→ 信号频率与笔数改变，胜率随之漂移。
   - 用 close 而非 HL 双树：换 HL 双树（顶/底建立在 high/low）信号会变。
   - 复权口径：yfinance `auto_adjust=False`（含派息缺口）；改全复权 close 阶梯改变。
   - 单标的：QQQ 是长牛标的，long-only 天然顺风；换熊市/震荡标的结论可能翻转（L3 未做）。
4. **下游推论**：
   - 若中枢过滤显著提升胜率 → 「PH 右侧 settle + 缠论结构合取」优于纯 PH，支持「右侧确认 + 趋势在场」的合取条件。若无改善/下降 → 中枢过滤在日线 QQQ 上不是有效增量（否定性结果，缩小有效域）。
   - 若否定出最大回撤显著小于对称settle但总收益跑输 → 否定出是「降波动换收益」的风控档，符合 alive persistence 用 running_max 封顶导致的早离场特性。
5. **谱系引用**：
   - settle=分型确认 / 全局低点不可反弹 settle —— `persistence_theory.md` §7.5/§10/§17.3；090号声明膨胀禁令。
   - 否定出=对象否定对象 —— 005b号 / `stop_signal`。
   - close 取负拿卖出信号的对称性 —— `a_dual_merge_tree` 取负原理（此处用 close 非 HL）。
   - 单标的回测有效域 ≠ 跨标的定义域 —— formalization-validity-domain（L2 vs L3）。
