## 3. 机制链：为什么 BTC 空头亏这么多（不是"regime"，是具体机制）

```
① 空头生成机制【BTC 与 CL 完全相同】
   持多(FullLong) + 次级别卖点@(k−1)  →  sink：减 1/3 核心 + 在 k−1 建 1/3 空头
   "次级别卖点" = 次级别回调信号 = 赌主升浪中会有一次回调
   → BTC/CL 都 ~900 笔 sink 短差、800 次 sink、多重赋格塔结构相似（用户观察正确）

② 分叉点【唯一的不同】：做空赌的"回调"是否真的发生
   ├─ CL（震荡市）：次级别回调真实发生，价格回落
   │   → 空头在 recover(次级别买点回补)/core_exit 时以更低或相近价平仓
   │   → sink 短差净赚 +18,174，recover +21,287
   │
   └─ BTC（强单边上涨）：次级别"回调"极浅极短，价格立刻创新高
       → 空头建仓即被套，持有数月（top10 hold 3万–41万 bar），价格涨 15%–31%
       → 无论怎么平（reduce 再 sink / core_exit 清仓 / recover 回补）都是高价平
       → sink 短差净亏 −172,298，recover −12,665

③ 放大机制：reduce（较高级别空头腿被再 sink）在 BTC = −147,882
   持空又遇次级别买点 → 下放减仓 → 在更高价实现浮亏 → L5/L6 套最深
```

**一句话**：空头的算法机制（次级别回调信号 → sink 做空 1/3）在 BTC 和 CL 上**完全相同**；唯一区别是 **BTC 是强单边上涨，次级别卖点把"主升浪中的微小停顿"误判为"回调"，做空后价格不回头而是创新高**。亏损不是某个途径（a 核心翻空在此版本不存在）或某个 bug 造成的，而是**"做空赌回调"这个信号在没有回调的强趋势里被系统性证伪**——分水岭可以用"建空时过去 1 天是否在上涨"精确切出来（上涨中建空 = 全部亏损所在）。

## 4. 结果包六要素

1. **结论**：BTC 空头 −214,229 的亏损 100% 来自途径 b（次级别 sink 短差，910/998 小仓贡献 −172,298），途径 a（核心翻空）在本数据版本不存在。亏损的精确触发条件是"在过去 1 天上涨趋势中 sink 建空"（该组 −223,735，是全部亏损；下跌中建空 +9,506）。CL 同一机制因震荡市回调真实发生而净赚。

2. **定义依据**：
   - 空头生成 = `cycle::sink_chunk`（`t_engine.rs` a81c6e384c）：FullLong + 次级别卖点@(k−1) → `reduce_at(k,1/3,"reduce")` + `add_at(k−1, Short)`。次级别卖点定义 = 该级别买卖点（缠论第 37 课背驰，记忆 `unified_recursive_operator_T`）。
   - 空头 pnl = shares×(entry_basis − exit_close)（`accounting.rs:reduce_at`，Short 腿）。
   - 同级别卖点 = `clear_to_cash("core_exit")` 清仓回现金（该版本注释/测试"步骤6 清仓不翻空"明示）。

3. **边界条件**（结论翻转条件）：
   - 若数据换为**当前翻转版**（512f784a74），途径 a（核心翻空）出现，归因框架须重做——核心仓会在同级别卖点处全仓翻空，亏损结构改变。
   - 若 BTC 行情转为震荡（次级别回调真实发生），sink 短差会像 CL 一样转盈——亏损是行情×信号的交互，非纯算法属性。
   - 若入场过滤"仅下跌中允许 sink 建空"，BTC 空头由亏转盈（L1 观测，需 L2 重跑验证）。

4. **下游推论**：
   - 「次级别卖点」作为做空信号在强单边趋势中无条件触发是亏损根因 → 需对 sink 做空加趋势门控（如"仅当更高级别非上行时允许次级别卖点 sink 做空"），呼应记忆 `t_short_leg_regime_function`「无'持多才做空'前提门」与 539 号「根翻空有效域 ⊂ 非上行」。
   - `recover` 符号（BTC 亏/CL 赚）是 regime 判别量候选：sink 短差是否盈利 ≈ 标的是否震荡。

5. **谱系引用**：539 号「根翻空有效域 ⊂ 非上行 regime」（记忆 `t14_t5_root_flip_necessity`/`unn_root_flip_mtm`，本诊断在 sink 短差层再次证实）；记忆 `t_short_leg_regime_function`（空头腿=亏损唯一来源，本诊断给出逐笔机制）；记忆 `t_short_close_level_mismatch`（平空级别错配，本诊断从入场时机维度补充）；`t_operation_self_replication`（ε 对称 sink/recover）。
