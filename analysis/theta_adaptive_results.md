# θ 自适应深度门 — 设计、实现与三标的判决

> 任务（2026-06-11 编排者）：REV 深度门 θ=1% 固定值在 OKLO/BRN 工作，QQQ 的
> 1 分钟中枢振幅几乎全 <1%，1065 对震荡型配对被门后只剩 3 对——量级失配，
> 不是策略失败。调研分布 → 设计自适应 θ → Rust 实装 → 三标的回测。
>
> 认识论等级：§1 分布调研 L3（三标的真实数据）；§4 守卫 L1（管线等价）；
> §5 回测判决 L3（三标的真实数据，预注册判据）。

## 0. 结论速览

1. **量级失配确认（任务前提成立）**：1 分钟锚中枢相对振幅 (ZG−ZD)/c 的
   pooled P50：OKLO 0.93% / QQQ 0.10% / BRN 0.20%。固定 θ=1% 在 OKLO 是
   ~P55（半数过门），在 QQQ 是 ~P99.7、BRN ~P96.9（基本全拒）——同一个常数
   在三个标的上是三个完全不同的门。
2. **自适应 θ（方案 B，因果滚动 P25）在 REV alpha 为正的标的上全面优于固定门**：
   OKLO Δ(vs P5) +410.4 → **+520.4pp**（+110pp），BRN +19.8 → **+71.5pp**（+51.7pp），
   胜率维持 51%+，MDD 持平或略好。
3. **QQQ 否定性判决（预注册判据 (a) 半否证）**：腿恢复成功（3 → 809 对，胜率
   48.7%）但净现金 −4696（vs 固定门 −1730）——量级失配是真的，但恢复出来的
   QQQ REV 短差本身是负 alpha。固定 θ=1% 此前在 QQQ 上"工作"的方式不是过滤，
   是误打误撞把 REV 整体关掉。**深度门是规模过滤器，不是 alpha 制造器**——
   它不能把负 alpha 标的变正（与 BTC 杠杆实验"sizing 修不了信号层"同构）。

三个结构事实：

- **QQQ 失配确认且比任务陈述更极端**：99.7% 中枢 <1%，P90 才 0.30%。θ=1%

- **级别间量级差一个台阶**（ladder2 P50 ≈ ladder3 P50 的 ~40-45%，三标的一致）：
  固定 θ 对不同 ladder 也是不同的门（OKLO：砍 L2 六成 / L3 不到两成）。
  自适应 θ 按层独立维护参照窗，同时消除标的间与级别间两种失配。

## 2. 三方案严格性裁定（设计任务2）

| 方案 | 定义 | 前瞻性 | 裁定 |
|---|---|---|---|
| A：锚自身振幅的分位数 | θ = 当前锚中枢振幅的 P25/P50 | — | **自指退化**：单个数没有分位数。若把"自身"读为"该标的全部中枢"，则坍缩为方案 C |
| B：滚动 N 个中枢的统计量 | θ_t(k) = 该层最近 window 个**已观测**中枢振幅的 q 分位 | **零前瞻**：参照集只含形成时刻 ≤ 当前 bar 的中枢 | **最严格，采纳** |
| C：标的级固定分位数 | θ = 回测期全样本分布的 q 分位（每标的一个常数） | **回测期内前瞻**：bar t 的门槛是 t 之后中枢振幅的函数 | 否定。须独立样本外期才合法，本任务全样本回测下不可用 |

方案 B 的严格形式（Rust `DepthRef`，预注册常数，零标的级拟合）：

- θ_t(k) = ladder k 最近 **window=50** 个中枢相对振幅的 **q 分位**（nearest-rank），
  q ∈ {0.25, 0.50} 两档消融；
- **排除当前锚自身**——门槛决策不得是被检对象自身振幅的函数（自指禁止，
  方案 A 否定理由的局部形式）；
- 参照样本 < **min_obs=10** ⇒ 回退固定 θ=1%（warm-up 维持基线门，不静默放行；
  可观测：`n_rev_theta_fallbacks`。实测 OKLO 1 次 / QQQ 0 / BRN 0——回退实际不参与）；
- 振幅观测点 = CenterBook 边界变化 bar（中枢形成/延伸的事件时刻），延伸原位
  更新（一个中枢一个参照条目）。

语义注记：q 分位门 = "当前锚中枢必须比该层近期中枢的 q 比例更宽"——尺度无关的
**相对选择性**，固定 θ 的"绝对深度"语义被替换而非近似。

### 5.1 预注册判据裁定

**(a) QQQ 恢复腿数与 payoff**：腿恢复**成立**（3 → 809 对 @P25，量级失配被消除；
胜率 48.7% 接近震荡型的跨标的常态 51-53%）。payoff **否定**：净现金 −4696
（vs 固定门 −1730，vs 门全关 V2o 的 1065 对也为负）。三个数据点
（V2o 全开负 / V2of 全关小负 / V2oa 中间负，且 P25 比 P50 更负 = 暴露越多
越亏）合并指向：**QQQ 1 分钟 REV 短差毛 alpha 为负，门的形态无关紧要**。

**(b) OKLO/BRN 保住固定门改善**：**成立且放大**。OKLO +410.4 → +520.4pp，
BRN +19.8 → +71.5pp。两标的 P25 > P50 > 固定（单调），胜率全部 51%+，
MDD 持平或改善——在 REV alpha 为正的标的上，固定 1% 门此前砍掉的腿
（OKLO ladder2 的六成 / BRN 的 96.9%）平均仍是正贡献，门越接近分布
主体（P25）越好。

### 5.2 机制解读

- **q 档单调性携带信息**：OKLO/BRN 上 P25 > P50（更宽的门更好），QQQ 上
  P25 < P50（更宽的门更亏）。自适应门把"REV alpha 的符号"从门参数里干净
  分离出来了——这正是固定 θ 做不到的：它把"标的 alpha 符号"和"量级失配"
  两个自由度搅在一个常数里。
- **深度拒数下降但不归零**（BRN 7324→4088）：相对门仍在拒绝该层近期分布
  左尾的窄中枢 + `c>ZD` 零利润空间拒并入此计数——门在工作，不是放行一切。
- **胜率向 51-52% 收敛**（OKLO 52.5→51.0，BRN 58.4→51.6）：固定门保留的
  右尾大振幅腿胜率更高但样本少；自适应门用量换质，净现金仍大幅上升——
  改善来自规模恢复，不是单腿质量提升。

## 6. 结果包六要素

1. **结论**：θ 自适应深度门（因果滚动 P25，V2oa25）实装并三标的验证。
   OKLO +110pp / BRN +51.7pp 优于固定 θ=1%；QQQ 腿恢复但 payoff 否定——
   QQQ 的问题不在门在 REV 本身。量级失配假设 L3 确认。
2. **定义依据**：深度门语义承自 2026-06-10 REV 配对修正任务（锚中枢振幅
   (ZG−ZD)/price ≥ θ 的可兑现空间下限）；中枢 ZD/ZG 取 CenterBook 账本
   快照（与 P5 域腿同源，单一真相源纪律）；震荡型兑现锚 = ZD 触线
   （第24课保证域的几何形式）。
3. **边界条件**：(i) 结论限 1 分钟 bar、三标的、全历史单段回测——无样本外期；
   (ii) q/window/min_obs 只测了 {0.25,0.50}×50×10 一组窗参，window 敏感性未扫
   （预注册单点，避免参数搜索过拟合，但也意味着 50 不是被证明的最优）；
   (iii) 若 QQQ REV 在其他出场结构下转正，"门形态无关"的否定结论需重检；
   (iv) BRN 行与在册 enginefix 表因尾部 1 bar 漂移不构成逐位对账（数值上相同）。
4. **下游推论**：(i) V2oa25 应作为 REV 配对路径的新默认门候选（替代 V2of 的
   固定 1%），待编排者裁决是否改写变体表默认；(ii) "REV 是否在某标的开启"
   是门参数之外的独立决断——需要标的级 alpha 符号的样本外判据，不能从
   本回测的 in-sample Δ 反推开关（过拟合）；(iii) `center_amp_log` 通道是
   通用市场性质观测面，后续任何振幅条件设计可直接复用；(iv) 级别间量级
   台阶（§1 第三点）提示 theta_amp（P5 主腿门，仍固定 1%）可能有同样的
   失配——独立工位候选。
5. **谱系引用**：REV 配对修正（2026-06-10 任务，V2f/V2of 谱系）；θ=1% 量级
   失配的首次记录在 REV 配对判决（QQQ 1065→3 对）；"sizing/门修不了负
   alpha 信号层"同构先例 = BTC 杠杆实验；090号（声明=能力：warm-up 回退
   可观测不静默）；231号（认识论等级标注）。
6. **影响声明**：Rust 交易层 6 文件改动（§3 表）+ 新回测脚本。**零侵入面**：
   O0≡P5 三标的四面对账 PASS；V2of（Fixed 模式）OKLO/QQQ 逐位等于在册、
   BRN 数值相同；legacy（非 rev_paired）路径不消费 ThetaMode。新增可观测：
   `n_rev_theta_fallbacks` counter + `center_amp_log` diag 通道。
   数据落盘：`analysis/data_cache/theta_adaptive_backtest.json` /
   `theta_adaptive_tables.md`。
