> 任务：固定 θ=1% 四次独立失配（QQQ/BRN/CL 1min/CL 秒级）后，将 θ 自适应
> （V2oa25）落地为 REV 配对路径的默认门，并在 9 标的 1min + CL 秒级 + BTC

## 1. 结论

### 1.1 落地内容（代码改动，commit fee48f2247）

V2oa25 升级为 REV 配对路径的**默认门形态**，三个组件：

|------|------|--------|

V2oa50 保留纯自适应作消融对照位。cargo test 106 全过；O0≡P5 守卫 11/11 标的 PASS。

**注意**：新 V2oa25 与首验纯自适应 V2oa25（OKLO+520/BRN+71.5pp，theta_adaptive_backtest.json 在册）
不逐位可比——首验无 41课门。本报告所有 V2oa25 数字均为落地形态。

### 1.5 结构发现：成本门是细分辨率域的真 binding

期货 1min / CL 秒级域：`n_rev_theta_cost_floor` ≈ `n_rev_depth_rejects`
（CL 8827/8385、GC 15354/14508、CL1S 18992/18767）——相对分位数在这些域
几乎恒低于 0.2% 下界，**θ_eff 实际 = 成本门下界**。纯分位数只在 OKLO
（cost_floor=0）和部分 BTC（7455/9635）生效。即：θ"相对化"在细分辨率域
退化为"成本下界化"——P0-c 比值表的 21 倍跨标的差在下界处被截断，这是
35课"级别不够大就没有操作意义"的量化体现，不是缺陷。

41课门触发 35–1160 次/标的（live 非死门，延续 P0+P1"41课门首次非死门"判决）。

## 2. 定义依据

- **35课**（成本门）："交易成本+交易误差相对波幅不够小的级别，长期操作没有意义"
  → θ_eff 下界 = 2×往返摩擦。
- **41课**（反向门）："大级别走势没有任何衰竭迹象时参与反向小级别买卖点是刀口舔血"
  → 父级别相邻 Up 段创新高 ∧ 无盘整背驰 = 拒开 REV。可编码判据沿用 P1 任务
  Down 侧形态的镜像（38课段内背驰结构）。
- **θ 自适应方案 B**（在册裁定，theta_adaptive_results.md §2）：因果滚动分位数
  是唯一零前瞻、零标的级拟合的相对化形式。

## 3. 边界条件（结论何时翻转）

1. **friction_rt=10bps 是预注册常数**（卖飞修复 be9.7bps 量级锚定）。真实摩擦
   显著高于 10bps（如 OKLO 点差）时下界过松，CL1S 的 +1963 净现金可能翻负；
   显著低于（期货大合约）时 GC/ZN 的拒绝可能过度。
2. **q=0.25/window=50 未做敏感性扫描**——若 q=0.50 或 window=200 下 GC 翻正/
   油链翻负，"默认门"参数需重裁。
3. 全部数字为**零摩擦回测**（BRN V1 +26.6pp 零摩擦伪影先例）——rev 对数从
   77→1494（BRN）意味着摩擦敏感度上升 ~19×，10bps 往返下 BRN +48635 净现金
   对应 1494 对 × 成本，正负判决在真实成交模式（next/touch）下需复核。
4. GC −14.6pp 若在 q/window 敏感性下稳定，需为 GC 类（避险金属 regime）增加
   排除判据——当前默认门**无标的级开关**（方案 C 前瞻禁令）。
5. F1 否证限当前双门参数（sub_cost_k=2, SUB_COST_Q=0.5, min_obs=10）；
   sub_noref 主导拒绝意味着参照定义域本身可能是瓶颈，非分型信号质量。

## 4. 下游推论

- **V2oa25 为默认门**后，所有 REV 配对回测的对照基线应声明 θ 模式——
  V2of（固定 1%）降为消融对照位，不再是主变体。
- QQQ/ZN/DX/GC 四标的 REV 负 alpha 在域恢复后确认 → 实盘配置中 REV 声部
  应仅在油链 + OKLO/BTC 类标的激活（regime 依赖，与多级别赋格 REV 三排序
  判决一致）。
- CL 秒级域已活（252 对净正）→ 秒级 a0 任务的"递归塔可建但单 K 线内展开
  不足"结论维持，但 REV 主腿在秒级不再是结构性死域。
- 成本门下界在细分辨率域 binding → 未来若引入更细级别（tick），θ 相对化
  自动退化为成本门，无需新机制。
