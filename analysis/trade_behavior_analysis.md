## 1. 闭腿类型分布 × 盈亏（本次最强发现）

| 闭腿口 | OKLO n/胜率/净现金 | BRN n/胜率/净现金 | 语义 |
|--------|------------------|------------------|------|
| **zd_touch（ZD 触线）** | 38 / **100%** / **+87,730** | 18 / **100%** / **+23,127** | 空腿回补于中枢下沿 |
| **t6（candidate Buy3 预回补）** | 116 / **37.1%** / **−46,813** | 39 / **35.9%** / **−9,640** | 中枢预离开止损 |
| t7（confirmed Buy3 回补） | 29 / 51.7% / +13,674 | 20 / 65.0% / −118 | 中枢离开确认止损 |
| forced（master/eod 强平） | 2 / 0% / −3,188 | 0 / — / — | — |

**结构判读**：
- zd_touch 100% 胜率是**几何必然而非 alpha**——开腿守卫要求 c > ZD（零利润空间拒），
  触线闭腿条件 c ≤ ZD，故凡走到此口的空腿回补价必低于开腿价。真正的信息量在
  **存活率**：能活到触线的腿 OKLO 21%（38/183）、BRN 23%（18/77）。
- **V2r 的全部正贡献来自 zd 触线腿；t6 是唯一结构性亏损口**，且两标的胜率几乎同值
  （37.1% / 35.9%）——这是机制性而非标的特异性。t6 占闭腿 63.4%（OKLO）/ 50.6%（BRN），
  其净亏损是 REV 腿为"等待触线"支付的止损成本：REV 经济学 = zd 必然盈利 ×存活率
  − (t6+t7) 止损成本。OKLO 该差额 +51.4K、BRN +13.4K，均为正——成本结构成立。
- **不可直接推论"砍掉 t6"**：t6 是预离开止损口，关闭它的反事实（腿被持到 t7/强平）
  本数据不可读出；candidate Buy3 撤销率（candidate 不被 confirm 的比例）才是
  t6 vs t7 取舍的判决数据——列为后续工位候选。

（亏损腿锚深度远高于门槛）：深度度量震荡空间大小，不度量中枢被突破的概率。

## 8. 判决汇总

1. **V2r 的盈利结构 = zd 触线几何兑现 × 存活率（21–23%）− t6/t7 止损成本**，
   两标的同构成立。alpha 不在闭腿口选择（zd 100% 是规则必然），在**开腿质量**
   （什么腿能活到触线）。
2. **t6 预回补是唯一结构性负口**（胜率 36–37% 跨标的同值），但它是止损机制，
   砍除的反事实需 candidate-Buy3 撤销率数据，本分解不裁决。
3. **盘背卖触发两标的一致净负**（payoff 0.73/0.77）——V2r-t1only 消融是
   数据驱动的下一个预注册实验。
4. **MDD 的缠论结构位置 = 趋势延伸段的中枢离开阶段**（连续多锚 t6/t7 批量止损，
   零 zd 兑现），深度门对此无保护——若需 regime 护栏，方向是"中枢离开概率"
   而非"中枢深度"。

## 9. 结果包六要素

1. **结论**：§1–§8。两标的逐笔分解 + 四项同构发现（闭腿口分化 / 盘背卖负贡献 /
   MDD 位置 / 亏损腿持仓更长）。
2. **定义依据**：REV 开腿 = confirmed Sell1 ∨ 盘整背驰卖 × 中枢存活 × 深度门
   （`level_operating_unit.rs::rev_paired_open`，第38课 RIDE↔REV）；闭腿四口 =
   T7 confirmed Buy3 / T6 candidate Buy3 / T5 同锚 Buy1 / ZD 触线
   （`step_down_paired`，闭腿集穷举）；中枢边界 ZD/ZG 第20课口径。
3. **边界条件**：①结论绑定修复后引擎代次（tape_fp 守卫，引擎再变更全表作废）；
   ②zd_touch 100% 胜率依赖"成交价恒 close、无滑点"的 P5 口径——真实执行下触线
   单的滑点可使其 <100%，但几何优势方向不变；③盘背卖负贡献若在期货其他标的反号
   则 V2r-t1only 方向作废；④t6 负口的"止损必要性"未经反事实检验——若 candidate
   Buy3 撤销率高（多数 candidate 不被 confirm），关 t6 可能反而增益，结论会从
   "保留 t6"翻向"只认 t7"；⑤时间分布是描述性弱信号（分桶样本 1–14 条），
   不可作门控依据。
4. **下游推论**：①M2 信号层若消费 V2r，开腿侧"只接 type1 卖"是首要消融实验；
   ②REV 的 regime 护栏方向应为中枢离开概率（如 candidate Buy3 出现率）而非深度门
   加严；③`rev_open_log/rev_close_log` 诊断流（Counters 内，PyO3 不可见）为后续
   任何 REV 行为分析提供常设数据面。
5. **谱系引用**：`project_rev_paired_fix`（配对修正与同锚 Buy1 空有效域）；
   `project_bsp_gap_root_cause` + `project_c_segment_fix_b2`（C段修复——本磁带代次
   的来源）；532号（seg-end 触发轴分离）；231号（认识论等级标注）；090号
   （zd_touch 100% 标注为几何必然而非 alpha——声明=能力）。
6. **影响声明**：新增 `rust/src/trading/trade_behavior.rs`（cfg(test) 纯 Rust
   行为分解产出）；`types.rs` Counters 增 `rev_open_log/rev_close_log` 字段 +
