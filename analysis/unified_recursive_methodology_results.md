## 结论（一句话）

形态学三层（分型→特征序列→中枢）是**同一递归方法**（骨架 an=f(an−1) 不变）
的辩证发展（谱系536）；线段=次级别走势是**同一-差异双重性**（同一段价格运动
**同一**地是次级别走势，但走势是否完成需特征序列确认是**差异**侧），settle 门
是差异侧的工程显式化（谱系537，与538号会计双重性互为对偶面）；同一笔物理交易
父=降成本/子=独立头寸是会计层的同构双重性（谱系538）；NRF v5（换清仓参照层）
**八标的 L3 否证**（P1 2/8 < v4 3/8），正确方向是恢复次级别确认作独立事件
闸门 + regime 门两正交分支（谱系539，预注册未实装）。

## Part 1：递归方法论的辩证发展（谱系536，L0）

### 1.1 骨架 vs 包装（对抗核验产物）

「分型→特征序列→中枢是同一方法的递归发展」由两部分构成，认识论资格不同：

| | 内容 | 原文支撑 | 资格 |
|---|---|---|---|
| **骨架** | an=f(an−1) 递归形式不变 + 级别由量累加涌现 | 直接（第33课:182/368 + 第65课:182 缠师亲笔） | 原文定理 |
| **包装** | 包含/重叠统一为一方法、「质变」、「无断裂连续谱」 | 不直接（综合层诠释） | 蜂群综合 |

**关键诚实标注**（四路源文考据 + 对抗核验，workflow `wf_41a4b2e7-15a`）：
- **「包含」≠「重叠」**：K线/特征序列层用包含（方向合并取 max/min，第67课:20
  明文「如同一般K线图中找分型的方法……也存在所谓的包含关系」）；中枢层用
  重叠（区间求交 max(a2,b2,c2)~min(a1,b1,c1)，第17课:1050）。缠师从未统一
  命名。不变量在 **K线↔特征序列层成立**，延伸到「重叠→中枢」是蜂群综合。
- **「质变」**是辩证框架措辞——第33课「量变引起质变」是网友「小鸟」提问，
  缠师只确认「加多了就是级别大的盘整」。
- **与526号「两层本质区别」张力**：第65课:180「严格意义上把线段当成次级别
  是不对的」。骨架（递归形式连续）成立，但「无断裂连续谱」弱化了缠师坚持的
  a0确认层/递归层本质区别。

### 1.2 对引擎的下游推论

引擎三层模块（`BiEngine`/`SegmentEngine`/`ZhongshuEngine`）的独立性是**工程
便利非概念独立**——三层共享同一递归算子 f。**构件依赖**（线段错→重叠区错→
中枢错，001号退化段实证）⇒ **下层走势完成（settle）是上层结构成立的前提**
——这是 Part 2 的概念前提。

## Part 2：BSP 同一-差异双重性修正（谱系537）

### 2.1 同一侧（本体，非代理）

线段在递归基（a0）= 次级别走势**本体**（谱系003 Move[0]=Segment、第18/30课
「一个次级别走势离开/回试」逐字一致）。前序「segment→Move[1] 替换」是**越级
错配**（Move[1]是父级非次级别），已被 `bsp_engine_sublevel_fix.md` 否决——
**同一侧确认：不替换 segment。**

### 2.2 差异侧（走势完成需确认，settle 门）

但走势是否完成需独立确认（第65课:50「线段破坏的充要条件就是被另一线段破坏」
= 线段结束客观判据 = `Segment.confirmed` = `SegView.settled`）。工程显式化 =
`require_settled` 门（本 session commit `79dd56c0a8`）：

```
confirmed = 基线背驰/几何 ∧ (!require_settled || segment.settled)
```

type1 合取 C 段 settle、type2 合取回试段 settle、type3 合取回抽段 settle——
压制 §3 pending 生长期伪背驰（C 段生长中 force_c<force_a 必然伪背驰，settle 后
1120/1121 反悔）。同源先例 = 525号「中枢组件用 `confirmed AND kind==settled`
过滤」，settle 门把同一判据从中枢构造扩展到 BSP 确认。

### 2.3 引擎双层消费已实现（cl_clearance §7.3，修复A/B2）

递归层 type1 背驰：A/C 段力度在 `segs = level-(L−1) Move 序列`运算；中枢边界
取自 `zss = level-L LevelZhongshu`（从下级 settled Move 重叠构造）。修复A/B2
已消除旧代理 bug（`seg_end=last_zs.comp_end` 致 C 段恒空 OKLO 16/16）。
**BSP 检测同时消费相邻两层、不能用一个代理另一个**——这是把029/A/B2 症状级
修复提升为存在论规则（谱系537）。
