## 3. 构成性核心预测验证（关键发现）

**清仓频率由走势结构自然分化，零regime门**：

| regime | 标的(sellpt) | 走势结构 |
|--------|-------------|---------|
| 强趋势(少清仓) | ES=4, OKLO=5, CL=6, BTC=6 | E\*持续高→高层type1罕见 |
| 震荡/弱势(多清仓) | QQQ=7, BRN=7, GC=8, DX=12 | E\*频繁回落→根层type1触发 |

分化方向**完全符合任务预测**（"CL波动清仓多，BTC强趋势清仓少"），且**纯由 E\*
涌现层产生**——无任何 ClearanceMode 选项、regime 门、标的白名单。这证实了
"清仓频率是走势结构的函数，不需要外部门控编码"这一构成性论点。

OKLO sellpt=5 + 暴露0.83 → +1077.6%（v4 +833%）：E\* 走势结构驱动比振幅棘轮
更精确地在强趋势中保持高涌现层、在回调中精确清仓，收益反超 v4。

## 4. 边界条件（结论翻转条件 + 否定性结果）

**P1 8/8 未达成**——失败的 3 个标的(BRN/ES/BTC)揭示比"清仓频率regime函数"
更深的结构边界：

- **BTC**(BH+1380%) / **ES**(BH+594%) = 史上最强单边牛市。E\* 已把清仓减到
  最少(ES=4)，但只要 sellpt>0 就踏空——因为**强牛市每个 type1 背驰后都创新高**，
  任何 type1 清仓都是负期望。唯一 8/8 的清仓判据是"永不清仓"=退化为 BH+杠杆。
- **BRN**(原油 sellpt=7) = 清仓过多，URS+63.7% < BH+87.4%。

**翻转条件**：若标的是强单边牛（BH 远超任何择时），URS 必劣于 BH（清仓踏空）；
若标的有显著回调/震荡结构（CL/GC/DX/QQQ/OKLO），URS 跑赢 BH 且优于 v4。

**这是有信息增量的 L3 否定性结果**：证伪"存在零参数清仓判据使 8/8≥BH"。
强牛市的踏空不是清仓**层**的问题（E\* 已最优，3/8→5/8 证明层定义是真改进），
而是清仓**动作本身**在 type1-后-创新高 结构中的负期望——这是清仓判据无法绕过
的结构边界（清仓频率regime不可约 → 升级为：清仓动作在强牛regime负期望）。

## 5. 下游推论

- **E\* 走势结构驱动清仓层是构成性正确形式**（优于振幅棘轮v4、事件选层CT），
  应作为 nested 框架的清仓层默认候选（5/8 + MDD 8/8 + 零flag）。
- **开放轴**：清仓动作的损失边界 = 强牛市 type1-后-创新高 的概率。这不是层选择
  问题，是清仓**触发词汇**问题——可能的精化方向：清仓需要 E\* 层 type1 **且** 上一级
  (E\*+1)走势已确认转向（而非仅 E\* 自身 type1）。但这接近 anc 门（已否证），需
  预注册严格区分"E\*+1转向确认"与"anc regime门"的构成性差异后才能测。
- v4 仍是 BTC/ES 强牛域的对照基线（v4 也未解决强牛踏空）。
