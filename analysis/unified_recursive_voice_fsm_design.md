## §0 核心论题与三个发现

**论题**：hold26、趋势停削、R2位置门、anc豁免、双向翻转、nest_forward、H1冻结、H4振幅门、Seq38、osc/rev短差、域门、成本门、93课强震荡门——这十三个独立 config flag 模块，是**同一个递归 voice 在不同走势状态下的自然行为**，不是开关组合。

三个支撑发现（来自本次代码与判决文档审计）：

**发现一：positional_fusion 已是统一 FSM 的未完成形态。** `LayerState{Flat, Armed, Pending, Long, Short, Gated}` + 每 bar 结构读数（trend_row/dir_row/中枢账本/DepthRef）已实现十三模块中的十一个——只是每个机制带一个 flag。统一 FSM 不是新建状态机，是**把 flag 冻结为恒真、把开关决策移交结构读数**。

**发现二：unified_osc（fusion_u）是统一论的先行实验。** 其 docstring 已写明设计纲领："不问'这个标的开不开 osc'，而问'此刻走势结构在哪个级别处于震荡相且振幅过门'"（038:28 regime 由分解级别内生定义）。三门合取（相位门×振幅门×93课强震荡门）已经把 co/h1/h3/h4 四个白名单模块统一为三个结构读数。本设计是同一逻辑推广到全部十三模块。

**发现三：白名单分裂的结构根源 = 模块各自带门、互相绕过。** 实证：nest_forward 的负域 {BTC, CL} 恰是 fusion_t 停削的最大赢家——nest 的 candidate 触发路径**绕过了停削窗口的 confirmed 消费门**，在停削保护的走势段里提前消费 orphan candidates（`interval_nesting_forward_positioning.md` §5.4 "诱空削减"）。每个模块在自己的消融实验里各自验证、各自带门，门没有共享 ⇒ 合取时互相打洞 ⇒ 负交互 ⇒ 按标的分白名单。**统一 FSM 的核心架构修正：门是相位的属性，不是词汇的属性**（§3 行为表）。

## §1 统一 voice 的存在论

### 1.1 voice 是什么

一个 voice@k 是 **38课操盘程式在级别 k 上的实例**：持有该级别配额 slice，按该级别的走势结构与买卖点做"卖点变少、买点回复原数量、绝不加仓"（026:34）的恒仓极性操作。原文依据：

- 026:34「本ID的仓位是一直不变的，最开始多少就是多少，上上下下，卖点的时候变少，买点的时候又回复原来的数量，但绝对不加仓」——voice 的恒仓基座（L0 定理，双向会计 §2.5 同股数量纲）。
- 038:30「你可以设定某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作……机械地按照一个规定的节奏去吸市场的血」——多 voice 并发的原文授权。
- 038:28「无所谓牛市熊市……市场被有效地肢解成一段段30分钟走势类型的连接」——voice 的 regime 由其分解级别**内生定义**，零外部标签。这是"缠论不能被标的特化"的最强原文支持。

### 1.2 递归自相似

084:14「不可复制的走势，却毫无例外地复制着自同构性结构，而这自同构性结构的复制性是绝对的」——每个 voice 运行**完全相同的 FSM**，差异只在级别坐标 k。voice@k 读 k 层结构、操作 k 层 slice、其行为受 voice@(k+1) 状态门控（§4 递归传导）、其反向窗口内激活 voice@(k−1)。

### 1.3 唯一参数 = a0

a0 = 最低级别 K 线粒度。其上一切级别由引擎递归涌现（笔→段→中枢→move→recL2…）；配额由 θ 权重（每层典型中枢振幅的因果滚动 P50 归一化，`positional.rs theta_weights`）从结构涌现——053:26/53:34 资金配额原文留白 + 026:34「级别的意义基本只和买卖量有关」的回测裁决形态。`FIRST_BSP_LADDER` 是 a0 的派生（买卖点事件流的承载下界，非自由参数）。

## §2 状态空间的严格推导：状态最小化定理

### 2.1 三分法：真状态 / 结构读数 / 账本事实

蜂群已积累五例"状态范畴胜事件范畴"判决（HoldTrend 第四例、osc_domain 第五例等），但需要更精确的区分——那些"状态"大多**不是 FSM 要存储的状态**，而是走势结构的每 bar 直读：

| 范畴 | 定义 | 例 | FSM 是否存储 |
|------|------|----|--------------|
| **结构读数** | 可从当前磁带行/中枢账本无状态重读 | kind(k)、dir(k)、θ_q(k)、中枢单调性、candidate 存在性、次级别证据 | 否——每 bar 纯函数 |
| **账本事实** | slice 的物理位置（钱在哪里） | Full / 短差在外 / Short / Gated / 铰链部分在外 | 是——这就是极性相 |
| **配对快照** | 开腿时刻冻结的比较基准，事后不可从当前结构重读 | 锚中枢 cs/ZD/ZG、seg1_low、candidate 极值、卖出股数 | 是——挂在极性相上 |
| **窗口锁存** | 事件留下的、结构不保留的记忆 | nest 武装窗口、三卖否决 latch（dead_down）、铰链身份未决 | 是——少量 bool/Option |

**状态最小化定理（L0）**：统一 voice 的存储状态恰好是 {极性相, 配对快照, 窗口锁存} 三元组。十三模块中没有任何一个需要额外状态——它们要么是结构读数（停削/anc/域门/成本门/H4/93课），要么是极性相的转移（hold26/双向/osc/层内C/Seq38），要么是窗口锁存（H1/nest/三卖否决/铰链）。

证明方式：§5 映射表逐模块给出其在三元组+读数下的表达；任何模块若需要第四类状态即否证本定理（目前无反例）。

### 2.2 极性相的完整枚举

```
Polarity =
  | Full                                   // 满持本层 slice（26课恒仓基座）
  | OscOut { shares, anchor(cs,zd,zg,alad), dead_down, restore_due }
                                           // 短差在外（先卖后买的配对态）
  | Hinged { q_out }                       // 44:44 铰链：先出一部分，身份未决
  | Gated                                  // 持币+回复门（纯回复门态，零空头暴露）
  | Short { units=M=N, proceeds_basis }    // 翻空（载体允许时；双向会计单相单律）
```

加上树根（master）的入场前态 `Flat / Armed(区间套布防)`。这与现有 `LayerState{Flat,Armed,Pending,Long,Short,Gated}` 几乎重合——差异：(1) `Pending`（资金推迟）降为 `restore_due` 标志（义务恒在逐 bar 重试，D7 同构），不是独立相；(2) 新增 `Hinged`（当前实装里铰链以 SubOut+escalate 路径隐式表达，统一后显式化）。

**FLAT = 测度零过渡**（双向会计 §5.3）：翻转 bar 内 cascade settle 四步序（①子树结算→②旧书平仓→③新书开仓 M=N→④子腿惰性实例化）的中间值，无任何 bar 以零持仓驻留。

### 2.3 行为函数（无状态）

```
act : (Polarity, Φ, gates, events) → Transition
其中
  Φ(k)    = 相位读数 ∈ {EXEMPT(满仓豁免), OSC_strong, OSC_weak, MOVE↓}   （§3.1）
  gates   = { amp: θ_q(k) ≥ k_cost×friction,  pos: c vs ZG/ZD 位置 }      （35课 / R2）
  events  = 本层与次级别的 BSP/背驰/candidate/中枢事件（磁带直读）
```

模式（osc/rev/停削/翻空……）**不是状态**——是 `act` 查表的行。这就是"零 config flag"的形式语义：当前每个 flag 选择"表里哪些行存在"；统一 FSM 中全表恒存在，行的触发由 Φ×gates×events 决定。

## §4 递归规则

### 4.1 常驻配额 × 递归激活（spawn 的严格形式）

任务 B 原拟"spawn 子 voice + 生命周期 = 反向线段"。严格化后修正为：**voice 树常驻（配额结构），活动状态递归门控**。理由：

1. spawn/销毁需要资金转移协议（违反 θ 权重配额的层级守恒）；激活/休眠只是行为开关。
2. 026:34 恒仓基座要求每层 slice 常驻——"子 voice 不存在"的严格语义是"该层 slice 处于 Full 且行为被门控"，不是配额消失。
3. 38课程式的反向段窗口已由 Φ(k) 读数表达：父层 EXEMPT ⇒ 子层停削（豁免传导）；父层 OSC ⇒ 子层全表激活。"spawn"= 父层进入震荡相时子层削减词汇重开，"销毁"= 行 2 的满仓义务强制回补。

递归终止（三范畴，与在册 SubLou 一致）：
- **存在论**：k < FIRST_BSP_LADDER ⇒ 无买卖点/中枢概念，voice 不可定义（a0 派生，62/77/78课笔=最低结构）。
- **经济**：θ_q(k) < k_cost×friction ⇒ 行 10 路由——该层 voice 的本层节奏永久休眠，slice 由上扫层代管（35:30，配额经 θ 权重自动趋零）。
- **结构**：该层从无中枢涌现 ⇒ θ 参照不可定义 ⇒ 保守休眠（不静默放行先例）。

### 4.2 豁免的递归传导（替代 ∃j 全局扫描）

当前 anc 豁免 = `∃j>k: trend(j)∧up(j)` 的**全局扫描**（TrendScope 三值 flag：Self/SelfOrAncestor/Ancestor，三种读法在 L3 上按标的分裂——ES/QQQ 取 Ancestor、BTC/CL 取 Self、GC/DX 全伤）。递归 FSM 给出唯一形式：

```
exempt(k) = (trend(k) ∧ up(k)) ∨ exempt(k+1)        // 每层只看直接父亲
```

归纳展开 ≡ SelfOrAncestor（fusion_ta）——**TrendScope 枚举在递归形式下消失**，这是 275号"附庸的附庸不是我的附庸"局部依赖原则在交易层的同构。fusion_ta 的在册双伤（GC/DX）根因不在范围轴而在错位轴（§3.1）：49:54 新中枢出口（行 4）使豁免窗口在趋势内新中枢形成时**逐层局部退出**，趋势内 OSC(C_N) 期的削减恢复。即：范围取最大（SelfOrAncestor 的递归形式）+ 出口取严格（49:54），替代当前"范围窄出口无"的三种平铺投影。预注册 §9 U3。

### 4.3 嵌套开空 = 在册削减回补（防膨胀定理）

m≤N 的嵌套开空与削减-回补在账本上同一（双向会计：零新 alpha 防膨胀，L0）。递归 FSM 不为子层引入独立空头书——子层反向操作恒以"卖出-接回"表达，翻转断面（行 14）仅在确认级别成立的层表达。

- **门是相位的属性，不是词汇的属性**——这是十三模块白名单分裂的统一解释：每个模块在各自消融实验中自带门，合取时互相绕过（nest 绕过停削窗口是实证案例）。统一 FSM 的本质不是合并代码，是合并门。
- **状态最小化**：十三模块没有一个需要新状态——全部分解为极性相转移、结构读数、窗口锁存三类。这与蜂群五次"状态范畴胜事件范畴"判决一致，但更进一步：那些"状态"是每 bar 重读的结构，FSM 真正要记的只有"钱在哪、开仓时冻结了什么基准、哪些事件留了锁存"。
- **递归消灭枚举**：TrendScope{Self,Ancestor,SelfOrAncestor} 三值 flag 在"每层只看直接父亲"的递归传导下归约为单一形式——全局扫描的参数自由度是平铺架构的伪自由度。
