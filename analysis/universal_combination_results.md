任务（2026-06-12）：一个配置，所有标的，零标的级参数——把所有标的无关
模块合取到双向系统。基线 fusion_btra_s34（BTC 全史在册最优 +7368.0%），
叠加 {nest_forward, H4 振幅门, 1s a0} 三模块。

**判决：全局普适配置否证（P1 6/8 / P2 1/8 / P3 破）；合取的增量符号
结构 8/8 可由单轴 regime 白名单预测（正交合取保号性第一例）；GC 意外
升新在册最优（+342.6 > hold26 +300.5，双向正域第五标的）。**

认识论等级：L3（八标的全史真实数据交叉验证，预注册判据先于运行）。

## 2. 机制归因

### 2.1 nest 增量符号 8/8 复现在册 nest regime 白名单（核心发现）

btran − btra 差分（nest 在双向基座上的边际增量）：

| 域 | 在册 nest_forward 判决（fusion_tn/trn 口径） | 本次（×双向基座） |
|----|------------------------------------------|-----------------|
| 正域 | OKLO +61.1 / ES +31.8 / BRN +6.3 / DX +3.7 | OKLO **+101.4** / ES **+53.5** / BRN **+17.5** / DX **+3.6** |
| 负域 | BTC −677 / CL −69 / QQQ −7 | BTC **−2410** / CL **−17.6** / QQQ **−7.3** |
| 近零 | GC ≈ 0 | GC −8.2 |

**正交合取保号性**：nest 轴的 regime 符号函数在更换基座（fusion_t→
fusion_btra_s34）后 8/8 保号——单轴白名单可预测合取臂的增量方向。
这是合取实验第一次给出"regime 函数跨基座稳定"的正面证据（对照：
负交互在册先例如 B+C 合流、双门合取均为符号翻转）。正域量级放大
（OKLO +61→+101，ES +32→+54）：双向基座给 nest 提供了新的作用面
（空头侧时机），正域标的两面同向受益。

### 2.2 BTC P3 破的解剖：nest × short 在路径 alpha 上互毁

BTC 空头腿已实现净现金：btra +50,804 → btran **−164,812**（翻空数
294→305 仅 +11）。在册 S1-S4 判决：BTC 双向增量的主体不在空头腿现金
而在翻转断面的 NAV 路径（躲跌 + 低位重入），且该路径效应以 confirmed
时点为锚。nest 把卖侧触发提前到 candidate×次级别第一证据——更早翻空
=更高的开空价位错误率（candidate 被打破的那部分由 nest_breaks 5,058
次部分拦截但非全部），同时买侧 nf 提前平空压缩了"低位重入"的低位。
两端同时移动后路径增益解体。**nest 负域（BTC/CL/QQQ）恰是双向/趋势
路径 alpha 最大的标的**——与在册"削减本身失血 vs 滞后失血"分解一致：
nest 修复滞后失血，但对路径 alpha 标的，滞后本身是 alpha 的组成部分。

### 2.3 ES/QQQ：P1 破在基座不在 nest

ES nest 增量 +53.5（正域复现）但 btra 基座本身 −75.8（vs fusion_tr）。
ES 在册修复模块是 **多头侧 anc 豁免**（hold26_anc，trend_scope=
Ancestor，26:80 满仓修复）——本臂的 a 是**空头镜像 anc 门**
（short_anc_gate），两者是不同机制（预注册时已声明）。trend_scope ×
short_mask × nest 的三轴合取未预注册、未实装——这是 ES/QQQ 修复的
唯一剩余路径，列开放轴首位。

### 2.4 GC：双向正域第五标的（意外正结果）

GC btra_s34 +342.6 > hold26 在册最优 +300.5（btran +334.4 亦超），
MDD −23.0 vs fusion_tr −37.1。GC 此前是 fusion 负域（fusion_t/anc/ta
全劣于 hold26）、S1-S4 探针未列；统一 s34 白名单首跑直接翻越在册最优
——空头条件轴的有效域比探针2 的 {BTC,CL,DX} 更宽。GC 的 anc_rejects
526 次 = 镜像门高频拦截，条件化开空（仅祖先 Trend∧Down 窗口）恰好
匹配 GC 的 range 性格。**GC 部署形态变更候选：hold26 → fusion_btra_s34**
（需独立确认臂：fusion_btr_s34 对照以分离 anc 门贡献，未预注册不擅跑）。

### 2.5 MDD 面：nest 7/8 改善

btran MDD ≤ btra：7/8（仅 BTC −59.6 略深于 −56.0）。与在册"nest MDD
改善 6/8"同构——正向定位让出场更早，回撤普遍变浅，且 8/8 浅于
fusion_tr。普适配置的 MDD 面是其最强读数（BTC −59.6 vs BH −84 /
CL −44.3 vs BH −94）。

## 5. H4 不可合取性矛盾上浮（no-workaround 义务）

**矛盾精确描述**：任务要求合取 H4；H4 的已实装对象 = osc 腿开腿准入
（LOU 引擎 `osc_amp_gate`；fusion 引擎 `OscRouting::Unified` 门②）。
fusion_btra_s34 无 osc 层 ⇒ H4 域空。使 H4 域非空的唯一路径 = 开
`OscRouting::Unified`，但 osc × short_mask 在翻转断面冲突：

- OscLayer 不变式：`outs[k].is_some() ⇒ layers[k] 为 Long`，osc 开腿
  = 本层 slice **全抛在外**（049:64）；
- 翻转断面已结算定义（bidirectional_nested_accounting §5.2）：同 bar
  同价、M=N 同股数、断面 pool 净流转 0；
- 层 k 持有 osc 在外腿时卖点到达 ⇒ 44课铰链升级为出清，出清价 = osc
  卖出价（更早 bar）≠ 断面价 ⇒ 若继续翻空，"同 bar 同价"与"断面无
  渗漏"两条已结算性质同时失效。

接受 A（强行合取）⇒ 须重定义翻转断面会计（已结算定义变更，触发
020号阻断等待）；接受 B（域空判决）⇒ H4 不进入本组合，普适配置不含
osc 层词汇。本判决取 B 并上浮：**osc 载体上的翻转断面会计是否值得
重定义**属编排者价值判断（选择类）。代价参照：fusion_u（osc 层之于
fusion 引擎的在册形态）未在任何标的进入部署矩阵——重定义的预期收益
无在册正面证据。

## 6. 结果包其余要素

**定义依据**（要素二）：027课区间套程序定理 + 038:258（nest）；26:80
镜像下沉（anc 门）；26:34 同股数 / §5.2 四步序（翻转断面）；035:30
（H4 判据原文，本判决其域空）；049:52/64（R2 双侧位置门）。输入特征
：八标的 1min 全史磁带（tape_fp 与 p7_conj 在册逐项一致）。

**边界条件**（要素三）：(a) 零摩擦 close 口径——nest 提高换手
（trades +5~10%），摩擦面下正域增量会收缩；(b) s34 白名单统一施加
——CL 的 −247pp 部分是 s24→s34 白名单错配非纯 nest 效应（两差分
纠缠，分离需 fusion_btra_s24n 臂，未预注册）；(c) GC 变更候选依赖
anc 门 + s34 的合取，btr 对照臂缺位 ⇒ anc 贡献未分离；(d) 1s 探针
单窗口下行 regime，上行窗结论可翻转；(e) P2 的"90%"对小基数标的
（DX 15.9）数值敏感。

**下游推论**（要素四）：(i) regime 函数跨基座保号性若在第二对轴上
复现（如 anc×nest），合取实验可降级为单轴白名单查表——蜂群实验
预算的结构性节省；(ii) GC 进入双向正域 ⇒ 探针2 的 (标的×层级) 符号
表需补 GC 行；(iii) ES/QQQ 修复钉死在 trend_scope×short×nest 三轴
合取（唯一未试路径）。

**谱系引用**（要素五）：区间套正向定位八标的判决（nest regime 白名
单）、双向 S1-S4 实装判决（BTC +7368 基线）、hold26_anc 白名单判决
（ES/QQQ 部署）、统一配置调研 v2（fusion_u/H4 门②）、osc 域腿判决
（co 白名单先例）、090号严格性、formalization-validity-domain
（L0-L3 标注）。涉及概念分离：H4 域空判决延续"形式化有效域 ≠ 定义
域"谱系（222/223/230号同型）。

**影响声明**（要素六）：新增 rust `fusion_btran_s{digits}` parse 臂
+ short_mask×nest 守卫放行（仅 anc∧¬ghost 形态）+ nf_buy 接入平空
出口（`cover_nest` 归因行）；在册模式零接触（guard-a/b/c 三守卫
逐位复现 BTC hold26/fusion_tr/fusion_btra_s34 + 八标的 tape_fp）；
新增 2 单测（257 全绿）。部署矩阵唯一变更候选 = GC。
