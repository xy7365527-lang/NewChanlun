## 2. 机制归因

### 2.1 H1 重审：机制普适、载体拖累（编排者假设的精确成立形式）

编排者重审假设"candidate 未决=走势方向未定，机制本身结构性"成立：
H1 在其定义域（osc 开腿准入）上 6/8 非负、BTC 单标的 +932pp（把 u 的
−4727 修回 1/5）。在册"OKLO 专属"判决的根源不是机制标的特异，而是
**当时的载体（LOU osc 白名单）与测量窗口**——换到 fusion osc 层后
普适性显形。但 H1 是寄生模块：f 无 u 即无对象，而 u 本身 5/8 为负
⇒ u∧f 合取仅 {OKLO,GC,QQQ} 微正。**H1 的下一个开放轴**：把"candidate
未决冻结"挂到非 osc 词汇（如翻空准入门——candidate type3 未决时不
翻空），那是新机制（非本轮已实装模块），需独立预注册。

### 2.2 Seq38 全负否证：载体依赖第二例 + 腿现金正/路径负第三例

Δq 0/8 正——LOU 在册正判决（OKLO +10.2/BRN +4.1pp）**不可迁移**到
fusion 框架。两层归因：

1. **腿现金 vs 路径效应分裂（第三例，B2/recL2 消融同谱型）**：seq38
   腿自身净现金 6/8 为正（BTC +294K / BRN +31.5K / GC +6.0K / QQQ
   +6.0K / OKLO +2.9K / DX +1.9K），但总收益 8/8 为负——伤害全在
   路径：slice 在外期间本层卖点被 44课铰链以**旧卖价**升级出清（替代
   了 base 的当价削减/翻空），重锚又重置削减周期；BTC 18.3K 次开腿
   = 18.3K 次对双向路径的劫持。
2. **无成本门的 LOU 逐字移植放大了开腿频率**：38课程式无振幅经济门
   （LOU 逐字，差分已声明），段层盘背事件在 fusion 高频触发；LOU 语境
   有 REV 域/声部结构钳制开腿，fusion 无此钳制。

### 2.3 u（H4 承载臂）：正域 {CL,GC,DX} = range/慢标的

Δu 正的三标的恰是 range 性格域（CL +19.1 / GC +4.8 / DX +0.1）；
BTC −4727 是单标的最大伤害（osc 腿净现金 −1.49M——强趋势标的的 osc
腿全在"卖了不该卖的"）。与 fusion_u 在册判决（未进部署矩阵）方向
一致；H4 ②门在 7/8 标的有判别力但其宿主整体为负 ⇒ "H4 模块全局正"
（任务前提，源自 LOU osc **摩擦面** 5/5）在零摩擦 fusion 面**不成立**
——口径分裂在册先例（H4 判决本就是"零摩擦 3/5 vs 摩擦调整 5/5"的
口径分裂第一例，本轮零摩擦读数与之自洽）。

### 2.4 交互结构：小效应近可加，大效应次可加

七标的 |残差| ≤ 37pp（v1 保号性/近可加在矩阵尺度复现）；BTC +5113
=各模块都在劫持同一批削减时点，重叠后伤害不满叠加。推论：**消融矩阵
的边际符号可信，量级在大效应标的不可线性外推**。

## 4. 结果包其余要素

**定义依据**（要素二）：49:68（H1 candidate 当下判据）/ 49:52（冻结
窗口前提）；38:36 + 答疑:296（Seq38 程式与 nobreak 岔判据本体）；
035:30（H4 ②逐字）；093:26（③强震荡）；026:80 镜像（anc）；027课
（nest）；044:44（铰链——seq38 路径伤害的承载机制）。

**边界条件**（要素三）：(a) 零摩擦口径——H4 的在册正判决在摩擦面，
本轮 Δu 符号不构成对其摩擦面判决的否证（口径分裂声明）；(b) Δf 是
osc 载体上的边际，H1 挂其他词汇未测；(c) Seq38 的 fusion 移植含三处
声明差分（不递归/无 earning 拒/保留满仓义务）——全负判决限此移植
形态，不及 LOU 原形态；(d) custody 分区使 u/q 不触白名单层——若
白名单扩张（如 s234），u/q 的对象域收缩，边际会变；(e) BTC 残差
+5113 表明该标的任何多模块合取的量级预测都不可线性外推。

**下游推论**（要素四）：(i) H1 机制升格为"普适修复门"候选——其在
非 osc 词汇上的挂载（翻空准入）是下一预注册轴；(ii) 载体依赖第二例
（Seq38 正→负）与第一例（H1 专属→普适）方向相反 ⇒ "LOU 在册判决
不预测 fusion 框架符号"成为一般教训：跨引擎模块迁移必须重测，在册
判决只许可词汇不许可符号；(iii) 腿现金正/路径负第三例巩固"新 alpha
全在路径/断面，不在腿自身"的结构结论（26:80 净额等价警告的第三次
实证）。

**谱系引用**（要素五）：v1 判决（正交合取保号性）、osc 白名单消除
调研+H1 判决（"OKLO 专属"被本轮推翻的对象）、Sequence38 严格形式
（LOU 正判决，本轮证其载体依赖）、H4 滚动振幅准入（口径分裂第一例）、
S1-S4 判决 B2（腿/路径分裂第一例）、双门负交互（V3 教训来源）、
090号严格性。涉及概念分离：**载体依赖**（同一机制在 LOU/fusion 两
载体上判决翻转，双向两例）建议新开谱系条目。

**影响声明**（要素六）：rust 新增——`OscRouting::Unified.h1_freeze` /
`Fusion.seq38_sub` 字段、`fusion_btra{mods}_s{digits}` 文法（旧名逐字
兼容）、osc/seq38 的 custody 分区、nf 透传 osc 出口与 SubOut 铰链、
try_restore reason 参数化（"sub_diff" 零漂移）、5 新计数器导出、
5 新单测；在册全部模式 guard 逐位复现（含 v1 btran 臂）零接触。
