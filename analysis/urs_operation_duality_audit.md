# URS 操作-双重会计身份审计——Phase 0 前置门

> 任务（2026-06-13 编排者）："每一个操作都有双重会计身份。不存在单一身份的操作。
> Phase 0 之前先做这个会计审计——列出 URS 当前所有操作点，逐一标注双重会计身份。
> 如果某个操作只有单一身份（比如清仓只平仓不翻转）——那就是实装缺口。"
> **认识论等级：L0**（纯代码追踪；操作枚举经 2 独立 agent + 直读代码 + §8 审计 D1 四路三角验证；
> 对抗核验阶段服务端限流未完成——load-bearing 缺口为单行代码事实，证据直接）。

## 0. 判决（先行）

**URS 8 个操作点中，2 个 SINGLE-GAP（清仓 C + 翻转）。其余 4 DUAL-COMPLETE + 1 GENESIS + 1 TERMINAL。**

| 操作 | URS 代码 | 该级别身份 | 次级别身份 | 双重性 |
|---|---|---|---|:---:|
| **C 清仓** | `unwind_to(0,"sellpt")` 294 | 平仓 N→0（变现回 free） | **缺失**（应反向开 0→N反向） | **❌ SINGLE-GAP** |
| **翻转** | **无实装**（注释 55 声明，无代码） | 应：方向切换 多↔空 | 应：原向回归+新向诞生（仓位连续） | **❌ SINGLE-GAP** |

| D 回补 | `pop_tail("recover",true)` 309 | 买回 m N-m→N 降成本 | 子平仓 P&L≡父降成本 | ✓ DUAL |

**一句话**：URS 把环23"出场=翻转=新建仓"退化为"出场=清仓到现金→F 重新开多"——清仓只做
"平仓"半身（该级别），缺"翻转"半身（次级别反向开仓）；翻转作为独立操作整体缺失。两缺口同根：
**URS 继承 v4 单向基座（根恒多头）**。E spawn 已证双向身份**可**实装（子可空可多），故缺口非
"双向不可实装"，而是 C/翻转特定继承了根恒多约束未改写。

## 1. 两个 SINGLE-GAP 的代码事实（四路三角验证）

### 1.1 C 清仓只平仓不翻转（编排者点名）

`unified_recursive.rs` C 块：
```rust
293  if sig.sell_any.get(estar) && located_sell[estar].is_some() {
294      unwind_to(0, bar, c, c, "sellpt", &mut chain, &mut free, &mut n_base, &mut res);
295      located_sell = [None; MAX_LADDER];   // located 清零 = 清仓即终点
296      acted = true;
```
`unwind_to(0)` 解栈全链 → 根经 `pop_tail` 根分支（`nested_fugue.rs`）：
```rust
208  match chain.last_mut() {
209      None => {                                          // 链空=根弹出
210          debug_assert_eq!(v.dir, Polarity::Long, "根恒多头（v4 无根翻转）");
211          *free += v.units * c + v.capital;              // 纯变现回现金
212          *n_base = 0.0;                                 // 无任何反向开仓原语
213      }
```
**该级别身份成立**（平仓 N→0），**次级别身份缺失**（无反向开 0→N反向）。清仓后仓位=全现金，
须等 F（`chain.is_empty()`）下个买证据重新开多。

### 1.2 翻转操作整体缺失

URS 全文无翻转原语。根分支 `debug_assert_eq!(v.dir, Polarity::Long)`（line 210）硬钉根恒多头。
环21"卖点翻空买点翻多→永远有方向"、环23"出场=翻转=新建仓"在 URS 无实装。子级别翻转**部分**
存在于 E spawn（子方向跟随子级别，Polarity 镜像），但**根级别翻转=0**。

### 1.3 双向机制已存在但 URS 未导入

`dual_voice.rs`：翻转断面 M=N（同股数翻转，两个独立会计动作，非单一符号翻转）+ ShortBook
双账本极性分离 + LayerState::Short + "同级别多空可共存"。`recursive_nested_fugue.rs`（RNF）：
"平多≠开空"推到极限（根永不平多）。**URS 既不导入 dual_voice 的翻转机制，也未走 RNF 的
"根永不平多"——而是 v4 的"清仓到现金→重新开多"，是两条路线之外的第三态（单向+现金中转）。**

## 2. 概念链正典依据（环21/22/23）

| 环 | 正典 | URS 是否满足 |
|---|---|:---:|
| 环21 多空对称 | "卖点翻空买点翻多→**永远有方向**。绩效=Σ\|涨跌幅\|" | **❌**（清仓到现金=无方向；只多头=只吃涨幅） |
| 环22 多空嵌套 | "父多→子空→孙多……每层跟随自己级别的势方向" | 部分（子级别交替✓，根级别恒多✗） |
| 环23 操盘三阶段 | "建仓→降成本/挣股数→**出场=翻转=新建仓**（循环）" | **❌**（出场=清仓到现金，非翻转=新建仓） |

URS 违反环21"永远有方向"（清仓到 free=flat）+ 环23"出场=翻转"（出场到现金非翻转）。
**长期单向 ⇒ 只捕获涨幅，丢失全部跌幅**（绩效 ≠ Σ\|涨跌幅\|，只 Σ涨幅）。这与 Phase 1
CL/ES 坍塌部分同源：清仓到现金=踏空后续走势（若翻空则吃到下跌）。

## 4. 结果包六要素

1. **结论**：URS 8 操作点审计——清仓（C）+ 翻转两项 SINGLE-GAP（应双重却单一），其余 DUAL-COMPLETE(4：
   A/B/D/E) + GENESIS(1：F) + TERMINAL(1：eod)。清仓只平仓不翻转（编排者点名）坐实；翻转作为独立操作
   整体缺失。根因 = v4 单向基座（根恒多头 `debug_assert Long`）+ dual_voice 双向机制未导入。

2. **定义依据**：编排者双重会计身份规格（清仓=平仓+翻转 / 降成本=卖+开反向 / 回补=买回+子平仓 /
   翻转=方向切换+新旧 voice）；概念链环21（永远有方向）/环22（方向交替）/环23（出场=翻转=新建仓）；
   代码事实 `unified_recursive.rs:294` + `nested_fugue.rs:208-213`（清仓纯变现）+ `:210`（根恒多断言）。

3. **边界条件**：结论翻转条件——若 URS 导入 dual_voice 的 ShortBook+翻转断面 M=N，改写
   `nested_fugue.rs:210` debug_assert 为极性中立，根 pop_tail 增加"平仓后用 free 反向开根空 voice
   （带否定线）"分支，则 C/翻转转 DUAL-COMPLETE，缺口消解。当前根恒多约束未改 ⇒ 缺口成立。

4. **下游推论（对 Phase 0-5 决定性）**：

## 5. 编排者裁决（2026-06-13）：翻转 = 降成本的极端情况（m=N），非独立操作

> "翻转=降成本的极端情况（m=N），不是独立操作。清仓时不是'平仓后重新开空'——是'卖出全部
> N 股=子 voice 用全部资金开空'。和降成本 E 操作完全同构，只是 m=N。否定线在子 voice 的
> 生命周期管理中保护（027:25 破极值→子 voice 强平）。"

### 5.1 对 §0/§3 框架的修正

本审计原把"翻转"列为**独立缺失操作**——**框架被裁决修正**：翻转不是独立操作，是 **E spawn 的
m=N 特例**。因此 URS 实为**一个**缺口（非两个）：**C 清仓用 `unwind_to(0)`（纯变现，line 311）
而非 `spawn(m=N)`（满仓反向子，line 334-403 同构）**。"翻转 SINGLE-GAP"应理解为"C 清仓未走
spawn 路径"的同一缺口的对偶面，非独立第二缺口。

### 5.2 spawn(m=N) 结构自洽性（基本情形 chain=[root_long]，L0 代码验证）

| 检验 | spawn(m=N) 行为 | 结论 |
|---|---|:---:|
| child 方向 | child_dir=Short（line 363-364 取父反向） | ✓ |
| child 字段 | {ladder:root−1, units:N, basis:c, capital:N×c, cost_pool:N×c, negate_line:located[estar]} | ✓ |
| 父 husk | root.units −= N → 0（line 389），保留在链（cost_basis 降成本史不丢） | ✓ |
| 守恒 §8.1 | Σ = husk 0 + child N = N（line 656 守卫 PASS） | ✓ |
| NAV 连续 | nav = free + husk(0×c) + child(capital N×c) = N×c = 翻转前 root.units×c（**无跳变**） | ✓ |
| 永远有方向（环21） | 翻转后仓位 = 子空 N（非现金 flat） | ✓ |
| 出场=翻转=新建仓（环23） | 卖全 N = 子空开仓，一个 spawn 动作 | ✓ |
| 仓位连续（编排者） | 父 husk 保留，无现金中转；子恢复时父回满（0→N）于降成本 basis | ✓ |

### 5.3 v3 否证两死因被本设计化解（关键）

- **死因②（翻转无否定线 → 强平归零）化解**：spawn 子**携带 negate_line**（line 376/386 = located
  极值）。B 否定扫描（line 277-290）/ A 强平（line 263-274）在 027:25 破极值时管理子 voice 生命
  周期——正是编排者"否定线在子 voice 生命周期保护"。v3 的字面翻空（unwind+无线 re-enter）无此保护。
- **死因①（无条件性 → 盘整税）化解**：spawn 受 nest_fired/confirmed + θ/cost/floor 门约束
  （line 343-352）= 条件化，非每 bar 无条件。

⇒ **本设计是 v3 开放轴"条件化翻空"的精确形式**，不是被否证的字面翻空。"和 E 完全同构"使翻转
继承 E 的全部条件化门 + 否定线机制。

### 5.4 唯一开放 subtlety（Phase 2 实装需裁决）：多 voice 链翻转时机

基本情形（chain=[root_long]，len=1）完全自洽。但 C 清仓触发时链可能已含子（降成本 spawn 的
[root_long, child_short, …]）。当前 C 的 `unwind_to(0)` 全链解栈。改 spawn(m=N) 后，多 voice 链
的翻转语义需裁决：

- **读法甲（先收敛后翻转）**：先 unwind 子回根（子降成本结算，根回满 N），再根 spawn(m=N) 翻空。
  = 两步（收敛 + 翻转）。保持"根级别整体翻转"语义。
- **读法乙（尾翻转传导）**：翻转就是 tail 的 spawn(m=tail.units)，多 voice 链自然嵌套（环22
  父多→子空→孙多 已是交替结构，无需特殊收敛）。= 一步，但根级别翻转语义经多层传导。

两读法在 len=1 退化为同一行为；len>1 时账务与回测结果不同。**这是 Phase 2 实装的唯一开放裁决点**
（编排者"卖出全部 N 股"在 len>1 时指"净 N"还是"tail 的 units"，决定甲/乙）。基本情形不依赖此裁决。
