## 2. Phase 0 递归确认：实装与有效性

### 2.1 实装（`recursive_confirmed`，trading 层消费门）

`rconf_sell[k] = located[k] ∧ rconf_sell[k-1]`，展开 = `∀j∈[FIRST_BSP_LADDER, estar] located[j]`
∧ `dir_state[bi]==Down`（a0=bi 层向下翻转 = segment.settled 方向投影）。located 是 sticky
区间套确认（含 sub-evidence 下探到 a0），是 confirmed 的强形式。翻转门从单层 located[estar]
强化为完整链 → 弱确认翻转被过滤。单测：`weak_confirm_blocks_flip_phase0`（弱链不翻转）+
`full_recursive_chain_enables_flip`（完整链翻转）+ `recursive_confirmed_requires_full_chain_to_a0`
（纯 helper）。cargo test 10/10 + 全量 323/323。

### 2.2 有效但不足

- **churn 确实降**：GC -60%、DX -72%、ES -46%、QQQ -51% trades。弱确认翻转被成功过滤。
- **收益部分回升**：ES +426→+487、GC +192→+245、BTC +459→+546、QQQ +149→+166。
- **但 P1 未恢复**：仍 2/8。根因二：
  1. **churn 主体是降成本非翻转**：CL 2282 trades 仅 3 sellpt（flips 低）——降成本循环
     （E spawn + D recover + B negate）主导，Phase 0 只过滤翻转门，不触降成本。
  2. **翻转在长偏标的结构性净负**：见 §3。

## 3. 根本结论：翻转在长偏标的净负（资产选择产物）

8 标的 **BH 全正（长偏）**。翻转捕获下跌，但长偏标的的下跌是**回调（会恢复）**——翻出多头
结构 → 错过上涨恢复 + 翻空被否定（有界失血）。这不是 Phase 0 能修的（确认再严，长偏标的
的"确认反转"多数仍是回调）。

**翻转 = 风险调整对冲，非 alpha**：
- MDD 8/8 优 BH，多标的显著改善（CL -66.7 vs -94、BTC -67 vs -84、BRN -65.8 vs -78.8）。
- 零强平（v3 死因②化解贯穿四阶段）。
- 翻空在下跌中对冲回撤，代价是绝对收益（长偏标的上是净成本）。

**翻转的 alpha 需双向/空偏标的才显形**——当前 8 标的全长偏，结构性disadvantage 翻转。
这是有效域问题（formalization-validity-domain）：翻转的有效域 = 双向/空偏 regime，
当前测试集（长偏）在其有效域之外。

## 4. 结果包六要素

1. **结论**：Phase 0 递归确认实装完成（trading 层消费门，cargo test 10/10）；显著减 churn +
   改善部分收益，但 P1 仍 2/8 未恢复基线 5/8。根因：churn 主体是降成本循环（非弱确认翻转）+
   翻转在长偏标的结构性净负。基线 URS（清仓到现金）仍绝对收益最优；翻转是风险对冲非 alpha。

2. **定义依据**：编排者 Phase 0 规格（`confirmed(k)=settled(k)∧∃sell_any/buy_any(k-1).confirmed(k-1)`）；
