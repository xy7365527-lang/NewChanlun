## 3. 为何收益仍降：长偏标的中翻空多为误判（churn）

- **churn 量化**：CL spawns 158→2116（13×）、negate 505、trades 2540；BTC negate 707。
  大量翻空被否定（价格升破 located → 否定 → 有界损失 → 回多）。
- **机制**：8 标的 BH 全正（长偏）。翻空捕获下跌，但长偏标的的下跌短于上涨——翻出多头
  到空头**错过上涨恢复** + 空头多数被否定（有界失血）。这是 v3 同型规律（翻空降收益），
  现在**安全化**（有界、零强平、MDD↓）但仍净负。
- **翻转 = 风险调整对冲，非收益增强**：MDD 改善（CL/BRN/BTC）证明翻空对冲了回撤，代价是
  收益。这是 risk-adjusted tradeoff，不是 P1（绝对收益≥BH）的改进。

## 4. ⚠ 关键 confound：Phase 2 在 Phase 0 缺席下测试

**翻转触发 = `sig.sell_any[estar] ∧ located_sell[estar]`**。located 是**单层**区间套确认
（nf_sell 由 sub-evidence 触发）。**Phase 0（编排者规格：confirmed 递归到 a0 settled——
`confirmed(k) = sell_any/buy_any(k-1) ∧ confirmed(k-1)`，递归基 confirmed(a0)=segment.settled）
正是为消除这种弱确认导致的误翻转**。

⇒ 当前 churn（CL 2540 trades、505 negates）substantially 是**缺 Phase 0 的产物**——
弱确认放行了大量本应被递归确认链过滤的误翻转。**这个 2/8 是 confounded 下界**：Phase 0
的严格递归确认应大幅减少误翻转 → 减 churn → 改善收益。

**编排者把 Phase 0 排在 Phase 2 前——本结果恰恰实证了为什么 Phase 0 必须先行。**
Phase 2 在错误顺序下测试，验证了机制安全性（v3 化解）但收益判决被 confound。

## 6. 结果包六要素

1. **结论**：翻转 = 降成本 m=N 实装完成（husk 设计，cargo test 10/10 + 全量 323/323）；
   v3 字面翻空两死因结构化解（零强平 + MDD 8/8 优 BH 且多标的改善）；但收益 P1 5/8→2/8，
   churn 爆炸，confound = 缺 Phase 0 弱确认。

   `unified_recursive.rs` C 块 spawn(m=N) + negate_line=located 极值。

3. **边界条件**：结论翻转条件——(a) 实装 Phase 0（递归确认到 a0 settled）后误翻转应大减
   ⇒ churn↓收益↑，P2 判决须 Phase 0 后重测；(b) 若标的非长偏（双向波动），翻空捕获下跌

4. **下游推论**：(a) **Phase 0 必须先行**——本 2/8 confounded 结果实证编排者排序；

   （MDD↓收益↓），若目标是 risk-adjusted（Sharpe/Calmar）而非绝对收益，翻转可能正向。
