## 0. 一句话结论（v3）

**系统不挣钱因为它在错误的级别交易。** 在可实现（close 执行、扣 0.2% 往返摩擦）口径下：

- **低级别（segment，引擎 99% 的交易）buy→sell 命中率 < 50%（43–46%，z 为负 −7.5 ~ −23.8）**，
  均值幅度（0.02–0.19%）低于摩擦地板——**只交易 segment 级别，三标的全部复利到 −100%（彻底归零）**。
- **可实现 alpha 只存在于递归高级别（recL2/recL3）**：单 swing 幅度是 segment 的 **10–1340 倍**，
  清得过摩擦——但信号稀有（往返 1–29 次/多年），**alpha 大但统计脆弱（L2-fragile）**。
- 引擎对所有级别**平等消费** → 把稀有的高级别 alpha 淹没在归零的低级别散单里。

> **区间套（把仓位路由到递归定位下来的高级别 BSP）是方向正确的修复**——CL 只消费 recL3 的反事实收益
> = **+154%（long-only）/ +819%（long-short）**，而引擎实际只做出 **+4.7%**。这个缺口就是区间套要回收的。
> 但其天花板被高级别信号的稀缺性封顶（recL3 在 CL 十年仅 9 次往返）。

瓶颈在**操作层（级别选择/出场/区间套路由）**，不在信号层正确性，不在会计层，也不在"方向"。

## 2. 信号延迟（Dim 2）

`deferred_bars = 0`（确认即成交）——确认延迟不是瓶颈。进场距反转极值 gap 0.2–1.2%（不远）。
**真正的"延迟" = BSP 结构价（线段低/高点）→ confirm-bar close 的缺口**：你不能在结构低点成交，
确认时价格已离开。这个缺口在低级别吃掉大部分幅度（见 §3）。

## 3. 方向正确率——结构价 vs 可实现（Dim 3，v3 修正）

### 3.1 两个口径必须分开

| 口径 | 买点价定义 | buy→sell 命中率 | 性质 |
|------|-----------|----------------|------|
| **BSP 结构价** | 线段端点（买=低/卖=高） | **0.70–0.83, z≤80** | **接近同义反复**（买点 by construction 在低点） |
| **close-at-confirm-bar** | 确认 bar 收盘（可成交价） | **0.43–0.46（< 50%！）, z 为负** | **可实现**——真实判别 |

**v2 报告的"方向有效 z=80"用的是结构价口径，是误导**——它只是确认"买点确实在低点"，不构成可交易方向优势。
**可实现（close）命中率在低级别 < 50%**：

| 标的/级别 | close 命中率 | z(命中) | close 均值幅度% |
|-----------|-------------|---------|------------------|
| OKLO/segment | 0.434 | **−7.5** | +0.19 |
| QQQ/segment | 0.455 | **−7.7** | +0.02 |
| CL/segment | 0.439 | **−23.8** | +0.02 |
| OKLO/recL2 | 0.457 | −0.5 | +25.5 |
| QQQ/recL2 | 0.583 | +1.2 | +2.40 |
| CL/recL3 | 0.600 | +0.8 | +11.6 |

**低级别 close 命中率显著 < 50%**（z 负且大），均值幅度微正**仅靠右偏**（少数大赢家），扣摩擦后归零。
**高级别命中率回到 ~50%+ 但 n 太小（z≈0，不显著）**。

### 3.2 结论

- v1 的"方向≈随机"对**可实现低级别信号**其实方向大致正确（命中率 ~44%，略劣于随机，均值靠偏度撑正）。
- v2 的"方向有效"用了同义反复的结构价口径，**撤回**。
- **真相：方向不是判别变量。判别变量是级别×幅度/摩擦（§4）。** 在能清过摩擦的级别上，
  即使命中率 ~50%，右偏的大幅度 swing 也能盈利；在清不过摩擦的级别上，命中率再高也归零。

## 4. 区间套分析——核心（编排者追加 4 问）

`_nesting_alpha_diag.py`：按 ladder 分组配对幅度 + **单级别交替策略反事实回测**（只消费该级别 BSP，
close 执行扣 0.2% 往返；long-only = flat 见 buy 开多/long 见 sell 平多；long+short = 反手）。
级别阶梯：ladder 2=segment(笔中枢级,最低可交易) 3=move(L1) 4=recL2 5=recL3 6=recL4；**无 ladder 0/1 BSP**（笔级未开仓）。

### Q1 + Q2：每级别配对幅度 & 高/低倍数

| 标的 | segment | move(L1) | recL2 | recL3 | **recL2/segment 倍数** | **recL3/segment 倍数** |
|------|---------|----------|-------|-------|------------------------|------------------------|
| OKLO | +0.19% | +0.48% | +25.5% | +75.0% | **134×** | **393×** |
| QQQ | +0.02% | +0.07% | +2.40% | +25.9% | **124×** | **1340×** |
| CL | +0.02% | +0.11% | +0.23% | +11.6% | **10×** | **511×** |

**高级别 BSP 配对幅度是低级别的 10–1340 倍**（close 均值口径）。幅度严格随级别单调放大 2–3 个数量级。

### Q3：只消费单一级别 BSP 的反事实收益（决定性证据）

| 标的/级别 | only-this-level **long-only** | **long+short** | 往返数 | vs 引擎全级别 / BH |
|-----------|-------------------------------|----------------|--------|---------------------|
| OKLO/segment | **−68.1%** | −97.8% | 1444 | 引擎 +321.9 / BH +307 |
| OKLO/move(L1) | −27.6% | −93.5% | 217 | |
| OKLO/recL2 | **+364.8%** | +131.8% | 14 | |
| OKLO/recL3 | +113.3% | +52.2% | 2 | |
| QQQ/segment | **−99.9%** | −100.0% | 3546 | 引擎 +166.2 / BH +175 |
| QQQ/recL2 | **+64.1%** | +5.8% | 29 | |
| QQQ/recL3 | +45.6% | +45.6% | 1 | |
| CL/segment | **−100.0%** | −100.0% | 17756 | 引擎 +4.7 / BH +28 |
| CL/recL2 | −77.3% | −96.2% | 148 | |
| CL/recL3 | **+154.1%** | **+819.4%** | 9 | |

**两条结论**：
1. **只交易低级别 = 彻底归零**（segment 三标的 −68% ~ −100%；move(L1) 也负）。摩擦地板下的复利死亡。
2. **只交易高级别 = 大幅正收益但极稀有**：OKLO recL2 +365%、CL recL3 +819%——但往返仅 1–29 次。
   **alpha 真实存在且巨大，但统计脆弱**（CL +819% 骑在 9 笔上，L2 级证据非鲁棒）。

→ **Q3 答案**：若用区间套只消费高级别（或递归定位下来的）BSP，理论 alpha **从归零/微正翻转为大幅正**
（CL：引擎 +4.7% → recL3 反事实 +154~819%）。**这是区间套接入能改善的最强证据。**
但天花板被高级别信号稀缺性封顶——不能单跑 recL3（十年 9 笔），需**沿递归塔聚合 recL2+recL3+** 并接受低频。

|------|------------------------|----------------|------------------|--------------|
| OKLO | **105%** | 103% | **−10225（净拖累）** | 105% |

- **趋势标的（OKLO/QQQ）：高级别 type1 多头 = 96–105% 的总利润，其余净零或负拖累。**
- **CL（震荡）只有 27%**——不是因为高级别没 alpha，而是**引擎没把仓位路由到高级别**：
  recL3 结构 alpha +154% 摆在那里，引擎只做出 +4.7%（27% 集中度 = 利润被摊薄在归零的散单里）。
  **CL 正是区间套缺失代价最大的标的。**

## 5. 结论：alpha 瓶颈定位（v3，可操作）

> 撤回 v1"取消做空腿"与 v2"方向有效"。真因：**级别×幅度/摩擦**。

1. **【根因·最高杠杆】交易级别太低，在摩擦地板之下 → 复利归零。**
   segment（99% 笔数）close 可实现幅度 < 摩擦，单级别交替回测三标的 −68% ~ −100%。
   → **设最低可交易级别门（friction floor gate）**：level ≥ recL2（高波动标的可放宽 move(L1)），
   segment 级 BSP 仅供区间套**定位**，不**独立开仓**。

2. **【alpha 来源·区间套】高级别 swing 幅度 = segment 的 10–1340 倍，清得过摩擦，但稀有。**
   → **区间套路由**：用高级别走势定方向+级别，向下定位进场点，仓位压倒性偏置 recL2+。
   反事实证明可把 CL 从 +4.7% 提到 +154~819%。**但需沿递归塔聚合多个高级别、接受低交易频率**（脆弱性来自稀缺）。

3. **【出场】出场对齐同级别下一反向 BSP**（buy 持到 next sell），兑现整段 swing——配对幅度的前提。
   现固定 sellpt/recover/negate 出场，赢家持仓 16–313× 于输家但占比少。

4. **【执行缺口】限价单在结构价附近挂单**回收"结构价→close"缺口（参 `project_selloff_fix_t1_bracket`）。救边际，救不了级别问题。

5. **【regime】无普适配置**：平滑上涨市做空连 recL2 都净亏 → long-only 高级别；高波动市 long+short 高级别。
   放弃"单配置跑赢 8 标的"（P1 6/8 不可证伪失败），改 regime×级别路由。

6. **不是瓶颈（排除）**：会计正确性、信号层构造正确性、确认延迟（deferred=0）。问题在操作层。

## 结果包六要素

1. **结论**：根因 = **级别×幅度/摩擦**。可实现（close）口径下低级别（segment，99% 交易）命中率 < 50%、
   均值幅度 < 摩擦地板 → 单级别交替回测复利归零（−68% ~ −100%）。可实现 alpha 仅在递归高级别
   （recL2/recL3，幅度 = segment 的 10–1340 倍），但稀有（往返 1–29）。引擎平等消费所有级别 →
   稀有高级别 alpha 被归零的低级别散单淹没。趋势标的高级别 type1 多头 = 96–105% 总利润。

2. **定义依据**：
   - 买卖点（`buysellpoint.rs`）：BSP 结构价 buy→sell 上涨 70% 是同义反复（买点在结构低点）；
     **可实现方向命中率 < 50%**——信号层无 bug（编排者假设验证），但"方向"不是 alpha 来源。
   - 走势/级别（`docs/concept_movement_chain.md`）：幅度随级别（segment→recL3）单调放大 2–3 数量级。
   - 区间套（第 27 课 / `nested_fugue_accounting.md`）：把仓位路由到高级别的机制；反事实证明其接入可把
     CL 从 +4.7% 提到 +154~819%（受高级别信号稀缺性封顶）。

3. **边界条件**（翻转条件）：
   - **摩擦地板（0.2% 往返）**：低成本期货（~0.02%/腿）地板下移，move(L1)/segment 可能转正，"级别太低"根因弱化；
     高成本（crypto ~0.5%/腿）地板上移，连 recL2 被吃，根因强化。
   - **高级别样本稀缺性**：recL3 往返 1–9 次 → 反事实 +154~819% 是 L2-fragile；若扩到更多标的/时段后高级别
     alpha 不复现，则"区间套能改善"被削弱。这是**最大的未决脆弱性**，须 L3 多标的复验高级别反事实。
   - 若**最低级别门 + 高级别偏置**实装后 P1 未改善，则"级别选择是瓶颈"被否证。

4. **下游推论**：仓位按级别幅度/摩擦比分配，压倒偏置 recL2+，segment 仅供定位；出场对齐反向 BSP；
   评价改风险调整后（MDD 8/8 优于 BH）；regime×级别路由替代单配置。

5. **谱系引用**：
   - **本报告自身经历了 v1→v2→v3 的概念分离**（方向随机→方向有效→级别才是判别变量），是"测量口径决定结论"
     的实例——结构价口径 vs close 可实现口径的分离。
   - 修正了与 `project_p3_random_gate_underpowered` 的关系：alpha 不只来自暴露，也来自高级别 swing 的右偏幅度；
     择时在**正确级别**上有效。
   - 与 `project_interval_nesting_forward`、`project_underperform_bh_osc_bleed`（级别是核心变量）真共振。
   - **新增量（待裁决是否结晶，语法记录类）**：**"可实现 alpha 的摩擦地板按级别×波动率切割 + 高级别 swing 的
     右偏幅度是唯一清得过摩擦的 alpha 源 + 区间套反事实量化（单级别交替回测）"**。
