# ADR：跨级确认是链不是桥；身份锚取不变量（值桥换锚）

- 日期：2026-07-22
- 状态：**已定**（编排者教义裁定，grill-with-docs 产出）
- 来源：#163 前置 grilling（编排者）、#107 断裂点调研、#120 值桥语义验证、#164 全量确证、map #106

## 背景

map #106 线的三份调研串出一个矛盾链：#107 发现身份桥固定 ℓ+1 是断裂点（43.2% 样本估计可恢复）；#120 裁定值桥（`source_index == seg_c_full.1` 单序号相等）语义正确、不存在有意义的放宽；#164 全量确证 #112 已实装的 multi 并集桥真实恢复仅 **1.03%**（17/1651）——并集桥方向收益基本为零，与 #107 的样本外推严重背离。

编排者 grill-with-docs 裁定：矛盾源于两个层面的术语错位——确认结构被误称为「桥」，身份锚被误放在 K 序号上。

## 教义裁定

1. **确认结构是链不是桥**。体系自下而上递归，递归必须连续。每个级别的确认是该级自治的、自上而下的区间套：L1 证书由 L1 自己级别往下看确认；L2 从 L2 自己级别另起一次。级别间不存在跳级查询。

2. **恰好存在（co-location）是结构性质**。递归连续性 ⟹ 拐点 x 同时坐落在 L0/L1/…/Lℓ（L2 走势终点 = 其最后 L1 子走势终点 = … = L0 某根 K），无需额外假设。

3. **跨级身份锚取不变量**：（分型方向， 极值价）。不同级别分型的值必有不同也有相同——取相同者。K 序号在包含合并下漂移（合并组锚 = 组内首根序号，非极值发生根），不作身份依据。

4. **同向同价碰撞由合并组区分**。W 底同价双脚是包含关系问题：两分型中 K 分属不同合并组；合并组互不相交、确认后稳定。身份三元组 =（方向， 极值价， 合并组锚）。

5. **值桥换锚**：候选分型 ≡ 离开段终点分型 ⟺ 三元同一。旧锚 `source_index == seg_c_full.1`（单序号相等）废。换锚不是放宽——问的还是「同一事件」，只是改用不漂移的坐标。#120 裁定被重述而非推翻：问题问对了，坐标用错了。

## 影响

- by_end_multi 并集跳查（#112 实装）是**错误形态**——#164 的 1.03% 是形态错误的实证，不是口径问题
- #163（多视窗最小实现形态）的裁定前提改写：路线须按链式确认 + 三元锚重新表述
- #107「43.2% 可恢复」定性修正：L1 断环而 L2/L3/L4 有覆盖者，链式语义下不应恢复——那不是可恢复来源，是跳环
- 身份锚相关实装（by_end / by_end_multi 键构造、absorb_exts 登记、typed_lookup / typed_lookup_multi）待按新锚重设——属 #163 后续执行线
- 词汇表 `CONTEXT.md` 已收录四枚术语：链 / 恰好存在 / 不变量 / 值桥
