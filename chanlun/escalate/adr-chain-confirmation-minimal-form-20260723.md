# ADR：链式确认的最小实现形态（#163 四问裁定）

- 日期：2026-07-23
- 状态：**已定**（编排者 grilling 裁定）
- 来源：#163 grilling（编排者）、ADR `adr-chain-confirmation-and-invariant-identity-20260722.md`（教义前提）、#107 断裂点调研、#164 全量确证、map #106

## 背景

2026-07-22 ADR 裁定确认是链不是桥、身份锚取不变量三元组后，#163 问最小实现形态：现形 #112 并集跳查（`by_end_multi` + `typed_lookup_multi` 的 `merged` 折叠，实测恢复 1.03%）如何按链式语义重述。本 ADR 落四问裁定：查询侧、键侧、表示侧、旧桥去留。

## 裁定

1. **查询侧：严格链——判定替换，管道改造。** 候选 x 的确认 = 从链顶逐级向下的自治区间套链：每级查该级自己的证书（过 `n_delta` + 因果守卫 `judge_at ≤ anchor`），闭合到 L0。**链顶 = 以 x 为拐点的最高级别走势类型所在级**——由恰好存在给出（x 只恰好存在于它是拐点的级），非塔顶移动窗口、非固定 ℓ+1。**缺环即拒、断环即拒**：lvl+1 单级过证不算，高级有证而中间断不算。并集折叠 `merged` 退役；`typed_lookup_multi` 改返回完整链谱系（连续闭合到哪级全落账，供归因与级别身份判定）。派生管道（`sync_events → derive_level_events → absorb_exts → NestCertificateIndex`）、first-wins dedup、因果守卫不动。typed 无合法链时回退旧臂 Xzd 通道的现行为不动。

2. **键侧：单键域归一。** 键 = `(ℓ, 分型方向, 极值价, 组锚@ℓ) → 身份集`，一套键域替换 `by_end` + `by_end_multi` 两套。合并组锚是该级包含层事实（x 在各级的组锚不同），键天然分级——级别居键内，不居身份内。三元锚由 provider 在事件构造点携带（gate 不二次推导，禁第二查法）。极值价相等 = 精确等值、无容差（容差 = 概率推断边门，v3 硬禁令）。`NestEventIdentity`（内部去重键）不动。

3. **表示侧：扩展 LevelProjectionLayer。** 级别身份在 L0 的独立体现落在每级投影层：层增该级三元锚索引（组锚@ℓ 由该级包含层单一来源供给），链式确认逐级查层——恰好存在物化为层间联动。层「只产描述体不持判定」纪律保留（判定唯一来源在门内）。L0 表示不携带级别维度：x 作为高级拐点未必是 L0 BSP，L0 携带无处可挂；且组锚@ℓ 是该级事实，L0 反推高级包含层 = 第二查法。层从门开可选骨架转为链式确认必载基座，门关口径随执行票定。

4. **旧身份桥：退役。** `typed_lookup`（固定 ℓ+1）+ `by_end` 键域 + single/multi comparison 装置一起删，终态无桥。兜底教义不成立（链缺时回退漂移坐标 = 给跳环开后门）；并行价值已被 #164 榨干（1.03% 形态错误实证）且违单键域。执行期 shadow 验证窗口属执行票验收口径，不改终态。L2 旧臂（`nest_gate_admit`）因 Xzd 回退通道存续，不在退役范围。

## 影响

- **链即身份**：x 的级别归属由链谱系给出，不再靠候选自报 `lvl` 猜方向——map #106 目的地（多视窗、各自级别身份往下递归）的实现形态由此闭合
- #107 跳环修正推到彻底：不止跳环拒，缺环即拒
- #112 并集形态全部退役：`by_end_multi` 键域、`merged` 折叠、cross 对照装置
- 「执行切分（T 线票型与验收口径）」从 map #106 Not yet specified 毕业成新票
- 术语结晶：**链顶** / **闭合** 落主仓 `CONTEXT.md`「确认结构」簇
