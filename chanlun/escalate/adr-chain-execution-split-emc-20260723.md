# ADR：链式确认最小形态的执行切分（#168 裁定：四票 EMC）

- 日期：2026-07-23
- 状态：**已定**（编排者 grilling 裁定）
- 来源：#168 grilling（编排者）、ADR `adr-chain-confirmation-minimal-form-20260723.md`（#163 四裁定，切分前提）、ADR `adr-chain-confirmation-and-invariant-identity-20260722.md`（教义前提）、#164 全量确证、map #106

## 背景

#163 四裁定（严格链 / 单键域三元锚 / 扩展投影层 / 旧桥退役）锁定后，#168 问执行切分：T 线票怎么分、每票验收口径怎么定。纪律：**只切不裁**——本 ADR 不重开 #163 的任何裁定，只落切分与验收口径的六题裁定。

## 裁定

1. **票拓扑：四票 expand-migrate-contract。** T1 键域重锚（expand）→ T2 投影层扩展 → T3 严格链判定（migrate）→ T4 旧桥退役（contract）。blocking 边：T2←T1、T3←T1+T2、T4←T3。理由：按票面字面切（键域票即删 `by_end`/`by_end_multi`）会迫使三个读者（`typed_lookup`/`typed_lookup_multi`/`has_bridge_key*`）同票改写，链判定并入键域票，切分塌缩、shadow 无处挂；EMC 让每票红线各自干净。

2. **T1 门形态：无门纯增写。** provider ext 携带三元锚（方向， 极值价， 组锚@ℓ）；组锚供给线首落（该级包含层单一来源，组锚 = 组内首根序号）；`absorb_exts` 增写新单键域 `(ℓ, 分型方向, 极值价, 组锚@ℓ) → 身份集`；旧双写冻结保留、读者零改动（**只增不删，删除一律归 T4**）；`NestEventIdentity` 不动；极值价精确等值无容差。先例：#112 `by_end_multi` 同款无门增写。红线 = 全量重放决策逐字节不变；锚值单测锁供给线正确性。

3. **层转必载门关口径：T3 并门。** T2 落地时层门保持现状（独立、默认关、零开销，#110 纪律不动）：骨架增三元锚索引（与 T1 同一供给来源），`cross_level_query` 改三元锚描述体，门开只产描述体、零判定消费。**T3 并门**：层门配置面退役，层载由链路径单一驱动——链活 ⟹ 层必载（索引成本即链判成本一部分）、链死不载（零开销红线不死）；`config.rs:369` 断言改写为「链启用 ⟹ 层必载」形态；八处 `None` 构造点不动；门关语义 = 本运行不消费链判定，与今生产形态逐字节一致。独立双门被否：「链开层关」错位态须靠断言禁掉，等于承认两门本不可独立。

4. **shadow 窗口判据（T3 验收交付、T4 入场条件）：四条件。**
   - **跑什么**：#164 同 corpus 全量 1651，T3 门开形态双读（链消费、并集降 shadow 对照格落账，`NestGateObs` 装置扩格）；同步跑既有 E2E 回归套件锁链外路径。
   - **对照什么**：逐候选裁决对（链 admit/reject × 并集 merged pass/fail）。换锚后两边非超集/子集关系（匹配面本身变了），必须逐候选双读，不得只做聚合数对比。差异按预期归因分类落账：缺环拒 / 断环拒 / 换锚恢复（链确认而并集 miss）/ 链顶谱系差。
   - **什么算过**（四条件全满足才开 T4）：① 差异 100% 落入预期分类，**零未解释**；② 链外一切路径（候选流、Xzd 回退、旧臂对照、exit 侧）与 T3 前逐字节一致；③ **方向守卫**——链确认总数显著高于并集 17（1.03% 基线），不设预设数值门槛，低于基线 = 未解释、窗口不过；④ 汇总统计落报告（裁定 5）。

5. **重跑报告形态：#164 同构三件套。** `chanlun/review-results/typed-none-strict-chain-dump-<date>.md` + 逐候选 `.jsonl` + 分析 `.py`，落 worktree `chanlun/review-results/`。骨架沿用 #164 六节、问题面换链语义：§0 总结论（四条件逐项 ✓/✗ + 链确认总数 vs 并集 17）；§1 方法 + **corpus 同一性证据**（候选流 1724 与 #164 dump 逐键对齐——决策变是预期，候选流必须逐字节同）；§2 链×并集四象限裁决矩阵 + per-level 分层；§3 差异归因分类账（计数 + 逐候选清单入 jsonl）；§4 链谱系分布（链顶级别 / 链长 / 闭合完整度——「链即身份」首次实证，map Destination 验收面）；§5 与 #164 三层对照（代理上界 25.62% / 并集实恢 1.03% / 严格链实恢 x%；真 nowhere 100 个链下状态复核）；§6 090 限制声明。附录：产物路径、运行命令、改动清单。

6. **出笼包。** 顺序：本 ADR → #168 resolution comment → close → #106 Decisions 回填 → 四票 create-then-wire。票型：`[task]` 前缀 + `wayfinder:task` 标签 + #106 子票 + native blocked_by 边，不指派（后续 session 按 frontier 认领）。票体两节（任务 + 验收口径），推理不复制、引本 ADR。本 session 无新领域术语结晶（链顶/闭合已于 2026-07-23 前场落主仓 CONTEXT.md；EMC、锚供给线、shadow 属执行词汇），CONTEXT.md 零写入。

## 影响

- map #106 进入纯执行期：四票为唯一工作线，按 blocking 顺序认领开工。
- **T3 是行为变更唯一发生点**（链判定上线）；T1/T2/T4 均为 bit-exact 锁票（增写 / 门关 / 删死码），行为变更被隔离在单票内、由 shadow 四条件把守。
- shadow 窗口 = 并集桥的历史终点：四条件过后，`typed_lookup` + `by_end` 系 + comparison 装置物理删除，终态无桥（#163 裁定 4 的执行闭环）。
- T1 供给线（包含层 → 组锚@ℓ 查询口）为 T1/T2 共有单一来源，结构性守住「禁第二查法」。
