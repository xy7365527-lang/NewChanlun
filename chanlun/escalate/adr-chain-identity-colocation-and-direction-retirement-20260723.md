# ADR：身份即同点递归；方向退役；出场同链（#206 三裁）

- 日期：2026-07-23
- 状态：**已定**（编排者 grilling 裁定）
- 来源：#206 grilling（编排者）、T3 shadow 报告（`chanlun/review-results/typed-none-strict-chain-dump-20260723.md`）、#205 机制分类研究、#173 停手勘察、#163/#168 裁定链

## 背景

T3（严格链判定）上线后的 shadow 全量测量与机制分类把三个问题推到台面：① T1/T2 两键侧「方向」注册分歧 469 例（cohort 确认率 0.00%）；② 多级链闭合率 = 0（三窗 106 个通过全为链顶=0 单级链）；③ T4 删除清单中的 `typed_lookup`/`by_end`/`has_bridge_key`/`ext.seg_c_full` 被勘察证实为 #76 出场门现语义本体，非 shadow。编排者 grill-with-docs 裁定如下。

## 裁定

1. **身份判据 = 同点递归；方向整体退役出身份层。** 跨级确认是递归区间套：分型在各级递归落到同一个点，即为同一事件；落不上 = 递归失败。方向（买/卖标签）在身份判定中**完全多余**——同一点可在不同级别分别为顶分型/底分型（如反向收束：L2 底、L1 顶），各级分型类型是各级自己的结构事实，都可为真；买卖标签属交易层（入场裁决、做空、短差），与身份层解耦。描述分型只用**顶/底**分类，不用方向。据此：
   - 身份锚自初版三元组（方向, 极值价, 合并组锚）**简化为两元（极值价, 合并组锚）**：极值价 = x 处 L0 分型价（严格跨级不变、精确等值无容差）；合并组锚 = 组内首根序号（包含层事实、不漂移）；同价双脚由合并组区分。
   - 教义 ADR（20260722）裁定 3/4 的「分型方向」措辞被本裁定**修订**（非推翻：锚仍是不漂移坐标，方向分量经实测与递归语义证为多余）。#170（20260723）「方向 = 级别-ℓ 转向」措辞同步作废——方向不是「各级各自为真的身份分量」，而是根本不参与身份。
   - 实装侧 T1 键域 / T2 层索引 / T3 链同向过滤随之去方向分量（执行票 T5a #207），shadow 按新语义重跑。方向见证装置（469 例分歧的度量对象）成为非概念，退役。
   - 实装便利事实（T1 探针已证）：价格与组锚同锚于 x 处 L0 分型，跨型（顶/底）共点不产生价格二义——方向位在键中本就零工作。

2. **多级零闭合归因 = 证书产量不足，供给侧挂 map #126。** #205 确证：首缺级 94.2% 双向皆无证、95.5% 首缺即链顶自身、链底 L0 未闭合 97.3%——塔产不足为绝对主因；方向自由化可挽回上界 ≤40（未计异向证 n_delta/守卫），非主因；组锚跨级匹配假设被否证为失败因。链语义本身无压制性问题。「按级别视窗各自确认」（map #106 Destination）当前被证书供给卡住，供给侧战线归 map #126「塔侧跨级链增产」，本 map 不重复开线；T5a 重跑后按新语义再结算一次数字。

3. **出场同构：买点买卖点卖同一套链；拍脑袋旧出场桥判删。** 区间套背驰是对称结构——卖点 = 反向的买点，同一套同点递归链同时回答入场与出场两侧，**出场不需要独立语义设计**。现 #76 出场门的固定 ℓ+1 桥（无因果守卫）是拍脑袋临时物，**判删**（非豁免保留）。出场门迁往同一套链判定（反向点 x′ 的链确认 ⟹ 准出；无链/断链 ⟹ 不准出，诚实口径保留）+ 锚供给接出场路径 + 出场测试换带锚夹具 + 删除四件（`typed_lookup`/`by_end`/`has_bridge_key`/`ext.seg_c_full`）——执行票 T5b #208（被 T5a 阻，迁移消费去方向后的链）。L2 旧臂 `nest_gate_admit`（Xzd 回退通道）保留不动。「终态无桥」（#163 裁定 4）修正为：进场侧已无桥 + 出场侧迁链后无桥。
