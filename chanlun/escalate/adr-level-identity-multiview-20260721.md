# ADR：买卖点级别身份不可在 L0 扁平化中丢失

- 日期：2026-07-21
- 状态：**已定**（编排者教义裁定，grilling #105 产出）
- 来源：#105 grilling（编排者）、#106 归因调研、#77 V4 三窗验收、map #59 横切⑪

## 背景

V4 三窗验收（#77）照实判定：typed 真链门在 wf7 震荡窗仍有害（Long 翻负 7.0× 于 v0 门）。#106 归因调研查了 4,673 个 typed miss，代码 bug = 0、键域错位 ≈ 0。

编排者 grilling 裁定：miss 的根因不是"教义结构（链不该存在）"，而是**级别身份在 L0 扁平化中丢失**——链存在但身份桥 ℓ=lvl+1 固定方向太窄，够不到内在级别的真实跨级链。

## 教义裁定

1. **跨级链是买卖点确认的必要条件**。买卖点 = 递归 + 区间套（缠论定义本身），否认它 = 否认买卖点的构成。

2. **跨级链不一定从最高级别往下递归**。从买卖点实际所在级别的次级别往下递归也合法。

3. **多空双开 + 嵌套多重赋格的意义** = 不同级别、不同方向的买卖点各自独立带自己的跨级链。

4. **级别不是固定时间窗口**。传统缠论用 1分/5分/15分解决级别视窗；本系统没有固定窗口，只有内在级别（塔从走势结构自生）。

5. **当前缺陷 = 扁平化**：所有级别的买卖点压在 L0（1 分钟 K 线）上显现，级别身份在压扁过程中丢失。

6. **可能解法**：每个内在级别在 L0 K 线上独立体现（多视窗），跨级链从各自级别身份出发往下递归。

## 影响

- 身份桥 ℓ=lvl+1 是症状不是根因——不改桥，改级别表示
- 影响全链路：塔输出格式、证书级别语义、身份桥、门消费、回测比对
- 与 map #59 横切⑪「塔内原生化长线」同级或为其前置
