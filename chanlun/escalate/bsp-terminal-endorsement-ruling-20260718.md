## T1 终端背书口径（S0+S1a 合并为一项终端背书裁定）

### 背景

p112 在 R1 口径下把 754 链整体归 (i) BSP 欠配错杀后，BSP 沉默的门链首杀分布为：S0 取段/坐标错位 113（73.4%）+ S1a τ 门上下文 37（24.0%），合计 150/154 = 97.4%（`p112-trend-predicate-caseaudit-20260717.md:121-122`）。两项的机械事实：

- **S0**：终端背书查法 `terminal_bits_new`（`p92_nest_replay_postruling.rs:940-953`）在 `levels[k].bsp` 上作 `source_index == event.turn_source` 位格等式精确匹配；D2 turn = L0 线段腿终点坐标格，BSP 点 = 级别-k 单元窗终点坐标格，两格结构性不可命中——113/113 案 `bsp_book=none`（S0 图 §1.3）。
- **S1a**：37 案 turn 恰为 level-1 单元终点（S0 通过），但 level-1 τ 门输入 `gate1[c_idx]==None`（归属 L1 中枢的入边关系落盘整块）。S1a 图证明：τ 门在其定义域内判决正确——L1 链在该坐标确实处于盘整块；错的是**提问的级别**。D2@1 事件的趋势对象是 L0 中枢链（nest level-1 投影种子 = tower[1] 窗携带核 = L0 中枢），BSP level-1 τ 门对象是 L1 中枢链（L0 中枢三元组上的几何检测链），两者差一整级（S1a 图 §1.4；附录 A 证明 per-run 与全局分解在被消费中枢上门值恒等，p112 的「decompose 上下文差异」归因修正为「链级别不同」，不改任何计数）。
- **两案同源**：S1a 图 §7 证明 S0 桥接（留在 `levels[ℓ]` 修坐标格）不治 S1a——37 案在 L1 账本根本没有点可桥（τ 门在生产侧已杀）；而级别移位把 S0 的 113 案带回 L0 腿坐标格（S0 grid 失配在同格下消解），且 C-b 窗口与 S0 的「c 责任单元」在 `[c_start, t*]` 语义上同构（最早点 = c 首个破核腿，即 037:22 次级别中枢见证的触发腿）。故按 S1a 图 §5 建议合并为一项裁定。
- **待裁问题**：①查法级别移位是否成立（含 S1a 图 §6.2-4 的 fiat 反读处置）；②坐标口径 C-a（精确坐标平移）/ C-b（窗口最早点）之选；③S0 的 A1 桥键（c 责任单元）在级别移位后的处置——被吸收还是并列保留。

### 教义依据（课号:段号，直读主仓博文原文核对）

1. **037:16（趋势级别 = 中枢级别）**——`037-第37课.md:16`：「当说a+A+b+B+c中有背驰时，首先要a+A+b+B+c是一个趋势。而一个趋势，就意味着A、B是同级别的中枢」。⟹ 事件的背驰级别由其 A/B 中枢所在链决定：nest level-ℓ 事件的 A/B 中枢 = tower[ℓ] 窗携带核 = `levels[ℓ-1]` 中枢 ⟹ 其趋势背驰级别 = `levels[ℓ-1]` 中枢链级别。级别身份由结构内容决定，不是可任意贴的标签。
2. **024:18（背书点应到背驰自己的级别找）**——`024-第24课.md:18`：「缠中说禅背驰-买卖点定理：任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰。」「某级别」= 该背驰所在的级别；终端背书的合法账本由背驰所在级别决定，不由装配桶号决定。
3. **043:26（查找只能向下）**——`043-第43课.md:26`：「由于背驰的级别不可能大于当下走势的级别，例如一个30分钟级别的背驰，只可能存在于一个至少是30分钟级别的走势类型中」。⟹ 终端背书向**上**一级（`levels[ℓ]`）查找违反上界；向**下**（`levels[ℓ-1]`）合法。查找方向只有下界。
4. **027:136（级别误判是错误，不是口径）**——`027-第27课.md:136`（宝钢案）：「你对背驰的判断是错误的，宝钢15分钟根本没有背驰……该背驰是典型的1分钟背驰」。缠师把「15 分钟背驰」直判为级别误判（实为 1 分钟背驰）——级别贴错不是口径自由，是判断错误。
5. **037:22（C-b 窗口/c 责任单元的结构根据）**——`037-第37课.md:22`：「由于c包含B的第三类买卖点，则c至少包含两个次级别中枢」。c 内含的次级别中枢在工程对象上 = c 区域内新形成的级别-(ℓ-1) 中枢单元；窗口 `[c_start, t*]` 内最早 confirm_side 点 = c 首个破核腿的落点，即该次级别结构见证的触发腿。
6. **037:18（否则条款 = 诚实判负边界）**——`037-第37课.md:18`：「c必然是次级别的……否则，就可以看成是B中枢的小级别波动，完全可以用盘整背驰来处理」。窗口内无 confirm_side 点 ⟹ None，是否则条款域的诚实判负，非放宽、非误杀。
7. **031:883（比较对象唯一，不新造比较对象）**——`031-第31课.md:883`：「盘整背驰一般都是中枢震荡时发生的，而趋势背驰，是a+A+b+B+c中，cb间的比较」。移位只修「去哪个账本找点」，不替换 (c,b) 段对身份，与 doc-trend 总判定（比较对象唯一 c vs b）一致。
8. **029:18（锚点 = 邻域身份，非位格等式）**——`029-第29课.md:18`：「最终通过1分钟以及1分钟以下级别的精确定位，最终可以找到背驰的精确点，其后就发生反弹」。「精确点」由次级别定位给出，是结构邻域身份；窗口最早点正是该邻域身份在级别-(ℓ-1) 网格上的落点。
9. **辅助锚**：027:14（趋势 ≥2 同级别中枢）、027:66（第一类 ⟺ 趋势背驰构成；盘整背驰买点仅周线以上有意义 ⟹ τ 门拒盘整块开一类是教义实装不是缺陷）、044:32（确认与操作都锚在背驰自己的级别）、029:16（背驰-转折定理：L0 趋势前后在 L1 链上呈现扩展/盘整是定理允许的形态，两链读数不矛盾）、027:20（盘整背驰比较与趋势背驰异构 ⟹ L1 链读出的盘整对象出口是 PanDivCert 通道，不是第一类）。

### 裁决

1. **查法级别移位生效**：nest level-ℓ 事件的终端背书账本 = `levels[ℓ-1].bsp`（`event_bsp_book_level`：ℓ≥1 ⟹ Some(ℓ-1)；ℓ=0 ⟹ None）。nest 桶号 ℓ 与 BSP 级别 ℓ 的恒等贴标判定为**级别混配装配工件**，不是谓词语义。实装面 = S1a 图 §3.4 H1–H5（`nest.rs` 新增 `event_bsp_book_level`/`TerminalMatch`/`terminal_bits_at_event` + 装配头注契约；p92 bin `terminal_bits_new` 委托；H4 只读核验探针 `p117_s1a_level_recheck.rs`；单测）。τ 门/塔/笔/线段/中枢/inclusion/BSP 生成主干零触碰；p112 归档探针不动。
2. **坐标口径 = C-b（窗口最早 confirm_side 点）**：`p.source_index ∈ [event.interval_b.0, event.turn_source]` 内最早 `confirm_side(event.side)` 点。C-a（精确坐标平移）保留为敏感性对照常数（实装报告须落 C-a/C-b 对照读数：预测差 = 5 延迟案）。选 C-b 的理由：对 70 延迟案形态（t* 晚于破核时点）鲁棒；最早性给出结构性身份保证（§6.1-2 证明）；且时点 ≤ t*，因果序为正，无前视入证。
3. **fiat 反读驳回**。S1a 图 §6.2-4 呈交的最强反读——「nest 桶号 ℓ ≡ BSP 级别 ℓ 是有意贴标签（fiat），则 37 案在 L1 的对象类别 = 盘整（037:18 否则条款），出口是 PanDivCert 通道，本设计整体不适用」——经正面审查**不予采纳**，理由四条，逐条可验：
   - fiat 读法必须主张的命题是「事件的级别身份与其中枢链级别可以不一致」。该命题与 **037:16** 直读冲突：趋势级别 = 中枢级别（A、B 同级别中枢），级别身份由中枢链结构内容决定，不是可脱离结构任意贴标的 fiat。
   - 与 **024:18** 冲突：背驰必制造**某级别**的买卖点——该级别是背驰自己所在的级别（`levels[ℓ-1]` 中枢链），背书查找的合法账本由之决定；把查找钉在 `levels[ℓ]` 等于断言背书级别可以脱离背驰级别任意指定。
   - 与 **043:26** 冲突：背驰级别 ≤ 当下走势级别是查找上界；fiat 读法把向上一级的查找合法化，违反上界。
   - 与 **027:136** 冲突：宝钢案中缠师把贴错级别的背驰判断直斥为「判断是错误的」——级别误判是错误，不是可保留的口径自由。fiat 读法等于把级别误判制度化为标签体系。
   - 补充事实层：37 案若真属 L1 盘整对象，其出口 PanDivCert 通道在 p109 同族 877 池上的实测是 0/877 有 confirm BSP（前裁定 R2 验收线节引 `p114-relaxation-ceiling-20260717.md:28-32`）——「改走盘整通道」在数据上同样无路，fiat 读法连工程退路都不成立。
   - 若编排者复议时仍采 fiat，须以新裁定文书明示该命题并逐条反驳上述四条教义直读；在此之前本裁定按结构内容落锤。
4. **S0 的 A1 桥键被吸收，不并列实装**。处置：S0 图的 A1「c 责任单元」桥（`terminal_bits_bridged`，units 桥键）**不实装**；其坐标精化语义由级别移位 + C-b 窗口同构承担。理由三条：①单一来源纪律（禁双口径补丁，p115 §6 先例）——同一终端门保留两套查法 = 口径 fork；②A1 留在 `levels[ℓ]` 修坐标格但不治 S1a（37 案在 L1 账本根本无点可桥），只有级别移位治两项之本；③A1 的固有边界（K1 见证未形成 ⟹ None；F2 背书单元完成晚于确认坐标 t*）在 C-b 下结构性消解（最早点 ≤ t*，因果序正，无「背书晚于确认」语义差）。A1 的「c 责任单元」概念作为 C-b 窗口的教义读法保留（037:22 c 内含次级别中枢见证），不立新函数；S0 图 §5.1 的 8 个单测夹具几何关系由实装工位按 C-b 口径改写吸收进 `terminal_bits_at_event` 测试（S1a 图 §5 的 4 个测试已覆盖同形夹具主干）。
5. **exec≥2 泛化登记**：移位规则对 nest level-ℓ≥2 事件同构适用（背书账本 = `levels[ℓ-1].bsp`；窗口最早点的身份保证证明结构不依赖级别——c_start 起该级最近中枢即该级趋势的 B）。验证域分层：37 案（exec=1）由 H4 探针逐项核验；exec≥2 由全量重放 CERT 对照按 exec 分层如实报告（T4 裁决第 4 条），不作逐案预承诺。
6. **p116 C2 对账义务**：本项落地即 `terminal_bits_new` 语义移位 ⟹ p116 归因规则书 R2.2.1【C2 终端门滤除】的 TERM 谓词口径（`p116-turnpoint-anchor-existence-20260717.md:145-149`：`levels[level].bsp` 位格等式）随之失效，须同步平移到级别移位查法，否则 p116 重跑产出幻影 C2（在 `levels[ℓ]` 查无点但实际背书已移 `levels[ℓ-1]`）。登记为 T1 实装关验收报告的对账义务（T4 裁决第 3 条细化）。
