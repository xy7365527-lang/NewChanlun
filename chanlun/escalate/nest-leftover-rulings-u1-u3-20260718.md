## U1 L5 provider 零覆盖（教义层即裁；归因层裁「未结」＋§6-4 探针与二叉处置预裁）

### 背景
p109 实测 L5 strict_pairs=8 而 events=0，各级 pair→事件命中率 L1 43.3%／L2 37.9%／L3 37.1%／L4 26.2%／L5 0%，链爬到 L4→L5 边必死身份门（`p109-chain157-gate-attrition-20260717.md:93-95`）。p114 复核 6,482/6,482 链 L5 事件数=0，「深度 5 在所有放宽情景 = 0」为现状硬墙（`p114-relaxation-ceiling-20260717.md:33`）。但 p107 把 L5 的零读作「市场事实（塔顶无候选结构，BSP 侧 max_lvl=4）」（`p107-level-funnel-audit-20260717.md:85,97-98`），与链侧 8 个 L5 结构 pair 并存——8 pair 无事件的原因（D2 pair 缺失 vs Extreme 未过）未分解（`p109-chain157-gate-attrition-20260717.md:206` §6-4）。问题：L5 零覆盖归「市场事实（塔顶无结构，020:40 更高级别须市场实际长出）」还是「provider 装配缺口」；涉天花板处验收线怎么写。

### 教义依据（课号:段号，直读主仓博文原文核对）
- **020:40**：缠中说禅走势级别延续定理一——「在更大级别缠中说禅走势中枢产生前，该级别走势类型将延续」（`020-第20课.md:40` 直读）。更高级别的存在是**条件性**的：市场实际长出更大中枢才有更高级别；原文既不封顶，也不承诺任何给定时刻之上必有一级。
- `doc-level-domain-20260717.md:16,96-99`（教义判定书）：级别无理论天花板（017:22 量词「任何级别」、028:770 级别只与所含中枢有关、chan99§级别:37「N无穷大」）；「L5 之上必然还有」同为假——两端（封顶／必然再有）都被原文拒绝。
- `doc-level-domain-20260717.md:174`（对工程裁定的建议 3）：正确验收谓词 =「若更高级中枢实际形成，则链应延伸」，而非固定层数必够或必有。

### 实证证据（报告:行锚）
- `p109-chain157-gate-attrition-20260717.md:93-95`：L5 strict_pairs=8、events=0、命中率 0%；塔级 = 6（L1–L5）。
- `p109-chain157-gate-attrition-20260717.md:206`（§6-4）：8 个 L5 strict pair 无事件的原因待分解——D2 pair 缺失 vs Extreme 未过，**本探针未执行**。
- `p107-level-funnel-audit-20260717.md:85`：provider 漏斗 L5 行全 0（F1 候选=0）；`:97-98`：「L5 的零是市场事实」读法（引 BSP 侧 max_lvl=4，p105 §0）。
- `p114-relaxation-ceiling-20260717.md:33`：深度 5 全情景 = 0，可达深度上限 = 4。

### 裁决
1. **教义层即裁（天花板问题关闭）**：L5 不是理论顶，也不是承诺位。任何「深度 5 必须 > 0／链必须爬到 L5」的验收指标非法（违反 020:40 条件性存在）；任何「L5 即塔顶、零覆盖天经地义」的封顶读法同样非法（doc-level-domain:99 两端拒绝）。**永久验收谓词 = 条件存在性**：若 Center[6]／L5 结构实际形成且经 D2 确认，则 provider 必须在 L5 发事件、链可延伸至深度 5；结构未形成则 L5 零覆盖合规，不作缺陷计数。
2. **归因层裁定：「L5 零覆盖」= 归因未结**。两读数并存是未分解事实：链侧 8 个 L5 结构 pair（p109:93）⟹「塔顶无候选结构」的强读法在字面形式上不成立（结构 pair 存在）；provider 侧零事件（p107:85）的原因未分解（p109:206）。在 §6-4 分解产出前——
   - 「深度 5 = 0」**不得签市场事实终审**；p107:97-98 的「市场事实」读法即日降级为「现状读数，待分解」（p107 的测量本身——provider 漏斗 L5 全 0——仍为有效数据，被更正的是从「provider 零候选」到「塔顶无结构」的解释跳跃）。
   - 亦**不得记为已定性缺陷**（Extreme 未过／结构不成立的可能未被排除）。
3. **签署 p109 §6-4 分解探针为合法归因探针**（只读、不进证书门，探针纪律同 `doc-divergence-validity-test-20260717.md:152` §5.4）：对 8 个 L5 strict pair 逐对分解无事件原因。其输出按**预裁二叉处置树**执行，无需新裁定：
   - (a) D2 pair 缺失（背驰结构在而 provider 未产事件）⟹ 归 **provider 装配缺口**，立实装修复任务；验收线 = 该 8 pair 中具确认结构者应产事件。
   - (b) Extreme 未过／结构不成立 ⟹ 归 **市场事实终审**，「深度 5 = 0」可签为正确市场答案；p107:97-98 读法届时恢复为终审签署。
   - (c) 残余第三因（既非 D2 缺失亦非 Extreme）如实落档，占比显著时另立裁定。
4. **p114:33「深度 5 硬墙」维持为现状读数**；其性质（市场硬墙 vs 装配硬墙）随 §6-4 分解落定，本裁定不预选。

### 验收线
- 全量重放报告义务：provider 级别谱的 L5 行（strict pairs／events／命中率）必填；pairs > 0 且 events = 0 时状态词一律「归因未结」，禁写「市场事实」终审、禁写「缺陷」定性（违例 = 文档缺陷）。
- 条件存在性入验收：未来任一重放中 Center[6] 形成且 L5 具 D2 确认结构而 provider events = 0 ⟹ 自动报实现异常（装配缺口）；Center[6] 未形成 ⟹ L5 零覆盖合规。
- §6-4 探针落地后按裁决第 3 条二叉树执行，结果落 escalate 备查档；探针实装为只读 bin，列入后续任务，不与在跑 p116 重放并发（生产源码只读纪律沿用）。

### 不回滚条款
- 不得把 L5（或任何固定 k）设为理论顶；不得把「L5 必有证书／链必到深度 5」设为任何验收或缺陷指标。
- 「深度 5 = 0」在 §6-4 分解前不得签市场事实终审（p107:97-98 读法降级即日生效）；分解后的终审签署亦须以探针证据为凭，不得凭 BSP max_lvl=4 单点推断。
- 条件存在性谓词不得被改写为固定层数承诺；provider 循环上沿的变更（如扩监听级别）属新裁定，附 §6-4 分解证据为前置。

### 教义依据（课号:段号，直读主仓博文原文核对）
- **037:18**：「c必然是次级别的，也就是说，c至少包含对B的一个第三类买卖点，**否则**，就可以看成是B中枢的小级别波动，完全可以用盘整背驰来处理」（`037-第37课.md:18` 直读）。否则条款针对的是 **c 不含三买的对象分类**（该对象 = B 中枢小级别波动，出口 = 盘整背驰处理），不是时效门槛——原文没有「三买须在某一期限内出现，逾期即非 c」的任何条款。
