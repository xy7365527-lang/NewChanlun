### 教义依据（课号:段号）

- **031:883 / 033:26**：比较对象唯一 = c vs b（最后中枢离开段 vs 进入段）。
- **025:761 / 025:296 / 025:339**：MACD 口径须以黄白线回拉 0 轴为前提。

## R2 pan 力度谓词 = 或关系信号集（027:32 结构；面积单通道必要门废止）

### 背景

### 教义依据（课号:段号）
- **027:32**：回抽 0 轴的黄白线再次下跌不创新低、柱子面积明显小于第 1 段——「只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准了」（或关系逐字；万科旗舰例顶层即盘背）。
- **026:521**：黄白不创新高/新低，**或**柱子面积之和小了，都是信号，「两个只要出现一个就要注意了」。
- **025:38**：黄白线不能创新高，**或者**柱子的面积**或者**伸长的高度——三信号以「或者」并联。
- **025:16**：面积更大仍判力度衰竭——反例钉死「面积小非必要条件」。
- **034:72**：最重要的是黄白线。**056:60**：1 分钟级别及以上须并看黄白线回抽 0 轴。
- **027:30-31**：价格幅度比较先于 MACD（万科先例）。
- **060:44 / 057:40 / 024:40**：面积口径 = 全部同色柱子面积之和。
- **033:26**（对称边界）：无衰减即无盘背——或集之外无信号即市场事实。

### 实证证据（报告:行锚）
- `p113-pan-caseaudit-20260717.md:14-19`：144/474 事件（30.4%）、504/1,020 链（49.4%）聋度；027:32 原文两项口径 58 个（两口径并列）。
- 同文 `:91-96`：分项信号计数——同色面积 25 / 黄白线 46 / 柱高 77 / 幅度 94；柱高+幅度贡献聋度主体；四 proxy 并集 144 ⊃ 027:32 两项 58。
- 同文 `:100-108`：聋度标本——混合柱 Σ|hist| 把反向柱计入分母（反向柱占 C 段面积 62%），同色口径下力度衰减明确。
- 同文 `:115-119`：判定——谓词过严实锤（数据事实）；330/474 事件四 proxy 全无衰减 = 市场事实，不得计入放宽通道。
- 同文 `:202-206`：修法建议 2——或集化两子件（同色柱口径替换混合柱；柱高/幅度 proxy 补位），可独立裁定。

### 裁决
1. **力度谓词 = 前提 ∧ 或集**：B 域黄白线回拉 0 轴（025:761 前提；机械化 = B 域 DIF 触/穿 0，容差口径须声明）∧ {同色面积 C<A（060:44 同色柱口径）∨ 黄白线峰 C<A（026:521）∨ 同向柱高 C<A（025:16/025:38）∨ 幅度 C<A（027:30-31）}，任一成立即有盘背力度信号。
2. **混合柱 Σ|hist| 严格 curr<prev 单通道必要门废止**——依教义判定（doc-pan:124）与逐案实证（p113:115-117）撤销其盘背确认门资格。
3. **成员集裁定**：或集 = 上列四员（p113 §2.1 的原文信号全集操作化，`p113-pan-caseaudit-20260717.md:96`）；027:32 严口径两项（58 事件）为其子集，读数落档备查。p113:205-206 留下的宽严取舍就此拍板：取四 proxy 并集——柱高（025:38「或者」第三员）与幅度（027:30-31 先于 MACD 的先例）有逐字原文支撑，且恰是聋度主体（p113:93-94），剔之无教义理由。
4. **边界不回滚**：四 proxy 全无衰减 ⟹ 判负 = 市场事实（033:26），此边界不因任何产量压力移动。

### 验收线

- 反例闸：任何事件在四 proxy 上全无衰减而判有信号 = 实装缺陷。
- 产量提示（非验收指标）：p114 判定面积放宽必要但不 carry——1,020 池过确认门后全部撞终端门（同族 877 池 0/877 有 confirm BSP，`p114-relaxation-ceiling-20260717.md:28-32`）；pan 终端确认语义另案（p109 §6-5c）。

### 不回滚条款

编排者主张『每个级别都应该有对应证书』。p107 §6 实测 L0 漏斗各级恒 0：provider `for level in 1..tower.len()`、装配 `for exec in 1..`（`p107-level-funnel-audit-20260717.md:201-203`）；L0 在终态账本有 14,487 个同向确认源（p105 增量口径 19,776 事件 = 全部 BSP 的 69.6%）结构性不可标记（`p105-cert-level-spectrum-20260717.md:18`）。doc-level-domain 判定 L0（线段级）在原文无背驰对象。问题：L0 不发证书是缺陷还是教义正解。

### 教义依据（课号:段号）
- **065:94**：一定要存在最低级别的中枢后，才有最低级别的走势类型，才会有背驰等概念的存在；在线段之下讨论背驰概念是没意义的；类背驰「和背驰是两回事情」——缠师对背驰概念定义域的显式裁定。
- **066:198**：背驰的概念标准的在最低级别之上用，线段上的只能是类背驰的判断。
- **069:148 / 087:108**：065 后成熟术语一致——线段域 = 类背驰。
- **035:16 / 017:40 / 060:42**：地板两层（理论地板 = 每笔成交；操作地板 = 人为设定最低级别）；背驰从「该层中枢→走势类型」起算。
- **088:196**：原文自己的最深一重区间套 = 线段内部笔间定位（类背驰域）——链可在背驰地板下续一重，但该重不是背驰证书。

### 实证证据（报告:行锚）
- `doc-level-domain-20260717.md:15,63-67`：L0 不能有背驰候选（定义链：背驰 ⟹ 最低级别走势类型 ⟹ 最低级别中枢；单线段无中枢）；递归地板 = L1。
- `p107-level-funnel-audit-20260717.md:43-50`：L0 不监听的影响面 = 最密 BSP 层不可见 + 地板封顶 L1，**但与多级链稀少无因果**——旧 CandDeltaEvent 路径监听 L0 后多级链仍 0/483。

- `doc-necessity-boundary-20260717.md:16,186`：「每级都该有证书」被 043:24 等教义证伪；废止逐级验收指标。
- `p109-chain157-gate-attrition-20260717.md:20-26`：6,482 链击杀主力在 provider 身份覆盖（58.5%）与终端背书（25.2%），不在 L0。

### 裁决
1. **现状确认**：nest 背驰证书体系不在 L0 发背驰证书——原文无此对象（065:94 定义链、066:198）。递归地板 = L1（Center[1] 中枢首构层）。
2. 「链必须递归到 L0」不得设为验收标准（违反 065:94）；链深 ≥2 为 0 不得归因「L0 未覆盖」。
3. L0 级精度定位若需要，单立**类背驰定位**工件（088:196 模式），与背驰证书分轨命名、分轨验收；该工件不在本裁定实装范围，另立任务。
4. 配套验收口径（承接 doc-necessity §6-2）：存在性探针为唯一合法异常判定式——真 L 级转折点 T 处存在任一级别 ℓ≤L 的背驰段证书且终点≈T 即合规（哪怕只 1 张）；**全级别零证书**才可报实现异常。

### 验收线
- 任何验收/缺陷指标不含 L0 覆盖；48/66（72.7%）单级链「已到最小级别」的声明统一标注为「L1 以下未观测」（`p107-level-funnel-audit-20260717.md:206-208` 的诚实读法）。
- 类背驰工件（若立）不得反注为背驰证书、不得冒充同级买卖点。

### 不回滚条款
- 不得以「补 L0 覆盖」为由把类背驰信号混入背驰证书体系。
- L0 监听与否的变更（如 provider 循环下沿）属新裁定，附 doc-level-domain §A.6 定义链的反驳义务。
