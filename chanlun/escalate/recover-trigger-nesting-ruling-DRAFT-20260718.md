## R1 recover 触发语义：子级别 BSP（正面裁 B；父级别 BSP 触发判非法）

### 背景

§9.10 留下唯一开放分叉（`bsp_consumption_redesign.md:245`）：子（回调对冲）归还父应由 **(A) 父级别 BSP**（父回调结束；2026-06-21 嵌套版当时实装）还是 **(B) 子自己级别 BSP**（子走势完成，及时平）触发。同段记录 (B) 的顾虑：「同一 type1_buy@子level 既是子完成归还 vs 子回调 sink 孙」的区间套语义歧义。三度迭代全史：

- **§9.9 扁平版**（:205-224）：`reconcile_all_levels` 同级别买点平空，sink/recover **592/592 全配对**（:216），BSP 从零消费到 592 次（里程碑）；但 BTC 牛市做空腿系统性亏损 short_leg_pnl=−21057（55.7% 亏损率，:218），strat +30.50% << BH +1380%（:215）。
- **§9.10 嵌套版**（:226-245）：`reconcile_recursive` 子归还父由**父级别 BSP**（core 持子时检查 type1_buy@core_level）触发（:243）；spawn 16 次把核心升到高级别 → 高级别买点罕见 → 子做空长期不平 → 牛市净空头 72.6%（:240）→ **穿仓 −238%**（:236）。诊断原文：「做空晚平：……精确重现 [[project_t_short_close_level_mismatch]]『做空晚平=平空级别错配』」（:243）。
- **§9.11 修复**（:247-264）：修复 1 递归归还子树（:251-254）→ **BTC −238% → +502%**、净空头 72.6% → 0%（:254，已跑验证）；修复 2 删 direction gate、耦合纯 BSP 类型驱动（type1_sell→sink / type1_buy→recover，:256-262，未跑验证——如实转录）。当前形态：「type1_sell@级别→sink……type1_buy@级别→recover（递归归还+回补）……89 测试绿」（:264）。

### 教义依据（课号:段号，直读主仓博文原文核对）

- **039:20**：「其中最大的就是向上段先买后卖与向下段先卖后买的韵律，如果这个韵律都错了，那操作就一团糟。」（`039-第39课.md:20` 直读）短差是**段内**的一对：向下段（父回调 = 子级别走势）先卖（sink）后买（recover），买点落在**该向下段自己的完成处** = 子级别。等父级别买点 = 等父整段走势完成，那不是回调的结束、是父趋势的结束——韵律错配，正落 039:20「操作就一团糟」的反面。
- **027:36**：「学过数学分析的，都应该对区间套定理有印象。这种从大级别往下精确找大级别买点的方法，和区间套是一个道理。」（`027-第27课.md:36` 直读）区间套方向 = 大级别给域、次级别定点，自上而下。recover 语义中父级别的角色 = 给出操作域（在哪个回调内对冲），子级别的角色 = 给出操作点（回调完成的精确点）。(A) 把操作点上挂父级别 = 区间套方向倒挂，把「找点的大级别」误当「定点的次级别」。
- **093:22**：「利用（1，0）后必然出现的震荡进行短差操作，由于都是先卖后买……」（`093-第93课.md:22` 直读）短差的买是**回补**（先卖后买的后一半），不是新开多、更不是等高级别再给信号——回补与同一次震荡（= 子级别走势）同在一段韵律内闭合。

### 实证证据（文件:行号）

- (A) 证伪：§9.10:236（strat −238% 穿仓）、:240（净 long 27.3% / short 72.6%）、:243（根因 = 父级别 BSP 触发 + spawn 升级 → 高级别买点罕见 → 做空晚平）。
- (B) 可行：§9.9:216（同级别买点 592/592 全配对，net 不空）、:243 末句（扁平版「用同级别买点（频繁）平得快」）；§9.11:254（递归归还修复后 +502%，净空头 0%）。
- 级别错配谱系：[[project_t_short_close_level_mismatch]]（§9.10:243 引；`docs/three_stages_accounting_design.md:412` 同构「闭合级别归属矛盾」；`docs/drain_and_three_stages.md:168`）。

### 裁决

1. **recover 触发 = (B) 子级别 BSP**：短差腿骑乘级别 j 的同父向买点（父多时为买点，父空时为卖点——同一次震荡的反向完成点）触发 `recover(p, j)`。父级别 BSP 触发 recover 判**非法**——它是平空级别错配（做空晚平）的定义性形态，已由 §9.10 −238% 穿仓证伪，任何实装/设计回潮 (A) 即违裁定。
2. **(B) 的歧义消解**（§9.10:245 登记的顾虑就此关闭）：「同一 type1_buy@j 双读」不成立，由两条既有纪律机械排除——
   - **纯 BSP 类型耦合**（§9.11 修复 2，:256-262）：type1_buy 只走 recover 方向、type1_sell 只走 sink 方向；同一买点不存在「又是 sink」的类型通道。
   - **单次路由**：BSP@k 只在级别 k 路由一次，消费者 = 级别 k 仓位与其最近活跃祖先（`nearest_active_parent(j)` = 严格更高第一个 active，`rec_engine.rs:1312-1315`）；孙腿齿轮由 BSP@(j−1) 驱动，不由 BSP@j 再消费一次。`route_bsp` 的 is_reduce 分支互斥（`rec_engine.rs:1815-1854`）即此纪律的实装形态。
3. **现状追认**：当前代码三条路径均已是 (B)，本裁定 = 概念定名 + 禁 (A) 回潮，非新行为——
   - instances 路径：`route_bsp` Some(p) 同父向分支 `recover(p, j, c)`（`rec_engine.rs:1834-1850`；recover 本体 :1666-1709，注释 :1666「次级别走势完成 ⇒ 整条短差平清 m=u_sub 升回父」）；测试锁定 `rec_driver.rs:181-192`（`子级同父向买点_recover`：level 2 买点触发、子平空、核心恢复原股数）。
   - flat 对照：`t_engine.rs:18`（模块注释「recover（子级 j 收同父向 BSP，j 持反父向短差）」）、`route_bsp` :667、同父向→recover :699、recover 本体 :605、测试 :1103。
   - LegPair 生产路径（Face A 默认）：`g_pair` `if b` 块先平空腿（`rec_engine.rs:2454-2461`，「买点：先平空腿（反向买卖点平）」，`last_close_reason=0`）——同为骑乘级别 k 的买点平该级别空腿，(B) 语义。
4. **recover 的语义定名**（090 防口径漂移）：recover = 同一次震荡短差对的**回补闭合**（平反向腿 + 归还父级仓位，同股数/同资本能量守恒，`rec_engine.rs:1674-1693`）。凡不满足「子级别同父向 BSP 触发 + 归还父级」两要素的平反向腿（否定线止损、塔清、NAV 强平、finish）**不称 recover**，会计分流见 R2 裁决 3。

## R2 衰减边界：recover 有效域的双面界声明

### 背景

路线图把本项登记为 G6（`mainline-merged-roadmap-20260717.md:44`「recover 率级别衰减边界（G6）」）；同一数据在 §9.7 标 G4（`bsp_consumption_redesign.md:173`），原始出处 zombie 诊断（`project_zombie_short_diagnosis.md:16,20,21`）：**recover 率 seg 层 CL 93% / BTC 85%，rL2 及以上全标的 0%**（:21）；nf_buy 级别衰减 move(3)≈5000 → recL2(4)≈150 → recL3(5)≈12 → recL4(6)≈1，每升一级少一个数量级（:20）；路径 B =「高层 sink 子层空头，recover 需父层 nf_buy 极稀疏（rL2 以上 recover 率=0%）」（:16）。含义：R1 的 (B) 触发在高级别同样失效——子级别买点本身在 rL2+ 稀疏到近乎不存在，recover 作为**配对归还机制**在该域结构性不可闭合（僵尸空头路径 B）。

### 教义依据

- **027:50**：「……由于级别不是无限可分的，不可能达到数学上唯一一点的精度。」（`027-第27课.md:50` 直读）区间套下探有底：recover 触发级别的下探不无限递归，底 = a₀ base case（§6:96-97：段太短无中枢真无买点）+ G1 摩擦地板（§9.7:170：segment 幅度 0.02-0.19% < 摩擦，99% segment 交易在摩擦地板下）。

### 实证证据

- 上界：zombie:20-21（nf_buy 数量级衰减 + recover 率 85–93%/0%）；§9.7:173（G4 转录 + 「回补的有效域=低级别」结论）。
- 下界：§9.7:170（G1 摩擦地板按级别切割）；§6:96-97（a₀ 线段 base case；029:396 保证段发育出中枢则本级别必有买点——中枢存在性是买点存在性的结构前提；`center.rs:48` 中枢≥3 门槛已直读核（`n<3` 不产中枢），`divergence.rs:158` judge_divergence 入口为转引自 §6:97/§10:269 的行锚）。
- 数量级衰减的结构必然性：递归塔每升一级单元组合数指数稀疏（塔几何），非 regime 偶然——regime 只影响短差腿盈亏（zombie:23-25：CL 震荡 short +1477 / ES 强牛 −257K），不影响买点密度的数量级方向。

### 裁决

1. **recover 有效域 = 级别带，双面界**：上界 = G6 衰减失效线（同父向买点密度不足以配对的级别，旧口径读数 rL2+）；下界 = G1 摩擦地板 + a₀ base case（027:50）。有效域内 recover 按 R1 闭合；有效域外**不建立 recover 期待**。
2. **失效域处置（两项，皆非 recover）**：
   - **源头**：不在失效域建立 recover 依赖的反向短差腿。现有相邻机制如实登记（本裁定不重裁其口径）：LegPair 开空 `t3sell ∧ below_core_long` 门（`rec_engine.rs:2531-2572`）；O6 R+ 被动保护（`sink_impl` `protect_core=true` 不开 hedge 空腿，`rec_engine.rs:1598-1651`）。
   - **在场**：失效域反向腿由**否定线**（结构破坏：空腿涨破进场 ZG，`pair_stop_loss_step` `rec_engine.rs:2293-2303`）或 **R3 退出条款**（塔清/d_top）闭合；两者都不是「回补」，不享受 recover 的同股数归还语义。
3. **会计分流（recover 语义只挂通道 0）**：`last_close_reason` 0=买卖点反向平（recover 语义唯一挂载点，`rec_engine.rs:2457-2459`）/ 1=否定线止损（:2286-2300）/ 2=NAV·finish（:2587-2599, 2629）；`pending_exit_trigger` 细分（#164 R2，:2459）。任何报告把通道 1/2 计入「recover 率」即口径污染（090）。
4. **090 诚实声明（读数口径）**：85–93%/0% 与 nf_buy 衰减数字产自 2026-06-17 flat 世代引擎（zombie 诊断，session cowork-2026-06-17），与当前 nest R1–R3 口径 + 关②修复后的 BSP 集**不同源**——本文引为**结构方向性证据**（数量级衰减方向），不作为当前生产口径的精确读数；定量位置以关②验收后的重测为准（验收线 2）。

### 验收线

- 全量重放/诊断报告的「recover 率」一律按裁决 3 的通道 0 口径统计；per-level recover 配对率（`recover_by_level`/`sink_by_level`，`rec_engine.rs:1661,1703`）与 per-level 短差腿 P&L（`short_pnl_by_level`，:1697）分层落账。
- 关②（1b）验收后按新 BSP 口径重测衰减边界（nf_buy 级别分布 + per-level 配对率），重测报告落 escalate 备查；若重测推翻数量级衰减方向（如 rL2+ 不再 0%）⇒ 本 R2 边界回复议；**R1 触发语义不复议**（语义层独立于定量边界）。
- 失效域新开 recover 依赖空头腿的实装 ⇒ 拒绝合入（违裁决 2 源头项）。

### 不回滚条款

- 不得为「救」失效域配对率而把 recover 触发器上挂父级别（= R1 判非法的 (A) 回潮）；失效域的答案是「不建立期待」，不是「换个级别等」。
- 不得把否定线止损改名 recover 或并入 recover 统计；两通道会计身份不同（止损=结构破坏退出，recover=韵律回补闭合）。

## R3 093:22 不回补条款：recover 的退出边界

### 教义依据

- **093:22**：「……由于都是先卖后买，所以如果发现市场选择了（-1，1），那么最后一次就不回补了，完全退出战斗。」（`093-第93课.md:22` 直读）先卖后买的短差韵律有一条 doctrine 内建例外：更高级别选择向下（(-1,1)）时，最后一次卖出**不回补**——不是延迟回补，是完全退出。
- **039:20**：向上段先买后卖、向下段先卖后买的韵律是操作合法性的前提；韵律的对象（段）被更高级别否定后，韵律不再延续。

### 裁决

1. **退出边界生效**：更高级别走势完成反向（=「市场选择了 (-1,1)」的可操作判据：**结构事件**——核心级别走势完成 d_top / C1 的最高级别超大卖点全量清仓，`bsp_consumption_redesign.md:177`；零价格阈值、零参数）⇒ 塔内所有短差腿随塔清，**无 recover 期待**：最后一次 sink 的子腿不做回补闭合，随 `clear_all`（`rec_engine.rs:1875`，core flip 清全塔）或 Face A d_top churn（`g_pair:2490-2528`，核心走势完成平/翻）整体退出。
2. **与 R1/R2 的衔接**：R3 退出不是 recover（不挂通道 0，走塔清/EOD 会计）；退出后的反向重建（新方向核心 + 新短差对）是新韵律的开始，与旧塔无归还关系。
3. **边界声明**：本条款只裁「何时不 recover」；退出的时机质量依赖走势完成判定（d_top/信号层口径），关①关②的口径变更会移动该判别的时点读数——影响退出**时机**，不影响条款本身。

### 验收线

- 单测：core flip/d_top 塔清后，旧塔子腿不存在 recover 挂单/期待（见单测计划 ④）；`clear_all` 路径无 `recover` 调用（代码走查 + 测试双重锁定）。
- 报告中塔清退出与 recover 闭合分账列示（会计分流同 R2 裁决 3）。

## R4 §9.4 旧句作废登记（以 C1 为准）

### 冲突与裁决

- **冲突**：§9.4:153「**永远在市场有方向**……卖点=反手做空，不只做多，零真空。每级别 Z₂ 恒有方向（多或空）。」与 C1（§9.7:177，编排者 2026-06-20 终裁：「所有级别所有卖点都是短差（reduce + 次级别开空），无 Z₂ 翻转、无整仓翻空。核心持多骑趋势永不翻空」）正面冲突。
- **裁决**：以 C1 为准，§9.4:153 旧句即日作废。「永远在市场有方向」的 C1 一致读法 = **核心恒持 + 次级别齿轮恒咬合**（卖点=reduce+次级别开空 / 买点=平空+回补；多空双开赋格 = 不同级别不同头寸，§9.1:138「平多≠开空」），零真空 = 韵律恒咬合（039:20），**非**每级别 Z₂ 翻转恒有方向。
- **登记理由（090）**：本文 R1–R3 全部立在 C1 语义上（sink/recover = 短差对，非翻转对）；旧句若并存，「卖点=反手做空」会把 recover 误读为「翻转回多」的逆操作，污染 R1 的语义定名。故显式作废，不留双口径。
