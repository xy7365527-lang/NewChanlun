判定逻辑：塔内 `si == b_start` 的记录中带 == 点带（== B 带）者唯一 ⟹ 点中枢与 B 解析到同一
条塔记录 = 同一中枢。两类情形：

- **10 点次**：b_start 全塔唯一记录（无任何碰撞面）⟹ 无歧义同一中枢。
- **8 点次**：b_start 被多级别复用（2-4 条记录，带互异）——跨级别 si 碰撞面**客观存在**；
  但点带与 B 带唯一匹配同一条记录 ⟹ 旧 proxy 的序号判等在这 8 件上**结论恰好为真**（碰撞未咬到）。

机制解释【推断】：一/三类判同是「点自身归属中枢 vs 事件 B」的同族比较——点中枢与 B 同指
该走势中枢，同级别同带时落同一记录；二类旧 proxy 是 c1.start_index（另一中枢的 si）对
b_start 的跨族比较，跨级别 si 碰撞才有机可乘（9/40 全假等值）。同一 proxy，暴露面不同。

附带事实【确证】：全塔 129 个 si 被多级别复用（最大 4 级同 si，见 si=178474）——若一/三类
点中枢落在异带记录上，旧 proxy 同样会出假等值；wf7 实测此类零发生（old ⊄ new = 0 旁证）。
**旧 proxy 对一/三类是「未爆的雷」，对二类是「已爆的雷」**——是否爆取决于点中枢级别分布，
非 proxy 本身变可靠。

未核实【未核实】：18 点次的 c1/c3 逐件分列无法从探针行恢复（band_cmp 未打印类位）；
聚合 4+14 已对账，逐件类属不影响「同一中枢」判定本身。
