## §2 P1/P2 合法性核验

### 2.1 判定域厘清（先回答「P1 管不管得到这 518 笔」）

P1/P2 的判定对象是**终端背书**（terminal endorsement）：nest 背驰事件（`NestCandidateEvent.kind` = Trend/Consolidation）在 `levels[ℓ-1].bsp` 账本的 `[c_start, t*]` 窗口内查询合法背书点，生产单一来源 = `terminal_bits_at_event`/`terminal_bits_in_book`（`rust/src/theta_v0/classifier/nest.rs:545-582,596-610`）。

本批 518 笔的入场消费是**另一条路径**：Γ 候选直接信号消费。证据链：

1. certificate 五元组（bits/class/level/source_index/dir）逐字段来自开腿 Γ 候选 `c`（`rust/src/theta_v0/backtest/runner.rs:1644-1655` 装配、`runner.rs:2486-2493` 落盘 `cand_bits = c.bits.class_index()`）。
2. Γ = 全级别 BSP 账本的点逐点成候选（`rust/src/theta_v0/strategy/interp.rs:275-316` `assemble_gamma`：`for point in level.bsp.iter()`）；候选的 `nest_confirmed` = 区间套证书基例 Conf^δ（候选自身 bits 的方向析取，`interp.rs:378-384`），**不是**终端背书查询。
3. `terminal_bits_at_event`/`terminal_bits_in_book` 在 lib 非测试代码中**零生产调用点**（全仓 grep：仅 `nest.rs` 定义与测试 + p92/p116/p124/p125 重放/审计 bin 调用）——M8 opsem 的 θ 解释器入场路径不经背书查询。
4. 各级 BSP 账本的产点是结构判据直产（`rust/src/theta_v0/classifier/mod.rs:416-433`：一/三类 `extract_first_third_for_level`、二类 `extract_second_for_level`），不经 nest 事件背书门。

**结论**：certificate 无 kind 字段不是数据缺失，是结构事实——`Candidate`（`interp.rs:71-93`）与 `BspPoint`（`bsp.rs:113-165`）本无 kind；kind 是背驰**事件**的属性，而这 518 笔消费的是**点**。「Trend 事件的背书被 type2/3 充任」在本消费路径上无对应行为，**此路径不存在 P1 违反的可能形态**。

### 2.2 背书路径的实装状态（P3 收紧已落地，Trend×type2/3 构造性排除）

背书路径侧，关③ P3 已在 worktree 生产单一来源实装（代码直读 `rust/src/theta_v0/classifier/nest.rs:563-581`）：`terminal_bits_in_book` 的 `CWindow` 臂按事件 kind 分域过滤——

- `Trend`：`confirm_side(side) ∧ (buy1|sell1) ∧ point.center.start_index == b_center_start`（:571-576）——**type2/3 点在 Trend 域被合法性过滤构造性排除**，「最早合法点」先于「最早点」（:529-533 头注，P3.1）。
- `Consolidation`：`confirm_side(side)` 即精确语义（:570），P2 裁决 5 零改动。
- owner 载体已补齐：一/二/三类点构造时填判定中枢（`signal.rs:553`、`:573`、`:597`；关③补记 2026-07-18② 路径 (a)）。

旁证：p125 审计的 v3 未收紧读数中 Trend 族 370 案 type2/3 背书已被 P4-1 定性非法并登记（`pan-terminal-endorsement-ruling-20260718.md:129`：「1,213 = 合法 748（Pan）＋ 待 owner 回读 95（Trend 一类）＋ 非法 370（Trend 二/三类）」）——该 370 是**收紧前**口径的历史读数；现行代码下同一查询不再产生。**引用该 v3 读数须携带此点类注记（P4-1 义务，:129），只报 1,213 总数 = 文档缺陷。**

### 2.3 事件级逐案核验：不可测（照实声明）

任务所问「trades 消费的 type2/3 点里有没有趋势族的点被当背书用」的**事件级**形态——即「某笔交易背后是否站着一个 kind=Trend 的 nest 事件、且其背书点是 type2/3」——在本批 artifacts 上**不可测**，理由三条（任一即充分）：

1. certificate 无事件 id、无 kind、无背书点坐标（§2.1-4：消费的是信号点本身，不是背书查询结果）；
2. `tower_events.jsonl` 只含塔结构事件（level_upgrade/new_center/extend），不含 nest 背驰事件流（无 kind=Trend/Consolidation 记录）；
3. trade↔event 无外键（`voice_id`/`position_node_id` 指向语音树，不指向事件账本）。

090 纪律：照实否定合格——本节为否定结论，不以 §2.4 的结构代理冒充事件级判定。

## §3 type1 仅 5 笔（0.97%）：教义预期对照

### 3.1 教义与生产双侧的「一类构成性稀有」

- **教义侧**：027:66 一类「肯定是趋势背驰构成的」——定义域 = ≥2 同级别中枢的趋势 + 背驰；027:18「多数的第二、三类买点，其实都是由盘整背驰构成的，而第一类买点，多数由趋势的背驰构成」——二/三类的高频是教义内禀；020:62「第三类买卖点比第一、二类要后知后觉」——三类天然高产。
- **生产侧门链对比**：一类 = τ 门（Trend ownership 块）∧ anchor 资格（686 窄域后）∧ 破核心 ∧ 037:20 破 b 极值 ∧ A/C 可配对 ∧ MACD 面积 C<A 六重合取（裁定文书 `bsp-terminal-endorsement-ruling-20260718.md` T2/T3）；三类 = 中枢离开 + 回抽不回的纯几何（`signal.rs:566-577`，无背驰、无 MACD）；二类 = 次级别第一类离开 + 回拉不创新极值（`signal.rs:590-601`、`extract_second_signals`）。一类是全系统门最多的点类，稀有是设计直译。

### 3.2 参照读数与差异归因

- p125 v3 全量（4,613,599 bar）背书域构成：type1 = 126/1,213 = 10.4%（`pan-terminal-endorsement-ruling-20260718.md:32`；Trend 族内 95/465 = 20.4%）。本批 0.97% 低一个数量级，差异可归三因（不可分账，照实声明）：(i) **域不同**——v3 读数是事件背书构成，本批是信号消费构成（入场还须赢 Γ 内 lex_argmin 竞争，`runner.rs:1673-1674` lex_top3 快照在证）；(ii) **窗口结构**——本窗 184 天先抑后扬强单边，完成的「≥2 中枢趋势 + 背驰」episode 数本就稀少（盘背/中枢离开结构则遍地）；(iii) **级别分布**——一类只在 L1 出现（5 笔），L0 一类零消费，L0 是候选基数最大的级别。
- **判定**：0.97% **方向性符合教义预期**（一类稀少是构成性的），现有证据**不能**判定为「一类被过度排除」；但下述两个子事实超出「稀有」可解释的范围，列异常清单（§4-A1）：buy1 = 0/518（本窗有一段 29k→25k 的完整下跌，底背一类是否生产过不可测）；5 笔全 Short 且聚簇两个坐标区（s=160,604 与 s∈[253,615, 258,787]）。「生产缺席 vs 产生但未赢竞争」的二分需要 Γ 候选全集 dump 才能判定——本批 artifacts 不含，照实列为不可测 + 后续核验项（§5-②）。
