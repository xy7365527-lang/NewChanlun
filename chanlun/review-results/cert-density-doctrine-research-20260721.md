# 调研：买卖点与证书密度差（~300×）的教义归因——背驰/区间套是不是必要条件

- 日期：2026-07-21
- 性质：教义调研（/research），亲读博文核对，全部带行锚。供 G1/G2 合并裁定书（g1-g2-window-ban-ruling-20260721.md）作论据。
- 结论先行：**背驰只是一买族的定义条件；区间套是背驰段转折点的精确定位方法。证书（N^δ 链）的定义域天然是 BSP 全集的小子集，~300× 密度差是教义结构的必然，不是漏检。**

## 1. 三类买卖点的字面定义不同，但操作确认统一经区间套+背驰

- **一买** = 下跌走势完成的转化关节点（`docs/chanlun/text/blog/017-第17课.md:60`）；背驰在本级（024:36/:40 MACD 面积背驰判定）。
- **二买** = 「在第一类买点出现后第一次次级别回调制造的低点」（017:60）——字面定义是次级别结构完成；**但「次级别回调完成」的确认本身内含背驰+区间套**：`027-第27课.md:60`「600685 第二买点的确认方法（区间套）」缠师亲示范——二买的低点就是次级别回调走势的背驰完成点。
- **三买** = 次级别离开中枢 + 回试不破 ZG（`020-第20课.md:60`）——字面定义是中枢几何；**「回试完成」同样要次级别走势完成判断 = 背驰确认**（回试段完成点 = 次级别一买/类一买）。

**编排者指正（2026-07-21）**：「次级别走势完成」内含区间套和背驰——字面定义层三类不同，操作确认层三类统一：所有买卖点都经「次级别走势 + 区间套 + 背驰」递归确认（主线全称语义，无例外）。差异只在确认链挂点：一买背驰段在本级（证书链从本级装），二三类背驰在一层之下（先降级，完成点才是确认锚）。

## 2. 区间套 = 方法，不是存在条件

- `027-第27课.md:36`「从大级别往下精确找大级别买点的方法，和区间套是一个道理」；027:50 级别非无限可分的精度边界；027:60「600685 第二买点的确认方法（区间套）」；027:320「5分钟背弛段的1分钟背弛段的次级别的背弛这样的三重背弛的……区间套定理的精确定位」。
- 区间套作用在**背驰段**上（逐级精确化其转折点）；没有背驰段就没有区间套的对象。它不是每个买卖点的存在性条件。

## 3. 证书 = 区间套确认的形式化，密度天然小

证书签发要求：背驰确认 + 逐级嵌套确认（N^δ）。在一买族子集上再叠两道门：基例门（次级别终端背书）+ N2 力度门（每级 rung 背驰确认——全量实测 A 2767→1980、B 2518→984，v2-rung-force-gate-impl-20260720.md §6.3）。三过滤器相乘 ⟹ ~300×（91/66 张证书 vs 29,860 BSP）。

## 4. 二三类买卖点的「递归确认」形态

主线「买卖点由次级别走势经区间套+背驰递归确认」对二三类点的体现 = **锚定一类点**（027:60 区间套确认二买的原文形态；生产实装 `descend_type1_anchor_depth`，econ_positive.rs:712-740 在用）。一类点吃全链（多级区间套证书），二三类点吃锚定（降到一类点完成确认）——递归确认对所有买卖点成立，多级全链只在一买族主场存在。

**级别关系限定（017:72，编排者追问落实）**：定律一（017:66「二类买卖点由次级别相应走势的第一类买点构成」）紧接限定「这某级别不一定是次级别」——次级别里可以是第二类买卖点；且不同级别可同时出现第一类买卖点（同步共振）。**T2 锚定不得硬钉 ℓ−1，须允许「某级别」（更深级或同步共振）。**

**三买级别刚性（020:60 / 053:66）**：三买 = 次级别离开中枢 + 次级别回试不破 ZG（020:60 两次明文「次级别走势类型」）；中枢定理三（053:66 引课程18）：两个次级别走势的组合仅三种（趋势+盘整 / 趋势+反趋势 / 盘整+反趋势）。次级别由中枢级别决定，无弹性——**T3 锚定 = 严格 ℓ−1 原子**。级别分治：T3 守 ℓ−1、T2 放开某级别。

**统一论与分类学的合一（037:257 答段，编排者指认张力）**：037 课答「所有买卖点，归根结底都是第一类买卖点，只是级别不同而已」——与三类分类学的张力消解为「原子 + 约束」：一买 = 本级背驰原子（无附加约束）；二买 = 次级别回调结束点（= 次级别一买原子，定律一明文）+「一买之后」约束；三买 = 次级别回试结束点（= 次级别一买原子）+「不破 ZG/ZD」约束。**确认层统一（买卖原子皆某级别一买=背驰点），分类层互斥（约束条件不同）**——体系「完全互斥分类 + 递归确认」的教义原型：互斥在结构位置层，递归在确认原子层。

**二买双口径并存（053:28 / 057:90）**：构成论（某级别一买）+ 形态论（「次级别上、次级别下，不创新低或盘整背驰」）——形态论定义中「盘整背驰」明文在内，坐实二买确认语义里力度判断是定义级成分。锚定/证书机器两个口径都要能表达。小转大情形（053:28）：该级别无一买时二买为最佳点，此时二买不在「一买后回调」框架内。

## 5. 对 T1「证书太稀疏」理由的修正

T1（cert-bsp-binding-ruling-20260721.md §T1）当年以「密度低 ~300× 不能作独立入场源」为据裁 sidecar 贴标——该理由问错了问题：证书不是信号源、也不要求覆盖全部买卖点；它是**一买族的递归确认机器**。密度差恰证其定义域正确。「证书当门」的语义 = 一买族入场准入；二三类点走锚定路径；两路互斥互补（完全互斥分类题中之义）。
