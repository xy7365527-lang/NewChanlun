## 1. 投影存在性

### 1.1 已证部分

Lean 在父级候选已给定时，证明了父级证书的局部判据（`BspClassification.lean:90`、`BuySellPredicate.lean:159`，父级确认为三类谓词的析取见 `:354`）：

- 一类：破最后中枢且背驰
- 二类：在一类之后，且回抽未再次破中枢
- 三类：离开中枢，第一次回抽不重新进入

### 1.2 关键订正（对原票猜想）

由「完整落在父中枢内」这一几何事实：

- **可排除一类**（无「破中枢」）
- **可排除三类**（无「离开后不回中枢」）
- **不能只凭中枢内几何排除二类** —— 二类本来就要求 `brokeCenter = false`，还必须知道它是否处于**父级一类之后的回抽序列**中

这是本票最重要的单条结论：**「在中枢内部」不足以推出「无父级证书」**，还需要历史条件（是否在父级一类之后）。

一个可检验的无父证条件族是 `brokeCenter = false ∧ leftCenter = false ∧ afterTypeOne = false`——此时一二三类谓词全假。但仓库**没有证明**：

```
W ⊆ [ZD, ZG]  ⟹  (brokeCenter, leftCenter, afterTypeOne) = (0, 0, 0)
```

### 1.3 反例族（条件反例，非闭合定理）

定义 `U(g) = {(c,j) : c ∈ C_{ℓ+1}, j ∈ {1,2,3}, Lift^δ_{j,ℓ}(c,g) = 1}`，取 `g ∈ P^δ_{1,ℓ}` 且 `U(g) = ∅`：则 g 是合法的局部次级别证书，但无父级投影。触发条件 = 对所有 (c,j)，`Host / Nest / Context / Fresh` 至少一项失败。

对「父中枢内震荡」子族，合理候选是 `Host=true, Nest=true, Fresh=true, Context_j=false ∀j`。但 `Context_j` 在 PDF 中未展开、Lean 中无实现，**该实例目前只能写成条件反例，不能冒充已闭合定理**。

## 2. 条件同构：证伪

`缠论的全互斥定义策略.pdf` p.18：

```
ShortDiffEntry(u,γ) ⟺ a_{p(u),t}=1 ∧ δ(γ) = −σ_{p(u)}
ShortDiffExit (u,γ) ⟺ a_{u,t}  =1 ∧ δ(γ) = +σ_{p(u)}
```

题设 `W = [γ_buy, γ_sell]`，方向依次 `+1, −1`。方向性反例：

- 父方向**多头** `σ_p = +1` 时，买点与父同向，**不满足 Entry 的反父方向条件**；正确的多头父短差顺序应是 `[sell, buy]`（卖点开空、买点平空）；
- `[buy, sell]` 只有在父方向**空头** `σ_p = −1` 时，方向上才可能成为「买点开 ShortDiff 多头、卖点平该腿」。

**⟹ 「两端均投影」不是充分条件。**

除方向外还缺七项：两证书属同一 carrier；入场时父声部 active；子槽位为空且证书新鲜、交易可行；未被风险事件或更高优先级动作拦截；子声部在两端间持续 active；中间无父失效/止损/风险平仓/更早的同父向证书；风险投影未改写目标头寸。

Lean 实际开启谓词为 `ParentValid ∧ χ^{−σ_p} ∧ Fresh ∧ F^{eq}`，关闭谓词还含父失效、同父向证书、止损与风险关闭（`SubVoiceOpenClose.lean:113`）。

补齐上述条件且 `σ_p = −1` 时可构造 `[buy, sell]` 短差周期，**但那是加强前提后的定理，不是题设条件本身**。

## 3. 无父级投影时的账本归属

`递归证明.pdf` p.7 定义父级解释器输入 `Γ_t = {(c,g,δ,I) : g ∈ P^δ_{1,ℓ}, I = I^δ_{ℓ+1}(c,g) ≠ ∅}`。

故 `I = ∅` 时：端点**不进入** `Γ_t`；不创建父级 position voice；不触发父级 `O_t / D_t`；父级交易账本不变。

**也不属于父级 `L_t`** —— `L_t` 记录的是「已形成父级候选证书、但被解释器冲突或约束拒绝」的不交易项；而 `I = ∅` 的端点在进入 `Γ_t` **之前**就被排除了。

严格类别应写作：**父级无证书、无 voice transition；事件仅保留为 ℓ 级局部证书 / 局部结构。**

（`级别容器.pdf` p.1–3 佐证：买卖点是转移标签，不是递归持仓节点；持仓节点是带级别、区间、方向、状态的 carrier。）

### 3.1 第二处关键订正

原票关键点拆开后：

- 「父中枢内完成且无 Lift ⟹ 无 ℓ+1 级证书及父级交易事件」——在 `Context` 全假前提下**成立**；
- 「因此不可能成为附着于父声部的 ShortDiff 子腿」——**不能推出**。还取决于父方向、父是否 active、子证书方向与许可门。

角色三分类（`OperationRole18.lean:237`）：`σ_p=0 → Ambient`；`δ_g=σ_p → FollowParent`；`δ_g=−σ_p → ShortDiff`。而「位于父中枢内部」在子声部许可模型中是**正向条件 `Inside`**（`VoiceThreeLevel.lean:162`），不是父级证书。
