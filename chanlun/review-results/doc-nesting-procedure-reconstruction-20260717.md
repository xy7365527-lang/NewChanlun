## 1. 引文逐条

### 1.A 程序本体（定理与操作表述）

027:36：「学过数学分析的，都应该对区间套定理有印象。这种从大级别往下精确找大级别买点的方法，和区间套是一个道理。」

027:44：「推而广之，可以证明缠中说禅精确大转折点寻找程序定理：」

027:44（定理）：「某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。」

027:46（操作表述）：「换言之，某大级别的转折点，**先找到其背驰段**，然后在次级别图里，找出相应背驰段在次级别里的背驰段，将该过程反复进行下去，直到最低级别，相应的转折点就在该级别背驰段确定的范围内。」

chan99§10.6:5：「区间套：就是根据背驰段从高级别向低级别逐级寻找背驰点(即买卖点)的方法。」（二级权威，同文复述）

### 1.B 输入的两种模式

**模式A：背驰力度关系已确认，背驰段仍在走，递归精化终点。**

027:32（万科例）：「从季度图就可以看出，万科跌破3.2元就发出背弛的信号。而实际操作中，光看季度线是不可能找到精确的买点的……因为季度线跌破3.2元后，**这个背驰的成立已经是确认了**，而第三段的走势，从月线、周线、日线等，**可以一直分析下去，找到最精确的背驰点**。」

（数据事实。注意：「确认」的是背驰力度比较关系；「第三段」——即父级背驰段——此时**仍在延伸**，其终点正是向下递归要找的东西。）

**模式B：活假设「进入背驰段」，自带证伪。**

027:332（作业答案后补充）：「方法很简单，例如这次是5分钟的下跌。因此在5分钟**进入背弛段后**，找1分钟相应段的背弛段，再找1分钟背弛段的背弛段，这样就可以精确定位了。」

027:676（回复 asdf）：「关键是先找到大一点级别的背驰段，然后再用小级别的背驰来找精确买点，这才是有用的。像这次大盘，**你首先确定目前已经进入5分钟的背驰段**，然后再按1分钟找买点，这才精确。当然，最好就是在30分钟的背驰段用5分钟找买点，短线这样就比较安全了。」

## 2. 算法重构（从引文到程序的每一步）

以下重构每一步都标注其原文锚点；无任何一步来自二手解读。

### 2.0 签名

```
区间套定位(L0, S0) -> 转折点区间（精确到可达最低级别）
  L0 : 父级别
  S0 : L0 上已进入/已确认的背驰段（进行中，终点未知）
```

### 2.1 前提条件 P（任一不满足则程序根本不适用）

- **P1 有可比较的两段**：围绕某中枢的两段走势方可比较力度（061:26「只要是围绕一中枢的两段走势都可以比较力度」）。纯盘整/中枢震荡延续中不存在转折问题（029:14）。
- **P2 趋势背驰须趋势成立**：A、B 为同级别中枢且 ≥2 个（037:16、027:14）；第一中枢后的「背驰」只是盘整背驰（027:16），盘背的比较对象是第一、三段（027:20）。
- **P3 c 段资格**：c 必然是次级别的、至少包含对 B 的一个第三类买卖点（037:18），且必须创新高/低（037:20；061:28——未创新高的 69 点「并不构成任何背驰」，70 点才「进入真正的背驰危险区」）。
- **P4 级别在概念域内**：背驰段级别须在线段以上，线段以下只有类背驰（065:94）。
- **P5 小转大不适用**：父级根本没进入背驰段时，无父级背驰段可输入，第一类点区间套抓不到（044:16、chan99§10.6:21）。
- 理论前提：走势必完美给出的整体结构是区间套存在的根据（102:26）。

### 2.2 输入 I（核心问题的正面回答）

原文给出两种合法输入模式，**两者都是进行中的背驰段**：

- **模式A（确认后精化）**：背驰力度比较关系已确认（如跌破前低而 MACD 不创新低），但背驰段 c 仍在延伸；递归只为精化 c 的终点。锚：027:32「这个背驰的成立已经是确认了，而第三段的走势……可以一直分析下去，找到最精确的背驰点」。
- **模式B（活假设跟踪）**：背驰段刚刚「进入」（第二中枢后 c 段启动，027:714），背驰关系未确认、可证伪；递归在「没有证据否定背驰之前」逐次进行。锚：061:26、027:188、027:332、027:676。

**两模式的共同内核**：输入 = 「父级背驰段 S0 已启动/进入」，**从不是「S0 已结束」**。推理：程序的目的是确定 S0 的终点（转折点，027:46「转折点就在该级别背驰段确定的范围内」；029:18「找到背驰的精确点，其后就发生反弹」）；若输入预设 S0 已完成，则终点已知，程序沦为空操作。027:162 更明说「背驰段什么时候结束」正是要到次级别图上去判断的事。

### 2.3 递归体 R（第 k 步，k ≥ 1）

输入：级别 L_{k-1} 的背驰段 S_{k-1}（进行中）。

- **R1 取相应段**：在次级别 L_k 图上取 S_{k-1} 的相应走势段（027:46「相应背驰段在次级别里」；027:332「找1分钟相应段的背弛段」）。
- **R2 递归门检查**：该相应段在 L_k 上是否已走出趋势（≥2 个 L_k 中枢）？若只有一个中枢，则「显然不可能构成趋势上的背弛」（027:342）——本步**不终止程序**，而是继续跟踪该段直到第二中枢形成；此级暂无背驰段可套（037:22 标之为「最标准最常见的情况」，即承认有例外）。
- **R3 找 L_k 背驰段**：在通过 R2 的相应段内，按同一套力度比较找出 L_k 的背驰段 S_k。包含关系严格：S_k ⊂ S_{k-1} 且「区间比之小」（027:38）；逐重即「背驰段的背驰段」（061:32）。
- **R4 活检/证伪**：随时检查——
  - E1：若 S_{k-1} 段力度恢复（大于前者），则 S_{k-1}「背驰段不成立」，无背驰，**程序以失败终止**（061:26、043:30）；
  - E2：若 L_k 背驰只造成一个新的 L_{k-1} 中枢而未终结 S_{k-1}，则 S_{k-1} 继续，程序回到对该段的跟踪（027:314）；
  - E3：若发现所谓背驰实为更低级别的背驰（宝钢型误判），则按真实级别重新定位，父级趋势继续（027:136、027:92）。
- **R5 端点共享**：S_k 的终结点 ≈ S_{k-1} 的终结点——精确定位到的就是转折点本身，反弹在其后（029:18；061:32-34 的四重链同顶收尾）。

### 2.4 终止条件 T

- **T1 成功终止**：递归至可达最低级别的背驰段，转折点落在其确定的区间内（027:46）；最深一重可到线段内部笔间定位（类背驰，088:196、065:94）。
- **T2 资源底**：级别有限（027:40），实操上 1 分钟背驰段即足（027:48）。
- **T3 确认终止（事后检验）**：转折点确立后，走势须满足背驰-转折定理的保证——原走势类型终止（029:16），回跌至少重新回到最后中枢（024:46）。**该检验是程序的组成部分**：它把「定位成功」与「父级假设被证伪/级别误判」区分开。
- **T4 失败终止**：E1/E2/E3 任一触发（见 R4）；小转大（E4）是父级假设被跳级证伪的特例（043:34、044:16）。

### 2.5 失败出口与「背了又背」

chan99§10.6:23 把 E1/E2 的活延状态命名为「反复背离（背了又背）」：父级进入背驰段、次级别力度大、父级迟迟无法背驰——「只要没有打破背驰段，就要密切注意」。这正对应程序在模式B 下的持续跟踪态：未证伪前不下结论，证伪即 T4 退出。（二级权威，与 061:26/043:30 相容。）

## 3. 核心判定：程序是否预设父级背驰已经成立？

**判定：不预设。**（数据事实 + 推理）

推理链（每步显式）：

1. 027:46 的程序第一步是「先找到其背驰段」——「找到背驰段」指认的是一个**已启动、未终结**的段；程序输出（转折点）正是该段的终点（027:46、029:18）。若输入预设背驰段已结束，程序目的即被抽空。（推理，锚 027:46/029:18）
2. 原文全部操作表述的输入措辞是「进入背驰段」而非「背驰成立」：027:188「宣告进入背弛段」、027:332「进入背弛段后」、027:676「确定目前已经进入5分钟的背驰段」、027:714「就意味着进入背驰段」。（数据事实）
3. 061:26 给出活假设语义：「都可以先假设是进入背驰段……一旦力度大于前者，那么就可以断定背驰段不成立……在没有证据否定背驰之前，就要观察……这种方法可以逐次下去」。程序**自带证伪出口**——这与「预设已成立」在逻辑上互斥：已成立者无需证伪条款。（数据事实+推理）
4. 唯一的「已确认」用例（027:32 万科）确认的也只是**背驰力度比较关系**，且「第三段」当时仍在延伸、终点待递归精化；且该例是超大级别盘整背驰（027:66 类第一类买点语境）。即模式A 预设的是「力度关系成立」，仍不预设「背驰段已结束」，更不构成对模式B 的否定。（数据事实）
5. 043:30 明文：「这个背驰段并不一定就演化成背驰」；043:34 给出「背驰段最终不成立」的合法形态。若程序预设已成立，这两句无意义。（数据事实）

**由此回答编排者的二选一**：

- 程序**不预设**父级背驰已成立 ⟹ 判别探针（任务A）是程序的必要组成。具体说：探针「父级背驰后价格是否回到最后中枢」正是 T3（024:46/029:16 的定理保证）的机械化；在模式B 实装下它是区分 T3（定位成功，父级背驰真）与 T4（假设证伪/级别误判）的**必要内建步骤**；在模式A 实装下它是 intake 的**必要前置闸**。两种实装口径下都不可缺。
- 同时，「父级未成立」样本须二分：
  - （i）从未满足 P1-P3（从未进入背驰段）者：本不该进链——若实测低产主要由此类构成，「少」有正当性；若 intake 把它们收进来，是 intake 缺陷而非定义苛刻。
  - （ii）曾进入后被证伪（E1/E2/E3）者：进链**合法**（模式B 允许活假设进入），但必须经 T4 退出、不得留下已结算证书——若 pipeline 把此类结算成证书，属结算/装配缺陷。

## 4. 对工程裁定的建议

1. **intake 口径必须显式声明模式**。若 nest 链 intake 采用模式A（只收已确认父背驰），则链中不应出现「父级未成立」样本，出现即 intake 缺陷；若采用模式B（收活假设），则必须同时实装 R4 证伪出口（E1：力度恢复判父级段不成立；E2：子级背驰后父级段继续）与 T3 回中枢检验——未实装证伪出口而把活假设结算成证书，是装配工件，不能归因市场事实，更不能归因定义苛刻。
2. **任务A 探针（回中枢检查）应实装为必经闸**，其原文依据是 024:46 + 029:16（程序自身的 T3），不是外部加严。它能机械化区分：回到过中枢 ⟹ 父级背驰真、其后同向破极值属新结构（市场事实）；未回到而破极值 ⟹ 父级假设证伪或级别误判（061:26/027:136），真背驰段仍在延伸。
3. **递归门（R2，027:342）应实装为链深分类标签**：「次级别相应段未走出≥2 中枢趋势」= 该级本无背驰段可套，链在该级中断属原文允许的形态（037:22「最标准最常见」非必然），应与「该套而未套」（检测聋度）分开计数。
4. **小转大应单列**。父级未进入背驰段而由 1 分钟级背驰引发转折（043:34、044:16）是原文承认的无链转折形态，chan99§10.6:21 明说此类区间套抓不到第一类点——这类转折不产生区间套链是结构性的，不计入欠产。
5. 对「66 张证书、深度≥2 链 0 条」的归因效力：只有当 (a) intake 模式已声明、(b) R2 递归门、R4 证伪出口、T3 回中枢检验均已实装且 (c) 小转大已单列之后，剩余的 0 才可归因市场事实/chan99§10.6:19「第一种最普遍」之张力；此前「少」既无正当性背书，也不能反向定罪定义——本重构把判别所需的原文零件全部备齐。
