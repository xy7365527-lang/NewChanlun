## §1 比较对象：c vs b，唯一且逐字

### 引文

1. **031:883**（答疑，逐字定义性回答）：「盘整背驰一般都是中枢震荡时发生的，而**趋势背驰，是a+A+b+B+c中，cb间的比较**。」
2. **033:26**（中枢角度释义）：「可以从纯粹中枢的角度对背驰给出另外的释义。对a+A+b+B+c，**背驰的大概意思就是c段的力度比b的小了**。那么，站在B这个中枢的角度……所谓顶背驰，就是最后这个中枢，向上离开比向下离开要弱。」
3. **024:22**（MACD 口径的三段定义）：「用MACD 判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，把这三段分别称为A、B、C 段。显然，B 的中枢级别比A、C 里的中枢级别都要大……**A 段之前，一定是和B 同级别或更大级别的一个中枢**……」
4. **024:24**（MACD 判据）：「A、B、C 段在一个大的趋势里，其中A 之前已经有一个中枢，而**B 是这个大趋势的另一个中枢**，这个中枢一般会把MACD 的黄白线（也就是DIFF 和DEA）回拉到0 轴附近。而**C 段的走势类型完成时对应的MACD 柱子面积……比A 段对应的面积要小**，这时候就构成标准的背弛。」
5. **024:28**（人寿实例）：「11日11点30分到15日10点35分构成一个中枢。15日10点35分到16日10点25分构成A 段。16 日10 点25 分到17 日10 点10 分，一个标准的三段构成新的中枢，也相应构成B 段……其后就是C 段的上涨，其对应的MACD 红柱子面积明显小于A 段的。」
6. **027:20**（与盘整背驰的明文区分）：「这里是把第一、三段看成两个走势类型之间的比较，**这和趋势背驰里的情况有点不同**。」
7. **061:26**：「要比较力度，发现背驰，首先要搞清楚是哪两段比较，其实，**只要是围绕一中枢的两段走势都可以比较力度**。」
8. **070:46**（17-38 一分趋势背驰实例）：「在今天的背驰判断中，关键是知道哪一段相比，显然，**27-32与35-38这两段去比**……MACD的红箭头，对应是回抽那一下，对应走势，就是最后一个1分钟中枢形成的时候。」（最后 1 分中枢 = 32-35，070:34）
9. **064:28**（比较对象由中枢决定，错配即否）：「110-111这段，相比较的，是104-105这段，**中间的中枢震荡的中枢，是105到110这个**。因此，这里根本不存在与108-109对比的问题。」
10. **027:14**：「对于背驰来说，肯定不会发生在第一个中枢之后，肯定是至少是第二个中枢之后。」

### 推理链

- 步骤 1：031:883 是直接问答形式的定义句——趋势背驰的比较对 = a+A+b+B+c 记号下的 **c 与 b**。a+A+b+B+c 中 A、B 是两个同级别中枢（037:16），b 是连接两中枢的段（= 进入最后中枢 B 的段），c 是 B 之后的段（= 离开最后中枢的段）。（数据事实）
- 步骤 2：033:26 独立复述同一对象：「c段的力度比b的小了」，并给出中枢力学解释（最后中枢对双向离开回拉相同，弱者必被拉回）。（数据事实）
- 步骤 3：024 课的 A/B/C 命名与 037 课的 a+A+b+B+c 命名是**同一结构的两套记号**：024:22 规定「A 段之前一定有（与 B 同级别或更大的）中枢」，024:24 规定「B 是这个大趋势的另一个中枢」，人寿实例（024:28）中 A 段 = 第一中枢与最后中枢之间的段。故 024 课的「A 段」= 037 课的 b（进入最后中枢的段），024 课的「C 段」= 037 课的 c（离开最后中枢的段），024 课的「B 段」= 最后中枢 B。**「A 段 vs C 段」与「进入段 vs 离开段」是同一对段的两种叫法，不是两种口径**。（数据事实）
- 步骤 4：与相邻概念的边界由原文自划：第一、三段比较 = 盘整背驰（027:20 明文「这和趋势背驰里的情况有点不同」）；围绕任一中枢的相邻两段都可比较力度（061:26），趋势背驰取其中围绕**最后**中枢的那一对（070:46、064:28 两实例逐字演示配对选择）；第一个中枢之后的「背驰」不是趋势背驰（027:14/16）。
- 步骤 5：把「A 段」读成**趋势首段 a**（a+A+b+B+c 的 a）与 024:22 明文冲突（024 课的 A 段之前一定有中枢；趋势首段 a 之前没有该趋势的中枢）；原文无任何一处把 c 与趋势首段比较。该读法判定为误读。（数据事实）

**判定（问 1）：比较对象唯一——c vs b（最后中枢离开段 vs 进入段）。「最后中枢的进入段 vs 离开段」与（024 课记号的）「A 段 vs C 段」同物；「第一、三段」属盘整背驰口径；「c vs 趋势首段 a」无原文支持。**

## §2 前提合取：趋势 ∧ c 次级别含三买 ∧ c 破极值

### 引文

11. **037:16**：「没有趋势，没有背驰，不是任何a+A+b+B+c形式的都有背驰的。当说a+A+b+B+c中有背驰时，首先要a+A+b+B+c是一个趋势。而一个趋势，就意味着A、B是同级别的中枢……」
12. **037:18**：「其次，**c必然是次级别的，也就是说，c至少包含对B的一个第三类买卖点**，否则，就可以看成是B中枢的小级别波动，完全可以用盘整背驰来处理。而b是有可能小于次级别的……也就是说，b在级别上是不能大于c的。」
13. **037:20**：「还有，如果a+A+b+B+c是上涨，**c一定要创出新高**；a+A+b+B+c是下跌，c一定要创出新低。否则，就算c包含B的第三类买卖点，也可以对围绕B的次级别震荡用盘整背驰的方式进行判断。」
14. **061:28**：「因为**背驰如果没有创新高，是不存在的**。所以，只有等70点出现时，大盘才进入真正的背驰危险区。」
15. **051:314**（答疑）：「B当然要出现第三类买点，否则B就没结束，都是围绕B的震荡，用盘整背驰就足以。」
16. **037:22**：「对c的内部进行分析，由于c包含B的第三类买卖点，则c至少包含两个次级别中枢……就可以继续套用a+A+b+B+c的形式进行次级别分析确定c中内部结构里次级别趋势的背驰问题，形成类似区间套的状态。」

### 推理链

- 步骤 1：037 课给出趋势背驰的四个必要条件：趋势（A、B 同级别，037:16）；c 次级别且含 B 的三买（037:18，051:314 重申——无三买则 B 未结束，只能按盘整背驰处理）；c 创新高/低（037:20，061:28 同文）；b 级别 ≤ c 级别（037:18）。四者是**合取**：037:20 明说缺「创新高」则降格为盘整背驰处理，037:18 明说缺「三买」则「完全可以用盘整背驰来处理」——缺一即改变对象类别，不是可选项。（数据事实）
- 步骤 2：「c 创新高/低」的参照是**趋势的前高/前低**（b 段的极值区域），而非仅最后中枢的 ZG/ZD：061:28 的实例语义是「没创新高则背驰不存在」，037:20 的否则条款把「未创新高的破中枢」归入盘整背驰——二者都表明破中枢边沿是**弱于**原文条件的。（数据事实）
- 步骤 3：「c 含三买」意味着 C 段作为次级别走势类型内部已有「离开 B + 次级别回拉不重回 B」结构（037:22 推得 c 至少两个次级别中枢）——这是 B 已结束、c 不是 B 的震荡的结构性证据。（数据事实）

**判定（问 1 补）：比较对象之外，原文给定一组 AND 连接的必要条件：趋势（≥2 同级中枢）∧ c 次级别含 B 三买 ∧ c 创趋势新高/低 ∧ b 级别 ≤ c。任何工程谓词缺其中一项，都不是「另一合法口径」，而是对另一个对象（盘整背驰或中枢震荡）的判定。**

## §3 力度度量：定义唯一、口径多元，MACD 面积是辅助 proxy

### 引文

17. **015:38**：「首先定义一个概念，称为缠中说禅趋势力度：前一"吻"的结束与后一"吻"开始由短线均线与长期均线相交所形成的面积。在前后两个同向趋势中,当缠中说禅趋势力度比上一次缠中说禅趋势力度要弱，就形成"背驰"。」
18. **015:42**：「缠中说禅趋势平均力度：当下与前一"吻"的结束时短线均线与长期均线形成的面积除以时间。」
19. **024:14**：「详细说说MACD 对背弛的辅助判断这样一种**不绝对精确**，但比较方便，容易理解的方法。」
20. **024:50**：「由于MACD 本身的局限性，要精确地判断背驰与盘整背驰，还是要从中枢本身出发……光用MACD 辅助判断……其准确率也应该在90%以上。而配合上中枢，那是100%绝对的，因为这可以用纯数学的推理逻辑地证明。」
21. **017:248/250**：「用均线或MACD看背驰都是**辅助性**的，都不是最重要的」「难道没有均线、没有MACD就判断不了背驰？显然不是。那只是辅助。」
22. **040:34**（答疑：不用 MACD 如何判断）：「看均线系统也行，短期均线与长期均线的面积比较就可以。**还有很多方法，道理都一样**。」
23. **025:38**：「最后，开始继续突破第二个中枢，MACD的黄白线以及柱子都再次重复前面的过程，但这次，**黄白线不能创新高，或者柱子的面积或者伸长的高度能不能突破新高（注：1黄白线2柱子面积3柱子高度）**，出现背驰，这就结束了这一个两个中枢的上涨过程。」
24. **027:32**（万科例）：「回抽0轴的黄白线再次下跌不创新低，而且柱子的面积是明显小于第1段的，一般来说，**只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准了**。」
25. **028:488**（答疑：趋势平均力度指标）：「MACD就可以了，一般人没必要用本ID那个指标，那东西是精确，但用起来很麻烦，还要自己编指标……还不如直接用MACD，准确率差点，但只要结合好中枢、背驰，95%以上是一点问题没有的。」
26. **064:393-395**（答疑：有没有更严格的方法）：「可以很严格的数学方法去确认，但太复杂，实用起来很麻烦，还要自己去编软件。**MACD只是辅助**，但用好了，98%的问题都解决了，足够实用了。」
27. **050:18**：「MACD只是力度比较的辅助，因此，是**先定好比较哪两段走势，然后才去选择看是1分钟的还是30分钟的更适宜辅助判断**……不能因此而改变先根据中枢与走势运动的分析，然后选出需要比较力度的走势段，最后才用MACD辅助判断的顺序原则。」

MACD 口径的内部条件（合取）：

28. **025:761**：「**用MACD判断背驰首先要有黄白线对0轴的回拉，这个都没有，在该级别就不存在什么背驰**，其他级别要相应去看了。」
29. **025:296**：「不是柱子缩短就是背驰……**因为背弛首先需要的是回拉0轴的黄白线**。」
30. **025:339/345**：「背驰需要多少个条件？光柱子缩短就背驰？前面的黄白线有回拉0轴吗？」「各位一定要把MACD判断背驰的几个条件综合起来，不能光看柱子就完事。」
31. **024:28**（面积预估）：「看MACD 柱子的面积不需要全出来，一般柱子伸长的力度变慢时，把已经出现的面积乘2，就可以当成是该段的面积。所以，实际操作中根本不用回跌后才发现背驰。」

### 推理链

- 步骤 1：定义层，背驰 = 走势力度衰竭（015:38），比较对象 = c 与 b（§1）。**「力度」本身是定义层原语，原文从未给它唯一的计算公式**。（数据事实）
- 步骤 2：度量层，原文先后给出并并列认可至少四个口径：均线面积/时间（015:38/42、040:34）、MACD 柱子面积（024:24）、MACD 黄白线新高与否（025:38）、MACD 柱子伸长高度（025:38）、以及缠师自制「精确但麻烦」的严格指标（028:488、064:393-395）。040:34「还有很多方法，道理都一样」是开放性承认。（数据事实）
- 步骤 3：MACD 的地位被原文反复压低到「辅助」：024:14「不绝对精确」、024:50「90%…配合上中枢100%」、017:250「那只是辅助」、050:18「力度比较的辅助」、064:395「MACD只是辅助」。故 **「MACD 面积 = 背驰定义」不成立；「MACD 面积 = 原文最常用、最明示的合法 proxy」成立**。（数据事实）
- 步骤 4：即使在 MACD 口径内部，原文给的也不是单一面积判据，而是合取式：黄白线回拉 0 轴为前提（025:761/296/339/345），面积、黄白线、高度三信号以「或者」并列（025:38），且「只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准了」（027:32）。即原文的 MACD 口径 = **回拉0轴 ∧ （面积 ∨ 黄白线 ∨ 高度）**，比「仅面积」宽在信号层、严在前提层。（数据事实）
- 步骤 5：多 proxy 并用不会破坏原文一致性——025:38 的「或者」与 027:32 的「其中一个符合就可以」表明原文在信号层接受 OR-组合；040:34 表明 proxy 族开放。推论：**工程上「MACD 面积唯一化」是一个窄化约定（合法但非教义），「多 proxy 支配序」是原文「还有很多方法」的合法实例化；两者之间的分歧属口径分歧，本身合法**。（口径产物）
- 步骤 6：050:18 的顺序原则（先定两段→再选度量）排除了「以 MACD 形态反推比较对象」的做法；064:28 是违反该顺序的反例演示（比较对象由中枢定，不由 MACD 图形方便定）。（数据事实）

**判定（问 2）：力度的定义唯一（走势力度衰竭），度量原文容许多口径；MACD 面积是合法 proxy 之一而非定义，其完整口径为「黄白线回拉0轴 ∧ （面积 ∨ 黄白线 ∨ 高度）」。故：两工程谓词在度量层同为 MACD 面积 Σ|hist|，属同一合法 proxy，不构成教义分歧；但若以「MACD 面积是原文指定的唯一定义」为由否定其他 proxy（黄白线、均线面积、多 proxy 支配序），则该主张违反原文（024:14/50、017:250、040:34）。**

## §4 「确认」需要的事件：c 完成 + 活假设证伪机制，不等事后回中枢

### 引文

32. **061:26**：「在实际操作中，65开始的走势，由于没实际走出来，所以在和55-60比较时，都可以**先假设是进入背驰段**。而当走势实际走出来，**一旦力度大于前者，那么就可以断定背驰段不成立**，也就不会出现背驰。在没有证据否定背驰之前，就要观察……其内部结构中的背驰情况，这种方法可以逐次下去，这就是区间套的定位方法，这种方法，可以在当下精确地定位走势的转折点。」

### 推理链

- 步骤 1：原文的「确认」不是单一事件，而是两层结构的合成：
  - **信号层（可预判、可证伪）**：c 行进中即可按活假设处理（061:26），面积可 ×2 预估（024:28），「不用回跌后才发现背驰」；当 c 创出极值且力度弱于 b 时，「背驰的成立已经是确认了」（027:32）。证伪通道常开：c 力度反超 b，则「断定背驰段不成立」（061:26），或小级别延伸使大级别摆脱背驰（043:30）。
  - **定位层（精确点）**：c 的完成点由区间套精确定位（029:18、027:46、037:22），该点即第一类买卖点（027:66）；c 完成的结构判据是「这段的结构被破坏」（064:28）/c 内部次级别背驰（037:22）。
- 步骤 2：回跌回中枢（024:46）与转折定理（029:16）是**背驰成立后的定理保证**，用于事后验证与最弱情形分类（029:52），原文从未把它列为确认背驰的**前提事件**；相反 025:126/477 明文「一定不能等什么确认」，044:32「只要在顶背驰时直接全部卖出就可以」。把「回到最后中枢」设为确认前提会使卖点延迟到定理兑现之后，与原文操作语句直接冲突。（数据事实）
- 步骤 3：因此「确认」在原文的精确内容是：**c 完成（结构被破坏/区间套定位到次级别背驰）∧ 完成时 力度(c) < 力度(b) 仍成立**。在此之前的所有判断都是活假设（可交易，025:126；可证伪，061:26）；在此之后的是定理后果（024:46、029:16）。（推理：步骤 1-2 合取）
- 步骤 4：对「背驰级别 < 走势级别」的小转大情形，原文另给必要条件（最后次级别中枢出三卖/三买，044:20-28）且明说「只有必要条件，而没有充分条件」（044:30）——该情形不在本报告主问题（同级趋势背驰谓词）内，但提示「确认谓词」不可跨情形复用。（数据事实）

**判定（问 3）：确认 = c 完成且力度(c)<力度(b) 保持；确认事件 = c 结构被破坏（等价地，区间套定位到 c 内部次级别背驰点）。在此之前是活假设（原文允许凭其交易，且要求证伪通道常开）；在此之后（回中枢等）是定理后果，原文明确反对将其用作确认前提。**

1. **教义层唯一谓词已给出（本报告总判定）**：比较对象 c vs b 唯一，前提合取唯一（趋势 ∧ 三买 ∧ 破极值），力度度量口径多元但须声明。**754 对分歧不能整体判为「合法多口径」**：两侧在度量层恰好同口径（都是 MACD 面积），分歧全部落在前提合取项覆盖与工程性附加门上。

3. **可机械执行的逐案对审程序**（建议，供后续探针）：对 754 个案例逐一检查全合取——(i) Trend 块 ≥2 中枢；(ii) c 包络破 b 包络极值（037:20）；(iii) c 内含对 B 的三买（037:18）；(iv) 黄白线回拉 0 轴（025:761）；(v) MACD 面积 c<b。全合取成立而 BSP 无点 ⟹ BSP 聋（anchor 门或取段差异）；全合取不成立而 D2 确认 ⟹ D2 宽。两类归属都能落到具体合取项上，无需引入教义外判据。
4. **力度口径的声明制**：MACD 面积继续作默认 proxy 合教义（024:24），但须补黄白线回拉 0 轴前提方为 025:761 意义下的完整 MACD 口径；多 proxy（`ForceFeatures` 5 维，divergence.rs:311-323）属 040:34「还有很多方法」的合法实例化——度量层的后续扩张合法，不构成对 D2/BSP 既有分歧的教义裁判。**反对以「MACD 面积是原文定义」为由把其他 proxy 判为违规**（违反 024:14/50、017:250、040:34）。
