# 跳空处理·原文规则调研（完全分类原则下的缺口归类）

## 背景

adopt_v1 落地后剩余 33 个 Unassigned 孤儿，其中跳空（成因桶=跳空）为最大子桶。用户裁决：完全分类是硬性正确性原则，Unassigned 只能是过渡态账本，不能是终态；且缠师原文明确给过跳空处理规则。本调研回原文语料取证。

## 原文证据（verbatim）

1. chan99/0046-第二十五节 具体走势的分析.md:85
   「缺口，被看成最低级别的，而1分钟以下级别，在 1分钟图上，被看成没有内部结构的线段，所以缺口和 1分钟以下级别在1分钟图上是同级别的。」
   —— 缺口 = 合法线段（无内部结构），并且同课 :93 让缺口段直接参与盘整背驰力度对比（B段 vs 缺口段）。:171 亦确认「一个线段，除非是缺口，否则必须由至少上-下-上或下-上-下的三折组成」——缺口是线段三折要求的唯一豁免。

2. blog/028-第28课.md:308
   「跳空的级别是无限低的，不构成任何中枢中的一段。这和分解定理没有什么矛盾的。」
   blog/028-第28课.md:746
   「这不必然是趋势，任何走势类型都可能，最极端的就是跳空缺口后形成新的"缠中说禅走势中枢"；其次，也不一定是次级别的，只要是次级别以下，例如跳空缺口，就属于最低级别」
   blog/028-第28课.md:754
   「连续的涨停只构成1分钟中枢的上移，而缺口是比1分钟还低的级别。其间连5分钟的中枢都不能形成。」
   —— 两同级别中枢之间的连接段可以是"次级别以下"，跳空是合法连接段；次级别下限检查对跳空不适用。

3. blog/036-第36课.md:34
   「围绕中枢的震荡，不一定都是次级别的……甚至是一个跳空缺口……无论怎么跳，最终都要形成更大级别的，只要不脱离这日线中枢，最后都至少会形成30分钟级别的走势。任何围绕日线级别的震荡，最终都必然可以按如下方式进行分解：A30-1+A30-2+A30-3+…+A30-m30+a」
   —— 结合性保证：中枢震荡内的跳空最终必被更大级别走势吸收，不存在"永久无归属"。

4. blog/036-第36课.md:128–131（新股开盘）
   「就把开盘前算跳空缺口上涨，和有缺口的情况是一样的」
   —— 序列起点/开盘缺口同样按跳空规则处理，与种子窗口（seed window）孤儿直接相关。

5. blog/057-第57课.md:28,32（与 chan99/0046 同文重述）
   「01段是跳空缺口……都可以看成是没有内部结构的线段」「其中下一段是跳空缺口，但无论如何，这就是一个线段」

## 裁决含义

- 完全分类原则下，跳空的正确终态归类 = **级别无限低的合法连接段/线段**，永远不应落 Unassigned。
- 我们分类器把「连接段须满足次级别/重叠」当硬条件，与 blog/028:308、:746 直接冲突 —— 这是跳空桶孤儿的根因（规则缺失，非数据噪声）。
- 修复方向（gap-connector 规则）：
  1. 跳空段免除三折与次级别检查（chan99/0046:171 豁免条款）；
  2. 作为连接段归属：两同级别结构之间的跳空按连接段并入分解链（blog/028:746）；
  3. 中枢震荡内：按结合性并入围绕该中枢的更大级别走势分解（blog/036:34）；
  4. 序列起点缺口按 blog/036:128–131 视同跳空上涨/下跌处理（覆盖种子窗口子桶）。
- 与账本约束的关系：以上全部只**新增归属**（ADOPT_ORPHAN 通道），不释放已有归属，满足单调性/append-only；与 adopt_v1 兼容，可作为 adopt_v2 增量规则。
