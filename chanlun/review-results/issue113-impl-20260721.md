# #113 出场门消费多级投影 — 实现报告 (2026-07-21)

## 摘要

出场门（`ExitNestGateCtx.reverse_admit`）从固定键 `typed_lookup` 切换为多级投影
`typed_lookup_multi`，与 #112 进场门 admit 的多级路径对齐。旧固定路径降级为
**comparison-only cross readout**（只计数、不参与决策）。判定依据仍仅为
`n_delta`（禁第二查法）；门关路径零行为变化（gate-closed bit-exact）。

- 依据：#113 ticket、#109 SPEC 验收标准、`chanlun/review-results/issue112-impl-20260721.md`

## 变更点

### `rust/src/theta_v0/backtest/runner.rs` — `ExitNestGateCtx`
- `reverse_admit` 主路径改为 `gate.typed_lookup_multi(...)`：命中集取**最深级别**
  证书，仅以其 `n_delta` 做出场放行判定（无第二查法）。
- 旧 `typed_lookup` 固定键结果保留为 cross readout：与 multi 结果比对后仅累加
  `cross_agree` / `cross_v0_pass_typed_rej` / `v0_rej_typed_pass` 及
  `single_multi_divergence` 计数，不影响决策。
- `ExitNestGateStats` 扩展：按级别 `level_hits`（`typed_hit_levels`）、
  `single_multi_divergence`；`NEST_GATE_EXIT` 报告行输出 path/total/admitted/
  rejected/typed_found/typed_none/flat_dir/admit_runs/rej_runs/cross_agree
  等字段（沿用既有格式，追加 multi 维度）。

### `rust/src/theta_v0/backtest/admission.rs` — `NestChainGate`
- 出场侧统一走 `has_bridge_key_multi` / `typed_lookup_multi`（`by_end_multi`
  与 `by_end` 在 `absorb_exts` 同点增量维护，O(1) 前置判据）。
- 固定键 `has_bridge_key` 自此无调用方（#112 进场 + #113 出场均已切换）：
  标注 `#[allow(dead_code)]` 并注明退役原因（固定键为 multi 键域子集，
  保留作域包含关系文档）。

## TDD 测试（先红后绿，镜像 #112 四类）

新增 5 个（`runner.rs` tests，前缀 `exit_gate_`）：

1. `exit_gate_reverse_admit_consumes_deeper_multi_level_hit` — 多级命中：
   深层级证书被消费，出场按其 `n_delta` 放行；`level_hits` 记入对应级别。
2. `exit_gate_reverse_admit_multi_miss_rejects` — 多级查无：无证书 ⟹ 出场
   抑制（`typed_none` 计数，reverse exit suppressed without cert）。
3. `exit_gate_reverse_admit_multi_causal_guard` — 因果守卫：证书终点不满足
   因果序（未来信息）不可被消费。
4. `exit_gate_reverse_admit_multi_coexists_with_fixed` — 共存：multi 决策与
   固定键 cross readout 同 bar 共存，分歧仅计入 `single_multi_divergence`，
   决策由 multi 独占。
5. `exit_gate_stats_observe_overlay_counts` — 统计口径：overlay 计数与
   `NEST_GATE_EXIT` 报告行字段一致。
