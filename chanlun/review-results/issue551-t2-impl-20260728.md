## 二、设计决策

### 1. 结构门拆为单一来源（`signal::first_structural_gates`）

第一类的三道结构门（`direction` / `extreme` / `comparable`）从 `judge_first_cached` 内联短路
中提出为一等结构。`judge_first_cached` 改为消费它并保持「三门全成立才产点」的收缩语义 —— 摘要
`16618955402698307653` 未动，debug/release 双跑同签名，bit-exact 已证。

候选事件产出改读**同一个门**，因此 `StructuralPredicates` 三项不再恒真。这满足 audit §6「不复读、
只共享更上游单一来源」：不是新造第二套判据，是把既有判据的分量暴露出来。

### 2. 四态映射（Trend 域）

`comparable ∧ extreme` ⟹ `Provisional`；任一不成立 ⟹ `Unresolved`。

`direction` 恒 `true` 是**结构必然**而非占位：门不成立时 `first_structural_gates` 返回 `None`，
`CandidateKey` 的 `seg_a`/`c_start` 根本没有来源，候选身份不存在。凡入簿事件此项必真。

严格性论证：`Unresolved` 不是「另一类候选」，而是**同一个 key 在其生命史中的未决阶段**。因为
C 右端不入键，037:20 的「同 episode 递延」（`signal` 侧同名测试）保证破核心腿与破极值腿共享
同一 key —— 于是 U→P 是身份不变的状态转移，`Provisional` 集合与 #550 口径**逐字段一致**，
候选定义未被扩张。

### 3. 力度不进候选由约定升为编译期约束

`observations_for_level` 入参删去 `hist`/`dif`/`closes_tick`/`gauge`：候选产出在**类型层**够不到
MACD 序列。`close_src` 保留，仅用于 `comparable` 的坐标可映射性判定（不读价格、不算面积）。

### 4. 同 episode 归约（本票发现的真缺陷）

同一 key 可由同一 episode 内的多条同向腿各产一次门结果。它们是同一候选在**同一时刻**的多份
证据，不是时间序列。#550 路径逐条喂事件簿，导致同 as_of 重跑时靠前的短区间被误判为**区间回缩
→ Invalidated**，US8 幂等被破（本票 TDD 中先红暴露）。

修复口径（`merge_episode_leg`）：
- `interval` 右端取最新腿 —— I(C) = [λ_C, 当前 episode 最新同向段端点]（Q5 区间口径）；
- `extreme` 取**析取** —— 037:20 判的是 I(C) 包络破 b 包络，而「I(C) 包络首次破 ⟺ 某同向段端点
  首次越界」（`signal` 函数头等价性注记），故 episode 内任一腿破极值即整个 I(C) 已破，该事实不
  因后续腿端点回撤而消失；
- `comparable` 取最新腿 —— 可比较性由当前 I(C) 区间决定；
- `first_provable_at` 取**首个**使全谓词成立的腿的结构位。

### 5. `first_provable_at: usize → Option<usize>`

未决期不落钟（禁提前写），首次全谓词成立时一次写入，后续即使退回 `Unresolved` 也不抹去。
这是 #535 红线②「禁未来回填 first_provable_at」的机器载体 —— 旧的非 Option 类型在 Unresolved
上线后会被迫写入一个「尚不可证的可证时刻」，那是伪造。

### 6. `CandidateKey.rule_version`

规则版本变 ⟹ 全体 key 变 ⟹ 旧 key 走既有消失路径判终态、新 key 从 ∅ 起。落实 E2E-O
「规则版本变 → 新 key，禁复活旧 key」。值 1 = #550 结构宽候选口径 + #551 四态全谱映射。

### 7. 空 L0 早退补 `advance`

`classify_with_tower_incremental` 在 `l0_units.is_empty()` 早退且不推进事件簿 —— 本 bar 消失的
候选被推迟到下一个非空 bar 才判失效。**延迟非无痕**：失效钟落到错误的 as_of，且其间已消失的
候选仍挂 active。这是 #535 红线③「丢 Invalidated 路径」的时序变体，本票修掉。修法是对保留下来
的因果簿走一次 `advance(&[], as_of)`，即既有单一路径，不新增判据。

### 8. 增量 memo 判据仍充分

候选观察的输入（centers / blocks / segments / anchors / close_src）是 bsp 输入的**真子集**，
故 `bsp_key` 不变 ⟹ 候选输入不变 ⟹ 候选不变。既有 `cached_candidate_key` memo 保持保守正确。

## 五、矛盾上浮 —— **已裁决：甲（编排者 2026-07-28）**

> 本节保留完整生成史（命题、两个可观测面、三条出路对照表）—— 谱系不因结论落地而删除。
> 裁决结论与落地载体见本节末「裁决段」。

### 命题

**E2E-O 的终态语义是历史相关的；fresh-full 的语义是历史无关的。裁定(i) 要求二者在每 key
最新 revision 上逐字段相等 ⟺ 要求终态语义历史无关。二者不可同时成立。**

### 两个可观测面（同源）

**面 A — 终态载荷冻结（生产可达）**：Pan 域候选一入簿即 `Confirmed`（#550 决策：把
`judge_pan_div` 证书投影为确认候选）。终态不改写 ⟹ 其 C 段区间冻结在确认时刻；而
`PanDivCert.seg_c` 此后仍随 bar 推进而变，fresh-full 对同 key 重判得到**当前**区间。
BTC 100k 实测：`payload_differ=25`、`fork_causal_only=34`，且 `payload_differ_live=0`、
`fork_causal_only_terminal=34/34` —— **差异 100% 落在终态候选上，活假设域零差异**。

**面 B — 上游塌空后回长（机制可达，生产未触发）**：上游塌空使候选身份消失 ⟹ 因果簿判
`Invalidated`（E2E-O 正确）；数据回长到**逐字段相同**的结构后，fresh-full 重新产出同一个 key
⟹ 裁定(i) 明令禁止的**复活型分叉**。锁在
`escalated_upstream_regrowth_after_collapse_revival_fork_metered`
（上浮期原名带 `forbidden` 字样，甲口径裁决后经收口批 `4a60f3e53f` 改名；旧名全文见该 commit 正文，登记见 §十.3）。
BTC 100k `invalidations=0` ⟹ 该分叉当前生产不可达。

### 三条出路与各自代价

| 出路 | 做法 | 代价 |
|------|------|------|
| **甲** 收缩裁定(i) 口径 | 等价锁只在**非终态**候选上要求逐字段相等；终态域的分叉作为 E2E-O 的定义后果接受并计量 | 裁定(i) 原文「每 key 最新 revision 集合逐字段相等」需修订；已实测该收缩版无条件成立 |
| **乙** 改 Pan 域状态映射 | Pan 首入判 `Provisional`（活假设），留 `Confirmed` 给真正的终局条件 | 需要一个本票范围外的终局判据（E2E-D4，SPEC Out of Scope）；#550 已落地并经 #554 影子终审 PASS 的决策被推翻；golden 与电池计数大幅翻转 |
| **丙** key 补「上游代次」分量 | 塌空即代次 +1 ⟹ 回长后是新 key，面 B 消解 | fresh-full 无状态、算不出代次 ⟹ 两侧 key 集合不可比 ⟹ 投影等价锁**全面**失效；且不解决面 A |

**实装侧倾向（仅供参考，不代行裁决）**：甲。它是唯一不推翻既有结算、不破坏等价锁本身、
且已被实测支持（`payload_differ_live=0`）的选项；乙的正确性取决于 D4 落地后对「终局」的定义，
属 N3+ 依赖序。

### 裁决段（编排者 2026-07-28：出路 = 甲）

**裁定(i) 修订后的正式文本**（与生产 doc `classify_with_tower_events` 函数头逐字一致）：

1. **非终态域逐字段相等，无条件**——因果簿中状态为 `Provisional`/`Unresolved` 的每个 key，
   fresh-full 侧必须存在同 key 且业务载荷逐字段相等。这一条是无条件断言，不允许任何豁免。
2. **终态域分叉 = E2E-O 终态语义历史相关的定义后果，接受并计量**——`Confirmed`/`Invalidated`
   的 key 上，因果簿与 fresh-full 的载荷差异、以及 key 集合差异（含复活型分叉）不再是违规，
   而是定义后果。对它们只**计量**（数出来、报出来、写清口径），**不再作无条件相等/禁止断言**。

修订的成因（一句话）：终态候选的载荷在终态时刻**冻结**，而其上游证书仍随 bar 推进而变，
fresh-full 无状态、按当前结构重判 —— 历史相关语义与历史无关语义在终态域必然分叉；原文
「每 key 最新 revision 逐字段相等」等价于要求终态语义历史无关，与 E2E-O 不可同时成立。

**乙/丙未被采纳的理由**（代价引自上表，不新增论证）：
- **乙（Pan 首入判 `Provisional`）**：需要一个本票范围外的终局判据（E2E-D4，SPEC 明列 Out of
  Scope）；且会推翻 #550 已落地、经 #554 影子终审 PASS 的状态映射决策，golden 与电池计数大幅
  翻转。即「用一个尚不存在的判据去换一个已结算决策」。
- **丙（key 补「上游代次」分量）**：fresh-full 无状态、算不出代次 ⟹ 两侧 key 集合不可比 ⟹
  投影等价锁**全面**失效（连非终态域也锁不住）；且它只消解面 B，对面 A（终态载荷冻结）无效。

**落地载体**（本切片）：

  `terminal_equal`/`terminal_differ`/`terminal_absent_in_fresh`。非真空三重前提：

### §十.1 `merged` 纯函数化（`c553ecbad6`）

### §十.2 Projection 归一（`3c053353e5`）

### §十.6 ∅→Invalidated 禁止边补机器锁（`cea839011a`）

原 `event_probe::on_append` 里有两个静默空分支 `{}`（∅→Invalidated、活候选→Invalidated）：既不计数也不拒绝
⟹ 该边一旦被走到，「从未发生」与「发生过但没人看见」不可区分。补两层锁：入口硬失败 + 探针 `unreachable!`，
并加两枚 `#[should_panic]` 测试（`--nocapture` 确认 panic 点均为入口锁本体 `cand_event.rs:458`，非探针 `unreachable!`）。

**范围限制（如实登记）**：入口锁是**运行期 panic**（`CandidateEventBook::advance` 首行调
`reject_unobservable_invalidation`，`assert!(observation.state != Invalidated)`），**不是编译期不可达**。
严格形式是给观察侧另立一个不含 `Invalidated` 变体的状态类型 —— 那会改到 `mod.rs` 等构造点，
**超出该切片授权，未做**。当前形式的诚实读法：该边在类型层**仍可表达**，只是在运行期被当场拒绝。

**该切片发现的更强事实（登记）**：`make_revision` **硬编码** `invalidated_at: None`（`cand_event.rs:513`）。
故一条 `state = Invalidated` 的观察若被放行，落簿的是「**终态但没有失效钟**」的畸形事件；
又因 `CandidateState::is_terminal()` 为真，该 key 的后续全部修订被**永久挡回**（禁复活）⟹
**畸形态当场钉死、不可修复**。这条推导链是入口锁必须是硬失败（而非记一笔继续）的根据：
`Invalidated` 的唯一合法构造点是 `invalidate()`（写 `invalidated_at`、递增 `revision`、要求 `prior` 存在），
失效是**事件簿对既有 revision 的判决**，不是外部观察的输入。

### §十.7 电池 bin `timestamp` 改显式错误（`90bda5b93d`）

`fn timestamp(date: &str) -> i64` 末尾的 `.unwrap_or(0)` 把解析失败静默伪装成纪元时间戳 ⟹
日期串损坏时 Bar 带着看似有效的时间戳进分类器，错误既不报也不可见。
改为 `-> Result<i64, String>`，错误沿本文件已有的 `Result<_, String>` 路径 `?` 传播
（`timestamp → raw_bar → raw_to_bars → load → run`），全链无 unwrap/expect/unwrap_or 兜回。
文件内残留两处 `unwrap_or` 与错误路径无关且不吞错（volume 缺失取 0.0 的 `Option` 缺省；`max_bars` 命令行省略取默认，其 parse 错误早已 `map_err` 传播）。
