## 裁定一：身份与窗口（判同桥）

- 身份 = **（中枢四条边快照, departure move 索引）**。四条边 = ZG/ZD 上下沿 + 起止两条时间边（补充十三）。
- 快照在注册时拍摄，称**临时右边**：候选判案专用（回抽回没回这个框，价格只对该框 ZG/ZD）。
- 活着期间窗口不动——行情物理保证：候选活着 ⟹ 价格在中枢外 ⟹ 中枢无延伸，左右侧均无新料子。
- 结局三分：
  - **Success → 快照转正**：临时右边成为中枢永恒右边；Success 事件即**中枢死亡证明**，发中枢账（Broken）。
    死亡证明开具时间 = 落锤知情时；中枢右边缘 = 快照右边（两个时间，不混）。
  - **重回 → 快照作废**：中枢延续（延伸/扩张/新生归中枢账管）；下一代候选按延展后的新窗口重新拍照。
  - **引擎改口**（重基/重切致窗口变或中枢消失）→ **处死记档进警报桶**（CenterRebased，对标补充十三题二
    RebaseVanished 先例）。不静默容忍、不桥接——判据锚的框没了，证的指向对象就没了。
- 中枢本体生灭归中枢生命周期账（补充十四出口三分），本账不跟踪。

## 裁定二：多 departure 并存

- **同一中枢同时刻至多一个活跃候选。** 严格相邻（retest = leave+1）物理保证：新 departure 出现时旧候选
  必已判完；未判完而来新 departure = provider 有病 → **报错拒收**（fail-loud）。
- 不同中枢各有活跃候选，天然并存（per-key 账本天然形状）。
- 历史身份全部留档不删。
- 教义背书：补充十五紧邻语义「任一失败即 None，禁止后扫替代配对」（等下次 = 永不）——一身份一次机会；
  新离开 = 新档，不是替旧档补考。

## 裁定三：终态映射

- **三态：Provisional（未决）/ Confirmed（成立）/ NotConstituted{reason}（从未成立族）**。
- 判败 = `NotConstituted{RetestReentered}`，契约写死四行语义：
  1. 候选从未成立（第一次回抽资格一次性，已消费，020:62）；
  2. 中枢未破坏（018:64 定理三逆否、101:76「依然没有被破坏，因为第三类卖点没出现」）；
  3. 不派生任何中枢生命周期事件（补充十四：延伸无事件）；
  4. 判败事件是**盘背观测源**（027:16 盘整背驰技术含义），归观测/短差通道，非终结非信号。
- 引擎改口 = `NotConstituted{CenterRebased}`：身份灭失、非破坏、记工程警报桶。与竞选失败同族
  （三类点从未成立）不同行，语义分开写。
- 终态后同身份迟到输入：**静默吸收 + 警报计数**（不炸管道；显著非零查 provider，RebaseVanished 哲学）。
- 残废输入（leave 未出中枢/回抽同向/不紧邻/missing）= **注册期拒收报错**，是错误不是终态。
- Restart = 新身份注册（Provisional），谱系载荷记前任身份；不走桥迁移（桥是同身份换键，本账快照不换键）。
- 先例：nest 终态吸收；nest `NeverConstituted` 与「曾构成后被推翻」严格互补；Cp `RetestReentersB`
  只读不改生命周期。

## 裁定四：restart 规则（Success 后）

- **Success 后同一中枢永禁新轮**——中枢已被杀死（裁定一），补充十三：死后任意时刻对旧价格带的穿越
  不构成旧中枢的三类点信号。现行自动机 `restart_allowed=false` 方向正确。
- 新中枢（含收编者大中枢）的新离开 = 新身份新档，合法（裁定二）。
- provider 给死中枢报新 departure = **报错拒收**（「给死人挂号」，账本自存死亡证明，内部可查，fail-loud）。
- 区分：同身份迟到输入（幂等问题，裁定三静默吸收）≠ 死中枢新注册（逻辑错误，本条报错）。

## 裁定五：钟体系

- **三钟**：
  - **出生钟**（registered_as_of）：注册知情时，首写永不改；
  - **落锤钟**（terminal_as_of）：判决知情时，首写永不改；Success 时即死亡证明开具时间；
  - **门卫钟**（last_as_of）：随推进前移，专查时间倒退（内核倒退拒绝纪律）。
- 每条修订自带知情时（as_of）。
- **位置进证据载荷，不是钟**：三类点位置 = 回抽笔终点；离开的边 = leave 笔终点。消费方画图定位用。
- **知情时 ≠ 位置**：回抽周二到最低点、引擎周四才确认走完——位置标周二，账本只说周四知道。
  回测不用未来信息，靠知情时保证。
- 单调：per-identity as_of 非降，违反 = 拒收 + 警报；引擎改口不算倒退，按裁定一处死。

## 裁定六：持久化/恢复

- **唯一真相 = append-only 修订日志**（只追加、不可篡改；谱系学原则）。
- **状态 = 日志折叠**；active/consumed/restart_allowed 是投影，重放即得，不单独持久化
  （日志+状态双真相必漂移，禁止）。
- 快照仅作**派生缓存**：带溯源（折叠到第 N 条）、重启校验、对不上扔掉重放；永非真相。
- 拒收/警报另记 audit 流（append-only），不进真相恢复路径（它们不改状态）。
- 日志按 run/窗口分界，头部带 provenance（窗口 + 数据基）；不承诺跨窗口身份连续。
- 先例：CompletedFreezeReducer（JSONL 正式边界只追加、replay 幂等、冲突拒绝）。

## 裁定七：身份缺席

- **缺席 ≠ 消失**。沉默 = 未决（等回抽那笔走完），是正常 pending；**永不设超时处死**
  （= 发明教义外终结，踩补充十四红线）。
- 消失仅两条显式路径：**判决**（成功/重回，行情亲口）/ **引擎改口**（观察显式携带窗口变/中枢无）。
  不许从「没消息」推断。
- 不需要 nest 的 IdentityVanished 二分（真推翻/接缝）——缺席不杀人，消失无分类。
- prefix 重放一致性白捡：状态 = 日志折叠，截到哪是哪，截口未决即未决。

## 裁定八：消费门户（三态三操作）

- **未决 → 备战档**：候选位置 + 快照端给下游**盯梢**——盯回抽的次级别回切入点（024:36：次级别一类点
  回补 = 该级别三类买点，真实入场发生在判完前）。名义 = 「盯这里」**不是**「买这里」；扳机是次级别
  结构，不在本账。**禁区：备战档不许被消费成买入信号。**
- **成功 → 成立档**：① 中枢死亡证明（不问迟到——054:60 延迟合法、#583 在案，死亡证明照开）；
  ② 交易层「三类点成立」+ 全套证据（知情时 + 位置）。迟到三类点的交易过滤归交易层自理（#587），
  本账不进口外部状态。
- **判败 → 短差档**：盘背通道（027:16 盘整背驰；#588 通道归属：观测不终结）——亚型签 + 三锁
  （键唯一/一一对应去重/账平断言，#606 S1 先例）；024:36/024:46 短差语义（上沿减/下沿补，
  campaign 同构）；已入场者失败处置通知（名义 = 通知非信号）。
- **总禁区**：账本不进口外部状态做消费过滤。
- 消费方登记归 #575（无消费方不接生产，防 built-but-unwired）。

## 对 T1 #573 内核定形的含义（双消费方）

四组泛型参数现有第二实例：

- **key**：nest 六元组 / 本账（四条边快照, departure 索引）——均需等值 + 序；
- **观察**：nest PanLive/Event / 本账（严格相邻 pair, outcome, 当前中枢窗口, as_of）；
- **转移策略**：nest 三态业务条件 / 本账三态 + 判据（回判、改口、残废拒收）；
- **原因载荷**：nest ForceOvertake/NeverConstituted/… / 本账 NotConstituted{RetestReentered|CenterRebased}
  + 证据（新旧窗口、位置、知情时）。

内核共享件按 #573 票面：per-key 注册/首建/append-only/倒退拒绝/终态吸收/钟首写/增量返回/迁移留史
（本账不用）/只读枚举/不变量骨架。
