## 研究问题

## 一、44课小转大原文证据路径

### 1.1 博客原版（`docs/chanlun/text/blog/044-第44课.md`）

**问题定义**（:14）：
> 有了上一课，对"背驰级别等于当下的走势级别"这最一般的情况，应该是很好把握了，唯一可能出现困难
> 的，就是"背驰级别小于当下的走势级别"这种情况，也就是所谓的小级别转折引发大级别转折。

**例子设定**（:16）：向上30分钟级别 a+A+b+B+c，c 是1分钟级别背驰，最终引发下跌拉回B里。

**中间级必须非空这一构造要求**（:18）——这是全篇与 chain_cert 数据形态最直接对应的一句：
> 首先，c 至少要包含一个5分钟的中枢，否则，中枢B就不可能完成，因为这样不可能形成一个第三类的买点。

**核心定理**（:22-26，"缠中说禅小背驰-大转折定理"）：
> 小级别顶背驰引发大级别向下的**必要条件**是该级别走势的最后一个次级别中枢出现第三类卖点；
> 小级别底背驰引发大级别向上的必要条件是该级别走势的最后一个次级别中枢出现第三类买点。

**必要非充分，明文强调两次**（:28,30）：
> 关于这种情况，只有必要条件，而没有充分条件……小级别顶背驰后，最后一个次级别中枢出现第三类卖点
> 并不一定就必然导致大级别的转折。

**操作细节示例**（:36-44）：30分钟操作者对5分钟回调的容忍范围、突破/不突破前次级别3买高点的判断、
全仓 vs 部分仓位（"打短差"）两种处理。

**"娇注"（本仓库既往批注，非原文）中的可操作特征清单**（:52,54-60）——这是全文库中对"小转大"识别
特征给出最具体候选项的段落：

> (娇：小转大实盘注意点1 本级别或者次级别中枢反向突破；2 次级别中枢出现3买卖；3 本级别3买转2卖，
> 3卖转2买；4 调整或者反抽的位置超过正常最后个次级别走势的的位置到达第二个中枢GGDD——形成同分3
> 买卖的高低点从而扩展大中枢前走势类型结束。）

> 注意点1：小级别背驰引发大级别转折可以转2级，转3级，转4级.....原理相同……
> 注意点2：这个该级别走势最后个次级别中枢是**动态的**，不一定为小级别背驰点前的中枢。

注意点2（"动态"）对识别假设很关键：不能假设"跳过点前最近的次级别中枢"就是判定对象，该中枢本身
会随走势演化改变身份。

### 1.2 编纂版对照（`docs/chanlun/text/chan99/0019-第七节 转折的力度与级别.md`）

44课博客版对应的是编纂版《教科书》第二章第七节，而非同编号章节——编纂版按"动力学"体系重排，
44课内容被并入更大的框架。编纂版给出三条定理构成的完整体系（:5-11）：

1. **趋势转折定律**：上涨转折=某级别第一类卖点；下跌转折=第一类买点。
2. **背驰-转折定理**：某级别趋势背驰将导致"该趋势最后一个走势中枢的级别扩展、该级别更大级别的
   盘整、或该级别以上级别的反趋势"——**三分类**（博客版44课未给出这个上位框架）。
3. **小背驰-大转折定理**：措辞与博客版几乎一致，"走势中枢"替代"中枢"，更严谨。

编纂版额外给出的、博客版没有的关键区分（:65-75）：

> **1、背驰级别等于当下的走势级别**……**2、背驰级别小于当下的走势级别**……这两种情况，对走势的
> 分解也是很有意义的……前后两个走势类型，就以该背驰点为分界；至于小级别背驰引发大级别转折的情况，
> 这种情况比较复杂，但分解的原则是一致的，就是走势类型分解原则。

编纂版的**分解判例**（:77）直接对应 chain_cert 的"skip 边"结构：a+A+b+B+c 中 c 出现1分钟背驰，
演化出30分钟中枢 C；若 C 和 B 不重叠 ⟹ 原走势未完成，延伸为 a+A+b+B+c+C；若 C 和 B 重叠 ⟹
（B+c+C）演化为日线中枢，a+A+b+B+c 只是日线走势类型的一部分——**这正是"该级别是否真的跳过"的
判据来源**：重叠与否，是几何可判定的量，与 chain_cert 的 `predicate_holds`（`C⊆C`）同构。

**结论**：编纂版比博客版多了"背驰-转折定理"三分类框架和分解判例，博客版多了具体操作细节和"娇注"
的可操作特征清单。两版对核心定理（必要非充分）的措辞高度一致，无实质冲突。

### 1.3 相邻课的角色（27/32/61/67/102课）

| **67课**（线段的划分标准） | 纯技术定义（特征序列、标准特征序列），是笔→线段→中枢递归体系的基础设施，与小转大关系最远。 |
| **102课**（再说走势必完美） | 给出**级别递归的完整分解式** a1A1+a5A5+a30A30（:38），强调"任何高级别的改变都必须先从低级别开始"——这是44课"小级别背驰逐步积累导致大级别转折"（chan99 0019:61）的深层理论基础：级别扩展不能跳过下层直接发生，必须经过下层的实际走势构造。 |

## 二、#636 双源研究：收敛面 vs 未覆盖面

### 2.1 收敛面（双源独立收敛同一答案）

据 #636 编排 session 核定评论（2026-07-29）：「本 session 独立调研（27/61/67/102课线）与裁定所引
研究（32/44课线）**独立收敛同一答案**」，即：

- **skip 边合法性判据 = `C⊆C` 谓词在存活端点间直接判定**（32课"要有对应关系，就必须满足区间套
  关系"的工程化，032:227 原文引用经核实无误）。
- **证伪节点不应连坐判死全链**——中间节点证伪时，链的死活由谓词裁，不由该节点裁。修订依据引用
  027:32（"背驰就是背驰，没有什么假背驰"）+ 102:428 + 061:28,32 + 067:236 等案例群，共同指向
  "识别错误 ≠ 结构本身失效"这一原则，从而 supersede 了原型"任一必需节点失效则谱系转 Invalidated"
  的连坐语义。

两条线（32/44 与 27/61/67/102）**论证路径不同、结论一致**：前者从"区间套关系是链段有效性的
充要判据"直接推出 skip 边判定规则；后者从"背驰判断本身可能出错，不能让识别层错误连坐结构层"
推出证伪节点不判死上级。二者互相独立、互相印证，未见冲突。

### 2.2 未覆盖面（明确留 fog）

**44课小转大证据路径本身**——#636 裁定③原文：「44课小转大证据路径留 fog（另票另裁，不进 N3）」；
#641 关票记录复述同一登记。具体缺口：

1. **"次级别中枢出现第三类买卖点"这一必要条件从未被实装为可检验的数据形态**。chain_cert 模块
   文档明确自述（mod.rs:64-67）：「44课'小转大'的替代必要条件（次级别中枢第三类买卖点）证据路径
   由 #636 裁定③明确留 fog，skip 边因此不携带任何替代证据——它只是'这里跳了一级 + 跳过处的事实
   计数'，比44课教义门槛宽」。也就是说，**当前 skip 边判定比44课定理宽松**：44课要求跳过处的
   次级别有一个完成的第三类买卖点结构，而 chain_cert 只要求跳过处几何上"套不住"（`断`）即放行
   skip 边，不检验该级别是否真的构成了完整的中枢+第三类买卖点。
2. **floor 完整口径**（E2E-L `CloseFloor_at` 三型：`FormalFloor`/`QuasiFloor`/`UnresolvedFloor`）
   同样留 fog（#641 取舍裁定第5条），与44课小转大在"到底应该允许跳到哪一级"这一问题上可能有耦合
   （地板条款目前只落地了"至少一条有效链段"这一格，未涉及"必须降到 L0/L1 才能 Close"）。
3. **"缺"与"断"两分格已实装，但未与44课的"次级别中枢是否完成"做交叉验证**。BTC 三窗实测（#641
   收口记录）skip 成因全部是"断"（`skipped_level_missing = 0`）——这只证明"跳过处该级别有候选
   存在"，不证明"该候选本身构成了完整的中枢+第三类买卖点"（44课的实际门槛）。二者被本任务视为
   同一件事的证据强度尚未核实，是本报告识别假设部分的主要着力点。

## 四、识别假设清单（区分裸跳过 vs 小转大式跳过）

以下每条假设标注：(a) 教义依据、(b) 现有数据是否可直接检验、(c) 若不可直接检验，需要的额外插桩。

### 假设 1：`inside_parent` 状态本身是初筛信号，但不是充分识别特征

- **内容**：`断-在父内接不上`（该级别有候选、落在父区间内、但套不住子端点）比`断-在父外`（该级候选
  整个落在父区间外）更接近44课"c至少要包含一个5分钟的中枢"的构造要求——至少说明该中间级别的候选
  几何上与父级"共存"而非"无关"。`断-在父外`更像候选属于完全不同的走势脉络（更接近"裸跳过"直觉：
  中间级别虽有候选事件产生，但与本次跳级的走势无实质关系）。
- **教义依据**：044:18（"c 至少要包含一个5分钟的中枢，否则中枢B就不可能完成"）+ chan99 0019:77
  的重叠判据（C 和 B 是否重叠决定分解方式）。
- **可检验性**：**可直接检验，数据已存在**。`ChainBookSummary::skipped_level_broken_inside` /
  `broken_outside` 已分别计数（三窗读数见上表：300k 为 96 vs 73，接近但不等——`inside` 略多，
  初步方向与假设一致但不足以下判定，因为两者未见显著分离）。
- **局限（须明示）**：`inside_parent` 只是几何共存的粗筛，不涉及该中间级候选自身是否构成过完整的
  中枢+第三类买卖点结构（44课的实际门槛）。仅凭这一个特征不能区分"小转大"与"该级别候选恰好几何
  上部分重叠但结构上不成立"这两种情况。

### 假设 2：`crossed_nodes` 的证伪时序——"曾经 Alive 后来 Falsified" vs "从未出现"

- **内容**：44课"注意点2"明确"最后一个次级别中枢是动态的"——意味着小转大过程中，判定对象本身
  会经历状态演化（曾经构成一个完整走势类型，后来因为上级几何扩展而被重新框定/吞并）。若跳过处
  的中间级候选在其生命史中**曾经**达到 `Confirmed` 态（即真的完成过一个次级别走势类型），比起
  该候选从一开始就没有被观测到（`Absent`）或从未 `Confirmed` 过就直接被证伪，前者更接近"小转大"，
  后者更接近"裸跳过"（该级别从未真正构造出对应结构）。
- **教义依据**：044:58"最后个次级别中枢是动态的，不一定为小级别背驰点前的中枢"；chan99 0019:47
  （下跌+盘整必须是两个**完成的**走势类型的连接，区别于中枢扩展这种未完成延续）。
- **可检验性**：**不可直接检验，需要额外插桩**。`AliveIndex::build`（mod.rs:434）只取每个
  `CandidateKey` 的**最新** revision（"取最新 revision 而非全史"，mod.rs:426），当前实现不追踪
  某候选是否曾经历过 `Confirmed` 态后又被证伪/替换。需要在 `ChainNodeTrace` 旁另开一路，对
  `crossed_nodes` 涉及的每个 key 回查 `CandidateStreams` 的全历史（数据已存在于事件流里，只是
  chain_cert 当前视图未读取）。

### 假设 3：跳过方向与几何超界方向的一致性（`PredicateBreachReason` 分布）

- **内容**：44课定理方向性明确——顶背驰引发向下、底背驰引发向上，且"必要条件是次级别中枢出现
  第三类卖/买点"，第三类买卖点本身有方向（突破中枢后回抽不回到中枢内）。若跳过发生在**谓词判过**
  的 skip 边上（当前三窗实测全部如此），超界方向这个字段实际不产生（`breach` 只在判不过时才有
  值）。但若把"谓词判过"的临界情形也纳入观察——即候选区间恰好压线套住父区间的那些 skip 边，
  其几何重叠程度（左右端点相对父区间的松紧）是否呈现方向性偏移，可能是比"缺/断"更细的信号。
- **教义依据**：044:22-26 定理本身的方向性表述。
- **可检验性**：**部分可检验，需扩展现有字段**。当前 `ChainEdge` 只存 `predicate_holds: bool`，
  判过的边不留几何余量（多"松"或多"紧"）。需要在链段（非事实边）上也记录端点区间相对位置，
  当前实现为节省载荷刻意不做（`breach` 恒 `None` 于 `predicate_holds == true` 时，mod.rs:265-269）。

### 假设 4：跳过级数与"至少含一个次级别中枢"的最小构造要求

- **内容**：44课举例全部至少跳两级（30分钟→1分钟，中间隔5分钟），且强调中间必须"至少包含一个
  中枢"（即中间级别不能是单一走势段，必须有中枢完成的痕迹——中枢需要至少3段次级别走势重叠，
  chan99 0019:43 的数量核算）。可以假设：`skipped_levels.len() >= 2`（多级同时跳）且这些级别
  全部落在"断"而非"缺"这一档，比单级跳（`skipped_levels.len() == 1`）更接近44课"小转大"的最小
  构造门槛——因为单级跳缺少"中间级别本身需要完成一个中枢"这一层复杂度，更像是几何上简单的边界
  未对齐。
- **教义依据**：044:18 + chan99 0019:43（中枢的最小段数核算）。
- **可检验性**：**可直接检验，数据已存在**。三窗路径形态（§5.4）显示路径长度上限为3（即最多
  只观察到跳1级的情形，`path.len()` 恒为2或3），**当前 BTC 实测数据本身不支持多级跳这一假设的
  验证**——需要更大窗口或不同标的数据才能观察到 `skipped_levels.len() >= 2` 的实例。此为本报告
  发现的一个数据覆盖面缺口，应在待裁问题中登记。

### 假设 5：skip 边在链路径中的位置（靠近 root 还是靠近 leaf）

- **内容**：44课的"小转大"是小级别（链的 leaf 端，背驰发生处）驱动大级别（链的 root 端，被拉回
  的中枢）的转折。若 skip 边系统性地更多出现在链路径的**leaf 附近**（小级别与其直接父级之间），
  而非 root 附近（大级别与次大级别之间），这与44课"小背驰"驱动的方向性一致；反之若均匀分布或
  更多出现在 root 附近，则更可能是通用的几何噪声（识别层误差累积、粒度不匹配等），与44课特定
  教义关系较弱。
- **教义依据**：044:16 的例子结构本身（c 是最小级别、背驰发生处；B 是被拉回的大级别中枢）。
- **可检验性**：**可直接检验，数据已存在但当前报告未做此切分**。`ChainEdge` 在 `edges` 向量中
  按 root→leaf 顺序排列，`skip_edges` 相对路径位置（首条边 vs 末条边）可从现有簿数据直接统计，
  无需改动数据结构，只是 #641 现有读数未按此维度切分。

### 假设可检验性小结

| 假设 | 现有数据可测 | 需要额外插桩 |

## 五、待裁问题清单（供 #686）

1. **44课必要条件是否需要实装为独立合取项**：当前 skip 边判定（`C⊆C` 谓词判过即放行）明显宽于
   44课字面要求（次级别中枢+第三类买卖点）。是否需要在链段判定之外，另加一层"44课式严格 skip"
   标注（不改变现有 Closed/Invalidated 判定，只作诊断标注），还是维持现状、教义门槛差异留给
   消费端自行判断？
2. **若要实装，五条假设里选哪几条、成本如何**：假设2、3需要新增数据追踪（候选历史 revision、
   链段几何余量），假设1、5可用现有数据立即统计但证据强度较弱。是否值得为假设2、3的插桩买单，
   还是先用假设1、5做一版低成本的初筛统计，看是否已能观察到有意义的分离？
3. **裸跳过与小转大式跳过在教义地位上是否需要不同判定权重**：即使能建立识别特征，是否应该在
   N3层（chain_cert）区分二者对 Closed/Invalidated 的影响，还是维持"skip 边只留痕、不判优劣"
   的现状，把区分完全留给 N4/N7 消费端？
4. **"全断零缺"这一实测结果的教义含义**：BTC 三窗 `skipped_level_missing` 恒为 0，即观察到的
   全部 skip 都至少满足"该级别有候选存在"这一弱化条件。这是否已经**排除了"裸跳过"在当前数据集
   上的存在**（因为"缺"对应的正是"中间级别真无对应结构"这一裸跳过的字面定义）？如果是，那么本票
   的研究问题在 BTC 三窗范围内可能是空集问题——需要先确认"缺"与"裸跳过"是否等价，再决定是否需要
   跨标的/更大窗口复测以找到"缺"的实例。
5. **floor 完整口径与44课小转大的耦合**：`CloseFloor_at` 三型的完整实装（尤其"必须降到 L0/L1 才能
   Close"这类地板要求）是否应该与44课的次级别中枢门槛一并裁定，还是两者互相独立、分开处理？
