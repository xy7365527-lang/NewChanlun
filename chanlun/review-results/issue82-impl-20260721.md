## 2. 候选枚举规则定稿（#80 裁定 §边界）

T2 锚定「某级别」候选枚举（`descend_type2_anchor_depth`）：

1. **严格链优先**：`descend_type1_anchor_depth`（ℓ−1 对齐 + 同步共振深度延伸）命中即返——旧门已收案例结果逐 bit 保持（`Some(d)` 深度语义不变）。
2. **逐级向下枚举**（严格链未命中）：frontier BFS，先 ℓ−1，再 ℓ−2…；同级候选按 `end_index` **降序**（离锚定 bar 最近者优先 =「向左最近」），首个 `div_cand` 背驰确认者中。
3. **因果性**：`end_index > source_index` 的候选出锚定 bar 因果前缀，排除（禁未来函数）。
4. **教义约束**：候选必须是一类点（`div_cand` 背驰确认），枚举不降低确认语义。
5. **禁第二查法**：段结构取自塔既有 `sub_moves` 次级别序列，力度判据复用 `div_cand` 同一机器（不新造分段/力度引擎）。
6. **返回**：`Some(d)` = 首个确认级别 ℓ′=ℓ−d；`None` = 父走势区间内任何级别无一类点 = 小转大域。

## 3. 形态论口径定稿（#81 裁定）

`type2_anchor_verdict(s, source_index, delta, hist)` 返回 `Type2AnchorVerdict`：

- **构成论列**（`construct_verdict`）：调 `descend_type2_anchor_depth`（#80 某级别枚举，单一来源）。
- **形态论列**（`morph_verdict: Type2MorphVerdict`）：
  - **骨架定位**：在 `s.sub_moves` 中找回抽段（`end_index==source_index` ∧ 方向=−δ）+ 前序 +δ 段（次级别上/下）+ 前序 −δ 段（前低/前高）。
  - **分支 A**（`branch_a_no_new_extreme`）：纯价格比较（Long→`curr.lo() > prev.lo()` / Short→`curr.hi() < prev.hi()`）。**签名不收 hist**（构造证明：类型层面不可能触达力度机器，#81 §边界「不得给它强加背驰前置」）。
  - **分支 B**（`branch_b_pan_divergence`）：复用 `segments_diverge`（`segment_macd_area` + `is_divergence`，同一冻结原语，禁第二套力度引擎）。
  - `confirmed()` = 骨架 ∧（分支 A ∨ 分支 B）。
- **并集**：`accepted()` = 构成论 Some ∨ 形态论 confirmed。
- **小转大标记**：`is_xiaozhuanda_morph()` = 构成论 None ∧ 形态论 confirmed（053:28）。
- **双登记**：两列各自独立登记，`accepted()` 取并集，**禁静默择一**（谱系学保留）。
