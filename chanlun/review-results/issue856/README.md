**统计口径**（`docs/agents/stat-provenance.md`）：**全样本终态描述统计**，不是预注册假设检验，
不做 walk-forward、不做多重比较校正。ED 是一条**全称命题**，故「找到反例」这件事不需要显著性；
下方的两比例检验只用来支撑另一条附加断言（Ext 与非 Ext 的占优率无差异）。
