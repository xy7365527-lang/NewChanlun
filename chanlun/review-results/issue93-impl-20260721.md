## 2. 根因与修复机制

### 根因链（实装卡 §2.2）
1. **指纹自溃（第一根因）**：gate 持有 tower Rc（`derived: Vec<(Option<Rc>, Option<Rc>)>`）⟹ classifier 端 `Rc::make_mut(&mut cache.moves_tower_l0)` strong_count>1 ⟹ 每 bar COW 新分配 ⟹ tower[0] Rc 指针逐 bar 变 ⟹ `ptr_eq` 恒失效 ⟹ level-1 逐 bar 全级重派生 O(n²)。
2. **COW 本身 O(n²)**：每 bar 全 Vec 克隆。
3. **重派生全前缀扫描**：O(prefix)/bar × 逐 bar = O(n²)。
4. **seen 计数口径放大**：派生即计（含未确认/重复）⟹ events_seen=166M。

### 步骤 0 修复（本报告范围）
- `derived` 字段不再持有 Rc ⟹ classifier `make_mut` 恢复 strong_count==1 原地 O(tail) ⟹ **根因①②同时消除**。
- 值指纹 = `(w_self, w_lower, tail_self, tail_lower)`：水线 `tower_confirmed_len` 证书保 `[..w]` 跨 bar bit-stable ⟹ 只比 `[w..]` 尾段（`LeveledMove: PartialEq`，O(未确认尾段) = O(1) 摊还）。
- 判定形态复刻 `forest_dirty_l0`（classifier/mod.rs:1583-1595，逐值比对 tail 先例）。
- 水线回退（clear/血缘断裂）⟹ 保守全量重派生（恒正确退化）。
- 构造性 bit-exact 论证（§3.1 步骤 0 四条）：塔内容不变 ⟹ ①provider 全部结构输入逐字节同；②confirm 扫描域不变 ⟹ confirm_t 不变；③hist/dif 前缀 append-only 逐位稳定；④pan 候选枚举同 ⟹ 派生事件集逐字节同 ⟹ 跳过 = 账本逐字节不变。

### 步骤 1（未实装，见 §7 未决项）
步骤 0 已达验收线（§4-5），步骤 1（三证书冻结）的边际收益在步骤 0 后大幅收窄——步骤 0 已将 derivations 从 O(n²) 降至 O(5k)（300k bar），进一步冻结 confirmed/终假 run 的边际收益需 T0 测量评估。
