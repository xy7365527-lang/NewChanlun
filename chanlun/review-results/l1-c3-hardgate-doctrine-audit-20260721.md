## 〇 一句话结论

**L1 的 C3 硬门是"教义指导下的工程裁定"，不是教义字面要求的硬性规范。** 第43课要求的是"小转大转折的确认语义包含新中枢+突破方向"——但教义原文没有说必须用硬门（过滤式）实现，而非诊断字段（标注式）实现。codex #44 选择硬门是有教义洞察的工程决策（防"确认退化成存在"），但放开到 C2-only 在教义上**不存在硬性障碍**——代价是确认口径变宽，需要另设防线。

## 一 codex #44 原始裁定

### 1.1 文件位置

`.chanlun/review-results/codex-decide-20260702-193853-5bbe.md`

（注意：项目中存在两个"#44"。另一个 `c-producer-review-44-20260623.md` 是 hook 复核，与 C3 无关。）

### 1.2 裁定决策

> **决策**：选 **(c)**。C3 重新设计为 `level==1` 专用的"背驰后新中枢 + 反向突破"**硬门**；`level>=2` 维持既定 C2-only，不纳入本次翻案。

对应 `gate_pass()` 规格（裁定 `:247-250`）：

```rust
pub(super) fn gate_pass(&self) -> bool {
    self.type2_confirmed && (self.level != 1 || self.c3_new_center_breakout_ok)
}
```

### 1.3 "必须加 C3" 还是 "可以加 C3"？

**codex #44 给的是"L1 必须加 C3"——是硬门，不是可选项。**

裁定拒绝了两个替代方案：

| 方案 | 内容 | 拒绝理由 |
|------|------|---------|
| (a) 弱化 C3 | C3 弱化为 `same_side_causal_ok` | "把 C3 空心化成'同侧 Type3 存在'，丢掉中枢对象和突破方向" |
| (b) C2-only 终态 | C3 永久只做诊断字段 | "C2-only 可作为临时基线，但永久化等于放弃第43课和044/039对'中枢形成后突破'的结构确认，且会让'确认'退化成'存在'" |

### 1.4 教义依据（裁定引用的原文）

裁定引用了以下教义锚点：

- **第43课** `043:34`："这第二种情况，**必然要先形成一个比1分钟级别要大的中枢，然后向下突破**"
- **第43课** `043:38`："形成一个比1分钟大的中枢后，**并不必然回跌，可以往上突破**"——突破方向才是判据
- **第44课注** `044:52`：四点实盘注意点，第1点"中枢反向突破"
- **思维导图定理128**："小转大的**必要条件**——该级别走势的最后一个次级别中枢出现第三类买卖点"

裁定的核心推理（`:254-256`）：

> 第43课语义不是"Type3 的 center 必须等于某条预选 last_zs"，而是"小级别背驰后先形成更大中枢，再看突破方向"。

## 三 第43课博文原文教义分析

### 3.1 文件位置

`docs/chanlun/text/blog/043-第43课.md`（321 行，标题：「有关背驰的补习课」，2007-04-06）

### 3.2 核心分类：两种转折方式

第43课的核心框架是区分**背驰级别与走势级别的关系**决定的两种转折：

**第一种：背驰级别 = 走势级别**（`:28-30`）

> 一个30分钟的走势类型，出现一个30分钟级别的背驰，那么这个背驰至少把走势拉向该30分钟走势最后一个中枢，当然就会跌破或升破相应的高点或低点。

→ 回跌是**必然的**。

**第二种：背驰级别 < 走势级别**（`:34`）——即"小转大"

> 这第二种情况，**必然要先形成一个比1分钟级别要大的中枢，然后向下突破**，最终形成回跌到B中的走势。

→ 回跌不是必然的，但**如果回跌发生，形式必然是"新中枢+突破"**。

### 3.3 "必然"修饰的是什么？

关键段落（`:38`）：

> 在形成一个比1分钟大的中枢后，**并不必然回跌，可以往上突破**，使得 a+A+b+B+c 继续延伸。

**教义原文的"必然"修饰的是转折的形式（如果转折发生，其形态必然包含新中枢+突破），不是判定的操作（你必须检查C3才能确认信号）。**

原文甚至明确说"可以往上突破"——即新中枢形成后突破方向不确定，这意味着 C3（反向突破）本身不是必然发生的。

### 3.4 第43课是否提到"C3/第三类买卖点"？

**没有。** 第43课全文没有出现"第三类买卖点"或"C3"这一术语。

C3（第三类买卖点）的概念来自第20-21课。第43课讨论的是背驰后转折的结构形态，其逻辑隐含在新中枢是否突破原中枢区间的操作规则中（`:194`）：

> 这种情况，如果不破前期高点，那只是一个新中枢，所以当然持有，如果破了，那就一定要走。

### 3.5 教义原文的确切语义

| 教义要点 | 原文依据 | 语义 |
|---------|---------|------|
| 小转大的转折形式 | `043:34` | "必然先形成更大中枢然后突破"——这是转折**如果发生**的结构描述 |
| 突破方向不确定 | `043:38` | "并不必然回跌，可以往上突破"——C3（反向突破）不是必然事件 |
| 操作规则 | `043:194` | "破了就走，不破就持有"——判断点在"是否突破前高" |
| 分解原则 | `043:44-48` | 更大中枢出现 ⟹ 走势级别升级——不是"过滤掉"，而是"重新分解" |

## 四 综合裁定：教义要求 vs 工程选择

### 4.1 教义要求了什么？

第43课教义确实要求：**小转大场景下（背驰级别<走势级别，对应 L1），转折的确认需要观察新中枢形成后的突破方向。**

这一点是教义硬约束——你不能只看到小级别背驰就确认转折，还需要看到新中枢+突破的结构证据。

### 4.2 教义没有要求什么？

教义**没有**要求：

1. **必须用硬门（过滤式）实现**——教义说的是"确认语义"，你可以用硬门过滤（C3 不过就不算 XZD），也可以用诊断字段标注（C3 不过仍算 XZD 但标注"未确认转折"）。两种实现在教义上等价，区别在消费侧语义。

2. **每个级别都判 C3**——第43课区分了两种转折方式，C3 的实质意义仅在"小转大"（第二种情况）中。对于背驰级别=走势级别（第一种情况），回跌是必然的，C3 无额外判别力。L1 对应"小转大"场景，所以 C3 有教义意义；L2+ 是否对应"小转大"取决于具体走势结构，不是级别硬绑定。

3. **C3 的具体口径**——原文说的是"中枢形成后的突破方向"，没有定义 ZG/ZD 突破 vs GG/DD 突破的精确口径。现行 `c3_new_center_breakout_ok` 用 ZG/ZD 是工程选择（codex #44 裁定原文边界条件）。

### 4.3 codex #44 的论证链

```
第43课教义：小转大的确认 = 新中枢 + 突破方向
    ↓ （语义映射）
L1 的 XZD 确认 = C2（二类买卖点）∧ C3（新中枢+反向突破）
    ↓ （实现选择）
C3 必须是硬门（不是诊断字段）
```

第一步（教义→语义映射）有教义依据。

第二步（语义→硬门实现）是**工程裁定**——codex #44 的理由是"防止确认退化成存在"。这个理由有教义洞察（缠论的"确认"确实比"存在"要求更多结构证据），但博文原文没有说"必须用过滤式而非标注式"。

### 4.4 如果放开到 C2-only，教义上有障碍吗？

**教义上没有硬性障碍，但有两个软性约束：**

1. **"确认退化成存在"的风险**（codex #44 的论证）：C2-only 的 XZD 确认不包含新中枢+突破的结构证据，在教义上等同于"背驰存在"而非"转折确认"。这在缠论语义上是口径变宽——不是错的，但确认标准降低了。

2. **操作规则的缺失**（第43课 `:194`）：缠师的操作规则是"破了就走，不破就持有"。如果 C3 不参门，相当于不执行"破了就走"的判断——在教义上等于放弃了这个操作纪律。

**结论**：放开到 C2-only 在教义上**可行**（不违反任何博文原文的硬性规范），但需要：
- C3 保留为诊断字段（当前已是如此）
- 消费侧（交易决策层）自行决定是否消费 C3
- 明确承认确认口径变宽（从"转折确认"降级为"背驰存在+二类买卖点"）

## 七 开放问题（供后续裁定参考）

1. **L1 滤除率 91.7% 是否合理？** 第43课的"小转大"是特定场景，不是所有 L1 背驰都是小转大。如果 91.7% 的 L1 候选不满足 C3，可能意味着大量 L1 背驰本就不是"小转大"场景——C3 硬门在正确地过滤，也可能在过度过滤。

2. **C3 的 ZG/ZD 口径是否足够？** codex #44 自己说"GG/DD 属 C4，不混入本判据"。但第43课原文的操作规则（`:194`）说的是"破前期高点"——更接近 GG/DD 而非 ZG/ZD。

3. **"确认退化成存在"是否可用其他方式补偿？** 如果 C3 退为诊断字段但消费侧（交易决策层）强制消费，在教义上是否等价于硬门？这是一个架构问题，不是教义问题。
