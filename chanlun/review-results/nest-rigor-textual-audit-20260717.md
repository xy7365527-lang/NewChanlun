## 问（1）：次级别背驰是否允许/必须发生在父级背驰段**之后**（我方口径的『回试段』）？

**答：不允许。原文要求次级别背驰段严格落在父级背驰段之内，且两者的终结点（转折点）基本重合；回试段在原文属于第一类买卖点之后的另一类结构，从不进入区间套包含链。**

### 1.1 包含方向：次级别背驰段 ⊂ 父级背驰段（严格、「一定」）

027:38（万科旗舰例，季度→月线）：
> 「以万科为例子，季度图上的第三段，在月线上，可以找到针对月线最后中枢的背驰段，而这背驰段，**一定在季度线的背驰段里，而且区间比之小**，把这个过程从月线延伸到周线、日线、30分钟、5分钟、1分钟……这区间不断缩小」

027:46（程序定理的操作表述）：
> 「某大级别的转折点，先找到其背驰段，然后在次级别图里，**找出相应背驰段在次级别里的背驰段**，将该过程反复进行下去，直到最低级别，相应的转折点就在该级别背驰段确定的范围内。」

061:32,34（四重标准图解，逐重为「背驰段的背驰段」）：
> 「65开始的走势是第一重背驰段，69开始的是第二重背驰段，**也就是65开始背驰段的背驰段**，而71开始的是第三重背驰段，也就是65开始背驰段的背驰段的背驰段……第四重的背驰段出现了。」
> 「72点这个背驰点的精确定位，是由65开始背驰段的背驰段的背驰段的背驰段构成的，这就构成一个区间套的精确定位」

027:320（作业答案，三重）：「通过**5分钟背弛段的1分钟背弛段的次级别的背弛**这样的三重背弛的类似数学分析中的区间套定理的精确定位」。

（数据事实：以上四处 + chan99§10.6:5「区间套：就是根据背驰段从高级别向低级别逐级寻找背驰点的方法」+ chan99§10.6:11 同文复述 027:46——全部用例都是背驰段嵌套背驰段，无一例越出父级背驰段右端点。）

### 1.2 时序：子级背驰的完成点 ≈ 父级背驰段的终结点，而非其后

027:332：「在5分钟**进入背弛段后**，找1分钟相应段的背弛段，再找1分钟背弛段的背弛段」——父级一进入背驰段就向下找，子级背驰的完成即父级背驰段的完成。
029:18：「一个5分钟背驰段的下跌，最终通过1分钟以及1分钟以下级别的精确定位，最终可以找到**背驰的精确点，其后就发生反弹**」——精确定位到的点就是转折点本身，反弹（即我方口径的回试/反应段）在**其后**，不属于定位对象。

（数据事实。旁证：p102 §5 的 Short 对照例 `p102-b-long-zero-attribution-20260717.md:106-108`「父子同顶收尾——教科书式区间套」，几何上正合此形。）

### 1.3 『回试段』在原文的对象身份：第一类买卖点**之后**的结构

052:516：「第二类买点的定义很明确，就是例如一个30分钟的第一类买点，一个5分钟次级别上去后，**一个5分钟回试不破低点**，那就是第二类买点，你说他该在哪一段？用结合进行次级别分解，**只能在第二段**。」
101:22：「所谓第二类买点，就是第一类买点的次级别回抽结束后**再次探底或回试**的那个次级别走势的结束点。」
020:60（第三类买卖点定理）：「一个次级别走势类型向上离开缠中说禅走势中枢，然后以一个次级别走势类型**回试**，其低点不跌破ZG，则构成第三类买点」。

（数据事实：原文中『回试』一律以转折/离开已经完成为前提，是第二、三类买卖点结构的构件；区间套定位的是第一类买卖点（027 整课、029:18），两者是先后两个对象。把回试段排除出第一类点的嵌套对象，正是原文的对象分类本身。）

### 1.4 关键附带：『背驰段』在原文是活假设，可被证伪——这决定 p102「子在父右」边的真伪归属

061:26：「65开始的走势，由于没实际走出来……都可以**先假设是进入背驰段**。而当走势实际走出来，**一旦力度大于前者，那么就可以断定背驰段不成立**，也就不会出现背驰。在没有证据否定背驰之前，就要观察……其内部结构中的背驰情况，这种方法可以逐次下去」。
043:30：「一个30分钟的走势类型，在30分钟级别进入背驰段，当然，**这个背驰段并不一定就演化成背驰**，因为，小级别的延伸足以使得大级别最终摆脱背驰」。
043:20：「有人经常问，为什么1分钟顶背驰后还涨，那有什么奇怪的，只要有一个1分钟的盘整，那就可以继续涨」。
027:136（宝钢案，缠师亲口纠错）：「你对背驰的判断是错误的，宝钢15分钟**根本没有背驰**……该背驰是典型的**1分钟背驰**」——看似本级背驰、实为低级别背驰时，本级趋势继续。

（数据事实。含义：若父级「背驰」确认后价格未回最后中枢而直接同向破极值，按原文该父级背驰段**尚未终结**——要么背驰段不成立（061:26/043:30），要么那是小级别背驰（027:136）；此时真父级背驰段仍在延伸，后到的子级背驰按 027:38 落在真背驰段**之内**。p102:75-78 所称的「回试/反应段」，若对应这种几何，在原文术语下不是回试（回试以转折完成为前提，§1.3），而是背驰段的延续。该标签本身是否为误贴，由 §5 的判别测试定。）

## 问（2）：定理是否保证**每个级别**都有对应次级别背驰（必然性）？

**答：不保证。027 的定理是定位程序（「可以……而确定」），不是存在性定理；原文承诺的最强形式是「转折点必源自某级别背驰」（024:18，级别不定）+「高级别改变必先从低级别开始」（102:38）。逐级对应只在区间套关系成立时成立（032:227），小转大可跳过任意中间级别（043:34、044:16），递归本身有条件（037:22），下降有底（065:94、027:40）。**

### 2.1 定理原文：程序而非存在性

027:44-46：「某大级别的转折点，**可以**通过不同级别背驰段的逐级收缩范围**而确定**」（程序、方法）；
027:38 的「一定在……背驰段里」是**存在后的位置必然性**（找到则必在内），不是**每级存在性**承诺。
（数据事实）

### 2.2 原文明确否定级别间的必然对应

032:227：「**背驰的级别和上涨的级别没有什么必然的对应关系，要有对应关系，就必须满足区间套关系**。」
044:16：「向上30分钟级别的a+A+b+B+c，如果c是一个**1分钟级别的背驰**，最终引发下跌拉回B里」——30分钟的 c 段可以直接由 1 分钟背驰终结，跳过中间各级。
043:34：「一个30分钟的走势类型，明确显示**没有出现30分钟的背驰**，也就是背驰段最终不成立，但却出现一个1分钟级别的背驰」。
043:26：「背驰的级别不可能大于当下走势的级别」——方向性约束只有上界。
044:30：「关于这种情况，**只有必要条件，而没有充分条件**」。
（数据事实：中间级别被跳过是原文明确承认的合法形态。⟹ 「每一级都应有对应证书」在原文下为假；链在跳级处断是市场事实，不是定义苛刻。）

### 2.3 递归下降本身有条件，且被原文标为「最标准最常见」而非必然

037:22：「由于c包含B的第三类买卖点，则**c至少包含两个次级别中枢**……这两个中枢构成次级别趋势的关系，是**最标准最常见的情况**，这种情况下，**就可以继续套用**a+A+b+B+c的形式进行次级别分析……形成类似区间套的状态」。
037:16：「没有趋势，没有背驰」；037:18「c必然是次级别的」；037:20「c一定要创出新高/新低」。
（数据事实：次级别递归要求 c 内含次级别趋势（≥2 次级别中枢）。原文用「最标准最常见」限定，即承认非标准情形存在——c 内部不满足时该级无（趋势）背驰段可套。）

### 2.4 下降有底：级别有限 + 线段以下无背驰

027:40：「这些级别不是无限下去的，因此，理论上并不能去证明就是一个如极限一样的点状情况的出现」；027:48 同旨。
065:94：「一定要存在最低级别的中枢后，才有最低级别的走势类型，才会有背驰等概念的存在……在线段之下讨论背驰概念是没意义的，但可以根据类似背驰的力度比较方法来讨论线段之下**类背驰**的现象，但这和背驰是两回事情」。
088:196：「三重的区间套定位，**最后一重是213-214之间的线段内部笔之间的定位**」——原文自己的最深一重已是类背驰。
（数据事实：链深天然有限，L4 零样本、未递归到 L1 均不违反原文。）

### 2.5 走势终完美的适用域：给方法存在基础，不给逐级承诺

017:22：「任何级别的任何走势类型终要完成」；
102:26：「如果市场走势没有本ID所揭示的整体结构，那么区间套是不会存在……区间套的方法，就是走势必完美的一个重要的应用」；
024:18：「任一背驰都必然制造某级别的买卖点，**任一级别的买卖点都必然源自某级别走势的背驰**」——『某级别』，非『每一级别』；
102:38：「任何高级别的改变都必须先从低级别开始」。
（数据事实：走势必完美保证父级背驰段**必完成**、其终点**必是某级别背驰的买卖点**——即向下定位总能停在某个级别上；它不保证沿途每一级都留下该级的背驰段。）

### 2.6 二级权威（chan99§10.6）的补充与张力

chan99§10.6:15：「低级别背驰是本级别背驰的**必要条件**而非充分条件……某个级别的走势背驰了，那么必须确定它**以下所有级别都转折了**」——注意用词是『转折』非『背驰』，与一级权威（024:18『某级别』、044:16 跳级）相容读法：本级别背驰 ⟹ 某个更低级别已背驰（逐级『转折』可经跳级传递）。
chan99§10.6:19：「**第一种情况最普遍**。其特点是时间和级别完全契合……直到所有的级别都在背驰段，最小的级别最终背驰」——编纂版的经验命题：完全契合的多级套是转折三形态中最普遍的。
（口径产物 + 待裁定：若『第一种最普遍』成立，则真父级背驰的常态伴侣应是多级链；实测 66 张证书链深 1/2/3/4 = 48/12/5/1（`p105-cert-level-spectrum-20260717.md:14`），单级占 72.7%。此张力方向性地指向检测/装配而非定义，但 chan99 是二级权威且该句是一级权威中没有的经验强度声明，不能单独定罪，仅列为与原文相容的怀疑权重。）

## 问（3）：包含要求的精确对象——哪段套哪段？

**答：背驰段套背驰段。每一级的被套对象都是『构成背驰的那段走势类型』（趋势背驰的 c 段 / 盘整背驰的后一比较段），A 段、B 中枢、背驰后的回试段都不是被套对象；端点共享（同顶/同底收尾）合原文。**

- 027:22（定义）：「在某级别的某类型走势，如果构成背驰或盘整背驰，就把这段走势类型称为某级别的背驰段。」
- 027:38：父级被套对象 = 「季度图上的**第三段**」（即 A/B/C 比较中的 C 段），子级 = 「针对月线**最后中枢**的背驰段」。
- 061:32：逐重 = 「背驰段的背驰段的背驰段」。
- 027:20（盘背比较对象）：「把第一、三段看成两个走势类型之间的比较」——盘背的背驰段同样是后一比较段。
- A 口径（leave.start→retest.end，`p102-b-long-zero-attribution-20260717.md:81-84`，宽 26–98 倍）把背驰后第一反向腿与前 C 区域一并吞入——该两部分无原文支持（§1.3、027:38），p102 判其伪嵌与本文一致。
- 端点：029:18（精确定位到背驰的精确点，其后才反弹）⟹ 子级背驰段终点 ≈ 父级背驰段终点；闭区间共享右端点合原文（p102 Short 对照即此形）。
（数据事实）

## 对裁定②的明确判定

**裁定②不违反原文。**（数据事实）

1. 其对象条款「构成背驰的那段走势类型」是 027:22 的逐字引用，027:44-46 的程序表述一致；
2. 「不含回试段」合原文：回试段在原文属第一类买卖点之后的第二/三类买卖点结构（052:516、101:22、020:60），区间套的全部原文用例（027:38/46/320/332、029:18、061:26-34、088:196）均不纳入；
3. 「不是 leave→retest 全跨度」合原文：027:38 要求严格包含且「区间比之小」，A 口径吞入的部分恰是无原文支持的两块。

**编排者假设链检验**：「若原文本就允许次级别背驰发生在父级背驰段之后，则裁定②是口径错误」——前提被原文否掉（§1.1-1.3）：原文本就要求严格包含于背驰段之内。故裁定②不是口径错误，「定义苛刻致低产」亦不成立（口径产物：B 口径未比原文加严）。

**但对称地，「每个级别都应该有对应证书」同样无原文支持**（§2）：区间套是条件性定位程序，非逐级存在性定理。两条从『定义』出发解释低产的路（过严 / 应然必有）都被原文关闭后，剩余合法归因只有三路，且原文给出可操作的判别式：

## 归因判别式（原文导出，可机械化，建议后续探针）

对每条「子级事件落在父级背驰段右端点之后」的候选边（p102 的 4 条 Long 边），取父级最后中枢区间 [ZD, ZG]，检查区间 (parent_b.end, child_b.end] 内价格是否回到该中枢：

- **回到过** ⟹ 父级背驰合原文成立（024:46「一旦出现背驰，其回跌，一定至少重新回到B段的中枢里」；029:16 背驰-转折定理），其后同向破极值属新结构，子级事件是后结构的背驰——裁定②拒发正确，**市场事实**。
- **未回到而直接同向破极值** ⟹ 该父级事件不满足背驰后的定理保证，即按原文它不是该级别背驰：或背驰段不成立（061:26、043:30）、或是小级别背驰误判（027:136 宝钢型）。此时真父级背驰段仍在延伸，子级背驰按 027:38 落在其内——装配层把 c 终点冻结过早 / 确认谓词把未结走势结算成背驰，属**装配工件**（或检测聋度），裁定②本身仍无错。
