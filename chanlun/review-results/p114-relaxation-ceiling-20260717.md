## 2. 上限语义（假设清单——读数前必读）

上限 = 以下全部按有利方向取值；标注各自的定性：

- (a) **全合取全过**：p112 全合取（趋势 ∧ c 破 b 极值 ∧ c 含三买 ∧ 黄白线回拉 0 轴 ∧ MACD 面积，
  `doc-trend-divergence-predicate-20260717.md:164`）对 154 基例全部通过。dump 无三买/黄白线
  数据 → **待裁定**（p112 逐案审计的对象），上限取 100%。
- (b) **边门放行**：方向门/包含门对复活着陆链全部放行。dump 侧无 L2+ 事件的方向与区间
  （p92 dump 只有证书行）→ **待裁定**；实测反锚 50 样本 0/50 过 L2 边（p109 数据:95-97）。
- (c) **身份门不变**：各级事件数 nk≥1 逐链已观测（P109_CHAIN events 向量）——上限里唯一的
  **数据事实**成分；同时也是天花板来源（L5 恒 0）。
- (d) **包含取 A 口径**：匹配事件 interval_a==pair 区间时 A 边构造性成立（p109 数据:23
  `a_edge_violations=0`，**口径产物**）。B 口径更深部分是最大拉伸项：50 样本 L2 边 30/41
  死于 is_sub@B。上限按现状双口径各发一张计（约定见 §1），即默认 B 侧也全活——**这是全部
  假设中最激进的一条**。
- (e) **情景 (2) 终端门**：474 基例 turn 上 confirm_side BSP 全部在场——dump 不可观测，
  同族实测 0/877 → **待裁定**，上限取全在场。

d_max 定义：链 d_max = max{d≤4：events[1..d] 全 ≥1}；基例 d_max = 其名下各链最大值（同一基例
不同链走不同上级 pair）。深度 5 恒不可达（L5 零覆盖，数据事实）。
