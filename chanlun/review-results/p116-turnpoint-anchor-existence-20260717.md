## §1 定义：真转折点（可操作）

### 1.1 定稿

> **真转折点 ≔ 因果塔在级别 ℓ（1≤ℓ≤5）完成的 typed 结构（趋势 Trend 或盘整 Consolidation）的终点 bar。**

可操作等价形：探针 dump 中 `TURN level=<1-5> kind=<Trend|Consolidation>` 行的 `end` 字段。`TURN level=0`（线段层）行只作诊断、不进定义域（§1.4）。

两点澄清：

1. 「完成」= 塔该级 typed 结构闭合并转化为下一结构（017:36），是**结构事件**，不含事后价格反转确认；本定义不承诺方向反转。
2. 「转折」的教义语义 = **走势类型转换**（029:16 三种后果：最后一个中枢级别扩展 / 更大级别盘整 / 该级别以上级别反趋势——仅第三种是方向反转）。方向反转点是真转折点的真子类，本探针不单独区分。

### 1.2 教义锚（逐条，一级权威；引文经本工位逐行核验）

- **017:22（终完美——完成的存在性）**：「任何级别的任何走势类型终要完成。后面一句用更简练的话，就是『走势终完美』。」
- **017:36（完成 ⟹ 转化——终点即类型转换点）**：「任何走势，无论是趋势还是盘整，在图形上最终都要完成。另一方面，一旦某种类型的走势完成以后，就会转化为其他类型的走势。」
- **021:66（升跌完备性定理——端点=买卖点）**：「市场中的任何向上与下跌，都必然从三类缠中说禅买卖点中的某一类开始以及结束。换言之，市场走势完全由这样的线段构成，线段的端点是某级别三类缠中说禅买卖点中的某一类。」
- **024:16（存在性锚承诺——探针的教义根基）**：「但出现背弛后必然有逆转，这是没任何商量余地的……任何的逆转，必然包含某级别的背驰。」
- **024:18（背驰-买卖点定理——转折点 ⟺ 背驰锚的全称链接）**：「任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰。」
- **029:16（背驰-转折定理——『转折』语义=类型转换）**：「某级别趋势的背驰将导致该趋势最后一个中枢的级别扩展、该级别更大级别的盘整或该级别以上级别的反趋势。」
- **029:18（几何要求——锚点与转折点邻域重合）**：「一个5分钟背驰段的下跌，最终通过1分钟以及1分钟以下级别的精确定位，最终可以找到背驰的精确点，其后就发生反弹。」（容差语义见 §3.4）
- **043:26（锚级别上界）**：「由于背驰的级别不可能大于当下走势的级别，例如一个30分钟级别的背驰，只可能存在于一个至少是30分钟级别的走势类型中。」——ℓ_anchor ≤ ℓ_turn。
- **065:94 / 066:198（递归地板）**：见 §1.4。

判定式的逻辑链（为什么这个定义合法）：017:22/36 给「完成点存在」；021:66 给「端点=买卖点」；024:16/18 给「买卖点 ⟺ 某级别背驰锚」；043:26 给锚级别上界；029:18 给锚点几何邻域。合起来：**每个真转折点（塔完成 typed 结构终点）必存在某级别 ℓ≤L 的背驰锚且锚点≈转折点**——这正是 doc-necessity-boundary §6.2 裁定的存在性探针形态，本定义把「真转折点」钉到塔的可观测事件上。

### 1.3 边界判定一：盘整完成点算不算转折点？

**判定：算。** 理由五条：

1. **终完美全称覆盖盘整**（017:36）：「无论是趋势还是盘整，在图形上最终都要完成……完成以后，就会转化为其他类型的走势」——盘整完成点与趋势完成点在「完成 ⟹ 转化」上同构，同为类型转换点。
2. **背驰-买卖点定理全称**（024:18「任一背驰」）：盘整背驰在背驰域内——043:30 注把「趋势背驰与盘整背驰」并列、024:48「无论背驰与盘整背驰，只要满足上面相应的标准，其技术上都是绝对的」。盘整完成点可携带背驰锚。
3. **升跌完备性**（021:66）：盘整完成后的离开段（向上或向下）其起点是三类买卖点之一，该买卖点即盘整完成点——盘整完成点落在完备性定理的端点覆盖域内。
4. **转折 ≠ 方向反转**（029:16）：背驰-转折定理三种后果中只有「反趋势」是方向反转；「中枢级别扩展」「更大级别盘整」恰是盘整型完成/转化的合法形态。以「不反转」为由排除盘整完成点，等于把 029:16 的三种后果砍掉两种，教义不成立。
5. **系统自洽**：nest 证书主体是 pan bucket（p100：A 口径 pan=29/41、B 口径 pan=22/25；v2 dump 同形态）。若把盘整完成点排除出定义域，存在性探针将对自身证书库绝大多数锚点失明——定义自毁。

### 1.4 边界判定二：塔 L0 线段终点是否计入？

**判定：不计入主判定集合。`TURN level=0` 行保留输出（诊断用），但存在性判定只对 level=1-5 执行，L0 单独计数、不进分母、不归 A 不归 C。** 理由五条：

1. **终完美的主语是「走势类型」**（017:22）：趋势/盘整才是走势类型；线段是走势类型的构成部件，部件终点不是「走势类型完成点」。
2. **065:94（递归有底）**：「一定要存在最低级别的中枢后，才有最低级别的走势类型，才会有背驰等概念的存在……在线段之下讨论背驰概念是没意义的，但可以根据类似背驰的力度比较方法来讨论线段之下类背驰的现象，但这和背驰是两回事情。」——锚证书语义（背驰确认）在裸线段终点无从附着。
3. **066:198**：「背驰的概念，标准的在最低级别之上用，线段上的，只能是类背驰的判断。」——线段层只有类背驰。类背驰是合法精度工具（069:30 月线历史大顶大底按「线段里笔的类背驰」判断；088:196 三重区间套最深一重是线段内部笔定位），但它「和背驰是两回事情」，nest CERT 管线不承载类背驰。
4. **工程对齐**：nest 事件管线级别域为 `1..tower.len()`（`rust/src/bin/p92_nest_replay_postruling.rs:626` 事件收集、`:745` 装配 exec 下界）；契约 `DIV`/`TERM level=<1-5>` 同域。L0 终点的锚在管线内**结构性不可见**，计入分母将制造成批假沉默，污染 A/C 分流。
5. **诊断价值保留**：小转大（044:16）允许锚落在极低级别；TURN level=0 的分布可旁证类背驰锚的可能位置，供人工复核 A2 案（§5）时参考——旁证不是判据。

## §3 方法

### 3.1 日志格式契约（编排者钉死，原样照录）

```text
TURN level=<0-5> end=<bar> start=<bar> kind=<Trend|Consolidation>   # 塔完成的 typed 结构终点=真转折点
DIV  level=<1-5> end=<bar> kind=<trend|pan> side=<Long|Short>       # 新口径背驰确认通过瞬间
TERM level=<1-5> bar=<bar> side=<Long|Short>                         # 终端 BspBits confirm_side 事件
CERT 行沿用现有格式：CERT caliber=<A|B> exec=<n> top=<n> as_of=<bar> side=<Long|Short> bucket=<...> kinds=<...> judge_at=<...> ids=<level>:<turn_source>:<b0>-<b1>|...
```

### 3.2 事件语义坐标（契约行 ↔ 生产代码，只读核验）

- **TURN**：塔 typed 结构（Trend/Consolidation MoveBlock）完成事件；塔构造 `classifier/mod.rs:370-447`（`for level_idx in 0..=l_max`，自然终止）。
- **DIV**：`NestCandidateEvent.divergence_confirmed=true` 的首证瞬间。产出 `provide_nest_candidate_events`（`rust/src/theta_v0/classifier/level_view.rs:652`）：
  - Trend 支：结构宽候选预滤（趋势块定位 `:667-674`、interval_a 跨度 `:675-677`、Extreme 预滤 `:684-696`，037:20）+ 全合取确认 `trend_confirm_time`（调用 `:702-717`，判定本体 `:560-638`：T4 回拉0轴 `:560-563`［025:761］∧ T3 三买 `:572`［037:18］∧ T5 力度或关系 `:613-624`［027:32］∧ T2 破极值 `:628-635`［037:20］）；确认时点 t* = 首个全成立时点（`:635`），confirmed 事件 `interval_b`/`turn_source` 收束到 t*（`:714-716`，禁前视 `:699`）。
  - Pan 支：中枢归属盘整块（`:739`）、窄锚 locate∧Extreme 优先 + R3 front-anchor 回退（`:744-755`，061:28）、R2 力度或关系 `segments_diverge_or`（`:776-784`，027:32）。
- **TERM**：`terminal_bits_new` 命中——在 `classification.levels[level].bsp` 中找 `source_index == event.turn_source` 且 `bits.confirm_side(side)`（`rust/src/bin/p92_nest_replay_postruling.rs:940-953`；登记 `:737`）。
- **CERT**：`assemble_typed_certificate` 产出（`rust/src/theta_v0/classifier/nest.rs:465-522`）；装配门坐标见 §5 判定树。

### 3.3 匹配规则（TURN × CERT）

- **期望侧 s**：TURN 行无 side 字段，由 typed 结构方向导出——上涨（Up）结构完成 ⟹ 顶 ⟹ 期望 **Short** 锚；下跌（Down）结构完成 ⟹ 底 ⟹ 期望 **Long** 锚（021:66 端点=买卖点；side 映射对照 `level_view.rs:678-681`：Down→Long / Up→Short）。kind=Consolidation 时由离开段方向同法导出。
- **锚级别域**：DIV/CERT 检索级别 ∈ [1, ℓ_turn]（上界 043:26；下界 1 = 管线地板，§1.4）。级别 > ℓ_turn 的证书不是该转折点的锚（043:26 反例即教义违规），不纳入匹配。
- **dt 基准**：对每张候选 CERT，取其 `ids` 全部身份的 `turn_source`（确认收束点 t*）与 `b1`（结构区间右端）对 `TURN.end` 的最小绝对差：`dt = min_identities min(|turn_source − T|, |b1 − T|)`。与 p100 `dt_any`（最近任意命中）语义同族。
- **窗口对称 ±W**：p100 先例 `dt_same` 分布有正有负（−519…+1191）——确认可先于或后于结构完成登记，窗口取对称。

### 3.4 容差语义（029:18 几何要求 + 多档 dt=0/±240/±1440）

**几何要求**（029:18）：「最终可以找到背驰的精确点，其后就发生反弹」——锚的背驰精确点应与转折点**邻域重合**；dt 度量该重合度。

**为什么不是单档 dt=0**：024:16/18 只承诺锚**存在**（某级别背驰），不承诺**确认延迟分布**；确认是当下渐进的（trend 全合取 t* = 首个全成立时点，`level_view.rs:635`；收束逻辑 `:714-716`），|dt|>0 是确认动力学的内禀形态，不是几何错位。单档 dt=0 会把确认动力学误判为无锚；单档 1440 会稀释 029:18 的几何要求。故三档分层，存在性判定与强度分层分离：

| 档 | 语义 | 依据 |
|---|---|---|
| dt=0 | 精确重合 | 029:18 几何理想形态 |
| \|dt\|≤240 | 强绑定 | p100 §3：240 落在 strong 组最大 \|dt\|=230 与 weak 组最小 \|dt\|=273 的**自然真空带**；≈4h@1m，与 029:18「1分钟以及1分钟以下级别精确定位」的确认窗口同量级 |
| \|dt\|≤1440 | 弱绑定 / **存在性门槛** | p100：A/B 双口径 1440 bar 内 100% 覆盖（最大 \|dt\|=1191）；1440 bar = 1 自然日@1m |

- **存在性判定以 1440 为门槛**：|dt|≤1440 内有同侧 CERT ⟹ 锚存在（HIT）；超出 ⟹ 无锚，进 §5 归因树。
- **0 / 240 只作强度分层**，不作存在性否决——沿用 p100 strong/weak 分层语义（真空带实证支撑，p100 §4.2 结论「不需要按级别自适应改造」继续有效）。

### 4.6 精度边界声明（引用本批任何数字前必读）

a. **DIV±1440 近邻是 C 类的超集证据，不等于「该转折的背驰」**：(i) 契约 v1 的 TURN 行无方向字段（未载 Up/Down），离线层无法执行 §3.3 期望侧匹配——锚定与 DIV/TERM 近邻均为**侧盲**口径；(ii) 近邻只证「窗口内存在某级别背驰确认事件」，不证该事件属于该转折的结构链；(iii) C 类 522 内含潜在 A3 改判空间（规则书 R2.2.2：有 TERM 而中间级无候选、父级结构反向为市场事实、双口径 Sub 同败者归 A 不归 C——13 案带更低级 TERM 标记者是链查入口，逐案链查本批未执行）。故 C 类一律按**门滤除嫌疑上界**读；逐门精确归因以 p107/p109 门级数据为准（p109：身份门 58.47%、终端门 25.16%、背驰确认门 15.74%、包含门 0.46%）。

### 6.2 核心判读：「递归不完美」的大头是门/口径工件，不是市场没背驰

L≥1 域内 **90.2%** 的转折点已有同域背驰确认（DIV）在 ±1440 窗口内发生、却被装配链各门滤成无证书沉默；教义内禀无锚（A 类）仅 **9 案（1.6%）且全在 L1**。L4 全部 9 案落 C 类——最高涌现级别零锚定是门滤除贯穿到顶的实证，不可读作「市场高级别无背驰」。合计事件层覆盖：锚定 48 案的 CERT 身份即背驰确认事件（⟹ 同窗口内必有 DIV）+ C 类 522 案 = **570/579 = 98.4%**（侧盲口径，§4.6-a）的 L≥1 转折点在事件层有背驰痕迹；缺口集中在「事件→证书」转化链，不在「市场→事件」层。「每个真转折点必有背驰锚」的教义承诺（024:16/18）在本数据上的失落主因是管线门，不是市场。

### 6.4 小转大 0 案读法（与关④在途的关系，如实写、不吹结论）

1. 该 0 **不**证明市场无小转大形态。本阶段小转大通道未实装——关④在途（p118 施工图，2026-07-18，`chanlun/review-results/p118-xiaozhuanda-branch-design-20260718.md`：装配环 `nest.rs:647-650` rung 的 divergence_confirmed 真值被丢弃、输出分类词汇无「小转大」值，小转大形态在证书对象上**无类**）。探针的 DIV/TERM 判据只能在现行事件宇宙内筛查，父级无背驰确认的事件链本来就不产出可挂的证书类。
2. 该 0 的实义：在现行事件宇宙内，凡无同域 DIV 的转折点（L≥1 仅 9 案）同时也不存在更低级终端确认痕迹——「沉默且无任何旁证」的集合极小，A 类 9 案是干净的教义内禀候选集。
3. 旁证：C 类中 13 案同时带更低级 TERM 标记（门滤除与潜在小转大通道信号并存）——形态信号存在但被门滤除掩盖。关④落地（TURN_CLASS 新口径）后本项须重测，0 案读数可能改写；本报告不为通道实装后的读数背书。

### 6.5 对双开有效域的含义

p120（`chanlun/review-results/p120-nested-voice-dual-ledger-design-20260718.md`）已钉死：双开一切验收量测（嵌套声部计数/级别分布/双开存活率/recover 率）必须在关①→关②串行链落地后的**最终 BSP 账本**上跑，在途账本读数无效。本探针三域划分给该最终账本的可期望容量定界：

- **C 类 90.2% 是关②（BSP 侧口径修复）修复后可定价量的上限**：修复释放的是「背驰已在事件层确认、被门滤除」的既有背书——口径回收，不是新预测产量；实际可回收多少取决于 C2/C3/C4/C5 内部构成与潜在 A3 改判（本批侧盲口径给不出，待 T1 后重跑 + 逐门归因，§4.6-a/d）。
- **A 类 1.6% 是教义内禀下限**：027:14（背驰时机或然）、044:16/044:30（小转大只有必要条件无充分条件）、032:227（区间套成立与否是市场事实）允许的合法无锚形态，任何管线修复不得许诺消除。L≥1 域内双开有效域的教义天花板 ≈ 98.4%（570/579），L0 域外与塔未涌现级别不在定义域。
- **8.3% 可捕获域是现行口径下已可用的锚定存量**（48 案，绑定强度分层 median|dt|=694.5 见 §4.5）——在关②落地前的在途账本上，这是双开验收量测唯一合法引用的锚定读数。
