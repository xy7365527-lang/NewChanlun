# 教义调研摘录：中枢种子锚 + A episode 成立性（task #85）

- 日期：2026-07-15

- 背景：`chanlun/review-results/failclosed-audit-20260715.md`（#84）§2.2 与 §3.2。

## 1. D1 侧：中枢种子"前三段 vs 最先三段"

### 1.1 摘录

1. **第17课核心定义**（`.chanlun/definitions/zhongshu.md:16,23`）：
   > "某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分，称为缠中说禅走势中枢。"
   —— 存在性口径：只要求"至少三个**连续**"，未限定必须是走势类型的**前**三段。
2. **第20课**（`zhongshu.md:42`）：
   > "缠中说禅走势中枢由前三个连续次级别走势类型的重叠部分确定，其后的走势有两种情况：一、该走势中枢的延伸。二、产生新的同级别走势中枢。"
   —— 语境是**延伸语义**：`[ZD,ZG]` 由构成中枢的前三段一次性确定、延伸不改（`zhongshu.md:162`：延伸时区间保持不变）。"前三个"的所指是**中枢自身的**前三段，引文本身未规定中枢首段必须等于走势类型窗口的首段。
3. **走势分解定理二**（`.chanlun/definitions/zoushi.md:28`）：任何走势类型至少由三段以上次级别构成 —— 窗口 ≥3 段是走势类型资格，不自动等于"前三段即中枢种子"。
4. **身份键旁证**（`zoushi.md:155`）：走势类型实例 identity key = "第一个中枢的首段索引" —— 设计文档以**中枢首段**（而非窗口首段）为身份锚，与"中枢可以不从窗口第 0 段开始"相容。

### 1.2 对读

- **读法 A（支持滑锚）**：第17课定义是存在性判据；窗口内"最先出现的连续三段重叠"即中枢起点，第20课"前三个"仅指中枢自身前三段（用于定 `[ZD,ZG]` 与延伸）。按此，36 窗中的合法三段本应成枢，现行 `project_extended_windows` 的 window[0..3] 焊死锚是**工程化收紧**而非教义要求。
- **读法 B（支持现状/追上游）**：若上游 `decompose` 产出的扩展窗口在语义上承诺"本窗口即一个以首三段起枢的走势段"，则首三段不重叠说明**窗口切分**有误，病灶在 decompose，滑锚只是遮蔽。此读法下 36 窗是上游问题的症状。
- 两读法都不支持"36 窗永久作废且无需解释"作为教义终局；区别只在修复位置（投影层滑锚 vs 上游切分）。工程前缀稳定性（seed 迟到/漂移、双锚 tie-break）是独立的裁定轴，教义文本不覆盖。

## 2. D2 侧：A 离开成立性（7 条回退候选）

### 2.1 摘录

1. **第24课**（`.chanlun/definitions/beichi.md:28`）：A、B、C 在一个大趋势里，A 之前已有一个中枢，B 是另一个中枢；C 完成时 MACD 面积与 A 比。
2. **边界条件**（`beichi.md:212`）：
   > "A/B/C段完整：A段和C段都必须是完成的离开段。"
3. **"第一个中枢后的背驰"边界情形**（`beichi.md` 边界/特殊情况 2）：
   > "企图脱离中枢的运动因力度不足被拉回" —— 不构成真正背驰比较基础。
   —— 与 7 条的结构完全同型：同向锚出现后价格回到 `prev_center` 核心 `[zd,zg]` 内侧，即"离开未成立"。
4. **结论翻转条件**（`beichi.md:239`）：A/C 选取错误 ⟹ 背驰结论翻转 —— 错配比缺失更危险，倾向 fail-closed。

### 2.2 对读

- 现行 `episode_start_in` 的"最后回中枢段之后无同向段 ⟹ None"（`divergence.rs:718-735`）与摘录 2/3 一致：失败离开不是"完成的离开段"，不得回退作 A。
- 既有裁定链（codex ac4 #1"episode 不桥接"、Q5 面积口径、Q7-#1 锚资格）与教义摘录同向，无冲突。
- **调研结论（待正式裁定确认）**：D2 的 7 条应维持现行 fail-closed，无实现变更；裁定文档可直接引用本节四条摘录。
