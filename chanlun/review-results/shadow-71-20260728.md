## §3 对抗验证记录（三条待裁结论，默认立场"假"）

**①「τ² 冻结先验」HIGH → PARTIAL，主控裁 MED。**
- 成立：`mu_estimator.rs:556-561` `w_z = w.n/(w.n + var_z/tau_sq)`，`var_z = std_sample()²` 无归一化；`l3_delta_r_alpha.rs:1446` `let tau_sq: f64 = 1.0;` 为唯一字面调用点，`runner.rs:478 run_theta_v0_pi_chi_shrink(tau_sq)` 全仓**零调用者**，别处无自适应设定；量级跃迁属实。
- 不成立：**后果被夸大**。消费面仅 `three_way_l2`（`#[ignore]` 慢测）与 selector 的 `shrink_tau_sq`（生产恒 `None`，`runner.rs:471`）；`chanlun/` 内查无三路对比落地报告；且 `mu_shrink` 已列入 χ 否决裁定书 §1① 撤销族谱。故**非"已发表结论失效"，而是"重跑该 harness 会得到伪三路"**。
- 验证者建议 LOW；**主控裁 MED**：注释"1.0 = 中性先验"在新量纲下已成假声明，且代码无任何 stale/失效标注，后来者重跑必得伪结果——高于纯可读性，低于 HIGH（不触生产、不推翻已发表结论）。

**②「Arm3 臂名」MED → PARTIAL → LOW。** χ 在 arm1/arm3 都开属实；但臂名并未声称「Arm1−Arm3 = χ 效应」——上游 `m8.rs:42` 原文即「隔离 G7+margin：Arm1−Arm3」，且 arm3 相对 arm0 恰只多 χ（`config.rs:226` `enforce_gross_cap` 默认 false），构型可辩护；报告已明写不解释为策略质量。降 LOW。

**③「生产接线未实装」→ REFUTED，非发现。** 票体确要求（issue #71 body：「χ 门接入（`runner.rs:707` chi=None → chi=Some）」），但 `chi-line-falsification-ruling-20260728.md` §1①「χ 线…不接生产、不进 Destination」、§3「生产零变化…不产生任何生产 diff」。**未接线 = 遵守裁定**。另注：`runner.rs:707` 现处 `run_theta_v0_pi_overlay` 文档区，票体行号已失效。

## §4 结果包六要素

1. **结论**：Standards PASS（带边界）／Spec PASS（带边界）；无 HIGH ⟹ **#71 关票**；7 MED + 5 LOW 转结转项。
2. **定义依据**：分级口径 HIGH = 错误结果／数据损坏／安全／违反仓内硬禁令（no-workaround、no-patch-mentality 声明膨胀）／把自建问题推给他票；MED = 明确违反仓内标准或强 Fowler smell 但不产生错误结果；LOW = 可读性／一致性／次要启发式。唯一 HIGH 候选（M1）经对抗验证确证"不触生产、不推翻已发表结论"，两项 HIGH 要件均不满足 ⟹ 降 MED。
3. **边界条件（结论翻转条件）**：
   - M1 升回 HIGH ⟸ `mu_shrink` 被接入生产（`selector` 的 `shrink_tau_sq` 由 `None` 变 `Some`），或发现任何**已发表**报告的结论依赖 `three_way_l2` 输出。
   - M5 升 HIGH ⟸ 设计稿 §5-B① 的「与既有基线逐字节 diff」被认定为 #71 的硬验收项而非可降级腿。
   - Spec PASS 翻转 ⟸ χ 否决裁定书被撤销（则"生产接线未实装"重新成为票体缺口，③ 从 REFUTED 转 HIGH）。
   - M7 升 HIGH ⟸ 出现 `entry_px ≤ 0` 的真实数据面（当前标的池不产生该值）。
4. **下游推论**：① `mu_shrink` / `three_way_l2` 在解冻或重跑前**必须先重锚 τ²**，否则产出为伪三路——建议连同 L2（θ scan 网格）一并处理；② χ 否决裁定书 §1① 的"全枚举"族谱需补录 `issue71_chi_gamma.rs`，否则 §4 五档树定档漏件（M6）；③ `gamma_dump.rs` 的 `admission_fields` 与 `selector` 的双源关系应纳入 χ G2 先例的同一单源纪律监控面（M3）；④ §5-B 基线腿若要兑现原设计，需引入跨 commit 的历史基线产物，非进程内自比可替代。
5. **谱系引用**：χ 线实测否决裁定（`chanlun/escalate/chi-line-falsification-ruling-20260728.md`，χ 族撤销 + 验收统计族档2-修）；#65 裁定（量纲③定义 + 切换点 + LCB 代数不动）；单源纪律 χ G2 先例（`admission.rs:1528`）；「基线逐位相同验收句悬空」旧案（`project_wf8_fourlayer_baseline_negative`）——M5 与之同型；coding-style 2026-07-27/28 两条适用范围注记（回放性能缓存、带修订留痕单线程账本免 immutability）已在 Standards 轴比对中适用，未据 immutability 产生任何发现。
