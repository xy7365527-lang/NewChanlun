## 0. 为什么重构

七轮诊断把「高级别一类买卖点几乎为零」追到了走势切分：T 算子在 lad4/lad5/lad6
上，趋势走势**拿不到自己的离开段 c**，于是判不出背驰、不产 type1。

但「切分边界写错了」只是工程表层。本文的论点是：**根因在存在论层——当前实现没有
把「确认」建模成递归，而是把它压平成了「本级别的中枢分组 + 背驰判据」。** 离开段 c
在切分阶段就被划给了下一段，是这个更深结构错误的一个症状。

要修的不是某一行边界，而是回到缠论对「走势、确认、买卖点」的第一性定义，重新推导
T 的运动形式。这份文档就是这个重新推导。

## 1. 第一性原理：递归是什么

**递归不是「函数自己调用自己」这个技巧，而是一种存在论姿态：把当前级别无法判定的
确认，下放给演化去解决。** 它是动力学——你不知道此刻这个顶是不是顶，但你知道「再
走下去」会告诉你，于是你把「确认」这个动作，交给下一层、交给时间。

### 1.1 不可判定性是递归的根据 `[L0]`

递归被迫出现的精确时刻：**一笔向上结束于顶分型，但顶分型不是确认。**

- 笔/分型定义（第62课）：顶分型 = 相邻三 K 线中间那根高点最高、低点也最高；
  「两个相邻的顶和底之间构成一笔」。
- 一笔是最小走势单元，**内部没有背驰**（不可再分，谈不上力度衰减）。它的结束只能由
  「笔破坏」标记，即顶分型。
- **但顶分型之后有两种未来，在顶分型那一刻长得一模一样**（第17课中枢定义 + 第67课
  线段终结）：
  - 它可能是**转折**（真的要跌了）；
  - 它可能只是**一个中枢的开始**（回一下，震荡「下—上—下」三段重叠，然后继续向上）。
- 第67课线段终结的两种情况，正是这个不可判定性的形式化：特征序列顶分型「第一、二
  元素间无缺口」→ 立即确认终结；「有缺口」→ **必须等后续特征序列出现底分型才能确认**。
  「有缺口」就是「本级别还判不了，要等」。

站在顶分型这一刻，本级别无法区分这两种未来。**这个「无法区分」就是递归被迫出现的
地方**：要回答「这是中枢的开始还是转折」，必须下放到次级别——去看顶分型之后，次级别
有没有走出一个完整的、带背驰的反向走势。

### 1.2 递归是有限截断的无穷过程 `[L0]`

那个次级别确认，又要靠它的次次级别确认……**确认是无穷递归的**。但交易必须在某个
有限级别上拍板。缠论用**区间套**（第29课）做这个截断：从大级别背驰段，到次级别背驰，
到再次级别，逐级收缩，直到最低操作级别——「这样就意味着第一种最弱的情况可能性可以
完全排除了」（第29课）。

> 谱系：006号（级别递归是唯一正式路径，自底向上）、540号（递归恒等式）。

## 2. 确认的递归结构（本文的轴）

> **介入是当下的确认，离开是确认的确认。**

这句话是整份重构的轴。展开它，T 的全部运动形式都从中导出。

### 2.1 两种确认 `[L0]`

**介入（买入一买）= 当下的确认。**
一买 = 下跌趋势的底背驰点（第29课 / 知识库§10.1）。在这一点，你确认「下跌走势的离开段
背驰了 = 下跌完成了」。这个确认是**当下的**：基于「到此刻为止」的信息，在背驰发生的
那一刻（由次级别区间套定位）做出。它是**左侧**的——在转折被价格证实之前介入。第29课：
「第一类买点是绝对安全的……即使是这样一种最低级别的反弹，也有足够的空间让买入获利」。

**离开（卖出）= 确认的确认。**
买入后持有，上涨走势展开。当上涨走出它的**离开段 c** 并背驰时，这个背驰：
1. 直接确认了「上涨走势完成」（卖点）；
2. **同时回溯确认了当初的介入是对的**——因为只有当初那个底确实是转折点，才会有这一
   整段上涨、才会有这个上涨的离开段 c。**离开段 c 的存在本身，就是对介入点正确性的
   事后追认。**

所以离开是「确认的确认」：它确认了上涨的完成（直接），又确认了介入的正确（回溯）。

### 2.2 结构量级的不对称 `[L0]`

介入和离开需要的**结构量级不同**，这是两种确认不对称的形式表达：

- **介入只需次级别一个背驰**来确认（当下，结构小）：区间套定位到的那一个转折点。
- **离开要求离开段 c 自己是一个完整的次级别趋势**来确认（确认之确认，结构大）。
  第37课原文：「c 必然是次级别的……**c 至少包含两个次级别中枢**；c 一定要创出新高
  （上涨）/新低（下跌）」。

这条不对称**直接化解了讨论中「离开=一笔」与第37课「c≥2中枢」的表面冲突**：

> 离开段 c 在级别 k 是**本级别的一笔**（1 个 level-k 单元）；这一笔展开到次级别是
> **一个完整走势**；第37课要求这个次级别走势是**趋势**（≥2 中枢）才构成标准趋势背驰。
> 「一笔」是压缩视图，「≥2 中枢」是展开视图，同一对象的两面（540号双重性）。

「离开=一笔」描述的是**结构归属**（离开是本级别的一个单元，不是一大段）；「c≥2中枢」
描述的是**这个单元展开后的内部要求**（它得是次级别趋势）。两者不矛盾。

### 2.3 与双重性谱系同构 `[L0]`

确认的递归结构与已结算谱系精确同构：

| 本文 | 540号双重性 | 537号 BSP 信号层 |
|------|------------|-----------------|
| 介入 = 当下的确认 | 压缩侧（构造用） | **candidate**（本级必要） |
| 离开 = 确认的确认 | 展开侧（确认用） | **confirmed**（次级别转折追认） |

537号原文：「candidate（压缩侧）须经 confirmed（展开侧）确认；区间套 = 本级必要非充分，
须下级转折确认」。**介入是 candidate，离开是 confirmed。**

### 2.4 向后看 vs 左侧：延异 `[L0]`

介入是当下（现在这一刻），离开是未来对当下的回望——**确认的确认必然在介入之后**。这制造
了一个内在的时间结构：

- 背驰在本质上是**向后看**的（对一段已完成走势下的判断）；
- 交易要**左侧**（在确认前介入）；
- 二者由递归（区间套确认）调和：你不是在走势完成后才买（右侧），而是在某个**有限级别**
  上，用次级别的背驰确认，左侧地买入更高级别的转折。

这正是 escalation `confirm-arming-differance` 记录的「延异存在论」：**高层完成时，
次级别确认必在过去**。该 escalation `[L2]` 实测 recL2 上 418/418 = 100% 时序错配
（末段 type1 平均在 ~13694 bar / 3.8h 之前）。「向后看 vs 当下」不是 bug，是确认的
递归结构的固有时间形态——但它的工程读法（武装点向前搜索 vs 向后回溯）尚未裁决（§8）。

## 3. 基本对象的递归构造（自底向上）

### 3.1 递归底：笔 = 最小走势 `[L0]`

- 笔（第62课）：相邻顶底分型之间；新笔要求顶底之间不含两端至少 3 根 K 线。
- **笔是最小走势**：递归从这里开始。一笔内部无中枢、无背驰。
- 一笔的结束 = 顶分型 = 笔破坏 ≠ 确认（§1.1）。「是中枢开始还是转折」下放次级别。

### 3.2 线段：构造侧对象（第67课）

线段「至少由三笔组成，前三笔必须有重叠」，由特征序列分型终结（第67课）。线段是
**笔→走势**之间的构造层。

> 谱系：003号（线段两口径：v0 三笔重叠贪心 / v1 特征序列等待分型，v1 为唯一正式）、
> 001号（退化段根因在笔定义）。本文聚焦走势递归，线段构造细节引用 003/001 不展开。

### 3.3 走势 = 进入段 + 中枢 + 离开段（第17课 / 第37课）`[L0]`

- 中枢（第17课）：「被至少三个连续次级别走势类型所重叠的部分」。
- 盘整 = 1 中枢；趋势 = ≥2 个依次同向中枢（第17课）。
- 趋势标准形 `a + A + b + B + c`（第37课）：a 进入段，A/B 同级别中枢，b 连接段，
  **c 离开段**。
- **离开段 c 归属当前走势，不归下一走势** `[L0]`（canon 取证，多条原文）：
  - 第37课：「c 一定要创出新高/新低」——c 创的极值是**当前**趋势的极值、终点；
  - 第37课：「c 至少包含对 B 的一个第三类买卖点」——c 是相对本趋势末中枢 B 离开的段；
  - 第29课背驰-转折定理：背驰点是当前趋势**完成**处，下一走势（盘整/反趋势）在其后开始；
  - 第18课中枢定理三：离开是相对本中枢/本走势定义的。
  - 故 c（含背驰点）是当前走势的**尾**，不是下一走势的**头**。走势 A 的离开段 c 与
    走势 B 的进入段**不是同一段**——B 的进入段是背驰点之后的反向次级别走势。

### 3.4 递归恒等式（540号）`[L0]`

> **Move(k) ≡ Level-(k+1) 的一笔**

级别 k 的一个完整走势，封装为级别 k+1 的一根笔。由此：

> **离开段 c 在级别 k = 1 个 level-k 单元 = 次级别（level k−1）的一个完整走势。**

这是 §2.2「离开=一笔（压缩）= c≥2中枢（展开）」的恒等式根据。

## 4. 怎么计算（单级别算子 T）

T 作用于级别 k 的单元序列，一次迭代含四步 a→b→c→d。下面给**第一性原理应有的计算**，
并对照 as-is。

### 4.1 步骤 a：中枢识别 `[L0]`

中枢 = 至少三个连续次级别走势的重叠区间（第17课）。重叠是**格运算**（区间交，
非群运算；谱系536）。核心区间 `[ZD,ZG]`、外缘区间 `[DD,GG]`。

`[as-is]` `center.rs:find_centers` 贪心顺扫，**核心争议点**：第31–35 行自述「贪心会把
离开前一中枢的连接段吸收为下一中枢的首单元」。这个吸收是 §4.3 c 段丢失的放大器。

### 4.2 步骤 b：走势切分 —— 核心修正

**第一性原理 `[L0]`：走势的右边界 = 离开段 c 的背驰点，不是下一个中枢的门口。**

因为（§3.3）背驰点才是走势的终点，下一走势从背驰点之后才开始。切分必须让离开段 c
留在当前走势内。

`[as-is]` `trend.rs:segment_into_trends` 把走势右边界定在 `starts[gi+1]` =
**下一组首中枢的首单元**（trend.rs:99–103），而非背驰点。结合 §4.1 的连接段吸收，
后果是离开段被系统性切走：

**c 段丢失的充要条件 `[L0]`（取证推导）**：
设当前组末中枢 B 的末单元绝对索引 `b_last`，下一组首中枢首单元 `a_next`。
- 无 c 段 ⟺ `c_start ≥ 切片长度` ⟺ `ue ≤ b_last + 1`；
- 非末组 `ue = a_next`，且贪心吸收恒令 `a_next = b_last + 1`；
- ∴ **非末组几乎必然无 c 段**（离开段被吸收为下一组首中枢首单元、划给下一组）。

**这是「被切走（cut_away）」而非「不存在（truly_absent）」** `[L0+L2]`：
- 判据：cut_away ⟺ `ue = b_last+1` 且 `b_last+1 < n`（离开单元在全局存在，只是不在本切片）；
  truly_absent ⟺ 末组且 `b_last = n−1`（B 吃到序列末，确实无离开单元）。
- BTC 实测 `[L2]`：所有无 c 段案例都是 `c_start == len`（精确相等，非 `>`），且全是中间组
  → **主导机制 = cut_away**。能保住 c 段的基本只有「最后一组 ue=n 且 B 未吃到末尾」。

**BTC 诊断数字 `[L2]`**（BTC 4,625,119 bar，structural 口径）：

| 级别 | 趋势走势 | 无 c 段 | 占比 | type1 产出 |
|------|---------|--------|------|-----------|
| lad6 (L3) | 3 | 3 | 100% | 0 |
| lad5 (L2) | 14 | 11 | 78.6% | 0 |
| lad4 (L1) | 59 | 45 | 76.3% | 1 |
| 合计 | 76 | 59 | **77.6%** | **1** |

全塔 BSP 分布 `[L2]`：type1 沿级别单调衰减 `165 → 68 → 14 → 3 → 0`（level0→4），
level3 起 type1_buy = 0。type3 占 93.2%（4595/4930），因 `detect_type3` 在每个中枢
离开点都触发、与 c 段无关——**「买卖点很多」是 type3 假象，定义转折的 type1 极稀缺。**

### 4.3 步骤 c：背驰判定 = 离开的确认 `[L0]`

背驰 = 离开段 c 的力度 < 进入段/前中枢力度（第24课形态学+动力学；第37课）。

**级别相关的判据分层 `[L0]`**（第64课）：
- **笔级别（递归底）= 类背驰**：「线段以下没有中枢，是类中枢、类背驰」（第64课）。
  离开是一笔，用力度比较 + 创新极值，**不要求 c≥2 中枢**。
- **趋势级别 = 真背驰**：第37课五条件，**含 c≥2 次级别中枢**（离开段须是次级别趋势）。

`[as-is]` `divergence.rs` 已按此分层：a0（`has_nest=false`）走类背驰；level≥1
（`has_nest=true`）激活全 5 条件（divergence.rs:236 分界）。**这个分层在概念上正确。**

**对「条件5」的再评价 `[L0+L2]`**（修正讨论中的口述）：条件5（c_nest≥2）在趋势级别是
第37课正确的，**不是判据 bug**。它 FAIL 大多是 cut_away 的**派生**——真离开段（含≥2中枢）
被切走，残留的「c 段」只剩 1 单元残渣（c_nest=1），自然过不了。根因仍收敛到 §4.2 的
**离开段被切走**。BTC `[L2]`：条件5 FAIL 仅 4 例，条件4 FAIL 12 例，而无 c 段 59 例——
**绝大多数走势在「有没有 c 段」这一关就死了，根本到不了条件4/5。**

### 4.4 步骤 d：封装 = 压缩侧 `[L0]`

终完美走势封装为上级一根单元（540号 Move(k)≡Level-(k+1) 笔）。携带 `inner_zhongshu_count`
（嵌套深度，供上级真背驰判定）与 MACD 面积（可加性求和上传）。`[as-is]` `operator.rs:encapsulate`
已实现。封装是**压缩侧**（构造用），与确认侧（展开）不可坍缩（540号）。

## 5. 怎么递归

### 5.1 递归底应是笔，不是线段 `[L0]` / 开放

`[as-is]` `build_a0_from_segments` 用 `orch.segments()`（**已确认线段**）作为 a0，每个
a0 单元 = 一根线段。**这把递归底起在了线段，跳过了「笔→线段」那一级确认。**

第一性原理（§3.1）：递归底是**笔**。a0 从线段起步，等于默认「笔级别那一次确认（一笔
向上、顶分型、是中枢开始还是转折）已经算完」——最底层那个一买的递归判定，在引擎里没有
发生的位置。

> 缠论侧有张力：走势中枢建立在线段之上（第17课「次级别走势」最低是线段），故「a0=线段」
> 有正典依据；但「递归从笔开始」要求笔级别也参与递归确认。**a0 取笔还是线段、影响最底层
> 一买，是开放问题（§8）。**

### 5.2 确认的下放：核心缺失 `[L0]`

`[as-is]` 取证明确（deviation #1）：当前「确认 = 结构冻结 chain reaction 自下而上，
**无级间显式下放机制**」。`operator.rs:96–98` 把「被反向走势终结」的中间走势标记
`completed`，但**不产 type1**——确认被压平成了「下一个反向走势出现了」这个本级别事件，
而不是「下放次级别去判定顶分型是中枢还是转折」。

**第一性原理 `[L0]`：T 在本级别遇到「顶分型/不可判定」时，应显式下放次级别确认，而非
返回 None 或按中枢机械分组。** `c_start ≥ len → None` 当前焊死了两种语义：
- **真·未完成**（离开笔还没出现，该等）——返回「未完成」是对的；
- **假·完成**（离开笔已出现但被切走，§4.2）——这是 bug。

引擎缺乏区分二者的能力，正因为它没有「确认下放」这个运动形式。

### 5.3 区间套：有限截断 `[L0]`

第29课区间套是确认下放的截断机制：大级别背驰段 → 次级别背驰 → 逐级收缩 → 最低操作级别。
第37课亦云 c 的内部确认「形成类似区间套的状态」。**区间套 = 把「确认的确认」落到可操作
的有限级别。** 这是 §6 介入点定位的算法骨架。

> 谱系：537号（区间套=本级必要非充分，须下级转折确认）。

### 5.4 涌现上界 r\* `[L0]`

递归向上直到不再涌现新单元（封装出的上级单元 < 3 根，无法构成中枢）。`[as-is]`
`mod.rs:iterate` 终止条件 `next_units.len() < 3`；`emergent_ceiling` 用 `completed`
标记取最高完成级别。此部分与第一性原理一致。

## 6. 何时介入

> 约束（讨论指令）：**市场永远无限做多，本文只走做多主线。** 做空的离开/确认结构
> 镜像但有失血有效域问题（多条谱系记录），本 session 搁置（§8）。

### 6.1 做多主线的确认链 `[L0]`

```
下跌趋势  →  离开段c背驰（底背驰）  →  一买 = 介入（当下的确认，左侧）
                                          ↓ 持有
上涨走势展开  →  上涨的离开段c走出 + 背驰  →  一卖 = 离开（确认的确认）
                                                ↑ 回溯追认了介入点正确
```

### 6.2 介入 = 当下的确认 `[L0]`

- 触发：次级别底背驰（区间套定位到的转折点，§5.3）。
- 性质：左侧、当下、结构小（次级别一个背驰即可）。
- 缠论依据：第29课「第一类买点……绝对安全」；一买 = 下跌趋势次级别跌破末中枢后的背驰点。

### 6.3 离开 = 确认的确认 `[L0]`

- 触发：持有的上涨走势走出离开段 c（次级别趋势，≥2 中枢）并背驰。
- 性质：向后看、确认之确认、结构大（离开段须是完整次级别趋势，第37课）。
- 双重功能：确认上涨完成（直接）+ 追认介入正确（回溯）。

### 6.4 介入/离开的不对称（重申 §2.2）`[L0]`

介入只需 candidate（次级别一背驰）；离开需 confirmed（离开段 c 是次级别趋势）。这个
量级差是「当下确认」与「确认之确认」的本质差，也是引擎「切走离开段 c」之所以**致命**
的原因——它切掉的恰是 confirmed 那一侧，于是介入永远悬空、走势永远不完成。

### 9.2 结果包六要素

1. **结论**：T 应以「确认的递归下放」为运动形式重构。介入=当下的确认（candidate，
   次级别一背驰，左侧）；离开=确认的确认（confirmed，离开段 c 是次级别趋势，向后看）。
   当前实现把确认压平成本级别中枢分组，导致离开段 c 被系统性切走（BTC 77.6% 无 c 段
   `[L2]`），高级别 type1 几乎归零（165→0 `[L2]`）。
2. **定义依据**：第17课（中枢/走势类型/走势必完美）、第37课（趋势背驰 a+A+b+B+c、
   c≥2中枢、c创新高、c形成类区间套）、第29课（区间套精确定位、一买绝对安全）、
   第24课（盘整背驰/MACD辅助）、第62课（笔/分型）、第64课（类背驰）、第67课
   （线段终结两情况=不可判定性）。
3. **边界条件**：本结论的有效域 = 缠论定义域（L0）。若 a0 取线段（as-is）则最底层
   一买不可表示；若不引入确认下放则「该等 vs 被切走」不可区分；经验有效性（L2/L3）
   需实装后回测，未回测前不成立。
4. **下游推论**：若离开段不再被切走且确认下放落地，高级别 type1 应从近零回升 → 自下
   而上涌现升级（`project_t_emergence_upgrade_ab`）与做空腿确认（`project_t_short_close_level_mismatch`）
