### 0.1 与螺旋枚举的方法对照

**关键差异（本文档存在的理由）**：螺旋 D∞ 的 ε 坐标是 ℤ/2 对合——群论上 τ 把多头帧映为空头帧，
**对称**。但会计运算在**线性 ℝ₊ 载体**上展开：多头持正股数（可 earning 增仓），空头持负股数
（earning 需"挣负股数"，L0 不可构造）。**τ 对称在 D∞ 几何中成立，在会计载体中破缺**。故从会计
运算独立枚举**必然**揭示螺旋 ε 细胞欠枚举的 τ-破不变量。这不是螺旋枚举的错误——是螺旋的
**定义域（D∞ 对称几何）⊊ 会计的定义域（D∞ 几何 × 载体凸性）**。

## 第 1 部分：会计层独立枚举

### 1.1 守恒类（4 条）

**AI-1（股数守恒）**：`Σ active voice.units = N_base`，每 bar 成立。
- 前置：任意操作前 Σ=N_base。后置：spawn 父−m 子+m / close 子归还父，Σ 不变。
- 不变量：单位只在级别间转移，不创造/消灭。τ-极性：**对称**（多空 voice 同记 units）。
- 投影：T₃₄/N8 → 槽 {r}（σ-不变 Casimir 在操作语境）。**已覆盖**。

**AI-2（NAV 价值中性，无条件）**：同价 c 操作前后 `nav = free + Σ多头 units×c + Σ空头 capital` 不变。
- 前置：nav_pre。后置：卖出 m@c 多头项−m×c、现金项+m×c 净 0。
- 不变量：**无条件**（不依赖盈亏/池竭/earning）。τ-极性：**对称**（c 对多空同价）。
- 投影：T₃₅/N8 → 槽 {φ,r,ε}（操作实现层）。**已覆盖**。

**AI-3（双层记账两侧一致）**：一笔物理交易在父子两账本单位增减相抵（防单边记账 bug）。
- 前置：物理量 m。后置：父 units−m ∧ 子 units+m，| 父Δ+子Δ |=0。
- 不变量：物理一笔 ⟹ 会计两视图，和为零。τ-极性：**对称**（记账结构与方向无关）。
- 投影：T₃₃/N8 → 槽 {φ,r,ε}。**已覆盖**。

**AI-4（递归链守恒，任意深度）**：父+子+孙+…units = N_base，对任意嵌套深度成立。
- 前置/后置：T₃₄ 归纳不依赖深度。不变量：守恒对 depth∈[1,7] 实测无关。
- τ-极性：**对称**。投影：T₃₉/N8 → 槽 {r}（自相似塔 + Casimir）。**已覆盖**。

### 1.2 重定基类（3 条）

**AI-5（N_base 双向重定基）**：`N_base ≡ 运行态在手单位聚合`，earning N+Δ / 亏损 N−δ，**同源一笔**。
- 前置：N_base（运行态，非建仓常数）。后置：earning 闭端 N+=Δ ∧ parent.units+=Δ 同源；
  亏损否定线 N−=shortfall ∧ parent.units−=shortfall 同源。
- 不变量："恒定"= **不主动加仓**（A₃，26 课），非数量不可变；`n_base±Δ` 与 `units±Δ` 同笔。
- τ-极性：**半破缺**（亏损侧对称，earning 侧增 N 仅多头——见 AI-10）。
- 投影：T₃₈/A4 → 槽 {φ,r,ε}（N 不主动加仓/双向重定基）。**已覆盖**。

**AI-6（涌现重组 N 不变）**：root_emergent_ladder 上移时 units/NAV 严格不变（1e-9 容差）。
- 前置：root@k。后置：root@k+1 ⊃ {原 root = child}，物理交易=0 ⟹ units/NAV 不变。
- 不变量：relabel = 重新读数（A₃ 禁加仓），与 AI-5 重定基**正交**（一个改标签，一个改物理量）。
- τ-极性：**破缺**（多头根爬 Up / 空头根爬 Down，方向相反——M5 τστ⁻¹=σ⁻¹）。
- 投影：T₃₀/A5 → 槽 {r}（根级别涌现），方向不对称内嵌 M5（{r,ε}）。**已覆盖（含 M5 编号缺失）**。

**AI-7（M=N 同股数翻转）**：子/根 voice 翻转 = 会计断面 cascade settle，单位数不变。
- 前置：units_pre。后置：旧方向关闭 + 反向开启，units_post==units_pre。
- 不变量：翻转 ≠ 加减仓（M=N）；翻转 ≠ 立即开新仓（等买卖点，a0 层首尾相连等待短）。
- τ-极性：**对称**（翻转是 τ 作用本身，M=N 守恒在 τ 下不变）。
- 投影：T₄₀（prove_t14_root_flip 共生覆盖 units_pre==units_post）→ 槽 {r,ε}。**已覆盖**。

### 1.3 条件恒等类（2 条）

**AI-8（child.P&L ≡ cost_reduction，条件恒等四去向）**：仅 {盈利 ∧ shortfall=0 ∧ cost_pool 足} 时
朴素恒等；一般情形分裂为 `cost_pool_reduce + earning_excess − shortfall_loss + free 沉淀`。
- 前置：close 时刻 leftover=capital−u_back×c。后置：四去向唯一分解。
- 不变量：双视图一致仅在**关闭时刻**成立；存活期父子各持不完整视图。
  **无条件成立的只有 AI-2（NAV 中性）**——AI-8 是 AI-2 的有条件特例。
- τ-极性：**对称**（恒等结构与方向无关，但 earning_excess 去向受 AI-10 约束）。
- 投影：T₃₇ → 槽 {φ,r,ε}（条件恒等）。**已覆盖**。

**AI-9（cost_pool 单调不增）**：降成本池只降 cost 或物化为 shortfall，**不产生负 cost_reduction**。
- 前置：cost_pool≥某值。后置：盈利→cost_pool 降；亏损→leftover=0 ⟹ cost_reduction=0，
  亏损物化 `n_base−=shortfall`（单位永久缩水）。
- 不变量：cost_pool 单调不增（向 0 及负方向，earning 阈在 ≤0）；亏损**不**反向充池。
- τ-极性：**对称**（单调性与方向无关）。
- 投影：**无专属槽**——最接近 T₄₈ Casimir（{r}），但 cost_pool 非 σ-不变守恒量而是**单调耗散量**。
  → **弱遗漏候选 TC-3**（§3.3）。

### 1.4 τ-破类（手性不对称，3 条）★

> 本节是会计层相对螺旋 ε 细胞的**核心增量**。螺旋 {ε} 细胞只列 3 条（T₂₄/T₃₆/T₂₇），

**AI-10（earning 构造不对称）**：cost≤0 后多头 `parent.units+=dq`（可构造）；空头"挣负股数"L0 不可构造。
- 前置：cost_pool≤0。后置：多头买入 Δ 正股数 N+=Δ；空头仅 `nrf_short_earning_hits+=1`（不增 units）。
- 不变量：**方向是 voice 属性，earning 金额守恒/极性翻转与方向无关（对称）；但资本化构造依赖
  载体凸性——线性 ℝ₊ 载体下空头侧撞 L0 墙（破缺）**。若给空头增 units 会破坏 AI-1 守恒。
- τ-极性：**破缺**（多可构造 / 空不可）。解除条件：换凸性载体（期权 DTE，`project_put_option_short_earning`）。
- 投影：T₃₆ → 槽 {ε}。**已覆盖**（螺旋 ε 细胞唯一显式 τ-破定理）。

**AI-11（MtM 根空头口径不兼容）** ★**强遗漏候选 TC-1**：根空头（parent=None）用**外部市场负债**口径
`nav = free + (capital − units×c)`；子空头用 **frozen-internal** 口径（capital 冻结，递延到回补）。
**同一 voice 不可兼容两套口径**——短父 spawn 长子在 MtM 下破坏守恒 +m×c。
- 前置：根 voice 经 T14 翻空（parent=None）。后置：根空头是**叶节点**（不嵌套降成本 E 跳过，
  `unified_necessity.rs:106-107,1376-1378`）；MtM nav=capital−units×c 真实兑现（翻转/平仓同价 c 守恒）。
- 不变量：**会计口径是节点拓扑位置的函数**——根（外部市场）vs 子（内部冻结）口径不同，
  且**不可混用**（T8 frozen-internal ⊥ T14 MtM-external，同 voice 不兼容）。这禁止了一整类操作
  （根空头嵌套 E）。
- τ-极性：**破缺**（多头根可嵌套 E spawn 子；空头根是叶节点不可嵌套）。
- 投影：**无专属槽**。最接近 M5（τστ⁻¹=σ⁻¹，空头根爬 Down，{r,ε}），但 M5 只刻画**涌现方向**
  （几何），AI-11 刻画**嵌套禁止 + 口径不兼容**（会计，更强）。M5 标为"编号缺失"，但其会计内容
  从未定理化。→ **强遗漏候选 TC-1**（§3.1）。

**AI-12（NAV 估值口径手性不对称）** ★**强遗漏候选 TC-2**：逐 bar NAV 的未实现 P&L **多头逐市**
（mark-to-market）/**空头取冻结 capital**（非逐市），未实现 (basis−c)×units **递延到回补结算**。
- 前置：价格变动 Δc。后置：多头 equity 逐 bar 反映 Δc；空头 equity 冻结，浮盈→低估 / 浮亏→高估。

  **终态 final_nav 正确**（全回补后双通道归零）。GAP 仅逐 bar 口径。

- 投影：**无专属槽**。这是 AI-10 的**对偶**——AI-10 是"盈利资本化"的 τ-破，AI-12 是"浮动估值"

### 2.1 定位类（7 条）

**TI-3（先势后定位时序）**：`compress_bar ≤ confirm_bar ≤ bar`，时序不可颠倒。

**TI-4（向心回溯方向）**：confirm 沿 φ≡0 母线**向心**回溯已 settle 内圈 type1，到成本门级别终止；
前向 confirm 是几何错误（type1 在内圈过去，够不着）。
- 前置：外圈 candidate@k。后置：confirmed = `since<bar ∧ helix`（母线逐圈贯通）。

### 定理 T₆₃（cost_pool 单调不增：降成本池的耗散单调性）｜= TC-3 弱，载体层 {r}

**陈述**：降成本累积池 cost_pool（父 voice 的成本基准聚合）**单调不增**——盈利回补降 cost_pool，

单调不增。∎
