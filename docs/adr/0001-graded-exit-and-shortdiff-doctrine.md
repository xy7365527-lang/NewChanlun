## 裁定条文

### S1 声部 = 一次建仓
声部节点 `v = (carrier, γ, σ, n)`：carrier 走势/容器，γ 入场证书，σ∈{+1,−1} 方向，n generation。
出处：完整的策略.pdf §8。注：缠论的全互斥定义策略.pdf §三 写作 `v=(c_v, η_v, σ_v, n_v)`，异名同构。
声部一经建立不可变；出场即声部终结，不存在"同一声部改仓"。

### S2 本级反向证书：typed exit 二分
- **一类反向证书**（须经**区间套 + 背驰确认**方成立）⇒ `CloseRoot`：该级该方向全部清仓。
- **三类反向证书** ⇒ `ReduceCore`：核心仓减仓，不全清。
出处：完整的策略.pdf §9 typed exit 枚举 `{CloseRoot, ReduceCore, CloseShortDiff, RiskExit, Hold}`。
注：确认逻辑（区间套/背驰）属证书成立层；出场层只消费已确认证书。二类反向证书不构成本级出场证书，其合法卖出身份仅短差、开空两种（见 S7）。

### S3 祖先证书 ⇒ 子树清仓（Close-Subtree）
结构不变量：`A_{t+1} = AncOK[(A_t ∖ D_t) ∪ O_t]`，`AncOK(S) = {v ∈ S : Anc(v) ⊆ S}`——父声部终结时后代被 AncOK 剪除，即子树清仓。
出处：完整的策略.pdf §8；缠论的全互斥定义策略.pdf p.24/27「Eat 命题」。
"确认自下而上、清算自上而下"为实现层流程补充【推断，非 PDF 教义】。
注：S3 清算为自上而下级联，S7「跨级别独立」为自下而上不级联——方向相反、不冲突。

### S4 次级别卖点不构成本级出场证书，至多短差
次级别反父方向证书走**短差开启通道**（first-match 互斥化下，短差开启仅在风险强平、本级证书平仓（根清仓/减核心）、短差平仓均未命中时成立，与本级平仓通道互斥），不触碰父声部。
出处：缠论的全互斥定义策略.pdf p.18/27；推导完全互斥分类.pdf §3。

### S5 短差与次级别操作：仅方向/角色等价
- 保留（PDF 已证）：「父级多头的短差 = 次级别做空；父级空头的短差 = 次级别做多」（推导完全互斥分类.pdf §3）。
- **删除**："L1 完整持仓周期 ≡ L2 一次短差"（周期同构）——PDF 零命中，转研究猜想（见"遗留问题"）。
- **删除**："总仓位=声部之和时短差自动涌现"——被多空对冲.pdf 定理1（净额 NAV 只能识别净头寸）与不可能定理证伪：对冲期间净和 `(+Q)+(−Q)=0`，短差在净额视角不可见。
- 短差为**显式独立机制**：专用谓词 ShortDiffEntry/ShortDiffExit、专用**短差开启/短差平仓通道**、专用出场类型 CloseShortDiff、分账本双腿 `P_sep = ∏_{v∈V}(R≥0 e_v^+ ⊕ R≥0 e_v^−)`。

### S6 短差基线表示 = 子级反向对冲声部
父级（ℓ+1）持仓期间：ℓ 级卖点 ⇒ 开 ℓ 级**反向**声部（`σ_u = −σ_{p(u)}`，父仓不动）；ℓ 级买点 ⇒ 平该反向声部。
出处：缠论的全互斥定义策略.pdf §三.3（p.17/27）「父级多头时，卖点开短差空头，买点平短差空头……这就是缠论买卖点在多空双开、多级别多重赋格里的操作语义」；推导完全互斥分类.pdf §5 分账本头寸空间。
**不采用**"同向声部清仓再入场"表示：二者净头寸轨迹不等价（对冲净头寸不变、清仓净头寸真实下降），不是同一策略的两种记法。

### S7 三本账：卖出动作的身份归属必须唯一（用户裁定，2026-07-23 终审）
- **动作全集（完全互斥）**：动作空间恰为 {开多、平多、开空、平空、开短差、平短差、不交易}（缠论的全互斥定义策略2.pdf p.16/37）。归属唯一：开多/平多→本仓账；开空/平空→空仓账；开/平短差→短差账（父仓不动 (+Q,0)→(+Q,−Q)）。互斥穷尽由三层保证：角色层 Σ_R 1[Role=R]=1（推导完全互斥分类.pdf p.4/19 §4）、状态层 X=⨆C_Θ⁻¹(z)、谓词层 Σ1[C_j]=1（另有 Rust mutex.rs 2^10 机器穷举）。
- **本仓账**（按级别分层）：开多首开/加仓记本仓账。只在该级别一类卖点全平——全平序是**级别内命题（必须，非应当）**；该级别新走势类型确认时，该级别本仓=0（状态断言）。一类点当场全平、允许当场反手，无「新走势类型确认」前置。二类点上本仓仍有残余 = **执行异常**：兜底强平并记异常，不是教义选项。
- **短差账**：回抽处高抛低吸，不动本仓教义账；父仓不动 (+Q,0)→(+Q,−Q)。
- **空仓账**：开空/平空同属空仓账（蓝图对应物：反向根 + P6/Open Root）。**首开反向仓标准位 = 一类卖点**（多重赋格的多空双开要求；一类点本身经背驰+区间套确认）【标记：可复检】；**二类卖点 = 第二入场/加仓（加空）位**。
- **风险强平**：跨账动作必须拆分为单账户动作序列，每条恰一身份（venue 侧净额投影只允许在最外层）。
- **二类点 B/C 消歧**：父声部 active⇒记短差账；无 active 父⇒记空仓账（子声部.pdf §15 + CONTEXT.md 反向根条款；#177 裁定三）。
- 推论：二类点合法卖出身份仅有短差、开空两种；「二类要不要全平」为混账产生的伪问题。
- **跨级别独立**：多级别持仓各级别各记各账；低级别走势终结不强制处理高级别仓位；低级别点位上对高级别仓位的高抛低吸记短差账，不属于平仓。
- **做空条款（市场依赖）**：本系统目标市场可做空，按「启用」处理；反向腿为教义正常条款，非可选项；禁空市场执行层降级条款本轮暂缓不写。

## 记账与资金约束（S6 推论）

- 账本必须**分腿**记录（多腿/空腿各自独立）且按级别分层，禁止只记净额。
- 毛暴露 ≠ 净暴露；资金分配递归按**毛暴露**约束：子对冲额度 ⊆ 父级短差额度，否则锁仓可无限套娃。此条为 #139 硬约束。

### 执行层让步与标记（#178 裁定，2026-07-23）

- **父仓不动证实层级**：v1 = 语义/记账层证实（现有）+ 双写断言（新增）；fill 层证实 = v1 显式让步。自指记录：ADR 行34（S5 删除条）批判净额视角，而 v1 执行层仍净额单出口，fill 级「父仓不动」不可证实，挂账。
- **档B（逐腿下单出口）标记**：「不是最严格的实现，以后再搞」（用户原话，2026-07-23）。本轮拦下理由：funding/borrow 毛暴露口径在蓝图与本 ADR 均无明文，换出口 = 发明新钱规矩，违反「不重设计、只对准蓝图」原则；待蓝图补齐该口径后单独立案。

## 出场通道优先级（#139 直接输入）

first-match 互斥化（`C_1=P_1，C_j = P_j ∧ ⋀_{k<j}¬P_k`，兜底为显式 Hold 裁决）：

> 风险强平 ≻ 本级证书平仓（内部按 S2 二分：CloseRoot/ReduceCore）≻ **短差平仓 ≻ 短差开启** ≻ 开仓 ≻ 记录 ≻ 加仓 ≻ Hold（兜底）

出处：缠论的全互斥定义策略.pdf p.18/27（P1–P8）。
祖先耦合**不是**通道谓词，由活动集层 AncOK 实现；若 #139 需显式通道，建议置于风险强平之后、本级证书平仓之前【推断，实现决策】。

## 遗留问题（研究票，不入教义）

**周期同构猜想（条件化）**：ℓ 级一个完整持仓周期是否恒等于 ℓ+1 级的一次短差？
关键不成立点（用户指出）：**次级别走势类型在上一级别可能有、也可能没有买卖点投影**——次级别走势类型可完整走完而父级别不产生任何证书（如父级中枢内部震荡）。故同构至多在"子周期端点均有父级可见投影"的条件下成立，需形式化证明/证伪（候选工具：外部数学证明工位）。

## 修正案一：短差重定义与点级别定账（2026-07-25，用户逐题终审，裁定票 #272）

依据：`chanlun/review-results/shortdiff-center-context-doctrine-20260725.md`（172 处短差原文条件集，一级源行锚抽验）。本节条款与上文冲突时**以本节为准**；未点名修订的条文（S1–S3、S5 删除条、记账与资金约束、执行层让步）不动。

### 修1 短差 = 减仓回补（唯一定义），S6 原表示废止

短差唯一形态 = 本级仓先减后补（先卖后买）。开空腿形态原文零命中（172 处检索；唯一命名程式 014:42 = 次级别一类卖点减仓、一类买点回补）。**S6「短差基线表示 = 子级反向对冲声部」（父仓不动 (+Q,0)→(+Q,−Q)）自本修正案起废止**；实现该形态的机制夺「短差」名、移交多空双开线处置（删除或更名归对冲由该线裁定，出场图不越权）。机制分两域（#273 名分盘点查实）：**#149 域**（SplitLegLedger / channel.rs P5 / OscillationBook，center_oscillation 默认关，生产零开火——原括号「休眠中、从未生产开火」仅指此域）；**散装域**（`classify_vertical` 反父证书 δ=−σ_p → interp fold 规则2/3 + fill.rs 三写入点，**生产开火 204/194 笔**，原括号表述对此域不成立，2026-07-25 勘误）。两域同为修1 废止形态，处置路线（词汇对齐 / 行为对齐）由多空双开线裁定。S6 的不可能定理论证保留有效——它证明的是「开空腿 ≠ 减仓回补」，恰是本条废止的理由之一。

### 修2 两个操作分立（原文「短差」一词混用，本系统拆开）

- **狭义短差**：本级中枢震荡高抛低吸。触发 = 本级信号（盘背 / 本级买卖点）；语境 = 本级中枢震荡；**趋势腿自动禁区**（震荡不在则信号不生，无需显式开关）；收手 = 三类买卖点（高抛后若出三类买点，于三类买点处回补——049/068）。
- **14 课程式**：大级别买点介入 + 次级别一类卖点减仓 / 一类买点回补（014:42）。**无走势类型限定**（趋势中合法）；其次级别一类卖点本身是次级别走势类型的合法点（三类买点形成前、回试段起点正是它）——属**次级别账自己的操作**，非本级短差。049 课「中枢上移差价不能做」禁的是本级差价，与 014:42 不冲突。

### 修3 点级别定账（旧 B/C 消歧退役）

**信号的级别 = 操作的级别 = 账的级别。**点自带级别身份（#134：级别身份是事件，确认时刻才存在）；「一个点只有一个级别」⟹ 归属唯一自动成立，不再依赖 ambient 环境判断。**S7「二类点 B/C 消歧：父 active⇒短差账；无父⇒空仓账」自本修正案起退役**，由点级别定账替代。

### 修4 每级一本账（三本账坍缩），S7 三本账条修订

本仓账 / 空仓账 / 短差账坍缩为**每级一本双向账 + 信号分源**：
- 一类点 ⇒ 全平（该级该方向全部清仓，原 CloseRoot 条不动）；
- 盘背 / 震荡点 ⇒ 减补（狭义短差，该级账内的减仓回补动作）；
- 二类点 ⇒ 不动 / 加仓（原条不动）；
- 次级别一类点 ⇒ 记次级别账（含首开反向，原空仓账条款级别内化——「首开反向 = 一类点」不变）。

分账禁净额、级别为分账维度、毛暴露递归约束（子对冲额度 ⊆ 父级短差额度）、现金单一根池：**全部不动**（每级账内多/空双腿仍分记）。

### 修5 账户层扁平、依存层递归（不违背递归原则的边界声明）

每级一本账只压平**账户层**；三条跨级通道**不动**：命（S3 祖先证书子树清仓，AncOK 存亡连坐）、信（区间套确认 / 级别身份事件）、钱（修4 保留的毛暴露额度树 + 现金单一根池）。

### 修6 点的生命周期（候选-确认）

背驰 = 一类点**候选**，非点本身。候选 → 区间套确认（点出生，按级别定账）；或 → 三类买卖点坐实（中枢破坏/中继，候选枪毙，无动作）。29 课转折三分类（中枢扩展 / 更大盘整 / 反趋势）：背驰不保证反转，「背了又背」合法存在。定账只消费已确认的点——与 S2「一类反向证书须经区间套+背驰确认」同条。

### 修7 短差降成本 = 组合层面读法

父账成本不被会计动作拉低；「短差降成本」= 次级别利润对父仓成本的经济对冲，**报告层呈现，不进交易决策**（与 S5 不可能定理删除条自洽）。

### 补充二：狭义短差实装口径（2026-07-26，用户逐题终审，原型佐证）

原型：prototypes/no-gate-two-books（四场景+对抗用例，独立验证「无门」成立，三条小裁定源自对抗发现）。

- **触发**：本级中枢在场（第三段重叠完成=中枢出生事件）+ **次级别买卖点**（B 裁定；盘背降为辅助参考，非触发必要条件——本口径比修2 字面宽，登记在案）+ 边界侧（上沿高抛/下沿回补）。
- **无互斥门**：本级账与次级别账各自只查自己前提；两前提同时满足可同时开火；敞口叠加归资金通道（毛暴露递归/根池额度）。「归属唯一」=每个动作恰落一本账（**仓位级别定账**），**非**「一个点只许一个动作」；信号可跨级。身份路由门=零（旧 B/C 消歧不再以任何形式复活）。
- **中枢=事件（#474 修订）**：出生=第三段重叠完成；死亡=三类买卖点；本级一类点只广播走势类型终结，**不清段序列、不杀中枢**，新走势类型的中枢边界由塔链自身给出。
- **挂起短差出口二分**：回补（下沿；或三类买点处收手回补）/ 终结（本级一类点全平、三类卖点、中枢破坏——承诺作废，**禁无本级买点证书复活仓位**）。
- **成本口径（修7 细化）**：本仓成本基不动（唯二出口：全平清零、加仓重算）；短差往返盈亏记该级账内「短差盈亏」标签桶（报告层呈现 + 阶段机输入——持仓阶段对齐另立 spec 票 #287）。

### 补充三：持仓阶段机对齐（2026-07-26，#287 裁定，用户逐题终审）
