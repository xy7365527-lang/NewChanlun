# 反向根准入：证书即准入，且仅限最高级别走势类型

反向开仓在赋格树里只有两种身份（`docs/formal-chain/最高级别走势类型.pdf` 的完全分类）：头顶有父容器即短差（挂父名下），头顶无父即反向根（自立根声部）——后者只可能出现在最高级别走势类型上。我们裁定：反向根的准入就是本级别反向证书本身（证书已含区间套＋背驰确认，区间套确认取第 27 课背驰段语义、不得等走势完成），**不另设门**；时序为先平后开（旧根子树清仓，再立反向新根）。

## Considered Options

- **口径 B（证书外另设门）**：被否。谱系 557 的 all_sell 无门做空成绩 L3 PARTIAL，说明问题在缺区间套确认口径，而非缺额外闸；在已含区间套＋背驰确认的证书之上再加门，是重复计费。
- **等走势完成再确认**：被否。最高级别完成样本稀疏，会重演谱系 556 的顶层腿冻结——故钉死背驰段语义。
- **允许跨级别双记（同一声部同时在两级别有会计意义）**：被否。分类互斥完备（有父⇒短差、无父⇒反向根），该情形不存在，账本无需新结构。

## Consequences

- 准入口径牵动全部回测成绩，改动即重跑基线——难逆转，故记档。
- 词汇表新增「反向根（Reverse Root）」，与「短差」构成互斥完备对（见 `CONTEXT.md`）。

## 修正案一（#157 grilling 裁定）：涌现互斥时序定理与机检不变量

**定理**：反向根在世期间，涌现天花板不可上移。更高级别涌现的必要前件（本级走势类型完成＋反向重叠成更高级中枢）包含本级买点证书成立；而买点证书即反向根的对称平仓。时间线恒为：卖点证书 → 反向根开仓 → 买点证书 → 反向根平仓 →（此后才可能）涌现上移。

**由此消解的整族问题**（后来者勿重新发明）：
- 「持仓中天花板上移后身份怎么办」（改挂/认父/降格为短差/身份冻结）——场景结构上不存在；
- 「存量反向根额度是否追溯受新父短差额度约束」——无腿能在世跨越涌现边界，追溯对象为空；
- 「身份是事件时点属性还是持续属性」——两种口径在可达状态空间内无差别，无需裁定。

**恰好性为事后陈述**：涌现后回望，已闭合的反向根腿在账上占据的位置恰好等于新参照系下一条短差。身份是参照系视图而非存储事实——账本零身份字段教义由该定理背书。

**机检不变量（裁定：立 assert，不作信任假设）**：回测引擎中，「涌现上移 bar 上存在在世反向根」一经命中即**显式失败**。定理由递归结构保证，但引擎是实现出来的递归——该断言是定理的哨兵；命中即证明涌现判定或证书时序存在实现级 bug（谱系 556/557 的教训：响亮失败优于静默假设）。

### Considered Options（修正案）

- **信任定理、不设 assert**：被否。断言成本近零（涌现事件极稀疏），而静默假设正是谱系 556/557 两次腐蚀的共同形态。
- **处理「持仓跨涌现」的改挂/追溯机制**：被否。为不可达状态造机制，且隐式改挂正是 user story 13 要防的静默腐蚀方向。
