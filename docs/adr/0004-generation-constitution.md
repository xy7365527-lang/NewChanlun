# 世代宪法：名分四态 + 现役线名单单源

仓库长期两代代码混居（v1/dual 与 π 同居 `fill.rs`）、`theta_v0` 模块住着 π 引擎、75 worktree + 141 分支的坟场无人收——根因是**名分没有单源**：什么代码是现役、什么该退役、什么是垃圾，全凭口耳相传。#467 原 SPEC 因此误诊（给不可达的 v1/dual 出场门设计迁移方案，实施核证才证伪前提）。我们裁定：立**名分四态**（现役 / deprecated 待退役 / 孤儿待删 / 垃圾待清）的机械判据，并把现役线名单（引擎 = π、git 线 = main、工位 = 白名单制）写成单源文本，落 `docs/agents/generation-constitution.md`；配开票门文本牙——触及 deprecated/孤儿代码的实施票未核名分不得挂 ready-for-agent。

## Considered Options

- **只清不立法**（直接把 v1/dual、坟场删掉）：被否。没有判据单源，删完还会再长——#467 误诊证明问题不在「没删」而在「无名分可依」。
- **判据写进 CONTEXT.md**：被否。CONTEXT.md 纪律是纯词汇表（glossary），机械判据与名单是流程/流程细节，放词条只剩一句话 + 指针。
- **工位单立第五态**：被否。worktree/branch 是容器不是名分，容器两态（在跑/残骸）足够，内容物按四态判。
- **机械门（CI/cron 强制核名分）一并立**：缓议。文本门零成本今天生效；机械门留给防复发票（#506）裁量，不预设。

## Consequences

- **#499（v1/dual 退役）与 #506（防复发）解锁**：退役有了名分依据，防复发有了文本门作为机械门的基线。
- **「世代」与「代际」分词**：代码谱系称世代，声部嵌套代数仍称代际（Generation, n），两词不混，已入 CONTEXT.md 词条互指。
- **深度分叉残壳**（4 个领先 main 1171 的 4 月 worktree）按一次性条款打包出仓再删，不立常例。
- **现役名单锚函数名不锚行号**——行号漂移已咬过一次（#467 原 SPEC 行号全漂）。
- **gap3-rework-codex9-fix 判残壳**：「真实工作线是 gap3」的过期记忆至此作废，main 唯一。

### 补充一：名分第五格「新生入口待驱动」（2026-07-29，用户裁定，#707）

- **缘起**：#575 消费方接线三票（#637/#638/#639）的新立消费入口机械落 §1「deprecated 待退役」格（生产零可达但有测试调用者），语义方向相反——影子评审 #638 grep 实证三面同处境（调用点全在测试区、生产零调用者）。判据把「新生入口、驱动链未接」与「退役残留、只剩测试吊命」混为一格；不修则每张接线票机械落 deprecated，名分读数系统性失真，与首要功能（让精力不流向死代码）反向——新生入口会被误判成该看病/该清的对象。
- **裁定**：§1 补第五格「新生入口待驱动」——机械判据 = 有票号 ∧ 入口已在生产代码立起（非测试段引用该类型）∧ 生产零调用者 ∧ 票面在案登记驱动链归后续票。转态规则：驱动链接上（有非测试调用者）⟹ 自动转现役；后续票作废/长期搁置 ⟹ 降格 deprecated（裁定时点名）；票面驱动登记失实 ⟹ 按原四态判。
- **与主文「工位单立第五态：被否」的关系**：不冲突——被否的是**容器**（worktree/branch）的第五态，本格是**代码实体**的名分；容器仍两态，内容物按五态判。
- **回填**：#638 resolution 与实施报告 §6 的「名分张力上浮 #500」登记按本格核销；#637/#639 无该登记（sanity 复核订正——两票 resolution 与报告均无此语），其消费入口按本格直接判定。三面（`CenterBook::consume_death_certificate` / `signal::drain_pan_div_short_retrace_observations` / `trading::ThirdPointBook`）自本裁定起判为「新生入口待驱动」，驱动链归 #575 后续票在案。
- **背景约束在案**：三面均处「消费入口已立、驱动链归后续票」的合法中间态（#637 裁定 3A、#639 裁定 B、#638 裁定二）——票面「生产调用点 ≥1」按「类型出现于生产代码即达标」的字面口径结，与机械判据的「非测试段引用该类型」条款同源。
