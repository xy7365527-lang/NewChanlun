# ADR-0006：N0 语义裁定——原生 Cand^δ = 结构宽候选，Sub 边 = C⊆C

map #529（塔内原生化长线）缺口清单 N0：`Cand^δ` 语义二分未统一（typed 结构宽候选 vs 旧 `cand_delta` 力度确认），Sub 边语义两形态并存（C⊆C vs I(A)⊆D_parent，gap-audit §2.G4 内部不一致②）。N1 起全部塔内原生实装待此定义。#537（grilling，编排者 2026-07-28 裁定）两问一次裁定；本 ADR 是该裁定的文书落库。事实底座 = `chanlun/review-results/e2eo-lineage-synthesis-20260728.md` 与 `nest-tower-native-gap-audit-20260717.md` §2.G4/§5。

## 裁定文本

1. **原生 `Cand^δ_ℓ` = 结构宽候选**：级别 ℓ 的背驰段**结构**候选——一次破中枢结构候选的完整证据包（破中枢 ∧ A 配对 ∧ 映射成立）。**力度确认不进候选身份**：力度是候选之后的独立门，各级门政策（level0 免门 #522、V2 rung 力度门、终端背书）照旧一级一裁，定义不替门做决定。
2. **Sub 边 = C⊆C**：相邻级区间套包含 = 子级背驰段区间 ⊆ 父级背驰段区间，双边同口径 `interval_b`（`source_index` 坐标域，闭区间包含，相切算包含——#246 相切=重合全域生效）。

## 依据

问 1（Cand 身份）：

- **#522 自洽**：level0 免门永久保留（2026-07-28 裁定）= 力度确认是「门」而非「候选定义」；若力度焊进候选身份，84.11% 免门信号（#450 实测）连候选都不是，与 #522 当场矛盾。
- **E2E-O 五阶段已分离**：`ObserveCandidate_at` 只产结构候选（D1-D3），力度在 `ReviseEvent_at`/`CloseFloor_at` 阶段合取——原生定义照五阶段切，天然是宽候选。
- **塔对象自述**：`CandDeltaEvent` 注释即「背驰段谓词判定（一次破中枢结构候选的完整证据包）」。
- **保留门的自由**：两语义仅 ℓ=0 有等价对拍（P1，`recursive_tower.rs:2215-2267`），ℓ≥1 无对拍；选宽候选不预设任何级别必须过力门。

问 2（Sub 边判据）：

- **教义形象**：区间套 = 「父背驰段内部的背驰段」（027:38/027:46，roadmap:62 已冻结）——套娃是同口径区间逐级相套，非拿子的此种段套父的彼种段。
- **机器可判自洽**：同口径包含谓词与 #246 相切=重合在同一坐标域同一定义族（包含/重合/缺口一套话）；`is_sub` 闭区间口径（`nest.rs:65-67`）可直接提升进塔（N2 的工作）。
- **与生产邻近侧同形**：typed 路径已在用 C⊆C，原生定义对齐它，audit §6 bit-exact 互验少一道口径换算。

## Considered Options

- **力度确认进候选身份**（旧 `cand_delta` 硬门形态）：被否——与 #522 冲突；把门焊死进定义，剥夺各级门政策的选择自由。
- **I(A)⊆D_parent**（旧 nest 门形态）：被否——两边是不同种对象（子 A 段区间 vs 父 D 段区间），与教义「套娃」形象不符；且是 nest 内部两条路径本就不一致（G4 内部不一致②）的遗留臂。**照实登记代价**：原生链与旧 nest 门由此不是同一谓词；旧臂留 nest 对照侧一字不动，ADR-0005 独立性不受影响。
- **两问分票**：被否——同一语义簇（候选身份 + 其包含边），audit N0 明列为同一裁定前置，分票只增簿记。

## Consequences

- **零代码变更**：本裁定是纯定义，不动任何既有实现；nest 管线三套 `Cand^δ` 实装原样保留（ADR-0005 独立对照身份不变）。
- **N1 解锁**：背驰段区间对象塔内原生载体的语义前提已备（载体承载结构候选之区间，Sub 边判据已定形），N1 票随即出笼。
- **#59 雾项「三套 Cand^δ 收敛」前提已备**：原生定义给了三实装可对齐的参照定义；对齐/口径声明的具体处置归 #257 线另裁，本 ADR 不预拍。
- **定义级约束成对生效**：本裁定与 #535 因果形态封口（四类非法近似禁入）共同构成 N1 起实装票的两条定义级验收约束。
- **力度门政策不变**：level0 免门（#522）、rung 力度门、终端背书原样；任何级别门政策的调整须各自另裁。
- **程序性**：本 ADR = N0 裁定文书；`cert-bsp-binding-ruling-DRAFT-20260717.md` 不动（其待裁项 1/3 已由 #534 批复）。
