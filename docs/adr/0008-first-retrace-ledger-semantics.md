# ADR-0008：买卖点身份账本语义——快照身份 / 三态 / 日志真相 / 三态三操作门户

#465 裁定 A（抽通用内核 + 建买卖点身份账本）之 T2：first_retrace 语义空白八条。#574（grilling，编排者 2026-07-28 在场逐条裁定）八问一次裁定；本 ADR 是文书落库。契约全文 = `chanlun/review-results/issue574-semantic-contract-20260728.md`；教义依据考据 = `chanlun/review-results/issue574-reentry-doctrine-research-20260728.md`（018:64/101:76/020:62/027:16/024:36/020:54-56 等原文锚逐字复核）；实装 spec = #620（`chanlun/plans/spec-kernel-and-retrace-ledger-20260728.md`）。前置 = 补充十三（四条边的框/判据锚框右边）、补充十四（出口三分/延伸无事件/禁第二种终结）、补充十五（紧邻配对/禁止后扫替代）、补充十六（37:18 分档/消费矩阵）。

## 裁定文本

1. **身份与窗口（判同桥）**：身份 = （中枢四条边快照, departure move 索引）。快照注册时拍摄为**临时右边**；活着期间窗口不动（候选活着 ⟹ 价格在中枢外 ⟹ 中枢无延伸，行情物理保证）。结局三分：**Success → 快照转正**（临时右边成为中枢永恒右边；Success 事件即中枢死亡证明发中枢账）；**重回 → 快照作废**（中枢延续，下一代候选按延展后新窗口重新拍照）；**引擎改口**（重基/重切致窗口变或中枢消失）→ 处死记档进警报桶（CenterRebased，对标 RebaseVanished 先例）。中枢本体生灭归中枢生命周期账，本账不跟踪。
2. **多 departure 并存**：同一中枢同时刻**至多一个活跃候选**（严格相邻 retest = leave+1 物理保证新 departure 出现时旧候选必已判完；未判完而来 = provider 有病，报错拒收）。不同中枢各自并存；历史身份全留档。教义背书 = 补充十五「任一失败即 None，禁止后扫替代」（等下次 = 永不）：一身份一次机会，新离开 = 新档非补考。
3. **终态映射**：三态 = Provisional / Confirmed / NotConstituted{reason}。判败 = `NotConstituted{RetestReentered}`，语义四行：①候选从未成立（第一次回抽资格一次性已消费，020:62）；②中枢未破坏（018:64 定理三逆否、101:76）；③不派生任何中枢生命周期事件（补充十四）；④判败事件是盘背观测源（027:16 盘整背驰技术含义）。引擎改口 = `NotConstituted{CenterRebased}`（身份灭失族，语义分行）。终态后同身份迟到输入静默吸收 + 警报计数；残废输入注册期拒收报错（错误非终态）；Restart = 新档注册、谱系载荷记前任，不走桥迁移。
4. **restart 规则**：Success 后同一中枢**永禁新轮**（补充十三：死后任意穿越旧价格带不构成旧中枢三类点信号）；新中枢（含收编者）新离开 = 新身份新档；provider 给死中枢报新 departure = 报错拒收（账本自查死亡证明）。
5. **钟体系**：三钟——出生钟（registered_as_of）/落锤钟（terminal_as_of）首写不改，门卫钟（last_as_of）倒退拒收 + 警报；每条修订带知情时（as_of）；**位置进证据载荷不是钟**（三类点位置 = 回抽终点）；知情时 ≠ 位置，回测不用未来信息靠知情时保证。
6. **持久化**：**append-only 修订日志 = 唯一真相**（CompletedFreezeReducer 先例：幂等重放、冲突拒绝）；状态 = 日志折叠（active/consumed/restart_allowed 是投影不单独持久化）；快照仅派生缓存（带溯源、可校验、非真相）；拒收/警报另记 audit 流不进恢复路径；日志按 run/窗口分界带头 provenance，不承诺跨窗口身份连续。
7. **身份缺席**：**缺席 ≠ 消失**——沉默 = 未决（等回抽判决），永不设超时处死（= 发明教义外终结，踩补充十四红线）；消失仅两条显式路径：判决（行情亲口）/ 引擎改口（观察显式携带）；不需要 IdentityVanished 二分；prefix 重放一致性 = 日志折叠天然成立。
8. **消费门户（三态三操作）**：**未决 → 备战档**（位置 + 快照只读盯梢，024:36 次级别回切入点归交易层；名义「盯这里」非「买这里」，禁消费成买入信号）；**成功 → 成立档**（中枢死亡证明不问迟到——054:60 延迟合法；交易层证据包全套，迟到过滤归交易层自理 #587，本账不进口外部状态）；**判败 → 短差档**（盘背通道亚型签 + 三锁：键唯一/去重/账平断言，#606 S1 先例；失败处置通知名义 = 通知非信号）。消费方登记归 #575（无消费方不接生产）。

## Considered Options

- **右端可动桥（nest bridge_identity 同构）**：被否。候选活着时中枢无延伸可桥（行情物理），桥为不存在的问题修机制；且判据锚定框（补充十三：价格只对该框 ZG/ZD），框换则证失指向。清算线「冻结成框 + 多 Owner」先例服务于押钱锚（补充十四/十五），分析层不押钱，改采「注册快照 + 成败定转正/作废 + 改口处死」。
- **RetestReenters 记 Invalidated（与 nest 终态同词）**：被否于名分——原文钉死唯一死法 = 三类点（018:64/101:76），重回 = 中枢延续语境（020:28-30/049:82/024:36），记「死」即发明第二种终结（补充十四禁令）。改立 `NotConstituted` 从未成立族（nest `NeverConstituted` 同族先例），机制仍终态吸收。
- **判败仅记事件不给终态**：被否——020:62 一次性会落空（晚到同身份输入无挡处）。
- **未决候选不入任何消费面（nest #64 Closed-only 原样）**：被否——024:36 原文序列（次级别一类点回补 = 该级别三类买点）使真实入场发生在判完前，备战档有教义操作语义；以「盯这里非买这里」+ 类型面隔离收边，不开信号门。
- **成功后允许同中枢新一轮**：被否——补充十三明文笔直（死后穿越不构成旧中枢信号）。
- **缺席超时处死**：被否——发明教义外终结，踩补充十四红线。
- **状态快照当真相持久化**：被否——双真相必漂移；日志唯一真相 + 快照仅派生缓存。
