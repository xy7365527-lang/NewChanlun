# ADR-0009：地板分层——记账从宽、消费从严（严档 / 悬置档 / QuasiFloor 挂起）

map #529 N3 落地后，塔链「地板」只有布尔合取（`has_segment` ≥1 有效链段），E2E-L `CloseFloor_at` 三型完整口径留 fog（#641 取舍裁定第 5 条「另票另裁，不随 N3 自动升级」）。#685（grilling，编排者 2026-07-29 裁定）一轮裁定 + 打包收法；本 ADR 是文书落库。前置 = #636（N3 终态语义）、#710（chan99 原句考证）、#711（skip 实证）、#741（最精确点位方法考证）。

## 裁定文本

1. **地板分层 = 记账从宽、消费从严**。谱系侧 `chain_cert`（#636 全规）不动：跳级照记、链照闭合、证伪留痕不复活、伤疤全可见；消费侧（N7 `Consume_at`）只收**严档**。
2. **严档 = Closed 且证据路径零跳**：链上每条边均为相邻级谓词判过边、节点全活——即「类别判定每环都验过」。**含跳 Closed 链 = 悬置档**：不判死、不消费、留档（缠师 088/067/102 三桩缺/断案例的悬置/降级形态，#710）。严档定义是递归体系自己的语言（链自身证据路径完整），不是「固定梯子每格无缺」。
3. **教义依据**：消费从严的理据 = 53 课「类别判定必须用紧邻次级别、不可跳」（误判风险是质变非精度损失）；chan99「必须确定它以下所有级别都转折」句**博文零命中**（编纂版独有，不单独承重）；缠师案例无一处「跳过继续套」、亦无一处「废链」。精度口径：严档 = 理论精度上界（027:48「甚至就是唯一的一笔」），但缠师不认可越严越好（53 课「太累毫无必要」、027:48「意义不大」）——严档是消费安全的形状，不是追求的目标。
4. **「跳」三分支**（#741，互不合并）：① 点位精细化跳跃（换大倍数显微镜）——不构成损失（53 课「没有冲突、极为自然」）；② 结构判定跳跃（省紧邻次级别确认）——误判风险；③ 市场结构小转大（44 课）——被迫的跳、无对象可验、无损失。
5. **QuasiFloor 挂起不立项**：线段内部笔间类背驰定位（L0 之下）不造候选源——53 课「太累毫无必要」+ 工程量大（新候选来源类型）+ 无消费者。挂触发：出现真需要 L0 类背驰定位的消费者再议。
6. **FormalFloor 级别校验由消费侧严档谓词承担**，`chain_cert` 不加级别地板检查（现行反事实锁测试维持）；`Open` 不分裂、`termination_reason` 不独立立项（诊断候选随 N7 实装一并定）。

## Considered Options

- **(a) 松**（维持 #636 现状，跳级照收照消费）：被否——无视 53 课「类别判定不可跳」，把缺环链与全环链同权消费。
- **(b) 紧**（chan99 字面：全级无跳才 Closed）：被否——原句零命中不承重；与缠师做法相悖；实测跳边链占 37.5~50%，判死一半链且严档外再无消费（#711）。
- **(c) 分层**（本裁）：谱系照实不可篡改 + 消费从严 = 缠师悬置/降级形态的工程化。

## Consequences

- **N7 消费门形状已定**：严档谓词 = Closed ∧ 零跳；读数设施已常驻（`p127_skip_impact`，#711），N7 实装时直接消费，无新增对象。
- **零生产代码变更**：本裁定不触 `chain_cert`；谱系语义（#636）全规维持。
- **悬置档处置**：留档不消费；若未来证据（更大窗口/多标的）或消费者需求变化要求重估悬置档，须新裁定，不自动升级。
- **与 #686 协同**：悬置档划分维度可叠加 inside/outside 诊断标注（#736 结局分离成立），但诊断标注不进门——入门只有零跳一维。
- **词表**：`CONTEXT.md` 增「地板三型」「严档与悬置档」，「闭合」条正名为 nest 对照侧纪律。
- **程序性**：本 ADR = #685 裁定文书；#685 余问（级别校验/QuasiFloor/Open 分裂/成因字段/落地序）按打包收法一并了结，不另出票。
