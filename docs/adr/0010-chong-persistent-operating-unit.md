# ADR 0010：持久操作单位命名为「重」，「声部」保留现名并登记错位

**日期**：2026-08-01
**裁定人**：编排者，走 [分区卷钱的机械 v0 #842](https://github.com/xy7365527-lang/NewChanlun/issues/842)（map [#787](https://github.com/xy7365527-lang/NewChanlun/issues/787)）当场拍板
**状态**：已采纳，`CONTEXT.md` 已同步（commit `2759890251` + `fddf197038`）

## 背景

原型票 [#842](https://github.com/xy7365527-lang/NewChanlun/issues/842) 造「分区卷钱的机械」时需要一个**持久的操作单位**——一份筹码长期按某个级别在某个标的上反复进出、成本一点点降下去、跨越多次建仓而不终结。

查 `CONTEXT.md` 发现**仓内没有这个概念**：

> **声部（Voice）**：一次建仓的完整生命周期实体……**出场即终结**。

⟹ 两套本体论。缠师那台机器的基本单位是**持久的**；本仓的基本单位是**一次性的**。这解释了两件长期想不通的事：为什么三阶段（`TStage`：降成本→退本金→增股数）在仓里总也挂不上（**三阶段是持久实体的状态机，而仓内只有一次性的声部**）；为什么 `CampaignBook` 按 `(级别, 方向)` 分（**那就是在试造这个持久实体，只是键选错了**）。

## 裁定

### 一、持久单位命名为「重」（缠师原词）

> `040-第40课.md:20`【正文】「可以变成 N 重层次的操作，**每一重都对应着一定的资金与筹码**」

**重 = ⟨标的 S，操作级别 ℓ，专属筹码 Q⟩**，三要件缺一不可。构成要件的两个来源：`038-第38课.md:30`【正文】「某个量的筹码按某个级别的分解操作」（筹码 + 级别）；`031-第31课.md:30`【正文】「资金管理中**针对每只股票**的最大原则」（标的）。

**判据**：一层有没有自己那份专属筹码，决定它是**独立的一重**，还是**别人的从属层**。这条判据同时解掉了 [#840](https://github.com/xy7365527-lang/NewChanlun/issues/840) 的 R1（第 35 课「主从」vs 第 40 课「并列」两幅图缠师从未对齐）——**二者不是两种架构，是同一架构的两种参数取值**；第 40 课内部那个断裂由换档解释（`040:14`「升级为大级别操作基础上**部分保持**小级别操作」——被保持的那部分必须有自己的筹码，故当场从从属层变成独立的一重）。

**架构落地补记**（[#827](https://github.com/xy7365527-lang/NewChanlun/issues/827)，2026-08-01 补）：操作级别要件 ℓ 在架构上兑现为「塔第 ℓ 层挂的那个操作分解层实例」——操作分解层的名分与边界见 [ADR 0011：操作分解层是一等模块](0011-operation-decomposition-layer.md)。

### 二、「声部」保留现名，但登记错位

**「声部」在缠论全语料（110 课 + chan99 + 天道）0 命中——它是本仓自造词。**

而在赋格里，**声部恰恰是贯穿全曲的持久线**，对应的是上文的**重**，不是本仓那个一次性实体。缠师给一次性实体的词是「**买卖操作**」（`049-第49课.md:60`【正文】「完成一次该级别的买卖操作，等待下一个买点出现」）。

⟹ **本仓的「声部」用在了与赋格原义相反的东西上。**

## 备选方案与取舍

| 方案 | 内容 | 判定 |
|---|---|---|
| **A（采纳）** | 加「重」，「声部」不动，术语表明记错位 | 新概念零成本；代价是赋格比喻在仓内不自洽 |
| B | 加「重」，同时把「声部」改名为「买卖操作」 | 全对齐，但要动 `CONTEXT.md` 核心条目 + 全仓 `Voice`/`VoiceSide`/`VoiceConfig` + ADR + spec |
| C | 不引入新词，把「重」的语义塞进某个现有概念 | 否——仓内现无任何持久实体能承载它 |

**选 A 的理由是代价不对称，且 B 的代价有实证**：[#283](https://github.com/xy7365527-lang/NewChanlun/issues/283) 那次机械改名（`ShortDiff` → `ReverseOpen`）留下的实伤是「**改名之后，按旧名字检索的人查不到它还活着**」——教义已由 [#272](https://github.com/xy7365527-lang/NewChanlun/issues/272) 判废、代码却留任，而改名切断了检索路径，使这一状态长期不被发现。

**代价明写**：保留「声部」意味着**赋格这个比喻在仓内是不自洽的**——比喻里持久的东西，在本仓是一次性的。缓解办法是 `CONTEXT.md` 明记一句「**不得由赋格比喻推理声部的性质**」——而拿比喻去推理，正是「立体性 vs 多重赋格」那场混乱的来源之一（见 [#840](https://github.com/xy7365527-lang/NewChanlun/issues/840)）。

## 后果

- `CONTEXT.md`「声部与生命周期」段新增「重」条目，并在「声部」条下加错位声明。
- **重是声部的容器，不是声部的替代**：一重按自己的级别反复进出，每次进出生成一个声部，**声部死而重不死**。
- **三阶段（`TStage`）的实例单位应随重走**，即逐 `(标的, 级别)` —— 而仓内三份实装（`CampaignBook` 按 `(级别, 方向)`／闭环 `tw_state` 全局单例／`rec_engine` 单 campaign）**无一如此**（[#840](https://github.com/xy7365527-lang/NewChanlun/issues/840) R2）。修法归 [#839](https://github.com/xy7365527-lang/NewChanlun/issues/839)，本 ADR 不裁。
- 同批入 `CONTEXT.md` 的另两条裁定（**重绑死标的、只做第一利润最大定理**；**各重保证金逐仓分开**）详见 `CONTEXT.md`「重」条目与 [#842](https://github.com/xy7365527-lang/NewChanlun/issues/842) 的 resolution，不在本 ADR 展开。
