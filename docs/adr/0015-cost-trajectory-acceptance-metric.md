# ADR 0015：验收尺子换成成本轨迹，净值 Sharpe 退场

**日期**：2026-08-02
**裁定人**：编排者，走 [[grilling] 目标函数不同源：原文求(成本↓,筹码↑)、本仓求净值 Sharpe，验收标准用哪把尺子 #833](https://github.com/xy7365527-lang/NewChanlun/issues/833)（map [#787](https://github.com/xy7365527-lang/NewChanlun/issues/787)）当场拍板

## 背景

[#832](https://github.com/xy7365527-lang/NewChanlun/issues/832) 系统性通读当场撞出：原文求的是 **(成本↓, 筹码↑)** 这个二维存量向量、基准是社会平均财富增长；本仓整套形式化链求的是**净值型 Sharpe > 0**。两把尺子不同源，而**同一套操作在两把尺子下可以得出相反结论**。

[ADR 0014](0014-intra-chong-unidirectional-inter-chong-no-arbitration.md)「本 ADR 未裁」段自陈「**本 ADR 的价值有一半悬在它上面**」——若按原文那把尺子，「净额抵消使净值不动」根本不构成问题。

在案前置：[ADR 0010](0010-chong-persistent-operating-unit.md)（「重」＝⟨标的, 操作级别, 专属筹码⟩）、[ADR 0013](0013-partition-machine-bidirectional-form.md) 裁定三（成本演化公式）与裁定四（闸门＝本金收回）、[ADR 0014](0014-intra-chong-unidirectional-inter-chong-no-arbitration.md)。

## 裁定

### 一、验收尺子换掉：净值 Sharpe 退场，改用原文那把

**编排者原话：「我觉得要换 不用夏普」。**

**否决的一侧**：净值型 `E[ΔR_{t+1}] > 0` / `Sharpe > 0`（`docs/formal-chain/买卖点alpha2.pdf` 答复A §12 ＝ p9–10 的 L3 判据）。

**采纳依据**——目标函数在原文有三处独立明文，非孤证：

> `048-第48课.md:22`【正文】「在成本为 0 前不断降低成本，在成本为 0 后不断挣筹码……**等大牛市真正结束那天，你拥有股票的数量最多而成本是 0**」
> `068-第68课.md:136`【每日解盘】「保持 0 成本，一年增加 1 到 2 倍的筹码，**别人挣钱，本ID挣筹码**」
> `103-第103课.md:164`【每日解盘】「大资金必须是**成本不断降低而筹码不断增加**的动态建仓，这是一个**基本的原则**」

**推理链**（按 ADR 0013 裁定一已立的「原文有明文处不被实装选择覆盖」）：一侧是三处原文明文，另一侧是形式化链继承下来的默认口径——**Sharpe 从未被当作一个决策裁过**（#833 票面自陈「此前从未登记过」）。天平不平。

**溯源标签**：`[新缠论:推论]`（目标函数本身 `[旧缠论]`；「据此换掉本仓验收口径」是推论）。

### 二、目标不是二维同时优化，是分段一维；三段判据各就其位

**「(成本↓, 筹码↑) 二维向量没有全序」这个难题不存在**——ADR 0013 裁定四的闸门已经把它解掉了：

| 阶段 | 在动的量 | 判据 |
|---|---|---|
| **闸门之前**（成本未归零，持仓量锁死 M＝N） | 只有成本 | **成本下降速率** |
| **闸门之后**（多头成本＝0／空头本金已收回） | 只有筹码 | **净头寸价值**（持仓市值） |
| 全程配套 | — | **操作频率** |

原文两侧两套规则是明写的：

> `031-第31课.md:169`【答疑】「**成本为 0 前，只补进相同的数量，仓位不增加。成本为 0 后，抛出后，跌回来，就把抛出的钱，全补进去**」

**为什么主判据取成本而不取净头寸价值**——成本的承重性质是：

> **成本只在已实现盈亏落袋时变动；价格自身涨跌不改变成本。**

依据 ADR 0013 裁定三的统一公式 `basis ← basis − d·π/units`（d ＝ +1 多／−1 空）——`π` 是**已实现**利润。**⟹ 成本轨迹天然剔除 beta**：牛市里持仓不动、币价翻倍，成本一分不降。

净头寸价值（`units × price`）单独作主判据有硬伤：**它是价格的函数**，牛市里它自己会涨，把 beta 算成成绩。**但在闸门之后该硬伤消失**——此时成本已归零，持仓市值全部是白赚的量，它就是战果本身。故它是**后半段**的判据，非主判据。（编排者当场提出「净头寸价值也行」，本条采纳其为闸门后判据。）

**配套判据「操作频率」是原文明写的，不是本仓加的**：

> `049-第49课.md:74`【正文】「这里所说的利润率，是指**每次操作的平均利润／需要占用资金的平均时间**，但，**真正能产生总体利润的，还与操作的频率有关**……所以在实际操作中，两者不能偏废。」
> （主控自查核实，路径 `docs/chanlun/text/blog/049-第49课.md:74`。**子代理未能核到此句**——见「本 ADR 的举证缺口」。）

**「成本下降速率」与缠师的「利润率」是同一个量**，不是第三个候选：闸门前赚的钱全部拿去降成本（ADR 0013 裁定四），故成本下降速度＝资金周转效率；两边由下句接死：

> `075-第75课.md:201`【正文】「**没有成本，本质上就是没有占用资金**，这样才有安心持股的可能以及效率。」

**溯源标签**：分段结构 `[旧缠论]`（`031:169`）；三段判据的具体取法 `[新缠论:推论]`。

### 三、不单独测 alpha —— 成本下降速率本身就是那个检验

**编排者问：「这个怎么才能知道有没有 alpha 呢 是不是其实也不需要？」本裁定答：不需要单独测。**

**推理链**：成本只在**已实现且已扣手续费**的盈亏落袋时下降（裁定二）。若操作无优势（进出等价于随机），高卖低买的期望毛收益 ≈ 0，扣掉手续费与滑点后**期望为负 ⟹ 成本不降反升**。故「成本能稳定下降」这件事本身即「赢面大于交易成本」的证据，无需第二个检验。且该检验**天然剔除 beta**（裁定二）。

**alpha 这个概念保留，定义改写**：

- 旧：alpha ＝ 扣除市场基准后的超额收益
- **新：alpha ＝ 成本下降速率中不能由手续费与随机性解释的那部分**

**统计机器整套保留**——样本量、置信下界、walkforward、置换检验一件不扔，**只换喂进去的被估量**（从「每期净值收益率」换成「每期成本降幅」）。换尺子 ≠ 放弃统计严格性。

**⚠️ 这个检验问的科目与旧检验不同，且门槛更低**：旧检验问「能否预测方向使净值上行」，新检验问「能否在既有波动中反复高卖低买成功」。后者不需要判断大方向，只需判断局部折返——**而这正是原方法（中枢震荡操作）本来设计要干的事**。旧检验拿「预测大方向」去考一套「在震荡里捡钱」的方法，属考错科目。

**溯源标签**：`[新缠论:推论]`。

### 四、「成本降到 0」的 0，扣手续费与资金费率

原文全语料**只有结果性断言、无一次计算式**（[#832](https://github.com/xy7365527-lang/NewChanlun/issues/832) 查实，含不含税费/分红/除权全未提），`043:136` 只给算例推不出唯一规则 ⟹ 属留白，须自定。

**裁定：算。**两条理由：

1. **裁定三的整个论证以此为地基**——「扣完手续费还能降成本才算本事」；不扣则该检验失效。
2. **永续合约的资金费率是持仓期间持续计提的**；不计入则长期扛单的仓位会显得成本很低，实际一直在流血。

**代价明写**：这使「成本降到 0」明显更难更慢。本仓当前**本就从未跑到过第三阶段**（见裁定六），计入这两项后更难触达。接受。

**溯源标签**：`[新缠论:选择]`（原文留白且推不出唯一规则，属自由选择）。

### 五、旧 INCONCLUSIVE 结论按 A/B 两类重新界定；裁规则，不逐个归类

**决定性证据（本票最重的产出，来自形式化链调研）**：

> **`ΔN_t = 0 ⟹ ΔSharpe = 0`**（`docs/formal-chain/买卖点alpha2.pdf` p21 ＝ 答复B §10；`多空对冲.pdf` p2–3 升级为「净额 NAV 不可识别定理」）

而**降成本短差按定义就是 `ΔN ≡ 0` 的同价转换**（`formal/Origin/TotalWealth.lean:159-161`）。

**⟹ 拿 Sharpe 给降成本类操作打分，读数在数学上恒等于 0**——不是「效果不显著」，是**该尺子对该类操作的读数与操作质量无关**。

同款一条：`formal/Tlayers/Accounting/Ledger.lean:182 nav_neutral_on_cost_reduce`（T₃₅）等式仍真，但**它证的是「NAV 度量不到降成本」，此前被读成「降成本无价值」**。读法翻转，定理不动。

**且这条定理是本仓全部「短差无价值」否证的推理引擎**（调研报告甲-2）。

**分类规则**：

| 类 | 被评价的操作 | 旧结论的效力 |
|---|---|---|
| **A** | 持仓量不变的操作（降成本短差、同价转换） | **不携带信息**——那个 0 是尺子给的，不是方法给的 |
| **B** | 真正改变持仓量的操作（判方向后建仓/离场） | **仍然有效**——Sharpe 在该类操作上有读数 |

**本 ADR 只裁规则，不在本票逐个归类**（编排者「照办」，主控按「本图纯决策图、逐个查属执行活」解读并明写于此，供事后纠正）。**用到某条旧结论时，先按本表判其 A/B 归属。**

**溯源标签**：`[新缠论:推论]`（`ΔN=0 ⟹ ΔSharpe=0` 本身是形式化链已证命题，分类规则是其推论）。

### 六、新判据的参数必须在重算任何旧实验之前钉死

**防的是**：「换把尺子重算一遍说不定就有效了」这个动作，与「改判据改到数据好看为止」**外形完全一致**，事后不可区分。

**规则**：成本下降速率的通过阈值、最小样本量、置信下界算法、频率判据的合成方式——**先落盘，再跑数**。参数本身未在本票裁定，见「本 ADR 未裁」。

**溯源标签**：`[新缠论:选择]`（流程规则）。

### 七、跨标的筹码不需加总（ADR 0013 裁定一的推论）

#833 票面第 3 问「跨标的怎么加总」**是伪问题**：按 [ADR 0010](0010-chong-persistent-operating-unit.md)「重」＝⟨标的, 操作级别, 专属筹码⟩ 与 ADR 0013 裁定一「各重的钱独立、互不挪用」，**每一重只管自己那个标的的筹码**，全局只受一个不等式上限约束。不存在跨标的加总这个动作。

同理，票面第 3 问后半「原文的筹码绑在不可做空语境上，本仓主战场是 BTC 永续，前提是否成立」**已由 ADR 0013 裁定三整段回答**（空头两相、无挣筹码相）。

**溯源标签**：`[新缠论:推论]`。

完整调研报告：`.chanlun/review-results/issue833-formal-chain-metric-dependency-2026-08-02.md`（221 行，opus 子代理，只读）。三段结论：

- **乙、与口径无关：11 条。硬证据 ＝ `formal/` 里 `Sharpe` 出现 0 次、`E[R]` 0 次、`期望收益` 0 次**——净值口径只活在 PDF 那批推导里，**Lean 结构层零影响**。
  **意外收获：成本口径在 Lean 里已有骨架**——`formal/Tlayers/Payoff.lean`（478 行）即第 31 课成本三态的形式化，其 `:168 reducing_no_position_increase` 正是「闸门前持仓量锁死 M＝N」；`formal/Origin/FullDefinitionStrategy.lean:184-189` 的 `LedgerState` R＝Π−A−W **本来就是收益表账本不是市值账本**，与成本口径兼容。换尺子是把现成配角扶正，不是从零起。
- **丙、需重证：6 条。丙-5 是硬前置**——裁定二那个公式的**分母（持仓量）在 Origin canonical base 里不存在**：`TWState` 七字段（`TotalWealth.lean:94-103`）无股数分量（`holding` 是市值摘要，`:103` 自陈）；`LedgerState` 四字段同样没有。带 `units` 的 `VoiceLedger`（`Ledger.lean:42`）是 legacy 层、Origin 版不 import。**要用这把尺子，须先给账本加持仓量分量并重证 TW 守恒/OQ-9。**

## 走图当场的一次自纠（照实登记）

主控在本票中断言「主生产链 `theta_v0/` 没有成本账本」，**该断言为假、当场订正**：`theta_v0/strategy/ledger.rs:149` 的 `TwState` 即三阶段账本（`free`／`holding`／`withdrawn`／`notional_in`／`stage`），`theta_v0/strategy/oscillation_campaign.rs:21` 注释明写「缠师口径『成本入账』」。

**误判成因**：拿废弃引擎 `recursive_t` 的字段名（`cost_basis`、`EarningShares`）去 grep 主生产链，而主链对同一事物用的是另一套命名（`holding`、`TStage`、`avg_cost`），**搜不到即下「没有」结论**。

**这与本图立图根因（没人知道现在已经有什么）同形，且是走图当场自己犯的**——继 [#827](https://github.com/xy7365527-lang/NewChanlun/issues/827)、[#834](https://github.com/xy7365527-lang/NewChanlun/issues/834) 之后本图第五个标本，也是 `feedback_search_scope_includes_repo_docs` 的又一次应验。**订正后的事实是**：账本存在，但按 GAP3 系列已关票的实测，真实 BTC 数据上从未推进到第三阶段。
