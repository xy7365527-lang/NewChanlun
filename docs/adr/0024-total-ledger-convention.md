# ADR 0024：总账口径——净额验收 / 毛账归因，两套并记 + 杠杆属实

**日期**：2026-08-18
**裁定人**：编排者，走 [[grilling] 总账口径：多区同时满仓算不算杠杆、毛账与净账的缺口怎么处置 #836](https://github.com/xy7365527-lang/NewChanlun/issues/836)（map [#787](https://github.com/xy7365527-lang/NewChanlun/issues/787)，#828 欠下三块之一）逐问拍板
**状态**：已采纳。本 ADR 只定口径与边界；对账定理的形式化与参数标定归后续票。

## 背景

[#828](https://github.com/xy7365527-lang/NewChanlun/issues/828) 裁定「N 层并行 = 原文留白处的本仓自主扩展」，据此欠下三块必须本仓自裁。本票管**总账口径**（账怎么记）。原文确认未处理总账：`049-第49课.md:52`【正文】单区「中枢向上移动时就应该满仓，这才是最正确的仓位」在多区并存下歧义；`080:471`【答疑】与 `056:38`【解盘】两处仓位快照均为单一账户口径，从未按级别拆账。形式化链（`docs/formal-chain/买卖点alpha2.pdf`）同文档两套记账并存：p22–24 毛收益求和 `R=Σ_{γ∈T} X_γ`（每声部用自己的出场时刻 `τ_γ`，依赖级别间会计独立）vs p33–37 净额逐 bar（级别只作状态键，对会计独立免疫）；§6–7 自证「腿级全覆盖可以成立；净值级收益为零或负」——两套之间的缺口文档从头到尾没有弥合。

## 裁定（六问全出，逐条）

### 一、多区同时满仓、合计超过本金 = 杠杆

原文「满仓」是单一账户口径；多区并行是 #828 的自主扩展，扩展不自动豁免杠杆定义。现状事实：执行层 `net_target_units`（净额求和）是唯一到达下单的路径；毛敞口上限 `enforce_gross_cap` 默认 **false**（`config.rs:227`，frozen bit-exact）；ADR 0014 保证金逐重分开 ⟹ N 重各自满仓 = 保证金占用合计 N 倍。**副题同裁**：现状净额合成 ≠ 「全账户满仓、各区分食」——它不 enforce 任何总满仓上限，只是求和。

### 二、两套并记、各有用途

- **验收用净额账**——执行层按什么成交就按什么验收，账实一致；
- **归因与杠杆暴露用毛账（分账本）**——毛账是唯一能看见「每重装了多少、双开敞口多大」的口径。

### 三、补对账定理，形态 B（两段）

- **第一段（账目恒等式）**：无成本时毛腿收益求和 ≡ 净额逐 bar 求和（§7 抵消定理 `G_p+G_c=σ(Q−H)ΔP` 的 telescoping 推广）；成本按腿分配后毛成本求和 ≡ 净成本求和。Lean 照证，Rust 落对账测试。
- **第二段（期望层关系）**：p22–24 毛分解（每腿用各自 `τ_γ` 的信息）与 p33–37 净分解（逐 bar 全互斥状态）的差异 = 条件信息差，不是账目差；「细分类不劣于粗分类」（`买卖点alpha2.pdf` 定理 2，p33–34）作为两套分解之间的正式关系写死。

### 四、「成本为 0」的会计定义

- 成本基 = 历史买入成本，扣已实现回收（**含手续费、资金费率**——#833 裁定四已定「0 扣手续费与资金费率」）；
- 降到 0 后持仓不动则成本基恒 0；**仓位百分比一律按市值计量**（与 `056:38`「70% 仓位成本为 0 的老股票」快照一致；0 成本只是成本基字段的值）；
- 报告层「成本为 0」标记线作为实现细节并入，不另立口径；
- **遗留子项**：分红/除权进成本基的口径（原文未提，全语料留白之一），本票或另票收。

### 五、风险度量：总账为主、逐区为辅

- 总账 `LeverageCaps`（毛/净两道，`risk.rs`）成为真实生效的验收闸：**毛 cap 管裁定一的杠杆暴露，净 cap 管裁定二的净额验收**；
- 逐区帽（`level_risk.rs` 级别资金权 + 逐子树毛 cap）当执行约束继续存在，不退役；
- 净 ≤ 毛桥已锚 Lean `Origin.LeverageCapital`；
- 总账户 cap 的参数源（γ̄ / 净 cap 数值）属后续参数票，本票只管「归谁」。

### 六、funding / borrow 毛暴露 = 每腿敞口绝对值之和

- funding 按腿毛敞口计、borrow 按空腿借券市值计（`gross_target_units` 同款坐标）；这是 #178 裁定三当年要的那句「蓝图明文」，**档 B（逐腿下单出口）自此取得单独立案资格**——立不立案由另一张票决定，本票只交付「口径已定」这个解锁事实；
- 执行层现是 Netting，毛口径先落虚拟毛账层，等档 B 立案才真实——与裁定二「毛账归因、净账验收」分工同款，不是矛盾。
