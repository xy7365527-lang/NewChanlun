# ADR 0030：退出授权三类来源、范围随类、动作映射表、终态即退休可重开、崩溃后继续

**日期**：2026-10-13
**裁定人**：代理依用户 2026-10-13 授权裁定（分析：claude-fable-5-1；根逐条复核并补充），走 [[grilling] 完整退出授权与责任退休 policy #1352](https://github.com/xy7365527-lang/NewChanlun/issues/1352)（#1323 / SPEC #1340，FU-07）
**状态**：已采纳。本 ADR 只定来源、范围、动作、退休判据与恢复政策，不授权任何真实撤单或平仓，不填阈值。

## 背景

[#659](https://github.com/xy7365527-lang/NewChanlun/issues/659) 把第 13 课均线语境的退出说法降为辅助参照，结构止损价名分为系统自设 Θ_risk；RESIDUAL FU-07 留下「完整退出授权与责任退休」未裁。R2 `economic_session` 没有退出或退休状态，唯一相关落点是 `rust/src/economic_session/book.rs:334` 对缺开局或 family 不符的事实记 Unmatched。缠师原文给了结构侧的退出理由（`031-第31课.md:26`、`049-第49课.md:60`、`012-第12课.md:16`，均【正文】）与一类非结构的停止理由（`026-第26课.md:26`【正文】「停止交易不是因为市场的原因，而是因为自身」），没有「责任退休」概念。

## 裁定

### 一、三类来源，各自独立、互不兜底

| 来源类 | 判的事 | 名分 | 记录 |
|---|---|---|---|
| 结构事实 | 该 Voice 的卖点成立或买入理由失效 | `[旧缠论]`：`031-第31课.md:26`【正文】「除非证明你买入的理由没有了，技术上出现严重的形态，否则都不能抛一股」；`049-第49课.md:60`【正文】 | `exit_source=structure` + 结构对象引用 |
| 具名系统风险条件 | 持有的环境不再成立 | 系统自设（#659）；`012-第12课.md:16`【正文】「对所有可能的情况都设置一套相应的应对程序」 | `exit_source=risk:<条件 id>`，条目 ⟨id, 触发事实来源, 范围, 动作, 版本, 授权人⟩ |
| 用户手动退出与急停 | 操作者决定 | 用户权限（`031-第31课.md:20`【正文】「自己的盘子，一定要自己负责」的边界含义） | `exit_source=manual:<授权 id>`，记授权人、范围、时间 |

任一类失败不触发另一类重判；风险与手动不得记成卖点（三类判的是不同的事，属 #799 限定词①）。系统风险条件只能授权非选择性动作（冻结新承担，或对声明范围内全部重施同一动作）；选择性减仓只能由用户手动点名重，否则就是 [ADR 0014](0014-intra-chong-unidirectional-inter-chong-no-arbitration.md) 禁止的重间仲裁。

**清单 v1 只定结构（根补充）**：类别为 SR-1 场所/部署者动作（[ADR 0021](0021-venue-selection-deferred.md) 裁定三）；SR-2 账户可用权益低于既有责任，动作 = 冻结 + 通知；SR-3 TB-09 证据失效，冻结新发送；SR-4 用户登记的资金期限（`026-第26课.md:26`【正文】）。各条目的具体触发阈值不在本 ADR 给出，随能力验证或生产激活由用户签署清单版本。

### 二、范围随来源类

结构 → 该重当前 Voice（S1）。风险条件 → 条目声明（S1–S4），范围内全部重同一动作。手动 → S1–S4，写入授权记录。跨重动作不是仲裁：同一授权 id，逐重各记一次退出与尾账，物理层合成净额。

### 三、动作映射表（无兜底）

| 来源类 | 动作 |
|---|---|
| 结构 | 撤该 Voice 未成交挂单 + 限价平仓（[ADR 0018](0018-limit-order-fill-model.md)）；残量与迟到成交进尾账 |
| 风险 / 手动 | 撤范围内全部挂单 + reduce-only 平仓，默认市价/IOC；条目或授权记录可改为限价 |

「只撤不平」是冻结状态，不是退出。结构退出的限价未成交，不自动升级为市价；升级须另一次授权。表中限价/市价的默认值是执行偏好（根补充）：用户可以改表，不牵动本 ADR 其余裁定。

### 四、责任退休 = 外部可核终态，可重开

四条件同时成立：全部订单经场所回报确认终态；归属该 Voice 的持仓为零；费用（含锁额费用尾）由实收事实结清、差额进尾账；E 中无 Pending。退休是状态，不是删除；迟到事实在同一 Voice 重开（TB-06-H），永不挂新 Voice（`book.rs:334`）。退休事件释放共同占用，触发 [ADR 0029](0029-common-cap-contention-policy.md) 等待 slot 的重算。终态确认前按最大责任保留。

### 五、崩溃恢复 = 继续原退出

授权在首次外部动作前持久化；恢复后先只读对账在途订单（外部未知按最大保留，不伪造终态），再于同一授权 id 下续做；三类来源一律如此。无法连接场所是失败态（保留最大责任、重试、不切判据、不回退旧 writer），不是另一种政策。

## 被否方案

X1（安全缺口，与 `026:26` 相悖）；X2（缺操作者最终权）；一律 S1 / 一律 S4 / 系统选重减；一律只撤 / 一律市价 / 限价未成自动转市价（#799 兜底形态）；R2 观察期（要填数字，只延迟）；R3 不设退休（没有释放触发）；恢复时重新评估（第二次判断）；一律等人工（把失败态当政策）。
