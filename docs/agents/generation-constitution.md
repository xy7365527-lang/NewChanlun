# 世代宪法（Generation Constitution）

> 2026-07-28 裁定（图 #500 根票 #501，grilling 四问四裁，编排者逐问确认；ADR 0004）。
> 首要功能：**让精力不再流向死代码**——名分不钉死，agent 就会继续给死代码看病（#467 原 SPEC 误诊是活例）。

## 1. 名分四态

仓内任何代码实体/文件/工位，名分四选一，判据机械可查：

| 态 | 机械判据 | 实证锚（2026-07-28 在案） |
|---|---|---|
| **现役** | 有非测试调用者 ∧ 无 deprecated 标记 ∧ 在唯一 git 线（main）上 | π 家族（`pi_theta_fill_loop_overlay` 及其薄包装） |
| **deprecated 待退役** | 带 `#[deprecated]`/deprecated note ∨ 生产零可达但有测试调用者 | `run_theta_v0`、`plan_and_fill_mtm(_dual)`（→ #499） |
| **孤儿待删** | 全仓零调用者（含测试零调用） | `run_theta_v0_dual` |
| **垃圾待清** | 无票号 ∧ 无引用 ∧ 非再生产物惯例外 | `G:/`、`kimi-export-session-*.md`、`.playwright-mcp/`、`.pytest_cache/` |

### 1.1 工位容器两态（不单立第五态）

worktree/branch 是**容器**不是名分。容器只有两态：

- **在跑**：对应票仍开 ∨ 有未提交在制品 ⟹ 白名单须留；
- **残骸**：票已关 ∧ 工作区干净 ∧ 无未合入 commit ⟹ 按判据清。

容器里装的内容按四态判。

### 1.2 深度分叉特例（一次性，不立常例）

票号无、在制品无、但深度分叉（如领先 main 1000+）的残壳：判垃圾待清，**删前打包 tar 出仓**留一手。

## 2. 现役线名单

- **引擎层**：**π 是唯一现役引擎**。锚定方式 = 家族根函数名（`pi_theta_fill_loop_overlay`），不锚行号（行号随版本漂移）。v1/dual = deprecated 待退役，处置见 #499。
- **git 线**：**main 是唯一现役线**。`main-rewritten` = main 的只读事实镜像（CI 触发器挂它），**不是第二条线**；`gap3-rework-codex9-fix` = 已吸收残壳（main 含其全部 except 2 commit，main 领先 260——2026-07-28 核），按垃圾清。
- **工位层**：**白名单制**。在跑工位显式登记于当日 roster（当前唯一：`/tmp/kimi-nest-mainline` = #421）；其余 worktree 默认残骸嫌疑，按 #502 判据清。新工位开工即登记。

## 3. 开票门（文本牙）

**实施票的 Problem Statement 若触及 deprecated / 孤儿名分的代码，票体必须先引本宪法 §1 判据核名分；未核名分的实施票不得挂 `ready-for-agent`。**

执行方式：开票/triage 环节 agent 自查（与交付纪律开票门同族）。机械强制（CI/cron 扫描）是否立，归 #506 裁量，本宪法不预设。

## 4. 边界

- 本宪法只管**名分判定与名单**，不管退役执行（#499）、清理判据细则（#502/#503）、归档口径（#504）、装备收编（#505）、机械防复发（#506）——那些是图 #500 各自的票。
- 名分判定与「代际（Generation, n）」（声部嵌套代数，CONTEXT.md 既有词条）无关——宪法用「世代」指代码谱系，两词不混。

## 5. 记账层产物口径（#504，2026-07-28）

review-results / handoff = **工作草稿**，不是档案：**活期绑定票**——关联票 open 期间留仓，票关后月度归档周期打包 tar 挪出仓（仓外 archive 目录）。roster（`.chanlun/agent-roster-*.md`）= 活文档，留仓 tracked。仓内长期只留活文档（CONTEXT/ADR/docs/纪律文本）。票上对草稿的路径引用在归档后失效，以文件名在 archive 包中检索——这是「归档」与「留存」的刻意区分。
