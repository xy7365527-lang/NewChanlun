# 统计结论口径标注与引用审查

管的是：一份归档判决的统计结论，在**被引用的那一刻**，能不能被人一眼判定「过没过异质审查」。**不规定必须用哪套统计算法**——探索性分析用自己的算法是正常科研实践，本规范防的是「没标来源的结论获得与冻结口径同等的权威」，不是算法分歧。

来源：#391（划线）/ #403（生效方式）/ #395（处置，已于 #424、commit `c95a993868` 落地，不重做）/ #390（map）。

## 生效与载体

本规范由编排者批准即生效。规范正文只放在本文件，`CLAUDE.md` 只挂入口指针。

## 两档判据（按落点，不按用途）

用途判据挡不住事故——「我以为这只是探索」挡不住结论被拿去当依据用。落点判据不依赖作者的自我认定。

| 档 | 触发条件 | 要求 |
|---|---|---|
| **轻** | 产出落盘进 `.chanlun/review-results/` 归档 | 标明结论用的是哪套统计口径（一行字即可） |
| **重** | 有人要拿某个结论**当决策依据**——写进另一份判决 / 当建票理由 / 写进长期记忆索引 | 引用方先查它过没过异质审查；没过 → 当场补，或标「未审」降级使用 |

轻档可直接写：

```text
**统计口径**: <本报告实际使用的统计方法、实现或冻结规范>
```

「引用」= 写判决 / 建票 / 写长期记忆索引这几类有明确动作的行为；纯阅读、纯指标展示不算。

## 责任归属：产出方止步于标注，引用方担审查

「会不会被后续引用」在产出时刻预判不了，故不要求产出方预判：

- **产出方**的义务止于如实标口径（轻档），不负责预判将来是否有人引用。
- **引用方**须确认异质审查报告存在，且其中的「审查对象」确实指向本次要引用的文件或代码位置；没过审就当场补审，或显式标「未审」降级使用。
- 只有真被引用的才付审查成本——多数归档永不被引用，不必人人预先过审。

## 默认降级，不设巡查

没标统计口径的归档，引用方**一律当「未审」降级使用，不得当决策依据**。

这是改默认值，不是惩罚条款：不设惩罚、不设定期巡查、不设机械扫描。成本落在想引用的人身上，自执行。

## 不追溯存量

本规范只管生效后的新产出，**不回头补标存量 200+ 份 `.chanlun/review-results/` 归档**。

旧归档没标口径 ≠ 已被否证，只是「引用时须走上面的重档流程」——未标注不是结论错误的证据，只是尚未过审的状态。

## 异质审查报告须带「审查对象」字段

审查报告若无统一锚点，未来无法检索核实「某条结论有没有被审过」（#392 曾核查 200+ 份 codex 报告，零命中）。

异质审查报告须带一行：

```text
**审查对象**: <被审查的文件路径或代码位置>
```

范本：`.chanlun/review-results/codex-oddeven-permtest-audit-20260727.md`。
