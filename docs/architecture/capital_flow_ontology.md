## 1. 数学基础：残差在规范场论中的精确位置

> 等级：**L0**（定义/定理 + 文献综述）。本节几乎零信息增量——它是把已有金融对象重命名为几何对象，价值在于使"残差=套利"成为定理而非比喻，并据此**否证**一条诱人但错误的下游路径。

### 1.1 残差 = 和乐 = 曲率（Ilinski / Farinelli，严格定理）

把资产标记为纤维丛上的点，每条边附一个平行移动算子（结构群 = 伸缩群 ℝ₊）：

- **时间边**（贴现/利率）：`U = exp(r_i Δ)` —— 利率是联络的时间分量。
- **空间边**（汇率/比价）：`U = S^{i,k}` —— 汇率/比价是联络的空间分量。

沿环路平行移动之积 `∏U` 偏离 1 即**曲率**：

```
F_plaquette = ∏_m U_m − 1
```

**Ilinski 定理**（arXiv:hep-th/9710148）："The curvature tensor for the connection consists of the excess returns to the risk-free interest rate for the local arbitrage operation." 即**曲率 = 套利超额收益**。

这正是本项目 `verify_cross_national_closure.py` 的实证位置：
- **Part A**（同结算尺三角环 GC→CL→ES→GC，全 USD 计价）：`max|Σω| = 8.9e-16` ≡ 0 → **平直联络，零曲率，L0 同义反复**。代数恒等强制闭合，不携带信息。这与 `recursive_decomposition_tree.md §8.5b` 的 a0 残差 `max|ρ|=8.9e-16` 是同一事实。
- **Part B**（跨结算尺 DX vs EURUSD，残差占 DX 方差 33.8%）：**非零曲率 = 持续的瞬时套利能力**（Farinelli "instantaneous arbitrage capability"，arXiv:0910.1671）。

> **517号谱系的几何重述**：和乐 `hol(γ)=exp(∮_γ ω)` 是 2-Simplex（循环）属性，曲率也是 2-form。本项目"和乐的信息有效域 = 环路穿越结算尺数 ≥ 2"在规范语言里就是："曲率非零仅当环路跨越非平直联络区域（跨结算尺）"。同结算尺内联络平直（曲率恒零），跨结算尺联络有曲率。**这是同一命题的两种语言，已自洽。**

### 1.2 为什么"残差 → 资本流量"没有免费的数学桥梁（度规问题）

在 Yang-Mills/电磁理论中，从曲率 F 到物质流 J 的唯一桥梁是：

```
d⋆F = J        （含源 Maxwell 方程）
dJ = d(d⋆F) = 0  （连续方程 ∂ρ/∂t + ∇·J = 0，因 d²=0 自动成立）
```

**关键障碍**：`⋆`（Hodge star）把 k-form 映到 (D−k)-form，**依赖度规**。物理时空的度规来自相对论（光速 c 是普适常数）；**金融里没有普适常数定义"资产 i 与资产 j 之间的距离"**。

候选度规及其失效：

| 候选度规 | 代数可行性 | 经验有效域 |
|---------|-----------|-----------|
| 协方差矩阵 σ_ij | ✅ 正定对称 | **❌ 循环**：σ 时变、估计依赖，且本身受资本流影响——用受 J 影响的 σ 去从 F 算 J 是循环论证 |
| 现金流 L² 内积（Farinelli 谱理论用） | ✅ | 用于刻画鞅测度（哪些测度无套利），**不是** Hodge star，不映 F→J |

**Malaney-Weinstein 的教训**（Nguyen, arXiv:2112.03460 的严格反驳）：他们用纤维丛联络处理"跨状态比较需平行移动"——概念正确（跨货币比较确实需要联络/汇率做平行移动），但 Nguyen 证明其具体数学贡献是**同义反复**，且**不存在典范联络**（无类比 Levi-Civita 的唯一选择）。

> **对跨国 K4 的直接推论**：跨结算尺残差非零说明 USD-fiber 与 EUR-fiber 之间联络不平直，**但规范理论本身不告诉你"正确"的换算（哪个联络）是什么**——必须由额外经验输入指定。**"用 Hodge star 从残差曲率直接算资本流"在金融中无严格基础，是有效域膨胀（230号同型），禁止采用。**

### 1.3 金融的"连续方程"：本项目已有的资本守恒律

最严格的金融连续方程（Farinelli）：`𝒟ρ^β + div J = 0`，但其 J 由利率向量独立定义。本项目 `capital_flow_taxonomy.py` 给出了一个**离散、可操作的对应物**——资本守恒律：

```
ΔM + ΔP + ΔC + ΔR = 0
```

其中 ΔM = −(ΔP+ΔC+ΔR) 由守恒律决定（M 是货币池/度量基准，026号双重身份）。这是本项目里**最接近"资本流量"的严格结构**，且与 Farinelli 同构地满足两个性质：

1. **守恒**：四顶点流量和为零（资本不凭空产生/消失——在闭合 K4 投影内）。
2. **独立定义**：流量 (ΔP,ΔC,ΔR) 是**输入变量**（来自 COT/缠论等），不是从价格残差导出——这与 Farinelli 的 J 独立于 F 完全一致。

> **诚实保留**：资本不像电荷那样严格守恒（信贷扩张/违约/央行发行/估值重估都破坏守恒）。`capital_flow_taxonomy.py` 的守恒律是**闭合 K4 投影内的会计恒等**，有效域 = 不考虑外部注入/估值重估的封闭系统。这是 L0 定义，其经验有效性（实际四顶点流量是否近似守恒）是 L2 待验证。

## 2. 补量：从价格残差到资本流量的三个独立信息源

> 既然 F→J 无免费桥梁（§1.2），"流量"必须来自残差**之外**的独立信息源。本项目有三个，互补且各有有效域边界。

### 2.1 信息源一：COT 持仓数据（量，但弱、滞后、共线风险）

> 等级：**L0/文献综述**；作为本项目信号需 L2 验证。

CFTC Commitments of Traders 提供期货市场的持仓结构，是唯一直接的"持仓量"数据。**正确映射**（用错报告会读到相反信号）：

| 标的 | 报告类型 | 投机资本代理类别 |
|------|---------|-----------------|
| GC 黄金 / CL 原油 | **Disaggregated** | **Managed Money** |
| 6E 欧元 / DX 美元指数 / ES 标普 | **TFF** | **Leveraged Funds** |

**会计恒等式（L0，必然真）**：期货零和 → 所有类别净头寸之和 ≡ 0。所以"Managed Money 净多增加"严格等于"其对手方（套保者+swap dealer）净空增加"——**ΔNet 是相对量，不是绝对资金注入量**。

**启发式解读（经验，需 L2）**：ΔNet(Managed Money) 作为投机资本**方向**代理（趋势跟随者的脚印）；Open Interest 变化作为**参与度/信念强度**过滤器。

**三个硬约束**：
1. **滞后**：周二快照、周五发布 → 回测必须施加 **≥1 周滞后**（零前视纪律，见 auto-memory `project_zero_lookahead_backtest`）。COT 的 Tuesday/Friday 错位是一个具体前视陷阱。
2. **代表性偏差**：只覆盖美国受监管期货，漏掉 OTC/现货/非美市场。对"全球资本流量级"代表性差，对"美国期货大户方向情绪"代表性较好。
3. **共线风险（关键）**：若 ΔNet 与价格残差/价格变化高度共线（Managed Money 趋势跟随 → 净头寸≈价格的滞后函数），则 COT 相对残差的**信息增量趋近零**（同义反复，见 auto-memory `project_backtest_benchmark_falsifiability`）。**并入主轴前必须先检验 COT ΔNet 与价格残差的互信息/相关性。**

> **金油轮动的诚实边界**：可比较 GC 与 CL 的 Managed Money ΔNet 观察金油间相对配置，但①黄金 Managed Money 多头占比异常高（≈44% OI），绝对水平不可直接比，须标准化；②"轮动"可能是去杠杆变现（raise cash）而非真轮动，需第三变量（总 OI/现金）区分；③与 auto-memory `project_omega_regime_falsified`（ω→美股方向被真实数据反向证伪）同域——COT 金油信号同样需 L2/L3，不得把否定包装成确认。

### 2.2 信息源二：资本守恒律分类（27 配置 → 病理态，本项目已有）

> 等级：枚举+判据 = **L0**；病态↔配置映射的经验有效性 = **L2**。

`capital_flow_taxonomy.py` 已把 (ΔP,ΔC,ΔR)∈{−1,0,+1}³ 的 27 配置完全分类为 7 种资本病理态（卢麒元三病态 + 健康/中性/过渡/溃坝）：

| 病态 | 判据 | 卢麒元语义 |
|------|------|-----------|
| FLIGHT 走资 | ΔM≥+2 | 资本涌向货币/外汇，避险外逃 |
| SEDIMENTATION 沉没 | ΔR>0 ∧ ΔP≤0 ∧ ΔC≤0 | 撤入不动产沉淀 |
| SPECULATION 空转 | ΔP>0 ∧ ΔP>ΔC | 金融吸资超实体（堰塞湖） |
| DAM_BREAK 溃坝 | ΔP<0 ∧ ΔP<ΔC | 实体回归（空转反演） |
| HEALTHY 健康 | ΔP=ΔC≠0 | 金融实体同步流转 |

**关键实质发现（代码 docstring）**：分类**不是时间反演对称**的——SPECULATION 的镜像本应是 DAM_BREAK，但 SEDIMENTATION(ΔR 方向) 与 FLIGHT(ΔM 方向) 判据破坏对称。**资本病理有方向偏好（沉没易、释放难；外逃骤、回流缓）。** 这是该分类相对纯对称代数模型的真实增量。

这一层是 §2.1（COT 提供流量方向）与 §3（缠论提供走势结构）的**汇流点**：流量配置 (ΔP,ΔC,ΔR) 由 COT/缠论填充，分类器把它映到病理态，病理态再映到操作（`_OPERATION` 表）。

## 3. 缠论在总拓扑中的角色

### 3.1 各边独立递归 → 联合读数（缠论的"联立方程"）

> 缠论原文依据（一级权威，第九节《走势及走势类型》）："级别的存在，使得对走势的判断可以联立了……走势的可能走势的边界条件就变得异常简单。"

各边（P/M、C/M、R/M、汇率边、折叠通道 ω）独立跑 `RecursiveOrchestrator` 递归，各自产出走势方向 σ ∈ {+1,0,−1}（`config_space.WalkDirection`）。联合读数 = 配置向量：

```
Γ = (σ_P, σ_C, σ_R)        # config_space.Configuration，27 配置
```

**关键本体论区分（527号）**：σ 是**走势方向态**，不是价格位置态。依"走势必完美"（24/29课），下跌 settle 后可**直接**转上涨，FLAT 不是必经中间态。故 σ 可 −1→+1 跳变，配置转换拓扑是 **81 边图**（`transition.py`），不是 54 边的价格位置投影。

**资本流转方向向量的构造**（回答问题 3.1）：联立各边走势方向得到 Γ，再经 `flow_to_walk` 的**逆向桥接**——但这里有一个谱系张力必须显式标注：

> **价格走势 σ ≠ 资本流量 Δ（方向代理陷阱）**。`capital_flow_taxonomy.flow_to_walk` 把流量映到走势（ΔX>0 → X 吸资 → X/M 涨 → σ_X=+1）是**经验假设（一阶近似）**，存量重估是偏差源。反过来从 σ 读 Δ 同样是假设，不是恒等。见 auto-memory `project_trend_direction_proxy`：用价格代理资本流量方向时，越级标签错配是真实风险。**故资本流转方向向量 = Γ 是"价格层的方向"，要升级为"流量层的方向"必须叠加 §2.1 的 COT 或 §2.2 的守恒律约束。**

**有效域边界（330号/294号，严格诚实标注）**：三病态签名都是**金融折叠的价格投影**，不是病态的实体机制。K4 测金融循环、测不到产业循环；缠论 D 算子对生产折叠是盲的。它们是病态的**可观测症状（L2 可验证）**，不是**原因诊断（在 K4 之外）**。

## 5. 索罗斯持仓表 → 跨国 K4 持仓表

> 来源：Soros《The Alchemy of Finance》Part III "Real-Time Experiment"（1985-08 至 1986-11），表名 "Portfolio Structure, in millions"，footnote (1)–(6) 解码。等级：L0 工程设计（借鉴成熟实践）。

### 5.1 Soros 持仓表的两个可移植不变量

Soros 表的核心不是资产清单，而是两个**会计不变量**，恰好对应 K4 的两个结构：

**不变量 A：货币敞口恒等式（footnote 6）= M 顶点归集**
```
Σ(所有货币腿净敞口) ≡ 基金总权益
net currency exposure 包含 stocks, bonds, futures, cash, margins
USD 空头 = (其他货币多头之和) − 总权益    # 美元敞口是余数，非独立腿
```
这与 K4 的 **026号 M 双重身份**精确同构：M（货币）既是顶点又是度量基准，σ_M 不参与配置（`config_space` docstring）。Soros 的"没有中性现金，现金本身是 USD 多头"= K4 的"所有边以 M 为分母"。

> **对跨国 K4 持仓表的硬约束**：汇率腿不能只记货币期货，必须把**商品腿、指数腿隐含的货币敞口归集进货币账**（做 GC/CL spread、做某国股指都隐含货币暴露）。否则净美元方向（你押注金油比下降=油涨的核心方向）会被错算。

**不变量 B：久期归一化（footnote 3/4）= 级别/波动率归一**
```
所有债券折算成 30 年国债等价市值（$100M 4-year ≈ $28.5M 30-year）
```
不同久期不可直接加总——必须归一到共同标尺才能读出"组合对利率的总方向"。这与 K4 的**级别归一**同构：不同级别的笔/段/走势不可直接加总，缠论用级别递归提供共同标尺。**你的金油 spread / 跨级别仓位也需要一个共同标尺**（波动率归一或 beta 归一）。

> **诚实示范**：Soros 对日债**故意不做波动率归一并显式声明**（footnote 5："We have not adjusted for this difference"）。口径不一致必须暴露，不能藏——这正是 no-patch-mentality 的体现。

### 5.2 决策框架：thesis → 持仓物质化 → 反馈 → 调仓

Soros 的循环（反身性）与本项目的"方向确认 + 缠论定时机"同构：

| Soros | 本项目 |

### 6.2 残差向量 → 各腿多空方向 + 仓位权重（核心设计决策）

这是整个持仓表的**价值判断核心**——把 §4 的向量映射到具体头寸。映射分两步：

**第一步：方向（由病理态 _OPERATION 决定，已在代码中）**

| 病理态 | 折叠通道腿（ω） | 指数腿（P） | 商品腿（C） | 与用户押注一致性 |
|--------|----------------|-----------|-----------|----------------|
| 空转（P/C 顶背驰）| **做 ω 下降**（多油空金/做空金油比） | 减多/做空 | 做多大宗 | ✅ 押注金油比下降 |
| 溃坝 | ω↓ | 减金融 | 做多 C | ✅ |
| 走资 | risk-off | 做流入国 P | — | — |
| 沉没 | 回避死水 R | — | — | — |

**第二步：权重（折叠共享性 W 区间套 + 信念强度）**

权重设计有两个已确立的约束 + 一个开放选择：

1. **折叠共享性 W（292号区间套，外层约束内层）**：Au(W=4) > Oil(W=3) > Bond(W=2) > RE(W=1)。外层折叠的方向是内层的边界条件——ω（金油）方向定了，才轮到单国 P 配置。
2. **货币恒等式（§5.1 不变量 A）**：各腿权重之和经货币归集后 ≡ 总权益。
3. **【开放设计决策——需价值判断】** 残差曲率大小 |F|（如 DX 方差 33.8%）→ 仓位**杠杆**的映射函数。这是 §1.2 留下的真实空白：|F| 是"套利能力/张力"的度量，但它**不是流量**。把 |F| 用作仓位大小有三种合理但不等价的选择：
   - (a) 线性：仓位 ∝ |F|（张力越大下注越大）；
   - (b) 阈值门控：|F| > 临界才开仓，否则空仓（避免在结构性 CIP 偏离上下注）；
   - (c) 背驰触发：忽略 |F| 绝对值，只在比价背驰（力竭）时反向开仓（§3.2）。

> **这一步不在本文档自行裁定**——它是 018号四分法的"选择"类（多种合理方案需价值判断），且 §1.2 已证明无几何唯一解。建议经 `/escalate` 或编排者代理（Gemini decide）裁定后写入 `transition.py` 的下游消费层。**绝不可声称"残差曲率直接给出仓位大小"**（那是 §1.2 否证的 F→J 膨胀）。我倾向 (c)+(b) 组合：阈值门控过滤掉结构性 CIP 噪声（COT/利差可估其规模），背驰触发提供时机——但这是倾向，非裁定。

### 6.3 不变量校验（每次调仓后强制）

借 Soros footnote + K4 守恒律，持仓表必须通过三个 invariant（可写为单测）：

## 8. 结果包六要素

**1. 结论**
跨国 K4 总拓扑的资本流转本体论：价格残差 = 纤维丛联络曲率（=套利，L0 严格），但**残差→资本流量无免费数学桥梁**（缺经验度规，§1.2）。流量信息须由三个独立源补充——COT 持仓（量，弱/滞后/共线风险）、资本守恒律 27 配置分类（已有 L0）、缠论残差走势结构（已 L2 部分验证走资/空转签名）。缠论的角色是给残差**走势结构**（方向/级别/背驰），比价背驰=相对定价力竭=反转候选。持仓表设计借 Soros 两个不变量（货币恒等式≅M 双重身份、久期归一≅级别归一）+ 四腿（汇率/折叠通道/指数/个股）+ 守恒律不变量校验。

DX 残差符号在 200 万 bar 上仅翻转 283 次（0.014%/bar）——极低翻转率 = 残差被趋势主导，不是高频震荡。这与 §8.5b（残差有趋势结构）一致，且量化了"方向"维度的持续性：**残差的方向是一个慢变量**，适合作为低频配置信号，不适合高频择时。ω 翻转率 4 倍于 DX（0.059%），说明金油比方向比美元篮子残差方向更易切换（金油轮动比结算尺漂移更频繁）。

### 9.3 维度2（加速度/MACD背驰）：聚合无边际，但高幅背驰簇集主要 regime

**诚实裁决（关键）**：聚合命中率 DX 20.0% / ω 10.5% ≈ **随机基率**——6 个已知 regime 各 ±45 天 ≈ 覆盖日历的 ~24%，故随机背驰点本就有 ~24% 命中概率。**故"残差背驰计数"对 regime 无聚合预测边际**——这直接印证背景中"缠论结构计数对残差无区分力（vs i.i.d. null）"。

**但**：高幅背驰点在最大的几个 regime 上 **±0–4 天近精确命中**：
- DX：2022-03-16（±1d，首次加息）、2022-09-28（±0d，美元见顶）、2024-09-18（±3d，首次降息）、2025-02-20（±4d，用户标注断点）。
- ω：2022-09-26（±2d）、2025-02-13（±7d）。

这些近精确命中**强于** ±45 天窗口的随机解释，但**尚未做幅度排序 + 置换检验**，故只能报告为**暗示性，非统计确证**。结论与 §8.5b 充分条件边界一致：**"有无背驰"无区分力，但"高幅背驰的时点"可能携带信息**——需后续做"按 MACD 面积排序取 top-K 背驰 + permutation null"才能定论。L2 待完成。

### 9.4 维度3（流量）：流量 proxy 不领先价格——被否证（最高信息量结果）

> 这是四维度中**唯一的强可证伪检验**，结果是**否定性的**——按 formalization-validity-domain 规则，否定结果缩小有效域，信息增量为正。

`flow = sign(Δr) × min(Vol_A, Vol_B)`，累积流量 `cumflow = Σflow`。三个证据共同否证"流量领先价格"：

1. **累积流量 vs 残差水平高相关（DX 0.79 / ω 0.47）但近同义反复**：`cumsum(sign(Δr)×vol)` 按构造就跟踪 r 的方向——高相关是构造性的，不是因果领先。
2. **滞后剖面平坦**：DX 从 lag−2880min（0.7851）到 lag+2880min（0.7899）仅变化 0.005；ω 峰值恰在 **lag=0**。真正的领先应表现为正滞后处相关显著高于零/负滞后——**没有这个特征**。
3. **瞬时流量对未来方向无预测力**：`corr(flow[t], Δr[t→t+k])` 在 k=1~120min 全部 ≈ 0 且**为负**（−0.05~−0.001）→ 流量若有任何效应，是微弱**均值回归**，绝非顺向领先。

**裁决**：**成交量瓶颈 `min(Vol_A,Vol_B)` 不为残差方向提供领先信息。** 量价关系在比价上的这个特定推广（sign×min-vol）**被否证**。

> **边界条件（结论何时翻转）**：本否证针对**这个特定 proxy 形式**（sign(Δr)×min-vol 的累积/瞬时相关）。不否证：①其他流量构造（如 OI 变化、COT ΔNet——§2.1 的真持仓量，而非成交量）；②非线性/状态依赖关系（线性相关测不到）；③更高级别重采样下的领先。**成交量（turnover）≠ 持仓量变化（position flow）**——成交量是换手，不直接是净流入；这可能正是 proxy 失败的根因，指向应改用 COT 净持仓（§2.1）而非成交量。

### 9.5 维度4（持续性/级别）：残差涌现 L3 多级别结构

两个残差递归都涌现到 **L3**（DX 85 中枢、ω 174 中枢），确认残差不是噪音、有真实多级别缠论结构（承 §8.5b 必要条件）。引擎自身的背驰 BSP 稀疏（DX 0 个、ω 2 个）——与既有发现一致（引擎 type1 BSP 仅 level-1 太细、不发 type2，见 auto-memory `project_complete_fugue_v2`）。**故"级别=持续性"的操作化应使用 §9.3 的独立 MACD 背驰，而非引擎 BSP。** 级别本身（L3）确认"高级别残差走势=慢变的、可持有的资本流转方向"，与维度1（方向是慢变量）相互印证。

### 9.6 四维度的综合操作含义

| 维度 | 操作角色 | 可用性裁决 |
|------|---------|-----------|
| 1 方向 | 低频配置方向（慢变量） | ✅ 可用 |
| 2 加速度 | 反转时机（仅高幅背驰，需置换检验确证） | ⚠ 谨慎，待 L2 完成 |
| 3 流量（成交量版） | — | ❌ 弃用；改用 COT 净持仓（§2.1） |
| 4 持续性 | 用级别给方向信号定权重（高级别=高确定性=高权重） | ✅ 可用（接 §6.2 sizing） |

**关键修正**：维度3 的否证**强化**了 §2.1 的判断——"量"必须来自**持仓量（COT 净头寸）**，不是成交量（turnover）。成交量是换手噪声，净持仓变化才是流量。这与 §1.2"残差→流量无免费桥梁"闭环：流量是独立信息源，且必须是正确的流量度量（净持仓，非成交量）。

### 10.2 Phase A/B/C vs 走资/沉没/空转：正交两轴，互补非冲突

### 10.3 Imperial Circle 的 fiscal-monetary mismatch = 残差曲率的一个生成源

chanlun-soros 的 **Imperial Circle**（Soros 里根时代模型）：财政扩张（赤字）+ 货币偏紧 → 高利率 → 强美元 → 资本流入 → 贸易赤字 → 自我强化至不可持续。其核心变量 **fiscal-monetary mismatch**（财政立场与货币立场的缺口）。

与本项目残差的关系（精确定位）：
- 跨结算尺残差（DX vs EURUSD，33.8% 方差，§1.1 = 非零曲率）度量"美元相对单一 FX 边无法解释的溢价"。
- **fiscal-monetary mismatch 正是这个美元溢价的一个生成源**——财政货币错配驱动美元吸引力，表现为残差曲率。
- **但（承 §1.2）残差→生成源不可逆**：CIP 偏离、风险溢价、Imperial Circle 都贡献残差曲率。Imperial Circle 是**可识别的一个生成源**（用财政/货币数据独立测量），与 COT（§2.1）同构地作为**独立输入**补充残差缺失的"成因"维度。

> 即：Imperial Circle 不是从残差读出来的，而是**残差的一个候选解释**，需财政赤字/货币立场数据独立确认。这把 §1.2 的"残差混入多个成分"具体化——fiscal-monetary mismatch 是其中一个可测分量，可用于从 33.8% 残差中**分离出** Imperial-Circle 成分 vs CIP 结构成分。
