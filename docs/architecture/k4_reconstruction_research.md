## 0. 执行摘要（结论先行）

调研的**首要发现**不是"K4 应该怎么重构"，而是一个被掩盖的事实：

> **现有代码中并存四套互相冲突的 K4 顶点映射，且"金"和"油"这两个折叠对象在不同模块被压平到不同顶点。这不是某个模块的 bug，而是把 292 号「折叠本体论」压平成「分类学单顶点标签」的必然后果。**

K4 重构的真正任务因此**不是**"换一组更好的顶点/标的"，而是**让代码层重新承载折叠（folding）这个本体论原语**——292 号已结算的核心命题是："矩阵划分是折叠的推论，不是前提。"现有代码恰恰反过来，把矩阵划分当前提、把顶点当原子，于是折叠对象（金、油）无处安放，各模块各自截取折叠的一个相位，互相矛盾。

下面用证据展开。

## 2. 折叠（Folding）：为什么会出现 §1 的冲突

### 2.1 折叠的定义（292 号 — 折叠拓扑本体论，最基础来源）

> **核心命题**："分类学处理不了折叠。拓扑应该从折叠出发建。矩阵划分是折叠的推论，不是前提。"

> **折叠定义**：同一个对象在不同截面（域）中呈现不同的范畴身份——**不是"既 A 又 B"，而是同一存在的不同相位（phase）**。

> **为什么必然**：各域（E/C/RE/$）因为自身不自足性而必然通过折叠在其他域中获得表达。域不能安息于域。

### 2.2 四个折叠的盘点（292 号第 2 节）

| 折叠对象 | 折叠的两域 | 共享性 | 稳定性 |
|---------|-----------|--------|--------|
| **Au（黄金）** | **C ↔ $** | 全局共享 | 千年稳定 |
| **Oil（石油）** | **C ↔ $** | 半共享（制度货币性） | 可撕毁（石油美元体系） |
| Bond（债券） | $ ↔ E | 经济体特有 | — |
| RE（不动产） | RE ↔ E, RE ↔ $ | 地区特有 | — |

**关键约束**：E–C 无直接折叠——资本在权益与商品间必须经过 $ 或 RE 中转。

### 2.3 §1 冲突的根因：折叠被压平成单顶点

把 2.2 和 §1 对照，谜底揭晓：

> **黄金的本质是 C↔$ 折叠**（292 号）。它在 C 截面是商品，在 $ 截面是结算尺/价值储藏。
> - 回测管线截取了**黄金的 C 相位**（GLD 当 C 顶点代理）。
> - 实时监控截取了**黄金的 $ 相位**（"黄金是现金等价物"，放 CASH）。
>
> **两者都对一半，都丢失了折叠的另一相位。** 这不是谁写错了，而是「单顶点标签」这种数据结构无法表达「同一对象的两个相位」——折叠被数据结构压平了。

> **石油同理**：Oil 是 C↔$ 半共享折叠（石油美元 = 油的 $ 相位）。实时监控把油钉死在 C 顶点，丢失了油的 $ 相位（结算通道性）。

### 2.4 折叠的层级约束（292 号第 3.4 节）

> "共享折叠是外层，特有折叠是内层。外层约束内层。"

```
第0层 Au 折叠（全局共享）  ← 约束 →
第1层 Oil 折叠（半共享）   ← 约束 →
第2层 Bond 折叠（经济体特有）← 约束 →
第3层 RE 折叠（地区特有）
```

此层级在 `src/newchan/scanner.py:4-7` 已部分实现（`quotient_rank` = 折叠等价类 + 商空间排序，292 号区间套顺序），但**仅在排序层**，未渗透到顶点定义层。

### 2.5 折叠生命周期（292 号第 4 节，D 算子签名标记）

| 阶段 | 特征 | 当前实例 |
|------|------|---------|
| 稳定期 | 背驰–恢复周期规律，叙事自洽 | — |
| **松动期** | 背驰增多，力度持续下降 | **当前 2020–2026** |
| 重新结算期 | 大面积落入 ker(D)，旧折叠解体 | 1971 换锚 |
| 未结算期 | 模态在不同窗口不连续 | BTC |

代码实现：`src/newchan/trading/fold_lifecycle.py`、`src/newchan/trading/fold_equivalence.py`（FoldChannel / EquivalenceClass）。

## 3. 金和油的本体论真相（254 号 + 259 号）

### 3.1 黄金：既是结算尺又是商品（254 号定理 3）

> **逐字**："黄金 ∈ Σ ∩ C。黄金既是结算尺空间 Σ 的一个节点，又是商品 C 顶点的表现。"

黄金双重身份：
- 作为 **Σ（结算尺空间）**节点：非循环的外部度量锚。
- 作为 **C（商品）**表现：可交易、储存、交割。

> **互测网络自测不可能性（254 号 OQ4）**："黄金是 Σ 中唯一既是尺子又是被测物的节点。黄金无法测量自身 → 在黄金截面中 C=$ → K4 退化为 K3。"

这正是 §2.3 描述的折叠在更精确的语言里的表达：黄金截面下 C 与 $ 不可分（K4→K3 退化）。**实时监控把金放 $、回测把金放 C，各自实现了退化后的 K3 的一端。**

### 3.2 石油：是结算通道，不是结算尺节点（254 号否定记录 #2）

> **被否定命题**：石油纳入结算尺 Σ。
> **修正**：
> ```
> Σ = {法定货币群(USD,CNY,EUR,JPY) ∪ 黄金}
> 油 = 结算通道（settlement channel，全球大宗贸易流量）
> ```

含义：油**不应作为独立顶点**，它是 C↔$ 折叠的一条通道（石油美元）。实时监控把油当成 C 顶点的唯一代理标的，是把"通道"误当"顶点"。

### 3.3 黄金特殊性的 L2 实证（259 号 — 黄金折叠剥离实验）

用 DBA（纯农产品）替换 GLD 做对照：

| 指标 | GLD | DBA | 结论 |
|------|-----|-----|------|
| C–$ 吸收率 | 92.8% | 80.4% | C–$ 吸收是 C 类一般性质，非黄金伪影 |
| E–C 偏相关 | −0.029（独立） | +0.217（耦合） | GLD 与股票独立，特殊 |
| C–R 类型 | 方向型（避险） | 幅度型 | GLD 避险耦合特有 |

> **推论 259-5（定理类）**："C 顶点的有效代理条件——需具有货币/结算属性（当前实例：黄金）。此条件随公理0的结算尺结晶演化。"

**对重构的直接含义**：C 顶点的代理应是带货币/结算属性的商品（黄金），不是纯工业品（油）。实时监控选 WTI 当 C 代理，与 259 号实证相悖。

### 3.4 资本循环角色映射（330 号）

| 顶点 | 资本形态 | 循环角色 | 折叠根据 |
|------|---------|---------|---------|
| $ | 货币资本 M | 起点/终点/度量基准 | 所有折叠汇聚点 |
| E | 生产资本 P 的金融索取权（股权 ≠ 实际 P） | 权益化增殖 | Bond 折叠端点 |
| C | 商品资本 | 物质投入 + 实物价值储备 | 物质折叠点（Au 特别） |
| R | 不动产 | 固定资本容器 | RE 折叠端点 |

## 4. σ 本体论（527 号）— 配置转换拓扑的边数之争

### 4.1 矛盾场景

| 代码位置 | 隐含假设 | 图论结构 |
|---------|---------|---------|
| `transition.py` | σ 是位置态，+↔− 必经 0 | 54 边图、P₃□P₃□P₃、二部、直径 6 |
| `config_space.py` | σ 是走势方向，可 −1→+1 直接跳 | 应为 81 边图 |

### 4.2 527 号结算结论（立场 B 成立，定理而非选择）

> **逐字**："上浮被撤回——此矛盾可自决，是定理而非选择。修复 transition.py 的 +↔− 禁令不需要改变定义——只是让它与既有的 σ 定义对齐。故这是实现错误，不是定义冲突。"

五步推导链：
1. `config_space.py` 显式声明 σ = WalkDirection = **走势方向**。
2. 缠论"走势必完美"（24/29 课一级权威）：下跌走势 settle 后可直接转上涨，盘整**不是**必经中间态。
3. ∴ σ 可 −1→+1 不经 0。
4. ∴ `transition.py` 的 +↔− 禁令与 σ 定义不一致 = **实现错误**。
5. 立场 A（数学优美的 54 边二部图）被 no-patch 规则否定——不能用数学便利约束本体论。

### 4.3 54 边图的处置

> **逐字（527 号）**："位置态/54 边图(P₃□P₃□P₃) 作为纯数学对象本身无误，但它**不是配置转换拓扑**。如未来确有用途，须单独命名为'价格位置态投影'，不得冒充配置转换拓扑。"

### 4.4 与 a0 确认层的关系（526 号）

- **a0 确认层**（已完成）：σ 是配置投影读数，操作性，"类中枢"/"类背驰"。
- **递归层**（尚未跑通）：σ 是走势方向，严格 aₙ=f(aₙ₋₁)。

> 第65课："分型、笔、线段并没有违反中枢的递归意义，只是用一种方法来确认具有操作意义的最小级别中枢与走势类型……两者都是 aₙ=f(aₙ₋₁)，唯一不同的就是预先给出的 a0。"

**对重构的含义**：σ 边结构必须改为 81 边图（27 配置 × 每节点可向任意方向翻转独立边）。当前 `transition.py` 的 54 边实现需重写（这是 527 号已定性的实现错误，按 no-workaround 必须重写而非加分支）。

## 5. ω（金油比）与 K4 的关系 + Omega Regime 证伪

### 5.1 ω 的定义（482 号 — 资本旋转动力学，L2）

> ω = Price(Gold) / Price(Oil)。金是退出 MCM′ 的沉没物，油是被 MCM′ 压价的 P 输入。金油比直接度量 MCM′（金融循环）与 P（产业循环）的力量对比——这就是 ω（角速度 = 剥削率）。

L2 验证数据（2000–2026）：协整 p=0.033，一阶差分 Pearson r=−0.364，L/GDP 当前偏离 +3.48σ。

**ω 的拓扑地位**：ω **不是** K4 的六条边之一。它是跨越「$ 体系内金融属性(E/$)」与「商品属性(C/$)」的张力指标。等价地，ω = 黄金 $ 相位 / 石油 $ 相位 —— 即**两个 C↔$ 折叠对象各自 $ 相位的比值**。这把 ω 与折叠本体论统一了起来。

### 5.2 Omega Regime 被证伪（L2，auto-memory `project_omega_regime_falsified`）

被否定假设："ω 下降 = 信用扩张 = 利好股票（BUY_EQUITY）"。

证伪结果：ω 上升期 SPY 前瞻 20 日收益 1.41% > ω 下降期 1.08%（方向相反），t 检验 p=0.069 不显著。M2 K4 门控把缠论引擎 +932% 的 alpha 砍到 +128%（门控方向反向拦截强多头）。

**对重构的含义（精确边界）**：
- **被否定**：ω 作为**实时入场择时门控**。
- **未被否定**：ω 作为**长期方向指标**（极端位 +3.48σ + 寄生不可永续）与**剥削率的理论本质**。
- K4 拓扑结构本身（六边、折叠）**完整保留**，移除的只是 ω regime 门控。

## 7. K4 重构需回答的问题 — 调研给出的答案

### Q1. 正确的四个顶点是什么？E/R/C/$ 还是其他？

**答**：四顶点 **E（动产）/ C（商品）/ R（不动产）/ $（现金/主权信用）** 是已结算正典（254 号 + 330 号 + graph.py），**不需要改**。需要改的不是顶点集合，而是**顶点的数据结构**——从「单标的标签」改为「能承载折叠相位的容器」。重构的存在论入口是 292 号："从折叠出发建，矩阵划分是推论。"

### Q2. 金(Au)和油(Oil)在 K4 中的正确位置？

**答**：
- **黄金**：本质是 **C↔$ 折叠对象**（254 号：∈ Σ∩C）。正确表达不是"放 C"或"放 $"，而是**同时持有 C 相位与 $ 相位**，在黄金截面下 K4 退化为 K3。当前代码的两套映射（回测放 C、监控放 $）各实现了退化的一端，**都不完整**。
- **石油**：是 **C↔$ 半共享折叠的结算通道**（254 号否定记录 #2：油是 channel 不是 Σ 节点）。**油不应作为独立顶点代理**。当前 k4_monitor 把油钉死在 C 顶点是把通道误当顶点。
- **C 顶点的代理**应优先选带货币/结算属性的商品（黄金，259 号推论 259-5），而非纯工业品（油）。

### Q3. R（不动产）用什么数据代理？

**答**：无单一正解；按截面校准。美元截面工程上当前最可行为 XLRE（贴近行业）或 TLT（频率对齐但与 CASH 冲突，需消歧）；理论最优为房价指数（频率受限）。重构应把 R 实现为**可配置 + 标注折叠相位（RE↔E / RE↔$）**的容器，而非硬编码单标的。跨经济体 R 必须逐截面指定（254 号 OQ2）。

### Q4. K4 折叠如何影响六条边的结构？

**答**：六条边（3 独立边 E/$、C/$、R/$ + 3 派生边 E/C、E/R、C/R）的代数结构（派生边 = 独立边之差，ker(D)=纯幅度耦合）保持不变。折叠影响的是**边的端点语义**：当端点是折叠对象（金、油）时，该边在不同截面读到不同值（黄金的 C/$ 边在 $ 相位下退化）。230 号 L2 已证三条独立边的独立性是**以 $ 为条件的条件独立性**（E–C 偏相关 −0.029，控制 $ 后恢复独立）——这与折叠层级（$ 是所有折叠汇聚点）一致。

### Q5. 跨国 K4 如何工作？

**答**（254 号 + ontology-v2-push.md §二）：每经济体一个 K4（4n 节点），国内边 6n、货币边 n(n−1)/2、跨国同类边 3·n(n−1)/2。独立边总数定理 = 4n−1。`graph.py:35` 已预留 `CROSS_NATIONAL` 边类型但未实现。折叠层级在跨国下展开为：Au（全局，所有经济体共享）> Oil（半共享）> Bond（经济体特有）> RE（地区特有）——共享折叠约束特有折叠（292 号 3.4）。

## 8. 重构建议（结果包格式）

### 8.1 结论

K4 重构的核心动作是**让折叠成为代码的一等原语**，按以下优先级：

1. **【最高·定理类】顶点数据结构折叠化**：把 `Vertex`/`AssetVertex` 的单标的映射，重构为「顶点 + 折叠相位标注」。金、油作为折叠对象同时挂在两个域上（金：C∧$；油：C∧$ channel），消除 §1 的四套冲突映射。统一 `k4_config.py`、`backtest/orchestrator.py`、`graph.py` 三处映射到单一真相源（single source of truth）。
2. **【高·实现错误】transition.py 改 81 边**：按 527 号已结算定理，删除 +↔− 禁令，σ 转换拓扑改为 81 边图。54 边图若保留须改名"价格位置态投影"。**按 no-workaround，重写而非加分支。**
3. **【高】C 顶点代理回归黄金**：依 259 号推论 259-5，C 顶点主代理用黄金（带结算属性），油降级为 C↔$ 折叠通道的观测量（用于 ω），不占顶点。
4. **【中】R 顶点可配置化**：移除 k4_monitor "美元→不动产"错配；R 实现为按截面可配置容器，标注 RE↔E/RE↔$ 折叠相位；消解 TLT 既当 R 又属 CASH 的冲突（要么 TLT 仅代理 CASH 久期、R 另选 XLRE；要么显式声明 TLT 承载双相位）。
5. **【中】ω 作为折叠派生量而非顶点/边**：ω = 金 $相位 / 油 $相位，实现为折叠对象 $ 相位的派生指标；仅用于长期方向，不接回实时门控（Omega Regime 已证伪）。

### 8.2 定义依据

- 顶点四元组 E/C/R/$：254 号、330 号、`graph.py:22`、`matrix_topology.py:25`。
- 折叠原语："矩阵划分是折叠的推论"——292 号核心命题。
- 金=C↔$ 折叠/∈Σ∩C：254 号定理 3、292 号第 2 节。
- 油=结算通道非顶点：254 号否定记录 #2。
- C 代理需结算属性：259 号推论 259-5（L2）。
- σ=走势方向/81 边：527 号五步推导（定理）。
- ω 非边、仅长期方向：482 号（L2）+ `project_omega_regime_falsified`（L2 证伪）。

### 8.3 边界条件（结论翻转条件）

- 若未来结算尺空间 Σ 演化（公理0 结晶变更），C 顶点的有效代理可能从黄金切换（259 号自陈"随公理0演化"）→ 建议 3 翻转。
- 若 transition.py 的 54 边图被赋予明确独立用途并改名，则 §8.1-2 不是"删除"而是"分裂为两个命名对象"。
- 若找到跨经济体统一的 R 代理（目前 254 号 OQ2 标注无解），§8.1-4 的"逐截面校准"可简化。
- 若折叠相位在某截面经 L2 验证为可忽略退化（如黄金 C/$ 在某时段不退化），该截面可暂用单顶点近似——但需 L2 证据，不得默认。

### 8.4 下游推论

- 统一映射真相源后，回测（backtest）与实时（k4_monitor）将首次读到一致的 K4 配置——当前二者对"黄金顶点"给出相反答案，意味着回测 alpha 与实时信号**不可比**（同一 regime 在两套映射下是不同配置）。这动摇了所有跨"回测↔实时"的 K4 结论的可比性。
- transition.py 改 81 边后，所有依赖"配置间最短路径/直径"的下游（如 regime 转移距离）数值会变（直径不再是 6）。
- C 代理从油改回金后，ω 的两个输入（金、油）都来自折叠对象 $ 相位，ω 的拓扑定义自洽，但所有用 WTI 当 C 顶点的历史回测需重跑。

本报告涉及概念分离的领域均有谱系：折叠（292）、多经济体本体论（254）、黄金折叠剥离（259）、金融vs生产折叠（294）、cash 双重身份（026）、K4 条件独立性（230）、K4 资本循环（330）、ω 动力学（482）、σ 本体论（527）、a0 递归区分（526）。**冲突识别（§1 四套映射）目前无对应谱系记录**——这是一个尚未被谱系捕获的"声明-能力缺口"（spec-execution-gap），建议在重构启动时新建谱系编号记录"折叠压平为单顶点"这一失效模式。
