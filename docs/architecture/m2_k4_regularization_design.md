## 0. 存在论定位

M2 不是"在 M1 之上加一个选股过滤器"。M1（操盘层）递归的基底是**单标的价格序列**；M2（选股层）递归的基底是**比价序列**与**配置序列**。两者是不同的存在体系（526 号：不同的 a0 给出方式 = 不同的存在体系）。本文档的首要任务是说清楚：**这些不同基底之间的桥接在哪些地方严格成立、在哪些地方是越级（先验上限）、在哪些地方是不可绕过的矛盾。**

文档不追求"能跑通"。文档追求"严格的形式是什么"。凡遇到离散与连续、定义域与有效域、操作层与存在层的冲突，一律显式标记为矛盾（C1–C5），不用补丁消解。

## 第一部分：配置空间递归的严格形式

### 1.1 问题的精确提法

`config_space.py` 的配置 Γ = (σ_E, σ_C, σ_R)，每个 σ ∈ {−1, 0, +1}，共 27 种。极性指数 S = Σ s(σ) ∈ {−3,…,+3}。

但这两个对象都是**派生量**，不是原始量：

- 每个 σ_i 是**某条独立边**（E/$、C/$、R/$）在其**最高涌现级别**上的走势方向之符号。
- 该走势方向本身是 `ratio_engine` + `recursive_stack` 对**比价 K 线**跑完整缠论递归（笔→线段→中枢→走势）后，在递归栈顶读出的结果。

所以"对配置空间做缠论递归"这个提法，必须先回答：**配置 Γ(t) 这个离散整数三元组序列，是不是一个可以承载缠论笔/线段/中枢的基底？** 缠论的级别来自连续价格的分型→笔→线段→中枢→走势这条递归链。配置序列既是离散的（27 态），又**丢弃了幅度与各边的级别信息**。

### 1.2 三条候选路径及其边界

**路径 A：对极性指数 S(t) 时间序列做缠论递归。**

S(t) 是整数序列，值域只有 7 个。把 S 当"价格"跑缠论：

- 分型需要连续 3 根 K 线的顶/底；在 7 值阶梯函数上，分型严重退化（大量相等值、无 OHLC）。
- 27 → 7 的压缩丢弃了绝大部分配置信息（同一个 S=+1 对应多个不同配置）。

**边界条件 / 翻转条件**：路径 A 仅当 S 被赋予有意义的连续插值时才成立——而 S 没有。S 是**汇总统计量（summary statistic）**，不是走势。在汇总统计量上跑缠论 = 在代理变量上跑缠论 = 越级（memory：走势方向代理陷阱）。**结论：路径 A 作为主路径被否定**，但作为 regime 切换的**粗诊断**有保留价值（见 1.5）。

**路径 B：对三分量 σ_E, σ_C, σ_R 各自独立递归。**

这恰好就是已有的**逐边缠论递归**（`ratio_engine.analyze_pair` 对每条边的比价 K 线跑标准管线）。配置 Γ 不过是三条独立递归在某一时刻的**联合快照**（ROADMAP 称"压缩视图"）。

**这是诚实的答案**：配置不是一个会自我递归的原始对象，它是三条缠论递归的**联合读数**。"配置空间的动力学" = 三条耦合缠论过程的联合轨迹。路径 B 没有引入任何新的递归——它只是把"配置递归"还原为"已经在发生的逐边递归 + 联合读数"。

**路径 C：六条边各自递归后做同步/异步分析。**（路径 B 的完整化）

K4 报告里 6 条边各跑了独立的递归栈（3 独立 + 3 派生）。派生边在**价格层**由独立边代数决定：E/C = (E/$)/(C/$)。但——

> **矛盾 C2（不可绕过，贯穿 Part 1 与 Part 3）**
> 价格层的代数恒等 **不下降到缠论结构层**。
> - 价格：E/C = (E/$)/(C/$)，精确恒等（`graph.py`：派生边可由独立边代数推导）。
> - 结构：Move(E/C) ≠ f( Move(E/$), Move(C/$) )，**不可推导**。
> 原因：笔/线段/中枢是价格路径的非线性泛函（包含处理 = 窗口极值，分型 = 局部序关系）。同态在取 max/min 处断裂。
> **后果**：派生边的缠论结构编码了独立边边际所丢失的**共动信息**——即 E 与 C 在同一个笔/中枢窗口内是同向还是反向。这正是 K4 报告所说"需结合派生边分析内部关系"。

路径 C 是信息最完整的，但它说明"配置递归"根本不是单一对象的递归，而是**六过程同步分析**。

### 1.3 核心矛盾 C1

> **矛盾 C1（配置空间不是合法的缠论递归基底）**
> - 缠论递归要求一个由连续价格生成的级别阶梯（笔→线段→中枢→走势）。
> - 配置空间是符号投影 σ = sign(走势方向)，**已丢弃幅度与各边级别**。
> - 因此无法在配置空间"之上"直接跑缠论，除非重新引入连续基底。
> - **两难（不可调和）**：
>   - 角 A：重新引入幅度 → 你又回到了边层，配置空间是冗余的。
>   - 角 B：保持离散 → 分型/笔在 27 态（或 7 值）阶梯上退化 = 越级。

### 1.4 严格形式：配置空间是 a0 层投影，递归活在边层

C1 的严格解（**不是补丁，是 526 号在宏观尺度的应用**）：

定义投影映射
```
Φ : (连续六边缠论联合状态) → (离散配置 Γ)
Φ = ( sign(highest-level move dir of E/$),
       sign(... of C/$),
       sign(... of R/$) )
```
Φ 是多对一的（巨大的纤维：不同级别、不同幅度的边状态映到同一个 Γ）。问"如何在配置空间递归"= 问"递归结构是否下降到商空间 Γ"。**它不干净地下降**，因为 Φ 抹掉了级别与幅度。

按 526 号的存在论区分：

| | a0 确认层（操作性） | 递归层（存在论） |
|---|---|---|
| 对象 | 配置 Γ、极性 S | 逐边走势类型递归 an=f(an−1) |
| 性质 | 类中枢、联合读数 | 严格中枢递归 |
| 在本设计中 | **配置空间** | **六条边的递归栈** |

**配置空间在结构上是一个 a0 式的确认层（类中枢），不是递归层。** 试图"在配置空间上跑存在论递归" = 把递归层的语法施加到 a0 层对象上 = 526 号范畴错误的宏观重演。

> 黑格尔读法：极性指数 S 是**抽象普遍**（master signifier，拉康 S1）——它把能指链（笔的序列）缝合（point de capiton）为一个总体方向，但代价是丢失全部特殊性。具体的真理在**特殊**（逐边走势）里。派生边是**中介**（Vermittlung）：它否定独立边的孤立性（展示共动），把特殊关系重新注入普遍。**具体普遍** = 带持久性权重、保留派生边共动信息的正则化配置（见 Part 3），而非裸的 S。

### 1.5 "配置中枢"与"配置趋势"的诚实定义

任务给的方向"配置中枢 = 配置稳定态，配置趋势 = 系统性轮动"是对的，但必须标明它们是 **a0 层读数**，不是缠论严格意义的中枢/趋势：

- **配置中枢（a0 读数）** = 一段时间内 Γ(t) 不变（三条独立边各自保持走势符号）。
  注意：Γ 可以停在 (+,+,+) 而每条边都在走一个大趋势。所以**配置驻留 ≠ 边层中枢**。配置驻留是远比边层中枢弱的条件。对应毛：**非对抗性矛盾共存**（三类资本并存而方向不激化）。
- **配置趋势（a0 读数）** = S(t) 单调漂移且伴随多条边同向运动（系统性轮动）。对应毛：**对抗性矛盾激化**（趋势背驰才能解决）。

这两个读数**禁止**被用作买卖点的递归级别——它们只能作为 regime 背景（大他者），不能进入 37 课的区间套作为某一级别（见 C4）。

### 1.6 候选构造：持久性加权极性 P(t)（L0 构造 / L2 待验）

若确实需要一个**连续的**配置层对象（使路径 A 的退化消失），唯一严格的构造是用各边当前走势的 **PH 持久性**或**中枢幅度**为权重：

```
P(t) = Σ_i  w_i(t) · s(σ_i(t)),   w_i(t) = persistence(edge_i 当前已结算走势)
```

- w_i 来自 `a_online_persistence`（PH settle）。低持久性的边贡献趋于零（噪声被抑制）。
- P(t) 是实值连续序列，**不**在 7 值阶梯上退化，可以合法地跑缠论笔/线段。
- 与 525 号衔接：σ_i 只在该边走势**局部完成**（settled）时才满额计权——局部完成性是计权条件，不是递归链完整性。

> **边界条件 / 翻转条件（C-P）**：P(t) 的缠论结构必须 L2 验证其携带超出各边边际的信息。若 P(t) 的买卖点只是各边买卖点的并集 → 配置层递归是冗余的，应删除 P(t) 构造。**这是一个可证伪的命题（V3）。** 在 V3 给出肯定结果前，P(t) 仅为候选，不进入生产路径（no-patch：不声明未验证的能力）。

### 1.7 矛盾 C6：单一 Γ 跨级别混合（同级别分解被破坏）

> 本节补 1.1。1.1 已点出 σ_i 取自各边"最高涌现级别"，但未追究其后果。追究下去是一个新矛盾。

K4 报告（L2）实测：三条独立边的最高涌现级别**不相等**——E/$ 到 L4，Au/$ 到 L3，Oil/$ 到 L3。当前 `k4_scanner` 取"各边最高级别走势方向"组装 Γ，意味着 Γ = (E 的 L4 方向, Au 的 L3 方向, Oil 的 L3 方向)。

> **矛盾 C6（单一 Γ 破坏同级别分解唯一性）**
> 38 课同级别分解定理："把所有走势按一固定级别的走势类型进行分解……具有唯一性"。
> 但 Γ 把不同级别（L4/L3/L3）的方向塞进一个三元组 = **跨级别混合**。一个混合了 L4 与 L3 方向的配置，不是任何单一级别上的走势状态——它在存在论上无定所。
> 这与 C1 不同：C1 说"配置不是递归基底"，C6 说"即使只当读数，单一 Γ 的读法本身违反同级别分解"。

**严格解（重构，非补丁）**：配置必须**级别索引**。不是单个 Γ，而是一族
```
Γ_L(t) = ( σ_E^(L)(t), σ_C^(L)(t), σ_R^(L)(t) )
```
其中每个分量取自**同一固定级别 L**。每个 Γ_L 满足同级别分解，C6 消解。`k4_scanner` 应输出级别索引族 {Γ_L}，而非单个"最高级别 Γ"。

### 1.8 配置递归的第二维度：级别维 RG 流与 regime 不动点

C6 把配置变成二维对象 Γ_L(t)——级别维 L × 时间维 t。1.6 的 P(t) 是**时间维**的连续化（持久性加权）；本节给出**级别维**的递归，二者正交互补。统一对象是 **P_L(t)**：每个级别一条持久性加权配置序列。

> **配置递归 = 级别维重整化群流（L0）**
> 沿级别维，每升一级 L→L+1，三条边各自被其自身递归栈粗化（settled move → 上一级别线段，`recursive_stack`），配置 Γ_{L+1} 是 Γ_L 的重整化。配置的"递归"严格地是：**配置场在级别维的 RG 流**，不是时间维的缠论笔（那是 C1 的范畴错误）。
> - 黑格尔读法：每升一级是对下一级的扬弃——否定（低级别抖动被抹平）+ 保留（方向被继承）+ 提升（呈现为更稳定状态）。这是与 1.4 的 a0 层投影 Φ **正交的另一条线**：Φ 是横向投影（六边连续 → 离散 Γ），RG 流是纵向粗化（级别 L → L+1）。

**这给出 regime 的严格定义，并使之可证伪**：

> **regime = RG 流不动点（L0 定义，核心待 L2）**
> 若存在级别 L*，使 Γ_L 对所有 L ≥ L* 稳定不变，则该稳定配置 = regime（真正级别不变的宏观状态）。这与 230 号"有效维数随级别退化"一致（高级别自由度更少，更易出现不动点）。
> **若不存在 L*（每级配置都不同）→ "宏观 regime" 是虚构**，配置层 L0（Part 4）失去对象。这是 M2 宏观分支的可证伪拱顶石（见 V7），必须先于其他验证执行。

### 1.9 配置的时间运动 = 异步合并事件流，及矛盾 C7

固定级别 L，Γ_L(t) 在时间上仍变化（某边走势 settle 后翻转）。其结构是精确的：

> **异步合并事件流命题（L0）**：三条边各自产生"方向改变事件"流。两条独立比价边在同一 bar 同时 settle 方向的测度为零。故 Γ_L(t) 是三流的**异步合并**——每次配置变化恰好一个分量改变。

这与 `transition.py` 相邻定义（"恰好一条独立边状态改变"）精确吻合——揭示该相邻规则不是人为约定，而是异步事件流的必然结构。但顺此追究，暴露第二个藏在代码里的矛盾：

> **矛盾 C7（σ 本体论：transition 的 +↔- 禁令）—— 已结算，527 号（定理/吸收）**
> `transition.py` 的 `adjacent()` 禁止 +↔- 直接跳转（必须经 0），这隐含 σ 是**有连续序的位置态**（如价格，从高到低必经中间）。
> 但 `config_space.py` 声明 σ 是**走势方向**（UP/FLAT/DOWN），k4 报告里 σ = trend.up/trend.down。而"走势必完美"允许走势方向直接翻转：一个下跌走势完成后可紧接一个上涨走势，中间不必有独立的"盘整走势"作 FLAT 态。即 σ 可 −1→+1 不经 0。
> - 若 σ 是位置态：transition 的 54 边 / 二部 / 直径 6 / |Aut|=48 全部成立。
> - 若 σ 是走势方向态（当前声明）：转换图应有 81 条边，上述全部图论性质失效。
>
> **结算（527 号，定理/吸收，非选择）**：上浮被撤回——此非定义冲突而是**实现错误**。判断依据（testing-override）：修复 transition.py **不需要改变任何定义**，只是让它与 config_space 既有的 σ=走势方向定义对齐。
> **定论：σ 是走势方向态（立场B）**，由已结算的 σ 定义 + 一级权威"走势必完美"必然推出。立场A 的"图论优美"是数学便利，被 no-patch §7 + 形式化有效域规则否定，无本体论依据。
> 下游（实现层，待执行）：transition 重建为 81 边图；原 54 边图若需要，单独命名为"价格位置态投影"，不得冒充配置转换拓扑；复核 230/231 是否依赖 54 边图性质。

## 第二部分：跨国 K4 拓扑

### 2.1 顶点的异质跨国性（结构的起点）

每个经济体 n 有一个 K4_n = (E_n, C_n, R_n, $_n)。关键观察：**四个顶点的跨国性质完全不同**，所以连接结构不是对称的。

| 顶点 | 跨国性质 | 可套利性 | 卢麒元对应 |
|---|---|---|---|
| **$**（主权信用/现金） | 内禀国别。$_US ≠ $_CN | 通过 FX | 信用本位、定价权 |
| **C**（商品/金油） | **全球单一定价**（近似）。Au、Oil 全球一个价（差汇率） | 高（可运输套利） | **金油两锚** |
| **E**（动产/股权） | 大体国别（SPY vs 沪深300） | 低（分割市场） | 资本流向之一 |
| **R**（不动产） | 强国别，几乎不可跨境套利 | 极低 | **沉没才能流转**（资本的汇） |

**这就否定了把跨国结构建成"两个 K4 的对称积"的想法。** $ 必须跨国连接（FX），C 是**共享**的（不该在每个经济体里各算一份），E/R 才是真正的本国纤维。

### 2.2 三种数学结构的检验

任务问：张量积 / 直积 / 纤维丛，哪个对？逐一证伪：

**直积 K4_US × K4_CN（否定）。** 8 个顶点、两个不相交 K4 + 跨国边。假设两经济体独立。**违反 C 的全球单一定价**：Au 在两国是同一资产，直积把它当成两个独立顶点 → 自由度过计数。错误。

**张量积（范畴积）K4 ⊗ K4（否定）。** 16 个顶点 = (US 顶点, CN 顶点) 的有序对，边定义为 (u,u′)~(v,v′) iff u~v 且 u′~v′。**本体形状错误**：我们没有"美国股权-配-中国商品"这样一个实体作为顶点。张量积的顶点不对应真实资产。错误。

**纤维丛（采纳）。** 这正是 `fiber_bundle.py` 在**单一经济体内部**已经使用的结构（底空间 = σ_E×σ_C 直积，纤维 = σ_R，联络 ω 由 β_er=−0.3355、β_cr=0.1531 校准）。把它**升一层**用于跨国：

### 2.3 跨国纤维丛构造

```
底空间 B   = 全球商品锚流形（Au, Oil 全球单一定价）   ← 卢麒元：金油两锚
纤维   F_n = 经济体 n 的本国资本容器 (E_n, R_n, $_n)   ← 国别分割的部分
联络   ω   = 汇率 $_n / 锚（USD 计价的本币）          ← 跨国 1-形式
全空间 P   = B ×_ω { F_n }                            ← 各国纤维沿 B 黏合
```

- **底空间共享**：金油是全球公分母（卢麒元的锚）。底是各国共有的。
- **纤维国别**：E、R、$ 是国别分割的。纤维在不同国别上"长得不同"。
- **联络/平行移动**：从经济体 m 的纤维移到 n 的纤维 = 经汇率换算。
- **同类边 = 截面比较**：SPY/沪深300、GLD/AU9999、CL/SC 比较的是**同一资产类别在不同纤维上的截面**。

> 这与 `graph.py` 已定义的 `EdgeType.CROSS_NATIONAL` 衔接：跨国同类边就是纤维间的截面比较边。**诚实声明**：现有 `fiber_bundle.py` 是**国内相关性丛**（底=E×C，纤维=R）；跨国丛（底=金油锚，纤维=E/R/$）是一个**不同的、新的构造**。不声称代码已实现跨国（no-patch：不声明代码不具备的能力）。

### 2.4 Holonomy = 空转（卢麒元框架的拓扑落点）

考虑环路：1 单位资本从 $_US 出发，两条路径回到 $_CN：

- 路径 1（汇率直达）：$_US → 经 FX → $_CN
- 路径 2（经商品）：$_US → 买美国黄金 → 在中国卖出黄金 → $_CN

无摩擦、黄金全球一价时两路径结果相等。两者之比 = **环路的 holonomy**：

```
Holonomy(US→CN) = (沪金 / 国际金) · (FX 隐含值) 的偏离
                = 1  (无摩擦)
                ≠ 1  (资本管制 / 溢价 / 定价权争夺) = 空转
```

- **Holonomy ≠ 0 = 卢麒元的"空转"**：资本在一个不闭合的环路里循环，压低价格（空转压价）。
- **沉没才能流转**：纤维里的 R（不动产）顶点是资本的**汇（sink）**——`flow_relation.py` 的 `VertexFlowState` 已有 SOURCE/SINK/NEUTRAL 角色分类，跨国时 R 是最深的 sink。
- **资本三流** = 三条独立边（E/$、C/$、R/$）的流向，由 `capital_flow.py` 的 `FlowDirection` 给出。

**同类边冗余度依赖可套利性**（Part 3 用得到）：

| 同类边 | 是否可套利 | 与 FX+holonomy 的关系 | 信息价值 |
|---|---|---|---|
| GLD/AU9999 | 可（黄金可运输） | ≈ FX·holonomy，**接近冗余** | holonomy 残差（空转度量） |
| SPY/沪深300 | 不可（股权不可跨境转换） | 与 FX 弱相关，**分割信息** | 纯相对强弱，高信息 |
| CL/SC（油） | 部分可（运输有成本） | 介于两者之间 | 区域基差曲率（C3） |
| R_US/R_CN | 几乎不可 | 几乎无关 | 最分割、最高信息、最低流动性 |

### 2.5 双国简化（US + CN）

按任务要求先做最小可行：

- **两个 K4**：US=(SPY, GLD, VNQ, $DXY)、CN=(沪深300/ASHR, AU9999/沪金, 房地产指数, CNH)
- **共享底**：Au=XAU、Oil=Brent/WTI/SC
- **联络**：USDCNH
- **同类边**：SPY/沪深300、GLD/AU9999、CL/SC、（R_US/R_CN）
- **最小跨国对象** = 各 K4 的 6 条边（12）+ FX 边（$_US/$_CN）+ 同类边

用户实盘已是隐式跨国操作：BZ（全球定价油）落在底空间，HK700（中国股权）落在 CN 纤维，OKLO（美国股权）落在 US 纤维，BTC（无国籍）——**BTC 是一个新的本体问题**：它既不在任何国别纤维里，也不在金油锚里。它是一个**漂浮能指**（拉康），暂记为底空间的第二锚候选（待编排者裁决，见决策点 D2）。

### 2.6 矛盾 C3：底空间非平坦

> **矛盾 C3（金油锚不是平坦底）**
> 商品有区域溢价：Brent vs WTI vs SC，不同市场的黄金溢价。所以底空间本身有曲率，丛在底层就非平凡。
> 卢麒元会说：锚正在被攻击（定价权争夺）。
> **处理**：底平坦是 **L0 理想化**；L2 必须测量底曲率（Brent−WTI−SC 价差、各市场金溢价）。不把"金油是平坦锚"当作已验证前提（formalization-validity-domain：有效域 < 定义域）。

## 第三部分：正则化

正则化 = 从冗余自由度中提取不变量。本设计识别**三层嵌套的冗余**，对应三类不变量。

### 3.1 冗余的三个来源

1. **代数冗余**：6 条边在价格层只有 3 个自由度（K4 的圈秩）。
2. **持久性冗余**：低持久性走势的 σ 是噪声，不该参与配置判定。
3. **统计冗余**：27 个配置在经验测度下有效维数 < 3（230 号：直积退化）。

### 3.2 代数不变量：圈条件（纠错码，**不是降维**）

K4 有 6 边、4 顶点，圈空间秩 = 6 − 4 + 1 = 3。连接 $ 的 3 条独立边构成生成树；3 条派生边各闭合一个三角形 = 3 个基本圈。在对数比价空间：

```
绕任一三角形：  log(E/Au) + log(Au/Oil) + log(Oil/E) = 0   （乘性 cocycle）
```

朴素的正则化会说"投影到生成树（3 条独立边），派生边丢弃"。**但 C2 否定了这条路**：派生边的缠论结构不由独立边决定，丢弃 = 丢掉共动信息。

**严格形式**：圈条件**不用作降维**，用作**纠错码 / 一致性检验**。

```
残差 ρ(t) = log(E/Oil)_直接测量 − [ log(E/Au) + log(Au/Oil) ]_重构
```

- ρ ≈ 0（噪声级）→ 数据一致，比价管线无 bug。
- ρ 显著且有结构 → 要么数据质量问题（ETF 溢价/费率/时段错配，见 K4 报告边界），要么**真实市场分割**（套利受阻）。
- ρ 本身是一个 **L2 可测的不变量**（V1）：跨国时 ρ 就是 holonomy 的对数。

> 不变量 #1：**圈闭合残差 ρ**。代数层 L0，经验值 L2。它把"6 边只有 3 自由"从降维理由转为可证伪的检验量。

### 3.3 持久性正则化：PH 权重 + 525 号局部完成性

- σ_i 只在边 i 的当前走势**局部完成（settled）**时才置为 ±1；否则置 0（盘整/未定）。局部完成性由 PH settle（`a_online_persistence`）判定——**525 号**：以局部完成性为判据，**不下钻验证递归链完整性**。
- 配置层据此变成"**持久性门控配置**"：只有高持久性的方向才进入 Γ。这正则化掉了 K4 报告里"未结算走势"造成的抖动。
- **边界（521 号）**：PH settle 是 candidate 层必要条件，**不是操作充分确认**。所以持久性门控只过滤配置的"形态学资格"，**不**单独触发操作——操作充分性需 MACD 背驰（见 Part 4）。用 PH 做入场/退出门控是越界（memory：PH settle 用途边界）。

> 不变量 #2：**持久性门控配置 Γ_settled**。它对噪声鲁棒，且诚实地停在"形态学必要条件"层，不冒充操作信号。

### 3.4 统计正则化：有效维数（230 号）+ Z2 对称折叠

**有效维数（230 号的直接延伸）。** `fiber_bundle.py` 已证：27 个代数配置在经验概率测度下，因 E-C 近独立（直积因子）、E-R 跷跷板（β_er<0）、C-R 同向（β_cr>0），有效自由度 < 3。

> 不变量 #3a：**有效维数 = 经验耦合矩阵的秩 / 圈秩**。这是最深的正则化——配置空间的**定义域是 27，有效域（有效自由度）经验上 < 朴素计数**。跨国时重做这个测量（V5）。

**Z2 对称折叠（多空对偶）。** 配置空间唯一干净的对称是全局符号翻转 σ → −σ（risk-on ↔ risk-off）：

- (+,+,+) ↔ (−,−,−)，S → −S。
- 不动点：仅中心 (0,0,0)。其余 26 个折成 13 对。商空间 = 1 + 13 = **14 个轨道**。

注意：3 条边的**置换对称 S3 被资产语义破坏**（金 ≠ 股，E-R 是跷跷板不是可交换的）。所以**没有**置换对称，只有 Z2。

> 不变量 #3b：**Z2 折叠后的 14 轨道配置空间**。
> **边界 / 翻转条件（C-Z2）**：Z2 是 **L0 代数对称**，其经验有效性（有效域）可疑——市场不对称（崩盘快于上涨、油涨≠油跌、β_er 的跷跷板破坏对称）。所以**按 Z2 折叠是一个待检验的假设（V5 的一部分），不是前提**（formalization-validity-domain）。若 L2 否证 Z2，则保留 27（或持久性门控后的子集），不折叠。

**与 `fold_equivalence.py` 的关系**：标的层折叠（5 通道、W 权重、商空间 F/~）和配置层折叠（Z2、14 轨道）是**两个不同层级的折叠**。前者折叠标的（352 号），后者折叠宏观配置。不要混用。商空间排序 rank = T·W（标的层）和配置 Z2 折叠（配置层）在管线里串联：配置层先定 regime → 标的层在 regime 内排序。

### 3.5 统一原理（黑格尔 / 拉康）

三层正则化是同一个运动：**剥离想象界的冗余（6 边、27 标签、想象的丰盈），抵达符号界的骨架（3 圈、有效 <3 维、master signifiers）。**

- 代数层（圈条件）= 符号秩序的语法约束。
- 持久性层（PH 门控）= 把无意义的抖动（imaginary noise）排除出能指链。
- 统计层（有效维数）= 找到真正起作用的少数自由度（point de capiton）。
- **抵抗符号化的实在（Real）** = 圈闭合残差 ρ + 跨国 holonomy（空转）——它们**不肯闭合**，正是卢麒元说的资本空转，也是系统最有信息量的产出（矛盾不是 bug）。

黑格尔正反合落点：
- **正**（直接）：3 条独立边，3 个自由度，孤立的资本三流。
- **反**（中介）：3 条派生边，否定独立性，揭示共动（C2 的非线性正是中介的力量）。
- **合**（具体普遍）：圈条件 + 持久性权重 + 有效维数——保留了独立边的方向、派生边的共动、以及对实在残差 ρ 的标记。

## 第四部分：与操盘层的有机结合

### 4.1 四层状态机 = 38 课的多级别分工

`state_machine.py` 的四层与 38 课的大资金多级别分工同构：

| 层 | state_machine | M2/M1 | 38 课对应 | 缠论级别 |
|---|---|---|---|---|
| L0 | L0_CONFIG | M2 配置（持久性门控 Γ_settled） | regime 背景 / 大他者 | 最大级别（持仓） |
| L1 | L1_EDGE | 跨角轮动（独立边/折叠等价类边） | 哪类资本受益 | 大级别 |
| L2 | L2_CORNER | 角内标的轮动（商空间排序代表元） | 选哪个标的 | 次级别 |
| L3 | L3_STOCK | 单标的中枢震荡操作 | T+0 高抛低吸降成本 | 操作级别（短差） |

三条公理就是操作纪律：

- **公理1（上层覆盖）** exit_abort(L_k) → 所有 j>k 进入 INACTIVE：regime 翻转（配置层趋势背驰）强制平掉所有下层短差。对应 38 课"向上段运作结束 → 转入向下段，逻辑相反（先卖后买）"。
- **公理2（下层依赖）** L_i 入场需 L_(i−1) ACTIVE：没有 regime 支持就不许选股，没选标的就不许操作。对应 38 课"只操作上涨和盘整类型，避开所有下跌类型"——配置层先把方向定死。
- **公理3（侧向轮动）** exit_normal 保持层 ACTIVE 等新角/新标的：一个标的的中枢震荡结束（不创新高/盘整背驰），层不关闭，等下一个标的。对应 38 课"一个中枢完成就继续关注下一个中枢"。

### 4.2 区间套对齐（37 课）与级别错配陷阱

37 课区间套：递归式 a+A+b+B+c 套中套，逐级下钻精确定位背驰。在 M2×M1 里，区间套的层次是：

```
配置层 P(t) 走势（若 V3 通过）   ← 最外层区间套（大级别背景）
   ⊃ 折叠等价类代表元的比价走势    ← 中层
      ⊃ 单标的走势               ← 操作级别
         ⊃ 单标的次级别中枢震荡    ← 最内层（T+0）
```

> **矛盾 C4（级别错配 / 越级陷阱，不可绕过）**
> M2 配置递归的基底是**比价/配置序列**；M1 操作递归的基底是**单标的价格序列**。两者是不同的递归链（不同的 a0，526 号）。
> E/$ 走势在 L4，**不**蕴含某只具体股票在 L4。把配置层直接当作单标的的某一区间套级别 = 把两条不同递归链强行接成一条 = 越级（对象否定对象的跨链误用）。
> **严格解（不是补丁）**：配置层与操作层**通过共振耦合，不通过单一递归**。

### 4.3 共振耦合而非单一递归

- 配置层（大他者）提供**方向与资格**：38 课"只做上涨+盘整"——配置告诉你哪些资产在上涨/盘整 regime，哪些在下跌 regime（禁做）。
- 操作层（单标的）提供**时机**：中枢震荡的买卖点（37 课区间套在**单标的自己的**递归链里精确定位）。
- 两者的接口是 `nesting/resonance.py`（共振检测）+ `nesting/bsp.py`（区间套买卖点）：当配置层方向与单标的买卖点方向一致时 = 共振 = 高置信信号。**配置不进入单标的的递归链，只与之共振。** 这避免了 C4 的越级。

毛：配置层是**主要矛盾**（决定哪类资本是当下矛盾的主要方面，如用户当前押注的金油比/美元信用），单标的操作是**次要矛盾**。主要矛盾规定次要矛盾的活动方向，但不取代它（先卖后买 vs 先买后卖由主要矛盾的方面决定）。

### 4.4 方向 / 降成本 / 杠杆的配置驱动

- **方向**：配置层独立边符号 σ_i → `cost_reduction_fsm` 的操作方向。σ 向上 → 38 课"向上段，先买后卖"；σ 向下 → "向下段，先卖后买"。
- **降成本模式**：38 课的 T+0 高抛低吸由 L3 单标的中枢震荡驱动，与配置层方向一致时全力降成本，方向矛盾时仅防御性降成本。
- **杠杆**：杠杆不是配置单独决定的。`options-selector` skill 的三 strike 落在缠论关键位置，杠杆是派生结果。配置只贡献**置信度**（|S| × 持久性 × Z2 折叠稳定性）作为杠杆的一个输入，**但必须叠加 MACD 背驰确认（521 号）**——PH 持久性是 candidate 必要条件，confirmed 才驱动杠杆。配置单独定杠杆 = 越界。

### 5.2 六项可证伪验证（L2/L3）

每项都设计为**可产生否定性结果**（否定缩小有效域，比确认更有价值）：

- **V1（圈闭合残差 ρ）** L2。测 log(E/Oil)_直接 vs log(E/Au)+log(Au/Oil) 的残差。
  *证伪*：ρ 大且有结构 → 代数正则化对缠论结构无效 / 存在真实分割。
- **V2（派生边信息）** L2。测 Move(E/C) 能否由 Move(E/$), Move(C/$) 预测。
  *证伪*：可预测 → 派生边冗余（C2 被经验否定，可降维）；不可预测 → 共动信息真实（C2 成立，必须保留派生边）。**两个方向都有信息增量。**
- **V3（配置递归良定性）** L2。测持久性加权 P(t) 的缠论买卖点是否超出各边买卖点的并集。
  *证伪*：只是并集 → 配置层递归冗余，删除 P(t) 构造（1.6 的 no-patch 兑现）。
- **V4（holonomy / 空转）** L3。测跨国环路残差随时间变化，与资本管制事件 / 卢麒元 regime 断点协整。
  *证伪*：holonomy 恒 ≈ 0 → 无空转，跨国丛退化为平凡丛，纤维丛结构对 US-CN 不增信息。
- **V5（有效维数 + Z2）** L3。在多经济体配置空间重做 230 号有效维数测量；检验 Z2 对称的经验有效性。
  *证伪*：有效维数 ≈ 朴素计数 → 无统计冗余可正则化；Z2 显著破缺 → 不许按多空对偶折叠（C-Z2 兑现）。
- **V6（操作对齐）** L3。四层状态机回测：配置驱动 L0 门控 vs **随机门控对照**（memory：回测基准不可证伪陷阱——必须有随机门控对照，不能只比 buy-hold）。
  *证伪*：配置门控不优于随机门控 → 配置层不产生 alpha，M2 对 M1 无有机贡献。
- **V7（RG 流不动点存在性，证伪 regime 概念本身）** L2，**最高优先 / 闸门测试**。对单国 Γ_L 沿 L=1,2,3,4 提取配置，检验是否存在 L* 使 Γ_L 对 L≥L* 稳定（1.8）。仅需已有单国数据，最便宜、最可能否证。
  *证伪*：不存在 L* → "宏观 regime" 是虚构，配置层 L0 失去对象，M2 宏观分支整体作废。**V7 是闸门：V7 失败则 V1–V6 无意义。** 验证顺序：V7 → V1/V2/V3（单国 L2）→ V4/V5/V6（跨国 + alpha，L3）。

### 5.3 否定性结果的价值声明

本文档全部命题在 V1–V6 执行前是 **L0（代数/定义）**。L0→L1（合成数据）信息增量为零。只有 V1–V6 的 **L2/L3 真实数据**能产生信息增量。**任何一项的否定性结果都直接修改本设计**：V2 否定 → 删派生边；V3 否定 → 删 P(t)；V4 否定 → 跨国丛退化；V5 否定 → 不折叠；V6 否定 → M2 不驱动 M1。设计必须为自己的被否证留好接口（no-patch：不声明未验证的能力）。

## 7. 结果包（六要素）

**1. 结论**
M2 正则化的严格形式 = 三层构造：
(a) **配置空间递归**被重构为**六边联合缠论递归 + 同步分析**，配置本身是 a0 层投影（526 号），不是递归基底（C1）；可选的连续化是持久性加权 P(t)（L0 构造，L2 待验）。
(b) **跨国 K4** = 纤维丛（底=金油锚，纤维=本国 E/R/$，联络=汇率），否定直积与张量积；holonomy = 卢麒元空转，同类边冗余度依可套利性分级。
(c) **正则化** = 三不变量：圈闭合残差 ρ（代数，纠错码非降维）、持久性门控配置 Γ_settled（525 号）、有效维数 + Z2 折叠（230 号，经验有效域待验）。
(d) M2 经**四层状态机 + 共振耦合**驱动 M1（38 课多级别分工 + 37 课区间套），通过共振而非单一递归避免越级（C4）。

**2. 定义依据**
- 配置/极性：`config_space.py` polarity_index、node_type；K4：`graph.py` 独立边/派生边/CROSS_NATIONAL。
- 派生边代数推导：`graph.py` 注释（价格层恒等）；非线性破同态：缠论笔/线段为路径非线性泛函。
- 转移相邻性 = 恰好一条独立边变一步：`transition.py`。
- 纤维丛底/纤维/联络：`fiber_bundle.py`（β_er, β_cr 校准）。
- 四层公理：`state_machine.py`。流场守恒/SOURCE-SINK：`flow_relation.py`。
- 操作程式：缠论 38 课（中枢震荡机械化操作）、37 课（区间套精确定位）。

**3. 边界条件（翻转条件）**
- C1：配置空间不是合法缠论递归基底（离散 + 丢级别/幅度）。
- C2：价格层代数冗余不下降到缠论结构层（派生边共动信息）——V2 可证伪。
- C3：金油底非平坦（区域溢价），底平坦是 L0 理想化——L2 测底曲率。
- C4：M2/M1 不同递归基底，强接一条链 = 越级——用共振耦合。
- C-P/C-Z2：P(t) 与 Z2 折叠的经验有效性待 V3/V5 验证；否证则删除/不折叠。
- **C6（同级别分解破坏）**：单一 Γ 取各边最高级别 = 跨级别混合（E/$=L4, Au/$=L3, Oil/$=L3），违反 38 课同级别分解唯一性——已重构为级别索引族 Γ_L（1.7）。
- **C7（σ 本体论，已结算 527 号，定理/吸收）**：`transition.py` 禁 +↔-（假设连续位置态）vs `config_space.py` 声明走势方向态（可跳变）。结算为**实现错误非定义冲突**——σ=走势方向态（立场B）由既有定义 + 一级权威推出。transition 应重建为 81 边图（1.9）。
- **C8（R 顶点数据缺口，行动类）**：k4 报告只跑 E/Au/Oil，σ_R 维基于占位，当前 27 配置 σ_R 分量不可信——需补 REIT 真实数据（5.1）。
- **regime 存在性（V7 闸门）**：若 RG 流无不动点，配置层 L0 失去对象，M2 宏观分支整体翻转作废。
