# 递归分解树 + 三层圈闭合架构设计

> 设计日期：2026-06-07
> 谱系上下文：529号折叠重构（M/P/C/R 四顶点 + 折叠通道）已完成；C 路径横向圈闭合（`k4_path_c.py`）已验证保留 96% alpha。
> 认识论等级：本文档是**架构设计 + 形式化操作定义**，纵向圈闭合的代数为 L0，单成分 σ 读数为 L2，纵向选股 alpha 为 L2（待回测，本设计不声称已验证）。

## 0. 执行摘要

M2 选股层当前只有**横向圈闭合**（同层 K4 六条边的代数冗余纠错，`k4_path_c.py`）和**跨国圈闭合框架**（汇率边 Σ 层，`cross_national_pipeline.py`）。本设计补齐缺失的**纵向圈闭合**——顶点与其成分之间的一致性检验——并把三层圈闭合统一进一棵**递归分解树**。

核心命题：

> **横向圈闭合检验"K4 六边读数是否自洽"（图论冗余）；纵向圈闭合检验"宏观顶点的趋势是否被其成分广泛支撑"（分解一致性）；跨国圈闭合检验"不同经济体的 K4 是否经汇率边对齐"（结算尺一致性）。三者共享同一个 L0 机制——在 σ 符号层做一致性表决——区别只在表决的对象与权重。**

纵向不闭合不是 bug，是**选股信号的来源**：宏观边说"P 强于 C"（股强于商品），分解 P 看哪些成分 `stock_i/C` 与宏观同向且高权重 = 趋势主驱动力 = 选股排序靠前；偏离宏观的成分 = 落后/反向信号。这正是缠论第73课"找到行业→找到龙头企业→比价关系发现低估品种"的代数化。

## 1. 存在论位置：与已有架构的关系

### 1.1 已有的两层圈闭合

| 圈闭合 | 模块 | 对象 | 机制 | 状态 |
|--------|------|------|------|------|
| **横向** | `strategy/k4_path_c.py` | 同层 K4 六条边的 σ | 三估计路径多数表决（`closure_consensus`） | ✅ 已验证（保留 96% alpha） |
| **跨国** | `topology/cross_national_pipeline.py` | 各经济体 K4 + 汇率边 Σ | 多条 FX 边同步同向 = 结算尺断裂（254号定理2） | ✅ 框架已实装（数据多缺口） |

### 1.2 三层圈闭合是同一机制的三个截面

横向圈闭合（`k4_path_c.py:206-219` 的 `_majority`）的本质：
- 同一个量（如 ES/GC 方向）有**多条独立估计**（直接读、过现金、过第三资产）
- σ 是离散符号 {+1,0,−1}，加法不满足恒等 → 独立估计可能矛盾
- **矛盾即可纠错信号**（噪声/级别错配被多数表决否决）

纵向圈闭合完全同构：
- 宏观顶点 P 的方向有**两种来源**：直接读 σ(P/ref)，或由成分加权合成 Σ wᵢ σ(stockᵢ/ref)
- σ 是离散符号 → 直接读与合成读可能矛盾
- **矛盾即结构信号**（趋势集中在少数成分 = 宽度不足 = 脆弱）

跨国圈闭合：
- 同一资产类（如各国股权）的相对强弱有**两种来源**：直接读各国 P/M，或过汇率边换算
- **矛盾即套利/错位信号**（254号：结算尺断裂候选）

> **设计原则**：纵向圈闭合**不重新发明**机制，而是把横向的 `closure_consensus` 模式推广到"顶点→成分"的加权场景。三者在 σ 符号层运算，都是 L0（纯代数，作用于已有读数，零信息增量）。

## 2. 递归分解树（四层）

```
Layer 3  跨国 K4 层
         US_K4 ←汇率→ CN_K4 ←汇率→ EU_K4 ←汇率→ JP_K4
         （cross_national_pipeline.py，横向圈闭合在汇率边 Σ）
              │  分解：每个经济体一个 K4
              ▼
Layer 2  单国 K4 层
         M / P / C / R 四顶点，六条边（3 独立 + 3 派生）
         （graph.py + config_space.py + k4_path_c.py，横向圈闭合在六边）
              │  分解：每个非货币顶点 → 其成分
              ▼
Layer 1  顶点分解层  ← 【本设计的纵向圈闭合发生在这里】
         P → 行业ETF/期货 → 成分股      （如 QQQ → SOXX → NVDA）
         C → 能源/金属/农产品 → 具体商品 （如 DBC → 能源 → CL）
         R → 商业/住宅/REITs → 具体标的
              │  分解：到不可再分的可操作标的
              ▼
Layer 0  个股操盘层
         每个叶标的用 E 版本（背驰定位器）操盘
         （次级别底背驰进场 + L2 趋势顶背驰出场，已验证）
```

### 2.1 分解的层级约束（292号区间套：外层约束内层）

292号折叠层级"共享折叠是外层，特有折叠是内层，外层约束内层"在分解树上的体现：

> **上层闭合是下层分解的前提**。只有当 Layer 2 的横向圈闭合给出"P 顶点方向明确"（如 σ(P/C)=UP），Layer 1 的纵向分解才有意义——分解一个方向不明（FLAT）的宏观顶点产出不了选股信号。

这是缠论第73课的级别纵向视野（73课第22-24段）：
> "用同一级别的视角去看走势，就如同用一个横切面去考察，而当把不同的级别进行纵向的比较，对走势就有了一个纵向的视野。一个月线级别的上涨，在年线级别上，可能就是一个中枢震荡中的一个小段。"

横向圈闭合 = 横切面（同级别六边）；纵向圈闭合 = 纵向视野（顶点→成分跨级别）。

### 2.2 DecompositionNode 数据结构

```
DecompositionNode
├── label: str                  # 人类可读标识（"US", "P", "SOXX", "NVDA"）
├── layer: TreeLayer            # 所在层（枚举）
├── vertex: Vertex | None       # 对应的 K4 顶点（仅 Layer 1 顶点分解节点非空）
├── symbol: str | None          # 数据源标的代理（叶节点/可观测节点非空）
├── weight: float               # 在父节点中的权重（市值权重，兄弟节点 Σ≈1）
└── children: tuple[Node, ...]   # 子节点（叶节点为空）
```

约束（系统边界，输入验证）：
- 非叶节点的 children 权重和 ∈ [1−ε, 1+ε]（市值权重归一）
- 叶节点必须有 symbol（可操作）
- Layer 1 顶点分解节点必须有 vertex（标明分解的是哪个 K4 顶点）

## 3. 圈闭合的两层结构（核心）

### 3.0 为什么是两层

圈闭合在**两个本体论层级**上各做一次，二者判据不同、不可混淆：

| 层 | 对象 | 判据 | 等级 | 失败的含义 |
|----|------|------|------|-----------|
| **Layer A：a0 精确闭合** | 原始 bar 的价格/比值 | **等式**（残差应 = 0） | L1 | 数据质量问题 |
| **Layer B：走势状态软闭合** | 各边递归涌现的走势状态 | **兼容性**（不要求相等） | L0/L2 | 结构信号（脆弱/冲突） |

> **核心区分**：Layer A 用等式（代数恒等，残差=0），Layer B 用兼容性（不强制相等）。**把 Layer B 也当等式检查是范畴错误**——它混淆了 a0 层的代数恒等与走势状态层的涌现结构。

### 3.1 Layer A：a0 精确闭合（数据质量检查）

逐 bar 检查代数恒等。横向（比值边，用户给定形式）：

```
ρ(t) = log(P/C)(t) − [ log(P/M)(t) + log(M/C)(t) ]
```

价格比值层这恒等式**构造上必为 0**（log(P/C)=log(P/M)−log(C/M)=log(P/M)+log(M/C)）。

纵向（指数分解）对应——"成分加权能否精确复制宏观指数"：

```
ρ(t) = log(P(t)) − log( Σ wᵢ · Sᵢ(t) )
```

判据：|ρ(t)| 应 ≈ 0。
- **ρ ≈ 0**：数据/权重自洽 → Layer B 结论可信。
- **ρ ≠ 0**：**数据质量门未通过**——权重错、成分不全、价格错位、分红未调整。此时 Layer B 选股结论不可信，**先修数据**（no-workaround：不在脏数据上跑选股）。

认识论：L1（验证数据/管线，零信息增量）。Layer A 是 Layer B 的**前置门**，不是信号源。

### 3.2 Layer B：走势状态软闭合（兼容性，不是等式）

#### 3.2.1 级别不对齐是信息，不是 bug（526号 a0 递归）

各条边从 a0 **各自**递归，涌现**自己的**级别体系（526号：aₙ=f(aₙ₋₁)，但每条边的 a0 起点与递归路径不同）。因此：

> **三个 L1 不是同一个 L1。** 边 P/M 的 L1 与边 M/C 的 L1 是两个独立递归涌现的级别，没有理由相等或对齐。强制 "L1 的 σ(P/M) + L1 的 σ(M/C) = L1 的 σ(P/C)" 是把**不可对齐的级别**硬塞进等式——范畴错误。

级别不对齐**携带信息**：
- 先涌现出**高级别结构**的边 = 信号最清晰 = 置信度最高 = 权重最高。
- 还在**低级别盘整**的边 = 信号不确定 = 置信度低 = 权重降低。

> ⚠ **对现有横向圈闭合的下游推论（诚实标注，不静默）**：`k4_path_c.py` 的 `closure_consensus` 隐含"所有边取各自最高级别 σ 并对齐"假设（注释自陈"同级别 σ 闭合"）。本约束（三个 L1 不是同一个 L1）**否定**该假设。修正横向 `closure_consensus` 为级别加权兼容性是**下游待修正项**，需独立谱系 + 回测验证（横向已验证保留 96% alpha，改动须证明不退化），**不在本次范围**。

#### 3.2.2 级别置信度权重

每条边读数携带 `(σ, level)`：σ 是**最高涌现级别**的走势方向，level 是涌现的最高级别（递归深度）。

置信度（**级别清晰度，与方向正交**）：

```
conf(level) = 1 − 2^(−level)        [新缠论:选择]
```

（L1→0.5、L2→0.75、L3→0.875…，"每升一级不确定性减半"）

> **conf 只依赖 level，不依赖 σ**：**高级别盘整**（如 L3 中枢，σ=FLAT）是清晰结构（高 conf + 明确无方向）；**低级别盘整**（L1 未涌现方向）才是不确定（低 conf）。这正是"还在低级别盘整的边权重降低"的精确含义。

有效权重 = 市值权重 × 级别置信度：

```
eff_weightᵢ = market_weightᵢ × conf(levelᵢ)
```

#### 3.2.3 兼容性检查（替代等式检查）

**不**检查"成分加权 σ == 宏观 σ"（等式），而检查**有没有边在高级别上与宏观严格相反**：

```
incompatibility = Σ_{i: σᵢ·σ_macro < 0} eff_weightᵢ
compatible = ( incompatibility ≤ θ )      [新缠论:选择，默认 θ=0.5]
```

- 成分 **FLAT（盘整）** → σᵢ·σ_macro = 0 → 不计入 incompatibility（**不否定宏观，兼容**）。
- 成分在**低级别**反向 → eff_weight 小（conf 低）→ 弱冲突。
- 成分在**高级别**反向 → eff_weight 大 → **真冲突，不兼容**。

这正是用户约束：低级别盘整的边不算冲突（信号不确定），高级别相反的边才算冲突。

#### 3.2.4 三个度量（级别加权版）

**(1) 加权方向合成** `synth = Σ eff_weightᵢ · σᵢ.value`（高级别清晰边主导）

**(2) 参与度背离** `concentration`（趋势宽度）

```
weighted_participation = Σ_{i: σᵢ==σ_macro} eff_weightᵢ   # 同向成分有效权重和
count_participation     = |{i: σᵢ==σ_macro}| / n           # 同向成分个数比例
concentration = weighted_participation − count_participation
```

- `concentration > 0`：趋势集中在高权重/高级别少数成分 → **结构脆弱**
- `concentration ≈ 0`：广泛参与 → 稳健
- `concentration < 0`：龙头分歧（罕见预警）

**(3) 成分残差** `residualᵢ = |σᵢ.value − σ_macro.value| ∈ {0,1,2}`（0 对齐、1 正交、2 反向）

#### 3.2.5 成分贡献度（选股信号来源）

```
contributionᵢ = eff_weightᵢ · (σᵢ.value · σ_macro.value) + λ · bsp_voteᵢ
              = market_weightᵢ · conf(levelᵢ) · (σᵢ·σ_macro) + λ · bsp_voteᵢ
```

- **高级别同向** → 大正贡献（清晰龙头，DRIVER）
- **高级别反向** → 大负贡献（真反向，CONTRARIAN）
- **低级别** → 小贡献（不确定，趋于 MARGINAL）

这把"先涌现高级别结构的边权重最高"直接编码进贡献度。第二项 `bsp_voteᵢ`（操作级背驰买卖点，与 `k4_path_c.bsp_signed_vote()` 同构）的权重 λ = `W_VERTICAL_BSP`。

#### 3.2.6 关键价值判断点：λ 与 θ

两个 **[新缠论:选择]** 自由参数：

| 参数 | 默认 | 含义 |
|------|------|------|
| λ = `W_VERTICAL_BSP` | 1.0 | >1 买卖点主导（反转择时）；<1 方向主导（趋势跟随）；0 纯方向 |
| θ = 不兼容阈值 | 0.5 | 相反高级别边的有效权重和超过 θ 即判不兼容 |
| conf(level) 公式 | 1−2^(−level) | 级别→置信度映射；可改为线性/分段 |

三者最优值均属 L2，需回测标定；默认值不声称最优。

## 4. 纵向选股信号（SelectionRanker）

### 4.1 排序产出

`SelectionRanker.rank(closure)` 按 `contributionᵢ` 降序，产出每个成分：

| 字段 | 含义 | 缠论第73课对应 |
|------|------|---------------|
| `symbol` | 标的 | — |
| `contribution` | 综合贡献（方向+买卖点） | 排序主键 |
| `weight` | 市值权重 | "70%投龙头、30%投成长" 的权重基准 |
| `residual` | 对宏观偏离度 | "比价关系发现低估品种" |
| `role` | 角色分类（见 §4.2） | "龙头 / 成长 / 落后 / 反向" |

### 4.2 成分角色分类（不做门控，做排序）

与 `joint_reading` 哲学一致——**不做允许/拦截，做排序**，由下游决定如何消费：

```
role = DRIVER     若 contribution > 0 且 residual == 0   # 主驱动力（同向高贡献，龙头候选）
       LAGGARD    若 contribution ≈ 0 且 residual >= 1   # 落后（盘整偏离，补涨候选）
       CONTRARIAN 若 contribution < 0 且 residual == 2   # 反向（逆宏观，做空/回避候选）
       MARGINAL   其他                                    # 边缘
```

> **认识论边界**：role 是**形态学分类**（candidate 层），不是操作充分确认。是否实际入场由 Layer 0 的 E 版本背驰定位器在该成分自身级别上确认（参见 auto-memory `project_ph_settle_usage_boundary`：拓扑形态是必要条件，操作确认需 MACD 背驰）。

### 4.3 与缠论第73课的对应

| 第73课原文 | 本设计代数对应 |
|-----------|---------------|
| "找到了行业，就到了具体企业的寻找" | Layer 1 顶点→行业→成分股的递归分解 |
| "70%投龙头，30%投成长" | 按 contribution（含 weight）排序的权重分配 |
| "只要行业顺序不变，投资比例就不变" | concentration 稳定 → 持有；concentration 漂移 → 调仓 |
| "密切关注比价关系，发现低估品种" | residual 大的 LAGGARD = 比价偏离 = 低估候选 |
| "把所有投资成本变为0" | Layer 0 E 版本降成本短差（已有，本设计不重复） |

## 5. 认识论标注（formalization-validity-domain 规则强制）

| 操作 | 等级 | 理由 |
|------|------|------|
| Layer A：a0 精确闭合（指数复制残差 ρ） | **L1** | 数据质量门——验证数据/权重自洽，零信息增量；非信号源 |
| Layer B 代数（synth/concentration/incompatibility/contribution、level_confidence） | **L0** | 纯代数，作用于已有 (σ,level) 读数，零信息增量（与横向 `closure_consensus` 同级） |
| DecompositionTree 结构验证（权重归一、层级约束） | **L0** | 定义检查，不依赖数据 |
| 单成分 σ(cᵢ/ref) 缠论读数 + level | **L2** | 真实数据缠论引擎产出，可证伪 |
| PoC（SPY/QQQ/SOXX 跑通管线） | **L1** | 管线正确性验证，**不验证选股 alpha**（信息增量为零） |
| 纵向选股 alpha（contribution 排序是否跑赢） | **L2（待验证）** | 需真实数据回测对照，本设计**不声称已验证** |

> **关键诚实声明**：§4 的 role 分类与 contribution 排序在 PoC 中只验证"管线产出结构正确"（L1）。"按 contribution 选股能产生 alpha"是 L2 待证伪假设，必须由独立回测（对照随机选股 / 等权基准）检验。L0→L1 信息增量为零（formalization-validity-domain 规则）。

## 7. 模块设计（`src/newchan/topology/decomposition_tree.py`）

```
# 树结构
TreeLayer(Enum)                  # CROSS_NATIONAL / NATIONAL_K4 / VERTEX_DECOMPOSITION / INSTRUMENT
DecompositionNode(frozen)        # 递归节点（label/layer/vertex/symbol/weight/children）
DecompositionTree                # 管理树：构建、遍历、层级取节点、权重验证

# Layer A：a0 精确闭合（数据质量门，L1）
A0ClosureResult(frozen)          # n_bars/mean_abs_residual/max_abs_residual/is_clean
a0_precision_residual(...)       # 逐 bar ρ=log(P)−log(Σ wᵢ Sᵢ) → A0ClosureResult

# Layer B：走势状态软闭合（兼容性 + 级别加权，L0）
level_confidence(level)          # conf = 1−2^(−level)（级别清晰度，与 σ 正交）
ComponentReading(frozen)         # 成分读数（symbol/weight/sigma/level/bsp_vote）
ComponentRole(Enum)              # DRIVER/LAGGARD/CONTRARIAN/MARGINAL
ComponentContribution(frozen)    # 含 level/level_confidence/eff_weight/residual/contribution
VerticalClosureResult(frozen)    # synth/compatible/incompatibility/concentration/contributions
VerticalClosure                  # check(macro_sigma, components, macro_level, w_bsp, theta)（L0）

# 选股排序
SelectionEntry(frozen)           # 单成分排序条目（symbol/contribution/weight/residual/role）
SelectionRanking(frozen)         # 排序结果（含 compatible/concentration）
SelectionRanker                  # rank(closure) → SelectionRanking
```

设计契约（与 `k4_path_c.py` 对齐）：
- **Layer A**（`a0_precision_residual`）作用于**价格序列**（数据质量门，前置于 Layer B）。
- **Layer B**（`VerticalClosure.check`）**只读 (σ,level) 读数**，不碰数据加载/递归引擎
  （L0 可单测，喂合成 (σ,level) 验代数；**不强制跨边级别对齐**——三个 L1 不是同一个 L1）。
- 数据加载/递归是 PoC 脚本的事（复用 `cross_national_pipeline` 同款列式 JSON + RecursiveOrchestrator）。
- 不可变（frozen dataclass）、类型注解齐全（python coding-style）。

## 8. 圈闭合残差的资本病理学映射（走资 / 沉没 / 空转）

> 假说提出者：编排者（"圈闭合残差的走势结构对应卢麒元三种资本病理状态"）。
> 认识论等级：映射结构本身 = L0（概念对应）；每种病态的缠论签名可验证性 = L2（待验证假设，本节**不声称已验证**）。

### 8.0 理论基础：卢麒元资本三流三病态

卢麒元框架（auto-memory `reference_lu_qiyuan`）：资本是能量（kg·m），三个流动维度各对应一种病态：

| 维度 | 健康态 | 病态 | 本质 | 谱系锚点 |
|------|--------|------|------|---------|
| 流向 | 资本配置到生产 | **走资** | 大规模资本外流（跨经济体） | 254号（结算尺/跨国流动） |
| 流速 | 资本流转增殖 | **空转** | MCM′ 脱离 P，金融自我增殖（堰塞湖） | 330号（堰塞湖）+ 482号（ω=剥削率/H1环） |
| 流速 | 资本适度沉淀 | **沉没** | 资本锁死退出循环（"沉没才能流转"——金耗散角动量） | 482号（金=退出MCM′的沉没物） |

### 8.1 核心假说：三层圈闭合 ↔ 三病态同构

三层圈闭合恰好对应三个资本流通界面，每种病态在对应层的**残差走势结构**上留下不同的缠论签名：

| 病态 | 圈闭合层 | 残差对象 | 缠论签名（残差的走势形态） |
|------|---------|---------|--------------------------|
| **空转** | 横向（同层六边） | P/$、C/$、P/C 边的走势方向关系 | a0 恒等闭合，但走势状态层三边一致指向"P/$↑ + C/$↓ ⟹ P/C↑（剥削率飙升）" = **方向模式** |
| **沉没** | 纵向（顶点↔成分） | 成分的 (σ, level) | 高市值 + 低 level + σ=FLAT（资本沉淀但不涌现走势）= **走势缺失** |
| **走资** | 跨国（汇率边 Σ） | 跨国闭合残差序列 | 残差形成**单向趋势**（走势，非中枢震荡）= 资本持续外流 = **单向趋势** |

> **关键区分（残差走势结构，不只是残差大小）**：病态签名不在"残差绝对值大"，而在**残差序列本身的缠论结构**——方向模式 / 走势缺失 / 单向趋势。三种病态在残差的三种缠论形态上各异，这正是编排者假说"残差的走势结构对应病理状态"的形式化。

### 8.2 空转的横向签名（金融循环剥削率走势）

横向 a0 精确闭合恒等（§3.1）：`log(P/C) = log(P/M) + log(M/C)`——**永远闭合**。空转因此**不**表现为不闭合，而是表现为走势状态层的**特定方向模式**：

- σ(P/$) = UP（金融资产 P 升值，MCM′ 增殖）
- σ(C/$) = DOWN（大宗商品 C 被结构性压价，482号"空转抽走 P 流动性"）
- 由 a0 恒等的价格含义：P/$ 涨 + C/$ 跌 ⟹ **P/C = (P/$)/(C/$) 必然强涨** = 金融对实物的**剥削率走势**。

P/C 边 = 330号的 SPX/OIL = **堰塞湖的价格投影**。
- P/C 持续单向上涨趋势（非中枢震荡）= 堰塞湖扩大 = 空转加剧。
- **P/C 边顶背驰**（37课，趋势力度衰减）= 空转崩溃临界 = 金油比回归点（482号"方向确认，时机由缠论定"）。

> 这是横向圈闭合的"闭合**内容**"分析（三边方向模式），超出当前 `closure_consensus`（只算 dissent 计数）。属横向模块的**下游推论**（需扩展 closure_consensus 输出剥削率走势），不在本次实现范围。

### 8.3 沉没的纵向签名（资本死水 vs 健康沉没）

沉没在纵向圈闭合上是**走势缺失**——资本（市值权重）在该成分，但不涌现缠论走势结构：

```
sedimentation_scoreᵢ = market_weightᵢ × (1 − conf(levelᵢ))   当 σᵢ = FLAT，否则 0
```

- **病态沉没（死水）**：高 market_weight + 低 level + σ=FLAT。资本沉淀但从未涌现方向（如僵尸企业、套牢不动产）。`eff_weight ≪ market_weight`——资本在，信号无。
- **健康沉没（金，482号"沉没才能流转"）**：σ(Au/$) **有方向**（金价涨），但金**不进入 P**（跨边独立，金的走势与 P 的走势解耦）。这是主动退出 MCM′ 耗散角动量，不是死水。

> **与 LAGGARD 的区分**（§4.2）：LAGGARD = **高 level** 盘整（清晰中枢，可能突破→补涨候选，资本会流转）；沉没 = **低 level** FLAT（从未涌现结构→死水，资本不流转）。级别维度（conf）正是区分二者的判据——这是本设计实现的纵向沉没检测（`sedimentation_signal`）。

### 8.4 走资的跨国签名（外流趋势 vs 结算尺断裂）

走资在跨国圈闭合上是残差的**单向趋势**：

- 跨国闭合残差 = `σ(P_A/C_A)` vs `σ(P_B/C_B) × FX(B/A)` 的不匹配（cross_national_pipeline）。
- **走资**：残差形成持续单向趋势（资本从 A 持续外流到 B）= A 的资产用同一结算尺系统性走弱，且**无法**由 A 内部 K4 横向闭合解释（是外流，非内部配置）。
- **区别于结算尺断裂**（254号定理2）：结算尺断裂 = **多条 FX 边同步同向大级别事件**（尺子本身崩）；走资 = **单经济体跨国残差趋势**（尺子没崩，资本在跨尺子流动）。

> 走资检测在 `cross_national_pipeline` 层（已有 FX 边 Σ 框架）。属跨国模块的**下游推论**，需多经济体 K4 完整数据（当前 EU/JP/CN 多缺口），不在本次实现范围。

### 8.5 可验证性与数据（L2，分病态标注）

| 病态 | 检验对象 | 数据需求 | 当前可得性 | L2 可验证？ |
|------|---------|---------|-----------|-----------|
| 空转 | P/C 边剥削率走势 + 顶背驰 | US K4 全顶点（ES/DBC/VNQ/UUP + GC/CL） | ✅ 1min 齐备 | **是**（可立即做） |
| 沉没 | 成分 (σ,level) 死水检测 | 宏观指数 + 真实成分股 (σ,level) | ⚠ 成分股数据缺口 | 部分（金的沉没可用 GC 验，成分股死水需补数据） |

### 8.5b 实证结果（L2，`analysis/capital_pathology_validation.py`，2026-06-07）

**判据**（编排者）：残差/比值有缠论走势结构（趋势+中枢+多级别）→ 耗散结构假说成立；纯噪音 → 否定。诚实报告。

| 比值/残差 | 窗口 | bars | 缠论结构 | 裁决 |
|----------|------|------|---------|------|
| a0 三角残差 ρ（ES/CL/GC） | 2016-2026 | 61471 | **max\|ρ\|=8.9e-16（恒0）** | 数据质量门✓（非病态信号，符合 §3.1） |
| **ω=GC/CL**（空转/剥削率，482号） | 2016-2026 | 61566 | L3，27走势（26趋势/1盘整） | **有强结构✓** |

| ES/GC（涉Au） | 2016-2026 | 61485 | L2，28走势（27趋势） | 有结构✓ → **否定"涉Au无结构"子假说** |
| **ASHR/SPY**（走资，CN相对US） | 2013-2026 | 3163 | L2，2趋势，**末 trend-down** | **有结构✓+下降=走资签名初步成立** |

**诚实裁决**：

1. **a0 残差恒 0**（8.9e-16=浮点精度）→ 确认 a0 精确闭合是数据质量门（数学恒等），**不携带病态信息**。对它做缠论递归是类型错误（§3.1 验证成立）。
2. **耗散假说必要条件成立**：数据充分的比值序列（ω、P/C、ASHR/SPY）**全部**有缠论走势结构（趋势+中枢+多级别），**无一为噪音**。残差是有序耗散结构，不是随机噪声。
3. **走资有方向签名**：ASHR/SPY 全程下降趋势（CN 资本相对 US 持续走弱）= 走资的缠论签名**初步成立**（方向=down-trend，非中枢震荡）。
4. **空转签名成立**：ω 与 P/C 在 2020-2022 QE→加息全程有强趋势结构，符合 §8.2（堰塞湖扩大=P/C 上升趋势）。
5. **子假说被否定（负结果，诚实记录）**：编排者预测"涉Au三角形残差无结构（循环外锚不参与）"，但 ES/GC（涉Au）实测有强结构（L2，28走势）。原因：黄金 2020-2026 本身大涨，是**活跃折叠通道**（292号 C↔M），不是静止锚——恰是 482号"金=沉没物"但沉没物在升值（ω 分子上涨）。
6. **沉没未验证**：VNQ 仅 2.4 年（2023-12+），日线 608 根不足以涌现高级别走势 = **数据缺口，非假说否定**。需补 VNQ 历史数据（≥10年）方可验证沉没。
7. **充分条件的边界（关键诚实保留）**：所有充分采样的比值都有结构，故"有无结构"**不足以区分病态**——区分需**走势方向模式**（ω↑=空转 vs ASHR/SPY↓=走资 vs R 脱耦=沉没），不只是"有无结构"。耗散假说的**必要条件**（残差非噪音）成立，**充分条件**（结构唯一对应病态）需方向模式 + 补全数据（沉没）进一步验证。

> **认识论定位**：本验证确立残差的缠论结构是真实的（L2 必要条件成立），但病态的**唯一识别**仍是 L2 待完成（需方向模式分类 + 沉没数据）。§8.7 管辖边界（金融折叠投影）不变。

### 8.6 操作意义（选股 / 配置指导）

若三种病态的缠论残差结构可区分（L2 待验证），对操作的指导：

- **空转检测 → 配置时机**：P/C 边（剥削率）顶背驰 = 空转崩溃临界 = 金油比回归启动。配置动作：减金融化 P（高估值成长），加实物 C / 金（482号方向：做金油比下降）。与用户押注（金油比下降、油涨）方向一致。
- **沉没检测 → 选股过滤**：纵向 `sedimentation_signal` 高的成分 = 资本死水，**选股回避**（避免选到沉没股，即使市值大）；金的健康沉没 = 价值储藏配置（耗散角动量的对冲腿）。
- **走资检测 → 经济体配置**：跨国残差单向外流的经济体 = 资产系统性贬值，**整体回避**；流入经济体 = 超配。对应缠论"比价关系发现低估"的跨国版。

### 8.7 管辖边界（严格诚实标注：金融折叠投影，非病态本身）

依 330号 + 294号，三种病态的缠论签名都有**不可逾越的有效域边界**，标注以防声明膨胀（090号）：

1. **330号**：K4 测金融循环，**测不到产业循环**。空转的"堰塞湖深度"（金融利润率 vs 产业利润率之差）不在 K4 数据范围——P/C 边只是堰塞湖的**价格投影**，不是堰塞湖本身。缠论 P/C 顶背驰检测的是金融循环内的价格转折，**不能**断言"产业循环 C→M′ 断裂"（范畴错误）。
2. **294号**：缠论 D 算子跑在价格序列上，对**生产折叠是盲的**。三种病态签名都是**金融折叠投影**——读到的是病态在金融市场的影子，不是病态的实体机制。
3. **走资 vs 数据错位不可分**：单条跨国残差趋势无法区分"真走资"与"数据时区/采样错位"——需多边交叉确认（254号 OQ：单边事件无法区分分子/分母变化）。

> 故本节全部映射的有效域 = **金融折叠的价格投影层**。它们是病态的**可观测症状**（L2 可验证），不是病态的**原因诊断**（在 K4 之外，330号分治边界）。

## 9. 结果包六要素

**1. 结论**
新增纵向圈闭合（两层：a0 精确闭合数据质量门 + 走势状态软闭合），与已有横向/跨国圈闭合统一进四层递归分解树。圈闭合在 σ 符号层做级别加权兼容性检验（L0），产出度量（synth/compatible/concentration/residual）与成分贡献度排序（选股信号）。**新增假说**：三层圈闭合残差的缠论走势结构对应卢麒元三资本病态（空转=横向方向模式 / 沉没=纵向走势缺失 / 走资=跨国单向趋势），其中纵向沉没检测本次实现。

**2. 定义依据**
- 横向圈闭合同构：`k4_path_c.py:206-283`（`closure_consensus` 三估计多数表决）。纵向把"三估计等权"推广为"成分市值加权"。
- σ = 走势方向态（527号）：`config_space.py:36-49`。纵向检验在走势方向符号层，σ 加法不封闭故不闭合即信息。
- 选股分类：缠论第73课"行业→龙头→比价关系"（`docs/chanlun/text/blog/073-第73课.md:32-48`）。
- 折叠层级（外层约束内层）：292号区间套 → 上层闭合是下层分解的前提（§2.1）。

**3. 边界条件（结论翻转条件）**
- 若参照系 ref 从 C 改为 M：纵向闭合退化为绝对方向一致性，concentration 含义不变但比价语义丢失。
- 若 λ=W_VERTICAL_BSP 回测最优值 ≫1：选股性格从趋势跟随翻转为反转择时，role 分类的 DRIVER/CONTRARIAN 语义需重审。
- 若成分股数据补齐后 L2 回测显示 contribution 排序无 alpha（劣于等权/随机）：纵向选股信号被证伪，分解树退化为纯诊断工具（concentration 仍可作脆弱性预警），不作选股主轴。
- 若上层（Layer 2）横向圈闭合给出 σ_macro=FLAT：纵向分解无意义（§2.1），SelectionRanker 应返回空排序而非强行排序。

**4. 下游推论**
- 若纵向闭合成立：M2 选股从"K4 极性门控"（已被 `project_m2_k4_selection_gate` 证伪毁 alpha）升级为"分解树贡献度排序"，绕开被证伪的 ω regime 门控。
- concentration 成为新的市场结构指标，可接入 fold_lifecycle（292号松动期检测）。
- Layer 0 衔接 E 版本：被选中的 DRIVER 成分进入背驰定位器操盘，闭环到已验证的进出场引擎。
- **资本病理学**（§8）：三层圈闭合残差走势结构 → 走资/沉没/空转三病态签名。纵向沉没检测本次实现；横向空转（P/C 剥削率走势）、跨国走资（残差趋势）属各自模块下游推论。空转检测若成立 → 接 482号金油比回归操盘（与用户押注同向）。

## 10. 资本流转守恒律的完全分类（27 配置 → 病理态）

> M2 选股层的理论核心。代码实现：`src/newchan/topology/capital_flow_taxonomy.py`（测试 14 项全绿）。
> 认识论：配置枚举 + 判据 = **L0**（纯定义/代数）；病态↔配置映射的经验有效性 = **L2**（§10.7 验证）。

### 10.0 出发点：资本守恒律

四顶点 M/P/C/R 的资本变化 (ΔM,ΔP,ΔC,ΔR)，每个 ∈ {+1(流入), 0(中性), −1(流出)}，守恒：

```
ΔM + ΔP + ΔC + ΔR = 0
```

取 (ΔP,ΔC,ΔR) 为 3 自由度（3³ = 27 配置），**ΔM = −(ΔP+ΔC+ΔR) 由守恒律决定**——
M 是货币池/度量基准（026号双重身份：资本流入 P/C/R 必从 M 流出）。ΔM ∈ {−3,…,+3}。

### 10.1 与 config_space 的同构（流量 ↔ 走势）

流量配置 (ΔP,ΔC,ΔR) 与 `config_space.Configuration` 的走势方向 (σ_P,σ_C,σ_R) **结构同构**
（都是 {−1,0,+1}³），但语义不同：流量是守恒量，σ 是价格比值方向。桥接 `flow_to_walk`：
**流量驱动价格**（ΔX>0 → X 吸资 → X/M 涨 → σ_X=+1）——经验假设（一阶近似，存量重估是偏差），非恒等。

### 10.2 病态判据（优先级，避免标签重叠）

依病理学映射（§8）+ 卢麒元资本三病态：

1. **NEUTRAL(中性)**：(0,0,0)。
2. **FLIGHT(走资)**：ΔM ≥ +2（资本强烈涌向货币/外汇）。
3. **SEDIMENTATION(沉没)**：ΔR>0 ∧ ΔP≤0 ∧ ΔC≤0（资本撤入不动产）。
4. **SPECULATION(空转)**：ΔP>0 ∧ ΔP>ΔC（金融吸资超实体）。
5. **DAM_BREAK(溃坝)**：ΔP<0 ∧ ΔP<ΔC（金融流出/实体流入，空转反演）。
6. **HEALTHY(健康)**：ΔP=ΔC≠0（金融实体同步）。
7. **TRANSITIONAL(过渡)**：其余。

> **走资判据的语义边界（330号管辖）**：单国 K4 的 ΔM≥+2 是"资本涌向货币/避险"——**走资（跨国流出）是其子集**（资本涌向货币后出境），但也可能是国内 risk-off 持币。区分需跨国层（§8.4），单国 K4 测不到（330号：金融循环症状检测器）。

## 11. Γ→Δ 映射性质：确定 / 多对一 / 一对多（理论+实证）

> 编排者问：Γ（三主边方向）能否唯一确定交叉边 / 资本流量 Δ？
> 代码：`analysis/gamma_delta_mapping.py`（信息论实证）；熵函数边界已验证（确定→0、均匀→log₂n）。

### 11.1 理论推导：σ 不保比值同态 → 一对多

**setup**：Γ=(σ_P,σ_C,σ_R) 只给三条主边（对 M）方向。Δ=(ΔP,ΔC,ΔR) 中
ΔP ∝ Σ f(P-incident 边) = f(σ(P/M))+f(σ(P/C))+f(σ(P/R))，依赖**交叉边** σ(P/C),σ(P/R)。
故 Γ→Δ 的性质取决于：**Γ 能否确定交叉边？**

**命题1（σ 不保比值同态）**：不存在函数 g 使 σ(A/B)=g(σ(A),σ(B)) 对所有价格序列成立。

> **证明（反例）**：取 σ(A)=σ(B)=UP（A、B 均上涨）。
> - A=[1,2,4,8]（指数涨）、B=[1,1.5,2,2.5]（线性涨）→ A/B 上涨 → σ(A/B)=UP。
> - A=[1,1.2,1.4,1.6]、B=[1,2,4,8] → A/B=[1,0.6,0.35,0.2] 下跌 → σ(A/B)=DOWN。
> 同样 σ(A)=σ(B)=UP，σ(A/B) 却不同（UP vs DOWN，还可 FLAT）。故无 g。∎

这是 §3.2.1"σ 加法不封闭"的精确化：走势方向算子 σ=D（缠论递归）是**非线性泛函**，
依赖整条价格序列的形态（分型/笔/中枢/背驰），不只是端点方向。

**推论1（Γ→交叉边 一对多）**：交叉边 σ(P/C) 不被主边方向 (σ(P/M),σ(C/M)) 决定。

**双重有损**（为何强一对多）：
1. **机制1（算子非线性）**：命题1——即使知道交叉边的**完整价格序列**（= 主边价格的代数组合，a0 层确定），σ(P/C) 也不是主边**方向**的函数。
2. **机制2（Γ 标签有损）**：Γ∈{+,0,-}³ 是方向标签，丢失幅度/形态。同一 Γ 对应**无数**价格实现（P/M 上涨的方式千差万别），各自产生不同交叉边。

两机制叠加 → Γ→交叉边**强一对多**。

**推论2（Γ→Δ 一对多）**：Δ 依赖交叉边（ΔP 含 σ(P/C),σ(P/R)），交叉边不被 Γ 定 → **Γ→Δ 一对多**。

**ω 的分辨力（部分，非完全）**：走势层有 3 个自由交叉边（σ(P/C),σ(P/R),σ(C/R)）。
Γ 定 3 主边但不约束交叉边（命题1）。ω=σ(C/M 内部金油分化)=σ(GC/CL) 是**1 条交叉边**，
给 1 个自由度 → **部分分辨**。完全确定需 3 条交叉边读数（= 直接测六边）。

> **理论闭环——为 k4_path_c"六边各自跑"提供依据**：正因 Γ→交叉边一对多，**不能**从三主边推出三交叉边，**必须**让六边各自独立跑缠论递归（k4_path_c 的核心设计）。这不是冗余，是必然——交叉边信息无法从 Γ 恢复。

### 11.3 诚实裁决

1. **Γ→交叉边 = 一对多**（H=1.584 bits>0，理论命题1实证确认）。仅 44% 的 Γ 唯一确定交叉边。
2. **ω 部分分辨**（增益 0.337 bits，消除 ~29% 剩余熵），但**不完全**（剩 0.811 bits）——因 ω 仅是 1 条交叉边，无法定全部 3 条。
3. **Γ→Δ = 一对多**（推论2；Δ 直接实证缺口——无 ETF fund flows/COT positioning 数据，故经"Γ→交叉边一对多 + Δ依赖交叉边"的**充分条件**推断，非直接验证）。
4. **理论闭环成立**：实证为 k4_path_c"六边各自跑递归"提供信息论依据——1.584 bits 的交叉边信息无法从 Γ 恢复，必须直接测量。

### 11.4 操作含义

- **Γ 不足以选股/配置**：单看三主边方向（risk-on/off 极性 S）会丢失 1.584 bits 的资产间相对结构信息。M2 选股必须读交叉边（k4_path_c 联合读数），不能只用 config_space 的 Γ 极性。
- **ω 是有用但不充分的补充**：金油比方向给 0.337 bits 分辨力（值得纳入），但不能替代直接测六边。
- **资本流量 Δ 推断需谨慎**：从价格走势（Γ/六边）推 Δ 是一对多 + 经验假设（§10.1 流量驱动价格），叠加两层不确定性。要确定 Δ 需真实流量数据（fund flows/COT），当前缺口。

### 11.5 结果包六要素

**1. 结论**：Γ→交叉边、Γ→Δ 均为**一对多**（理论：σ 不保比值同态；实证：H(交叉边|Γ)=1.584 bits）。ω 部分分辨（0.337 bits）不完全。为 k4_path_c"六边各自跑"提供理论依据。

**2. 定义依据**：σ=走势方向态（527号，§3.2.1 加法不封闭）；命题1 反例证明；信息论条件熵（边界已验证）。

**3. 边界条件**：
- 若改用价格**幅度**（非方向标签 σ）：机制2 消除，但机制1（σ 非线性）仍致一对多。
- 若 σ 改为连续走势强度（非 {+,0,-}）：熵度量变，但同态仍不保。
- 若补全三交叉边读数：(Γ,3交叉边) 完全确定六边（平凡——等于直接测六边）。
- 若 Δ 流量数据补齐：可直接验证 Γ→Δ（当前为充分条件推断）。

**4. 下游推论**：
- k4_path_c 六边各自跑递归是**必然**（非冗余）——理论闭环。
- config_space 的 Γ 极性 S 是**有损投影**（丢 1.584 bits），不可单独用于选股。
- ω 纳入选股特征（0.337 bits 增量），但非充分统计量。

### 11.6 最细分辨率压力测试（1min a0，L2 否定性结果）

> 编排者假设：30m/日线版剩余熵未到 0 是 a0 太粗致配置 σ 退化；换 **1min a0** 让 σ 不退化 → 剩余熵可补到 0。
> 脚本 `analysis/gamma_delta_1m_resolution.py`（**全 Rust 引擎** `newchan_rust.RecursiveOrchestrator`，10 边 fork 并行）；结果 `analysis/gamma_delta_1m_results.md`。
> 实例：期货折叠通道 {ES,GC,CL,$=DX}（UTC 1min 精确对齐，避 UUP 时区/RTH），窗口 2018-12-26+，交集 1.88M bar/边，日采样 2297 天。**跨 a0 数值不可比**（实例/X 维度/窗口/numeraire 全异，formalization-validity-domain 规则）。
>
> **⚠️ σ 级别修正（spec-execution gap）**：§11 全篇把 σ 标为「涌现最高级别走势」是**声明膨胀**——`current_moves()[-1]` 实际是 **L1 走势**（level=1，五层管线输出），最高递归级别在 `current_recursive()`（独立）。**代码行为正确**（固定 L1 是 regime 观测量的正确选择——最高级别 move 跨年致单窗口 σ 冻结，是陷阱，见 `project_highest_level_sigma_frozen`），错的是标签。§11 所有「最高级别走势」读作「L1 走势」；结果有效（L1 在各 a0 一致）。

**裁决：假设前半确认，后半否证。**

1. **σ 非退化 = 确认**：1min 顶层走势 σ 在 2297 天翻转 **638–984 次**（30m 仅 75 次，日线 1–2 次），+/0/− 近 1:1:1。配置 σ 完全不退化。
2. **剩余熵补到 0 = 否证（强否定性结果）**：贪心从 H(X|Γ)=2.763 仅经 ω(+0.067)、6E(+0.023) 两步即停在 **2.074 bits**；其余 6 候选（DX/BRN/ZN/slope/VIX/gold/oil）真实增益 < 0.005 阈值。**变量用尽仍到不了 0**（样本/cell=7.93 健康 → 非过拟合切碎；gold/oil=Γ 主边故真实增益恒 0，已验证冗余）。
3. **机制——非退化与可定性对立**：a0 越细 → σ 翻转越频 → 交叉边 X 自身熵越大 → Γ+外部变量解释的份额反而越小。Γ→交叉边一对多（294号 D 算子非线性、527号 σ 不保比值同态）随分辨率细化**单调放大不可约熵**（不是"分辨率不变"——初版措辞经 Gemini 裂隙2 修正）。
4. **控制实验（隔离 a0，回应 Gemini 裂隙2）**：`analysis/gamma_delta_1m_resolution_a030m_control.md`——同期货实例 {ES,GC,CL,DX}、同窗口、同 numeraire、同 X=2，**仅 a0 30m→1min**：残余熵 **0.418→2.074 bits（+1.656）**，贪心可用变量 **5→2** 塌缩。a0 效应真实且方向确认（初版"1min 2.074 > 30m 正典 0.812"确含实例混淆，但隔离后结论方向不变）。
5. **方法论待补（Gemini 裂隙4）**：过拟合诊断"样本/cell=7.93"用名义 N；σ 由 1.88M bar 涌现日末采样高度自相关，Neff 可能 ~60–230 → 真实样本/cell 0.25–1.0。主结论"补到0=否证"不依赖此诊断（来自贪心提前停，自相关只会加剧"到不了0"），但精确残余值须先做 Neff 校正（block-bootstrap）。
6. **强化 §11.4 结论**：交叉边不可约性在最细 a0 上**更强**而非更弱 → k4_path_c「六边各自跑」的信息论依据在分辨率极限处加固，非削弱。M2 选股读交叉边不可用 Γ 极性+regime 代理替代。
