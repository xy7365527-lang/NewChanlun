## 0. 核心命题

**完全分类 → 完全正则化。系统中零人为选择。**

正则化（regularization）在此的精确含义：管线中每一层的每一个参数，都不是操盘者拍脑袋设定的自由变量，而是**另一层输出的派生量**。当所有自由变量都被上游输出消解后，系统达到「完全正则化」——不存在任何需要人为价值判断的旋钮。

形式化表述：设管线层级为 $L_1, \dots, L_5$，每层的参数集合为 $\Theta_i$。完全正则化要求

$$\Theta_i = f_i\big(\text{output}(L_{j}), \; j \neq i\big), \quad \forall i$$

即 $\Theta_i$ 完全由其他层的输出决定，$\Theta_i$ 中不含自由维度。**人为选择 = 自由维度 > 0**。本管线的设计目标是把全系统的自由维度降到 0。

> **认识论标注（L0）**：「零人为选择」是一个关于架构的*结构性*命题，不依赖真实数据。它声明的是「参数无自由维度」这一代数性质，不声明「该管线在真实市场上盈利」。后者是 L2/L3 命题，需独立的真实数据假设检验，本文不作此声明（见 §6 形式化有效域边界）。

### 与「完全分类」的关系

正则化的前提是分类完全。若资产空间、走势形态、买卖点类型中任一存在「未分类剩余」，则该剩余处必然出现人为选择（操盘者必须临时决定如何处置未分类对象）。因此：

- 第一层 K4 必须**穷举**资产空间（四象限完全覆盖经济体资本去向）；
- 第二层缠论必须**完全分类**走势（递归分解无剩余，走势必完美——见 §6 假说 P1）；
- 买卖点必须**完全分类**为三类（缠论原文定理：任何级别的操作机会必属第一/二/三类买卖点之一）。

分类的完全性是正则化的*必要条件*。任何一处分类不完全，正则化即在该处失效，自由维度 > 0。

## 1. 五层架构总览

```
┌─────────────────────────────────────────────────────────────┐
│ L1  K4 扫描器     穷举资产空间 → {标的, 方向, 操作级别}        │
│         │  级别由区间套自然确定（非参数）                      │
│         ▼                                                     │
│ L2  缠论引擎      streaming 笔→段→中枢→走势→买卖点            │
│         │  级别从递归层涌现（非切图周期）                      │
│         ▼  → {买卖点, 级别, confirmed}                        │
│ L3  PH 确认器     τ = 操作级别笔均振幅（派生）                 │
│         │  settle = 否定性必要条件                            │
│         ▼  → {settle_confirmed, persistence, alive_count}    │
│ L4  仓位 FSM      267/338 cost_reduction_fsm                  │
│         │  次级别信号来自区间套下一层（非独立参数）            │
│         ▼  → {操作指令, 数量}                                 │
│ L5  期权映射器    strike ← 中枢边界；expiry ← persistence映射  │
│            → {合约, strike, expiry}                          │
└─────────────────────────────────────────────────────────────┘
```

每层的输出是下层的输入，且每层的参数由**非相邻层**的输出反向约束（见 §5 参数来源表）。这种交叉约束是「完全正则化」区别于简单流水线的关键：不是单向数据流，而是参数的全局闭合。

## 2. 第一层：K4 扫描器

### 2.1 职责

以 K4 四象限（E/C/R/\$）穷举资产空间，通过区间套逐层收窄到具体标的，输出 `{标的, 方向, 操作级别}`。

### 2.2 K4 四象限

四个顶点对应经济体中资本的四种去向（谱系 254）：

| 顶点 | 符号 | 含义 |
|------|------|------|
| Equity | E | 权益类资产（股票/股权） |
| Commodity | C | 商品（原油、铜、农产品等） |
| Rate / Real | R | 利率/实物锚（含黄金 Au 作为终极锚） |
| Cash / Dollar | \$ | 现金/美元 |

完全图 $K_4$ 的六条边对应六组比价关系。资本守恒：任意时刻资本必在四象限之一或在边上流动，**无第五去向**——这是穷举性的本体论保证（254 号资本流本体）。

### 2.3 比价关系决定象限间相对强弱

象限间的相对强弱由比价（ratio）读出，比价本身是 K4 的边：

- ω 纸实比（纸面资本 / 实物资本）——空转检测维度（见用户记忆「资本旋转动力学」）；
- 金油比（Au/Oil）——R↔C 边；
- 铜金比（Cu/Au）——C↔R 边内的工业 vs 避险分量。

比价不是外生指标，而是 K4 边的参数化。比价的方向（升/降）即资本在两象限间的流向。

### 2.4 区间套逐层收窄

区间套（nested interval）逐层收窄，定位次序固定，无人为选择：

```
象限（K4 顶点） → 板块 ETF → 个股
   强弱由比价定        强弱由板块内缠论定
```

每一层收窄都由上一层的比价/结构强弱排序唯一确定，操盘者不在任一步「挑选」标的——挑选由排序算法替代。

### 2.5 级别由区间套自然确定

**操作级别不是参数，是区间套深度的函数。** 区间套收窄到第 $k$ 层，则操作级别即第 $k$ 层对应的缠论级别。这是 L1 与 L2 之间的第一个正则化约束：L2 的「操作级别」入参由 L1 的区间套深度派生，而非独立设定。

### 2.6 输出

```python
{
    "symbol": str,         # 收窄到的具体标的
    "direction": str,      # "long" / "short"，由比价方向定
    "op_level": int,       # 操作级别，由区间套深度定
}
```

### 2.7 当前实现状态（如实标注）

**部分实现**。`src/newchan/k4_config.py` 与 `src/newchan/topology/k4_scanner.py` 已实现：
- K4 完全图拓扑（四顶点 + 六条边 `ALL_EDGES`）；
- `AssetVertex`、`Configuration`、`WalkDirection` 数据结构；
- `RecursiveOrchestratorSnapshot → K4 Configuration` 映射；
- 比价关系作为六条边的参数接口。

**未实现**：多经济体「结算尺空间 Σ 展开」的递归编码、区间套到个股的自动收窄链。即任务大纲所述「K4 待开发」**不准确**——配置/扫描骨架已存在，缺的是上层展开逻辑（见 §7 阻塞项修正）。

### 3.1 职责

### 3.3 confirmed / settled 解耦（已结算）

买卖点的两个状态各司其职（maimai #2 v0.7 翻转，TBD-2/3 已结算）：

- **confirmed** = 买卖点自身确认条件（**可操作信号**）：
  - 第一类：背驰确认（三维度比较成立）；
  - 第二类：次级别回调/反弹不创新极值；
  - 第三类：中枢突破后回试不破边界。
- **settled** = 走势完成验证（**事后因果确定**）：覆盖该买卖点的 `Move.settled`。

旧设计将 confirmed 绑定 `Move.settled`，导致走势末端所有买卖点恒 False（自相矛盾）。解耦后 confirmed 提供实时操作信号，settled 提供事后级别涌现驱动。

### 3.4 级别定义与涌现（525号修正后）

**级别不是「切到 30 分钟图」这种周期参数，而是从数据涌现的递归层级。** `RecursiveStack` 从 level=1 的 `settled` Move 自动递归构造 level≥2 的中枢/走势，`level_id` 自动递增（level=k 中枢的 settled 状态驱动 level=k+1 构造），默认展开至 `max_levels=6`。

525号修正后，级别定义的三个要素：

1. **PH persistence 作为连续级别度量**：persistence 值提供连续的级别量度（不依赖递归链是否完整到底），τ 从操作级别笔振幅派生（见 §4.2）。
2. **笔中枢路径（`zhongshu_from_strokes`）作为终端递归单元**（525号新增）：把笔当作第17课定义的"最低不可分解级别的单位"，三笔重叠构成笔中枢，笔级别走势可作为更高级别中枢组件。
3. **中枢组件成立条件 = 局部完成性**（525号原文考据）：次级别图上完成即可，**不下钻验证内部递归链完整性**（第18课:24 "不用再看下面级别"）。

这是 L2 内部的正则化：级别不是输入的自由变量，是 settled 因果链的派生输出。

### 3.5 笔中枢路径与107号 C1 的关系（525号澄清）

107号 C1（zhongshu.md #3）：「中枢组件必须是线段（次级别走势类型），笔不可作为中枢组件」。

**C1 的有效域 = 段中枢（线段级中枢）**：在段中枢级别，组件必须是次级别走势类型，单个笔不是走势类型（走势类型须含≥1中枢）。

**笔中枢是不同级别的中枢**：把笔当作"终端递归单位"（第17课:40 的角色），笔不是"次级别走势类型组件"。因此笔中枢**不违反** C1（笔仍不可作段中枢组件）。

递归关系：
```
笔 → (三笔重叠) → 笔中枢 → (笔中枢组合) → 笔级别走势(盘整/趋势)
                                              ↓ 作为组件（局部完成即可）
                                         更高级别中枢
```

### 3.6 真假中枢的严格限定（525号修正123号）

> **⚠️ 525号修正**：123号原将"递归链完整可追溯至 Move[0]"作为真中枢的**有效性判据**。
> 原文考据发现缠师第18课:24 + 第17课答疑:1098 **明确否定**"递归链必须完整到底"。

修正后的严格限定：

| 判据用法 | 判定 | 理由 |
|---------|------|------|
| 作为**口径A（自下而上递归）的构造不变量** | ✅ 合法 | 口径A内 Move[k] 本就从 Move[0] 构造，"可追溯"是构造副产品 |
| 作为**中枢有效性的概念判据** | ⚠️ 越界 | 原文不支持；不得用"链未完整"判废本级别已完成中枢 |

**关键范畴分离**：
- 中枢只有**"完成 vs 未完成"**（原文范畴），无**"真 vs 假"**的有效性等级
- **"未完成" ≠ "假"**——实时数据中"最高级别总是不完整"是时间窗口问题，不是结构缺陷
- 真/假二分**保留**，但严格限定为**"组件完成状态（settled）+ 口径A内部一致性"**

## 4. 第三层：PH 确认器

### 4.1 职责

以持续同调（Persistent Homology，PH）在每个级别提供**动力学度量**，作为缠论形态学之外的独立监视层，输出 `{settle_confirmed, persistence, alive_count}`。

> **存在论位置（378 号）**：PH 不替代缠论，是「缠论旁边的独立监视层」——缠论提供形态学递归，PH 在每一层提供动力学度量。378 号将 PH 定位为「穿越记录增强工具」，**非预测核心**。

### 4.2 τ = 操作级别笔均振幅（派生，非参数）

PH 的尺度阈值 $\tau$ 不是自由参数，而是 L1+L2 输出的派生量：

$$\tau = \text{mean}\big(|p_1 - p_0|\big), \quad \text{笔} \in \text{操作级别}$$

即「操作级别」（由 L1 区间套深度确定）下所有笔的平均振幅。这是 L3 的核心正则化约束：PH 的尺度选择由操作级别的实际笔振幅决定，操盘者不设定阈值。

**PH persistence 作为连续级别度量**（525号推论）：persistence 值天然提供一个**不依赖递归链完整性**的连续级别量度。525号否定了"递归链完整到底"作为级别有效性判据后，persistence 的连续性与"局部完成性"互补——persistence 衡量结构的幅度规模（∈ ker(D)），局部完成性判定组件是否成立。τ 从缠论笔振幅派生，将 PH 的尺度锚定在缠论的自然单元上。

> **认识论标注（L1→待 L2）**：「τ = 笔均振幅是 PH 的正确尺度」是一个 L1 经验断言（合成数据可验证管线，不验证假设）。其有效性需真实数据 L2 检验。「persistence 作为级别度量」同为 L1 断言。

### 4.3 PH settle 替代传统右侧确认（525号推论）

传统缠论的"右侧确认"在实时中常面临两难：等确认则信号滞后，不等则信号不可靠。PH settle 提供了一个数学上精确的替代：

**candidate（L2 结构信号）+ PH settle（L3 动力学确认）= 进场条件**

- L2 产出 candidate 买卖点（结构条件满足，背驰几何成立）；
- L3 的 PH settle 提供独立的因果确认（merge tree 合并事件因果确定）；
- 两者联合构成进场信号，settle 是否定性必要条件（只能否定假信号，不能肯定真信号）。

> **认识论标注（L1）**：「candidate + PH settle = 有效进场条件」是 L1 架构断言。有效性需 L2 真实数据检验。

### 4.4 settle = 否定性必要条件

PH 的 settle（结算）是**否定性必要条件**，由因果 merge tree 实现（`src/newchan/a_online_persistence.py`）：

- `OnlineMergeTree.update(price)` 维护 1D 价格序列的在线/因果 sublevel-set H0 merge tree；
- 合并事件在鞍点 peak $P$ 处发生，其配对结果（谁死、persistence 多少）**因果确定当且仅当** $P$ 右侧已出现 $\geq P$ 的价格点 $Q$；
- 与缠论同构：分型的因果确认 = persistence 合并事件的因果 settle。

**否定性的精确含义**（有效域约束）：persistence $\in \ker(D)$——只能算「创新低/幅度」这一**必要条件**，不能算「力度衰竭」（MACD 动量，§5 不可约维度）。因此 PH 的 settle 只能**否定假买卖点**（结构被合并即否定），**不能肯定真买卖点**。这是 L3 在管线中的角色：过滤器（filter），非生成器。

### 4.5 输出

```python
{
    "settle_confirmed": bool,    # MergeBar.settled，因果确定
    "persistence": float,        # death - birth，幅度度量
    "alive_count": int,          # 当前未 settle 的 alive 分量数
}
```

附加：`trend_health(window)`（主导分量 persistence 增长率 > 0 ⟺ 趋势未衰竭）、`stop_signal(entry)`（否定性止损：入场分量进 settled 或反向分量 persistence 超入场阈值）、`level_switch_event`。

### 4.6 当前实现状态

**算法稳定，认识论边界清晰**。`a_online_persistence.py` 的单调栈 O(n) 流式算法 + 因果 settle 判据为 **L0**（merge tree 数学属性）。「persistence ≈ 力度」「dominant = 主导级别」为 **L1** 断言，真实数据 L2/L3 验证前不升级。

338 号对 267 号的四项修正：动态重置初始资金、显式化摩擦成本阈值、驳回时间维度退出条件、补充强趋势浅回调规则。

### 5.3 次级别信号来自区间套下一层（非独立参数）

FSM 的 `SUB_LEVEL_SELL` / `SUB_LEVEL_BUY`（短差触发）信号不是独立设定的参数，而是 **L1 区间套下一层的缠论买卖点**。即：主级别持仓的短差由次级别信号驱动，次级别由区间套的下一层（第 $k+1$ 层）确定。

> **与操盘方法同构（275 号「附庸的附庸不是我的附庸」）**：主级别持仓不管次次级别短差。每层只看自己的直接下级——主级别管次级别信号，次级别管次次级别。这是局部依赖原则在仓位管理上的体现，也是 L4 正则化约束：短差级别由区间套深度派生，非自由设定。

```python
    "quantity": float,  # 由满仓满融约束 + 当前状态派生
}
```

## 6. 第五层：期权映射器

### 6.1 职责

将 L2 缠论结构 + L3 persistence 映射为期权合约，输出 `{合约, strike, expiry}`。三个 strike **全部落在缠论关键位置上，杠杆是派生结果**（options-selector skill）。

### 6.2 strike 从缠论结构（中枢边界）

strike 不反推杠杆、不用 delta/IV 优化，全部来自缠论结构位（做多三腿示例）：

| 腿 | Strike 来源 | 缠论含义 |
|----|------------|---------|
| 卖 put | 当前级别止损位 | 买点失败位 |
| 买低 put | 下一个更大级别支撑 | 大级别崩溃保护 |
| 买 ITM call | 当前级别中枢上沿 / 结构立足点 | 利润区起点 |

中枢边界 `[ZD, ZG]`（TBD-5 已结算：中枢判定范围 = `[ZD,ZG]` 非 `[DD,GG]`）直接提供 strike 锚点。**杠杆 = 名义敞口 / put 距离**，由结构紧凑度自动确定，是结果而非目标。

### 6.3 到期日 = persistence → 时间映射（数据学习）

到期日由 L3 的 persistence 映射到时间维度：

$$\text{expiry} = T_{\text{target}}(\text{persistence}) + \text{buffer}$$

其中 $T_{\text{target}}$ 是 persistence（幅度度量）到「走势完成所需时间」的映射函数。当前 skill 采用 `T_target上限 + 45 天 buffer`（默认），禁止贴事件日期。

> **认识论标注（L1→L2 待验证）**：「persistence → 时间」映射是一个需从真实数据**学习**的关系。persistence 是幅度度量（$\in \ker D$），时间是独立维度，二者的映射函数 $T_{\text{target}}$ 不是 L0 恒等式，必须经真实数据回归/学习获得。当前的「+45 天 buffer」是 L1 启发式占位，**非已验证映射**。这是 L5 当前最大的自由维度残留——见 §7 阻塞项。

### 6.4 输出

```python
{
    "contract": str,       # 期权合约标识
    "strike": float,       # 从中枢边界派生
    "expiry": str,         # 从 persistence 映射 + buffer
}
```

### 6.5 当前实现状态

**规则完整，自动化代码缺失**。`options-selector` skill（`.claude/skills/options-selector/SKILL.md`）定义了完整的 strike 派生规则与四个必答问题，但尚无自动化代码模块将 L2/L3 输出直接转为合约。`persistence → 时间`映射的数据学习未实现。

## 结果包（六要素）

**1. 结论**
本文给出五层完全正则化操盘管线的设计蓝图：K4 扫描器 → 缠论引擎 → PH 确认器 → 仓位 FSM → 期权映射器。核心命题「完全分类 → 完全正则化，零人为选择」被精确表述为「全管线参数自由维度 = 0」。当前代数自由维度残留唯一集中在 L5 的 `persistence → 时间`映射。

**2. 定义依据**
- 「完全正则化」依据 §0 形式定义 $\Theta_i = f_i(\text{output}(L_{j\neq i}))$；
- K4 穷举性依据 254 号资本流本体（资本无第五去向）；
- 级别涌现依据 L2 `RecursiveStack` 的 settled Move 递归（`recursive.py`）；
- settle 否定性依据 `a_online_persistence.py` 因果 merge tree 判据（persistence $\in \ker D$）；
- strike 派生依据 options-selector skill 的结构位映射表；
- FSM 依据 267/338 号操作方法论。

**3. 边界条件（结论翻转条件）**
- 若 P1 被否证（走势非完美分类）→ §0「完全分类」前提失效 → 正则化在 L2 断裂，本蓝图核心命题翻转；
- 若 L3 真实数据检验 τ ≠ 笔均振幅的正确尺度 → L3 自由维度 > 0；
- 若 `persistence → 时间`映射无法从数据稳定学习 → L5 永久残留自由维度，「零人为选择」在 L5 不可达；
- 若 K4 区间套展开发现存在「未分类资产剩余」→ L1 穷举性失效。

**4. 下游推论**
- 若本蓝图成立，则操盘的全部人为判断被上游输出消解——操盘者角色从「决策者」变为「管线监视者」；
