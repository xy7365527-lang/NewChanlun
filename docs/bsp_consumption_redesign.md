## 1. 最简架构：N 个独立自相似级别引擎

### 1.1 信号层（不变，已验证）
`iterate` 产出 `levels[k].bsps`（全 6 类，11281 个，携 kind/level/price/bar，types.rs:223）。走势结构（中枢/走势/笔）是**信号层的事**——它产出 BSP，操作层不碰走势结构。

### 1.2 操作层（最简：每级别一个 T 实例直接消费本级别 BSP）
每个级别 k 一个 T 实例 `LevelEngine_k`（同一 T 算子的实例，仅级别不同 = 自相似），**独立持仓 + 独立响应**，只消费 `levels[k].bsps`：

**BSP→操作是分层短差路由**（编排者裁决 C1，2026-06-20：**无 Z₂ 翻转**）：**所有级别的所有卖点都是短差**（reduce + 次级别开空），区别只在幅度和级别。**不存在整仓翻转**——每级别操作永远是 reduce→次级别做空→次级别买点回补→本层恢复（齿轮咬合）。

| BSP（任意 level k） | 操作 | 机制 |
|---------|------|------|
| **type1_sell @ k** | **sink**：reduce 本层 k 的 1/3 + 次级别（k−1）开空同股数 | 齿轮：本级 reduce 驱动下级 short |
| **type1_buy @ k** | **recover**：次级别平空 + 本层 k 回补同股数（归还上级仓位） | 齿轮：下级 recover 归还上级 |
| **type2/type3 @ k** | 加仓/持有确认（中枢上移/破位，029:58）| h⁺ |
| **最高级别超大卖点（月线+）** | **全量清仓**（一次性，第31课总结算）| 唯一全平触发 |

**删除 flip/reverse/Z₂**：核心永远不整仓翻空（持多骑牛）；做空全在次级别短差（有界 1/3）。这回到早期结晶（[[emergent-direction]] 四步循环 / [[recursive-nested-fugue]] 平多≠开空）。

**零硬编码 · 完全自相似（编排者裁决 2026-06-20，纠正"最高级别特殊分支"）**：**每个 T 实例做完全一样的事**，route_bsp **不区分** BSP 级别==核心 vs <核心，**不硬编码全量清仓**：
- `type1_sell @ 我的级别` → reduce 我的 units **归还父级** + 次级别开空。
- `type1_buy @ 我的级别` → 次级别平空 + **从父级 recover** 回我的 units。
- **最高级别的"父级" = root 现金池（TRoot.free）**——这不是特殊分支，是递归 base case（最高级别 reduce → 现金归 free）。
- **全量清仓是涌现的，非 hardcode**：最高级别走势完成时，各层 reduce 逐层向上归还（最终归 free）= 全量退出的自然结果。route_bsp 里**没有** `if 最高级别 then 全量清仓`。

### 1.3 齿轮耦合：核心持仓（H⁰）+ 各级别减仓-回补短差（H¹），无翻转
（[[project_t_multiscale_independent_filters]] / [[project_spiral_engine_v2_bitexact]] D∞ 群 + 编排者 C1 裁决）
- **H⁰ 核心仓**：核心持多骑趋势，**永不整仓翻空**（C1：无 Z₂ 翻转、无 τ）。只在超大级别卖点全量清仓。
- **H¹ 机动短差**：每级别的 sink/recover 减仓-回补循环 = 齿轮。**BSP 是驱动齿轮的力**（type1_sell→reduce，type1_buy→recover）。
- **相邻级别咬合 = sink/recover 配对**（同股数 = 能量守恒）：
  - 本级 type1_sell → reduce 本层 1/3 + 次级别开空 m（父转 → 驱动子转），rec_engine.rs:444。
  - 次级 type1_buy → 子级平空 m + 本层 recover 1/3（子转回 → 归还父转），rec_engine.rs:495。
  - 同股数进出（M=N）保证能量守恒（TW 中性）。
- **τ⊥减仓（范畴正交，session5）**：C1 删除 τ（翻转 ε 维）；只保留减仓（M 维 units 变化）。所有卖点都是减仓短差，不是翻转。
- **触发器换 BSP**：齿轮转动由 BSP（type1）驱动，不由走势 completed（本次重构的唯一改动——齿轮结构保留，删 flip/promote/Z₂）。

### 1.4 滤波器：每级别一个带通滤波器，提取自己频率的 |涨跌幅|
- **每级别 = 带通滤波器**：高级别提取低频大趋势的 |涨跌幅|，低级别提取高频回调的 |涨跌幅|。
- **总 P&L = Σ 各级别滤波器输出**。**落码须 per-level P&L 追踪**——验证每个级别独立贡献正收益。
- **多空双开**：不同级别可同时多/空（L4 持多骑大趋势 ∧ L1 持空吃回调）= 多声部赋格。
- **绩效=Σ\|涨跌幅\|** = N 级别带通滤波器并联吃掉所有尺度的绝对涨跌。

### 1.5 多重赋格的验收标准
**8 标的回测中，每个级别应独立贡献正的 |涨跌幅| 提取**（per-level P&L > 0）。若某级别持续负贡献 → 该级别的 BSP 消费有问题（诊断信号，不是 regime 借口）。这是多重赋格"做对"的判据。

## 2. 删除走势跟随残留（保留齿轮结构）

消费 BSP 后，**走势跟随的间接推导机制**删除，但**齿轮结构（sink/recover + Z₂ 翻转）保留**：

| 机制 | 处置 | 理由 |
|------|------|------|
| **extract_chain / chain[0] 投影** | **删** | 操作层直接读 `levels[k].bsps` 分层路由，不需要"链" |
| **promote**（回调短头升格核心，**自下而上**级联） | **删** | promote 的自下而上方向**已否证**（§7 区间套是自上而下）；回补 = 本级别 type1 candidate 经区间套自上而下被次级别 confirm 后翻 Z₂ |
| **chain[0].direction 触发 flip/spawn** | **删** | 翻转由本级别 type1 BSP 触发，不由裸走势方向 |
| **emergent 门控 / clear_root** | **删** | −1069% 做空陷阱根源；走势方向锚/退出观望都是 workaround |
| **spawn**（核心随 r\* 升级） | **保留/简化** | 核心级别=最高活跃级别，随塔生长自然上移（齿轮加顶层），但触发判据换 BSP |
| **sink / recover**（齿轮咬合短差） | **保留** | = §1.3 齿轮间耦合，触发器从走势 completed 换为次级别 type1 BSP |
| **Z₂ 翻转**（本级别整仓翻转，旧 flip） | **保留** | = §1.3 振荡器翻转，触发器换本级别 type1 BSP |

**结论**：删的是**走势跟随的间接触发**（chain/promote/emergent/clear_root），保留的是**齿轮+滤波器结构**（Z₂ 翻转 + sink/recover 咬合 + per-level 滤波）。唯一改动 = **触发器从走势结构换成 BSP**。

## 3. 回补修 ep13：区间套自上而下定位（非自下而上，约束 #7 纠正）

> **纠正**：先前写"低级别 type1_buy 直接触发回补（bottom-up）"= **已否证的旧方向**（project_located_direction_discovery）。正确是**区间套自上而下**。

ep13 真凶 = 回补判据用**走势 completed**（rec_driver.rs:131），死等最高走势反转（1.2M bar）。修复 = 触发器换 **type1 BSP** + **区间套自上而下定位**：
- **高级别 type1（candidate）** = 操作意图（核心级别背驰 = 回补/翻转 candidate）——比走势 completed 早（背驰点先于走势完全闭合）。
- candidate **级联武装下面所有层**；**次级别 confirm**（次级别 type1 located）= 区间套收窄到精确点（第27课同一转折点逐级收缩）。
- confirm 后**操作执行在高级别**（高级别 type1 独占利润；99% 的 segment 级别交易在摩擦地板下=噪声，约束 #7）。

ep13 修复：核心做空（高级别空头）→ 高级别 type1_buy candidate 出现（核心级别背驰底，**早于 1.2M bar 的走势 completed**）→ 武装下层 → 次级别 type1_buy confirm → 回补执行。**既不死等走势 completed（修 ep13），也不被低级别噪声直接触发（避 segment 噪声）**——区间套自上而下是两者之间的严格中道。

## 4. 三模式 = BSP 过滤器，在最简引擎上测量（编排者补充 2）

模式是 `combine_modes`（divergence.rs:202）对 type1 的过滤：Structural（结构 5 条件，纯公理）/ AND（结构∧MACD 双确认）/ OR（任一）。最简引擎正确消费 BSP 后，三模式效果可真实测量：**哪种模式的 BSP 集合消费后产生正确操作循环**（8 标的回测）。模式只影响赚多赚少（哪些 BSP 算数），不影响能否正确操作（编排者裁决 3）。

## 6. 一个不回避的边界：底分型 ≠ 一类买点（诚实上浮）

每段下跌必有几何底分型，但**一类买点是背驰点**（知识库:363），背驰需中枢（≥3 单元，center.rs:48 / divergence.rs:158）。本引擎 **a₀=confirmed&&Settled 线段**（backtest.rs:160）非笔/bar——段太短（<3 单元）无中枢 → 该级别真无 type1（ep6/9/10/11 的 0 买点）。「回调再短也有底」成立，「底就有一类买点」不严格——递归有 a₀ base case 硬底（第64课「线段只存在最低级别之下」）。**要消除此边界须把 a₀ 下沉到笔/分型层**（更深递归，独立改动，escalate）。但 029:396 保证：**只要段发育出中枢，本级别必有一类买点被本级别 LevelEngine 消费**。

### 9.1 嵌套递归赋格：平多≠开空，净额翻转是空头不赚根因（约束 #1）
- **同一笔物理交易不同级别不同会计身份**：父级卖出 = 该级别降成本；子级别开空 = 独立逐仓头寸。资金守恒：父卖出释放的现金 = 子开仓的资本（同股数，无需额外配额）。
- **平多 ≠ 开空**（编排者 C1 终裁：本级别卖点=短差不是翻转）：本级别 type1_sell → **sink（reduce 本层 1/3 + 次级别开空）**，核心不翻空（持多骑牛）；开空永远是次级别独立逐仓头寸。**不存在"净额翻转/整仓翻空"**。全量平仓只在最高级别超大卖点（月线+，第31课总结算）。
- **空头不赚的根因 = 净额翻转而非逐仓独立**（[[project_t_short_leg_regime_function]] 跨 8 标的 L3）。本重构每级别独立逐仓头寸（齿轮 §1.3），从结构消除净额翻转。

### 9.2 递归正则化：每级别操作必须由次级别锚定（约束 #2，核心）
- **递归正则化 = 区间套反向应用 = 缠论操盘的严格形式**。每级别的操作**必须被次级别结构锚定**，否则是盲操作。
- **每层的域来自上一层，每层的操作点来自下一层**：级别 k 的操作域（在哪个走势内操作）由 k+1 层给定；操作点（精确触发）由 k−1 层 confirm 给定。
- **多重赋格 = 反向区间套在级别塔上的逐层应用**：每层 candidate（来自本层 type1）+ 次级别 confirm（区间套自上而下）→ 操作。无次级别 confirm 的本级别 type1 = candidate 未武装，不操作（避免盲操作/segment 噪声）。
- **type3 买点是回补位不是止损信号**（§1.2）：三买/三卖 = hold-confirm（中枢上移/破位确认持有），不是减仓止损。

### 9.3 H⁰/H¹ 物理重诠释 + τ⊥减仓正交（约束 #3）
- **H⁰ = 核心仓**（2/3 恒持，σ-不变，本级别 Z₂ 状态）。**H¹ = 机动仓**（1/3 短差，次级别 sink/recover 减仓-回补循环）。几何塔：本级别核心 2/3、次级别短差 1/3、次次级别 1/9…。
- **τ（翻转）⊥ 减仓（范畴正交）**：τ 是 ε 维（手性）的**全翻转**（本级别 type1 → Z₂ 多↔空）；减仓是 M 维（units）的**量变化**（次级别 sink 减 1/3）。两者不同范畴，不可混淆——本级别翻转 ≠ 次级别减仓。**四步循环（sink→hold→recover→hold）= H¹ 的 1-cycle**。cd_Q=1 → 两层闭合（核心+机动）。
