# 缠论全互斥策略:已查清奇偶交替是持有窗方向恒等式——那怎么提取真正可交易的 alpha?

## 背景:我们已经查清的(三路独立验证)

BTC 1min 全历史 461万 bar、12626 个买卖点信号,6 级别 × 2 方向的逐信号 μ̂ 呈现 12/12 奇偶交替(买 L0+L1−L2+L3−L4+L5−,卖反相)。经过零模型对照 + 恒等式分解 + 三路 beta/alpha 分析,已确定性地查清:

**1. 奇偶交替是持有窗方向恒等式,不是独立可交易信号。**
`sign(μ̂(level,δ)) = sign(δ × 持有窗净涨跌)` 到成本精度。μ̂ 不是独立的"级别方向 alpha",它是 δ 乘上"买确认→卖确认这段市场净涨跌"。级别间的符号交替来自各级别持有窗净涨跌方向的经验分布(涨段/跌段相反,方向依赖市场,非结构必然)。

**2. 机制 A(几何必然)被零模型否证。** 纯多级别 ZigZag(无缠论谓词,只是几何摆动)跑同一条 BTC,6 配置全部**不出**奇偶交替。所以交替是缠论买卖点定义特有的,但——

**3. 它是缠论"确认/出场口径"特有,不等于"结构 alpha"。** ZigZag 缺力度轴(无中枢/背驰),不出交替;缠论出交替。但交替的载体是"确认滞后 + 持有到下一反向信号的出场口径"让持有窗净涨跌方向随级别交替。这是口径特有,不是"结构预测了未来"。

**4. beta/alpha 分解(方向签名 PnL 下)**:(μ+ + μ−)/2 ≈ 方向中性结构 edge;(μ+ − μ−)/2 ≈ 市场漂移 beta。全历史 BTC:买腿 Σ=+38.4万(顺涨 beta),卖腿 Σ=−6.2万(逆涨),净 +32.1万主要是 BTC 上涨的 beta,不是 alpha。

**5. 短差为什么没双向赚**:双向赚需往返振幅 > 入场滞后 + 出场滞后 + 成本,买卖两边同时成立 = 震荡/中枢往返 regime。BTC 强上涨 → 只顺大级别一边满足,逆大级别短差亏。镜像对称破缺 + 确认滞后,两条件都不满足 PDF"两边都赚"的前提。

## 核心问题:那怎么提取真正可交易的 alpha?

我们现在知道了"奇偶交替不是 alpha、短差在强趋势市不双向赚、净值主要是 beta"。**但这是否定性结论——它告诉我们什么不是 alpha,没告诉我们什么是。** 我们想问:

### 问题 1:在这个系统里,真正的可交易 alpha 应该长什么样?
既然 (μ+ + μ−)/2 是方向中性结构 edge(买卖都因结构正确而受益的部分),那么:
- 一个**市场中性组合**(同时持有多个级别的买卖点,让方向 beta 相互抵消,只留结构 edge)能否提取正的 (μ+ + μ−)/2?
- 还是说 (μ+ + μ−)/2 在扣掉确认滞后+成本后其实 ≤0(结构 edge 不存在,一切都是 beta)?这需要什么检验来定案?

### 问题 2:确认滞后是 alpha 杀手还是 alpha 来源?
我们的分析显示确认滞后(走势终完美才确认,价格已走过一波)是奇偶交替的载体,也是短差双向赚失败的原因。那么:
- 减小确认滞后(更早入场,牺牲确认度)能否让 μ 转正?还是更早入场=更多假信号,净效应更差?
- 缠论"走势终完美"的确认要求,本质上是不是就注定了"入场时 alpha 已经走完"?如果是,缠论买卖点的可交易 alpha 是否根本不在"方向"而在别处(如仓位管理/风险控制/止损位)?

### 问题 3:σ_higher(上级方向)过滤能否救活它?
我们还没做上级方向条件化。理论上 μ(ℓ,δ,σ_higher) 拆开后:
- 顺上级方向(δ=σ_higher)的买卖点 vs 逆上级方向(δ=−σ_higher)——前者应该是趋势跟随,后者是抄底摸顶。
- 是否**只有顺上级方向的买卖点有正 μ**?如果是,那"多级别协同"的正确形式就是"用上级方向过滤同级别信号",而不是奇偶相位。
- 这个 σ_higher 过滤和奇偶交替是什么关系?会不会 σ_higher 一加,奇偶交替就消失了(说明交替本来就是 σ_higher 的代理)?

### 问题 4:如果 BTC 全历史 alpha 都是 beta,那验证 alpha 必须换非单边市场?
BTC 2017-2026 是强单边上涨。在这种市场里,做多顺势=beta,任何"净值为正"都可能是 beta 而非 alpha。
- 是否必须在**震荡市**(如某些外汇对/区间品种)或**做市场中性**才能真正检验缠论结构 alpha?
- 还是有办法在单边市场里用统计手段(如我们要做的方向标签置换检验)剥离出 beta 之上的结构 alpha?
