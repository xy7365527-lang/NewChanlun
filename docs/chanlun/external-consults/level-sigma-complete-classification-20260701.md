## 核心命题(ChatGPT 严格结论)

> 真正的 alpha 候选不是"奇偶交替",而是 (ℓ, δ, σ_higher) 的交互项。
> 级别 ℓ 改变了"顺/逆上级方向"的操作语义。低级别逆上级=短差,高级别逆上级=接飞刀。

## 关键定义:相对上级方向 q

**q_i := δ_i · σ_i^H**(δ=交易方向,σ^H=入场时上级方向态)
- q=+1:顺上级方向
- q=−1:逆上级方向

条件收益 μ_{ℓ,q} = E[X_i | ℓ_i=ℓ, q_i=q],其中 X_i = δ_i(P_τout − P_τin) − C_i。

## "只做顺上级"被严格否证

ChatGPT 假设 μ_{ℓ,+} > μ_{ℓ,−} ∀ℓ。实测 μ̂_{0,−}>μ̂_{0,+}、μ̂_{1,−}≫μ̂_{1,+}。
**严格证明**:若存在级别(L1)使 μ_{1,−}>0 且 μ_{1,+}<0,则该级别"只做顺上级"严格劣于"只做逆上级"。
⟹ **顺/逆上级方向不能脱离级别单独决策**。正确状态 z=(ℓ,q),不是 z=q。

## L2→L3 翻转边界的机制:级别函数 θ(ℓ)

**θ(ℓ) = 信号平均持有期 / 父级走势平均生命期**
- θ(ℓ)≪1 → 逆上级只是父级走势内部局部短差(有振幅就赚)
- θ(ℓ)≈1 或 >1 → 逆上级=对抗父级甚至更高级主趋势(接飞刀)
- 临界级别 ℓ*:ℓ<ℓ* 逆上级=短差,ℓ≥ℓ* 逆上级=趋势对抗。数据里 **ℓ*≈3**

**严格声明**:这不是纯理论必然,是"缠论级别定义+当前出场口径+BTC 1m尺度"的经验临界点。
**L2→L3 翻转是经验估计的级别相位边界,不是无需检验的理论常数**(需跨标的/跨窗口验证)。

## 为什么 L1 贡献几乎全部超beta

总贡献 **G_ℓ = n_ℓ · μ_ℓ^edge**(信号数 × 每笔平均超beta edge)。
- n_ℓ 随级别几何衰减(L0=11149→L1=1059→L2=324→L3=69,ρ≈0.1)
- μ_ℓ^edge:L0太噪(edge低),L1过滤噪声但样本够(峰值),L2+样本降+确认滞后增(edge降)
- G_ℓ=n_ℓe_ℓ,n_ℓ几何降、e_ℓ先升后降 ⟹ G_ℓ 必在中间某级最大 = **L1 甜蜜点**
- 符合缠论"次级别回调进场"直觉。**但不是跨市场定理,是 BTC 当前出场口径经验事实**

## σ_higher 正确用法:级别分段,非全局过滤

不能全局"q=+1才做"或"q=−1才做"。正确规则:**χ(ℓ,q) = 1[LCB(μ_{ℓ,q}) > θ]**
经验规则候选:
- L0/L1:允许/偏好逆上级 q=−1(短差)
- L2:顺逆都可,需更多检验(边界层)
- L3+:禁止逆上级,甚至可能全禁做,除非 OOS 证明正收益
最终不应凭点估计硬编码,应写成 χ_t(ℓ,q)=1[LCB_t(μ_{ℓ,q})>θ]。
**全互斥策略正确做法:每个状态都定义,但只交易正条件收益状态。**

## 奇偶交替 = level×σ_higher 边际投影

μ_{ℓ,δ} = Σ_{s∈{+1,−1,0}} μ_{ℓ,δ,s} · P(σ^H=s | ℓ,δ)。
奇偶交替不是充分状态下的原始规律,而是**未条件化 σ^H 时的边际现象**。
ℓ 本身不是最终 alpha 状态,(ℓ,δ,σ^H) 才是。可继续细化 z=(ℓ,δ,σ^H,h,exit rule,β,c,...)。

## Y_i 单标的退化(确认我方判断"完全正确")

单标的同持有窗:B_i=P_τ−P_t=H_i ⟹ Y_i=δ(H−B)−C=δ(0)−C=**−C**(数学恒等退化)。
不是"没alpha"证据,是残差定义在单标的单因子上不可用。**改用分层置换是正确的单标的剥beta方法。**

## 三判据(区分"级别真结构"vs"级别尺度beta投影")

1. **条件均值** μ̂_{ℓ,q} = (1/n_{ℓ,q}) Σ_{i:ℓ_i=ℓ,q_i=q} X_i(raw)
2. **分层置换 p-value**:分层 S_i=(ℓ_i, σ_i^H, h_i bucket, time block) 内置换 δ_i。
   **per-(ℓ,q) 统计量** T^obs_{ℓ,q}=Σ_{i:ℓ_i=ℓ,q_i=q} X_i(不是全局和!修复 codex 全局T被L0主导92.6%的批评)。
   若 p_{ℓ,q}<0.05 且 T^obs_{ℓ,q}>0 → 该 level×σ_higher 相对方向状态有 beta 之上的结构信息。
3. **OOS 稳定性**:walk-forward 窗口,train 估 μ̂^train_{ℓ,q},OOS 检验 LCB_OOS(μ_{ℓ,q})>0。

**可交易结构 alpha 充要条件**:μ̂>0 ∧ p_perm<0.05 ∧ LCB_OOS>0(三者同时满足)。

## 最终可执行判据(第十节)

下一步不检验 μ(ℓ,δ),而检验 **μ(ℓ,q), q=δσ^H**。只接受 LCB_OOS(μ_{ℓ,q})>θ 且 p_perm<0.05。
策略 π(ℓ,q)=trade if (ℓ,q)∈G, no trade otherwise,G={(ℓ,q): LCB(μ_{ℓ,q})>θ}。
**候选 G(当前样本,非最终定理):(L0,q=−1),(L1,q=−1),(L2,q=+1/−1)**。

## 最终结论

σ_higher 的发现没否定级别理论,反而证明"级别"必须和上级方向**联立**使用。
真正的缠论多级别 alpha 不应写成"偶级别买、奇级别卖"这么粗,而应写成
**"按 (ℓ,δ,σ_higher) 的全互斥状态选择正条件收益动作"**。
