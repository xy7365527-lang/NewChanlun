# σ_higher(上级方向)与级别的交互:为什么同一个"逆上级方向"信号在低级别赚钱、高级别巨亏?这跟缠论"级别"概念是什么关系?

## 背景:我们已经查清的(承接奇偶交替证伪 → σ_higher 检验)

BTC 1min 全历史 461万 bar、12626 个买卖点信号、6 级别 × 2 方向。之前已确定性查清:
1. 奇偶交替(买 L0+L1−L2+L3−...)是**持有窗方向恒等式**,不是独立 alpha(随机置换 perm_p=0.69)。
2. Y_i beta 残差检验在 BTC **单标的退化**:corr(成交价差, 同期市场收益)=1.0,扣净 beta 后残差恒为 −成本(零 alpha)。所以改用**分层置换**(固定 level+σ_higher+持有期分桶,层内只 shuffle 买卖方向 δ,让 beta 被分层吸收)。

## 本轮做的:σ_higher(上级方向)条件化(ChatGPT 你上次建议的"第一优先级"实验)

我们给每个买卖点标注了 **σ_higher = 入场时上级级别的方向态**(+1 上级涨 / −1 上级跌 / 0 无上级),然后分组检验。

## 结果:你上次的假设被否证,但揭示了一个跟"级别"深刻相关的结构

### 你上次的假设:"只有顺上级方向(δ=σ_higher)的买卖点有正 alpha"→ **否证**

| 组 | n | 平均每笔 PnL | 分层置换 perm_p |
|----|---|-----|--------|
| 顺上级(δ=σ_higher) | 8411 | +18.1 | 0.002(显著) |
| 逆上级(δ=−σ_higher) | 4212 | **+40.0** | 0.004(显著) |

顺上级、逆上级**两组都显著**,而且**逆上级反而更赚**(40.0 > 18.1)。所以"用上级方向过滤"不是 alpha 来源。

### 但真正的发现:σ_higher 的收益符号**随级别翻转**

| 级别 | 顺上级 平均 PnL | 逆上级 平均 PnL |
|------|-----------|-----------|
| L0 | +20.3 | +39.8 |
| L1 | −5.0 | **+66.8** |
| L2 | +25.8 | +20.1 |
| L3 | −55.5 | **−212.1** |
| L4 | −21.1 | −127.1 |

**符号翻转边界在 L2→L3**:
- **低级别(L0/L1)**:逆上级方向**更赚**(L1 逆上级 +66.8,顺上级反而 −5.0)。
- **高级别(L3+)**:逆上级方向**巨亏**(L3 逆上级 −212.1 = 最大失血,顺上级 −55.5 也亏但轻)。

全样本"逆上级更赚"(判定1)是 L0/L1 大样本(样本几何衰减 ~×0.1/级:L0=11149→L3=69)淹没 L3+ 小样本的结果。

### 超 beta 收益(策略 − 全做多)几乎全来自 L1

| 级别 | 策略 Σpnl | 全做多 Σpnl | 差(超beta) |
|------|------|--------|-----|
| L0 | 297520 | 260943 | +36578 |
| **L1** | 25689 | −81919 | **+107608** |
| L2 | 7644 | 4039 | +3605 |
| L3 | −8215 | −11752 | +3536 |

L1 层策略的买卖方向选择远优于无脑全做多(全做多在 L1 亏 −81919,策略赚 +25689)。超 beta 收益 88% 来自 L1。

## 核心问题:这跟缠论"级别"是什么关系?

我们的直觉解读(想请你确认或纠正):

### 问题 1:符号翻转边界 L2→L3 有缠论意义吗?
"逆上级方向"的买卖点,在**低级别是短差/回调兑现**(大趋势中的次级别反弹,快进快出赚钱),在**高级别是接飞刀**(逆真正的大趋势,巨亏)。这是不是就是缠论说的——**同样的形态(逆父级别方向)在不同级别有相反的操作意义**?低级别逆势=可做的短差,高级别逆势=送死?PDF §9"L0 买点逆大级别接飞刀"说的是不是这个,只不过我们发现它其实是**级别依赖**的(低级别逆势反而对)?

### 问题 2:为什么偏偏是 L1 贡献了几乎全部超 beta 收益?
L1(次级别)是超 beta alpha 的主要来源,L0(最细)和 L2+ 都很弱。这是缠论级别里的什么位置?是不是 L1 正好是"次级别回调进场"的天然尺度——比 L0 噪声少,比 L2+ 样本足、又还没大到变成趋势对抗?还是这只是 BTC 特有的、我们出场口径(持有到下一反向信号)在 L1 尺度的配对放大假象?

### 问题 3:σ_higher 应该怎么用?
既然 σ_higher 的效应符号随级别翻转,那"上级方向过滤"就不能全局用(不能一刀切"只做顺上级")。正确形式是不是**级别分段**:L0/L1 允许甚至偏好逆上级(短差),L3+ 严禁逆上级(接飞刀)?这在缠论里对应什么操作原则?

### 问题 4:奇偶交替 = level × σ_higher 交互项,这说明什么?
我们发现:固定 σ_higher 后,原来干净的 12/12 奇偶交替(偶级别买正/奇级别买负)乱了——同一个(级别,方向)在 σ_higher=+1 和 −1 两种情况下符号不一致。所以奇偶交替不是"级别独立的结构",而是"级别 × 上级方向的交互投影"。这个交互项在缠论里是不是就是**多级别联立**(缠论强调的"级别间的走势关系")的一种统计显影?

## 想要的
我们想搞清楚:**"级别"在这里到底扮演什么角色**——是 alpha 的真正载体(L1 相位),还是只是 beta 在不同时间尺度上的投影?符号翻转边界 L2→L3 是缠论级别理论的必然,还是 BTC 数据特有?下一步该怎么设计实验把"级别真结构"和"级别尺度上的 beta 投影"分开?(注:所有结果都是 L2 单标的 BTC,强单边上涨市,还没跨标的验证。)
