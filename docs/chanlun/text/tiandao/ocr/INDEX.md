## 页码换算复核（本票第三轮独立复核）

**`正文页 = PDF 页 − 18`，自 PDF p19 起生效；PDF p1–18 为前置页（封面/版权/序/目录），书上不印页码，不适用该公式。**

两条独立证据：

1. **页脚数字直读**（PyMuPDF 裁页面底部 6% → 500dpi → `tesseract --psm 11` 数字白名单）：PDF p19–495 共 477 页，**416 页页脚读出的数字恰等于「PDF 页 − 18」**；39 页未读出数字（章首扉页无页码、整页图、页脚被脚注挤走）；22 页读出数字但与预期不等——**逐条核对后全部是 OCR 漏位**（如 p151 读成 `133`（应 153）、p132 读成 `14`（应 114）、p170 读成 `132`（应 152）），**没有任何一页给出可支持「偏移量≠18」的读数**。
