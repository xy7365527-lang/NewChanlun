## 第 1 部分：问题的精确重述——两个正交的覆盖

### 1.1 覆盖空间回顾

覆盖空间 `p: E → B`：连续满射，每个 `b ∈ B` 有开邻域 `U` 使 `p⁻¹(U)` 是 `E` 中
互不相交开集（**层 / sheets**）的并，每层同胚映到 `U`（**均匀覆盖 evenly covered**）。
纤维 `p⁻¹(b)` 离散。覆盖的对称性由**层变换群（deck transformation group）**刻画——
保 `p` 的 `E` 自同构。

### 1.2 缠论给出两个正交的覆盖结构

概念运动链产生**两个不同的覆盖**，对应群论文档（`concept_movement_group.md`）的两条
真关系式：

| 覆盖 | 环 | 层 = sheets | 层变换群 | 群论文档关系式 |
|------|----|-----------|----------|--------------|
| **级别覆盖** | 13（g₁₃） | 各级别（recL1, L2, L3, …） | ⟨σ⟩ ≅ ℤ（级别移位） | R₃（HNN stable letter σ） |
| **方向覆盖** | 21（g₂₁） | {多, 空} | ⟨τ⟩ ≅ ℤ/2（方向反演） | R₂（对合 g₂₁²=e） |

- **级别覆盖**是**无限层覆盖**（ℤ 层，群论文档构造 (a)：`π₁(Γ)=ℤ`）。尺度不变性
  `σ W_form σ⁻¹ = W_form`（R₃）= 各级别纤维同构。这是"塔变高但结构不变"
  （`project_pcf_1s_a0_source_collapse`）的覆盖论形式。本文档**不**处理级别覆盖。
- **方向覆盖**是**双层覆盖（double cover）**：恰两层 {多, 空}，层变换 τ = 方向反演，
  `τ² = id`（翻两次方向回原方向）。**任务问的不对称在这个覆盖里。**

> **关键区分**：任务陈述说"覆盖空间的每一层（每个级别）执行同一套逻辑"——这是**级别
> 覆盖**的语言。但任务问的"多空交替处不是局部同胚"是**方向覆盖**的问题。两个覆盖正交：
> 多空不对称**不在级别维度**（级别覆盖在 R₃ 下对称），**在方向维度**（方向覆盖在
> 载体层破缺）。本文档第一个澄清就是把问题从级别覆盖移到方向覆盖。

### 1.3 方向双层覆盖的两种全局形态

ℤ/2 双层覆盖在拓扑上只有两种（由 `H¹(B; ℤ/2)` 分类）：

| 形态 | 模型 | 绕基空间一圈（多→空→多） | 单值性（monodromy） |
|------|------|------------------------|--------------------|
| **平凡** | 圆柱 `B × {多,空}` | 回到原层（多回多） | trivial |
| **非平凡** | 莫比乌斯带 | 翻到对侧再回（多↔空扭转） | non-trivial |

**本文档的核心命题**：方向覆盖在**走势层是平凡的（圆柱，对称）**，在**会计载体层是
非平凡的（莫比乌斯带，扭转）**。不对称 = 载体层覆盖的非平凡单值性。

## 第 2 部分：多空不对称的范畴定位——走势结构 vs 会计载体

> 任务问题 1：不对称从哪来？是走势结构的不对称，还是会计载体的不对称？是必然还是经验？

### 2.1 走势层：方向覆盖是正则的，τ²=id 对称（必然）

**命题 P1（走势层多空对称）**：在纯走势层，方向覆盖 `p_trend: E_trend → B` 是**正则
（Galois）双层覆盖**，层变换 τ（方向反演）是同胚，τ²=id。多空完全对称。

**证明**：由 T₂₄（多空对称），A₀ 是关于"走势"的命题，不区分方向——方向是势 Φ 的分量
（D0.1），A₀ 对上势与下势对称。由 R3 对上涨走势与下跌走势分别实例化，二者都终完美
（T₂）。故"上涨走势完美 → 翻空"与"下跌走势完美 → 翻多"是 τ 互映的两个同构纤维。
τ 把多 sheet 的走势结构（分型/笔/线段/中枢/背驰/买卖点，T₆–T₁₃）逐一映到空 sheet
的镜像结构（顶分型↔底分型、顶背驰↔底背驰、卖点↔买点），是同胚。τ²=id（翻两次回原向）。
故走势层方向覆盖正则、对称。□

**这层对称是必然的（L0）**——它直接来自 A₀ 的方向无偏性（T₂₄ 证明）。绩效在这层
= Σ|涨跌幅|，多空各吃一半，无偏。

### 2.2 载体层：价格状态空间 ℝ₊ 的半直线拓扑不对称（必然）

**命题 P2（载体层拓扑不对称）**：把走势纤维替换为"走势 × 载体状态"后，空 sheet 的纤维
携带**无界亏损**结构，多 sheet 携带**有界亏损**结构。τ 不再是载体层的同胚。

**证明**：会计载体的状态由价格 `c` 参数化。资产价格空间是**半直线**
`c ∈ ℝ₊ = [0, ∞)`（资产价格非负——有限责任 + 资产非负，§2.4 论根源）。

- 多头持 `q > 0` 单位，价值 `V_long(c) = q·c`，PnL `= q·(c − c₀)`。下行 `c → 0⁺`：
  `PnL → −q·c₀`（**亏损有界于本金**）。`c = 0` 是 ℝ₊ 的**闭端**（吸收壁：归零/退市，
  亏损封顶）。
- 空头持 `q` 单位（逐仓 capital `= q·c₀`），PnL `= q·(c₀ − c)`。上行 `c → ∞`：
  `PnL → −∞`（**亏损无界**）。`∞` 是 ℝ₊ 的**开端**（无壁：价格可无限上涨，亏损
  无封顶 → capital 耗尽 → 强平）。

ℝ₊ 作为半直线，**两端拓扑不同**：`0` 是闭端（属于空间，可达，是吸收边界），
`∞` 是开端（不属于空间，不可达，无边界）。τ（方向反演 `c ↦ 2c₀ − c` 或等价的多空
PnL 互换）把"朝闭端的有界亏损"映到"朝开端的无界亏损"——**它把闭端映到开端，而闭端
与开端拓扑不同胚**（一个紧致边界点，一个非紧致开方向）。故 τ 在载体层**不是同胚**。□

> **这是不对称的真正来源**：不是走势结构（走势层 τ 是同胚，P1），是**价格状态空间
> ℝ₊ 半直线的两端拓扑不对称**。多头的风险朝闭端（有界），空头的风险朝开端（无界）。

### 2.3 裁定：不对称是会计载体的必然性质，不是走势的，不是纯经验的

**回答任务问题 1**：

| 候选 | 裁定 | 依据 |
|------|------|------|
| 走势结构的不对称 | **否** | P1：走势层 τ 是同胚，多空对称（T₂₄ 必然） |
| 会计载体的不对称 | **是** | P2：ℝ₊ 半直线两端拓扑不对称（必然，非经验） |
| 纯经验的不对称 | **否** | P2 是 ℝ₊ 拓扑的 L0 推论，不依赖任何回测读数 |

**不对称是必然的，但它的必然性在载体层不在走势层**。走势"终完美对涨跌都成立"
（T₂₄，环 21）确实对称——这个对称是真的，但它只在**走势范畴**为真。一旦走势被**资本化
为载体头寸**，载体的价格空间 ℝ₊ 的拓扑不对称就介入。两个范畴：

> 走势层（A₀）：ℤ/2 对称，圆柱覆盖。
> 载体层（capital）：ℤ/2 破缺，莫比乌斯覆盖。
> **不对称 = 从走势范畴下降到载体范畴时，τ 从同胚退化为非同胚。**

这与群论文档 R₂ 的记录吻合并给出**更深的根因**：R₂ 说"g₂₁²=e 在概念层成立（L0），
在实装层有效域收缩（根 voice 只开多）"。群论文档把收缩归为"实装选择"。本文档证明：
**收缩不是实装选择，是载体拓扑必然**——任何线性载体（股票/期货）的 ℝ₊ 价格空间都
强制这个收缩。实装的"根恒多"是对这个必然不对称的**正确响应**，不是偷懒。

### 2.4 根源链：有限责任 → 半直线 → 时间之箭

为什么价格空间是 `[0, ∞)` 而非 `(−∞, ∞)`？追到底：

```
有限责任（资产最多归零，不倒欠）
  ⟹ 资产价格 c ≥ 0
  ⟹ 价格空间 = 半直线 [0, ∞)
  ⟹ 两端拓扑不对称（0 闭 / ∞ 开）
  ⟹ 多头亏损有界 / 空头亏损无界
  ⟹ 方向覆盖在载体层非平凡（莫比乌斯）
```

**期货负价反例的处理**（2020 WTI −37 美元）：期货可负价**恰恰因为期货不是"资产"
而是"合约义务"**——移除了"资产非负"的保护。期货空头的无界风险因此**更纯粹**
（连 `c=0` 的部分缓冲都没有）。这不否证 P2，是 P2 的极端化：合约载体把半直线
`[0,∞)` 退化为全直线 `(−∞,∞)`，空头风险无界性不变，多头也失去下界保护。
→ 载体的"责任结构"决定价格空间边界，价格空间边界决定多空不对称。

## 第 3 部分：覆盖空间框架下如何处理

> 任务问题 2：覆盖映射在空头层是否 still well-defined？

### 3.1 均匀覆盖条件在载体层破缺

**命题 P3（均匀覆盖破缺）**：`p_trend`（走势覆盖）是合法双层覆盖（均匀覆盖成立）；
`p_trade = p_trend × (载体状态)`（操作覆盖）在多空交替点**均匀覆盖条件破缺**。

**证明**：均匀覆盖要求每个 `b ∈ B` 的邻域 `U` 上，`p⁻¹(U)` 的各层**同胚**于 `U`。
走势层：多 sheet 与空 sheet 都同胚于走势主题 `U`（P1），均匀覆盖成立。
载体层：多 sheet 纤维 = 有界亏损区间 `[−q·c₀, ∞)`（拓扑：半无限闭区间）；空 sheet
纤维 = 无界亏损区间 `(−∞, q·c₀]`（拓扑：半无限闭区间，但朝相反方向无界）。表面看两者
都是半无限区间——但 τ 要求的是**保留"朝吸收壁方向"**的同胚。多 sheet 的吸收壁在
`c=0`（有限距离，可达）；空 sheet 的吸收壁在 `c=∞`（无限距离，不可达）。τ 把可达
吸收壁映到不可达方向——**不保吸收壁结构**。故 `p_trade` 的两层在"风险边界"这个
结构上不同胚，均匀覆盖破缺。□

**回答任务问题 2 的第一半**：覆盖映射在空头层**走势维度 still well-defined**
（P1，τ 保走势结构），**载体维度 not well-defined as a covering**（P3，τ 不保
吸收壁/风险边界结构）。well-defined 与否取决于你问的是哪一层的覆盖。

### 3.2 非平凡单值性 = earning 自由度的丢失

**命题 P4（单值性障碍 = 空头 earning 不可构造）**：绕方向覆盖走一圈
（多 → 空 → 回多）的单值性在走势层平凡、在载体层非平凡；非平凡单值性的**精确内容**
就是 T₃₆ 的"空头 earning L0 构造性不可表示"。

**证明**：

*走势层单值性*：多 sheet → τ → 空 sheet → τ → 多 sheet，`τ²=id`，回到原走势状态，
单值性平凡（P1）。

*载体层单值性*：考虑 earning 自由度。earning（T₃₆）= cost_basis 穿 0 后把纯利润
**资本化为更多同向头寸**。
- 多 sheet 的 earning：cost ↓ 穿 0 后，`parent.units += dq`（增正股数，
  `nested_fugue_accounting.md` §7）。增的正股朝**闭端**方向（多持有，价格 ≥ 0，
  可无限持有，等待无成本）——**earning 算子在多 sheet 闭合**（增仓后仍是合法多头态）。
- 空 sheet 的 earning：开空均价上穿后继续盈利需"挣股数"= 持**负数量股**——朝
  **开端**方向增仓（更多空头 = 更大无界风险 + 更多保证金）。但"负数量股"在线性载体的
  状态空间 `{units ∈ ℝ₊}` 中**无对应点**（units 不能为负数量的同向头寸而不改变载体
  语义）。**earning 算子在空 sheet 不闭合**（增仓出空间）。

故绕覆盖一圈后，多 sheet 携带 earning 自由度回到原点，空 sheet 在 earning 维度上
"丢失"了一个自由度——单值性把 earning 自由度**抹掉**（non-trivial）。这个被抹掉的
自由度 = 莫比乌斯带绕一圈后的方向扭转 = T₃₆ 空头 earning 的 L0 不可表示性。□

**回答任务问题 2 的第二半**：覆盖映射在空头层**不保 earning 结构**（虽然保走势结构
P1、保守恒/极性结构 §5.4）。这就是莫比乌斯带的"扭转"在缠论会计里的物化——
**空头 sheet 是缺一个 earning 自由度的退化纤维**。

### 3.3 莫比乌斯 vs 圆柱：保结构层的精确清单

把各结构层按"τ 是否同胚（覆盖是否平凡）"分类：

| 结构层 | τ 保结构？ | 覆盖形态 | 定理依据 |
|--------|-----------|---------|---------|
| 走势形态学（分型→中枢→买卖点） | ✅ 同胚 | 圆柱（对称） | P1 / T₆–T₁₃ / T₂₄ |
| 操作量（量 ∝ 势 θ） | ✅ 同胚 | 圆柱（对称） | §5.1 / T₁₈ |
| 守恒（Σunits = N_base） | ✅ 同胚 | 圆柱（对称） | §5.4 / T₃₄ |
| 极性翻转（basis ← basis − d·π/u） | ✅ 同胚 | 圆柱（对称） | §5.4 / `bidirectional_accounting` |
| 降成本（同股数进出短差） | ✅ 同胚 | 圆柱（对称） | §5.3 / T₂₀ |
| **earning 资本化（增仓）** | ❌ 非同胚 | **莫比乌斯（扭转）** | P4 / T₃₆ §11.3 |
| **风险边界（吸收壁）** | ❌ 非同胚 | **莫比乌斯（扭转）** | P2/P3 |
| **持有成本（carry）** | ❌ 非同胚 | **莫比乌斯（扭转）** | §5.2 |

**结论**：方向覆盖**几乎处处是圆柱（对称）**，只在三个相邻的层
（earning / 风险边界 / carry）是莫比乌斯（扭转）。这三层有共同根：都涉及**价格空间
ℝ₊ 的开端（∞）**——earning 朝开端增仓、风险边界在开端缺壁、carry 是持有到开端的
时间成本。**不对称完全局域化在"朝 ∞ 方向"的三个层**。

  资本主义的走势本身。」→ **理论层支持多空对称**（走势 = 多空合力）。
- **第 86 课（86:31）**：「股指期货、融资融券，**本质上不过提供了一个双向的交易机制**，
  但任何投资获利的关键，是对市场走势的正确判断，这一点，是不会因为交易机制的改变而
  改变的。」→ **机制层对称**（双向），获利根据是走势判断（与方向无关）。
- **第 86 课（86:35）**：「对于真正掌握缠中说禅技术分析的人来说，融资融券、股指期货，
  **不过是多了一些操作的工具**，本质上，还是走势的买卖点问题，没有任何新的东西。」
  → 对高手是**对称工具**。

### 4.2 实操层：风险不对称（损失成倍放大 / 劝阻裸做空）

- **第 86 课（86:33）**：「对于融资融券来说，由于有杠杆的作用，对操作的精度要求更高，
  **一旦判断失误，损失也会成倍放大**。因此，对于一般的投资者来说，**最好不要参与这种
  高风险的游戏，安心地做好正股的操作，才是正道**。」→ **实操层明确风险不对称 + 对一般
  投资者劝阻裸做空**。这是 P2（载体层不对称）的缠师原文锚点。
- **第 84 课（84:316）**：「目前没有任何的现货卖空……任何在期货中的空头头寸，最终都会
  被疯狂的逼空走势所吞没……筹码就那么少，资金又那么多，**任何的空头头寸最终都是
  死路一条**。」→ **特定语境否定**（A股指数期货推出前、现货无卖空机制、筹码少资金多的
  逼空环境），**非无条件否定做空**。它否定的是"在无界上行风险的市场结构中持有裸空头寸"
  ——正是 P2 的无界亏损端在特定市场结构下的极端化。

### 4.3 做空程序：头寸词汇恒非负（"先买后卖"）

- **第 84 课（84:126）**：「别以为做空就是砸，那是最笨的手段，**做空的本质，就是让多头
  自相残杀**，因此，做空开始的时候，**经常要比多头还要多头**。」
- **第 84 课（84:488）**：「空头现在的策略可以大公开：在震荡中**先买后卖，逢反弹必抢**，
  然后再抛出，制造出无穷的抛压。」
- **第 84 课（84:298）**：「一旦政策不兑现，那么**反手做多**才有好的题材与空间。」

→ 缠师的"做空程序"在头寸词汇上**恒非负**（先买后卖、比多头还多头、反手做多）。
这印证记忆 `project_bidirectional_fugue_verdict` 的 FATAL 判断：**84 课证明的是意向的
串行切换（先做多吸筹→后抛压），不是净空头头寸的存在性证明**。覆盖论表述：缠师在
**多 sheet 上操作**（先买持正股），用多头工具制造下跌，而非进入空 sheet 的无界风险区。

### 4.4 凸性载体：认沽权证 = 放大的做空机制（持有正资产）

- **第 15 课（15:47）**：「对于认沽权证来说，如果你手头有正股……把认沽权证当成正股的
  影子，当你的正股出现卖点时，你的认沽权证一定出现买点，这样，当你的正股被减仓时，
  **认沽权证就可以增仓**，这样，在数量级上配合好，就可以在一个家庭里，左右逢源，
  **立于不败之地**。」
- **第 15 课（15:49）**：「认沽权证，**本质上就是放大的做空机制**，认沽权证的买点，就是
  正股的卖点，认沽权证的卖点，就是正股的买点……认购、认沽两者的配合，就可以编织出最
  复杂的操作来。」

→ 缠师对**纯做空方向**的唯一实操示范用的是**认沽权证**（凸性载体）。关键：
「认沽权证就可以**增仓**」= **空头方向的 earning（增仓）在认沽载体下可构造**——
因为持有认沽 = 持有正资产（d=+1，认沽自身坐标系是多头书）。这是 §6 凸性载体方案的
原文锚点，也是 T₃₆"解除条件 = 换凸性载体"的缠师原文出处。

### 4.5 原文总结：缠师对多空对称的整体立场

```
理论层（走势）：完全对称——多空通杀、双向机制、走势判断与方向无关。  [P1]
实操层（载体）：明确不对称——损失成倍放大、劝阻一般投资者裸做空、
              逼空环境空头死路一条。                              [P2]
做空实现：     不进裸空 sheet——做空程序头寸恒非负（先买后卖），
              纯做空方向用认沽权证（凸性载体，持正资产）。          [§6]
```

**缠师原文与本文档推导完全一致**：走势层对称（P1）、载体层不对称（P2）、解决方案是
**不进裸空头寸**（做多工具运作 OR 凸性载体）。缠师本人从未持有过线性载体的裸空头寸
作为 earning 主体——这不是缠师的疏忽，是 P2 的必然性在缠师实操中的体现。

## 第 5 部分：必然性解决方案（推论链对空头的展开，不引入否定线）

> 任务问题 4：从推论链推导，不引入经验性工具（不用否定线 T₄₁）。逐环展开对空头的含义。

### 5.1 第 15 环（级别=操作量）对空头：量对称

**空头仓位量由什么决定？** 由该级别**空头势**的大小决定，与多头对称。

T₁₈：操作量 `m = p_units × θ_sub/θ_total`，θ = 该级别振幅（势的力度投影）。势 Φ 是
方向 × 力量 × 趋向（D0.1），**量只取力量分量 θ，方向分量不进入量的计算**。故空头
仓位量 = 空头势的 θ 配额，与多头同公式。**T₁₈ 对空头对称成立（量与方向无关）**。
覆盖论：操作量层 τ 同胚（§3.3 表第 2 行，圆柱）。

### 5.2 第 16 环（成本门）对空头：门对称 + carry 不对称

**空头的成本门是什么？** `θ(k) < friction` 终止——与多头同判据，**但 friction 在空头
侧多一项 carry（持有成本）**。

T₁₉：递归在 `θ(k) < friction` 终止（势幅度 < 成本 = 势消失）。判据形式对空头对称。
**但 A₄（摩擦 f > 0）在空头侧扩展**：
- 多头持股：持有无现金成本（除机会成本），`friction_long = 佣金 + spread`。
- 空头持仓：必须**借入**标的（融券利息）或**展期**（期货 roll）或**承担时间价值**
  （期权 theta）。`friction_short = 佣金 + spread + carry·T_hold`
  （记忆 `project_put_option_short_earning`：`friction_put = 佣金 + spread + Θ·T_hold`）。

故**空头成本门 > 多头成本门**（高出 carry·T_hold）⟹ 空头递归比多头**早终止一层**
（同样的势 θ，空头更可能 `θ < friction_short`）。覆盖论：carry 层 τ 非同胚
（§3.3 表，莫比乌斯）——carry 是"持有到开端方向的时间成本"，多头无此项。

> **这是不对称的第二个层（carry）**。它与 earning 不对称（P4）同根：都涉及"朝 ∞ 方向
> 持有"的代价。多头朝闭端持有（免费等待），空头朝开端持有（付租金等待）。

### 5.3 第 17 环（降成本）对空头：降成本对称 / earning 不对称（分离）

**空头的降成本怎么做？** 持空时低级别**上涨**做多回补（对父空头降成本 = 抬高开空均价）。
这一步**对称**。但 earning（增仓）**不对称**——必须把两者分离。

**命题 P5（降成本/earning 分离）**：T₂₀（降成本）对空头对称，T₃₆（earning）对空头不对称，
二者是**不同的算子**，不可混为一谈。

**证明**：
- **降成本（同股数进出）**：父空头释放 m 单位给孙多头（在反弹中做多 = 对父降空头成本），
  完成后回补 m 单位。会计：`basis ← basis − d·π/units`，d=−1（空头），
  `proceeds_basis ↑`（抬高开空均价）——这是多头 `cost ↓` 的**极性镜像**
  （`bidirectional_accounting` 协变公式）。守恒 Σunits 不变（T₃₄）。**降成本是同股数
  进出（m 进 m 出），不增仓，朝 ℝ₊ 内部移动均价，不触及开端 ∞**。故 τ 同胚，对称。
- **earning（增仓）**：cost_basis 穿 0 后增 Δ 单位**同向**头寸。多头增正 Δ（朝闭端，
  可构造）；空头增负 Δ（朝开端，P4 不可构造）。**earning 增仓，朝 ℝ₊ 开端移动，触及
  ∞ 的不对称**。故 τ 非同胚，不对称。

**关键洞察**：降成本"同股数进出"的对称性恰恰来自它**不增仓**（不朝开端移动）——它只在
ℝ₊ 内部把均价推来推去，两端拓扑不对称碰不到。earning 的不对称来自它**增仓**（朝开端
移动）——直接撞 ∞ 不对称。**第 17 环对空头的正确展开 = 保留降成本对称、隔离 earning
到 §6 凸性载体**。□

### 5.4 第 22 环（多空嵌套）：父空→子多→孙空的会计递归对称

**父空头 → 子多头 → 孙空头的会计递归**在守恒/极性层**完全对称**。

T₂₅（方向交替递归）：每层 voice 跟随自己级别的势方向，相邻级别方向相反。
T₃₄（守恒 Σunits = N_base）：**守恒律不区分方向**——单位数量纲（26:34"34"），父 −m、
子 +m、孙 −m₂ 的代数和守恒，对任意方向序列 {多,空,多,…} 成立。
T₄₀（翻转 = 会计断面，M=N）：子级别走势完美 → 旧方向关闭 + 新方向开启，同股数
（M=N，`bidirectional_accounting` §5.2 cascade settle），对称。

故**多空嵌套的会计递归（守恒 + 极性 + 断面翻转）在任意深度、任意方向序列上对称**
（§3.3 表第 3/4 行，圆柱）。covering 论：方向覆盖与级别覆盖正交——多空嵌套是**两个
覆盖的纤维积**，守恒律在纤维积上逐层成立（N8 `prove_n8_conservation` 每 bar 守卫，
L2 零违反）。

> **不对称只在 earning 资本化层（P4），不在会计递归层**。父空→子多→孙空的"记账"完全
> 对称；只有当某层 voice 想把 cost 穿 0 后的利润**增仓为更多同向头寸**时，空头层才撞墙。

### 5.5 两个必然方案（穷尽，二选一或并用）

由 §3.3，方向覆盖在 earning/风险边界/carry 三层非平凡。覆盖空间要求每层同构，
故必须处理这三层的破缺。**穷尽地只有两个方案**：

| 方案 | 操作 | 覆盖论含义 | 代价 | 实装 |
|------|------|-----------|------|------|
| **(a) 截断纤维** | 空 sheet 只保走势/守恒/降成本，放弃 earning | 接受退化纤维（空 sheet 缺 earning 自由度），覆盖映射在 earning 层不保结构但在其余层保 | 绩效 ≠ 严格 Σ\|涨跌幅\|（空头无 earning 复利，T₂₄ 差距） | **unn 现状**（根恒多，子空只降成本，T₃₆ 仅计数 `nrf_short_earning_hits`） |
| **(b) 换凸性载体** | 空 sheet 改用认沽期权，把开端 ∞ 折叠为有界 | 认沽把空 sheet **同胚映回多 sheet**，恢复均匀覆盖（含 earning） | 引入时间维不对称（DTE/theta，§6.2） | 期权层（缠师 15 课原文路径，未在 unn 实装） |

**这两个方案都不引入否定线（T₄₁）**——否定线是"破 candidate 极值 → 关闭 voice"的
**经验风控工具**（27:25），它处理的是"势没真正反转"的结构信号，与本文档的**载体拓扑
不对称**正交。方案 (a)/(b) 纯从覆盖空间结构（earning 算子是否闭合）推导，不需要否定线。

> **缠师本人同时用了 (a) 和 (b)**：纯做多持仓 + 降成本 = (a) 的对称部分；纯做空方向用
> 认沽权证 = (b)（15:47/49）；做空程序"先买后卖"= 留在多 sheet 不进裸空（既非 a 也非 b，
> 是**根本不进破缺区**）。三者都不依赖否定线作为多空对称的解。

## 第 6 部分：凸性载体——期权是否是空头不对称的必然解

> 任务问题 5：§11.3 A7 审计建议"换凸性载体（期权）"。期权是否必然解？

### 6.1 认沽把空 sheet 同胚映回多 sheet（恢复均匀覆盖）

**命题 P6（凸性载体恢复局部同胚）**：认沽期权载体使方向覆盖在 earning/风险边界两层
**恢复平凡（圆柱）**——认沽 voice 同胚于多头 voice。

**证明**：认沽期权的损益 `V_put(c) = max(K − c, 0) − premium`：
- 损失下界 `−premium`（c ≥ K 时）——**有界**。价格空间从空头的 `(−∞, q·c₀]`
  （朝开端无界）变为 `[−premium, ∞)`（朝闭端有界）。**凸性把开端 ∞ 折叠为有界**——
  在 `−premium` 处人为安装了一个吸收壁（对应多头在 `c=0` 的吸收壁）。
- 持有认沽 = **买入资产**（现金 → 合约，资产购买非负债创设），`units_put ≥ 0`，
  `d = +1`（认沽自身坐标系是多头书）。earning：纯利润可买入更多认沽张数
  （`units_put += Δ`，正增仓，**可构造**）——15:47 原文「认沽权证就可以增仓」。

故认沽 voice 的纤维（earning 可构造 + 损失有界）**同胚于多头 voice 的纤维**。τ 在
"认沽 sheet ↔ 正股 sheet"之间恢复同胚（认沽买点 = 正股卖点，15:49）。
`PutVoice ≅ OrganicLedger`（零新会计类型，`project_put_option_short_earning`）。
均匀覆盖在 earning/风险边界层恢复。□

**回答任务问题 5 的第一半**：**是**，凸性载体（期权）是恢复"空头 earning 可构造 +
损失有界"的解——它把 ℝ₊ 开端的不对称**折叠**掉，使空 sheet 同胚于多 sheet。

### 6.2 不对称守恒定理：换维不消除（期权不是完全对称解）

**命题 P7（不对称守恒，本文档核心否定性产出）**：方向覆盖的非平凡单值性**不可被任何
载体完全消除，只能在维度间转移**。凸性载体把"价格维不对称（无界亏损）"转换为"时间维
不对称（DTE/theta）"，总不对称守恒。

**证明**（无套利论证）：设存在载体 L 使空 sheet 完全同胚于多 sheet——即空头获得多头的
**全部**性质：损失有界 ∧ earning 可构造 ∧ **永续持有无成本** ∧ 无需换载体。
- 多头持正股的"永续无成本"来自：价格 ≥ 0 的**闭端是免费的**（归零不再亏，等待不花钱，
  时间站在持有者一边——可无限等待走势终完美 T₂）。
- 若空头载体 L 也提供"朝开端 ∞ 的永续无成本保护"，则 L 是一个**永不过期、零成本的
  上行保险**。由无套利：一个覆盖无界上行风险的永续零成本保险**不存在**（其卖方承担
  无界负债却收零权利金 → 卖方必然破产 → 无人提供 → 无套利排除）。
- 故任何提供"损失有界"的空头载体**必须收取非零代价**。凸性载体（期权）的代价以
  **时间维**出现：
  - **有限期（DTE）**：免费认沽到期蒸发——"不败"恢复但"永续"不恢复
    （`project_put_option_short_earning`：有限期不败）。
  - **theta 租金**：持有认沽有时间价值侵蚀（carry，§5.2）——多头持股无此项。
  - **载体必选性**：多头 earning 用正股本身（无需换载体），空头 earning **必须**换
    认沽（载体必选，残余不对称）。
  - **卖方侧回归**：恢复只覆盖**买方**认沽；卖出认沽（裸卖 put）非对称定理回归
    （卖方承担有界上行收益 + 大幅下行风险，又是 ℝ₊ 不对称的另一面）。

故空头不对称**没有被消除，被从价格维（无界亏损）搬到时间维（DTE/theta/载体必选）**。
总不对称守恒。□

**回答任务问题 5 的第二半**：期权是**买方空头 earning 的必然解**（恢复损失有界 +
earning 可构造），但**不是完全对称解**。期权解的是 ℝ₊ **价格维**的不对称，代价是引入
**时间维**的不对称。这是一个深刻的否定性结果：

> **多空不对称是覆盖论的拓扑障碍（莫比乌斯带的扭转），不是工程缺陷。** 它可以被
> 局部对称化（凸性载体在价格维折叠），但全局单值性障碍守恒——你能把莫比乌斯带的扭转
> 从一个位置推到另一个位置，但不能把它变成圆柱。期权把扭转从"价格维"推到"时间维"。

### 6.3 根源：时间之箭（多头被动 / 空头主动）

不对称守恒（P7）的最深根源是**时间的不对称**，比任何载体更深：

```
多头：买入持有，时间站在持有者一边
      （价格 ≥ 0 ⟹ 可无限等待走势终完美 T₂，等待无成本，被动即可）
空头：无论何载体，时间站在对立面
      （无界上行风险 ⟹ 必须主动管理 OR 有限 DTE OR 付 carry 租金）
```

A₀（走势终完美 T₂）保证有限时间内必然完成——这个"有限性"对多头是**资源**
（持有到完美即可，时间是朋友），对空头是**约束**（必须在完美前管理无界风险或承担
时间成本，时间是敌人）。**多头可以纯被动地兑现 A₀（持有），空头必须主动地与时间赛跑
兑现 A₀**。这就是为什么：
- 缠师做多是"建仓 → 持有 → 降成本"（被动，A₃ 恒仓 26 课）；
- 缠师做空是"先买后卖、逢反弹必抢"（主动，84:488）或"认沽配合"（凸性，有 DTE 约束）。

**覆盖论终极表述**：方向双层覆盖的莫比乌斯扭转 = **时间之箭在多空两个 sheet 上的相反
取向**。多 sheet 顺时间（持有），空 sheet 逆时间（赛跑）。τ 翻转方向**同时翻转时间取向**
——这就是绕一圈不回原状的扭转。这个扭转不可消除，因为时间之箭不可消除。

## 第 7 部分：结果包六要素

### 1. 结论

在覆盖空间框架下严格推导多空不对称，**主要产出是否定性的**：

1. **两个正交覆盖**：级别覆盖（ℤ 层，R₃ σ，对称）与方向覆盖（ℤ/2 双层，R₂ τ）。
   多空不对称在**方向覆盖**，不在级别覆盖。
2. **不对称的范畴定位**（问题 1）：不对称是**会计载体的必然性质**（P2：ℝ₊ 半直线
   两端拓扑不对称），**不是走势结构的**（P1：走势层 τ 同胚，T₂₄ 对称），**不是纯
   经验的**（L0 拓扑推论）。根源链：有限责任 → 价格 ≥ 0 → 半直线 → 多头有界/空头无界。
3. **覆盖映射的处理**（问题 2）：走势维度 well-defined（保结构），载体维度
   not well-defined as covering（P3 均匀覆盖破缺）。非平凡单值性（P4）的精确内容 =
   空头 earning L0 不可构造（T₃₆）。不对称**局域化在 earning/风险边界/carry 三层**
   （都涉及 ℝ₊ 开端 ∞）。
4. **缠师原文**（问题 3）：理论层对称（86:31 双向机制 / 84:36 多空通杀）、实操层
   不对称（86:33 损失成倍放大 + 劝阻裸做空）、解决方案是不进裸空头寸（84:488 先买后卖 /
   15:47 认沽权证）。**原文与推导完全一致**。
5. **必然性解决方案**（问题 4）：T₁₈ 量对称 / T₁₉ 门对称+carry 不对称 / T₂₀ 降成本
   对称（不增仓）/ T₃₆ earning 不对称（增仓撞开端）/ T₂₅ 会计递归对称。穷尽两方案：
   (a) 截断纤维（unn 现状）/ (b) 换凸性载体。**均不引入否定线**。
6. **凸性载体**（问题 5）：期权是买方空头 earning 的必然解（P6 同胚映回多 sheet），
   但**不是完全对称解**——**不对称守恒定理**（P7）：换维不消除，价格维不对称转为
   时间维（DTE/theta）。最深根源 = 时间之箭（多头被动持有 / 空头逆时间赛跑，§6.3）。

### 3. 边界条件（结论翻转条件）

- **若**证明存在永续零成本的上行无界风险保险（否证 P7 无套利论证），**则**不对称守恒
  定理失败，空头可完全对称化，期权成为完全解。当前无套利排除此载体。
- **若**价格空间被证明是全直线 `(−∞,∞)`（如纯合约义务载体，无资产非负保护），**则**
  多空两端都无界（对称），P2 退化——但此时多头也失去下界保护（§2.4 期货负价），
  不对称从"有界/无界"变为"对称无界"，覆盖在两层都非平凡。
- **若**证明空头 earning 在某线性载体下可构造（否证 T₃₆/P4），**则** §3.2 单值性变平凡，
  方向覆盖在载体层恢复圆柱，方案 (b) 不必要。当前 ℝ₊ 拓扑排除（负股数无对应点）。
- **若**编排者裁定方向覆盖应建模为级别覆盖的子结构（而非正交覆盖），**则** §1.2 的
  正交性假设需重审，两覆盖的纤维积结构（§5.4）改变。

### 4. 下游推论

  其余层对称的选择。
