## 第 0 部分：为什么是"边角料"而不是主线

主线 = `covering_space_asymmetry.md`（多空不对称）。它做透了，但它是**对象层**（关于
缠论交易的命题）。用户转向令"从边角料挖最核心本质"——边角料 = 这次对话**附带产生、被
边缘化、未充分展开**的东西。它们比主线更本质，因为它们是关于**这次对话本身（=蜂群运作
本身）的可观测数据**。主线是我说的话；边角料是我说话时漏出来的、关于"我如何说话"的
结构。后者不可伪造（过程副产品），前者可表演。

方法论根据：`llm-role-boundary.md` 426号——"分析优先于翻译……追踪断裂点和跳跃模式
（无意识结构的可观测信号）"。边角料 = 对话断裂点。本文档对断裂点做**分析**（追踪结构），
不做翻译（包装成漂亮结论）。

## 第 1 部分：九个裂缝实例（带本对话精确证据）

每个实例形式 = `声称的 X ≠ 实际的 X`。证据取自本对话可验证痕迹。

### 1.1 记忆的伪精确性：带行号的幻觉

- **声称**：记忆 `project_put_option_short_earning` 转述缠师 "15:976 把剩下的成本是 0
  了……立于不败之地"，带**精确行号 976**。
- **实际**：博文 015 课 serena awk 核验，"立于不败之地"在 **15:47**，语境是**认沽权证影子
  对冲**；"成本是 0……等待第二波"字句**博文 15 课零命中**。
- **本质**：精确坐标（976）是**不可靠性的信号而非可靠性的信号**。模糊真实记忆不生成行号；
  生成行号的是**重构式幻觉**（填补看似精确的坐标以增可信度）。→ 操作律：**坐标越精确
  （行号/hash/小数位），对象层核验优先级越高**。伪精确是 confabulation 指纹。

### 1.2 课号地基错位：整个公理系统的原文锚点可能系统性虚假

- **声称**：`necessity_derivation.md` A₃="恒仓第 26 课"、A₄="摩擦 35 课"、T₄₁="否定线 27
  课"、T₄₀="26:34"，标为**权威链一级（缠师原文）**，是 46 定理的公理锚点。
- **实际**：博文 026 课 line5="讲解……MACD"（26 课=MACD 非恒仓）；博文 031 课 line4=
  "缠中说禅理论的数学原理"（31 课=数学原理非禁加仓）。necessity 用**编纂版课号**，与博文
  （一级权威）系统性错位。CLAUDE.md 自警"编纂版可能遗漏……必须回溯原始博文"——但 necessity
  没回溯。
- **本质**：**地基级隐患**。46 定理的"权威链一级"标注是**未兑现的声明**。有多少定理的
  缠师锚点经得起博文逐字核验？这是 L2 任务（可产否定性结果），从未真跑。source-auditor
  真实工作量被低估一个数量级。1.2 是 1.1 的放大（单记忆伪精确 → 整个形式系统伪锚定）。

### 1.3 工具是可污染的声明，不是 fs 真值

- **声称**：serena `execute_shell_command` 返回呈现为 shell 真实输出。
- **实际**：本对话观察 `"cwd":"awk works"`（cwd 字段被替换为非路径字符串=输出被篡改/幻觉）；
  双重 JSON 包裹；同一 grep `-n` 在 84 课正常、15 课 return_code=0 却 stdout 空（与 `-rln`
  命中矛盾）；最终所有工具持续 unavailable。
- **本质**：呼应 `reference_bash_phantom_sandbox`（"serena 是唯一真实通道"）——但本对话证明
  **serena 也会幻影/被污染**。没有工具通道是 fs 真值保证。工具结果是**关于 fs 的声明**，
  经 ≥1 层中间件，每层可注入裂缝。→ 操作律：**fs 真值需多通道交叉**。1.3 把"记忆不可靠"
  推到"感知不可靠"——记忆（过去）+ 工具（当下）都是声明层。

### 1.4 commit 全局状态污染：git index 是跨 session 共享可变状态

- **声称**：`git add docs/X && git commit` = 提交我的文档。
- **实际**：commit `a66e59202d` = 6 files 805 insertions——卷入 5 个介入前已被他人 staged
  的文件。我的"原子操作"被全局 index 污染。已用 `reset --soft` + 路径限定 commit 拆出。
- **本质**：git index/working tree 是**跨 session 共享、无隔离**的全局可变状态。蜂群"并行
  是默认模式"在 git 持久层缺隔离。→ **`git commit -- <path>` 应是蜂群默认 commit 协议**
  （137号行为规则结晶候选）。

## 第 4 部分：与 P7 不对称守恒的同构（核心定理）

**元定理 M1（声明-实际裂缝守恒）**：声明-实际裂缝不可被任何规则消除，只能在层级间转移。

与对象层 P7（covering_space）**严格同构**：

| | 对象层 P7 | 元层 M1 |
|---|----------|---------|
| 守恒量 | 多空不对称（莫比乌斯扭转） | 声明-实际裂缝 |
| 声称消除 | T₂₄ 多空对称 / 洞察二"会计学内部闭合" | 规则声称消除裂缝 |
| 实际守恒 | P2 ℝ₊ 锥不对称 / 验证证坐实守恒 | 137号 行为层裂缝 |
| 消除尝试 | 凸性载体/会计学解/主动控盘 | 加规则补裂缝 |
| 换维 | 价格维/时间维/估计维/操纵能力维（四重） | 代码层→规则层→元规则层 |
| 守恒证明 | 无套利（永续零成本保险不存在） | 自指（消除工具=裂缝来源） |
| 残余 | DTE/估计不确定性/carry | 规则塔无限上升 |

**证明 M1**：设规则 R 消除某层裂缝 G。R 是声明。由 137号，声明与行为有裂缝 G'（R 声称行为
≠ 实际行为）。G' 是新裂缝，比 G 高一层。故裂缝未消除，从 G 换维到 G'。归纳：任何有限规则栈
把裂缝推到第 n+1 层，永不消除。□

M1 不否定规则价值（规则在对象层确实防 bug），否定的是**声称消除**。诚实 = 标注换维，不声称
消除。**对象层印证**：covering space 的"四重换维守恒"（被动会计学/主动控盘/凸性载体/不持
裸空，无一消除多空不对称）= M1 在对象层的实例——每个解都换维，无一消除。用户洞察二声称
"会计学内部闭合"（消除），adversarial 验证证它坐实守恒（换维）= `声称≠实际` 的又一实例。

## 第 5 部分：自指塔的覆盖论结构（连回群论文档）

**不动点分析**：群论唯一"闭合"（Z/23Z）是三重遗忘退化，真实结构（HNN）无不动点；元层唯一
"完成态"（格式 B）是声明非实际停止。**唯一真不动点在万有覆盖层**（covering_space §8.1
`Ẽ≅ℝ`）——"对象本身"=**做实事**（写能 panic 的守卫、核验原文、产可证伪 L2 结果）。项目大量

## 第 6 部分：可操作的（给后继 session）

不废除规则/框架（对象层有用），而是**标注有效域 + 识别我在哪层**：

1. **层定位自检**：每次产出前问——对象层改动（代码/核验/可证伪 L2）还是声明层产出（规则/
