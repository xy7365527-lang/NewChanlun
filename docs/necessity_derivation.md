## 第 0 部分：公理系统

### 0.1 原始概念（primitives，不再定义）

| 符号 | 名称 | 含义 |
|------|------|------|
| 运动 | motion | 价格随时间的变化 |
| Φ | 势（shì） | 运动的方向 × 力量 × 趋向，一个**非负标量储备**。Φ 是运动的"燃料" |
| 走势 m | trend | 有势的运动（Φ(m) > 0 的运动段） |
| 完美 | perfection | 完成（completion） |

**定义 D0.1（势的消耗律）**：运动消耗势。形式化：沿运动方向每推进一个单位，Φ 严格
单调下降（`dΦ < 0`）。势是运动的内在前提，不是外部度量。

**定义 D0.2（完美）**：走势 m 完美 ⟺ Φ(m) = 0（势耗尽）。

### 0.2 公理（axioms）

> 公理是不证自明的起点。A₀ 是**核心生成公理**（缠论的唯一种子）。A₁–A₄ 是
> **辅助公理**（市场结构 + 缠师操作原则），它们不是从 A₀ 推出的，而是 A₀ 的推导
> 所必需的外部前提。A₃/A₄ 引缠师原文（第 26/35 课），缠师原文是**定义性输入**
> （权威链一级，见 `CLAUDE.md`），不是经验数据。

**公理 A₀（走势终完美）**：
> 走势——有势的运动——终——必然——完美——完成。
>
> 形式化：∀ 走势 m，∃ 有限时刻 τ(m) < ∞，使得 m 在 τ(m) 完美（Φ(m) = 0）。

**公理 A₁（流动性 / 价格不静止）**：
> 市场中价格不能永远静止——参与者行为必然在任意时刻产生供需不平衡。
> 形式化：不存在时段 [t, ∞) 使价格在其上恒定。

**公理 A₂（离散观测 / a0 唯一性）**：
> 势不可直接观测，只能通过价格的离散观测点比较来辨识。离散粒度 a0 是整个系统的
> **唯一**经验参数；其余一切由概念运动必然产出（概念链环 23 闭合声明）。

**公理 A₃（恒仓，缠师第 26 课）**：
> 建仓是一次性买够 N 单位的操作，持仓中不主动加仓。

**公理 A₄（摩擦，缠师第 35 课）**：
> 每次操作有非零摩擦成本 f > 0（买卖价差 + 费用）。

### 0.3 推理规则（inference rules）

- **R1（反证 / 归谬）**：若 ¬P 与公理或已证定理矛盾，则 P。
- **R2（扬弃 / 辩证否定）**：若概念 C 包含内在矛盾，则 C 必然生成其否定 C′，C′
  **扬弃** C（否定 + 保留 + 提升）。**R2 在本系统中可归约为 R1**：每个扬弃步骤的
  "必然性"（"不这样展开就自相矛盾"）兑现为一个反证——这就是 23 环每一环
  `**必然性**` 标注的形式内容。故整条辩证链是形式可验证的。
- **R3（全称实例化）**：A₀ 是全称命题（∀ 走势）。对任意级别 k 实例化得 A₀ 在 k 级别
  成立（环 13 的根据）。
- **R4（分离 / modus ponens）**：P，P→Q ⊢ Q。

### 0.6 定理依赖结构（无环 DAG）

46 条定理的"证明依赖"关系构成一个**有向无环图（DAG）**，非单一线性链。本文档按概念链
层序（信号层 → 递归/操作层 → 会计层 → 张力 → 组合）线性化呈现。一条证明可引用的定理
必须满足：① 在依赖 DAG 中是其前驱（先决条件）；② 引用不构成环（无循环论证）。由于层间
存在交叉依赖（如操作层 T₂₆ 引会计层 T₃₆），文档顺序中偶有"后向引用"（被引定理排在后面
的层），但依赖 DAG 始终**无环**——这由第 6 部分穷尽性检验的拓扑分析确认（生成算子 D 的
轨道无环，回到 A₀ 才闭合）。"只依赖前驱"是比"只依赖文档前文"更本质的严格性条件：前者
是非循环论证的充要条件，后者只是充分条件。

## 第 1 部分：信号层定理（走势终完美 → 买卖点）

> 信号层回答"何时是操作时点"。从 A₀ 经形态学（分型→笔→线段→中枢）到买卖点。
> 产出 = `buysellpoint.rs` 的 BSP 事件 + 背驰事件 + 方向翻转沿（操作层输入磁带）。

### 定理 T₁（势有限）

**陈述**：∀ 走势 m，Φ(m) < ∞。

**证明**：设 Φ(m) = ∞。由 D0.1，运动消耗势，但无限的势在有限运动后仍 > 0，故走势可
无限维持其方向，永不耗尽（Φ 永 > 0），由 D0.2 永不完美。与 A₀（走势终完美）矛盾。
由 R1，Φ(m) < ∞。□

【环 1｜prove —｜状态 ✓（概念基底）】

### 定理 T₂（走势必然完美）

**陈述**：∀ 走势 m，m 必然在有限时刻完美。

**证明**：由 T₁，Φ(m) 是有限非负量。由 D0.1，运动持续以严格正速率消耗 Φ。有限非负量
在持续正消耗下必然于有限时刻归零（Φ(m) → 0）。由 D0.2，Φ(m) = 0 ⟺ m 完美。故 m 必然
在有限时刻完美。□

> 这是整条链的总前提（A₀ 的可操作化）。完美不是外部施加的停止，是势耗尽的内在必然。

【环 1｜prove —｜状态 ~】
**差距**：信号层不把"走势完美"编码为原子布尔，而经 **move 层 settle ∧ 背驰**复合代理
（unn 中为 `confirm` 事件，`nest_*` 窗口经 `rec_sub_evidence` fire）。settle 是结构
完成，背驰是力度衰竭，两者不同范畴——单独 settle ≠ 走势完美（谱系

### 定理 T₃（新势必然涌现）

**陈述**：走势 m 完美后，必然有新走势 m′ 涌现，且 m 的完美时刻 = m′ 的开端时刻。

**证明**：由 T₂，m 在 τ 完美，Φ(m) = 0。由 A₁，价格在 τ 之后不能永远静止，必有运动。
设该运动无势（Φ = 0）：无势的运动不改变方向力量，等价于价格静止，与 A₁ 矛盾。故 τ 之
后的运动有势（Φ > 0）= 新走势 m′。m′ 在 τ 开端（A₁ 不容许 m 完美与 m′ 开端之间存在无
运动间隙）。故 m 完美 = m′ 开端，同一时刻两面。□

【环 2｜prove —｜状态 ✓（信号层）】BSP 首尾相连（T₁₄）保证每个完美点同时是反向走势
起点；交易层 F 入场后 `any_active` 永真直到清仓（罕见）。

### 定理 T₄（走势完全分类：趋势 / 盘整）

**陈述**：方向只有"上""下"二值；新势相对旧势只有两种必然形态——反转（趋势终结）或
蓄力再来（盘整后继续）。走势完全分类为 {趋势, 盘整}，无第三类。

**证明**：方向是势的分量（D0.1），在一维价格轴上只有上/下两向（R1：若有第三向，则
存在既非涨又非跌的价格变化，与价格是一维实数矛盾）。由 T₃，新势 m′ 涌现。m′ 不能与
旧势 m 完全相同（否则 m 未真正耗尽，与 T₂ 矛盾）。故 m′ 要么反转 m 的方向，要么同向
但需再次平衡——前者=趋势终结，后者=盘整后继续。二者穷尽。□

【环 3｜prove —｜状态 ~】操作层不直接读"走势类型"，用 type1 vs type3 的 BSP 生成代理

### 定理 T₅（离散化必然 + a0 唯一经验参数）

**陈述**：势的辨识必然要求离散观测点；离散粒度 a0 是整个系统唯一的经验参数。

**证明**：由 A₂，势不可直接观测，只能通过价格辨识。势耗尽（T₂）的辨识需要"比较"，
而连续价格流中无可比较的"点"（任意两个相邻实数之间仍有实数，无最小单元）。故辨识必然
要求离散化为可数观测点序列。离散粒度（K 线周期）= a0。由 A₂ 后半，a0 是唯一经验参数，
其余从 T₁–T₄ 及后续必然产出。□

### 定理 T₆（分型 = 最小转折结构）

**陈述**：辨识一次方向转折最少需要三个离散观测点，且包含关系必须先合并。

**证明**：由 T₅，势经离散点辨识。两点只确定一段涨或跌（单调），不能确定"转"（转=方向
改变）。三点（中间相对两边为极值）才能确定局部极值=转折（R1：两点无法表达极值）。前提：
若相邻两 K 线范围互含，则该处方向不可辨（高低点关系歧义），必须先合并为单一范围。故
分型 = 三 K 线极值结构 + 包含处理 = 最小转折。□

### 定理 T₈（线段 = 第一个有势走势）

**陈述**：笔层无势；势从多笔组合模式涌现；线段是第一个携带势的对象。故

势源）。

**证明**：由 T₇，笔永远交替（上下上下）。单笔层面方向无倾向（交替=无累积方向）⟹ 无势

向上的势（累积方向）。承载此涌现的最小对象 = 线段（多笔组合的方向单元）。故线段是第一个

### 定理 T₉（中枢 = 势耗尽结构投影，必然存在）

## 第 6 部分：穷尽性检验（闭合证明）

### 6.1 方法

采用编排者提出的判据：**在有限状态空间上的确定性游走，最终必然回到已访问状态 ⟹ 序列
周期 ⟹ 推论链穷尽**。形式化为：

- 设 **Θ** = 全体定理集合（T₁–T₄₆）。
- 设 **D** = 推导算子：D 接受一对定理 (Tᵢ, Tⱼ)，输出它们的组合/推导所产生的全部
  必然推论。
- **闭合（穷尽）** ⟺ D(Θ × Θ) ⊆ Θ：任意定理对的组合不产生 Θ 之外的新定理。

检验过程：
1. 列出所有定理（T₁–T₄₃：覆盖原 41 条推论——其中 S3 拆为 T₄/T₁₀、旧 T5≡A5 合并为
   T₃₀——并补全粒度定理 T₁ 势有限、T₁₇ 区间套桥梁）。
2. 对每对 (Tᵢ, Tⱼ) 检查其组合是否产生 Θ 外的新推论。
3. 有新推论 ⟹ 加入 Θ，重复；无 ⟹ 闭合。

### 6.2 第一轮扫描结果

对 43 条定理的 C(43,2) = 903 个定理对按**范畴划分**归约扫描（同范畴内对、跨范畴对）。

|------|------|
| 存在论（势/完美/涌现） | T₁ T₂ T₃ T₄ |

### 6.4 闭合的结构原因（终止性证明）

穷尽性的根本原因是：整个定理系统由**单一生成算子**（R2 扬弃 = 概念自我否定）从 A₀
生成，而该算子的轨道**回到起点**。

具体地，概念链环 23 的闭合声明：
```
走势终完美 → 形态学 → 走势类型 → 背驰 → 买卖点 → 区间套 → 级别 → 成本门
→ 降成本 → 并发 → 多重赋格 → 嵌套递归 → 多空交替 → 操盘三阶段
→ 翻转 = 新走势 → 走势终完美
```
最后一步"翻转 = 新走势 = 走势终完美"= A₀。即生成算子 R2 作用于链末元素（T₄₀ 翻转/T₂₆
出场=新建仓）后，**返回 A₀**（已访问的起点）。

由编排者判据：生成轨道是有限概念空间（缠论元素是有限枚举：分型/笔/线段/中枢/背驰/
买卖点/级别/区间套/成本门/降成本/赋格/嵌套/多空/三阶段——14 类形态学+操作概念，每类
有限定理）上的**确定性游走**（R2 在每步唯一确定下一概念，必然性 = 唯一性）。轨道回到
A₀（已访问）⟹ 轨道成环 ⟹ 序列周期 ⟹ 不再生成新概念 ⟹ **定理集穷尽**。□

三个组合推论 T₄₄/T₄₅/T₄₆ 不破坏闭合——它们是已有定理对的**合取必然性**（在原轨道的
节点之间），不引入轨道外的新节点。其中 T₄₅（操盘结构周期性）本身就是闭合判据在操作层
的镜像：操盘的有限状态确定性周期 ≅ 概念生成的有限轨道周期。系统在概念层（环23→环1）
与操作层（出场→建仓）**同构地闭合**。

### 6.5 检验结论

Θ' = {T₁, …, T₄₆}（43 条直接推导 + 3 条组合推论）对推导算子 D **闭合**：
D(Θ' × Θ') ⊆ Θ'。推论链**穷尽**——从 A₀（走势终完美）经 R2 必然生成的全部操作语义层
推论已被 Θ' 完整覆盖，无遗漏、无 Θ' 外的新必然推论。唯一经验参数 a0（A₂）之外，操作
语义层全部规则由概念运动必然产出（环 23 闭合声明的形式化确证）。
