## 第 1 部分：作用空间的精确定义

### 1.1 三坐标与群（承 541 号 + spiral_exhaustive §0.1）

$$G = D_\infty = \langle\, h,\ \tau \mid \tau^2=e,\ \tau h\tau^{-1}=h^{-1} \,\rangle \cong \mathbb{Z}\rtimes\mathbb{Z}/2,\qquad \sigma := h^{23}$$

| 坐标 | 范围 | 缠论语义 | 算子 |
|------|------|---------|------|
| φ 角向（相位） | ℤ/23ℤ | 走势进度，唯一奇点 φ=0（背驰 ∧ 手性翻转） | h（推进一环） |
| r 径向（级别） | {0,1,…,R−1}，R=MAX_LADDER=**11** | 级别 = 圈数，r=λ^k；口径 0=bar,1=笔,2=线段,3=move/L1,4..10=递归层 | σ=h²³（升一级别） |
| ε 手性（绕向） | {±1} | 多/空，仅在 φ=0 翻转 | τ（多↔空） |

**helix 编码**：把 (φ,r) 合并为单一 helix 坐标 n，φ = n mod 23，r = ⌊n/23⌋。则 h: n↦n+1，
σ=h²³: n↦n+23（φ 不变，r+1）。这把"绕一圈角向 = 升一级径向"（T₅₆ h²³=σ）编码为单一平移。

### 1.2 二象性：环面（Burnside 域）vs 有界阶梯（否定面域）— **本文档的统一枢纽**

D∞ 是无限群，Burnside 引理 #orbits = (1/|G|)Σ|Fix(g)| **要求有限群作用于有限集**。化解方式有二，
它们是**两个不同的作用域，对应正面/否定面两侧**：

| | **环面紧化 S_cyc**（§2 用） | **有界阶梯 S_bd**（§3/§4 用） |
|---|---|---|
| 级别空间 | r ∈ ℤ/Rℤ（σ: r→r+1 **mod R**，回绕） | r ∈ {0,…,R−1}（σ 在 r=R−1 顶层**无像**） |
| 群作用 | D∞ → 有限商 **D₂₅₃**（h 阶 23R=253），忠实，Burnside 适用 | h 在顶层非双射 ⟹ **D∞ 不通过螺旋作用作用在 S_bd 上**（群作用不存在） |
| σ 的群论身份 | ⟨σ⟩≅ℤ/R 有限循环 | ⟨σ⟩ 不闭合（顶层缺像）⟹ 仅单子（monoid），非群 |
| 适合枚举 | **轨道**（正面：什么互相可达） | **边界缺陷 / 合法-非法转移**（否定面） |
| P3 径向越界谓词 | **恒真（vacuous）**——环面无边界 | **有判别力**——越界即非法 |

> **统一线索（贯穿全文）**：正面枚举（Burnside，46 轨道）活在**环面**；否定面枚举（边界缺陷、非法
> 转移）活在**有界阶梯**；**环面 → 有界阶梯的"切口"恰是 σ-不变性破裂之处，而那个破裂就是全部否定性

> 涌现。两个域不可混用同一谓词集（C1/C6 caveat）。

## 第 3 部分：三类分类 → 修正为 2×2 四类（操作/观测 × 合法/非法）

### 3.1 为什么"三类"不穷尽（C3 证伪，载体歧义 + 观测维缺失）

任务原设想三类：不变量轨道 / 合法变化轨道 / 非法变化轨道。对抗复核证伪其穷尽性，两处裂缝：

**裂缝 1（载体歧义）**：D∞ 每元素有唯一正规形 w = h^a τ^b（a∈ℤ, b∈{0,1}）。但合法性谓词
（τ 应用的相位 φ、r 轨迹是否越界）是**轨迹性质**，不是群元素性质——同一群元素 h^a 可由多条轨迹实现
（例如"先 σ⁻¹ 跌破 r=0 再 σ 回补"中途越界，端点 h^a 在界内）。**载体若取裸群元素则 P3 看不见中途
越界（覆盖错误）；若取轨迹则正规形唯一性失效**（一元素多轨迹）。⟹ 载体必须是**操作轨迹（生成元
序列）**或 **(群元素, 模式) 二元组**，不是裸群元素。

**裂缝 2（观测/操作轴正交于群词）—— 决定性**：存在一个维度，群词完全看不见——**读 vs 写（观测 vs
操作）**。仓库 escalation `2026-06-15-confirm-arming-differance.md` 依**第30课逐字**确证：

> "交易具有**延异性**……任何群体性交易都不具有**同时性**……必然有先后。"
> "交易是有时间性的，而这时间，**不可逆**……如果今天的交易可以变成昨天的，那本ID的理论马上土崩瓦解。"

延异（différance）= 延迟 + 差异。由此：**当下读过去的踪迹（观测）合法且是 confirm 的必要机制；
回到过去操作（改写已发生）才非法**。向心 confirm（T₄₉）读已 settle 的内圈 type1 = σ⁻¹ = h⁻²³，
群词 a=−23<0 ⟹ 按时间方向谓词 P1 判"非法/时间倒流"。**但它是合法的——作为观测而非操作**。同一 σ⁻¹
词，观测/操作两读法合法性**相反**。P1 仅凭 a 的符号无法区分 ⟹ 三谓词不穷尽。

### 3.2 修正：四类分类（穷尽性恢复）

载体 = (操作轨迹, 模式 m∈{operate, observe})。合法性是 (正规形 (a,b), m, τ 应用的 φ, r 轨迹 vs 界) 的
函数。**穷尽划分 = 2×2 四类**：

| | **合法** | **非法** |
|---|---|---|
| **操作 operate**（状态迁移=写） | 前向推进：a≥0（时间前向）∧ τ 仅在 φ=0（T₅₁）∧ r 轨迹 ∈[0,R−1]（不越 MAX_LADDER） | 时间倒流操作 a<0；中途翻手性 τ@φ≠0；顶层越界 σ@r=R−1（升到 MAX_LADDER 之上）；底层 σ⁻¹@r=0 |
| **观测 observe**（读已沉淀踪迹=读） | **向心读过去**：σ⁻¹ 沿 φ=0 母线读已 settle 的内圈 type1（T₄₉，a<0 但读过去合法） | **前向读未来**：读未发生的 type1（前向窗口 confirm = 几何错误，covering doc §7.3，够不着） |

**判别谓词（均在正规形 (a,b) + 轨迹 + 模式上可计算）**：
- P0（模式）：operate / observe —— **正交于群词，C3 补的第四维**。
- P1（时间方向，仅 operate 域）：a≥0 合法 / a<0 非法。**在 observe 域被悬置**（读过去 ≠ 回过去操作）。
- P2（手性翻转相位）：τ 仅在 φ=0 合法 / φ≠0 非法。
- P3（径向越界，仅有界阶梯 S_bd）：r 轨迹 ∈[0,R−1] 合法 / 越界非法。**环面域恒真（C1/C6 caveat）**。
- 在 observe 域，P1 替换为 P1'（读取时间朝向）：读过去（向心）合法 / 读未来（前向）非法。

**穷尽性**（修正后成立）：每个 (轨迹, 模式) 落入恰一格。{合法操作} ⊔ {非法操作} ⊔ {合法观测} ⊔
{非法观测} = 全体 (轨迹, 模式)。P1/P2/P3 仅在 operate 子域构成二分；observe 子域由 P1' 二分。

### 3.3 不变量轨道在四类中的位置

任务的"不变量轨道"对应 §2 的 **46 条 σ-轨道**——它们是**操作的不动方向**（沿母线 σ 作用，58 条不变量
在其上常值）。在四类框架里，σ-轨道是"操作"行的**纤维**（每条母线 = 一个 ⟨σ⟩-轨道），合法操作沿母线
升（σ@界内），非法操作越界（σ@顶层），合法观测沿母线向心读（σ⁻¹ 读过去），非法观测前向读未来。
**故不变量轨道不是与"合法/非法变化"并列的第三类，而是四类的底层纤维坐标**——这本身修正了任务的
"三类之和=总轨道"设想：正确的穷尽是 **2×2 模式×合法性，纤维化在 46 条 σ-轨道上**。
