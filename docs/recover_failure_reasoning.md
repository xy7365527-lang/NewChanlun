## 0. 结论（一句话）

编排者诊断的三个症状（买信号 58%、891 noop、recover 50.5%）**不是三个独立 bug，是同一个根的三个衍生**。
根本病根是：**`sink` 把缠论的"次级别短差 = 减仓到现金"（第26课恒仓降成本），错误地实现成了"减仓 + 开反向空头持有"**。
更深一层，这是把 **D∞ 群的 ε 翻转（相邻级别方向相反）当成了缠论的次级别操作**——而 ε 翻转的有效域是
"本级别走势结束的方向翻转"（`flip`，已正确），**不是**次级别短差（次级别走势与本级别**同向**，第65课）。

修复方向：**`sink` = 减仓到现金（删 ε 翻转），`recover` = 用现金买回核心方向**。
`flip`（本级别翻转）保留 ε 翻转——双向做空能力完整保留在 flip 里，不损失。

## 2. 缠论原文：次级别短差的严格定义

### 2.1 短差 = 恒仓减仓到现金（第26课）

> 第26课:34 —— "本ID的仓位是**一直不变的**，最开始多少就是多少，上上下下，**卖点的时候变少，买点的时候又回复原来的数量**，但绝对不加仓，一开始就买够。"

这是次级别短差的**字面定义**：核心仓 N 股恒定，卖点卖出一部分（变少 → 那部分变**现金**），买点用现金买回（回复 N）。
高卖低买的差价 = 降成本。**中间持有的是现金，不是空头。**

> 第26课:80（补充原则2）—— "**除了日线的单边上扬走势，短线必须坚持**。但仓位可以控制，例如用其中的 **1/3**。"

→ 短差用 1/3 仓位（=`MOBILE_FRAC`，引擎已对）；但**单边上扬走势中不做短差**。

### 2.2 卖了等回跌回补（第33课）

> 第33课:34 —— "2888 点的第一卖点没走，那么 03011100 的 2859 点也该走了……当然要**走了等回跌以后看情况再回补**，而后面又出现了 100 点的回跌，然后出现底背驰，当然就是一个**完美的回补点**了。"

> 第33课:48（围绕中枢操作总纲）—— "每次向下离开中枢只要出现底背驰，那就可以介入了……次级别回抽一旦不重新回到中枢里，就意味着第三类买点出现了，就**一定要买回来**。"

→ 卖出（变现金）→ 等回跌 → 底背驰/三买 → **买回来**。回补是用现金买回，不是平空头。

### 2.3 做空是期货特性，不是默认短差方式（第33课）

> 第33课:50 —— "对于指数，最大的利益在期货里。不过，期货的情况有很大的特殊性，**因为期货是可以随时开仓的，和股票交易凭证数量的基本稳定不同**，所以在力度分析等方面有很多不同的地方。"

→ 缠师明确区分：股票"交易凭证数量基本稳定"（恒仓，短差只能先买后卖降成本），做空（先卖后买）是期货才有的能力。
即使第26课:34 说"也应该学会先卖后买"，那是**高手在震荡中对该级别走势方向的双向操作**（下跌段做空），不是"在上涨核心仓之下叠加次级别空头"。

### 2.4 强趋势中次级别卖了要立即买回（第29课）

> 第29课:256 —— "如果大级别是第二买点开始的初升、甚至是**主升段**，看小级别的背驰有多大意义？**就算卖了，也要马上找位置买回来**。"

→ 主升段（单边上扬）里，次级别卖点即使卖了也要**马上买回**——绝不是开空头持有。

### 2.5 次级别走势与本级别同向（第65课，引擎注释自引）

> 第65课 `Move(k) ≡ Level-(k+1) 笔`（`t_engine.rs:507` 自引）：低级别走势类型**组成**更高级别的笔/段。

→ 次级别上涨**组成**本级别上涨——相邻级别方向**通常一致**，不是相反。

## 3. 当前引擎 sink/recover 的实际语义 vs 原文

### 3.1 sink 的代码（t_engine.rs:535–555）

```rust
fn sink(&mut self, parent, sub, bar, c) {
    let pdir = self.layers[parent].direction;
    let m = mobile_quota(u_p);          // = u_p / 3 ✓（第26课 1/3）
    let mob = flip(pdir);               // ← ε 翻转：短差方向 = 反父向
    reduce_at(parent, m, ...);          // 父级减 1/3 ✓（卖点变少）
    add_at(sub, m, mob, ...);           // ← 用这 1/3 现金"开反向空头" ✗
}
```

净敞口变化：父级 `+u_p` 多头 → `(u_p − m)` 多头 **+ `m` 空头**。
净方向敞口 = `(u_p − m) − m = u_p − 2m`。**比缠论"减仓到现金"（净敞口 `u_p − m`）多空了一份 `m`。**

### 3.2 对照表

| 维度 | 缠论原文（§2） | 当前引擎 sink | 一致？ |
|------|---------------|--------------|--------|
| 减仓比例 | 1/3（26课:80） | `mobile_quota = u/3` | ✓ |
| 减仓去向 | **现金**（26课:34 "变少"） | **反向空头**（`add_at(sub, mob)`） | ✗ |
| 净方向敞口 | `u − m`（始终偏多/偏空，顺势） | `u − 2m`（甚至净持空，逆势） | ✗ |
| 回补方式 | 现金买回（33课:34 "回补"） | recover 平空头（依赖配对买点） | ✗ |
| 相邻级别方向 | 同向（65课 组成关系） | 反向（`flip(pdir)` ε 交替） | ✗ |
| 强趋势行为 | 卖了马上买回（29课:256） | 开空头持有，等买点 | ✗ |

**6 项有 5 项与原文冲突，根都在 `add_at(sub, m, flip(pdir))` 这一行的 ε 翻转。**

## 4. 根本病根：ε 翻转用错了地方

### 4.1 三层归因

| 层 | 内容 |
|----|------|
| 表层（症状） | 买<卖、891 noop、recover 50.5% 失败、核心恢复 84% |
| 中层（病根） | sink 把"减仓"做成"减仓 + 开反向空头"。开空必须平空，牛市买点 < 卖点 → 50% 空头僵尸 + 涨段持空失血（−16929） |
| 深层（范畴错误） | 把 **D∞ 群的 ε 翻转**（相邻级别方向相反，`σ⁻¹∘τ` 几何塔）当成缠论的次级别操作。缠论次级别短差是恒仓减仓到现金（**无翻转**），且次级别与本级别**同向**（第65课） |

### 4.2 为什么三症状都是这一个根的衍生

- **症状1（买<卖 58%）**：牛市的真实信号特征（上涨段多 → 顶背驰卖点多于底背驰买点）。
  - 在"减仓到现金"模型下：买<卖只意味着**仓位偏轻**（温和踏空），核心多头始终在场。
  - 在"开空"模型下：买<卖意味着**开空 > 平空** → 空头僵尸 + 涨段持空失血（致命）。
- **症状2（891 noop / level 不匹配）**：sink 把空头**绑定到特定 ladder**，recover 要求**同 ladder 同向买点**才能平。
  - "减仓到现金"模型下：现金是**共享池**（不绑 ladder），任何相关级别买点都能买回核心 → 无 level 匹配问题。
- **症状3（recover 50.5%）**：开空必须找配对买点平空，买点不够 → 1323 空僵尸。
  - "减仓到现金"模型下：**没有"平空"这回事**——最坏情况只是现金未用尽（仓位偏轻），不存在僵尸空头。

### 4.3 ε 翻转的正确有效域：flip（不是 sink）

`flip`（核心级反向翻转，route_bsp:686–703）= 本级别走势结束 → 反向。**那里 ε 翻转是对的**：
- 本级别卖点 = 本级别走势完美结束 → 清多翻空（吃下跌段，实现"Σ|涨跌幅|双向"）。
- 这是 26课:34 "也应该学会先卖后买" 的正确载体——**对该级别走势方向的翻转**。

`sink`（次级别短差）= 本级别走势**未结束**，次级别回调 → 应**减仓降成本**（恒仓），**不翻转**。
- 在这里施加 ε 翻转 = 在本级别走势中途逆着方向开次级别空头 = 系统性逆势。
- BTC §3 数据"96% 持多 + 93% 持空同时"正是这个逆势叠加的物理形态。

> **一句话**：ε 翻转属于 flip（级别走势的"换向"），被误用到了 sink（级别走势内部的"减仓"）。
> `formalization-validity-domain`：D∞ 群作用（ε 翻转）在代数上对全级别成立（定义域），但其交易语义有效域只覆盖 flip（本级别换向），不覆盖 sink（次级别短差）。把它用到 sink = 有效域膨胀。

## 5. 为什么这不是已被堵死的三条路

`strict-fix-proposal` 把方案空间二分为"砍空头腿 / regime 条件化"（都判否），并提"成本门/结构门"。
本方案是**它们都没覆盖的第四条路**，关键区别如下：

| 路径 | 内容 | 判定 | 本方案是否= |
|------|------|------|-----------|
| 砍空头腿 / 回归 v3 只做多 | 连 **flip 翻空**也禁（`force_long_only`） | 能力损失（下跌标的裸多裸亏） | **否**：flip 翻空完整保留，下行能力不损 |
| regime 条件化 | 按 regime 判断**是否开空** | 539 §9.4 已 L3 否证 | **否**：无条件（所有标的/regime 一致），不是 regime 判别 |
| 成本门 / 结构门 | 门控 sink **触发频率**，保留开空本质 | 未必充分（539 域不可约） | **否**：不改频率，改 sink **语义本身**（删开空） |
| **本方案：sink = 减仓到现金** | sink 不开反向仓，recover 用现金买回 | 待 L3 验证 | — |

**关键论证**：strict-fix 的二分假设了"sink 必须开空才能双向"。但**双向能力在 flip 里已经有了**——
sink 不开空不损失任何做空能力，只是把"次级别逆势空头"换成"次级别减仓现金"。这正是原文（§2）的字面要求。

**这是实现错误，不是定义冲突**（`testing-override` 判据）：修复 = 让实现符合第26课定义，**不改变任何缠论定义**。
触动的是 `operate.rs`/spiral 的 ε 几何塔形式化——但那是形式化工具，且 `t_engine` 是 standalone（不绑 542 `prove_sigma_quota` 守卫），可独立修。

## 6. 严格修复方案

### 6.1 sink → 减仓到现金（删 ε 翻转）

```rust
// 旧：reduce_at(parent, m) + add_at(sub, m, flip(pdir))   ← 减仓 + 开反向空头
// 新：reduce_at(parent, m)                                 ← 减仓到现金（资金留 free）
//     记录 pending_recover[parent] += m                    ← 待回补量（核心方向）
```

减仓的 realized 仍按父向核算（`account_reduce`）——父多减仓 = 降成本（第31课降成本阶段），符合既有三阶段会计。

### 6.2 recover → 用现金买回核心方向

```rust
// 旧：reduce_at(sub, u_sub) + add_at(parent, m)            ← 平空头升回
// 新：add_at(parent, pending, pdir)                        ← 用现金在父向买回（恢复核心）
//     pending_recover[parent] = 0
```

回补量 = 之前 sink 减掉的累计待回补量（恒仓回复，第26课"回复原来的数量"）。

### 6.3 子级 layer 的处置

次级别短差不再是"次级别空头 Layer"，而是"核心仓的减仓 + 共享现金缓冲"。
`drain` 当前已经是"减仓到现金不开空"（drain:589）——本方案实质是**让 sink 退化为 drain 的减仓 + 一个待回补量记账**，recover 从待回补量买回核心。

### 6.4 双向对称（下跌 regime 不损能力）

- 上涨核心（Long）：次级别卖点 → 减多到现金；次级别买点 → 现金买回多。
- 下跌核心（Short，由 flip 翻空建立）：次级别买点 → 减空到现金；次级别卖点 → 现金买回空。
- 做空趋势完全保留在 flip + Short 核心里，sink/recover 只做该核心的恒仓减仓/回补。ε 镜像保留（对父向对称），只删"反向开仓"。

## 7. 认识论等级与边界条件

- **诊断（§1–§5）= L0**：代码 + 原文，不依赖回测。sink 开空违背第26/29/33课是确定的。
- **修复有效性 = L3 待验证**：sink=减仓到现金能否让 BTC 跑赢/8 标的 P1 提升，**必须回测，不可假设**（不重复 NRF v5"机制成立但普适性否证"的错误）。
- **诚实边界**（`formalization-validity-domain`）：消除"涨段持空失血（−16929）"是结构确定的（不开空就没这笔亏）；
  但"核心 churn 少赚"（REAL-data §6：HEAD L1 +14611 vs v3 +811680）是 **flip 频率**问题，**正交于本方案**，sink 修复不必然解决 flip 过度翻转。本方案只修 sink，不修 flip。
- **结论翻转条件**：修复后 8 标的 P1 若 < ε 塔基线 ⇒ 本方案否证（sink 减仓到现金过度踏空，劣于开空对冲）。
  特别地：若 BTC 升但震荡标的（CL/OKLO）跌 ⇒ 说明 sink 开空在震荡中是有效短差（开空吃次级别回调利润），本方案只对强牛成立 = 退化为 regime 域读数。

## 8. 结果包六要素

1. **结论**：recover 50.5% 失败 + 891 noop + 买<卖**不是三个 bug**，是 `sink` 把"次级别减仓到现金"（第26课）错实现为"减仓 + 开反向空头"的三个衍生。根本范畴错误 = ε 翻转（D∞ 群作用）用到了 sink（次级别短差），而其有效域只覆盖 flip（本级别换向）。修复 = sink 减仓到现金 / recover 现金买回；flip 保留 ε 翻转（双向能力不损）。
2. **定义依据**：第26课:34（恒仓"卖点变少买点回复"）、26课:80（1/3 + 单边上扬不做短差）、29课:256（主升段卖了马上买回）、33课:34（卖了等回跌回补）、33课:50（做空是期货特性，股票凭证数量稳定）、65课（次级别与本级别同向）。输入数据特征：BTC 空头 2647 笔总 pnl −16929、54.6% 涨回才平、最大 10 笔全是高级别逆势做空、96% 持多∧93% 持空——全部满足"sink 开空 = 逆势"的判据。
3. **边界条件**：修复后 8 标的 P1 < ε 塔基线 ⇒ 否证。BTC 升而震荡标的（CL/OKLO）跌 ⇒ sink 开空在震荡是有效短差，本方案退化为强牛域读数。flip churn（核心少赚）正交于本方案，sink 修复不必然解决。
