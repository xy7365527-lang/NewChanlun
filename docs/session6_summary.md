## 1. 本 Session 的旅程（按时间顺序）

### 起点：v3 的 T24 手性 panic

`fugue_v3`（手动分层 ladder：bi=1/segment=2/move=3/recL2=4…）的操作层有一条**手性交替不变量**：
几何塔相邻级别方向应相反（sink 穿 ε=−1）。代码里 `T24` 检测「相邻同向占用」并 panic。
但建仓阶段（未出卖点）相邻同向是**合法**的——panic 把合法状态当成 bug。

**改动**：`operate.rs:476` / `layer.rs:102` / `prove.rs:46` 把 T24 从 panic 不变量降为**观测计数**
（137 号 make-decision-observable）。手性交替被重新认识为 **regime 依赖的观测量，非全局不变量**——
`emergence_upgrade` 把核心 relabel 上移会留 idle 间隙，间隙两侧 sink 填入的腿可同向。

> 这一步的存在论意义：手动展开递归（v3 的 4 类层间接缝 bug：segment 缺 nf / F-sink 双下界 /
> σ-ascend 推稀疏 / recover 方向被拦）暴露了「手动分层 ladder」架构的脆弱性，催生了统一递归算子 T。

### 主线 1：统一递归算子 T（信号层）

把所有级别还原为**单一算子的迭代深度** `aₙ=f(aₙ₋₁)`（缠师第 65 课）。`rust/src/recursive_t/`
standalone 实装，不依赖 v3 nucleus：

  条件 1+4+力度；`>0` → 真背驰 5 条件全检）。
- 阶段 2 对照 v3：匹配率 = regime 函数（0.774 DX 震荡 → 0.210 OKLO 强趋势单调降）；recL2+ 的

## 2. 学到了什么

### 2.1 缠论的操作逻辑（原文考古，L0 文本依据）

调研报告 `analysis/chanlun_original_operation_structure.md` 逐字摘自一级权威博文：

1. **四步跨级别循环**：主级别买点建仓 → 趋势顶背驰卖点 → 清仓；次级别（30/5 分钟）减仓-回补短差降
   成本；次次级别（1 分钟）区间套精确定位主级别买卖点的「那一个点」。
2. **会计双重性**：短差 = **对主仓位本身的「减仓-回补」循环（先卖后买）**，钱和股票不断流动以摊低
   成本（第 25 课 025:208）——**不是**「恒定多头 + 独立空头账本」。A 股现货无独立空头，「卖出」=减多头、
   「回补」=加多头；真空头仅用**认沽权证**（第 15 课 015:976，做空是载体特例非默认机制）。
3. **买卖点首尾相连**：第 24 课背驰-买卖点定理「任一背驰都必然制造某级别的买卖点，任一级别的买卖点
   都必然源自某级别走势的背驰」。日线顶背驰卖 → 回跌 → 5/30 分钟底背驰买 → 重新上涨甚至创新高。
4. **卖点 = 翻空（载体特例）**：缠师的「卖」首先是减多头；只有在确认转弱（第 93 课 `-1,1`：向下笔后
   反抽不创新高）时「最后一次不回补，完全退出战斗」= 主仓清空。真做空 = 认沽期权语义。
5. **走势终完美**：背驰 → 走势终结 → 新走势开始。背驰 = MACD **同色柱面积之比 C<A**（红对红、绿对绿），
   黄白线（DIFF/DEA）校验 B 段中枢是否回拉 0 轴。趋势背驰回跌**至少回到 B 中枢**；盘整背驰用于
   「盘整中弄短差」。
6. **1/3 机动仓 + 单边上扬禁短差**（第 26 课 026:80，**最关键**）：短差用主仓「其中的 1/3」；
   **「除了日线的单边上扬走势，短线必须坚持」**——单边上扬是短差**禁区**。

### 2.2 T 算子：统一递归 aₙ=f(aₙ₋₁)

- **信号层 + 操作层自我复制**：同一算子 T 既生成各级别的中枢/走势/背驰/买卖点（信号层），又在操作层
  把「核心仓 + 1/3 机动短差」结构递归到每个级别（操作层）。仓位层的几何塔（1/3, 1/9…）是
  sink sizing 自然涌现的，不是硬编码。
- **级别是迭代深度**：取消 v3 的手动分层 ladder 常量，级别由**中枢**定义（谱系 008/010），r* 由数据
  涌现。消除了 v3 的 4 类层间接缝 bug（手动展开递归的接缝）。

### 2.3 群论：Z₂ 翻转 + 齿轮咬合 + 多尺度滤波器

- **Z₂ 翻转**：每级别一个二值状态机（多/空），核心级反向 BSP = flip（走势终完美 → 新走势）。
- **齿轮咬合**：区间套 top-down——高 ladder 先更新，子级读父级本 bar 最新状态。父级减仓下放
  σ⁻¹∘τ（sink），次级别走势完成 σ∘τ（recover）。手性交替 = 相邻级别方向相反（sink 穿 ε=−1）。
- **多尺度滤波器**（#7 版）：删跨级耦合，每涌现级别独立 Z₂ 只响应自己 BSP。产出 regime×scale
  二维画像，但失去核心主导 → 机械翻转踏空。
- **教训**：群作用的代数正确（NAV 中性、Σ|units| 守恒、手性交替）是 **L0**，不蕴含经验有效
  （形式化有效域规则 222/223/230 号）。耦合机制「代数成立」≠「赚钱」。

### 2.4 级别涌现：自下而上 + 自上而下双向

- **自上而下**（区间套约束，原引擎已有）：子级语义由父级状态决定（持多卖点=sink、持多买点=recover）。
- **自下而上**（#10 新增）：低级别走势完成 → 封装成上级单元 → 核心仓 relabel 升级归属到涌现上界
  （第 65 课）。方向门控：仅「核心仓极性 == 涌现走势方向」时升级（持多∧涌现向上）。
- **关键洞察**：6 次升级 ≠ 边际事件——每次升级开启一段**长期路由 regime 改变**，此后数千个低级别 BSP
  全变子级 churn。少数结构事件的杠杆效应巨大。

### 2.5 recover 全量归还 vs 1/3 几何衰减

- **1/3 几何衰减**（σ-不变，与 542 号 operate.rs `recover_chunk` 一致）：子级短差 m₀·(2/3)ⁿ 永不
  归零，核心仓渐近永不回 100%——这是 ε 几何塔的**设计属性**，非 bug。
- **全量了结**（方案②）：次级别走势**完成**是 0/1 事件（非配额事件）⟹ 整条短差一次性平清，资金全
  回核心。**概念分离**：recover 能指有两个所指——「τ 转移 σ-不变 1/3」vs「次级别走势了结全量」。
- **L3 判决**：全量 = regime 方差缩减器。救穿仓（清掉过度做空残余）、杀震荡（1/3 残余正是震荡短差
  的 alpha 源）。**改善的是绝对失血 + MDD，不是 P1。**

`max_chiral_same_dir = 2`（最多 2 对相邻同向 = emergence 留下的 idle 间隙两侧 sink 同向填入）。

### 4.2 代码面（`t_engine.rs` 逻辑链）

读 `route_bsp`（`t_engine.rs:292`）/ `sink`(:240) / `recover`(:263) / `emergence_upgrade`(:227)：

**三个机制全部是「降敞口」方向，叠加 = 3% 净敞口：**

1. **emergence 锁死核心 → enter/flip 重建通道关闭**（决定性根因）。
   `step` 阶段 A'（`t_engine.rs:364`）在 BSP 路由**前**把核心 relabel 上移到涌现上界（BTC 升到
   ladder 7 = T4）。核心升高后，`nearest_active_parent(j)`（:155）对几乎所有低级别 BSP 都返回那个
   升上去的核心 ⟹ 它们从「核心级 `enter`/`flip`」（:317 `None` 分支，**用全部 free 满仓重建的唯一
   入口**）退化为「子级 `sink`/`recover` 短差」。高 ladder 的 BSP 极罕见 ⟹ flip 几乎不再触发
   （CL/OKLO/BRN：60+ 笔 → 1 笔）。核心仓首次 `enter` 后**只能被 sink 单调侵蚀（每次 −1/3）**，
   `free` 池的 94% 现金再也不被 `enter` 用掉 ⟹ 毛敞口坍缩到 5.6%。

2. **ε 几何塔本身的几何衰减**。核心被 sink 减 1/3、1/9…，相邻级别方向相反（手性交替）⟹ 同一时刻
   多空并存（`max_concurrent_voices=4`），对冲比率 46% ⟹ 净敞口 = gross × (1−46%) ≈ 3%。

3. **全量 recover 清掉残余敞口**。次级别走势完成整条短差平清，进一步把过度做空残余收回 ⟹ 降绝对失血、
   降 MDD，但也降敞口。

**方向正确率 27.7% < 50% 的根因**：核心翻空在牛市错边。四象限里「空头逆势(涨段持空) −128,251」是最大
亏损源——这正是 539 号「翻空有效域 ⊂ 非上行 regime」在 BTC 强牛上的显形。emergence 把核心锁在高
ladder 后，核心一旦翻空就长期错边，而低级别短差（L3/4/5）反而在 churn 中赚了 +79,478，被高级别核心
亏损 −49,850 吃掉大半。

### 4.3 瓶颈的精确诊断

| 问题 | 答案 |
|------|------|
| 每时刻多少级别同时持多/持空？ | `max_concurrent_voices=4`，几何塔多空并存（手性交替），对冲 46% |
| 哪些级别贡献「对冲」？ | 相邻级别（核心 L6/7 持多 vs sink 下放的 L5 短差持空），手性塔结构性对冲 |
| 涌现升级触发几次？核心在哪？ | 4-11 次/标的；BTC 核心被锁在 ladder 7（T4） |
| BSP 信号问题还是操作逻辑问题？ | **操作逻辑问题**。配对率不是解释变量（ON sink/recover 配平率多数 ≥ OFF）；真因是 emergence 关闭了 enter/flip 满仓重建，叠加几何塔对冲 + 全量 recover 收敛，三者全是敞口缩减器 |

**结论**：3% 净敞口不是某一个 bug，是**三个方差缩减器叠加的必然结果**。它们各自在「救穿仓」上有效，
但联合作用 = 把引擎压成一个「几乎空仓、多空对冲、方向还错」的低暴露 churn 机器。**P1 0/8 不是调参没
调好，是这套架构的结构性上限。**

## 5. 下一步方向（从缠论原文严格推导）

瓶颈定位指向一个**原文级缺口**：引擎缺第 26 课「日线单边上扬走势，短线必须坚持」这道门。所有「改进」
都在无差别地降敞口，因为它们**没有 regime 判别**——强牛和震荡用同一套 sink/recover/emergence。

### 方向 B（最高优先）：regime 门——单边上扬关闭短差

> 必然性来源：026:80（单边上扬禁短差）、024:210（上涨中段「只能打点短差，甚至可以不管」）。

在 `sink` / `emergence_upgrade` 触发前加**走势类型判别**：
- 主级别 settled 为**单边上扬趋势**（无次级别顶背驰/盘整背驰转弱）⟹ **禁止 sink 做空、禁止 emergence
  churn，核心仓坚持满仓**。
- 仅在「盘整 / 趋势末段背驰」regime 下开启短差。
- 判别量候选：主级别走势是否 settled 为趋势 + 次级别是否**盘整背驰**（非纯振幅，需 MACD 柱面积）。

**预期**：直接对治 BTC 强牛踏空——单边上扬里核心仓全程坚持（不被 sink 侵蚀），暴露回到 ε 对称版的
水平，同时震荡段保留短差 alpha。这是把 ε 对称（#5，正域 7/8）的趋势捕获**保留**，再用 regime 门补上
它在穿仓标的上的缺口，而非用涌现/全量 recover 无差别压敞口。

### 方向 C：仓位三分——核心仓 2/3 恒持 + 机动仓 1/3 + 现金缓冲

> 必然性来源：026:80、009:482（1/3~1/2）、025:365/477（永留机动）。

当前 emergence 把核心锁死后 sink 单调侵蚀核心，**没有「核心仓坚持」的份额保护**。改为：
- **核心仓 ≈ 2/3**：日线买点建立，趋势顶背驰才清；单边上扬全程坚持，**sink 不可侵蚀核心**。
- **机动仓 ≈ 1/3**：唯一参与 sink/recover 短差的份额，被上限钳制。
- **现金缓冲**：供回补与突发。

这把 sink 的「单调侵蚀核心」改为「只在机动仓 1/3 内循环」——核心仓 2/3 永远在场吃趋势，暴露不会
坍缩到 5.6%。

### 方向：保留 emergence 但归还核心重建权（emergence A/B 开放设计轴）

涌现 relabel 后**仍允许更高/同级 BSP 触发 flip 全仓重建**，而非把所有低级别 BSP 降为子级 churn。
即 emergence 只改「归属级别」，不剥夺「核心级满仓重建权」。

### 优先级与排序

基于本 session 的 L3 证据，严格排序：

```
ε 对称几何塔（#5，正域 7/8）+ 方向 B regime 门 + 方向 C 仓位三分
  ≻ ε 对称单独（穿仓标的缺保护）
  ≻ 涌现/全量 recover（无差别降敞口，P1 0/8）
  ≻ 耦合/翻转（穿仓）
```

**核心判断**：回到 ε 对称基座（恢复其 +664% 趋势捕获），用 regime 门补穿仓缺口，**而不是**在涌现/
全量 recover 这条「无差别降敞口」的路上继续走。本 session 已证明后者的终点是 P1 0/8。

## 6. 结果包六要素
