## 3. 核心技术发现详录

### 3.1 c 段切走机制（代码 + 充要条件推导 + BTC 数据）

**代码链路**：
- `trend.rs:segment_into_trends`：两步。①`group_centers_by_direction` 把中枢按"依次同向"分组
  （`same_direction_step` 用外缘 [DD,GG]：后中枢 DD>前 GG=上、外缘重叠=None 断裂）。②映射回单元
  切片：第 gi 组终点 `ue = starts[gi+1]` = **下一组首中枢的首单元绝对索引**（trend.rs:99–103），
  最后一组 ue=n。
- `divergence.rs:judge_trend_divergence`：`c_start = 末中枢末单元+1`（切片坐标，line 179），
  `c_start >= len → return None`（无离开段 c，line 180–182）。
- `center.rs:find_centers`：第 31–35 行**自述**"贪心扫描把离开前一中枢的连接段吸收为下一中枢的首单元"。

**充要条件推导**（取证 agent 给的，我核对成立）：
设当前组末中枢 B 末单元绝对索引 `b_last`，切片起点 `us`，长度 `L=ue-us`，下一组首中枢首单元 `a_next`。
- 切片坐标：`c_start = (b_last - us) + 1`。
- 无 c 段 ⟺ `c_start >= L` ⟺ `(b_last-us)+1 >= ue-us` ⟺ **`ue <= b_last+1`**。
- 非末组 `ue = a_next`，且贪心吸收**恒令** `a_next = b_last+1`（连接段被吸收成下一中枢首单元）。
- ∴ **非末组几乎必然无 c 段**。

**cut_away vs truly_absent 判据**：
- cut_away ⟺ `ue = b_last+1` 且 `b_last+1 < n`（离开单元在全局存在、只是不在本切片）= 主导。
- truly_absent ⟺ 末组且 `b_last = n−1`（B 吃到序列末）。
- **BTC 实测**：所有无 c 段案例都是 `c_start == len`（精确相等，非 `>`），且全是中间组 → 全是 cut_away。

**BTC 诊断数字** `[L2]`（4,625,119 bar，structural 口径）：
| 级别 | 趋势走势 | 无 c 段 | 占比 | type1 |
|------|---------|--------|------|-------|
| lad6(L3) | 3 | 3 | 100% | 0 |
| lad5(L2) | 14 | 11 | 78.6% | 0 |
| lad4(L1) | 59 | 45 | 76.3% | 1 |
| **合计** | **76** | **59** | **77.6%** | **1** |

全塔 BSP 分布：type1 单调衰减 `165→68→14→3→0`（level0→4）；type3 占 93.2%（4595/4930）——
`detect_type3` 在每个中枢离开点都触发，与 c 段无关，是"买卖点很多"的假象。

**重要修正**：历史说的"58% 无 c 段"是旧诊断数字，重跑实测是 **77.6%**。

### 3.2 确认的递归结构（概念 + 演进 + 被质询后的修正）

**初始命题（用户给的种子 + 我的形式化）**：
- 递归的本质 = 把当前级别无法判定的确认下放给演化解决（动力学）。不可判定性的根据：**顶分型不是
  确认**——之后可能是转折、也可能是中枢的开始（下-上-下三段重叠），本级别长得一样，必须下放次级别。
- **介入 = 当下的确认**（一买=下跌趋势底背驰，左侧）；**离开 = 确认的确认**（上涨离开段 c 背驰，
  既确认上涨完成、又回溯追认介入正确）。
- 与谱系同构：介入=压缩侧/candidate（537号），离开=展开侧/confirmed。
- 递归恒等式（540号）：Move(k)≡Level-(k+1) 笔 → 离开段 c 在级别 k = 1 个 level-k 单元 = 次级别
  一个完整走势。

**被穷尽质询修正的关键点**（§3.3 的 C15）：
> 我最初把"介入/离开"的**时间/认识论不对称**，错误地形式化成了**结构量级不对称**（说介入只需
> "次级别一个背驰"、离开需"离开段 c 是次级别趋势 ≥2 中枢"）。**这是错的**——缠论买卖点结构对称
> （一买=下跌趋势背驰、一卖=上涨趋势背驰，都需 ≥2 中枢趋势背驰 + 区间套）。正确：介入和离开**结构
> 对称**，区别只是**方向**（底/顶背驰）和**时间**（离开在后、因而回溯验证介入）。"确认的确认"是
> 时间因果关系，不是结构大小关系。

**a0 = 笔还是线段的张力**：用户说"递归从笔开始"，但严格缠论里**笔不是走势类型**（笔无中枢），
中枢=次级别**走势类型**重叠，故 a0 必须是**线段**（C5）。"笔是最小运动，但不是最小走势类型"；
"递归从笔开始"应保留为"确认的递归在笔/类背驰层触底"，与"a0=线段"是两件事。
