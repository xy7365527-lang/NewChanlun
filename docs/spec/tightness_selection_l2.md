# T(S) 选股效果 L2 验证方案

## 谱系引用

- 350号：收敛紧度量化
- 350号下游推论4：高 T 标的是否确实产生更高质量的买卖点？
- 267号：区间套操作方法论

## 认识论等级

L2（真实数据验证，单时段多标的）。

## 核心假设

**H0（零假设）**：T(S) 高的标的与 T(S) 低的标的产生的买卖点，在后续走势质量上无显著差异。

**H1（备择假设）**：T(S) 高的标的产生的买卖点，后续走势质量显著优于 T(S) 低的标的。

## 验证设计

### 方法：前向收益窗口法（Forward Return Window）

对每个标的的每个买卖点，记录其触发时刻的 bar 索引和价格，然后测量触发后 k 个 bar 的前向收益。

**买点质量指标**：
- `fwd_return_k`：买点触发后 k 根 bar 的收益率 `(close[bar_idx+k] - price) / price`
- `max_favorable_excursion`（MFE）：触发后 k 根 bar 内的最大有利偏移
- `max_adverse_excursion`（MAE）：触发后 k 根 bar 内的最大不利偏移

**卖点质量指标**：方向对称——卖点的"有利"是下跌。

### 分组方式

1. **按 T(S) 分位**：将 24 标的按 T(S) 降序排序，分为 high-T 组（前 1/3）和 low-T 组（后 1/3）
2. **对比指标**：两组的平均前向收益、平均 MFE、胜率（fwd_return > 0 的比例）

### 窗口参数

- k = [5, 10, 20, 40]（覆盖 1周/2周/1月/2月）
- 仅使用 confirmed=True 的买卖点

### 时间切分

- 训练期（用于计算 T(S)）：前 80% bars
- 测试期（用于评估买卖点质量）：后 20% bars
- T(S) 在训练期结束时刻固定，测试期内不更新

### 统计检验

- Wilcoxon rank-sum test（非参数，不假设正态分布）
- p < 0.05 视为显著

## 产出

1. 每标的买卖点清单（时刻、类型、T(S)、前向收益）
2. high-T vs low-T 组的汇总统计
3. 显著性检验结果
4. 否定性结果同等记录（L2 验证的否定性结果比确认性结果更有价值）

## 边界条件

- 日线数据上买卖点稀疏（5年约 1200 bars），样本量可能不足 → 报告置信度
- T(S) 使用 `_compute_structural_tightness`（扩展版），与 `convergence_tightness` 不同
- 仅覆盖 A 股日线，不覆盖 ETF / 期货

## 影响声明

- 如果 H0 被否决：T(S) 作为选股指标的有效性得到 L2 支持
- 如果 H0 未被否决：T(S) 可能仅是结构深度度量，不具选股预测力 → 需重新审视 350号
