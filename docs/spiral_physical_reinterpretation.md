### 1.1 (φ,r,ε) 不包含"数量"

**关键澄清（决定 Q2 命运）**：**数量（units、仓位大小、机动仓比例）不是 (φ,r,ε) 的坐标**。它是 D∞ 作用所**系数化的模 M**——T48 证明 units 是唯一 σ-不变 Casimir（守恒律建在股数而非价值上）。群同调 Hⁿ(D∞, M) 把 M 作为系数模，正是因为数量是"被群作用搬运的量"，不是"群作用的坐标"。

```

```

### 1.2 由此：减仓 ≠ τ（Q2 的范畴错误）

用户 Q2 设想："τ（ε→−ε）= 减仓 = 仓位在 ε 维上的部分翻转，不是全翻。"

1. **ε 是二值的**（ℤ/2）。τ²=e 是对合。**二值量没有"部分翻转"**——τ 要么把 ε 全翻（+1→−1），要么不动。"部分"在二值集上无定义。
2. **减仓动作本身改变的是数量 M，不是方向 ε**。减仓（短差步骤①平多）那一刻你仍是多头（ε=+1 不变），只是 units 减少 δ。减仓是 M 上的标量减法，τ 是 ε 上的对合——**两者作用在正交的对象上**（M ⊥ ε）。（注：短差的**后续**步骤②会真做空穿 ε=−1，但那是闭路里的**另一步**、用 τ 工具，不是"减仓=τ"；减仓与开空是闭路相邻两步，§2.5.A。）
3. 用户感到的"部分"是真实的，但它**活在 M（数量）维**，不在 ε（方向）维。这个"部分"的精确身份是 **§2.5 的 H₁ 闭路 M-系数权重 f=1/λ**（机动仓 1/3），不是 τ 的分数幂。

**τ 的真正物理意义**（§2.3）= **顶背驰处核心仓的完全退出+反手做空**（第一类卖点反转，T14/T51），这是 ε 的**全翻**，且**只在 φ=0 发生**。τ 是离散对合工具；短差则是用到 τ 的**有时序闭路**（§2.5）。τ 不是减仓，也不是短差整体。

> **L0 裁决**：减仓 ∈ End(M)（数量自同态，步骤①），翻转 = τ ∈ Aut(ε)（方向对合，闭路拐角工具）。把"短差整体"诠释为单个 τ = 混淆 1-cycle（H₁）与群元素（0-维），且把 M（连续）与 ε（二值）混为一谈。**Q2 应改为：短差 = H₁ 的四步 1-cycle（§2.5），τ 专作闭路②④拐角的离散手性翻转工具**。
