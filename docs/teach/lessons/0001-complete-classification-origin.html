完全分类的严格形式

第 0001 课 · 行为等价纤维分类器，以及一个「人造矛盾」如何消失

缠论说「走势终完美」——走势的递归分解是穷尽的，没有余项。 这是公理。但要让它能回测、能被证伪，你得先回答一个数学问题：「完全分类」严格写出来，到底是什么对象？ 这一课就给你那个对象，并让你看穿两种写法的严格性差距。

1. 错误的直觉：完全分类 = 一张情况清单

最自然的想法是把走势穷举成几类（趋势上 / 趋势下 / 盘整），列一张表，证明「每个走势恰好落进一类」。 这叫有限划分（finite partition）。它没错，但它不够——它只说「分了类」，没说「凭什么这样分」。 两个走势被分到同一类，仅仅因为它们的标签相同吗？那标签本身从哪来？

2. 严格的形式：纤维 = 行为等价类

codex 的 origin 给出了本质的定义（Origin/CompleteClassification.lean）：

structure CompleteClassifier (X Class Omega TraceOut) where
  classify : X -> Class
  trace    : X -> Omega -> TraceOut
  complete : ∀ x y, classify x = classify y  ↔  BehEquiv trace x y

其中 BehEquiv trace x y := ∀ω, trace x ω = trace y ω—— 两个走势在一切未来环境 ω 下产生完全相同的轨迹，就叫行为等价。

关键的是那个 ↔（当且仅当）。 它说：classify 把两个走势分到同一类 当且仅当 它们行为上不可区分。 于是分类器的每个纤维（同类的走势集合）恰好是一个行为等价类—— 不多一个、不少一个。这就是「完全」的精确含义：分类既不过粗（合并了行为不同的）也不过细（拆开了行为相同的）。

有了这一个 ↔，其余全是推论，不需额外假设：

推论含义
same_class_same_behavior同类 ⟹ 行为相同
distinct_classes_behavior_separated异类 ⟹ 行为可区分
ClassifierPartition分类自动诱导出一个有限划分（穷尽且互斥）
..._behavior_quotient类 ≅ 行为等价商集 X/∼

对比我们旧版（GPT 包逐字复制的「不变性+完备性+可实现性」三条件 I:X→P）：要三条独立假设拼出双射，笨重。 新版一个 ↔ 就锁死了纤维结构，更本质。严格性差距：自洽推导 vs 复制拼装。

3. 一个「矛盾」如何被表示选择消解

我们旧版卡在这里（曾叫 §1 矛盾）：把递归抽象成单参数函数 Fstep : Dₙ → Dₙ₊₁（一个 n 级对象 → 一个 n+1 级对象）。 但缠论里「一个 n+1 级走势由≥3 个不同的 n 级走势构成」——是个序列。 单参数装不下序列，于是旧版用 [m,m,m]（同一个走势复制三份）硬塞，退化、造假。

codex origin 怎么解的？它根本不用单参数抽象递归。 它用具体的分级 List 函数管线（Origin/ChanlunElements.lean）： 
strokesOf  : List Fractal -> List Stroke
segmentsOf : List Stroke  -> List Segment
movesOf    : List Segment -> List Center -> List Move
「≥3 段合成上级」自然发生在 segmentsOf / movesOf 内部——输入就是序列，输出就是序列，根本不需要 [m,m,m]。

这一课最值钱的一句话：那个「矛盾」从来不在缠论里，它在你选的抽象里。 换一个忠实于对象的表示（序列进、序列出），矛盾不治而愈。这就是为什么编排者决定「从更严格的起点重写」而不是在旧起点上打补丁—— 补丁治不好选错的抽象。

4. 但要诚实：origin 证了什么、没证什么

origin 里这些管线定理（parse_total_unique 等）大多是 total_unique_of_fun—— 即「函数即全且唯一」，这是 L0 平凡真理（任何函数都满足）。 origin 自己说它 "deliberately an interface"。真正的缠论保真度—— segmentsOf 是否真的实现了第67/71课的特征序列法——不在 origin 里， 留给实例（引擎）去填，并且只有跑真实数据（L2）才能被证伪。

所以「严格的 schema」≠「忠实的实装」。骨架严格是必要的第一步，但别把骨架的 L0 真理当成「策略有效」。
