认识论分级：有效域不等于定义域

第 0006 课 · L0/L1/L2/L3——为什么「代数成立」和「build 绿」可以一个字的新信息都没有

蜂群每天产出大量「已验证」「已证明」「已对齐」。这一课给你一把分级尺， 量任何这类声明到底兑现了多少。核心只有一句话，但它能戳穿一半的声明膨胀： 一个形式化工具的「有效域」可能严格小于它的「定义域」——它在代数上对所有对象成立， 不等于它在真实数据上对所有对象成立。把前者说成后者，就是声明膨胀。

1. 两个域：定义域 vs 有效域

先把两个词分清，它们是这门课的地基。

词含义例子
定义域这个形式化操作在代数/逻辑上可以施加的全部对象「完全分类」可以声称覆盖所有走势模式
有效域这个操作的结论在实际数据/语境下真正成立的范围它实际只在部分模式上经验成立

「在定义域上代数成立」≠「在定义域上经验成立」。声称二者相等，必须有与定义域等大的验证—— 否则就是把「我能对所有对象写出这个公式」偷换成「这个公式对所有对象都对」。

2. 四个等级，以及那条致命的零增量

每次形式化操作都必须标一个验证等级。关键不在背下四档，而在看懂 L0→L1 的信息增量是零。

级名称含义信息增量
L0纯代数/定义不依赖数据，从定义推导（如「函数即全且唯一」「圈秩=3」）零（同义反复）
L1合成数据验证验管线正确性，输入是你自己造的数据零（验管线，不验假设）
L2真实数据验证单标的/单时段假设检验，可能产生否定性结果正（可以否证）
L3交叉验证多标的/多时段/多代理变量的真实数据高（否证鲁棒性）
为什么 L0→L1 增量为零？因为合成数据的独立性验证是同义反复。 数据由你生成，独立性由你控制——你拿这数据「验证」出来的独立性，只是把你预设进去的东西再读出来。 L1 能确认管线没 bug（代码跑通、类型对、流程不崩），不能确认假设成立（缠论真的这样运作）。 0001/0002 课里那个「函数即全且唯一」就是典型 L0：任何函数都满足，对缠论一无所知。

这条尺直接接上前几课：

  • 0002 的「schema ≠ 忠实实装」：schema 真理是 L0；「build 绿」证明的是类型对（L0），不是缠论对（要 L2 才证伪）。
  • 0005 的不同构裁定与 OQ-9：诚实标了「全程 L0」——它是结构定理，有效域=定义域，不需 L2；但也没声称三阶段策略盈利（那是 L3）。这是正确标注的范例。

3. 否定性结果比确认性结果值钱

这是反直觉但严格的一条：L2/L3 产生的否定性结果（假设被否证）比确认性结果更有价值。 否定性结果缩小了有效域的边界——它告诉你「这里不成立」，是真信息；确认性结果只是「这次没能否证」，信息少得多。

谱系 230号 是活教材。K4 三条独立边 E/$、C/$、R/$ 跑真实数据（L3），结论是 「不满足无条件独立性」——一个否定性结果。但它没止于「否了」，而是读出精确分层： 控制 $ 后 E/$ vs C/$ 偏相关 −0.029（$ 介导的耦合，独立性恢复）。 否证非但没毁掉模型，反而把有效域的真实形状测了出来。这就是 L3 的信息密度。

4. 三起判例：有效域 ≠ 定义域，反复发生

这条规则（formalization-validity-domain，谱系 231号）不是凭空立的，是从三次真实翻车结晶的。 三例同一个形状——形式化工具在定义域上代数成立，却被误当成在定义域上经验成立：

谱系定义域上声称有效域实际错型
222号
守恒律范畴错误		加法守恒律全局成立仅在特定范畴内成立（把离散流向拓扑约束误判为近似）范畴错误
223号
分类不完备		模式D 派生边分类覆盖所有情况只覆盖部分模式（遗漏混合状态）不完备
230号
直积退化		27 配置直积代数成立（3 自由度）概率度量下退化为 <3 自由度退化

编排者从这三例提炼出那句洞察——「合成数据的独立性验证是同义反复」——并把它升为规则 231号。 三例的共同教训：代数能写出来 ≠ 经验站得住。222 是 gemini 异质否定抓出来的，223 也是， 说明同质工位看不见自己的有效域膨胀，需要异质质询或真实数据来戳。

5. 四种声明膨胀模式（按图索骥）

把规则反过来用，就是四个可直接核对的禁止模式：

有效域膨胀 → L0/L1 验证后声称「已验证」却不标等级
合成确认偏差 → 用合成数据「验证」你预设进合成数据里的属性
定义域=有效域假设 → 声称代数结构在全定义域经验有效，却无 L2+ 证据
等级省略 → 产出里干脆不标认识论等级
本课自身的诚实标注（不豁免自己）：这一课是方法论结晶，讲「如何分级」。 它本身是 L0 级产出——不依赖任何真实数据，从规则 231号和谱系 222/223/230 推导。 它不是「缠论引擎有效」的 L2 主张。把一堂教 L 分级的课说成「已验证缠论」，正是它要教你戳穿的那种膨胀。

6. 对 Phase2 重锚的直接推论

#89/#91/#93/theta_v0 正在向 Origin canonical base 重锚，每个 port 都会报「已重锚 / 已对齐 / 已验证」。 这堂课给你一把尺：重锚的「已验证」是 L 几？有效域多大？

  • #89（RecursiveLevelSystem 重锚）、#91（分类极限 guardrail 重锚）：重锚后若只过 lake build，那是 L0（类型对），不是「缠论递归/分类对」——后者要真实数据。别让「编译通过」冒充「忠实重锚」。
  • theta_v0 contract 重锚：bit-exact 对齐 Lean pipeline 是 L0/L1（验管线一致性，输入若是合成的就是 L1，零增量）；真实数据回测出否定性结果才是 L2。theta_v0 的回测 strat≈0% 必须分层诊断（引擎产不出信号=工程层 / Θ 产信号但不盈利=经验否证），否则混淆 L0 缺陷与 L2 否证。

谱系 230号已经示范：真实数据的否定性结果（「不满足无条件独立性」）是 port 重锚能交出的最有价值的东西——它缩小有效域，不是失败。

带走的锋利问题（拿去质询任何「已重锚/已验证/已对齐」声明）

「你说这个 port 已重锚/已验证——这是 L 几？ 如果证据是 lake build 绿 / bit-exact / 合成数据跑通，那是 L0/L1，信息增量为零——你验的是管线，不是缠论假设，别叫它『已验证』。 你的有效域有多大？你声称覆盖整个定义域（所有走势/所有标的/所有时段），还是只测了一个标的一个时段？ 要声称定义域=有效域，给我与定义域等大的验证。 还有——你这次重锚有没有可能产出否定性结果？如果它在结构上不可能被真实数据否证，那它就是 L0 同义反复，谈不上『验证』。 给不出 L2+ 证据就老实标 L0，把『代数成立』讲成『经验有效』就是 222/223/230 第四次重演。」
