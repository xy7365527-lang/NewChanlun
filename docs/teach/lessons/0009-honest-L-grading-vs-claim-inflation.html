2. 本课的核心范本：ForceConformance.lean 怎么「诚实标级」

这一轮最该让编排者学的一份文件，是 Origin/ForceConformance.lean（#131）。它面对一个真缺口： 「rust 的 MACD 引擎，到底是不是 Lean ForceMeasure 的合法实例？」——这是关于真实数值引擎在真实 K 线上行为的经验命题， 当前没有 L2 数据验证。换句话说，这个缺口现在填不了。关键在于：填不了的时候，它把缺口放在了哪里。

缺口载体sorry / 裸 axiom 伪装成定理structure 字段（MacdForceMeasureWitness）+ Prop 前件（MacdConformsTo）

这正是 0006 课「有效域 ≠ 定义域」的正确应对姿势。#131 把一份产出诚实切成两半：

有效域（真证的）严格小于定义域（声称覆盖的），而且这个差额被显式写出来了，没有被一个 L0 桩堵住假装满了。

3. 为什么「诚实标级」比「假装满级」严格——而不是更弱

直觉上会觉得「承认还差 L2」像是没做完、是退让。恰恰相反。把 L2 缺口显式留成前件，比偷偷用 sorry 或合成数据糊过去更严格，原因有三：

  1. 可质询：前件是显式的，下游能一眼看到「这里依赖一个未验证的 L2 假设」，于是能去验它、能否证它。sorry 把缺口藏起来，下游看不到缺口，误以为满了。
  2. 可否证（0006 课的核心）：#131 写明「若真实 MACD 违反公理则不构成 witness」——这是一个能产出否定性结果的结构。L0 同义反复（任何函数都满足的桩）结构上不可能被真实数据推翻，所以它谈不上「验证」，信息增量为零。
  3. 声明=能力（no-patch-mentality 的「诚实」条）：代码能做什么就声明什么，不多不少。#131 声明的是「L0 结构 + L2 接口假设」，它就真的只有这些，一字不多。这才是 090 号「严格 = 声明与实际一致」。
对照陷阱（0008 课的 total_unique_of_fun 桩）：那个桩是「假装满级」的反面教材——用一个 L0 平凡真理（函数即全且唯一）堵住「古怪线段怎么切」的洞，看起来满了其实空的，且结构上不可否证。 #131 是同一个位置的正解：洞填不了就把洞显式标出来 + 标 L2 + 留否证入口，不拿桩堵。
一句话判据：看到一个「已 formalized」声明，去找它的最弱那一环——那一环是 sorry/裸 axiom/L0 桩（膨胀），还是显式 Prop 前件 + L2 标注（严格）？最弱环的放法，决定整份产出的严格性。

4. 一个不该被「全绿」盖过的细节：闭环不变量是「流通」不是「生成」

#125 管线声明「R=Π−A−W 贯穿入口到出口」，机器证了。但我要你看清它怎么证的——证法是 exact (…).ledger.inv， 即不变量是 LedgerState 的结构字段，每个中间态由 chanlunTransition 自动携带，末态自动携带。这是「流通性」（入口带着、一路不丢），不是「生成性」（用归纳从无到有论证出来）。

这不是缺陷——对一个「保不变量」的闭环，流通性恰好是对的形式，且它是 L0 结构定理（有效域=定义域，0006 课说这类不需 L2）。 但你质询时要能说出它是哪一种：如果有人把「R=Π−A−W 端到端成立」说成「我们推导出账本必然守恒」，那是夸大——它是「我们规定 ledger 携带 inv，并证明每步 transition 不破坏它」。 区分「流通 vs 生成」，是你不被一句「闭环已证」糊弄过去的关键。

5. 三层识破法这一轮的运用（0002 §3，复用模板）

每条「done」我都套了同一个三层。把它内化成肌肉记忆：

  1. 反退化见证：给具体例子证明没退化。#117 给了 eventType1(→A+1) vs eventType3(→A+2) 两个具体事件产不同 ledger；rust 给了买 A+1 ↔ 卖 A−1 的 assert_eq；TW 给了两个 TW 三量相同仅 stage 不同的态。给得出 = 没退化。
  2. 哪一层真理：每个「过了」都标了 L 等级。判据血肉与 rust 触到了 L1（缠论规则真编码 / MACD 真算），TW 与管线闭环是 L0（结构定理，有效域=定义域）。没有一个声明把 L0 说成「已验证」冒充 L2——这是这一轮过闸的根本原因。
  3. 边界条件：什么情况翻？#131 自己写明：真实 MACD 违反公理则 conformance 假设不成立（L2 可否证）。TW：若 stage 字段被删则不同构反例翻——而它没被删。能说出翻的条件 = 真严格。
