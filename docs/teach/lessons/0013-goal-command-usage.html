/goal —— 收敛目标驱动蜂群持续运行

用一个可证伪的收敛目标，让蜂群自主跑到达成、遇矛盾、或资源耗尽——不每步等你确认。这是 624 号「AGENT×持续监控象限无承载者」的唯一修：Lead runtime 层的运行时纪律承载（非 hook/teammate）。

一句话用法

/goal <目标描述>     # 设定收敛目标
/goal                  # 无参：从路线/中断点推导 goal

设定后 Lead 进入 7 步循环，只在三种合法条件停止。

设定时的契约（强制）

  1. 可收敛：单一可验收交付物，不是宏大愿景。宏大 goal 拆里程碑序列，/goal 一次只锚一个里程碑。
  2. 可证伪：每个 acceptance 项必须 falsifiable=true，否则 goal_reducer._validate_acceptance 在 reduce 时 raise ValueError 拒绝（lesson 0011 锋利问题②：验收不可证伪则 goal 永动空转）。
  3. append GOAL_SET 事件到 .chanlun/goals/events.jsonl（字段：goal_id, description, acceptance[], base_head=当前 git HEAD, ts）。
  4. 调 python scripts/ceremony_scan.py → reducer 纯函数 reduce → current_goal projection + ready_workstations。

运行协议（7 步原子循环，不等确认）

评估 → scan → spawn(无依赖全并行) → 监控 → 真封(lake build+cargo) → commit → 回评估

每轮是原子链，不被总结段落/确认信号打断（137号/post-commit-flow）。编排者消息在当前原子轮到达边界后统一回应，不中断（224/225号）。编排者可随时 INTERRUPT 改 goal——Lead 立即收敛到新 goal。

三种合法停止（不存在第四种）

条件动作
goal 达成输出交付物（可证伪产出）+ 格式B（状态快照+排除理由）
真实矛盾/escalate（定义冲突/需价值判断/缺外部数据权限）
资源耗尽报告进度 + 剩余工位 + 精确 blocker

「总结后停下来」「等确认」以问号结尾——都是违规（137号）。

实战：你当前的 goal

goal_id: g-strict-mutex-classification-strategy
acceptance: 0/3 passed
ready_workstations: lean-nest, lean-roles18, rust-role18, rust-signal
sub_goals: 12（Lean 链 6 + rust 链 6，依赖 DAG）

reducer 从 events.jsonl 纯函数重算（同输入同输出，无 IO/时间/随机）。ready = 未 passed ∧ 无 blocker ∧ 所有 blocked_by 已 passed。

恢复（跨 session）

无参 /goal 或 /ceremony：reduce events → 有 active goal 继续；无则从 roadmap/中断点推导。state 降 projection：session/interrupt 文件仅 base_head 匹配时作 hint，不匹配则 reduce 重算（消除状态过时；base_head_stale 标记不匹配）。

事件类型（events.jsonl append-only）

event语义
GOAL_SET设定 goal（acceptance 必须 falsifiable）
DECOMPOSE分解 sub_goals 树（containment 树 + blocked_by DAG）
EVIDENCE工位产出证据
CHECK_PASS某验收项通过
BLOCKED阻塞（定义冲突/缺数据/需编排者裁决）
SUPERSEDEgoal 被替代
CLOSEDgoal 闭合（所有 acceptance CHECK_PASS）

分层防污染（575号）：goal events ≠ genealogy。只有 goal 定义/验收/分解原则语义变更才升格 genealogy（用 goal_event_id 反向引用）。

关键区分

goal ≠ 基因组：CLAUDE.md 是创世静态根（ceremony 内化）；goal 是运行时动态根（蜂群递归展开 = goal reducer 的确定性运行，非 Lead 认知）。Lead 降 bootstrap/IO actuator（033号：Lead=DAG 解释器，不做实质认知）。
