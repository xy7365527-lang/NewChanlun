# Notes

教学偏好与工作笔记的草稿本，非正式产出，供未来备课时参考。

## 教学偏好（2026-08-01 确立）

1. **用人话，禁黑话。** 任何缠论概念、代码标识符可以保留原形，但解释这些词的时候要用大白话，
   不能用黑话解释黑话。
2. **先直觉，后原文。** 每个结论先给一个能一眼看懂的直觉版本，再上原文引用做实锤——顺序不能反，
   原文先上会把人拒之门外。
3. **抽象说法后面必须跟具体后果。** 不能只说"这是个重要的关系"就停在那——每一句抽象论断都要接一句
   "所以……会怎样"或"所以……不会怎样"，落到一个可检验的具体结果上。
4. **他会当场拍裁定。** 上课过程中学习者会直接给出裁定性的判断（不是在问问题，是在下结论）。
   教学材料要能承接这些裁定——记录进对应课的学习记录，并标注拍板的日期与依据的出处，
   不能当场记完就丢。
5. **溯源必须诚实区分"原文明文"与"推断"。** 原文里逐字有的，标"原文"，给出 `文件:行号`；
   靠推理链拼出来但原文没有直接这样说的，必须标"推断"，写清楚推理链用了原文哪几句话作前提。
   两者绝对不能混着不标。
