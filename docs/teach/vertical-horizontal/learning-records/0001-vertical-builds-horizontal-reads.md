# 纵向递归造级别，横向同级别分解读级别——为什么后者不需要延伸/扩展/升级

学习者通过第 0001 课确认：延伸、扩展、升级三个概念全部服务于"造出更高一级"，
同级别分解不造级别、只读级别，所以用不上这三个工具。这条结论直接约束
[issue #787](https://github.com/xy7365527-lang/NewChanlun/issues/787) 架构正本地图里
"同级别分解模块"的边界——它不应该依赖中枢延伸/扩展逻辑，这是后续画模块图、
收拢重复口径的直接依据。

## 关键点

1. **三个概念服务于同一件事。** 延伸问"是不是在长大、够不够格往上走"，扩展问
   "合并后是不是高一级中枢"，升级直接就是往上走——三者本质都是"造更高一级"的判据，
   同级别分解从定义上就不产生这个问题（`038-第38课.md:26`）。

2. **最容易漏看的半句。** `038-第38课.md:26` 说的不是"这个级别不用中枢语境"，而是
   "只有你选的操作级别不定义延伸，它以下的所有级别照常允许中枢延伸"。以下的级别是中间产物，
   要晋升；操作级别本身是最终产物，只管下单。这是本课判定最容易被误读的一处，
   下次讲解或复述这条规则时要特别检查有没有漏掉"以下全允许"这半句。

3. **「横向递归」说法被订正为「横向」。** 横向（同级别分解）切一次就完，不自我调用，
   不是递归；真正递归的只有纵向。"多重"来自沿纵向铺开的 N 个横切位置，
   不是横向自身具有递归性。

4. **"按角色分不按级别分"是推断，不是原文明文。** 推自 `038:26` 的规则形态
   （某级别不延伸、以下延伸、以上不考虑）+ `038:30` 的多级别并行许可（"你可以设定某个量的筹码
   按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作"）。原文对多个操作级别之间
   具体怎么协调是空白，这条"按角色分"的说法是本课在这个空白处给出的推断。
   **将来若查到原文明文讨论这个协调机制，需回来修订本记录、并修订第 0001 课对应段落。**

5. **学习者当场拍的两条裁定**（原话记录，未在课程正文中展开，仅记录于此）：
   - 「重 = 一个操作级别的旁路读法 + 一份筹码，这是多重赋格的关键」——把 ADR 0010 定义的
     「重」三要件（〈标的、操作级别、专属筹码〉）与"旁路读法"这个说法直接挂钩，
     指向"重"就是多重赋格里每一刀的具体承载单位。
   - 「我们多空双开，不存在'避开下跌类型'的问题」——`038-第38课.md:20`
     原文的操作假设是单向持仓（"操作中只选择其中的上涨和盘整类型，而避开所有下跌类型"）；
     学习者指出本系统的假设不同（多空双开），所以这条原文的操作建议不能照搬，
     但这不影响本课讲的"同级别分解不需要延伸/扩展"这条结构性结论——那条结论与做多做空无关。
