第 0001 课

为什么同级别分解不需要中枢延伸 / 扩展这些概念

一句话答案：延伸、扩展、升级这三个概念全是「造级别」用的工具。 同级别分解不造级别，它只是在造好的级别上读。工具没有使用场景，所以收起来。

展开一：那三个概念其实在问同一件事

概念表面在问真正在问
延伸这个中枢震荡了很多段，还算同一个吗？它是不是在长大、够不够格往上走
扩展两个中枢挨着，要不要合成一个大的？合成之后就是高一级的中枢
升级——直接就是往上走

三个都在服务同一件事：造出更高一级的东西。

而同级别分解第一句话就把"上面"封死了。原文：

「至于该级别以上级别，根本不考虑，因为所有走势都按该级别给分解了。」

038-第38课.md:26【正文】

上面没有了 ⟹「要不要往上走」这个问题不存在 ⟹ 回答它的工具自然收起来。

关键分寸：不是「这些规则不适用」（那是豁免）， 是「没有场景需要用到它们」（根本没这回事）。

展开二：那震荡很多段怎么办

原文自己给了答案，而这答案本身就是上面推理的证据：

「如果这5分钟次级别延伸出（延伸成）6段，那么就当成两个30分钟盘整类型的连接」

038-第38课.md:22【正文】

不往上升，就往旁边摊。 6段 = 两组3段 = 两个并排的30分钟盘整。这就是「允许盘整+盘整」在这个视角下成立的原因—— 本来要往上升的东西，被摊平成同一层的两个。

展开三：最容易漏的半句

这是全课最重要的一处。

第38课从来没说"同级别分解不用中枢语境"。它说的是：

「在某级别中，不定义中枢延伸，允许该级别上的盘整+盘整连接；与此同时， 规定该级别以下的所有级别，都允许中枢延伸，不允许盘整+盘整连接； 至于该级别以上级别，根本不考虑，因为所有走势都按该级别给分解了。」

038-第38课.md:26【正文】

只有你选的那一层不用，底下每一层照常用。 为什么？因为底下每层都还在往上造——造到你选的那层为止。

底下那些级别是中间产物，中间产物要晋升； 你选的那一层是最终产物，最终产物只管下单。

连到纵向递归 / 横向 / 同级别分解

在干什么是递归吗用不用延伸/扩展
纵向·往上 造级别：1分钟段→1分钟中枢→5分钟段→5分钟中枢→… 是，每级用下级造 用——全靠它判能不能上一级
纵向·往下（区间套） 在高级别的点上往下钻，找更精确的位置 是，每钻一层同一套判定 用
横向（同级别分解） 读级别：选定一层，把市场切成一段段那层的走势类型 不是——切一次就完 不用——因为不往上走

依赖单向：你确实"不能直接同级别分解"。「30分钟走势类型」这东西得先被造出来， 而造它靠的正是纵向递归和那些延伸/扩展规则。纵向先跑，横向才有东西可读。 反过来不成立：纵向造级别时从不需要知道你打算在哪层操作。

原文钉死：

「对30分钟来说，只要5分钟级别的三段上下上或下上下类型有价格区间的重合就构成中枢」

038-第38课.md:22【正文】

一处订正：「横向递归」这个说法不成立——横向方向上没有递归， 同级别分解是一次性切分，不自我调用。真正递归的只有纵向。 那个"多"来自别处：多重赋格 = 在塔的 N 个不同高度上各横切一刀， N 是沿纵向铺开的。 

纵向递归造出一座塔
   ↓
在塔的 N 层各横切一刀      ← 每一刀 = 一个操作级别 = 一个「重」
   ↓
每一刀分一笔钱、按自己的节奏买卖

多重赋格下"每一级都做同级别分解"怎么办

冲突：三个级别同时操作（5分钟/30分钟/日线）， 30分钟这层在"30分钟视图"里是天花板（不延伸），在"日线视图"里是脚下的中间层（要延伸）。 同一层两套相反规则。

楼的比喻

每一层楼有两样东西——

是什么规则谁需要它
楼板 结构件，撑着上面那层 够不够格撑起上一层 → 延伸/扩展/升级 上面那层楼
走廊 使用面，住这层的人在这儿走动 怎么走、走到哪停 → 同级别分解 住这层的那笔钱

每层都有楼板（楼一直往上盖，本仓的塔爬到 L5 一层没停过）； 不是每层都有人住（只有放了钱的那 N 层才铺走廊）。 于是30分钟这层：楼板照"延伸"的规则造（日线要踩着它）， 走廊照"不延伸"的规则铺（住这层的钱要在这走动）。 互不干扰，因为是同一层楼上的两样不同东西。

换个角度（更实的说法）

延伸 = 把连续震荡的很多段吸收成"一个"中枢
不延伸 = 把同样的东西摊成"好几个"并排的中枢

  • 往上造要"一个"——高一级的走势段需要一整块完整震荡区间当构件；摊成好几个，上面不知道拿哪个。
  • 做买卖要"好几个"——每一个都是一次买卖机会；合成一个就只剩一次机会，中间那些来回全错过。

不是"哪个对"的问题，是"拿去干什么"的问题。 盖楼要整块的，做买卖要分段的。同一堆砖，两种用法。

为什么这不违反"同一判定每级必须一样"

规则只有一条，只是判断依据不是级别——

拿去往上造 → 延伸（合成一个）
拿去下单 → 不延伸（摊成几个）

单操作级别的世界里这两句恰好能翻译成"操作级别那层不延伸、以下全延伸"， 因为那个世界里只有顶层是拿去下单的，"是不是顶层"和"拿去干什么"重合了。 多重赋格打破这个重合。规则没变，是"谁在消费它"变复杂了。

溯源诚实标注：「按角色分而非按级别分」这一条是 推断推断，原文没有这句话； 推自 038:26 的规则形态 + 038:30 的多级别并行许可：

「你可以设定某个量的筹码按某个级别的分解操作，另一个量的筹码按另一个更大级别的分解操作， 这样，就如同开了一个分区卷钱的机械」

038-第38课.md:30【正文】
