## 0. 审计对象边界（有效域辨识，关键）

**审计对象 = `rust/src/theta_v0/`**（canonical 九元组 S_Θ 的实装：`classifier/{signal,recursive_tower,center,divergence,...}` + `strategy/{mod recognize,risk,exec,voice}` + `backtest/runner`）。

**不是审计对象**（但提供谱系先验）：`rust/src/recursive_t/`（rec_engine/rec_driver/anchor/cascade/top-gate）是**另一套架构**（T 引擎 + 区间套），谱系 553/557 的做空 L3 实验跑在它上面，**不是 theta_v0 引擎**。两者引擎不同 ⟹ 553/557 的「做空机制成立但 alpha 有效域≈空集」结论**不能 bit-exact 迁移到 theta_v0**，但提供强先验（见 §2 long-only 维度的谱系引用）。

## 2. 核心结论：Θ v0 离完整缠论最关键的缺口（按对 alpha 影响排序）

### 头号缺口辨识：long-only 是「结构头号」但「alpha 头号」需 L2 复核

**编排者线索「long-only 是否头号缺口」的精确回答：是结构完整性的头号缺口（系统性缺一半方向），但不能未经 L2 直接断言它是 alpha 头号缺口。**

理由（谱系引用，formalization-validity-domain）：

- **结构层（L0 确定）**：long-only 使 Θ v0 在下跌行情只能空仓，系统性放弃做空方向的全部择时机会 + 「盈利来自 beta」嫌疑成立。这是七维度中唯一**系统性砍掉一半定义域**的退化，结构优先级 P0。
- **alpha 层（需 L2，有反向先验）**：谱系 **553**（cascade flip L3 否证=空集）+ **557**（顶层 all_sell 闸门 L3 PARTIAL）在 **recursive_t 引擎** 上实测：做空机制成立（建空、不穿仓、解冻），但**收益是 regime 函数，无单一标的因做空转超 BH**（「机制有效域 ⊋ alpha 有效域≈空集」）。8 标的样本以强牛 regime 为主，做空腿在强牛失血（539 复现）。
- **关键有效域辨识**：553/557 跑在 recursive_t（非 theta_v0），引擎不同 ⟹ 不能 bit-exact 迁移。**但提供强先验**：若 theta_v0 接通做空后用同样的 8 标的强牛样本测，大概率复现「做空机制成立但 alpha≈空集」。**所以补 long-only 的价值首先是结构完整性（消除 beta 嫌疑、让 Θ 全定义域可跑），其 alpha 增量必须 L2 在 theta_v0 自己的引擎上独立验证，不能假设。**

### 缺口聚类（按修复性质）

1. **方向截断类（P0 结构 / alpha 待 L2）**：#1 long-only。fill 引擎物理改造（units 允许负仓 / 双账本多空腿），信号层已就绪，risk 层 `signed_notional` 已预留。**结构补全无条件做（消除声明膨胀：`pi_strict` 声明了 Short 但引擎不兑现）**；alpha 增量 L2 复核。
2. **背驰框架类（P1，同根）**：#2 背驰精度 + #6 走势分解。共同根因=**跳过走势类型分类（τ∈{P,U,D}）直接面积比较**，背驰用「相邻同向段递减」代替缠论「趋势末段 vs 中枢隔开前同向段」。修复=先实装走势类型四分类门控，再在其上区分趋势背驰/盘整背驰。这是**择时信号质量**的核心（假背驰=假买卖点=噪声）。
3. **声部对冲类（P1，结构预留就位）**：#5 多声部。缠论「次级别短差独立反向双开」是主仓持有期的 alpha 来源，v0 单声部放弃这层。`voice_side`/`parent_cap`/`signed_notional` 定义完整、无消费者——补 v1 = 让 recognize 产嵌套子声部决策 + runner 多账本执行。
4. **已基本完整类（P2-P3）**：#3 级别递归、#4 中枢、#7 笔/线段——结构完整或已结算，深度/延伸态局部待核。

## 3. 结果包六要素

**1. 结论**：Θ v0 实装在七个缠论内在语法维度上的完整性分布为：完整/已结算（#3 级别递归、#4 中枢、#7 笔段）、退化（#1 long-only fill 截断、#2 背驰单一面积口径、#5 单声部无对冲、#6 无显式走势类型门控）。头号**结构**缺口=#1 long-only（系统性缺一半方向）；头号**alpha 信号质量**缺口=#2/#6 背驰框架（假背驰=噪声择时）；头号**alpha 来源**缺口=#5 多声部对冲（放弃次级别短差套利）。long-only 是结构头号，但其 alpha 增量被谱系 553/557 反向先验压制，须 L2 在 theta_v0 引擎独立复核。

**2. 定义依据**：
- #1：FULL §七镜像等变 `B_i↔S_i` + strict §5 `long_short_both_open_allowed` 要求多空对称；实装 runner.rs:637 `Sell→close_long` 注释「做空腿待 strategy 订单语义定」+ runner.rs:573 `units 正=多` 坐实 fill 层只持多。
- #2：知识库 §9.1「趋势背驰需 A/B/C 三段，B 段中枢更大」「没有趋势就没有背驰」；实装 divergence.rs:102 `is_divergence = curr_area < prev_area`（单一相邻同向段比较，无三段框架）。
- #5：FULL §八九「同单位数反向双开」「次级别短差不减父仓」；实装 mod.rs:431「v0 classifier 不产嵌套子声部」，recognize 产 depth=0 独立根。
- #6：知识库 §7.1 盘整/趋势二分 + §8 走势分解；实装 signal 路径直接从中枢+段几何提取买卖点，不经 τ∈{P,U,D} 走势类型门控。

**3. 边界条件（结论翻转条件）**：
- 若 theta_v0 接通做空后 L2/L3 在**非强牛 regime 标的样本**（震荡/熊市充足）上测出做空腿正 alpha ⟹ #1 升级为 alpha 头号缺口（当前先验来自强牛为主的 8 标的，是样本偏差敏感的）。
- 若 center.rs 已实装走势类型门控且我未检索到 ⟹ #6 状态从「退化」上修（本审计未深入 center.rs 全部状态机，#4 延伸态/#6 走势类型门控是检索覆盖边界）。
- 若 recognize 路径外另有产嵌套子声部的入口我未发现 ⟹ #5 状态上修（已 grep mod.rs recognize 全路径，depth 恒 0 坐实，边界=classifier 是否有别的 voice 入口）。

**4. 下游推论**：
- v1 实装应**先做 #2/#6 背驰框架**（择时信号质量是其余一切的前提——假买卖点喂给任何方向/声部架构都是噪声），再做 #5 多声部，#1 long-only 结构补全可并行（信号层已就绪）但 alpha 验证须独立 L2。
- #1 的结构补全会触发 runner.rs fill 引擎重写（units 负仓 / 双账本）+ metrics.rs 做空 PnL 口径，影响 backtest 全链。
- 当前 L2 否证（任务 #67 在做）若在 long-only 引擎上得「strat 不盈利」，**不能直接归因 Θ 无 alpha**——须分层：是 long-only 砍一半（#1）+ 假背驰（#2）+ 无声部对冲（#5）的叠加，还是 Θ 走势识别本身无 alpha。本审计为该分层提供缺口清单。

**5. 谱系引用**：
- **553**（cascade flip L3 否证=空集 + 对称双吃两错误形式否证，正确形式未试）：做空在 recursive_t 引擎上「机制成立但 alpha 空集」，且明确「不声称做空目标不可达」（正确形式=每级别精确骑走势切换未试）。
- **557**（顶层 all_sell 闸门 L3 PARTIAL）：做空机制成立（建空/不穿仓/解冻）但收益 regime 函数，「机制有效域 ⊋ alpha 有效域」。
- **003**（线段概念分离 v0/v1）+ **001**（古怪线段/新笔结算）：#7 笔段已 settled。
- **不确定谱系**：theta_v0 引擎自身的做空/背驰精度是否有独立谱系记录——已 grep `.chanlun/genealogy/`，未发现 theta_v0 专属的 long-only/背驰精度结算记录（553/557 属 recursive_t）。#2 背驰精度、#5 多声部、#6 走势类型门控的缺口**疑似尚无 theta_v0 专属谱系**，本审计是首次系统标注。

**6. 影响声明**：本产出新建 `docs/theta-v0-grammar-audit.md`（审计文档，不改任何 .rs/.lean）。诊断结论影响 v1 实装路线（缺口优先级）+ 为任务 #67 的 L2 否证提供分层归因清单。未改动任何代码或定义，是 L0 读码审计。
