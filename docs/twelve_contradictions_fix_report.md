#### 4.4.1 c段缺失：代码链路 + 充要条件（任务「特别关注」）

`[as-is]` 三段叠加（逐字源码，HEAD 06c9739f7e）：

1. `center.rs::find_centers`（line 79）：中枢终结后 `i = last + 1` 继续扫描，**贪心吸收**离开
   前一中枢的连接段为下一中枢首单元（line 31–35 自述此简化）。
2. `trend.rs::segment_into_trends`（line 99）：走势组边界 `ue = starts[gi+1]` = 下一组首中枢
   首单元绝对索引。
3. `divergence.rs::judge_trend_divergence`（line 179–182）：`c_start = 末中枢B末单元+1`；
   `c_start >= t.units.len() → return None`。

**充要条件**（与 `t_engine_profit_destination §2.2g`、session §3.1 独立一致）：
```
无 c 段 ⟺ ue ≤ b_last+1（b_last=末中枢B末单元）
非末组 ue = a_next（下一组首中枢首单元），贪心吸收恒令 a_next = b_last+1
∴ 非末组几乎必然无 c 段（cut_away，非 truly_absent）
```

`[L2]` BTC 4.6M bar：趋势走势 76 个，**59 个无 c 段 = 77.6%**；type1 全塔 165→68→14→3→0，
level3 起 type1_buy=0。（历史说的 58% 是旧诊断，重跑实测 77.6%。）

#### 4.4.2 为什么是定义冲突而非实现错误

离开段 c（末中枢 B 之后创新高那段）在缠论里**双重归属**：
- 它是**上涨趋势的离开段**（第37课趋势背驰 5 条件的核心载体——无 c 则背驰无从判定）；
- 它同时是**通往下一个反向走势的过渡**（type1 卖点后下跌趋势的进入段 a' 从 c 顶起算）。

但 `Unit` 是**不可分原子**（一笔/一个次级别走势），代码必须归属唯一走势。"c 既属上涨离开、
又属下跌进入"在原子归属下不可表达——这是**谱系 540（递归结构同一-差异双重性）/ 537（BSP
信号同一-差异双重性）在 c段层的显现**。

任一修复形态（改 `find_centers` 连接段归属 / 改 `segment_into_trends` 组边界 / 引入重叠切片）
**都改变中枢与走势的边界定义**，进而改变 `encapsulate` 输出与所有级别的递归塔结构。这命中
testing-override 判据「修复需改变定义的边界」→ **定义冲突**。「放松条件4」这条参数路也被
`§2.2g 轴B` 否定为非 bug（下跌不创新低是 539号「翻空有效域⊂非上行」的信号层显现，regime
读数）。

#### 4.4.3 C7（中枢扩展）与实证4（BTC 盘整）的同源性
