# 缠论统一递归算子 T

> 用一个递归算子 T 取代 v3 引擎的手动分层 ladder 架构。
>
> **核心命题**（缠师第65课原话）："如果对数学有点了解的就知道，两者在递归的形式上是一样的，都是 **aₙ=f(aₙ₋₁)**，唯一不同的就是预先给出的 **a₀**。" 本文档把这个 `f` 形式化为算子 T，把 v3 的 bi/segment/move/recL2/… 分层全部还原为 T 的迭代深度。

---

## 0. 文档定位与认识论声明

### 0.1 本文档是什么

本文档是缠师"递归"一词（第65课《再说说分型、笔、线段》）的**形式化**，不是新理论。所有结构来自缠师博文（三级权威链之首，见 `CLAUDE.md`）。文档的任务是：

1. 把"一组单元序列 → 找重叠 → 中枢 → 走势类型 → 成为上级单元 → 回到开始"这个循环，写成一个**单一算子 T**；
2. 证明 v3 引擎的手动分层（bi=1/segment=2/move=3/recL2=4/…）是 T 的**展开式**，每层之间的接缝 bug 是展开导致的，不是缠论本身的；
3. 给出从 v3 迁移到 T 的路径。

### 0.2 认识论等级标注（强制，见 `formalization-validity-domain.md`）

| 内容 | 等级 | 理由 |
|------|------|------|
| 算子 T 的定义（§1）、a₀ 构造（§2）、买卖点涌现（§3） | **L0** | 从缠师定义直接推导，不依赖数据，零信息增量但建立结构 |
| 操作导出（§4）、v3 对照（§5） | **L0/L2 混合** | 结构推导是 L0；引用 v3 回测读数（如 OKLO/BTC 百分比）是 L2 有效域观测 |
| 背驰拓扑化（§6） | **L0 + 开放** | 结构性背驰判据有原文（L0）；度量剩余（MACD 面积）的拓扑替代是开放轴，不声称已验证 |

**关键诚实声明**：本文档定义 T 是 L0 操作——它说明"如果接受缠师定义，则结构必然如此"。它**不**自动证明 T 引擎的回测会跑赢 v3。"T 在架构上消除接缝 bug"是 L0 必然（§5.2 给出反证），"T 引擎的有效域"需要 L2/L3 实测，本文档不预先声明。

### 0.3 骨架 vs 综合层包装（谱系 536，严格性边界）

缠师亲笔给出的是**递归骨架**：`aₙ=f(aₙ₋₁)` 在所有级别形式不变（第65课、第33课）。但"把笔的包含处理（取 max/min 合并）与中枢的重叠（区间求交）统一为同一个 `f`"是**蜂群综合层的包装，缠师原文不直接支持**。

本文档的处理：
- **骨架部分**（有原文）：T 的存在、形式不变性、a₀ 唯一性 —— 标注 `[原文]`；
- **包装部分**（综合层）：T 的统一类型签名、单一实现 —— 标注 `[综合]`，并指明它在哪一层与原文的"包含 ≠ 重叠"区分接合。

这条边界不是修辞，是 §1.3 的硬约束：**T 在 a₀ 内部（分型→笔→线段，用包含处理）和 a₀ 之上（走势类型递归，用重叠）使用的是两套不同的合并算子**，统一的只是"找单元→找结构→升级"的循环外壳。

### 0.4 三轴正交基础（复用已有形式化，`docs/operation_route_exhaustion.md` §6B）

T 不是孤立设计，它挂接到项目已固化的三轴正交框架：

| 轴 | 内容 | T 的位置 |
|----|------|---------|
| **H⁰**（形态学） | 分型/笔/线段/中枢/走势类型 **+ 方向**（方向的唯一源头） | **T 就是 H⁰ 构造轴**（自底向上生成级别结构） |
| **groupoid**（观测） | 信号确认 + 区间套定位（逆极限） | T 的**逆遍历**（区间套，§3.4，自顶向下只读） |
| **H¹**（操作） | D∞ word（仓位流动），消费方向不产生方向 | T 的**导出结构**（§4，操作层读 T 输出） |

**这条挂接决定了全文的架构**：T 属于 H⁰ 构造轴。它生成结构和方向；它**不**包含操作（H¹）、**不**包含背驰确认的度量部分（这部分在 groupoid 轴用 MACD 或拓扑替代）。v3 的病根正是把这三轴塞进一个分层 ladder 里互相干扰（§5）。

## 1. 算子 T 的严格定义

### 1.1 原文依据

第65课（2007-07-20 答疑），缠师对"递归"的唯一系统性论述：

> "请注意中枢的**递归定义的存在性意义**，与分型、笔、线段的**操作性意义**的区别。……如果对数学有点了解的就知道，两者在递归的形式上是一样的，都是 **aₙ=f(aₙ₋₁)**，唯一不同的就是预先给出的 **a₀**，纯理论上的，这 a₀ 就是从每一分笔的成交开始的，但这没有实际可操作性；所以，就要用分型、笔、线段来确认这个 a₀。而站在递归的程序上，**这两者没有本质区别**。" `[原文]`

第63课《替各位理理基本概念》，递归构造级别序列：

> "有了线段，就可以定义1分钟的中枢，然后就是1分钟的走势类型，然后**按照递归的方法，可以逐步定义5分钟、30分钟、日、周、月、季度、年的中枢和走势类型**。" `[原文]`

第64课（2007-07-11 答疑）：

> "笔、段都是针对最低级别说的，**有了最低级别，按中枢和走势类型的递归定义，后面的级别就可以严格推出来了，没必要用什么笔和段**。" `[原文]`

**这三段确立了 T 的存在与作用域**：T 是把"级别 n 的走势类型序列"映射到"级别 n+1 的走势类型序列"的算子；a₀（最低级别）一旦由分型/笔/线段确认，T 就独立接管，笔和段退场。

### 1.2 T 的类型签名 `[综合]`

定义级别 k 的状态为该级别的**走势类型序列**：

```
S_k = [ M_k^1, M_k^2, ..., M_k^m ]      // 级别 k 的走势类型（Move）序列
```

其中每个 `M_k^i` 是一个**完整的**（已终完美的）级别-k 走势类型。算子 T：

```
T : S_k  ↦  S_{k+1}

T(S_k) = [ M_{k+1}^1, M_{k+1}^2, ... ]
```

**递归恒等式**（谱系 540，`docs/emergent_level_direction.md` §1.3）：

```
M_k^i  ≡  Level-(k+1) 的一根"笔"
```

即：级别 k 的一个完整走势类型，就是级别 k+1 的一个构成单元。这不是比喻，是结构定义——`Level-(k+1) 的笔定义域 = Level-k 走势序列`。整个递归塔：

```
        a₀ = S_0    （笔序列，最低级别走势类型的构成单元）
              │ T₀（特殊：用包含处理 + 特征序列，见 §2）
        S_1 = T(a₀)  （Move(1)：最低级别走势类型，必须含中枢）
              │ T
        S_2 = T(S_1) （Move(2) = recL2）
              │ T
        S_3 = T(S_2) （Move(3) = recL3）
              ⋮
        S_k = Tᵏ(...) 直到数据耗尽
```

**形式不变性** `[原文]`：T 对所有 `k ≥ 1` 是同一个算子（第64课"后面的级别就可以严格推出来了"）。这是 v3 必须取代的核心——v3 给每个 k 写了独立的特殊处理，T 只有一份。

> ⚠️ **a₀ 的两套合并算子**（§0.3 边界落地）：`T₀: a₀ → S_1` 不是普通的 T。从笔到线段用**特征序列的包含处理**（第67课），从线段到第一个中枢用**重叠**（第17课）。`T₀` 之后，所有 `T: S_k → S_{k+1}` (k≥1) 才是统一的"重叠→走势类型"循环。统一的是循环外壳，不是合并算子本身。

### 1.3 T 的四个内部步骤

给定输入 `S_k = [M_k^1, ..., M_k^m]`，T 内部执行四步：

#### 步骤 a) 重叠检测 → 中枢 `[原文]`

第17课《走势终完美》中枢递归定义：

> "某级别走势类型中，被**至少三个连续次级别走势类型所重叠**的部分，称为缠中说禅走势中枢。" `[原文]`

形式化（`docs/formal_axioms.md` §3.2 硬公理）：连续三个走势类型 `M_k^i, M_k^{i+1}, M_k^{i+2}`，各自高低点 `(g, d)`：

```
ZD = max(d_i, d_{i+1})            // 中枢下沿（编纂版口径：前两段定核心区间）
ZG = min(g_i, g_{i+1})            // 中枢上沿
Center 成立  ⟺  ZG > ZD          // 三段有公共重叠区间
```

> **口径差异记录**（博文 vs 编纂版，agent 考古确认）：第17课答疑用全三段 `(max(a2,b2,c2), min(a1,b1,c1))`；编纂版第八节用前两段 `ZG=min(g1,g2), ZD=max(d1,d2)`。二者非矛盾——`[ZD,ZG]` 是核心震荡区间，`[DD,GG]` 是含全部波动的外缘区间（`GG=max(g_n), DD=min(d_n)`）。T 实现以编纂版前两段定 `[ZD,ZG]`，全部段定 `[DD,GG]`，两者都保留。

**严格性标注**（谱系 536 + `operation_route_exhaustion.md` §6B.5）：

> **重叠 = 区间交集 ∩**，是**格运算（lattice meet），不是群运算**。中枢是 `k` 级走势重叠**涌现的新对象**——涌现 ≠ 等变。D∞ = ⟨h,τ⟩ 群作用里没有"交集"这个运算。

这一标注是 T 与 v3 的螺旋/D∞ 框架的接缝：T 的步骤 a) 属于 H⁰ 形态学构成（群作用之外），**不能**用 σ-等变（群作用复制）描述。v3 把中枢检测内聚在信号层 `crate::spiral::signal::CenterBook` 是对的；T 继承这个分离。

#### 步骤 b) 走势类型识别 → 盘整/趋势 `[原文]`

第17课：

> "**盘整**：……某完成的走势类型只包含一个缠中说禅走势中枢。"
> "**趋势**：……某完成的走势类型至少包含两个以上**依次同向**的缠中说禅走势中枢。" `[原文]`

形式化：对步骤 a) 产出的中枢序列 `[C^1, C^2, ...]`：

```
count(centers) == 1                    → 盘整（Consolidation）
count(centers) ≥ 2 且依次同向          → 趋势（Trend）
    后中枢 DD > 前中枢 GG               → 上涨趋势
    后中枢 GG < 前中枢 DD               → 下跌趋势
```

（中心定理二，知识库 §6.5；同向判据用外缘区间 GG/DD。）

#### 步骤 c) 走势完美判定 → 走势终结 `[原文]`

第17课走势终完美原理：

> "**基本原理一：任何级别的任何走势类型终要完成。**"
> "**基本原理二：任何级别任何完成的走势类型，必然包含一个以上的缠中说禅走势中枢。**" `[原文]`

走势何时"完成"（终完美）？由**背驰**判定（第24课背驰-买卖点定理）：

> "任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰。" `[原文]`

**这是 T 中唯一的度量剩余**（详见 §6）。结构上：

```
走势类型 M_k 完成  ⟺  M_k 的最后一段相对前一同向段力度衰减（背驰）
                  ⟺  在 M_k 末端产生 k 级别买卖点（type1）
```

背驰判据本身有两个层次：
- **结构性**（第37课趋势背驰5条件，`[原文]`，不依赖 MACD）：A、B 同级别中枢，c 为次级别且至少含对 B 的一个三类买卖点，c 创新高/新低；
- **度量性**（第24课，`[原文]` 但缠师明示是辅助）：MACD 面积 C 段 < A 段。

T 在步骤 c) **只调用结构性判据**；度量判据是 groupoid 轴的精化（§6）。

#### 步骤 d) 封装 → 上级单元 `[原文]`

第17课走势分解定理：

> "**走势分解定理二：任何级别的任何走势类型，都至少由三段以上次级别走势类型构成。**" `[原文]`

封装即递归恒等式的实现：

```
M_{k+1}^j  :=  TrendTypeInstance( [C^1, C^2, ...], 已 confirmed )
            =  把"包含中枢的、已终完美的 k 级走势序列段"封装为一个 k+1 级单元
```

封装后 `M_{k+1}^j` 成为 `S_{k+1}` 的元素，等待下一次 T 迭代。

**双重性约束**（谱系 540/537，硬约束，§0.4）：封装**不可坍缩**。`M_k^i` 同时是：
- **压缩视图**（构造用，第57课"线段就是其次级别走势类型"）：给上级提供方向 + 区间；
- **展开视图**（确认用，第65课"严格说线段不是走势类型，连中枢都谈不上"）：有内部中枢 + 背驰 + 完成判据的完整走势。

T 的封装必须**两个视图都保留**。坍缩到压缩侧 = 丢失"何时完成/什么级别"的构造性必然 = v5 踏空（L3 否证，记忆 `project_signal_layer_duality`）。这是 §5.2 中 v3 一类 bug 的概念根源。

### 1.4 避免循环的归纳定义 `[综合]`

T 的归纳定义必须避免循环论证（`docs/necessity_derivation.md` §3.1）：

```
基础（base case）：a₀ = S_0 由分型/笔/线段确定（§2），不依赖中枢
归纳（step）：S_{k+1} = T(S_k)，其中
    - 中枢是对 S_k 施加的判定算子（步骤 a，不依赖走势类型分类）
    - 走势类型实例是对"含中枢的 S_k 段"的分类（步骤 b，依赖中枢，不依赖更高级别）
    - 故无循环：S_{k+1} 只依赖 S_k，不依赖 S_{k+1} 自身或 S_{k+2}
```

**不可跳级不变量 I1**（`formal_axioms.md`）：

```
Center[k] 的组件必须来自 S_{k-1}（即 Move[k-1]），禁止 Move[k-2] 直接参与。
```

这是 v3 "F 入场域 ≠ 操作域"病的反面——T 强制每一级只消费**直接次级别**，不允许跨级引用（§5.2 反证 bug-b）。

### 1.5 T 的不动点与终止条件

T 的迭代不是无限的，有两个终止方向：

#### 向上终止（生成方向，small→large）

```
r*(t) = sup{ k ≥ 1 : 存在 t 时刻或之前已形成的完整 Move(k) }
```

`r*(t)` 是**涌现上界**（`emergent_level_direction.md` §1.4），随时间单调不减（走势形成是不可撤销的历史事件，append-only）。T 在每个时刻只能迭代到 `r*(t)`——再高的级别尚未有足够的次级别走势构成，T 没有输入。**这取代 v3 的 MAX_LADDER=11 硬上界**：T 的上界是数据涌现的，不是常量。

#### 向下终止（a₀ 基底，large→small）

第17课，递归不能无穷下降：

> "这里有一个递归的问题，就是这次级别不能无限下去……'分'不是无限的……**在实际之中，对最后不能分解的级别，其缠中说禅走势中枢就不能用'至少三个连续次级别走势类型所重叠'定义，而定义为至少三个该级别单位K线重叠部分。**" `[原文]`

a₀ 是 T 的 base case（§2）。在 a₀，中枢定义从"三个次级别走势类型重叠"退化为"三个单位 K 线重叠"。

#### T 的"不动点"语义

T 没有传统意义的代数不动点（`T(S) = S`）。它的**收敛对象是走势终完美**：每个 `M_k^i` 在终完美时"封闭"成上级单元，这个封闭是局部不动点——一旦 confirmed，该走势不再被 T 修改（append-only）。全局上，T 的迭代在 `r*(t)` 处暂停，等待新数据把 `r*` 推高。

```
局部不动点：M_k^i.confirmed = true  ⟹  M_k^i 冻结（H⁰ append-only）
全局暂停点：当前所有级别迭代到 r*(t)，等待 t+1 的新 bar
```

## 2. 初始条件 a₀

### 2.1 为什么递归需要起点

第65课明确 a₀ 是递归的唯一经验输入。但 a₀ **不可观测**（"从每一分笔的成交开始……没有实际可操作性"）。因此需要一个**几何脚手架**把 K 线变成第一级单元。第63课：

> "如果我们首先确立了显微镜的倍数……那么就可以开始定义……分型、笔、线段等等。" `[原文]`

a₀ 的存在论根据是第17课的"分不是无限的"——递归必须有 base case，否则无穷下降。

### 2.2 a₀ = 三层几何脚手架（分型 → 笔 → 线段）

a₀ 不在 T 的递归内（T 处理 `k≥1`），它是 T 的**输入构造器** `T₀`。三层（知识库 §3–§5）：

#### 层 1：分型（第62课）`[原文]`

> "第二K线高点是相邻三K线高点中最高的，而低点也是相邻三K线低点中最高的，本ID给一个定义叫**顶分型**……" `[原文]`

**前置**：K 线包含处理（知识库 §2，先左后右，遵守结合律不遵守传递律）。

#### 层 2：笔（第62/65课 + 新笔定义）`[原文]`

> "两个相邻的顶和底之间构成一笔……一定是相邻的顶和底。" `[原文]`
> "从分型到笔，必须是一顶一底……所有的图形，都可以唯一地分解为上下交替的笔的连接。" `[原文]`

**新笔定义**（《忽闻台风可休市》，编纂版缺失）：顶分型最高 K 线与底分型最低 K 线之间（不含），至少 3 根 K 线。新笔条件比旧笔宽松，根治古怪线段。

#### 层 3：线段（第65/67课，特征序列法）`[原文]`

> "线段分解定理：线段被破坏，当且仅当至少被有重叠部分的连续三笔的其中一笔破坏……**线段破坏的充要条件，就是被另一个线段破坏。**" `[原文]`（第65课）
> "出现特征序列的分型，是线段结束的前提条件……把前面'线段破坏的充要条件就是被另一个线段破坏'**精确化**了。" `[原文]`（第67课）

特征序列法（知识库 §5.3–5.5）：向上线段笔序列 `S1X1S2X2…SnXn`，特征序列取 `X1X2…Xn`；元素当 K 线做包含处理得标准特征序列；其上找分型 → 新线段形成则旧线段终结。

**硬约束**（第78课）：`一个线段，两端的一顶一底，顶肯定要高于底`。

> **概念分离警示**（谱系 003，知识库 §5.8）：线段有两个口径——口径 A（三笔重叠，参考实现）vs 口径 B（特征序列，主口径），真实数据差异 4.72 倍。T₀ 用**口径 B**（特征序列），口径 A 降级为参考。

### 2.3 a₀ 一旦确立，笔/段退场

第64课（关键，T 与 a₀ 的分界）：

> "线段只针对最低级别，把次级别当线段，只能看成是比喻，**严格的说法，线段只存在最低级别之下**。" `[原文]`

形式化：

```
T₀:  K线  →[包含处理]→ 分型  →[一顶一底]→ 笔  →[特征序列]→ 线段  →[重叠×3]→ Move(1) = S_1
T:   S_k  →[重叠×3 → 走势类型 → 封装]→ S_{k+1}   (k ≥ 1)

分界：T₀ 用"包含处理 + 特征序列"（笔/段几何）；T 用"重叠"（走势类型递归）。
      a₀ = S_1 之后，笔和段永久退场（第64课）。
```

**这直接修复 v3 的 bug-a**（segment 层没有 nf 信号，§5.2）：v3 把 segment 当成一个独立 ladder 层（=2）并试图给它发信号，但缠师说线段"只存在最低级别之下"——segment 是 `T₀` 的中间产物，**不应该**是 T 的一个递归级别。T 架构里 segment 根本不在 `S_k (k≥1)` 序列中，自然不需要 nf 信号。

### 2.4 从 K 线数据构造 a₀（算法）`[综合]`

```
输入：K线序列 [bar_0, bar_1, ...]
1. 包含处理：合并有包含关系的相邻 K 线（先左后右，§2.1）→ 非包含 K 线序列
2. 分型识别：在非包含序列上标记所有顶/底分型（§3）
3. 笔划分：相邻顶底 + 新笔条件（中间≥3根 K 线）→ 笔序列（一顶一底交替）
4. 线段划分：特征序列法（§5.5）→ 线段序列，附"顶高于底"硬约束校验
5. 第一个中枢：连续三段线段重叠（ZG>ZD）→ Move(1) 的第一个中枢
   → 输出 S_1（最低级别走势类型序列）
```

工程映射：v3 的 ladder 0（bar）/1（bi）/2（segment）就是 `T₀` 的三层；它们**不是** T 的递归级别，而是 a₀ 构造器的内部步骤。T 引擎应把它们封装在 `a0_scaffold` 模块内，对外只暴露 `S_1`。

### 2.5 a₀ 基底层的判据退化（类中枢 / 类背驰）

第64课正文：

> "站在严格意义上，**线段以下是没有中枢的，所以说是类中枢**……而后的回拉，其实刚好构成一个奔走型的上下上结构……这其实也就构成另一个微型类中枢。" `[原文]`

第65课答疑（区间套在基底层）：

> "用区间套的方法，在定位线段之下的精确买卖点时，实际上用到的就是**类背驰的力度比较**。" `[原文]`

形式化约束：在 a₀ 基底层（线段及以下），没有真中枢/真背驰，只有"类中枢/类背驰"。T 的步骤 c)（背驰判定）在基底层退化为类背驰的力度比较。这与项目记忆 `project_ph_settle_usage_boundary`（PH settle 是候选层必要条件，非操作充分确认，confirmed 需 MACD 背驰）的边界吻合。

## 3. 买卖点作为 T 的不变量

### 3.1 买卖点 = 走势类型切换临界点（不是独立信号）

核心命题：**买卖点不是独立定义的信号，是 T 迭代中走势类型切换的临界点。** 原文依据，第24课背驰-买卖点定理：

> "任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰。" `[原文]`

由于背驰 = T 步骤 c)（走势完成判定），买卖点就是 T 步骤 c) 的输出。第17课趋势转折定律：

> "任何级别的上涨转折都是由某级别的第一类卖点构成的；任何的下跌转折都是由某级别的第一类买点构成的。" `[原文]`

形式化：

```
M_k 在末端终完美（背驰）  ⟹  在该点产生 k 级别 type1 买卖点
                           ⟹  S_k 中 M_k 封闭，新的反向 M_k' 开始
买卖点 = T 迭代中 S_k 序列里"一个走势类型结束、下一个开始"的临界 bar
```

**这就是"不变量"的含义**：买卖点不需要单独的检测器，它是 T 迭代过程的**伴随产物**——每次 T 在某级别封闭一个走势类型（步骤 d 封装的瞬间），就在该级别的该 bar 标记一个买卖点。v3 给每个 ladder 层单独算 BSP（`current_buysellpoints`，O(N²) 性能瓶颈，记忆 `project_bi_zhongshu_on2_two_walls`）；T 把 BSP 作为迭代不变量，迭代到哪里 BSP 就涌现到哪里。

### 3.2 三类买卖点从 T 迭代涌现 `[原文]`

三类买卖点（编纂版第三章第四节，对称给出买点）：

#### 第一类买点 = 趋势的背驰终结

> "第一类买点：某级别下跌趋势中，一个次级别走势类型向下跌破最后一个走势中枢后形成的**背驰点**。" `[原文]`

T 涌现：`M_k` 是下跌趋势（步骤 b 判定 ≥2 同向中枢向下），其最后一个次级别走势 `M_{k-1}^last` 跌破最后中枢后背驰（步骤 c）→ type1 买点。**它是 T 在级别 k 的步骤 c) 直接输出。**

#### 第二类买点 = 次级别第一类买点

第17课买卖点定律一：

> "任何级别的第二类买卖点都由次级别相应走势的第一类买点构成。" `[原文]`

T 涌现：type1 买点后，次级别（k−1）上涨结束再次下跌，该次级别走势的结束点。**它是级别 k−1 的 type1 买点在级别 k 的投影**——即 `type2_k = type1_{k-1}`（递归定义，T 自然产生，无需独立检测）。

#### 第三类买点 = 中枢离开 + 回抽不破

> "第三类买点：某级别上涨趋势中，一个次级别走势类型向上离开走势中枢，然后以一个次级别走势类型回抽，其低点不跌破走势中枢上边缘 ZG 的走势中枢终结点。" `[原文]`

T 涌现：`M_k` 离开中枢 `C` 向上（步骤 a 中枢已封闭），次级别回抽低点 > `C.ZG` → type3 买点。**它是 T 步骤 a)（中枢终结）+ 一次次级别回抽的合取。**

### 3.3 买卖点完备性（归约到第一类）`[原文]`

第37课：

> "所有买卖点，归根结底都是第一类买卖点，只是级别不同而已。" `[原文]`

编纂版完备性定理：

> "买卖点的完备性定理：市场必然产生赢利的买卖点，只有第一、二、三类。" `[原文]`

**对 T 架构的意义**：T 只需在每级别产生 type1（步骤 c 的背驰输出）。type2 = 次级别 type1 的投影（定律一），type3 = 中枢终结 + 回抽（步骤 a 派生）。所以 **T 的买卖点不变量本质上只有一种**——type1，其余两类是它在递归塔里的不同投影。这取代 v3 的 N3 链（"全三类 BSP 消费"，`unified_necessity.rs:429`）的手动分类：在 T 里三类是同一不变量的递归视图，不是三个独立分支。

### 3.4 区间套 = T 的逆极限（自顶向下，对偶遍历）

区间套是 T 的**对偶**——T 自底向上生成（small→large），区间套自顶向下定位（large→small）。第17课的认识论约束（关键）：

> "**不能从低级别看起，分析图形，要从高看到低。低级别走势的意义，是在高级别意义的彰显后才能彰显。**" `[原文]`

编纂版区间套定义：

> "区间套：根据背驰段从高级别向低级别逐级寻找背驰点（即买卖点）的方法。"
> "精确大转折点寻找程序定理：某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。" `[原文]`

第37课给出区间套的递归本质（`a+A+b+B+c` 自相似嵌套）：

> "可以继续套用 a+A+b+B+c 的形式进行次级别分析确定 c 中内部结构里次级别趋势的背驰问题，**形成类似区间套的状态**。" `[原文]`

**形式化为逆极限**（`operation_route_exhaustion.md` §6B.4）：

```
区间套 = lim←( 信号_k )  =  ⋂_k { 级别 k 的 type1 买卖点区间 }

从 k = r*(t)（最高涌现级别）向下：
    I_{r*} ⊇ I_{r*-1} ⊇ ... ⊇ I_1     // 区间逐层收缩（必要条件链）
    精确买卖点 = ⋂ I_k                 // 逆极限 = 全局截面（覆盖空间，§0.4）
```

理论依据（编纂版）：

> "低级别背驰是本级别背驰的**必要条件而非充分条件**……我们说某个级别的走势背驰了，那么必须确定它以下所有级别都转折了。" `[原文]`

**T 架构落地**：区间套**不是 T 的步骤**，是对 T 输出的**只读逆遍历**（谱系 011："定级别 = 对递归构造结果的自顶向下只读遍历，不修改 RecursiveStack"）。T 构造塔（修改状态），区间套读塔（只读，逆极限收敛）。二者对偶但分离。

**这直接修复 v3 的概念混淆**：v3 把 source（区间套链顶，自顶向下）和 sink/recover（操作，自底向上流动）塞在同一个 `operate.rs::step()` 里互相干扰（§5.2 bug-b/d）。T 把"区间套定位"（groupoid 轴只读）和"操作"（H¹ 轴）彻底分开。

## 4. 操作作为 T 的导出结构

### 4.1 T 只产结构，不管仓位

**严格边界**：T 是 H⁰ 构造轴，输出 `{级别 r*, 中枢, 走势类型, 方向, 买卖点}`。**仓位管理不在 T 内部。** 这是三轴正交（§0.4）的直接推论——H⁰ 产生方向，H¹（操作）消费方向但不产生方向（`operation_route_exhaustion.md` §6B）。

谱系 543 的约束：

> "操作 = path（D∞ 的 word），不是硬编码循环模式（CyclePhase 四步相位机）。引擎只有 h/τ 两原子，循环是涌现序列。核心仓是涌现（每次 τ 只下沉 f=1/λ）。"

### 4.2 操作层读 T 的输出（H¹ 读 H⁰/groupoid）`[综合]`

操作层是一个独立算子 `Op`，读 T 的输出 + 区间套定位：

```
Op : ( T 输出, 区间套定位 )  ↦  原子操作 ∈ {h, τ, e}

每 bar 每级别 k：
    读 T 的方向 dir(M_k) 和买卖点
    读区间套链顶 source（自顶向下定位）
    若 type1 买点 confirmed（区间套收敛）→ τ 升回 / h⁺ 建仓
    若 type1 卖点 confirmed         → σ⁻¹∘τ 下沉 / 平仓
    否则 → e（仓位不变）
```

`Op` 用 D∞ = ⟨h, τ⟩ 群（`operation_route_exhaustion.md` §1.1）：`h` = 角向推进（走过买卖点），`τ` = 手性翻转（反手，仅 φ=0 手性缝）。**操作是 word（path），净效果是群元素，不变内容是 1-cycle（H¹）。**

### 4.3 四步跨级别循环的导出 `[原文 + 综合]`

缠师的"四步操作"（建仓→减仓→回补→清仓的跨级别循环）**不是预设的状态机**，是 `Op` 读 T 输出涌现的序列（谱系 543）。导出：

```
T 输出 M_k 上涨趋势确立  →  Op: h⁺ 在 source 层建核心仓（H⁰ 持有）
T 输出 M_{k-1} 次级别卖点  →  Op: σ⁻¹∘τ 下沉 1/λ 配额做次级别短差（E sink）
T 输出 M_{k-1} 次级别买点  →  Op: σ∘τ 升回（D recover）
T 输出 M_k 趋势顶背驰     →  Op: τ 清仓（C，仓位归零或反手）
```

四步是 `Op` 在不同级别买卖点上的响应序列，**循环外壳来自 T 的递归结构**（每级别都有买卖点 → 每级别都可操作），不是硬编码。缠论第26课"恒仓"操作（1/3 配额）映射为 `MOBILE_FRAC = 1/λ`。

**关键修正**（谱系 544）：四步循环的"相邻级别方向相反"**不是 L0 不变量，是 regime 依赖观测量**——上涨初期各级别都做多（相邻同向合法），某级别出卖点后才翻空。`Op` 的 sink/recover 方向相容是适用域条件，不是全局公理。**这正是 v3 bug-d（recover 方向检查被 core_ladder 拦）的根源**——v3 把 regime 观测量硬编码成了不变量（§5.2）。

### 4.4 H⁰ 核心仓 / H¹ 机动仓映射到 T 的迭代深度

`docs/emergent_level_direction.md` §5 + `orbit_enumeration` §4 的两层闭合：

```
H⁰（核心仓）：T 高迭代深度的输出（高级别走势方向，r* 附近）
              → 核心仓跟随最高涌现级别的走势方向，长期持有
              → 是涌现的（每次 τ 只下沉 1/λ，高层多数留存即核心仓）

H¹（机动仓）：T 低迭代深度的输出（次级别买卖点）
              → 机动仓在次级别买卖点做短差，σ-不变内容 1 维（cd_ℚ=1）
              → 1/λ 配额参与次级别震荡
```

**形式化**（两层闭合 H⁰ ⊕ H¹）：

```
总操作空间 = H⁰（高级别方向固持） ⊕ H¹（次级别循环短差）
无 H²（无第三种操作，operation_route_exhaustion §6B.3）
```

**核心仓是涌现，不是显式拆分**（谱系 543）——v3 不应硬拆 `core_units/mobile_units`，而应让核心仓从"高层稀疏下沉的多数留存"中涌现。T 架构继承：核心仓 = T 高迭代深度方向的留存，机动仓 = T 低迭代深度买卖点的 1/λ 流动。

> ⚠️ **σ-ascend 的处置**（v3 bug-c 的根源，§5.2）：v3 用 σ-ascend 把核心仓"推高"到更高 ladder（relabel），导致核心仓落到 T50 标度律 `f(k)∝λ⁻ᵏ` 的稀疏端，回补信号指数级变罕见。T 架构里核心仓**不需要被推高**——它本来就是 `r*` 附近高迭代深度的涌现产物，`r*` 随数据自然上升，不需要人为 relabel。σ-ascend 是 v3 手动模拟"核心仓涌现"的补丁，在 T 里不存在。

### 5.2 v3 的 4 类 bug 在 T 架构中为什么不可能

这是本文档的**核心 L0 论证**：4 类 bug 全部是"手动展开递归"导致的接缝，T（不展开）从架构上消除它们。

#### bug-a：segment 层没有 nf 信号 → T 中不可能

**v3 病灶**（`signal.rs:209` / `morphology.rs:55`）：`for k in PENDING_LO(3)..MAX_LADDER`，循环不覆盖 segment(k=2)，故 `nf_sell[2]/nf_buy[2]` 恒 None。

**T 反证**：segment 是 `T₀`（a₀ 构造器，§2.3）的中间产物，**根本不在** `S_k (k≥1)` 递归序列中。第64课"线段只存在最低级别之下"——segment 不是 T 的级别，不应该有走势信号（nf）。v3 的病是把 `T₀` 的内部步骤（segment）错误地提升为 T 的一个递归级别（ladder=2），于是必须给它发信号，但它结构上不该有。**T 里 a₀ 之下的笔/段被封装在 `a0_scaffold` 内，对 T 不可见 → 不存在"segment 层缺 nf"的问题。**

#### bug-b：F 入场域(FIRST_BSP=2) ≠ sink/recover 操作域(PENDING_LO=3) → T 中不可能

**v3 病灶**（`operate.rs:407` 入场层 source 可达 2；`operate.rs:331` sink 循环下界 3）：仓位落点下界 = FIRST_BSP(2)，操作触发下界 = PENDING_LO(3)，两个下界故意不同，导致"停泊层 k−1 ≠ 触发层 k"的未结算概念空位（escalation `2026-06-17-2049`）。

**T 反证**：T 强制不可跳级不变量 I1（§1.4）——每级别只消费直接次级别，操作和定位都锚定**同一个**迭代深度 k。`Op`（§4.2）读 T 的级别 k 输出做级别 k 的操作，不存在"入场用 source(2)、操作用 PENDING_LO(3)"的双下界。**根源**：v3 的双下界来自把"区间套定位"（source，自顶向下）和"操作流动"（sink，自底向上）混在 `operate.rs` 一个函数里。T 把二者分到 groupoid 轴（区间套只读）和 H¹ 轴（`Op`），各自锚定自己的级别，没有跨域下界对齐问题。这与 unn 的 N7（`prove_n7_spawn_self_level` 强制 `trigger_ladder == voice_ladder`）同构——**触发 = 自层**。

#### bug-c：σ-ascend 推高核心仓 → 回补信号稀疏 → T 中不可能

**v3 病灶**（`operate.rs:238-244` σ-ascend relabel + T50 标度律 `f(k)∝λ⁻ᵏ`）：核心仓被 relabel 推到高 ladder，落到标度律稀疏端，高层 nf 信号指数级罕见。

**T 反证**（§4.4）：T 架构里核心仓是 `r*` 附近高迭代深度的**自然涌现**（高层稀疏下沉的多数留存），不需要被"推高"。`r*` 随数据 append-only 上升，核心仓跟随，但这是结构涌现不是 relabel。σ-ascend 是 v3 手动模拟"核心仓涌现"的补丁——T 直接涌现核心仓，**没有 ascend 这个操作，也就没有"推高导致稀疏"**。

#### bug-d：recover 方向检查在 core_ladder 层被拦 → T 中不可能

**v3 病灶**（`cycle.rs:81-84`）：recover 期望子层方向 = `flip(parent_dir)`，但当 `sub == core_ladder` 时子层是核心仓（多头）≠ 期望（空头），`d_sub != expected_child` 直接 `return false`。

**T 反证**（§4.3 + 谱系 544）：v3 把"相邻级别方向相反"硬编码成 recover 的**不变量**（`cycle.rs:81`）。但谱系 544 已结算：手性交替是 **regime 依赖观测量，不是 L0 不变量**——上涨初期各级别都做多（相邻同向合法）。`Op`（T 的操作层）把方向相容作为**适用域条件**（regime 函数），不是硬约束。当 regime 是单边上涨时，相邻级别可以同向，recover 不应该用"必须反向"拦截。**根源**：v3 在 bug-b 的双下界基础上，让 sink 把空头下沉到 core_ladder 附近，再用一个错误的不变量（方向必反）拦 recover。T 没有双下界（bug-b 已消除），也不把 regime 观测量当不变量（544），双重消除 bug-d。

#### 4 类 bug 的统一诊断

```
4 类 bug 全部 = 手动展开递归 T 成分层 ladder 的接缝：
  bug-a：把 T₀ 内部步骤（segment）误当 T 级别 → 缺信号
  bug-b：把 groupoid（定位）和 H¹（操作）混在一层 → 双下界不对齐
  bug-c：手动 relabel 模拟核心仓涌现 → 推到标度律稀疏端
  bug-d：把 regime 观测量（544）当不变量 → 方向检查误拦

T 不展开递归（单一算子，形式不变），三轴分离（H⁰/groupoid/H¹），
regime 观测量不当不变量（544）→ 四类接缝在架构上消失。
```

> **诚实声明**（L0 vs L2）：以上是 **L0 架构论证**——T 在结构上不可能产生这 4 类接缝 bug。它**不**声称 T 引擎回测必然跑赢 v3。回测有效域是 regime 函数（项目反复确认，记忆 `project_nrf_v4_strict_accounting` 等），需 L2/L3 实测。事实上 v3 的 revert（`cbdad96702`：把"提升下界到 PENDING_LO"的修复 revert，因 OKLO +306%→−47.5%）正说明"修 bug"和"回测收益"是正交的——bug-b 的某个修法改善了架构一致性却恶化了某 regime 的收益。**T 消除 bug 是架构净化，收益是独立的有效域问题。**

## 6. 背驰的拓扑化可能性

### 6.1 背驰是 T 中唯一的度量剩余

T 的步骤 a)（重叠）、b)（中枢计数）、d)（封装）全是**纯结构**（区间交集、计数、递归恒等式），完全拓扑化。唯一的度量判据在步骤 c)——**走势完美判定（背驰）**。问题：背驰能否也拓扑化，让 T 成为纯结构算子？

### 6.2 缠师明示：MACD 是辅助，结构是本质 `[原文]`

第17课答疑（最直接）：

> "**用均线或MACD看背驰都是辅助性的，都不是最重要的**……难道没有均线、没有MACD就判断不了背驰？显然不是。那只是辅助。" `[原文]`

第24课（MACD 的有效域 + 结构性 100% 的承诺）：

> "由于 MACD 本身的局限性，要精确地判断背驰与盘整背驰，**还是要从中枢本身出发**……光用 MACD 辅助判断……准确率也应该在 90% 以上。**而配合上中枢，那是 100% 绝对的，因为这可以用纯数学的推理逻辑地证明。**" `[原文]`

第64课（结构性背驰存在的明证）：

> "**可以很严格的数学方法去确认，但太复杂，实用起来很麻烦**……MACD 只是辅助，但用好了，98% 的问题都解决了。" `[原文]`

**结论**：缠师明确背驰有一个**结构性（纯数学）判据**，MACD 只是它的实用近似。这意味着背驰**部分可拓扑化**——结构性的部分。

### 6.3 结构性背驰判据（第37课，已拓扑化的部分）`[原文]`

第37课趋势背驰5条件（石猴总结，缠师认可）：

> "1. A、B 是同级别的中枢；2. c 必然是次级别的……c 至少包含对 B 的一个第三类买卖点；3. b 在级别上不能大于 c；4. 上涨 c 一定要创出新高，下跌一定要创出新低；5. c 至少包含两个次级别中枢。" `[原文]`

这 5 条**全是结构判据**（中枢级别比较、买卖点存在性、新高新低、中枢计数），**不含 MACD 面积**。它们可以直接编码进 T：

```
背驰_结构(M_k) ⟺
    M_k = a+A+b+B+c 形式的趋势（A、B 同级别中枢）
    ∧ c 是次级别走势，含对 B 的一个 type3 买卖点
    ∧ level(b) ≤ level(c)
    ∧ c 创新高/新低
    ∧ c 至少含 2 个次级别中枢
```

**这部分是拓扑必然**——T 步骤 c) 用结构判据 `背驰_结构`，可完全拓扑化。

### 6.4 拓扑替代候选（度量剩余的处置）

但第37课5条件**不区分"c 段力度强弱"**——它判定"是否构成背驰候选"（结构形态），不判定"力度是否真的衰减"（度量强弱）。后者是 MACD 的领地。候选拓扑替代：

| 候选 | 机制 | 拓扑化程度 | 评估 |
|------|------|-----------|------|
| **PH persistence**（项目已有） | 中枢生灭的 persistence（max-min 闭式） | 拓扑（H₀ persistence） | 已验证是**候选层必要条件，非操作充分确认**（记忆 `project_ph_settle_usage_boundary`）——拓扑判 candidate，MACD 判 confirmed |
| **中枢嵌套深度比较** | c 段内部递归深度 vs a 段（区间套自相似，§3.4） | 拓扑（逆极限收缩率） | 第37课"c 内部套用 a+A+b+B+c"=区间套力度比较；缠师第65课"区间套用的就是类背驰的力度比较" `[原文]` → **这是结构化的力度** |
| **结构复杂度**（子中枢计数） | c 段子中枢数 vs a 段 | 拓扑（计数） | 弱代理，未验证 |
| **MACD 面积**（缠师原判据） | 红绿柱面积 C<A | 度量（不可拓扑化） | 缠师承认是辅助，90-98% 准确 |

**关键洞察**（第65课 + 第37课）：缠师的**区间套力度比较**本身就是一种"结构化的背驰"——"在定位线段之下的精确买卖点时，实际上用到的就是类背驰的力度比较"。区间套的逆极限收缩率（高级别区间向低级别收窄的速度）是一个**拓扑量**，可以替代相当一部分 MACD 力度判断。

### 6.5 划线：拓扑必然 vs 度量剩余

```
┌─────────────────────── 拓扑必然（T 内部，纯结构）───────────────────────┐
│ 背驰的"结构形态"：第37课5条件                                            │
│   - a+A+b+B+c 趋势形态（中枢级别 + 计数）                                │
│   - c 创新高/新低、含 type3、子中枢≥2                                    │
│ 背驰的"结构化力度"：区间套逆极限收缩率（第37/65课，类背驰力度比较）       │
│   - PH persistence 判 candidate 层                                       │
│   - 嵌套深度收缩率 判结构力度衰减                                        │
└──────────────────────────────────────────────────────────────────────┘
                              ↓ 划线在这里 ↓
┌─────────────────────── 度量剩余（groupoid 轴精化，T 外部）─────────────┐
│ 背驰的"精确力度确认"：MACD 面积 C<A                                      │
│   - 缠师承认是辅助（90-98%），配合中枢才 100%                            │
│   - 不可纯拓扑化（依赖价格×成交量的连续度量）                            │
│   - 作为 confirmed 层的最后一道精化，在 groupoid 轴，不在 T 步骤 c)      │
└──────────────────────────────────────────────────────────────────────┘
```

**划线原则**（L0 论证 + 项目记忆）：

1. **T 步骤 c) 只用拓扑必然部分**（结构形态 + 结构化力度）→ 产出 **candidate 买卖点**（走势完成的结构条件满足）。
2. **MACD 度量剩余下放到 groupoid 轴**（区间套定位时的最后精化）→ candidate 升 **confirmed**。
3. 这与项目已结晶的边界一致：`project_ph_settle_usage_boundary`（PH settle = candidate 必要条件，confirmed 需 MACD 背驰）、`project_divergence_gate_entry_exit_falsified`（MACD 背驰门控进出场在某 regime 否证——度量判据有有效域）。

**为什么必须划这条线而不全拓扑化**（严格性，不掩盖矛盾）：

缠师说"配合中枢 100% 可纯数学证明"，但**也**说结构性判据"太复杂，实用起来很麻烦，还要自己去编软件"（第64课）。这意味着：**结构性 100% 判据在理论上存在，但缠师本人未给出完整形式**——他给的是 MACD 近似。

> **诚实划线**：本文档**不声称**已经把背驰完全拓扑化。它声称：
> - 背驰的**结构形态**（第37课5条件）= L0 拓扑必然，已可编码；
> - 背驰的**结构化力度**（区间套收缩率 + PH persistence）= L0 拓扑候选，**部分**替代 MACD，但替代率未经 L2/L3 验证；
> - 背驰的**精确力度**（MACD 面积）= 度量剩余，缠师的实用判据，划在 T 外部的 groupoid 轴。
>
> 完全拓扑化（消除 MACD）是**开放轴**，不是已结算结论。缠师承诺的"纯数学 100% 判据"存在性是 `[原文]`，但其完整形式是项目的未解问题（属 `formalization-validity-domain` 的有效域边界——拓扑替代的有效域 ⊊ MACD 的定义域，需 L2/L3 实测划定）。

### 6.6 实装策略裁决：纯结构优先的渐进路线（编排者 2026-06-18）

**裁决**：T 引擎 step c)（走势完美判定）采用**纯结构优先**的实装序——

```
执行序（不是 §6.5 三选项的静态划线，而是动态收敛）：
  阶段 1：step c) 零 MACD 依赖，只用纯结构性背驰
          （第37课5条件 + 区间套收缩率 + PH persistence）
          → 跑通 T 全流程，验证"拓扑能走多远"
  阶段 2：与 v3 的 nf 信号 L2 对照，定位纯结构在哪些 regime/标的漏判
          → 否定性结果 = 拓扑替代率不足的具体位置
  阶段 3：仅在阶段 2 暴露的有效域缺口处，加 MACD 作 groupoid 轴 confirmed 精化
          → MACD 补的是"已知的、被定位的"缺口，不是先验保险
```

**理由**：

1. **划线位置不变，执行序明确**——§6.5 的结构/度量分界不变（结构必然在 T 内，MACD 度量剩余在 groupoid 轴外）。新增的是**先后**：先把纯拓扑路线跑到底，再决定 MACD 补在哪。
2. **契合 `formalization-validity-domain`**：否定性结果（纯拓扑在某 regime 漏判的**具体位置**）比确认性结果（MACD 兜底"看起来都对"）信息增量更高——它缩小有效域边界。先加 MACD 兜底会**掩盖**纯拓扑的真实有效域，使"拓扑能走多远"这个问题不可证伪。
3. **MACD 推迟而非删除**：缠师承诺"配合中枢 100% 纯数学可证"（第24课），但完整形式未给出。纯结构先行正是逼近这个未解判据——若纯结构在某处不足，缺口本身就是"缠师未给出的那部分纯数学判据"的定位器，届时再决定用 MACD 近似还是继续找结构判据。

**认识论标注**：阶段1纯结构跑通 = **L1**（管线正确性，零信息增量但验证 step c) 无 bug）；阶段2与 v3 nf 对照 = **L2**（真实数据，可否证）；阶段3 纯拓扑 vs MACD 替代率 = **L2/L3**（有效域读数）。

**对 §3.1 不变量的影响**：买卖点作为 T 的迭代不变量，在阶段 1 是 **candidate 级**（结构条件满足）；阶段 3 加 MACD 后某些 candidate 升 **confirmed**。阶段 1-2 期间，T 输出的买卖点全部标注 `candidate`，不冒充 confirmed——这与谱系 537（candidate/confirmed 双重性）一致，不坍缩。

## 7. 结果包（六要素）

### 1. 结论

设计了统一递归算子 **T**，取代 v3 的手动分层 ladder 架构。T 的核心：
- **单一算子**，形式不变（第65课 `aₙ=f(aₙ₋₁)`），把 v3 的 bi/segment/move/recL2/… 还原为 T 的迭代深度；
- **四步内部循环**：重叠（格运算→中枢）→ 走势类型（中枢计数）→ 走势完美（结构性背驰）→ 封装（递归恒等式 `Move(k)≡Level-(k+1) 的笔`）；
- **a₀ 用独立构造器 T₀**（分型→笔→线段，§2），不在 T 递归内（第64课"线段只存在最低级别之下"）；
- **买卖点 = T 的迭代不变量**（走势类型切换临界点，三类归约到 type1，§3）；
- **区间套 = T 的逆极限**（自顶向下只读逆遍历，§3.4）；
- **操作 = T 的导出结构**（独立 `Op` 算子读 T 输出，H¹ 轴，§4）；
- **背驰部分拓扑化**：结构形态 + 结构化力度 = 拓扑必然（T 内部）；MACD 精确力度 = 度量剩余（groupoid 轴，T 外部，§6）。

文档：`docs/unified_recursive_operator_T.md`。

### 2. 定义依据

每个结构均引缠师原文原句（带课号）：递归核心（第65课 `aₙ=f(aₙ₋₁)`）、中枢递归定义（第17课）、走势分解/盘整趋势/走势终完美（第17课）、背驰-买卖点定理与 MACD 辅助性（第24课）、趋势背驰5条件（第37课）、线段特征序列（第65/67课）、新笔（《忽闻台风可休市》）、区间套（编纂版+第37课自相似）、类中枢/类背驰（第64课）。复用项目已固化形式化语言：三轴正交 H⁰/groupoid/H¹、递归恒等式（谱系540）、D∞=⟨h,τ⟩、逆极限=区间套。

### 3. 边界条件（结论何时翻转）

- 若**回测有效域**被误当架构验收：T 消除 4 类 bug 是 **L0 架构必然**，但 T 引擎跑赢 v3 是 **L2 有效域问题**（regime 函数）——v3 的 revert `cbdad96702`（修 bug-b 却恶化 OKLO 收益）证明"修 bug"与"收益"正交。若有人用"T 回测更高"论证 T 正确，结论翻转为无效论证。
- 若**背驰完全拓扑化被声称已完成**：本文档只声称结构形态（第37课5条件）= L0 必然，结构化力度（区间套收缩率/PH）= L0 候选未验证替代率，MACD 度量剩余仍在 T 外部。若 PH/收缩率的 L2/L3 实测显示替代率不足，"背驰部分拓扑化"的可用边界收窄。
- 若**骨架 vs 包装的边界被抹除**（谱系536）：T 的"统一"仅指循环外壳；`T₀`（包含处理）与 `T`（重叠）是两套合并算子。若把二者强行统一为单一 `f`，越出原文支持范围。

### 4. 下游推论
