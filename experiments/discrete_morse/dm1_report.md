# DM1: 单纯复形构造 + 同调计算 + 离散 Morse 函数

## 实验概要

从 `.chanlun/block-topology/relations.jsonl`（6672 条关系记录）构造抽象单纯复形，
计算 Z₂ 系数下的同调群（Betti 数），在复形上构造离散 Morse 函数（Coreduction 贪心算法），
找到临界集并验证 Morse 不等式。

认识论等级：**L0→L1**（代数构造 + 管线正确性验证）

## 单纯复形构造

| 维度 | 名称 | 数量 | 构造方法 |
|------|------|------|---------|
| 0 | 顶点（区块） | 2182 | relations.jsonl 中所有 from/to 哈希去重 |
| 1 | 边（关系） | 4432 | from→to 对作为无向边去重，排除自环 |
| 2 | 三角形 | 2906 | 三角形闭包：A-B, B-C, A-C 同时存在 |

- 复形维度：2
- 总单纯形数：9520
- 关系类型：全部为 `depends_on`

## Betti 数（Z₂ 系数）

| Betti 数 | 值 | 拓扑含义 |
|----------|-----|---------|
| β₀ | 4 | 4 个连通分量（已用 BFS 独立验证） |
| β₁ | 607 | 607 个独立环路（1-维洞） |
| β₂ | 1259 | 1259 个空腔（2-维洞） |
| χ (Euler) | 656 | = V - E + T = 2182 - 4432 + 2906 |

### 拓扑特征解读

- **β₀ = 4**：谱系 DAG 有 4 个连通分量。主分量包含绝大多数区块，
  另有 3 个较小的孤立子图。
- **β₁ = 607**：大量独立环路，表明依赖关系中存在高度的循环结构。
  这在谱系图中对应"多条路径汇聚到同一区块"的模式——
  一个区块可以通过不同的依赖链到达另一个区块。
- **β₂ = 1259**：大量空腔。β₂ > β₁ 表明三角形闭包非常密集，
  许多三角形的边界互相抵消形成 2-环路。这反映谱系图的局部聚类性很强。

### 计算方法

- ∂₁（2182 x 4432 矩阵）：Z₂ 高斯消元，rank(∂₁) = 2178
- ∂₂（4432 x 2906 矩阵）：Z₂ 高斯消元，rank(∂₂) = 1647
- 已验证 ∂₁∂₂ = 0（边界算子组合为零——链复形条件）

## 离散 Morse 函数

算法：**Coreduction**（Mrozek 2009 标准贪心）

| 指标 | 值 |
|------|-----|
| 配对数 | 1580 |
| 临界 0-单形 m₀ | 853 |
| 临界 1-单形 m₁ | 2852 |
| 临界 2-单形 m₂ | 2655 |
| 简化率 | 33.2%（3160/9520 单纯形被配对消除） |

### Morse 不等式验证

| 不等式 | 成立 | 数值 |
|--------|------|------|
| m₀ >= β₀ | True | 853 >= 4 |
| m₁ >= β₁ | True | 2852 >= 607 |
| m₂ >= β₂ | True | 2655 >= 1259 |
| m₀-m₁ <= β₀-β₁ | True | -1999 <= -603 |
| χ_Morse = χ_Betti | True | 656 = 656 |

**全部通过。**

### Morse 效率分析

Morse 效率 = 1 - (m_k / β_k 的接近程度)。理想的 Morse 函数使 m_k = β_k。

- m₀/β₀ = 853/4 = 213.2x（0-维效率低——大量冗余临界顶点）
- m₁/β₁ = 2852/607 = 4.7x（1-维效率中等）
- m₂/β₂ = 2655/1259 = 2.1x（2-维效率较好）

Coreduction 在高聚类系数的图上效率受限：三角形密集导致余面数普遍 > 1，
使得大量单纯形无法配对（alpha > 1 → 不进入队列）。
更优化的算法（如 Perseus 的迭代优化或随机化 Morse 函数）可能得到更少的临界单纯形。

## 边界条件

- 以下条件下结论会翻转：
  - 如果 relations.jsonl 包含非 `depends_on` 类型的关系且需要不同维度的建模
  - 如果使用有向单纯复形（当前忽略了方向信息）
  - 如果使用 Z 系数而非 Z₂ 系数（可能得到不同的 Betti 数，特别是存在扭转时）
- Coreduction 是启发式算法，不保证最优 Morse 函数
