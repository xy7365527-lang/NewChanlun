## 要回答的问题

「无门」行为——本级账与次级别账各自只查自己的前提、**无互斥门**——在四个典型场景下是否始终：动作归属唯一、账目清晰、没有任何情形看起来"不对"。

- S1 中枢形成期（第 1-3 段，无已确认中枢）：只有次级别账动？
- S2 中枢在场震荡：两前提同时满足 → 两账同时开火、各记各账？
- S3 高抛后出三类买点：本级于三类买点处回补（收手规则），次级别账不受影响？
- S4 本级一类卖点：本级全平 + 父死子从（命通道独立于账）？

教义出处：#272 裁定 + ADR 0001 修正案一/补充一 + 「门的必要性」讨论（结论：门不必要且有害，每本账只查自己前提）。

## 运行

```bash
python3 prototypes/no-gate-two-books/sim.py
```
