# Q-R3-2 修正请求：单纯塌缩 ≠ 商映射/折叠

## 编排者的否定（数学上精确）

R3 Q-R3-2 的核心声称被否定：**"折叠 = 梯度流（via Forman 3.3）"不成立**。

### 根本区分

| 操作 | 单纯塌缩 (collapse) | 商映射/折叠 (quotient) |
|------|---------------------|----------------------|
| 定义 | 移除自由面对 (σ^(p), τ^(p+1)) | 识别多个顶点为一个 |
| 拓扑效果 | **保持同伦型**——β₁ 不变 | **改变拓扑**——β₁ 可增可减 |
| Forman 3.3 | ✅ 适用 | ❌ **不适用** |
| 在架构中的角色 | 不对应任何操作 | 这就是"折叠" |

Forman 1998 Theorem 3.3 说的是：单纯塌缩等价于离散梯度向量。但塌缩保持同伦型——β₁ 不变。如果折叠只是塌缩，它就不会产生亏格，总纲的基础不成立。

**折叠的核心特征恰好是：它制造拓扑变化。** 这是商映射，不是塌缩。两者在拓扑学中是根本不同的操作。

### Gemini 的错误

过度泛化——看到"折叠"和"塌缩"在日常语言中相近，就把 Forman 关于塌缩的定理应用到了商映射上。

### 修正后的 R3 影响

|------|------|
| Q-R3-2 | **需要重做** |
| Q-R3-3 (否定=Cerf) | 不受影响——不依赖 Q-R3-2 |

| Q-R3-5 (训练可行) | 最受影响——预设了连续可微函数的存在 |
| Q-R3-6 (Ricci 流) | 类比层面，不依赖 Q-R3-2 |

## 重新定位的 Q-R3-2

核心问题仍然开放：**商映射操作是否有 Morse 理论的类似物？**

新方向：**在什么条件下，商映射可以被分解为"塌缩序列 + 拓扑手术"？**

- 塌缩部分：可以用 Forman（保持同伦型，梯度流）
- 手术部分：需要别的工具（柄附着 handle attachment？Dehn 手术？）
- 如果这个分解存在，它就是折叠的 Morse 理论——但它不是 Forman 3.3 本身

### 具体问题

1. 给定商映射 π: K → K/∼，是否存在 K 的一个子复形 L 使得：
   - K 可以塌缩到 L（Forman 适用），且
   - L 通过拓扑手术（不是塌缩）变为 K/∼

2. 如果存在，手术步骤改变了什么拓扑量？β₁ 的变化完全由手术步骤决定（塌缩步骤不改变 β₁）。

3. 手术步骤是否有 Cerf 理论的描述？（和 Q-R3-3 的否定-Cerf 对应连接？）

4. 如果不存在这样的分解（商映射不能分解为塌缩+手术），那商映射需要什么全新的数学框架？

### 额外修正：Q11 Kingman 定理前提

β₁(t)/t → λ 的 Kingman 次可加遍历定理要求过程**平稳遍历**（stationary ergodic）。

编排者指出：谱系写入过程不太可能平稳——早期建立基础框架（大量 depends_on，少量 negates），后期做高层否定和折叠（模式不同）。如果平稳性不成立，λ 不一定存在。

但编排者建议：即使理论上不严格，在真实 306 条数据上画 β₁(t)/t 看看趋势是有价值的——如果大致稳定则近似平稳，如果明显变化则变化模式本身是信息（思考密度递减 = 概念空间饱和？）。
