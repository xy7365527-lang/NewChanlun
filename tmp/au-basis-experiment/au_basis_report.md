# Au 边内部结构最小检验：现货/期货 basis 在 2020-04 同步压缩前后的行为

## 1. 结论

**判决：LEADING_SIGNAL——但形态不是"前导扩张"，而是"前导振荡→cluster期间回归"。**

Au 边的内部结构（basis = GC=F - GLD*10）在 K4 同步压缩 cluster（2020-04-22 至 2020-05-05）之前经历了剧烈的双向偏离：

| 时间 | Basis | Z-score | 事件 |
|------|-------|---------|------|
| 2020-03-16 | 69.5 | **-2.42** | Basis 急剧压缩（现货相对期货跌更快） |
| 2020-03-18 | 70.3 | **-2.00** | 持续压缩 |
| 2020-03-24 | 126.2 | **+2.16** | Basis 急剧反转扩张（期货相对现货涨更快） |
| 2020-04-09 | 149.3 | **+2.45** | **Basis 绝对峰值**（期货升水达历史极端） |
| 2020-04-13 | 130.7 | +1.33 | 开始回落 |
| **2020-04-22** | **111.4** | **+0.11** | **Cluster 第1天——basis 已回归正常** |
| 2020-04-29 | 86.1 | -1.36 | Cluster 期间最低 basis |
| **2020-05-05** | **94.2** | **-0.80** | **Cluster 最后1天** |

关键发现：

1. **Basis 的极端偏离发生在 cluster 之前，而非期间。** Basis z-score 在 cluster 期间最大 |z| = 1.36，远低于 2σ 阈值。而在 cluster 前 9 个交易日（2020-04-09），basis 达到峰值 149.3（z = +2.45）。
2. **Basis 的前导模式是双向的。** 先是 3月中旬的负向极端（z = -2.42），然后 3月底-4月初的正向极端（z = +2.45）。振荡幅度从正常的 ~95-105 区间扩大到 69.5-149.3。
3. **Cluster 的到来伴随着 basis 的回归而非发散。** 当 K4 的 Mahalanobis 距离和 eff.dim 同时走极端时，Au 边的内部结构反而在收敛。

## 2. 定义依据

- **Basis 定义**：GC=F（COMEX 黄金期货连续合约）减去 GLD*10（SPDR Gold Trust ETF 价格乘以10，近似 1 盎司现货金价）
- **Z-score 定义**：(basis - rolling_20d_mean) / rolling_20d_std
- **同步压缩 cluster 定义**（329号结算）：Mahalanobis 极端 + 四节点 eff.dim 同时 < 5th percentile 的天数，2020-04-22 至 2020-05-05 共 6 天
- **前导信号阈值**：|z| > 2.0 且在 cluster 开始日（2020-04-22）之前至少 5 个交易日出现
- **数据来源**：yfinance（GC=F 和 GLD 日线收盘价），2019-07-01 至 2020-12-31

## 3. 边界条件（何时结论会翻转）

1. **如果 rolling window 不是 20d**。测试了单一窗口（20d）。更短的窗口（如 5d 或 10d）可能使 z-score 更敏感但更嘈杂；更长的窗口（如 60d）可能吸收掉 3 月中旬的极端值。结论的定性方向（"前导振荡→cluster 期间回归"）对窗口长度不敏感——basis 绝对值的时间序列不受窗口选择影响。
2. **如果用伦敦定盘价替代 GLD 作为现货代理**。GLD 有管理费（~0.40%/年）导致长期偏低，且 GLD 的 NAV 可能在极端流动性事件中与现货偏离。但 2020-03/04 的 basis 偏离幅度（70→150，约 80 点振幅）远大于 GLD tracking error（通常 < 1 点）。
3. **如果 K4 同步压缩的定义变更**。如果 cluster 被重新定义为包含 3 月中旬的天数，则"前导"和"同步"的边界会改变。但 329号结算明确界定了 cluster 的范围。
4. **如果 basis 的正确定义不是 GC=F - GLD*10**。GC=F 是近月合约的连续拼接，换月时会有跳跃。2020-04 附近 GC=F 从 April 合约滚动到 June 合约，这个换月可能贡献了 4/09 峰值的一部分。需要检查合约滚动日期——**这是一个已识别但未验证的风险**。

## 4. 下游推论

### 4.1 K4 框架层面

如果 basis 的前导振荡是真实信号（而非合约滚动伪影），则 K4 的"原子 ratio"假设有一个精确的软化方向：**每条边不是一个标量，而是一个带内部结构的区间**。Basis = 边的"宽度"——正常时宽度稳定，坍缩前宽度先扩张再回缩。

这不否定 K4 的拓扑结构（四节点+六边），但否定了边的原子性假设。log(price ratio) 不足以捕获边在坍缩前的行为——需要至少一个额外自由度（basis 或其等价物）。

### 4.2 实验设计层面

Cluster 期间 basis z-score 最大 |z| = 1.36，不到 2σ。这意味着：

- **如果只看 cluster 期间**，basis 是"正常的"——不会被任何阈值方法检测到
- **信息在 cluster 之前就已经释放了**。等到 Mahalanobis 和 eff.dim 同时告警时，Au 边的内部紧张已经释放完毕

这与物理学中的"前兆滑移"（precursory slip）类似：大地震之前的小震群。Au basis 的双向振荡是 K4 同步坍缩的前兆。

### 4.3 其他 cluster 的行为

| Cluster | 日期 | Basis z-score | 行为 |
|---------|------|--------------|------|
| Cluster 2 | 2020-06-11 | +0.94 | basis 正常；但前一天（06-10）z = **-3.24**（极端压缩） |
| Cluster 3 | 2020-11-09 | **-2.67** | basis 当天极端压缩（与 Cluster 1 期间模式相反） |

Cluster 2 和 Cluster 3 的行为与 Cluster 1 不一致：

- Cluster 2：前一天有极端 basis 压缩，cluster 当天回归——与 Cluster 1 的模式相似（前导偏离→cluster 期间回归）
- Cluster 3：cluster 当天本身就是 basis 极端日——basis 压缩与同步坍缩同步发生

结论：basis 的前导模式不是确定性的。Cluster 1 有明确的前导振荡，Cluster 2 有弱前导，Cluster 3 是同步的。**单事件 L2 验证无法区分"前导是规律"和"前导是巧合"。**

## 5. 谱系引用

- **329号**：K4 同步压缩 cluster 的定义和天数列表（Mahalanobis 极端 + 四节点 eff.dim 同时 < 5th percentile）
- **K4 框架**（OQ4 系列）：四节点六边拓扑，边 = log(price ratio) 的原子假设
- **230号**：直积退化——形式化工具的有效域可能小于定义域（basis 检验是对"边的原子性"这一形式化假设的有效域探查）

### 合约滚动风险标注

2020-04-09（basis 峰值日）需要特别检查：GC=F 近月合约从 April（GCJ0）滚动到 June（GCM0）的日期通常在 April 合约到期前几天。COMEX 黄金 April 2020 合约的最后交易日是 2020-04-28。如果 yfinance 的 GC=F 在 4 月初就开始使用 June 合约价格，则 4/09 的峰值可能部分反映了 June-April 的 contango 而非真实的 spot-futures basis。

**这不改变定性结论**（3 月中旬的双向振荡不受合约滚动影响），但 4/09 峰值的**绝对幅度**可能被高估。
