### 核心原则

**不测而测**。扬弃概率论框架（缠师原始的 30%x30%x40%），替代为完全分类的二值判断。全程不预测，结构完备则操作，不完备则不动。

扬弃的理由：三个独立程序（缠论走势、比价关系、基本面）在本体论中已统一为资本流在不同尺度上的读数（254号开放问题3）。不独立的事件乘概率没有意义。概率论框架的前提（三者信息不重叠）不成立。

**默认前提：满仓满融**。与降成本方法结构性配合：杠杆仓位使每次短差绝对收益翻倍，回收目标不变（自有资金），降成本所需短差次数减半。不是操盘者的偶然选择，是方法论的天然加速器。

### 一、选股 + 定级别（纠缠的，非线性）

选股和定级别纠缠在一起。选股过程中已经在考察级别——没有可操作买卖点的标的被剔除，而买卖点的有无与级别相关。

**第一步：二值筛选。** 在层 1 和层 2 的完全分类上扫描：

- 缠论筛：该标的在哪个级别上有完备的买卖点结构？没有则排除。有则同时确定操作级别
- 比价筛：层 1 的 K4 配置是否支持该标的所在矩阵？不支持则排除
- 基本面筛：操盘者外部判断，不入语法，具有平等否决权
- 三者不是三道独立筛，是同一个资本流在不同尺度上的读数。比价通过走势读取，基本面被走势和比价延迟地书写

**第二步：区间套收敛排序。** 满仓满融只能选一个标的。在通过二值筛选的标的中，选区间套收敛最紧的。

收敛路径：K4 配置（E/Au/R）-> 板块（指数/ETF）-> 个股。收敛可以停在任何一层——哪层结构最完备就在哪层操作。板块 ETF 本身可以是操作标的，不必须下沉到个股。

收敛紧度 = 嵌套层数 x 级别大小 x 各层一致性。大级别收敛优于小级别收敛。这是结构内生的排序，不是操盘者外部选择。

选股输出 = 区间套收敛最紧的那一个标的 + 该标的的操作级别。

### 二、三阶段操作

**阶段 1 建仓：** 买点出现，一次性满仓满融进入。不分批。

**阶段 2 降成本（多层嵌套短差）：** 主级别持仓不动，次级别做短差——卖点减仓，买点加回。每次短差同时降低持仓成本和融资利息。次级别内部可用次次级别做更小短差，形成递归嵌套。每层短差动用比例 <= 上层的 n%。终止条件：累计回收 >= 初始自有资金。

**阶段 3 退出本金：** 抽出原始自有资金。剩余仓位 = 市值 - 融资负债 = 纯利润。后续操作只在利润仓位上。

### 三、小转大

不可事前预测，事后由结构确认：次级别走势超出次级别结构范围，更大级别结构成立。

满仓满融下已经是最大仓位，不需要加仓。小转大是纯粹的好消息。处理：旧级别短差停止，在新主级别定义下的次级别出现后，在新级别上继续短差降成本。

小转大产生赋格：旧循环的利润底仓 + 新级别上的新降成本循环，同时运行在同一标的上。

### 四、止损

止损是结构内生的：买点的定义包含否定条件，买点结构失效 = 止损点。满融下止损必须绝对果断——没有等待空间。

**大转小的处理：**
- 买点结构被破坏 -> 立即止损
- 买点结构未被破坏，走势尚未展开 -> 等待

### 五、不换仓原则

持仓期间不因外部机会换仓。理由双重：

1. **不测而测原则**：退出只根据当前标的自身结构信号。"B 出现更好机会"不是 A 的结构事件，用 B 的结构决定 A 的操作违反了只分类当前标的状态的原则
2. **降成本不可逆性**：已积累的成本优势是沉没收益，换仓归零全部降成本进度。卖出后以新价格重新建仓，成本可能更高

错过其他机会是满仓满融的结构性代价，不通过违反操作纪律来弥补。等 A 给出退出信号后重新扫描。

**合法性审计**：编排者-Claude 推导中进行了审计——卖出 A（结构未失效）进入 B（更好机会），违反缠论"操作只根据当前标的自身结构"的原则。审计结论：不合法。

### 六、免费仓位管理

退出本金后，免费仓位的处理 = 不测而测。当时结构是什么就怎么处理。主级别卖点出现就平仓。如果已经小转大，看新的主级别结构。全程二值分类。

### 七、赋格的定义

满仓满融下赋格 = 同一个满仓仓位上、不同级别的短差操作的嵌套 + 小转大后新旧循环并存。不是多个独立仓位的并行操作，是单一仓位上的多层嵌套。

### 不入语法的外部要素（仅两项）

- 基本面判断（否决权）
- 仓位比例 n%（每层短差动用比例）

### 边界条件（267号原文）

- 满仓满融前提下，等待有利息成本。结构判断的二值性不变，但操盘者需意识到等待在消耗资金
- 选股的区间套收敛假设市场中同时存在多个候选标的。如果只有一个通过二值筛选，收敛排序退化为单一选择
- 仓位比例 n% 的合理范围：过大（>50%）导致次级别操作风险过高，过小（<5%）导致降成本极慢。编排者实盘中使用两层赋格
- 本文档不覆盖层0监控的操作化——那是系统级别的框架有效性监控，不是个股操作

## 编排者建议的攻击方向

### 攻击方向 1：融资额度退化
连续止损后融资额度缩水，"满仓满融"的前提退化——此时方法论的哪些环节失效？

具体场景：
- 初始自有资金 100万，融资 100万 = 总仓位 200万
- 买点进入后，结构失效，止损，损失 20万（10%）
- 新自有资金 80万，融资额度可能下降（券商动态调整）
- 假设融资额度仍然 1:1，则总仓位 160万——满融仍成立但绝对值缩水
- 连续 3次止损后：自有资金 51.2万，总仓位 ~100万
- "降成本所需短差次数减半"的加速效应是否仍然成立？
- 降成本的终止条件"回收 >= 初始自有资金"——这里的"初始"是第几次入场的自有资金？

### 攻击方向 2：区间套收敛紧度接近时的选择稳定性
两个标的收敛紧度非常接近时，选择是否稳定？微小变化是否导致频繁切换？

具体场景：
- 标的A：5层收敛，中级别（30min），各层一致性90%
- 标的B：4层收敛，大级别（日线），各层一致性95%
- 收敛紧度 = 嵌套层数 x 级别大小 x 各层一致性
- A的紧度：5 x 中级别权重 x 0.9
- B的紧度：4 x 大级别权重 x 0.95
- 大级别权重 vs 嵌套层数，谁权重更大？文档未量化
- 如果两者计算后紧度相近，新bar出现可能导致A略优→B略优→A略优的频繁切换
- 但持仓后不换仓原则防止了切换——问题是：如果持有A，B出现更紧收敛，这是否构成"等到A给出退出信号"的理由被加速寻找？

### 攻击方向 3：不换仓原则的极端代价
持有标的进入长期横盘，融资利息持续消耗，同时明确的大级别机会出现在其他标的上

具体场景：
- 持有某ETF，月度级别买点进入，正常短差降成本进行中
- 突然出现黑天鹅（但该ETF结构未失效，买点未被破坏），ETF进入震荡
- 此时次级别短差机会减少，降成本速度急剧下降
- 融资利息：假设年化8%，则每月0.67%。100万融资每月吃掉6700元
- 同期，另一个标的出现年级别大底的买点（历史性机会）
- 不换仓原则禁止换仓——但"等到A结构失效"可能需要数月甚至半年
- 极端情况：A结构永远不"正式失效"（永远不破买点低点），但一直横盘
- 融资利息累积超过降成本收益，方法论整体进入负收益状态
- 这种"结构未失效但经济上已经失效"的场景，267号如何处理？

### 攻击方向 4：降成本终止条件的可达性
不同市场环境下，"累计回收 >= 初始自有资金"是否可达？

具体场景：
- **震荡市**：次级别短差机会充足，降成本速度快。看似最有利，但震荡市频繁震荡可能导致频繁假卖点，降成本实际效率可能不高
- **单边上涨市**：主级别持仓盈利，但次级别做空方向的卖点出现少（主趋势向上不易出现有效卖点）。降成本靠的是次级别短差，单边市反而减少次级别操作机会
- **快速反转市**：进入后市场快速反转，买点结构迅速被破坏，来不及执行任何短差就需要止损。终止条件从未被触发
- **核心问题**：在不同市场环境下，降成本终止条件的期望可达时间是多少？方法论是否假设了某种市场环境的暗前提？

### 攻击方向 5（其他可能盲区供Gemini扩展）
- 次级别短差的交易摩擦成本（手续费、印花税）是否被纳入降成本计算？
- "满仓满融"在中国A股市场的监管约束：融资比例、集中度限制、T+1制度与短差的兼容性
- 区间套收敛排序是每日/每周重新计算的吗？重新计算的频率如何不违反不换仓原则？
- 次级别短差的仓位 n% 在连续成功后是否应该调整？方法论固定了n还是允许动态？
