# R2 联合研究上下文：语义拓扑——连续-离散界面的数学形式化

## R1 已确立的基础

R1 对离散侧（K 内部代数结构）已完整形式化：

- **K_active = Mapper Nerve**（形式证明，L0）
  - 全量图 K_full → 删除被否定节点 K_surv → 版本链商映射 K_active
  - K_active 等价于 Mapper Nerve，Nerve 定理（Borsuk 1948）适用
- **β₁ 差值分解**：β₁(K_full) - β₁(K_active) = "被否定杀死的环" + "版本链内部的环"
- **Zigzag 持续同调**替代 Vineyard（因为 K_active(t) 是非单调序列）
  - 文献：Carlsson & de Silva 2010, Foundations of Computational Mathematics
- **Poset Morse 理论**替代 Forman Morse（因为 K 是有向图，Forman 1998 假设无效）
  - 文献：Chari 2000, Minian 2012
- **连续-离散界面**通过 Vietoris-Rips 复形连接：
  - LLM 嵌入空间 S 中的区块通过 VR_ε 形成离散复形
  - ε 越过 d(v_i, v_j) 时拓扑跳变，满足 Morse 引理

## 系统架构

### 连续空间 S

LLM 嵌入空间。区块 v_i 对应 S 中的向量（通过 LLM encoder）。S 是高维连续空间，距离编码语义相关性。S 中没有类型、没有否定、没有方向。

### 离散空间 K

区块拓扑（K_full / K_surv / K_active）。类型化有向边：depends_on, negates, modifies, supersedes, references。K 中没有距离——关系要么存在要么不存在。

### 两个映射

**φ: S → K（铭写）**
- LLM 输出文本 → 编排者将文本编码为区块+类型化关系 → 写入 K_full
- φ 是有损压缩：S 中距离近的区块可能在 K 中没有显式边（遗漏）；S 中距离远的区块可能在 K 中有强类型边（编排者添加）
- φ 不保距，不保序，不保拓扑——由编排者判断驱动的非系统映射
- 等价关系：K ≈ VR_{ε*}(S) + 编排者添加的边 - 编排者遗漏的边

**ψ: K → S（反馈）**
- 拓扑信息（局部关系、tree/critical 标记、共享概念标签、β₁ 变化）注入 LLM 上下文
- LLM 被这些信息 conditioning → 输出改变 → 铭写为新的 K 结构
- ψ 不是数学函数——通过自然语言传递信息，LLM 决定如何使用

**核心数学问题**：ψ∘φ 的迭代动力学——多轮穿越后系统拓扑演化的可描述特征。

## 六个具体问题（Q7-Q12）

### Q7（φ 的保真度度量）

给定区块的嵌入向量集合，构造 VR 持久条形码 PD(S)。给定 relations.jsonl，构造 K 的持久条形码 PD(K)。定义 φ 的信息损失为 PD(S) 和 PD(K) 之间的 bottleneck 距离或 Wasserstein 距离。

**问题**：这个距离有界吗？如果有界，界是什么的函数——区块数量、关系密度、类型分布？

数学问题的完整展开：
- PD(S) = 对嵌入向量矩阵做 VR 持久同调，得到出生-消亡对集合
- PD(K) = 对 relations.jsonl 的图结构做持久同调（需要定义图的滤函数）
- bottleneck 距离：d_B(PD(S), PD(K)) = inf_γ sup_x ||x - γ(x)||_∞
- Wasserstein 距离：W_p(PD(S), PD(K)) = (inf_γ Σ ||x - γ(x)||^p)^(1/p)

**可操作计算步骤需求**：
1. 如何为 K（图结构，无天然滤函数）定义滤函数？
2. bottleneck 距离的界——是否有稳定性定理给出界？
3. Python 实现：GUDHI 的 bottleneck_distance / wasserstein_distance

### Q8（φ 的非 VR 成分的结构）

定义三个边集：
- VR_only = VR_{ε*} 中存在但 K 中不存在的边（遗漏）
- K_only = K 中存在但 VR_{ε*} 中不存在的边（编排者添加）
- Both = 两者都存在的边

**问题**：K_only 中的边在 K 的临界集中是否过表达？如果 K_only 边倾向于临界，意味着编排者的判断（不是语义距离）才是拓扑结构的驱动力。

**可操作计算步骤需求**：
1. 如何精确定义 ε*？
2. 临界边的定义（在 Morse 意义下）
3. 统计检验：K_only 和临界性的独立性检验
4. Python 实现框架

### Q9（ε* 的最优选择）

是否存在一个最优的 ε* 使得 VR_{ε*}(S) 最接近 K？"最接近"可以用同调群的同构来定义：使得 β₁(VR_{ε*}) = β₁(K) 的 ε* 范围是什么？

**数学展开需求**：
- ε* 是否唯一？还是一个区间？

### Q10（ψ 的形式化）

定义 ψ 的效果：
- v_with = 给 LLM 拓扑上下文时的输出嵌入向量
- v_without = 不给 LLM 拓扑上下文时的输出嵌入向量
- ψ 强度 = ||v_with - v_without||
- ψ 方向 = (v_with - v_without) / ||v_with - v_without||

**问题**：ψ 的方向是否和 K 的拓扑特征对齐？

**数学展开需求**：

### Q11（ψ∘φ 的不动点）

如果 ψ∘φ 有不动点——存在某个 K 的状态使得 ψ 反馈给 LLM 后 LLM 的输出铭写回来不改变 K——那系统达到了拓扑均衡。

**问题**：不动点是否存在？β₁ 在不动点处的值是什么？稳定还是不稳定？

**数学展开需求**：
1. 不动点的存在性：Brouwer/Schauder 不动点定理的适用条件
2. 迭代动力学的线性化：ψ∘φ 在不动点附近是否可线性化？Jacobian 的谱半径决定稳定性？
3. 如果 ψ 是非确定性的（LLM 是随机过程），不动点变为不动"分布"——如何处理？
4. 与 GAN 的类比：ψ∘φ 类似 GAN 训练，已知 GAN 的 Nash 均衡条件
