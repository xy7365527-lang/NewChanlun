## 背景：R3 的现状

R3 研究线的核心问题 Q-R3-2 已被证伪并修正：

## 编排者的论证（为什么 Goresky-MacPherson 合适）

### 核心障碍
商映射（识别顶点）产生**奇异点**：折叠点的邻域结构异常（多倍入射边）。商空间不是流形，Forman 框架不直接适用。

### 分层 Morse 理论的思路
Goresky-MacPherson (1988)：把有奇异点的空间分解为若干层（strata），每层自身光滑，层间粘合方式编码奇异性。在分层空间上定义 Morse 函数：
- **光滑层**上的临界点 → 标准 Morse 贡献（和 Forman 一样）
- **奇异层**上的临界点 → 额外拓扑贡献（法锥 normal cone 决定）

### K_active 天然是分层空间
- **光滑层**：未折叠区块（邻域结构正常）
- **奇异层**：折叠点（多区块识别为一点，邻域异常）

### 核心定理
穿过奇异层临界点时，同调群的变化由临界点所在层的**法锥（normal cone）**的拓扑决定。
- 法锥编码"这个奇异点有多少区块被折叠、区块间关系如何"
- 不同折叠类型 → 不同法锥 → 不同同调贡献

## 第一步：Whitney 分层条件的形式化检查

### 背景
Whitney 分层（Whitney stratification）是 Goresky-MacPherson 分层 Morse 理论的技术前提。需要两层结构满足 Whitney 条件 A 和 B。

### 具体问题

**问题 1a**：设 K 是有限有向图（即 1 维单纯复形），∼ 是顶点等价关系（有限多对顶点被识别），K/∼ 是商空间。设分层为：
- S₀（奇异层）= 折叠点（被识别的顶点的像）
- S₁（光滑层）= 所有其他点（包括非折叠顶点和边的内部）

形式化验证：这个两层分层是否满足 Whitney 条件 A？Whitney 条件 B？

**问题 1b**：Whitney 条件的原始定义适用于 ℝⁿ 中的光滑子流形对。但 K/∼ 是有限单纯复形的商，本身是 PL（分段线性）空间，不是光滑流形。
- Goresky-MacPherson 的分层 Morse 理论是否有纯 PL 版本？
- 还是需要将 K/∼ 嵌入 ℝⁿ 并在光滑层面验证 Whitney 条件？
- 如果需要嵌入，具体嵌入方案是什么？

**问题 1c**：如果上述两层分层不满足 Whitney 条件，最小修复是什么？（例如：细化分层，将不同"折叠程度"的点放入不同的层）

### 输出要求

## 第二步：最小例子的完整计算

### 构造

三个区块：A、B、C（顶点）
边：A→B（depends_on），B→C（depends_on）
折叠操作：识别 A∼C（两个顶点被识别为同一个点，设其像为 [AC]）

### 折叠前（K_full）

**顶点集**：{A, B, C}
**边集**：{AB, BC}（1-单纯形）
**拓扑**：路径图 A—B—C（同伦等价于点，β₀=1, β₁=0）

### 折叠后（K_active = K_full/∼）

商映射 π: K_full → K_full/∼，其中 A∼C，π(A) = π(C) = [AC]，π(B) = B
**顶点集**：{[AC], B}
**边集**：{[AC]B（由 AB 诱导）, B[AC]（由 BC 诱导）}
**拓扑**：这是一个圈！两个顶点之间两条边，形成 S¹ 的单纯剖分。

### 要求计算的内容

**2.1 同调群计算**

对 K_full：
- H₀(K_full; ℤ) = ?
- H₁(K_full; ℤ) = ?

对 K_active：
- H₀(K_active; ℤ) = ?
- H₁(K_active; ℤ) = ?

用链复形明确展示计算过程（给出边界算子矩阵）。

**2.2 分层结构**

在 K_active 上定义分层：
- S₀ = { [AC] }（奇异点，折叠了两个顶点）
- S₁ = { B } ∪ { 两条边的内部 }（光滑部分）

问题：这个分层满足分层空间的公理（frontier condition: S₀ 的闭包 ⊂ S₁ ∪ S₀ 的闭包 [AC] 是否在 S₁ 的闭包中？）

**2.3 法锥（Normal Cone）计算**

计算奇异点 [AC] 的法锥 C_[AC]：
- 法锥 = 以 [AC] 为顶点的星形邻域（Star [AC]）除以链接（Link [AC]）的商

**2.4 分层 Morse 函数**

在 K_active 上定义 Morse 函数 f: K_active → ℝ：
- 提议：f([AC]) = 0，f(B) = 1，f(边[AC]-B) = 0.5，f(边B-[AC]) = 0.5
- 检查：这是否是合法的分层 Morse 函数？（需要满足 Goresky-MacPherson 对临界点的定义）
- [AC] 和 B 是否都是临界点？

**2.5 临界点的拓扑贡献**

使用分层 Morse 理论的主定理（Goresky-MacPherson 1988）：

对于光滑层临界点：贡献 = 由临界点指标决定（和 Forman 一样）
对于奇异层临界点：贡献 = 法锥的缩减同调 H̃_*(C_p; ℤ) 决定（这是关键！）

**2.6 验证**

验证：β₁(K_active) = 1（因为 K_active ≅ S¹）是否被以下正确预测：

## 第三步：法锥分类的可行性评估

### 问题

缠论的折叠操作有若干类型：
1. **笔折叠**：两个相邻笔（bi）的端点被合并（segment simplification）
2. **段折叠**：段（segment）内部的结构被简化
3. **中枢折叠**：三段走势对应的三个区块被合并为一个中枢节点
4. **趋势折叠**：多个中枢被识别为同一个趋势

**问题 3a**：对每种折叠类型，法锥 C_p 的拓扑类型是什么？
- 法锥是 S^k（k 维球面）吗？k 是什么？
- 还是更复杂的空间？

**问题 3b**：是否存在有限多种不同的法锥拓扑类型？如果是，枚举它们及其同调群。

**问题 3c**：如果法锥分类是有限的，这意味着什么？（折叠的拓扑效力只有有限多种 → 区块拓扑的同调动力学由有限种"基本操作"生成）

### 约束

- 区块拓扑的节点数有限（目前 ~380 个）
- 折叠操作由 supersedes/modifies 关系诱导
- 每次折叠识别 k 个顶点（k = 2, 3, 或更多）
