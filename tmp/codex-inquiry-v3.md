【2. 推演 A：循环约束对趋势方向的传递】

设 A(t),B(t),C(t)>0，定义  
R_AB(t)=ln A/B, R_BC(t)=ln B/C, R_AC(t)=ln A/C  
则 R_AC = R_AB+R_BC 恒成立。  
对时间区间 [T₀,T₁]，定义区间平均对数收益  
r̄_XY = (R_XY(T₁)-R_XY(T₀))/(T₁-T₀)

若趋势判定规则为 “r̄>ε” → 上涨，“r̄<−ε” → 下跌，“|r̄|≤ε” → 盘整，其中 ε>0 为阈值，则：

1. 若 r̄_AB>ε 且 r̄_BC>ε ⇒ r̄_AC > 2ε−δ  
其中 δ ≤ |Cov(ΔR_AB,ΔR_BC)| / (T₁−T₀)。当区间长度多于相关性衰减时间、协方差项可忽略 ⇒ r̄_AC>ε ⇒ 同向。  

2. 若 r̄_AB>ε 且 r̄_BC<−ε，无法单凭方向判定 r̄_AC；需比较幅度  
r̄_AC = r̄_AB + r̄_BC  
若 |r̄_AB|≈|r̄_BC| 则 r̄_AC≈0 ⇒ 盘整  
若 |r̄_AB| > |r̄_BC|+ε ⇒ 上涨  
若 |r̄_BC| > |r̄_AB|+ε ⇒ 下跌  

3. 结论  
• 方向可传递的充分条件：两条独立边方向相同且强度差距 > ε。  
• 必要条件：不存在幅度抵消。  
文档中“趋势明确时约束强”可精确化为：  
min(|r̄_AB|,|r̄_BC|) > ε  且 |r̄_AB + r̄_BC| > ε

【3. 推演 B：比价 MACD 的数学表达】

设价格序列 P_A(t),P_B(t)  
指数移动平均 EMA_k[X](t) = α_k X(t)+(1-α_k) EMA_k[X](t-1)，α_k = 2/(k+1)

比价序列 R(t)=P_A(t)/P_B(t)

MACD_R(t)=EMA_12[R](t)−EMA_26[R](t)

写作:

EMA_12[R] = EMA_12[P_A / P_B]   
≠  EMA_12[P_A] / EMA_12[P_B]   (因 EMA 非线性)

故  
MACD_R = f(P_A,P_B)  ≠ g(P_A) − g(P_B)

具体展开一次递归：

EMA_k[R](t)=α_k P_A(t)/P_B(t)+(1-α_k) EMA_k[R](t-1)

不可拆分为 A、B 各自函数之差。  
物理含义：MACD_R 衡量的是“短/长期均价比”的相对斜率变化，等价于  
MACD_R ≈ (EMA_12[A]/EMA_12[B]) − (EMA_26[A]/EMA_26[B]) + 高阶项  
仅当 B 近似静止（P_B ≈ const）时，MACD_R≈MACD_A。  
若 A,B 同时上涨同幅度，则 R≈常数 ⇒ MACD_R≈0。  
结论：  
• MACD_R 捕获的是 A 相对 B 的加速，而非各自绝对加速之差。  
• 文档中“流转力度导数”之说可以精确定义为：  
  ΔMACD_R >0 表示 A 相对 B 的上涨在加速；ΔMACD_R <0 表示相对上涨在放缓或反向加速。

【4. 推演 C：27 种配置与派生边方向】

记独立基底 (E$,C$,R$) 的状态集合 S={+,−,0}

映射 F:S³ → {+,−,0}^{3}   
F(E$,C$,R$) = (sig(E/C),sig(E/R),sig(C/R))  
其中  
sig(E/C)=Sign(f_E$ - f_C$)  
我们用 f_+ = 1, f_0 = 0, f_- = −1 作为强度序数，再设阈值 ε 如推演 A

规则：  
d_EC = f_E$ − f_C$  
若 |d_EC|<ε → 0  
若 d_EC>ε → +  
若 d_EC<−ε → −  
同理得 d_ER, d_CR

取 ε=1 (最粗糙) 得到派生边方向表：

基底 (E$,C$,R$)
( +, +, + ) → d_EC=0→0, d_ER=0→0, d_CR=0→0   （配置 #1，纯尺子效应）
( +, −, − ) → d_EC=+2→+, d_ER=+2→+, d_CR=0→0   （配置 #7）
( +, 0, 0 ) → d_EC=+1→+, d_ER=+1→+, d_CR=0→0
( +, −, 0 ) → d_EC=+2→+, d_ER=+1→+, d_CR=−1→−
……
遍历 27 组可得完整表，确认无遗漏。  

检验文档声明：  
• #1 派生边“≈0” 成立  
• #2（全部−）同理  
• 若基底同向但强度差异大 (现实中常见)，则派生边可能非 0 ⇒ “≈0” 近似失效条件：  
  |f_E$ − f_C$| ≥ ε or |f_E$ − f_R$| ≥ ε  
文档需补此边界说明。
