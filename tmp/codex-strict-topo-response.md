──────────────────────────  
1.  一维 CW 复形的同调群 H\*(X)  
──────────────────────────  
1. 数学严格性  
   • 已有严谨定义：笔序列 X 是 1-维 CW，0-cell=分型，1-cell=笔。  
   • Theorem: 若 X 无自环且 1-cells 构成线性链，则  
     H₀(X) ≅ ℤ ，H₁(X)=0。  
   • 证明仅用 CW 同调长确界序列即可完成。  

2. 计算可行性  
   • O(1)。只要统计 V=节点数、E=笔数，再查链结构是否含圆环。  

3. 新信息量  
   • 0。已知它必然是一条线段的同胚类型。  

4. 诚实风险  
   • 极高＝“为拓扑而拓扑”。同调只给出连通且无洞——和现在的语义标注完全等价。  


──────────────────────────  
2.  持续同调 (Persistent Homology, TDA)  
──────────────────────────  
1. 数学严格性  
   • 取滑动窗口嵌入 Φ: ℝ¹(time) → ℝᵈ, d≳3，或直接用  
     点云 P = {(t, price_t)}⊂ℝ²。  
   • 对任意 ε≥0 构建 Vietoris–Rips 复形 VR_ε(P)。  
   • 得到过滤 {VR_ε}；其持久模 Bᵖ = ⊕_i k[t]·[σ_i]，长度给出持久条带。  
   • 可与笔级别过滤对接：ε ←→ 笔尺度 Δt。  
   • Proposition: 长寿命 H₁-bar 与价格周期（回撤—反弹）对应。  

2. 计算可行性  
   • 复杂度 O(n³) 最差，但 Gudhi/Ripser 对 n≤5 000 点的 2-维点云求 H₁ 仅需秒级。  
   • 代码栈：python-gudhi + numpy；GPU 上用 Cuda-Ripser。  

3. 新信息量  
   • 能定量比较“价-时回路”的尺度与稳定性——语义标注层给出的只是离散笔，不含尺度鲁棒性信息。  
   • 可定义指标：  
     PH_cycles = Σ (birth_i – death_i)·1_{life_i>τ} ，度量“持久环能量”。  

4. 诚实风险  
   • 中等。若不与交易逻辑结合，只是花哨图。但把 ε-尺度对齐到笔尺度，可直接检验“不同笔模式”是否真产生不同拓扑条带——具备可检验性。  


──────────────────────────  
3.  亏格 & Euler 特征 χ  
──────────────────────────  
1. 数学严格性  
   • χ(X)=V–E。若 X 是线段则 χ=1。  

2. 计算可行性  
   • 与 1 类似，O(1)。  

3. 新信息量  
   • 无。只能告诉我们“这是一条线段”。  

4. 诚实风险  
   • 极高。与已知事实重复。  


──────────────────────────  
4.  层理论 (Sheaf Theory) 在笔复形上  
──────────────────────────  
1. 数学严格性  
   • 定义：令 𝒞 为笔 CW 的大覆盖（节点与边）。  
     定义价格层 ℱ : 𝒞ᵒᵖ→Vect,  
     ℱ(v)=ℝ（分型时刻价格），ℱ(e)=ℝ²（该笔的(高,低)）。  
   • 级别递归给出层间射：  
     ι_{low→high}: ℱ_low ⇒ ℱ_high (restriction maps)。  
   • Cohomology H⁰(ℱ)=全局一致价差，H¹(ℱ)=层内“矛盾闭合”。  
   • 命题: H¹(ℱ)=0 ⇔ 同一价位不被不同级别同时标为顶与底。  

2. 计算可行性  
   • 对 1-维复形层上 Čech-cohomology = kernel/coker 的矩阵秩计算，  
     O(V+E)。SciPy-sparse 足够。  

3. 新信息量  
   • 可用来检测“级别一致性”——即缠论常说的“同级别分解不冲突”。  
   • H¹≠0 给出最小冲突环，可反馈给策略修复标注。  

4. 诚实风险  
   • 低-中。若目标正是验证多级别一致性，这里提供客观判定；否则会显得晦涩。  


──────────────────────────  
5.  范畴论视角：级别递归 ⟶ 小范畴 𝒦  
──────────────────────────  
1. 数学严格性  
   • 对象：不同级别的笔复形 X_i。  
   • 态射：分解 functor F_{i→j}: X_i → X_j, i<j，  
     满足 F_{j→k}∘F_{i→j}=F_{i→k}（分解传递性）。  
   • 命题: 若所有 F_{i→j} 保拓扑型且单射，则系统同构于  
     一个由滤子指派的逆向图谱 (pro-object)。  

2. 计算可行性  
   • 只要保存分解映射就行，复杂度主要在存储。  

3. 新信息量  
   • 允许把“换模式”理解成自然变换 η: F → F'。  
   • 可以比较不同笔模式（wide/strict/new）在范畴同伦意义下是否自然同构。  

4. 诚实风险  
   • 中等。若最终目标是交易信号，范畴同构未必有直观解释。  
     但它可用来保证实现层面的“模式兼容性”——对库作者有价值。  


──────────────────────────  
6.  Morse–Smale 复形  
──────────────────────────  
1. 数学严格性  
   • 视价格函数 f: time→ℝ。令流 φ 根据 ∇f（=±1，向上记+1，向下–1）。  
   • 分型 = 离散 Morse 临界点。  
   • 连接它们的流线段即笔。  
   • Morse–Smale 复形 = {稳定/不稳定流形的截交图}。  
   • 命题: 若缠论笔严格满足顶-底交替，则 Morse–Smale 复形正好与  
     当前 CW 复形同胚；违反时将出现额外 0-cells 或 1-cells → 自动暴露“错误笔”。  

2. 计算可行性  
   • 离散 Morse 对 1-D 数据线性时间；可用 dionysus / scipy-gradient-morse。  

3. 新信息量  
   • 提供“自动选笔”替代算法，而非事后验证。  
   • 可输出临界点对 (birth,death)＝趋势持续度，直接映射交易阀值。  

4. 诚实风险  
   • 低-中。若团队已用人工划笔，此法可给客观基线。否则只是另一个“自动笔法”。

推荐实施路线：  
Step 1. 引入 Morse–Smale 自动笔，校验人工标注 → 最小落地成本。  
Step 2. 在同一时间窗内计算价格点云的 H₁-持久条带，阈值 τ=笔平均周期；将长寿命环记为“潜在震荡区间”，与缠论“中枢”交叉验证。  
Step 3. 构造价格层 ℱ ，计算 H¹(ℱ)；每当 H¹≠0，触发调仓或告警“多级别冲突”。  

这样三者互补：  
Morse–Smale 给局部分段，PH 给全局尺度鲁棒性，Sheaf Cohomology 给多级别一致性 —— 真正扩展了现有仅靠“标注拓扑语义”的框架。
