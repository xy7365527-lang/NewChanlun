# D 算子 L2 真实数据验证方案

认识论标注：本文档是 L2 验证的**方案设计**（L0），方案执行后的结果才是 L2。

谱系引用：281号（回测框架搭建）、267号（操作方法论 v1）、231号（形式化有效域规则）。

## 一、问题定义

D 算子从 `RecursiveOrchestratorSnapshot` 提取三种读数：

| 读数 | 定义 | 代码位置 | 当前验证等级 |
|------|------|---------|------------|
| **方向态**（direction） | 最新 settled 走势的方向（UP/DOWN/FLAT） | `types.py:76-81` | L0 |
| **幅度态**（amplitude） | 当前走势 vs 前一走势的价格区间之比 | `types.py:84-91` | L0 |
| **吸收态**（absorption） | 最后一个中枢是否 settled=False（正在吸收新段） | `types.py:94-98` | L0 |

D 算子跑在 K4 完全图的六条边上（`types.py:9`），六条边的联合 D 读数构成 K4State。

**核心假设（待验证）**：D 算子的三种读数能够有效区分市场状态，使得基于 D 读数做出的操作决策（选股、建仓时机、短差方向）优于随机决策。

**281号下游推论1原文**："回测框架的D算子读数（方向态/幅度态/吸收态）是否能有效区分市场状态——待L2真实数据验证"。

## 三、验证方案设计

### 3.1 数据源

**原则**：增加多样性以增加否证力。单标的单时段的确认无法否证，多标的多时段才能暴露有效域边界。

| 维度 | 已有 | 扩展方案 |
|------|------|---------|
| K4 三标的 | SPY/GLD/TLT | 不变（K4 定义锁定） |
| 候选标的 | 5 个行业 ETF | 11 个行业 ETF（XLK/XLF/XLE/XLV/XLY/XLI/XLB/XLP/XLU/XLRE/XLC） |
| 时段 | 全历史（~2004-2024） | 分段验证（见 3.2） |
| 频率 | 日线 | 日线（不变，与操作级别一致） |

**标的选择理由**：11 个 SPDR 行业 ETF 覆盖 GICS 全部 11 个行业板块，是 267号"区间套收敛路径"中"板块"层的自然候选集。已在 `scanner.py:27-30` 定义。

### 3.2 时段分割（样本外验证）

将全历史分为三段，验证 D 算子在不同市场环境中的表现：

| 段 | 时段 | 市场特征 | 作用 |
|----|------|---------|------|
| A | 2004-2012 | 次贷危机 + 复苏 | 训练段（调参用，如果需要） |
| B | 2012-2019 | 低波动牛市 | 验证段 1 |
| C | 2019-2024 | COVID + 高通胀 + 加息 | 验证段 2 |

三段独立跑回测，D 算子的区分能力应在三段中**一致有效或一致无效**。如果仅在某段有效，则有效域 < 定义域，需标注。

### 3.3 验证指标

每种 D 读数单独评估 + 联合评估。

#### 3.3.1 方向态验证

**假设 H1**：方向态 UP 后的 N bars，标的价格上涨概率 > 50%（优于随机）。

**度量方法**：
1. 记录六条边方向态每次从 non-UP 转为 UP 的时刻 t
2. 计算 t+5, t+10, t+20 日的价格变化方向
3. 统计方向态预测命中率
4. 对照：同时段随机选择时刻的命中率

**否定条件**：如果方向态 UP 后 N bars 价格上涨概率与随机无显著差异（p > 0.05, 双尾 binomial test），则 H1 被否证。

#### 3.3.2 幅度态验证

**假设 H2**：amplitude > 1.0（当前走势幅度大于前一走势）与趋势延续正相关。

**度量方法**：
1. 在方向态 UP 的子集中，按 amplitude 分为两组：>1.0 和 <=1.0
2. 比较两组在后续 N bars 的平均收益
3. amplitude > 1.0 的组应表现更好（趋势力度更大）

**否定条件**：如果两组平均收益无显著差异（p > 0.05, Welch's t-test），则 H2 被否证。amplitude 不提供方向态之外的额外信息。

#### 3.3.3 吸收态验证

**假设 H3**：absorption=True（中枢正在吸收新段）时进入的操作，退出时亏损概率更高。

**度量方法**：
1. 将所有操作按建仓时的 absorption 状态分组
2. 比较 absorption=True 组和 absorption=False 组的盈亏比
3. absorption=True 应关联更高的风险（中枢未闭合 = 走势方向不确定）

**否定条件**：如果两组盈亏比无显著差异，则 H3 被否证。吸收态不提供风险区分信息。

#### 3.3.4 联合验证（K4 配置变化的信号质量）

**假设 H4**：K4 配置变化（polarity 变动）后的选股信号命中率高于配置稳定期的随机选股。

**度量方法**：
1. 标记所有 K4 配置变化时刻
2. 配置变化后首次选股命中的标的，计算持有 60/120/240 日的收益
3. 对照：在配置稳定期随机选择同一标的集合中的标的，计算同期收益
4. 配置变化应提供择时信号（在变化时刻选股优于随机时刻）

**否定条件**：如果配置变化后选股收益与随机选股无显著差异，则 H4 被否证。K4 配置变化不提供择时信息增量。

### 3.4 消融实验（Ablation Study）

验证三种读数的**边际贡献**：

| 实验 | 保留读数 | 消除读数 | 目的 |
|------|---------|---------|------|
| Full | 方向态 + 幅度态 + 吸收态 | - | 基准线 |
| A1 | 方向态 + 幅度态 | 吸收态 | 吸收态的边际贡献 |
| A2 | 方向态 + 吸收态 | 幅度态 | 幅度态的边际贡献 |
| A3 | 幅度态 + 吸收态 | 方向态 | 方向态的边际贡献 |
| A4 | 仅方向态 | 幅度态 + 吸收态 | 方向态是否足够 |
| Random | - | 全部 | 随机决策基准 |

消融方式：将被消除的读数替换为常量（direction=FLAT, amplitude=1.0, absorption=False），等价于该读数不携带信息。

**比较指标**：每组的操作次数、胜率、盈亏比、最大回撤。

### 3.5 六条边的信息冗余检测

K4 六条边中，三条比价边（E/Au, E/R, Au/R）与三条顶点边（E/$, Au/$, R/$）的 D 读数之间存在代数关系（比价 = 顶点之比）。

**假设 H5**：比价边的 D 读数不完全由顶点边的 D 读数决定（比价边携带额外信息）。

**度量方法**：
1. 用三条顶点边的 D 读数训练一个简单模型（logistic regression），预测三条比价边的方向态
2. 计算预测准确率
3. 如果准确率 > 90%，则比价边几乎不携带额外信息——六条边冗余

**否定条件**：如果顶点边可高精度预测比价边方向态，则比价边的 D 读数是冗余的。有效 D 读数数量从 6 退化为 3。

## 四、实验设计

### 4.1 控制变量

| 变量 | 控制方式 |
|------|---------|
| 回测引擎 | 使用 `BacktestOrchestrator`，不修改代码 |
| 初始资金 | 固定 1,000,000 |
| 融资比例 | 固定 1.0（满仓满融） |
| 短差比例 | 固定 0.1（10%） |
| 数据频率 | 日线 |
| 数据源 | yfinance（与已有 L2 脚本一致） |

### 4.2 对照组

| 对照组 | 设计 |
|--------|------|
| Random Baseline | 在相同数据上，随机选择建仓时刻和标的，保持操作频率与 D 算子驱动的回测相同。跑 1000 次取分布 |
| Direction-Only | 仅使用方向态（amplitude=1.0, absorption=False），验证方向态是否是唯一有用读数 |
| Buy-and-Hold | 等权持有全部候选 ETF，作为被动投资基准 |

### 4.3 样本量

- K4 边：6 条边 x 3 时段 = 18 组 D 读数序列
- 候选标的：11 ETF x 3 时段 = 33 组回测
- 消融实验：6 组 x 3 时段 = 18 次回测
- 随机基准：1000 次 x 3 时段 = 3000 次
- 总计约 3069 次回测实例

### 4.4 统计检验

| 检验 | 方法 | 显著性水平 |
|------|------|-----------|
| 方向态命中率 vs 随机 | Binomial test（双尾） | alpha = 0.05 |
| 幅度态分组收益差异 | Welch's t-test | alpha = 0.05 |
| 吸收态分组盈亏比差异 | Mann-Whitney U test | alpha = 0.05 |
| 消融实验组间差异 | Kruskal-Wallis test | alpha = 0.05 |
| 多重比较校正 | Bonferroni | 5 个主假设 -> alpha_adj = 0.01 |

## 五、否定性假设（核心）

formalization-validity-domain.md 要求：**L2 的核心价值是否证能力**。以下列出明确的否定条件——**什么结果会否定"D算子能区分市场状态"这一假设**：

### 5.1 强否定（任一成立则 D 算子假设被否证）

1. **H1 被否证**：方向态 UP 后价格上涨概率 <= 50%（方向态无预测力）
2. **Full 组 vs Random 组无差异**：D 算子驱动的回测与随机操作在胜率、盈亏比上无显著差异（D 算子整体无信息增量）

### 5.2 弱否定（缩小有效域，不完全否证）

3. **H2 被否证**：幅度态不提供额外信息 -> D 算子有效读数从 3 退化为 2
4. **H3 被否证**：吸收态不提供额外信息 -> D 算子有效读数从 3 退化为 2（或从 2 退化为 1）
5. **H5 被否证**：比价边冗余 -> 有效 D 读数边从 6 退化为 3
6. **时段不一致**：D 算子仅在部分时段有效 -> 有效域 < 定义域，需标注市场环境约束

### 5.3 否定性结果的价值

按 231号规则：否定性结果比确认性结果更有价值——否定性结果缩小有效域边界，确认性结果只是未能否证。

- 如果 D 算子被强否定 -> 回测框架的信号源需要重新设计（281号边界条件）
- 如果 D 算子被弱否定 -> 精确标注有效域，删除无信息增量的读数

## 六、结果包

### 结论

设计了 D 算子 L2 真实数据验证方案，包含：5 个可否证假设（H1-H5）、6 组消融实验、3 段时段分割、3 个对照组、统计检验框架。

### 定义依据

- D 算子三种读数的定义：`types.py:36-64`（Direction, DOperatorReading）
- D 算子提取逻辑：`types.py:66-104`（extract_d_reading）
- K4 完全图六条边：`types.py:113-181`（EdgeState, K4State）
- 回测全流程编排：`orchestrator.py:203-542`（BacktestOrchestrator）
- 267号操作方法论 v1：选股二值分类、区间套收敛排序、满仓满融默认前提

### 边界条件

- 如果 yfinance 数据不可用或覆盖不全 -> 需要替换数据源（alpha_vantage, polygon.io 等）
- 如果行业 ETF 的历史不覆盖 2004 年 -> 该 ETF 从段 A 中排除，仅参与有数据的时段
- 如果 RecursiveOrchestrator 在长序列上出现性能瓶颈 -> 分 chunk 处理（但需保证跨 chunk 状态连续）
- 如果 1000 次随机回测计算量过大 -> 降至 100 次，但显著性检验的 power 会降低
- 时段分割依赖人为判断市场阶段 -> 替代方案：滚动窗口（rolling window, 窗口宽度 = 500 bars, 步长 = 50 bars）

### 下游推论

1. 如果 H1-H4 全部未被否证 -> D 算子具有 L2 验证的市场状态区分能力，回测框架的信号源设计合理
2. 如果方向态唯一有效（H2+H3 否证） -> 简化 DOperatorReading 为仅 Direction，删除 amplitude/absorption 字段
3. 如果比价边冗余（H5 否证） -> K4 从六条边退化为三条独立边，EdgeState 和 K4State 的结构需重构
4. 消融实验的结果为后续优化提供排序依据
