# 层内折叠检验实验报告

认识论等级：**L2**（真实数据验证）
数据来源：317号谱系实验一的 24 个 ratio 断裂事件 + 12 次中枢状态转换

## 核心假设

ratio 序列的断裂事件之间存在序列依赖（后一次断裂的动力学特征被前一次约束）。如果成立，这就是层内折叠——ratio 序列自己折回自身。

## 判决：否定（0/3）

两层都不存在非平凡层内折叠。

## Agent A（ratio 断裂层）

### 方法

对 24 个断裂事件使用四种离散化方案构建状态转移矩阵，加上连续特征的 lag-1 自相关分析和游程检验。

### 结果

| 方案 | 状态数 | chi-square p 值 | 结论 |
|------|--------|-----------------|------|
| 原始4-cluster | 4 | 0.049 | 边界显著，但 cluster 2/3 各仅 1 个成员，统计力不足 |
| 方向二分类 (up/down) | 2 | 0.790 | 完全不显著——转移概率接近均匀 |
| 强度三分类 | 3 | 0.881 | 完全不显著 |
| 波动率三分类 | 3 | 0.307 | 不显著 |

**方案1 的 p=0.049 不可信**：cluster 2（2008金融危机）和 cluster 3（2011欧债危机）各仅 1 个样本。转移矩阵中这两行各只有 1 次转移，chi-square 期望频率 < 1，检验前提不满足。排除这两个单成员 cluster 后（方案2-4），所有 p 值 >> 0.05。

**连续特征 lag-1 自相关**（95% 临界值 = +/- 0.408）：

| 特征 | 自相关 | 显著？ |
|------|--------|--------|
| level_shift | -0.160 | 否 |
| volatility_ratio | 0.132 | 否 |
| post_trend_slope | -0.208 | 否 |
| departure_speed | 0.258 | 否 |
| mean_reversion_corr | -0.285 | 否 |
| oscillation_rate | -0.136 | 否 |
| stabilization_days | -0.078 | 否 |
| new_regime_distance | 0.033 | 否 |

8 个特征无一达到显著水平。断裂事件在特征空间中无序列记忆。

**游程检验**（方向序列 up/down）：游程数 13，期望 12.667，z=0.143，p=0.886。完全随机。

### 环路检测

所有方案的有向图都是强连通的（单个大 SCC），因为所有状态对之间都有非零转移。这不是"发现了环路"——当转移矩阵接近均匀分布时，所有状态对之间自然有转移，强连通是平凡的。

### Agent A 结论

ratio 断裂事件之间**统计独立**。无论从离散化转移矩阵、连续特征自相关、还是游程检验看，都没有发现序列依赖。第 N 次断裂的动力学特征不被第 N-1 次断裂约束。

## Agent B（中枢转换层）

### 结果

12 次转换的类型序列是**完全确定性交替**：
```
(extending->expanding), (expanding->newborn), (extending->expanding), (expanding->newborn), ...
```

每个中枢的生命周期固定是 extending -> expanding -> newborn。这不是经验性发现——这是中枢定义的逻辑必然：中枢先延伸（新段落入区间），然后扩展（区间被突破），然后产生新中枢。

转移矩阵：
- 从 extending->expanding 出发：100% 转向 expanding->newborn
- 从 expanding->newborn 出发：100% 转向 extending->expanding

这是 **L0 级别的同义反复**，不是 L2 级别的经验发现。对确定性序列做 chi-square 检验无意义。

### 中枢生命周期长度

| 中枢 | ext->exp (段数) | exp->new (段数) | 总段数 |
|------|-----------------|-----------------|--------|
| 0 | 3 | 1 | 3 |
| 1 | 3 | 1 | 3 |
| 2 | 3 | 1 | 3 |
| 3 | 5 | 11 | 14 |
| 4 | 3 | 7 | 9 |
| 5 | 4 | 5 | 8 |

生命周期长度有变化，但样本仅 6 个，lag-1 自相关均未达到临界值（+/- 0.817）。无法断言生命周期长度存在序列依赖。

## 跨层同构检验

**不适用**。Agent B 层内结构是确定性的（定义性交替），Agent A 层内结构是随机的（无序列依赖）。一个确定性过程和一个随机过程之间讨论"拓扑同构"无意义。

## 总结

| 检验项 | 结果 | 含义 |
|--------|------|------|
| ratio 断裂转移矩阵 vs 均匀分布 | p >> 0.05（方案2-4） | 无偏离 |
| ratio 断裂特征自相关 | 8/8 不显著 | 无序列记忆 |
| ratio 断裂方向游程检验 | p=0.886 | 完全随机 |
| 中枢转换序列 | 确定性交替 | 是定义，不是发现 |
| 跨层同构 | 不适用 | 两层性质根本不同 |

**层内折叠假设被否定**。ratio 序列不折回自身。断裂事件是统计独立的离散冲击，没有从前一次断裂到后一次断裂的信息传递。

结合 317号谱系实验一的结论（跨层时间耦合否定 0/3），当前证据表明：ratio 断裂既不与中枢转换耦合（跨层），也不与自身的历史耦合（层内）。
