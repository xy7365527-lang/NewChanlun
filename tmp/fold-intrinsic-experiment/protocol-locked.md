## 对齐与判决标准（锁定，不可修改）

### 对齐方法
不设固定对齐窗口。对齐窗口从时间差分布中内生确定。

具体操作：
1. Agent A 标记所有断裂事件时间戳集合 T_A
2. Agent B 标记所有中枢状态转换时间戳集合 T_B
3. 对每个 t_a ∈ T_A，计算 δ = min_{t_b ∈ T_B}(t_b - t_a)（最近的Layer 2事件的时间差，保留符号）
4. 画出 δ 的分布，从分布中读出自然窗口

### 判据一：聚类数量
Agent A 在无引导条件下聚出的类别数 N_clusters。
- N_clusters = 3 → 通过
- N_clusters ≠ 3 → "三"是理论投射，记录实际数量，分析含义

### 判据二：聚类特征对应
Agent A 的聚类特征与中枢三状态（延伸/扩展/新生）的对应。
统计检验：列联表 + Fisher精确检验（或卡方检验，视样本量）。
- p < 0.05 → 对应显著，通过
- 0.05 ≤ p < 0.10 → 边缘显著，部分通过
- p ≥ 0.10 → 不通过

### 判据三：时间方向性
Layer 1 断裂事件是否系统性领先 Layer 2 中枢状态转换。
- 时间差分布中位数 > 0 且 75% 以上落在正侧 → 方向性成立
- 否则 → 方向性不成立

### 显著性水平
p < 0.05（双侧），锁死不可修改。
