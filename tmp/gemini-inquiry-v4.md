## 一、数学严格性质询

### 1.1 C1-C3 充分条件是否真的充分？

v4 §2.4 给出三个充分条件：
- C1: 三条直接边方向一致（全部流入或全部流出某顶点）
- C2: 两条直接边方向一致 + 第三条均衡
- C3: 两条直接边方向一致 + 第三条反向但力度显著弱于前两条

**质询**：C1-C3 是关于**直接边**的条件，用于推断**派生边**的方向。但 v4 没有给出从 C1-C3 到派生边方向的**推导过程**。

具体反例构造尝试：

考虑 K4 中四顶点 A, B, C, D。假设我们关注派生边 A/C（即 A 和 C 之间没有直接比价数据，需要从 A/B、B/C 推断）。

设 C1 成立：A/B 上涨（资本 B→A）、B/C 上涨（资本 C→B）、A/D 上涨（资本 D→A）。

问题：这三条直接边的方向一致性（都指向 A 流入），能否推断 A/C 的方向？

- 从 A/B↑ 和 B/C↑ 可以推断 A/C 应该↑（资本 C→B→A 的传递链）
- 但这个推断依赖**传递性假设**：资本从 C 流向 B，再从 B 流向 A，所以资本从 C 流向 A

**问题**：传递性在比价关系中不成立（dengjia.md 明确说传递性不满足）。A/B↑ + B/C↑ 不蕴含 A/C↑。

这不是反例——因为 v4 的 C1-C3 不是在做传递性推断，而是在做**拓扑约束**推断。但 v4 没有区分这两种推断的数学基础。

**判定**：C1-C3 的充分性**未被证明**。v4 给出了条件但没有给出从条件到结论的推导。这是一个声明，不是定理。严格性要求：要么给出证明，要么降级为启发式判据。

### 1.2 log-MACD 的线性可加性

v4 §4.1 声称：

```
MACD(ln(A/C)) = MACD(ln(A/B)) + MACD(ln(B/C))
```

因为 ln(A/C) = ln(A/B) + ln(B/C)，而 MACD 是线性算子。

**质询**：MACD 的核心是 EMA（指数移动平均）。EMA 的定义：

```
EMA_t = α · x_t + (1-α) · EMA_{t-1}
```

EMA 是否是线性算子？验证：

```
EMA(x + y)_t = α · (x_t + y_t) + (1-α) · EMA(x+y)_{t-1}
             = α · x_t + (1-α) · EMA(x)_{t-1} + α · y_t + (1-α) · EMA(y)_{t-1}
```

这要求 `EMA(x+y)_{t-1} = EMA(x)_{t-1} + EMA(y)_{t-1}`，即线性性在 t-1 时刻也成立。

归纳基底：EMA_0 通常取序列前 N 个值的简单平均（SMA）。SMA 是线性的：SMA(x+y) = SMA(x) + SMA(y)。

归纳步骤：如果 EMA(x+y)_{t-1} = EMA(x)_{t-1} + EMA(y)_{t-1}，则由递推公式，EMA(x+y)_t = EMA(x)_t + EMA(y)_t。

**结论**：EMA **是**线性算子（在初始化条件一致的前提下）。因此 MACD = EMA_fast - EMA_slow 也是线性的。

**但有一个关键前提**：两个序列 ln(A/B) 和 ln(B/C) 必须在**相同的时间索引**上计算 EMA，且初始化窗口相同。如果 A/B 和 B/C 的交易时间窗口不完全重叠（例如 A 停牌导致某些时间点缺失），则线性可加性**不严格成立**。

**判定**：数学上正确，但需要**时间对齐前提条件**的显式声明。v4 没有声明这个前提。

### 1.3 "27种配置给出派生边的允许范围"

v4 §5 声称完全分类定理：3条直接边 × 3种状态(+/–/0) = 27种配置，每种配置给出派生边的允许范围。

**质询**：

1. v4 没有给出这 27 种配置的**完整枚举表**。声称"穷尽"但不展示穷尽结果，这不是严格的数学陈述。

2. "允许范围"的精确数学描述是什么？是一个区间？一个集合？一个概率分布？v4 没有定义。

3. 27 种配置中，有多少种能给出派生边的**唯一方向**？有多少种只能给出**范围**？如果大部分配置只能给出范围而非唯一值，那么"完全分类"的实际信息量是什么？

**判定**：27 种配置的声称缺乏实质内容——没有枚举、没有精确的"允许范围"定义、没有守恒约束下的合法配置计数。这是一个**框架声明**，不是定理。

## 二、两层结构的完备性

### 2.1 第一层与第二层之间是否存在中间地带？

v4 §2.5 定义两层：
- 第一层：单边分析（pair-level），无条件合法
- 第二层：K4 关系图（topology-level），有条件合法

**质询**：考虑以下场景——

分析者有 3 个标的 A, B, C（不是完整的四矩阵），构成 3 条边。这不是 pair-level（涉及多条边的交叉分析），也不是 K4（只有 3 个顶点，不是 4 个）。

这个场景属于哪一层？

- 如果归入第一层：但分析者在做跨边比较（比如 A/B 的力度 vs B/C 的力度），这超出了"单边分析"的范畴
- 如果归入第二层：但这不是 K4，只是 K3

**判定**：两层结构存在**中间地带**——多边但非完整四矩阵的分析。v4 没有处理这个情况。

可能的修复：第一层是"单边"，第二层是"任意多边关系图"，K4 是第二层的一个特例。但这需要重新定义第二层的合法性条件。

### 2.2 K4 浮现性的判定标准

v4 §2.5 说 K4 是"级别依赖的浮现结构"——只有当四个顶点在同一递归层级上都有已完成的走势类型时，K4 才"浮现"。

**质询**：

1. "已完成的走势类型"是什么意思？一个完整的趋势？一个完整的中枢？还是至少一笔？v4 没有精确定义。

2. 四个顶点的走势类型完成时间几乎不可能同步。如果 A 在级别 3 上有完成的走势，B 在级别 3 上正在进行中，K4 是否"部分浮现"？v4 的二值判定（浮现/不浮现）是否过于粗糙？

3. 浮现性判定需要**同时检查 4 个顶点 × 6 条边**的走势状态。这在实操中如何执行？v4 §7 的操作流程提到"级别扫描前置步骤"，但没有给出扫描算法。

**判定**：K4 浮现性的判定标准**不够精确**，缺乏可操作的定义。

## 三、定义一致性质询

### 3.1 v4 §2.5 "级别依赖等价关系" vs dengjia.md 的 C-1/C-2/C-3

v4 引入新语义："两个资产在递归层级 L 上等价，当且仅当两者在层级 L 上都有已完成的走势类型。"

dengjia.md 的等价对条件是 C-1（可比性）、C-2（非退化）、C-3（流动性）。

**质询**：v4 的"级别依赖等价"与 C-1/C-2/C-3 是什么关系？

- 如果是第四个条件（C-4）：那么 dengjia.md 需要更新，增加 C-4
- 如果是对 C-2 的级别化扩展：那么 C-2 的含义从"比价非常数"变为"比价在特定级别上有完成的走势"——这是语义变更，不是扩展
- 如果是独立于 C-1/C-2/C-3 的新概念：那么"等价"一词被赋予了两种不同含义——dengjia.md 的等价（数据质量筛选）和 v4 的等价（走势完成状态）

**判定**：v4 引入了与 dengjia.md 不一致的"等价"语义，且没有显式声明这是新增条件还是语义变更。这是**定义分裂**——同一术语在两个文件中有不同含义。

### 3.2 v4 §2.3 乘法守恒 vs liuzhuan.md 加法守恒

v4 §2.3 声称"严格的守恒是乘法形式"：

```
A/B × B/C × C/A ≡ 1
```

liuzhuan.md 的守恒是加法形式：

```
Σ net(V) = 0
```

**质询**：这两个守恒是**不同层面**的约束：

1. **乘法恒等式**是价格水平上的**代数恒等式**——对任意三个价格 A, B, C，(A/B)(B/C)(C/A) = 1 永真。这不是物理约束，是数学恒等式。它不携带任何关于资本流转的信息。

2. **加法守恒**是流场方向上的**物理约束**——资本不凭空产生也不凭空消失。这是一个可以被违反的约束（违反时说明有外部流入/流出）。

v4 说"严格的守恒是乘法形式"，暗示乘法守恒比加法守恒更基本。但实际上：

- 乘法恒等式是**永真的**（trivially true），不需要"守恒"这个词
- 加法守恒是**有信息量的**（可以被违反，违反本身是信号）

把一个永真的代数恒等式称为"严格的守恒"，并暗示它比有信息量的物理约束更基本，这是**概念混淆**。

**判定**：v4 §2.3 的"乘法守恒"表述有误导性。乘法恒等式和加法守恒是不同层面的东西，不存在"哪个更严格"的关系。v4 需要明确区分：
- 代数恒等式（永真，用于一致性检查）
- 流场守恒（可违反，违反是信号）

### 3.3 补充：乘法恒等式对 MACD 的约束

虽然 (A/B)(B/C)(C/A) ≡ 1 在价格水平上永真，但在 MACD 层面：

```
ln(A/B) + ln(B/C) + ln(C/A) = 0  （永真）
```

由 MACD 的线性性（1.2 节已验证）：

```
MACD(ln(A/B)) + MACD(ln(B/C)) + MACD(ln(C/A)) = 0
```

这意味着**三角形上的 log-MACD 之和恒为零**。这是一个有用的一致性约束——如果计算出的三个 MACD 之和不为零，说明时间对齐或初始化有问题。

但这仍然是代数约束，不是流场守恒。v4 应该区分这两者。

### 4.2 "确定性来自穷尽+观测"

v4 的核心论证：27 种配置穷尽了所有可能 → 每种配置给出允许范围 → 观测缩小范围 → 确定性。

**质询**：

1. "穷尽"只是说没有遗漏配置，不等于每种配置都能给出有用的约束。如果 27 种中有 20 种的"允许范围"是全集（+/–/0 都可能），那么穷尽的信息量接近零。

2. "观测缩小范围"把确定性的来源从理论推导转移到了经验观测。这本身不是问题（缠论本来就是经验理论），但 v4 的定位是"形式化"——如果最终还是要靠观测，那形式化框架的附加值是什么？

3. v3 的问题是"过度声称确定性"。v4 的修复方向是"降低确定性声称"。但降低到什么程度？v4 没有给出精确的边界——哪些配置下确定性高（可以不观测直接推断），哪些配置下确定性低（必须观测）。

**判定**：v4 的修复方向正确（承认不确定性），但**没有量化不确定性的程度**。一个严格的版本应该对每种配置给出确定性等级。

## 五、新发现的问题

### 5.1 make_ratio_kline 的 high/low 计算错误

equivalence.py 中：

```python
result["high"] = a["high"] / b["high"]
result["low"] = a["low"] / b["low"]
```

这在数学上是错误的。比价 K 线的 high 应该是 max(A/B) 在该时间段内的最大值，不是 A 的 high 除以 B 的 high。

当 A 创新高而 B 也创新高时，A_high/B_high 可能接近 1（两者同步上涨），但实际比价的最高点可能出现在 A 高而 B 低的时刻（即 A_high/B_low）。

严格的比价 K 线 high = max(A_t/B_t) over all ticks in bar，但如果只有 OHLC 数据，近似上界是 A_high/B_low，近似下界是 A_low/B_high。

**判定**：这是代码层面的已知问题，但 v4 的理论框架建立在比价 K 线之上，如果比价 K 线的 high/low 计算有系统性偏差，会影响笔的划分和力度计算。v4 应该声明这个近似的边界。

### 5.2 级别扫描的循环依赖

v4 §7 要求"级别扫描前置步骤"——在做 K4 分析之前，先确认四个顶点在目标级别上都有已完成的走势。

但"已完成的走势"本身需要跑完整的缠论管线（笔→线段→中枢→走势类型）。这意味着：

1. 先对每个顶点的价格序列跑缠论管线（确定走势完成状态）
2. 然后对每条边的比价序列跑缠论管线（确定流转方向）
3. 然后做 K4 聚合

步骤 1 和步骤 2 是独立的（可以并行），但步骤 2 的**解读**依赖步骤 1 的结果（只有在 K4 浮现时才能做拓扑层分析）。

这不是循环依赖，但 v4 没有明确这个执行顺序。
