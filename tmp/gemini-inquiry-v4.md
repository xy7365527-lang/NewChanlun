# Gemini 视角质询报告：全球资本流转 v4

## 总体评价

v4 相对 v3 有实质性改进。两层结构的引入、定理降级为约束命题、C1-C3 条件化——这些都是正确方向。但 v4 在数学精确性上仍有若干缺口，部分"修复"实际上是把问题从一个位置移到了另一个位置。

---

## 1. 数学严格性

### 1.1 C1-C3 充分条件——不充分

**反例构造**：设 A/B 在第3层递归有已完成的上涨趋势（C1满足），幅度30%（C2满足），无破坏性回撤（C3满足）。B/C 同样满足 C1-C3，也是上涨趋势，幅度25%。

A/C = (A/B) × (B/C)。两者都在上涨，A/C 的价格水平确实在上升。但 A/C 的**走势类型**取决于 A/C 序列自身的递归构造——它可能形成的是盘整（一个大中枢内的震荡），而非趋势。

为什么？因为 A/B 的上涨和 B/C 的上涨在时间上可能有相位差。A/B 先涨后平，B/C 先平后涨。合成的 A/C 序列可能是：先涨（A/B主导）→ 平（两者抵消）→ 再涨（B/C主导），形成一个中枢+两段离开，即盘整而非趋势。

**结论**：C1-C3 保证了派生边的**累计变化率**同号，但不保证派生边的**走势类型**与独立边一致。走势类型是组合判定（中枢结构），不是累计变化率的函数。

**建议**：C1-C3 应降级为"必要条件+高概率指示"，而非"充分条件"。或者增加 C4：派生边自身的走势类型已通过第一层分析确认。但这就回到了"需要观测"——与 v4 §5 的立场一致，只是 §2.4 的措辞需要调整。

### 1.2 log-MACD 线性可加性——严格成立，但有隐含条件

v4 声称：MACD(ln A/C) = MACD(ln A/B) + MACD(ln B/C)

推导：ln(A/C) = ln(A/B) + ln(B/C)（对数的加法性）。

MACD = EMA_fast - EMA_slow。EMA 是线性算子吗？

EMA 的递推公式：EMA_t = α × x_t + (1-α) × EMA_{t-1}

这是线性递推：如果 x_t = y_t + z_t，则 EMA(x)_t = EMA(y)_t + EMA(z)_t（初始值为0时严格成立）。

**但**：初始值不为0时，EMA 的线性性依赖于初始条件相同。实际计算中，三条序列（ln A/C, ln A/B, ln B/C）的 EMA 初始值分别设定，可能导致暂态偏差。

**结论**：log-MACD 的可加性在稳态下严格成立，在序列起始的暂态期（约 2×slow_period 根K线）有微小偏差。工程上可忽略，但数学上应注明。

### 1.3 "允许范围"缺乏精确描述

v4 反复说"27种配置给出派生边的允许范围"，但从未给出这个范围的数学描述。

对于配置(+,+,+)，派生边 E/C 的允许范围是什么？v4 只说"取决于相对力度，需实际观测"。但数学上可以更精确：

- E/$ = + 且 C/$ = + → E/C = (E/$)/(C/$)
- 如果 E/$ 涨幅 > C/$ 涨幅 → E/C = +
- 如果 E/$ 涨幅 < C/$ 涨幅 → E/C = –
- 如果 E/$ 涨幅 ≈ C/$ 涨幅 → E/C = 0

所以配置(+,+,+)下，E/C 的允许范围是 {+, –, 0}——即**无约束**。这意味着独立边全正时，对派生边完全没有约束力。

对于配置(+,–,–)，E/C = (E/$)/(C/$)，E/$ 涨 C/$ 跌 → E/C 必然涨。允许范围 = {+}。

**建议**：v4 应该给出 27 种配置各自的派生边允许范围表。这是可以穷举的，而且是本文最有价值的产出之一。不给出这个表，"约束命题"就是空壳。

## 2. 两层结构的完备性

### 2.1 存在中间地带

v4 的两层划分：
- 第一层：单条比价线独立分析
- 第二层：K4 代数约束

但存在第三种操作：**跨边结构比较**。例如：E/$ 和 C/$ 各自独立跑缠论（第一层），然后比较两者的背驰时间点是否接近。这不是代数约束（不涉及 E/C = E/$/C/$），但也不是纯独立分析——它利用了两条边之间的**时间同步性**信息。

这种操作在 v4 的框架中无处安放。它不需要 C1-C3 条件（不涉及代数约束传递），但它确实利用了多条边的联合信息。

**建议**：承认存在"1.5层"——跨边结构比较，不依赖代数约束但利用时间同步性。或者将其归入第一层的扩展（"多条第一层分析的时间对齐比较"）。

### 2.2 K4 浮现性判定不够精确

"足够多的顶点对满足等价条件"——多少是足够？

数学上：K4 有 6 条边。如果只有 3 条边合法，你有一个三角形子图。三角形上可以做循环乘积约束检验（A/B × B/C × C/A = 1），但不能做完整的 27 配置读取。

**建议**：给出子图的分类——3条边（三角形）、4条边、5条边、6条边（完整K4），以及每种子图上可做的操作。

## 3. 定义一致性

### 3.1 级别依赖等价关系 vs C-1/C-2/C-3

v4 §2.5 引入的"两个资产在递归层级L上等价"是一个**新概念**，与 dengjia.md 的 C-1/C-2/C-3 不在同一层面。

C-1/C-2/C-3 是**数据层**筛选：这两个标的的比价K线值不值得看。
v4 的级别依赖等价是**结构层**判定：这两个标的在特定递归层级上是否都有已完成走势。

两者是不同层面的条件，应该明确为 C-4（结构完成条件），而非对 C-2 的扩展。C-2 检查的是"比价序列是否退化"，C-4 检查的是"两端走势是否在目标层级上已完成"。

### 3.2 乘法守恒 vs 加法守恒——不矛盾，但需要显式化关系

v4 §2.3：A/B × B/C × C/A ≡ 1（乘法恒等式，价格水平）
liuzhuan.md：Σ net(V) = 0（加法守恒，流场方向）

两者不矛盾——它们在不同层面上运作。乘法恒等式约束价格水平，加法守恒约束流场方向。但 v4 说"严格的守恒是乘法形式"暗示加法形式不严格，这与 liuzhuan.md 的表述冲突。

实际上：加法守恒 Σnet(V)=0 在 net(V) 的定义下是精确的（每条边贡献 +1 给一端 -1 给另一端，总和为0）。它不是近似。v4 §2.3 说的"加法守恒只在小波动时近似成立"指的是**价格变化率**的加法性（r_AC ≈ r_AB + r_BC），不是 net flow 的加法性。

**建议**：v4 §2.3 需要区分两种"加法"：价格变化率的加法（近似）vs 流场方向计数的加法（精确）。

### 3.3 三态配置 vs net(V) 整数计数

v4 的配置分类用边的三态(+/–/0)，liuzhuan.md 用顶点的 net(V)。两者是对偶的：

- 边三态 → 可以计算每个顶点的 net(V)
- net(V) → 可以反推边的约束

但映射不是一一对应的。同一个 net(V) 分布可以对应多种边配置。v4 没有显式化这个映射。

## 4. v3 问题是否真正修复

### 4.1 模式D——问题被移动而非解决

v3：(+,+,+) → 派生边≈0（错误）
v4：(+,+,+) → 派生边需观测（正确但不完整）

v4 承认了 v3 的错误，但没有给出替代方案。"需观测"不是答案，是承认不知道答案。

如 1.3 所述，(+,+,+) 下派生边的允许范围是 {+,–,0}——完全无约束。这意味着独立边全正时，K4 关系层对派生边**没有任何信息**。你必须完全依赖第一层（独立观测派生边）。

这不是缺陷——这是数学事实。但 v4 应该直接说出来，而不是用"需观测"模糊处理。

### 4.2 "确定性来自穷尽+观测"——逻辑上成立

v4 的核心论点：27种独立配置穷尽输入空间 + 观测派生边消歧 → 唯一全局读取。

这在逻辑上是成立的。穷尽性来自 3^3=27 的组合完备性。消歧来自实际观测。两者结合给出唯一读取。

但"观测"本身有不确定性（走势可能在构建中）——这不是把问题移到了另一个地方，而是正确地识别了不确定性的来源：不确定性不在配置分类中（那是穷尽的），而在走势判定中（那是时间依赖的）。v4 的 unknown 机制正确处理了这一点。
