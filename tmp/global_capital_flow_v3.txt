零、起点
缠论在单标的维度上是完备的。给定一条K线序列，走势必完美定理保证了走势结构的完全可分类性——笔、线段、中枢、走势类型、买卖点，每一层都有穷尽的分类和确定的操作应答。
但缠论有一个缺口：选股。标的之间的选择，缠师说用基本面和经验。这是他整个体系里唯一需要概率论和外部知识的位置。
缠论的区间套解决了时间维度上的选择问题（什么时候操作），但"操作什么"不在区间套的管辖范围内。基本面填补这个缺口的方式是倒果为因的——利润、营收是资本已经配置完毕后的会计结果，用上一轮配置的结果预测下一轮配置的方向，逻辑上是滞后的。
本文的核心命题：比价K线上的缠论分析可以填补这个缺口。缠师已经允许比价K线作为独立系统纳入缠论分析。将比价分析扩展到全球资产类别之间，资本流转的全局图景从比价走势结构中直接涌现。由此，选股从经验判断变为比价走势分析的递归下钻——和时间维度上的区间套是同一种操作。

───────────
一、比价K线
1.1 定义
这不需要论证——价格除以价格得到价格，K线就是K线。走势必完美定理的证明只依赖K线序列的组合性质，不依赖K线的来源。缠师本人已经明确说过：可交易的独立系统都可以用缠论分析。
1.2 本体论意义
比价K线把缠论的定义域从"一个资产的价格序列"扩展到"任意两个资产之间的关系序列"。走势必完美不再只是说"每个标的的走势有完备结构"，而是说"资产之间的关系本身有完备结构"。
比价走势直接呈现的是资本正在如何在两个资产之间重新配置——不是滞后的财报数据，是实时的、正在发生的结构变化。资本流转比基本面更为根本。

───────────
二、数学基础
以下数学性质不是框架的骨架，而是保证完全分类不遗漏不重复的必要工具。没有这些，完全分类就不严格。
2.1 射影化
比价操作的数学本质是射影化（projectivization）。四个价格时间序列取商后，比价序列生活在正射影空间中——只有比值有意义，绝对标度被消去。丢失的是绝对价格（缠论不需要），保留的是比例结构（缠论需要）。
2.2 独立性约束
n 个标的产生 n(n-1)/2 个比价对。但存在代数约束：
A/B × B/C = A/C
任何三个标的的三条比价线中只有两条独立。n 个标的的独立比价线数为 n-1。
对K4图：4个顶点，6条边，圈秩 = 6-4+1 = 3。只有3条独立边。选定一个基准标的（比如黄金），其余3条边就是完备基底，其余边是基底的乘积。基准的选择决定了你看到什么。
2.3 循环乘积约束
A/B × B/C × C/A ≡ 1
这是恒等式，永远成立。它告诉你哪些走势类型配置在数学上不可能，从而减少完全分类的搜索空间。先前假设的加法守恒（四个顶点 net flow 之和为零）只在比价变动小时近似成立，大幅波动时会漂移。严格的守恒是乘法形式的。
2.4 说明：独立性对方向的约束
代数约束是关于水平的（A/C的值等于A/B×B/C的值）。走势方向是关于变化率的。乘积的变化率不等于变化率的乘积，所以两条边的方向不能完全决定第三条边的方向。但在趋势明确时，约束是强的：如果A/B和B/C都在强势上涨趋势中，A/C几乎不可能处于下跌趋势。这个"几乎不可能"的程度取决于趋势的强度和级别。
实践意义：纯资产三角形内部"三边同向"的信息量比表面上少，其中一部分是数学冗余。跨三角形的一致性（纯资产三角形与现金边之间）才是完全独立的信号。

三、四矩阵与K4图
3.1 四矩阵的两个来源
自下而上（缠师路径）
对大量比价对运行缠论分析，发现：某些比价对长期处于盘整（它们属于"同一类"——内部相对价格没有趋势性变化），某些比价对有明确的大级别趋势（资本在它们之间有方向性流动）。前者自然聚类成一个"角"，后者定义了角与角之间的边。拓扑是走势分类的结果，不是前提。
自上而下（卢麒元路径）
资本主义经济周期的结构分析：资本在扩张期从现金流向股票和商品，在收缩期从股票和房地产流回现金。四矩阵——动产（股票债券）、不动产（房产）、商品（大宗）、现金（含黄金、存款、数字货币）——不是统计聚类，而是关于资本流转的结构性命题。
交汇
缠师路径给出方法论的合法性——比价分析在缠论内部是自洽的。卢麒元路径给出先验结构和聚类转换的条件——走势分类只能告诉你"当下的聚类是这样的"，卢麒元能告诉你"什么条件下聚类会重组"。
验证方法：用历史数据对主要资产类别跑全量比价分析，看走势结构涌现出的聚类和四矩阵的吻合度。

四个顶点（EQUITY, COMMODITY, REALESTATE, CASH）两两相连，形6条边。每条边是一条比价K线，对其运行缠论分析。

3.3 现金角的双重身份
现金角同时是矩阵的一个顶点和整个矩阵的度量基准——其他三个角的价格都用现金角来度量。控制了度量基准就控制了整个流转图的读法。这是美元霸权在此框架中的数学表达。
3.4 结算锚定物子图
现金角内部有结构。美元、国债、黄金、石油之间的比价关系揭示度量体系本身的健康度。当锚定物之间的比价在盘整（均衡），四矩阵信号可信。当锚定物之间出现趋势性分裂，度量基准本身裂开了。
锚定物子图是整个系统最底层的监控层：在读四矩阵流转之前，先读结算锚定物子图的健康度。

四、缠论分析层
对每条比价K线运行完整的缠论管线：包含关系处理 → 分型识别 → 笔构造 → 线段构造 → 中枢识别 → 走势类型判定 → 背驰判定 → 买卖点识别。和单标的的缠论分析完全一样，因为比价K线就是K线。
4.1 背驰与MACD
缠论判定背驰用MACD面积比较。比价K线上的MACD面积给出的是资本流转的力度变化——不是"流了多少"（绝对流量），而是"流转在加速还是减速"（力度的导数）。背驰 = 流转动力衰竭，走势即将反转。
这取消了"流量"问题。缠论从来不处理绝对量。方向由走势类型给出，力度变化由MACD面积给出，转折点由背驰给出。三者都在缠论语法之内。

4.3 级别结构
"构建中"是在某个特定级别上说的。5分钟级别未定，30分钟级别可能已定。每条边取其走势类型已确定的最低级别参与全局读取。
级别差异本身就是信息：如果 E/C 在日线级别才确定而 E/$ 在5分钟就确定了，前者是慢速大尺度的资本重配置，后者是快速的短期资金进出。级别差异直接告诉你不同流转路径的时间常数。
拓扑不变性的精确位置：在给定级别上、走势类型已确定的边上成立。换基准、换周期，只要走势方向判读不变，全局读取不变。级别越大，已确定的比例越高，全局图景越稳定。这是"走势必完美"在多资产空间中的自然延伸。

五、K4走势类型配置的完全分类定理
这是本文的核心定理。它对全球资本流转的地位，等同于走势类型分类对单标的走势的地位。没有它，全局图景的读取就是"看图说话"；有了它，全局图景的读取就是穷尽了一切可能性的确定性判断。
5.1 状态空间
每条边有三种状态：上涨趋势（+）、下跌趋势（–）、盘整（0）。构建中的边不参与分类——它们被排除在外，等待走势完成。
6条边×3种状态 = 729种表观配置。但由于独立性约束（只有3条独立边），大量配置被排除或约束。
5.2 独立基底与派生边
选定现金角为基准。3条独立边为：
E/$， C/$， R/$
3条派生边为：
E/C = (E/$) / (C/$)
E/R = (E/$) / (R/$)
C/R = (C/$) / (R/$)
独立基底有3条边 × 3种状态 = 27种独立配置。每种独立配置部分约束了3条派生边的方向。
5.3 定理陈述
5.4 分类枚举（核心模式）
以27种独立配置中提取具有代表性的核心模式：
模式 A：全面流入单角（强共振）
独立基底状态：E/$ = +，C/$ = –，R/$ = –
派生边约束：E/C ≈ +（强），E/R ≈ +（强），C/R ≈ 0 或弱方向
全局读取：资本从商品、房地产、现金同时流入动产。动产角是强汇点。
操作方向：在动产角内部下钻找买点。
模式 B：轮动（资本在两角间流转）
独立基底状态：E/$ = +，C/$ = –，R/$ = 0
派生边约束：E/C ≈ +（强），E/R ≈ +（弱），C/R ≈ –（弱）
全局读取：资本主要从商品流向动产，房地产和现金角相对均衡。
操作方向：做多动产、做空商品，或纯粹在动产角内找买点。
模式 C：全面盘整（无方向）
独立基底状态：E/$ = 0，C/$ = 0，R/$ = 0
派生边约束：全部 ≈ 0
全局读取：四个角之间无方向性资本流转。全局均衡。
操作方向：角内部的单标的操作，不依赖全局流转方向。
模式 D：分裂（纯资产边与现金边矛盾）
独立基底状态：E/$ = +，C/$ = +，R/$ = +
派生边约束：纯资产边全部 ≈ 0（三个资产同涨，相对关系不变）
全局读取：不是"资本流入所有资产"，而是现金角在贬值（美元贬值/通胀）。纯资产三角形的均衡确认了这一点——资产之间没有真实流转，只是尺子变了。
操作方向：核查锚定物子图。如果M2/黄金上涨，确认是货币扩张。可能需要对冲货币贬值而非追逐资产名义涨幅。
模式 E：危机（全面流向现金）
独立基底状态：E/$ = –，C/$ = –，R/$ = –
派生边约束：纯资产边全部 ≈ 0（同跌，相对关系不变）
全局读取：资本从所有资产同时流向现金。典型的流动性危机或通缩模式。
操作方向：持有现金或现金等价物（黄金），等待背驰信号。
模式 F：背驰共振（全局反转信号）
任何模式的边中，多条同时出现MACD背驰。
全局读取：当前流转模式的动力在衰竭，全局流转方向即将反转。
操作方向：准备从当前模式切换到下一个模式。这是最重要的交易信号。

六、区间套下钻：选股成为定理
6.1 横向区间套
缠论的区间套原来只解决纵向问题——同一标的的不同时间级别。比价框架将区间套延伸到了横向：
哪个角 → 哪个板块 → 哪个标的 → 什么时候。全部在缠论的形式语法之内。没有一步需要基本面分析或经验判断。
6.2 递归性
上下层的关系是双向的。上层流场约束下层选择（只在资本流入的角里找买点）。下层结构修正上层判读（角内部多个标的同时背驰可能预示流场方向即将改变）。和时间维度上大小级别的递归校验完全一样。
6.3 国家/区域维度
同一类资产在不同国家之间也有资本流转。美股/A股的比价K线就是一条有缠论结构的K线。不需要单独设计"区域维度"——它已经在比价K线里了。哪条跨区域比价线出现了最清晰的缠论结构，那条就是当下最需要关注的跨区域流转路径。

七、操作流程：从背驰到下钻
27种配置是穷尽分类——保证你不会遇到一个"没见过的状态"。但日常操作不是坐在那里查表。操作的入口始终是背驰。
7.1 入口：背驰
你在某个角的代表标的上看到背驰。比如SPY在某个级别出现顶背驰。这是单标的缠论，你已经会了。背驰告诉你：动产角即将失血。但失血往哪里去？单标的分析不知道。
7.2 比价线告诉你方向、速度、力度
这时候看从背驰角出发的三条比价线。不是六条全看，是看三条。比如动产角背驰，看 E/C、E/R、E/$：
三个你关心的东西——流向、流速、流量变化——分别对应走势方向、级别、MACD面积变化。全部是缠论自己的语法。不需要知道"流了多少亿"。缠论从来不处理绝对量。
7.3 四步操作流程
第一步：发现背驰
在某个角的代表标的上看到背驰。这是入口。
第二步：读比价线
看从背驰角出发的三条比价线。哪条有趋势、什么级别、MACD面积在扩大还是缩小。这告诉你资本正在流向哪里、多快、动力是否还在。
第三步：下钻目标角
确定了流向后，到目标角内部下钻——在那个角的板块和标的里找缠论买点。
第四步：纯资产边校验
如果 E/C 说资本流向商品，检查 C/R。如果 C/R 也在上涨趋势，商品不只是相对动产走强，是相对所有非现金资产都在走强，信号更硬。如果 C/R 盘整，只是动产和商品之间的轮动，不是商品的全面走强。
7.4 27种配置表的作用
27种配置不是你每天查的东西。它是后盾——无论三条独立边是什么组合，你都已经知道全局读取是什么。日常操作的入口始终是背驰，然后比价线告诉你方向、速度、力度。

八、M2与宏观边界条件
M2属于结算锚定物子图，不属于六条边的比价分析。MACD在每条边的比价K线上提供力度变化（流场的内在度量），M2在锚定物子图上提供宏观背景（流场存在的边界条件）。前者回答"这条路径上的流转在加速还是减速"，后者回答"整个流转发生的池子在扩张还是收缩"。

九、定位
缠师说过缠论适用于一切可以被K线化的独立系统。比价K线是独立系统。将比价分析扩展到全球资产类别，用K4完全分类定理穷尽所有可能的全局流转模式，用区间套从全局流转方向一路下钻到具体标的的买卖点——这就是缠论在选择维度上的自然延伸。不是新理论，是缠论本身。
数学基础（射影化、独立性约束、循环乘积）保证了完全分类的严格性。政治经济学维度（卢麒元的四矩阵）给出了先验结构和聚类转换的条件。两者不是缠论的替代品，是缠论在全球尺度上运行时不得不理解的技术基础。
资本流转比基本面更为根本。基本面是资本已经配置完毕后的会计记录。比价走势是资本正在进行的重新配置的实时呈现。缠论可以读后者而不能读前者。由此，选股从缠论体系的经验残余变为形式语法的内在推论。概率论的剩余被取消了。
