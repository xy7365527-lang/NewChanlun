## 1. 配置空间的级别递归（R1-R3）

### 核心命题：配置空间没有独立的递归构造

配置空间的"级别"不是从配置事件序列自下而上递归构造的，而是**继承自边层（比价K线）的递归级别**。

**定义依据**：
- v4 §4.3："'构建中'是在某个特定递归层级上说的。第2层走势未定，第3层走势可能已定。每条边取其走势类型已确定的递归层级参与全局读取。"
- v4 §2.5："级别越大，K4越完整；级别越小，K4越碎片化。"
- `level_recursion.md` v1.0：级别 = 递归层级（level_id），从 Move[0]=Segment 逐级向上构造。

**理由**：配置空间的状态（27种K4配置之一）是从6条边的走势状态**读取**出来的，不是从配置序列自身**构造**出来的。走势必完美定理保证每条比价K线有完备的递归结构，但不保证配置状态的时间序列有同样的结构。

### R1: 配置层级别 k 的定义

```
Config[k] = K4Config 在递归层级 k 上的读取

具体地：
  对每条边 e ∈ {E/$, C/$, R/$, E/C, E/R, C/R}：
    若 e 在层级 k 上有已完成走势类型（Move[k].settled = True）：
      edge_state(e, k) = 该走势类型的方向（+/-/0）
    否则：
      edge_state(e, k) = unknown（不参与配置读取）

  Config[k] = K4Config(
    e_cash = edge_state(E/$, k),
    c_cash = edge_state(C/$, k),
    r_cash = edge_state(R/$, k)
  )
  前提：三条独立边在层级 k 上都有已完成走势类型
  否则：Config[k] 退化为 K3 子图配置（见 v4 §5.5 附录）
```

### R2: 级别 k 与 k+1 的关系

配置层级别 k+1 不是"级别 k 配置的组合"，而是**边层级别 k+1 走势完成后的新读取**。

```
Config[k] → Config[k+1] 的转换不是组合操作，而是：
  每条边各自从 Move[k] 递归构造 Center[k+1] → Move[k+1]
  当足够多的边在 k+1 层完成走势后，Config[k+1] 浮现
```

**关键性质**：
- Config[k+1] 比 Config[k] 更稳定（高级别走势完成需要更长时间）
- Config[k+1] 比 Config[k] 更完整（高级别上更多边有已完成走势——v4 §2.5）
- Config[k+1] 的方向可能与 Config[k] 不同（这就是多层级配置叠加问题，见§5）

### R3: 配置层级别与边层级别的对应关系

**一对一映射**：配置层级别 k = 边层级别 k。

```
配置层级别 k 的一个"笔" ≠ 边层级别 k 的一个笔
配置层级别 k 的一个"状态" = 边层级别 k 的走势方向的聚合读取

配置层没有自己的笔/线段/中枢——它的结构完全由边层的递归结构决定。
```

**边界条件**：
- 如果将 net($) 视为时间序列并在其上运行缠论递归，则配置层会获得独立的递归结构。但 net($) ∈ {-3,-2,-1,0,+1,+2,+3} 是离散值，不满足缠论K线的连续性前提。在离散序列上运行包含处理→分型→笔的管线，语义不明确。
- 如果将来定义连续的"极性指数"（如 ln(E/$) + ln(C/$) + ln(R/$) 的加权和），则可以在其上运行缠论递归，配置层将获得独立的级别结构。但这是**新构造**，需要独立论证其走势必完美性质。当前不在已结算定义范围内。

## 2. 配置空间的买卖点精确定义

### 前置问题：配置空间的"背驰"是什么？

**结论：配置空间的背驰 = 结构性背驰（边层背驰的聚合），不是极性指数序列的 MACD 背驰。**

理由：
1. net($) 是离散值，MACD 在离散序列上不具备缠论要求的力度度量性质
2. 缠论的背驰定义要求"趋势中最后一段离开中枢的力度弱于前一段"——这预设了中枢和走势类型的存在，而配置空间没有独立的中枢结构
3. 边层的每条比价K线各自有严格定义的背驰（`beichi.md` v1.1 已结算），配置空间的背驰应从边层背驰聚合涌现

**配置空间背驰的形式定义** [新缠论]：

```
ConfigDivergence(k) 成立，当且仅当：
  在递归层级 k 上，驱动当前 Config[k] 的独立边中，
  至少 2 条同时出现背驰（趋势背驰或盘整背驰）。

"驱动当前配置"的含义：
  若 Config[k] = (+,+,+)（risk-on），驱动边 = {E/$, C/$, R/$}
  若 Config[k] = (+,-,-)（动产独涨），驱动边 = {E/$}（主导方向），
    但背驰判定需要 E/$ 自身背驰 + 至少一条派生边确认
```

### 2.1 配置空间第一类买点（Config-1B）

**定义**：在递归层级 k 上，K4 配置处于"risk-off 趋势"中，驱动 risk-off 的边出现结构性背驰。

**前提条件**：
1. Config[k] 在时间上经历了至少两个连续的 risk-off 阶段（net($) ≥ +2 持续，中间有 net($) 回落但不翻负的"中枢"）
2. 驱动 risk-off 的独立边（E/$=-, C/$=-, R/$=-）在层级 k 上各自处于下跌趋势

**触发条件**：
```
Config-1B(k) 成立，当且仅当：
  (1) 至少 2 条独立边在层级 k 上出现趋势背驰（底背驰）
  (2) 背驰的边是驱动当前 risk-off 配置的边
  (3) 背驰在各边上独立确认（Divergence.confirmed = True）
```

**安全性保证**：每条边的背驰独立满足缠论背驰-买卖点定理（`beichi.md` v1.1）→ 每条边至少回拉到其最后一个中枢 → 配置从 risk-off 向 risk-on 方向转变。

**失败条件**：
- 仅 1 条边背驰，其余 2 条继续下跌 → 不是 Config-1B，是单边的边层 1B
- 背驰后回拉不足以改变 Config[k] 的 net($) 符号 → 配置层盘整，非趋势反转

### 2.2 配置空间第一类卖点（Config-1S）

**定义**：对称于 Config-1B。在递归层级 k 上，K4 配置处于"risk-on 趋势"中（net($) ≤ -2 持续），驱动 risk-on 的边出现结构性背驰（顶背驰）。

```
Config-1S(k) 成立，当且仅当：
  (1) 至少 2 条独立边在层级 k 上出现趋势背驰（顶背驰）
  (2) 背驰的边是驱动当前 risk-on 配置的边
  (3) 背驰在各边上独立确认
```

### 2.3 配置空间第二类买点（Config-2B）

**定义**：Config-1B 出现后，配置从 risk-off 回升，然后再次回落但不重新进入 risk-off 趋势的那个点。

```
Config-2B(k) 成立，当且仅当：
  (1) Config-1B(k) 已出现
  (2) 之后配置向 risk-on 方向移动（net($) 减小）
  (3) 然后配置再次向 risk-off 方向回落
  (4) 回落中，驱动回落的边在层级 k-1 上出现第一类买点
      （买卖点定律一：二类买卖点由次级别一类买卖点构成）
  (5) 回落不重新进入 risk-off 趋势（net($) 不重新达到 +2 以上的持续状态）
```

**安全性保证**：继承自缠论买卖点定律一 + 走势终完美。

### 2.4 配置空间第二类卖点（Config-2S）

对称于 Config-2B。Config-1S 后回升不重新进入 risk-on 趋势。

### 2.5 配置空间第三类买点（Config-3B）

**定义**：配置从某个"配置中枢"向 risk-on 方向离开后，回试不跌破中枢上沿。

```
Config-3B(k) 成立，当且仅当：
  (1) 存在一个"配置中枢"：Config[k] 在某个 net($) 区间内震荡
      （至少 3 条边在层级 k 上各自经历了一个中枢）
  (2) 配置向 risk-on 方向离开（net($) 显著减小）
  (3) 配置回试，但 net($) 不重新回到中枢区间的 risk-off 端
  (4) 回试中，至少 2 条边的回试不跌破各自中枢的 ZG
```

**注意**：配置空间的"中枢"不是严格定义的（配置空间没有独立的中枢构造）。这里的"配置中枢"是一个操作性概念——多条边同时处于各自的中枢内，导致配置在一个区间内震荡。

### 2.6 配置空间第三类卖点（Config-3S）

对称于 Config-3B。

## 3. 共振条件形式化

### 3.1 共振的定义

**共振** [新缠论] = 不同层次的买卖点在时间上重叠出现。

```
三层结构：
  配置层（K4 配置）→ 全局方向
  边层（比价K线）  → 角级别方向
  底层（单标的K线）→ 标的级别方向

共振 = 三层中 ≥2 层同时给出同方向的买卖点信号
```

### 3.2 共振强度度量

```
Resonance(t) = Σ layer_signal(t)

其中 layer_signal(t) ∈ {0, 1}：
  配置层：Config-BSP 在时间 t 附近触发 → 1
  边层：  从背驰角出发的比价线 BSP 在时间 t 附近触发 → 1
  底层：  目标标的的 BSP 在时间 t 附近触发 → 1

Resonance = 3：三层共振（最高确定性）
Resonance = 2：双层共振（高确定性）
Resonance = 1：单层信号（标准确定性）
Resonance = 0：无信号
```

### 3.3 共振的级别匹配

**问题**：配置层级别 k 的信号应与边层什么级别的信号共振？

**回答**：同级别。

```
共振匹配规则：
  Config[k] 的买卖点 ↔ 边层级别 k 的买卖点 ↔ 底层级别 k 的买卖点

理由：
  Config[k] 是从边层级别 k 的走势状态读取的（R3）
  因此 Config[k] 的转折必然伴随边层级别 k 的转折
  底层级别 k 的转折是边层级别 k 转折的必要条件
    （低级别背驰是高级别背驰的必要条件——beichi.md v1.1 区间套定理）
```

**边界条件**：
- 配置层级别 3 的信号 + 边层级别 1 的信号 ≠ 共振（级别不匹配）
- 配置层级别 3 的信号 + 边层级别 3 的信号 = 共振（同级别）
- 但边层级别 3 的信号内部可以用区间套下钻到级别 1 精确定位

### 3.4 共振与 v4 模式F 的关系

v4 §5.4 模式F（背驰共振）："任何模式的边中，多条同时出现MACD背驰。"

模式F 是边层内部的共振（多条边同时背驰），对应本文的 ConfigDivergence。
三层共振 = 模式F（边层共振）+ 底层标的背驰 + 配置层趋势反转。

## 4. 区间套统一

### 4.1 纵向区间套（时间维度，标准缠论）

```
在同一条K线序列上：
  级别 k 背驰段 D[k] → 范围 [a, b]
  级别 k-1 在 [a, b] 内找背驰段 D[k-1] → [a', b'] ⊂ [a, b]
  ...
  最低级别找到精确转折点
```

**已实现**：`nested_divergence_search()` + `RecursiveStack`（`beichi.md` v1.1 #5 已结算）

### 4.2 横向区间套（空间维度，v4 §6.1）

```
在跨标的维度上：
  配置层：哪个角正在接收资本（Config[k] 的流转方向）
  边层：  角内哪个板块最强（板块间比价走势）
  底层：  板块内哪个标的有买点（单标的缠论）

  Config[k] 确定方向 → 边层确定板块 → 底层确定标的和时机
```

**原文依据**：v4 §6.1 "哪个角 → 哪个板块 → 哪个标的 → 什么时候。全部在缠论的形式语法之内。"

### 4.3 统一形式

**命题**：纵向区间套和横向区间套是同一个递归操作的两个实例。

```
统一形式：
  高层确定方向（约束集合），低层确定精确位置（在约束集合内搜索）

纵向：高级别走势方向 → 低级别精确转折点
横向：配置层流转方向 → 边层目标角 → 底层目标标的

两者的共同结构：
  (1) 高层给出约束（方向 + 范围）
  (2) 低层在约束内搜索（背驰 / 买卖点）
  (3) 搜索结果反馈高层（低层背驰确认高层背驰 / 角内标的背驰确认流转方向反转）
```

**同构论证**：

| 属性 | 纵向区间套 | 横向区间套 |
|------|-----------|-----------|
| 高层 | 级别 k 走势 | 配置层 Config[k] |
| 低层 | 级别 k-1 走势 | 边层 / 底层 |
| 约束传递 | 背驰段范围收缩 | 流转方向约束标的选择 |
| 反馈 | 低级别背驰 → 高级别背驰的必要条件 | 角内标的背驰 → 流转方向反转的先行信号 |
| 终止 | 最低可观察级别 | 具体标的的具体买卖点 |

**v4 §6.2 的双向性**："上下层的关系是双向的。上层流场约束下层选择（只在资本流入的角里找买点）。下层结构修正上层判读（角内部多个标的同时背驰可能预示流场方向即将改变）。"

这与纵向区间套的双向性完全对应：高级别约束低级别搜索范围，低级别背驰是高级别背驰的必要条件。

## 5. 多层级配置叠加

### 5.1 问题陈述

在递归层级 3 上，Config[3] = (+,+,+)（全面 risk-on）。
在递归层级 1 上，Config[1] = (-,-,-)（全面 risk-off）。

这不是矛盾——这是标准的缠论多级别结构：大级别上涨趋势中的小级别回调。

### 5.2 处理原则：大级别优先

**定义依据**：缠论基本原则——大级别走势方向决定操作方向，小级别走势确定精确位置。

```
决策规则：
  方向 = Config[k_max]（最大已完成级别的配置方向）
  位置 = Config[k_min]（最小级别的配置状态确定入场时机）
```

### 5.3 叠加分类

```
同向叠加（增强）：
  Config[3] = (+,+,+) 且 Config[1] = (+,+,+)
  → 所有级别一致 risk-on，信号最强
  → 操作：在目标角内积极寻找买点

反向叠加（减弱）：
  Config[3] = (+,+,+) 且 Config[1] = (-,-,-)
  → 大级别 risk-on，小级别 risk-off（回调中）
  → 操作：等待小级别 risk-off 结束（Config[1] 出现 Config-1B），
          然后在大级别方向上入场

正交叠加（独立）：
  Config[3] = (+,0,0) 且 Config[1] = (0,+,0)
  → 大级别仅动产涨，小级别仅商品涨
  → 两个级别关注不同的角，信号独立
  → 操作：以大级别方向为主（动产角），
          小级别商品角信号作为短线机会但不改变主方向
```

### 5.4 冲突处理的形式化

```
ConflictResolution(Config[k_high], Config[k_low]):

  case 同向:
    strength = max  # 信号增强
    action = 积极入场

  case 反向:
    strength = reduced  # 信号减弱
    action = 等待 Config[k_low] 转向与 Config[k_high] 一致
    # 这就是纵向区间套在配置空间的应用：
    # 大级别确定方向，小级别确定时机

  case 正交:
    strength = Config[k_high] 的强度不变
    action = 以 Config[k_high] 为主，Config[k_low] 的正交信号
             作为独立的短线机会
```

## 结果包六要素

### 1. 结论

- 配置空间的级别递归继承自边层递归级别，不是独立构造（R1-R3）
- 配置空间的背驰 = 结构性背驰（多条边同时背驰），不是极性指数的 MACD 背驰
- 配置空间的三类买卖点通过边层买卖点的聚合定义，保持与缠论原始定义的同构
- 共振 = 配置层 + 边层 + 底层同时给出同方向信号，级别必须匹配
- 纵向区间套与横向区间套是同一递归操作的两个实例
- 多层级配置叠加遵循大级别优先原则

### 2. 定义依据

- **级别递归**：`level_recursion.md` v1.0（级别 = 递归层级，Move[0]=Segment 为归纳基底）
- **买卖点**：`maimai.md` v1.0（三类买卖点完备性定理，背驰-买卖点定理）
- **背驰**：`beichi.md` v1.1（趋势背驰/盘整背驰定义，区间套，MACD三维度OR）
- **流转关系**：`liuzhuan.md` v1.0（net(V) 共振判定，守恒约束）
- **等价关系**：`dengjia.md` v1.2（C-1/C-2/C-3 筛选 + K4 结构前提）
- **v4 文本**：§2.5（两层结构）、§4.3（级别结构）、§5.4 模式F（背驰共振）、§6.1-6.2（横向区间套）、§7（操作流程）
- **K4 配置**：`transition_topology.py`（27种配置枚举，net_cash，派生边约束）

### 3. 边界条件

- **配置层独立递归的翻转条件**：如果定义连续的极性指数（如 Σ ln(X/$) 的加权和）并证明其满足走势必完美，则配置层获得独立递归结构，本文的 R1-R3 需要重写
- **Config-1B 退化条件**：如果仅 1 条边背驰而非 ≥2 条，则不构成配置层买点，仅为边层买点
- **K4 不完整时**：Config[k] 退化为 K3 子图配置，买卖点定义仍适用但确定性降低
- **共振级别不匹配时**：不构成共振，各层信号独立评估
- **全局盘整态**（Config #3, 全0）：无配置层买卖点信号，退回角内操作

### 4. 下游推论

- **操作策略**：Config-1B 是最大级别入场信号（全局 risk-off 终结），应在目标角内积极下钻找买点
- **风控**：Config-1S 是最大级别离场信号（全局 risk-on 终结），应减仓或对冲
- **选股**：横向区间套将选股纳入缠论形式语法——Config[k] 确定角 → 边层确定板块 → 底层确定标的
- **代码架构**：Config-BSP 检测器需要聚合多条边的 Divergence 输出，不是独立的管线
