## 一、横向区间套六步的入口/出口条件精确形式化

### 1.1 记号约定

设递归层级为 k。对任一比价线 e，记：

- BSP(e, k, t) ∈ {1B, 2B, 3B, 1S, 2S, 3S, ∅}：边 e 在层级 k、时刻 t 上的买卖点状态
- D(e, k, t) ∈ {top_div, bot_div, ∅}：边 e 在层级 k、时刻 t 上的背驰状态
- σ(e, k, t) ∈ {+, 0, −, unknown}：边 e 在层级 k、时刻 t 上的走势类型

对配置空间：

- Γ(k, t) = (σ(E/$, k, t), σ(C/$, k, t), σ(R/$, k, t))：层级 k 在时刻 t 的配置
- S(k, t) = Σ_e s(σ(e, k, t))：极性指数，s(+)=+1, s(0)=0, s(−)=−1

### 1.2 六步形式化

**第一步：配置层出现买点**

入口条件：
```
∃ k₀, t₀ 使得：
  (E1) S(k₀, t) 的事件序列在 t₀ 处出现底背驰
       （后一段下降推动的累积面积 A₂ < 前一段下降推动的累积面积 A₁）
  (E2) Γ(k₀, t₀) 在 t₀ 之前经历了持续的 risk-off 走势
       （S 的事件序列构成至少一笔下降，即 S 从某个值单调递减至少 2 个极性单位）
```

出口条件：
```
  (X1) 配置层一买确认：S(k₀, t₁) > S(k₀, t₀) 对某 t₁ > t₀
       （极性指数开始回升，确认底背驰成立）
```

产出：k₀（操作级别）、t₀（配置层买点时间窗口）、方向 = risk-on。

失败条件：S 继续下降并创新低——底背驰被证伪，回到等待。

**第二步：独立边出现买点**

入口条件：
```
  (E1) 第一步已完成：配置层一买在 (k₀, t₀) 确认
  (E2) ∃ 独立边 e* ∈ {E/$, C/$, R/$}, ∃ t₁ ≥ t₀ 使得：
       BSP(e*, k₀, t₁) ∈ {1B, 2B, 3B}
       即 e* 在层级 k₀ 上出现买点
```

出口条件：
```
  (X1) 买点在 e* 上确认（背驰确认 + 价格反转确认）
  (X2) 目标角 = e* 的非现金端
       E/$ 出买点 → 目标角 = E（动产）
       C/$ 出买点 → 目标角 = C（商品）
       R/$ 出买点 → 目标角 = R（不动产）
```

产出：目标角 V*、买点类型、买点时刻 t₁。

优先级规则（多条边同时出现买点时）：
```
  背驰力度更大的边优先：
  priority(e) = |A_prev(e) - A_curr(e)| / A_prev(e)
  即 MACD 面积衰减比例越大，转折越确定，优先级越高
```

**第三步：选国家**

入口条件：
```
  (E1) 第二步已完成：目标角 V* 确定
  (E2) ∃ 跨国同类边 e_cross ∈ {V*_i / V*_j : i ≠ j}, ∃ t₂ ≥ t₁ 使得：
       BSP(e_cross, k_cross, t₂) ∈ {1B, 2B, 3B, 1S, 2S, 3S}
       其中 k_cross 是 e_cross 的支配级别
```

出口条件：
```
  (X1) 买卖点在 e_cross 上确认
  (X2) 目标国家 = 买卖点指向的端
       SPY/沪深300 出一卖 → A股方向（A股即将相对走强）
       SPY/沪深300 出一买 → 美股方向（美股即将相对走强）
```

特殊情况：
```
  若无跨国同类边出现买卖点：
    不偏向特定国家，在目标角 V* 的所有国家中等待买点
    → 跳过第三步，直接进入第四步（在所有国家的 V* 角内并行搜索）
```

共振增强：
```
  若货币边 $_i/$_j 的买卖点方向与 e_cross 一致：
    确定性提升（两个独立信号指向同一方向）
  若不一致：
    各自独立操作，不互相否决
```

**第四步：角内选板块**

入口条件：
```
  (E1) 第二步或第三步已完成：目标角 V* 和（可选的）目标国家 i* 确定
  (E2) 对板块集合 {B₁, B₂, ..., Bₘ} ⊂ V*_i*，
       ∃ 板块 Bⱼ, ∃ t₃ ≥ t₂ 使得：
       BSP(Bⱼ / Index(V*_i*), k_sector, t₃) ∈ {1B, 2B, 3B}
       其中 Bⱼ / Index(V*_i*) 是板块对角指数的比价线
       k_sector 是该比价线的支配级别
```

出口条件：
```
  (X1) 买点在 Bⱼ / Index(V*_i*) 上确认
  (X2) 目标板块 = Bⱼ
```

**第五步：板块内选标的**

入口条件：
```
  (E1) 第四步已完成：目标板块 Bⱼ 确定
  (E2) 对标的集合 {s₁, s₂, ..., sₙ} ⊂ Bⱼ，
       ∃ 标的 sₗ, ∃ t₄ ≥ t₃ 使得：
       BSP(sₗ / Index(Bⱼ), k_stock, t₄) ∈ {1B, 2B, 3B}
       其中 sₗ / Index(Bⱼ) 是标的对板块指数的比价线
       k_stock 是该比价线的支配级别
```

出口条件：
```
  (X1) 买点在 sₗ / Index(Bⱼ) 上确认
  (X2) 目标标的 = sₗ
```

**第六步：标的内纵向区间套**

入口条件：
```
  (E1) 第五步已完成：目标标的 sₗ 确定
  (E2) sₗ 在其支配级别 k_dom 上有已确认的走势类型
```

出口条件：
```
  (X1) 纵向区间套收敛：
       级别 k_dom 背驰区域 → 级别 k_dom - 1 背驰区域 → ... → 最低可操作级别的精确买点
  (X2) 入场执行
```

### 1.3 六步的递归不变量

每一步都保持同一个不变量：

```
Invariant(step_i):
  入口 = 上一步产出的买卖点确认
  操作 = 在当前层的比价线集合中等背驰、确认买卖点
  产出 = 流向确认 ∧ 介入目标 ∧ 进入下一步的资格
```

六步不是六种操作，是同一个操作 `wait_divergence → confirm_BSP → narrow_scope` 的六次应用。

### 1.4 阻塞与跳过

```
阻塞规则：
  若 step_i 无买卖点出现 → 阻塞在 step_i，不进入 step_{i+1}
  等待是区间套的核心纪律

跳过规则：
  仅 step_3（选国家）可跳过：
    当无跨国同类边出现买卖点时，在所有国家并行搜索
  其余步骤不可跳过
```

## 二、横向与纵向统一——交织形式化与统一区间套算子

### 2.1 统一区间套算子

定义区间套算子 N（Nesting）：

```
N : (SearchSpace, Level) → (Target, BSP_confirmation)

其中：
  SearchSpace = 当前层的标的/比价线集合
  Level = 当前关注的递归层级
  Target = 买卖点指向的下一层搜索目标
  BSP_confirmation = 买卖点确认记录
```

纵向和横向区间套都是 N 的实例：

```
纵向实例：
  N_vert(e, k) → (e, k-1)
  同一条比价线 e，从级别 k 下钻到级别 k-1

横向实例：
  N_horiz(S_i, k_i) → (S_{i+1}, k_{i+1})
  从搜索空间 S_i（如配置空间）下钻到 S_{i+1}（如独立边集合）
  级别可能同时降低：k_{i+1} ≤ k_i
```

### 2.2 交织的形式化

实际操作中纵向和横向交织。定义区间套路径为 N 的有限序列：

```
Path = N₁ ∘ N₂ ∘ ... ∘ Nₘ

其中每个 Nⱼ 是纵向或横向的实例。
```

交织的结构性约束：

```
约束1（级别单调性）：
  沿路径 Path，级别序列 k₁ ≥ k₂ ≥ ... ≥ kₘ
  区间套只能向低级别下钻，不能向上跳

约束2（搜索空间收缩性）：
  |S₁| ≥ |S₂| ≥ ... ≥ |Sₘ|
  横向的每一步收缩搜索空间（从全局→角→板块→标的）
  纵向的每一步收缩时间范围（从大级别背驰区域→小级别精确点）

约束3（终止性）：
  Path 必终止于某个具体标的的某个具体级别上的买卖点
  终止条件：达到最低可操作级别 ∨ 达到具体标的
```

### 2.3 标准交织路径

最常见的交织模式：

```
典型路径：
  N_horiz(配置空间, k₀)          → 目标角 V*
  N_horiz(独立边, k₀)            → 目标国家 i*（或并行搜索）
  N_horiz(板块比价线, k_sector)   → 目标板块 Bⱼ
  N_horiz(标的比价线, k_stock)    → 目标标的 sₗ
  N_vert(sₗ, k_dom)              → 级别 k_dom - 1
  N_vert(sₗ, k_dom - 1)          → 级别 k_dom - 2
  ...
  N_vert(sₗ, k_min)              → 精确入场

即：先横向收缩到标的，再纵向收缩到时机。
```

替代路径（横纵交替）：

```
  N_horiz(配置空间, k₀)    → 目标角 V*
  N_vert(V* 独立边, k₀)    → 独立边上更低级别 k₀-1 的结构
  N_horiz(板块比价线, k₀-1) → 目标板块
  N_vert(板块比价线, k₀-1) → 更低级别
  ...

即：每下钻一层空间，同时降低一层时间级别。
```

两种路径都合法，选择取决于数据可得性（哪些比价线在哪些级别上有已完成走势）。

### 2.4 统一算子的代数性质

```
结合律：(N₁ ∘ N₂) ∘ N₃ = N₁ ∘ (N₂ ∘ N₃)
  路径的分组方式不影响最终结果

非交换律：N_horiz ∘ N_vert ≠ N_vert ∘ N_horiz（一般地）
  先确定标的再下钻级别 ≠ 先下钻级别再确定标的
  前者是标准路径，后者在某些情况下也可行但搜索空间更大

幂等性不成立：N ∘ N ≠ N
  每一步 N 收缩搜索空间或级别，重复应用产生新的收缩
```

## 三、反向传递形式化

### 3.1 反向传递的数学表达

定义从底层到上层的信号传递函数。

设层级结构为：标的层 → 板块层 → 角层 → 配置层。

**标的层 → 板块层**：

```
对板块 B 内的标的集合 {s₁, ..., sₙ}，定义板块层背驰指标：

DivCount(B, k, t) = |{sᵢ : D(sᵢ/Index(B), k, t) = top_div}|

即板块内同时出现顶背驰的标的数量。

板块层力度衰竭条件：
  DivCount(B, k, t) / n ≥ θ_sector

其中 θ_sector 是板块层汇聚阈值。
```

**板块层 → 角层**：

```
对角 V 内的板块集合 {B₁, ..., Bₘ}，定义角层背驰指标：

DivCount(V, k, t) = |{Bⱼ : D(Bⱼ/Index(V), k, t) = top_div}|

角层力度衰竭条件：
  DivCount(V, k, t) / m ≥ θ_corner

其中 θ_corner 是角层汇聚阈值。
```

**角层 → 配置层**：

```
对三条独立边 {E/$, C/$, R/$}，定义配置层背驰指标：

DivCount(Config, k, t) = |{e ∈ {E/$, C/$, R/$} : D(e, k, t) = top_div}|

配置层力度衰竭条件：
  DivCount(Config, k, t) ≥ 2
```

### 3.2 汇聚阈值的结构性确定

汇聚阈值 θ 不是经验参数，它有结构性的下界：

```
θ 的下界论证：

如果板块 B 内有 n 个标的，且 m 个出现顶背驰（m/n ≥ θ），则：
  板块指数 Index(B) = Σ wᵢ · sᵢ（加权和）
  板块指数的 MACD 面积 ≈ Σ wᵢ · MACD(sᵢ)

当 m/n 足够大时，背驰标的对指数 MACD 的贡献权重总和 W_div = Σ_{i∈div} wᵢ
如果 W_div > 1/2（背驰标的的权重超过半数），则：
  Index(B) 的 MACD 面积必然受到拖累
  → 板块级别的力度衰竭是标的级别力度衰竭的加权聚合

因此：
  θ_sector 的下界 = min θ 使得 Σ_{i : D(sᵢ)=top_div} wᵢ > 1/2
  等权情况下：θ_sector > 1/2

  θ_corner 的下界类似，但板块间权重差异更大
  → θ_corner 的下界取决于板块在角指数中的权重分布
```

### 3.3 汇聚的时间结构

反向传递不是瞬时的。底层背驰出现后，上层走势的力度衰竭是渐进的：

```
时间序列：
  t₁：第一个标的出现顶背驰
  t₂：第二个标的出现顶背驰
  ...
  t_θ：背驰标的数量达到汇聚阈值 → 板块层力度衰竭信号
  t_板块：板块比价线本身出现顶背驰（板块层信号确认）

性质：t₁ < t₂ < ... < t_θ ≤ t_板块

t_θ 是板块层力度衰竭的最早预警时刻。
t_板块 是板块层背驰的确认时刻。

两者之间的时间差 = 预警提前量。
```

### 3.4 反向传递与正向下钻的对偶

```
正向下钻（区间套）：
  配置层买点 → 独立边买点 → 板块买点 → 标的买点
  方向：自上而下
  功能：收窄搜索空间，确定介入目标

反向传递：
  标的层卖点汇聚 → 板块层力度衰竭 → 角层力度衰竭 → 配置层卖点
  方向：自下而上
  功能：最早预警，逐层减仓

对偶性：
  正向下钻的入口 = 上层买点（全局方向确认后下钻）
  反向传递的入口 = 底层卖点（局部方向反转后汇聚）

  正向下钻回答：在哪里入场
  反向传递回答：什么时候开始退出

  两者的算子结构相同（都是 N 的序列），但方向相反。
```

## 四、买卖点=流向确认=介入信号——三位一体的充要条件

### 4.1 形式化声明

**定理（三位一体）**：对任一比价线 e = X/Y，以下三个命题在 e 的支配级别上等价：

```
(P1) BSP(e, k, t) = 1B
     （e 在级别 k 的时刻 t 出现一买）

(P2) FlowConfirm(X←Y, k, t) = True
     （级别 k 上，资本从 Y 流向 X 的走势确认）

(P3) Enter(X_direction, k, t) = True
     （级别 k 上，在时刻 t 介入 X 方向）
```

即 P1 ⟺ P2 ⟺ P3。

### 4.2 等价性证明

**P1 ⟹ P2**：

```
BSP(e, k, t) = 1B
⟹ e = X/Y 在级别 k 上的下跌走势出现底背驰并终结
⟹ X 相对 Y 的下跌力度衰竭，即 Y 对 X 的走强力度衰竭
⟹ 资本从 Y 流向 X 的走势即将开始（下跌终结 = 上涨的必要前置）
⟹ FlowConfirm(X←Y, k, t) = True
```

**P2 ⟹ P3**：

```
FlowConfirm(X←Y, k, t) = True
⟹ 在级别 k 上，资本正在从 Y 流向 X
⟹ X 方向是正期望方向（资本流入支撑上涨）
⟹ 介入 X 方向是合理的
⟹ Enter(X_direction, k, t) = True
```

**P3 ⟹ P1**：

```
逆否命题：¬P1 ⟹ ¬P3

若 BSP(e, k, t) = ∅（e 在级别 k 上没有买点），则：
  要么 e 在下跌趋势中且未出现背驰 → 流向未确认 → 不介入
  要么 e 在盘整中 → 方向未定 → 不介入
  要么 e 在上涨趋势中但已离开买点区域 → 介入时机已过

所有情况下 Enter = False。故 ¬P1 ⟹ ¬P3，即 P3 ⟹ P1。
```

### 4.3 三位一体的操作含义

三个命题不是三个需要分别检查的条件。它们是同一个事件的三种描述：

```
看到一买 = 确认了流向 = 得到了介入信号

不存在：
  "看到一买但流向不确定" → 不可能（一买的定义就是下跌终结=流向反转）
  "流向确认了但不能介入" → 不可能（流向确认就是介入信号）
  "需要介入但没有买点" → 不可能（介入以买点为前提）
```

### 4.4 扩展到配置空间

对配置空间：

```
(P1') 配置空间一买：S 的事件序列出现底背驰
(P2') 全局流向确认：资本从现金流回资产端
(P3') 全局介入信号：开始横向区间套下钻

P1' ⟺ P2' ⟺ P3'
```

### 4.5 买卖点的否定（对象自我否定）

买卖点的否定不是外加的止损规则，是走势结构的自我否定——买卖点成立条件的反面。

```
一买的否定：价格跌破一买前低点。
  一买声明"下跌走势在此背驰终结"，跌破前低 = 走势没有终结 = 结构自我否定。

二买的否定：价格跌破一买低点。
  二买以一买为前提，一买被否定 → 二买的前提不再成立。

三买的否定：价格跌回中枢内部。
  三买声明"离开中枢的走势力度足够"，回到中枢 = 力度不足 = 结构自我否定。

卖点的否定与买点对称：
  一卖的否定：价格突破一卖前高点。
  二卖的否定：价格突破一卖高点。
  三卖的否定：价格涨回中枢内部。
```

否定条件是买卖点定义的组成部分，不是独立于买卖点的"止损规则"。

在三位一体框架下，买卖点的否定同时意味着：

```
BSP 否定 ⟺ 流向确认撤销 ⟺ 介入信号失效

一买否定：
  (¬P1) BSP(e, k, t₀) = 1B 被证伪
  (¬P2) FlowConfirm(X←Y, k, t₀) 撤销——资本并未从 Y 流向 X
  (¬P3) Enter(X_direction, k, t₀) 失效——介入依据消失
```

## 五、共振的精确定义和度量

### 5.1 共振的形式定义

**定义（共振）**：设 {e₁, e₂, ..., eₙ} 是一组比价线（可以在不同层次——配置层、边层、底层），设 {k₁, k₂, ..., kₙ} 是各自的支配级别，设 t 是时刻。

```
Resonance({(eᵢ, kᵢ)}, t) 成立，当且仅当：
  (R1) ∀ i: BSP(eᵢ, kᵢ, t) ≠ ∅
       （每条线在各自支配级别上都有买卖点）
  (R2) 所有买卖点方向一致
       （全部是买点或全部是卖点，不存在一条出买点另一条出卖点）
  (R3) 时间重叠：|tᵢ - tⱼ| ≤ Δ(kᵢ, kⱼ) ∀ i,j
       其中 Δ(kᵢ, kⱼ) 是级别 kᵢ 和 kⱼ 对应的时间容差
```

### 5.2 时间容差的确定

```
Δ(kᵢ, kⱼ) 的定义：

取两个级别中较大者 k_max = max(kᵢ, kⱼ)。
Δ = 级别 k_max 的最近一笔的时间跨度。

理由：级别 k 的一笔是该级别的最小结构单位。
两个买卖点只要在同一笔的时间跨度内出现，就是"同时"的。
```

### 5.3 共振强度

```
ResStrength({(eᵢ, kᵢ)}, t) = Σᵢ w(eᵢ, kᵢ) · I(BSP(eᵢ, kᵢ, t) ≠ ∅)

其中：
  I(·) 是指示函数
  w(eᵢ, kᵢ) 是权重函数：

  w(e, k) 的定义：
    配置层信号：w = 3（最高权重——全局方向确认）
    独立边信号：w = 2（角级别方向确认）
    派生边信号：w = 1（一致性增强，但不独立）
    底层标的信号：w = 1（局部确认）
```

### 5.4 共振的层次分类

```
三层共振（最高确定性）：
  配置层买点 + 独立边买点 + 底层标的买点
  ResStrength ≥ 6
  操作：满仓

双层共振（高确定性）：
  配置层 + 独立边，或 独立边 + 底层
  ResStrength ∈ [3, 6)
  操作：重仓

单层信号（标准确定性）：
  仅独立边买点，或仅底层买点
  ResStrength ∈ [1, 3)
  操作：轻仓

增强因子：
  派生边共振：在已有共振基础上，若派生边也出现一致方向的买卖点
  → ResStrength += 1（每条共振的派生边）
  → 确定性提升但不改变层次分类
```

### 5.5 共振的级别匹配条件

```
严格匹配：
  配置层级别 k₀ 的买点 ↔ 独立边级别 k₀ 的买点
  → 完全共振（同一级别的同一事件在不同视角的表现）

宽松匹配：
  配置层级别 k₀ 的买点 ↔ 独立边级别 k₁ 的买点，其中 k₁ < k₀
  → 部分共振（大级别方向确认 + 小级别精确入场）
  → 有效，但确定性低于严格匹配

无效匹配：
  配置层级别 k₀ 的买点 ↔ 独立边级别 k₁ 的买点，其中 k₁ > k₀
  → 无效（不能用小级别的配置信号去确认大级别的边信号）
```

## 六、转换拓扑操作深化

### 6.1 k步可达集

定义：从配置 Γ₀ 出发，经过恰好 k 步转换可以到达的配置集合。

```
Reach(Γ₀, 0) = {Γ₀}
Reach(Γ₀, k) = ∪_{Γ ∈ Reach(Γ₀, k-1)} Adj(Γ)

其中 Adj(Γ) = {Γ' : Γ 和 Γ' 只在一条独立边上不同，且该边只在相邻态间跳转}
```

具体计算（以 Γ₀ = (+,+,+) 为例）：

```
Reach((+,+,+), 0) = {(+,+,+)}

Reach((+,+,+), 1) = {(0,+,+), (+,0,+), (+,+,0)}
  （三条边各自可以从 + 退化为 0）

Reach((+,+,+), 2) = {(−,+,+), (0,0,+), (0,+,0),   ← 从 (0,+,+) 出发
                      (+,−,+), (0,+,+)*, (+,0,0),   ← 从 (+,0,+) 出发
                      (+,+,−), (+,0,+)*, (0,+,+)*}   ← 从 (+,+,0) 出发
  去重后（不含 k=0 和 k=1 的配置）：
  新增 = {(−,+,+), (0,0,+), (0,+,0), (+,−,+), (+,0,0), (+,+,−)}

Reach((+,+,+), 3) 包含中心附近的大量配置...

Reach((+,+,+), 6) = 全部27种配置
  （图的直径为6，从 (+,+,+) 到 (−,−,−) 需要6步）
```

### 6.2 可达集的操作含义

```
Reach(Γ₀, 1)：下一步可能的配置。
  → 你当前的持仓在一步后可能面对的市场环境
  → 每种可能性对应一条边的走势变化
  → 你应该对每种可能性有预案

Reach(Γ₀, 2)：两步内可能的配置。
  → 风险评估的时间窗口更长
  → 包含了"某条边走完盘整后可能反转"的情况

一般地：Reach(Γ₀, k) 随 k 增大而快速扩展，
  在 k=3 时已经覆盖了大部分配置空间。
  → 超过3步的路径规划意义不大——不确定性太高
```

### 6.3 配置路径与路径概率

```
定义：配置路径 π = (Γ₀, Γ₁, ..., Γₖ)，其中每对相邻配置满足 Γᵢ₊₁ ∈ Adj(Γᵢ)。

路径 π 的结构信息：
  触发边序列：(e₁, e₂, ..., eₖ)，其中 eᵢ 是 Γᵢ₋₁ → Γᵢ 变化的边
  方向序列：(d₁, d₂, ..., dₖ)，其中 dᵢ 是 eᵢ 的状态变化方向

路径不等概率：
  哪条路径更可能，取决于哪条边更接近完成走势。
  如果 E/$ 正在盘整中枢的边缘且 MACD 面积在收敛 → E/$ 即将完成走势
  → 包含 "E/$ 状态变化" 的路径更可能

  形式化：
    P(Γ → Γ' via e) ∝ proximity_to_completion(e)
    proximity_to_completion(e) = 边 e 当前走势结构距离完成的"距离"
      （中枢内笔的数量、MACD 收敛程度等结构性信号）
```

### 6.4 最短路径与全局反转

```
从 Γ₁ 到 Γ₂ 的最短路径长度：
  d(Γ₁, Γ₂) = Σ_{e ∈ {E/$, C/$, R/$}} d_e(σ₁(e), σ₂(e))

  其中 d_e(s₁, s₂) = 轴上距离：
    d_e(+,+) = 0, d_e(+,0) = 1, d_e(+,−) = 2
    d_e(0,0) = 0, d_e(0,±) = 1
    d_e(−,−) = 0, d_e(−,0) = 1

  最大距离：d((+,+,+), (−,−,−)) = 2+2+2 = 6

操作含义：
  d(Γ_current, Γ_target) 告诉你从当前配置到目标配置至少需要多少个走势完成事件。
  每个事件对应一次独立边的走势完成——不是瞬时的，是结构性的时间跨度。

  d = 1：下一个事件就可能到达。密切关注即将完成走势的边。
  d = 2-3：中期可达。有时间准备。
  d = 4-6：远期目标。不在当前操作范围内。
```

## 七、代数一致性检验的诊断分类算法化

### 7.1 一致性检验的形式定义

```
对三条边 (e₁, e₂, e₃) 满足代数关系 e₁ = e₂ · e₃（或等价地 ln e₁ = ln e₂ - ln e₃），
定义一致性状态：

Consistent(e₁, e₂, e₃, k, t) ∈ {consistent, inconsistent, undetermined}

consistent：
  σ(e₁, k, t) 在 DirConstraint(σ(e₂, k, t), σ(e₃, k, t)) 内
  其中 DirConstraint 是 v4 §2.4 给出的方向约束映射

inconsistent：
  σ(e₁, k, t) ∉ DirConstraint(σ(e₂, k, t), σ(e₃, k, t))

undetermined：
  三条边中有 unknown 状态（某条边在级别 k 上未完成走势）
```

### 7.2 方向约束映射

```
DirConstraint : {+, 0, −}² → P({+, 0, −})

DirConstraint(+, −) = {+}      异号 → 方向确定
DirConstraint(−, +) = {−}
DirConstraint(+, +) = {+, 0, −}  同号 → 不确定
DirConstraint(−, −) = {+, 0, −}
DirConstraint(+, 0) = {+, 0}    一端为0 → 部分约束
DirConstraint(0, +) = {0, −}
DirConstraint(−, 0) = {−, 0}
DirConstraint(0, −) = {0, +}
DirConstraint(0, 0) = {+, 0, −}  双0 → 不确定
```

### 7.3 诊断分类算法

当 Consistent = inconsistent 时，执行以下诊断分类：

```
Algorithm DiagnoseInconsistency(e₁, e₂, e₃, k, t):

  Input: 三条边、递归层级、时刻
  Output: 诊断类型 ∈ {level_mismatch, temporal_lag, structural_divergence}

  Step 1: 检查级别匹配
    k₁ = dominant_level(e₁)
    k₂ = dominant_level(e₂)
    k₃ = dominant_level(e₃)
    if max(k₁,k₂,k₃) - min(k₁,k₂,k₃) > 1:
      return level_mismatch
      // 诊断：边之间的支配级别差异过大
      // 处理：在公共级别 min(k₁,k₂,k₃) 上重新检验

  Step 2: 检查时间滞后
    t₁ = last_completion_time(e₁, k)
    t₂ = last_completion_time(e₂, k)
    t₃ = last_completion_time(e₃, k)
    if max(t₁,t₂,t₃) - min(t₁,t₂,t₃) > duration_of_one_pen(k):
      return temporal_lag
      // 诊断：边的走势完成时间差异过大，状态读取不同步
      // 处理：等待滞后边完成走势后重新检验

  Step 3: 否则
    return structural_divergence
    // 诊断：真实的结构性背离——不同路径上的资本流转确实不一致
    // 处理：这是信息，不是错误。不同路径上看到的是不同的资本流转。
    //        信号确定性降低，但不否决单边的买卖点。
```

### 7.4 诊断结果的操作映射

```
level_mismatch:
  → 降级到公共级别重新检验
  → 如果公共级别上一致，信号有效但确定性低于同级别一致
  → 如果公共级别上仍不一致，进入 Step 2

temporal_lag:
  → 不一致是暂时的（走势完成时间不同步）
  → 等待滞后边的走势完成
  → 滞后边完成后，不一致可能自动消解
  → 消解 → 信号增强；未消解 → 进入 structural_divergence

structural_divergence:
  → 接受不一致为事实
  → 单边的买卖点仍然有效（第一层分析永远合法）
  → 确定性降低：不享受代数一致性增强的确定性溢价
  → 框架的自修正性：后续买卖点会更新判断
```

### 7.5 一致性状态的配置空间投影

```
对K4的四个K3三角形子图：

△ECR：Consistent(E/C, E/R, C/R, k, t) → 纯资产层面的一致性
△EC$：Consistent(E/C, E/$, C/$, k, t) → 股商+货币层面
△ER$：Consistent(E/R, E/$, R/$, k, t) → 股房+货币层面
△CR$：Consistent(C/R, C/$, R/$, k, t) → 商房+货币层面

K4完全一致 = 四个三角形全部 consistent
K4部分一致 = 部分三角形 consistent
K4不一致 = 多个三角形 inconsistent

部分一致时，consistent 的三角形构成可信子图，在子图内操作。
```

## 八、等待状态的形式化

### 8.1 等待的数学描述

等待是区间套的核心纪律。将等待状态形式化为一个有结构的对象，而不是简单的"不操作"。

```
定义 WaitState(step, scope, k, t):

  step ∈ {1, 2, 3, 4, 5, 6}：当前阻塞在横向区间套的第几步
  scope：当前搜索空间
    step=1: scope = 配置空间（等配置层买点）
    step=2: scope = {E/$, C/$, R/$}（等独立边买点）
    step=3: scope = 目标角内的跨国同类边（等国家选择信号）
    step=4: scope = 目标国家目标角内的板块比价线（等板块买点）
    step=5: scope = 目标板块内的标的比价线（等标的买点）
    step=6: scope = 目标标的的级别结构（等纵向区间套收敛）
  k：等待的递归层级
  t：进入等待的时刻
```

### 8.2 等待状态的内部结构

等待不是无信息的空白。等待状态有内部演化：

```
WaitState 的监控变量：

  proximity：各条边距离走势完成的接近度
    定义：proximity(e) = f(MACD收敛度, 中枢内笔数, 距背驰区域的距离)
    proximity ∈ [0, 1]，1 = 即将完成

  scope_coverage：搜索空间内已有信号的覆盖率
    定义：已出现某种买卖点信号的边数 / 搜索空间总边数
    scope_coverage ∈ [0, 1]

  tension：搜索空间内的结构性张力
    定义：不同边的走势方向的分散度
    高张力 = 多条边即将同时完成走势 = 下一个买卖点可能即将出现
    低张力 = 边的走势在各自中枢内平静震荡 = 可能还要等很久
```

### 8.3 等待状态的退出条件

```
WaitState 的退出条件（恰好一种）：

  搜索空间 scope 内某条边出现买卖点
  → WaitState 退出
  → 进入区间套的下一步

WaitState 不会因为以下原因退出：
  × "等太久了" → 时间不是退出条件
  × "看起来快要有信号了" → proximity 不是退出条件（只是监控变量）
  × "市场在动" → 市场动不等于买卖点出现
  × "其他层有信号" → 必须是当前层的信号才能退出当前层的等待
```

### 8.4 等待状态的局部操作边界

等待配置层信号时，不是完全空仓：

```
定义 LocalOpBoundary(wait_step):

  wait_step = 1（等配置层买点）:
    允许：在第一层（单条比价线）上做局部操作
    禁止：依赖配置层方向的仓位
    仓位上限：轻仓（缺少配置层方向支撑）

  wait_step = 2（等独立边买点）:
    允许：配置层方向已确认，在任意角的比价线上做操作
    禁止：重仓某一个角（尚未确认具体角）
    仓位上限：中等（有配置层方向但无角级别确认）

  wait_step = 3-5（等国家/板块/标的买点）:
    允许：在已确认层的方向上持有仓位
    禁止：增加未确认层的仓位
    仓位上限：递增（每确认一层增加仓位上限）

  wait_step = 6（等纵向区间套收敛）:
    允许：在已确认的标的上持有初始仓位
    禁止：满仓（精确入场时机未确认）
    仓位上限：该标的的配额 × 纵向确认比例
```

### 8.5 等待状态与配置空间盘整的关系

```
配置空间盘整（Γ = (0,0,0) 或 S 在某区间内震荡）是等待状态的特殊情况：

  wait_step = 1
  scope = 配置空间
  tension = 低（三条边都在盘整，方向未定）

  此时：
    配置层无买卖点 → 不做配置层操作
    但第一层分析永远合法 → 可以在单条边上做局部操作
    仓位受限于 LocalOpBoundary(1)

  配置空间盘整的退出：
    S 的事件序列出现三买或三卖（从盘整中枢突破）
    → 配置层方向确认
    → 从 wait_step=1 进入 wait_step=2
```

## 九、配置空间的极性指数递归——理论基础

### 9.1 S 的事件序列上的缠论实体

文档一 §3.9 已经定义了配置空间的缠论实体。这里深化其理论基础。

S(t) 的事件序列是整数格点 {−3, −2, −1, 0, +1, +2, +3} 上步长为 1 的路径（引理1）。

**关键性质**：步长恒为 1 消除了包含关系处理的需要，但不消除缠论递归构造的合法性。

```
S 序列上的缠论构造：

分型：底分型 S(tᵢ₋₁) > S(tᵢ) < S(tᵢ₊₁)，顶分型对称
  → 合法（分型只需要三个相邻值的大小关系）

笔：底分型到顶分型（或反之），极性跨度 ≥ 2
  → 合法（笔的定义是连接相邻分型，加最小跨度门槛排除噪声）
  → 跨度 ≥ 2 意味着：一笔至少跨越 2 个极性单位，至少包含 2 个事件

线段：笔的组合，标准线段构造
  → 合法（线段构造只依赖笔序列的组合性质）

中枢：至少三笔有重叠区间 [S_min, S_max]
  → 合法（中枢定义只需要笔的价格范围有重叠）

走势类型：上涨/下跌/盘整，基于中枢位置关系
  → 合法
```

**力度度量**：S 本身只有 7 个离散值，但累积 MACD 面积 A(段) = Σᵢ∈段 Aᵢ 是连续量，提供了充分的力度分辨率。

### 9.2 配置空间级别的两种理解方式

**方式一（文档一的立场）**：配置空间有独立的递归构造。S 的事件序列上可以构造笔、线段、中枢、走势类型，形成独立的递归层级体系。

**方式二（v1 初稿的立场）**：配置空间没有独立的递归构造，其级别继承自边层。

**调和**：两种方式不矛盾。

```
调和论证：

边层级别 k 的走势完成 → 触发配置空间的事件
→ 配置空间事件序列积累到一定程度后，在 S 上形成笔
→ 笔组成线段 → 围绕中枢 → 确认走势类型

配置空间的递归构造确实是独立的（由 S 的事件序列自身决定），
但其材料（事件）来自边层的走势完成。

类比：河流的水位序列有自己的波动结构（独立递归），
     但每次水位变化是上游支流注入导致的（材料来自上游）。

因此：
  配置空间的级别 ≠ 边层的级别（独立递归体系）
  配置空间的事件 = 边层走势完成的投影

  两个级别体系各自独立，但通过"事件触发"关联。
```

### 10.2 下游推论

1. **文档三（操盘方法）需要的输入**：v2 的等待状态形式化和局部操作边界直接约束了文档三的仓位规则——等待状态的 LocalOpBoundary 就是仓位上限的形式来源。

2. **反向传递与降成本递归的衔接**：反向传递（§三）的汇聚阈值和时间结构是文档三 §6.3"底层预警阶段"的形式基础。底层一卖的汇聚触发逐层减仓——汇聚阈值 θ 决定了"多少底层一卖算系统性衰竭"。

3. **共振与仓位的映射**：共振强度 ResStrength 直接映射到文档三 §5.1 的仓位确定性。ResStrength ≥ 6 → 满仓，ResStrength ∈ [3,6) → 重仓，ResStrength ∈ [1,3) → 轻仓。

4. **诊断分类与风控**：代数一致性检验的 structural_divergence 诊断意味着"不同路径上的资本流转不一致"——这是降低确定性的信号，不是停止操作的信号。但它约束了文档三的风控：structural_divergence 状态下不享受代数一致性增强的确定性溢价。

5. **转换拓扑与跨角轮动**：k步可达集 Reach(Γ₀, k) 为文档三 §2.3"跨角轮动"提供了形式框架——从当前配置出发，预判下一步可能的配置，在可能性中等待买卖点。

### 10.3 边界条件

以下条件成立时，v2 的部分结论需要修正：

- **汇聚阈值 θ 的经验偏差**：θ 的下界（§3.2）依赖权重分布的假设。如果实际板块/角的权重分布极端偏斜（一个标的占板块权重 >50%），则 θ 的下界需要重新计算。
- **S 序列上的缠论构造在极端值时退化**：当 S = +3 或 S = −3 时，S 只能向一个方向移动。此时"中枢"、"走势类型"等构造在边界附近的语义可能需要单独处理。
- **时间容差 Δ 的级别依赖**：Δ 的定义依赖"级别 k 的最近一笔的时间跨度"。如果不同边的笔的时间跨度差异极大（一条边的一笔是3天，另一条是3个月），Δ 的选择需要取较大者以避免遗漏。
