## 第一部分：MACD 在缠论体系中的位置

### 1.1 原文定位：辅助工具，非主判据

缠师在第24课首次系统阐述 MACD 对背驰的辅助判断，核心定位明确：

> "由于MACD本身的局限性，要精确地判断背驰与盘整背驰，还是要从中枢本身出发，但利用MACD，对一般人理解和把握比较简单点，而这已经足够好了。光用MACD辅助判断，即使你对中枢不大清楚，只要能分清楚A、B、C三段，其准确率也应该在90%以上。而配合上中枢，那是100%绝对的。"（第24课）

> "背驰也是有精确定义的，但精确定义对一般人来说也没意义，需要用到测度论里很多的知识，用MACD来辅助判断，效果至少95%以上，已经足够好了。"（第29课答疑）

**结论**：MACD 在缠论中是**操作层辅助工具**，不是背驰的精确定义本身。精确定义基于中枢和走势力度（需测度论工具），MACD 是其近似实现。

### 1.2 MACD 使用的标准方法（第24课）

A/B/C 三段法：
1. A、B、C 三段在一个大趋势里
2. A 之前已有一个中枢
3. B 是大趋势的另一个中枢
4. B 段使 MACD 黄白线（DIF/DEA）回拉到 0 轴附近（**前提条件**）
5. C 段 MACD 柱子面积 < A 段面积 → 标准背驰

### 1.3 MACD 三维度判断（第25课）

缠师在第25课给出了三个维度的综合判断：

> "黄白线不能创新高，**或者**柱子的面积**或者**伸长的高度能不能突破新高"

三维度：
1. **黄白线高度**（DIF 峰值）：C段 DIF 不创新高
2. **柱子面积**（MACD 柱子面积之和）：C段面积 < A段面积
3. **柱子伸长高度**（HIST 峰值）：C段单根柱子最大伸长 < A段

**组合关系**：已结算为 **OR**（任一满足即判定背驰）。
- 文本证据：第25课"或者"连接、第26课答疑"两个只要出现一个"
- 谱系记录：108号 C2 选择项

### 1.4 MACD 的三个特殊场景（第25课）

#### 1.4.1 急促走势（MACD 柱子伸长极限）

> "一个太快速的走势，1分钟图的反应也太慢了…打开一个MACD图，首先应该很敏感地去发现该股票MACD伸长的一般高度，在盘整中，一般伸长到某个高度，就一定回去了，而在趋势中，这个高度一定高点…一旦触及这个乖离的极限，特别是两次或三次上冲该极限，就会引发因为乖离而产生的回调。"

**当前实现状态**：beichi.md 边界条件 #5（急促走势特殊处理）已记录，但**未编码**。急促走势的 MACD 柱子极限值判断需要统计历史极限高度，属于经验性判断而非严格定义。

#### 1.4.2 连续涨停走势

> "股票不断一字涨停…MACD出现一波一波类似正弦波动的走势，这时候不能用背驰来看，最简单，就是用1分钟的中枢来看，只要中枢不断上移，就可以不管。"

**当前实现状态**：beichi.md 边界条件 #6 已记录。连续涨停场景下 MACD 失效，应回退到中枢上移判断。**未编码**（需要涨停检测 + MACD 失效标记）。

#### 1.4.3 MACD 不是万能的——黄白线回拉 0 轴是前提

> "背驰需要多少个条件？光柱子缩短就背驰？前面的黄白线有回拉0轴吗？背驰和柱子缩短不是一回事情，不能把问题简单化了。"（第25课答疑）

**当前实现状态**：T4（B段穿越0轴前提检查）已实现。`_b_segment_crosses_zero()` 检查 B 段 DIF 值是否同时存在正值和负值。

### 1.5 MACD 参数问题

#### 1.5.1 缠师原文对参数的态度

> "MACD的灵敏度，和参数有关，一般都取用12、26、9为参数，这对付一般的走势就可以了"（第25课）

缠师使用标准参数 (12, 26, 9)，未提出按级别调整参数。

#### 1.5.2 当前实现

`src/newchan/indicators.py:14-26` 中 `calc_macd()` 默认参数为 `fast=12, slow=26, signal=9`，与缠师使用一致。

#### 1.5.3 参数是否需要根据级别调整？

**原文依据**：缠师未提出按级别调整 MACD 参数。其建议是在走势极快时**换用更大级别的图**（如30分钟），而非调整参数。

> "一般来说，这种走势…如果用MACD配合判断，就用长一点时间的，例如看30分钟。"（第25课）

**当前仓库立场**：
- 口径A（递归级别）中，MACD 仅在 raw bar 层（Level 1）有意义（beichi.md 第420行）
- 高级别（Level 2+）背驰力度使用价格振幅（`_amplitude_force`），不使用 MACD
- 237号三态诊断已确认：高级别力度使用振幅 ∈ ker(D)，是结构性限制

**结论**：不需要按级别调整 MACD 参数。缠论体系内的解决方案是**换用更大 TF 的图**看 MACD，而非修改参数。这与本仓库的多 TF 架构（`MultiTFPipelineAdapter`，v100实现）一致。

### 1.6 DIF 零轴穿越与走势类型的关系

#### 1.6.1 原文论述

> "一般来说，一个标准的两个中枢的上涨，在MACD上会表现出这样的形态，就是第一段，MACD的黄白线从0轴下面上穿上来，在0轴上方停留的同时，形成相应的第一个中枢，同时形成第二类买点，其后突破该中枢，MACD的黄白线也快速拉起…然后进入第二个中枢的形成过程中，同时MACD的黄白线会逐步回到0轴附近，最后，开始继续突破第二个中枢…"（第25课）

#### 1.6.2 形式化对应

| 走势阶段 | MACD 状态 | 当前实现 |
|----------|----------|---------|
| 第一段上涨 | DIF 从 0 轴下穿上来 | 未检测 |
| 第一个中枢形成 | DIF 在 0 轴上方横盘 | 未检测 |
| 突破第一中枢 | DIF 快速拉起 | 未检测 |
| 第二中枢形成 | DIF 回拉 0 轴附近 | T4 检查（B段穿越0轴） |
| 突破第二中枢 | DIF 再次拉起但不创新高 | T6 检查（DIF峰值比较） |
| 背驰 | 面积/高度/DIF 不创新 | T2/T6/T7 OR 判断 |

**未实现项**：DIF 零轴穿越作为走势阶段识别的辅助信号。当前 MACD 仅用于背驰判断的 A/C 段比较，未用于走势阶段的实时追踪。

**是否需要实现**：这是**操作层辅助信息**，不是定义层必须。缠师的描述是帮助读者理解走势结构与 MACD 形态的对应关系，不是新增定义。如果要实现，属于 B 系统（可视化/操作辅助）而非 A 系统（形式化引擎）。

### 1.7 MACD 作为辅助工具的严格性

缠师反复强调 MACD 是辅助，精确判断来自中枢本身。但本仓库的实现路径是：

1. **A 系统（形式化引擎）**：背驰判断主要依赖 MACD 三维度 OR（T2/T6/T7）+ B段穿越0轴前提（T4）
2. **中枢本身的力度判断**：通过 a+A+b+B+c 结构中 c 与 a 的力度比较（中枢角度的等价释义，第33课）

当前实现中，"中枢角度的力度判断"本质上也是通过 MACD 面积/峰值来量化的——即 MACD 是中枢力度的**代理度量**。这符合缠师"配合上中枢，那是100%绝对的"的描述——中枢确定了 A/B/C 段的划分，MACD 确定了力度的数值比较。

**严格性评估**：当前实现的严格性取决于两个层面：
- **A/B/C 段划分的严格性**：依赖走势类型（Move）和中枢（Zhongshu）的正确识别 → 已由 v1 管线保证
- **力度比较的严格性**：MACD 面积/峰值比较是精确的数值操作 → 已实现

**已知局限**：MACD 参数固定为 (12,26,9)，对极端走势（急促/涨停）可能失效。这是 MACD 指标本身的数学特性，非实现缺陷。

#### 2.5.1 OQ5 结构性扩展：现金角子图双层检测（编排者裁定）

**核心发现：$ 顶点的双重身份悖论**

K4 的 $ 顶点具有双重身份：既是 K4 的一个普通顶点，又是整个 K4 的**度量基准**。这导致 K4 的六条边在信号质量上分裂为两类：

| 边类型 | 边 | 特征 | D 算子产出可靠性 |
|--------|-----|------|------------------|
| 纯资产边 | E/Au、E/R、Au/R | 消去了货币因子，纯结构信号 | 高 |
| 现金边 | E/$、Au/$、R/$ | 资产运动和尺子运动的叠加（两者都是真实的） | 受尺子运动叠加影响 |

**同步阅读结构**

OQ5 的检测不是前置层→主层的两步操作，是六条边的同步阅读：

同步阅读 K4 六条边的 D 算子产出。纯资产边读出资本在资产间的流转方向。现金边读出资产运动和尺子运动的叠加态。两组边之间的不一致——纯资产边说 E/Au 力度在衰竭，但 E/$ 和 Au/$ 各自没有对应的背驰信号——这个不一致本身 IS 尺子正在参与运动的直接显影。

- 操作对象：K4 六条边全部
- 操作工具：D 算子 + MACD
- 判断方式：六条边的走势结构是否自洽。自洽 = 尺子状态稳定。不自洽 = 尺子正在运动，不自洽的形态（哪几条边矛盾、矛盾的走势结构是什么级别）就是尺子状态的阅读
- 不自洽不是一个独立的"第三层"量——是同一张图读出来的东西

**阅读顺序纪律**

当现金角子图不稳定时，三条现金边的 D 算子产出的结构**本身就已经在告诉你它不可靠了**——走势结构退化、背驰判断失效、笔的力度互相矛盾。不需要从外面给它打折扣，它自己的结构产出就是病态的。

因此不是"降权/升权"，是**阅读顺序变了**：
- **正常情况**：六条边一起读
- **现金角子图不稳定时**：先读三条纯资产边（E/Au、E/R、Au/R），从中获得资本流转方向的判断；然后把现金边（E/$、Au/$、R/$）的产出作为**现金角状态的诊断**来读，而不是作为**资本流转信号**来读

同一条边，读法变了——从信号变成了症状。这完全在缠论语法内部，不需要权重系数，就是读图时知道自己在读什么。

**与 OQ4（K3 截面）的关系**：OQ4 的 K3 截面（E/Au、E/R、Au/R）恰好是上述三条纯资产边。当现金角子图不稳定时，K3 截面是优先阅读的信号源——这从结构上解释了 K3 截面的操作价值。

**编排者裁定**：不作为新的开放问题，而是 OQ5 的结构性扩展。核心洞察：六条边的同步阅读，不自洽的形态就是结算尺状态的实时显影。

**编排者语言修正**（PDF 对话裁定）：
- "噪声"是外在语言——现金边读到的是资产运动和尺子运动的叠加，两者都是真实的
- "降权/升权"是外在语言——不是给信号打折扣，是阅读方式的变化
- "前置监控层"是外在语言——不是先检查尺子再决策，是同步阅读六条边
- "强度"是外在语言——结算尺状态是结构性判断，不是量级赋值
- 扭曲是常态。美元同时是顶点和尺子 = 当前结算体系的存在方式。不存在"尺子不动"的正常态

### 4.2 OQ 系列揭示的共性问题

1. **D 算子在大级别上的吸收效应**：DXY 55年被一个中枢吸收（OQ5），日线 6600 bar 产出极少走势（229号）。这不是 bug，是缠论线段定义的固有特性。

3. **比价边的 D 算子语义统一**：OQ2 和 OQ4 确认了比价边上 D 算子的方向态读数与顶点边语义一致，验证了 K4/K5 框架的内部一致性。

4. **$ 双重身份悖论与阅读顺序纪律**：K4 的 $ 顶点既是顶点又是度量基准，导致六条边分裂为纯资产边（E/Au、E/R、Au/R）和现金边（E/$、Au/$、R/$）。OQ5 的三重联立检测需要前置层（现金角子图稳定性）作为可信度保证。当现金角不稳时，阅读顺序变化：先读纯资产边获取资本流转方向，再把现金边产出作为现金角状态的症状来读——同一条边从信号变成症状，不需要外部权重系数。OQ4 的 K3 截面恰好是三条纯资产边——现金角不稳时优先阅读的信号源。
