## 观察 1（架构信号）：pipeline_backtest.py 的层级定位——信号级与策略级的分离

### 现象

v88 新增 `src/newchan/pipeline_backtest.py`（323行），与已有 `src/newchan/backtest.py` 形成两层回测架构：

- **BacktestEngine**（backtest.py）：信号级——见 BSP 即入场，缠论体系退出
- **PipelineBacktestEngine**（pipeline_backtest.py）：策略级——配置扫描 -> 区间套 -> 共振 -> 状态机入场

PipelineBacktestEngine 内部消费 pipeline.py 的全部组件（`scan_configuration`、`locate_bsp`、`compute_position`、`execute_entry`、`execute_exit`），将 v76 的操盘方法四层架构（本体论+级别买卖点+操盘方法）落地为可回测的引擎。

### 判定

正面信号。两层回测架构对应缠论的两个层次——BSP 信号本身的质量（信号级）vs 完整交易管道的表现（策略级）。这是 v76 操盘方法架构的自然下游。19 个测试覆盖了基础流程、配置影响、否定退出、状态机跟踪、结果一致性和去重——测试设计与 pipeline.py 的语义结构对齐。

### 边界条件

1. `_build_resonance_signals`（第105-126行）使用简化逻辑：从单个 BSP 构建 CONFIG + INDEPENDENT_EDGE 双层信号使共振检查通过（需 >= 2 个同方向信号）。这是回测环境的合理简化，但意味着策略级回测中共振逻辑的筛选力被绕过——真实场景中共振信号来自多源。
2. `_OpenTrade`（第129-138行）使用可变 `@dataclass`（非 `frozen=True`），但字段在创建后实际不被修改——这是内部跟踪对象，不违反不变性原则的实质（不参与状态传递链）。

## 观察 2（实验方法信号）：K4 独立性实验的合成数据局限性

### 现象

`scripts/k4_independence_test.py` 执行 K4 独立边独立性检验。结果：

- **数据源**：合成数据（GBM，AlphaVantage 不可用）
- **Pearson 相关**：0.22-0.27（中等相关，由 $ 共同分母产生）
- **偏相关**（控制 UUP 后）：-0.01 ~ 0.05（接近零）
- **配置空间覆盖率**：27/27 = 100%
- **理论发现**：E/$ vs R/$ 滚动相关标准差 0.152（独立性时变）

偏相关接近零证实了条件 I1（控制 $ 后独立性恢复），配置空间 100% 覆盖证实了直积结构未退化。

### 判定

方法论正确但结论效力有限。合成数据（独立 GBM）在设计上就保证了 $ 因子去除后的独立性——这是循环验证（synthetic data 的构造本身就假设了独立性）。真正有信息量的检验需要真实市场数据，此时 E/R/C 之间可能存在 $ 之外的耦合（risk-on/off、央行政策同向影响等）。

脚本设计本身预留了 AlphaVantage 接口和真实数据路径，当 API 可用时可直接切换——这是正确的实验基础设施设计。

### 边界条件

- 合成数据结论**不可推广**到真实市场——仅验证了计算管线的正确性
- 真实数据检验时，偏相关 > 0.2 将触发 `independence_violation` 分类，可能否定 K4 独立边假设在特定时段的有效性

## 核心发现

1. **pipeline_backtest.py 实现了信号级/策略级回测的分层**——对应缠论 BSP 信号质量 vs 完整操盘方法的两个评估维度。v76 四层架构的可测试化。
2. **K4 独立性实验的合成数据路径是管线验证而非假设验证**——偏相关接近零和 100% 配置覆盖是合成数据的设计特性，不是实证发现。真实数据检验待 API 可用后执行。
3. **v88 没有新的结构性发散信号**——三个工位是已知方向的推进，无新概念矛盾。

## 下游推论

1. **K4 独立性实验需真实数据复验**——当前结论仅验证计算管线正确性。当 AlphaVantage 可用（或接入其他真实数据源）时，应复跑 `k4_independence_test.py`。如果真实数据偏相关显著 > 0，需要修正 K4 配置空间的独立性假设。这不是新谱系——是 K4 独立性谱系的自然续集。
2. **策略级回测共振简化需后续验证**——`_build_resonance_signals` 的双层简化使共振检查形式上通过但实质上不筛选。当回测引擎用于策略评估时，需要用真实共振信号替代简化构造，否则策略级回测退化为信号级回测+状态机开销。
