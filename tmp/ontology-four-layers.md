**版本**: v1.0

## 零、总览

缠论的单标的本体论是一条链：

```
K线 → 包含关系 → 分型 → 笔 → 线段 → 中枢 → 走势类型 → 走势必完美
```

将缠论延伸到比价空间后，本体论扩展为四层结构。每一层都有完整的缠论实体（分型、笔、线段、中枢、走势类型），每一层的走势必完美独立成立。

```
第一层（底层）：比价K线          — 价格序列 A(t)/B(t)
第二层（边层）：六条比价线的缠论实体  — 走势类型、中枢、背驰
第三层（图层）：K4 关系图         — 代数约束、等价关系、浮现性
第四层（配置层）：配置空间         — 转换拓扑 P₃□P₃□P₃ 上的缠论实体
```

四层之间的关系：底层构成边层，边层的走势完成触发配置层的事件，图层提供边层之间的代数约束。

## 一、第一层：底层——比价K线

### 1.1 定义（v4 §1.1）

比价K线是两个资产价格序列的逐时刻商：

```
R(t) = A(t) / B(t)
```

其中 t 的粒度由两端资产能同步配对的最细数据决定。

**数据质量前提**（三个条件，缺一不可）：
1. 时间戳同步：两个标的的K线在相同时间窗口上对齐
2. 流动性：两端标的在对应时间窗口内都有真实成交
3. 非零价格：分母标的价格为零时比价无定义

这些是数据层前提，不是理论层前提——走势必完美不依赖这些条件，但比价K线的生成依赖。

### 1.2 本体论意义（v4 §1.2）

比价K线把缠论的定义域从"一个资产的价格序列"扩展到"任意两个资产之间的关系序列"。走势必完美不再只是说"每个标的的走势有完备结构"，而是说"资产之间的关系本身有完备结构"。

### 1.3 缠论实体构造

比价K线就是K线。标准缠论管线无条件适用：

```
比价K线 R(t)
  → 包含关系处理
  → 分型识别（顶分型 / 底分型）
  → 笔构造
  → 线段构造（特征序列法）
  → 中枢识别（三段重叠）
  → 走势类型判定（盘整 / 趋势）
```

### 1.4 走势必完美在底层的成立

走势必完美的证明只依赖K线序列的组合性质——有限序列上的分型、笔、线段数量有限，走势类型的分类穷尽。比价K线是一条数列，组合性质成立，走势必完美成立。

**不需要**：级别匹配、对方走势完成、代数约束。底层分析是无条件合法的。

## 二、第二层：边层——六条比价线的缠论实体

### 2.1 K4 图的六条边（v4 §3.2）

四个资产类别顶点（EQUITY, COMMODITY, REAL_ESTATE, CASH）两两相连，形成 6 条边。每条边是一条比价K线。

**六条边的分类**：

| 类型 | 边 | 特征 |
|------|-----|------|
| 独立边（现金边） | E/$, C/$, R/$ | 实质是标的的绝对价格（以美元计） |
| 派生边（纯资产边） | E/C, E/R, C/R | 美元因子被消去，反映资产间真实相对流转 |

代数关系：`ln(E/C) = ln(E/$) - ln(C/$)`，`ln(E/R) = ln(E/$) - ln(R/$)`，`ln(C/R) = ln(C/$) - ln(R/$)`。

独立边数 = n-1 = 3（n=4 个顶点）。圈秩 = 6-4+1 = 3。

### 2.2 每条边的缠论实体

每条边独立运行完整的缠论管线（第一层构造），产出：

- **分型**：比价K线上的顶底分型
- **笔**：连接相邻顶底分型的单调段
- **线段**：笔的组合（特征序列法）
- **中枢**：至少三段重叠的价格区间
- **走势类型**：盘整（1个中枢）或趋势（≥2个中枢）
- **背驰**：MACD面积比较（力度衰竭信号）

### 2.3 每条边的三种状态（v4 §4.2）

| 状态 | 符号 | 定义 |
|------|------|------|
| 上涨趋势 | + | 至少两个不重叠的同向中枢，走势方向向上 |
| 下跌趋势 | - | 至少两个不重叠的同向中枢，走势方向向下 |
| 盘整 | 0 | 中枢内震荡，走势方向未定 |

**构建中**的边：走势类型尚未确定。在第一层可分析（次级别结构），但不参与第三层（K4关系图）的配置读取。

### 2.4 MACD 的两层口径（v4 §4.1）

| 口径 | 适用层 | 域 | 用途 |
|------|--------|-----|------|
| 原始价格域 MACD | 第二层（单条边内部） | 价格域 | 同一条边内前后两段走势的背驰判定 |
| log-MACD | 第三层（跨边比较） | 对数域 | 跨边力度比较（消歧派生边方向） |

log-MACD 可加性：`MACD(ln A/C) = MACD(ln A/B) + MACD(ln B/C)`

**前提条件**（三个，缺一不可）：
1. 两个序列在相同时间索引上计算 EMA
2. 初始化窗口（SMA 起算点）相同
3. EMA 周期参数一致

**数学基础**：EMA 是线性算子（归纳证明：SMA 线性 → EMA₁ 线性 → EMA_t 线性），ln 将乘法转为加法，两者组合给出精确的可加性。

### 2.5 走势必完美在边层的成立

每条边是一条独立的比价K线，走势必完美在每条边上独立成立（同第一层的论证）。六条边各自独立，互不干扰。

## 三、第三层：图层——K4 关系图

### 3.1 两层结构（v4 §2.5）

比价分析存在两个层次，各自有不同的合法性条件：

**第一层：比价K线分析（无条件合法）**
任何两个资产的比价序列都可以跑缠论。不需要级别匹配，不需要对方走势完成。六条比价线各自独立跑缠论——这永远合法。

**第二层：K4 关系图（有条件合法）**
K4 图的意义在于边之间的代数关系：循环约束、独立边约束派生边、一致性检验、消歧。这些操作预设了边之间是可比较的。

### 3.2 等价关系：K4 浮现的条件

**数据层等价**（C-1/C-2/C-3，静态，一次性检查）：
- C-1 可比性：重叠交易时间窗口
- C-2 非退化：比价不是常数
- C-3 流动性：两端有充足市场深度

**结构层前提**（动态，随走势演进变化）：
> 两个资产在递归层级 L 上等价（可比较），当且仅当两者在层级 L 上都有已完成的走势类型。

两层条件是叠加关系，不是替代关系。第一层不满足 → 比价序列本身无意义。第二层不满足 → 比价序列可分析（单条线），但不参与 K4 拓扑层。

### 3.3 代数约束（v4 §2.2-§2.4）

**乘法恒等式**（价格水平，永真）：
```
A/B × B/C × C/A ≡ 1
```

**加法恒等式**（流场方向，拓扑性质）：
```
Σ net(V) = 0，对所有顶点 V 求和
```
其中 net(V) = Σ flow(eᵢ, V)，flow ∈ {+1, -1, 0}。这是有向图的拓扑恒等式——每条边对两端顶点分别贡献 +1 和 -1，求和必然为零。

两者作用于不同层面：乘法恒等式约束价格水平的代数关系，加法恒等式提供顶点净流量的簿记框架。加法恒等式不排除任何边方向组合——27 种配置全部满足 Σ net(V) = 0。

**独立性对方向的约束**（条件化，v4 §2.4）：

三个操作性判据（C1-C3），满足时代数约束在走势层面足够紧：
- C1（同级别完成）：参与约束的边在同一递归层级上都有已完成走势类型
- C2（幅度下界）：走势累计变化率远大于噪声阈值
- C3（回撤不破坏趋势结构）：走势在观察期内没有破坏趋势结构的回撤

这些判据有结构性理由，但不是被证明的充分条件。

### 3.4 27 种配置的穷尽分类（v4 §5）

3 条独立边 × 3 种状态 = 27 种独立配置。每种配置对派生边的方向给出约束范围。

派生边约束规则（log 空间 ln(X/Y) = ln(X/$) - ln(Y/$)）：
- 异号 → 方向确定（差的符号唯一）
- 同号 → 方向不确定 {+,-,0}（谁变得快决定方向）
- 一端为 0 → 部分约束 {s, 0}（s 为非零端的主导方向）
- 双零 → 不确定 {+,-,0}

确定性来自穷尽+观测，不是来自穷尽本身。

### 3.5 K4 的浮现性（v4 §2.5）

K4 的存在论地位：
- 作为六条独立比价线的集合，K4 永远在那里（第一层分析永远合法）
- 作为具有内部代数结构的关系图，K4 在特定递归层级上、当足够多的顶点对满足等价条件时才浮现

级别越大，K4 越完整；级别越小，K4 越碎片化。K4 不完整时退化为 K3 三角形子图（4 个子图：△ECR、△EC$、△ER$、△CR$）。

### 3.6 K4 图层不构造自己的缠论实体

图层的本体论角色是**约束层**，不是**实体层**。它不产生自己的分型、笔、线段——它提供的是边层实体之间的代数关系和一致性检验。图层的产出是：
- 27 种配置的分类
- 派生边的约束范围
- 一致性检验结果
- 消歧后的全局流场读取

缠论实体的构造发生在边层（第二层）和配置层（第四层），不发生在图层。

## 四、第四层：配置层——配置空间本身作为缠论对象

这是 v4 中尚未显式构造的新内容。前三层处理的是"六条边各自的走势"和"边之间的代数关系"。第四层的核心洞察是：**27 种配置本身构成一个离散空间，这个空间上可以定义缠论实体**。

### 4.1 转换拓扑：P₃ □ P₃ □ P₃

**构造**（已实现于 `src/newchan/transition_topology.py`）：

每个 K4 配置是三条独立边状态的三元组 (e_cash, c_cash, r_cash)，每个分量取值 {+, 0, -}。这是一个 3×3×3 的离散立方体——三维路径图 P₃ 的笛卡尔积。

**转换规则**：每步只改一条独立边的状态，且只能相邻态跳转：
- +↔0 合法（趋势进入盘整，或盘整突破为趋势）
- -↔0 合法（同上，反向）
- +↔- 禁止（趋势不能直接反转为反向趋势，必须经过盘整）

**禁止 +↔- 的缠论理由**：走势必完美定理保证走势类型的完整性——一个上涨趋势必须经过盘整（至少一个中枢的震荡阶段）才能转为下跌趋势。直接从 + 跳到 - 意味着跳过了中间的走势结构，违反走势必完美。

**节点分四层**：

| 层级 | 含 0 个数 | 节点数 | 邻居数 | 特征 |
|------|----------|--------|--------|------|
| 角（corner） | 0 | 8 | 3 | 方向极其清晰，退出方式少 |
| 棱（edge） | 1 | 12 | 4 | 一条边盘整，两条有方向 |
| 面（face） | 2 | 6 | 5 | 两条边盘整，一条有方向 |
| 中心（center） | 3 | 1 | 6 | 全局盘整态 (0,0,0)，枢纽 |

**结构性质**：
- 总节点数：8 + 12 + 6 + 1 = 27
- 直径 = 6：从 (+,+,+) 到 (-,-,-) 需要 6 步（每条边各经过 +→0→-）
- 中心 (0,0,0) 是枢纽：到任何节点最多 3 步
- 对称性：全部取反（+↔-，0 不变）给出 13 对 + 1 个自对称 = 14 个独立配置

### 4.2 极性指数：配置空间的"价格"

**定义 D1**：极性指数 P(v) 是配置节点 v 的三条独立边状态之和。

```
P(v) = sign(e_cash) + sign(c_cash) + sign(r_cash)
```

取值范围：{-3, -2, -1, 0, +1, +2, +3}

**与 net($) 的关系**：P(v) = -net($)。极性指数是现金顶点净流入计数的取反——P(v) > 0 表示资本从现金流出（现金贬值），P(v) < 0 表示资本流入现金（现金升值）。

**极性指数的层级分布**：

| P(v) | 节点层级 | 节点数 | 含义 |
|------|---------|--------|------|
| +3 | 角 | 1 | (+,+,+) 现金全面贬值 |
| +2 | 棱 | 3 | 两涨一盘，现金流出 |
| +1 | 角+面 | 3+3=6 | 两涨一跌 或 一涨两盘 |
| 0 | 棱+中心 | 6+1=7 | 现金中性（含全局盘整） |
| -1 | 角+面 | 3+3=6 | 两跌一涨 或 一跌两盘 |
| -2 | 棱 | 3 | 两跌一盘，现金回流 |
| -3 | 角 | 1 | (-,-,-) 流动性危机 |

### 4.3 极性指数序列：配置空间的"K线"

**定义 D2**：极性指数序列 {P(v(t))} 是整数值时间序列。

当边层的走势类型在时间 t 发生变化（某条独立边从一种状态转换到另一种状态），配置节点 v(t) 沿转换拓扑移动一步，极性指数 P(v(t)) 相应变化。

**关键性质**：
- P(v(t)) 是离散整数序列，取值有界于 [-3, +3]
- 每步变化量为 ±1（因为每次只改一条边，且只能相邻态跳转）
- 序列的时间戳不是等间距的——它由边层走势完成事件驱动

**与边层的接口**：配置层不直接消费K线数据。它消费的是边层的走势完成事件——当某条独立边的走势类型从一种状态转换到另一种状态时，配置层记录一个新的时间点。

### 4.4 配置空间的缠论实体构造

以下构造是严格推导，不是类比。每一步都给出构造的精确定义和成立条件。

**定义 D3：配置空间的分型**

配置空间的分型 = 极性指数序列的局部极值。

```
顶分型：P(t-1) < P(t) > P(t+1)
底分型：P(t-1) > P(t) < P(t+1)
```

其中 t-1, t, t+1 是连续三个配置转换事件的时间戳。

**成立条件**：极性指数序列是整数值序列，局部极值的定义与标准缠论分型定义在结构上同构——都是"左低中高右低"或"左高中低右高"。包含关系处理同样适用（当连续两个时间点的极性指数相同时，按标准包含规则处理）。

**定义 D4：配置空间的笔**

配置空间的笔 = 连接相邻顶底分型的极性指数单调段。

构造规则与标准缠论笔定义同构：
- 顶分型和底分型之间至少有 1 个独立的配置转换事件（对应标准笔的"至少5根K线"约束在离散空间中的最小形式）
- 顶分型的极性指数高于底分型的极性指数（"顶高于底"硬约束）

**定义 D5：配置空间的线段**

配置空间的线段 = 笔的组合，特征序列法适用。

特征序列法的适用性：配置空间的笔是极性指数的单调段，笔与笔之间的包含关系和特征序列的定义与标准缠论完全同构。

**定义 D6：配置空间的中枢**

配置空间的中枢 = 至少三笔重叠的极性指数区间。

```
Center_config = [P_low, P_high]
其中 P_low, P_high 是至少三个连续配置笔的极性指数区间的重叠部分
```

由于极性指数取值有界于 [-3, +3]，中枢的区间也有界。

**定义 D7：配置空间的走势类型**

配置空间的走势类型：
- 盘整：包含 1 个配置中枢，极性指数在某个区间内震荡
- 趋势：包含 ≥2 个不重叠的配置中枢，极性指数有方向性移动

趋势的含义：极性指数从低值区间向高值区间移动（上涨趋势 = 资本持续从现金流出），或从高值区间向低值区间移动（下跌趋势 = 资本持续流入现金）。

### 4.5 走势必完美在配置层的成立

**定义 D8**：走势必完美在配置层成立。

**证明**：

1. 极性指数序列 {P(v(t))} 是整数值序列，取值有界于 [-3, +3]（7 个可能值）
2. 每步变化量为 ±1（转换拓扑的相邻性约束）
3. 在有界整数序列上，分型数量有限，笔数量有限，线段数量有限
4. 走势类型的分类穷尽（盘整或趋势）
5. 因此，配置空间的走势必然终结——极性指数不可能无限单调移动（上界 +3，下界 -3），也不可能无限震荡而不形成可分类的走势结构

**有界性是关键**：单标的K线的走势必完美依赖的是组合穷尽性（有限序列上的结构数量有限）。配置层的走势必完美额外获得了一个更强的约束——值域有界。极性指数最多从 -3 走到 +3（或反向），中间最多 6 步。这意味着配置层的趋势走势有天然的幅度上限。

**与边层走势必完美的独立性**：配置层的走势必完美不依赖边层的走势必完美。即使某条边的走势在某个级别上尚未完成，配置层的极性指数序列仍然是有界的、可分类的。两层的走势必完美各自独立成立。

### 4.6 "构建中"状态的传递性

**规则**（Gemini 独立发现，补充为显式规则）：

任何一条派生边，只要其代数构成中的任何一条独立边在某递归层级上处于"构建中"，则该派生边在该层级上也应被视为"构建中"，不参与配置读取。

推导：`ln(E/C) = ln(E/$) - ln(C/$)`。如果 E/$ 的走势类型未定，则 E/C 的走势类型也必然未定——因为 E/C 的值域依赖于 E/$ 的最终走势方向。

对配置层的影响：如果某条独立边处于"构建中"，则配置节点在该边的分量上是未定的，配置层的极性指数也是未定的。此时配置层在该时间点上不产生有效的转换事件。

### 4.7 配置层的级别递归

配置层的缠论实体（D3-D7）构成了配置空间自己的递归链：

```
配置转换事件序列（原子）
  → 极性指数序列（配置层的"K线"）
  → 配置分型（D3）
  → 配置笔（D4）
  → 配置线段（D5）= ConfigMove[0]
  → 配置中枢（D6）= ConfigCenter[1]
  → 配置走势类型（D7）= ConfigMove[1]
  → ...（递归向上）
```

由于极性指数取值有界（[-3, +3]），配置层的递归深度天然受限——不可能构造出很多层级的配置中枢。这与边层的递归深度受数据长度限制是不同的约束来源，但效果相同：递归自然终止。

### 4.8 四层之间的关系

```
第一层（底层）  ──构成──→  第二层（边层）
     │                        │
     │                        │ 走势完成事件
     │                        ↓
     │                   第四层（配置层）
     │                        ↑
     │                        │ 代数约束
     │                        │
     └──────────────→  第三层（图层）
```

- **底层→边层**：每条边的比价K线是底层构造的实例。边层是底层的六重并行。
- **边层→配置层**：边层的走势完成事件（某条独立边从一种状态转换到另一种状态）驱动配置层的时间序列。配置层不直接消费K线数据。
- **图层→配置层**：图层的代数约束（27 种配置分类、派生边约束范围）为配置层提供一致性检验框架。
- **配置层→边层**（反向）：配置层的走势结构（配置中枢、配置趋势）为边层的分析提供全局上下文——当配置层处于趋势中，边层的个别反向信号可能是噪音而非反转。

## 五、Gemini 三个独立发现在四层框架中的处理

### 5.1 net($) 歧义性

**问题**：v4 §5.5 枚举表中的 net($) 列仅反映三条独立边对现金顶点的净流入计数。读者可能误认为 net(V) 总是只计算独立边。

**在四层框架中的处理**：

net($) 的计算之所以只用了三条独立边，是因为 E/$, C/$, R/$ 恰好是连接到现金顶点的全部三条边。这是现金角作为基准的特殊性质，不是一般规则。

对于其他顶点（如 EQUITY），net(E) 需要考虑 E/$, E/C, E/R 三条边——其中 E/C 和 E/R 是派生边，其方向可能不确定（取决于独立边的符号组合）。因此，非现金顶点的 net 值在同号配置下是不确定的，需要观测派生边后才能计算。

在配置层中，极性指数 P(v) = -net($) 只使用独立边，定义是精确的。其他顶点的 net 值属于图层（第三层）的消歧产出，不属于配置层。

### 5.2 黄金归属

**问题**：黄金既可被视为商品（COMMODITY），也可被视为现金等价物（CASH），造成分类重叠。

**在四层框架中的处理**：

四矩阵的四个顶点是**资本容器类别**，不是具体资产。具体资产到类别的映射是操作层决策，不是本体论定义。本体论只定义：
- 四个顶点存在
- 六条边连接它们
- 每条边上有比价走势

黄金的归属取决于分析目的：
- 作为结算锚定物子图的成员（v4 §3.4）：黄金在 CASH 角内部
- 作为大宗商品的一种：黄金在 COMMODITY 角内部

框架要求的是**在一次分析中，每个资产的归属唯一且排他**。不同分析场景可以有不同的归属映射，但同一场景内不允许重叠。这是操作层约束，不是本体论约束。

### 5.3 "构建中"传递性

**问题**：如果一条独立边处于"构建中"，其代数构成的派生边意味着什么？

**在四层框架中的处理**：

已在 §4.6 中作为显式规则补充。传递性规则：独立边构建中 → 派生边构建中 → 配置层该时间点无有效转换事件。

这是四层结构的自然推论：配置层消费的是边层的走势完成事件。如果边层的走势未完成，配置层就没有输入。不需要额外的规则——配置层的事件驱动架构天然处理了这个问题。

## 六、层间关系的精确描述

### 6.1 底层→边层：实例化

边层的每条边是底层构造的一个实例。底层定义了"如何从价格序列构造缠论实体"，边层将这个构造并行应用于六条比价K线。

关系类型：一对多（一个构造规则，六个实例）。

### 6.2 边层→图层：约束提供

边层产出每条边的走势类型和状态。图层消费这些状态，通过代数约束（乘法恒等式、独立性约束）提供一致性检验和配置分类。

关系类型：多对一（六条边的状态汇聚为一个配置读取）。

### 6.3 边层→配置层：事件驱动

边层的走势完成事件（独立边状态转换）驱动配置层的时间序列。配置层不直接消费K线数据，只消费状态转换事件。

关系类型：事件驱动（边层是生产者，配置层是消费者）。

### 6.4 图层→配置层：约束框架

图层的 27 种配置分类和派生边约束范围为配置层提供静态约束框架。配置层的每个节点都是图层已枚举的 27 种配置之一。

关系类型：静态约束（图层定义了配置层的状态空间）。

### 6.5 配置层→边层：全局上下文（反向）

配置层的走势结构为边层提供全局上下文。当配置层处于趋势中（极性指数持续移动），边层的个别反向信号需要在全局上下文中重新评估。

关系类型：上下文提供（配置层是高层，边层是低层）。

## 七、结果包六要素

### 1. 结论

四层本体论文档完成。从比价K线（底层）到配置空间（配置层），每一层都有完整的缠论实体定义和走势必完美的独立成立条件。配置层是新增内容，核心构造是：转换拓扑 P₃□P₃□P₃ 上的极性指数序列 → 配置分型 → 配置笔 → 配置线段 → 配置中枢 → 配置走势类型。走势必完美在配置层的成立依赖极性指数的有界性（[-3, +3]）。

### 2. 定义依据

- **比价K线**：v4 §1.1，缠师原文第9课（"可交易的独立系统都可以用缠论分析"）

### 3. 边界条件

- **配置层缠论实体退化**：如果边层的走势完成事件极其稀疏（大级别走势长期不完成），配置层的极性指数序列可能过短，无法构造有意义的分型和笔。此时配置层的缠论实体不存在——不是框架失效，是数据不足。
- **极性指数的离散性限制**：极性指数只有 7 个可能值，配置中枢的区间可能非常窄（如 [0, 1]）。这意味着配置层的走势结构比边层粗糙得多——配置层是宏观结构指标，不是精细操作工具。
- **翻转条件**：如果放弃 +↔- 禁止规则（允许走势直接反转），转换拓扑从 P₃□P₃□P₃ 变为 K₃□K₃□K₃（完全图的笛卡尔积），直径从 6 降为 3，配置层的走势结构会更短更碎片化。

- 配置层的级别递归（§4.7）天然受限于极性指数的有界性，递归深度极浅（估计 1-2 层），这本身就是信息——配置层的结构是宏观的、低频的
