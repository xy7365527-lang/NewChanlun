## 3. 验证窗口1：2002-2007 反例

### 3.1 269号核心问题回顾

Gemini Round 3 提出致命反例：2002-2007 美元120→70，月线三重联立满足（中心失构+外围升构+黄金共振），但2008年证明美元霸权完好。编排者提出级别匹配化解：月线满足但年线不满足。

### 3.2 D 算子读数

**DXY 年线**：2002-2007的美元下跌只是年线上的**一笔下跌**（Stroke[3]: 121.02→70.70），没有形成线段、中枢、走势。D 算子在年线上不读出"结构破坏"。

**DXY 月线**：2001-2008 期间的笔结构：
```
Stroke[27]: down 121.02→80.39  (2001-07 → 2004-12)
Stroke[28]: up   80.39→92.63  (2004-12 → 2005-11)
Stroke[29]: down 92.63→83.60  (2005-11 → 2006-05)
Stroke[30]: up   83.60→87.30  (2006-05 → 2006-10)
Stroke[31]: down 87.30→70.70  (2006-10 → 2008-04)
```
月线上有多笔交织，但这些笔全部落在月线中枢 [90.54, 110.31] 内部（作为中枢内的振荡），**被 D 算子的 D3 层吸收**。

**三重联立检测**：
- 中心失构（DXY下跌趋势）：**否**——年线无趋势走势，月线无突破中枢
- 外围升构：**否**——外围品种同样无走势
- 法币/黄金共振：**否**——黄金同样无走势

### 3.3 验证结论

**三重联立在年线和月线上均不满足。**

这一结果**强支持编排者的级别匹配论证**（269号 Round 3）：

1. 2002-2007 的美元下跌在年线上只是一笔，不构成趋势走势
2. 在月线上，下跌被一个覆盖 DXY 全部历史的大中枢吸收
3. D 算子没有在任何大级别上读出"结构破坏"
4. 因此三重联立判据在这个窗口正确地**不报警**

**但需要注意**：这个结论同时揭示了一个更深层的问题——D 算子在超大级别上可能过于"迟钝"。DXY 的整个 55 年历史被读为一个大盘整，这可能意味着年线/月线级别的三重联立判据**永远不会触发**，因为没有任何事件能突破这个大中枢。

## 4. 验证窗口2：1971 布雷顿森林崩溃

### 4.1 数据限制

DXY数据从1971年1月开始。在年线级别上，1971-1975窗口只有5根K线，完全不够形成笔结构。在月线上，1971-1975有约60根K线，但整个 1971-2026 的662根月线管线只产生了52笔和1个中枢。

### 4.2 D 算子读数

**无法验证**。原因不是方法论问题，而是数据物理约束：
1. DXY在1971年前不存在（美元指数1967年设定基线但yfinance数据从1971年起）
2. 黄金、外围汇率的长历史数据在免费API中不可用
3. 布雷顿森林崩溃前后需要至少1960年起的数据才有意义

### 4.3 数据获取建议

要验证1971窗口，需要：
- DXY或等价指数的1960-1980数据（需付费数据源或学术数据库）
- 黄金价格的1960-1980数据（伦敦金定盘价，需付费）
- GBP/USD等汇率对的1960-1980数据（需付费）

潜在数据源：
- FRED (联邦储备银行数据)：可能有部分汇率数据
- World Gold Council：历史金价
- Bank of England：历史英镑汇率
- 需要 `pandas_datareader`（当前未安装）

## 5. 多序列级别对齐问题

269号第三个未解决问题：三个资产分别在不同级别触发时，联合状态级别如何判定。

当前验证结果表明**这个问题暂时不可实测**：所有品种在大级别上都没有产出走势，联合状态判定无数据基础。

原因：大级别走势形成需要的数据量超出了当前免费API的覆盖范围（需要更长的历史或更多的K线）。

## 6. 边界条件

当前结论在以下条件下翻转：

1. **使用更长历史数据**（1944年起的DXY等价指数）：可能产生更多线段和中枢，改变走势读数
2. **使用不同笔模式**（严笔 vs 宽笔）：当前使用 wide 模式，strict 模式可能产生更多笔
3. **使用日线聚合而非月线**：在日线上运行然后用递归级别升级，可能产生更丰富的中间结构
4. **D 算子参数调整**：当前使用默认参数，不同参数可能改变 ker(D) 边界
