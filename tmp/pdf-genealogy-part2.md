### 编排者决断
**不做 C→Au 重命名**。理由：

1. **本体论 vs 认识论**：C 顶点是本体论层面的资本池完全分类（权益/商品/债券/现金），259号揭示的是认识论约束（D 算子的有界性），不是本体论修正

- C 顶点语义保持"商品"不变

## 五、层0 的本体论地位重新认识（第76-86页）

### 层0 是什么？

编排者与 Claude 经过多轮推导，层0 的认识经历了以下演变：

1. **初始**：层0 = 结算尺空间，独立的第三层
2. **自指假说**：层0 同时是层1/层2 运行的前提条件和历史产物 → 自指折叠点
3. **编排者修正**：不是自指（A→A），是**互测网络**（A→B→C→A）—— 尺子之间互相量
4. **缠论可运行性**：汇率对（USD/CNY、XAU/USD 等）有 K 线，缠论完全可以在上面运行
5. **最终定位**：三层保留，但层0 增加**语义递变标注**

### 三层语义递变（定义3 补全）

| 层 | 缠论运行域 | 结构事件语义 |
|---|---|---|
| 层0 | 汇率对 | 公理0 有效域的动态边界检测（框架有效性判断） |
| 层1 | 跨资产耦合 | 资本在 E/Au/R 之间的配置转折 |
| 层2 | 具体标的 | 操作点位 |

三层用同一套工具（中枢、背驰、买卖点、区间套），但产出的语义递变。

### 互测网络的操作含义

- 结算尺互测网络 = 多把尺子之间互相测量
- 缠论在每条汇率对上独立运行 → 产出结构事件
- 以某结算尺为分母的**星形子图**中，多条汇率边同步出现同方向大级别结构事件 = 结算尺地位变化的特征信号
- 单条边的结构事件不充分（无法区分分子变化和分母变化）

### 定理2 修正

- 判据：星形子图同步一致模式
- 级别标注：日线级别同步 = 短期信心危机；月线/年线 = 结构转折

## 七、操作方法论 v1 的完整推导（第90-117页）

### 核心原则：不测而测
- 扬弃缠师概率论框架（30%×30%×40%）
- 替代为完全分类的**二值判断**：可操作 / 不可操作
- 全程不预测，结构完备则操作，不完备则不动

### 概率论框架为何被扬弃
- 概率乘法预设三个程序（缠论走势、比价关系、基本面）的独立性
- 但三者不独立——是同一个资本流在不同尺度上的读数
- 不独立的事件乘概率没有意义

### 默认前提：满仓满融
- 与降成本方法结构性配合：杠杆仓位使每次短差绝对收益翻倍，回收目标不变（自有资金）
- 降成本所需短差次数减半
- 不是操盘者的偶然选择，是方法论的天然加速器

### 操作方法论七要素

**一、选股 + 定级别（纠缠的，非线性）**
- 第一步：二值筛选
  - 缠论筛：有没有完备买卖点结构？同时确定级别
  - 比价筛：K4 配置是否支持？
  - 基本面筛：操盘者外部判断，不入语法，具有平等否决权
  - 三者不是三道独立筛，是同一个资本流在不同尺度上的读数
- 第二步：区间套收敛排序
  - 满仓满融只能选一个标的
  - 收敛路径：K4 配置 → 板块（指数/ETF）→ 个股
  - 收敛可以停在任何一层——哪层结构最完备就在哪层操作
  - 大级别收敛优于小级别收敛

**二、三阶段操作**
- 阶段1 建仓：买点出现，一次性满仓满融进入，不分批
- 阶段2 降成本：主级别持仓不动，次级别做短差。每层 ≤ n%。终止条件：累计回收 ≥ 初始自有资金
- 阶段3 退出本金：剩余仓位 = 市值 - 融资负债 = 纯利润

**三、小转大**
- 不可事前预测，事后由结构确认
- 满仓满融下不需要加仓——已经满仓
- 旧级别短差停止，在新主级别的次级别出现后继续
- 小转大产生赋格：旧循环利润底仓 + 新级别降成本循环并存

**四、止损**
- 结构内生：买点结构失效 = 止损点
- 满融下止损必须绝对果断
- 大转小处理：结构破坏→止损；未破坏→等待

**五、不换仓原则**
- 持仓期间不因外部机会换仓
- 理由1：不测而测——"B 出现更好机会"不是 A 的结构事件
- 理由2：降成本不可逆性——换仓归零全部进度
- 编排者确认：换了再进来就难了，已积累的成本优势不可替代
- **审计结论**：用 B 的结构决定 A 的操作 = 违反不测而测（不合法）

**六、免费仓位管理**
- 退出本金后 = 不测而测
- 主级别卖点出现就平仓
- 如果已小转大，看新的主级别结构

**七、赋格的定义**
- 满仓满融下赋格 = 同一个满仓仓位上、不同级别的短差操作的嵌套 + 小转大后新旧循环并存
- 不是多个独立仓位的并行操作，是单一仓位上的多层嵌套

### 不入语法的外部要素（三项）
1. 基本面判断（否决权）
2. 仓位比例 n%（每层短差动用比例）
3. 最小可操作短差级别（市场交易制度约束，如 A 股 T+1）
