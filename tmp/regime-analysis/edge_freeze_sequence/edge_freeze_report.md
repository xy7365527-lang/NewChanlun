# 边冻结进入/退出序列分析报告

**日期**: 2026-03-04
**认识论等级**: L2（三个独立历史体制的真实数据验证）
**谱系依据**: 330号（K4拓扑与资本循环映射）、329号（折叠内在性检验最终结算）

---

## 一、结论

### 330号预测检验结果：部分确认

330号预测：**不同金融循环断裂位点应产生不同的边冻结模式**。

| 体制 | 窗口 | 推断断裂节点 | 分异度 | 判定 |
|------|------|-------------|--------|------|
| 1987 (22天) | 1987-01-06 ~ 1987-02-04 | **USD** | 0.2831 | DIRECTIONAL_CONFIRM |
| 1990-91 (219天) | 1990-10-23 ~ 1991-09-06 | **Commodity** | 0.0815 | DIRECTIONAL_CONFIRM |
| 2020-21 (263天) | 2020-04-03 ~ 2021-04-23 | **Commodity** | 5.5288 | DIRECTIONAL_CONFIRM |

**三个体制全部通过方向性检验**（含断裂节点边的 vol ratio 均值 > 不含断裂节点边的 vol ratio 均值），但：

- 1987 和 1990-91/2020-21 断裂节点分异（USD vs Commodity） -- 符合预测
- 1990-91 和 2020-21 断裂节点相同（均为 Commodity） -- 不够分异
- **没有观测到 Equity 断裂**（P->C 断裂类型缺失）

结论：330号预测的**方向性**（含断裂节点边 vol 偏高、不含断裂节点边 vol 偏低）在三个体制中均成立。**节点分异性**部分成立（2种/3种），但 Equity 断裂类型未被观测到。

## 二、定义依据

### 方法

- **边** = log(节点A价格 / 节点B价格) 的日收益率
- **边波动率** = 20天 rolling std of edge returns
- **vol ratio** = 体制内均值 / baseline均值（>1=激活，<1=冻结）
- **baseline**: 体制开始前60个交易日（2020-21特殊处理：截止到2020-02-15，避免COVID crash污染）
- **节点分异度** = avg_vol_ratio(含N边) - avg_vol_ratio(不含N边)，最大分异度节点 = 推断断裂位点
- **entry phase**: 体制前30天（用于分离进入冲击和持续状态）

### 数据源

- USD: yfinance `DX-Y.NYB` (美元指数)
- Equity: yfinance `^GSPC` (S&P 500)
- Commodity: FRED `DCOILWTICO` (WTI现货)
- Au: yfinance `GC=F` (黄金期货，仅2020-21)

## 三、三个体制详细分析

### 3.1 1987体制（三节点，22天）

**历史背景**: 1987年1月-2月，S&P 500在1986年底调整后反弹的初期。此压缩窗口在1987年10月黑色星期一之前约8个月。

**entry vol ratios** (体制内/baseline):

| 边 | vol ratio | z-score |
|----|-----------|---------|
| USD/Equity | **1.194** (激活) | +0.99 |
| USD/Commodity | **0.656** (冻结) | -1.22 |
| Equity/Commodity | **0.642** (冻结) | -1.67 |

**时序**:
- **第一条冻结边**: Equity/Commodity，1987-01-06（体制第1天）
- **第二条冻结边**: USD/Commodity，1987-01-14（体制第7天）
- **唯一暴动边**: USD/Equity，1987-01-27（体制第16天）

**模式解读**: 不含USD的边（Equity/Commodity）大幅冻结至baseline的64%。含USD的两条边分裂：USD/Equity激活（119%），USD/Commodity冻结（66%）。最大分异节点=USD（含USD边均值0.925 vs 不含USD边0.642，分异度0.283）。

**退出**:
- 三条边在退出后20天内全部恢复正常（2-25 ~ 2-27），几乎同步

**解读**: 这不是330号定义的"M->P断裂"的完美实现（因为USD/Commodity也冻结了），更像是**美元重新定价**——USD/Equity边活跃（美元和股市的相对价格在调整），而Commodity脱钩（油价在此期间相对稳定，石油市场无独立冲击）。

### 3.2 1990-91体制（三节点，219天）

**历史背景**: 1990年8月2日伊拉克入侵科威特 -> 油价从8月的$20+飙升到10月的$40+ -> 1991年1月17日"沙漠风暴"开始 -> 油价暴跌回$20。此窗口覆盖了整个海湾战争周期。

**entry vol ratios** (前30天, 1990-10-23 ~ 1990-11-29):

| 边 | vol ratio | z-score |
|----|-----------|---------|
| USD/Equity | 1.123 | +0.73 |
| USD/Commodity | **1.221** (最高) | +1.01 |
| Equity/Commodity | 1.187 | +0.88 |

**sustained vol ratios** (第31天以后):

| 边 | vol ratio |
|----|-----------|
| USD/Equity | 0.976 (近正常) |
| USD/Commodity | **0.674** (冻结) |
| Equity/Commodity | **0.628** (冻结) |

**时序**:
- **第一条暴动边**: USD/Commodity，1990-10-29（体制第5天）
- 此后整个entry phase无冻结
- sustained phase进入深度冻结（Commodity边降至baseline的63-67%）

**模式解读**: entry phase三条边全部激活（海湾危机的冲击波），但含Commodity边（1.204均值）高于不含Commodity边（1.123），分异度0.0815。sustained phase出现典型的**Commodity边冻结**模式——USD/Commodity和Equity/Commodity降至baseline的63-67%，而USD/Equity几乎回到正常（0.976）。

**解读**: 这是330号预测的"C->M'断裂"的实现。oil shock → 含Commodity边先暴动 → 冲击消散后含Commodity边冻结。注意entry和sustained的反转：entry是冲击期（全图激活但Commodity边领先），sustained是冻结期（Commodity边冻结而其他边正常）。

### 3.3 2020-21体制（四节点，263天）

**历史背景**: COVID crash (2020-03) -> 史诗级QE -> WTI负油价 (2020-04-20) -> 全球资产大反弹。

**baseline**: 截止到2020-02-15（COVID crash前的平静期），避免2020年3月极端波动污染baseline。

**entry vol ratios** (前30天, 2020-04-03 ~ 2020-05-15):

| 边 | vol ratio | z-score |
|----|-----------|---------|
| Au/USD | 2.887 | +6.49 |
| Au/Equity | 3.203 | +4.82 |
| Au/Commodity | **9.401** | +12.14 |
| USD/Equity | 6.564 | +17.67 |
| USD/Commodity | **9.679** | +11.03 |
| Equity/Commodity | **10.160** | +66.43 |

**节点分异度**:

| 节点 | 含节点边均值 | 不含节点边均值 | 分异度 |
|------|------------|-------------|--------|
| **Commodity** | **9.747** | 4.218 | **+5.529** |
| Au | 5.163 | 8.801 | -3.638 |
| USD | 6.377 | 7.588 | -1.211 |
| Equity | 6.643 | 7.322 | -0.680 |

**riot序列**（注意：这些日期在regime_start 2020-04-03之前，来自pre窗口）:
1. Au/Equity: 2020-02-21
2. USD/Equity: 2020-02-21
3. Au/USD: 2020-02-25
4. USD/Commodity: 2020-03-02
5. Equity/Commodity: 2020-03-04
6. Au/Commodity: 2020-03-06

**sustained vol ratios**:

| 边 | vol ratio |
|----|-----------|
| Au/USD | 1.816 |
| Au/Equity | 1.628 |
| Au/Commodity | 1.745 |
| USD/Equity | 2.517 |
| USD/Commodity | 1.671 |
| Equity/Commodity | 1.494 |

**模式解读**: 全图极端激活（所有边vol=baseline的3-10倍），但Commodity相关三条边（Au/Commodity, USD/Commodity, Equity/Commodity）vol ratio均值=9.75x，远高于不含Commodity的三条边（Au/USD, Au/Equity, USD/Equity）均值=4.22x。这与329号的"含OIL边暴动+不含OIL边冻结"一致（只是"冻结"在此处是相对冻结——4x vs 10x，绝对值都远高于baseline，但相对差异极大）。

**riot序列的额外信息**: 最先暴动的是含Equity的边（Au/Equity和USD/Equity在2-21），然后才是含Commodity的边（3-02开始）。这反映了COVID crash的传导路径：**先是Equity冲击（2月下旬股市暴跌），再是Commodity冲击（3月油价战争+负油价）**。但体制内的持续分异指向Commodity作为最大断裂位点。

## 四、330号预测检验总结

### 4.1 被确认的

1. **方向性分异**: 三个体制中，含断裂节点边的vol ratio均值**始终高于**不含断裂节点边的vol ratio均值。分异度分别为0.2831 (1987/USD)、0.0815 (1990-91/Commodity)、5.5288 (2020-21/Commodity)。

2. **节点分异——部分确认**: 1987断裂节点=USD, 1990-91/2020-21断裂节点=Commodity。两种不同的断裂类型被观测到。

3. **1987模式（USD断裂）**: 不含USD的边（Equity/Commodity）冻结至baseline的64%，唯一暴动边=USD/Equity。这接近330号预测的"M->P断裂"模式，但USD/Commodity边也冻结了（而非暴动）。

4. **1990-91模式（Commodity entry暴动→sustained冻结）**: entry phase含Commodity边领先暴动，sustained phase含Commodity边深度冻结而USD/Equity边回到正常。时序结构清晰。

5. **2020-21模式（Commodity极端分异）**: 含Commodity边vol=baseline的9.75x vs 不含Commodity边=4.22x。绝对值全部激活但相对差异5.5x。

### 4.2 不完全符合的

1. **1987的USD断裂不完美**: 330号预测"含USD边暴动+不含USD边冻结"。实际：含USD的两条边分裂（USD/Equity暴动，USD/Commodity冻结）。不是纯粹的"含USD边暴动"。

2. **1990-91的Commodity断裂弱信号**: entry phase分异度仅0.0815（全图激活，三条边差异不大）。需要等到sustained phase才出现清晰的冻结模式。entry phase的信号强度不足以做实时判断。

3. **2020-21的Commodity断裂——"冻结"是相对的**: 不含Commodity边vol=baseline的4.22x，不是绝对冻结（329号观察的是0.5x）。这是因为COVID crash+QE导致全图极端激活，"冻结"只在边间相对比较中存在。

### 4.3 未被观测到的

1. **Equity断裂类型（P->C断裂）**: 三个体制中没有一个的断裂节点是Equity。330号的三种预测（M->P, P->C, C->M'）中P->C类型缺失。

2. **Au断裂类型**: 2020-21中Au的分异度为-3.638（含Au边反而低于不含Au边），Au不是断裂位点。

### 4.4 意外发现

1. **entry/sustained反转**: 1990-91体制显示entry phase（冲击期）全图激活但含Commodity边略高 → sustained phase（持续期）含Commodity边深度冻结。冻结不在进入时刻而在冲击消散后。这对330号模型是重要修正——**边冻结是冲击后的持续状态，不是冲击本身的特征**。

2. **2020-21的riot序列**: 含Equity边最先暴动（2-21），含Commodity边在2周后才暴动（3-02~3-06）。传导路径有时序结构。

3. **分异度量级差异极大**: 2020-21的分异度（5.53）是1987的（0.28）的20倍、1990-91的（0.08）的70倍。这可能反映COVID+负油价的极端性，也可能反映四节点体制下分异度的系统性放大。

## 五、边界条件

1. **三节点 vs 四节点不可直接比较**: 1987/1990-91是三节点三边，2020-21是四节点六边。边数不同导致分异度量纲不同。
2. **Baseline选择影响判定**: 2020-21的baseline截止到2020-02-15（COVID前）。如果用默认baseline（含COVID crash），所有边的z-score接近0，检测不到信号。baseline选择是分析的关键自由度。
3. **WTI作为Commodity代理**: 1987/1990-91的Commodity仅用WTI。如果用CRB综合指数，结果可能不同。
4. **体制窗口预设性**: 三个体制的起止日期是预先给定的（来自先前的同步压缩分析），不是本分析内生发现的。
5. **entry_phase_days=30的任意性**: 1987体制仅22天（entry=全体制），1990-91和2020-21的30天entry是固定参数。不同的entry窗口可能改变分异度量级。
6. **样本量**: n=3个体制，统计推断力极弱。三种断裂类型只观测到两种。

## 六、下游推论

1. **330号模型需要从"进入冻结"修正为"冲击→持续冻结"**: 1990-91显示冻结不在进入时刻而在冲击消散后。模型应区分冲击期（全图激活，断裂节点边略高）和持续期（断裂节点边冻结）。

2. **Equity断裂类型是待填空**: 需要找到P->C断裂的历史体制（可能的候选：2008年金融危机、2000年互联网泡沫？但这些体制的同步压缩窗口需要独立识别）。

3. **实时应用的限制**: 1990-91的entry phase分异度仅0.0815，不足以在实时中判断断裂节点。需要等到sustained phase才有清晰信号——这意味着断裂节点的实时判断在冲击初期是困难的。

## 八、影响声明

本分析对330号"断裂位点->边冻结模式"预测执行了三个历史体制的L2检验。方向性分异在三个体制中均成立，节点分异观测到两种类型（USD和Commodity），P->C断裂类型（Equity断裂）未被观测到。发现1990-91体制的entry/sustained反转——冻结是冲击后的持续状态而非冲击本身的特征。330号预测的基本框架得到方向性支持，但需要修正：（1）加入entry/sustained时序结构；（2）承认Equity断裂缺失。不构成对330号的否定也不构成完全确认。
