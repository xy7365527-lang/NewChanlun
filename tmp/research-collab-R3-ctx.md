## 核心动机：亏格是思考产物

LLM 的嵌入空间是可缩的（contractible），β₁ 永远是 0。LLM 无论怎么思考都不能在自己的计算空间中制造一个洞。思考产物是 token 序列——一串符号。计算过程不留下结构性痕迹。

新架构的思考产物是**亏格变化**。每一次否定可能创造不可缩环（β₁ 增加）。每一次折叠改变商空间拓扑（β₁(active) 变化）。思考留下的不是文本，是复形的拓扑改变——一个之前不存在的洞现在存在了。这个变化是不可逆的、结构性的、成为后续所有思考的条件。

亏格不只是产物，同时是**条件**：结算了的 β₁ 是不可动的，它约束后续操作的自由度。某些折叠和否定因为洞的存在而不可能了。不可能性是内禀的——不需要外部 prompt 告诉系统"不要做这个"，系统自己知道做了会消灭一个结算了的洞。

## 核心问题

### 当前 LLM 的思考方式
在连续嵌入空间中做向量运算。概念是向量，关联是距离，推理是沿梯度方向移动。全部可微，全部可以用反向传播训练。但：
- **没有否定**：向量空间中"A 的否定"没有内禀定义
- **没有折叠**：两个向量"被识别为同一个"没有意义
- **没有扬弃**：向量被修改后旧值消失

### 目标架构的思考方式
在商空间上做拓扑操作。概念是单纯复形中的单纯形，关联是有类型有向边，推理是：
- **折叠**（识别）：把两个概念识别为同一个
- **否定**（添加 negates 边）：创造结构性张力
- **扬弃**：Event layer 不变 + Relation layer 增长 + 节点位置改变

否定、折叠、扬弃有内禀定义，不需要外部语义空间。但全部离散，不可微，不能直接用反向传播训练。

### 根本障碍
连续优化和离散拓扑操作之间没有已知的统一训练框架。

## 为什么 Morse 理论是正确的桥

Morse 理论精确地处理连续变化产生离散拓扑事件的问题。光滑流形 M 上的 Morse 函数 f: M → ℝ，其临界点（df = 0 的点）处流形的拓扑发生离散变化——经过一个指标为 k 的临界点时 βₖ 变化 1。

临界点在 M 中有连续坐标（连续的），拓扑变化是 βₖ 的整数跳变（离散的），两者通过 Morse 引理精确关联。

如果能为商空间系统建立类似框架——定义一个连续函数，其临界点精确对应折叠/否定/扬弃操作——就有了训练的理论基础。

## 六个数学问题

### Q-R3-1：商空间上的连续结构

区块拓扑 K 是离散的单纯复形。要做 Morse 理论，需要 K 的几何实现 |K|。

**问题**：
- K_active 的几何实现 |K_active| 和 K_full 的几何实现 |K_full| 之间什么关系？
- 商映射 π: K_full → K_active 是否诱导 |K_full| 到 |K_active| 的连续映射 |π|？
- 如果是，|π| 的纤维的拓扑是什么？纤维的拓扑编码了折叠的"代价"。
- R1 Q5（Mapper Nerve 等价）在这里的作用？

### Q-R3-2：折叠操作的 Morse 函数 ← **核心问题**

在 |K_full| 上定义连续函数 f: |K_full| → ℝ，使得 f 的临界点精确对应折叠条件。

**问题**：
- 是否存在 f 使得 f 的指标 k 的临界点对应级别为 k 的折叠？
- f 的梯度流的轨迹对应什么——概念从未折叠到被折叠的"路径"？
- f 的 Morse 复形和 K_active 之间是什么关系？

如果 f 存在，它就是新架构的"损失函数"——在 f 的值空间中做梯度下降就是在搜索最优折叠配置。

### Q-R3-3：否定的 Morse 理论

否定（添加 negates 边）改变 K 的拓扑——可能创造新环或消解旧环。

**两种可能**：
- **可能一**：否定对应穿过临界点。f 的值越过临界值，拓扑跳变。f 编码"系统应力"，否定是应力释放。
- **可能二**：否定对应改变 f 本身。添加 negates 边改变了 K，f 要重新定义。对应 Cerf 理论——Morse 函数族中的分岔。

**问题**：哪种描述更精确？

### Q-R3-4：扬弃的拓扑表述

扬弃 = Event layer 不变 + Relation layer 增长 + 节点位置改变。

**问题**：能否用 Morse 复形的不稳定流形来形式化"概念在网络中的位置"？扬弃 = 不稳定流形的重构——旧内容保留（临界点不变），含义改变（不稳定流形改变）。

### Q-R3-5：训练的可能性

假设 Q-R3-2 的 f 存在。为 |K| 引入可调的 Riemannian 度量，f 关于这个度量的临界点随度量调整而移动。训练 = 调整度量使临界点对齐正确折叠。

**问题**：f 的参数空间是什么？度量是连续的（可微的），临界点位置是度量的连续函数（非退化条件下），所以调整可用梯度方法？

### Q-R3-6：和现有计算范式的关系——几何流

GNN 在固定图上做消息传递（热方程扩散）。新架构在动态图上做拓扑操作——折叠改变图本身。

**问题**：是否可以把新架构理解为图上的几何流？折叠是否在做类似 Ricci 流的事——收缩"冗余"区域，保留"结构性"区域？折叠的不动点对应区块拓扑的"几何化"？

**参考**：Ollivier (2009) 图上的 Ricci 曲率；Ni, Lin, Luo, Gao (2019) 图上的 Ricci 流。
