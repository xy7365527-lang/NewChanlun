## 研究背景

### 项目的四个联结性质

一个基于 LLM 多智能体系统的概念形式化项目（缠论 — 中国股市技术分析理论），产出被铭写为"区块拓扑"：
- **递归**：计算改变计算规则本身（蜂群修改自己的 skill 和 workflow）
- **拓扑**：β₁（第一 Betti 数）驱动系统行为（不可缩环 = 不可消解的概念矛盾）
- **异步**：高层事件追溯性改变低层事件的分类（否定、扬弃）
- **自指**：系统观测自己的 β₁ 并据此决定下一步操作

### 核心数据结构

- **区块**：content-addressed（SHA256），不可变，仅追加
- **关系**：depends_on, negates, negated_by, modifies, supersedes, references — 有类型、有向
- 当前规模：~380 个区块，~4535 条关系边

### 框架混淆问题（已确认）

之前做了三个实验（DM1/DM2/DM3）在谱系 DAG 上做纯图论计算，发现"关系类型标签和临界性统计独立"（p=0.0927）。但这回答的是图论问题，不是架构问题。架构问题是：**LLM 的连续输出被铭写为离散拓扑后，拓扑信息反馈回 LLM 是否改善了 LLM 的输出质量？** 这个问题从未被测试。实验里没有 LLM。

## 核心架构描述

### 不是图重写，是分层商空间

**编排者的关键洞察**：折叠不是替换（图重写），是识别（商空间操作）。被折叠的东西不消失，在全量图中保留。

- **基底空间（全量图）**：不可变的仅追加单纯复形。区块是0-单纯形，关系是1-单纯形
- **商映射（折叠/展开操作）**：由全局拓扑条件触发。缠论的递归定义（笔→段→走势类型→更高级别）就是逐层商映射
- **商空间（活跃图）**：当前视角下的简化表示。拓扑不变量被系统自指性地观测
- **历史熵**：β₁(full) - β₁(active)，编码被折叠和否定"杀死"的环的数量

双图结构是核心：全量图只增长不收缩，活跃图随折叠变化。β₁(full) 单调递增，β₁(active) 随折叠波动。

### LLM 的角色：商映射的候选集生成器

LLM 在连续空间中做模式识别（"这几根K线的结构看起来像一个中枢"），等价于提议一个商映射（"这些区块可以被识别为等价"）。拓扑层验证并执行。

LLM 不需要理解拓扑。语义相似性是拓扑等价的有效代理——但代理不等于理解。拓扑约束（折叠后 β₁ 怎么变？是否和现有 negates 矛盾？）由拓扑层检查。

### 缺的数学桥梁

**连续优化（梯度下降/LLM训练）和离散拓扑操作（商映射/折叠）之间没有已知的统一训练框架。**

- Gumbel-Softmax：连续松弛破坏离散性精确性
- GNN pooling（DiffPool）：pooling 后原始节点消失，没有双图结构
- PersLay/DTM：可微拓扑层，方向对但还不能做商映射

编排者的直觉：Morse 理论可能是桥梁——临界点是连续的（在流形上有坐标），但对拓扑的影响是离散的（经过临界点时 βₖ 变化 1）。

## 编排者提出的数学路径

### 路径 A：离散 Morse 理论（Forman 1998）

1. 在现有谱系上构造离散 Morse 函数，找到临界集
2. 按谱系编号递增构造，记录临界集的时间演化（Cerf 分岔点）
3. 验证：跳跃点 vs 编排者的谱系学判断是否一致
4. 如果不一致的模式揭示了标准理论的扩展方向 → 类型化离散 Morse 理论（论文）

**已知困难**：Forman 假设无向单纯复形。谱系 DAG 是有向有类型的。

### 路径 B：折叠的 Morse 理论描述

定义一个"参数化离散 Morse 函数族"——把谱系编号当作参数 t，在每个 t 定义复形 Kₜ 和离散 Morse 函数 fₜ。{fₜ} 的分岔点对应折叠事件。这是离散 Cerf 理论的实例。

### 路径 C（编排者未提但上一轮 Gemini 建议）：范畴论框架

LLM 视为从文本范畴到向量空间范畴的函子。商映射视为余极限（Colimit）。为连续-离散统一提供严格数学桥梁。

### 路径 D（编排者未提但上一轮 Gemini 建议）：Mapper ↔ 活跃图

TDA 中的 Mapper 算法本质上是 Reeb 图的离散化。与"活跃图是全量图在某种覆盖下的简化"结构相似。

## 核心研究问题（开放讨论，不是 yes/no 决策）

### Q1：商空间操作的数学形式化

把区块拓扑的折叠操作写成精确的数学语言。给定全量单纯复形 K（有类型有向边），折叠操作 φ 是什么？商复形 K/φ 的同调和 K 的同调之间有什么关系？这个关系是否给出 β₁(full) - β₁(active) 的拓扑解释？

### Q2：有向有类型复形上的 Morse 理论

Forman 的离散 Morse 理论需要什么样的扩展才能处理有向有类型单纯复形？Minian 的工作走了多远？类型标签对 Morse 不等式有什么影响？

### Q3：参数化族和 Cerf 分岔

把谱系演化建模为离散 Morse 函数的参数化族。Vineyard 理论（Cohen-Steiner 2006）和这个设定的关系是什么？有没有更好的框架？

### Q4：连续-离散界面

Morse 理论的核心承诺是"临界点是连续的，拓扑变化是离散的，两者精确关联"。这个承诺能否从经典/离散 Morse 理论推广到"LLM 的连续语义空间和区块拓扑的离散结构之间的界面"？如果能，精确的数学表述是什么？

### Q5：Mapper 和商空间的关系

Mapper 算法构造的 nerve of a covering 和区块拓扑的活跃图之间有形式化的对应吗？折叠操作能否表述为 Mapper 的参数选择？

### Q6：最有希望产生第一个具体结果的方向

哪个路径最可能在几周内产出一个可计算、可验证的具体结果（不是论文，是在现有 380 个区块上的计算实验）？
