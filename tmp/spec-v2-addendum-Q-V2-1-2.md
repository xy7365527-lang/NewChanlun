# v2 规格修正附录：Q-V2-1 和 Q-V2-2 的干净解

## Q-V2-1：两种 Negate，两种时机

### Case A：遭遇已有矛盾（w 已存在于 K_active）

穿越中发现已有顶点 v 和 w 互相矛盾。添加 negation 边 w→v。
因为 v 和 w 都已存在，它们之间大概率有替代路径（穿越路径本身就是证据）。
negation 边 + 替代路径 = 环。**Δβ₁ = +1 在否定步**。

### Case B：创造新反题（w 新建）

穿越中产生全新想法来反驳 v。w 是新顶点。添加 negation 边 w→v。
w 刚诞生，v 到 w 之间无路径。**Δβ₁ = 0 在否定步**。
等 Sublation 创建 C（C→v, C→w），三角形构成环。**Δβ₁ = +1 在扬弃步**。

### 结论

两种情况都合法。净效果相同（+1），时机不同。
Case A 更符合穿越/遭遇范式（遭遇已有结构中的矛盾）。
Case B 更符合创造性思考（新想法从遭遇中涌现）。
规格同时支持两种。

## Q-V2-2：创建即到达

新创建的顶点（synthesis C，或新 antithesis w）没有入边——穿越无法从外部到达。

**解法**：创建即到达。创建 C 的那一刻，当前位置就是 C。
从 C 出发，沿 C→A 或 C→B 走回已有结构。穿越继续。

source 状态是暂时的——后续操作会自然创建指向 C 的边（当某个未来节点 depends_on C 时），C 从 source 变为可达顶点。

不需要跳跃机制、优先级标记或额外规则。

## 影响评估

v2 核心结构不受影响。修正是明确化，不是重构。
