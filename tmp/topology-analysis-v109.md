## 一、重复结构

### 1.1 depends_on 模式重复

精确匹配的 depends_on 集合：

| 模式 | 重复次数 |
|------|---------|
| `[020]` | 4 个区块共享 |
| `[014]` | 3 个区块共享 |
| `[017]`, `[015]`, `[115]`, `[178,182]` | 各 2 个区块共享 |

这些是低阶聚类：多个区块仅依赖同一个根节点。不构成结构异常——早期概念节点（014, 015, 017, 020）作为基础定义被多个下游引用是正常的。

### 1.2 关系类型分布

| 类型 | 数量 | 占比 |
|------|------|------|
| depends_on | 644 | 54.4% |
| related | 458 | 38.7% |
| tensions_with | 31 | 2.6% |
| records | 15 | 1.3% |
| negates | 13 | 1.1% |
| negated_by | 13 | 1.1% |
| splits | 5 | 0.4% |
| residue_of | 4 | 0.3% |

`related` 占 38.7%——接近 `depends_on`。这意味着拓扑中近四成的边是"相关"而非"依赖"，对 DAG 严格性分析而言这些边不携带方向性约束。

### 1.3 内容类型碎片化

`content.type` 有 38 种变体，其中：
- 核心类型（语法记录 72 + meta-rule 28 + 定理 18 + 选择 16 + 矛盾记录 9 + 矛盾发现 8）覆盖主体
- 6 个区块使用繁体 `語法記録`（141, 143, 145, 177, 178, 179），与简体 `语法记录` 不一致
- 1 个区块使用繁体 `張力標記`（180）
- 大量长描述性 type（如"语法记录（已在运作的规则显式化：数学语言与缠论语言的对应关系）"）——这些本质上是 title 而非 type

## 二、剩余积累

### 2.1 孤立节点（零关系）

6 个节点完全没有 incoming 或 outgoing 关系：**198, 201, 206, 207, 209, 210**

这些节点在 `id_mapping` 中存在，有对应的 block 文件，但：
- block 内容中 type=?，title=?，deps=0，refs=0（除 198 外均为 hollow blocks）
- 不出现在 relations.jsonl 的任何一端
- 形成 6 个独立的连通分量

**判定**：这些是空壳区块——id 被分配但内容未填充、关系未建立。属于剩余积累。

### 2.2 Hollow Blocks（有 ID 无实质内容）

18 个 hollow blocks（type=? 且 title=?）：
```
193, 204, 205, 206, 207, 208, 209, 210, 211, 212, 213, 214, 217, 218, 219, 220, 227, 228
```

其中：
- 204-214 是一个连续段（11 个），集中在 cc source
- 217-220 又是一个连续段（4 个）
- 227-228 是两个

这些区块在 id_mapping 中占位，在 blocks 目录下有文件，但内容字段全为空。

### 2.3 Partial Blocks（有标题无类型）

33 个 partial blocks（有 title 但 type=?）：
```
182, 229-260
```

整个 229-260 段（32 个区块）都没有 `content.type`。这些是较新的区块，使用 `refs` 字段而非 `content.depends_on` 来记录依赖，但 type/status 字段未填充。

### 2.4 未映射哈希

relations.jsonl 中有 33 个哈希不在 id_mapping 中，涉及 40 条关系（含 4 条重复）。这些可能是：
- 被删除的区块的残留引用
- 迁移过程中的孤儿记录

### 2.5 Refs-Relations 不一致

16 条 refs 引用没有对应的 relations.jsonl 条目：
- 181 -> 154, 162, 174
- 182 -> 178, 181
- 193 -> 184-2-first-real（非法 ID）
- 224 -> 137, 143, 218
- 225 -> 224, 137
- 226 -> 224, 225, 137, 057, 173

这表明新式 block（使用 refs 字段）与旧式 relations.jsonl 之间存在同步缺口。refs 声明了依赖，但 relations.jsonl 未记录。
