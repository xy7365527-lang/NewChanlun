## 3. 模式发现

### 3.1 [重复] 否定+依赖重叠

14 条 negates 中有 **11 条**（78.6%）与 depends_on 共存于同一对节点：

| 否定者 | 被否定者 |
|--------|----------|
| 064 | 062 |
| 068 | 065 |
| 068 | 066 |
| 087 | 086 |
| 088 | 032 |
| 095 | 073b |
| 116 | 105 |
| 156 | 154 |
| 162 | 158 |
| 173 | 088 |
| 215 | 214 |

观察: 否定在本拓扑中几乎不以独立形态出现，而是叠加在依赖关系之上。否定不是"断裂"，是"扬弃"（Aufhebung）——否定者依赖被否定者才能否定它。

### 3.2 [重复] 否定链

两条三级否定链：

1. **173 --negates--> 088 --negates--> 032**
2. **274 --negates--> 073a --negates--> 073**

无更长的链。无否定环（否定图是 DAG）。

### 3.3 [重复] 同一目标的反复否定

- **073b**: 被 095 和 135 分别否定（两个独立否定者）
- **062**: 被 064 否定 + negated_by 093（但 093 negates 062 的正向边缺失——见 5.2 节）

观察: 073b 所代表的概念位置具有某种"回返"倾向，需要多次否定才能完成清算。

## 5. 273号否定拓扑代数模式检测

### 5.1 扬弃模式（Aufhebung）— 已充分显现

定义: 否定者 A negates B，且 A depends_on B，且存在 C depends_on A。

11/14 的 negates 边与 depends_on 共存（78.6%）。每个否定者都有下游依赖者：

| 否定者 | 被否定者 | 下游依赖 |
|--------|----------|----------|
| 064 | 062 | 065, 066, 067, 078, 080 |
| 068 | 065/066 | 069, 121, 132 |
| 087 | 086 | 088, 090, 103 |
| 088 | 032 | 089, 103, 134, 173 |
| 095 | 073b | 096, 097, 105, 116, 135 |
| 116 | 105 | 130 |
| 135 | 073b | 153 |
| 156 | 154 | 157, 158 |
| 162 | 158 | 174 |
| 215 | 214 | 229 |
| 274 | 073a | （目前无下游）|

观察: **扬弃是本拓扑中否定的唯一模式**。不存在"纯切断"——每次否定都保留依赖并产生下游。否定运算不是幂零的。

### 5.2 negated_by / negates 不对称

| 类型 | 细节 |
|------|------|
| 缺 negates 正向边 | 062 negated_by 093，但无 093 negates 062 |
| 缺 negates 正向边 | 095 negated_by 096，但无 096 negates 095 |
| 缺 negated_by 反向边 | 274 negates 073a，但无 073a negated_by 274 |
| 缺 negated_by 反向边 | 135 negates 073b，但无 073b negated_by 135 |
| 缺 negated_by 反向边 | 215 negates 214，但无 214 negated_by 215 |

观察: 5 对不对称，否定拓扑的代数结构在数据层面不完整。

### 5.3 extends 关系（新增类型）

3 条 extends 关系，全部来自 272 号：

- 272 --extends--> 218 [附庸的附庸不是我的附庸——局部依赖原则]
- 272 --extends--> 069 [递归拓扑蜂群局部依赖涌现全局DAG]
- 272 --extends--> 005 [否定之否定精确化——边有效性标记变化]

观察: extends 是 273 号之前引入的关系类型，仅 272 号使用。与 depends_on 的语义区分：extends 表示"在其基础上扩展"而非"需要其存在"。
