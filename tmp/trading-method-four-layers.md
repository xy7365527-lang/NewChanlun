# 四层降成本递归操盘方法

**版本**: v1.0
**状态**: 生成态
**日期**: 2026-02-27

---

## 0. 总述

缠论第三层回答"怎么把成本降到零以下"。本文形式化四层降成本递归——配置层、边层、角内轮动层、标的内操作层——的利润传递机制、仓位函数、止损规则、盘整态处理，以及与已有 `backtest.py` 的对接接口。

核心命题：**每一层的一卖利润向下一层传递，压低下一层的持仓成本。配置层保证整个递归的方向是顺风的。**

四层结构：

```
L0 配置层：配置空间买卖点 → 全局 risk-on/risk-off
  └─ L1 边层：比价线买卖点 → 确定目标角
       └─ L2 角内轮动层：角内比价线买卖点 → 标的切换
            └─ L3 标的内操作层：标准缠论多级别联立 → 短差降成本
```

## 1. 利润传递机制

### 1.1 定义

层 L 的一卖利润传递给层 L+1，压低层 L+1 的持仓成本。传递方向是**从上到下**（从宏观到微观），与区间套下钻方向一致。

| 传递路径 | 语义 | 机制 |
|----------|------|------|
| L0→L1 | 配置层一卖 → 边层成本缓冲 | 配置空间一卖时全局减仓，释放的已实现利润作为边层操作的"免费子弹" |
| L1→L2 | 边层一卖 → 角内轮动成本缓冲 | 比价线一卖退出角时，角级别已实现利润覆盖角内下一次轮动的入场成本 |
| L2→L3 | 角内轮动 → 标的内成本缓冲 | 标的切换时，前一个标的的已实现利润覆盖下一个标的的入场成本 |
| L3 内部 | 标的内短差 → 成本归零/挣股票 | 标准缠论多级别联立，次级别买卖点做短差（backtest.py 已实现） |

### 1.2 精确公式

设层 L 在时刻 t 的操作产生已实现利润 `profit(L, t)`，层 L+1 在时刻 t 的持仓成本基础为 `cost(L+1, t)`，持仓规模为 `size(L+1, t)`。

**利润传递公式**：

```
cost(L+1, t) = cost(L+1, t-1) - profit(L, t) / size(L+1, t)
```

其中：
- `profit(L, t)` = 层 L 在时刻 t 的一卖已实现利润（绝对金额）
- `size(L+1, t)` = 层 L+1 当前持仓的单位数量
- 当 `cost(L+1, t) ≤ 0` 时，层 L+1 进入成本归零/挣股票阶段

### 1.3 传递的离散性

配置空间是离散的（27种配置 × 有限递归层级），因此利润传递不是连续流，而是**事件驱动**的：

- L0 传递事件：配置空间一卖确认时触发（极性指数走势类型完成）
- L1 传递事件：比价线一卖确认时触发（边上走势类型完成）
- L2 传递事件：角内标的切换时触发（角内比价线买卖点确认）
- L3 内部传递：次级别买卖点确认时触发（backtest.py `_check_short_diff` 已实现）

### 1.4 传递的单向性与累积性

利润只向下传递，不向上回流。每一层的成本基础只能被上层利润压低，不能被下层操作影响。这保证了：
- 上层决策不受下层操作噪音干扰
- 成本归零是单调递减过程（在同一持仓周期内）

## 2. 仓位函数

### 2.1 配置层仓位 f(P)

配置层仓位是极性指数 P(v) 的函数。极性指数 = 现金顶点的净流入计数 net($)（v4 §5.5，`transition_topology.py:129` `net_cash` 属性）。

```
P(v) = net($) = Σ sign(X/$)，X ∈ {E, C, R}
P(v) ∈ {-3, -2, -1, 0, +1, +2, +3}
```

仓位函数（做多视角，即资本从现金流出 = risk-on）：

```
f(P) : {-3,...,+3} → [0, 1]

P = -3  →  f = 1.0   （现金全面贬值，三类资产同涨，满仓）
P = -2  →  f = 0.7   （两类资产涨一类盘整，重仓）
P = -1  →  f = 0.4   （单类资产涨或轮动，中仓）
P =  0  →  f = 0.1   （全局均衡，底仓观察）
P = +1  →  f = 0.0   （单类资产跌，空仓或对冲）
P = +2  →  f = 0.0   （两类资产跌，空仓）
P = +3  →  f = 0.0   （流动性危机，全面空仓）
```

**离散性说明**：P(v) 只取 7 个整数值，仓位函数是离散映射，不是连续函数。上表中的具体数值是**参考值**，实际参数需要回测标定。核心约束是单调性：P 越负（现金越弱），仓位越高。

**做空视角**：若 `allow_short = True`，P > 0 时可建立空头仓位，仓位函数关于 P=0 对称翻转。

### 2.2 边层仓位 g(edge_state, flow_direction)

边层仓位是边状态和流转方向的函数。

输入：
- `edge_state`：比价线当前走势状态（趋势上涨/趋势下跌/盘整）
- `flow_direction`：资本流转方向（从 StrokeFlow 读取，v4 §7.2）

```
g(edge_state, flow_direction) : {趋势, 盘整} × {流入, 流出, 均衡} → [0, 1]

(趋势上涨, 流入目标角)  →  g = 1.0  （边确认 + 流向确认，满配该角）
(趋势上涨, 均衡)        →  g = 0.5  （边确认但流向不明确，半配）
(盘整, 流入目标角)       →  g = 0.3  （流向确认但边未确认，轻配）
(盘整, 均衡)             →  g = 0.1  （双不确认，底仓）
(趋势下跌, 流出目标角)   →  g = 0.0  （反向，不配）
```

边层仓位受配置层仓位约束：`actual_edge_position = f(P) × g(edge_state, flow_direction)`。

### 2.3 角内轮动仓位 h(relative_strength)

角内标的之间的仓位分配由相对强度决定。

输入：角内标的 A、B 的比价线走势方向。

```
h(A/B) : {A强于B, B强于A, 均衡} → 分配权重

A/B 趋势上涨  →  A 权重高，B 权重低
A/B 盘整      →  均配
A/B 趋势下跌  →  B 权重高，A 权重低
```

角内轮动仓位受边层仓位约束：角内所有标的的仓位之和 = 边层分配给该角的仓位。

### 2.4 标的内仓位

标准缠论仓位管理，已在 `backtest.py` 中实现：
- 大级别买卖点决定方向和入场
- 次级别买卖点做短差（`position_fraction` 控制机动资金比例，默认 1/10）
- `PositionPhase` 追踪成本阶段

## 3. 配置空间止损

### 3.1 止损的缠论定义

止损 = 买入程序的判断条件被否定（`backtest.py:425` 注释："退出条件 = 买入程序的判断条件被否定，不是价格偏离度量"）。这一原则在四层中一致适用。

### 3.2 各层止损条件

| 层 | 买入条件 | 止损 = 买入条件被否定 |
|----|---------|---------------------|
| L0 配置层 | 极性指数走势类型出现一买（net($) 从正转负的背驰点） | 极性指数走势类型被否定：一买后极性指数创新低（趋势延续而非反转） |
| L1 边层 | 比价线走势类型出现一买（目标角比价线背驰） | 比价线走势类型被否定：一买后比价线创新低 |
| L2 角内轮动 | 角内比价线出现买点（标的 A 相对 B 走强的买点） | 角内比价线走势类型被否定：A/B 比价创新低 |
| L3 标的内 | 标准缠论买卖点（type1/type2/type3） | 标准缠论退出条件（backtest.py `_check_exit_condition` 已实现） |

### 3.3 止损的层级传递规则

**低层止损不一定触发高层止损。** 判断标准：低层止损是否否定了高层的买入条件。

```
L3 止损（标的内走势被否定）：
  → 不触发 L2：标的 A 走势被否定不等于 A/B 比价走势被否定
  → 操作：L2 层检查角内比价，可能切换到标的 B

L2 止损（角内比价被否定）：
  → 不触发 L1：角内轮动失败不等于边层比价走势被否定
  → 操作：L1 层检查边层比价，可能切换到另一个角

L1 止损（边层比价被否定）：
  → 不触发 L0：单条边的走势被否定不等于配置空间走势被否定
  → 操作：L0 层检查极性指数，可能切换到另一条边

L0 止损（配置空间走势被否定）：
  → 全局退出：所有下层仓位清零
  → 这是系统性风险防护（220号谱系：风控是买卖点系统的内在属性）
```

**唯一的强制级联**：L0 止损 → 全层清仓。因为配置层走势被否定意味着全局方向判断错误，所有下层操作的前提（顺风）不再成立。

### 3.4 止损与利润传递的交互

止损触发时，该层的未实现利润不传递给下层。只有已实现利润（一卖确认后）才参与传递。这保证了利润传递的确定性——传递的是已锁定的利润，不是浮盈。

## 4. 全局盘整态处理

### 4.1 盘整态识别

全局盘整态 = 配置 #3（v4 §5.4）：三条独立边全部为 0，即 E/$ = 0, C/$ = 0, R/$ = 0。

```python
# transition_topology.py 中的表示
Config(equity=0, commodity=0, real_estate=0)  # 配置 #3
# net_cash = 0，极性指数 = 0
```

盘整态的走势结构识别：极性指数在配置空间形成中枢（P(v) 在 {-1, 0, +1} 之间震荡，无方向性突破）。

### 4.2 盘整态策略

```
配置空间中枢形成（极性指数盘整）：
  → L0 仓位：f(0) = 0.1（底仓观察）
  → L1-L3：仅在角内部做标的内操作，不依赖全局流转方向
  → 短差程序正常运行（标的内操作不依赖配置层方向）
```

### 4.3 盘整态的退出

配置空间中枢突破 = 极性指数走势类型完成盘整后出现三买或三卖：

```
三买（极性指数向下突破中枢后回抽不破 ZD）：
  → 全局 risk-on 重新启动
  → L0 仓位按 f(P) 重新计算

三卖（极性指数向上突破中枢后回抽不破 ZG）：
  → 全局 risk-off
  → L0 仓位降至 0（或建立空头）
```

### 4.4 长期盘整态

v4 §7 例外条款："全局盘整态下可能长期无背驰信号。退回角内操作或空仓等待——不是框架失效，是全局流场在该层级上没有方向。"

长期盘整态下，四层递归退化为两层：
- L2 角内轮动：基于角内比价线的相对强弱
- L3 标的内操作：标准缠论

L0 和 L1 处于等待状态，不产生信号也不产生利润传递。

### 5.3 四层编排器接口草案

```python
@dataclass(frozen=True, slots=True)
class FourLayerConfig:
    """四层递归配置。"""
    config_level: int          # L0 配置空间递归层级
    edge_level: int            # L1 边层递归层级
    rotation_level: int        # L2 角内轮动递归层级
    operation_level: int       # L3 标的内操作级别
    short_diff_level: int | None  # L3 短差级别
    position_table: dict[int, float]  # P(v) → 仓位映射
    allow_short: bool = False
    initial_capital: float = 100_000.0


@dataclass(frozen=True, slots=True)
class LayerState:
    """单层状态快照。"""
    layer: int                 # 0-3
    cost_basis: float          # 当前成本基础
    realized_profit: float     # 已实现利润（可传递给下层）
    phase: PositionPhase       # 成本阶段
    signal: str | None         # 当前信号（buy/sell/hold）


@dataclass(frozen=True, slots=True)
class FourLayerSnapshot:
    """四层递归状态快照。"""
    layers: tuple[LayerState, LayerState, LayerState, LayerState]
    config_id: int             # 当前配置编号（1-27）
    polarity: int              # 极性指数 P(v)
    total_position: float      # 总仓位比例
```

### 5.4 PositionPhase 的四层扩展

当前 `PositionPhase` 只追踪 L3 的成本阶段。四层递归中，每一层都有独立的成本阶段：

```
L0 成本阶段：配置层累计利润 vs 配置层入场成本
L1 成本阶段：边层累计利润（含 L0 传递）vs 边层入场成本
L2 成本阶段：轮动累计利润（含 L1 传递）vs 轮动入场成本
L3 成本阶段：标的内累计利润（含 L2 传递）vs 标的内入场成本（已有）
```

每层独立追踪 `PositionPhase`，但上层利润传递会加速下层的 `COST_REDUCTION → COST_ZERO → EARN_SHARES` 转换。

## 6. 风控（220号谱系）

### 6.1 风控 = 买卖点系统的内在属性

引用 `fengkong.md`：风控不是独立模块，是买卖点系统的内在属性。四层递归中，每一层的止损就是该层的风控。不存在独立于买卖点之外的"风控模块"。

### 6.2 四层风控层级

```
L0 风控 = 配置层止损 = 系统性风险防护
  极性指数走势被否定 → 全层清仓
  这是最高层级风控，防护的是全局方向判断错误

L1 风控 = 边层止损 = 角级别风险防护
  比价线走势被否定 → 退出该角，不影响其他角
  防护的是单条流转路径的判断错误

L2 风控 = 角内轮动止损 = 标的选择风险防护
  角内比价被否定 → 切换标的，不影响角级别判断
  防护的是角内相对强弱判断错误

L3 风控 = 标的内止损 = 单标的风险防护
  走势类型被否定 → 退出该标的（backtest.py 已实现）
  防护的是单标的走势判断错误
```

### 6.3 风控的递归性

高层风控覆盖低层：L0 止损触发时，L1-L3 的所有仓位强制清零，无论低层状态如何。这不是"额外的风控规则"，而是逻辑必然——配置层走势被否定意味着"全局方向是顺风的"这一前提不再成立，所有基于此前提的下层操作失去存在基础。

低层风控不影响高层：L3 止损不触发 L0 止损。单标的走势被否定是局部事件，不否定全局方向判断。

## 结果包六要素

### 1. 结论

四层降成本递归的完整形式化：利润传递公式 `cost(L+1, t) = cost(L+1, t-1) - profit(L, t) / size(L+1, t)`；离散仓位函数 `f(P)` 基于极性指数的 7 值映射；止损 = 各层买入条件被否定，唯一强制级联是 L0→全层清仓；盘整态退化为 L2+L3 两层操作；与 backtest.py 的对接通过四层编排器实现，L3 层完全复用现有代码。

### 2. 定义依据

- **利润传递**：缠师第9课"比价关系的变动也可以构成一个买卖系统"→ 比价线一卖产生利润 → 利润可传递给下层操作
- **仓位函数**：v4 §5.5 极性指数 net($) 定义（`transition_topology.py:129`）；v4 §5.4 27种配置穷尽分类
- **止损定义**：220号谱系概念1"退出条件 = 买入程序的判断条件被否定"（`backtest.py:425`）
- **风控内在性**：`fengkong.md` "风控不是独立模块，是买卖点系统的内在属性"
- **盘整态**：v4 §7 例外条款"全局盘整态下退回角内操作或空仓等待"
- **短差程序**：220号概念3，`backtest.py:450` `_check_short_diff`

### 3. 边界条件

- **翻转条件1**：若配置空间在目标递归层级上不完整（K4 退化为 K3 子图），L0 层信号不可用，四层退化为三层或两层
- **翻转条件2**：若极性指数走势类型处于生成态（未完成），L0 仓位函数的输入不确定，应使用保守值 f(0)
- **翻转条件3**：仓位函数 f(P) 的具体参数值需要回测标定，本文给出的是结构约束（单调性），不是最优参数
- **翻转条件4**：利润传递公式假设各层操作时间尺度分离（L0 远慢于 L1 远慢于 L2 远慢于 L3），若时间尺度重叠，传递语义需要重新定义

### 4. 下游推论

- backtest.py 的 `BacktestEngine` 可作为 L3 层引擎直接复用，无需修改
- 四层编排器需要消费 `transition_topology.py` 的 `Config` 和 `net_cash` 作为 L0 输入
