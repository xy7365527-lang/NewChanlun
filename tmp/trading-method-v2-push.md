# 全球资本流转拓扑：操盘方法

Global Capital Flow Topology: Operating Method

本体论回答"世界由什么构成"。文档二回答"在什么位置操作"。
本文档回答"怎么把成本降到零以下"。

核心命题：缠论的降成本递归在四个层级上同构地运行。每一层的操作完全一致——买点进、卖点出、利润向上传递。四层叠加后，全局持仓成本被压到零以下。

───────────
一、降成本递归的本质

1.1 单标的降成本（缠论标准操作）

一买进场 → 持有到一卖出部分 → 出掉的利润覆盖剩余仓位的成本 → 剩余仓位成本为零或负 → 这部分仓位是白送的。然后在次级别的每个买卖点上重复：次级别一买加仓、次级别一卖减仓，每次操作都在降低整体成本。

级别越多，递归越深，成本压得越低。

1.2 降成本的前提

降成本递归是正期望的，当且仅当你在正确的方向上。如果你做多一个正在失血的资产，级别再多你也降不了成本——每次次级别反弹都比上一次弱，一卖出掉的利润不够覆盖一买加的仓位的亏损。

方向对 = 降成本递归收敛。方向错 = 降成本递归发散。

1.3 四层结构保证方向

四层中的每一层都对下一层的方向提供结构性保证：

配置层保证边层方向——配置空间上涨走势中，独立边的上涨段系统性地比下跌段更长、更强。
边层保证角内方向——独立边确认资本流入某角时，该角内标的的上涨系统性地有资本流入支撑。
角内保证板块方向——角内比价确认资本流入某板块时，该板块的标的系统性地有板块层面的资本流入。
板块保证标的方向——板块比价确认某标的跑赢时，该标的的上涨不是孤立的。

每一层不是绝对保证——是系统性地提高下一层操作的正期望。四层叠加后，最底层操作的方向正确概率被系统性地抬高。

二、四层降成本递归

2.1 第三层：标的内操作（缠论标准）

这是最底层，也是唯一直接产生交易的层。

在确定的标的上，用多级别联立操作降成本。支配级别确认方向，次级别找买卖点，更小级别精确进出。

一买进场，一卖出部分，利润覆盖剩余成本。次级别的每个买卖点上做加减仓——次级别一买加仓，次级别一卖减仓。每一轮操作都在压低持仓成本。

这就是缠师讲的标准操作。本框架不改变它，只是把它嵌入更大的递归中。

2.2 第二层：角内轮动

一个标的的走势终结了（支配级别上出现背驰，一卖确认），但上层信号没变——资本仍然在流入这个角。

你不退出角。你在角内换标的。

具体操作：标的A出现一卖 → 兑现利润 → 在角内找下一个出现一买的标的B（文档二 §四的板块/标的选择）→ 用A的利润作为B的入场资金。

效果：角级别的仓位保持甚至增加，但具体标的已经换了。A的利润直接补贴了B的入场成本。如果A赚了30%，B的入场成本就被补贴了30%。

多次轮动后，角级别的持仓成本可以降到负——你拿着一堆标的，每一个的入场成本都被之前标的的利润覆盖了。

角内轮动的入口：标的层面的一卖 + 角层面没有一卖。
角内轮动的出口：角层面出现一卖（独立边的背驰确认）。

2.3 第一层：跨角轮动

角级别的走势终结了——独立边出现背驰，一卖确认。配置发生转换。

你减仓当前角，但不一定全部变现金。转换拓扑告诉你下一个配置可能是什么（文档二 §五）。你在转换拓扑给出的可能性中等买卖点——哪条边先出一买，资本就在流向那个角。

具体操作：角A的独立边出现一卖 → 减仓角A，兑现角级别利润 → 等待另一条独立边出现一买 → 用角A的利润进入角B。

效果：全局配置级别的持仓成本在下降。每次配置转换，你从失血的角退出、进入吸血的角，利润从前一个角带到下一个角。

跨角轮动的入口：独立边的一卖 + 配置空间没有一卖。
跨角轮动的出口：配置空间出现一卖。

跨角轮动也包含跨国家轮动。同一角内，如果跨国同类边出现买卖点（文档二 §四第三步），你可以把一个国家的利润带到另一个国家的同类资产。USD/CNY的买卖点跟跨国同类边的买卖点共振时，跨国轮动的确定性最高。

2.4 第零层：配置层操作

配置空间本身有走势类型和买卖点（文档二 §三）。

配置空间一买 = 全局risk-off模式力度衰竭 = 最大级别的入场信号。此时开始下钻——通过横向区间套找目标角、目标国家、目标板块、目标标的。

配置空间一卖 = 全局risk-on模式力度衰竭 = 最大级别的减仓信号。此时开始收缩——逐层退出，利润回收到现金。

但你不需要等配置空间一卖才开始减仓——文档二 §六已经说了，底层的一卖是最早的预警。你的减仓是从底层一卖开始的，逐层向上传递，到配置空间一卖时仓位已经大幅减轻。

三、四层递归边界条件完整枚举

v1 描述了四层递归的正常运行。本节枚举每一层的启动条件、终止条件和异常退出条件。

3.1 形式化符号

设四层从上到下为 L₀（配置层）、L₁（跨角/边层）、L₂（角内轮动）、L₃（标的内操作）。

对每一层 Lₖ，定义：
- entry(Lₖ)：进入该层的条件
- exit_normal(Lₖ)：正常退出条件
- exit_abort(Lₖ)：异常退出（止损）条件
- state(Lₖ) ∈ {INACTIVE, ACTIVE, SUSPENDED}
  - INACTIVE：该层未启动
  - ACTIVE：该层正在运行
  - SUSPENDED：该层的上层已退出，该层暂停等待新的上层入口

3.2 L₀ 配置层

entry(L₀)：配置空间出现一买（极性指数 S 的下跌走势背驰终结）。
  前置：配置空间在该支配级别上有已确认的下跌走势类型。
  触发：累积面积 A 后段 < 前段（背驰确认）。

exit_normal(L₀)：配置空间出现一卖（S 的上涨走势背驰终结）。
  触发：A 后段 < 前段（上涨力度衰竭）。
  效果：所有下层进入 SUSPENDED，等待新的 entry(L₀)。

exit_abort(L₀)：配置空间一买被否定。
  触发：S 跌破一买前的低点（配置空间的走势结构被破坏）。
  效果：全面清仓，所有下层强制 INACTIVE。

状态转换图：
```
INACTIVE --[entry(L₀)]--> ACTIVE --[exit_normal(L₀)]--> INACTIVE
                              |
                              +--[exit_abort(L₀)]--> INACTIVE
```

L₀ 无 SUSPENDED 状态——它是最高层，没有上层。

3.3 L₁ 跨角/边层

entry(L₁)：某条独立边出现一买，且 state(L₀) = ACTIVE。
  前置：L₀ 已确认方向（配置空间处于上涨走势或盘整中有方向）。
  触发：独立边 e 的下跌走势背驰终结 → 资本流向该角。

exit_normal(L₁)：当前角的独立边出现一卖，但 state(L₀) = ACTIVE。
  效果：减仓当前角 → 进入跨角轮动 → 等待另一条独立边一买。
  注意：L₁ 的正常退出不是终止，是切换——从角A退出进入角B。L₁ 的真正终止是 L₀ 退出。

exit_abort(L₁)：当前角的独立边一买被否定。
  触发：该独立边跌破一买前的中枢下沿。
  效果：全部退出该角。L₂、L₃ 强制 INACTIVE。
  L₁ 本身回到 ACTIVE（仍在跨角轮动中），等待新的独立边一买。

SUSPENDED 条件：state(L₀) 变为 INACTIVE。
  效果：L₁ 暂停跨角轮动，持有当前仓位但不新开角。等待新的 entry(L₀)。

状态转换图：
```
INACTIVE --[entry(L₁)]--> ACTIVE --[exit_normal: 角切换]--> ACTIVE（换角）
                              |
                              +--[exit_abort(L₁)]--> ACTIVE（等新角）
                              |
                              +--[L₀ exit]--> SUSPENDED --[new entry(L₀)]--> ACTIVE
                                                  |
                                                  +--[L₀ abort]--> INACTIVE
```

3.4 L₂ 角内轮动

entry(L₂)：角内某标的/板块的比价线出现一买，且 state(L₁) = ACTIVE 在该角。
  前置：L₁ 已确认该角是当前的目标角。
  触发：板块/标的比价线的一买确认。

exit_normal(L₂)：当前标的出现一卖，但该角的独立边没有一卖。
  效果：兑现利润 → 在角内寻找下一个一买标的 → 轮动。
  注意：与 L₁ 类似，正常退出是切换（换标的），不是终止。

exit_abort(L₂)：当前标的的入场买点被否定。
  触发：标的比价线跌破买点前的结构支撑位。
  效果：退出该标的，在角内等下一个买点。

SUSPENDED 条件：state(L₁) 退出该角（L₁ 正常退出做角切换或 L₁ 止损）。
  效果：L₂ 暂停角内轮动。如果 L₁ 的角切换回到同一个角（罕见但代数上可能），L₂ 恢复。

状态转换图：
```
INACTIVE --[entry(L₂)]--> ACTIVE --[exit_normal: 标的切换]--> ACTIVE（换标的）
                              |
                              +--[exit_abort(L₂)]--> ACTIVE（等新标的）
                              |
                              +--[L₁ exit 该角]--> SUSPENDED
```

3.5 L₃ 标的内操作

entry(L₃)：在目标标的上，纵向区间套确认入场点，且 state(L₂) = ACTIVE。
  前置：横向区间套已锁定标的，纵向区间套已收窄到可执行的买点。
  触发：标的在支配级别的一买/二买/三买确认。

exit_normal(L₃)：标的在支配级别出现一卖。
  效果：减仓或清仓该标的。利润传递给 L₂。

exit_abort(L₃)：入场买点被否定。
  触发：标的价格跌破买点对应的结构支撑位（一买的止损 = 一买前低点，三买的止损 = 中枢上沿）。
  效果：止损出场。亏损由上层利润缓冲吸收。

L₃ 无 SUSPENDED 状态——它是最底层的原子操作。L₃ 终止后回到 L₂ 的控制。

3.6 层间关系的三条公理

**公理1（上层覆盖）**：高层止损强制覆盖所有低层。
  exit_abort(Lₖ) → 对所有 j > k，state(Lⱼ) := INACTIVE。
  不需要等低层各自的止损条件触发。大级别走势结构被破坏意味着所有小级别的方向基础不存在了。

**公理2（下层不创造上层入口）**：低层的信号不能替代上层的入口条件。
  L₃ 的一买不能替代 L₂ 的入口（必须有角内比价的买点）。
  L₂ 的利润不能替代 L₁ 的入口（必须有独立边的买点）。
  但：低层信号反向预警上层（文档二 §六）——多个 L₃ 同时出现一卖是 L₂ 走势力度衰竭的预兆。

**公理3（层间传递需要卖出事件）**：利润从低层向高层传递，当且仅当低层发生卖出事件。
  没有卖出就没有传递。持有中的浮盈不参与上层成本计算。

3.7 异常路径枚举

**路径 A：正常全周期**
entry(L₀) → entry(L₁) → entry(L₂) → entry(L₃) → [降成本递归运行] → exit_normal(L₃) → exit_normal(L₂) → exit_normal(L₁) → exit_normal(L₀)

**路径 B：底层止损，上层不受影响**
... → entry(L₃) → exit_abort(L₃) → L₂ 寻找新标的 → entry(L₃) → ...

**路径 C：角级别止损，切换角**
... → entry(L₂) → ... → exit_abort(L₁) → L₂/L₃ INACTIVE → L₁ 等新角 → entry(L₁) → ...

**路径 D：配置层止损，全面清仓**
... → exit_abort(L₀) → 所有层 INACTIVE → 等待新的 entry(L₀)

**路径 E：底层预警触发逐层减仓**
L₃ 多标的同时一卖 → L₂ 减仓 → L₁ 减仓 → L₀ 确认一卖 → 清仓
这是最理想的退出路径——不是止损，是预警驱动的逐层有序撤退。

**路径 F：层间时序错位**
L₁ 的某角独立边出现一卖（L₁ exit_normal），但 L₂/L₃ 仍在该角内持有标的。
处理：L₁ 的退出信号立即传递给 L₂/L₃ → L₃ 不等自身一卖，直接按 L₁ 信号减仓 → 公理1适用。

3.8 SUSPENDED 状态的精确语义

SUSPENDED 不是 INACTIVE。区别：

INACTIVE：该层从未启动或已清仓。重新启动需要完整的 entry 条件。
SUSPENDED：该层有仓位（或有历史利润缓冲），但上层入口条件暂时不满足。

SUSPENDED 层的行为：
- 不新开仓位
- 已有仓位按标的内的止损条件管理（L₃ 的止损仍然有效）
- 如果持有标的出现一卖，可以减仓（利润锁定），但不轮动到新标的
- 等待上层重新 entry 后恢复 ACTIVE

SUSPENDED 的时间上限：如果上层在合理时间内没有重新 entry（配置空间持续盘整），SUSPENDED 层逐步清仓，最终回到 INACTIVE。"合理时间" = 当前 SUSPENDED 层仓位的支配级别的一个完整走势周期。超过这个时间没有新的上层入口，视为方向判断已过期。

四、利润传递的数学结构

4.1 符号系统

设总资金为 K₀（初始资金）。时间离散化为事件序列（买卖点事件）。

在每一层 Lₖ 的第 n 次操作中：
- Cₖ(n)：第 n 次操作的入场成本
- Rₖ(n)：第 n 次操作的退出收益
- Pₖ(n) = Rₖ(n) - Cₖ(n)：第 n 次操作的利润

累积利润：
Πₖ(N) = Σ_{n=1}^{N} Pₖ(n)

累积成本：
Ξₖ(N) = Σ_{n=1}^{N} Cₖ(n) - Σ_{n=1}^{N-1} Rₖ(n)

即：每次入场投入减去之前所有退出回收。Ξₖ(N) 是第 N 次操作时的净投入——如果累积利润足够大，Ξₖ(N) 可以为负（意味着你已经把本金全部收回还有余）。

4.2 单层传递方程

在 L₃（标的内操作），设支配级别走势内有 M 次次级别操作。

初始投入：C₃(1) = W₃ · K₀（W₃ 为该标的的仓位权重）。

第 m 次次级别操作的利润率：rₘ = Pₘ / Cₘ。

次级别一卖减仓比例：qₘ ∈ (0, 1]。

第 m 次操作后的剩余仓位成本：
C₃_remain(m) = C₃(1) · ∏_{j=1}^{m} (1 - qⱼ · (1 + rⱼ) / (1 + rⱼ · (1 - qⱼ)))

简化形式——设每次减仓比例相同（q），每次利润率相同（r）：
C₃_remain(m) = C₃(1) · (1 - q · r / (1 - q + q·r'))^m

其中 r' 是回撤后的实际退出利润率。

更直观的递推形式：

设第 m 步结束后，账面总值为 Vₘ，成本基础为 Bₘ。

B₀ = C₃(1)（初始成本）
V₀ = C₃(1)（初始值等于成本）

第 m 步：次级别一买加仓 δₘ，次级别一卖减仓比例 qₘ。

一买后（持仓增加）：
V_m^+ = Vₘ₋₁ · (1 + ρₘ) + δₘ
B_m^+ = Bₘ₋₁ + δₘ

其中 ρₘ 是从上一个次级别买点到这个次级别买点之间的收益率。

一卖后（部分兑现）：
Vₘ = V_m^+ · (1 + σₘ) · (1 - qₘ)
Bₘ = B_m^+ · (1 - qₘ)
cashₘ = V_m^+ · (1 + σₘ) · qₘ

其中 σₘ 是从加仓点到减仓点的收益率。

降成本条件：cashₘ > δₘ，即每次减仓回收的现金大于加仓投入。

4.3 跨层传递方程

利润从 L₃ 向 L₂ 传递：

当 L₃ 完成一个完整周期（标的 A 从入场到退出），产生利润 P₃(A)。

L₂ 的角内轮动将 P₃(A) 作为下一个标的 B 的入场资金的一部分：

C₃(B) = C₃(A) + P₃(A) - withdrawn
       = R₃(A) - withdrawn

其中 withdrawn 是 L₂ 从 L₃ 利润中提取的部分（如果 L₂ 需要向 L₁ 传递利润）。

通常 withdrawn = 0（L₂ 把全部利润滚入下一个标的），则：

角级别累积净成本：
Ξ₂(N) = C₃(1) - Σ_{n=1}^{N-1} P₃(n)

即初始投入减去所有已兑现的标的利润。当 Σ P₃(n) > C₃(1) 时，Ξ₂(N) < 0——角级别持仓成本为负。

同理，利润从 L₂ 向 L₁ 传递：
Ξ₁(N) = C₂(1) - Σ_{n=1}^{N-1} P₂(n)

从 L₁ 向 L₀ 传递：
Ξ₀(N) = C₁(1) - Σ_{n=1}^{N-1} P₁(n)

4.4 传递链的形式表达

整个四层递归的利润传递可以写成一个嵌套求和：

全局净成本 = K₀ - Σ_{i₀} [Σ_{i₁} [Σ_{i₂} [Σ_{i₃} P₃(i₃, i₂, i₁, i₀)]]]

其中：
- i₀ 索引配置层操作周期
- i₁ 索引第 i₀ 个周期内的角轮动次数
- i₂ 索引第 i₁ 个角内的标的轮动次数
- i₃ 索引第 i₂ 个标的内的次级别操作次数

每个 P₃(i₃, i₂, i₁, i₀) 是一次原子交易的利润。

全局持仓成本为负 ⟺ 四重嵌套求和 > K₀。

4.5 传递效率

定义传递效率 η(Lₖ → Lₖ₋₁) = 实际传递到上层的利润 / 该层总利润。

η < 1 的原因：
- 止损事件消耗利润：exit_abort 导致亏损，抵消之前的利润
- 摩擦成本：交易成本、滑点、税
- 时间损耗：SUSPENDED 期间的机会成本

传递效率的决定因素：
- 方向正确率越高，η 越大（止损越少）
- 层级越高，方向正确率越高（四层保证机制），η 越大
- L₃ 的 η 最低（单标的操作的方向正确率最低），L₁ 的 η 最高（跨角轮动在配置层方向保证下操作）

4.6 传递链的乘法结构

全局传递效率 = η(L₃→L₂) × η(L₂→L₁) × η(L₁→L₀)

若每层 η = 0.7（30%利润被止损和摩擦消耗），全局传递效率 = 0.343。

若每层 η = 0.85（四层保证机制将止损率压低），全局传递效率 = 0.614。

提高 η 的唯一方法是提高方向正确率——这回到了四层保证机制。不是通过减少止损来提高 η（那是放大风险），是通过上层方向保证来减少需要止损的次数。

五、全局盘整期操作空间展开

5.1 全局盘整的精确定义

配置空间盘整 = 极性指数 S 在某个区间 [S_low, S_high] 内反复震荡，配置空间的走势类型为盘整（单个中枢内的震荡）。

全局盘整不等于所有边都在盘整。全局盘整只要求极性指数 S 没有方向——个别独立边可以有方向性走势（一涨一跌对 S 的贡献可以相互抵消）。

5.2 全局盘整期的合法操作空间

按 L₀ 状态分类：

**情形 A：L₀ = INACTIVE（无配置层入口）**

配置空间盘整中没有出现过一买。这是最保守的情形。

合法操作：
- L₁ 不启动（没有配置层方向保证）
- L₂ 不启动
- L₃ 独立运行：在单条边的买卖点上做标的内操作。仓位上限受约束（§八 仓位确定性函数的无配置层项）

这对应 v1 §七 的描述——局部机会，不是全局性操作。

**情形 B：L₀ = SUSPENDED（有历史仓位）**

此前有一个配置层周期运行过，配置层一卖已出但仓位未完全清除（SUSPENDED 态）。

合法操作：
- L₁/L₂ = SUSPENDED：不新开仓，已有仓位按止损管理
- L₃ 在已有标的上继续次级别操作（减仓为主）
- 配置空间如果在盘整中出现新的一买 → L₀ 重新 ACTIVE → 所有下层恢复

**情形 C：L₀ = ACTIVE 但在盘整中枢内**

配置空间一买已确认，但 S 进入中枢震荡。配置层走势类型 = 盘整。

合法操作：
- L₁ 运行受限：只在中枢震荡区间内做买卖（中枢内的次级别操作）
- 中枢内的操作逻辑：中枢下沿附近一买（极性低位），中枢上沿附近一卖（极性高位）
- 本质上是配置空间的次级别降成本操作——在配置空间中枢内做波段

**情形 D：配置空间盘整但个别独立边有方向**

这是最常见的全局盘整情形。

例：E/$ = +, C/$ = -, R/$ = 0 → S = 0（极性中性）但 E-C 之间有明确的资本流转。

合法操作：
- L₁ 可以启动有限版本：只在有明确方向的独立边上操作
- L₂ 在该角内轮动
- L₃ 正常运行
- 但仓位上限低于 L₀ = ACTIVE 的情形（§八）

5.3 全局盘整的转换边界

全局盘整终止的两种方式：

**三买/三卖突破**：S 突破中枢区间 → 配置空间方向确立 → L₀ 进入 ACTIVE。

**中枢扩展**：盘整持续，中枢级别升高。这意味着全局方向在更大级别上未定。操作空间进一步收缩——中枢越大，中枢内的次级别操作级别也越大，操作频率越低。

5.4 全局盘整期的仓位上限

设全局盘整期的最大仓位为 W_max_flat。

W_max_flat = f(共振信号数) × g(独立边方向数)

其中：
- f(0) = W_min（只有标的内买点，最小仓位）
- f(k) 随共振信号数 k 单调递增但有上限 W_ceiling < 1
- g(0) = 1（全盘整态，不加权）
- g(d) 随有方向的独立边数 d 递增

W_ceiling < 1 保证全局盘整期永远不会满仓——没有配置层方向保证时不应承受满仓风险。

精确的 f、g 函数见 §八。

六、止损层级覆盖的精确定理

6.1 止损定义的统一形式

**定理（止损统一形式）**：在层 Lₖ，以买点 B 为入场依据。B 对应一个走势结构 W（W 是产生 B 的那段走势）。止损触发 ⟺ 走势 W 的结构被否定。

"结构被否定"的精确定义：
- 一买的止损：价格跌破 W（下跌走势）的终点（= 一买位置）之前的最后一个中枢的下沿。更严格的止损是跌破一买前的最低点（下跌走势的起点或区间内最低）。
- 二买的止损：价格跌破一买的低点。因为二买的含义是"一买后的回调不破坏新方向"，如果跌破一买，新方向被否定。
- 三买的止损：价格跌回中枢区间内（回到中枢上沿以下）。三买的含义是"中枢突破确认"，跌回中枢 = 突破失败。

6.2 分层止损公理

**公理（高层覆盖）**：exit_abort(Lₖ) 触发时，对所有 j > k，无论 Lⱼ 自身的止损条件是否已触发，Lⱼ 立即执行退出。

直觉：L₁ 止损 = "这个角的方向判断错了"。那么角内的所有标的操作（L₂/L₃）的方向基础已经不存在——不需要等每个标的各自触发止损。

**推论1**：止损执行的时间复杂度是 O(1) 而不是 O(层数)。高层止损直接广播到所有低层，不逐层传递。

**推论2**：高层止损的触发频率低于低层。因为高层走势结构的破坏需要更大的价格变动。四层结构中，L₀ 的止损几乎不触发（配置空间走势的结构破坏需要全球性事件），L₃ 的止损相对频繁（单标的层面的正常波动就可能触发）。

6.3 止损后的恢复路径

L₃ 止损后：回到 L₂ 控制，在角内寻找新的买点标的。利润缓冲 = 之前 L₂ 累积的轮动利润。

L₂ 止损后（角内找不到买点且原标的也止损了）：回到 L₁ 控制，在其他角寻找买点。利润缓冲 = 之前 L₁ 累积的跨角利润。

L₁ 止损后：回到 L₀ 控制，等待新的独立边买点。如果 L₀ 仍然 ACTIVE（配置层方向没变），L₁ 可以重新 entry。

L₀ 止损后：全面清仓，等待。没有利润缓冲（L₀ 是最高层）。这是最坏情况，但也是最罕见的——四层保证机制的目标就是让 L₀ 止损几乎不发生。

6.4 止损与降成本的关系定理

**定理（止损-成本对偶）**：设层 Lₖ 的累积利润为 Πₖ，止损亏损为 Δₖ。
降成本递归在该层仍然有效 ⟺ Πₖ > Δₖ。

即：只要累积利润大于止损亏损，降成本递归就在运行。止损不是降成本的敌人——止损是降成本的安全阀，它切断的是发散方向的亏损，保护的是已累积的利润。

**推论**：在四层保证机制下，高层的 Πₖ / Δₖ 比值系统性地大于低层。因为高层方向更确定（上层保证），止损触发更少（结构更稳定），而利润通过跨角/跨周期轮动持续累积。

七、仓位确定性函数

7.1 共振层数→仓位比例映射

定义共振信号集 S = {s₁, s₂, ..., sₙ}，其中每个 sᵢ 是一个已确认的买点信号，来自不同层级或不同比价线。

**仓位确定性函数**：

W = W_base × ∏_{i=1}^{n} (1 + αᵢ · wᵢ)

其中：
- W_base：基础仓位，由最高层已确认信号决定
- αᵢ ∈ {0, 1}：第 i 个信号是否存在（0 = 未确认，1 = 已确认）
- wᵢ > 0：第 i 个信号的权重

信号集的标准序列：

| 信号 sᵢ | 层级 | 权重 wᵢ | 含义 |
|----------|------|---------|------|
| s₁ 配置层一买 | L₀ | w₁ | 全局方向确认 |
| s₂ 独立边一买 | L₁ | w₂ | 角方向确认 |
| s₃ 派生边共振 | L₁ | w₃ | 方向加强 |
| s₄ 跨国同类边共振 | L₁ | w₄ | 跨国确认 |
| s₅ 货币边共振 | L₁ | w₅ | 汇率方向一致 |
| s₆ 板块比价一买 | L₂ | w₆ | 板块确认 |
| s₇ 标的比价一买 | L₂ | w₇ | 标的确认 |
| s₈ 标的纵向区间套确认 | L₃ | w₈ | 精确入场 |

7.2 W_base 的取值

W_base 由最高层已确认信号决定：

- 有 s₁（配置层一买）：W_base = W_config（配置层基础仓位，如 0.6）
- 无 s₁ 但有 s₂（独立边一买）：W_base = W_edge（边层基础仓位，如 0.3）
- 只有 s₈（标的内买点）：W_base = W_single（单标的基础仓位，如 0.1）

7.3 权重 wᵢ 的约束

所有权重满足：

∏_{i=1}^{8} (1 + wᵢ) ≤ 1 / W_base

这保证即使所有信号同时确认，W ≤ 1（不超过满仓）。

权重的相对大小关系：
w₁ > w₂ > w₃ ≈ w₄ ≈ w₅ > w₆ > w₇ > w₈

即高层信号的权重大于低层——这反映了确定性的层级结构。

7.4 具体数值示例

设 W_config = 0.5, W_edge = 0.25, W_single = 0.08。

| 场景 | 确认信号 | 计算 | 仓位 |
|------|----------|------|------|
| 满共振 | s₁-s₈ 全确认 | 0.5 × (1+0.15)×(1+0.12)×(1+0.06)×(1+0.06)×(1+0.05)×(1+0.04)×(1+0.03)×(1+0.02) | ≈ 0.97 |
| 配置+边 | s₁, s₂, s₈ | 0.5 × 1.15 × 1.12 × 1.02 | ≈ 0.66 |
| 仅边层 | s₂, s₆, s₇, s₈ | 0.25 × 1.12 × 1.04 × 1.03 × 1.02 | ≈ 0.31 |
| 仅标的 | s₈ | 0.08 × 1.02 | ≈ 0.08 |

7.5 仓位函数的性质

**单调性**：每增加一个确认信号，仓位严格递增。
**上界**：W ≤ 1。
**下界**：W ≥ W_single（只要有任何买点就有最小仓位）。
**层级敏感性**：去掉 s₁ 对仓位的影响远大于去掉 s₈。

八、背驰力度与仓位分配量化

8.1 问题：同层多个买点的仓位分配

当同一层出现多个买点时（比如两条独立边同时出一买），§七的仓位确定性函数给出了总仓位 W。本节解决的是 W 在多个同层标的之间的分配。

8.2 MACD衰减比作为权重函数

定义背驰力度比：

d(e) = 1 - A_后(e) / A_前(e)

其中 A_前(e) 和 A_后(e) 分别是边 e 的前一段推动和后一段推动的 MACD 面积。

d(e) ∈ (0, 1)：
- d(e) → 1：后段面积远小于前段，极度背驰，转折确定性最高
- d(e) → 0：后段面积接近前段，弱背驰，转折确定性低

8.3 分配函数

设有 m 条边/标的同时出现买点，背驰力度比为 d(e₁), ..., d(eₘ)。

第 j 个的仓位分配：

w_alloc(eⱼ) = W × d(eⱼ)^γ / Σ_{i=1}^{m} d(eᵢ)^γ

其中 γ ≥ 1 是集中度参数：
- γ = 1：线性分配（与背驰力度成正比）
- γ > 1：向高背驰力度的标的集中（指数越大越集中）
- γ → ∞：全部分配给背驰力度最大的一个

8.4 γ 的选取

γ 的选取依赖于层级：

- L₁（跨角分配）：γ₁ 较小（如 1.5），因为角之间的分散化本身有价值
- L₂（角内标的分配）：γ₂ 较大（如 2.0），因为角内标的的风险同源，集中到最确定的那个
- L₃（标的内加仓分配）：γ₃ = 1（线性），因为同一标的内的不同级别买点是互补的

8.5 跨边力度比较的口径

当比较不同边的 d(e) 时：

同层级内（都是独立边，或都是角内标的比价线）：直接比较 d(e) 即可。因为 d(e) 是无量纲的比值（后段/前段），已经是自归一化的。

跨层级：不直接比较。L₁ 的 d(e) 和 L₃ 的 d(e) 不可比——它们描述的是不同量级的走势结构。仓位分配只在同层内进行。

8.6 力度-仓位的动态更新

d(e) 在走势进行中会变化——后段面积还在累积。操作时使用的 d(e) 是买点确认时刻的快照值。

买点确认后，如果后续走势使得 d(e) 增大（更加背驰），可以在次级别买点加仓时提高分配比例。反之，如果后续走势消解了背驰（新的推动力出现），降低分配。

但初始入场的分配 w_alloc(eⱼ) 在入场时刻锁定，不追溯调整。追溯调整 = 追涨杀跌。

九、跨国轮动特殊性

9.1 跨国轮动的代数分解

跨国同类边 E_i/E_j 不是独立边。它可以分解为：

E_i/E_j = (E_i/$_i) × ($_i/$_j) × ($_j/E_j)

即：i国动产对j国动产的相对表现 = i国动产对i国货币的表现 × 货币对表现 × j国动产对j国货币的表现（的倒数）。

跨国轮动的买卖点出现在 E_i/E_j 上——这是一条独立可观测的比价序列，直接跑缠论。分解是用于诊断的，不是用于操作的。操作只看 E_i/E_j 的买卖点。

9.2 货币边共振条件

当 E_i/E_j 出现一买（i国动产相对j国动产的跌势背驰终结）时，检查货币边 $_i/$_j。

**共振**：$_i/$_j 也出现一买（i国货币相对j国货币的跌势背驰终结）。含义：不仅资产端在反转，汇率端也在支持——i国货币在升值，叠加资产走强，双重利好。

**反向**：$_i/$_j 出现一卖（i国货币在走弱）。含义：资产端的相对走强被汇率损失部分抵消。跨国轮动的净收益 = 资产端收益 + 汇率端收益。如果汇率端为负，净收益被削弱。

**中性**：$_i/$_j 盘整。汇率不构成额外的确认或阻力。

9.3 汇率风险的形式化

定义跨国轮动的总收益率：

r_cross = r_asset + r_fx + r_asset × r_fx

其中：
- r_asset = (E_i/E_j)_exit / (E_i/E_j)_entry - 1 （资产端收益率）
- r_fx = ($_i/$_j)_exit / ($_i/$_j)_entry - 1 （汇率收益率）
- 交叉项 r_asset × r_fx 在两者都不极端时可忽略

汇率风险 = r_fx 的方差对 r_cross 的贡献。

9.4 汇率对冲的结构性条件

在以下条件下，汇率风险可以被结构性对冲（不需要外汇衍生品）：

**条件**：同时在两个国家持有同一角的资产，方向相反。

即：做多 i 国动产 + 做空 j 国动产。此时 r_fx 的影响被两端仓位部分抵消——i 国货币升值对 i 国多头有利，对 j 国空头的本币计价也有利（j 国资产以 j 国货币贬值计价更便宜）。

完美对冲条件：两端仓位等值（以共同货币计）。实际操作中不追求完美对冲——买卖点决定仓位，不是对冲比率决定仓位。

9.5 跨国轮动在仓位函数中的位置

跨国轮动的确定性由以下信号叠加：

- E_i/E_j 的买卖点（跨国同类边信号 s₄）
- $_i/$_j 的买卖点（货币边共振信号 s₅）
- E_i/$_i 和 E_j/$_j 的买卖点（各自国内独立边信号 s₂）

当三者共振时：跨国轮动的确定性最高，仓位函数给出最大权重。
当只有 E_i/E_j 有买点：确定性中等，仓位受限。
当 E_i/E_j 有买点但 $_i/$_j 反向：确定性降低，仓位进一步受限。

十、周期间传递累积效应

10.1 配置层操作周期

一个完整的配置层操作周期 Ω_k：从第 k 次 entry(L₀) 到第 k 次 exit(L₀)。

周期 Ω_k 的总利润：
P₀(k) = Σ [该周期内所有四层操作的净利润]

周期 Ω_k 的入场资金：
K(k) = K₀ + Σ_{j=1}^{k-1} P₀(j) - Σ_{j=1}^{k-1} D(j)

其中 D(j) 是第 j 个周期的提取（如果有的话——从投资账户中取出用于消费的资金）。

如果不提取（D(j) = 0）：
K(k) = K₀ + Σ_{j=1}^{k-1} P₀(j)

10.2 成本为负的数学证明（条件性）

**定理（成本为负的充分条件）**：

若存在 N 使得 Σ_{k=1}^{N} P₀(k) > K₀，则第 N+1 个周期开始时的全局净成本 Ξ₀(N+1) < 0。

证明：
Ξ₀(N+1) = K₀ - Σ_{k=1}^{N} P₀(k) < 0    （由假设直接得出）

此后所有周期的入场资金完全来自之前的利润——初始本金已被完全回收。

**假设条件**（定理成立的前提）：

H1（方向正确率）：每个周期的利润为正的概率 > 0.5。在四层保证机制下，这是合理的——配置层买点是全局方向确认，在该方向上操作的正期望被四层结构保证。

H2（利润率下界）：存在 ε > 0，使得每个盈利周期的利润率 P₀(k)/K(k) ≥ ε。这要求走势结构提供足够的利润空间——即每个配置层走势的幅度大于交易成本和止损损耗。

H3（止损上界）：每个亏损周期的亏损率 |P₀(k)|/K(k) ≤ δ < 1。L₀ 的止损控制亏损不超过本金的 δ 比例。

在 H1-H3 下：

E[P₀(k)] = p · ε · K(k) - (1-p) · δ · K(k) = K(k) · (pε - (1-p)δ)

当 pε > (1-p)δ 时（正期望条件），E[P₀(k)] > 0。

累积利润的期望：
E[Σ_{k=1}^{N} P₀(k)] 随 N 单调递增。

因此存在 N* 使得 E[Σ_{k=1}^{N*} P₀(k)] > K₀。

**注意**：这是期望意义上的。实际路径可能因为连续止损而延迟达到成本为负。但只要正期望条件持续满足（四层保证机制在运行），累积利润最终超过初始本金是概率1的事件（大数定律的推论）。

10.3 复利效应

不提取利润时，K(k+1) = K(k) + P₀(k)。

如果每个周期的利润率近似恒定为 r₀：
K(N) = K₀ · (1 + r₀)^N

这是指数增长。达到成本为负所需的周期数：
N* = ⌈log(2) / log(1 + r₀)⌉

（因为需要 K(N*) ≥ 2K₀，即累积利润 ≥ K₀）

例：r₀ = 0.15（每个配置周期收益15%），N* = ⌈log2/log1.15⌉ = 5 个周期。

10.4 提取策略

如果 D(k) > 0（每个周期提取部分利润），达到成本为负的时间延长。

固定比例提取 D(k) = d · P₀(k)（d ∈ [0, 1)）：

K(k+1) = K(k) + (1-d) · P₀(k)

达到成本为负所需周期数：
N*_d = ⌈log(2) / log(1 + (1-d)r₀)⌉

提取不影响降成本递归的存在性（只要 d < 1），只延长达到的时间。

十一、降成本递归收敛/发散条件形式化

11.1 收敛的定义

降成本递归收敛 ⟺ limₙ→∞ Ξₖ(n) < 0（第 k 层的累积净成本最终为负）。

降成本递归发散 ⟺ Ξₖ(n) 随 n 单调递增（每次操作都在增加净成本——方向错误）。

11.2 单层收敛条件

**定理（单层收敛充要条件）**：L₃（标的内操作）在支配级别走势内收敛 ⟺ 走势方向与操作方向一致。

精确形式化：设操作方向为做多（做空对称）。支配级别走势为上涨走势（至少两个不重叠的向上中枢）。

在上涨走势中：
- 每个次级别买点后的上涨段幅度 > 每个次级别卖点后的回调段幅度（趋势的定义）
- 因此 rₘ > 0 的概率系统性地大于 rₘ < 0 的概率
- 因此 E[Pₘ] > 0
- 因此 Ξ₃(M) 随 M 递减

逆否命题：如果支配级别走势为下跌或盘整，做多方向的降成本递归不收敛——次级别的反弹越来越弱（下跌趋势中）或不确定（盘整中）。

11.3 跨层收敛条件

**定理（跨层收敛的充分条件）**：

若满足以下条件组：
(a) L₀ 处于上涨走势（配置空间方向向上 = 全局 risk-on）
(b) L₁ 在目标角的独立边处于上涨走势
(c) L₂ 的轮动标的中，盈利次数 > 亏损次数
(d) L₃ 在每个标的的支配级别上方向正确

则四层降成本递归全部收敛。

证明思路：
(a) → L₁ 的每个角选择都在正确方向上（配置层上涨 = 有吸血角存在 = 角轮动有正确方向）
(b) → L₂ 在正确的角内操作（角在吸血 = 角内标的系统性上涨）
(c) → L₂ 的累积利润为正
(d) → L₃ 在每个标的上的降成本递归收敛

四层叠加：(d) 保证 L₃ 利润为正 → 传递给 L₂ → (c) 保证 L₂ 利润为正 → 传递给 L₁ → (b) 保证 L₁ 利润为正 → 传递给 L₀ → (a) 保证 L₀ 利润为正。

**关键认识**：(a)-(d) 不是独立条件。(a) 是 (b)-(d) 的结构性保证——配置层方向正确系统性地提高了下层方向正确的概率。这就是四层保证机制的数学内容。

11.4 发散的诊断

降成本递归在某层发散时的信号：

**L₃ 发散信号**：
- 次级别一买后的上涨段越来越短（力度衰竭）
- 次级别一卖后的回调段越来越深（方向在反转）
- 连续两次加仓后止损 → 降成本变成了加码亏损

**L₂ 发散信号**：
- 连续两个标的在角内轮动后亏损
- 角内找不到有效的一买标的（角在失血，所有标的都在跌）

**L₁ 发散信号**：
- 连续两个角的轮动亏损
- 配置空间极性指数 S 持续下降但没有触发 L₀ 止损（还在中枢内）

**L₀ 发散信号**：
- 配置空间一买后，S 没有如预期上升反而持续下降
- 多条独立边同时背驰方向与 L₀ 方向相反

11.5 发散的处理

检测到发散信号 → 不等止损触发就主动减仓。

这不是违反"止损才退出"的原则——这是"预警驱动的有序撤退"（§三路径E）。发散信号本身就是低层一卖的集合。

具体规则：
- L₃ 发散 → 停止加仓，等一卖减仓
- L₂ 发散 → 停止角内轮动，持有仓位等止损或反转
- L₁ 发散 → 减仓到最低，只保留已经成本为负的仓位
- L₀ 发散 → 按止损处理

"只保留成本为负的仓位"——这是降成本递归的核心价值。一旦某个仓位的成本被降到负，它的存在是无风险的（你已经把本金全部收回）。发散只影响成本仍为正的仓位。

11.6 收敛速度

在理想条件下（方向正确、传递效率 η = 1），降成本递归的收敛速度：

Ξₖ(n) = C₀ · exp(-λₖ · n)

其中 λₖ > 0 是第 k 层的衰减常数，取决于：
- 该层每次操作的平均利润率 r̄ₖ
- 操作频率（与走势的支配级别成反比——级别越大，操作越少但每次利润越大）

近似关系：λₖ ∝ r̄ₖ × fₖ

其中 fₖ 是操作频率。

高层（L₀/L₁）：fₖ 低但 r̄ₖ 高（大级别走势的利润率大）
低层（L₂/L₃）：fₖ 高但 r̄ₖ 低（小级别走势的利润率小）

两者的乘积可能在不同层级上量级相近——降成本递归在每一层以相近的"有效速度"收敛。这是四层结构的一个优雅性质：不是某一层特别快或特别慢，而是每一层都以与其级别匹配的速度在降成本。

十二、完整操作周期（扩展版）

12.1 入场阶段

配置空间出现一买 → L₀ ACTIVE → 横向区间套逐层下钻（文档二 §四）→ 确定目标角 → L₁ ACTIVE → 确定目标板块/标的 → L₂ ACTIVE → 标的内纵向区间套精确入场 → L₃ ACTIVE。

此时所有层都在运行。持仓成本 = 入场价格。降成本递归开始。

仓位 = W(s₁, s₂, ..., sₙ) 由当时已确认的信号集决定（§七）。

12.2 持有阶段（降成本递归运行中）

**L₃ 循环**：次级别一买加仓 → 次级别一卖减仓 → 利润压低持仓成本 → 重复。
**L₂ 循环**：标的一卖 → 角内无一卖 → 轮动到新标的 → 利润传递 → 重复。
**L₁ 循环**：角独立边一卖 → 配置无一卖 → 轮动到新角 → 利润传递 → 重复。

三个循环嵌套运行。每个循环的频率不同（L₃ 最快，L₁ 最慢），但逻辑完全一致。

12.3 底层预警阶段

角内多个标的同时出现一卖 → L₂ 发散信号 → 开始减仓。
多条独立边同时出现背驰 → L₁ 发散信号 → 继续减仓。
配置空间累积面积 A 开始衰减 → L₀ 预警 → 仓位已大幅减轻。

12.4 退出阶段

配置空间出现一卖 → L₀ exit_normal → 清除剩余仓位（成本为负的仓位可以选择保留）。

兑现配置层级的利润。进入等待——等下一个配置层一买。

12.5 周期间过渡

第 k 个周期结束后：
- 已兑现利润 = P₀(k)
- 可用资金 = K(k) + P₀(k) - D(k)
- 等待 entry(L₀)

等待期间：
- 可以做单标的操作（L₃ 独立运行，轻仓）
- 不做配置层级操作

12.6 多周期后的状态

N 个周期后：
- 如果 Σ P₀(k) > K₀：全局成本为负，后续操作无本金风险
- 如果有部分仓位在各周期中持续保留（成本为负的"永久仓位"）：这些仓位是历史利润的结晶

十三、定位

降成本递归是缠论操盘方法在全球资本流转框架中的自然延伸。

缠师的降成本操作在单标的上运行。本框架把同一个操作扩展到四个层级——标的内、角内轮动、跨角轮动、配置层操作——每一层的逻辑完全一致：买点进、卖点出、利润向上传递。

v2 在 v1 的基础上完成了：
1. 四层递归的边界条件完整枚举——每层的启动、终止、异常退出条件，层间关系的三条公理
2. 利润传递的数学结构——嵌套求和、传递效率、乘法结构
3. 全局盘整期的操作空间——四种情形的合法操作边界
4. 止损层级覆盖的精确定理——统一形式、分层公理、恢复路径
5. 仓位确定性函数——共振层数→仓位的显式映射
6. 背驰力度与仓位分配——MACD衰减比→权重函数
7. 跨国轮动特殊性——货币边共振条件、汇率风险形式化
8. 周期间传递累积——成本为负的条件性证明
9. 降成本递归收敛/发散条件——单层充要条件、跨层充分条件、发散诊断

四层叠加不是四种不同的策略。它是同一个操作——降成本递归——在不同层级上的同一种表现。区间套已经统一了"选什么"（横向）和"什么时候"（纵向）。降成本递归统一了"怎么操作"——在每个层级上都是买点进、卖点出。

最终产出：全局持仓成本为负。之后的仓位是白送的。
