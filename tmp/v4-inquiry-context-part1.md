## 关键定义文件摘要

### 等价关系（dengjia.md）
- 等价对条件：可比性（重叠交易窗口）、非退化（比价非常数）、流动性（充足市场深度）
- 数学性质：不满足自反性和传递性，严格说是"可比较关系"
- 本体论降格（025号谱系）：等价关系是筛选条件，不是本体关系
- 注意：当前定义中没有"级别依赖"的概念——v4 §2.5 引入的"两个资产在级别L上等价"是新增语义

### 比价关系（bijia.md）
- 核心：比价变动构成独立买卖系统（第9课）
- 不变量：IR-1对称性、IR-2独立性、IR-3完备性
- 比价K线上运行完整缠论管线

### 流转关系（liuzhuan.md）
- 四矩阵K4图上的有向流场
- 顶点流量 net(V) = Σ flow(eᵢ, V)
- 共振判定：|net(V)| ≥ 2
- 守恒约束：Σ net(V) = 0（加法形式）
- 注意：v4 §2.3 说"严格的守恒是乘法形式"，但 liuzhuan.md 用的是加法守恒。这是一个潜在不一致。

### 级别递归（level_recursion.md）
- 级别 = 递归层级 level_id（自然数，从0开始）
- Move[0] = Segment（归纳基底）
- 口径A（递归级别）是唯一正式路径，口径B（TF级别）不使用
- 递归终止：Move[k] < 3 时停止

## 关键代码摘要

### equivalence.py
- EquivalencePair: frozen dataclass (sym_a, sym_b, category)
- validate_pair(): 三层退化检测（CV预筛 → 笔力度 → MACD动力）
- make_ratio_kline(): A/B 的 OHLCV 除法
- 注意：当前代码没有"级别依赖的等价关系"概念——validate_pair 只检查数据质量，不检查走势完成状态

### capital_flow.py
- FlowDirection: A_TO_B / B_TO_A / EQUILIBRIUM
- StrokeFlow: 单笔资本流转（方向+力度）
- strokes_to_flows(): 笔序列→流转序列映射
- 注意：当前代码只处理单边（pair-level），没有K4关系层的实现

## 已知的 v4 与现有定义/代码的潜在不一致

1. liuzhuan.md 用加法守恒 Σnet(V)=0，v4 §2.3 说严格守恒是乘法形式
2. dengjia.md 没有级别依赖的等价关系概念，v4 §2.5 引入了这个
3. equivalence.py 的 validate_pair 不检查走势完成状态
4. capital_flow.py 没有 log-MACD 实现
5. liuzhuan.md 的共振判定用 net(V) 整数计数，v4 的配置分类用三态(+/–/0)——两者的关系未显式化
