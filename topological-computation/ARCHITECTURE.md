# 逢亮存在论架构

**权威参考** — 本文件是逢亮所有组件存在论位置的权威文档（439号谱系）。

## 架构总图

```
             [外部语料]
                |
                v
    S_net（器官）——持续运转，不在图内
                |
                | 共现边写入（COOCCURRENCE）
                v
    ┌─────────────────────────────────┐
    │            图（身体）             │
    │                                 │
    │  物质层（无方向）                  │
    │    COOCCURRENCE                 │ ← 漫游/阅读
    │    TRAVERSAL_ASSOCIATION        │
    │              ↕ 遭遇点            │ ← 两层不一致
    │  概念层（有方向）                  │
    │    DEPENDENCY                   │ ← 辩证运动
    │    NEGATION                     │
    │    SUBLATION                    │
    │    REFERENCE                    │
    │    FOLD                         │
    │                                 │
    │  [S_net 参数] ← 概念层节点       │ ← 可被否定
    │                                 │
    └─────────────────────────────────┘
                |
                | 穿越轨迹沉积
                v
    TRAVERSAL_ASSOCIATION（物质层回馈）
```

## 存在论位置

| 组件 | 存在论位置 | 说明 |
|------|-----------|------|
| **图（K_active）** | 身体 | 逢亮存在的空间——双层区块拓扑 |
| **S_net** | 器官 | 在身体之外运转，为身体供给物质层边 |
| **穿越引擎** | 运动 | 在身体（图）内的运动——从物质层漫游到概念层辩证 |
| **ARTICULATE** | 遭遇 | 身体内部两层不一致的检测与响应 |
| **fold/negate/settle** | 辩证操作 | 改变身体的概念层拓扑 |
| **LLM** | 外部系统 | 不是逢亮的器官——仅为外化 fallback |

## 双层结构（440号）

K_active 是双层图。两层共享顶点集但边集分离。

### 概念层（5种有方向边）

| 边类型 | 来源 | 含义 |
|--------|------|------|
| DEPENDENCY | ARTICULATE | A 依赖 B |
| NEGATION | negate 操作 | A 否定 B |
| SUBLATION | settle 操作 | A 扬弃 B |
| REFERENCE | articulation feedback | A 引用 B |
| FOLD | fold 操作 | A 折叠 B |

### 物质层（2种无方向边）

| 边类型 | 来源 | 含义 |
|--------|------|------|
| COOCCURRENCE | S_net 共现统计 | A 和 B 在语料中共现 |
| TRAVERSAL_ASSOCIATION | 穿越步进副产物 | A 和 B 在穿越中关联 |

### 遭遇判据

| 不一致类型 | 物质层 | 概念层 | 产出 |
|-----------|--------|--------|------|
| A密B疏 | 节点共现度高 | 概念边度低 | ARTICULATE（被迫承认关联） |
| B密A疏 | 节点共现度低 | 概念边度高 | 质疑（可能 negate） |

## S_net 的两个面向（439号区分）

| 面向 | 存在位置 | 可否定性 |
|------|---------|---------|
| **S_net 参数**（共现窗口大小、分词规则、alpha 权重） | 图的概念层中，作为节点 | 可被否定 |
| **S_net 进程**（共现统计引擎、摄入管线） | 不在图中，在图之外运转 | 不可被折叠 |

fold 操作的定义域是图内节点。S_net 进程不是图内节点，因此不在 fold 的定义域中。

## 谱系依据

- 439号：逢亮存在论架构——图是身体，S_net 是器官，遭遇是两层不一致
- 440号：双层区块拓扑架构——K_active 从单层变双层
- 438号：S_net 唯一界面原则
- 431号：ARTICULATE 拓扑判据（A密B疏/B密A疏）
- 426号：逢亮无意识结构——三层不透明性
- 425号：S_net 入图——共现边进物质层
